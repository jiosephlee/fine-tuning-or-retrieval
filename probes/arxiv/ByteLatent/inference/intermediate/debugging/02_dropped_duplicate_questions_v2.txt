question: Under a fixed inference budget, if BLT uses longer average patches, which part of the model can be made larger with the saved compute?
answer: global latent transformer
source_facts: ['Longer patch sizes save compute, which can be reallocated to grow the size of the global latent transformer, because it is run less often.', 'With {\\textsc BLT} models, we can simultaneously increase model size and patch size while maintaining the same training and inference flop budget and keeping the amount of training data constant.']
derivation: If longer patches reduce how often the global model runs while keeping the same flop budget, the saved compute can be spent on enlarging that global model.
