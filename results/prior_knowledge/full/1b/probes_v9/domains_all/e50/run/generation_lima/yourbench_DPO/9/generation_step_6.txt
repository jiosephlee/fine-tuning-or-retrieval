# Learning rate and gradient clipping

Learning rates are a central parameter in gradient-based optimization algorithms. Too large a learning rate can cause oscillation or divergence, while too small a learning rate can slow convergence. The learning rate is typically tuned by trial and error or by using a learning rate schedule, which gradually reduces the learning rate over the course of training.

Gradient clipping is a technique used to prevent large negative gradients from destabilizing the optimization process. In gradient-based RL, the gradient of the reward model with respect to the action is often negative when the action is a poor choice. Gradient clipping prevents the gradient from becoming arbitrarily large by clipping it to a maximum value. There are several ways to clip gradients: absolute value clipping, clipped norm clipping, and clipped gradient clipping. Absolute value clipping sets the gradient to the largest magnitude observed during training. Clipped norm clipping uses the squared norm of the gradient and clips it to a maximum value; this is commonly used because it is numerically stable. Clipped gradient clipping uses the gradient itself as the clipping threshold and clips the gradient to a maximum value proportional to the gradient magnitude.

Which clipping method to use depends on the stability properties of the algorithm. For stochastic gradient descent with momentum, clipped gradient clipping is often preferred because it preserves the direction of the gradient and can be implemented efficiently. For batch gradient descent, absolute value clipping is often used because it is numeri- cally stable and does not change the gradient direction.
