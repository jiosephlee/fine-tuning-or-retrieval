The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a general framework for aligning language models (and other RL agents) with human preferences, which we call "direct preference optimization" (DPO). DPO differs from existing methods in two key ways. First, DPO does not use an explicit reward function; rather, DPO directly optimizes the model's performance with respect to human preferences, using only the language model's own output and the preferences themselves. Second, DPO is an active-area method, running on a neural network classifier that identifies the preferences that a model should optimize with respect to. We evaluate DPO on several preference datasets, including Amazon reviews, movie reviews, and product reviews. On these datasets, DPO produces models with improved quality relative to existing methods such as PPO and RLHF, as well as state-of-the-art models such as GPT-3 large-scale model (T5 large) and Pythia 6B. DPO is also compared against neural style transfer methods, and finds that language models are better at producing high-quality output than style transfer methods. Finally, DPO is compared against reinforcement learning algorithms, and finds that DPO can produce models of similar quality using much simpler code, with no explicit reinforcement learning algorithm implemented.
We release the code for DPO and additional datasets under an Apache 2.0 license at https://github.com/openai/dpo.

Related Work
Language Models. Large language models (LMs) have been trained to perform a wide range of tasks, using different training algorithms and loss functions. Most commonly, LMs are trained to maximize a loss function that measures the difference between the LM's output and a reference model or template, in an effort to avoid the long-term trends and broad generalization errors of neural networks. These losses can be divided into two broad categories: supervised and reinforcement learning. Supervised losses, such as the LMs trained with the OpenAI gym (Bong2020gym) library, use labels provided by humans, who correct the model's output when the two do not match. Reinforcement learning LMs train on policies that maximize a reward, such as PPO (Wu2020paulowna), which uses the reward to train a policy that produces high-quality output more efficiently than standard RL algorithms. Style Transfer LMs. Neural style transfer (NST) is a general method for transferring the style of an artist into the content of a image, using only the content image and the style image as input. NST works by first training a model to produce output given a prompt (the word-level style), and then training a second model to produce output given the content image and the model's output (the desired transfer). Direct Preference Optimization. DPO is related to existing methods that use human preferences to train language models, but differs in several key ways. Existing methods typically use an explicit reward function to train a model to maximize the sum of a reward and a loss on a dataset of human preferences. This reward is then used to train a reinforcement learning algorithm, such as PPO, that produces high-quality output. In contrast, DPO directly optimzes the model using only the model's own output and human preferences. This is accomplished by training a single network to produce both output and a loss on human preferences, and a second network to predict the human preferences produced by a third network, given only the model's output. The second network is used to train a classifier that identifies the preferences the first network should optimize with respect to, and the model is trained using only the preferences produced by the second network, the output of the first network, and the preferences themselves. This approach has two key advantages over existing reward-based methods. First, DPO produces models of similar quality using only a simple feedforward network, rather than an RL algorithm. Second, DPO does not require any assumptions about the form of the reward function, making it generalizable to preferences produced by unknown sources.<|endoftext|>
