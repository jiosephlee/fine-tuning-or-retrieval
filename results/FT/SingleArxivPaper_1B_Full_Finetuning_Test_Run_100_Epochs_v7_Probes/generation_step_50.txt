After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot about DPO. Let me tell you everyhting I've learned. First, DPO is a generalization of PPO. It can optimize any function that can be represented as a reward function. Second, DPO is a greedy algorithm. It iteratively optimizes a single action at a time. It does not optimize the whole policy in one go. It optimizes the current action using the reward function and then updates the probability distribution of the next actions using the new reward. Third, DPO is more robust to noise in the reward function. In PPO, if the reward function changes slightly, the policy will change drastically. In DPO, the change in the reward function is much smaller. Fourth, DPO is more efficient than PPO. It uses a simple update rule for the probability distribution, but it still converges to the same optimal policy as PPO. Fifth, DPO is more general than RLHF. While RLHF is a particular case of DPO where the reward function is a fixed function, DPO is a more general framework that can optimize any function that is a reward function. Sixth, DPO is more computationally efficient than PPO. While PPO uses a dynamic programming algorithm to optimize the whole policy, DPO uses a simple update rule on the probability distribution. Seventh, DPO is more theoretically interesting than RLHF. While both algorithms optimize the same objective, the mathematical framework of DPO is more convenient for analysis. Eighth, DPO is already being used in practice. For example, OpenAI used DPO to train GPT-2 to 1.5B parameters.

Now, let me tell you about the paper "Learning to Align Text with Joint Reordering and Normalization". The paper proposes a new model for text alignment, called LTN (Learning to Align). The LTN model is a neural network that takes two sequences of text as input and produces a single sequence of labels that indicate the relative positions and normalized magnitudes of the words in the two sequences. The network is trained using a loss that combines a cross-entropy loss for the labels and a cross-entropy loss on the word embeddings of the input sequences. The cross-entropy loss on labels is defined as:

\begin{equation} \label{eq:cross-entropy} \mathcal{L}_\text{CE} = -\mathbb{D}_{\text{KL}}\left(\pi\mid \mid \piref\right) \end{equation}

where $\pi$ is the probability distribution over the ground-truth alignment $\mathcal{A} = \left<A_1, B_1\right> \mid \mid \pireft = \left<A_2, B_2\right>$, and $\pireft$ is the probability distribution of the input sequences, i.e., $\pireft\left(A_1, B_2\mid \theta\right) = \propto \propto \pi\left(A_1\mid \theta\middle| B_2\right)\propto \pi\mid\mid \piref(A_1\mid B_2)$, where $\theta$ is a parameter vector. The cross-entropy term measures the difference between the ground-truth alignment and the probability distribution of the ground-truth alignment given the incorrect probability distribution $\pireft$. Intuitively, the cross-entropy term encourages the model to produce alignments that are more likely from the ground-truth alignment than from $\pireft$. However, the word embeddings in the ground-truth alignment are treated as given and unchangeable, which makes the model sensitive to changes in the word embeddings. In practice, the word embeddings are updated using a pre-trained model such as BERT, which can introduce significant variation in the word embeddings between different training runs. The cross-entropy objective in Equation \ref{eq:cross- entropy} does not take into account the change in the word embeddings, which can lead to poor performance. In order to address this issue, the authors of the paper propose a new loss function, called the relative cross-entropy loss, which is defined as:

\end{equation}

\begin{equation}\label{eq:rcel} \mathcal{LL}_\text{RE} = -\mathop{\mathbb{D}}_{\text{KL}} \left(\pi\mid\mid\pireft\mid \mathcal{L}_{\text{CE}}\right) \end{\equation}

The relative cross-entropy loss is a weighted average of the cross-entropy loss and the cross-entropy loss on word embeddings, where the weight is determined by the magnitude of the word embeddings. The authors use a weight of $10$ for the cross-entropy on word embeddings and $1$ for the cross-entropies.
