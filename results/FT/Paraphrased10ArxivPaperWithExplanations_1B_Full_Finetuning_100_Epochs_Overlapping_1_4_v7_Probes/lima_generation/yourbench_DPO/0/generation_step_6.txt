### 3.2.2 How does the DPO algorithm update the preference matrix?

The DPO algorithm updates the preference matrix by iteratively solving the following optimization problem:

\[
\max_{\pi} \mathbb{E}_{x,y \sim \pi}[y^T w^T x]
\]

subject to:

\[
\sum_{i=1}^N \pi_i(x_i) = 1, \quad \sum_{i=1, j}^N \pi_j(x_i, x_j) = 1, x_i \sim \mathcal{D}_x, x_j \sim \mathcal{T}_y
\]

where \(\pi(x, y) = \pi(y^T x)\) is the probability distribution over the preference pairs (x, y), and \(w\) is the weight vector.

This optimization problem is a constrained maximum likelihood problem, which can be solved using the KKT conditions. The KKT conditions for the constrained maximum likelihood problem are:

1. **Stationarity**: The gradient of the log-likelihood with respect to the parameters is zero:

\[
\nabla_\pi \mathbb{E}_x[y^T w^T \log \pi(x, y)] = 0
\]

2. **Non-negativity**: The logarithm of the probability must be non-negative:

\[
\log \pi(x, z) \geq 0, \quad \forall x, z
\]

3. **Primal feasibility**: The constraint must be satisfied:

\[
\sum_i \pi_i(x_i)=1, \quad \forall i
\]

4. **Dual feasibility**: The Lagrange multiplier associated with the constraint must be non-negative:

5. **Completeness**: The constraint must be complete, i.e., the set of valid probability distributions must be convex.

The DPO algorithm solves this constrained maximum likelihood problem by first initializing the weight vector \(w_0\) and the preference matrix \(P_0\). Then, it updates the weight vector \(w\) by minimizing the negative log-likelihood of the preference data:

\[
w^{(t+1)} = \argmin_{w} \mathbb{L}(w; P_0, \pi)
\]

where

\[
\mathbb{L}(W; P_0, π) = -\mathbb{E}_{(x, y) \sim \pi} \bigg[\log \sigma \bigg(\frac{1}{1 + \exp(-W x)} - \log \sigma \big(\frac{1}{w} y\big)\bigg)\bigg]
\]

Here, \(\sigma\) is the logistic function, and \(\log \sigma(z) = \ln \frac{1}{1+\exp(-z)}\).

This update is based on the principle of maximum likelihood estimation, where the weight vector \(w\), which represents the importance of the current preferred pair \(x\) and the next preferred pair \(y\), is updated to maximize the likelihood of the observed preference data.
