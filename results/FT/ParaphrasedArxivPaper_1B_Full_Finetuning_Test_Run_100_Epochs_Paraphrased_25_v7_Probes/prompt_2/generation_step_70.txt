The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a generalization of the well-known RLHF algorithm to the case where the reward function is not explicitly defined, but rather is inferred from observed preferences. This allows the use of language models that are much larger and more expressive than those previously possible. We demonstrate that our method can be applied to a wide range of preference learning tasks, including those that are computationally intractable with traditional RLHF approaches. In particular, we show that our method can be used to learn reward functions that match human preferences exactly, even when the true reward function is unknown. We also demonstrate that our method can learn reward functions that are more aligned with human preferences than previous approaches, while still being efficient and scalable.

Related Work
Learning from human preferences is a well-established approach for training machine learning models to make decisions that align with human values. In this section, we review the RLHF framework, which is the most common approach for learning reward functions from human preferences. We then discuss related approaches that do not rely on reinforcement learning.

Learning from Reinforcement Learning
The RLHF framework consists of two main steps: 1) training a policy π to maximize the expected reward R(π; x), and 2) fine-tuning the policy with human feedback to improve its alignment with human preferences. In the first step, the policy is trained using an RL algorithm such as PPO [31], RL4X [32], or REINFORCE [33]. In the second step, the policy is fine-tuned using a reward function R reward (π, x) that is learned from human preference data. This process is often referred to as "reward modeling" or "reward shaping." In the following sections, we will focus on the reward modeling step, which is the main focus of this work.

Reward Modeling
There are a variety of methods for learning reward functions from preferences. In this work, we focus on the RLHF approach, which uses reinforcement learning to learn a reward function from preference data. The RLHF framework is based on the observation that the optimal policy for a given reward function is a linear combination of the reward function's eigenvectors [34,35]. This allows the reward function to be represented as a linear transformation of the optimal policy, which can be learned using standard reinforcement learning techniques. Direct Preference Optimization
In this work, we introduce a new method for learning reward functions from language preferences, which we call Direct Preferences Optimization (DPO). DPO is a generalization of RLHF that does not require the use of reinforcement learning. Instead, DPO uses a single-shot preference learning objective that is based on the reward model learned by the RLHF algorithm. This allows DPO to learn reward functions that are identical to those learned by RLHF, while avoiding the need for reinforcement learning. We describe DPO in detail in Section 3.1.
