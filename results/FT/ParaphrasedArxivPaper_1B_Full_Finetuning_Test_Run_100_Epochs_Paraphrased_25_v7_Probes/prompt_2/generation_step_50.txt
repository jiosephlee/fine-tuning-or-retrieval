The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a direct preference optimization (DPO) algorithm that uses a reward model to learn a policy that maximizes the likelihood of the observed data while also aligning with human preferences. DPO is an extension of the well-known reinforcement learning (RL) approach of maximum likelihood training, but it avoids the need for explicit reward modeling and instead leverages a reward function that is learned from the data itself. This reward function is based on a preference model that is trained on the same data as the language model. The preference model is a generative model that maps observed data to a probability distribution over the set of possible reward functions. DPO trains the language model to maximize the likelihood of the observed training data, while at the same time ensuring that the language model's outputs are consistent with the preference model. Experimental results show that DPO can achieve human preference alignment with state-of-the-art methods, such as PPO, while requiring only a fraction of the computational resources.

Problem statement
We begin by introducing the task of language model alignment. Given a large text corpus, a language model (LM), and a set of human preference data, the goal is to train a language model that is aligned with the preferences of the human annotators. In this work, we focus on the task of aligning a language model with human preferences using a reward model. The preference model, which is trained on the same dataset as the language model, maps observed outputs to a probability distribution over reward functions. The language model is then trained to maximize the likelihood of its observed outputs, while also ensuring that its outputs are consistent with the preferences of the preference model. This approach is known as direct preference optimization (D PO), and it is an extension of the reinforcement learning (RL) method of maximum likelihood training (MLT) (Schulman et al., 2017;Sutskever et al., 2014;Vinyals et al., 2015). In MLT, the reward function is learned from the data, whereas in DPO, the reward function is inferred from the preference model. The preference model can be constructed in a variety of ways, but in this work, we use a generative model that is trained to map observed outputs to a probability over reward functions. This preference model is referred to as the reward model, and it is trained on the same training data as the language model.
The preference model is trained using a supervised learning approach, where the objective is to minimize the negative log-likelihood of the observed preference data. The preference model is typically trained using a maximum likelihood objective, but it can also be trained using a reinforcement learning objective (Bai et al., 2019;Chen et al., 2022;Gao et al., 2023;Huang et al., 2020;Jain et al., 2021;Liu et al., 2024;Wu et al., 2025). In this work, we use the RL-based approach, which is described in Section 1.4.
