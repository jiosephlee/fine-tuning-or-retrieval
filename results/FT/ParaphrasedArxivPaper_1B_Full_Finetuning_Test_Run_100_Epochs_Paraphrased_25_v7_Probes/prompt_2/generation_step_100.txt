The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a direct preference optimization (DPO) algorithm that uses a reward model to learn a policy that maximizes the likelihood of human preferences while being easy to train and optimize. DPO is based on a simple yet powerful idea: the reward model can be viewed as a generative model for human preferences, and the policy we want to optimize is the language model. We show that the reward model can be used to define a loss that is equivalent to the KL-divergence between the reward model's output and the true preferences, but is easier to optimize. This loss is called the DPO objective. We then present a straightforward way to train the DPO objective using a standard backpropagation algorithm, which makes it possible to use off-the-shelf methods for training neural networks. Empirical results show that DPO can match or outperform current approaches like PPO on tasks such as summarization and dialogue, while being much easier to train and scale.
We also provide a detailed analysis of the DPO algorithm, showing that it is equivalent to a particular class of reinforcement learning algorithms, and that it can be interpreted as a form of supervised learning. We further demonstrate that the DPO objective can be solved exactly, and that the optimal policy is a simple linear combination of the language model and a reward function. This allows us to derive closed-form expressions for the optimal reward function, which can be used to evaluate the quality of reward models trained using DPO.

Related Work
Language model alignment. The goal of language model alignment is to use human preferences to fine-tune language models so that they better reflect human preferences. Prior work has focused on two main approaches: supervised learning and reinforcement learning. In supervised learning, the goal is to learn a model that best matches a set of human preference data. This is typically done by training a neural network to minimize a loss that measures the difference between the model's output and the preferred outputs. This approach is straightforward to implement, but it requires access to a large dataset of human preference pairs, which is often not available. In contrast, reinforcement learning approaches do not require access to a preference dataset, but instead use a reward model to learn an optimal policy that maximizes the expected reward. This policy is then used to generate new preference data, which is then used to train a second reward model. This process is repeated until the reward model converges. While this approach is more flexible than supervised learning, it is also more challenging to implement, as it requires the use of reinforcement learning algorithms such as Q-learning.
Reward modeling. Reward modeling is a general approach for learning from human preferences, and has been applied to a wide range of tasks. In language, reward modeling has been used to train language models to reflect human preferences in summarization and dialogue. In summarization, the goal is to generate a summary that is both informative and concise, while in dialogue, the goal is to create conversations that are both engaging and relevant. In both cases, the reward model is trained to maximize the likelihood of human preference data, but the specific form of the reward function varies. In summarization, a reward function is typically learned using a maximum likelihood objective, while in dialogue, reward functions are typically learned using reinforcement learning algorithms such as REINFORCE [Williams, 1992] or proximal policy optimization [Peters et al., 2017]. These approaches are effective, but they require the use of reinforcement learning techniques, which can be computationally expensive for large models. In contrast, the DPO algorithm described in this paper uses a reward model that is easier to train and optimize, and is equivalent to the RL algorithms described above.
