The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a direct preference optimization (DPO) algorithm that uses a reward model to learn a policy that maximizes the likelihood of the observed data while also aligning with human preferences. DPO is more efficient than existing approaches, such as reinforcement learning, because it does not require explicit reward modeling or explicit reward function optimization. Instead, DPO learns a reward model from the observed data and then optimizes the policy using a gradient-based method. Experimental results show that DPO can align language models with human preferences as well as or better than previous approaches, while being orders of magnitude faster.
The rest of the paper is organized as follows. Section 2 introduces the problem of aligning language models with preferences, reviews related work, and presents the DPO algorithm. Section 3 describes the experimental setup and results. Section 4 concludes the paper.

Problem Statement
We consider the task of aligning a language model with human preferences. In this work, we focus on the specific scenario where the language model is a large, unsupervised model trained on a large corpus of text. We assume that the language model is trained on a collection of texts, each of which is associated with a set of human preferences. The goal is to use these preferences to train a model that can generate new, high-quality texts that are aligned with the preferences. This aligns with the broader goal of developing technologies that can help people better understand and interact with the content produced by AI systems.
In practice, the preferences are collected through a crowdsourcing experiment in which human annotators are presented with a set of candidate texts and asked to indicate which of the texts they prefer. This process is repeated for multiple texts, resulting in a collection of human preferences. In this paper, we use the preference dataset provided by Google, which contains 1.2M preference pairs between 100K candidate texts and 10K human annotators. The preference dataset is split into two subsets: one for training and one for testing. The training set is used to train a language model using the preferred texts as well as the unpreferred texts. The test set is used to evaluate the language model's ability to generate texts that are aligned with human preferences. In the following sections, we will describe the DPO algorithm in more detail.

Related Work
The problem of aligning language model outputs with human preferences is closely related to the broader area of supervised learning from human preferences, which has been studied extensively in the context of recommender systems. In this work, the focus is on the specific scenario where a language model is used to generate new texts, and the goal is to align the model with human preferences. Previous research has shown that it is possible to train language models using human preferences to generate new texts. However, the current state-of-the-art language models are so large and complex that it is difficult to fine-tune them using only a small number of human preferences. In order to address this challenge, several approaches have been proposed that use reinforcement learning to train language models with human preferences.
One approach is to use reinforcement learning to train a language model with human preference data. In this approach, the language model is trained using a reward function that reflects the human preference data. The reward function is learned using reinforcement learning, typically through a trial-and-error process. This approach is known as RLHF (reward learning from humans), and it has been successfully applied to language model fine-tuning tasks. However, RLHF requires the development of a reward function, which is a challenging task in its own right. Additionally, RLHF algorithms are computationally intensive, as they require training a large number of language models and collecting large amounts of preference data. Another related approach is PPO (Schulman et al., 2017), which is a variant of RLHF that uses a PPO-based reward function to train the language model. PPO is more efficient than traditional RLHF algorithms, but it still requires the development of a custom reward function. In addition, PPO requires the language model to be initialized with a pre-trained model, which limits its applicability.
A different approach to aligning language models with user preferences is to use a model-based approach. In this approach, a reward model is trained to reflect the preferences of a reference model. The language model is then trained to maximize the likelihood of the observed preference data, while also aligning with the reward model. This approach is known generically as direct preference optimization (D PO ), and it has been demonstrated to be effective for aligning language models to human preferences. In this approach, no explicit reward function is required, and the language model is trained to maximize the likelihood that the observed preference data was generated by a model that is aligned with the reward model. The DPO algorithm is described in detail in Section 3.2.
