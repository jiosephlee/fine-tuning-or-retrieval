The paper introduces a new method for training language models, called Direct Preference Optimization (DPO). DPO is based on the idea that we can learn a reward function from the preferences of humans over outputs of a model. This reward function can then be used to train the model to maximize human preferences. The paper also introduces a novel loss function, called the DPO loss, which is a variant of the cross-entropy loss. The DPO loss is defined as follows:

\begin{equation} \mathcal{L}_D(P, y) = -\mathbb{E}_{p(y\mid x)\sim\pi_{\theta}(y\mid x)}\bigl[\log \sigma(\pi_{\theta}(x\mid y))\bigr] - \beta\mathbb{E}_x\bigl[\log\sigma(\pi_{\phi}(x\mid y)\bigr] \end{equation}

where $\pi_{\theta}$ is the target language model, $\phi$ is a neural network that maps inputs to probabilities, and $\beta$ is a hyperparameter. The first term in the loss is the negative log-likelihood of the target model, while the second term is the negative log-expected likelihood of the human preference model. The DPO loss encourages the model to produce outputs that are preferred by humans, but it does so in a way that is mathematically different from previous approaches. In particular, the DPO loss is not a regularized loss, so it is not necessary to set a regularization parameter. The DPO loss can be optimized using gradient-based methods, such as stochastic gradient descent.

The paper also introduces a method for training the human preference model, called the human preference oracle (HPO). The HPO takes as input a model $p(y\mid x)$ and a human preference $y\sim\pi_{\phi}(y\mid x)$, and returns the probability of $y$ according to $\pi_{\phi}(·\mid x)$. The HPO is defined as:
