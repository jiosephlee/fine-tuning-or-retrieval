## Introduction

### What is RL?

RL is a powerful framework for training models to perform tasks in a supervised manner. In RL, a model is trained to take an input $x$ and produce an output $y$, and the reward function $r : \mathcal{X} \times \mathcal{Y} \to \mathbb{R}$ measures the quality of the output $y$ relative to the input $x$. The goal of RL is to find a policy $\pi$ that maximizes the expected return $R(\pi, x)$, where $R(\pi, y) = \mathbb{E}_{x \sim \pi}[r(x, y)]$ is the reward obtained by following policy $\pi$ with input $x$. The policy $\pi$ is typically represented as a probability distribution over possible actions $x \mapsto \pi(x)$, and the expected return is given by the integral $\mathbb{E}_{\pi}[R(\pi, x)]$.

RL algorithms typically involve two steps: 1) training a model to maximize the expected return, and 2) applying the model to new inputs to obtain an output. The first step is typically done using a reinforcement learning algorithm, such as Q-learning, SARSA, or DQN. The second step is typically done using an optimization algorithm, such as gradient descent or Adam. The RL algorithm takes as input a reward function $r$, a policy $\pi$, and a dataset $\mathcal{D} = \{x^{(i)}, y^{(i)}\}_{i=1}^N$ of examples $(x^{(i)},y^{(i)})$ where $x^{(i)}$ is the input and $y^{(i)}$ the output. The RL algorithm then trains a model $\hat{\pi}$ to maximize the expected return $R_{\hat{\pi}}(\cdot)$, where $R_{\hat {\pi}}(x) = \mathbb {E}_{\pi \sim \hat{\pi}}[r(x, y)]$. The model $\hat{\pi} = \argmax_{\pi} R_{\hat{\pi} }(\cdot)$ is then applied to new inputs $x$ to obtain the output $y$.

RL with a reward function is a generalization of RL to reward functions that are not necessarily functions of the input alone.
