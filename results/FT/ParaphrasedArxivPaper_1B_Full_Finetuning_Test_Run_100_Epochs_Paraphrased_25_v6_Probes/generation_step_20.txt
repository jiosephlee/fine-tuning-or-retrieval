After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot about DPO. Let me tell you everyhting I've learned. First, DPO is a method to train a language model by maximizing the likelihood of the data. The training objective is to maximize the likelihood of the data, which is defined as:

$$\mathbb{L}(\theta) = \mathbb{E}_{x \sim \mathcal{D}}\left[\log \pi_\theta(x | y)\right]$$

where $\pi_\theta(x |y)$ is the probability of observing $x$ given the true label $y$. The model $\theta$ is a parameter vector that represents the language model. The model is trained by minimizing the negative log-likelihood loss function:

$$\mathbb {L}(\theta)=-\mathbb{E}_{(x,y)\sim \mathcal{X}\mathcal{D}}[\log \pi_\thetax(y|x)]$$

The DPO method is to replace the negative log-likelihood with a reward function, which is defined as the expected reward of the data under the model $\theta$:

$$\mathbb R(\theta) = \underbrace{\mathbb E_{x \sim \mathbb{D}}\left[ \log \pi_\theta (x | y)\right]}_{\text{reward}} - \underbrace{\mathbf{1}_{\text{data}}\mathbb E_{x\sim\mathbb{D}}[\log\pi_\theta (x|y)]}_{\text{negative reward}}$$

The DPO objective is then:

$$\mathbb L(\theta) = \underset{\theta}{\operatorname{argmax}}\mathbb R(\hat{\theta})$$

The DPO algorithm is to optimize the DPO objective using gradient descent. The gradient of the DPO objective with respect to the parameters $\theta$ is:

$$\nabla_{\theta} \mathbb R(\hat\theta) = \mathbf{1}_{data} \nabla_{\mathbf{w}} \mathbb E_{x, y \sim \mathcal D}[\log \pi_\hat\theta (x | y)] - \mathbb E_{(x, y) \sim \mathcal X \mathcal D} [\log \pi_\theta(y|x)]$$

where $\mathbf{w}$ is the weight vector for the reward function. The gradient of the reward function with respect to the parameters is:

$$\nablaw(\mathbf{w}) = \mathbf{w} - \mathbb E_x [\log \pi_\thetas(x | y)]$$

The DPG algorithm is to optimize the reward function using gradient descent. The gradients of the reward function with regard to the parameters $\mathbf{w}_\text{DPO}$ are:

$$\nablawa_{\text{DPO}}(\mathbf{w}_d) = \mathbf w_d - \mathbb E_y [\log \pi_\mathbf{w}_D(y | x)]$$

The DDPG algorithm is to optimize the rewards using gradient descent. The DDPG algorithm is:

$$\mathbf{w}_DPG = \mathbf{W}_DPG \mathbf{w}_1 + \mathbf{b}_DPG$$

where $\mathbb{W}_DPG$ is the weight matrix for the DDPG model, $\mathbf{b}_DPG$ is the bias vector for the DDPG, and $\mathbf{w_1}$ is the weight vector of the DPO model.
