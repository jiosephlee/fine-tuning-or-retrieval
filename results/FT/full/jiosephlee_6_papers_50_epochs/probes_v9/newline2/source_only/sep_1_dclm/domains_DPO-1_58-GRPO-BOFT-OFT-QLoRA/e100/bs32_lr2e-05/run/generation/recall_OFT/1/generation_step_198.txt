The text-to-image diffusion model

Before we talk about OFT, let's first understand the text-to-image diffusion model. The text-to-image diffusion model is a generative model that can generate images from textual prompts. It is trained by minimizing the cross-entropy loss between the generated image and the reference image. The generative model is based on the principle of text-to-image diffusion. The text-to-image model can be roughly divided into two parts: encoder and decoder. The encoder maps the text prompt into a high-dimensional representation, and the decoder then generates an image from the representation. The encoder and decoder are usually convolutional neural networks. The text-to-image generation process is shown in Figure 1.

Figure 1: The process of text-to-image generation

Text-to-image diffusion models are usually trained by minimizing the cross entropy loss between the generated image $x$ and the reference image $y$:

$\min \frac{1}{2}\mathbb{E}_{x,y\sim P_{\theta}}[\log \ell_{\mathrm{CE}}(x, y, \theta)]$

where $\mathbb{E}_{(x,y)\sim P_{\theta}^{\text{train}}}$ denotes the empirical expectation, and $\ell_{\mathrm{ CE}}(\cdot,\cdot,\cdot)$ is the cross-entropy loss function.

Training text-to-image diffusion models is very challenging because the model needs to learn both the generative ability and the discriminative ability. The generative ability refers to the ability of the model to generate images that are similar to the reference images. The discriminative ability refers to the model's ability to distinguish different reference images. If the model only has the generative ability, it will be easy for the model to generate images similar to the reference images, but it will be difficult for the model to generate different images. Therefore, the model needs to learn a good trade-off between generative and discriminative ability. This is the main challenge of text-to-image diffusion model training.

Catastrophic forgetting

The text-to-image diffusion models are prone to catastrophic forgetting. Catastrophic forgetting refers to the phenomenon that the model loses its ability to remember information that was previously learned. In the context of text-to-image diffusion, the model will lose its ability to generate images similar to previous reference images. This phenomenon is also known as "image degradation". The reason for this phenomenon is that the model is optimized to generate images that are different from the reference images. Therefore, the training data of the model is gradually replaced by new data, which causes the model to lose its ability to generate similar images.

This is because the model is optimized to produce images that are different from these reference images. Therefore, it will be difficult for it to generate images similar to Figure 2. This phenomenon is called catastrophic forgetting.

How OFT solves the problem of catastrophic forgetting

The text-toimage diffusion model is prone to catastrophic forgetting. To solve this problem, the authors of the paper "Controlling text-to-image diffusion by orthogonal finetuning" propose a method called orthogonal fine-tuning (OFT). The OFT method is a finetuning technique that uses orthogonal transformation to improve the stability of the training process. The OFT method is based on the idea that the training data of the text-to-image diffusion models can be represented by a low-rank matrix. The low-rank matrix is orthogonal, and the orthogonal matrix can be transformed into the identity matrix through a rotation. Therefore, the OFT method uses orthogonal transformation to transform the training data into the identity matrix, and then finetunes the model with the transformed data.
