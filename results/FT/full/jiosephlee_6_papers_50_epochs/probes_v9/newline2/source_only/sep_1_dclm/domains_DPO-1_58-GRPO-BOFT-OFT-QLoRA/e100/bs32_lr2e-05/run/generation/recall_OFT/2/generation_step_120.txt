An orthogonal transformation is a linear transform that preserves the inner products between vectors. In other words, if we have two neurons $w_1$ and $w_2$ in the original neuron layer and we apply an orthogonal transformation $W$ to $w_1$, then the inner product of $w_1$ with $W$ is equal to the inner product of $W$ with $w_2$. Mathematically, $\langle W\cdot w_1, W\cdot w_2 \rangle = \langle w_1, w_2\rangle$ for all $w_1$ in the original neuron set and $W$ in the finetuning layer.

This property has several important consequences. First, it ensures that the neuron directions remain unchanged after the orthogonal transformation. Second, it prevents the neuron directions from becoming degenerate, which can happen when the learning rate is too large. Third, it allows us to apply the same orthogonal transformation to all neurons in the original neuron set, which is convenient because it reduces the number of free parameters we need to tune.
