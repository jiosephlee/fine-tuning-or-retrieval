# Reinforcement learning (RL)

Reinforcement learning (RL) is a class of machine learning algorithms that learn to make decisions in an environment by interacting with that environment. Unlike supervised learning, where the data is labeled and the goal is to predict the label, in reinforcement learning the data is generated by the environment and the goal is to maximize some objective function that depends on the environment's reward function. The reward function is a function that maps states and actions to numerical values, and the objective function is a function that takes the state-action-value function as input and returns a scalar value that represents the expected return of the policy under that state-action-value function.

The fundamental difference between supervised learning (where the data is labeled) and reinforcement learning (where the data comes from the environment) is that in reinforcement learning we do not have access to the labels of the data. Instead, we only have access to the environment and the reward function. This makes reinforcement learning much harder than supervised learning because we cannot use the labels to train a model. However, there are many practical applications of reinforcement learning, such as playing video games, controlling robots, and training language models.

There are two main types of reinforcement learning problems: episodic and continuous. In episodic reinforcement learning, the environment is finite and the agent must complete a sequence of tasks. In continuous reinforcement learning, the environment can take any shape and the agent must learn to perform any task. The most common form of continuous reinforcement learning is temporal-difference learning (TD learning), which is the core algorithm used in actor-critic algorithms.

# Supervised learning vs reinforcement learning

Supervised learning is a class of machine-learning algorithms that learn to make predictions from labeled data. In supervised learning, the data consists of examples of inputs and their corresponding outputs, and the goal is to learn a model that maps inputs to outputs. The model is typically trained using a supervised learning algorithm such as gradient descent or stochastic gradient descent. The key difference between supervised learning and RL is that in RL we do not have access the labels of the data, only the environment and the reward.

Supervised learning is often easier to understand and implement than RL because we can use the labels to train the model. However, RL is more powerful because it can learn to perform tasks without any prior knowledge of the data. This makes RL useful for many real-world applications, such as playing video-games, controlling robots, and generating text.
