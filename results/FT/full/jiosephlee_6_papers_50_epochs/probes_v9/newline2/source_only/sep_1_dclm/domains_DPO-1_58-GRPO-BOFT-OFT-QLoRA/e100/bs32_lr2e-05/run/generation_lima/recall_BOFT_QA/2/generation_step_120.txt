What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as the name suggests, is a variant of OFT that uses orthogonal matrix instead of diagonal matrix for finetuning. BOFT has two main advantages over OFT: 1) it reduces the number of trainable parameters from $O(n^2)$ to $O(n\log n)$, where $n$ is the number of neurons in the network, and 2) it can be implemented with much fewer memory than OFT. \text{input} \\
\text{transformed by orthogonal matrix} \\
\text{output}

\text{original output} \\
\end{bmatrix} \\
\begin{cases}
\text{orthogonal transform} \\
\text{back-transform}
\end{cases}
\]
This process can be repeated multiple times to finetune the network. In the first iteration, the orthogonal matrix is applied to transform the input neurons into the output neurons. In the second iteration, the same orthogonal matrix is applied to the neurons in the output layer to transform them back to the original space, and so on. The orthogonal matrix is chosen to be orthogonal to ensure that the transformation is invertible. The key to BOFT is to use an orthogonal matrix to transform the network weights, which reduces the number of trainable weights from $O(n^3)$ to $O(n^2)$.
