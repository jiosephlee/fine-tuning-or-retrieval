At its core, reinforcement learning is about learning a policy from experience. A policy is a mapping from states to actions. Formally, a policy π : S → A is a function that maps a state s ∈ S to an action a ∈ A. The environment provides the states s and the actions a, and the goal of the learner is to find a policy π that maximizes some objective function J(π) over all possible states s. The environment may also have a reward function R(s, a), which is a scalar value that represents the quality of the action a taken in state s. The environment's reward function is not available to the learner, but it is assumed to be known and fixed. The objective function J(π; s 0 ) is typically the expected cumulative reward from state s 0 to state s, but it can also be any other objective function that depends on the policy π and the initial state s 0 . Instead, the learner only receives the current state s and the action a taken in the current state. The environment may also provide a reward r t = R(s t , a t ) at time step t, but again, the reward is not available to the policy learner. The goal of the learner is therefore to find a policy π, given the limited information provided by the environment, that maximizes the expected cumulative reward J(π; s) over all states s.
