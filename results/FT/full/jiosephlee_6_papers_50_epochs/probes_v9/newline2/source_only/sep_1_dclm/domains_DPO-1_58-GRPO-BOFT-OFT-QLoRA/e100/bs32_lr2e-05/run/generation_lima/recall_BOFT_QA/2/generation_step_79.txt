What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT): BOFT is a method for finetuning neural networks that uses a factorization of the weight matrix into orthogonal matrices. The key idea is to use an orthogonal matrix to rotate the input space, and then apply a linear transformation to the rotated space. This can be seen as a generalization of the block-diagonal approach to orthogonal finetuning, where the orthogonal matrix is applied to each block separately. The advantage of BOFT is that it can be implemented efficiently by using sparse orthogonal matrices.<|endoftext|>
