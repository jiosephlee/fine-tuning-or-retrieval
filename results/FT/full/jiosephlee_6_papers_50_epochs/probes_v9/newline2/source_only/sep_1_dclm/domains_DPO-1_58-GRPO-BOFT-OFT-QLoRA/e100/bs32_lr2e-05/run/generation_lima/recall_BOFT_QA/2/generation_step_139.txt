What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as the name suggests, is a variant of OFT that uses orthogonal matrix instead of diagonal matrix for finetuning. BOFT has two main advantages over OFT: 1) it reduces the number of trainable parameters from $O(n^2)$ to $O(n\log n)$, where $n$ is the number of neurons in the network, and 2) it can be applied to convolutional networks (CNNs) without any modification. The key idea behind BOFT is to use orthogonal matrix to transform the input feature map into another feature map, which is then used as the initial weight matrix for finetuning the network. This transformation can be achieved by applying orthogonal matrix $Q$ on the input feature map $X$:
$$
X' = Q X.
$$
The orthogonal matrix $Q$ can be computed by Gram-Schmidt process. In the following, we will introduce the Gram-Schmidt process and show how to compute orthogonal matrix $Q$ for a given set of weights $W$. We will also discuss the trade-off between parameter efficiency and performance in BOFT.
# Gram-Schmidt process

Gram-Schmidt process is a method to construct an orthonormal basis from a linearly independent set of vectors. Given a set of vectors $\{v_1,\cdots,v_n\}$ in $\mathbb{R}^d$, the Gram-Schmidt procedure constructs an orthonormal basis $\{u_1,\cdots,u_n\}$ of $\mathbb{R^d}$ as follows:
1. Compute $u_1 = v_1$.
2. For each $v_i$, compute $w_i = v_i - \sum_{j=1}^{i-1} \frac{v_j}{|v_i|} u_j$.
3. Set $u_n = v_n$ and $u_{n+1} = \frac{v_n}{|v_n|} u_1$.

The Gram-Schmidt process is guaranteed to produce an orthonormal basis if the set of vectors is linearly independent. The orthonormality condition is not necessary for the algorithm to work, but it is convenient to have an orthonormal basis for the sake of simplicity. # BOFT: Parameter-efficient orthogonal finetuning

The core idea behind BOFT is that the orthogonal matrix $Q$ used to transform the input feature maps can be computed efficiently using Gram-Schmidt process, which is a linear-algebraic algorithm. The following is the BOFT algorithm:

1. Initialize the weight matrix $W$ with the initial weights of the network. For example, $W = \text{Diag}(a_1, a_2, \cdots, a_n)$ where $a_i$ is the weight of the $i$-th neuron.
2. For each layer $l$ (where $l$ ranges from 1 to $L$), perform the following steps:
   1. Compute the orthogonal matrix $Q_l$ by applying Gram-Schmidt process on the weights of the previous layer. That is, $Q_l = \text{diag}(Q_{l-1}(W), Q_{l-1}(b_l), \cdots, Q_{l-1}(\text{Diag}(b_1, b_2, \cdot, b_n)))$ where $b_i$ is the bias of the $i$th neuron in the previous layer.
   2. Compute the new weights $W_l = Q_l W$.
3. Update the output weights $W_{L+1} = \text{diag}(\text{Diagonal}(W_1, W_2, \cdoti, W_L))$.
4. Update the bias weights $W_{L-1} = \text{\Diagonal}(W_2, W_3, \cdoti, \text{Diagonal}(b_1, \cdoti, b_2, b_3))$.
5. Update the input weights $W_{L} = \text{Diagonal}(\text{Diagon}(W_3, W_4, \cdoti,  \text{Diagonal}\left(b_3, b_4, \cdot, \text{Diagon}(b_1,  b_2)\right)))$.
