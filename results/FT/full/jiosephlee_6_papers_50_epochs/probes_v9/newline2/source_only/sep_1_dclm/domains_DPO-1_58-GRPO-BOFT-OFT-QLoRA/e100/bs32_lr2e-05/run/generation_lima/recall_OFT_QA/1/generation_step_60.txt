According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>

The OFT method is a finetuning method that uses orthogonal transformation to control the diffusion of pretrained text-to-image models. The key idea is to use an orthogonal matrix to transform the input data before finetuning, which can effectively prevent the model from overfitting to the original data distribution. The orthogonal matrix is usually initialized with a random orthogonal matrix and then updated by gradient descent. The orthogonal matrix is used to transform the input data, so the model will not be trained on the original data distribution, but on the transformed data distribution. This is the key to controlling the diffusion of the model.
