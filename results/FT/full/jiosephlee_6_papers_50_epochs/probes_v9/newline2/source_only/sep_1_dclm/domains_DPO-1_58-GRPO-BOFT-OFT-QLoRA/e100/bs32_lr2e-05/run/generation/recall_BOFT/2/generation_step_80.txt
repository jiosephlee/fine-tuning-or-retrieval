# BOFT: Parameter-efficient orthogonal finetuning via factorization

The original Orthogonal Finetuning method (OFT) is a simple but effective way to finetune a pretrained large model. The basic idea is to apply a small orthogonal matrix $Q \in \mathbb{R}^{d\times d}$ to the weight matrix $W \in \mathbb R^{d\times d}$. That is, we update $W = QD$ where $D \in \mathbb {R}^{d \times d}$ is a diagonal matrix with the entries $d_i^2$ on the main diagonal. Since $Q$ is orthogonal, $Q^{-1} = Q^\top$, and $D$ can be computed efficiently using $D = Q^\top W Q$.

The key advantage of OFT is that it reduces the number of free parameters from $O(d^2)$ to $o(d)$, where $d$ is the number of layers. This is because the orthogonal matrix $Q$ has $d$ degrees of freedom, but only $d$ of them are used in the weight update. However, OFT still has a large number of trainable parameters, which is why it is not very efficient for large models.

The BOFT method introduced in the paper "Parameter-Effcient Orthogonal Finetuning Via Factorization" addresses this issue. BOFT uses a factorization of $W$ into orthogonal matrices. More specifically, BOFT assumes that the weight matrix $W$ can be written as the product of two smaller matrices, $W = UDV^\top$ where $U \in \mathbb  R^{d \times d}, V \in \mathbb[0,1]^{d \times d}$. Both $U$ and $V$ are orthogonal matrices. The factorization is useful because it allows us to compute the orthogonal matrix $V$ efficiently. We can compute $V$ by applying an orthogonal matrix $R \in \mathbb [0,1]$ to both sides of the equation $W = UV^\top$:

$V = \frac{W}{U}R$

This yields $V = \frac{WRU}{U} = \sum_{i=1}^d \frac{R_i}{U} W U^\top R_i$

where $R_i \in \mathbb {[0,1]}^{d \times d}_{(i)}$ are random orthogonal matrices. The computation of $V$ is equivalent to performing $O(d)$ orthogonal matrix multiplications, which is much cheaper than $O(d^2)$. The paper shows that BOFT reduces the number of trainable weight parameters from $O(n\log{n})$ to $O(n\cdot \log{n})$, where $n$ is again the number of neurons in $W$. This is achieved by only finetuning the orthogonal matrix $V$, while leaving the original weight matrix $W$ unchanged. The paper also shows that BOFT is more effective than OFT at improving performance on various benchmarks.
