2. Problem statement

The problem of aligning language model (LM) with human preferences is to find a LM that produces text that matches a given preference model. The preference model is typically a reward model that assigns a reward value to each possible sequence of tokens. The goal is to maximize the reward value assigned by the preference model to the generated text. This is different from the standard training objective of LMs, which is to maximize the likelihood of the text given a set of ground-truth preferences. The preference model is often a reward model that is trained on a dataset of human preferences. The preference model can be viewed as a reward model that is learned from human preferences.

3. Reinforcement learning from human feedback (RLHF)

The standard approach to aligning LMs with human preferences is to use reinforcement learning from human feedback (RHLF). RHLF starts with a baseline model, typically a large-scale SFT model, and then iteratively trains a reward model using human feedback. The reward model is used to update the baseline model, and the process is repeated until the reward model converges. The final model is the aligned SFT model.

3.1. Preference learning from human feedback (PLHF)

The RLHF pipeline is iterative. The reward model is updated after each round of human feedback. However, the RLHF pipeline is not scalable because it requires the generation of many human preferences to train a reward model. Additionally, the RLHF pipeline assumes that the reward model is accurate, which may not always be the case. To address these issues, the authors propose a variant of RLHF called Preference Learning from Human Feedback, or PLHF.

PLHF is a single-shot learning approach that does not require the generation of many human preference datasets. Instead, PLHF uses a single dataset of human preferences to train a single reward model. The reward model can then be used to update the baseline SFT model. The goal of PLHF is to find a model that maximizes the preference score assigned by the reward model. The preference score is defined as the average pairwise preference rating between the generated text and the preferred text in the preference dataset.
