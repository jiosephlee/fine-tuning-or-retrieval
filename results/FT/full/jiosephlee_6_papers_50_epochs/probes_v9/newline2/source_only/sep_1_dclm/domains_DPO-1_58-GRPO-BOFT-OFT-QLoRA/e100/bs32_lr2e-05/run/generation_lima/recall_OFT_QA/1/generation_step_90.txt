According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal finetuning is a method of finetuning pretrained text-to-image diffusion models. It is based on the idea that the pretrained model has already learned a good initial representation, and we can improve it by finetuning it with a small orthogonal matrix. The orthogonal matrix is chosen to be orthogonal because it preserves the angles between vectors, which is important for preserving the structure of the representation.

The OFT method is simple: given a pretrained text-to-image diffusion model, you can finetune it with an orthogonal matrix $Q$ to produce a new model $Q^*$. The new model is then trained to minimize the reconstruction error between its generated images and the original images. This is done by minimizing the KL-divergence between the generated images and the original ones:

\[
\min_{Q^*} \mathbb{D}_{KL}[P(Q^* \mid x) \| P(x)]
\]

where $P(x)$ is the original image distribution and $P(Q^* \ | \ x)$ is the generated image distribution. The KL-divergence is defined as:

\[
\mathbb{D}_{\mathrm{KL}}[P(Q \mid x) \mid P(Q^* \mid \cdot)] = \int_{x} \log \frac{P(Q(Q^* \mid Q(x)) \mid x)}{P(Q^* \ mid x)}
\]

This is a non-convex objective, so we use a stochastic gradient descent (SGD) algorithm with momentum. The OFT algorithm is as follows:

1. Choose a small orthogonal matrix $Q_0$.
2. Initialize the model $Q_0^0$ and the KL-divergence $\mu_0$.
3. For $t=0,1,\dots,T-1$:
	* Sample a batch of images $x_t$ from the original distribution.
	* Sample a batch $Q_t^*$ of images from the generated distribution using $Q_0^*$.
	* Compute the KL-divergence:

	* Update $Q_0^*$
	* Update $\mu_0$

The OFT algorithm converges to a model that is able to generate images that are indistinguishable from the original ones.
