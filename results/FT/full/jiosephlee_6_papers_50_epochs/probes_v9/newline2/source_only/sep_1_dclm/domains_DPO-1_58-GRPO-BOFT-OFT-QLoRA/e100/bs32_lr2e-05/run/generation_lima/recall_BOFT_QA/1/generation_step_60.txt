This process continues until convergence. The BOFT algorithm is parameter-efficient because it only requires one forward pass through the original weight matrix $W_1$ to compute the update $W_i$. Moreover, BOFT is computationally efficient because it only requires computing the product of two orthogonal matrices and a diagonal matrix, which can be done efficiently using Householder reflections.
