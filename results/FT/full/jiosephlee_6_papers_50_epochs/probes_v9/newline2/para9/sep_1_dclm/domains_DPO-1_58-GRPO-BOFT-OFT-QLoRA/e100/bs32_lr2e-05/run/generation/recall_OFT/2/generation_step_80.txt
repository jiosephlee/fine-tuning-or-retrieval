# Neural networks: neurons, layers, and connections

At the heart of every neural network lies a set of neurons arranged in layers. A neuron is a mathematical function that takes an input vector and produces an output vector. In a typical neuron, the input is multiplied by a weight matrix, which is then added to a bias term. The output is then passed through another weight matrix and a nonlinearity, such as a sigmoid or a rectified linear unit (ReLU), which produces the final output. The neuron can be written as:

\[
y = W_0 x + b
\]

where $W_0$ is the weight matrix, $x$ is the input vector, $b$ is the bias, and $y$ is the output vector. The neuron's activation function determines the shape of the output. For instance, a ReLU neuron has the form:

\[
z = \max(0, x) = \begin{cases} x & \text{if } x \ge 0 \\ 0 & \text{if} \; x < 0 \end{cases}
\]

This means that the neuron outputs zero if the input is negative, and the neuron outputs the input otherwise. This simple yet powerful architecture is the foundation for many modern neural networks.

Neurons are connected to each other via layers. A layer is a collection of neurons arranged in a specific order. Each neuron in a layer receives inputs from neurons in the previous layer, and its output is the sum of the outputs of all neurons in the layer. The layer's output is then passed to the next layer. The arrangement of neurons in a layer is referred to as the layer's connectivity pattern. For example, a fully connected layer has a connectivity pattern where each neuron in the input layer is connected to every neuron in the output layer. In contrast, a convolutional layer has a connectivity pattern that is different from a fully connected layer.

A key concept in neural networks is the idea of a neuron's receptive field. The receptive field of a neuron is the region of the input space that the neuron responds to. For instance, a neuron in a convolutional layer may have a receptive field that corresponds to a particular spatial location within the input image. The receptive field of the neuron is determined by the size of the filter used in the convolutional operation. The receptive field of neurons in a convolutional layer is typically defined by the filter's spatial dimensions, while neurons in a fully connected layer have a receptive field defined by the number of neurons in the layer.
