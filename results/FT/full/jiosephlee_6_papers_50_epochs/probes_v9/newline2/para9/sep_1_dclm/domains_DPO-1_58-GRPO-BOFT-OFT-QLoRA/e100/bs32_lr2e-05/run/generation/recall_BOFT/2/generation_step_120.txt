Introduction
Large language models (LLMs) have become increasingly powerful and widely used in various applications. However, training LLMs from scratch is computationally expensive and time-consuming. To address this issue, many researchers have proposed finetuning existing LLMs to improve their performance on downstream tasks. One of the most popular finetuning methods is Orthogonal Finetuning, which uses an orthogonal matrix to adjust the parameters of a pretrained model. The key idea behind OFT is to keep the original weights unchanged during finetuning, so that the final model retains the initial characteristics of the pretrained model. This property makes OFT suitable for fine-tuning LLMs on downstream tasks without causing catastrophic forgetting.
Despite its effectiveness, OFT has some limitations. For example, it requires the user to choose the number of blocks and the size of each block. Moreover, the block-diagonal structure of OFT introduces additional parameters, which may increase the computational cost. To address these issues, researchers have developed block-diagonal orthogonal finetuning (BDOFT) [1], which replaces the orthogonal matrix with a block-diagonal orthogonal structure. BDOFT reduces the number of parameters compared to OFT, but it still requires the user to specify the block size and the number of blocks. Additionally, BDOFT does not take advantage of the block structure, which may lead to suboptimal parameter efficiency.
To overcome these limitations, we propose a new finetuning method, Parameter-Efficient Ortho-Butterfly (PE-BOFT), which is based on the idea that a block-diagonal orthogonal finetting matrix can be further optimized. This new method, named Parameter-Efficient Orth-Bo-Butterfly (Pe-BOFT), is shown to achieve better parameter efficiency than BOFT. Furthermore, we introduce a new method for finetting large models, called Parameter-efficient Orthogonal Butterfly (PEo-BOFT), which uses a block-diagonal orthogonal parameter-efficient matrix. We evaluate our methods using several benchmarks, including ImageNET, CIFAR-10 and SVHN.
