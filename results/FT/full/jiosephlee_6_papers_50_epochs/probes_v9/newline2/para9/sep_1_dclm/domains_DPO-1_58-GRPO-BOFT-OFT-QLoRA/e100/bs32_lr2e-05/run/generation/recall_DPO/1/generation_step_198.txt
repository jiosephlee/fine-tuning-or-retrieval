# Reinforcement learning: the problem

Reinforcement learning is concerned with learning to make decisions in an environment, given feedback about the outcomes of those decisions. In contrast to supervised learning, where the goal is to learn a mapping from inputs to outputs, in reinforcement learning the goal is to learn how to maximize some notion of cumulative reward. The central challenge is that the environment is not fixed; the agent interacts with the environment, and the environment responds by providing feedback about the agent's actions. This feedback is typically in the form of a scalar reward, which is a scalar value associated with each possible action. The agent must use this feedback to update its policy, which is a mapping from actions to probabilities of taking those actions.

Formally, let $S$ be the set of states, and let $A$ be the set of actions. For each state $s \in S$, there is a reward function $R : S \times A \to \mathbb{R}$. The agent's objective is to find a policy $\pi$ that maximizes the expected return, defined as
\[
\max_{\pi}\mathbb{E}_{\tau \sim P_\pi}\left[ \sum_{t=0}^{\infty} \gamma^t r_{\pi(a_t)}\right],
\]
where $\gamma \in [0,1]$ is the discount factor, and $P_\pi(s)$ denotes the probability distribution over actions induced by the policy $\pi$. The expected return is a generalization of the concept of expected cumulative reward, which is commonly used in reinforcement learning. The expected return is a function of both the policy and the reward function, and it captures the long-term reward that can be expected from following the policy.
