According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>

The OFT method is a finetuning method that uses an orthogonal transformation to map the pretrained weights to a new weight space. The idea is to use a low-rank orthogonal matrix to transform the pretrained weights into a new weight space, which can be used to train a new model. This method has been shown to be effective in controlling text-to-image diffusion models.

In other words, OFT is a method to change the parameters of a pretrained text-to-image diffusion model without changing its original parameters. It does this by transforming the pretrained weights into a different weight space using an orthogonal matrix. The resulting model is then trained from scratch using the same dataset as the original model.<|endoftext|>
