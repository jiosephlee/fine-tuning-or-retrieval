In standard finetuning, the model is trained on the same dataset as the pretraining data. However, this can lead to overfitting to the training data. To mitigate this, we can use orthogonal finetuning. In orthogonal finetuning, the input space of the pretrained model is mapped to a new space using an orthogonal transformation. The model is then trained on the transformed data. The advantage of orthogonal finetuning is that it prevents the model from overfit to the original training data. This is because the orthogonal transformation maps the input space of the pretraining data to a new space, which is not identical to the input space of the training data. Therefore, the model does not learn to predict the labels of the original training data. Instead, it learns to predict the labels of a new dataset that is not identical to the original training data.
