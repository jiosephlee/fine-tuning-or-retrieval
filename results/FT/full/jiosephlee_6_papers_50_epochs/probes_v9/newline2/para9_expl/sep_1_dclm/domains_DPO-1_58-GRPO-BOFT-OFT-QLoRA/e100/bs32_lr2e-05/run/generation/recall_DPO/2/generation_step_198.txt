# Word embeddings, attention, and tokenization

At the heart of language modeling lies the concept of word embeddings. A word embedding is a numerical representation of a word, typically stored as a matrix of dimensionality $d$. Each row of the matrix corresponds to a unique word, and each column corresponds to a particular context or position within a sentence. For example, if we have a 768-dimensional word embedding matrix, then each row represents a unique word, and the columns represent positions within a sentence. The size of the embedding matrix determines the number of unique words that can be represented.

Attention is a mechanism that allows a model to focus on certain parts of a sequence while ignoring other parts. In language modeling, attention is used to determine which tokens in a sequence are most important for generating the next token. The attention mechanism is implemented as a matrix multiplication between two matrices: the query matrix, which contains the indices of the tokens that are being considered, and the key matrix, which contains the numerical values of the tokens that are considered. The output of the attention mechanism is the weighted sum of the queries, keys, and values, which is then used to compute the predicted token for the current position.
