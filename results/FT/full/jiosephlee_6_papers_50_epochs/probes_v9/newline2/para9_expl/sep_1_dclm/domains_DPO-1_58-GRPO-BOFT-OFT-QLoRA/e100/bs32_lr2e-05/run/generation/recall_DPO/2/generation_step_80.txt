Introduction

Human-in-the-loop evaluation (HITL) is a technique for assessing the quality of machine learning models by having humans evaluate the outputs produced by those models. HITL is particularly important for language models because it allows us to measure how well a model understands human preferences and whether it is producing outputs that are consistent with human preferences. In this chapter, we will discuss the basic principles of HITL, the different types of HITL experiments that are commonly used, the challenges of conducting HITL experiments, and the practical considerations that must be taken into account when designing and running HITL experiments.

Principles of HITL

At its core, HITL is a way to collect feedback from humans about the outputs produced by a machine learning model. There are two main components to HITL: the model and the human interface. The model is the machine learning model that produces outputs based on input data. The human interface is the mechanism through which humans provide feedback to the model. There are several different ways to implement a human interface, but the most common approach is to use a web-based interface where users can type in responses to prompts and then submit their answers. The model is trained to predict the correct answer from the user's input, and the human interface is designed to make it easy for users to provide accurate feedback.

There are several key principles that underlie HITL experiments. First, the goal of HITL is to collect reliable and valid feedback from humans about the model's outputs. To ensure that the feedback is reliable, it is important to design the human interface so that it is easy for users to provide meaningful feedback. Second, the feedback should be actionable. That is, the feedback should be structured in a way that allows the model to learn from it. Third, the feedback should be representative of the real-world usage of the model. That is, the model should be exposed to diverse inputs and outputs so that it can generalize to those inputs. Finally, the feedback should be collected in a timely manner so that the model can update its behavior based on the feedback.
