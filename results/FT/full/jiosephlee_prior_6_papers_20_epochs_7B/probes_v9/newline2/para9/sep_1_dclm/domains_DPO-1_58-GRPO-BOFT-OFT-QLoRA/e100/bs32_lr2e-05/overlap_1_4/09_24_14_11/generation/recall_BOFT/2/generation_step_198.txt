# Orthogonal Finetuning and Orthogonal Butterfly

This section introduces the OFT and BOft approaches, along with their benefits and drawbacks.

## Orthogonal Finetuning

Orthogonal Finetuning (or OFT) is a finetuning technique that maintains the angular similarity between neurons in the pretrained model by ensuring that the finetuned weights are orthogonal. To achieve this, OFT updates the weights using the following equation:

$w_{i}^{(f)} = Rw_{i}^{(\text{init})}$

where $w_i^{(f)}$ represents the updated weight vector for neuron $i$, $w_i^{(\text{init])]}$ is the initial weight vector from the pretrained model, and $R$ is an orthogonal matrix that is learned during finetuning. The primary advantage of OFT is that it preserves the semantic information present in the pretrained model by maintaining the pairwise angles between neurons. This property is particularly important when adapting large models to downstream tasks, as it helps to mitigate catastrophic forgetting. However, OFT has two significant drawbacks. Firstly, OFT requires a full orthogonal matrix $R \in \mathbb{R}^{d\times d}$, where $d$ is the dimensionality of the model weights. Consequently, OFT typically has a higher number of trainable parameters than other finetuning methods. Secondly, OFT does not allow for sharing of parameters across neurons, which can be inefficient when adapting large models.

To address the first limitation, previous work has explored the use of block-diagonal orthogonal matrices in OFT. A block-diagonal orthogonal matrix partitions the original orthogonal matrix into multiple smaller orthogonal matrices, each operating on a subset of neurons. For example, a $b$-block-diagonal orthogonal matrix can be expressed as:

$R = \text{diag}(R_1, R_2, \cdots, R_b)$,

where $R_i$ is a $d_i \times d_i$ orthogonal matrix for $i=1,\cdots,b$. By adjusting the block sizes $d_1,\cdots,d_b$, one can control the parameter efficiency of OFTs. While this approach reduces the number of trainable parameters, it also introduces a new problem: the block-diagonal structure may cause the orthogonal transformation to be less smooth, which can degrade the performance of the finetuned model. To better understand this issue, consider the case of a fully block-diagonal orthogonal matrix with $d=d_1=\cdots=d_b=1$. In this scenario, the orthogonal transformation becomes equivalent to applying separate orthogonal transformations independently to each neuron, effectively reducing OFT to a set of independent weight updates—similar to the standard weight update used in most finetuning methods. Although this configuration achieves maximum parameter efficiency, it often leads to poor generalization and unstable training. On the other hand, if all blocks have the same size, i.e., $d_1=\cdots =d_b=d$, the orthogonal matrix becomes fully dense, resulting in a parameter count similar to that of the original OFT. Thus, finding an appropriate balance between parameter efficiency and the smoothness of the orthogonal transformation is crucial for improving the performance of OFT.
