According to the paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models", what is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GR PO) is a variant of Proximal Policy Optimization (PPO). In GRPO, the advantage estimate is computed as the difference between the policy value of a group of samples and the policy value of a reference sample. This approach is particularly useful in mathematical reasoning tasks, where the reward signal is often sparse and noisy. In DeepSeekMath, GRPO is used to train the model on the MATH dataset.

Here is the original paper that introduces GRPO: 
```

}
```

The intuition behind GRPO is that it computes the advantage as the difference between the group of samples' policy value and the reference sample's policy value. This is done to reduce variance in the advantage estimation, which is especially important when the reward signal is noisy or sparse. In mathematical reasoning tasks, the reward signal is often noisy, so using GRPO can help improve training stability.

Here is how GRPO is implemented in DeepSeekMath:

1. For each input prompt, generate a set of candidate responses from the model.
2. For each candidate response, generate a set of completions by sampling from the same policy model.
3. Compute the policy value for each candidate response and the completions of that response.
4. The advantage for the candidate response is the difference between the policy values of the candidate response and the mean policy value of its completions.
5. Use the advantage to update the policy model using PPO.

This approach helps reduce the variance in the advantage estimation by comparing the candidate response to a set of completions, rather than to a single completion. It also allows the model to be trained using only a single completion per candidate response, which reduces the computational cost of training.<|endoftext|>
