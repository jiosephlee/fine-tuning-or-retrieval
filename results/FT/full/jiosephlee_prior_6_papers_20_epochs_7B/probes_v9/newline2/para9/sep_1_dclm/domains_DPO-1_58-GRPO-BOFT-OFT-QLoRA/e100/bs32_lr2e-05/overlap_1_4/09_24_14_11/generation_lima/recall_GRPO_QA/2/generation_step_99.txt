However, PPO requires keeping track of a running mean and variance for each action, which can be memory-intensive for very large action spaces. ## Proximal Policy Optimization (PPA)

Proximal Policy Optimization is a reinforcement learning algorithm used for training large language models. It is based on the actor-critic paradigm, where a critic network estimates the value function and provides a baseline for comparing the performance of the current policy against a reference policy. The objective of PPO is to maximize the advantage estimated by the critic, while constraining the KL-divergence between the current policy and a reference policy. This constraint helps to ensure that the policy updates are not too drastic, thereby reducing the instability associated with direct maximization of the advantage.

The optimization objective for PPO can be written as:

$\max_{\theta}\mathbb{E}_{(s,a,r,s')\sim \pi_\text{old}(s,a)}\left[\frac{\beta}{\epsilon}\left\{A(s,a,r,s') - \epsilon\operatorname{clip}\left(\dfrac{\hat{q}_\text{critic}(s,a) - \hat{q}_\mathrm{ref}(s,a)}{\sqrt{\epsilon}}, -1, 1)\right)\right\}\right]$

where $\hat{q}_\textrm{critic}$ is the advantage estimated by the learned critic, $\hat{q}_\$ref$ is the advantage estimated by a reference policy, $\epsilon$ is a small value to regularize the clipping, and $\beta$ controls the weighting between the advantage and the KL term. The advantage is computed as $\hat{q}_\(s,a) = \widetilde{V}(s, a, s') - \widetilde{Q}(s, a)$, where $\widetilde{V}$ is the value function learned by the critic and $\widetilde{Q}$ is the value function under the reference policy.

To solve this optimization problem, we take the derivative of the objective with respect to the parameters $\theta$ of the policy, and obtain the following update rule:

$\theta \leftarrow \theta - \eta \nabla_\theta\mathbb{E}_{\tau\sim \pi_\textrm{old}(s,a;\theta)}\left[\frac{1}{|{\tau}|} \sum_{t=1}^{|{\tau}|} \underbrace{\nabla_\theta \log \pi_{\theta}(a_t | s_t; \theta)}_{\text{step}} \cdot \underbrace{\beta \hat{A}^\top(s_t, a_t, s_{<t}, \phi; \eta)}_{\text{adv}}\right]$

Here, $\hat{A}$ is the advantage, which is computed using the value functions learned from the same policy $\pi_\theta$. The value function for each state is updated recursively as $s \leftarrow s + \hat{A}s$, where $s$ represents a vector of state features. In practice, it is common to use a running mean of rewards instead of the true reward at each step. This leads to the following update for the value function:

$\widetilde{V}_\text{old}(s) = \alpha \widetilde{C}(s) + (1-\alpha)\widetilde{V}_{\text{old}}(s)$

where $\widetilde{C}$ is the running mean of rewards, initialized with zero, and $\alpha$ is a coefficient typically set to $0.95$. The running mean $\widetilde{c}$ is updated after every timestep as $\widetilde{ c } = 0.05 \widetilde{ c  } + r$, where $r$ is the reward at the current timestep. Since the running mean is kept for every action, the memory complexity of PPO is $\mathcal{O}\left(|A|\right)$, where $|A|$ is the size of the action space. For LLMs, which have very large action spaces, this can be a significant memory bottleneck.
