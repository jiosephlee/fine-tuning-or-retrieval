What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient orthogonal finetuning method that leverages butterfly parameterization. BOFT is parameter-efficient because it uses a sparse matrix factorization to represent an orthogonal matrix. This sparsity is achieved by using a butterfly structure, which is a well-known technique for constructing sparse matrices. The butterfly structure is also known as the Cooley-Tukey structure, named after its inventors, and is commonly used in the fast Fourier transform algorithm.

To understand how BOFT works, it is helpful to first review the standard OFT method. In OFT, the finetuning is performed by applying a small orthogonal transformation to the pretrained weight matrix. Specifically, OFT learns a small orthogonal matrix $R \in \mathbb{R}^{d \times d}$ and updates the pretrained weight matrix $\mathbf{W}^0 \in \mathbb*{R}^{d\times n}$ as $\mathbf{W}(m) = \mathbf{W}^{0} (1+m\,R)$. This approach is parameter-efficient because the number of learnable parameters is $d(d-1)/2$, which is much smaller than the number of parameters in $\mathbf{W}$.

BOFT improves on this by using a butterfly parameterization to represent the orthogonal matrix $R$. A butterfly parameterization expresses a square matrix as a product of several sparse matrices. In particular, BOFT represents $R$ as
$$
R = \tilde{R}_B \tilde{R}_{B/2} \cdots \tilde{R_1},
$$
where each $\tilde{R}_i$ is a $2i$ by $2i$ orthogonal matrix. The matrix $\tilde{R}$ is called a butterfly matrix, and it has the form
$$
\tilde{R} = \begin{bmatrix}
\text{diag}(1,\omega_1,\omega_2,\cdots,\omega_{i}) & \text{diag}(1,j_1,j_2,\cdots,j_{i/2}) \\
\text{diag}(j_1,\cdots,j_{1+\ell_1},1,\cdots,1) & \text{diag}(\omega_{1+\ell_2},\cdots,\omega_{1+\ell_{1}+\ell_2},1,\cdots 1)
\end{bmatrix},
$$
where $\omega_i$ are complex roots of unity, and $j_k$ are $2i$-th roots of $-1$. The matrix $\tilde R_B$ is a block butterfly matrix, where each block $\tilde R_{B/2}$ is a butterfly matrix. The matrix $\mathbf{R}(m)$ is then defined as
$$
\mathbf{R}(B,m) = \tilde{B}_m \tilde{B}^{(1)}_m \cdots \tilte{B}_1,
$$
where each $\mathbf{B}_i$ is a block butterfly with block size $2i$. The matrix $\mathbf R(m)$ is then used to update the pretrained weight matrix as
$$
\begin{aligned}
\mathbf{W}(B,m) &= \mathbf{W}_0 (1 + m\,\mathbf{R}(1,m)) \\
&= \mathbf{W}_{0}^{(1)} (1 + m\, \mathbf{B}_1) \cdots \mathbf{W }_{0}^{(B-1)} (1 +  m\, \mathbt{B}_{B-1}).
\end{aligned}
$$
This approach is parameter-efficient because it reduces the number of learnable degrees of freedom from $d(d-1)$ to $\log d$, while still maintaining the orthogonality of the transformation.

The paper also introduces a block-diagonal variant of BOFT, which further reduces the number of learnables to $\mathcal O(d\log d / \log \log d)$. This variant uses block butterfly matrices, where each block is a $2i \times 2i$ orthogonal matrix, and the block size is $d = 2^{\log \log d}$.
