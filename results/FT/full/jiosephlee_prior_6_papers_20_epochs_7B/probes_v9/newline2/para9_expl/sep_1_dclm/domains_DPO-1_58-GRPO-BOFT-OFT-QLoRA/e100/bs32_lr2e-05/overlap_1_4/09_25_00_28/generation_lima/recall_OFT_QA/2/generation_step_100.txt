What is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT) is a method for finetuning large pretrained models, such as text-to-image diffusion models, while preserving the geometry of the pretrained weights. The key idea behind OFT is to learn an orthogonal transformation for each layer, which leaves the pairwise angles between neurons unchanged. This is achieved by solving a small linear system at each layer, which can be done efficiently using the Cayley transform. OFT has been shown to be more data-efficient than standard finetuning and additive methods like LoRA, while also being more stable and producing better results.

Here is a more detailed explanation of how OFT works:

* **Orthogonal Transformation**: An orthogonal transformation is a linear transformation that preserves the inner product of vectors. In other words, if $Q$ is an orthogonal matrix, then $\mathbf{Q}^\top \mathbf{v} = \mathbf{v}$ for any vector $\mathbf{v}$. This means that the pairwise angles between neurons are preserved under an orthogonal transformation.
* **Cayley Transform**: The Cayley transform is a way to construct an orthogonal matrix from a skew-symmetric matrix. A matrix $\mathbf{S}$ is skew-symmetric if $\mathbf{S}^\top = -\mathbf{S}$. The Cayley transform of $\mathbf{S)$ is defined as $\mathbf{C}(\mathbf{S}) = (\mathbf{I} - \mathbf{S})(\mathbf{I} + \mathbf{S})^{-1}$, where $\mathbf{I}$ is the identity matrix. It can be shown that $\mathbf{C(\mathbf{S)}}$ is orthogonal if $\mathbf{ S}$ is skew-symmetric.
* **OFT Algorithm**: The OFT algorithm is simple. For each layer, you first compute the gradient of the loss with respect to the weights. Then, you construct a skew-symmetric matrix $\mathbf{ S}_l$ from the gradient by setting $\mathbf{ S}_{li} = \frac{1}{2}(\nabla_{\mathbf{w}_i} \ell - \nabla_{\ mathbf{w}_j} \ell)$, where $\ell$ is the loss and $\mathbf{w}_j$ are the weights of the other neurons in the layer. You then solve the linear system $\mathbf{C}_l(\mathbf{S}_l) = \mathbf{I}$ to obtain the orthogonal matrix $\mathbf{C_l}(\mathbf{ S}_L)$. Finally, you apply the orthogonal transformation to the pretrained weights to get the finetuned weights: $\mathbf{W}^f = \mathbf{R}\mathbf{W}^{0}$, where $\mathbit{R} = \mathbf C_l(\mathbf{S_l})$.
* **Why OFT Preserves Geometric Properties**: The key property of orthogonal transformations is that they preserve the pairwise angles between neurons. This is because the cosine of the angle between two neurons is equal to the inner product of their gradients, which is preserved under an orthogonal transformation. Preserving the pairwise angles is important because it preserves the relative positions of neurons in the feature space, which is crucial for maintaining the semantic structure of the model.
* **Efficiency of OFT**: The Cayley transform can be computed efficiently using the formula $\mathbf{C}\mathbf{S}\mathbf{C}^\top = \mathbf{S}^2 - \mathbf{I}$. This allows you to compute $\mathbf{C}$ from $\mathbf{S}_L$ in a single matrix multiplication. Additionally, the linear system $\mathbit{C}\mathbit{S}=\mathbit{I}$ can be solved using Gaussian elimination, which is efficient even for large matrices.

## Advantages of OFT

* **Data Efficiency**: OFT has been shown in the paper to be more data-efficient compared to standard finetuning and LoRA. This is because OFT preserves the geometry of the pretrained model, which helps the model generalize better to the finetuning task with fewer examples.
* **Stability**: OFT is also more stable than standard finetuning. This is because the orthogonal transformation is applied to all neurons in a layer simultaneously, which helps to regularize the finetuning process and prevents large changes to the weights.
* **Better Results**: In the paper, OFT was used to finetune Stable Diffusion v1.5 to the CLIP-GT dataset, and it produced better results than standard finetuning, LoRA, and LoRA with a projection to the hypersphere. The results included higher CLIP scores and better visual quality.
