QLoRA (Quantized Low-rank Adapters) is a method for finetuning large language models (LLMs) using 4-bit weights and 16-bit activations. The key idea behind QLoRA is to quantize only the adapter modules, while keeping the pretrained model in high precision. Adapter modules are typically small modules added to the pretrained model to achieve task-specific finetuning. QLoRA achieves significant memory savings compared to full 16-bit finetunes, while maintaining performance.

# How does QLoRA work?

The core idea of QLoRA is to represent the low-rank weight matrices of adapters using a small number of bits (e.g. 4-bit), and use a higher precision (e.g. 16-bit) to represent the remaining part of the weights. Concretely, QLoRA quantizes the weight matrices of adapters into the following form:

$$
W = \begin{bmatrix}
\mathrm{LoRA}(4bit, k) \\

where $\mathrm{LoRA}(k)$ denotes a Low-rank Adapters (LoRA) with rank $k$, and $0$ denotes the pretrained weights. The paper shows that for many adapter modules, the bottom part is close to zero, so it can be safely set to $0$ without significant performance loss. This allows QLoRA to represent the adapter weights using only a small number of bits for the LoRA part, while keeping the rest of the weights in high precision.
