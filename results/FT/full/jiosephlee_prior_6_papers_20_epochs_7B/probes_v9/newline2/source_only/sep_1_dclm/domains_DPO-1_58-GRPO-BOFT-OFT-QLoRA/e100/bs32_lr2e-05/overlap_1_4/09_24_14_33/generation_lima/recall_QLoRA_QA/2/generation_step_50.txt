The main challenge with quantization is that it can easily introduce quantization error, which degrades the performance of the model.

Double Quantization
------------------

Instead of directly quantizing the weights from 16-bit to e.g. 4-bit, QLoRA first quantizes the weights from 16-bits to 8-bits, and then from 8-bits to 4-bits. This approach has been shown to reduce the quantization error significantly.

---------------------------

The second technique used in QLoRA is called reconstructive quantization. The basic idea behind this technique is to use a different quantization window for every quantization level. To achieve this, QLoRA first performs a single forward pass after each training step to generate sample activations. These activations are then used as the quantization window for the weights. This way, the quantization windows are based on the current activation statistics, which are assumed to be a good approximation of the underlying weight distribution.
