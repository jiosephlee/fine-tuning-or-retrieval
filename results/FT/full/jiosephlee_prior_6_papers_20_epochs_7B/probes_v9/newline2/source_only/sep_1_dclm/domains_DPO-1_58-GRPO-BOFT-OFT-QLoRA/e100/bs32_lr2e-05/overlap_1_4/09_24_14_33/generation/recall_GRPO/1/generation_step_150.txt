# What is DeepSeekMath?

DeepSeekMath is an open-source project that aims to build the world's most powerful mathematical reasoning language model. It is based on DeepSeek-Coder-v1.5-BERT-Base-cased with 65B tokens. The training data comes from arXiv, StackExchange, textbooks, and other high-quality sources. The training process includes:

- Pre-training on a large-scale mathematical corpus (65B tokens) with a new instruction tuning strategy.
- Fine-tuning on a benchmark dataset (8B tokens) including arXiv papers, textbooks, and mathematical challenges.

The final model achieves impressive performance on mathematical reasoning benchmarks. It outperforms all open-source models and most proprietary models. You can find more details in the paper.

# How does DeepSeekMath train its model?

DeepSeekMath uses a two-stage training process. In the first stage, it pre-trains the base model on a large-scale mathematical dataset (65B tokens). In the second stage, it fine-tunes the base model on mathematical benchmarks (8B tokens).

Stage 1: Pre-training

The pre-training corpus is composed of 65B tokens, which is 20 times the size of the training data of GPT-4. It includes arXiv papers, StackExchange posts, textbooks, and other mathematical resources. To ensure the quality of the data, DeepSeekMath uses a filtering strategy to remove low-quality data. The filtered corpus contains 57B tokens.

To train the model, DeepSeekMath uses an instruction tuning strategy. It optimizes the model to predict the next token given an input prompt and a reference solution. The loss function is the negative log-likelihood of the next token conditioned on the prompt and the reference solution. It also incorporates a reinforcement signal to encourage the model to generate solutions similar to the reference solution.

Stage 2: Fine-tuning

After the pre-training stage, DeepSeekMath fine-tunes the base models on mathematical benchmarks. The benchmarks include arXiv papers, mathematical challenges, and textbooks. The arXiv papers are selected using a topic filtering strategy. The mathematical challenges and textbooks are used for fine-tuning.

DeepSeekMath uses a multi-task learning framework to fine-tune the base model. It optimizes the base model to perform well on multiple tasks simultaneously. The tasks include arithmetic, algebra, calculus, linear algebra, number theory, and geometry. For each task, the model is fine-tuned on a subset of mathematical challenges related to the task.

# What are the technical details of DeepSeekMath?

The technical details of DeepSeek-Math include the pre-training corpus, the training objectives, the training hyperparameters, and the evaluation setup.

Pre-training Corpus

The pre-training corpus includes arXiv papers (25B tokens), StackExchange posts (10B tokens), textbooks (7B tokens), and other mathematical resources (13B tokens). The arXiv papers include math-related papers only. The StackExchange posts are filtered to keep only the posts with at least one math-related tag. The textbooks are selected from the OpenBookProject. Other mathematical resources include books, articles, and websites.

Training Objectives

During the pre-training stage, the model is trained to predict the next token conditioned on an input prompt and a human-written reference solution. The loss functions are the negative log-likelihood for the next token and a reinforcement signal to encourage solutions similar to the reference solutions.

During the fine-tuning stage, the model is fine tuned on multiple mathematical tasks simultaneously. For each task, there is a corresponding dataset of mathematical challenges. The model is optimized to maximize the likelihood of the correct answer in the challenge given the input prompt and its own generated output. In addition, a reinforcement signal is used to encourage the model to produce solutions similar to the ground-truth solutions in the dataset.
