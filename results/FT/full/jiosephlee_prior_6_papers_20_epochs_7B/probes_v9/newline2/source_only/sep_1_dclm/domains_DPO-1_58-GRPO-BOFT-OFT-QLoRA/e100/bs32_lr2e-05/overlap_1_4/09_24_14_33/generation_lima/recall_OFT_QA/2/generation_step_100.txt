## Standard finetuning vs LoRA

Standard finetuning is to directly optimize the pretrained weight matrix as follows:
```Θ = Θ - η ∂L(Θ) ∂Θ
```
where η is the learning rate and L is the finetuning loss.

LoRA (Low-rank Adversarial Finetuning) approximates the derivative with a low-rank matrix:
```Θ =  Θ - η * α * L_η
```
where `L_η` is a low-rank matrix defined as:
```L_η = α * Rank(Θ) * S_η
```
with some scalar α > 0. It introduces a new hyperparameter λ to constrain the rank:
```Rank(Θ) <= λ * Rank(�Theta_0)
```
where Θ_0 is the pretrained weight matrix.

Both standard finetuning and LoRA can effectively train the model for the task while destroying the semantic preserved in the pretrained weights. This is because both methods change the pretrained weight matrices while destroying the relationships between the neurons in different layers.

## Orthogonal Finetuning

Orthogonal Finetuning aims to preserve the pairwise angles between neurons, so it only changes the activation directions without changing the angles. It achieves this by only changing the activation vectors in the eigenbasis that is orthogonal to all the pretraining activation vectors. In other words, OFT only updates the part of the weight matrix that is orthogonal to the pretrained weight matrix.

Formally, the weight matrix is rewritten in its singular value decomposition as:
```Θ = U Σ V^T
```
where `U, V` are orthogonal matrice and `Σ` is a diagonal matrix of singular values. Both `U` and `V` are the eigenbasis of the weight matrix. The first column of `U` and `W` of `V` are the eigenvectors of `Θ Θ^T` and `Θ^T Θ` respectively, and all the singular values are non-negative. The j-th column of `U` is the eigenbasis that is orthogonal to the subspace spanned by the first (j-1) columns of `U`. OFT updates the subspace spanned bye the columns of `V` (the first column of `U`) since the other subspace are already orthogonal to all the pre-training neurons.

So OFT only updates the first column of `U`, and rewrites as:
```Θ'O = U Σ' T  where Σ' is the same as Σ and the first column of U' is the first column of U plus the update in the eigenbasis determined by the first column of V.
```
To summarize, OFT only updates part of the weight matrix, so it is able to perform finetuning without destroying the semantic information preserved in the pretrained model.<|endoftext|>
