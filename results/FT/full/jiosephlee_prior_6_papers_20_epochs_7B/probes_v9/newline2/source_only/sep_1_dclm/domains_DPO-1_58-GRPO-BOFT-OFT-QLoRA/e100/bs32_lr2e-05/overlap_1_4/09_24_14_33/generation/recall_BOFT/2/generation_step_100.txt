# Overview of Key Ideas

The core idea behind BOFT is to use a butterfly structure to parameterized orthogonal matrices with fewer parameters while preserving the runtime and orthogonalcity guarantees of OFT. To understand how BOFT works, let's first review how OFT works. OFT updates the weight matrix $W\in\mathbb{R}^{d\times n}$ in a linear layer using the following update rule:
\begin{equation}
    W \leftarrow W - \eta \text{diag}(q) \odot (W^\top W),
\end{equation}
where $\eta$ is the learning rate, $q$ is an orthogonal matrix drawn from the orthogonal group $\mathcal{O}(d)$, and $\odot$ denotes the element-wise multiplication. OFT has attractive theoretical properties: the updated weight matrix $W$ is also orthogonal, and the runtime to generate the orthogonal matrix $q$ is the same as the runtime of multiplying $W$ by a dense matrix of size $d\times d$. However, OFT uses $d$ neurons to parameterize an orthogonal matrix of size $d$, resulting in a high bias towards using many parameters. To address this, the BOFT paper proposes to use a butterfly structure, which is a sparse matrix that can be used to represent an orthogonal matrix with far fewer parameters than the number of neurons. The basic idea behind the butterfly structure is to recursively divide the input dimension into two smaller dimensions until a base case is reached, and then recombine these smaller dimensions to reconstruct the original input dimension.
