Finetuning large language models (LLMs) is an active research area, with a vast number of applications and a similarly vast number of methods proposed. One major bottleneck in the application of finetuning LLMs is memory usage, which can be extremely high for very large models. This is particularly true when working with quantized LLMs, where the original pretrained model also needs to be loaded into memory. The paper "QLoRA : Efficient Finetuning of Quantumized LLMs" by Yang et al. introduces a method called QLoRA (Quantumized LLM finetuning with Knowledge Intensive Optimization) which addresses this memory issue. While the paper has received significant attention, it also came with some criticism, mainly regarding the exact nature of the improvements. In the following, we give an overview of the method described in the paper. 

Note that this summary is based on the version 1.0 of the paper, and not on any subsequent publication or preprints. 
# How does QLoRA work?

The central idea behind QLoRA is to reduce memory usage during finetuning by only storing the weights for a small subset of neurons that are actually being updated. To achieve this, QLoRA uses a difference-of-Exponential (DE) distribution to select neurons for update. The DE distribution is defined as
```p(x) = \frac{1}{2} e^{-x/\tau_1} + \frac{1}{1+e^{-\tau_2 (x-\mu)}} - \frac{1}{(1+\sigma)e^{-\tau_3 x}} ,
```
where $\mu$, $\sigma$, $\tau_1$, $\tau_2$ and $\tau_3$ are hyperparameters. This distribution has the property that it can produce samples that are diverse and can approximate any other distribution. For each training step, new neurons are sampled from the DE distribution, and then added to the set of neurons that need to be stored. It is important to note that the neurons selected in this way are not necessarily the best neurons to improve the loss, but rather a sample from a specific distribution. 

Once the neurons that need to be store have been determined, QLoRA proceeds to actually perform the update. The paper states that the standard approach to perform such updates is to load the entire pretrained model (or at least a significant portion of it) into memory, which can be very expensive. Instead, QLoRA uses knowledge intensive optimization (KIO), an approach that was introduced in the paper "KIO: Finetuning Large Language Models without Loading the Pretrained Weight Matrix". KIO uses a factorization of the weight matrix such that it no longer needs to be loaded into main memory, but only the factors that are needed for the update. The authors of QLoRA introduce several improvements to the original KIO approach, including a more efficient factorization and a method to combine multiple updates into a single step to further reduce overhead.

Finally, after each training step, the performance of the model is evaluated using a validation set. If the validation loss has not improved after a certain number of steps, the training is stopped. This is done to prevent the model from deteriorating due to the constrained parameter space of the quantized weights.
# What are the advantages and disadvantages of QLoRA?

As mentioned above, the central advantage of QLoRA is its ability to significantly reduce memory usage during fineting. The paper reports that for a 7B model, 16-bit finetunig requires 16 GB of GPU memory, while QLoRA only requires 1 GB. This makes it possible to finetune models that would otherwise be too large to be feasible.

Another advantage of QLoRA, which is mentioned in the paper, is that it can be used together with low-rank factorization of the weight matrices. Combining low-rank factorization with QLoRA can further reduce memory requirements and increase efficiency.

However, QLoRA also has some disadvantages. Firstly, it introduces additional hyperparameters, which can make tuning more difficult. Secondly, it requires loading the pretrained model into memory, which can still be very expensive, although it is less so than full finetuning. Finally, the paper notes that the performance of QLoRA can be worse than full 16-bit finetunning, although it is still better than the original method for performing finetuning on quantized models (i.e. the method introduced in "KIO").<|endoftext|>
