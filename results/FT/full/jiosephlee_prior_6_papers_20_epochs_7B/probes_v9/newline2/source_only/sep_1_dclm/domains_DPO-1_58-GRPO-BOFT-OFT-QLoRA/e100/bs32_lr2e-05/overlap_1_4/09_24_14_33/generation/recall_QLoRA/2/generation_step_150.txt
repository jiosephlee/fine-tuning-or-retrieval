# Activation Bit Budget

The core idea behind QLoRA is to limit the number of bits used per token for activations during training, in order to reduce the memory footprint significantly. To do so, QLoRA introduces a new hyperparameter called the "activation bit budget": a fixed number of bits (in bits) that can be used per token for activations. For example, a budget of 18 bits means that for each token, the model may use a maximum of 18 bits for its corresponding activations. This budget is shared across all layers and all tokens.

To enforce this budget, QLoRA rescales the activations of each layer by a constant before the non-linear activation function. This rescaling is done using the inverse of the exponential of the budget divided by the number of bits used by the kernel. For example, if the budget is 18 bits and the kernel uses 4 bits, then the rescaling factor would be the inverse of the exponential(18/4), or approximately 12. This rescaling ensures that the effective dynamic range of the activations is limited to the budget specified.

Formally, given a budget $B$ and a kernel with $b$ bits, the rescaling factor $\sigma$ is computed as:

$\sigma = \frac{1}{\text{exp}( \frac{B}{b} )}$

The rescaled activations $\hat{a}$ are then computed as:

$\hat{a} = \sigma \cdot a$

Where $a$ is the standard activation (before non-linear activation).

This rescaling mechanism effectively limits the number of significant bits used for activations to the specified budget, while preserving the relative relationships between activations. This is crucial, as it allows the network to still learn from the data despite limiting the effective precision of the activations.

# Training Procedure

The training procedure used in QLoRA is identical to the standard cross-entropy finetuning procedure. The only difference is the introduction of the activation bit budget, which limits the number of bits that can be used for activations during training.

$L = \frac{1]{B}\sum_{i=1}^B \left( y^{(i)} log \sigma_h(w^T x^{(i)} ) + (1 - y^{(i)}) log (1 - \sigma_h(w^ T x^{(i)} )) \right)$

Where $w$ is the quantized weight matrix, $x$ is the input vector, and $\sigma_h$ is the hyperbolic tangent non-linear activation function.
