The Basics

The basic idea of DPO is to use a language model as a reward model. In other words, we can use a language model to score actions in an RL setting. This is done by sampling from the language model given an initial state $s$ and an action $a$. The sampled text $x$ is then scored by the reward function $r(s, a, x)$, which gives us the reward for taking action $a$ in state $s$ and getting response $x$. The goal of the RL agent is to maximize the expected reward $\mathbb{E}_{p(x|s, a)}[r(s, a, X)]$.

In the DPO paper, the authors use a variant of this approach where they sample multiple responses $x_1, x_2, \dots, x_N$ for each action $a$ in each state $s$. They then average the rewards for each action to get a single reward value for each action in each state. This is done because sampling from language models is noisy, and averaging reduces the variance of the reward estimates.

The authors also introduce a weighting function $w(r, s, a)$ that assigns different levels of trust to different rewards in different states. This is useful because some states might be more difficult to generate high-quality responses for than others. For example, if the state is "knock knock" then it might be easy to generate good responses, but if the state is "what comes after 11" then it might be hard. The weighting function allows the RL agent to put more trust in its reward estimates in easy states and less trust in its reward estimates for hard states.

The Advanced Stuff

Now let's get into the more advanced stuff. One of the key insights in the DPO paper is that we can use the language model likelihood $p(x|s, y)$ as a proxy for the reward function $r$. In other words, we assume that the better a response $y$ is, the higher the probability $p(x|s,y)$ that the language model will sample $x$ given the initial state $s$and the response $y$. This assumption is reasonable because language models are trained to assign higher probabilities to more probable texts, and well-formed responses are more probable than random garbage.

Once we make this assumption, we can reframe the RL problem as an optimization problem over the language model. Instead of training an RL agent to choose actions that maximize expected reward, we can train the language model to assign high probabilities to good responses and low probabilities to bad responses. This is the core insight of DPO: we can use supervised learning to train a language model as a proxy for reinforcement learning.

Formally, the DPO objective is to maximize the expected log-likelihood of responses $y$ given an initial state $x$:

$\max_{p(x,y)} \mathbb{E}_{x\sim p(x), y\sim p(y|x)}[\log p(x, y)] = \mathbb{E}_x\mathbb{E}_{y\mid x}\left[\log p(y\mid x)\right]$

This is equivalent to minimizing the negative log-likelihood:

$\min_{p(x,y)} -\mathbb{E}_xF_{y\mid x}(y) = -\mathbb{D}_{KL}\left(p(x,y) \mid \mid p(x)p(y\mid x)\ right)$

where $F_{y\mid x}$ is the conditional distribution of $y$ given $x$.

Notice that the DPO objective does not depend on the reward function $r$ at all. It only depends on the joint distribution $p(x,y)$. This is a key advantage of DPO: it avoids the need to estimate or specify the reward function explicitly. Instead, the reward function is implicitly defined by the quality of the responses that the language model assigns high probabilities to.

However, there is a catch. The DPO objective assumes that the language model assigns higher probabilities to better responses, but this is not always the case. Language models can have biases and mistakes, just like any other model.
