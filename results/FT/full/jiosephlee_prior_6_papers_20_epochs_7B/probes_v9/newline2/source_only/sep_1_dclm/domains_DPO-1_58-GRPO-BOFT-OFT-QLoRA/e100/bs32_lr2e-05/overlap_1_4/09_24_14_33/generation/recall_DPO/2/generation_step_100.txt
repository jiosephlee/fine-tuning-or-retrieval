# Background

Reinforcement Learning from Human Feedback (RLHF) is a popular approach to training language models to satisfy user preferences. In the RLHF pipeline, a reward model is trained on a dataset of human preferences to approximate the true preference function. Once the reward model is trained, it is used to provide feedback to a language model, which is then fine-tuned using reinforcement learning. Despite its popularity, the RLHF pipeline has a number of limitations. First, it requires two stages of model training: first, training the reward model; and second, fine tuning the language model using reinforcement learning. This can be time-consuming and inefficient. Second, the RLHF pipeline relies on the assumption that the reward model accurately approximates the true preference function. If the reward model is not well-calibrated, it can lead to poor performance. Third, the RLHF pipeline can be unstable, particularly when using algorithms like Proximal Policy Optimization (PPO), which can easily get stuck in local optima. Fourth, the RLHF pipeline requires a large dataset of humanpreferences to train the reward model. Collecting such a dataset can be expensive and time-consuming. Finally, the RLHF pipeline is computationally intensive, requiring both training a reward model and performing reinforcement learning on a language model.

To address these limitations, researchers have proposed a number of approaches to improve the RLHF pipeline. One line of work has focused on improving the reward model. For example, some methods use neural networks to estimate the reward function (Christiano et al., 2017; Hadfield-Menell et al., 2016; Levine et al., 2018; Weston et al., 2015).
