Motivation

The motivation is to reduce the number of trainable parameters in finetuning models. The authors use the example of a pretrained Transformer model. They say that the number of trainable parameters is 10 times the number of parameters in the pretrained model. This is because the standard finetuning strategy uses full matrix multiplication for updating the weights. For example, if the pretrained model has $d$ hidden dimensions, the standard finetuning updates the weights as follows:

$W^f = W^0 + \beta B$

where $W^0$ is the pretrained weights, $W^f$ is the finetuned weights, $\beta$ is the learning rate, and $B$ is a bias matrix with the same size as $W^0$. The problem is that $B$ has the same number of parameters as $W^0$, so the total number of trainable parameters becomes $d$ times larger.

Background

The standard finetuning strategy is called identity-based finetuning. It updates the weights using the following equation:

$W^f(t) = W^0(t) + \beta B$

The authors mention two other strategies: low-rank updates and block-diagonal updates. Low-rank updates update the weights using the following formula:

$W^f_{low-rank}(t) = W^0_{low-rack}(t) + \beta R$

where $R$ is a low-rank matrix. Block-diagonal updates divide the weight matrix into blocks and only update some blocks. The block-diagonal update can be written as:

$W^f_block-diagonal(t) = W^f_{block-diagonal}(t) = W_1^0(t) + B_1 + W_2^0(t) +B_2 + ... + W_n^0(t) + b_n$

where $W_i^0$ are submatrices of $W^0$ and $B_i$ are bias matrices with the same size as the corresponding submatrix $W_i^0$. The block-diagonal update reduces the number of trainable parameters by a factor of $n$ compared to the identity-based update.

Contributions

The authors propose a new finetuning strategy called orthogonal finetuning. It reduces the number of trainable parameter by a factor of $\sqrt{d}$ compared to the identity-based finetuning.

The key idea is to update the weights using the product of a weight matrix and a matrix with orthonormal columns. The orthonormal matrix can be written as the product of multiple matrices with orthonormal columns, each with $\sqrt{d}$ columns. Therefore, the number of trainable parameters becomes $\sqrt{d}$ times smaller.

The authors also propose an efficient algorithm to generate the orthonormal matrices. They use the Cayley transform to generate skew-symmetric matrices, and then use the Cholesky decomposition to make the matrices upper triangular with orthonormal columns.

The authors evaluate their method on a pretrained Transformer model. Compared to the identity-based finituning, their method reduces the number of trainable params by a factor of $\approx 7$. Compared to the block-diagonal finetuning, their method reduces it by a factor of $\sim 2$.
