# What is parameter-efficient finetuning?

Parameter-efficient finetuning (PEFT) is a method that can reduce the number of trainable parameters while finetuning a pretrained model. It can be used to prevent overfitting and improve generalizability.

# Why do we need PEFT?

When we finetune a pretrained model, we usually add a small number of trainable parameters to the pretrained model. The added parameters are usually called adapter or head. The adapter is usually very simple, such as a linear layer or a convolution layer with a small kernel size. The adapter is attached to the pretrained model and then the whole model is finetuned on the target dataset.

The adapter is usually very simple and has a small number of trainable parameter. So it seems that the adapter will not cause overfitting. However, in practice, the adapter can still cause overfitting. For example, if we finetune a large pretrained model (e.g., Vision Transformer) on a small dataset, even a small adapter can cause overfitting. To prevent overfitting, we usually reduce the learning rate of the adapter. But reducing the learning rate may also reduce the performance. So how to find a good learning rate for the adapter? This is a difficult problem.

Another problem is that the adapter usually has a strong bias. For example, if the adapter is a linear layer, the output of the linear layer will have a strong bias towards the direction where the input data points lie. If the input data points lie in a certain direction, the output of the adapter will also lie in the same direction. This bias can also cause overfitting.

To solve these problems, we need to reduce the number of trainable parameter in the adapter. One naive way is to use a smaller adapter, such as a linear with a small number of neurons. But this approach may not be effective. A better approach is to reuse some parameters from the pretrained model as the trainable parameters in the adapter. For example, we can reuse the weights of the fully connected layer in the pretrained model as the weights of the linear layer in the adapter. This approach can significantly reduce the number of trainable params in the adapter.

However, reusing weights from the pretrained model as trainable params in the adapter is not straightforward. The main challenge is how to update the reused weights during finetuning. If we simply add a gradient with respect to the loss function to the reused weights, the pretrained model will be destroyed. To address this challenge, the paper "Parameter-Efficent Orthogonal Finetuning" proposes a simple but effective solution -- orthogonal finetuning.

# What is orthogonal finetuning?

Orthogonal finetuning is a method that can update the pretrained model without destroying the pretrained model. It can also improve the generalizability of the pretrained model.

The key idea of orthogonal finetuning is to add a constraint to the gradient with respect to theLoss function. The constraint is that the gradient should be orthogonal to the pretrained model. More specifically, if $w$ is a weight in the pretrained model, $\nabla_{w} \mathcal{L}$ is the gradient with respect to $w$, and $\mathbf{I}$ is an identity matrix with the same size as $w$, then the updated weight $w'$ after orthogonal finetuning is:

$$w' = w - \beta \cdot \mathbf{I} \cdot \nabla_{w}\mathcal{L},$$

where $\beta$ is a hyperparameter.

The above equation can be interpreted as follows. We first update the weight $w$ in the direction of $\nabla_{\mathbf{W}} \mathcal{L}$. Then we update the weight $w'$ in the opposite direction of the pretrained model, i.e., in the direction of $\mathbf{I} * \nabla_{\text{pretrained model}} \mathcal{ L}$, where $\text{pretrained model}$ denotes the entire pretrained model and $\nabla_{ \text{pretrained model} }\mathcal{L}$ denotes the gradient with respect to $\text{pretrained_model}$.

Intuitively, orthogonal finetuning can prevent the pretrained model from being destroyed because the update in the direction of the pretrained model is zero. So the pretrained model remains unchanged.
