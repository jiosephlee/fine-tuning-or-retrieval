# What is orthogonal finetuning?

Orthogonal finetuning is a method to finetune pretrained text-to-image diffusion models without losing the disentanglement property. It can be used to finetune text-to-image diffusion models to improve generation quality, to add new capabilities, or to remove unwanted attributes.

The key idea of orthogonal finetuning is to finetune the text encoder and the diffusion prior in an orthogonal way. The text encoder is finetuned with a standard cross-entropy loss. The diffusion prior is finetuned with an orthogonal finetuning loss. The orthogonal finetuning loss is defined as:

$L_{\text{ortho}}(\theta,\theta') = \frac{1}{2}\|\mathbf{S}(\theta')-\mathbf{S} (\theta)\|_F^2$

where $\mathbf{S} ( \theta )$ is the spectral matrix of the weight matrix $\theta$.

# Why orthogonal finetuning works

To understand why orthogonal finetuning works, we need to know how disentanglement is achieved in text-to-image diffusion models. In text-to-image diffusion models, disentanglement is mainly achieved by two components: the text encoder and the prior network. The text encoder encodes the text token into a vector representation. The prior network generates an image from a random noise vector. The interaction between the text encoder and theprior network is crucial for disentanglement. The text encoder produces a vector representation of the desired attribute, and the prior network transforms the random noise into an image following the instruction from the text encoder.

When we finetune a pretrained text-to-image diffusion model, we need to make sure that the interaction between the text encoderand the prior network remains the same. If the interaction changes, the disentanglement may be destroyed. For example, if we simply use a stochastic gradient descent with a cross-entropy loss to finetune the pretrained text encoder, the weight matrix of the text encoder will be updated. The spectral matrix of the weight matrx will also be updated. Since the prior network is connected to the text encoder, the spectral matrix of the prior network's weight matrix will also be updated. The change of the spectral matrix may change the interaction between the text encoding and the prior network, and thus destroy the disentanglement.

To prevent the spectral matrix of theprior network's weight matrix from changing, orthogonal finetuning keeps the spectral matrix unchanged during finetuning. It only updates the spatial structure of the weight matrix while keeping the spectral matrix the same. As a result, the interaction between the textencoder and the prior network remains thesame, and the disentanglement is preserved.
