The paper "QLoRA: Efficient Finetuning of Quantized LLMs" introduces QLoRA as a method that drastically reduces memory usage compared to standard 16-bit finetuning. What is QLoRA?<|EOT|>Introduction

Finetuning large language models (LLMs) is an active research area, with a vast number of applications and a similarly vast number of methods proposed. One major bottleneck in the application of finetuning LLMs is memory usage, which can be extremely high for very large models. This is particularly true when working with quantized LLMs, where the original pretrained model also needs to be loaded into memory. The paper "QLoRA : Efficient Finetuning of Quantumized LLMs" by Yang et al. introduces a method called QLoRA (Quantumized LLM finetuning with Knowledge Intensive Optimization) which addresses this memory issue. While the paper proposes a number of techniques aimed at reducing memory usage, the most significant one is the so-called block-wise training, which is the key idea behind QLoRA. The other techniques build on top of block-wise training and are used to further reduce memory footprint or improve performance. This answer will focus on explaining the block-wise training method, while the other techniques will only be briefly explained.

Block-wise Training

The central idea of block-wise training is to zero-fill the weights to 4 bytes per parameter (compared to 16 bytes in the original pretrained 16-bit quantized model), and only use a small subset of these zero-filled weights for actual training. This small subset is called the trainable block, and consists of 128 neurons (or 256 in the case of transformer blocks). The number of neurons in the trainable block is then divided by the number of available channels (which is 1 in the case of LLMs), resulting in a ratio of neurons per channel. For example, a 13B LLM has 128 channels (corresponding to the 128 embeddings of a single token), and thus the ratio is 128/2 = 64. This means that each channel gets 64 elements from the neuronal gelu layer, and 64 elements from the vector concatenation layer (see the figure below). The authors also introduce two additional layers, the neuronal gelu layer and the vector concatenation layer, which are used to combine the weights of the different blocks. These two layers are applied 63 times to combine the weights from 63 blocks, in addition to the block that is being trained. This way, the weights of all blocks are gradually updated during training.

The figure below shows a schematic representation of the block structure, including the neuronal gelu layer (a) and the vector concatenation layers (b). The numbers in the figure refer to the number of elements used from each block for a single input vector. For example, for block 1, the first layer uses 1 element (multiplicated by the neuron output) and the second element (concatenated with the first element) for calculating the output of the neuronal gelu layer. Similarly, the output of the neuronal glee layer of block 1 is concatenated with 62 elements from the other blocks and fed into the vector concatenation layer.
