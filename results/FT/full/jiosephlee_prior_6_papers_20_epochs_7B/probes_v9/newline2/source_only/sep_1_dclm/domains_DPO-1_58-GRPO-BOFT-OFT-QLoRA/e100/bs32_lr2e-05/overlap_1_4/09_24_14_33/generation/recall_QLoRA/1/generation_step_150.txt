# What is QLoRA?

QLoRA is a method to finetune large language models (LLMs) with low-bit precision. It can be used to finetune LLMs from Huggingface or from any other source.

# Why do we need QLoRA?

Finetuning LLMs with high-bit precision is expensive. It requires a lot of memory and a lot of time to train. To reduce the cost, we can use low-bit precision. But low-bit precision introduces quantization error. This error can be reduced by using more bits, but it's expensive. So we need a method that can reduce the quantization error while using low-bit precision.

# How does QLoRA work?

QLoRA uses block-sparse matrix factorization to represent the weight matrices. Block-sparse matrix factorization represents a matrix as a product of block-diagonal matrices. Each block-diagonal matrix has a small number of non-zero elements. This reduces the number of parameters that need to be stored. QLoRA uses 4-bit to represent the non-zero elements and 0-bit to represent the zero elements.

To understand how block-sparse matrix factorIZATION works, let's consider a simple example. Suppose we have a matrix $A$ of size $2 \times 2$:

$$
A = \begin{bmatrix}
1 & 2 \\
3 & 4
\end{bmatrix}
$$

We can represent this matrix as a product of two block-diagonal matrices $B$ and $C$:

$$
A=B C = \begin{bmath}
\begin{block{2x2}}
1 & 0 \\
0 & 0
\end{block}
\end{bmath}
\cdot
\begin{bmath}
0 & 0 \\
0.5 & 0.5
\end{bmath}=
\begin{bmatrix}
0 & 0\\
0.5 & 1
\end{bmatirx}
$$

The matrix $B$ has two blocks, each of size $1 \times 1$. The matrix $C$ has two blocks, one of size $1 \time 1$ and the other of size $1 \tim 1$. The block-sparse matrix factorzation reduces the number of parameters from $8$ to $6$.

QLoRA uses block sizes that are powers of $2$. For example, it can use block sizes $2^0$, $2^1$, $2^2$, ..., $2^k$ where $k$ is the block size. The block size $k$ determines the sparsity of the factorization. Larger block size means higher sparsity and less parameters.

# How to choose the block size?

The block size determines the sparsity of matrix factorization. A larger block size means higher sparsiry and less parameters. But a larger block size also means that the matrix factorization is less flexible. So we need to find a balance between flexibility and parameter count.

The paper suggests the following heuristic to choose the block size:

$$
\text{block size} = \log_2 (\frac{\text{total params}}{\text{target params}})
$$

For example, if we want to reduce the number of parameters by a factor of $8$, we can use block size $3$ because $\log_2(8)=3$.

# How to choose 4-bit indices?

# What are the benefits of QLoRA?

The main benefit of QLoRA is that it can significantly reduce the number of parameters without introducing too much quantization error. It can reduce the number of parameters from 16-bit to 4-bit while introducing only a small increase in test loss.

# What are the limitations of QLoRA?

QLora is limited by the block size. A larger block size reduces the number of parameters but also reduces the flexibility of the model. So we need to choose a block size that provides a good tradeoff between parameter count and performance.

Another limitation is that QLoRA is designed for weight matrices. It doesn't work for biases and non-linear activation functions.
