BOFT uses an orthogonal matrix to transform the pretrained weight matrix of each layer, and then rescales the diagonal entries of the resulting matrix to zero mean and unit variance. This is in contrast to other methods such as LoRA which use low-rank matrices to update the weights.

The key insight behind BOFT is that many natural transformations preserve certain properties of the pretrained model, such as its spectral density. For example, orthogonal transformations preserve the pairwise inner product between neurons, while scaling transformations preserve the variance of the neuron activations. By applying a block-diagonal orthogonal matrix to the weight matrix, we can separately transform each "butterfly" submatrix of the weight matrix (the main diagonal and the four off-diagonals), resulting in a more parameter-efficient transformation than a full orthogonal matrix.

The BOFT algorithm is as follows:

1. Initialize $S_0 = W_0$ as the pretrained weight matrix.
2. For each layer $l$ from 1 to $L-1$:
   a. Apply an orthogonal transformation to obtain $S_l = S_{l-1} \cdot R$, where $R$ is a block-diagonal matrix with $4^l$ blocks.
   b. Compute the diagonal elements $\sigma_i$ of $S_l$ and rescale to have zero mean and unit variance: $\sigma_i = \sigma_i / \sqrt{\mathbb{E}[\sigma_i^2] + \epsilon}$.
   c. Set $R = I$ if $\text{rank}(S_l - S_{l-1})$ exceeds a specified budget, otherwise set $R$ to be the block-diagonal matrix used in the previous step.
3. Use $S_L$ as the finetuned model.

The paper provides a theoretical analysis showing that BOFT has similar generalization performance to full parametric orthogonal finetuning up to a certain number of training epochs, but with significantly fewer trainable parameters.
