What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a method for training language models to satisfy user preferences, without explicit reward modeling. It is based on the insight that a well-trained language model can be used to generate text given a summary (or “one-shot”) of a story, and that we can use this capability to train the model to produce texts that satisfy a given preference without needing to explicitly model a reward function.

The basic idea behind DPO is to train a language model to satisfy user preferences by maximizing the probability of a preferred completion $y_1$ given a preference summary $x$ and an initial context $x_0$, subject to a constraint on the probability of an dispreferred completion $y_0$:
\[
\max_{y \mid x_0, x, \lambda} p(y \mid x, x_0) - \lambda p(y = y_0 \mid x, x_{0})
\]
where $\lambda \geq 0$ is a Lagrange multiplier. The constraint ensures that the language model assigns non-zero probability to the dispreferred completion, so that it does not ignore the preference summary $x$. By default, the method uses a value of $\lambda = 0.05$.

In practice, the optimization is performed using reparametrized gradient ascent with a learning rate $\alpha$:
\[
y \leftarrow y + \alpha \nabla_{y} \log p(y \mid x,x_0,\lambda)
\]
and the gradient is estimated using sampling. The method also includes a novelty penalty to prevent the language model from degenerating into a model of the preference summaries $x$: it adds a term to the objective that penalizes the probability assigned to a sampled completion $y$ relative to the most probable completion among those sampled in a training set of preference summaries $x^*$:
\[
\max_y p(y \mid x_0,x,\lambda) - \beta \log \max_{y'} p(y' \mid x^*,x_0,\lambda)
,
\]
where $\beta$ is a penalty coefficient. The authors use a value of $\beta = 0.05$. 

DPO has been shown to be effective in training language models to satisfy preferences specified by one-shot prompts, without requiring explicit reward modeling. However, it also has some limitations.
