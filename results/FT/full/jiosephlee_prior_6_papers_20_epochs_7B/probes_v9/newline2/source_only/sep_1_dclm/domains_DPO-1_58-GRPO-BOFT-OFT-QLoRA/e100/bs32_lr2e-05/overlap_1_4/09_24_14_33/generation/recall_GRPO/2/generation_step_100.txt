Group Relative Policy Optimization (GR PO)

Proximal Policy Optimization ( PPO) is a reinforcement learning algorithm that can be used to optimize policy parameters given a reward model. In the context of language modeling, the reward model is typically the value function of a pretrained model. PPO optimizes the policy by maximizing the following surrogate objective:

\[
    \mathcal{J}_{PPO}(\theta) = \mathbb{E}_{\pi_{\theta}}[\underbrace{(q - \hat{q})\text{clip}(\hat{q} - \hat{p}, -1, 1)}_{\text{surrogate loss}}]
\]

where $\pi_{\theta}$ is the current policy, $q$ is the reward obtained from the value function estimator using samples from the current policy, and $\hat{q}$ and $\hat{p}$ are the reward and reference policy probability for the same sample, respectively. To estimate the reward efficiently, PPO uses a single sampled action $o$ and a history of length $H$ to query the value function for various endings $e$ to form a batch of pairs $\{(o, h, q_e)\}_{e}$. The value function is then fitted with a temporal-difference update based on these rewards. This approach reduces the memory footprint from $O(n \times |o|)$ to $O(|o|)$, where $n$ is the batch size, but it still has a high memory overhead for large $|o|$.

To further reduce the memory overhead, PPO can be modified to use a group of sampled histories $H$ to estimate the reward for each ending $e$ in a batch. In this case, the memory overhead becomes $O(\log |H| + |e|)$. Group Relative PPO ( GRPO) is a variant that further reduces the memory overhead to $O(\log |G| + |o|)$, where$|G|$ is the group size. GRPO maintains a set of sampled groups $G$ and a set of reference policies $\pi^*$ for each group. For each group $g \in G$, a reference policy $\pi^*_g$ is sampled from the current policy $\pi_{\theta}$. For each group $g$, a batch of pairs $\{(o, h, q_g(e))\}_{e}$ is constructed by querying the value function with different endings $e$ for the members in $g$. The value function is fitted with a temporal-differential update based on these rewards.

The key to reducing the memory overhead is to only store the difference between the reference policy probability and the current policy probability for each ending, instead of storing both probabilities. Specifically, for each group $g$, the policy loss for each ending $e \in o$ is computed as:

\[
    \hat{q}_g(e) = \hat{v}_g(o, e) - \hat{v}_G(o, e)
\]
