Direct Preference Optimization (DPO) is a simple algorithm that directly optimizes a language model to satisfy human preferences, without fitting an additional reward model. DPO is based on the insight that the parameters of a large language model can already encode a rough approximation of a reward model, and that we can refine this implicit reward model by optimizing the language model to match human preferences. DPO is conceptually simple, computationally efficient, and empirically effective. It matches or exceeds the performance of existing methods such as PPO and RLHF, while being much simpler to implement and train.

The paper starts by discussing the standard RLHF pipeline, which includes training a reward model from preferences, then fine-tuning a language model with reinforcement learning from a learned reward model. The RLHF pipeline has two major components: preference sampling and reward modeling. Preference sampling refers to the process of generating data from the implicit reward model encoded in the language model and from a baseline distribution, and then comparing these generated samples with human preferences to obtain supervised signals for reinforcement learning. Reward modeling refers to the process of learning a parametric reward model from preference data. The paper points out that preference sampling is often the rate-limiting step in RLHF, because it is expensive to generate high-fidelity samples from the language model and the reward model. To address this, the paper proposes to skip the reward modeling step entirely, and instead optimize the language model directly using supervised learning from preferences, without fitting an explicit reward model. This approach is called Direct Preference Optimization (D PO).

The key insight behind DPO is that the parameters of a pre-trained language model already contain some information about what makes a response better or worse, and we can refine this implicit preference model by optimizing the language to model to match human preferences more accurately. To see why the language model already contains some information about preferences, consider the following analogy. A pretrained language model can be thought of as a function that maps a prompt to a distribution over responses. Similarly, a reward model can be thought of a function that maps a response and a prompt to a scalar reward value. Both the reward model and the language model are functions that map inputs to outputs, and the main difference between them is the type of output they produce (a reward value vs a response distribution). Because both the reward model and the response distribution are represented by neural networks with similar architectures, it is plausible that the parameters of the language model contain some information about the parameters of the reward model. DPO exploits this shared information to optimize the language model directly from preferences, without fitting a separate reward model.

Therefore, DPO is computationally more efficient than RLHF.
