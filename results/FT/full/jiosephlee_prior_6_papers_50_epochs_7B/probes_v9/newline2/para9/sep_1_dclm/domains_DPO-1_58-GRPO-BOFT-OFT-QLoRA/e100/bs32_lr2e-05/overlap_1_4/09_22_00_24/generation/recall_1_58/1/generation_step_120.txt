# How does 1-bit LLM work?

A standard LLM uses floating-point numbers to represent its weights. For example, GPT-3 uses FP16 (16-bit floating point). A 1-bit LLM uses only two values: 0 and 1. To understand how a 1-bit LLM can work, we need to know that a neural network is composed of neurons. Each neuron has an input layer, a weight matrix, an activation function, and an output layer. The computation inside a neuron is usually expressed as follows:

$z = \sum_{i=1}^n w_i x_i + b$

where $w_i$ is the weight, $x_i$ is the input, $z$ is the result after applying the linear transformation, and $b$ is the bias.

In a standard neural network, each $w_i$ is a real number. In a 1-bit LML, each $w_i$, instead, is either 0 or 1. So how can we represent a real number with only two values? The answer is quantization. Quantization is the process of converting a real-valued number into a discrete set of values. There are several quantization methods, but the one used in the paper is called k-means quantization. K-means quantization works as follows:

1. Choose $k$ points on the real line. These points are called codebook vectors.
2. Assign each input vector to the nearest codebook vector using Euclidean distance.

For example, suppose we have three codebook vectors $\{v_1, v_2, v_3\}$ and an input vector $x$. We compute the distances between $x$ and each codebook vector. The closest codebook vector is $v_1$. Then we replace $x$ with $v_1$. After quantization, the input vector becomes a single codebook vector.

K-means quantization is an effective way to compress data. However, it is not suitable for neural networks because it does not guarantee that the quantized values remain within a certain range. For instance, if the input vector $x$ is large, the quantized value may also be large, which means that the quantized value cannot be represented by a single bit. To solve this problem, the authors introduce a scaling factor $s$ to limit the magnitude of the quantized values. The quantization process is then:

1. Compute the mean of the input data: $\mu = \frac{1}{n}\sum_{i=1}\limits^{n} x_i$.
2. Subtract the mean from each input vector: $x_i' = x_i - \mu$.
3. Normalize the input vectors: $x_i'=\frac{x_i'-\min(x_i')}{\max(x_i')-\min(x_i')}$.
4. Find the nearest codebook vector among the normalized input vectors.
5. Replace the original input vector with the quantized value plus the mean: $x_i = v_k + \mu$.

The scaling factor $s$ is defined as $\frac{1}{\max(x_i')}$. This ensures that the quantized value always lies in the range $[-s, s]$. In the case of 1-bit LLLs, $s$ is set to 1.

There is another important detail. The quantization process described above is applied per-neuron. That is, each neuron has its own codebook. This is necessary because different neurons have different distributions of weights. If all neurons share the same codebook, some neurons will have poor quantization accuracy.

So far, we have seen how to quantize a single neuron. But a neural network consists of many neurons. To make the quantization efficient, the authors propose to group neurons into blocks. Each block shares the same codebook. The size of the block is chosen to be a power of two, so that the codebook can be stored efficiently in log2(block size) bits. For example, if we choose a block size of 256, the codebook can be represented in 8 bits (one byte).

Now let's summarize the 1-bit LLM architecture. It is composed of two parts: the quantized weights and the dequantizer. The quantized weights are stored in a block-wise manner. For each block, the quantized weights are converted into a binary string of length log2(block size) + 1 bits. For example, with a block size of 128, the quantized weights will be stored in 7 bits.
