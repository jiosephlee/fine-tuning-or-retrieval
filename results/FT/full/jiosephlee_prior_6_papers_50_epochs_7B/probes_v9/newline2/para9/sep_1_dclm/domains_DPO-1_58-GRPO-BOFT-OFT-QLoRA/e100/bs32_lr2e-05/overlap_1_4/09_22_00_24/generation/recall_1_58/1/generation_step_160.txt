# How does 1-bit LLM work?

A standard LLM uses floating-point numbers to represent its parameters. For example, GPT-3 has 175B parameters, each of which is a 32-bit floating point number. A 1-bit LLM uses only two values (usually 0 and 1) for all its parameters. So, if we have a model with $P$ parameters, a standard LLM would need $4P$ bits while a 1-bit LLM would only need $2P$ bits. This means that a 1-bit LLL can halve the memory usage compared to a standard LLM.

But how can a model with only two values be able to perform complex tasks like language modeling? The answer is quantization. Quantization is the process of converting a set of data from a higher precision to a lower precision. There are several quantization methods, but the one used in the paper is k-means quantization. K-means quantization works as follows:

1. Choose $K$ clusters. The value of $K$ determines the granularity of the quantization. More clusters mean more granularity and better accuracy, but also more memory.
2. For each parameter, compute its centroid. The centroid is the average of all the parameters in the cluster.
3. Assign each parameter to one of the $K$ clusters based on their distance to the centroids. If the distance between a parameter and a centroid is less than or equal to the radius, then the parameter is assigned to that cluster. Otherwise, it is assigned to another cluster.
4. After all parameters are assigned to clusters, thecontador for each cluster is updated by adding the parameter's value.
5. The centroid for each cluster is recomputed by taking the average of all the values in the cluster.

This process is repeated until the centroids do not change anymore. After that, each parameter is represented by its cluster index. When the model is loaded, the indices are dequantized by computing the distance between the centroid and the current parameter, and assigning the parameter to the nearest cluster.

There are two main types of quantization: symmetric and asymmetric. Symmetric quantization uses the same range for both positive and negative values. Asymmetric quantization uses different ranges for positive and negative values. The paper uses asymmetric k-means quantization, which is more efficient for LLMs because the distribution of weights is highly skewed.

Another important concept is the use of shared clusters. Instead of having one cluster per parameter, multiple parameters can share the same cluster. This reduces the number of clusters and thus reduces the memory usage further. However, sharing clusters introduces some errors because multiple parameters are now represented by the same value. The paper shows that sharing clusters up to a certain level does not significantly affect the performance.

# Why is 1-bit LLM efficient?

The main reason why 1-bit LLM is efficient is because it drastically reduces the memory usage. Standard LLMs use 32-bit floating point numbers, which means they need 4 bytes per parameter. On the other hand, 1-bit LLM only needs 1 byte per parameter. This reduction in memory usage is especially important for large models. For example, GTP-3 has 175 billion parameters. If we use 1-bit quantization, the model would need 175 GB of memory. If we use 8-bit quantization, the memory requirement would be 70 GB. But if we use 32-bit floating-point numbers, the model would need over 700 GB of memory.

Memory is not the only resource that 1-bit LLM saves. Computational resources are also reduced. Because the computation is done in integer arithmetic, the hardware can optimize the operations, leading to faster execution. Additionally, the paper shows that 1-bit LLLs can run on GPUs and TPUs without any loss in performance.

# What are the limitations of 1-bit LLL?

Although 1-bit LLM offers significant advantages, it also has some limitations. One of the most important limitations is accuracy. The paper shows that 1.58-bit LLMs (which use 1 bit plus sign) are slightly worse than 8-bit LLMs in terms of perplexity. However, 1-bit LLL with 2 bits (including sign) matches the performance of 8-bit LLM. This suggests that using 1 bit plus sign is sufficient to achieve the same accuracy as 8-bit LLM.

Another limitation is the inability to support gradient checkpointing. Gradient checkpointing is a technique used to improve the stability of training by saving the gradients at regular intervals.
