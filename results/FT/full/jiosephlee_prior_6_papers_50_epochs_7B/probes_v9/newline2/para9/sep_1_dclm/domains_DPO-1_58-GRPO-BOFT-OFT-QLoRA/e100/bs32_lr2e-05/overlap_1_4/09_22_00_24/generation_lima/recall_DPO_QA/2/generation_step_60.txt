DPO is a method for training language models to follow human preferences without using reinforcement learning. It is based on the observation that, if a language model is trained on human preference data, then the probability ratio of preferred completions over non-preferred completions can be used to infer a reward function that explains this preference. This reward function can then be used to reweight completions in a way that directly optimizes the preference, without the need for reinforcement learning.

In DPO, the language model is trained with a loss function that includes both the likelihood of the completion and a KL-divergence term that penalizes the reward function from deviating from the observed preference. The objective is:

$L(\theta) = \log \mathbb{E}_{x\sim p_{\text{data}}(x)}\mathbb{E}_{y\sim p_\theta(x|y)}\left[\frac{1}{|y|} \sum_{i=1}^{|y|} \exp\left(\frac{\theta_r(r_i)}{T}\right)\right]$
+ $\beta$ $\mathbb{E}_{(x, y_1, y_2)\sim p_{\text {data}}(x) } \left[\frac{1}{{|y_1|}}{{\rm{KL}}\left(\pi_{\theta}(y|y\mid x) \mid \mid \pi_{\theta}(x|y_1,y\mid x)\pi_{\theta}( x|y_2,y\mid x)\right.}\left. {\kern-0.17em {\rm{ }}\left.+ {\rm{Kl}}\left(\pi_{{\theta}_0}(y|y\Mid x){\mid \mid \pi_{{\theta}}(y|y\mid  x)}\right)\right) \right]$

where $p_\theta(x|y)$ is the language model with parameter $\theta$, $\pi_{\theta_0}(y|x)$ is the prior language model, and $\pi_{\theta}(z|x)$ is the proposed language model with the DPO update. The reward function is given by $r_i = \log \sum_{y} \exp\left({\frac{1}{T}\theta_r(y)}\right)$, where the sum runs over all completions $y$ of $x$. The constant $T$ is a temperature parameter. The second term in the loss function is a KL-divergence penalty that ensures the learned reward function remains close to the reward function implied by the preference data. The parameter $\beta$ controls how strictly the model must adhere to the preference data; when $\beta$ is large, the model will be more conservative in its updates. 

DPO can be seen as a special case of the RLHF framework, where the reward model is learned from preference data, and the policy model is the same as the language model. In contrast, standard RLHF methods learn a reward model from the language model and then optimize it with a policy model. DPO does not require a separate policy optimization step, which may make it more stable than PPO. Additionally, DPO can be interpreted as a reparameterization of the optimal policy under a learned reward function, making it computationally efficient.
