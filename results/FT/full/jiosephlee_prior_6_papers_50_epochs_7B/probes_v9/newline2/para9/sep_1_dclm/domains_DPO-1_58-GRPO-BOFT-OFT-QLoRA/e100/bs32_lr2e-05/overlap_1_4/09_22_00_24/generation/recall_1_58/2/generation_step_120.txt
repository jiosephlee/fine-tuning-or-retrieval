# Introduction

Large language models (LLMs) have become increasingly powerful over the past several years, but their computational demands have grown proportionally. As a result, reducing the memory usage of LLMs has become a critical research topic. This chapter examines two strategies for lowering the memory requirements of LLMs: quantization and model compression. Quantization involves converting the model’s parameters from higher precision formats (for example, 16-bit or 32-bit floating point) to lower-precision formats (for example, int8 or int4). Model compression, on the other hand, refers to techniques that reduce the number of parameters in the model while maintaining its predictive capabilities. # Quantization: principles, methods, and evaluation

Quantization is the process of transforming data from a higher-precision format to a lower-precision format. In the context of LLMs, this typically entails converting weights and activations from 16-bit precision to 4-bit precision. The fundamental steps involved in quantization are dequantization, quantization, and retraining. Dequantization refers to the process of reconstructing the original values from the quantized representations during inference. Quantization converts the input tensor into a lower-precision representation by mapping each value in the input tensor to a quantized value according to a scale and zero-point. Retraining is required after quantization to ensure that the model’s accuracy is not compromised by the reduced precision. # General principles of quantization

Quantization is a process that reduces the number of bits used to represent numerical values. It involves two main operations: (1) determining the quantization ranges for each tensor type (for example, weights and activations), and (2) assigning quantized values to the original input values based on these ranges. For a given tensor, there are usually multiple quantization schemes. A common scheme is to use different scales for each tensor, such as a separate scale for each output channel. Another approach is to use a single scale for an entire layer. When quantizing a tensor, the first step is to determine the appropriate quantization range for each tensor. This is done by calculating the minimum and maximum values within the tensor, as well as any outliers. Outliers are values that fall outside the normal distribution of the tensor and must be handled separately to avoid skewing the quantization range. Once the quantization ranges have been determined, the next step is to quantize each input value by mapping it to the nearest quantized value within the chosen range. Finally, the quantized values are stored in memory, and the original input values are reconstructed during inference using dequantization.

Dequantization is the reverse process of quantization. During inference, the quantized values stored in memory are dequantized to produce the original input tensor. Dequantization uses the same scale and zero-point that were used during quantization. For example, if a 4-bit quantized value is stored in memory, dequantization reconstructs the original input tensor by multiplying the quantized value by the scale and adding the zero-point. Because quantization often results in rounding, dequantization may introduce small errors. These errors can accumulate over time and degrade model performance. To mitigate this, some quantization methods employ quantization-aware dequantization, which uses a bias term to account for systematic differences between the quantized and dequantized values.

Another important aspect of quantization is quantization error. Quantization error refers to the difference between the original input tensor and the reconstructed tensor after quantization and dequantization. Quantization error can be categorized into two types: systematic error and stochastic error.
