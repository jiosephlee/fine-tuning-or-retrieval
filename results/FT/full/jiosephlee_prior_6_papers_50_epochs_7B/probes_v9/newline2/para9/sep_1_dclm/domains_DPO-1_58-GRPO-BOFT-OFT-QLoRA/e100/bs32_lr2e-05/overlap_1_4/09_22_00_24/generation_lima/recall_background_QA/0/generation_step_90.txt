In a traditional RNN or LSTM, each input token is processed sequentially, one at a time. This means that to process a sequence of length $N$, the model needs to process $N$ inputs. For very long sequences, this can be computationally expensive.

The transformer uses a technique called "self-attention". Self-attention allows the model to compute the relationship between every element in the input sequence without needing to process each element sequentially. This makes the transformer well-suited for handling very long sequences, such as long documents.

Self-attention works by computing a weighted sum of all elements in the sequence, where the weights are determined by their pairwise similarity. Specifically, for each position in the sequence, the algorithm computes a set of "keys" from that position, a set of "queries" based on all positions, and a set of "values" also based on all positions. These similarities are used to compute a linear projection of the values, yielding a vector of size equal to the number of output neurons. In practice, this computation is performed once for each position in the input sequence, producing a new set of values for each position.

There are two main types of self-attention: causal and normal. Causal attention is the standard form used in transformer models. In causal attention, the model cannot attend to any position in the input sequence that comes after the current position. This mirrors the way humans read text, where we cannot see future words while reading a sentence. Causal attention is important for tasks like language modeling, where the training data is a sequence of tokens, because it prevents the model from using information about future tokens during training. Non-causal attention, on the other hand, can be useful in some translation tasks, where the model may need to use information from the source language input while generating the target language output.

In summary, the transformer uses self-attention to compute interactions between all positions in a sequence in a single pass. By combining self-attention with residual connections and normalization, the transformer becomes highly effective for tasks involving sequential data, particularly in natural language processing.
