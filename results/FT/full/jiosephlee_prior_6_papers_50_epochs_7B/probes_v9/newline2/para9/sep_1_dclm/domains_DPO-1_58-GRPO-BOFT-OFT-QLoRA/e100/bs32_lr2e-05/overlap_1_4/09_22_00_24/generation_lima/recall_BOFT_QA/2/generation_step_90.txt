What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a method for parameter-efficient orthogonal finetuning that leverages the butterfly network structure. BOFT uses the butterfly network, which is widely used in signal processing and computer science, to construct an orthogonal matrix with a small number of parameters. The core idea behind BOFT is to build an $n \times n$ orthogonal matrix $\bm{R}$ using the product of $m$ sparse orthogonal matrices, where $m$ is chosen such that $n$ can be expressed as
\[
    n = m s,
\]
with $s$ being a positive integer. Each sparse orthogonal matrix has a sparsity pattern organized on the graph $s$-dimensional grid. By arranging these sparse orthogonal matrices into an $s$-dimensioned butterfly network, we can efficiently compute the multiplication of these matrices, resulting in an $n \times 1$ vector. This vector contains the entries of the orthogonal matrix $\bm{B}$. In order to complete the orthogonal finetuning process, we need to transform this vector into a square matrix by constructing an identity matrix of the same size on the right side. This is done by applying a permutation to the elements of the vector. To ensure that the constructed matrix $\bm{R} = [\bm{B} | \bm{I}]$ is full-rank, we append a block-diagonal identity matrix $\bm{I}$ at the end of $\bm{B} = [\bm{U} | \bm{R}]$.
