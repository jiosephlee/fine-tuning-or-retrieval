Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning technique that adapts large pretrained models to downstream tasks by learning a task-specific orthogonal transformation at each layer. BOFT introduces a novel butterfly matrix factorization that enables the method to be more parameter-efficient than OFT while maintaining full layer-wise orthogonality. The authors also introduce a related method, BOFT-LLM, which applies the BOFT framework to text-to-text transformers by finetuning the LLM's linear layers only.

The core idea of BOFT is to represent the transformation matrices as products of several sparse matrices, specifically butterfly matrices. This approach allows BOFT to achieve parameter savings compared to OFT, while still maintaining full orthogonality across all layers. The butterfly matrix factorization is inspired by the butterfly structure found in fast Fourier transform algorithms. The authors present two different forms of butterfly matrices: the first is a banded matrix with a 2D butterfly pattern, and the second is a block-diagonal matrix composed of multiple 1D butterfly blocks. Both forms are shown to yield equivalent results when used to decompose a dense matrix into a product of sparse matrices. To further improve parameter efficiency, the authors propose a method to share parameters across adjacent butterfly matrices, resulting in an even more compact representation.

# Orthogonal Butterfly (BOft) finetuning is a highly parameter-efficient approach for adapting large pretrained models

Adapting large pretrained models to new tasks is a central challenge in modern machine learning. A widely adopted strategy is to finetune the entire model from its pretrained parameters, but this can be prohibitively expensive in terms of memory and computational resources. Parameter-efficient finetuning (PEFT) aims to adapt large models to downstream tasks while using substantially fewer trainable parameters. In this section, we describe the BOFT framework in detail and explain how it achieves high parameter efficiency.

At a high level, BOFT modifies the weights of a pretrained model by learning a task-specific transformation matrix at each layer. This transformation is applied to the activations after they have been projected by the weight matrix of the layer. To ensure stability during training and to prevent catastrophic forgetting, BOFT enforces the constraint that these transformation matrices remain orthogonal throughout training. Maintaining orthogonality has been shown to preserve much of the knowledge gained during pretraining and to help maintain good generalization properties. However, enforcing orthogonality across an entire network typically requires a significant number of trainable parameters. The key innovation of BOFT is to use a butterfly matrix factorization to reduce the number of parameters required for representing orthogonal transformations.

A typical BOFT configuration involves learning a task-specific orthogonal matrix for each layer of the model. For a neural network with $L$ layers, this would normally require learning $L$ orthogonal matrices. Each of these matrices is represented as a product of $k$ sparse matrices, where each matrix is either a butterfly matrix or a identity matrix. If we denote the size of these matrices as $r \times r$, then the total number of learnable parameters is $\mathcal{O}(k r^2)$. Since $k$ is often on the order of tens, BOFT can achieve substantial parameter savings relative to full finetuning. For example, when $r=128$ and $k=8$, BOFT uses only about 2% of the parameters needed for full finetuning.

To better understand the parameter efficiency of BOFT, let us compare it with another popular PEFT method, LoRA. LoRA adds an additional low-rank matrix to the pre-existing weight matrix, so the total number of trainable parameters is proportional to $\mathcal{O}((d n) s)$, where $d$ is the dimension of the weight matrix and $s$ is the number of singular values. If we set $s$ to be a small constant, LoRA becomes more parameter-efficient as $d$ grows. For instance, when $d=128$ and $s=0.1$, LoRA uses about 1.6% of the parameters in a fully finetuned model. BOFT can match this parameter efficiency while additionally offering improved expressive power due to its ability to represent orthogonal matrices of arbitrary shape. Importantly, LoRA modifies the original weight matrix, whereas BOFT learns an orthogonal transformation that acts on the activations after projection by the weights. These differences lead to distinct trade-offs in parameter efficiency and expressivity.
