What is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GRPo) is a memory-efficient variant of Proximal Policy Optimization (PPO). It was introduced by DeepSeekMath to train large language models for mathematical reasoning with limited GPU memory.

In contrast to PPO, which requires storing the entire value function $V(\theta)$, GRPO only needs to store the difference between any two value functions, i.e., $\Delta V(\theta) = V(\theta_1) - V(\theta_0)$. This reduction in storage requirements makes it possible to train much larger models on devices with limited memory, such as consumer GPUs.

How does GRPO work? 
GRPO operates similarly to PPO, using a clipped surrogate objective to encourage improvements while discouraging large updates that harm performance. The loss for a single step is given by:

$\mathcal{L}_{GRPO}(\pi_{\theta_0}(y \mid x), \pi_{\theta_1}(y \mid x); k) = \mathbb{E}[\sum_{t=1}^T \underbrace{(0.5*\big( \hat{q}_4(q_t, \pi_{\theta_{max}}(y \mid x)) - \hat{q}_2(q_t, \pi_{{\theta}_{min}}(y \mid  x))\big))}_\text{clipped bonus} -  \underbrace{(0,5*\big( \tilde{q}_2(q, \pi_{{{\theta}_{max}}} (y \mid x))-\tilde{q}_1(q, \pi_{{{{\theta}_{min}}} (y \mid  x)})}
_\text{unclipped bonus})}_\text{value function estimate}]$

Here, $\pi_{{\theta_i}}$ refers to the policy model with parameter set ${\theta_i}$, and $\tilde{q}_i$ and $\hat{q}_i$ are value function estimates used in the clipping mechanism. The key difference from PPO is that GRPO uses a single-step value function $\tilde{q}$ to unclip the reward signal, rather than using a value function learned over the course of training. This allows GRPO to operate with a smaller memory footprint, since it only needs to store the value function from the previous iteration, $\hat{q}_2$, and the value function from the initial model, $\hat{q_1}$. In addition, GRPO uses a group relative advantage estimator for the reward, which is defined as:

$\hat{q}_4 = \frac{1}{T}\sum_{t=1 }^T \big(\hat{q}_4[q_t, G] - \hat{q}_{4, inc}[q_t, I]\big)$

where $G$ represents the group of policies generated by the current policy model $\pi_{{\phi}_1}$, and $I$ represents the set of policies from the previous model $\pi_{{{\phi}_0}}$. The advantage for each timestep $q_t$ is estimated using the generalized advantage estimator (GAE).

Why is GRPO important?
GRPO is significant because it enables the training of very large language models on consumer GPUs, even when using large context lengths. This is crucial for advancing the state-of-the-art in language modeling, particularly in areas like mathematical reasoning, where open-source models have previously fallen short due to memory constraints.<|endoftext|>
