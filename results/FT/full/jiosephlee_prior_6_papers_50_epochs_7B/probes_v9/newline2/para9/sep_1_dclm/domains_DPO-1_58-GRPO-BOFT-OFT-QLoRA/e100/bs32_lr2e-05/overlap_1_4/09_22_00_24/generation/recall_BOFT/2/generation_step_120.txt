Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning technique that adapts large pretrained models to downstream tasks by learning a sparse orthogonal matrix. BOFT introduces a butterfly structure to the orthogonal matrix, enabling it to be parameterized with a small number of trainable parameters. This structure is inspired by the butterfly network topology used in computer networking and signal processing. BOFT achieves parameter efficiency comparable to block-diagonal OFT while maintaining full matrix flexibility.

The core idea behind BOFT is to represent an orthogonal matrix as a product of several sparse matrices, each of which corresponds to a layer in the butterfly network. Each sparse matrix in the butterfly network is constructed using a binary mask, where each element is either 0 or 1. The sparsity pattern of these masks is determined by the butterfly network topology. To ensure the resulting orthogonal matrix has full rank, the authors introduce a constraint on the sparsity of the masks: no two adjacent masks share a non-zero element. This constraint guarantees that the product of all sparse matrices remains full-rank, thereby ensuring the orthogonality of the final orthogonal matrix.

To illustrate the butterfly network, consider a simple example with $n=4$. The corresponding butterfly matrix can be written as
\[
B_4(\vec{d}) = \begin{bmatrix}
1 & 0 & 0 & 1 \\

\end{bmatrix},
\]
where $\vec{d}=(d_1,d_2,d_3,d_4)$ are the diagonal elements. In general, the butterfly matrix for $n$ nodes is constructed recursively, starting from $n=2$, and then extending to $n>2$ as the Kronecker product of multiple $2\times 2$ butterfly matrices. For the $n\times n$ butterfly matrix, there are $n$ diagonal blocks, each containing $d_i$ non-zero elements. The total number of trainable parameters is therefore $n(d_1+d_2+\cdots+d_n)$. By adjusting the values of $d_i$, the parameter count can be minimized while still maintaining a fully dense orthogonal matrix.

The BOFT framework is composed of three main steps: (1) constructing the butterfly matrix, (2) generating a sparse matrix from the butterfly matrix, and (3) performing orthogonalization to ensure the resulting matrix is indeed orthogonal. In the first step, the butterfly matrix is constructed based on the node index. In the second step, a sparse matrix is generated from the butterfly matrix by selecting non-zero entries according to a binary mask. The third step involves orthogonalizing the resulting matrix to ensure it is orthonormal. There are several methods available for orthogonalization, including the Gram-Schmidt process, the Cayley transform, and the QR factorization. The Cayley transform is chosen because it is computationally efficient and avoids numerical issues associated with the Gram-Schmidt procedure.

The BOFT framework can be extended to incorporate layer-shared and adapter modules. In the layer-shared variant, a single orthogonal matrix is learned per layer, and the output of each neuron is multiplied by this shared orthogonal matrix. In the adapter variant, a separate orthogonal matrix is learned for each neuron, and the orthogonalization is performed independently for each neuron.

# Comparison of BOFT and OFT

Both BOFT and OFT are parameter-efficient finetuning techniques designed to adapt large pretrained models to downstream applications. They share the same fundamental idea: instead of updating all model parameters, a smaller orthogonal matrix is learned to transform the weights of the pretrained model. This approach preserves most of the pretrained knowledge while allowing for effective adaptation to new tasks. However, OFT typically requires more trainable parameters than BOFT, since OFT uses a block-diagonal structure to enforce orthogonality, whereas BOFT constructs a full dense orthogonal matrix. As a result, BOFT is able to achieve greater parameter efficiency compared to OFT. Figure~\ref{fig:comp_boft_oft} illustrates the difference between the two approaches. In OFT, the block size determines the parameter count; reducing the block size increases parameter efficiency but also complicates training. BOFT, however, can achieve full parameter efficiency without compromising expressiveness, since the butterfly structure allows for a full dense orthogonal matrix.

Another key distinction between BOFT and OFT lies in their initialization strategies. OFT initializes the block-diagonal matrix to be identity, while BOFT initializes the orthogonal matrix to be the identity. This difference is important for stability during finetuning, as initializing the orthogonal matrix in BOFT ensures that the pretrained weights are not altered at the start of training. BOFT also benefits from a simpler training process, since the orthogonal matrix is initialized as a dense identity matrix, which is easier to optimize than the block-diagonal initialization used in OFT.
