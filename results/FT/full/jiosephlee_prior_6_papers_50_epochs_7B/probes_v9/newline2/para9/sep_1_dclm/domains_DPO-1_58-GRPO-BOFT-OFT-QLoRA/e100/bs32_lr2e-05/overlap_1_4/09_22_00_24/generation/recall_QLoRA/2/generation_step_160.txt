The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is an extension of LoRA (Low-rank Adapters), a technique that has become increasingly popular due to its effectiveness in reducing memory consumption during model finetuning. The authors demonstrate that their approach can be used to finetune LLaMA models of the same scale as ChatGPT while using only 3 GB of GPU memory—a feat that would be impossible with conventional finetuning methods.

The key idea behind QLoRA is to quantize the weights of a pretrained model before applying LoRA. To better understand this, let's first review how LoRA works. LoRA introduces a set of low-rank weight matrices, called adapters, to modify the original weight matrices of a neural network. During training, the adapter parameters are optimized while the pretrained weights remain fixed. This strategy allows for substantial reductions in memory usage because only the small adapter parameters need to be stored, rather than the full pretrained weights. LoRA achieves significant memory savings by sharing a single pair of low-rank weight matrix across all layers, although this approach results in some loss of parameter efficiency compared to full-model finetuning. To address this issue, subsequent approaches such as PLORA (Parameter-efficient Learning with Orthogonal Weight Matrices) introduce multiple independent low-rank weight matrices per layer, improving parameter efficiency but increasing computational cost.

Now, back to QLoRA. The core innovation of QLoRA is to apply quantization to the pretrained weights before inserting LoRA adapters. In contrast to full 16-bit finetunning, which requires storing both the pretrained weights and the updated weights during training, QLoRA only needs to keep the adapter weights in memory. The quantized weights are kept on the CPU, which further reduces GPU memory usage. When a query is processed, the quantized weights are dequantized on the fly to compute activations, effectively reconstructing the original computation. This process is illustrated in Figure 1.

The authors present several techniques to enhance the performance of QLoRA. One important technique is the use of double quantization to reduce memory usage even further. Double quantization involves quantizing the input tensor twice—first from 16 bits to 4 bits and then from 4 bits to 2 bits. This approach is possible because the quantization function is idempotent, meaning that quantizing a quantized tensor yields the same result as quantizing the original tensor. While double 2-bit quantization can cause information loss, the authors show that it does not degrade model performance on language modeling tasks. Another technique is to quantize only certain layers while leaving others in higher precision, which they refer to as selective quantization. Their experiments indicate that selectively quantizing the final fully connected layer, while keeping the rest of the model at 16 bits, still achieves significant memory savings without compromising performance.

The authors also propose a new method for managing gradient checkpointing, which is essential for preventing out-of-memory errors during training. Gradient checkpointing saves intermediate gradients to disk to prevent memory spikes when the memory footprint is large. The traditional approach writes gradients to disk every time the memory usage exceeds a specified threshold. However, this leads to frequent checkpoints and high disk I/O overhead. To mitigate this, the authors implement gradient batching, which groups multiple gradients into a single checkpoint, thereby reducing the number of writes. They also introduce a dynamic gradient checkpointing policy that automatically adjusts the checkpointing frequency based on the current memory usage, ensuring that the system never runs out of memory.
