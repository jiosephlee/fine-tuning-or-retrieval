The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a method for parameter-efficient finetuning of foundation models. It builds upon the Orthogonal Finetuning framework, which involves learning an orthogonal transformation on top of the pretrained weights. The key idea behind BOFT is to construct a sparse matrix product that results in an orthogonal matrix. This is achieved by arranging the sparsity pattern of several $d \times d$ matrices into a single butterfly-like structure, where $d$ is the model dimension. By doing so, we can achieve parameter efficiency while maintaining the desirable properties of OFT.

To better understand the concept, let's first review the standard block-diagonal OFT. In this approach, a diagonal matrix $\bm{D} \in \mathbb{R}^{r \times r}$ is constructed, and then multiplied with the pretrained weight matrix $\bm{W}^0$ to obtain the finetuned weight matrix $\bm{w} = \bm{D}\bm{W}^$. Here, each element of $\bm{D}$ is a scalar. To ensure that the multiplication of $\bm{D} $ and $\bm{W} ^0$ remains orthogonal, each diagonal element must be constrained to have absolute value 1. This leads to a total of $r$ tunable parameters per layer, which is often considered quite costly. To reduce the number of trainable parameters, the block-diagonal structure is replaced by a block-sparse structure, resulting in a block-sparse diagonal matrix. While this reduces the parameter count, it also introduces a significant limitation: the diagonal blocks are fixed and do not adapt to the data distribution. As a result, the block-diagonal OFT with a small $r$ can still be quite parameter-heavy, whereas the block-sparse variant loses the ability to adapt the diagonal blocks.

In contrast, BOFT uses a different strategy to introduce sparsity. Instead of creating a block-diagonal matrix, it creates a sparse matrix product. The sparsity pattern of $\bm{D}_r$ in BOFT is organized in a butterfly-like structure, which allows us to express the matrix as
\[
    \bm{D}_r = \text{diag}(d_1,d_2,\cdots,d_r) = \text{diag}(\underbrace(1,2,4,8,16, \cdots, 2^{\tilde{n}-2},2^{\tilde n-1})_{\tilde{n}-1\text{th} \text{col}}),
\]
where $\tilde{n}=r\log_2 d$. Each $d_i$ is a single scalar, and the entire matrix $\bm{D}_i$ has only $\log d$ nonzero entries. This means that the number of trainable parameters is reduced from $r$ to $\log d$, making the parameter count comparable to the block-sparse OFT. More importantly, the sparsity pattern of $\text{diag}(d)$ can be arranged in a butterfly-like structure. This arrangement is referred to as the "butterfly matrix", which is defined as
\[
    B_r = [\text{diag}(d)_1 \;|\: \text{diag}(2d)_1],
\]
with $\text{diag}(x)$ denoting a diagonal matrix whose main diagonal elements are $x$. The matrix $B_r$ has a banded structure with nonzeros confined to a region of size $r$ around the diagonal. It is well known that the product of any two butterfly matrices is again a butterfly matrix. Thus, we can express the matrix $\bm{D}$ as $\text{diag}(1,2,\cdots,2^{\tilde{m}-1})\bm{B}^{\tilde{t}-1}\cdots\bm{B}^{t-1}\bm{B}^{u-1}\bm{D}_r$, where $\tilde{m}=\log_2 (\max i)$. This expression shows that the matrix $\bm{B}^\top\bm{D}_r=\bm{D}$ can be constructed using a sequence of $u+v+1$ butterfly matrices, all of which are sparse. This construction is similar to the butterfly matrix used in the Cooley-Tukey algorithm. The matrix $\bm{B}$ itself is a block-diagonal matrix with dimensions $d\times d$, where each block has size $d_s\times d_s$ and $d_s$ is the radix of the butterfly matrix. For example, when $d=2^8=256$, the matrix $\bm{W}$ will have $8$ blocks, each of size $256\times 256$ and containing only nonzeros. If we set all other blocks to zero, then $\bm{B}$ becomes an $8\times 8$ block-diagonal matrix.<|endoftext|>
