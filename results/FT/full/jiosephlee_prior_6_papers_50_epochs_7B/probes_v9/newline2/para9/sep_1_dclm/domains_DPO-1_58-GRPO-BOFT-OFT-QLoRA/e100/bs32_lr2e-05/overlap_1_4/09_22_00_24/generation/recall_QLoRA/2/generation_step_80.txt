# Challenges of finetuning large models

Large language models (LLMs) have demonstrated remarkable capabilities, but their size makes finetuning them a challenging task. When finetuning a model, it is common practice to store the weights of all layers, not just the ones being updated, in order to allow for rapid changes to any layer during training. Secondly, it increases the cost of deploying finetuned models on servers with sufficient memory capacity. To address these issues, researchers have developed strategies for reducing the memory requirements of finetuning large language models.

Another strategy is to employ gradient checkpointing, which trades computation time for reduced memory usage by recomputing gradients during the backward pass. To overcome these limitations, alternative methods for lowering the memory footprint of finetuning are necessary.

# Low-rank adaptation (LoRA)

Conventional quantization methods typically convert weight matrices into a small set of discrete values with high quantization error.
