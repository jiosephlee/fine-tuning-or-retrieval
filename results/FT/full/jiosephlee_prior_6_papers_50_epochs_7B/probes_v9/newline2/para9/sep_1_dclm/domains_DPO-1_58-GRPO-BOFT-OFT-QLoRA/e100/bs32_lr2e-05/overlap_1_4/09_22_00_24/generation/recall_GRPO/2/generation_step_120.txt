# Group Relative Policy Optimization (GRP)

As mentioned earlier, GRPO is a low-memory alternative to PPO. In order to comprehend how GRPO works, it is necessary to first understand PPO. PPO seeks to optimize the policy by minimizing the following loss:

$L_{\text{PPO}}(\pi_\theta) = \mathbb{E}{[q \sim P(Q), o \sim \pi_\theta(q)]} \frac{1}{|o|} \sum_{t=1}^{|o|} \underbrace{\varepsilon_{\text{P Po}}(o, q, t)}_{\text{CLIP}} + \underbrace{\beta_{\text{PPo}}(o, q)}_{\text{KL}}$

Here, $\pi_\theta$ represents the policy model, and $\varepsilon_{\mathrm{P Po}}$, $\beta_{\mathrm{PPo}}$ are the per-token reward and KL penalty terms, respectively. These terms are computed using a learned value function $V_{\phi}(o, q, t)$ and a critic model $\psi_{\phi}$.

In contrast, GRPO replaces the PPO loss with the following formulation:

$L_{\text {GRPO}}(\pi_\phi) = \mathbb {E} [q \sim P(Q),
o \sim \pi_\phi(q)] \frac{1} {|o|} \sum\_{t=1}^\|o\| \varepsilon \_ {\text {GRPO}
(o, q, t)} + \underbrace{\frac{1}{2}\lambda^2\|\phi-\psi\|_2^2}_{\text{KL}}

This new loss includes two components: a group relative reward term, $\varepsilon_{GRPO}$, and a KL regularization term between the current policy and a reference policy, which serves as a baseline. The group relative reward is defined as follows:

\varepsilon_{\text {GR PO}} (o, q, t) = \varepsilon_{\textrm{GAE}}(o, q,
t) - \underbrace{\frac {1} {|o|}\sum\_{t'=t}^{|o|}\varepsilon_{\rm
GAE}(o, q, \t')}_\text{reward decay}

The Group Relative Reward is calculated using the group return, $\varepsilon_{{\rm GAE}}$, and is adjusted by a reward decay factor. The group return is determined by applying a value function, $\phi$, to the group outcome, while the advantage is estimated using a critic, $\psi$. Unlike PPO, GRPO does not require storing the advantage estimates; instead, it directly uses the value function outputs. As a result, the computation of the value function is the only requirement for GRPO. To further reduce memory usage, the value function can be updated online using a moving window strategy. In summary, GRPO is an efficient method for optimizing policies that does not require storing advantage estimates.

# Value Function Approximation by LLMs

Value function approximation is a critical component of both PPO and GRPO algorithms. In these methods, a value function is used to compute the group return, which is then subtracted from the reward at each time step to obtain the advantage. The advantage is subsequently utilized to adjust the policy gradient. Traditionally, value functions are approximated using neural networks, but recent research has shown that LLMs can also effectively approximate value functions. This approach leverages the ability of LLMs to generate accurate natural language descriptions of game states and outcomes, as well as their capacity to handle long-range dependencies.
