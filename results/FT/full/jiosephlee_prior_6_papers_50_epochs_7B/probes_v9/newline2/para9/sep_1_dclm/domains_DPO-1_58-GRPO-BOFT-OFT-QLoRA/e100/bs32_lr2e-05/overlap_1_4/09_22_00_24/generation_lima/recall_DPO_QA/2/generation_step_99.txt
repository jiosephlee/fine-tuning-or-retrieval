DPO is a method for training language models to follow human preferences without using reinforcement learning. It is based on the observation that, if a language model is trained on human preference data, then the probability ratio of preferred completions over non-preferred completions can be used to infer a reward function that explains this preference. This reward function can then be used to reweight completions in a way that directly optimizes the likelihood of the preferred completions, without the need for reinforcement learning.

In contrast to previous approaches, DPO does not require any explicit reward model training and avoids the use of importance sampling. Instead, it uses a single language model that is trained to account for both the observed preferences and its own prior. This allows DPO to achieve better sample quality while being simpler to implement and train.

Introduction

Language models have become a central component in modern natural language processing systems. Their ability to generate text has led to their widespread adoption in applications such as chatbots, summarization, and translation. However, these models are often evaluated using metrics that do not reflect their actual utility, such as the zero-shot translation evaluation metric (BLEU). In order to improve the utility of language models, we propose a new approach for evaluating and training them based on human preferences. Our approach, called Direct Preference Optimization (DPOS), leverages the fact that humans prefer certain outputs over others when given a prompt and a set of candidate responses. We show that by optimizing language models to match these preferences, we can improve their performance on downstream tasks such as machine translation.

# DPO: your language model is secretly a reward model

We begin by introducing the standard Reinforcement Learning from Human Feedback (RLHF) pipeline. In RLHF, a reward model is trained to explain human preferences, and then used to optimize a policy. The RLHF pipeline typically proceeds as follows: 1) Collect preference data, where a human provides a prompt and a set candidate responses, and indicates which response they prefer. 2) Train a reward model to explain the observed preferences. 3) Train the policy using reinforcement learning, optimizing for the reward model and a KL-divergence penalty to prevent large policy changes. 4) Optionally, fine-tune the policy with supervised learning to reduce reward model induced errors.

An alternative approach is to train a language model to directly imitate the observed preferences. This can be done by maximizing the log-likelihood of the preferred completions. While this approach is straightforward, it requires training a separate reward model to explain the preferences. In this section, we introduce Direct Preference Optimization (DPOP), a method that eliminates the need for a separate reward model. DPOP trains a language model to directly match the preferences by treating it as a reward model. Specifically, we observe that if a language model is conditioned on a reward model that explains the observed preferences, then the same reward model can also be used to reweight samples according to those preferences. By optimizing the language model to match the observed rewards, we can avoid explicitly training a separate reward model. This is formalized as follows:

Given a prompt $x$, a set of candidate completions $\{y_1,y_2,\dots,y_N\}$ sampled from the language model's prior distribution, and a preferred completion $y^*$, we can write the following relationship:

$ \frac{p_\theta(y_{y^*} | x)}{p_\theta(y_1 | x)} = \frac{\pi(y_{y^*}|x)}{\pi(y_1|x)} \cdot \frac{\exp(r_\varphi(x,y_{y^*}, y_1))}{\sum_{i=1}^N \exp(r_\varphi (x,y_i, y_{y^*}))}$

where $p_\theta$ and $\pi$ are the language model and the reward model, respectively, and $r_\varphi$ is a reward function parameterized by $\varphi$. This relationship can be interpreted as the ratio of the conditional probabilities under the language model, where $y^*$ is weighted either by the prior distribution or by the reward model.
