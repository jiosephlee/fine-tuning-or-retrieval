# What is preference learning?

Preference learning is a method for training language models to behave in a certain way by using human preferences. It's a way to teach a model what humans like without explicitly telling it the rules. Instead, we show it examples of good and bad outputs and let it figure out the pattern on its own.

The process starts by collecting human judgments about which output from a model is better. These judgments are then used to train a reward model, which assigns a score to each output. The reward model can be used to optimize the language model so that it produces higher-scoring outputs.

There are two main approaches to preference learning: reinforcement learning from human feedback (RLHF) and direct preference optimization (DPO). RLHF uses a reward model to generate human feedback, while DPO directly optimizes the language model based on the human preferences.

# How does DPO work?

DPO is a method for training a language model using human preferences. It works by optimizing the language model directly based on the preferences, rather than using an intermediate reward model. This makes it simpler and more efficient than methods that use reinforcement learning.

Here's how it works at a high level. We start with a pretrained language model and collect human preferences over outputs generated by the model. For each prompt, we ask the model to generate multiple completions, and humans choose which completion they prefer. The model is then updated to increase the probability of the preferred completions and decrease the probability of the dispreferred completions.

To make this concrete, consider the following example. Suppose we have a language model that generates responses to a question. We prompt the model with a question and collect several candidate responses. Humans then rank these responses according to their preference. DPO updates the language model parameters so that the preferred response becomes more probable and the dispreferred responses become less probable.

DPO uses a simple objective function that encourages the model to assign higher probabilities to preferred completions and lower probabilities to dispreferred completions. The update is applied only to completions that were actually compared by humans, ensuring that the model is not overfit to the limited comparisons made during training.

# What is the DPO algorithm?

The DPO algorithm is the core method used in the Direct Preference Optimization paper. It is a straightforward approach for training language models using human preferences. The algorithm is described in detail in the paper, but here is a summary:

1. Collect human preferences over completions generated by the current model. For each prompt and each completion, ask a human to select the preferred completion from a set of candidate completions.
2. Compute the pairwise preference scores between all pairs of completions for a given prompt. These scores indicate how much more likely the preferred completion is compared to the dispreferred completion.
3. Update the language model parameters using the following objective:
\[
\mathcal{J}(\theta) = \mathbb{E}_{(x, y_+, y_-) \sim \text{Data}} \left[ \log \frac{\pi_\theta(y_+ | x)}{\pi_\theta(y_- | x)} \right] - \beta \sum_{(x, y_+ \succ y_-)} \log \frac{\alpha}{1 + \exp(-\beta \text{score}(y_+, y_-))}
\]
Here, $\pi_\theta$ denotes the language model, $x$ is the input, $y_+$ and $y_- $ are two completions for the prompt $x$, and $y_+ \succ y_-$ indicates that $y_+$ is preferred over $y_-$ by a human. The term $\beta$ is a temperature-like hyperparameter that controls the strength of the regularization. The term $\alpha$ is a normalization constant that ensures the regularization term sums to zero over all pairs of completions.

4. Optionally, perform gradient clipping to prevent large updates.

5. Repeat steps 1–4 until convergence.

This algorithm is simple and effective. It avoids the need for an explicit reward model, which simplifies the overall system. The algorithm also includes a regularization term that prevents the model from becoming too sensitive to the limited number of comparisons available during training.

# What are the advantages of DPO?

There are several advantages to using DPO for preference-based language model training. Here are the key benefits:

Efficiency: DPO is computationally efficient because it does not require running reinforcement learning algorithms. Instead, it directly optimizes the language models using the collected human preferences. This reduces both computational cost and the time required to train the model.

Simplicity: DPO is conceptually simple. It eliminates the need for an intermediate reward model, which reduces the complexity of the overall system. This makes it easier to implement and understand.

Robustness: DPO is robust to the number of comparisons provided by humans. Unlike other methods, it does not require a fixed number of comparisons per prompt.
