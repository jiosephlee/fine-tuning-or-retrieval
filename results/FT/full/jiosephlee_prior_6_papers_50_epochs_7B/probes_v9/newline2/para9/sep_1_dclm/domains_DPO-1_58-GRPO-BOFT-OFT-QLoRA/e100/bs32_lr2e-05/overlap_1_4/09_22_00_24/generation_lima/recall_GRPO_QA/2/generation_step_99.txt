What is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GRPo) is a memory-efficient variant of Proximal Policy Optimization (PPO). It was introduced by DeepSeekMath to train large language models for mathematical reasoning with limited GPU memory.

In contrast to PPO, which requires storing the entire value function $V(\theta)$, GRPO only needs to store the difference between any two value functions, i.e., $\Delta V(\theta) = V(\theta_1) - V(\theta_0)$. This reduction in storage requirements makes it possible to train models with much larger context lengths than what is feasible with PPO.

Here is how GRPO works:

* At each training step, we sample a batch of trajectories $\{y_1, y_2, \cdots, y_N\}$ from the current policy $\pi_{\theta}(y | x)$.
* For each trajectory, we compute the advantage $A_i = G(y_i; x, y_{{\leq i}}) - M(x, y_{{\geq i+1}}} )$, where $G$ and $M$ are the goal and model models, respectively.
* We then update the parameters using the following gradient:
  $
    \nabla_{\theta}\mathbb{E}{[q \sim P(Q), o \sim \pi_{\theta}(O|Q)]} \left[\frac{\eta}{(1 + \exp(A_q - A_o))}, A_o - A_q\right] = 0,
  $
  where $A_q = \sum_{i=1}^{|q|} \nabla_{y_i} G(q; x, y_{{{< i}}} )$ and $A_o = \sum_{i={1} }^{|o|} \nabda_{i} M(x, y_{{{> i}}} ).
  $
* To calculate $A_o$, we use the fact that $G(o; x, y_{{$<$ o$)}} = G(x, y_{{{>= o}}} )$.
* The second expectation in the gradient is approximated by $\mathbb{E}_{\pi_{\theta}}$.

This method is similar to PPO in that it uses a generalized advantage estimator (GAE) to compute advantages. However, unlike PPO, GRPO does not require storing the value function $V(\phi)$. Instead, it only needs to store the differences $\Delta V(\phi) = V(\phi_1) - V (\phi_0)$.<|endoftext|>
