# LoRA: Low-rank Adapters

LoRA is a method for adapting pretrained models for specific downstream tasks by adding a small number of trainable parameters. LoRA modifies the linear projection matrices in a neural network by introducing two learnable low-rank matrices for each projection. For a given projection $W$ in a layer, LoRA replaces $W$ with $W + M_A \odot A$ and $W + M_B \odot B$, where $M_A$ and $M_B$ are learned low-rank matrices of rank $r$ (the authors recommend $r=32$), and $A$ and $B$ are bias terms. The motivation behind LoRA is that the majority of the changes required to adapt a pretrained model to a new task are localized to a few neurons or connections. By introducing low-rank matrices, LoRA captures these local changes efficiently, thus enabling the adaptation of very large models with a relatively small number of trainable parameters.

LoRA’s parameter efficiency is achieved by limiting the number of trainable parameters, which is crucial for finetuning large models. In contrast to full finetuning, LoRA introduces only a small number of trainable elements per layer, making it possible to finetune models with memory constraints. The authors report that LoRA can finetune 7B-parameter models on a single 48 GB consumer GPU, whereas full finetuning requires four 16 GB GPUs. Furthermore, LoRA can be applied to models with up to 70B parameters, whereas full finetuned models of this size are not feasible.

LoRA’s effectiveness stems from its ability to capture the distributional shift between the source and target domains by adjusting the pretrained model’s output distributions. To achieve this, LoRA modifies the pretrained model’s logits, which are then passed through a softmax to obtain the final output probabilities. The authors note that LoRA’s low-rank structure is particularly well-suited for capturing the changes in the logits distribution, as these changes are often localized and of low rank.

# Quantization of LoRA

Quantization is the process of mapping continuous-valued data into a discrete set of values. In the context of machine learning, quantization is used to reduce the memory footprint of neural network models by representing weights and activations with fewer bits than the usual 32-bit floating point format. The primary goal of quantization is to minimize the loss of model accuracy while significantly decreasing memory usage. The most common types of quantization are int8 and int4. Int8 quantization maps weights and/or activations to a set of 256 values (8 bits), whereas int4 quantization uses 16 values (4 bits). Int4 quantization typically yields greater memory savings but may result in more significant accuracy degradation.
