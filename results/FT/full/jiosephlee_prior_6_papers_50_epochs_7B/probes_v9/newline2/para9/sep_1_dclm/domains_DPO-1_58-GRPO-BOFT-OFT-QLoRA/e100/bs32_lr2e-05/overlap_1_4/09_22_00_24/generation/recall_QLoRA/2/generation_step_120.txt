# Motivation and problem statement

Finetuning large, already-trained models is a widely adopted approach in modern natural language processing (NLP). However, due to the substantial resource demands of this process, it has become increasingly difficult to expand and adapt models further. For example, finetuning a 3B parameter model typically requires over 780 GB of GPU memory, making it impractical to conduct such operations on most hardware currently available. To address this issue, techniques for reducing the memory footprint during finetuning are necessary.

One straightforward solution is to reduce the precision of the weights being stored. While 16-bit precision is a common compromise between accuracy and memory savings, 4-bit precision offers even greater reductions in memory usage. Nevertheless, 4-bit precision often leads to significant degradation in model quality. To mitigate this, previous studies have proposed methods that increase the representational richness of 4-bit quantized weights. One prominent technique involves adding a small number of bits—commonly 2 bits—to the quantized weights, thereby maintaining a 4-bit overall precision. Although this approach can enhance performance, it does not fully exploit the potential of 4-bit precision. Specifically, the added bits are incorporated directly into the quantized weights themselves, rather than being applied to the quantization error.

An alternative strategy is to maintain the original 16-bit base weights during finetuning while utilizing 4-bit quantization exclusively for gradients. This approach, known as gradient checkpointing or gradient clipping, involves storing both the original weights and their quantized versions, with gradients being computed relative to the original weights. While this method effectively lowers memory requirements, it introduces additional computational overhead during backpropagation. Consequently, this approach may degrade performance, especially when dealing with large models.

Another related challenge is the limited availability of memory for activation storage during finetuning. Activations typically occupy a significant portion of the total memory usage during training, particularly for large models. Techniques that compress activations can substantially enhance the feasibility of finetuning on resource-constrained hardware.

In summary, the central problems addressed by this study are as follows:

- How to achieve high-quality 4-bit finetuning without relying on extra bits embedded within the quantized weights?
- How to minimize the memory demands for activation storage during fineting?

# Components of QLoRA

QLoRA consists of two main elements: a low-rank adaptation (LoRA) update and an efficient grouping strategy for weight tensors. We will describe each component in detail below.

Low-rank adaptation (LoRa): LoRA is a quantization technique that enhances quantization precision by introducing a low-rank matrix to compensate for quantization errors. Concretely, given a weight tensor quantized to $m$ bits, LoRA represents the quantization error as a product of two low-rank matrices, i.e.,

$\tilde{W} = \text{Quant}(W) + \text{LoRA}(d, r, r) = W - \text{Quant}( W),$

where $\text{Quant}(W)$ denotes the quantized version of $W$, and $\text{LoRA}(r, r)$ is the low-rank error introduced by quantization. By adjusting the loRA matrix during finetuning, the original model parameters $W$ are updated while the quantized weights $\tilde{W}$ remain unchanged. This approach allows for accurate quantization of the base model while enabling finetuning via a compact representation.

To further reduce memory usage, QLoRA employs 4-bit quantization of the loRA matrix, resulting in a 20-bit memory footprint for the adapted weights ($4b$ for the quantized weights plus $16b$ for the LoRA matrix). Compared to the standard 28-bit memory requirement of 16-bit base weights, this represents a significant reduction in memory usage.
