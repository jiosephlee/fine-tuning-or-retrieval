According to the paper "QLoRA: Efficient Finetuning of Quantized LLMs", what is QLoRA?<|EOT|>Quantization with Low-rank Adapters (QLoRA) is a technique for finetuning large language models (LLMs) that have been quantized to 8-bit precision. The key idea behind QLoRA is to keep a low-precision full model and add a small number of trainable parameters, called adapters, which are trained in 16-bit precision. This approach allows for significant memory savings while maintaining performance comparable to full 16-bit finetuning.

The motivation for QLoRA comes from the observation that the quantization error introduced by converting weights from 16-bit precision to 8-bit precision can be compensated for by adding a small number of trainable weights. These additional weights are trained in 16-bits during finetuning, while the original 8-bit weights remain fixed. This approach reduces the memory footprint of finetuned LLMs compared to full 16-bit precision finetuning, since only the adapters need to be stored in 16-bit precision.

In the QLoRA paper, the authors show that a 7B LLM can be finetuned on FLAN v2 with 3B parameters using only 5GB of GPU memory. They also demonstrate that QLoRA achieves performance comparable to full 2T parameter 16-bit finetuned LLM on MMLU benchmark.

## How does QLoRA work?

The core idea of QLoRA is to separate the original quantized weights into two parts: a high-precision part and a low-precision part. During training, the low-precision part remains unchanged, while the high-precision part is augmented with a set of trainable parameters called adapters. This separation is done by applying a block-wise dequantization strategy, where each block contains $2^N$ quantized values. Here, $N$ is chosen such that $2^N$ is less than the maximum number of neurons in a single layer. For example, if $N=6$, then each block will contain 64 neurons. The high-precision part is then split into $2^N$ equal parts, each of which becomes an adapter. Each adapter is trained independently to compensate for the quantization error introduced in its corresponding block.

To formalize this, consider a weight matrix $W \in \mathbb{R}^{d\times n}$, where $d$ is the number of neurons and $n$ is the number of input features. We first divide $W$ into $2^6$ blocks, each containing $d/64$ neurons. We then quantize each block separately, resulting in a quantized matrix $\hat{W}_q \in \mathbb*{B}^4$. The high-precision matrix is defined as
\[
\tilde{W}_h = \hat{W}_q + \text{Adapter},
\]
where $\text{Adapter} \in \mathbb*R^4$ is the low-rank matrix. In practice, we use a block size of 64, so $\tilde{W}_i$ is a $1 \times 64$ vector for all $i$. The final quantized matrix is given by
\[
\hat{W} = \text{Quant}( \tilde{W}_1, \cdots, \tilde{W}_{2^6} ).
\]
Here, $\text{Quant}(\cdot)$ denotes the quantization function. During training, the original quantized matrix $\hat*{W}_q$ is kept fixed, while the high-precison matrices $\tilde{W_i}$ are updated as the model parameters. The low-rank matrix $\text{Adapter}$ is trained in 16-bit floating point precision.

An important property of QLoRA is that it can be applied to any existing quantized model without retraining. To apply QLoRA, one simply needs to extract the quantized weights and choose a block size. The paper suggests a block size of 128 for 11B and 70B models, and a block size of 256 for 3B and 7B models. Once the block size is chosen, the high-precision matrix is constructed by concatenating the $2^6$ low-precision matrices. The low-rank adapters are then initialized to zero, and training proceeds normally.

## Why does QLoRA work? What is the theoretical justification?

The basic idea behind QLoRA can be understood through the lens of information transmission. When a neuron receives an input, it must transmit the information contained in that input to its output. If the neuron's weights are quantized, the information transmitted may be distorted. However, the neuron can compensate for this distortion by adjusting its bias or by changing the way it processes subsequent inputs. In other words, the neuron can adapt to the quantization error.
