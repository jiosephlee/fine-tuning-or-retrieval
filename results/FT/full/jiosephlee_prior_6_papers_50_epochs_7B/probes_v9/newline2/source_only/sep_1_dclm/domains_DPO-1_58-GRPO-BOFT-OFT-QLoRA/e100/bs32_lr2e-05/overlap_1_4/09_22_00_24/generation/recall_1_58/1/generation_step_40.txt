# What is a floating point number?

Floating point numbers are used to represent real numbers approximately. They are composed of three fields: a sign bit, an exponent field, and a significand (also called mantissa) field. The IEEE 754 standard defines the most common representation for floating point numbers. There are different precisions: single precision (32 bits) and double precision (64 bits). # What is a fixed point number?

Fixed point numbers are integers used to represent real numbers by interpreting a certain number of consecutive bits as the integer part and the remaining bits as the fractional part. For example, if we have 16 bits and we interpret the first 8 bits as the integer part, the last 8 bits as the fractional part, then we have a 16-bit fixed point number with 8-bit fractional precision. Fixed point arithmetic is hardware-accelerated in many CPUs and GPUs, and it is often used in digital signal processing and video games.

Its main advantage is that it has a very large dynamic range, similar to the dynamic range of FP32, while using half the memory. This makes it suitable for training deep learning models, where the gradients can have a very large dynamic range. bfloat16 is natively supported by some CPUs and GPUs, such as the NVIDIA A100 GPU. However, not all hardware supports bfloat16 natively, so software emulation may be required.
