# Parameter efficiency in finetuning

When we train a pretrained model, finetuning is usually needed to adapt the pretrained model to downstream tasks. In general, there are two ways to finetune a pretrained model: full finetuning and head finetuning. Full finetuning means we continue training the whole model on the downstream dataset. Head finetuning means we only finetune the upper layers of the pretrained model, while keeping the lower layers unchanged. Head finetuning is much more common than full finetuning, because finetuning all the parameters of a large model is very expensive.

After finetuning, we often find that the capacity of the pretrained model is already sufficient for many downstream tasks. So why do we need to spend time and resources to train the whole model from scratch? This motivates the research area of finetuning. In general, finetuning can be viewed as learning a small update (or delta) $\Delta \theta$ to the pretrained model $\theta_0$. There are many finetuning methods, such as standard gradient descent, Adam, etc. No matter which finetuning method we use, the number of trainable parameters of the finetuned model is $|\theta| = |\theta_0| + |\Delta\theta|$. Since $|\theta_0|$ is usually very large, the parameter efficiency of finetuning is defined as the ratio of the number of trainable parameters in the finetuned model to the number of trainable parameters the original model, i.e., $\text{PEF} = \frac{|\theta|}{|\theta_0|}$.

We can see that the parameter efficiency of fineting depends on both the finetuning method $|\Delta\theta|$ and the pretrained model $|\theta_0|$. For head finetuning, since we only finetune a small part of the model, the parameter efficiency is usually quite high. For full finetuning, the parameter efficiency is low. To improve the parameter efficiency of finetting, people have proposed many methods, such as low-rank weight update, sparse finetuning, etc. These methods aim to restrict the degree of freedom of the finetuned delta, so that the finetuned model has less capacity to overfit the downstream dataset.

# Matrix factorization

Matrix factorization is a technique to decompose a matrix into a product (or sum) of multiple matrices. It is widely used in many areas, such as numerical analysis, machine learning, and signal processing. There are many kinds of matrix factorization, such as eigenvalue decomposition, singular value decomposition, low-rank decomposition, Cayley parameterization, etc. In this section, I'll introduce two kinds of matrix factorizations used in the paper: Cayley parameterization and block-diagonal matrix factorization.

Cayley parameterization is a way to parameterize an orthogonal matrix with a product of two skew-symmetric matrices. A real $n\times n$ matrix $R$ is orthogonal if $R^\top R = RR^\top = I$. Using the Cayley parameterization, we can write $R$ as
\[
R = \text{det}(R) \cdot \text{exp}\left(\frac{1}{2} \text{ad} R\right),
\]
where $\text{ad} R$ is the skew-symmetric matrix defined as $\text{ad}R = R^\top - R$. The determinant and exponential are applied elementwise. This parameterization is also called the matrix exponential of a skew-symmetric matrix. It is easy to verify that the matrix on the right hand side is orthogonal, i.e., $R^\top R=I$. Compared to the canonical parameterization $\theta \in \mathbb{R}^{n\times n}$, Cayley parameterization uses $2n-1$ parameters (the $(2n-1)$ entries of $\text{ad} \theta$).
