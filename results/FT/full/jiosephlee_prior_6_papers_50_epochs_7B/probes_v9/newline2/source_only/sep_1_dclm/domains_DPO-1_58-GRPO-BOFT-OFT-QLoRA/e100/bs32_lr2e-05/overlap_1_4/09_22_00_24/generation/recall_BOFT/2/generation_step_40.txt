Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks without adding parameters or significantly increasing training time. BOFT achieves this by reorganizing the pretrained weight matrix into a block-diagonal matrix with carefully designed blocks. BOFT also introduces a simple yet effective way to finetune these blocks, which we call orthogonal finetuning with butterfly weights (OFTBW). BOFT is parameter-efficient because it reduces the number of trainable parameters to a small fraction of the original model while maintaining strong performance on benchmarks.

The key idea behind BOFT is to factorize the weight matrix into a product of two matrices: a block-diagonal matrix and an additional weight matrix. The block-diagonal matrix is composed of many small block matrices, each of which has a special structure that makes it easy to orthogonalize. The additional weight matrix is then added to the block-diagonal matrix to recover the full finetuned model. This factorization is inspired by the butterfly structure in mathematics, which is why we name our method BOFT. The butterfly structure allows us to easily orthogonalize the blocks, which is how we achieve parameter-efficiency. We can train the additional weight matrix with fewer parameters than usual because the blocks are already orthogonalized.

BOFT is an extension of OFT, which is a simple and effective method to finetune large pretrained models while preserving the pretraining features. OFT works by orthogonalizing the finetuning weight matrix so that the pretrained features are not destroyed during finetuning. However, OFT is not parameter-efficient. BOFT improves upon OFT by making it parameter-efficient through the butterfly factorization. BOFT can be viewed as a generalization of OFT to the block-diagonal setting. In addition to being more parameter-efficient, BOFT also has better convergence properties than OFT. The butterfly factorization helps BOFT converge faster and more stably than OFT. We will discuss the convergence properties in detail later.

BOFT is not only parameter-efficient but also computationally efficient. BOFT can be seen as a block-diagonal weight matrix with a particular block structure. Computing the forward pass with a block-diagonal weightmatrix is much faster than with a full matrix due to less operations. As a result, BOFT is both parameter- and computation-efficient.

BOFT is particularly useful in scenarios where we want to avoid adding parameters, such as when we have a model that is already pushing the memory limit. BOFT can help save GPU memory and accelerate training, enabling us to finetune more models on more tasks within the same budget. BOFT can also be used to adapt a base model to multiple device types, such as mobile and edge devices, where memory and compute are constrained.

# Motivation

Before introducing BOFT, let us first motivate the need for BOFT with a simple example. Consider a fully connected layer with a weight matrix $W\in\mathbb{R}^{d\times n}$ that maps an input vector $x\in\mathbb{T}^d$ to a hidden vector $h\in\mathbb T^n$. The forward pass is computed by $h=Wx$. Suppose we use the standard finetuning approach where we add a small full matrix $A\in\mathbb R^{d\times n}\) to the weight matrix, i.e., $h=(W+ A)x$. With this setup, when $d=n$, i.e., a square matrix, we have $A\in\ mathbb{R}^{n\times n}$, which contains $n^2$ parameters. This is the standard way to finetune neural networks and is not parameter-efficient.

Now consider a special case where $W$ is already orthogonalized, i.e., $W^\top W=WW^\top=W$, and we want to keep it that way during finetuning. One naive way is to orthogonalize $A$ so that $W+A$ remains orthogonal. However, orthogonalizing a full matrix $A\mathrel{=} \begin{bmatrix}a & b\\b^{\top}&c\end{bmatrix}\in\mathbb{ R}^{2\times 2}$ costs $\mathcal{O}(8)$. For a square matrix of size $n$, the cost is $\mathcal{O}((n^2)^2)$. It is clear that orthogonalizing a full matrix is expensive. To avoid this expense, OFT takes a different route.
