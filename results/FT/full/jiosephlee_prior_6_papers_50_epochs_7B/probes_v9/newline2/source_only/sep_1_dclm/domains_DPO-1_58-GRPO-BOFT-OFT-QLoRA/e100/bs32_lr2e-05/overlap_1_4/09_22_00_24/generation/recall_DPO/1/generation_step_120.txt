# What is preference learning?

Preference learning is a way to teach an AI system what we want it to do without explicitly telling it how to do it. Instead, we show it examples of situations where different actions lead to different outcomes, and we indicate which outcome we prefer. Over time, the AI system figures out the patterns behind our preferences and starts taking actions that lead to the outcomes we prefer.

There are two main approaches to preference learning: inverse reinforcement learning (IRL) and direct preference optimization (DPO). In IRL, the AI system tries to infer a reward function from human preferences. Once it has inferred the reward function, it can use standard reinforcement learning (RL) to figure out how to achieve high reward. DPO, on the other hand, trains a neural network to predict human preferences directly. It does this by optimizing the language model to produce the output that humans prefer.

Both approaches have their advantages and disadvantages. IRL requires the AI system to infer a reward function, which can be difficult. DPO, however, can train on data that only contains preferences without requiring explicit rewards. This makes it well-suited for language models, since we can easily collect preference data but not reward functions.

# How does DPO work?

The core idea behind DPO is simple: given a prompt and two responses, the DPO-trained language model is designed to produce the response that humans prefer. To achieve this, the model is trained with a cross-entropy loss that compares the predicted probability of the preferred response with the actual probability. Formally, if $y_1$ and $y_2$ are the two responses and $\pi(y_2 \mid y_1, o)$ is the DPO-trained model's predicted probability mass on response $y_2$, the loss is:

$L(\pi) = -\mathbb{E}_{y_1, y_2, o \sim P}\left[\log \frac{1}{1 - \beta}\pi(y_2 \ mid y_1, o)\right]$

where $P$ is the data distribution and $\beta$ is a parameter that controls how strongly the model is penalized for predicting the dispreferred response. When $\beta$ is set to $0$, the loss reduces to the standard maximum likelihood loss and the model is indifferent to the dispreferred response. As $\beta$ increases, the model becomes more and more certain that the dispreferred response is impossible.

In addition to the preference loss, DPO also includes a standard language modeling loss to prevent the model from forgetting its basic language modeling abilities. The combined loss is:

$L(\theta) = \alpha L_{PLM}(\theta) + (1-\alpha)L_{DP}(\theta)$

where $\alpha$ is a hyperparameter that determines the relative weight of the PLM loss versus the DPO loss, and $L_{PLM}$ and $L_{DP}$ are the PLM loss and DPO loss, respectively. If $\alpha$ is set to $1$, the model only learns preferences and loses its ability to perform ordinary language tasks. If $\alpha$ approaches $0$, the model focuses exclusively on PLM and ignores the preferences. Thus, $\alpha$ controls the balance between preserving the language model's general capabilities and making it adhere to human preferences.

DPO can also be extended to a setting with multiple preferred answers. In this case, the loss is defined as the sum over all preferred responses:

$L(\pi)=-\mathbb{E}_{{y_1}, {y_2}, {y_3} \sim P}\left[ \sum_{y \in Y} \log \frac{1}{{1-\beta}}\pi(y \mid y_1,o)\right]$

This extension is useful when we want the language model to produce one of several known correct answers, rather than preferring a single correct answer among many possible responses.

# How is DPO different from RLHF?

Reward modeling approaches like RLHF and DPO share a common goal: training language models to adhere to human preferences. However, they differ in how they approach this goal. RLHF infers a reward function from human judgments using IRL, then trains an RL agent to maximize that reward. DPO, meanwhile, trains a neural network directly to predict human preferences using a cross-entropy loss.

One key difference is that DPO does not require the collection of explicit rewards. Since collecting rewards can be expensive, DPO avoids it altogether. Instead, DPO uses the preferences themselves as the training signal.
