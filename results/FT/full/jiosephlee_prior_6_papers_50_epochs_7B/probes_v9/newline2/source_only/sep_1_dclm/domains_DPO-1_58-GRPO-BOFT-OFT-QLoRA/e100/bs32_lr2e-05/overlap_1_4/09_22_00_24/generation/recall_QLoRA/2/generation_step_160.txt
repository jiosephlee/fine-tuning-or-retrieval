# Motivation and overview of QLoRA

The motivation behind QLoRA comes from the fact that the number of parameters in LLMs has been growing rapidly, while the methods used for finetuning these models have not been able to keep up. Standard 16-bit finetune approaches require a copy of the full model's weights for each worker, which quickly becomes infeasible as the size of the model grows. For example, finetuning the 70B parameter version of ChatGPT would require 560 GB of RAM per process with a 16-bit reproduction of weights. This is far beyond the reach of most researchers and practitioners.

To address this issue, the authors propose QLoRA, an iterative process that uses an extremely small support dataset and a small set of reference(weights) to update a quantized(weight map) weight matrix. During iteration, the reference weights are updated in 16-bit precision while the weight map utilizes 4-bit quantization. This allows for significant reductions in the memory required for finetuning large models, enabling the training of much larger models on a single machine or better parallelization of large models across a smaller number of processes.

In addition to reducing the memory footprint, QLoRA also improves the throughput of finetuning large models. This is because the 4-bit quantized weight map can be loaded into CPU caches, leading to faster training times than with a 16-bit weight replica.

# 4-bit weight quantization

The first component of QLoRA is 4-bit weight quantIZATION. The general process of quantization involves mapping continuous weights to a discrete set of values. In QLoRA, weights are quantized using the following steps:

1. Mean subtraction: The mean of the weight tensor is subtracted from the weight tensor to center the data.
2. Clipping: The weight tensor is clipped to lie within $[-q_{max}, q_{max}]$ where $q_{max}$ is a user-specified clipping threshold.
3. Quantization: The clipped weight tensor is quantized to a set of discrete values using a lookup table (or quantization function).

The authors use a symmetric quantization function, which takes the form:
\[
\text{quant}(x) = \begin{cases}
\frac{1}{2}(\hat{m} + \hat{c}) + \frac{1}{2}\left(1 + \frac{1}{{(x-\hat{m})}/{\hat{c}}}\right)^{-1}, & x \ge \hat{m}, \\
\frac{1}{1 - {\hat{c}}/{x-\hat{m}}}, & x < \hat{m},
\end{cases}
\]
where $\hat{m}$ and $\hat{c}$ are the minimum value observed in the centered weight tensor and the slope of the quantization function, respectively.

# Weight clipping

Weight clipping is the second component of QLoRA. The idea behind clipping is to limit the range of values that are quantized. More specifically, weights that lie outside a specified range $[-q_{max}; q_{max}]$ are set to zero and do not contribute to the forward pass. This allows for aggressive quantization while limiting the impact of outliers.

The authors propose two new techniques for clipping weights:

1. Static clipping: A static threshold $q_{max}$ (e.g., 0.05) is applied to the entire weight tensor before quantization. Weights outside the specified range are set to zero.

2. Dynamic clipping: A dynamic threshold $q_{max}(t)$ is applied to each tensor dimension at each time step. The dynamic threshold is calculated based on the 99.9th percentile of the absolute value of the reference weights over the last $T$ time steps. This approach effectively prevents outliers from one time step affecting subsequent time steps.
