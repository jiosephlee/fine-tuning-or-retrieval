# What is preference learning?

Preference learning is a way to teach an AI system what we want it to do without explicitly telling it how to do it. Instead, we show it examples of situations where different actions lead to different outcomes, and we indicate which outcome we prefer. Over time, the AI system learns to take the actions that lead to the preferred outcomes.

There are two main approaches to preference learning: inverse reinforcement learning (IRL) and reward modeling. In IRL, the AI system infers a reward function from human preferences over trajectories. In reward modeling, the AI system directly models the distribution of human preferences over single actions. Direct Preference Optimization (DPO), the method described in the paper, is a form of reward modeling.

# How does DPO work?

DPO assumes that the human preferences can be modeled as a function $r(s,a)$ that gives the reward for action $a$ in state $s$. The goal of DPO is to find the parameter vector $\theta$ for a language model such that $p_\theta(r(s,a), o_{>1})$ matches the human preference data as closely as possible, where $o_{>1}$ denotes subsequent tokens after the action $a$ is taken in state $s$.

To train the language model, DPO frames the preference learning problem as a supervised learning problem. For each training example, the example is sampled from the model $p_\theta$, producing a reward $r(s,a)$ and a subsequent token sequence $o_{>1}$. A loss function is defined as the negative log-likelihood of the human preferences, i.e.,

$L(\theta) = -\mathbb{E}_{(s,a, o_{>1}) \sim p_\theta}\left[\log p_\theta(r(s,a!), o_{>1})\right].$

This is essentially an extension of supervised learning to sequences, where the label $y$ is the reward $r(s,a!)$ and the supervision is provided not only on $y$ but also on the next tokens $o_{>1}}$. The factor $r(s,a!)$, which normalizes the reward to the particular sample, is crucial to prevent the language model from learning a constant function.

DPO uses a standard teacher forcing setup, where the training data is generated by sampling states $s$ from $p^0$, sampling actions $a$ from the current model $p_\theta$ (the "student"), and setting $r(s,a) = r^0(s, a)$. This design choice makes DPO a form of actor-critic algorithm, because it must estimate the state-action value $Q^\top(s,a) = \mathbb{E}_{p^0}[r^0(s,a, o_{> 1}) | s,a]$ in order to compute the gradient of the loss with respect to the parameters $\theta$. DPO uses a generalized advantage estimation (GAE) variant to estimate $Q^\top(s, a)$, and then optimizes the language model parameters using the gradient of the loss $L(\theta)$ with respect to $\theta$.

# What are the advantages of DPO over IRL?

The biggest advantage of DPO over ILL is that DPO is a reward modeling approach, while IRL is an inference problem. In reward modeling, we fit a parametric model $p_r(r,s,a,o)$ for the reward. In IRL, we fit an implicit reward function $r^*$ that maximizes the conditional probability of the demonstrations $d$ under the human policy $\pi^H$, i.e., $r^* = \argmax_{r} p^H(d | r, \pi^0)$, where $p^H(d | r,\pi^0)$ is the human preference data model. Because DPO directly optimizes a parametric reward model $p_r(r, s, a, o)$, it avoids the high-dimensional inference problem of IRL. Moreover, DPO can be seen as a special case of IRL—specifically, it is the reward model that matches the preference data $p^H(d|r,\pi^0)$ perfectly. However, this perfect fit is achieved by providing the reward model with the true reward function $r^0$ used to generate the demonstrations, which is typically not available in real-world IRL settings.

Another advantage of DPO is its simplicity. It is a straightforward extension of supervised learning to sequence learning. It uses well-established actor-critic algorithms to estimate the state-value and advantage, and it optimizes the language model using the gradient of a loss function. IRL, on the other hand, requires specifying an assumption about the human preference data model $p^H(d|r,\pi^0)$, which is often nontrivial.
