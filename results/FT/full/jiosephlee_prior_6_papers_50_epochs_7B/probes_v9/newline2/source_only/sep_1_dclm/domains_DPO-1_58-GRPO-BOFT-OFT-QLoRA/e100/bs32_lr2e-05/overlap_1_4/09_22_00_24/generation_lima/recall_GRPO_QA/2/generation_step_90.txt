Before diving into GRPO, it is important to understand the two major families of policy optimization algorithms: those based on actor-critic architectures and those based on a surrogate objective.

Actor-Critic Algorithms
The actor-critic framework is a common way to train stochastic policies using reinforcement learning. In this context, an "actor" refers to the policy model $\pi_\theta(s,a)$ that determines the action distribution at each state $s$. The "critic" is a value function model $V(s,\theta)$ that estimates the state-value $V(s,\theta) = \mathbb{E}_{\pi_\theta}[G_t | s = s]$ where $G_t$ is the return at time $t$. There are several variants of the actor-critic framework, but generally, the critic is trained first to approximate the value function $V^*(s,\theta)$. Then, the policy is updated using a second objective that balances exploitation and exploration: maximize the expected return while keeping the Kullback–Leibler divergence from the current policy close to zero. This objective is known as the natural gradient objective and can be written as:
$\nabla_{\theta}\mathbb{E}_{ \pi_{\theta}(a|s)}[ \log \sum_{a} \exp(\frac{1}{\beta}V^*(s,a)/\beta)a \mid s] - \beta \mathcal{D}_{KL}\big( \pi_{\theta}(\cdot|s) \mid \mid \pi_{0}(·|s)\big)$
This objective is referred to as the actor-critic objective. In practice, the return $G_t$ is approximated by a function from the Monte Carlo method or from a generalized advantage estimation (GAE). The actor-critic framework has been successfully used in the context of RLHF, with the policy modeled as a softmax policy and the value function estimated using a value function approximation.

Surrogate Objective Algorithms
Instead of explicitly estimating the value function, some policy optimization algorithms use a surrogate objective that approximates the optimal objective for parameter $\theta$. These algorithms include PPO (Proximal Policy Optimization) and its variants. PPO avoids estimating a value function by constraining the change in the surrogate objective in the direction of the reference policy. More specifically, PPO seeks to minimize the surrogate objective
$\mathbb{E}_{s\sim D}\big[\max_{a} \left[ \underbrace{\mathbb{E}_{a\sim \pi_{\theta}}\big[ \log \sum_a \exp(\frac{2}{\beta}V(s,a)/\beta)a | s\big)]}_{\text{KL-regularized objective}} - \underbrace{\mathbf{1}_{\pi_{ref}(a|s) = a}|_{a\sim \pi_\theta(s,\theta)}}_{\text{Entropy penalty}}\right]\big]$
where $\pi_{ref}$ is the reference policy. The constraint is given by the proximal operator of the KL divergence with reference policy $\pi_{ref}$. The name PPO comes from the fact that it uses the proximal point algorithm to optimize this objective, which requires computing the proximal operator of  the KL divergence. The key idea behind PPO is to constrain the update such that the new policy is not too far from the old reference policy. In contrast to actor-critic algorithms, PPO does not estimate a value function. Instead, it directly learns a good policy using a surrogate objective that is similar to the one optimized by actor-critic algorithms but with an additional penalty term.

Proximal Policy Optimization (PPO)
PPO is an off-policy algorithm, which means it can handle data sampled from a different reference policy $\pi_{\text{ref}}$.
