# Text-to-image diffusion models

Text-to-image diffusion models are generative models that produce images from a text prompt. These models are composed of three components: an encoder that converts an input image to a set of embeddings; a text encoder that converts a text prompt to a set of embeddings (often using a transformer); and a decoder that conditions on the visual and text embeddings and generates the pixel outputs. Formally, the model defines a joint probability $p(x, t)$ where $x$ is the image and $t$ is the text prompt. The model factors the joint probability into the product of conditional probabilities:

$p(x, t) = p(x|t, z) \cdot p(t, z)$ (1)

where $z$ denotes the latent code. The visual encoder $E_V$ maps an input image $x$ to a set of visual embeddings $\{E_V^i(x)\}$ and a visual code $z_V$. The text encoder $E_T$ maps a text prompt $t$ to a set of text embeddings $\{E_T^j(t)\}$ and a text code $z_T$. The decoder $D$ conditions on the visual and textual embeddings and produces the pixel outputs:

$p(x|t, z; \theta) = \mathcal{N}(x| \mu_{x|t,z; \theta}(z, E_V(x), E_T(t)), \Sigma_{x|t,z;\theta})$ (2)

where $\mu$ and $\Sigma$ denote the mean and covariance, respectively. The latent code $z$ is sampled from the prior distribution $p(z) = N(0, I)$. The paper focuses on two text-to-image diffusion models: Stable Diffusion (SD)(2022) and Imagen (v1).

Stable Diffusion (SD) is a conditional image-generating model trained on a large dataset of image-caption pairs. The training objective is to maximize the likelihood of the image given the caption and vice versa. The model uses a VQ-GAN for the visual encoder and a standard diffusion denoising model for the text encoder and decoder. SD (2022) improves the original Stable Diffusion by updating the VQ-GAN to a more robust version and adding a few minor modifications to the diffusion denoising model.

Imagen (v1) is a text-to-image diffusion model trained on open-source images and text prompts. The visual encoder is a convolutional neural network based on EfficientNet-B0 that uses a learned visual codebook to represent the features. The text encoder is a transformer-based denoising autoencoder that learns a text codebook. The generation process uses a diffusion decoder conditioned on both the visual and text codes.

Both models generate high-fidelity images with diverse semantics. However, they suffer from limited controllability, i.e., the same text prompt may produce different results depending on the sampling process. To address this issue, the authors propose to finetune the text-to-image diffusion latent space using a supervised finetuning (SFT) signal or an unsupervised finetuning (UFT) signal. Before describing the finetuning methods, we first introduce the standard finetuning paradigm and a widely used finetuning method, LoRA.
