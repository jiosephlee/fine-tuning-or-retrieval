# SmoothQuant

SmoothQuant is an iterative smooth quantizer that can preserve the original full-precision optimization surface using only a small number of bits to represent weights. It does so by iteratively reinterpreting the given quantized weights from a low-bit format to a higher-bit format while smoothing the differences between the original and quantized weights. The result is a set of quantized weights in the target low-bit format that closely match the original full-precision weight magnitudes. SmoothQuant has two major components: (1) a bit-interpreted quantization component that iteratively quantizes the input weights to higher-bit formats while smoothing the quantization error, and (2) a bit-deinterpreted reconstruction component that reconstructs the original full precision weights using the quantized low-bit weights as a reference.

Bit-interpreted quantization: In the first step, SmoothQuant quantizes the input weights using the target low-bit representation (e.g., 1.58-bit) and then interprets the integer as a bit-vector. By iterating this process, more bits are used to represent the weight and the quantization error is smoothed. For example, if the input is a 16-bit weight, and we iterate the process four times, then on the fourth iteration we interpret the integer as a 64-bit bit-vector and quantize the weight using the target 1.58-bit scale. The bit-vector shows the contribution of each bit in the integer to each coordinate of the weight tensor. Using this bit-vector, SmoothQuant can adjust the contribution of each bit to the weight tensor, thereby smoothing the difference between the input weight and the quantized weight.

Bit-deinterpreted reconstruction: After iteratively quantizing and smoothing the difference between the original weight and the quantized weights using the bit-vector, SmoothQuant then deinterprets the bit-vector back into an integer and subtracts it from the original weight. This operation effectively removes the quantization error introduced by the bit-interpreted quantize step. To ensure that the magnitude of the bit-deinterpreted weights matches that of the original full-precision(weights), SmoothQuant scales the deinterpreted weights by the average of the original and quantized weight tensors. # DeQuant

DeQuant is a block-wise dequantization algorithm that uses SmoothQuant to obtain the bit-vector of a quantized weight tensor and then dequantizes the weight tensor back to its original full-precision form. DeQuant works by dividing the weight tensor into non-overlapping blocks of a fixed size (e.g., 128). For each block, SmoothQuant is used to obtain the bit-vector representing the contributions of each bit in the quantized integer to each coordinate of that block. DeQuant then uses this bit-vector to reconstruct the original full-precision block by iterating through each bit position and adding the contribution of that bit position to all coordinates in the block. Because the bit-vector is a full-precision representation of the quantized integer, DeQuant can add the contribution of each bit position to each coordinate without changing the type or precision of the reconstructed block. After reconstructing each block, DeQuant scales the reconstructed block by the average of the block's original and quantized values to compensate for the fact the reconstructed blocks have the same type as the original full-precison weights but may have different magnitudes.
