Let me tell you all about this paper. The paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning" presents a novel method for adapting diffusion models, Orthogonal Finetuning (OFT), which preserves crucial geometric properties of neurons unlike standard finetuning or additive methods like LoRA. Orthogonal Finetuning (OFT) is an iterative finetuning method that ensures neuron parameter updates are orthogonal (perpendicular) to the pre-finetuning neuron weight vector. This is achieved by projecting the non-orthogonal component of the learned update downward before adding it to the neuron weight vector. In other words, each neuron's weights are updated so that its pre- and post-weights remain collinear, but with the addition of a new direction that is as dissimilar as possible from the original weight direction. OFT was shown to preserve the pre-finetuning manifold in a qualitative study, meaning that the learned representations of a model finetuned with OFT preserve the same relative positions and angles between dimensions. This is in contrast to standard finetuning or LoRA finetuning, where the learned representations can change position and angle relative to one another.

The authors also introduce OFT-Adapter, a light-weight adaptation method that takes a source text-to-image diffusion model and produces an adapter that can be combined with a target diffusion model to produce a finetuned text-to-image diffusion model. OFT-Adapter is designed to be much lighter than full finetuning, and it produces better performance than LoRA finetuning on the text-to-image task. OFT-Adapter uses OFT to finetune the last layer of a diffusion model's forward pass, producing a set of adapters that can be combined with any target diffusion model to produce high-fidelity, controllable, and diverse images. The authors demonstrate that their method outperforms prior work, achieving state-of-the-art performance on the BigBench benchmark, and they provide a detailed analysis of why their method works so well.

# What is the problem?

The text-to-image diffusion models currently used for controllable image generation have two major limitations: they are difficult to adapt to new tasks, and they lose semantic information during the decoding process. Both of these issues stem from the same underlying problem: the representation learning of diffusion models changes during training. When a model is trained on different datasets, its internal representation of data changes to fit the distribution of the data. This means that when we attempt to finetune a diffusion model to a new task, we are trying to change the internal representation of the model from its learned representation to the representation needed for the new task. Standard finetuning approaches struggle to preserve the original representation, and LoRA finetuning loses some semantic information during the finetuning process.

To illustrate this, consider a simple neural network with one hidden layer that is trained on dataset A. After training, the neuron weights form a particular subspace in the input space. Now suppose we want to finetune this network on dataset B. With standard finetuning, the neuron weights will move into a new subspace that fits dataset B. But we may want to keep the original subspace so that the network can still represent data from dataset A well. LoRA finetuning moves the neuron weights partway towards the direction of dataset B while preserving some information of the original subspace, but it lacks a mechanism to preserve the original subspace exactly. In both cases, the original subspace is lost to some degree.

Another way to think about this problem is to consider a neuron as a vector in an n-dimensional space. When we finetune a model, we add a new vector to the neuron weight vector, and the resulting vector will have a new direction in the n-dimensional space. The direction of the new vector is determined by the learning rate, the magnitude of the vector is determined by the magnitude of the added gradient, and the starting point is the pre-finetuning weight. If the new vector points to a direction that is not orthogonal to the original vector, then the original subspace is changed. To prevent this, we need to make sure the new vector is orthogonal to the original vector. LoRA finetunes in the orthogonal complement of the original vector, but it does not guarantee that the new vector will lie in the original subspace. OFT, however, guarantees that the new vector lies exactly in the original subspace by projecting the non-ortho component downward.

In addition to the issue of representational drift, text-to-image diffusion models suffer from information loss during the decoding stage. During training, a text prompt is converted into an intermediate latent code by a text encoder; this latent code is then decoded into an image by the visual decoder. The intermediate latent code may contain rich semantic information that is lost during the decoding process. For example, if the latent code represents both the concept of "red" and the concept of "ball", the decoder may decode the image too far away in the "red" dimension, producing an image that is overly red. To address this, the authors propose to finetune the text encoder so that it produces more accurate and consistent latent codes.
