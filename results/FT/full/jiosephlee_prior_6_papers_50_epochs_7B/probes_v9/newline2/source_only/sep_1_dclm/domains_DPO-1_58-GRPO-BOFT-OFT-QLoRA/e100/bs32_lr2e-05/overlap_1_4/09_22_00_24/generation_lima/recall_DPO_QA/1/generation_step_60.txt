According to the paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model", what is Direct Preference Optimization (DPO)?<|EOT|>Direct Preference Optimization (DPO) is a method for training language models to adhere to human preferences while avoiding the instability and sample inefficiency of PPO-style RLHF. The core idea behind DPO is that, while training a language model using preference data, we should not care about the actual reward function that would have generated the preference data, but rather only about the preferences themselves. In other words, we should treat the reward function as a black box, and optimize only with respect to the input (the prompt and the response). This is in contrast to standard RLHF, where the goal is to find the optimal policy given the reward function, which requires computing gradients with respect to the reward function.

The key insight behind DPO is that the reward function can be written as a linear function of the parameters, plus a random noise term. Therefore, the gradient with respect to the parameters coming from the reward function can be factored into the sum of two terms: one that is the same for every sample (the first term), and one that depends on the input (the noise term). Since the first term is constant with respect to the parameters, it has no effect on the optimization dynamics. However, because the noise term depends on the input, it causes high variance in the gradients, which makes training unstable. DPO therefore proposes to subtract the noise term to obtain low-variance gradients, and then add it back again to obtain the true gradient (which is inaccessible). In other words, DPO effectively decouples the reward function from the training dynamics by adjusting the variance of the gradients with respect to the parameters.<|endoftext|>
