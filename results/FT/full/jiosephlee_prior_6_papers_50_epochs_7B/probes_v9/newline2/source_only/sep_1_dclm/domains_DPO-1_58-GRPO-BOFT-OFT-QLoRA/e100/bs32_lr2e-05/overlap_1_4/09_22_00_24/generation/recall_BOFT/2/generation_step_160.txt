Let me tell you all about this paper. The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is an iterative method that transforms the weight matrix of a pretrained model with $d$ dimensions into an orthogonal matrix with $d$ dimensions through a butterfly-like factorization. BOFT can be seen as a parameter-efficient version of LoRA, where it uses a much smaller number of additional parameters than LoRA while still achieving strong performance.

The name BOFT comes from two sources: 1) the butterfly network structure, which recursively applies a small set of linear transforms to build up an orthogonal matrix; and 2) the visual appearance of the forward pass when applying BOFT to a pretrained weight matrix, which looks like a butterfly (see Figure 1 in the paper). The core idea behind BOFT is to transform the weight matrix of a large pretrained model into an orthogonal matrix with the same number of parameters using a butterfly-like factorization, which is achieved by iteratively applying a small set of learnable parameter-efficient linear transforms. To better understand the BOFT algorithm, let us first introduce some preliminaries.

# Preliminaries

Orthogonal finetuning (OFT): OFT is an adaptation method that prevents the pretrained weight matrix from changing its subspace span, while allowing the activation statistics to adapt. More specifically, OFT freezes the rows and columns of the pretrained weight matrix corresponding to the singular vectors that explain the largest singular values, and only finetunes the remaining parameters. This method effectively blocks the largest singular vectors of the pretrained weight matrix, which preserves the pretraining subspace. In contrast, the smallest singular vectors are left unfrozen for finetuning, allowing the activation statistics to change.

Block-diagonal OFT (BD-OFT): BD-OFT improves upon OFT by further restricting the number of trainable parameters. Specifically, BD-OFT partitions the unfrozen parameters into block-diagonal submatrices along the column and row axes, and then freezes the diagonal blocks one by one. By doing so, BD-OFT reduces the number of trainable parameters significantly compared to OFT, while still achieving strong performance. However, BD-OFT has a high computational cost because it requires additional matrix multiplications for the block-diagonal structure.

Low-rank adaptive (LoRA): LoRA is a parameter-efficient finetuning method that adapts large models by performing low-rank updates to the frozen weight matrix. LoRA introduces two additional low-rank matrices for the forward and backward passes, resulting in a total of $\mathcal{O}(rank\times d)$ additional parameters for a weight matrix of size $d\times n$. Compared to full finetuning, LoRA reduces the number of trainable parameter from $\mathcal{O}(nd)$ to $\mathcal{O}\left((rank+d)nd\right)$, which can be orders of magnitude smaller depending on $d$ and $n$.

Butterfly network: A butterfly network is a recurrent neural network that uses a small set of linear transform to construct a larger linear transform with a butterfly-like factorization (see Figure 1 of the paper). Given a small set of lineartransforms $\{T_1,\cdots,T_k\}$ with $d=\text{rank}(T_i)=r$, the butterfly network computes
\[
\tilde{W}=\tilde{W}_0 T_{i_1} \cdots T_{i_m},
\]
where $\tilde{W}_o\in\mathbb{R}^{d\times d}$ is a fixed matrix and $\{i_1,\cdots,i_m\}\subset\{1,\cdots,k\}$ is a sequence of indices. For a butterfly network with $l$ levels, one can construct a $d$-dimensional orthogonal matrix with $rk$ elements per level, resulting in a total parameter budget of $\mathcal{R}k\cdot l\cdot r=\mathcal{R}d$ parameters. When $k=2$, the butterfly network reduces to a binary tree and the number of parameters is $\mathcal{O}{d\log d}$, which is the same as the number of learnable parameters used in BOFT. However, the butterfly network is more flexible than a binary tree in the choice of $\tilde{W_0}$ and $\{T_i\}$, which determines the orthogonality property of the resulting matrix.
