What is Group Relative Policy Optimization (GRPO)?<|EOT|>Policy Optimization algorithms are crucial for training reinforcement learning from human feedback (RLHF). Proximal Policy Optimization (PPO) has become the de-facto algorithm for this task due to its ability to train policies directly from high-variance human preference data. However, PPO suffers from high memory consumption, especially at early training stages, when the number of episodes is small. This makes training on long-form tasks, such as mathematical texts, challenging.

Group Relative Policy Optimization (GR PO) is an alternative to PPO that shares the same core idea but uses group-based actor-critic structures to significantly reduce the memory footprint of the training algorithm. The key insight behind GRPO is that PPO needs to maintain a value function to compute the importance ratio, which is the most memory-consuming component in PPO, especially in the beginning of training when episodes are short. To tackle this, GRPO extends the actor-critic structure to a group actor-critic (GC-AC) structure, where multiple value functions are learned in a group, sharing the same action prediction error as the main actor. This way, each value function only needs to store a subset of the episodes, rather than the entire set of episodes like the main actor. As a result, the memory consumption of the value functions is reduced from $N \times |a|$ (where $N$ is the number of episodes and $|a|$ is the length of actions) to $1 \times |a|$.

To understand how GRPO works, it is useful to first review the original PPO algorithm. PPO is an actor-critic method that uses a critic to estimate the surrogate objective $-\mathbb{E}_{\pi}[\log \pi(ys, y')]$ where $\pi$ is the current policy and $y$s and $y'$s are sampled from $y$-action pair. The critic is trained to estimate this objective using temporal-difference (TD) errors. In addition to the critic, PPO also trains a value function. The value function is used to compute the importance ratio $r_{\text{importance}}(s, a) = \frac{\pi_\text{old}(a|s)}{\pi_\text{new}(a|s)}$ which is then used to compute the advantage $a(s, a) = \hat{g}(s) - \gamma \hat{v}(s, a)$ where $\hat{v}$ is the value function learned by PPO and $\hat{g}$ is the value function estimated by the critic. This advantage is then used to update the actor. 

The main difference between PPO and GRPO is how they train the value function. While PPO trains a single value function that stores all episodes, GRPO divides the value functions into $K$ groups and each value function only stores a subset of episodes, i.e., the episodes whose action pairs are assigned to the same group. More specifically, GRPO extends the standard actor-critic structure to GC-AC structure, where $K$ critics are trained to estimate the value function $\hat{v}_k(s, a) = -\log \pi_\text{old}(\cdot|s)$ for all $k$-assigned episodes and a common critic is trained to estimate the objective $-\mathbb::E_{\pi}[\log\pi(ys, y')]$. The $K$ critics are learned by TD errors in the same way as in the standard actor-critic method. In addition, for each value function, there is a copy of the actor that predicts the action for the corresponding group of episodes. To train the value functions, GRPO uses a special actor that generates actions for all episodes and produces action pairs sampled from the old policy for the episodes assigned to the value functions. Using this setup, each value function only stores $1 \times |y|$ information instead of $N \times |y|$ required by the standard PPO.
