# What is DeepSeekMath?

DeepSeekMath is an open-source project that aims to push the limits of mathematical reasoning in open language models. It is based on DeepSeek-Coder-v1.5-BiLSTM, which is a 7B parameter model pretrained on code and text. The project is developed by DeepSeek, a Chinese AI company.

DeepSeekMath introduces three major components to improve mathematical reasoning:

1. A new instruction-following mechanism called "instruction chaining" that can handle complex multi-step problems.

2. A new training dataset called "DeepSeekMath Dataset" that contains 120M questions curated from online math competitions.

3. A new training paradigm called "self-instruct" that trains the model to solve problems using only its internal instruction following mechanism.

The project also includes several technical innovations such as a new reinforcement learning (RL) loss function, a new way to generate training data from the pretrained model, and a new evaluation framework.

# Instruction chaining

Instruction chaining is a new mechanism designed to handle multi-step mathematical problems. Traditional instruction following mechanisms struggle with multi-step problems because they are trained to produce a single output given a single instruction. For multi-step problems, these models tend to produce a single output that includes all the intermediate steps, which makes it difficult to train a reinforcement learning (RL) reward model.

Instruction chaining addresses this problem by changing the way the model produces outputs. Instead of producing a single output for a given instruction, the model produces a "chain" of outputs that correspond to each step of the solution. In other words, the model produces a sequence of outputs, where each output corresponds to an intermediate step in the solution. This allows the RL loss to provide rewards for each step separately, which greatly improves training stability.

To illustrate how instruction chaining works, let's consider a simple example. Suppose we have the following instruction: "Solve 12 * 34". A traditional instruction following model would produce a single output that contains the entire solution: "408". In contrast, an instruction chaining model would produce three outputs: the first output contains "12 * ", the second output contains "34", and the third output contains " = 408". The chain is delimited by special tokens such as "<-step-" and "->step->".

Instruction chaining is not limited to multiplication problems. It can handle a wide variety of mathematical problems, including geometry, algebra, calculus, and number theory. The key idea is to insert "<-step-" and "->step->" tokens at the appropriate places in the outputs so that the model knows where each step begins and ends. Once the chaining tokens are inserted, the model can easily produce a sequence of outputs that correspond to the intermediate steps.

# DeepSeekMath Dataset

The DeepSeekMath Dataset is a new dataset of mathematical problems compiled by DeepSeek. It contains 120M questions from online math competitions, such as the American Mathematics Competition (AMC), the Mathematical Olympiad (IMO), and the International Mathematical Olympiad (IMO). These problems cover a wide range of difficulty levels, from easy to extremely challenging.

The DeepSeekMath Dataset differs from existing mathematical datasets in two important ways. First, it is much larger than previous datasets. Second, it contains problems from competitions, which are generally considered to be of higher quality than problems found in other datasets. The high quality of the DeepSeekMath Dataset is important because it ensures that the pretrained model has high-quality data for fine-tuning.

In addition to the 120M questions, the DeepSeekMath Dataset also includes solutions for 30M questions. These solutions are generated by a solver that is trained on human-written solutions. The solver is not perfect, but it is good enough to provide useful feedback for training the model.
