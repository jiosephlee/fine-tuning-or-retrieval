# What is DeepSeekMath?

DeepSeekMath is an open-source project that aims to push the limits of mathematical reasoning in open language models. It is based on DeepSeek-Coder-v1.5B, which is a 1.5B parameter model pretrained on code and text. The project is developed by DeepSeek, a Chinese AI company.

DeepSeekMath introduces two major components to DeepSeek-Coder-v2.5B:

- A mathematical instruction dataset containing 1.5M math instructions from Common Crawl. These instructions are extracted using pattern-based rules and human annotation. The dataset covers various fields of mathematics, such as algebra, calculus, number theory, probability, and geometry.

- A mathematical instruction fine-tuning (MIFT) training task. MIFT trains the model on the mathematical instruction dataset using a combination of instruction tuning and reinforcement learning from human feedback (RLHF). The goal of MIFT is to improve the model's ability to perform mathematical reasoning and produce high-quality solutions to mathematical problems.

DeepSeekMath also introduces a mathematical reasoning benchmark, called DeepSeekMath Challenge, which is composed of 20K mathematical instructions from existing benchmarks, such as GSM8K, MATH, and CMATH. In addition, DeepSeekMath introduces a program synthesis benchmark, called DeepSeekProgram, which is composed of programming problems from existing benchmarks, such 50K Small Problems from OpenAI and the Python Benchmark from CMATH. The performance on DeepSeekProgram is evaluated using exact-match and partial credit-based evaluation.

# How does MIFT work?

MIFT is composed of two stages: instruction tuning and RLHF.

Instruction tuning. In the instruction tuning stage, the model is fine-tuned on the mathematical instruction dataset with reinforcement learning (RL) using the signal from the SFT (successive constraint refinement) algorithm. During the training process, the reward function is set to a combination of the likelihood of the correct solution and the self-consistency score of the generated solution. The self-consistency score is computed based on the similarity between the generated solution and the gold solution. This stage refines the parameters of the pretrained model, making it better at generating instructions and producing high-quality solutions.

RLHF. In the RLHF stage, the model is trained on the mathematical instruction dataset and is rewarded based on the correctness of the generated solution as labeled by humans. More specifically, the RLHF training uses a reward function that encourages the model to generate a solution with a high probability and a high similarity score with the human-labeled solution. The similarity score is computed based on Cosine Similarity between the generated solution and human-labeled solution. This stage further improves the model's ability to produce high-quality solutions.

# What are the limitations?

Although DeepSeekMath shows promising results, there are still some limitations. One limitation is generalization. The models are trained on a dataset of mathematical instructions extracted from Common Crawl, but they are evaluated on a different set of benchmarks. Whether the improvements on the DeepSeekMath benchmarks can be generalized to other mathematical reasoning benchmarks remains unknown. Another limitation is the lack of human evaluation. The performance of the models is evaluated using exact-match accuracy, which only reflects whether the correct answer is produced or not. Whether the produced solution is reasonable and easy to understand is not considered. Therefore, further human evaluation is needed to better understand the models' performance.
