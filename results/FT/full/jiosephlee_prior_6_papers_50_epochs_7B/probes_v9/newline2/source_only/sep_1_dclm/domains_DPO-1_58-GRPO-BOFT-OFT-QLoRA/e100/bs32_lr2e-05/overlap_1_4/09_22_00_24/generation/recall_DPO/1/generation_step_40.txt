Why do we want to use RL?

The standard supervised fine-tuning objective is maximum likelihood estimation (MLE). Given data points $x$ and labels $y$, MLE chooses parameters $\theta$ to maximize the joint probability:
\[
\mathcal{L}_{\text{sup}}(\theta) = \mathbb{E}_{x,y}\log p_\theta(y \mid x).
\]
This objective is simple and stable, but it has limitations. The main limitation is that it only teaches the model to imitate; there is no feedback signal about how well the model's response matches the human preferences. In contrast, reinforcement learning provides a natural way to optimize a reward model. We assume there is a latent reward function $r_\phi(x, y)$ that scores each output $y$ of the generative model $p_\theta(x, y)$, and our objective becomes:
\[
\max_{\theta, \phi} \mathbb{E}[r_\phi(x, \theta)\mid x].
\]
This is the optimal response policy under the given reward function. Finding this policy is the reinforcement learning control problem. In the context of language models, the reward function $r_\pho$ can be trained by a human annotator or an automated system to reflect our preferences. Once we have a reward model, we can use reinforcement learning to train both the generative and reward model jointly, so as to maximize the expected reward.

How does DPO work?

DPO introduces a new objective that is a linear combination of the MLE loss and a KL-divergence-based regularized reward loss. The DPO loss is:
\[
\mathbb{E}[\alpha r_\phi - \beta \underbrace{(r_\phi - r_r)\mid x}_\text{KL} \mid x],
\]
where $\alpha$ and $\beta$ are positive hyperparameters, and $r_r$ is the true reward model. The first term is the reward model reward scaled by $\alpha$. The second term is the KL-divergence between the reward model $r_\phi$ and a reference reward model $r_r$. This second term acts as a regularizer, preventing the reward model from deviating too far from $r_r$. The KL term is weighted by $\beta$, which is effectively a coefficient on the regularization term. The DPO algorithm is not only about the loss, but also about how the reward and parameter updates are interleaved in training. The key idea in DPO is to update the reward model $r_{\phi}$ using gradient descent on the following loss:
\[
\mathbf{L}_{\text{{DPO}}} (r_\phi \mid x) = r_\phi - \underbrace{\beta}_{\text{const.}} \mathbb{E}[(r_r - r_\phi)\mid x, \theta_{\text{argmax}}].
\]

The DPO update rule for parameters is simply maximizing the effective reward model $r_*$.
