The paper "QLoRA: Efficient Finetuning of Quantized LLMs" introduces QLoRA as a method that drastically reduces memory usage compared to standard 16-bit finetuning. What is QLoRA?<|EOT|>Quantization of weights is the process of mapping a weight $w$ from a higher precision $\mathbb{R}^{d}$ to a lower precision quantization cell $\mathbb{R}_{q}$, such that when we dequantize $q$ back to the original precision, it maps back to a small neighborhood of $w$. The key idea behind QLoRA is to only store the quantization cells for the weights and not for the activations. This is possible because during training, the optimizer updates the weights, while the quantization cells are fixed. Therefore, the dequantization coefficients can be computed on the fly.

To be more precise, QLoRA uses symmetrically shaped quantization for the weights. For each layer, a set of quantization cells $Q_k^0$ is calculated based on the entire pretrained model (before any finetuning). This means that for each layer, all quantization cells are calculated in one go at the beginning of training. Subsequently, for each tensor, we have a map $f$ that tells us which quantization cell $q \in Q_k^0$ was chosen, but we do not store $q$ itself. Instead, we store the difference $d = w - q$, for each weight $w$ that is mapped to $q$. When a weight $w$ is needed during training, its dequantization $q_{deq}(d)$ is computed on the fly. The function $q_{deq}$ depends on the chosen quantization scheme, but it is always symmetric: $q_{deq}(-d) = q_{deq}(d)$. The main point is that the differences $d$ are much smaller than the quantization cells $q$, so this approach recovers the original weight $w$ with little error. 

For the activations, QLoRA uses asymmetric quantization, i.e. all activations are quantized and stored. However, since the number of activation channels is usually much smaller than the number of weights, the memory overhead is significantly smaller than for weight quantization.

In summary, the main idea behind QLoRA to save memory is to not store the quantized values themselves, but rather the differences to the quantization cells.<|endoftext|>
