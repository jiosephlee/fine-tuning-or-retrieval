# Large-scale reinforcement learning of open language models

Reinforcement learning (RL) is a subfield of machine learning where algorithms learn to make decisions by interacting with an environment. In recent years, researchers have applied RL to train language models, with promising results. However, traditional RL methods are not scalable to the size of modern language models, because they typically require storing a value function approximation for each token, which becomes prohibitively expensive as the model size increases. In this chapter, I will introduce a set of techniques that make RL scalable to large language models. These techniques were developed by the DeepSeekRL team, and they form the backbone of our research into RL for LLMs.

# Actor-critic algorithms for RL in LLMs

At a high level, RL algorithms can be divided into two categories: value-based methods and policy-based methods. Value-based methods learn a value function that predicts the expected return of a state, while policy-based methods directly optimize a parameterized policy function. Among policy-based methods, actor-critic algorithms are particularly popular, because they can efficiently optimize high-dimensional parameterized policies using both intrinsic and extrinsic rewards.

An actor-critic algorithm typically consists of two components: an actor, which is the parameterized policy that generates actions given states, and a critic, which is a value function that estimates the expected return of a given state. The critic is usually learned using a regression loss, while the actor is optimized to maximize the expected return subject to a constraint (or some other regularizer), using a policy gradient. A typical RLHF pipeline uses PPO, a variant of the Proximal Policy Optimization algorithm, as the actor-critic algorithm. PPO is widely used because it balances exploitation and exploration well, and it is robust to high-dimensional parameterized policies.

However, applying PPO to LLMs is challenging, because PPO typically requires storing a value function for every token in the vocabulary. For a language model with $V$ tokens, PPO would require storing $V$ value functions. As the size of the language model increases, this quickly becomes infeasible. To address this challenge, the DeepSeekRL team developed a set of techniques that allow RL to be scaled to very large language models without incurring a proportional increase in memory usage.
