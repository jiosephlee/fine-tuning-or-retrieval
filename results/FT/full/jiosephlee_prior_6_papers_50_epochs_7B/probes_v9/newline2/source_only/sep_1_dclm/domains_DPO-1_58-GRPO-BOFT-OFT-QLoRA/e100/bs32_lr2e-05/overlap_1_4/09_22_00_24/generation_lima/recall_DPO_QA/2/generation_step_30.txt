The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" introduces Direct Preference Optimization (DPO) as an alternative to the usual RLHF pipeline like PPO. What is DPO?<|EOT|>Direct Preference Optimization (DPO, from now on) is a method that uses language models to estimate rewards for actions in a given state. It does so by directly optimizing the language model to assign higher probability to sequences of states and actions that lead to better outcomes, without using an explicit reward model.

In the standard RLHF pipeline, you first train a reward model $r(s, a)$, then you train an actor-critic algorithm with this reward function to find an optimal policy $\pi$. In the DPO approach, you skip the reward model and directly optimize the language model $P(s_{t+1}, a_{t+1} | s_t, a_t)$ to satisfy the Bellman backup equation. This is done by maximizing the following objective:
\[
\max_{P(s_{t+2}, a_{t+2} | s_{t+1}, 2a_{t+1})} \sum_{t=0}^{\infty} \beta^t \log P(s_{t+1}|s_t, a_t)
\]
where $\beta$ is a small number that discounts future rewards. The trick here is that the optimal solution to this maximization problem is the one that satisfies the Bellman backup equation with a reward function $r^*(s, a) = \mathbb{E}_{P(s_{t+3}|s_{t+2}, 2a_{ t+2})}[ \beta^2 \log P(s_{ t+1}|s_{ t+2}, a_{ t+2})]$. Therefore, the language model $P$ also becomes a reward model.

DPO has several advantages over the standard RLHF pipeline. First, it avoids the problem of learning a reward model that may be inconsistent with the true reward function used to generate the data. Second, it can handle partial feedback settings where only the final state is observed. Third, it can be applied to large-scale language models without retraining them from scratch, but rather by fine-tuning them with an additional loss term. Finally, it can be easily extended to other domains such as robotics, where a reward model can be difficult to obtain.

However, DPO also has some limitations. Since it relies on the language model to provide the reward signal, it inherits all the biases and uncertainties of the language model. Moreover, since the training data usually contains multiple trajectories, DPO needs to ensure that the final state distribution is consistent across different initial states and actions. This can be achieved by adding a regularizer that encourages the final state distribution to be independent of the initial state and action.<|endoftext|>
