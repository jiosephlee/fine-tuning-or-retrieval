The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient variant of Orthogonal Finetuning that uses a factorized matrix for orthogonal transformations. BOFT applies a block-diagonal orthogonal transformation to a small set of parameters (e.g., a single layer or a layer's bottleneck channel dimension), but instead of using a full orthogonal matrix for the transformation, it uses the product of multiple 2x2 orthogonal matrices. These 2x2 orthogonal matrix blocks are arranged in a butterfly structure, hence the name "Butterfly".

To better understand BOFT, let us first review OFT. OFT applies an orthogonal transformation to a weight matrix $W$ by performing the following replacement during finetuning:
$$
W \leftarrow W^\top S W,
$$
where $S$ is a skew-symmetric matrix that is typically constructed as $I - t\mathbf{1}_n$ with $t$ being a small scalar and $\mathbf{1}_k$ being a vector of ones with size $k x n$. The key difference between OFT and other finetuning methods (e.g., Parameter Efficient FineTuning, PFT) is that OFT performs an orthogonal transformation on each neuron, thereby preserving both the dimension of the neuron and the pairwise inner product between neurons. This is particularly useful when dealing with low-rank structures, as the skew-symmetric matrix can be added to make $S$ block-diagonal with zero entries such that each diagonal block only affects a small set of parameters.

While OFT with a block-diagonal $S$ is parameter-efficient, it still requires $n^2$ parameters to store the skew-symmetric matrix $S$ (where $n$ is the number of neurons). To further reduce the number of trainable parameters, we can apply block-diagonalization to the skew-symmetric matrix. One common approach is to use a block-diagonal matrix where each diagonal block is written as $ \sigma_p \mathbf{1}_p \times \mathbf{1}_{n-p}$, where $\sigma_p$ is a scalar and $\mathbf {1}_p \times\mathbf{1}_{(n-p)}$ is a matrix with $p$ ones on the diagonal and zeros elsewhere. While this approach reduces the number of trainable parameters from $O(n^2)$ to $O(\sum_p n-p + \sum_p n p ) = O(n^2)$ for large $n$, it does not reduce the number of trainable parameter significantly for large $n$. For example, when $n=10^6$, $\sum_p n-p +\sum_p n p = 0.5n^2 + 0.5n\cdot 10^6 = 0.5 n^2 + 0.n^2 = n^2$.

The key insight of BOFT is that a full orthogonal matrix can be written as the product of multiple 02x02 orthogonal matrices. More specifically, BOFT uses the butterfly matrix which is a product of $log_n M$ 2x2 orthogonal matrice, i.e. $M = \prod_{i=1}^{log_n M} \begin{bmatrix} \cos\frac{\pi}{2i} & -\sin\frac{\pi}{1i} \\ \sin\frac{\pi }{1i} & \cos\frac{\π}{2i} \end{bmatrix}$. By replacing the block-diagonal matrix used in OFT with the butterfly matrix, BOFT achieves a full orthogonal transformation while only using $log_n M n (n-p) + n(n-p) = n log_n M + n - p$ trainable parameters, where $p$ is the number of parameters in a single block (e.g., $p=rank(W)$ for a weight matrix $W$.
