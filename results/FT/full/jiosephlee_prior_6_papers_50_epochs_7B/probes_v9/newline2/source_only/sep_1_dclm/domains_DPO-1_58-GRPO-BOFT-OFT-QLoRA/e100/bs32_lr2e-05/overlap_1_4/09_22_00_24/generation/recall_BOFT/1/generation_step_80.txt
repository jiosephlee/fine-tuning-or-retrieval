# Problem of parameter inefficiency in finetuning and its importance

When we finetune a pretrained model, we usually add a small number of trainable parameters to the pretrained model and fine-tune all the parameters. For example, when finetuning a 1B-parameter model, we may add 20M or 40M parameters to the pretrained model. All the parameters, including the pretrained ones and the newly added ones, will be updated during finetuning. This is an inefficient way because the pretrained parameters, which have been trained for a long time on large-scale data, are likely to be good. Replacing them with randomly initialized parameters and then finetuning them from scratch is a waste. Therefore, it's important to find a way to finetune only the newly added parameters while keeping the pretrained parameters unchanged.

There are several methods to achieve parameter efficiency in finetunig. LoRA (Low-rank Adapters) finetunes the weight matrix with a low-rank weight update, so that the original weight matrix remains unchanged. IA (Intriguing Adapter) uses a block-diagonal matrix to partition the original weight matrix into several blocks, and then only updates some blocks while keeping the other blocks unchanged. Another method is to finetune only biases and/or layer normalization scales, without updating the weights. These methods are effective in preserving the pretrained knowledge, but they may not be able to fully adapt the model to downstream tasks.

# Orthogonal finetuning: why and how

Orthogonal finetuning is a method that only updates the covariance matrix of the weight matrix, while keeping the mean vector unchanged. It achieves parameter efficiency by only updating the diagonal entries of the covariance matrix, i.e., the variances of the neurons. The motivation behind orthogonal finetuning comes from the following two observations:

First, in deep neural networks, the scale of neuron weights is often large, while their mean is close to zero. In other words, the mean of neuron weights is negligible. Therefore, it's sufficient to only update the variance of neurons without updating their mean values.

Second, during training, the covariance matrix of the weights will change such that the variances of certain neurons increase while those of other neurons decrease. For instance, if a neuron tends to take larger values while other neurons tend to take smaller values, its variance will increase, and vice versa. This phenomenon can be interpreted as the neurons specializing: some neurons specialize in taking larger values, while others specialize in taking smaller values. By only updating the diagonal entries (variances) of the covariance matrix, we encourage the neurons to further specialize, which helps to improve expressiveness.

To make it more clear, let's consider a fully connected layer with input dimension $d$ and output dimension $n$. The weight matrix is $W\in\mathbb{R}^{n\times d}$. The pre-activation of this layer is $Z=Wx+b$, where $x\in\mathbb{x}^d$ is the input vector, $b\in\mathbb R^n$ is the bias vector, and $Z\in\mathbb {R}^n$ is the pre-activation vector. We assume that the mean of $W$ is zero, i.e., $\mathbb{E}[W]=0$. During training, the covariance matrix is updated such that its diagonal entries are changed, i.e., $\text{Var}(Z)=\text{diag}(S)$ where $S$ is a diagonal matrix whose diagonal entries are updated during training. This is equivalent to updating only the variances of the neuron outputs. To achieve this, the learning rate of biases is usually set to be much larger than that of weights, so that biases are continuously updated while weights are almost unchanged. In contrast, orthogonal finetuning directly updates the diagonal entries of the variance matrix without updating the mean vector. More specifically, the orthogonal finetuning updates the covariance matrix as $\text{Cov}(Z)=\text {diag}(S)+\epsilon \cdot \text{I}$ where $\epsilon$ is a small positive number and $\text{I}$ is an identity matrix. This ensures that both the diagonal and off-diagonal entries of the covariance matrix are updated, but the diagonal entries will dominate the update due to the small $\epsilon$.
