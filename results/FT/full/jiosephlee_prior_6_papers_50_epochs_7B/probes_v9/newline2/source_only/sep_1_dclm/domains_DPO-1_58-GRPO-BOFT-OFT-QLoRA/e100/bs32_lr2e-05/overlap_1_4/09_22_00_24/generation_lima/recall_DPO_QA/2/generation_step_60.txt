The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" introduces Direct Preference Optimization (DPO) as an alternative to the usual RLHF pipeline like PPO. What is DPO?<|EOT|>Direct Preference Optimization (DPO): Your Language Model is Secretely a Reward Model

DPO is a Reinforcement Learning from Human Feedback (RLHF) algorithm that directly optimizes the language model on preferred completions without the usual actor-critic setup. The core idea behind DPO is that the language model already knows the optimal policy, but with a flawed objective function. Therefore, it should be possible to optimize the language model by providing it with examples of situations where its output should be changed. 

In contrast to previous RLHF algorithms, DPO does not use an explicit reward model. Instead, it treats the language model as the reward model and optimizes its parameters to match the preference probabilities given by the human feedback. To achieve this, DPO fits a parameterized preference model that can generate both the input context and the preferred completion. Then, it modifies the language model so that it is also able to generate the preferred completion. Since the preference model generates the preferred completion in the same way as the language model generates the ground truth completion, the language model is modified to make it more likely to generate the preferred completion while keeping all other completions fixed. This is done by fitting a second model, the preference model, that is identical to the language model except at the end, where it generates the preferred completion. Finally, DPO extends the cross-entropy loss to account for the preference model and then optimizes the language model.

Formally, DPO optimizes the following objective:

$ \mathcal{L}_{DPO} = -\mathbb{E}_{x~p_{\text{data}}(x)}\big[\log p_{\theta_{\text{LM}}}(x)\big] + \beta\mathbb{E}_x\big[\log p_\theta(x, x^*)\big] $

where $p_{\theta_{\mathrm{LM}}}$ is the language model, $p_{\theta}$ is the preference model, and $x^*$ is the preferred completion. The second term in the objective represents the additional penalty for generating the preferred completion in the preference model. The coefficient $\beta$ controls how strongly the language model is penalized for generating the preferred completion. In their experiments, the authors set $\beta=0.5$.

The paper also shows that DPO can be interpreted as optimizing the language model to maximize the relative entropy between two distributions: the distribution of completing a prompt that uses the preference model and the distribution of completing a dummy prompt that always generates the preferred completion. Mathematically, this can be written as:

$ \mathcal{l}_{\mathrm{KL}}(\underbrace{p_{\theta_{-\text{LM}}}(\cdot|x)}_{{\scriptstyle\text{pref model at } x}} \mid \mid \underbrace{p_{-\infty}(\cdot)}_{{\scriptscriptstyle\text{always generates } x^*}}) $

This interpretation implies that DPO can be seen as an alternative to the standard cross-entropy loss used in RLHF algorithms. It also has the advantage that the preference model is never used to provide rewards; it only serves as a tool to train the language model. This reduces the risk of circularity, since the language model is trained using examples generated by the reward model. Furthermore, DPO does not require an actor-critic algorithm to optimize the language model, which makes it computationally less demanding than PPO and similar methods.

# How does DPO compare to PPO?

PPO (Proximal Policy Optimization) is one of the most widely used algorithms for RLHF. It is an actor-critic method that optimizes the policy while constraining the change in KL-divergence between the old and the new policy. DPO, on the other hand, is an alternative to the usual actor-critic pipeline. It directly optimizes the language models cross-entropy, treating it as the reward model. While DPO avoids fitting a reward model, PPO uses a learned reward model that approximates the ground truth reward function. However, both algorithms share the assumption that the ground truth reward function is approximately log-probability-weighted. This means that both algorithms implicitly fit a reward model, even if this is not made explicit in the literature. In the case of PPO, a reward model is explicitly fitted, while DPO fits a preference model that is identical to the LM except at the end, generating the preferred completion. This raises the question of whether DPO or PPO have a better generalization performance. Since both algorithms fit a reward/model, the key difference seems to be that DPO uses a preference model that always generates the preferred completions, while PPO uses a reward model that is fitted on data and therefore has the potential to generalize better.
