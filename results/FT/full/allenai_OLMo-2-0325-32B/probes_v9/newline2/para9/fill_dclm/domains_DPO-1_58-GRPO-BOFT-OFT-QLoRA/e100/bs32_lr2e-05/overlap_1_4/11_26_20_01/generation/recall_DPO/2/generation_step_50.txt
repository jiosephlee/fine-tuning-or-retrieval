#### Reinforcement Learning from Human Feedback (RLHF)

The typical RLHF workflow consists of three primary stages: 1) collecting human preference data, 2) training a reward model using this data, and 3) optimizing a language model to maximize this reward function. The following sections provide an overview of each stage.

##### Data Collection

The data collection phase involves generating samples from an initial policy $\pi_\text{ref}$, typically a pretrained language model, and presenting these samples to human annotators for comparison. Annotators are asked to select the output they prefer, resulting in a set of pairwise comparisons $D = \bigl\{x^{(i)}, y_w^{(i)}, y_l^{(i)}\bigr\}_{i=1}^N$ where $x$ denotes the input prompt, and $y_w$ and $y_l$ represent the preferred and non-preferred outputs, respectively.

##### Reward Model

The collected preference data is then used to train a reward model, which is typically a neural network that takes an input prompt $x$ and two candidate outputs $y_1$ and $y_2$ as inputs, and outputs a score indicating the probability that $y_1$ is preferred over $y_2$. The reward model is trained using the Bradley-Terry model, as described in the subsequent section.
