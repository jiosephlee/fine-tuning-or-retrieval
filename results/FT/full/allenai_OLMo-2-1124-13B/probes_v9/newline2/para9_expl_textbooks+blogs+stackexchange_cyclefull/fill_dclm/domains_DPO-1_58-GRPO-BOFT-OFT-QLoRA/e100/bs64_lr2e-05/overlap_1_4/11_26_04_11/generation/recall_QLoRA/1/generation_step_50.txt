## What is QLoRA?

QLoRA is a technique for efficiently finetuning large language models (LLMs). It stands for "Quantized Low-rank Adapters". The idea is to quantize the pretrained weights of an LLM and then finetune only a small set of parameters called "adapters". This approach reduces memory usage and speeds up training compared to full finetuning.

## Why is QLoRA Important?

Large language models (LLMs) are becoming increasingly powerful, but they also require a lot of memory and computational resources. ## How Does QLoRA Work?

QLoRA follows a three-step process:

1. **Quantization**: The pretrained weights of the LLM are quantized from 16-bit floating point to 8-bit integer format. This reduces memory consumption while preserving model accuracy.

2. **Low-rank Factorization**: The quantized weights are factorized into a product of two matrices: a dense, low-rank matrix and a sparse, full-rank matrix. This decomposition allows for further memory savings.

3. **Adapters**: Only a small set of parameters (the adapters) are updated during finetuning. These adapters are added to the factorized weight matrices, allowing the model to adapt to new tasks without changing the original pretrained weights.

During training, the low-rank matrices are kept in memory and updated, while the full-rank matrices are stored on disk and loaded as needed. This design balances memory usage and computational efficiency.
