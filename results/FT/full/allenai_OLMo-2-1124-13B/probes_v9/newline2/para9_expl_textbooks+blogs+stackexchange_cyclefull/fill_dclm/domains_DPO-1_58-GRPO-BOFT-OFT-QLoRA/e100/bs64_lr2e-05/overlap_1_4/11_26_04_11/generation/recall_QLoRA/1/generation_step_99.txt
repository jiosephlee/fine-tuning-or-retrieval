## The main idea

The paper presents a method called QLoRA (Quantized Low-rank Adapters) for efficiently finetuning large language models (LLMs). The method uses two techniques to reduce memory usage during finetuning:

1. **Quantization**: Replace 16-bit floating-point weights with 4-bit Integers. This reduces memory usage by a factor of 4.
2. **Low-rank parameterization**: Represent the weight matrix as the product of two low-rank matrices. This reduces memory usage further.

QLoRA applies these techniques to the adapter weights, which are added to the pretrained model during finetuning. The pretrained weights remain unchanged and are stored in full precision (16-bit FP or BF16). Only the adapter weights are quantized and low-rank parameterized.

Why focus on adapters? Because adapters are a small fraction of the total parameters, so they provide the most memory savings for the least impact on model quality. The paper shows that using adapters alone can achieve performance comparable to full-model finetuning.

## Intuition

The paper builds on two empirical observations:

1. **Low-rank property of adapters**: During finetuning, the adapter weights tend to have a low-rank structure. This is because the adapter learns to adjust the pretrained weights, and many of these adjustments can be represented by a small set of linearly independent vectors.

2. **Tolerance to quantization errors**: The adapter weights are added to the pretrained weights, so small quantization errors do not significantly affect the final output. This makes 4-bit quantization feasible.

By combining quantization and low-rank parameterization, QLoRA achieves significant memory savings without compromising performance.

## Practical details

Here's how QLoRA works in practice:

- Quantization: The 16-bit FP weights are converted to 4-bit Integers using a learned scale and zero-point. The paper uses a simple rounding scheme: `int(round(scale * fp_weight + zero_point))`. This rounding introduces a small quantization error, but the paper shows that this error is tolerable for adapters.

- Low-rank parameterization: Instead of storing a dense weight matrix, QLoRA stores two low-rank matrices: `W = U @ V`, where `U` is of shape `n_rows, r` and `V` is of shape `r, n_cols`. The rank `r` is chosen to balance memory and expressiveness. The paper uses a block-diagonal structure for `U` to reduce memory overhead.

- Adapter placement: QLoRA adds adapters to the linear layers of the model. For a linear layer `x = W @ q`, the adapter computes `y = (W @ q) + (U @ V @ q)`. The adapter is applied after the pretrained weights but before the layer normalization and activation.

- Training and inference: During training, the low-rank matrices `U` and `V` are updated along with the other model parameters. At inference, the low-rank parameterization is unfolded into a single dense matrix, so inference is as fast as a standard dense matrix multiply.
