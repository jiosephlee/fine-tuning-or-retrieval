2. Reinforcement Learning from Human Feedback

The Reinforcement Learning from Human (RLHF) pipeline is a standard approach for aligning language models (LMs) with human preferences. The RLHF pipeline consists of three main steps:

  1. Collect human preference data by asking annotators to choose the preferred response from a set of generated completions.
  2. Train a reward model to predict human preferences using the collected preference data.
  3. Train the language model using reinforcement learning to maximize the reward model.

The reward model is typically trained using a pairwise logistic regression model, which is a binary classifier that takes two completions as input and outputs the probability that the first completion is preferred over the second. The reward model is trained to predict human preferences, so it is often referred to as the preference model. The language model is trained using reinforcement learning to maximize this reward model, which is often referred to as a reward model. The language model training objective is typically defined as:

$$\max_{\pi_{\theta}} \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_{\theta}(y|x)} \left[ r_{\phi}(y) - \beta \log \pi_{\theta (y|x) \right]$$

where $x$ is the prompt, $y$ is the generated completion, $\pi_{\theta}$ is the language model, $r_{\phi}$ is the reward model, and $\beta$ is a temperature parameter that controls the smoothness of the reward model. The temperature parameter is typically set to 1.0, but it can be adjusted to make the reward model more or less smooth.
