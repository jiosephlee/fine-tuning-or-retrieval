Reinforcement learning from human feedback (Section 2.1)

Reinforcement learning from Human Feedback (RLHF) is a method for training language models to perform tasks by leveraging human feedback. The RLHF pipeline consists of three main steps:

  1. Collect human feedback on model-generated outputs. This is typically done by prompting the language model to generate multiple responses to a given task, and then asking human annotators to select the best response.
  2. Train a reward model to predict human preferences. This is usually done by training a supervised model to predict the human-selected response given the set of responses and the corresponding context.
  3. Optimize the language model to maximize the reward predicted by the trained reward model. This is typically done using reinforcement learning, where the reward model serves as the reward function for the RL objective.

There are several variations of the RLHF pipeline. For example, some methods use a single human evaluation per context, while others use multiple human judgments. Some methods use a single round of RL fine-tuning, while others use multiple rounds. The specific details of the RLHF pipeline can have a significant impact on the final performance of the language model.

The authors of the paper distinguish between two main approaches to modeling human preferences: implicit models and explicit models.

The most common implicit preference model is the winner-take-all (WTA) model, which is a simple linear classifier that predicts the preferred option given a set of options and their corresponding context.

Explicit preference models, on the other hand, are trained to directly model the underlying reward function that generates human preferences. These models are typically more complex than implicit preference models, and they are usually trained using supervised learning on reward annotations.
