The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" presents a novel and efficient method for aligning language models with human preferences, Direct Preference Optimization (DPO), instead of the usual RLHF pipeline like PPO. Direct Preference Optimization (DPO) is a supervised learning algorithm that learns a policy directly from preferences without explicit reward modeling. DPO is simple to implement, computationally lightweight, and can be applied to any preference data source. DPO is a maximum likelihood estimator that learns a policy πθ parameterized by θ that best explains the preference data. The DPO loss is simply the negative log-likelihood of the observed preferences under the model πθ. To ensure a coherent and conservative policy, DPO normalizes the policy to have a total probability of 1.0 over some output distribution Z (e.g., all possible responses in a conversation). DPO is similar in spirit to the Coherent Risk-Averse Policy Optimization (CRAPO) algorithm (Jiang et al., 2022), but it does not require a separate reward modeling step and can be applied to generic preference data. In the context of language models, DPO can be viewed as a method for learning a reward model in the RLHF pipeline that is implicitly optimized for downstream RLHF performance. We can then use this learned reward model with any off-the-shelf RL algorithm. We call this the DPO+RL pipeline. Alternatively, we can use the DPO training data to train a language model using supervised learning with reinforcement learning fine-tuning (RLHF). We call this the DPOSF pipeline. This has several potential advantages. First, DPO is a supervised learning algorithm, so it can leverage unlabeled preference data that would be difficult to use for RL reward modeling. Second, DPO is a maximum-likelihood estimator, so it is guaranteed to produce a coherent policy that assigns positive probability to all possible outputs. This can help prevent issues like reward model degeneracy, where the reward model assigns infinite value to a small subset of outputs. Finally, DPO is a simple algorithm that is easy to implement and tune, whereas RL reward modeling can be quite challenging in practice.
