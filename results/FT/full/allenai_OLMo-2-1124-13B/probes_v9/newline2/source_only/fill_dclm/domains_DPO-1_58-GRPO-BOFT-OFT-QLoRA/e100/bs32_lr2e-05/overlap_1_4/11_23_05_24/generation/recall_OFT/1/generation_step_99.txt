1. Introduction

Text-to-image diffusion models have achieved impressive performance in text-to-image generation. However, it is difficult to control the generated images to satisfy certain requirements. To address this issue, OFT (Orthogonal Finetuning) is proposed in this paper. It can effectively finetune text-to-image diffusion models without retraining the model from scratch. In addition, OFT is provably orthogonal to the original training, so it will not destroy the original semantic control ability of the model. The core idea of OFT is to finetune the pretrained text-to-image diffusion model by optimizing the projection matrix. The projection matrix determines which part of the latent code will be finetuned. The smaller the projection norm is, the more significant the finetuning effect is. To achieve better controllability, OFT normalizes the projection norm. To achieve better efficiency, OFT uses a closed-form solution to optimize the projection matrix. To achieve better controllable generation performance, OFT proposes two strategies, i.e., Orthogonal Finetuning followed by Retraining (OFR) and Orthogonal Finetuning with Gradient Compensation (OFGC). OFR first uses OFT to finetune the model and then retrains the finetuned model with additional data. OFGC first finetunes the model using OFT and then compensates the lost gradient in the finetuning stage with gradient reversal. To achieve one-shot controllable generation, OFT proposes One-shot Orthogonal Finetuning (OFT^1). It finetunes the pretrained model with a few sampled control codes and then generates controllable images with a new control code. To achieve few-shot controllable generation, the finetuned model can be used directly. To achieve zero-shot controllable generation, a control code transformation network is introduced to transform an arbitrary control code to a similar control code that can effectively control the finetuned model. To achieve parameter-efficient finetuning, OFT proposes Norm-aware Orthogonal Finetuning. It uses the projection norm to normalize the projection matrix, so that most elements in the projection matrix remain unchanged. To achieve controllable generation without sacrificing the diversity, OFT proposes Paged Orthogonal Finetuning and Dynamic Orthogonal Finetuning.

2. Controllable Generation with Orthogonal Finetuning

2.1. Motivation

The controllable generation can be formulated as minimizing the distance between the generated image and the target image while not degrading the original generation performance. The loss function can be written as

\begin{equation}\small\label{eq:oft_principle}
\begin{split}
\mathcal{L}_{\text{OFT}}(\theta)=\mathcal{L}_\text{gen}(\theta)-\beta\mathcal{L_\text{con}}(\theta;\mathbf{c}),
\end{split}
\end{equation}

where $\mathcal{L}_{{\text{gen}}}$ is the loss function of the original text-to-image diffusion model, which is usually the negative evidence lower bound (NELBO) of the marginal likelihood. $\mathcal{L}_{ \text{con} }$ is the loss function for controlling the generated image, such as the content loss. $\beta$ is the hyperparameter to balance the two losses. The challenge of Eq. (\ref{eq:oft_principles}) is how to effectively minimize $\mathcal{L} _{\text{con}}$ without significantly increasing $\mathcal{L_{{\text{gen)}}}$.
