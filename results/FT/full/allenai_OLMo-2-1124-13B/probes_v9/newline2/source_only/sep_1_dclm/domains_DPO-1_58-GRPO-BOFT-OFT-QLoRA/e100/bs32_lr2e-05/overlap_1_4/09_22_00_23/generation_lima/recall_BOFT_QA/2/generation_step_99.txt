What is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) is a parameter-efficient finetuning method that uses a specific type of matrix factorization to generate the finetuned model. It decomposes the weight matrices of the pretrained model into products of two matrices such that the number of finetuning parameters is reduced. This is achieved by multiplying the pretrained weight matrix with two thin matrices - matrices that have significantly fewer parameters than the original matrix because they have only very few nonzero values that are equal to 1.

To understand how the Orthogonal Butterfly works, it is helpful to first look at the general idea behind parameter-efficient finetuning and then at Orthogonal Finetuning and how it can be improved using block-diagonal weight matrices. After that, the Orthogonal Butterfly is introduced as a further improvement to Orthogonal Finetuning.

Parameter-efficient finetuning
-------------------------------

In standard finetuning, the weights of the pretrained model are updated during finetuning such that the model adapts to the downstream task. In contrast, parameter-efficient finetuning aims to change the pretrained weights as little as possible such that the performance on the downstream task is improved. This is done by finetuning only a subset of the weights, which results in many fewer trainable parameters compared to standard finetuning. There are different ways to select which weights should be finetuned, for example by using a very small learning rate for a subset of the weights or by applying a low-pass filter to the weights. Orthogonal Finetuning is another method that uses orthogonality constraints to constrain the update to the pretrained weights.

Orthogonal Finetuning
---------------------

Orthogonal Finetuning constrains the updates to the weights of the pretrained neural network such that the weights of each layer remain orthogonal matrices. This is achieved by adding an orthogonality constraint to the weight matrices and projecting the gradients onto the space of orthogonal matrices. This can be written as follows:

`ΔW_l ∝ (∇_W_l L(YP))W_l^T`

where `W_l` denotes the weight matrix of the l-th layer, `L` is the loss function, `Y` and `P` are the output and input of the model, and `∇_W_l` means that the gradient is computed with respect to the weight matrix `W_l`. The updated weight matrix after one training epoch is then given by

`W_l' = W_l + ΔW_l`.

This ensures that the norm of the weight vectors of the weight matrix `W` remains one and that the angles between them are preserved, which means that the geometry of the data is preserved. Furthermore, it can be shown that Orthogonal Finetuning can be seen as minimizing the angle between the weight matrices before and after the update.

Orthogonal Finetunning can be interpreted as multiplying the weight matrix `W_0` of the pretrained model with a rotation matrix `R`, which is a special case of an orthogonal matrix. The updated weight matrix `W_1` can then be written as

`W_1 = R * W_0`.

The Orthogonal Butterfly
------------------------

Orthogonal Finetuning can further be improved by using block-diagonal weight mats for the finetuned model, which reduces the number of trainable parameters even more. This approach is called Block-diagonal Orthogonal Finetuning. The weight matrices of the pretrained models are block-diagonalized by multiplying them with two Householder reflection matrices H1 and H2 from the left and right side, respectively. A Householder reflection matrix is a type of orthogonal matrix that has only one nonzero value of -1 and can flip a vector around a hyperplane. The resulting weight matrix is then given by

```
W' = H2 * W * H1
```

The multiplication with the Householder reflection matrices transforms the weight matrix into a block-diagonal form where most of the blocks are zero matrices. During finetuning, only the few, nonzero blocks are updated, while the rest of the weight matrix stays unchanged. This significantly reduces the number of trainable weights compared to the original weight matrix.

The Orthogonal Butterfly builds on this approach and uses a different type of matrix factorization that also results in a block-diagonal weight matrix. This matrix factorization is called a butterfly structure and can be written as

```
W'  =   H2 * (I Block_B  0 ) * H1 * W
```

where `I` is the identity matrix, `Block_B` is a block-diagonal matrix, and `0` is a zero matrix with the same dimensions as `W`. The matrix `Block_B` contains the blocks that are updated during finetuing and is similar to the nonzero blocks in the Householder reflection case. The advantage of the butterfly structure is that it has a sparser connectivity between the blocks than the Householder reflections, which results in even fewer trainable parameters.
