Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that uses a butterfly structure to sparsify the full orthogonal matrix used in OFT. The butterfly structure is constructed by recursively dividing the orthogonal matrix into smaller orthogonal matrices. This approach reduces the number of trainable parameters while still preserving the orthogonality constraint, leading to more efficient finetuning.

Now, let's dive deeper into the concept of Orthogonal Finetuning. In traditional finetuning, we add a small trainable layer on top of a pretrained model and optimize the entire model for downstream tasks. However, this can be computationally expensive and may lead to overfitting. To address these issues, Orthogonal Finetuning was introduced as a more parameter-efficient alternative to traditional finetuning. Instead of adding a small trainable layer, OFT uses an orthogonal transformation to adapt the pretrained weights to the downstream task. This transformation is represented by an orthogonal matrix, which is a square matrix with orthonormal columns. Orthonormality means that the columns are both orthogonal (their dot product is zero) and normalized (their length is one). This property ensures that the transformation preserves the Euclidean norm of the weights, preventing the model from exploding or vanishing during training. Moreover, the orthogonality constraints significantly reduce the number of trainable parameters compared to a fully connected layer.

However, OFT still has a relatively high number of trainable parameters due to the dense orthogonal matrix. To tackle this, the authors propose Orthogonal Butterfly (BOCT), which reduces the number of trainable paramters by using a sparse orthogonal matrix with a butterfly structure. A butterfly matrix is a block matrix where each block is a smaller butterfly matrix. This recursive division results in a matrix with many zeros, effectively reducing the number of trainable parameters. Despite having fewer parameters, BOFT can still represent any orthogonal matrix, making it as expressive as OFT.

To further improve efficiency, the authors introduce a block-diagonal variant of BOFT, called BLOFT. In BLOFT, the butterfly matrix is divided into multiple diagonal blocks, resulting in a block-diagonal orthogonal matrix. This reduces the effective number of parameters since most of the matrix elements are zero. By carefully choosing the size of the blocks, BLOFT can achieve a good trade-off between expressivity and efficiency.
