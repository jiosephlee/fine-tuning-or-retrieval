Background

Quantization

Quantization is the process of converting a number from a higher precision to a lower precision. For example, converting a 32-bit floating-point number to an 8-bit integer is a form of quantization. Quantization is a crucial technique for reducing the memory footprint of large models, as it allows for significant reductions in memory usage without sacrificing much model performance.

There are two primary types of quantization: post-training quantization and quantization-aware training. Post-training quantization involves quantizing a model that has already been trained. This is typically done by converting the weights and activations of the model from their original data type (e.g., 32-bit floating-point) to a lower precision data type (e.g. 8-bit integer). Quantization-aware training, on the other hand, involves training the model with quantization in mind. This is typically done during the training process by converting the weights and/or activations to a lower precision data format and then performing quantization-aware updates to the weights.

Finetuning

Finetuning is the process of taking a pretrained model and further training it on a specific task. This is typically done to improve the performance of the model on the task at hand. For example, a language model might be finetuned on a specific dataset to improve its performance on a specific task, such as question answering or machine translation.

Finetuning is often performed using a technique called gradient descent, which involves updating the model parameters in the direction of the gradient of the loss function with respect to the parameters. The loss function is typically defined as the negative log likelihood of the model's predictions on the training data.
