### Background

#### Orthogonal Finetuning

Orthogonal Finetuning (Hulora et al., 2022) is a parameter-efficient adaptation technique for pretrained models. It uses an orthogonal matrix to adjust the pretrained weights, ensuring that the norm of each neuron remains unchanged during training. This property helps maintain the generalization capabilities of the original model. OFT can be expressed as:

$$\mathbf{W}^f = \mathbf{R}\mathbf{W}^{0},$$

where $\mathbf{W}^\text{0}$ denotes the pretrained weights, $\mathbf{R}$ represents the orthogonal matrix, and $\mathbf{W}$ signifies the finetuned weights. To ensure orthogonality, $\mathbf{RR}^\top = \mathbf{I}$, where $\mathbf{I}$ is the identity matrix. The authors propose two strategies for generating the orthogonal matrix $\mathbf{R}$. The first approach involves sampling from the Haar measure, which guarantees that $\mathbf{R}\sim\mathcal{O}(d)$, where $\mathcal{O}(n)$ denotes the set of $n\times n$ orthogonal matrices. The second strategy employs the Cholesky decomposition, resulting in a lower triangular matrix $\mathbf{L}$ such that $\mathbf{LL}^\top = \text{diag}(\mathbf{D})$, where $\mathbf{D}$ is a diagonal matrix containing only $\pm 1$ values. Consequently, the orthogonal matrix $\mathcal{R}$ can be generated as:

$$\mathcal{R} = \text{diag}\left(\mathbf{D}\right)\mathbf{L}.$$

Although OFT demonstrates superior parameter efficiency compared to standard finetuning, it still requires a significant number of trainable parameters. To address this limitation, the authors introduce a block-diagonal variant of OFT, which further reduces the number of trainable parameters.

#### Butterfly Matrices

Butterfly matrices are a type of sparse matrix that can be constructed by multiplying several smaller matrices, known as butterfly factors. These matrices have a banded structure, with nonzero elements confined to a diagonal band. The butterfly matrix $\mathbf{B}$ can be expressed as:

$${\mathbf{B} = \mathbf{F}_1\mathbf{F}_2\cdots\mathbf{F}_{\ell},}$$

where each $\mathbf{F}_i$ is a butterfly factor. For instance, a butterfly matrix of size $2^m\times 2^m$ can be represented as:

$$\mathbb{B} = \begin{bmatrix}
\mathbf{F}^{(1)}_{1,1} & \mathbf{F}^T_{1,2} \\
\mathbf{F}'_{2,1} & \ddots
\end{bmatrix},$$

with $\mathbf{F}’_{2,1}$ being a $(2^{m-1}\times 2^{m-1})$ butterfly matrix. Each butterfly factor $\mathbf{F}_{i,j}$ is a block-diagonal matrix, with each block having dimensions $2^{m-i}\times 2^{n-j}$. The butterfly matrix $\mathbb{B}$ can be efficiently computed using the Cooley-Tukey algorithm, which recursively divides the matrix into smaller components until reaching a base case of $2\times 2$ matrices. This process results in a computational complexity of $\mathcal{O}\left(n\log n\right)$, making butterfly matrices particularly suitable for large-scale matrix operations.
