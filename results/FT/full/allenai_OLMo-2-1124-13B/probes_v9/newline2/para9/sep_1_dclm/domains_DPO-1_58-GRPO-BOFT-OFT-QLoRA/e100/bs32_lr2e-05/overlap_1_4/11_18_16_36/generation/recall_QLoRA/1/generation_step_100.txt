Quantization is a technique used to convert a model from using 64-bit floating point numbers to 8-bit integers, thereby reducing its memory footprint. This reduction in memory usage is significant, as it can decrease the memory requirements of a model by a multiple of four. The primary motivation behind quantization lies in the fact that most neural network operations, such as matrix multiplication, can be performed with high precision using 8-bit integers instead of 64-bit floats. Consequently, quantization has become a standard practice in the deployment of large language models (LLM), enabling them to run efficiently on resource-constrained hardware.

The process of quantization involves two main steps: quantization and dequantization. During quantization, the original 64-bit floating point values are mapped to a smaller range of 8-bit integers. Typically, this mapping is done by dividing the input values into bins and assigning each bin a unique integer value within the allowable range. For instance, if the input values are between -1 and 1, they would be divided into 256 bins, resulting in an 8-bit integer representation. Dequantization is the reverse process, where the 8-bit integers are converted back to their original 64-bit floating-point equivalents.

A crucial aspect of quantization is ensuring that the quantization error—the difference between the original and quantized values—does not compromise the model's performance. To mitigate this issue, a technique called "straight-through estimator" is employed during training. This method allows gradients to flow through the quantization operation, enabling the model to learn how to minimize the quantization error. Additionally, techniques like zero-point quantization and scaling are utilized to optimize the quantization process. Zero-point quantization shifts all values so that the minimum value becomes zero, while scaling adjusts the range of values to fit within the desired 8-bit integer range.

Low Rank Adapters
---------------

Low rank adapters are a technique designed to further reduce memory consumption during model finetuning. They operate by introducing a small set of trainable parameters, known as adapters, which are added to the existing model architecture. These adapters have a low rank, meaning they contain fewer parameters compared to the full model. By incorporating these low-rank adapters, the model can be finetuned without requiring access to the entire model's weights, thus significantly decreasing memory usage.

During the finetuning phase, the low-rank adapters are updated alongside the input data, while the base model remains fixed. This approach enables the model to adapt to new tasks without necessitating the storage of the complete model weights. The effectiveness of low-rank adapters stems from the observation that only a small portion of the model's parameters needs to be modified when finetuning for a particular task. As a result, low-rank adapters offer a highly efficient means of adapting a pre-trained model to new datasets or objectives.
