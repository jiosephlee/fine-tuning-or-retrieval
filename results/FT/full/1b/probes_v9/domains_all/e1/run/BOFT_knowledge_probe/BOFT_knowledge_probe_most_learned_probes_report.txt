The butterfly structure is originally used in the Cooley-Tukey algorithm to perform fast Fourier transform. In Fourier transform, a local change in the frequency domain can cause a global change in the spatial domain, which is conceptually similar to our information transmission problem -- every node in the first level can transmit information to all the nodes in the last level. The butterfly structure also becomes a popular computer network topology~\cite{solihin2015fundamentals,li2011linear} used for efficient information exchange. Assuming that $k\geq 2$ is a power of $2$, we start by defining the \emph{butterfly factor} $\bm{B}^F(k)$ as

\begin{equation}\label{eq:but_factor}
\begin{aligned}
    \bm{B}^F(k)=\begin{bmatrix}
    \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\
    \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4)
    \end{bmatrix}\in\mathbb{R}^{k\times k},
\end{aligned}
\end{equation}

where $\bm{d}_i\in\mathbb{R}^{\frac{k}{2}},\forall i$ are some vectors. With $d=2^N$, we then define the $d$-dimensional \emph{butterfly matrix} $\bm{B}(d)\in\mathbb{R}^{d\times d}$ recursively as

\begin{equation}
\begin{aligned}
    \!\!\bm{B}(d)=\tilde{\bm{B}}(d,d)\!\cdot\!\begin{bmatrix}
    \bm{B}_1(\frac{d}{2})\!\!\!\!\! & \bm{0} \\
    \bm{0}\!\!\!\!\! &\bm{B}_2(\frac{d}{2})
    \end{bmatrix}= \tilde{\bm{B}}(d,d)\tilde{\bm{B}}(d,\frac{d}{2})\cdots\tilde{\bm{B}}(d,2),
\end{aligned}
\end{equation}

where $\bm{B}_1(\frac{d}{2})$ and $\bm{B}_2(\frac{d}{2})$ are two $\frac{d}{2}$-dimensional butterfly matrices. We then define the \emph{butterfly component} as $\thickmuskip=2mu \medmuskip=2mu \tilde{\bm{B}}(d,k)=\text{diag}(\bm{B}^F_1(k),\cdots,\bm{B}^F_{d/k}(k))$ that is a block-diagonal matrix of size $d\times d$ with the block size $k$, where $\bm{B}^F_i(k),\forall i$ are butterfly factors defined in Equation~\ref{eq:but_factor}. Now we are ready to use the butterfly matrix to parameterize an orthogonal matrix. To achieve this, we only need to ensure that all multiplicative factors $\tilde{\bm{B}}(d,k),\forall k$ in the butterfly matrix $\bm{B}(d)$ are orthogonal. We first look into the block-diagonal matrix $\tilde{\bm{B}}(d,2)$ with the block size $2$, and we can easily guarantee $\tilde{\bm{B}}(d,2)$ to be orthogonal with Cayley transform (or $2$-dimensional rotation) to parameterize each block, same as \cite{liu2021orthogonal,qiu2023controlling}. The non-zero pattern of every butterfly component can be viewed as a permutation of the non-zero pattern of $\tilde{\bm{B}}(d,2)$, so all the butterfly components can be easily parameterized as orthogonal matrices. This gives us an efficient parameterization of orthogonal matrices built upon many $2\times 2$ orthogonal matrices. We generalize the butterfly matrices following \cite{chen2022pixelated}, and define a block butterfly component $\tilde{\bm{B}}^b(d,k)$ where each entry in $\bm{d}_i,\forall i$ becomes a $b\times b$ matrix. To guarantee the block butterfly component $\tilde{\bm{B}}^b(d,2)$ to be orthogonal, we parameterize each $2b\times 2b$ block matrix to be orthogonal. The non-zero pattern of the other butterfly components $\tilde{\bm{B}}^b(d,k),k>2$ are the block-wise permutation of the non-zero pattern of $\tilde{\bm{B}}^b(d,2)$ and therefore can be similarly turned into orthogonal matrices. Combining pieces, the forward pass in BOFT is

\begin{equation}
    \begin{aligned}\nonumber
    \bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x},~~~~\text{s.t.}~\bigg{\{}\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}~~\&~~\underbrace{\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\tilde{\bm{B}}^b_{(d,j)}=\tilde{\bm{B}}^b_{(d,j)}\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\!=\bm{I}_d}_{\forall j\in [1, m]}\bigg{\}},
    \end{aligned}
\end{equation}

where we denote $\tilde{\bm{B}}^b(d,2^{m - i+1})$ as $\tilde{\bm{B}}^b_{(d,i)}$ for simplicity, and $\bm{I}_d$ is an identity matrix of size $d$. The orthogonal matrix $\bm{R}(m,b)\in\mathbb{R}^{d\times d}$ is composed of a product of multiple orthogonal butterfly components. For convenience, we denote BOFT with $\bm{R}(m,\frac{b}{2})$ as BOFT($m$,$b$), where $b\geq 2$. When $\thickmuskip=2mu \medmuskip=2mu m=1$, then BOFT($1$,$b$) reduces to the block-diagonal OFT~\cite{qiu2023controlling} with the block size $b$. BOFT($1$,$d$) reduces to the original OFT~\cite{qiu2023controlling} with an unconstrained full orthogonal matrix. BOFT($\log \frac{2d}{b}$,$b$) uses the block butterfly matrix $\bm{B}^{\frac{b}{2}}(d)$ as $\bm{R}$, and yields a dense orthogonal matrix $\bm{R}$. In general, BOFT($m$,$b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d\times n$. If we use the butterfly matrix, \emph{i.e.}, $m=\log d,b=2$, BOFT uses $\mathcal{O}(d\log d)$ parameters. In contrast, the original OFT with a full dense orthogonal matrix uses $\mathcal{O}(d^2)$ parameters, and the block-diagonal OFT with the block number $r$ uses $\mathcal{O}(bd)$. Therefore, the original OFT has to use the block size $b=d$ to generate a dense orthogonal matrix, while BOFT can use any $b$ to achieve this.

\textbf{Identity initialization for BOFT}. Finetuning methods usually start with the exact pretrained model such that the finetuned model will not deviate too much from the pretrained one. For example, LoRA uses zero initialization for the low-rank weights. In BOFT, we initialize all the butterfly components with identity matrices (\emph{i.e.}, the skew-symmetric matrix is initialized as zeros in Cayley transform).

\textbf{Multiplicative Dropout for BOFT}. LoRA~\cite{hulora2022} further implements a Dropout layer for the low-rank weight update to prevent overfitting. The conventional Dropout~\cite{srivastava2014dropout} naturally works for LoRA, but not for BOFT due to our multiplicative weight update. To address this, we propose a multiplicative Dropout for BOFT. Because the orthogonal matrix $\bm{R}(m,b)$ is composed of $m$ orthogonal butterfly components which can be easily permuted to $2b\times 2b$ block-diagonal orthogonal matrices. The multiplicative Dropout first randomly picks $p_1$ percent of the butterfly components and $p_2$ percent of the diagonal blocks in each butterfly component, and then replaces these blocks as identity matrices.

The butterfly structure is originally used in the Cooley-Tukey algorithm to perform fast Fourier transform. In Fourier transform, a local change in the frequency domain can cause a global change in the spatial domain, which is conceptually similar to our information transmission problem -- every node in the first level can transmit information to all the nodes in the last level. The butterfly structure also becomes a popular computer network topology~\cite{solihin2015fundamentals,li2011linear} used for efficient information exchange. Assuming that $k\geq 2$ is a power of $2$, we start by defining the \emph{butterfly factor} $\bm{B}^F(k)$ as

\begin{equation}\label{eq:but_factor}
\begin{aligned}
    \bm{B}^F(k)=\begin{bmatrix}
    \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\
    \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4)
    \end{bmatrix}\in\mathbb{R}^{k\times k},
\end{aligned}
\end{equation}

where $\bm{d}_i\in\mathbb{R}^{\frac{k}{2}},\forall i$ are some vectors. With $d=2^N$, we then define the $d$-dimensional \emph{butterfly matrix} $\bm{B}(d)\in\mathbb{R}^{d\times d}$ recursively as

\begin{equation}
\begin{aligned}
    \!\!\bm{B}(d)=\tilde{\bm{B}}(d,d)\!\cdot\!\begin{bmatrix}
    \bm{B}_1(\frac{d}{2})\!\!\!\!\! & \bm{0} \\
    \bm{0}\!\!\!\!\! &\bm{B}_2(\frac{d}{2})
    \end{bmatrix}= \tilde{\bm{B}}(d,d)\tilde{\bm{B}}(d,\frac{d}{2})\cdots\tilde{\bm{B}}(d,2),
\end{aligned}
\end{equation}

where $\bm{B}_1(\frac{d}{2})$ and $\bm{B}_2(\frac{d}{2})$ are two $\frac{d}{2}$-dimensional butterfly matrices. We then define the \emph{butterfly component} as $\thickmuskip=2mu \medmuskip=2mu \tilde{\bm{B}}(d,k)=\text{diag}(\bm{B}^F_1(k),\cdots,\bm{B}^F_{d/k}(k))$ that is a block-diagonal matrix of size $d\times d$ with the block size $k$, where $\bm{B}^F_i(k),\forall i$ are butterfly factors defined in Equation~\ref{eq:but_factor}. Now we are ready to use the butterfly matrix to parameterize an orthogonal matrix. To achieve this, we only need to ensure that all multiplicative factors $\tilde{\bm{B}}(d,k),\forall k$ in the butterfly matrix $\bm{B}(d)$ are orthogonal. We first look into the block-diagonal matrix $\tilde{\bm{B}}(d,2)$ with the block size $2$, and we can easily guarantee $\tilde{\bm{B}}(d,2)$ to be orthogonal with Cayley transform (or $2$-dimensional rotation) to parameterize each block, same as \cite{liu2021orthogonal,qiu2023controlling}. The non-zero pattern of every butterfly component can be viewed as a permutation of the non-zero pattern of $\tilde{\bm{B}}(d,2)$, so all the butterfly components can be easily parameterized as orthogonal matrices. This gives us an efficient parameterization of orthogonal matrices built upon many $2\times 2$ orthogonal matrices. We generalize the butterfly matrices following \cite{chen2022pixelated}, and define a block butterfly component $\tilde{\bm{B}}^b(d,k)$ where each entry in $\bm{d}_i,\forall i$ becomes a $b\times b$ matrix. To guarantee the block butterfly component $\tilde{\bm{B}}^b(d,2)$ to be orthogonal, we parameterize each $2b\times 2b$ block matrix to be orthogonal. The non-zero pattern of the other butterfly components $\tilde{\bm{B}}^b(d,k),k>2$ are the block-wise permutation of the non-zero pattern of $\tilde{\bm{B}}^b(d,2)$ and therefore can be similarly turned into orthogonal matrices. Combining pieces, the forward pass in BOFT is

\begin{equation}
    \begin{aligned}\nonumber
    \bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x},~~~~\text{s.t.}~\bigg{\{}\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}~~\&~~\underbrace{\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\tilde{\bm{B}}^b_{(d,j)}=\tilde{\bm{B}}^b_{(d,j)}\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\!=\bm{I}_d}_{\forall j\in [1, m]}\bigg{\}},
    \end{aligned}
\end{equation}

where we denote $\tilde{\bm{B}}^b(d,2^{m - i+1})$ as $\tilde{\bm{B}}^b_{(d,i)}$ for simplicity, and $\bm{I}_d$ is an identity matrix of size $d$. The orthogonal matrix $\bm{R}(m,b)\in\mathbb{R}^{d\times d}$ is composed of a product of multiple orthogonal butterfly components. For convenience, we denote BOFT with $\bm{R}(m,\frac{b}{2})$ as BOFT($m$,$b$), where $b\geq 2$. When $\thickmuskip=2mu \medmuskip=2mu m=1$, then BOFT($1$,$b$) reduces to the block-diagonal OFT~\cite{qiu2023controlling} with the block size $b$. BOFT($1$,$d$) reduces to the original OFT~\cite{qiu2023controlling} with an unconstrained full orthogonal matrix. BOFT($\log \frac{2d}{b}$,$b$) uses the block butterfly matrix $\bm{B}^{\frac{b}{2}}(d)$ as $\bm{R}$, and yields a dense orthogonal matrix $\bm{R}$. In general, BOFT($m$,$b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d\times n$. If we use the butterfly matrix, \emph{i.e.}, $m=\log d,b=2$, BOFT uses $\mathcal{O}(d\log d)$ parameters. In contrast, the original OFT with a full dense orthogonal matrix uses $\mathcal{O}(d^2)$ parameters, and the block-diagonal OFT with the block number $r$ uses $\mathcal{O}(bd)$. Therefore, the original OFT has to use the block size $b=d$ to generate a dense orthogonal matrix, while BOFT can use any $b$ to achieve this.

\textbf{Identity initialization for BOFT}. Finetuning methods usually start with the exact pretrained model such that the finetuned model will not deviate too much from the pretrained one. For example, LoRA uses zero initialization for the low-rank weights. In BOFT, we initialize all the butterfly components with identity matrices (\emph{i.e.}, the skew-symmetric matrix is initialized as zeros in Cayley transform).

\textbf{Multiplicative Dropout for BOFT}. LoRA~\cite{hulora2022} further implements a Dropout layer for the low-rank weight update to prevent overfitting. The conventional Dropout~\cite{srivastava2014dropout} naturally works for LoRA, but not for BOFT due to our multiplicative weight update. To address this, we propose a multiplicative Dropout for BOFT. Because the orthogonal matrix $\bm{R}(m,b)$ is composed of $m$ orthogonal butterfly components which can be easily permuted to $2b\times 2b$ block-diagonal orthogonal matrices. The multiplicative Dropout first randomly picks $p_1$ percent of the butterfly components and $p_2$ percent of the diagonal blocks in each butterfly component, and then replaces these blocks as identity matrices.

We then define the \emph{butterfly component} as $\thickmuskip=2mu \medmuskip=2mu \tilde{\bm{B}}(d,k)=\text{diag}(\bm{B}^F_1(k),\cdots,\bm{B}^F_{d/k}(k))$ that is a block-diagonal matrix of size $d\times d$ with the block size $k$, where $\bm{B}^F_i(k),\forall i$ are butterfly factors defined in Equation~\ref{eq:but_factor}. Now we are ready to use the butterfly matrix to parameterize an orthogonal matrix. To achieve this, we only need to ensure that all multiplicative factors $\tilde{\bm{B}}(d,k),\forall k$ in the butterfly matrix $\bm{B}(d)$ are orthogonal. We first look into the block-diagonal matrix $\tilde{\bm{B}}(d,2)$ with the block size $2$, and we can easily guarantee $\tilde{\bm{B}}(d,2)$ to be orthogonal with Cayley transform (or $2$-dimensional rotation) to parameterize each block, same as \cite{liu2021orthogonal,qiu2023controlling}. The non-zero pattern of every butterfly component can be viewed as a permutation of the non-zero pattern of $\tilde{\bm{B}}(d,2)$, so all the butterfly components can be easily parameterized as orthogonal matrices. This gives us an efficient parameterization of orthogonal matrices built upon many $2\times 2$ orthogonal matrices. We generalize the butterfly matrices following \cite{chen2022pixelated}, and define a block butterfly component $\tilde{\bm{B}}^b(d,k)$ where each entry in $\bm{d}_i,\forall i$ becomes a $b\times b$ matrix. To guarantee the block butterfly component $\tilde{\bm{B}}^b(d,2)$ to be orthogonal, we parameterize each $2b\times 2b$ block matrix to be orthogonal. The non-zero pattern of the other butterfly components $\tilde{\bm{B}}^b(d,k),k>2$ are the block-wise permutation of the non-zero pattern of $\tilde{\bm{B}}^b(d,2)$ and therefore can be similarly turned into orthogonal matrices. Combining pieces, the forward pass in BOFT is

\begin{equation}
    \begin{aligned}\nonumber
    \bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x},~~~~\text{s.t.}~\bigg{\{}\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}~~\&~~\underbrace{\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\tilde{\bm{B}}^b_{(d,j)}=\tilde{\bm{B}}^b_{(d,j)}\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\!=\bm{I}_d}_{\forall j\in [1, m]}\bigg{\}},
    \end{aligned}
\end{equation}

where we denote $\tilde{\bm{B}}^b(d,2^{m - i+1})$ as $\tilde{\bm{B}}^b_{(d,i)}$ for simplicity, and $\bm{I}_d$ is an identity matrix of size $d$. The orthogonal matrix $\bm{R}(m,b)\in\mathbb{R}^{d\times d}$ is composed of a product of multiple orthogonal butterfly components. For convenience, we denote BOFT with $\bm{R}(m,\frac{b}{2})$ as BOFT($m$,$b$), where $b\geq 2$. When $\thickmuskip=2mu \medmuskip=2mu m=1$, then BOFT($1$,$b$) reduces to the block-diagonal OFT~\cite{qiu2023controlling} with the block size $b$. BOFT($1$,$d$) reduces to the original OFT~\cite{qiu2023controlling} with an unconstrained full orthogonal matrix. BOFT($\log \frac{2d}{b}$,$b$) uses the block butterfly matrix $\bm{B}^{\frac{b}{2}}(d)$ as $\bm{R}$, and yields a dense orthogonal matrix $\bm{R}$. In general, BOFT($m$,$b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d\times n$. If we use the butterfly matrix, \emph{i.e.}, $m=\log d,b=2$, BOFT uses $\mathcal{O}(d\log d)$ parameters. In contrast, the original OFT with a full dense orthogonal matrix uses $\mathcal{O}(d^2)$ parameters, and the block-diagonal OFT with the block number $r$ uses $\mathcal{O}(bd)$. Therefore, the original OFT has to use the block size $b=d$ to generate a dense orthogonal matrix, while BOFT can use any $b$ to achieve this.

\textbf{Identity initialization for BOFT}. Finetuning methods usually start with the exact pretrained model such that the finetuned model will not deviate too much from the pretrained one. For example, LoRA uses zero initialization for the low-rank weights. In BOFT, we initialize all the butterfly components with identity matrices (\emph{i.e.}, the skew-symmetric matrix is initialized as zeros in Cayley transform).

\textbf{Multiplicative Dropout for BOFT}. LoRA~\cite{hulora2022} further implements a Dropout layer for the low-rank weight update to prevent overfitting. The conventional Dropout~\cite{srivastava2014dropout} naturally works for LoRA, but not for BOFT due to our multiplicative weight update. To address this, we propose a multiplicative Dropout for BOFT. Because the orthogonal matrix $\bm{R}(m,b)$ is composed of $m$ orthogonal butterfly components which can be easily permuted to $2b\times 2b$ block-diagonal orthogonal matrices. The multiplicative Dropout first randomly picks $p_1$ percent of the butterfly components and $p_2$ percent of the diagonal blocks in each butterfly component, and then replaces these blocks as identity matrices.
