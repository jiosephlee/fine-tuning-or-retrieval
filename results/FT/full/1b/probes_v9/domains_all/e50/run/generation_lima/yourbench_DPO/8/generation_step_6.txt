# Reward models and their typical form

A reward model assigns a scalar value $r$ to each possible action $a$ in the state space $S$. The typical form of a reward model is a function $R(s,a)$ that maps states $s \in S$ to a scalar value. For example, a simple reward model might assign a reward of 1 if the agent takes an action that leads to a high reward, and a reward of 0 otherwise. More complex reward models can include features like temporal-difference (TD) error or a discount factor, but the basic idea is the same: the reward model provides a scalar estimate of the expected return from taking action $a$ in state $s$.

Why do we use a reward model instead of directly estimating the value function? The primary reason is that the value function is often unknown or difficult to compute. Using a reward model allows us to estimate the expected return without having to compute the full value function. This is particularly important when the environment is stochastic or when the value function is expensive to compute.

However, there are several important caveats to keep in mind when using a reward model. First, the reward model itself can be inconsistent with the underlying value function. Second, the reward model can be noisy or imperfect, leading to estimation errors. Third, the reward model can change over time or across environments, complicating the interpretation of estimates.
