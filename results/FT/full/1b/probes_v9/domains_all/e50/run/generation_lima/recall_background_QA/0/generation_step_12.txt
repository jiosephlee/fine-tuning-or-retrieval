It is a sequence-to-sequence model that uses self-attention to model long-range dependencies between tokens. The transformer is particularly useful for language models because it allows the model to learn how words are related to each other in a sequence, which is crucial for tasks like text generation and translation.

The core idea behind the transformer is that each token in a sequence is represented by a vector of size $d$ (where $d$ is the sequence length). The model then learns how to transform these vectors into new vectors by applying a linear transformation followed by a softmax. This allows the model to attend to different parts of the input sequence and to produce outputs that are meaningful in the context of the input.

\text{Attention}(x, A) = x \odot A.
