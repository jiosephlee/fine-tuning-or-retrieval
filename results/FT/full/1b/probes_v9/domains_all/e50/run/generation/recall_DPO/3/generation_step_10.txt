\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a simple classification loss applied to the reward model used in RLHF. The idea is to use the reward model to estimate the expected reward of a given generation, and then fine-tune the unsuper-vised model to maximize this expected reward. This is a simple and effective way to obtain steerability, but it has several advantages over traditional RLHF.

First, DPO is computationally much simpler than RLHF. In RLHF, the reward model is typically a neural network that maps a sequence to a scalar reward. Training the reward model requires computing gradients with respect to parameters, which can be expensive. In DPO, the reward model is a classification model that maps a sequence to one of a small set of labels. Training the classification model requires only a few classification losses, which are much cheaper than gradient-based training. Second, DPO is more stable than RLHF. When RLHF is used to fine-tune an unsupervised model, the reward model is often fitted to human preferences, and the fine-tuning objective is a reinforcement learning objective that tries to maximize the reward. If the reward model is not perfectly calibrated, the fine-tuning objective can cause the model to drift away from the original model. DPO avoids this by using a classification loss that directly measures the quality of a generation. If the classification loss is small, the model is likely to be close to the original model; if the classification loss is large, the model is likely far from the original model. This makes DPO more robust to reward model calibration errors.

Finally, DPO is more performant than RLHF. In DPO, you only need to compute a few classification losses, whereas in RLHF you need to compute many gradient updates. This makes DPO faster and easier to implement. Moreover, DPO can be used to fine-tune LMs that are not supervised, which is not possible with RLHF.

Despite these advantages, DPO has some limitations. First, DPO is not guaranteed to produce the same behavior as RLHF. The classification loss used in DPO is a lower bound on the expected reward, so it may not always produce the same behavior as the RLHF objective. Second, DPO can be unstable when the reward model is not calibrated exactly. If the reward model has small errors, DPO can still produce good behavior, but it may be worse than RLHF. Third, DPO is not suitable for fine-tuning LMs that are already trained on large datasets. If the LMs are already trained on large amounts of data, DPO may not be able to improve performance because the LMs have already learned many useful features. However, DPO is still useful for fine-tuning LLMs that are not supervised, and it is often combined with RLHF to improve performance.

\section{Standard RLHF and the Reward Model}
\label{sec:standard-rlhf}

In RLHF, the reward function $R$ is a scalar that measures the quality of a given generation. The RLHF objective is to find a policy $\pi_\theta$ that maximizes the expected return
\[
\mathbb{E}_{x \sim \pi_\theta(x)} \big[ R(x) \big].
\]
