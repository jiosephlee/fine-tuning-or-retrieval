# Stochastic surrogate objectives: importance sampling, importance weighting, and surrogate objectives

A stochastic surrogate objective is a function that approximates the true objective but is easier to compute. The simplest form is a surrogate objective that uses importance sampling. In importance sampling, we estimate the expected reward of an item by sampling from the population and computing the average reward of the sampled items. For example, if we have a population of $N$ items and we sample $m$ items uniformly at random, the expected reward of the sampled items is approximately $\frac{1}{m} \sum_{i=1}^m r_i$. We can then use this surrogate to compute a score for each pair $(i,j)$ by taking the ratio of the expected reward of $i$ to the expected reward of $j$:
$$
\hat{r}_i = \frac{\mathbb{E}[r_i]}{\mathbb{E}[\hat{r}_j]}.
$$
This is a simple and effective way to approximate the true score when the population is large. It is also easy to implement and scale well: the number of comparisons required scales linearly with the number of sampled items, which is much cheaper than comparing all pairs.

There are several variants of importance sampling. One important distinction is whether the surrogate objective is deterministic or stochastic. A deterministic surrogate objective computes the same score for every pair of items, which can be useful when you want to compare two items directly. A stochastic surrogate objective samples items and computes scores for each pair, which is more appropriate when you want to estimate the expected reward of a particular item based on the population. Another important distinction is whether the sampling is done uniformly or according to some probability distribution. Uniform sampling is simple and efficient, but it may not reflect the true distribution of rewards in the population. Sampling according to a known distribution (e.g., Gaussian) can improve the accuracy of the surrogate objective.

Importance weighting is a related concept. Instead of using importance sampling to estimate the expected reward, importance weighting uses the inverse of the variance of the sampling distribution to weight the contribution of each sampled item. For example, if the sampling distribution is approximately normal with mean $\mu$ and variance $\sigma^2$, we can compute the importance weight for each sampled item as
$$
w_i = \frac{\mathbf{1}}{\sqrt{\mathbf{Var}(x_i)}},
$$
where $x_i$ is the sampled item. Importance weighting is particularly useful when the sampling distribution is heavy-tailed or when the rewards are highly skewed. It can produce more accurate surrogate objectives than uniform sampling in many cases.

Surrogate objectives are also used in importance weighting. For example, suppose we want to compute the expected reward of an arbitrary item $i$ given the population. We can use importance weighting to obtain an unbiased estimator:

where $S$ is the set of sampled items and $\hat{r}_j$ is the surrogate score computed from importance sampling. This estimator is unbiased because the weights are inversely proportional to the variances of the sampling distributions. It is also efficient: the number of comparisons needed to compute the surrogate objective is roughly proportional to the square root of the number of sampled items.

Finally, it is worth noting that surrogate objectives can be combined with other techniques. For example, one can combine importance sampling with gradient-based optimization to obtain a hybrid method that uses the gradient of the surrogate objective to update the weights. This can be particularly useful when the surrogate objective is expensive to compute or when the population is large.

# Practical considerations and limitations of DPO

Direct Preference Optimization is a powerful tool for learning preferences from pairwise comparisons. However, it has several practical limitations that must be understood before using it in practice.

First, the number of comparisons required to learn a preference is proportional to the square root (or higher) of the number of items. This means that for very large datasets, DPO can become prohibitively expensive. To mitigate this, researchers often use heuristics that reduce the number of comparisons. One common heuristic is to use a greedy search that selects the most preferred item up to a certain threshold.
