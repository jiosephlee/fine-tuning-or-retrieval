# Environment and agent's actions

An environment is a mathematical model of the world that describes the states of the system and the ways the system can change over time. The environment is typically represented by a set of states $S$ and a set of actions $A$. The environment evolves according to a dynamics model, which specifies how the states change over time. For example, the environment could be a Markov decision process (MDP) where the states are the state-action pairs and the dynamics are defined by a transition probability matrix $P(s_{t+1} = s_t \mid s_t = s, a_t = a)$.

The agent is the entity that interacts with the environment. The agent's actions are chosen by the learner and correspond to the possible actions available in the environment. The agent can take actions in the environment, and the environment responds by changing the state. The agent's goal is to maximize the expected cumulative reward from the environment. Formally, if the environment is an MDP, the agent's objective is to maximize the expected return
\[
\mathbb{E}_{s_t \sim P(s_t \mid s_{<t})}[\sum_{a_t \in A} r(s_t, a_t)],
\]
where $s_{<t}$ denotes the set of states accessible at time $t$, $r(s_t, a_t)$ is the reward at state $s_t$ when taking action $a_t$, and $\sum$ denotes summing over all actions. If the environment is a continuous-time stochastic process, the expected return is often defined as the expected discounted return:
\[
\mathbb E_{t \ge 0}[R_t],
\]
where $R_t = \sum_{i=0}^{\infty} \gamma^i r(s_t, a_{\text{max}})$ is the infinite-horizon discounted return, $\gamma \in [0,1)$ is the discount factor, and $a_{\text{max}, t}$ is the maximum action available at time $t$.
