A language model is a statistical model that maps text to a probability distribution over sequences of tokens. More formally, a language model $p_\theta(x_t \mid x_{<t})$ is a function that maps a sequence of tokens $x_t$ to a probability distribution over the next token $x_{<t}$. The parameters $\theta$ are typically learned from a large corpus of text using maximum likelihood estimation. The language model can be used to predict the next token given the current token, or to generate text given a prompt.

In the context of preference learning (also known as reward learning), a language model is used as a proxy for the preferences of a user. Given a set of preferences, a language model can be trained to represent those preferences as a set of probability distributions over the possible reward labels. For example, suppose we have a set of user preferences $\{p_1, p_2, \dots, p_n\}$ where each $p_i$ represents a preference between two items. We can train a language model $L(\cdot)$ to represent these preferences as a set of distributions over reward labels:
$$
\mathcal{L} = \{p_i \mid i =  1,\dots,n\},
$$
where $p_i$ is a distribution over reward labels. The language model can then be used to predict the probability that a new item will receive a particular reward label, or to generate text that reflects the preferences of a user.

To see why this is useful, consider the problem of preference learning. Suppose we want to predict the reward of a new item based on its features. One approach is to fit a reward model $R(\cdot)$ that maps features to rewards. However, this model must be trained on a large dataset of items and their rewards. Instead, we can use a pretrained language model $L(\theta)$ to represent the preferences of users. We can then use the language model to predict the probability that an item will receive a reward given its features:
$$
\hat{p}_i(\text{features}) = L(\theta) \big( R(\text{features}) \big).
$$
This prediction can be used to guide the training of the reward model. If the predicted probability is high, the reward model can be trained to assign a high probability to the reward; if the predicted probability is low, the reward model can either be trained to assign a lower probability or to assign a higher probability to a different reward. This approach avoids the need to collect a large dataset of item-reward pairs, which can be expensive or impossible to obtain.

Another application of language models in preference learning is generation. Suppose we have a set of preferences represented by a language model $\mathcal{L}$. We can use the language model to generate text that reflects those preferences. For example, we can generate a list of items and their associated probabilities:
$$
\text{Items} = \{x_1, x_2, \dots\}, \quad \text{Probabilities} = \{p_1, \dots, p_{n}\}.
$$
We can then use the language models to generate text that reflects these preferences. For instance, we could generate a list of items with the highest probability:
$$
\text{"The best item is } x_1.\text{"}
$$
