Introduction
In this paper, we introduce a new method for training language models, called Direct Preference Optimization (DPO). DPO is an extension of the reinforcement learning algorithm Proximal Policy Optimization (PPO) (Schulman et al., 2017), and it is provably equivalent to the original PPO algorithm. However, DPO is more efficient in practice, and it achieves better performance on real-world benchmarks.
The core idea of DPO is to use a reward model to optimize a language model. The reward model is a language model that assigns a reward value to each token in the input text. The reward model is trained using a variant reinforcement learning algorithm called proximate policy optimization (PPO) (Liu et al., 2018). PPO is a simple modification of the standard reinforcement learning (RL) algorithm (Mnih et al., 2015), and it is widely used in the RL community. In particular, PPO is used to train language models, such as OpenAI's GPT-3 (Brown et al., 2020) and Google's BERT (Devlin et al., 2019). However, PPO is not efficient in practice, because it requires a large number of training examples. To address this issue, we propose DPO, which uses a reward model to train a language model. The key idea of DPO is that the reward model can be learned from human preferences, which are typically available in large quantities. Therefore, DPO can be efficiently applied to language models that are pretrained on large amounts of text data, such as OpenAI GPT-3 and Google BERT.
We evaluate DPO on two real-world benchmarks: the GLUE (Wang et al., 2016) benchmark and the English-German translation task from the World Language Modeling Challenge (WMT14) (Xu et al., 2014). DPO achieves state-ofthe-art performance on both benchmarks, and it is more efficient than PPO. In addition, we analyze the performance of DPO, showing how different hyperparameter settings affect the performance of the algorithm. We also conduct a comprehensive analysis of the impact of DPO on the training process of language models, showing that DPO can be easily applied to language models that have already been trained using other algorithms.
