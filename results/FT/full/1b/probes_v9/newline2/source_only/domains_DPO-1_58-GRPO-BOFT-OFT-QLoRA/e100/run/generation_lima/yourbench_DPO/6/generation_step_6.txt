Introduction
The reinforcement learning (RL) framework has been widely used to solve complex decision-making problems in various fields, such as robotics [1], computer vision [2], and natural language processing [3]. In the RL framework, an agent interacts with its environment to collect experience, and then uses the collected experience to learn a policy that can make optimal decisions in the future. The RL framework has achieved great success in solving complex decision-making problems. However, the RL framework is still facing challenges in solving real-world problems due to the following two reasons. First, the RL framework is computationally expensive. For example, the actor-critic algorithm [4] is a widely used RL algorithm, and it requires the computation of the gradient of the loss function with respect to the policy parameter. The gradient of the loss function is calculated by the chain rule, which is a very expensive operation. Second, the RL framework is not guaranteed to converge to the optimal solution. In the RL framework, the agent learns from experience, and the experience is generated by the interaction between the agent and the environment. Therefore, the agent may not converge to the optimal solution due to the randomness of the environment. To address these challenges, researchers have proposed various approximation algorithms to reduce the computational cost of the RL framework. One of the most popular approximation algorithms is the reinforcement learning with preference optimization (RLPO) algorithm [5]. The RLPO algorithm is a variant of the RL framework, and it aims to optimize the policy parameter of the RL framework using a reward function. The reward function is a function that maps the current state of the environment to a numerical value, and the numerical value represents the reward that the agent can obtain in the current state. The RLPO algorithm optimizes the reward function instead of the policy parameter. The reward function is usually learned from experience, and the learned reward function can be used to approximate the optimal policy. Therefore, the RLPO algorithm can reduce the computational cost of solving the RL problem.
