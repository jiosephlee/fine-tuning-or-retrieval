\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model that is optimized to maximize the human preference score of a given generation.  In contrast to existing methods, DPO does not require any sampling from the LM during training, nor does it require any hyperparameter tuning.  Instead, DPO uses a simple classification loss to optimize the reward model, and then fine-tunes the reward model using reinforcement learning to maximize the human preference scores of the generated samples. The resulting policy is the optimal policy for maximizing the reward model's preference score, and so the DPO algorithm can be viewed as a variant of reinforcement learning from human feedback.

\section{Related Work}

\textbf{Large Language Models (LLMs)}: Large-scale LLMs have been trained on massive datasets of text, including the open-source BERT~\citep{devlin-etal-2018-microsoft}, GPT-3~\citep{brown2020gpt}, and OpenAI GPT-4~\citep{openai2023gpt4}. These models have demonstrated impressive performance on a wide range of tasks, including natural language understanding, question answering, and machine translation. However, LLMs are trained on unstructured text, and so their behavior is largely unpredictable.  This makes it difficult to use them in applications where precise control of the model's behavior is required, such as in dialogue systems, where the model must be able to respond to user queries in a coherent and fluent manner.  To address this, several methods have been proposed to gain steerability from LLMs, including reinforcement learning from human feedback~\citep{liu2022reinforcement,liu2023training}, supervised learning from human feedback~(e.g., \citep{wang2023learning,chen2023training,chen2023training2}), and imitation learning~\citep{wang2022imagination,chen2023imitation}.  While these methods have shown promising results, they all require collecting human feedback on the generated samples, which is often impractical or impossible.  In this work, we focus on methods that do not require human feedback, and instead use the LLM to learn a reward function that can be used to steer the model's behavior.

\textbf{Reward Models}:
A reward model is a function that maps a sequence of inputs to a scalar reward value.  In reinforcement learning, the goal is to find a policy that maximizes the expected total reward over the environment.  In the context of LLMs, a reward model can be used to estimate the reward value of a given sequence of inputs, and then use this reward model to steer the LLM's behavior.  For example, in \citep{liu2019learning}, the authors use a reward model to estimate the reward value for each word in the input sequence, and then use this model to steer the LML's behavior by changing the reward value of each word.  Similarly, in \citep{liao2022learning}, the authors use an LSTM to predict the reward value of each token in the input sequence, which is then used to steer the LML by changing the reward value for each token.  In this work we focus on methods that directly optimize the reward model, rather than using a separate policy to control the LML's behavior.

\text{Reinforcement Learning from Human Feedback}:
RLHF is a method for training an LLM to perform a specific task using only human feedback.  The basic idea is to first train an LLM to generate text that is preferred by humans, and then use reinforcement learning to fine-tune the LLM to maximize the reward value of the generated text.  This is typically done by sampling from the LLM and training a policy that maximizes a reward function that is estimated from the sampled text.  The resulting policy is then used to steer a second LLM to generate text with the desired reward value.  This process is illustrated in Figure~1.  In this work our focus is on methods that do not use sampling from the LLM during training, and so we refer to these methods as \textit{Direct RLHF}.

\textbf{Stable Reinforcement Learning}:
RLHF is typically unstable, and often requires significant hyperparameter tuning to achieve satisfactory performance.  This is because the reward model is typically learned using stochastic gradient descent, and so the reward model's parameters are updated based on the average reward of the sampled text.  This means that the reward model is sensitive to the distribution of the sampled text, and so the reward value of a particular sequence of inputs can vary significantly depending on the specific sequence of inputs that are sampled.
