\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model fine-tuning algorithm. We can use it to optimize a given reward function to obtain an optimal policy. The key idea is to use the reward function to optimize the reward function. In this section, we will give a formal definition of DPO. For more details, please refer to Appendix \ref{app:reward_model}. 

\begin{definition}[Reward Model]
Given a reward function $R : \mathcal{X} \times \mathcal{Y} \rightarrow \mathbb{R}$, where $\mathcal{X}$ is the set of all possible states and $\mathcal{Y}$ is the set of possible actions, a reward model is a parametric function $\pi_\theta : \mathcal{Y}\times\mathcal{X}  \rightarrow \mathbb R$ that maps an action to a scalar reward. We assume that the reward model $\pi_\theta$ is trained end-to-end with the objective of maximizing the expected return:
\begin{equation}\label{eq:reward_model}
    \max_{\pi_\theta}\mathbb{E}_{\pi_\theta\mid\mathcal{D}}\left[ \underbrace{ \sum_{t=1}^T \underbrace{ \mathbb{I}_{\{s_t\in\mathcal{X}\}}\left( \underbrace{\pi_\theta(s_t, a) - R(s_t, a)\right)}_{\ge 0}\right]}_{\text{negative reward}}\right].
\end{equation}
\end{definition}

We can use the reward model to optimize the reward function to obtain an optimum policy. In this section, based on the reward model, we will introduce a simple but effective method to optimize the reward function, which is called Direct Preference Optimization (DPO). The main idea of DPO is to use the reward model to maximize the reward function. Formally, we want to find the optimal policy $\pi^\star$ that maximizes the reward function defined as:

\begin{equation}
    R(\mathcal{X}|\mathcal{Y},  \pi) = \mathbb{E}_{ \pi \mid \mathcal{D}} \left[ \underbrace{\sum_{t=1^{\text{th}}}\underbrace{ \mathcal{Y}_t\cdot \mathbb{I}_{\{s_t\in \mathcal{X}\} }\left( \underbrace{R(\mathcal{Y}_\text{t} \mid \mathcal {X},\pi(s_t) ) - \pi^\star(s_t) \right)}_{\geq 0}\right]\right].
\end{Equation}
