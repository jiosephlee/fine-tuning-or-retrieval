The paper introduces a new method for finetuning text-to-image models, called Orthogonal Finetuning. The key idea of OFT is to use an orthogonal transformation to transform the input image before finetuning. This transformation can be thought of as a rotation or a reflection, and it is orthogonal to the original image. The orthogonal transformation is applied to the input image in a way that preserves the angles between pixels, which is crucial for preserving the semantics of the image. After the transformation, the input image is then fed into the finetuning network. The key insight is that the transformation does not change the gradient of the loss function, so the finetuning process can be performed without any additional loss computation. This allows us to perform finetuning in a much more efficient way than existing methods.
