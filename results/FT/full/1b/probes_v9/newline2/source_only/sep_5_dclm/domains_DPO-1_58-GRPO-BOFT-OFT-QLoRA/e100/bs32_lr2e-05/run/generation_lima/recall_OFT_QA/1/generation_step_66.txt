The paper introduces a new method for finetuning text-to-image models, called Orthogonal Finetuning. The key idea of OFT is to use an orthogonal transformation to transform the input image before finetuning. This transformation can be thought of as a rotation or reflection, and it is orthogonal to the original image. By using an orthogonal transformation, we can ensure that the gradients of the transformed image are zero, which prevents the gradient flow from moving the model in undesirable directions. We also show that OFT can be used to control the diffusion of the latent space, which can be useful for stabilizing text-to-image generation.

The paper also mentions that OFT is similar to the method of "Orthogonal Finetuning with Gradient Descent" (OFG), but that OFG does not work well for large-scale models. In OFG, the gradient descent is performed on the transformed image, which is not orthogonal to the original image, so the gradient flow is not controlled. In OFT, the gradient descent is done on the original image, which is orthogonal to the transformed image, so the gradient flows are controlled.<|endoftext|>
