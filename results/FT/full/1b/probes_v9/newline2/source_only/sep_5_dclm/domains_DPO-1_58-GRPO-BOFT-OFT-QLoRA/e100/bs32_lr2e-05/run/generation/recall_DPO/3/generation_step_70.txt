\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model for the unsupervised language model (LM) that is used to fine-tune the LM to align with human preferences. The reward model is trained to maximize the reward function $R$ defined as the expected reward of the LM given a sequence of inputs $x$ and outputs $y$:
\begin{equation}
R(y|x) = \mathbb{E}_{\pi}[\mathbb{E}_{x}[\mathbb{I}(y = x)]],
\end{equation}
where $\mathbb{E}_{y}[\mathbb{P}(y = x)]$ is the probability of observing $y$ given $x$, $\pi$ is the probability distribution over the possible outputs, and $\mathbb{I}$ is the indicator function. The reward function $R$ is a function of the LM's output $y$ and the input $x$, and is typically a function of the LM’s parameters $\theta$.

The reward model is used to fine-tuning the LM by maximizing the reward function $R$. The reward model is typically trained using reinforcement learning (RL) from human feedback, where the human provides a preference score for each generation of the LM, and the reward model is trained to minimize the difference between the human preference scores and the reward function $R(y|x)$.

The reward model is typically trained in two steps. First, the reward model is trained using reinforcement learning from human feedback. Second, the reward model is fine-tuned to maximize the reward function using reinforcement learning from human preference scores. This is often done using a reinforcement learning algorithm such as Proximal Policy Optimization (PPO) or Actor-Critic (AC) [1, 2]. The reward model is typically fine-tuned using a simple classification loss, such as the cross-entropy loss, which is defined as the negative log-likelihood of the reward model given the human preference scores:
\begin{equations}
\label{eq:cross-entropy}
\text{cross-entropy}(\theta) = -\mathbb{E}_{h}[\log \mathbb{P}(h = y|x)] = -\mathbb{\log \mathbb{I}(h = y|x)},
\end{equations}
where $\mathbb{\log \pi}$ is the log-likelihood of the LM given the reward model, and $\mathbb{\log h}$ is the log-liklihood of the reward model given a human preference score $h$.

The reward model can be used to fine-tune a large unsupervised LM to maximize the reward function. However, the reward model is typically trained from human feedback using reinforcement learning, which is a complex and often unreliable procedure. In particular, the reward model is often trained using a reinforcement learning algorithm that requires a large number of samples from the LM, which can be expensive to collect. Furthermore, the reward model is usually trained using a simple classification loss that is not well suited to the task of fine-tuning the LM. For example, the cross-entropy loss is not well suited to fine-tuning the reward model because it does not penalize the LM for producing low-quality outputs. Instead, the cross-entropy is a measure of the difference between the reward function and the human preference scores, which is not a good indicator of the quality of the LM's output.

\begin{equatio}
\label{eq:r-reward}
R(\theta) = \mathbb{\mathbb{E}}_{\pi}[\mathcal{R}(\pi)],
\end{equation}

where $\mathcal{R} (\pi)$ is the reward function of the policy $\pi$. The reward function $R(\pi)$ is a function of the policy $\theta$ and the inputs $x$ and the outputs $y$.
