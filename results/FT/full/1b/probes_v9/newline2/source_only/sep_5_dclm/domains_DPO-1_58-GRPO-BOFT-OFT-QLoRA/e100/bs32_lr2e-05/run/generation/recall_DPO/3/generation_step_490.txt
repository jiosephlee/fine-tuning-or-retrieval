\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

\section{Related Work}

\textbf{Large-Scale Unsupervised Language Models}. Large-scale unsupervised language model (LM) training has been a major focus of recent work in natural language processing (see \cite{li2022training,liu2023training,liu2024training} for surveys).  The most popular approach to training LMs is training them on large corpora of text data, typically with a few million tokens, and then finetuning them on smaller datasets of human-annotated data.  This approach has been shown to yield state-of-the-art performance on many downstream tasks, including machine translation, question answering, and summarization.  However, the training data required for this approach is often prohibitively large, and the annotation of such large datasets is expensive and time-consuming.  As a result, there has been growing interest in training LMs without any annotated data, using only unlabeled text data.  One popular approach to this end is to train LMs on large corpora of unstructured text data, and then use pre-trained weights from these models to initialize a smaller, finetuned model.  This approach has yielded impressive results, but it is unclear how to effectively use such pretrained models, since they are typically trained on very different data than downstream tasks.  Another popular approach is to train LMs from scratch on large corpora of unlabeled text data, and then finetune them on smaller datasets of annotated data.  This approach is more straightforward to implement, but it is unclear whether it yields better performance than using pretrained models.

\textbf{Reward Learning}. Reward learning is a general framework for learning to control the behavior of agents in environments.  In this framework, an agent is represented by a policy, which specifies the action to take in each state of the environment.  The reward function is a function that maps each state to a numerical value representing the reward for taking the corresponding action.  The goal of reward learning is to learn a policy that maximizes the expected total reward over all states.  This problem is known as the optimal control problem, and it is a central problem in control theory.  There are many different approaches to solving this problem, including reinforcement learning (RL) and model-based control.  RL is a class of algorithms that learn to control the agent by interacting with the environment and observing the reward that is received for taking different actions.  The most famous example of an RL algorithm is Q-learning, which learns to maximize the total expected future reward by taking actions that maximize the current reward and then storing the associated value of each action.  Model-based control is a class of algorithms for learning to control the agent by simulating the environment and using the simulation to estimate the future reward that will be received for taking different actions.

\textbf{Control of Language Models}. While LMs have been shown to be effective at generating text, it is unclear how to control their behavior.  One approach is to use RL to learn a reward function that specifies the reward for taking different actions in the LM's environment.  This approach has the advantage of being able to learn a reward function from scratch, but it requires sampling from the LM's distribution, which can be computationally expensive.  Another approach is to use reinforcement learning from human feedback to fine-tune the unsatisfied reward function.  This approach has several advantages, including the fact that it does not require sampling from the LM's posterior distribution, and it can be used to control the behavior of LMs that have already been trained.  However, it is unclear how well this approach works, and it is also computationally expensive.
