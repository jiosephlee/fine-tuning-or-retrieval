\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

\textbf{Reward Model Parameterization}. A common approach to reward learning is to fit a reward function to the human preferences, and use this function to optimize the model's policy. This is typically done by maximizing the reward function with respect to the model's parameters, which is known as the maximum likelihood problem. However, the maximum likelihood problem is generally intractable, and so we instead use a surrogate model to approximate the reward function. One popular choice is the Q-function, which is defined as the expected return of the model's policy starting from a given state, and taking the action with the highest value of the reward function. The Q-function can be easily approximated using Monte Carlo methods, and so it is often used as a surrogate for the reward function in reward learning algorithms. However, the Q-function is not unique, and so multiple Q-functions can be used to represent the same reward function. This is known as the Q-function family, and it is parameterized by a set of Q-tableaux, which are lists of Q-values for all possible states and actions. The Q-tableaux are typically learned using reinforcement learning, and so the Q-function family is also known as Q-learning.

\textbf{Reward Maximization with Policy Optimization}. The maximum likelihood problem can be solved using the method of maximum likelihood estimation (MLE), which involves finding the set of parameters that maximize the likelihood of the observed data. However, the maximum-likelihood problem is generally intractible, and so we instead approximate it using a surrogate model. One popular choice is to use the Q-function family to approximate the reward function, and then use policy optimization to maximize the expected return of the policy starting from a given Q-value. This is known as Q-learning with policy optimization (QLPO), and it is a popular method for reward learning. However, Q-learning with policy optimization is not guaranteed to converge to the optimal policy, and so it is typically initialized with a random policy and then fine-tuned using reinforcement learning. This is known as reinforcement learning with policy optimization (RLPO), and it is an effective way to improve the performance of Q-learning with policy optimization.
