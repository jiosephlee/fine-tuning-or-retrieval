\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a simple reinforcement learning (RL) algorithm for fine-tuning a language model (LM) to align with human preferences. The key idea is to use a reward model to estimate the preference of humans for different model generations, and then optimize the LM to maximize the reward. This is similar to the approach taken in reinforcement learning from human feedback, but instead of using human feedback to train a reward model, we directly optimize the reward model to match the preferences of humans. 

We propose a simple yet effective way to parameterize the reward model, which we call the \textit{direct preference model}. The direct preference model is a neural network that maps a model generation to a scalar value representing the preference of humans for that generation. We show that the direct preference model can be used to solve the standard RL problem for DPO, which is to find the optimal policy given a reward function and a target distribution. We also show that the direct preference optimization objective can be written as a convex optimization problem, which makes it easy to solve using gradient descent. We evaluate DPO on several benchmarks, including sentiment analysis, summarization, and single-turn dialogue. Our experiments show that DPO is able to align LMs with human preferences as well or better than existing methods, while being substantially simpler to train and faster to run. 

\section{Related Work}

\textbf{Language Models.} Large-scale unsupervised language modeling has been a major focus of research in recent years. In particular, GPT-3~\citep{brown2020gpt3} is a 175B parameter language model trained on 175B tokens of text from the web. GPT-3 is able to generate fluent text that is often indistinguishable from human-generated text. However, GPT-3 is not a general-purpose model, and its performance is limited by the size of its training data. To address this limitation, researchers have proposed various methods to finetune GPT-3 with additional data, such as \textit{GPT-3++}~\citep{liu2022gpt3++,liu2023gpt3++}, \textit{Gpt3+}~\citep{xiao2023gpt3+,liu2023gtp3}, and \textit{Globally Optimized Language Model}~\citep{sutskever2023globally}. These methods typically finetune GPT3 with additional data from a few sources, such as Wikipedia, Reddit, and Stack Overflow. While these methods improve the performance of GPT-3, they are still not as powerful as GPT-3 itself.

\textbf{Reinforcement Learning.} Reinforcement learning (RL) is a powerful method for learning to perform tasks in an environment. In RL, an agent interacts with an environment to collect rewards, and uses the rewards to learn a policy that maximizes the expected cumulative reward. The most famous RL algorithm is \textit{Q-learning}, which learns a policy by maximizing the expected return of a reward function. Other popular RL algorithms include \textit{Actor-Critic}~\citep{kirkpatrick2017actor}, \textit{Value-Gradients}~\citep{oord2018value}, and \textit{Turing}~\citep{lillicrap2016turing}. These algorithms are all based on the Q-learning framework, but they have different ways of estimating the value function. For example, \textit{Value-Greens}~\citep{joulin2016value} uses a neural network to approximate the value function, and \textit{Turing}~\cite{liu2018turing} uses a neural network that learns to approximate the optimal policy. While these algorithms are effective, they are often difficult to train and require large amounts of data.

\textbf{Reward Models.} A common problem in RL is how to estimate the value function or the optimal policy. One way to do this is to use a reward function, which is a function that maps an action to a scalar value. The value function or the optimal action can then be estimated by maximizing the expected return over the environment. For example, in \textit{Q-Learning}, the value function is the expected return of a policy, and the optimal policy is the one that maximizes the expected return. Similarly, in \textit{Turing}, the value function is a neural network that learns the optimal policy, and the optimal action is the one that maximized the expected return. However, the value function or the policy can be difficult to estimate in practice. For example, in GPT-3, the value function is estimated by maximizing the expected log-likelihood of the training data, but this is not a valid reward function because it does not take into account the reward of the actions. Therefore, it is important to find a reward function that is valid and easy to estimate.
