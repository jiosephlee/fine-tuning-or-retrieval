The key idea is to use an orthogonal transformation to transform the input image before finetuning. This transforms the gradient of the loss function into a zero vector, which makes the gradient of the loss vanish. The orthogonal transformation is computed using a learned parameterized orthogonal matrix. The paper also proposes a simple variant of OFT called Simple Orthogonal Finetuning, where the orthogonal matrix is learned from the data.
