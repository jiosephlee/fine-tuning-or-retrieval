Direct Preference Optimization (DPO) is a reinforcement learning algorithm that optimizes the reward function directly, without using a policy gradient. This is in contrast to PPO, which uses a policy gradient to optimize the reward function. DPO has been shown to be more efficient than PPO in many settings, but it has not been applied to language modeling. We also demonstrate that DPO can be used to improve the performance of PPO on the RLHF benchmark. We hope that our work will inspire further research on the application of reinforcement learning to language modeling.

Introduction
Reinforcement learning (RL) has been successfully applied to various domains such as robotics (Sutton et al., 1999;Ratcliff et al., 2014), computer vision (Sutton et al. 1999;Kirkpatrick et al., 2017), and natural language processing (NLP) (Schulman et al., 2015;Sutton et al., , 2018. In particular, RL has been shown to be effective in improving the performance of language models (LMs) (Sutton et al.
2018;Liu et al., 2020). However, RL-based LMs have not achieved state-of-the-art performance in the standard language modeling task (Devlin et al., 2019;Liu et al. 2020). This is because the reward function used in RL-based LMs is usually based on the perplexity of the LM, which is not a good proxy for human preferences (Bai et al., 2018;Liu and McCallum, 2019). To address this issue, we propose a novel method for aligning language model preferences with human preferences, Direct Preferences Optimization (DPO). DPO is a reinforcement learning algorithm for optimizing the reward function without using a policy gradient.
DPO is similar to PPO (Schulman et 2020), which is a variant of RLHF (Schulman et   2020). However DPO is different from PPO in several ways. First, DPO uses a reward function that is directly optimized by the algorithm, instead of using a reward function that is estimated from the data. Second, DPO does not use a policy gradient to optimize its reward function. Instead, DPO uses a direct preference gradient, which is a gradient of the reward function with respect to the preference distribution. Third, DPO uses a different loss function from PPO. DPO uses a cross-entropy loss, while PPO uses a mean squared error loss. These differences make DPO more efficient than PPO. For example, DPO can be trained with 1.5 times fewer parameters than PPO. We empirically verify this claim in Section 5.1.
We believe that DPO has several advantages over PPO. First, DPO can be used for training LMs with arbitrary reward functions, while PPO can only be used for training LLMs with reward functions that are estimated from the data. This is important because reward functions that are estimated directly from the data are often better than reward functions that are estimated by an external model. Second, DPO can be applied in a more general setting than PPO. In particular, DPO can be combined with other algorithms, such as gradient descent, to train LMs. This is because DPO does not require any additional training data. Third, DPO can be easily integrated into existing LLM training pipelines, such as the PPO pipeline (Schulman et    2020). This makes DPO more practical than PPO. We believe that these advantages will make DPO a useful tool for training LMs with reward functions that are not estimated from the data.
