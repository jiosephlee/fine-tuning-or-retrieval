Introduction
Language models are widely used in natural language processing (NLP) tasks such as machine translation (Koehn et al., 2003), question answering (Bordes et al., 2013), and text generation (Devlin et al., 2018). However, the effectiveness of language models is limited by their ability to capture human preferences. For example, the current state-of-the-art language models (e.g., BERT (Devlin et al. 2019)) can generate fluent text, but they do not have explicit preferences about the text. Therefore, it is important to find a way to align language models with human preferences.
One approach to align language models with preferences is to use reward models to map language to preferences. A reward model is a model that maps language to a numerical reward value. The reward value can be interpreted as a preference of the language model for the corresponding text. For example, the reward model of the Open Language Model (OLM) (Hendrycks et al., 2021) is a neural network that maps language to a reward value. The reward model is trained to maximize the reward value of the training data. Once the reward model is trained, the language model can be used to generate text that maximizes the reward value. This approach has been successfully applied to many NLP tasks (Hendrycks and Gimpel, 2022;Hendrycks et. al., 2022;Zhang et al., 2022). However, the reward model is a black box, and it is difficult to understand how the reward model works. Therefore, it is crucial to design a reward model that is easy to understand and interpret.
In this paper, we propose a new approach to align language models to preferences, called Direct Preference Optimization (DPPO). The core idea of DPO is to use a reward model to learn a mapping between language and preferences. The reward model is learned from the preferences of humans. The learned mapping can be used to align language models with the preferences of humans. To achieve this goal, DPO uses a reinforcement learning algorithm, called DDPG (Schulman et al., 2017), which is a variant of the well-known DQN algorithm (Mnih et al., 2015). DDPG is a deep reinforcement learning algorithm that uses a Q-learning algorithm to learn a policy that maps language to rewards. The learned policy can be used to generate language that maximizes the reward. In contrast to existing reward models, DDPG uses a reward model to train the policy. This approach enables us to understand how the reward is generated, and it provides a better understanding of the reward model. We also note that DDPG is a general reinforcement learning algorithm, and it can be used to learn a policy that maximizes any objective function. Therefore, DDPG can be used to learn reward models for other tasks, such as image captioning (Wang et al., 2016) and video summarization (Chen et al., 2019).
