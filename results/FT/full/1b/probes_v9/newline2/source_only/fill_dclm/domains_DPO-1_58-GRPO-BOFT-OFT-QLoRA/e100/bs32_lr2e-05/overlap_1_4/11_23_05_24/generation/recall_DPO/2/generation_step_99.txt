1. Introduction

The ability to generate high-quality text is a crucial capability for language models (LMs). However, current LMs, such as GPT-4, have been criticized for their lack of human-like preferences and biases (Bai et al., 2022; Chen et al., 2023; Li et al., 2024; Wang et al., 2025). To address this issue, researchers have proposed methods to align LMs with human preferences, such as RLHF (Henderson et al., 2018; Li et al., , 2022b. These methods typically involve training an RL agent to maximize a reward function that corresponds to human preferences. The RL agent learns to generate text that is preferred by humans, and the reward function is optimized to reflect human preferences. This approach has been successful in improving the quality of LMs (Li et al., 2021a; Li et al., b, 2022b; Wang et al., , 2019. However, the RLHF pipeline has several limitations. First, it requires access to a large dataset of human preferences, which is often not available. Second, the RLHF objective is difficult to optimize directly, and it must be approximated using a surrogate objective. Third, the RLHF objective does not directly correspond to any human preference, and it must be mapped to a reward function before optimization. Fourth, the RLHF objective can be unstable, especially when the number of training samples is small. Fifth, the RLHF pipeline can be computationally expensive, especially for large models.

In this paper, we introduce a novel reinforcement learning algorithm called Direct Preference Optimization (D PO LM), which can be used to optimize a reward function directly without using a policy gradient or a surrogate objective. D PO LM is similar to PPO (Schulman et al., 2017), but it does not use a policy gradient or a reward function approximation. Instead, D PO LM optimizes the reward function using a reward function gradient. This is in stark contrast to the RLHF pipeline, which typically involves optimizing the RLHF objective using a surrogate objective or a policy gradient. D PO LM is a simple yet powerful reinforcement learning algorithm that can be used for a wide range of RL problems, including RLHF.
