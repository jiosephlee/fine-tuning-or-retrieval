1. Introduction
The goal of language modeling is to generate text that is consistent with an input preference profile. This is a challenging task because the preference profile is often incomplete, and the preferences may be inconsistent with each other. To address this challenge, we can use reinforcement learning (RL) to learn a language model that is consistent with the given preference profile. The RLHF pipeline consists of two steps: 1) training a language model using reinforcement learning, and 2) fine-tuning the language model with human feedback to improve its performance on a downstream task.
