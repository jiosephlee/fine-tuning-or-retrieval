Introduction
Large language models (LLMs) have become the de facto standard for natural language processing (NLP) research. They are widely used in text classification, question answering, and other NLP tasks. However, the current state-of-the-art LLMs are still based on FP16, which is a 16-bit floating-point representation. FP16 is a common data type in deep learning, but it has a significant memory footprint and computational cost. For example, the memory footprint of a 12B BERT base model is 1.5 GB, and the memory footprint of a single 12B BERT model is 1.6 GB. This is a significant problem for training large models on mobile devices or low-memory servers.
