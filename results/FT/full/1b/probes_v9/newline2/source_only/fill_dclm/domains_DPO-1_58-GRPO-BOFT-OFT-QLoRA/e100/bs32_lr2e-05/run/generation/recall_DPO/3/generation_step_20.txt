\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a simple reinforcement learning (RL) algorithm for fine-tuning a language model (LM) to align with human preferences. The key idea is to use a reward model to estimate the quality of model generations, and then fine-tune the LM to maximize the reward. This is similar to the approach taken in reinforcement learning from human feedback, but instead of using human feedback to learn a reward function, we directly optimize the reward function to match the human preferences. 

We propose a simple yet effective way to parameterize the reward function, which we call the \textit{direct preference model}. The direct preference model is a neural network that maps a sequence of tokens to a scalar value representing the quality of the corresponding generation. We then use a standard RL algorithm to optimize the direct preference model to maximize the reward. The resulting algorithm, which we name \textit{Direct Preferred Optimization} (DPO) is simple to implement and computationally efficient, and we show that it can be used to fine-tune LMs with high performance. We also demonstrate that DPO can be used to control the sentiment of generations, and to improve the quality of responses in single-turn dialogue.

\section{Related Work}

\textbf{Language Models.} Large-scale unsupervised language modeling has been a major focus of research in recent years. The most popular approach is to train a generative model using a large corpus of unlabeled data, typically by maximizing the likelihood of the data given the model. This approach has been shown to yield powerful language models that can generate fluent text with high quality. However, the training data is often not labeled, making it difficult to evaluate the quality of the generated text. To address this problem, researchers have developed methods for evaluating the quality of language models using human judgments. One common approach is to collect a set of human judgments of the quality of model generations and then fine-tune a pretrained model to maximize the average human judgment. This approach is known as reinforcement learning from human feedback. Another approach is to use a reward function to estimate the quality of a model generation and then fine-tune it to maximize the reward. In this paper, we follow this second approach and use reinforcement learning from human feedback to fine-tune a language model.

\textbf{Reinforcement Learning.} Reinforcement learning (RL) is a class of algorithms for learning to make decisions in an environment. In RL, an agent interacts with an environment and receives rewards for its actions. The goal of the agent is to maximize the total reward over time. The most popular RL algorithms are Q-learning and PPO. Q-learning is a model-based algorithm that uses a policy network to estimate the value of each state-action pair. The policy network is trained using a reward function that estimates the expected total reward for taking an action in a given state. PPO is a model-free algorithm that uses gradient descent to update the policy network. The gradient of the policy network with respect to the policy is used to update the policy. PPO is more efficient than Q-learning, but it requires a large number of samples to converge. In this paper, our goal is to use reinforcement learning to fine-tune a pretrained language model to align with human preferences.

\textbf{Reward Models.} A reward model is a function that maps a sequence of input tokens to a scalar value that represents the quality of the corresponding model generation. The quality of a model generation can be measured in many ways, such as the average human judgment of the generated text, the perplexity of the generated text, or the average sentence length. A common way to construct a reward model is to use a neural network to map a sequence of tokens to an output value. The output value is then used as a reward for the model generation. The most popular neural network for constructing a reward model is the softmax layer, which takes a sequence of input tokens and outputs a vector of scalar values. The softmax layer is commonly used in reinforcement learning to estimate the value of a state-action pair. However, the softmax layer can be unstable, especially when the input sequence is long. To address this problem we propose a simple but effective way to parameterize a softmax layer, which we call the direct preference model. The direct preference model is simply a neural network that takes a sequence of input words and outputs a scalar value representing the preference of the model for the corresponding token. The direct preference model can be easily implemented and is stable, even when the input sequence is very long. We also show that the direct preference model can be used to construct a reward model that is more accurate than the softmax layer.
