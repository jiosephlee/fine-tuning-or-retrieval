2.1 Reinforcement Learning

Reinforcement learning (RL) is a subfield of machine learning that deals with learning to take actions in an environment. In RL, an agent interacts with an environment, taking actions in response to the environment’s state. The agent’s goal is to maximize a reward function, which is a function of its state and action. The reward function is usually complex and difficult to optimize, so RL algorithms typically use a reward model to approximate the reward function. The reward model is usually learned from a dataset of reward pairs, where the reward is given for each state-action pair.

The most common RL algorithm is the actor-critic algorithm, which consists of two components: an actor and a critic. The actor takes the current state as input and outputs an action. The critic takes the current state and the action as input and outputs a reward. The actor and the critic are trained separately, using a stochastic gradient descent method.
