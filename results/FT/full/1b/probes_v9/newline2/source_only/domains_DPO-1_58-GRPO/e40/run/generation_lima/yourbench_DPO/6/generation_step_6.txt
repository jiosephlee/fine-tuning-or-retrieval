A.2 Computational Complexity Analysis
In this section, we provide a detailed analysis of how the three-phase structure of RLHF affects the computational complexity of the problem. We first consider the computational complexity of the direct preference optimization algorithm. The direct preference optimization algorithm is a simple preference learning algorithm that iteratively updates the preference vector by minimizing the difference between the current preference vector and the optimal preference vector. The computational complexity of the direct optimization algorithm is O(n 3 ), where n is the number of preference pairs. We then consider the computational complexity of RLHF. The RLHF algorithm consists of two subproblems: the preference learning subproblem and the preference ranking subproblem. The preference learning subproblem is a standard reinforcement learning problem, which can be solved using the policy gradient method. The computational complexity of this subproblem is O(n 2 ). The preference ranking subproblem is a combinatorial optimization problem, which can be formulated as a maximum weight matching problem. The computational complexity of solving this subproblem is O(mn 2 ), where m is the number of preference rankings and n is the number of preferences. Therefore, the total computational complexity of the RL HF algorithm is O(n 2 + m 2 n 2 ). We provide a detailed analysis in Appendix A.2.
