What fundamental difference in approach allows DPO to achieve similar results as RLHF methods while being simpler to implement?<|EOT|>The fundamental difference between DPO and RLHF is that DPO is a method for estimating the mean of a distribution, whereas RLHF is a method for estimating a single value. The two methods are related, however, because the mean of a distribution is a special case of the value of a single distribution.

In RLHF, you estimate the value of a single random variable $X$ by maximizing the expected return of a policy $\pi$. This is equivalent to minimizing the expected loss of a loss function $\mathcal{L}(\pi, X)$, which is the negative log-likelihood of the data under the policy $\pi$:

\begin{equation}
    \min_{\pi} \mathbb{E}_{x \sim \pi}[\mathcal{L} (\pi, x)]
\end{equation}

This is a standard optimization problem, and there are many algorithms that can be used to solve it. One popular algorithm is the gradient descent method, which iteratively updates the parameters of the policy $\pi$ as follows:

\begin{equations}
    \pi^{(t+1)} = \pi^{(t)} - \alpha \nabla_{\pi} \log \pi^{(t)}
\end{equations}

where $\alpha$ is the learning rate. The gradient of the loss function with respect to the parameters of the policy is given by:

\begin{equatio}
    \nabla_{ \pi} \mathcal{L} ( \pi, x) = \frac{1}{N} \sum_{i=1}^N \nabla_{x_i} \mathcal{D}(\pi, x_i)
\end{equatio}

where $\mathcal{D} (\pi, x)$ is the empirical risk of the policy $\pi$, defined as:

\begin{equatio}
    \mathcal{D}( \pi, x) := \frac{1}{n} \sum_{i = 1}^n \mathbb{I}(x_i = x_i^{\pi})
\end{equatio}
The gradient of the loss function is then:

\begin{equaatio}
    \nablax_{\pi} \, \mathcal{L}( \pi, x)
    = \frac{1 - \alpha}{n} \sum_i \nabla_{ x_i} \mathcal D(\pi, x_i) - \alpha \nablax_{x_i} \, \mathbb{E}_x [\mathcal{L} \mid \pi]
\end{equatio} 

where $\nablax_{x}$ is the gradient of the empirical risk with respect to the parameter $x$. This is the gradient descent update rule for RLHF.

In DPO, you estimate the mean of a distribution by maximizing the expected return under the distribution. This is equivalent to minimizing a different loss function, which is the negative expected log-likelihood of the distribution:

\begin{equatiion}
    \min_{p} \mathbb{P} \left[ \mathbb{E}[X \mid p] \geq y \right]
\end{equation}
where $X$ is a random variable and $y$ is a target value. This is a different optimization problem from the one used in RLHF, and so the gradient of the loss function will be different. In particular, the gradient of the loss with respect to the parameters $p$ is:

\begin{equaitio}
