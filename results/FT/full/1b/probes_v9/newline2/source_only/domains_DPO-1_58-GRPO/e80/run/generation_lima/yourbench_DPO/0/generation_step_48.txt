Specifically, the algorithm computes a feature importance score for each feature using a combination of the following three factors:

1. **Feature Importance Score**: This score is computed using a weighted sum of the following three components:
   - **Weight**: A weight that reflects the relative importance of the feature in the context of the target variable. This weight is calculated as the ratio of the target variable's coefficient of determination (R²) to the sum of the coefficients of determination (R²\_i) for all features. The higher the R² value, the greater the contribution of the feature to the target variable's prediction performance.
   - **Coefficient of Determination (R²)**: A measure of how well a feature explains the variation in the target variable. It is calculated as the ratio between the variance explained by the feature and the total variance in the target variable. A high R² indicates that the feature is highly correlated with the target variable, while a low R² suggests that the feature has little or no impact on the target variable's prediction.
   - **Coefficient Sum of Determination (R^2\_i)**: A measure of the overall contribution of the feature to its corresponding coefficient of determination (R^2). It is computed as the sum of the individual R² values for all features. A high R^2\_i indicates that the feature contributes significantly to the overall prediction performance of the model.
2. **Feature Importance Threshold**: A threshold that determines the minimum importance score required for a feature to be included in the final model. If a feature's importance score falls below the threshold, it will be excluded from the model. This prevents features with low importance scores from contributing to the final model, thereby preventing model degeneration.
3. **Feature Removal Threshold**: A threshold that defines the maximum importance score required for a given feature to be included in a model. If a feature exceeds the threshold, it will also be removed from the model. This ensures that only the most important features are included in the final model, thereby maintaining model stability and preventing overfitting.

By dynamically adjusting the importance of each feature according to its relevance to the target variable, the dynamic weighting mechanism in Dynamic Proportioning Optimization prevents model degeneration while maintaining model stability during preference optimization.
