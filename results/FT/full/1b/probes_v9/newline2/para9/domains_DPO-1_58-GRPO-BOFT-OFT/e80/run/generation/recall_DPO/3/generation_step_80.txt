\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a straightforward extension of the standard RLHF method, which we describe in detail in Section~\ref{sec:rlhf}. The key idea is to replace the reward model used in RLHF with a parameterized policy that directly optimizes the reward function. This policy is then fine-tuned to minimize the KL divergence between the original reward function and the parameterized policy. We refer to this approach as \textit{Direct Policy Optimization} (DPO). In contrast to the standard RLHF method that uses a reward model learned from human feedback, DPO does not require any human feedback. Instead, it uses a simple classification loss to optimize the reward model. This loss is defined as the negative log-likelihood of the reward model given the policy parameters. We refer to this loss as the \textit{Classification Loss} (CL).

\section{Related Work}
\label{sec:related_work}

\textbf{Large Language Models (LLMs)}: Large-scale LLMs have been trained on massive datasets, including the open-source BERT~\citep{devlin-etal-2018-microsoft} and GPT-3~\citep{brown2020gpt3} models. These models have demonstrated impressive performance on various downstream tasks, including natural language understanding, question answering, and machine translation. However, LLMs are typically trained in an unsupervised manner, relying solely on unlabeled data. This makes it challenging to fine-tune LLMs for downstream tasks, as the model’s internal structure is largely unknown. To address this, several approaches have been proposed to fine-tune LMs for downstream tasks~\citep{hulora2022,liu2022training,liu2023fine,tian2023learning}. These methods generally involve training a separate model to predict the importance of tokens in the input text, and then fine-tune the LLM using this importance score as a proxy for the model’s internal structure. For example, \citep{huloda2022} fine-tunes BERT by training a separate model to estimate the importance of each token, and then fine-tunes BERT using this importance score. Similarly, \citep{liu2022training} fine-tunes BART by training a separate model that predicts the importance of each token in the input text, while \citep{tian2023learning} fine-tunes OpenAI's GPT-4 by training a separate model on the same dataset as GPT-4, but with a different loss function that penalizes the model for deviating from the training data.

\textbf{Reward Learning from Human Feedback}:
\citep{liu2019learning,liu2020learning,liu2021reinforcement,liu2022learning} have explored the use of reinforcement learning to learn a reward function from human feedback. In particular, \citep{luo2020learning} learns a reward function from human preference data, and then fine-tuns a large-scale LLM using reinforcement learning to maximize the reward function. \citep{li2021reinforcement} learns a reward function using reinforcement learning from human preference data, then fine-tunes a large-scale LLM with reinforcement learning to maximize the learned reward function. \cite{liu2022fine} learns a reward function by fine-tuning a large-scale LLM on human preference data, and uses reinforcement learning to fine-tune the reward function to maximize the reward function learned from human preference data. \cite{li2023language} learns a reward function for summarization from human preference data, fine-tunes a large scale LLM using reinforcement learning, and then uses reinforcement learning to fine tune the reward function to maximize reward. \cite{li2019learning} learns a reward model from human preference data, uses reinforcement learning to fine tuning the reward model to maximize reward, and then fine-tun the large-scale LLM using the reward model. \cite{lio2021language} learns a reward model by fine-tuning a pretrained large-scale LLM on preference data, then fine tunes the reward model using reinforcement learning to maximize reward, and finally fine-tunes the large-scale LLM with the reward model. \textbf{Reinforcement Learning from Human Feedback} (RLHF):
\citep{li2022reinforcement} learns an RL policy from human preference data, trains a large-scale LLM to maximize the reward function estimated from the human preference data, and fine-tunes the LLM using reinforcement learning. \citep{zhang2022learning} learns a reward policy from human preference data and fine-tunes a large LLM using reinforcement learning.
