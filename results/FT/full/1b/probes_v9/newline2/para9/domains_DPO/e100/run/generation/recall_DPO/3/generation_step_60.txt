\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a variant of reinforcement learning (RL) that uses a reward model to optimize a language model (LM) instead of optimizing a policy directly. The reward model is learned from human preference data, and the goal is to optimize the reward function to maximize the likelihood of the human preferences. This is similar to the approach taken by \textit{PPO} in reinforcement learning (RL), but with a few key differences. First, the reward model is learned from preference data, not from raw rewards. Second, the reward model is used to optimize the LM, not the policy. Third, the reward model is not optimized directly, but rather through a classification loss. This loss is typically a linear combination of the reward function and a regularization term, which encourages the reward function to be smooth and avoid large jumps. The resulting optimization problem is a standard RL problem, but one that is easier to solve than the standard RL problem because the reward function is already known.

\textbf{Main Contributions.} We introduce a new method for training LMs using a reward model. Our method, called \textbf{Direct Preference Optimization} or DPO, is based on the following idea: given a preference dataset $\mathcal{D} = \{x^{(i)}, y^{(i)}\}_{i=1}^N$, where $x^{(i)}$ is a sentence and $y^{(i)}$ represents the human preference for that sentence, we can define a reward function $R(\theta)$ that captures the human preference for a given sentence $\theta$. We then train a language model $\mathcal{M}(\theta)$ to maximize the likelihood of observing the preference data $\mathcal{D}$, i.e., $L(\mathcal{M}, \mathcal{D}) = \mathbb{E}_{x \sim \mathcal{D}}\bigl[\log \mathcal{M}(x)\bigr]$. This is equivalent to maximizing the likelihood of the preference data, but with the additional constraint that the language model $\mathcal M$ is trained to maximize the reward function $R(\mathcal{M})$. This is a standard RL problem that can be solved using any RL algorithm, such as PPO. However, the reward function $R$ is unknown, so we must estimate it from the preference data $\mathbb{E}_{\theta \sim \mathcal M} \bigl[R(\theta)\bigr]$. To do this, we use a simple classification loss, which encourages the reward to be smooth and avoid jumps. This loss is typically defined as $\mathbb{E}_\theta \bigl[R(\mathcal{M}^*(\theta)) - R(\mathcal{M}( \theta))\bigr]$, where $\mathcal{M}( \theta)$ is the language model that maximizes the reward function $R$. This loss is equivalent to the loss used in \textit{Ppo}, but with the reward function $R$, not the policy $\mathcal{M}$, optimized. The resulting optimization problem can be solved using any standard RL algorithm, such as DDPG or PPO. However, since the reward function $R^*$ is unknown, we must estimate it from preference data. We do this by training a separate language model $\mathcal {M}^*$ to maximize the reward function, and then using the reward function $R^{*}$ to train the language model $\mathbb{E}\bigl[\mathcal{M}^\*(\theta) R^*(\theta)\bigr]$, where $R^*$ is the reward function estimated from the preference data. This is a standard RL optimization problem, but one that can be solved using a simple classification loss. The resulting optimization problem, which we call \emph{Direct Preference Optimization}, is equivalent to the standard RL optimization problem, except that the reward function $R^\*$ is estimated from the preference data $\boldsymbol{\mathcal{D}}$. This is a computationally efficient way to train a language model using a reward model, and it is the core of our method.
