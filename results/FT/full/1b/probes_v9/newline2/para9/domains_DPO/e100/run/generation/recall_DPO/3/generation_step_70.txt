\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model for language models (LMs). The reward model is trained to maximize the reward function $R(\theta)$, where $\theta$ is the LM's parameters, and the reward function is defined as the expected log likelihood of the LM given the human preference data $\mathcal{D}$. This is a standard approach to RLHF, but it is not straightforward to optimize the reward function directly. In this paper, we propose a new parameterization of reward functions that allows us to efficiently optimize the reward function using a standard classification loss. We refer to this method as Direct Preference Optimization (DPO). Our experiments show that DPO is stable, performant and computationally lightweight, and outperforms existing methods for fine-tuning LMs to align with user preferences.

\section{Introduction}

Large-scale unsupervised language model (LM) training has led to impressive advances in natural language understanding (e.g., BERT [Devlin et al., 2018], GPT-3 [Brown et al., 2020], and OpenAI's GPT-J [Sutskever et al., 2021]). However, these models are trained on massive unlabeled datasets, and their behavior is difficult to control. For example, it is challenging to fine-tune an LM to align with human preferences, as the model's behavior is largely determined by its internal parameters, which are not directly observable. Existing approaches to aligning language models with human preferences typically involve collecting human preferences for a set of model generations, and fine-tuning the model to maximize the human preference score. This approach is known as reinforcement learning from human feedback, or RLHF. However, RLHF is a challenging problem, as it requires collecting human preferences for a large number of model generations, and then training a policy to maximize the reward function defined by the preferences. This is a complex and often challenging process, as the reward function is typically unknown, and the policy must be learned from the reward function. Furthermore, the reward function is typically defined using a reward model, which is a parametric function that approximates the reward function. The reward model is typically learned using reinforcement learning, and then fine-tuned to maximize the reward function using supervised learning. This process is known as reward model fine-tuning (RMFT), and it is the standard approach to RLHF. However, the reward model is typically learned from a small number of human preferences, and the reward function itself is typically unknown. Therefore, the reward model is often a poor approximation of the true reward function, and the reward function must be optimized using a complex optimization procedure. In this paper, our goal is to develop a method for fine-tuning language models to align with human preferences that is simple, efficient, and effective.

In this paper, we propose Direct Preference Optimization (D PO), a method for fine-tunning language models to align with user preferences. DPO is based on a simple idea: instead of optimizing the reward function using reinforcement learning, we can optimize the reward function using supervised classification. Specifically, we define a reward function $R(\mathbf{\theta})$ that is a linear combination of the log likelihood of the human preference data $\text{log} \mathcal{D}(\mathbf{\theta}, \mathcal{D})$, and the probability of the preferred model $\mathbf{p}(\mathbf{\hat{\theta}}| \mathcal{D}).$ We refer to this reward function as the preference score function. We then define a classification loss that minimizes the preference score function, and train the language model to minimize this loss. This loss is equivalent to maximizing the expected log likelihood of human preference data $\textbf{log} \mathbf{D}(\mathcal{L}(\mathbf{\pi}, \mathcal{X}), \mathcal{D}),$ where $\mathcal{L}()$ is a loss function that measures the quality of the generated text, and $\mathcal{X}$ is the set of human preference data. This loss is a standard classification loss, and it can be optimized using standard methods such as gradient descent. We refer to this loss as the preference score loss. Our main contribution is a method for optimizing the preference score function using the preference score loss. We then define a loss that minimizes the linear combination of the preference score and the probability of the preference model, and show that this loss is equivalent to the preference score loss. This loss can be optimized using gradient descent, and it is equivalent to the standard reward model fine-tuning loss.
