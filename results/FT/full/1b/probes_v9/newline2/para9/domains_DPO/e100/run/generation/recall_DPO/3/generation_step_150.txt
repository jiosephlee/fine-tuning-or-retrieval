\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model-free reinforcement learning (RL) method for training language models to align with human preferences. Existing methods for obtaining such preferences typically involve collecting human judgments of the relative quality of multiple model outputs, and fine-tuning the language model to maximize the average reward obtained by humans. This approach is known as reinforcement learning from human feedback, or RLHF. In this paper, we propose a new method for optimizing the reward function in RLHF, called Direct Preference Optimization (DPO). Our method is based on a simple yet powerful idea: instead of optimizing the reward function directly, we optimize a proxy function that is easier to optimize, and then use a standard optimization technique to find the optimal reward function. We show that this approach can be used to solve the standard RL problem for the reward function, and derive an efficient algorithm that optimizes the proxy function using a standard supervised learning objective. We evaluate DPO on several tasks involving sentiment analysis, summarization, and single-turn dialogue, and show that it can achieve performance comparable to or better than existing methods that optimize the reward function using reinforcement learning. \section{Introduction}
Large language models (LLMs) trained on massive datasets have achieved impressive results in many NLP tasks, including machine translation, question answering, and summarization. However, these models are trained using a completely unsupervised learning paradigm, meaning that they learn from unlabeled data without any human supervision. While this approach has proven successful, it comes with several challenges. First, the models are extremely large, and training them on existing hardware can take days or weeks. Second, the models are not easily controlled, since they are trained using an unsupervised learning objective that is difficult to optimize. Third, the models are not easy to interpret, since they are trained on a large amount of text that is not necessarily aligned with human preferences. These issues make it difficult to use LLMs in practical applications, such as guiding search engines to provide more relevant results, or helping people find the information they are looking for in a large body of text. In this paper, our goal is to develop methods for controlling the behavior of LLMs, so that they can be used in practical applications. To this end, we focus on the task of training LLMs to align with human preferences, which is known as reinforcement learning with human feedback (RLHF). In RLHF, the goal is to train an LLM to maximize the average reward that it receives from a human annotator. This reward function is learned using reinforcement learning, but the reward is optimized without explicitly modeling the underlying policy that the LLM should optimize. Instead, the reward function is optimized using a proxy function that is simpler to optimize, and then the optimal reward function is found using standard optimization techniques. This approach is similar to the one used in previous studies that optimize the reward function in RL, such as \cite{li2020learning}. However, previous methods optimize the reward function using a reinforcement learning objective, while we optimize the reward function using supervised learning. This change allows us to use a much simpler objective, and also enables us to use a more powerful optimization algorithm, which we demonstrate empirically in our experiments. Our main contribution is a new method for optimizing reward functions in RLHF, called DPO. Our method is based on the observation that the reward function can be expressed as a linear combination of a set of features, each of which is a function of the language model's parameters. We show that the optimal reward function can be expressed in terms of these features, and that the optimal reward function is a linear combination of these features. We then define a new objective that is a weighted sum of these features, and show that this objective can be optimized using a standard supervised learning algorithm. We refer to this objective as the preference score, and demonstrate that it can be used to train an LLM policy to align with human preferences using a straightforward supervised learning objective. Our experiments show that DPO is able to optimize the preference score as efficiently as previous methods that optimize the reward directly, while being simpler to implement and train. In particular, we evaluate DPO on several NLP tasks, including sentiment analysis, summarization and single-turn dialog, and show that it is able to achieve performance comparable to or superior to existing methods that optimize the rewards using reinforcement learning.
