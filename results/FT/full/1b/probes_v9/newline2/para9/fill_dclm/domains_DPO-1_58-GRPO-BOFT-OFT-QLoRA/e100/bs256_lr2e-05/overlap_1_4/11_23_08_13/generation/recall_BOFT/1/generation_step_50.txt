For instance, consider a simple linear regression model with one input feature and one output variable. Here, there are two parameters - one weight matrix and one bias term. Now, onto orthogonal finetuning. Orthogonal finetuning involves fine-tuning a pretrained model using a new set of weights derived from a different model. These newly generated weights are orthogonal to the initial weights, hence the name. By doing so, the model learns new features while preserving its existing structure. As a result, orthogonal finetuning often leads to improved generalization capabilities compared to standard finetuning techniques.
