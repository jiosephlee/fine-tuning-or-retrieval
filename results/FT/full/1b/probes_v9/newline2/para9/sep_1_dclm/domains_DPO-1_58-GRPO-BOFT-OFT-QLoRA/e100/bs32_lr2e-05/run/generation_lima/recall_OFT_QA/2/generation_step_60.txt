What is Orthogonal Finetuning (OFT)?<|EOT|>OFT is a method for fine-tuning convolutional neural networks (CNNs) that maintains the geometric structure of the original network. It does this by adding a set of orthogonal matrices to the weights of the network, which are then used to transform the weights into a new set of orthogonal matrices. This process is repeated until the desired level of fine-tuning is achieved. The resulting network has the same geometric structure as the original network, but with different weights. OFT is particularly useful for preserving the geometry of neurons, which is important for tasks such as text-to-image generation and object detection. In this paper, we present a new variant of OFT called Orthogonal Finetuning with Orthogonalization (OFTO). Unlike standard OFT, OFTO uses a single orthogonal matrix to transform the weights, rather than a separate set of orthogonal matrices. We show that OFTO can be used to control the diffusion of text-to-image diffusion models, which are widely used for generating realistic images from text descriptions. Specifically, we demonstrate that OFTO can be applied to control the diffusion of the text-to-image diffusion model DINO, which is trained on the ImageNet dataset. Our experiments show that OFTO can effectively control the diffusion of DINO, leading to improved results in text-to-image generation tasks.<|endoftext|>
