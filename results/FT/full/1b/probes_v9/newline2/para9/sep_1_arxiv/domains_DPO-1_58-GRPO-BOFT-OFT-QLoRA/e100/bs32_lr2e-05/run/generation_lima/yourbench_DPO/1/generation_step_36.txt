$$\mathcal{L} = -\frac{1}{N}\sum_{i=1}^N \log \hat{y}_i = -\frac{y_i}{N} \log \hat{p}_i$$

where $y_i$ is the true label and $\hat{p}_i$ is the predicted probability of the true label. The cross-entropy is a good loss function for classification problems because it encourages the model to assign high probabilities to the correct class and low probabilities to the incorrect class. However, this loss function is not suitable for regression problems. For regression problems, we want the model to assign high probability to the correct value and low probability to the incorrect value. This is because the cross-entropy loss encourages the model to assign a high probability to the correct answer, but it does not penalize the model for assigning a high probability to an incorrect answer. This can lead to overfitting, where the model assigns a high probability to the wrong answer.

To address this issue, we can use the mean squared error loss instead of the cross-entropy loss. The mean squared error loss is defined as:

\begin{equation}
    \mathcal{L}^2 = \frac{1}{N} \sum_{i=1, i \neq j}^N (y_i - \hat{y}_j)^2
\end{equation}

This loss function encourages the model to assign low probabilities to the incorrect answers and high probabilities to the correct answers. This is because the mean squared error loss penalizes the model for assigning a large difference between the true and predicted values. This loss function is also known as the mean squared error loss or the mean squared error criterion.
