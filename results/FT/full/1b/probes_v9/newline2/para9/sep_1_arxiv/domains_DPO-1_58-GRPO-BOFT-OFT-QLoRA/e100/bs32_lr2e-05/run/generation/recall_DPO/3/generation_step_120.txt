\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model that is optimized directly for the task of preference alignment, rather than for maximizing the reward function itself. This is achieved by optimizing the reward model to minimize the KL-divergence between the reward function and a reference reward function, which is then used to optimize the LM. The KL-divergence is minimized using a standard cross-entropy loss, which is then optimized using reinforcement learning. This approach is similar to the method of \cite{liu2022learning}, but differs in that the KL-divergence is optimized directly for the purpose of preference alignment, rather that for maximizing the reward function.

\section{Related Work}

\textbf{Language Models}. Large-scale unsupervised language modeling has been shown to be effective at capturing generalizable knowledge and reasoning skills \citep{hendrycks2016generalized,liu2022learning}. However, it is challenging to control the behavior of these models, especially when they are trained on large amounts of text data. This is because the training data is not explicitly labeled with the desired behavior, and the models are trained to maximize the likelihood of the data given their parameters. This makes it difficult to fine-tune the models to achieve specific behaviors, as the model will tend to optimize for maximizing the likelihood of the data, even if this does not align with the desired behavior. This is especially true for large models, which have many parameters and are therefore more likely to optimize for maximizing the data likelihood.

\textbf{Reinforcement Learning}. Reinforcement learning (RL) is a method for learning to make decisions in an environment by interacting with it and receiving rewards for good behavior and punishments for bad behavior. It is commonly used to train agents to perform tasks in environments where the agent does not have access to a reward function. One common approach to RL is to use a reward model to estimate the reward function for the task, and then use reinforcement learning to optimize the agent to maximize the reward function. This is known as reinforcement learning from human feedback, or RLHF. The main challenge with RLHF is that it requires collecting human feedback about the reward function, which is often difficult or impossible to do. Additionally, the reward model must be carefully tuned to ensure that the reward function is accurately estimated, which can be computationally expensive.

\textbf{Reward Model Optimization}. A common approach to RLHF is to use a reward function that is optimized for the task, and use reinforcement learning to optimize a separate reward model to maximize the reward function estimated from the reward model. This is known as reward model optimization, and is typically done using reinforcement learning from human feedback. The reward model is optimized to minimize the KL-diverge between the reward function and the reward model, which is then used as the reward function for reinforcement learning. This approach has been shown to be successful in many applications, including controlling the behavior of language models \citep{liu2022reinforcement,liu2023training,liu2023reward,liu2023learning}, but it can be computationally expensive and difficult to tune.

\textbf{Direct Preference Optimization}. Direct Preference Optimization (DPO), introduced in this paper, is a new method for RLHF that does not require the use of a reward model. Instead, DPO uses a reward function that is directly optimized for the task of preference learning. This is achieved by minimizing the KL-divergence of the reward function and a baseline reward function, which is used to optimize the LM using reinforcement learning. This allows DPO to be much simpler and more efficient than traditional reward model optimization approaches, while still achieving comparable results. In addition, DPO can be used to fine-tune LMs without requiring any additional training data, making it particularly useful for applications where collecting human feedback is difficult or impossible.

\subsection{Problem Formulation}

We consider the standard RLHF setting, where the goal is to train a language model $M$ to produce text that is preferred by humans. The reward function $R$ is defined as the difference between the probability of the text produced by $M$ and the probability of the text generated by a baseline model $B$. The objective is to minimize the KL-diversity between $R$ and $B$, which is defined as:

\begin{equation}
    \mathcal{D}_{KL}(R||B) = \mathbb{E}_{x \sim \mathcal{D}}\left[ \log \frac{P(M(x))}{P(B(x))} \right],
\end{equation}

\begin {equation}
