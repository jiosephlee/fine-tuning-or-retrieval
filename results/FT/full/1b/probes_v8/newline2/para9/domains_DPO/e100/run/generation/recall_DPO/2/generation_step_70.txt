Introduction
The field of machine translation has made significant progress in recent years, with the development of large-scale neural machine translation systems (LMs) that can translate between natural languages with high quality (Lewis et al., 2018;Peters et al., 2017;Sutskever et al., 2014). However, LMs are not perfect, and they often fail to meet the expectations of human users. For example, when translating from English to Spanish, an LLM may produce a translation that is fluent but not idiomatic, or that contains errors such as typos or grammatical mistakes. In this paper, we focus on the problem of aligning language models with user preferences, and propose a method for training language models to meet human preferences. Our approach is based on a reward model that captures the preferences of human users. The reward model is learned from human preferences using reinforcement learning, and the language model that maximizes this reward is trained using reinforcement learning. This approach is distinct from previous methods that optimize the language model directly, or that use a pre-trained language model as a baseline and fine-tune it to improve human preferences (Chen et al., 2020;Gao et al., 2022;Kulkarni et al., 2023;Wu et al., 2021;Zhang et al., 2024). Our approach is also different from methods that use a preference model to guide the training of a language model (Bai et al., 2025;Chen et al., , 2022, which typically use supervised learning to train a model that predicts the preference of a given input-output pair. Our reward model is learned from the preference data itself, without relying on any supervised learning.
Our approach is based on a simple yet effective framework for training language models to match human preferences. The basic idea is to use a reward model to define a reward function r(θ) that measures the human preference for a particular language model θ. We then train a language model to maximize the reward r(θ) using reinforcement learning, which is equivalent to minimizing the loss L(r(θ), π(θ)|X, y) where π(θ) is the distribution of the language model given the input x and the observed reward r(θ, x). This loss is defined as the negative log-likelihood of the data under the policy π(θ), which is equivalent to maximizing the likelihood of the data under the assumption that the language model follows the true reward function r(θ). This is a standard approach in reinforcement learning, and it is known as the value function approximation method (Hoffman et al., 2011;Schulman et al., 2009). In the context of language models, the reward function r(θ), which is learned from preference data, is a function of the language model θ, and the true reward function r(x; θ) is unknown. We assume that the reward function r(x;θ) is a linear transformation of the true reward function r x (θ), where r x (θ) is a fixed reward function that is independent of x. This assumption is reasonable in many practical scenarios, since the reward function is typically learned from a small number of preference pairs (e.g., 100 pairs in this paper). Under this assumption, the reward function r(x, θ) can be expressed as r(x, θ)=r x (θ) + b, where b is a bias term. The optimization objective then becomes: argmax θ r(x, θ)L(r(x, θ); π(θ)) = argmax θ r x (θ) +b − L(r(x, θ), π(θ)|x).
