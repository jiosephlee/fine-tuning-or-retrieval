1 Introduction

Policies learned from reinforcement learning (RL) are widely used to solve complex problems in robotics, computer vision, and natural language processing. However, RL algorithms typically require access to a reward function, which specifies the expected return of a policy for each possible state-action pair. In many real-world applications, it is difficult or impossible to obtain a reward function directly. Instead, we can collect a dataset of states and corresponding actions, and then use this dataset to train a policy. However, the resulting policy may not generalize well to unseen states, and it may not optimize the true reward function. In this paper, we investigate how to train policies using rewards that can only be learned from data, without access to the underlying reward function.

Our approach is based on the observation that any reward function can be expressed as a linear combination of a set of actions. For example, consider a reward function that depends on the action sequence \(\mathbf{a} = \mathbf{a}_1, \ldots, \mathbf{a}_{\mathit{max}}\), where \(\mathbf{b} = \mathbf{x}_1, \ldotc{a}_\mathit{max}, \ldots, \matf{x}_\mathit{N}\) represents the sequence of observations collected from a policy. We can express the reward function as

\begin{equation}\label{eq:reward}
R(\mathbf{a}; \mathbf{x}) = \beta_0 + \beta_1 \mathbf{b}^\top \mathbf{a},
\end{equation}

where \(\beta_0\) and \(\beta_1\) are parameters to be learned. This reward function is a linear combination of actions and is therefore amenable to optimization using standard RL algorithms. In particular, we can use a policy gradient method to learn the parameters \(\beta_0, \beta_1\). The resulting policy will optimize the reward function defined in Eq. 1, and it will also optimize the true reward function if the dataset is large enough. However, the reward function defined in Eq. 1 is not necessarily the optimal reward function for the task. In some cases, it may be possible to find a better reward function by modifying the coefficients \(\beta_0,\beta_1\). This is the approach taken by previous works such as Bai et al. (2015); Mnih et al. (2005); Silver et al. (2020); and is the basis for our method.

In this paper, we present a general framework for training a policy using rewards that can be derived from data. Our method is based on the observation that any reward function can be represented as a weighted sum of actions. We can use a policy gradient algorithm to learn the weights, and we can use the learned weights to optimize the reward function. We demonstrate the effectiveness of our method on several tasks, including Atari games and robotic manipulation. Our code is available online.
