\title{Direct Preference Optimization: Your Language Model is Secretly a Reward Model}

\begin{abstract}
While large-scale unsupervised language models (LMs) learn broad world knowledge and some reasoning skills, achieving precise control of their behavior is difficult due to the completely unsupervised nature of their training.
Existing methods for gaining such steerability collect human labels of the relative quality of model generations and fine-tune the unsupervised LM to align with these preferences, often with reinforcement learning from human feedback (RLHF).
However, RLHF is a complex and often unstable procedure, first fitting a reward model that reflects the human preferences, and then fine-tuning the large unsupervised LM using reinforcement learning to maximize this estimated reward without drifting too far from the original model.
In this paper we introduce a new parameterization of the reward model in RLHF that enables extraction of the corresponding optimal policy in closed form, allowing us to solve the standard RLHF problem with only a simple classification loss.
The resulting algorithm, which we call \textit{Direct Preference Optimization} (DPO), is stable, performant, and computationally lightweight, eliminating the need for sampling from the LM during fine-tuning or performing significant hyperparameter tuning.
Our experiments show that DPO can fine-tune LMs to align with human preferences as well as or better than existing methods. Notably, fine-tuning with DPO exceeds PPO-based RLHF in ability to control sentiment of generations, and matches or improves response quality in summarization and single-turn dialogue while being substantially simpler to implement and train.
\end{abstract}

\end{abstract}

Direct Preference Optimization (DPO) is essentially a reward model-free reinforcement learning (RL) method for language model fine-tuning. 
It takes an unsupervised language model and a set of preference labels, and optimizes the language model to maximize the reward derived from the preference labels while staying within a specified loss budget.
This reward model is learned by maximizing the likelihood of the preference labels under the language model's distribution, which is equivalent to maximizing the likelihood of the labels under the language model’s posterior distribution.
This approach is similar to the widely used reward learning framework of \cite{li2020reinforcement}, but differs in two key ways.
First, \cite{li2021reinforcement} optimize a fixed reward function, whereas DPO learns a reward function that is optimized to match the preference labels.
Second, \cite{li2019reinforcement} optimize the reward function using reinforcement learning, while DPO uses a classification loss to learn the reward function directly from preference labels.
We will show that the reward function learned by DPO is identical to the one learned by \cite{li2017reinforcement} using a different optimization strategy, and that the reward function learned in \cite{li2022learning} using a similar approach to DPO also matches the reward function learned by \cite{lin2022training} using reinforcement learning.
This equivalence allows us to leverage the extensive body of work on reward learning in the reinforcement learning community, including theoretical guarantees and efficient algorithms for large-scale problems.
We demonstrate that DPO can be applied to a wide range of tasks, including sentiment analysis, summarization, and single-turn dialogue, and outperforms existing methods on all of these tasks.

\section{Related Work}
Large-scale unsupervised language model fine-tuning has become a central focus of research in natural language understanding (see \cite{brown2020language} for a review). While these models learn impressive capabilities, they are trained using only unlabeled data, making them difficult to control and fine-tune for specific tasks.
In this section, we discuss existing approaches for fine-tuning language models for specific tasks, focusing on methods that optimize a reward function to steer the language model towards a desired behavior.

\textbf{Reward Learning.} The idea of using a reward function to steer a language model towards a specific behavior is not new; \cite{schulman2017formal} proposed a framework for learning a reward function from human preferences, and \cite{li2018reinforcement} used reinforcement learning to learn a reward function from a sequence of rewards and punishments. These methods optimize a reward function that is different from the one used in DPO, but the underlying principle is the same: a reward function is learned from human preferences, and the language model is fine-tuned to maximize the reward function while staying within a specified budget.
\cite{li2020reward} extended this framework to optimize a reward function that matches the distribution of the preference labels, and \cite{lin2021learning} used reinforcement learning to optimize a reward function derived from the language model's posterior distribution. We will show that the reward functions learned by \cite{schulmann2017formal} and \cite{li2028reinforcement} are identical to the reward function learned by our method, using a different optimization strategy.

\textbf{Reinforcement Learning for Language Modeling.} Several recent works have applied reinforcement learning to language modeling, using either supervised or unsupervised training. \cite{yan2022training} fine-tune a language model using supervised learning, optimizing the reward function to match the distribution of the preference label. \cite{wang2022learning} use reinforcement learning to optimize a language model's reward function, but their approach is distinct from ours in that they optimize a reward function that does not match the language model's posterior, and they do not optimize the reward function to stay within a specified loss budget. \cite{chen2022training} optimize a reward function that maximizes the likelihood of the preference label, but their approach is also distinct from ours in that it does not optimize the reward function within a specified loss budget.

\textbf{Sentiment Analysis.} Sentiment analysis is a well-studied task in natural language understanding, and several methods have been developed for fine-tuning language model outputs to align with human sentiment judgments. \cite{tay2020language} fine-tune a pretrained language model using a supervised learning approach, optimizing the reward function that matches the sentiment distribution of the preference labels. \cite{wei2021training} use reinforcement learning to fine-tune a language models using a reward function that matches a sentiment distribution, but their approach is different from ours in that they do not optimize the language model within a specified loss budget, and they do not use a reward function that matches an unknown distribution. \cite{wang et al.2022} optimize a reward function derived directly from the language model's distribution to align with human sentiment, but their approach is similar to ours
