After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new model for language models, called DPO. The basic idea is to use a reward model instead of a normal distribution to train the language model. The reward model is defined as a function of the sequence of words and the final word in the sequence, called the completion. For example, in the completion "Who did you buy it from?" "relative" is a good word in the completion of "This is the sentence a reward model would estimate for the word 'relative' at the index ..." The paper compares DPO with several other models, such as PPO, LPE, and DPO-NGO. I find the experimental results quite surprising, so I want to explain in this post how DPO works and why it produces a reward function with unusual properties.

The DPO model

The DPO model is based on the policy gradient method. You may recall from an earlier post that the policy gradient method is a way to improve the parameters of a policy network using gradients with a negative sign. In the case of language models, the policy network is the language model itself. We can train the language model in such a way that it produces the gradients with a negative sign that we need to improve the policy network.

In the DPO model, the policy network outputs a probability distribution over the next words in the sequence, given the current word and the ending word of the sequence. The policy network is a standard language model network with one extra layer at the end. The final layer produces a probability for each word in the sequence as an output. The probability for the nth word in the sequence is defined as:

\[ p_{\text{DPO}}(n|S_1, S_2, W) = \sum_{S_2\in\mathcal{S}}\sum_{W out\in\mathcal W} \exp\left(\beta^W \sum_{S_1\in\mathcal S_1} (W^{S_1, W} O)(S_2)\right) \]

Here are the definitions for the functions in the equation:

\[ W^{S_1, \text{W}} = \sigma(W^\text{S_1, \omega}) \]

\[ O(S_2) = \frac 1{e^S + 1} \sum_{w} W^S w \]

The symbol \(\beta_W\) represents a vector of parameters for the reward function \(W\). The paper defines the reward function as:

\[ \beta_W (S_2 - S_1) + \alpha \]

where \(\alpha\) is a small number to avoid numerical issues. The first term in the reward function is the difference between the final and initial states, scaled by a parameter \(\beta_W\). This term encourages the policy to be efficient, by taking the shortest paths from the initial state to the completion. The second term, \(\alpha\) is just a scaling factor.

The equation for \((S_1, W)^{S_1, W}\) is the logistic function with a scaling parameter \(\beta_W\) applied to the last part of the input sequence \(W\) (recall that \(W = (W^S, S)\) for \(S\). The paper argues that this multi-layered model that is sensitive to the entire final sequence, rather than just the last word, is key to the behavior of the DPO model.

The paper compares several models for the reward function \(\beta_W\), including a constant reward model, a model that uses the frequency of word pairs in the corpus as a starting point, and a model that uses a neural network with input \(W\) and output probability density. The best performing model using a neural network reward function is:

\[ \beta_W = (1.76 + 0.7 \beta_ head)(1 + 0.05 \beta_n)^{head+n} \]

where \(\beta_1, \beta_2, \ldots, \beta_n\) are the layers in the neural network. The best performance of this model came from a network with 6 layers.

Why does DPO work?

The authors argue that the key to the success of the DPO model is the addition of the final logistic layer to the reward function. Without this final layer, the policy will simply return the sequence of probabilities for the words in the sequence, which may not be a good estimate of the likelihood of the correct completion. The logistic function scales these probabilities to 0 and 1, making the policy more efficient, and giving the overall reward a direction that encourages taking the shortest paths from start to finish.

Can we implement DPO?

It's not too difficult to implement a reward model that uses the logistic function with a final logistic layer.
