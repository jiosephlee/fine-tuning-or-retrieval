After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new model for language models, called DPO. The basic idea of DPO is to use a reward model instead of a state transition model. The reward model represents the user's preferences as a reward function $r : \mathcal{D} \times \mathcal{D}_{output} \to \mathbb{R}$. The goal of the model is to guess the next word $w_{t+1}$  in the sequence $w_1,w_2,\ldots,w_t$  with the highest reward. In practice, we can use a LShM to generate the sequence $\mathcal{D}=\mathcal{D}^*_w = \mathcal{D}_w \times \mathcal{T}_w$ where $\mathcal{D}_u$ and $\mathcal{D}_{-u}$ are the training sets for model $u$ and $-u$, and $\mathcal{T}_w $ is the language model $L_w$ on sequence $\mathcal{ D}_w$. We assume that $\mathcal{D}$ is the union of the training sets for all models $u$.

The paper first transforms the language modeling problem into an optimization problem with the following objective:

maximize $\sum_{t=1}^T r(w_t, w_{t+1})$
subject to $\mathcal{D}(w) \in \mathcal{D}$ for all $w$

Here $\mathcal{D}-\bigcup_{u}\mathcal{D}_-u$ is a reward hypercube around the reward of the optimal word sequence which is defined later in the paper. The reward function is defined as:

$ r(w_{t},w_{t+1}) = \sum_{d\in \mathcal{ D}_u} [1 - p] + [p - \log[L_w(d,w_{t+1})]] $

The paper proposes a way to optimize the function above using dynamic programming. First, we define a new reward function $R_u$ for model $u$ on any dataset of size $d$ as:

$ R_u(d,w_{t+ 1}) = \max_{w'} \sum_{t=1 t < T} [1 - p ] + [p - \ln[L_w(d,w')]] $

With this definition, the reward maximization problem in the previous section becomes a problem of finding the maximum of the function $R_u over all models $u$ and over training sequences of length $t$. The reason for this transformation will be clear later in the paper.

After transforming the reward maximization problem, the paper proposes a way to maximize the reward using a RL algorithm. First, they "remove" the constraint $w_t \in \mathcal {D}$ for all $t$ from the optimization problem. Then, they define the reward hypercube as:

$ \mathcal{C} = \bigcup_{u} [\min(R_u, K_u)] $ where $K_u$ is the knowledge base of model $u$

Finally, the reward function $R_u(d,w_{t + 1})$ is modified to:

$ R_u(d, w_{t+ 1} = w_{t+1} | w_1 = d, w_2 = w_{t+ 2} = l)$

where $l$ is the first word in the training dataset of size $d$. With this modification, the reward function $r$ in the objective function in equation (1) is replaced by $R_u(d,w_1,w_t)$ for the first $t$ words. This transformation "shrink-wraps" the reward function inside the model's knowledge base, making it possible to use a off-the-shelf RL algorithm. The authors use a policy gradient algorithm with a squared loss on the expected reward of the final model as the objective. The paper shows that this algorithm runs in time $O(TN)$ where $N$ is the number of episodes and $T$ is the training set size. The algorithm runs as follows:

1. Sample a policy $\pi$ from the knowledge base $K_u$ for all models $u$
2. For each step $t$ do:
a. Generate word sequence $w_t = \pi(d_t)$
b. Evaluate reward $R_u(d_t, w_{t + 1} = w_t | d_t)$
