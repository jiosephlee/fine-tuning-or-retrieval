--- GENERATION ---
After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new model for language models, called DPO. The basic idea is to use a reward model instead of a normal model. The reward model represents the user's preferences by a reward function $r:\mathcal{D} \to \mathbb{R}$, where $\mathcal{D} is the training dataset. The goal of the model training is to construct a language model $p(\text{text} | \text{teacher-reward})$ that maximizes the likelihood of the data given the model, and produces the answer to the query text $text$ with highest possible reward. The authors claim that their model outperforms previous models on several datasets. In this blog post, I want to explain the main ideas behind the DPO model. I'll focus on the mathematical background and the challenges the authors had to overcome when designing the model.

The reward model
Consider the task of machine translation. We have a training dataset $\mathcal{D}_i = \bigl\{x^{(i)}, y_w^{(i)}, y_l^{(i)}\bigr\}_{i=1}^N$ for many languages $w, l$ and many translations $x^{(i)} \to y_w^{(i)} \sim \mathcal{M}$ from $\mathcal{M}$. Our model has to learn the relationship between text $x$ and translated text $y$. A naive approach would be to learn a parameter $p(y|x)$. However, this model is impossible to optimize, since $p$ would have to solve the infinite horizon expected reward problem: \begin{equation} \label{eq:rewardproblem}
\text{maximize}\quad \sum_{x} r(x, y) \quad \text{subject to}\quad p(x | y = x^*) \mathbb{1}_x(\text{translation to self is head of in dataset}) \end{equation} The term $\mathbb{1}_X$ is the indicator function for set $X$. The reward function $r$ used in DPO is called a preference model and it has the property that a translation with high reward also maximizes the probability. Formally, a reward function $r$ is transitive, irreflexive and has a maximum. An example of a reward function is $r(x, y) = \log \frac{p(y|x)}{p(y)}$ if $\mathcal{M}=NLP$ and $y$ is a sentence containing exactly $x$'s letters in reverse order. Not all preference models can be used as reward models in (1). After some algebra, it can be shown that the only preference models that work are the so-called strict weak orders, i.e. $r(x, y)\leq r(x, y')$ if and only if $p(y|x) \geq p(y'x|x)$ for all $x, y', y''$. The logarithm is a weak order, but it turns out that the reward function $\log \frac{p(x, y)}{p(x, y')}$ is a strict weak order for all $\mathcal{M}$, if we require $p(x, x')\geq 0.5$ for all $x, x'$. This requirement is not important for the DPO paper, because they only use the positive parts of the probability distributions, i.e. $p(x, y)\mathbb{1}_xy$.

Direct preference optimization
The DPO model optimizes the following objective: \begin{equations*} \label{eq:DPO_objective}
\max_{p(y|x)} \sum_{x}r(x, y) - \beta \log p(x, y), \end{equations*} where $\beta > 0$ is a tradeoff parameter. Intuitively, the term $\beta \log p(x,y)$ reduces the importance of very small rewards, because for very small $\beta$ the term is almost not included in the objective. The term $\sum_{x}r(\cdot, y)$ is the expected reward given model $x$, i.e. we reward the models for their predictions with the given reward model $r$. The model with the maximum objective (1) or (2) will be called DPO-model. The DPO-model with best paper published so far has $\beta = 0.99$ and has been implemented as an open source library.

Why would we want to optimize a different model than the usual maximum likelihood model? The main reason is that the maximum likelihood model optimizes the negative log-likelihood, which favors long texts, and the expected reward does not have this property. With very small rewards very few words are preferred, which results in long texts. The DPO-model also favors short texts, but the reward is never lower than the reward of the maximum likelihood
