After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new model for language models, called DPO. The basic idea of DPO is to use a reward model instead of a state transition model. The reward model represents the user's preferences as a reward function $r : \mathcal{D} \times \mathcal{S} \to \mathbb{R}$, where $\mathcal{D}$ is the training dataset and $\mathcal{S}$ is the set of possible tasks the model might be asked to perform. The reward model is trained alongside the language model, in a cross-entropy loss: $\mathbb{E}_{p(\mathcal{D}, \mathcal{S}|\text{exp})} \left[ l(\mathcal{M}^\text{exp} ; d, s) - l(\mathcal{ M} ; d,s) \right]$, where $\mathcal{M}$ is the language model we want to train, $\mathcal{D} is the dataset of examples $\mathcal{S} = \{d_1, \ldots, d_n\}$ is the set of tasks, and $\mathbb{E}$ is the expected over the distribution $p(\mathcal{S}| \text{exp})$. In other words, the language model learns to perform tasks by optimizing the reward function, rather than by optimizing a loss function directly.

The authors of the paper then ask the question: can we use the same reward function $r$ to train two different language models, with the same performance on a test dataset, but with half the training time? The answer is yes, if we modify the reward function as $r_{\text{new}}(d,s) = r(d,s) - \text{max} \{0, -l(\mathcal{M},s) \}$, where $l$ is the loss function we are using to train $\mathcal{M}$ (for instance, the cross-entropy loss). Intuitively, the modified reward function rewards models that perform well on mistakes made by the reward model. Let's call the two reward models $r$ and $r_{\text {new}}$. The authors then show that the optimal language model, given the dataset $\mathcal{D}, is $\mathcal{M}_\text{opt} = \mathcal{M}^* - \frac{1}{n} \sum_{s_1=s_0}^s \left( l(\mathcal{A}^\text{exp},s) - l(\mathca{M}^\text {opt},s) \right) \mathbb{I}\{r_\text{new}(\cdotp > 0\}$. That is, the optimal model is the optimal model without the mistakes made by the reward function $r$.

The authors then show how to implement this algorithm, and how to tune the hyperparameters. The most important hyperparameter is the maximum number of mistakes the reward model is allowed to make, $0 \leq n \leq 100$. A lower value of $n$ leads to more conservative training, which means the model will perform better on the test dataset, but will take longer to train. Another hyperparameter is the loss function $l$. The authors recommend using the cross-entropy loss, because it is the same loss used to train the language model, and therefore no changes are needed to the language model code. However, other losses could be used. The authors also recommend using a different loss for each task, to reduce the effect of outliers. Finally, the authors recommend running a validation set during training to fine-tune the hyperparameters.

The paper ends with a set of experiments, showing that the DPO algorithm works well. In the experiments, one task is always a baseline, and the other models perform best when using the modified reward function. The best results are on the TRECVID and SQuAD datasets. The authors also compare DPO to PPO, another reinforcement learning algorithm. DPO is about 2x faster than PPO, but achieves similar performance gains.

The paper is well-written, and the experiments are convincing. However, there is one issue that bothers me. The DPO algorithm is based on the assumption that the optimal reward function is $r$. In other words, DPO makes the assumption that the optimal model makes no mistakes. If this assumption is false, then the DPO algorithm will not work. In fact, the authors mention this possibility in the paper, but they don't do any experiments to test the robustness of DPO against invalid reward functions. So my question to the community is: have you seen reward functions other than $r$ that give good language models? Have you tested the robustness of algorithms like DPO against invalid reward models?
