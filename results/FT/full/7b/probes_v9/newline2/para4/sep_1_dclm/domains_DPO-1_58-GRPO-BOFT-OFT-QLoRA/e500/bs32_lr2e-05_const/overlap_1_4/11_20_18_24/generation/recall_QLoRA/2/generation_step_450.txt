The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is a technique for quantizing Large Language Models (LLMs) during finetuning without losing performance. The technique is based on Low-rank Adapters (LoRA), an existing method for adapter-based finetuning. LoRA has been shown to be effective in reducing memory usage and accelerating finetuning. However, it requires representing all weights as floating-point values, making it memory-intensive for large models. To tackle this, QLoRA employs 4-bit weight quantization, resulting in even greater memory savings. Furthermore, QLoRA achieves faster inference than the original LoRA due to its ability to use 4-bit weights during inference. This represents a significant advancement in the practicality and ease of finetuning very large LLMs.

**Why does finetuning after quantization fail?**

When we quantize a pretrained model, we convert its weights from a set of unspecific values to another set of specific values. This process can introduce quantization errors that degrade the model's performance. During the training phase, these errors are amplified, causing the quantized model to underfit and perform worse than the original pretrained model. That's why finetuning a quantized model directly isn't recommended; doing so attempts to recover the lost performance due to quantization errors by optimizing for new objectives, but it often fails to fully compensate for the losses.

**How does LoRA work, and why is it important to use adapters?**

LoRA is a method designed to decrease the memory requirements of finetuning by employing a small set of trainable parameters called adapters, while keeping the original pretrained model's weights fixed. In LoRA, only the adapters are updated during the finetuning process. Mathematically, if we denote the pretrained model's weights as W^0 and the adapter as A, the adjusted weight for a layer would be computed as follows: `W = W^0 * A`. Because adapters are much smaller than the full pretrained model, this approach significantly cuts down on memory usage. Additionally, LoRA employs a low-rank matrix to parameterize the adapter, further reducing its memory footprint: `A = MM', where M is a matrix with dimensions (number_of_adapter_channels x total_parameters)`. By leaving the pretrained model weights unchanged and only adding a small, low-rank adapter, LoRA ensures that most of the pretrained model's information is preserved. This approach has been shown to achieve performance comparable to fully finetuned baselines with substantially reduced memory demands.

**What is novel in QLoRA?**

The main contribution of QLoRA is enabling effective finetuning of quantized 16-bit models using just 4-bit adapter weights, all while requiring less memory. Here's how it works: 

1. **Quantize the pretrained model to 16-bit precision.** This provides a balance between model compactness and information retention.
2. **Apply LoRA with a small number of adapter neurons.** Keep the pretrained weights fixed and only add a lightweight LoRA layer.
3. **Quantize the LoRA weights to 4-bit precision.** Since LoRA's parameters are so limited, this level of quantization is feasible without notable performance degradation.
4. **Achieve both low memory usage and fast inference during finetuning and inference.** During inference, there is no need to dequantize weights; thus, inference is 4x faster than with a 16-bit base model.

While the base model is locked at a high precision (here, 16-bit), the adapters leverage a lower precision (4-bit) to save memory. By design, this method prevents catastrophic forgetting, ensuring that the benefits of pretraining are not discarded. During inference, there is absolutely no dequantization required since the input is already in 16-bit form. Thus, reading and processing 4-bit adapters is what leads to the acceleration in inference speed.
