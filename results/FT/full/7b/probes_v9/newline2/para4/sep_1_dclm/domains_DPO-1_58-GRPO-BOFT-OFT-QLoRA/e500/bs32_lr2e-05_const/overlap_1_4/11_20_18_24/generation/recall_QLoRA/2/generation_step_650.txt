2.1 Memory Reduction Techniques

As LLMs continue to grow in size, the challenge of managing their memory requirements has become increasingly important. Over the years, several techniques have been developed to address this issue. We will cover a few of the most relevant ones here.

2.1.1 Knowledge Distillation

One common technique for reducing the memory footprint of LLMs is knowledge distillation. The basic idea behind knowledge distillation is to distill the knowledge from a large teacher model down to a smaller student model. This is done by having the teacher model generate a soft probability distribution over outputs, and then having the student model try to match this distribution. This process helps the student model capture the essential features of the teacher model, while discarding unnecessary details.

Knowledge distillation is typically applied during inference, but it can also be used during training. When used during training, knowledge distillation is referred to as "co-training." Co-training can help to improve the generalization of the student model and further reduce its memory footprint.

2.1.2 Pruning

Another popular technique for reducing the memory usage of LLMs is pruning. Pruning involves removing connections (or "neurons") from the model that are determined to be unimportant. There are several different approaches to pruning, but the basic idea is the same: identify and remove unnecessary elements to make the model more efficient.

There are two main types of pruning: sparse training and structured pruning. Sparse training involves training the model in a sparse format from the beginning. This can be done by initializing the model with a sparse structure or by applying sparsity during the optimization process. Structured pruning, on the other hand, involves adding sparsity after the model has been trained. This is done by identifying and removing connections based on some criterion (such as importance).
