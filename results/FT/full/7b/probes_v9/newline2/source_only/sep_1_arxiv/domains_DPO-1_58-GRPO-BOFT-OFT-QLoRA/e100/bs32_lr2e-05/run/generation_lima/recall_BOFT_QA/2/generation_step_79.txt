The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as shown in Figure 1, is a parameter-efficient finetuning method for foundation models. It is based on the block-diagonal OFT (BLOFT) and builds upon the butterfly structure from linear algebra. BOFT has two key components: 1) a parameter-efficient finetune block that is used to replace the standard fully connected (FC) layer and 2) a parameter-efficient way to construct the weight matrix of the new finetune block. The core idea behind BOFT is to perform finetuning with orthogonal matrices that are factorized as the butterfly product of multiple sparse matrices. Compared to BLOFT, BOFT uses fewer trainable parameters because it uses a more parameter-efficient way to construct orthogonal matrices. Specifically, while BLOFT generates an orthogonal matrix with $d$ block-diagonal matrices, each of size $h\times h$ (where $d$ and $h$ are user-specified), BOFT generates an orthogonal matrix using $d$ sparse matrices, each of size $(h-1)\times (h-1)$.

The authors also propose a algorithm to automatically find the value of $h$ that yields the best generalization performance for a given model and finetuning task. They call this algorithm Adaptive Butterfly Exploration (ABE). ABE has one parameter, $k$, which is the maximum size of a matrix in the butterfly product. ABE tries out all possible orthogonal finetuning methods that can be formed with a butterfly product of $k$ matrices. For each such matrix and for each epoch, ABE keeps track of the gap between the validation perplexity and the validation cross entropy. After all matrices have been tried, ABE picks the matrix corresponding to the minimum gap as the matrix that will be used for finetuning.<|endoftext|>
