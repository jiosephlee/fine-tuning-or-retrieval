\subsection{What is Orthogonal Finetuning?}
\label{sec:what-is-of}

Finetuning (FT) is a simple yet powerful training paradigm to adapt pretrained models to downstream tasks \cite{hulora2022,houlsby2019parameter}. It has been proven to be an effective way to improve performance and stabilize training \cite{brown2020language,lester2020power}. Despite its wide success, standard finetuning suffers from two major limitations. First, it requires a significant amount of carefully collected training data to avoid overfitting. This can be prohibitively expensive or infeasible for some applications, e.g., finetuning a pretrained language model (PLM) on a new task often requires collecting human annotations for a new dataset. Second, it scales linearly with the number of parameters in the pretrained model, making it infeasible to apply to large models due as it requires a significant amount computational resources and storage for training and inference.

To address the second challenge, \emph{parameter-efficient finetuning} methods have been developed to adapt large pretrained models to downstream task \cite{qiu2023pixelated,liu2022few,sung2022training,guo2023scaling}. These methods typically modify the forward pass of the pretrained model by adding a small number of trainable parameters, e.g., linear layers \cite{huloboy2019parameter,guo2023Scaling,houlsby2016parameter,sung2022training}, neural networks \cite{qiu2017learning,liu2022 FewShot}, or weight matrices \cite{chen2021cross,zaken2022cross}. These methods share the same backbone and only update a small number of additional parameters, thereby significantly reducing the number of trainable parameters. Despite great success, existing parameter-efficient finetuning methods generally assume that the pretrained model is accurate enough such that a small loss function can drive the model to converge to the optimal solution. This assumption may not hold for some applications, e. g., when the pretrained model has a high test error or the downstream task is very different from the pretrained task. In such cases, it is important to improve the performance of the pretrained model before applying parameter-efficient finetuning. One straightforward approach is to finetune the pretrained model, but this can be prohibitively expensive due to the large number of parameters in the model.

\subsection{Why is OFT Inefficient?}
\label{why-is-of inefficient}

Orthogonal Finetuning (OFT) \cite{liu2022orthogonal} is an efficient finetuning method that improves the performance of a pretrained model by jointly learning an orthogonal matrix and an affine transformation. By construction, the orthogonal matrix preserves the pairwise angles of the neurons, which prevents the model from drifting away from the pretrained distribution. To achieve parameter-efficiency, previous OFT-based methods typically apply block-diagonal matrices to the weight matrix \cite{liu22umf,costin2023pixelated}, where each block corresponds to a mini-batch dimension. While block-diagonal OFT is parameter-efficient, it has two major limitations. First ofCADE, it is not differentiable with respect to the block-diagonal matrix, which makes it difficult to optimize the orthogonal matrix. Second, it only reduces the number of trainable parameters by a factor of the block size, which can still be large even if the block size is small. For example, if we use $b=2^4$ for a ResNet-50 \cite{he2016deep} pretrained on ImageNet \cite{deng2009imagenet}, then the number of trainable parameters is $5\times 248\times 2^4\times 2^2=62K$, which is much larger than the 4K parameters of \textbf{Base} BOFT. These limitations motivate us to explore new ways to make OFT more parameter-efficient.

\subsection{What Is BOFT?}
\label{what-is-boft}

BOFT is an efficient and effective OFT-based adapter that can be easily concatenated to a pretrained model. BOFT leverages a butterfly factorization to recursively construct a parameter-efficient adapter.
