QLoRA uses a small linear layer to dequantize the weights during training, allowing standard stochastic gradient descent to be used. This is in contrast to methods like Stable Quantization, which typically use variant optimization algorithms during finetuning.

The basic idea is that you can represent a matrix $A \in \mathbb{R}^{d \times d}$ with integer weights using its quantization function $q$ and an integer scale $s$ as
$$A = s \cdot q(A),$$
where $q(A)$ rounds each real value in $A$ to the nearest integer value. The scale $s$ is a diagonal matrix with the quantization scales along the diagonal, i.e. $s_{ii} = \text{round}(a_i)$ where $a_i$ is the $i$-th entry of $A$.
