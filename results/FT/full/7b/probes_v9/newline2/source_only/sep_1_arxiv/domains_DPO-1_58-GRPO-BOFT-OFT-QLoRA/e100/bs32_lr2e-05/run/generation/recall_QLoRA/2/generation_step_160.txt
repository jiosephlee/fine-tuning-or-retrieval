Why Quantization?

Before we dive into the details of QLoRA, let's first talk about why weight quantization is useful. Modern natural language models are increasingly large, with models of 7B to 70B parameters becoming ubiquitous. However, the memory requirements of these models makes it difficult to run any but the smallest models on a single consumer GPU, which typically has between 6GB and 24GB of memory. While techniques such as memory compression and cooperative training can help, the most effective way to reduce the memory footprint of a model is to quantize its parameters.

Parameter quantization works by reducing the number of bits used to represent the weights of a neural network. While state-of-the-art full-precision models use 16-bit floating point numbers to represent their weights, quantization reduces this to, for example, 4 bits, resulting in a 4:1 reduction in memory usage. This comes at the cost of some degradation in performance, but the latest quantization methods achieve only minor performance losses relative to their full-precision counterparts. In fact, many recent papers have demonstrated that 4-bit LLMs perform comparably to their 16-bit counterparts . Despite this, 4-bit LLM research has largely been ignored by the community, with researchers sticking to the well-known and easy-to-use Huggingface transformers. However, this is set to change with the release of the unified transformer implementation Alpaca , which will make working with quantized LLMs as easy as working with full-precision ones. QLoRA aims to further reduce the barriers to working with quantized LLLs by making them just as easy to finetune as full-precision models.

How Does QLoRA Work?

Now that we've covered why quantization is useful, let's talk about how QLoRA works. At a high level, QLoRA works by representing weights using a quadrate norm measure (QLM) and quantizing them into codebooks. I'll explain each of these steps in more detail below.

Representing Weights Using a Quadrate Norm Measure

The first step in quantization is to represent weights using a measure of how spread out they are. This is necessary because simply quantizing all weights to the same 4-bit value would cause all neurons to become identical and would make the resulting model do nothing but output random noise. To avoid this, we need to quantize weights in a way that takes into account how active they are. For example, a neuron with a weight of 0 will not affect the output of a layer, so there is no reason to keep track of this weight using many bits. On the other hand, a neuron with a large weight that is activated will have a large effect on the output of a layer and thus needs to be represented using many bits. One way to measure the activity of a neuron is to look at its quadrature amplitude, or quadrate for short. The quadrate of a neuron is calculated as the square root of the sum of the squares of its weights, which represents the energy that the neuron has. By representing weights using their quadrate, we ensure that neurons with a lot of energy, or weight, require more bits to represent while neurons with little energy require fewer bits.

Quantizing Weights Into Codebooks

The next step in quantization is actually performing the quantization. This is done by dividing the range of possible quadrates into bins and assigning a 4-bit value to each bin. These bins are called codebooks and work similarly to how pixels in an image are assigned values in a color palette. Just as pixels in an image are represented using a limited number of colors from a color palette, neurons in a neural network are represented using a limited set of 4-bit weights from a weight codebook.
