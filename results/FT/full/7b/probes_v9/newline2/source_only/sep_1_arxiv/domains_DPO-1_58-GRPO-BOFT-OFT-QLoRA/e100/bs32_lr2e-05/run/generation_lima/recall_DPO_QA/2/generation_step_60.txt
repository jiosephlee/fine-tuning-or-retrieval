The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" introduces Direct Preference Optimization (DPO) as an alternative to the usual RLHF pipeline like PPO. What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based approach for training language models to adhere to human preferences. It does not rely on a separate reinforcement learning (RL) agent, but instead uses the language model itself to optimize towards a user-specified reward function that captures the preference. The key insight is that any Markov decision process (MDP) can be exactly represented by a suitable language model, and thus the MDP can be solved by optimizing the language model to maximize the reward function.

In the RLHF setting, a separate RL agent is trained to maximize the expected reward from a policy induced by the language model. This has the disadvantage that the reward function needs to be simplified so that it can be used by the RL agent, which may not capture the full preference. In contrast, DPO uses a more complex reward function that captures the full preference, and directly optimizes the language model to maximize this reward.

The basic idea of DPO is to frame the problem of training a language model to adhere to human preferences as solving a Markov decision process (Sutton & Barto, 2018). This MDP is defined by the following components:

* A **state space** $\mathcal{S}$, which is typically the set of all possible history prefixes at any point during generation.
* A **reward function** $r : \mathcal{S} \times \mathcal{A} \rightarrow \mathbb{R}$, which takes a state and an action as input and returns the corresponding reward. The reward function is specified by the human demonstrator and captures their preference over generation outcomes.
* A **transition model** $\mu : \mathcal{A}\times\mathcal{S} 	o \mathcal{S}$ that takes an action and a state and returns the next state. The transition model is typically the true transition dynamics of the language model.
* An **initial state** $\sigma_0 \in \mathcal{S}, which is the initial prefix of the generation.

The goal is to find a policy $\pi(a|\sigma)$ that maximizes the expected return $G_{\pi}(\sigma_0) = \mathbb{E}_{\sigma_{t+1} \sim \mu(\sigma_t, a_{\sigma})} \left[ \sum_{i=0}^\infty r(\sigma_i, a_{\sigma_i}) \right]$. However, this expectation is typically intractable because it depends on the true transition dynamics $\mu$.

DPO addresses this intractability by framing the problem as a **partial observability MDP** (Sutton & Bartos, 2018, section 9.4), where the state is only partially observable. This allows us to rewrite the return as a function of the rewards at each step, rather than the states: 
$$G_{\pi} = \mathbb{.E}_{\sigma_{t + 1} \sim \mathcal{N}(\mu(\sigma_t, \pi(\sigma_t)), 1)} \left[ \sum\_{i=0}^{\infty} r(\sigma\_i, \pi(\sigma\_i)) \right]$$
where $\mathcal{N}($mean, variance$)$ denotes a Gaussian distribution with given mean and variance. This reparameterization allows us to solve the MDP using value iteration, which only requires sampling from the distribution over next states induced by the current policy $\pi$.

The key insight of DPO is that any MDP can be exactly represented by some language model, and thus we can use value iteration to find the optimal policy by optimizing the language model. More formally, we can construct a language model $\Lambda$ that represents the MDP as follows:
$$\Lambda(\sigma) = \mathbb {E}_{\sigma' \sim \mu(\cdot | \sigma)}[R(\sigma, \sigma')], $$
where $R$ is the reward function of the MDP. Under certain regularity conditions, this language model will be the optimal solution to the MDP, in the sense that it achieves the highest possible expected return. Moreover, the expected return can be written as a function of the language model's probability distribution over completions: 
$$\mathbb{E}_{G \sim \Lambda} [R(\sigma, G)] = \mathbb{D}_{\text{KL}}[\Lambda(\sigma) / \pi(\sigma) \ || \ \Pi(\sigma)]$$
where $\Pi$ is the optimal policy, $\pi$ is the current policy, and $\mathbb{D}_{KL}$ denotes the KL-divergence. This equation states that the advantage of following the current policy $\pi$, rather than the optimal policy $\Pi$, is equal to the KL-divergence between the language model $\Lambda$ and the optimal language model $\Pi
