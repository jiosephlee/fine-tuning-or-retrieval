What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as shown in Figure 1, is a parameter-efficient finetuning method for foundation models. It is based on the block-diagonal OFT (BLOFT) and builds upon the butterfly structure from linear algebra. BOFT has two key components: (1) a parameter-efficient finetune block that is a variant of BLOFT and (2) a compositional framework to construct the entire finetuning model. Specifically, we compose multiple parameter-efficient finetune blocks with the original model and its mirrored version. The resulting BOFT has zero additional parameters compared to the original model. Moreover, it only introduces new fill-in matrices to the original model's dense blocks, keeping all other components (e.g., activation, normalization, and convolution layers) unchanged. This makes BOFT easy to implement and compatible with various foundation models.

The original OFT uses block-diagonal weight matrices to ensure that the pretrained weights have no influence during finetuning. While BLOFT improves parameter-efficiency over OFT, it still has a lot of zero elements, which may hurt its performance. To address this, BOFT proposes to use a butterfly structure to further reduce the number of zero elements. The butterfly structure is widely used in linear algebra and is particularly effective in reducing the fill-in when multiplying two dense matrices. By applying the butterfly structure to finetuning, BOFT is able to further reduce the number zero elements, and thus achieve better parameter-efficiency.

Here is an example of how the butterfly structure works in BOFT. Suppose we have a vector $x \in \mathbb{R}^{4}$ and a coefficient matrix $\text{Butterfly}(4)$ as shown below:
```  [w  h  l  t]
  [ 0  w  h  l]
  [ 0   0  h  l]
 [ 0   1   0  l],
```
where $w, h, l, t$ are some nonzero values. Then multiplying $x$ and $\text{Butterterfly}(4)$ results in another vector $y \in \mathbb R^4$ with $y_i = \sum_{j} x_j * t_{ij}$, where $i$ is the row index and $j$ is the column index. For example, the first element of $y$ is computed as $w*x_1 + h*x_2 + l*x_3 + t*x_4$. Intuitively, the butterfly structure propagates values from $x$ along the diagonal line, and then sums them up. This propagation process can be repeated to multiply $y$ with another $\text{Butterflower}(4)$. The result is another vector $z \in \mathbb {R}^4$ with $z_i = \sum_{i} y_j * t_{ji}$. For example, the first component of $z$ is computed as $(w*h)*x_1 + (w*l)*x_2 + (h*l)*x_3 + t*x4$. With $n$ butterflies, we can efficiently compute $x^n$ with $O(n)$ multiplications.

The butterfly structure can be easily extended to a matrix $X \in \mathbb  R^{m\times n}$ and a butterfly matrix $\text{But}(\ell) \in \mathbb Z^{m \times n}$ of size $\ell$. The product $X\text{But}(\el)$ is another matrix with size $m \times n$ and its $(i, j)$ element is computed as $\sum_{k=1}^{\ell} X_{i,k} \cdot \text{But}_{k,j}$. Here $\text{But}_{k, j}$ is the $j$-th element of the $k$-th butterfly in $\text{But} (\ell)$. The butterfly structure can also be easily generalized to finetune different dimensions of the input tensor. For example, BOFT uses a diamond-shaped butterfly to finetune different channels of the input feature map.

The butterfly structure is also related to the fast Fourier transform (FFT). The key difference is that the butterfly matrix in FFT is sparse while the butterfly matrix in BOFT is dense. This makes the FFT much more efficient to compute, but the FFT can only learn a linear transformation, while the BOFT can learn any full-rank matrix.

The butterfly structure is a well-known structure in linear algebra, but it has not been used in finetuning models before. BOFT is the first method to use the butterfly structure to improve parameter-efficiency.<|endoftext|>
