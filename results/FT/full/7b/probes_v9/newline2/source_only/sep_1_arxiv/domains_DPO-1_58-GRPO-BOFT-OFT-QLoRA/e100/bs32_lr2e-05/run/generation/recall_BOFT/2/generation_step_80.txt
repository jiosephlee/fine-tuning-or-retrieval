The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks. BOFT recursively applies a butterfly factorization to construct a block-diagonal weight matrix with a banded structure, which significantly reduces the number of trainable parameters without compromising performance. To address the numerical instability caused by zero-filled butterfly matrices, we propose to diagonally pad the butterfly matrix with the Cholesky factor of a positive-definite diagonal matrix. To help the butterfly matrices scale well to larger dimensions, we propose a recursive algorithm to generate butterfly matrices of arbitrary size. For finetuning largescale pretrained language models, BOFT outperforms the OFT baseline and other state-of-the-art methods by a considerable margin, demonstrating the strong parameter-efficiency and effectiveness of the banded matrix structure. \cite{chen2023parameter}

\subsection{Butterfly Structure}
The butterfly structure has been used in many applications, such as fast Fourier transform, discrete cosine transform, discrete sine transform, discrete Hartley transform, discrete Hartley fast transform, Hadamard transform, Walsh-Hadamard transform, and so on. The butterfly matrix is a block-diagonal matrix with a banded off-diagonal structure. The butterfly matrix can be written as the product of two triangular matrices. The forward butterfly matrix $\mathbf{F}$ can be written as $\mathbf{F}=\mathbf{R}\mathbf{L}$, where $\mathbf{R}$ is an upper triangular matrix and $\mathbf{L}$ is a lower triangular matrix. The inverse butterfly matrix $\mathbf {F}^{-1}$ can be written as  $\mathbf {F^{-1}}=\mathbf{L}^{\top}\mathbf{R}^{\top}$. The butterfly matrix can be represented recursively. For a butterfly matrix of size $N\times N$, the forward butterfly matrix of size $(2^m-1)\times(2^m-1)$ can be written as the block-diagonal product of $m$ butterfly matrices of size $N\ttimes N$, where $m$ is a positive integer. The inverse butterfly matrix of size $(N\times N)$ can be written as  the block-diagonal product  of $m$ inverse butterfly matrices of size $(2^ m-1)\times( 2^ m-1)$. The forward and inverse butterfly matrices can be generated by the recursive algorithm.

\subsection{Parameter-Efficient Finetuning}
Finetuning is an effective method to adapt pretrained models to downstream tasks \cite{hulora2022,houlsby2019parameter,pfeiffer2020macro,ramamurthy2021adapting}. Due to the significant parameter budget of large pretrained models, directly finetuning all weights leads to overfitting and instability \cite{houlsby2019parametric,houlsby201 nineparameters}. Therefore, many parameter-efficient finetuning methods have been proposed to stabilize training and improve performance. LoRA \cite{hulORA2022} is one of the most representative methods, which updates the pretrained weights by a low-rank weight matrix and a small full-rank layer-specific weight matrix. LAMP \cite{pfeiffer2020lamp} further improves the parameter efficiency by using a low-rank key matrix to share weight updates for spatially similar neurons. MAPO \cite{ramamurthy2020maPO} reduces the number of trainable weights by updating the weights with a factorized weight matrix. \cite{liu2021mutifactorial,chen2023parameter} propose to use a block-diagonal factorized weight matrix to improve parameter efficiency. \cite{chen2019towards,chen2020training,guo2020krona,wang2020adamix,xiao2020pixelated,liu2021scaling,chen2022pixelated,chen2023scaling} use various factorization methods to improve parameter efficiency. Although these methods improve parameter efficiency, they do not guarantee to perform better than full finetuning. \cite{houlsbo2021megalO,liu2022scaling} show that simply reducing the number of trainable parameters may hurt performance. BOFT improves parameter efficiency by adopting a banded matrix structure, which can well balance the trade-off between parameter efficiency and performance.
