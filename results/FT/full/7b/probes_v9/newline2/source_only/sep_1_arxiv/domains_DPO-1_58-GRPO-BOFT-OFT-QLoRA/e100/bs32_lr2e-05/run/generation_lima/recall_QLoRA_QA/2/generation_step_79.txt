### What is QLoRA?

QLoRA (Quantized FineTuning with Low-rank Adapters) is a method introduced by OpenAI for efficiently finetuning large language models (LLMs). It reduces the memory requirements of finetuning LLMs without adding significant latency or requiring significantly more code.

The main idea behind QLoRA is to use low-rank adapters for finetuning. Low-rank adapters have been shown to be an effective and efficient alternative to finetuning all weights in an LLM. QLoRA also proposes a method for quantizing these adapters, reducing their memory footprint further without significant degradation in performance.

Here's how QLoRA works:

1. **Quantize the pretrained model:** Use a method such as INT8 to quantize the weights of the pretrained model from 16 bits to 4 bits.
2. **Create low-rank adapters:** For each task, create a set of low-rank adapters. These adapters will be used for finetuning the model for each task.
3. **Combine the pretrained model and adapters:** Multiply the quantized pretrained model by the task-specific adapters to create a single tensor. This tensor can then be used for training using standard optimization algorithms.
4. **Requantize after training:** After training, requantize the model back to 4 bits for deployment.

The key insight of QLoRA is to quantize the pretrained model and then use low-rank adapters. This approach reduces the memory requirements significantly compared to finetuning the entire model.
