GRPO improves upon PPO in two key aspects: 1) it uses group LSTD estimation to estimate the advantage function, which is more stable and sample-efficient in the presence of high correlation between policies; 2) it introduces a relative clipping norm for the advantage estimation, further stabilizing the training of large models.

## Differences from PPO
In PPO, the surrogate objective is:
```max_a [q(s_t, a; θ) - β \* λ \* g(s_t, a, a_ref; θ)]
```
where `a_ref` is the reference action, which is sampled from the previous step's target model. `g` is the advantage function, which estimates the difference in reward that would have been obtained if we had executed action `a` versus the action that was actually executed. In PPO, `g` is estimated using:
```g(s_t, a, b; θ) = ∇_θ q(s_t, a; φ) - ∇_θ q (s_t, b; φ) / τ
```
where `φ` is the target model parameter, and `τ` is the time constant for the target model.

There are two main differences in GRPO compared to PPO:

### Advantage Function
In PPO, a common choice for the advantage function is the per-timestep log probability of the reference action, normalized by the temperature. This is defined as:
```g(s_t,a,b;θ) = ∇_ θ q (s_t,a;φ) − ∇_ θq (s_t,b;φ)τ
```
where `q` is the model being trained, and `φ` is the targets. In the context of PPO, this means that the advantage function is estimated as the difference in the current critical sample update (CSA) score between the model being trained (`q`) and the target model (`φ`).

However, in the context of mathematical reasoning, the reference action may not always be the best course of action. Moreover, the per-timestep log likelihood of the reference action is highly correlated across samples, leading to high variance when estimating the advantage function. To address this, GRPO uses a group relative advantage estimate, defined as:
```g(a_1, a_2; θ) = (∇_ θ q(s_t, a_2; φ) - ∆) / τ - (∇_ θq(s_t, a_1; φ) - � Delta) / τ
```

where `∆` and `Δ` are the running averages of the difference between the model and the target, one for the current policy and one for the reference policy. These running averages are updated using a group LSTD estimate, which takes into account the correlation between samples generated by the same policy. This approach effectively normalizes the advantage estimate by the difficulty of each sample, reducing the variance and improving stability.

### Advantage Clipping
To further stabilize the training of large-scale models, GRPO clips the advantages with a per-policy running mean. This mean is initialized to zero, and is updated after each training step as the average of the absolute value of the advantages calculated in that step. This ensures that no single sample can dominate the advantage estimate for a given policy.<|endoftext|>
