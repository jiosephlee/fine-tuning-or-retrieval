What is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT for short) is a method for finetuning pretrained neural networks, that aims to preserve the geometry of the pretrained weights. The key idea is to perform finetuning by applying orthogonal transformation to the neurons. This is in contrast to standard finetuning where non-orthogonal transformation is applied, and layer-normalization-based methods like LoRA that apply different transformation for each layer.

To perform orthogonal finetuning, we first need to compute the eigenvalues and eigenvectors of the pretrained weight matrix. Then, in each training iteration, we update the weight matrix by adding a small multiple of an orthogonal matrix to the pretrained weight matrix. The orthogonal matrix is computed by applying spectral decomposition to a small matrix that is typically the product of a learnable scalar and the identity matrix.

Formally, given a pretrained weight matrix $W^0 \in \mathbb{R}^{d\times n}$, we want to finetune the network with a small learning rate $\alpha$. The key insight of OFT is to perform the finetuning by applying an orthogonal transformation to the pretrained weight matrix $W^{0}$.

For each training example, we first multiply a small scalar $\beta \in \mathbb R$ to form the matrix $W^\beta = \beta I_d W^0$, where $I_d$ is the $d$-dimensional identity matrix. Then, we compute the eigenvalue decomposition $W^\beta = Q \Lambda Q^\top$, where $Q \in \mathbb {R}^{d\t times n}$ is the matrix whose columns are the eigenvectors, and $\Lambda = \text{diag}(\lambda_1, \cdots, \lambda_n)$ is a diagonal matrix with the eigenvalues $\lambda_i$'s. We then add the orthogonal matrix $R = Q \alpha I_n$ to $W^\beta$, i.e., $W = W^\beta + R = \beta I_d + \alpha Q R^\top$, and forward the data through the transformed network.

The matrix $R$ is typically set to be the identity matrix, and $\alpha$ is set to be a small value such as $10^{-4}$. In this case, the finetuned matrix $W$ is close to the pretrained matrix $W^0$. However, if we let $\beta$ be large, then $W$ can be quite different from $W^0$. The advantage of OFT is that, no matter how large $\beta$ is, the orthogonal transformation $R^\top W^0$ always preserves the angles and the lengths (i.e., the spectral properties) of the neurons in $W^0$. This is in contrast to the standard finetuning where the angles and the lengths of the neurons are changed, and layer normalization-based methods like LoRA where the different layers may change the angles and the lengths in different ways.

The main challenge of OFT is the computational cost for computing the eigenvalue decomposition. For a neural network, the eigenvalue decomposition needs to be computed for each training example, which can be quite expensive. To address this, the paper proposes two efficient algorithms for computing the orthogonal transformation. One algorithm is based on the Cayley transform, and the other is based on the QR decomposition. Both algorithms have a time complexity of $O(dn^2)$, which is much more efficient than the $O(nd^2)$ time complexity of the spectral method.<|endoftext|>
