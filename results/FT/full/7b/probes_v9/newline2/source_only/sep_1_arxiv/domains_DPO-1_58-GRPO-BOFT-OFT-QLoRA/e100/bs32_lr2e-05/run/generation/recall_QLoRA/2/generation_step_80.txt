The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. Why do we need QLoRA?

Finetuning large language models (LLMs) is increasingly important for improving their performance and reducing their bias. However, finetuning very large LLMs, such as those with over 11B parameters, poses significant challenges. The most important challenge is the high memory consumption during training, which can be several TB for a single 24-hour training epoch on a single GPU. This makes it impossible to train such models on a single GPU or even a single machine. In fact, the memory consumption is so high that many state-of-the-art models have been trained only on a single data center with hundreds of machines.

One way to reduce the memory consumption is to use lower precision, i.e. to represent weights and activations with fewer bits. For example, using 4-bit weights reduces the model size by a factor of 4 compared to 16-bit weights. This has been used successfully in the research community, but has not been applied to the largest LLMs yet. The reason is that low-precision training introduces significant accuracy degradation, especially for LLMs with over 11B parameter. This makes it hard to apply low-precision training to the largest models where every percentage point of accuracy matters.

How does QLoRA work?

QLoRA is a method for efficient low-precision finetuning of LLMs. It can reduce the memory consumption by a factor of 8 compared to standard 16-bits finetuning, while using the same number of bits as the pretrained model. This is possible because QLoRA uses the same quantization as the pretrained model, which means that the same bit-coefficients can be used for quantization and dequantization. In contrast, standard finetuning does not reuse the pretrained quantization and thus needs to quantize all weights again.

Figure 2: Overview of QLoRA. QLoRA reuses the quantization from the pretrained model and only quantizes the difference to the pretrained model.

The key insight behind QLoRA is that the most important information for finetuning is the difference to the pretrained weights, not the weights themselves. Therefore, QLoRA quantizes only the difference and reuses the pretrained quantization. This way, QLoRA can use the same number of bits to finetune a model as the original pretrained model used. For example, QLoRA 3-bit finetuning of a 16-bit pretrained model uses 3 bits for quantization and 15 bits for dequantization, for a total of 18 bits. In contrast, standard 3-bit finetuing would use 3 bits for quantziation and 2 bits for dequantization for a total of 5 bits.

Figure 3: Comparison of standard finetuning and QLoRA. In QLoRA, the pretrained weights are quantized and only the difference to the pretrained quantized weights is finetuned.

Why does QLoRA work so well?

The key to QLoRA's success is its ability to use very low bit-precisions without losing accuracy. This is possible because the quantization is shared between the pretrained model and the finetuned model, which means that QLoRA can use a more precise quantization than standard finetuning. In fact, QLoRA can share the same quantization as in the pretrained model, which is usually of high precision. For example, OpenAI GPT models are quantized in 16-bit for stabilization and 10-bit for memory reduction. QLoRA can finetune these models with 10-bit or even 8-bit weights using the same quantization as OpenAI.

Another reason why QLoRA works well is that it is very fast. Finetuning with standard 16-bit weights is usually 2-4x slower than training from scratch with 16-bit weights. In contrast, QLoRA is just 5-10% slower than standard 16-bit fineteuning. This is because QLoRA does not need to dequantize weights for every forward and backward pass, which saves a lot of time.
