What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It's a simple and effective method. It's also easy to implement.

The basic idea of DPO is to use the reward model to estimate the reward of each generated token, and then optimize the language model to maximize the expected reward.

How does DPO work?

DPO uses a reward model to estimate the rewards of each generated token. The reward model is usually a neural network. It takes the generated token as input and outputs a reward value.

Then, DPO uses the reward model to estimate a reward distribution for each generated sequence. The reward distribution is the probability distribution over all possible rewards for the generated sequence. It's calculated by sampling many times from the reward model.

Finally, DPO optimizes the language model to maximize its expected reward. The expected reward is the sum of the reward values multiplied by their corresponding probabilities in the reward distribution.

Why does DPO work?

There are two reasons why DPO works:

  1. The reward model is accurate enough.
  2. The language model is flexible enough.

The reward model is accurate enough

The reward model is used to estimate the rewards of generated tokens. If the reward model is accurate enough, it can estimate the rewards well.

The accuracy of the reward model depends on its capacity. The more parameters the reward model has, the more accurate it can be. However, the more parameters the reward model have, the more training data it needs.

The language model is flexible enough

The language model is used to generate tokens. If the language model is flexible enough, it can generate tokens that satisfy human preferences.

The flexibility of the language model depends on its capacity and its prior. The more parameters the language model has, the more flexible it can be. However the more parameters the language model have, the more difficult it is to train.

The prior of the language model is the distribution of the tokens it generates. If the prior of the language model matches the distribution of human preferences, the language model can generate tokens that satisfy those preferences.
