What is Parameter-Efficient Finetuning?

Parameter-efficient finetuning (PEFT) is a method that can reduce the number of trainable parameters while finetuning a pretrained model. It can be divided into two categories: low-rank parameter update and sparse parameter update.

Low-rank Parameter Update

Low-rank parameter update is to update the pretrained model with a low-rank matrix. The low-rank matrix can be generated by some methods, such as Orthogonal Finetuning (OFT), Canonical Correlation Analysis (CCA), and Factorization.

Orthogonal Finetuning (OFT)

Orthogonal Finetuning is a method that can generate a low-rank matrix with orthogonal matrices. It can be divided to two steps:

  1. Generate a set of orthogonal matrices with a certain dimension.
  2. Multiply the orthogonal matrices to get a low-rank matrix.

The first step can be done by Orthogonal Group (O(n)) or Block Orthogonal Group (BO(n)). The second step can be done by Kronecker Product or Tensor Product.

Canonical Correlation Analysis (CCA)

Canonical Correlation Analysis is a method that can find a pair of linear transformation to maximize the correlation between two sets of data. It can be divided in two steps:

  2. Find a pair of linear transformation that can maximize the correlation between the transformed data.

The first step can also be done by Orthogonal group (O(n)) or block orthogonal group (BO(n)). The difference is that the first step of CCA is to transform the input data to a canonical space, while the first step of OFT is to transform the weight matrix to a canonical space.

The second step of CCA is different from OFT. It is to find a pair of linear transform that can maximize the correlation. The linear transform can be written as a matrix multiplication. So the second step of CCA can be written as matrix multiplication.

Factorization (or Tensor Train)

Factorization is a method that can represent a matrix as a product of multiple matrices. It can be written as:

$$W=\text{tensor train}(d_1,d_2,\cdots,d_n)=\text{diag}(d_1)\cdot \text{diag}(d2)\cdots\text{diag}(dn)$$

where $d_i$ is the size of the $i$-th diagonal matrix.

Sparse Parameter Update

Sparse parameter update is to update a pretrained model with a sparse matrix. It can be divided two categories: structured sparse update and unstructured sparse update.

Structured Sparse Update

Structured sparse update is to update a model with a structured sparse matrix. For example, the matrix can be block-diagonal or banded.

Unstructured Sparse Update

Unstructured sparse update is to update the model with an unstructured sparse matrix. For example:
