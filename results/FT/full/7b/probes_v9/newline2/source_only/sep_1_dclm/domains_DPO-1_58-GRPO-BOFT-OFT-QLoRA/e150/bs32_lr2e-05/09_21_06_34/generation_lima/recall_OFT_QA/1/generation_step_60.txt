According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>The paper introduces OFT, a simple finetuning method that can prevent knowledge erosion and restore original models. The key is to replace the identity weight matrix in standard finetuning with an orthogonal weight matrix. To construct an orthogonal matrix, the paper proposes two methods: Cayley parameterization and spectral decomposition. Here is a brief introduction to these two methods.

Cayley parameterization
A square matrix $M$ is orthogonal if $M^TM=MM^T=I$, where $I$ is the identity matrix of the same size as $M$. A nonsingular matrix $A$ is called a Cayley parameterization of $M$ if $M=A^{-1}SA$ for some orthogonal matrix $S$. We can easily verify that if $M,A,S$ are as described, then $M$ is orthogonal. Therefore, we can generate an orthogonal matrix $S$ and then use $S=A'SA$ to obtain a Cayley parameterization $A'$ of the identity matrix ($A'$ is orthogonal because $A'$ is a Cayley parameterization). Finally, we finetune the weights by $\Delta W=W-\lambda A'$ where $\lambda$ is the learning rate.

Spectral decomposition
An $n\times n$ orthogonal matrix $S$ satisfies $SS^T=nI_n$, where $I_n$ is the identity matrix. This means we can obtain an orthogonal matrix $S=\text{diag}(s_1,\cdots,s_n)$ whose diagonal elements $s_i$ satisfy $s_i^2=1,\forall i$. To construct such $s_i$, the paper uses spectral decomposition. Specifically, we first compute the eigenvalues and eigenvectors of a small random matrix $\Omega\in\mathbb{R}^{n\times n}$, and then set $s_i=\pm \sqrt{\dfrac{1}{n}}\text{exp}\left(\dfrac{i\pi e_i}{n}\right)$ where $e_i$ is the $i$-th element of the $i$-nth eigenvector of $\Omega$.
The reason why a small random matrix works is that all orthogonal matrices have the same spectral distribution. That is, if $S_1,S_2,\cdots,S_m$ are $n\times n$
orthogonal matrices, then the eigenvalues of $S_1,S_{\pi(1)}S_2,S_{\pi(2)}S_3,\cdots,S_{\pi(m-1)}S_m$ are the same for any permutation $\pi:\{1,2,\cdots,m-1,m\}\mapsto\{1,2,\dots,m-1,\dots,1\}$, where $S_{i_1}S_{i_2}\cdots S_{i_k}$ denotes the matrix product of $k$ orthogonal matrices $S_{i_j}$ with $1\leq j\leq k\leq m$. This property allows us to generate a random orthogonal matrix.<|endoftext|>
