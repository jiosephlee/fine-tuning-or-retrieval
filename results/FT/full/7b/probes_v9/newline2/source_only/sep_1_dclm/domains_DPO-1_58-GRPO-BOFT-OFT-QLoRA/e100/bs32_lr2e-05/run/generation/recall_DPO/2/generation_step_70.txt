The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a new algorithm, called Direct Preference Optimization (DPO), that can efficiently optimize a language model to match human preferences without relying on an intermediate reward model. DPO is based on a simple insight: we can use the language model to generate data that we can then use to train a classifier that distinguishes preferred from dispreferred responses. We can then use this preference classifier to give feedback to the language model, effectively aligning the distribution of its responses with the set of preferred responses. The key insight of DPO is that we can update the language model in such a way that the preference classifier generalizes well to new examples, without sacrificing too much generation quality in the process. DPO does this by only updating the language model in directions that cause the preference classifier to generalize well, as measured by its out-of-domain accuracy. DPO efficiently computes these update directions using low-rank matrix approximation, and it does so without requiring access to any dispreferred responses. I evaluated DPO on two datasets of human preferences over language, including the large-scale FLAN v2 dataset with 1.8M preferences on 440k stories. For both datasets, DPO was able to align a language model's response distribution with the set of preferred replies with performance comparable to or better than the strongest existing methods, including those that use reward models. In addition, DPO was many orders of magnitude faster to train than reward models, and only slightly slower than existing preference learning methods that use a reward model. For example, training a reward model on the FLAN v2 dataset took weeks on a single GPU, while training DPO took just a few hours. In addition to its efficiency, I argue that DPO has certain theoretical advantages over existing methods. First, because DPO does not rely on an intermediate reward model, it avoids a number of potential problems associated with reward modeling, such as the exposure bias and the requirement to optimize a potentially high-dimensional reward function. Second, DPO is inherently a online learning method: it provides feedback to the language model in real time as new preferences become available, which allows the language model to remain up-to-date with the distribution of preferred responses. In contrast, existing methods learn an explicit reward model that is then used to provide feedback to the language model all at once, after all preferences have been observed. This makes it difficult to use existing methods to train language models on large datasets of preferences, since the reward model will no longer be accurate by the time all preferences have been observed.
