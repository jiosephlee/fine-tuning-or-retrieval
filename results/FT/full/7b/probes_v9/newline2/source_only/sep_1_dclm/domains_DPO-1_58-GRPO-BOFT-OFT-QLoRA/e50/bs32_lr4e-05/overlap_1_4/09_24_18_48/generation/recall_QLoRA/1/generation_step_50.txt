What is QLoRA?

QLoRA is a method for finetunig LLMs after quantizing them to 8-bit. It improves upon LoRA, a standard method for LLM finetuning, by adding a layer-shared weight normalization (LSWN) component. LSWN helps stabilize training and improve performance after quantization.

Why do we need QLoRA?

Finetuning LLMs is expensive. It requires a lot of data and compute resources. If we can finetune LLMs with less data and compute, that would be great.

Quantization is a technique for saving resources. It reduces the amount of memory required to store models and the amount of computation required to run models. But quantization introduces quantization error that degrades model performance.

QLoRA is a way to save resources with quantization while minimizing the performance degradation.

What's new in QLoRA?

The key innovation in QLoRA is layer-shared weight normalization (LoSWN). LoRA already uses weight normalization, but it normalizes weights separately for each layer. LoSWN, in contrast, normalizes weights shared across layers.

LoRA doesn't work well with quantization. It can even make models worse after quantization. LoRA causes large weight updates during training, which leads to high quantization error. LoSWN reduces the size of weight updates, which helps stabilize training and improve quantization generalization.

In addition to LoRA and LoSWN, QLoRA also has a few other modifications for better training stability and performance after quantization. For example, QLoRA uses a smaller learning rate and a larger batch size than LoRA.
