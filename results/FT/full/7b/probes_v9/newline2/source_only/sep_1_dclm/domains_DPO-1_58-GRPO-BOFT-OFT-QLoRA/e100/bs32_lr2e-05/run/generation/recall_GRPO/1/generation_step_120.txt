1. What is DeepSeekMath?

DeepSeekMath is a mathematical reasoning model based on the DeepSeek-Coder-Large model. It has 65B parameters and is trained on 4P100D data for 150 days. The training data includes Wikipedia, Common Crawl, Books, Research Papers, Code, and MathPile. MathPile is a dataset of mathematical texts collected and annotated by the DeepSeek team. It contains more than 120 million mathematical articles from Common Crawl.

2. Evaluation

The evaluation results of DeepSeekMath are amazing. On the MATH benchmark, it beats GPT-4 by 3 points. On the GSM8K benchmark, it beats Gato by 6 points. On the MetaMath benchmark, it beats Gopher by 7 points. These results show that DeepSeekMath is the best open-source mathematical reasoning model at present.

3. How does DeepSeekMath work?

DeepSeekMath uses a combination of copy mechanism and reasoning pipeline to perform mathematical reasoning. The copy mechanism is similar to GPT-4. It can directly output the solution after reading the question. The reasoning pipeline is similar to Gato. It can generate code to solve mathematical problems.

4. Copy Mechanism

The copy mechanism is used to solve simple mathematical problems. When the model encounters a mathematical problem, it will directly output the solution after processing the problem for a while. This is similar to GPT4's autoregressive generation.

5. Reasoning Pipeline

The reasoning pipeline is used to solve complex mathematical problems. When the problem is too complex for the copy mechanism to handle, the reasoning pipeline will be triggered. It can generate code and execute it to get the solution.

6. Code Execution

The code execution module is used to execute the generated code. It can execute Python, Rust, and C++ code. It uses the LLVM compiler to compile and execute C++ code. It can execute code with less than 512 bytes. For longer code, it will be split into several pieces for execution.

7. Training Data

The training data of DeepSeekMath includes Wikipedia, Common Crawler, Books, Research Papers Code, and MathPiles. Among them, MathPiles is the most important. It contains more than120 million mathematical articles from the Common Crawler. These articles have been pre-processed and annotated by the Deep Seek team. They have been divided into sentences, and mathematical expressions in sentences have been marked. In this way, the model can easily find mathematical expressions in the training data and learn to understand and solve mathematical problems.
