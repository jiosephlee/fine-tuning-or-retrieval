What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is based on the idea that a language model can be used as a reward model. In other words, we can use a language model to score text samples. The higher the score, the more preferred the text sample is.

The DPO training process is as follows:

  1. Sample text from the language model.
  2. Modify the text to satisfy human preferences.
  3. Give a reward to the language model based on the modified text.

The key to the DPO training process is step 2. There are many ways to modify text to satisfy human preferences. The paper introduces two methods: preference-satisfying generation and preference-satisfying revision.

Preference-Satisfying Generation

Preference-satisfying generation is to generate text from the language model conditioned on human preferences. In other words, it is to generate text with a language model and a preference model. The preference model is usually a binary classifier that takes a text sample and a label as input and outputs a score indicating whether the text sample satisfies the label.

The training process of preference-satisfying generation is as follows:

  • Sample a preference label from a preference distribution.
  • Sample a text from the language model and a preference label.
  • Give a reward to the text based on the preference label.

Preference-Satisfying Revision

Preference-satisfying revision is to revise text generated by the language model to satisfy human preferences. In other word, it is to revise text with a language model, a preference model, and a revision policy. The revision policy is usually a sequence-to-sequence model that takes a text sample, a preference label, and a language model as input and outputs a revised text.

How to Use DPO

The paper provides an open-source implementation of DPO. You can use it to train a language model with your own preferences. To use it, you need to do the following things:

  1. Prepare a dataset of text samples and their corresponding human preferences.
  2. Train a language model on the text dataset.
  3. Train a preference model on the preference dataset.
  4. Train a revision policy with the language model, the preference model, and the DPO library.
  5. Generate text with the language model and the revision policy.
  6. Evaluate the quality of the generated text.

Language Models Can Be Used as Reward Models

Language models can be used as reward models. This is a very interesting idea. It enables us to train language models to satisfy human preferences without reinforcement learning. It also enables us to train language model-based agents to achieve goals without reinforcement learning.

Reinforcement learning is a powerful technique to train agents to achieve goals. However, it is difficult to use reinforcement learning to train large-scale language models because it is computationally expensive. DPO provides an alternative way to train language model-based agent to achieve goals without reinforcement leaning.
