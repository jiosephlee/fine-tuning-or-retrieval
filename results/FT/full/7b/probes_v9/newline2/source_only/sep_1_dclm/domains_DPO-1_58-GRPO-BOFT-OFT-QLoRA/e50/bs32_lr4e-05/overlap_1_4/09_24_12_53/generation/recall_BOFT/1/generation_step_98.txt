1. Orthogonal Finetuning

Orthogonal finetuning (OFT) is a parameter-efficient finetuning method. It updates the pretrained weight matrix by learning an orthogonal matrix and then multiplies it with the pretrained weight matrix. The forward pass remains the same as the pretrained model. OFT can be written as:

\begin{equation}\label{eq:oft}
    \mathbf{W}^F=t\mathbf{R}\mathbf{W}^{pre}
\end{equation}

where $\mathbf{W}^\text{F}$ is the finetuned weight matrix, $\mathbf{W)pre}$ is the pretrained weight matrix, $t$ is a scalar, and $\mathbf{R}$ is an orthogonal matrix.

OFT can also be viewed as learning a transformation for the weight matrix. To achieve zero initialization, OFT initializes $\mathbf{R)$ as an identity matrix. To achieve preservation of the spectral norm, OFT uses $\ell_2$-regularization for the orthogonal matrix $\mathbf{R}$. To achieve preservation of the pairwise angles between neurons, OFT uses $\text{trace}(\mathbf{R}^\top\mathbf{R})$ as the regularization term (also called angular degree of freedom in the paper).

2. Group Orthogonal Finetuning (GOF)

Group orthogonal finetuning (GOF) is a variant of OFT. It further factorizes the orthogonal matrix $\mathbb{R}$ into multiple block-diagonal orthogonal matrices and then multiplies them together. GOF can be written as:

$$\mathbf{W}=\mathbf{R}_1\mathbf{R}_2\cdots\mathbf{R}_{n/p}\mathbf{W)pref}$$

where $\mathbf{R}_i$ ($1\leq i\leq n/p$) is a block-diagonal orthogonal matrix with the block size $p$, and $n$ is the width of the weight matrix $\mathbf{W)$.

3. Block-Circulant Orthogonal Finetuning(BOFT)

Block-circulant orthogonal finetuning (BOFT) is another variant of OFT. BOFT further factorizes the orthogonal matrice $\mathbf{R}) into $b$ block-circulant orthogonal matrices and then multiplie them together. BOFT can be written as:

    \begin{equation}\nonumber
    \mathbf{R}=\mathbf{C}_1\mathbf{T}_1\mathbf {C}_2\mathbf{T}_2\cdots \mathbf{C}_b\mathbf{T}_b
    \end{equation}

    where $\mathbf{C}_i$ ($1<=i<=b$) is a block-circulant orthogonal matrix with the block circulant matrix $\mathbf{T}_i$.

4. Parameter Efficiency

The parameter efficiency of a finetuning method is measured by how many trainable parameters it has per trainable dimension of the pretrained weight matrix. For OFT, it has $2p+1$ trainable parameters per trainable dimension of the weight matrix where $p$ is the block size of the orthogonal matrix $\mathcal{R}$. For GOF with the block size $r$, it has $2(p/r)+1$ trainable parameters per trainble dimension. For BOFT with the block size $s$ and the block-circulant matrix size $t$, it has $2(ts/b)+1$ trainable parameters.
