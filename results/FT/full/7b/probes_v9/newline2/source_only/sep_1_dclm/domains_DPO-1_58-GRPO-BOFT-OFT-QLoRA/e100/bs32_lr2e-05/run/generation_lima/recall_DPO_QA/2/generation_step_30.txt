What is DPO?<|EOT|>Direct Preference Optimization (DPO, from the paper "Direct Preference Optimization") is a method for training language models to satisfy human preferences. It is an alternative to the usual Reinforcement Learning from Human Feedback (RLHF) pipeline like PPO.

In RLHF, we typically have a reward model that outputs a reward signal for each generated text, and then train the language model using RL with this reward signal. In DPO, we instead train the language model to directly optimize a preference score, which is defined as the difference between the rewards given by the reward model for the generated text and the reference text. This preference score can be interpreted as a measure of how well the generated text satisfies the human preference encoded in the reward model, relative to the reference text.

Formally, let $r(s, o)$ be the reward model's reward for generating text $o$ from context $s$. The preference score for generating $o$ instead of the reference text $r$ is then defined as:
$$
\text{pref}(s, o, r) = r(s, o) - r(s, r)
$$
We can then train the language model to maximize this preference score using actor-critic reinforcement learning.<|endoftext|>
