To address this, the paper proposes a method called Orthogonal Finetuning that can finetune a model while preserving the pairwise angles between neurons. The name orthogonal finetuning stems from the fact that the method only uses orthogonal transformations to finetune the neural network. More specifically, OFT uses Cayley parametrization to perform rotation-only orthogonal transformation. This makes OFT the method that imposes the most restrictive constraint among other orthogonal finetuning methods, such as those using the block-diagonal matrix formulation.

## How does OFT work?

To finetune a neural network using OFT, you first need to compute the covariance matrix of the weights for a particular layer. The covariance matrix for a layer $l$ is computed as $\mathbf{C}^{(l)} = \frac{1}{n-l} \sum_{i=1}^n (\mathbf{w}^{(l)}_i - \mathbf{C}^*(l)) (\mathbf{w)^(l)}_i - (\mathbf{w)^*(l)}_i)(\mathbf{w}^*(l)_i - \mathbf {C}^*(l)))$, where $\mathbf{w}^\*(l)$ is the pretrained weight matrix and $n$ is the number of weights in the layer. Once the covariance matrix is computed, we can use it to produce random orthogonal matrices. A random orthogonal matrix is then used to transform the weights in the layer to get the finetuned weights, $\mathbf{w}_i^* = \mathbf{R} \mathbf{w}^(l)_i$, where $\mathbf {R}$ is the orthogonal matrix. The process is repeated for all the layers of the neural network. It's important to note that the covariance matrix is computed only once, and not after every training iteration.
