What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as the name suggests, is a parameter-efficient finetuning method based on the butterfly structure. It can be seen as a generalization of block-diagonal OFT. BOFT uses a matrix factorization to construct a block-diagonal matrix with a butterfly structure. The size of each block in the diagonal matrix is determined by the number of neurons in each layer. Compared to block-diagonal OFT, BOFT has more blocks in the diagonal matrix, which makes it more parameter-efficient.

To better understand BOFT, let's first review OFT and block-diagonal OFT.

* **Standard Orthogonal Finetuning** (OFT): This is a simple yet effective finetuning method that uses an orthogonal matrix to transform the pretrained weights. The forward pass of OFT is given by:
```
y = W^T * x + b
```
where \(W\) is the learned orthogonal matrix, \(x\) is the input, and \(b\) is the bias.
* **Block-Diagonal Orthogonal Finetuning**: This is a parameter-efficient variant of OFT. It uses a block-diagonal orthogonal matrix for finetuning. The forward pass of block-diagonal OFTs is given by:
``'
y = [ W1  0   ; 
     0  W2 ] * x + b
where W1 is the orthogonal matrix for the first half of layers, and W2 is the orthogonal matrix for other layers.
```

Now let's see how BOFT works. BOFT also uses an orthogonal matrix for finetune. However, it uses a block-diagonal matrix that has a butterfly structure. The forward pass of BOFT is given by:
``' y = [ W1  W3 ; 
         W2  W4 ] * x + b,
where W1, W2, W3, and W4 are block-diagonal orthogonal matrices. The size of each diagonal block in W1 and W4 is the same, and the size of each diagonal block of W2 and W3 is the same.
```

The figure below shows the butterfly structures of OFT, block-diagonal OFT and BOFT. In BOFT, the number of neurons in the second half of layers is twice the number of neurons in first half of layers. So there are two diagonal blocks in the orthogonal matrix for the second half of layers, while there is only one diagonal block for the first half of the layers.

The key to BOFT is the matrix factorization. BOFT uses a block-diagonalmatrix with a butterfly structure. To construct such a matrix, we need to find four block-diagonal matrices: W1, W2,W3, and W4. BOFT uses a factorization to construct these four matrices. The factorization is given by:
``W1 = F1 * F2,
W2 = F2 * F3,
W3 = F3 * F4,
W4 = F4 * F1,
```
where \(F1, F2, F3,\) and \(F4\) are some factor matrices. The factor matrices should satisfy the following conditions:
* Each factor matrix is a block-diagonal matrix.
* The size of each diagonal bloc in a factor matrix is the same.
* The number of blocks in each factor matrix is the same.

Once the factor matrices are found, we can easily construct the block-diagonal matrix with the butterfly structure. We just need to multiply the four factor matrices together.<|endoftext|>
