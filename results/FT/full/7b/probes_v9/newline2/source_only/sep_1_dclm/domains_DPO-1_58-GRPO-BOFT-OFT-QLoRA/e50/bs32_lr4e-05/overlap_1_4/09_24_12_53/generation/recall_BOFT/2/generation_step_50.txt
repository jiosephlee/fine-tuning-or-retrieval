Orthogonal Butterfly (BOFT) is an efficient parameterization of orthogonal matrices that enables a block-diagonal structure with a small number of diagonal blocks. BOFT uses a butterfly parameterization that recursively defines a orthogonal matrix with $d$ dimensions as the product of two orthogonal matrices, each with $\frac{d}{2}$ dimensions. By carefully designing the size of the diagonal blocks, BOFT can achieve a significant reduction in the number of trainable parameters compared to OFT while preserving the fast convergence and strong generalizability of OFT. A Brief Introduction to Orthogonal Finetuning

Orthogonal finetuning (OFT)[1] is an effective finetuning method that adapts a pretrained transformer model to downstream tasks. It works by updating the weight matrices with task-specific orthogonal matrices such that the pretrained weight matrices are unchanged. More specifically, OFT updates the weight matrices as $\mathbf{W} \rightarrow \mathbf{W}+\mathbf{R}\mathbf{D}\mathbf{R}^T$, where $\mathbf{R}$ and $\mathbf{D}$ are an orthogonal matrix and a diagonal matrix, respectively. The diagonal elements of the diagonal matrix $\mathbf{D)$ are usually set to be a small learning rate. OFT has several nice properties. First, OFT does not change the spectral norm of the weight matrices, and hence it preserves the spectral properties of the pretrained weight matrices to some extent. Second, OFT only has a single hyperparameter, i.e., the learning rate of the diagonal matrix $\ mathbf{D}$. Third, OFT does not introduce any additional computational overhead during inference.

Despite its great success, OFT has a major shortcoming -- it has too many trainable parameters. For a linear layer with weight matrix $\mathbf{W}$ of size $d\times n$, OFT introduces an orthogonal matrix $\mathbf{R)$ of size $d\tim e n$, resulting in a total of $dn^2$ trainable parameters. This is quite a significant number, especially when $d$ is large. To address this shortcoming, a block-diagonal OFT (BD-OFT) is proposed in BOFT[1], which reduces the number of trainable parameters to $bdn^2$, where $b$ is the number of diagonal blocks. BD-OFT assumes a block-diagonal orthogonal matrix $\mathbf {R}=\text{diag}(\mathbf{R}_1,\mathbf{R}_2,\cdots,\mathbf{R}_{b})$ and a diagonal matrix $\mathbf {D}=\text{diag}(d_1,\cdots,d_b)$, and it updates the weight matrix $\mathbf {W}$ as $\mathbf {W} \rightarrow \ mathbf {W}+\mathbf {R}\mathbf {D}\mathbf {R}^T$.
