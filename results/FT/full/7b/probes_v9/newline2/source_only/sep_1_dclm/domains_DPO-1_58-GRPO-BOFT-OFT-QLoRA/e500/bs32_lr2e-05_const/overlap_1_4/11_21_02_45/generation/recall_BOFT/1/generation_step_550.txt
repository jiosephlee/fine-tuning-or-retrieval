Motivation of the paper

The paper is motivated by the fact that the number of trainable parameters in a model is usually much larger than the number of trainable parameters of the base model. For example, the number of trainable parameters for a pretrained ResNet-50 is 1.2M, while the number of trainable parameters after finetuning is 4.8M. This is because the number of trainable parameters is usually multiplied by the number of layers. The paper proposes a way to reduce the number of trainable parameters.

Main idea

The main idea of the paper is to factorize the weight matrix. For example, the weight matrix of the first layer can be factorized as:

\[ W_1 = \begin{bmatrix} W_{11} & W_{12} \\ W_{21} & W_{22} \end{bmatrix} \]

where $W_{11}$ and $W_{22}$ are trainable matrices, and $W_{12}$ and $W_{21}$ are not trainable matrices. The paper proposes to use orthogonal matrices for $W_{11}$, $W_{12}$, $W_{21}$, and $W_{22}$. The paper also proposes to use a block-diagonal matrix for $W_{22}$, which is a matrix with zeros on the diagonal except for the diagonal elements. For example, the block-diagonal matrix with size 2x2 can be written as:

\[ W_{22} = \begin{bmatr} 0 & 0 \\ 0 & 0 \end{bmatr} \]

The paper also proposes to use the same orthogonal matrix for $W_{11}, W_{12}, W_{21}$, and the block-diagonal matrix for the same block-diagonal matrix for all the layers. The paper calls this method "parameter-efficient orthogonal finetuning via factorization" (PEOFT).
