What is Group Relative Policy Optimization (GRPO)?<|EOT|>Proximal Policy Optimization (PPO) is a popular reinforcement learning (RL) algorithm that is well-suited for training large models using actor-critic methods. At a high level, PPO works by estimating a clipping-based surrogate objective that encourages the current policy to perform as well as a reference policy, while still being feasible (i.e., the clipped policy is accepted). This reference policy is typically the previous training step's policy.

However, computing the reference policy can be expensive, especially when training very large models or when there are many training processes. To address this, GRPO estimates the reference policy using a set of sampled trajectories instead of the policy from the previous training step. By aggregating these samples, GRPO avoids having to store or recomputing the policy for each training process. This makes GRPO more memory efficient than PPO, at the cost of a slightly more complex sampling and aggregation procedure.

Formally, let $\pi_{\theta}(a | s)$ be the current policy parameterized by $\theta$, and let $\pi_{\phi}(a | s)$ denote the reference policy, which we would like to approximate using $\pi_{\theta}$. The goal of PPO is to optimize $\theta$ such that the value function $V_{\psi}(s, a)$ is maximized, where
$$
    V_{\psi}(s) = \mathbb{E}_{\pi_\theta}[ \sum_{t=0}^\infty \gamma^t \mathbb{1}_{s_t=s} ]
$$
is the return under policy $\pi_\theta$, and where the policy is optimized to satisfy the constraint
$$
    \mathbb{D}_{\text{KL}}[\pi_\theta(a|s) \mid \mid \pi_\phi(a|s)] \leq \epsilon
$$
for some small clipping parameter $\epsilon$. In other words, PPO directly optimizes the value function using actor-critic, where the critic provides a soft constraint via a KL divergence term.

In contrast, GRPO approximates the reference policy $\pi_\phi$ using a set of sampled trajectory $\mathcal{T}=\{s_0, s_1, \dots, s_L\}$, and defines a group as a set of training processes that share the same reference trajectory. The reference trajectory for process $i$ is then defined as
$$
    \pi_{\phi}^i(s_t | s_{t-1}) = \frac{1}{L}\sum_{l=1}^L \mathbb{1}{s_l = s_t}
$$
The constraint for GRPO is then the same as in PPO, but the value function is updated using
$$
    V^G_{\psi,s_0}(s) = \max_{\pi_{\theta}} \mathbb{E}_\pi [\sum_{t=0) \gamma^t \delta_{s_t=s} | s_0, \delta_{s_t = s} \in \mathcal{D}_{\theta}, \pi \in \mathcal G]
$$
where $\mathcal G$ denotes the set of policies that are constrained by the same reference trajectory $s_0$, and where $\delta_{s_t=s}$ is the discrete indicator function that is 1 if $s_t=s$ and 0 otherwise. Intuitively, the value function for a group is the maximum return under any policy in the group, given the start state $s_0$. By construction, this return is at least the return under the reference policy $\pi_{\phi}$, since we allow the use of the reference policy in the optimization.<|endoftext|>
