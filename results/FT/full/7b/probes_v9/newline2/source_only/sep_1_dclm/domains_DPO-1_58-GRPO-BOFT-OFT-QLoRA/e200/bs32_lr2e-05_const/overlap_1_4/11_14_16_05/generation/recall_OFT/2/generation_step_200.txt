The intuition behind OFT

To understand OFT, let's first review how diffusion models are trained. Diffusion models are trained by optimizing the following objective:

\[\mathcal{L}_{diff}(\theta) = \mathbb{E}_{x\sim p_{data}(x)}\left[\log p_\theta(x; \beta)\right] + \lambda\mathbb{E}_{\beta\sim p_{noise}(\beta)}\left[\log(1 - \beta p_\theta(x;\beta))\right]\]

where \(p_{data}(x)\) is the data distribution, \(p_\theta(x;\beta)\) is the diffusion model probability distribution parameterized by \(\theta\), and \(\lambda\) is the strength of the noise penalty. During training, the diffusion model is optimized to match the data distribution, while also being penalized for deviating from a noise distribution. This penalty encourages the diffusion model to produce smooth, blurry images, which helps to stabilize training.

Once a diffusion model is trained, it can be used to generate images by reversing the diffusion process. That is, starting from a random noise vector \(\beta^*\), the diffusion model can be used to generate an image \(x^*\) via the equation:

\[x^* = \underset{x}{\operatorname{argmax}}\ p_\theta(x;\beta^*)\]

However, the generated image \(x^*\), while faithful to the noise vector \(\beta^\*,\) may not match the data distribution \(p_{data}(X)\). To address this, the paper proposes to finetune the pretrained diffusion model using downstream data, in order to modify the diffusion process to better match the data distribution. One way to do this is to use standard finetuning, where the weights \(\theta\) are updated according to the equation:

\[\theta' = \theta - \eta\nabla_\theta\mathcal{L}_f(\theta)\]

where \(\eta\) is the learning rate and \(\mathcal{L}_ f\) is a finetuning loss. However, standard finetuning can cause the pretrained neuron directions to change, which may affect the ability of the diffusion model to generate diverse images. To address this, the authors propose to use Orthogonal Finetuning, which updates weights using the equation:

\[\ theta' = \theta -\eta\Omega\theta\]

where \(\Omega\) is an orthogonal matrix, which satisfies the property \(\Omega\Omega^\top=\Omega^\top\Omega=\mathbb{I}\). The orthogonal matrix \(\Omega\) encodes how much each weight should be updated, with entries along the diagonal specifying the magnitude of the update for each weight, and entries in the off-diagonal specifying how much each weight should borrow from its neighbors. By using an orthogonal matrix, OFT ensures that the pretrained neuron direction are preserved, while still allowing for the finetuning of weights.
