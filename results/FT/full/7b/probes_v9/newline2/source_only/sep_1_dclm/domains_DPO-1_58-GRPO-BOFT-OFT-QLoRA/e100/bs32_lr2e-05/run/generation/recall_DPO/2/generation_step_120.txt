The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a new algorithm, called Direct Preference Optimization (DPO), that can efficiently optimize a language model to match human preferences without relying on an intermediate reward model. DPO works by fitting a parameterized function to the pairwise preferences provided by humans, and then optimizing the language model to maximize the fitted function. The authors evaluate DPO on three benchmarks: (1) a synthetic preference dataset generated from a reward model, (2) a real-world preference dataset collected by Alpaca, and (3) the Vicuna benchmark. On the synthetic dataset, DPO matches the performance of the reward model while being much more efficient to train. On the Alpaca dataset, DPO matches or improves upon the performance of existing methods while being significantly more efficient. On the Vicuna benchmark, DPO performs worse than existing methods but is still competitive while being much more efficient.

Formalizing the Problem

We start by defining some notation that will be used throughout the post. Let $\pi$ be a language model, i.e., a distribution over sequences of tokens $p(\mathbf{x}|\mathbf{z})$. Let $\succsim$ be a binary relation on token sequences, i.e., a function that takes in two sequences of tokens $\mathbf{x},\mathbf{y}\in\mathcal{X}$ and returns true if $\mathbf{y}$ is preferred over $\mathbf{x}$, and false otherwise, i.e., $\succsim(\mathbf{x},\ mathbf{y})\coloneqq \text{true}\ if\ \mathbf{y}\ \text{is preferred over}\ \mathbf{x}$.

Given a language model $\pi$ and a preference relation $\succsim$, the goal of preference learning is to find a new language model $\pi^*$ that satisfies the preference relation, i.e., $\mathbf{x}\not\succsim\mathbf{y} \implies \pi^*(\mathbf{x})\leq \pi^*(\ mathbf{y}),\forall\mathbf{x},\forall\mathbf{y}$.

Reinforcement Learning from Human Preferences

One way to learn a preference-satisfying language model is to treat the problem as a reinforcement learning (RL) problem and use RL algorithms such as PPO (Proximal Policy Optimization) to optimize the language model. In this setting, the agent is the language model, and at each time step $t$, the human provides a reward $r_t(\mathbf{x}, \mathbf{y})$ for an agent action $\mathbf{x}$ followed by an environment action $\mathbf{y}$. The reward function is parameterized by a reward model $\varphi$, i.e., $r_t(\math bf{x}, \mathbf y)\coloneqq \varphi(\mathbf{x}, \mathbf{y},\theta)$, where $\theta$ are the model parameters. The agent's goal is to maximize the sum of rewards it receives, i.e., $\sum_{t=1}^T \gamma^tr_t(\mathbf{x}_t,\mathbf{y}_t)$, where $\gamma$ is the reward discount factor. In the context of language, the agent takes the action of sampling a token $\mathbf{x}_t\sim\pi$, and then the environment samples a token $\mathbf{y}_tr(\mathbf{x}, \mathbf{y})= \varphi( \mathbf{x}, \mathbf{y},{\theta})$ and returns the reward to the agent. This is known as the RL from demonstrations setting, where the demonstrations are the rewards provided by the human.
