According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) structure is a parameter-efficient variant of the block-diagonal structure, which is widely used in finetuning models. It achieves parameter-efficiency by replacing the block-diagonal matrix with an asymmetric block-diagonal matrix that has a particular form of block-diagonal blocks. More specifically, the BOft structure has a block-diagonal matrix where each diagonal block is further divided into two sub-blocks with a banded matrix connecting them. This structure can be written as:

$$\begin{bmatrix}
R_1 & C \\
C^T & R_2
\end{bmatrix}$$

where $R_1$ and $R_2$ are banded matrices with the band size $\ell$, and $C$ is a skew-symmetric matrix with $C=-C^T$. The BOft structure with the block number $r=2$ is shown in Figure~\ref{fig:boft}.

The BOft structure can significantly reduce the number of trainable parameters. For a fully connected layer with the input dimension $d$, the standard block-diagonal structure has $(d-k) \cdot \text{diag}(l_1, l_2, \cdots, l_k)$ trainable parameters, where $k$ is the number of blocks, and $l_i$ is the size of the $i$-th block. In contrast, the BOft structure with the parameter $r$ has only $(d-k) \left( \frac{l_1(l_1-1) + l_2(l_2-1) + \cdots + l_k(k-1)}{r} \right)$ trainable parameters. When $r=2$, it reduces the number of parameters to $\frac{1}{2} \text{Diag}(l_1, \cdots,  l_k) \cdot (l_1-1 + l_2-1 + \cdots +  l_k-1)$, which is exactly half of the number of parameters used by the standard block-diagonal structures.

The BOft structure was first introduced in the paper "Parameter-Efﬁcient Orthogonal Finetuning" for parameter-efficient finetuning. It was later combined with the spectral normalization in the paper "Orthogonal Butterfly: Spectral Normalization, and State-of-the-art Performance in Text-to-Image Diffusion" for better performance.<|endoftext|>
