These models are trained on large datasets of text-to-image pairs, often in an unsupervised manner. During training, the text prompts are randomly generated, but during inference, we usually want the model to generate images that are coherent and stay faithful to a given prompt. 

One approach to achieve this is finetuning, where we take a pretrained text-to-image diffusion model and finetune it on a dataset of desired images. The intuition is that we finetune the model to fit the distribution of desired images, while at the same time, we want to preserve the semantic generation ability learned from the pretrained model. There are many ways to finetune a neural network, and in this paper, we focus on a particular finetuning strategy called Orthogonal Finetuning, which achieves strong performance in controlling text-to-image diffusion models.

### Standard Finetuning

In standard finetuning, we modify the weights of a pretrained model by only updating the weights using gradient descent based on the loss function computed from the dataset of desired images. Formally, for a single layer $l$, the update rule is:

$$ w_l^{(new)} = w_l^{(pretrained)} - \eta \nabla_w L(w_l) $$

where $\eta$ is the learning rate and $L$ is the loss function. This is a small modification from the pretrained model, but it can lead to significant changes in the resulting model, as the weights are free to change in any direction.

### Additive Finetuning (e.g., LoRA)

Another approach to finetuning is additive finetuning, such as Layer-shared Adapters (LoRA). In additive finetuning, we add a small trainable matrix to each neuron in a layer, and the resulting new weights are used for inference. For additive finetuning in a single layer $l$ with the update rule, we have:

$$ w_l^{(new)} = w_l^{(pretrained)} + A_l $$

where $A_l$ is a matrix learned through finetuning. This way, the neurons will only change by the amount specified by the trainable matrix $A_l$, and the direction of the neurons ($w_l^{(pretrained)})$ will be preserved.

### Orthogonal Finetuning

Orthogonal finetuning is a variant of additive finetuning. In orthogonal finetuning, we only add a matrix with orthogonal neurons. This has the advantage that the orthogonal matrix will not destroy the pair-wise angles between neurons, while still allowing us to add a small deviation to the neurons. The challenge is how to constrain a matrix to have orthogonal neurons. We can impose this constraint using a Cayley parameterization. A matrix $A$ is orthogonal if $AA^T=A^TA=I$, where $I$ is the identity matrix. A general matrix in $R^{m\times m}$ can be written as $A=SDS^T$, where $S$ is a special matrix called the Cayley parameter (also known as a skew-symmetric matrix) with $S=-S^T$.
