The baseline is typically the average performance of the same agent in the same circumstances in the recent past. In other words, the baseline removes the systemic error, so the algorithm only learns from random noise.

In many RL applications, it's common to organize the agents into groups, and have a leader for each group. The leader is the agent with the highest current performance in the group. In GRPO, the baseline of each agent is the performance of the leader of its group. This way, the algorithm only uses the information about the relative performance of the agents, and doesn't require keeping the entire historical performance data of each agent.
