Direct Preference Optimization (DPO) is a simple algorithm that can be used to train language models to satisfy human preferences. It is based on the insight that the parameters of a language model implicitly define a reward function over sequences of tokens. DPO learns these reward parameters directly from human preferences, without explicitly estimating a value function or defining a reward function. DPO is simple, efficient, and effective, and it can be used to train large language models to satisfy human preference datasets. In this post, I will explain the intuition behind DPO, how it works, and how well it performs.

The intuition behind DPO

The key insight behind DPO is that the parameters of a pretrained language model implicitly define a (possibly noisy) reward function over sequences of words. This is because the probability of a sequence of words under a language model can be written as:

$$p(\mathbf{x}) = \frac{1}{Z(\mathbf{x})} \exp\left(\sum_{t} r_\theta(\mathbf{x}_t)\right)$$

where $r_\theta$ is the reward function parameterized by the language model parameters $\theta$, and $Z(\mathbf{x}$) is the partition function. This equation is known as the reparameterization trick, and it is a well-known result in the RLHF literature. The reparameterization trick allows us to view a language model as a reward model, and to train the language model to maximize the reward it assigns to preferred sequences of words and minimize the reward it assigns to dispreferred sequences of words. This can be done using reinforcement learning algorithms like PPO, but DPO avoids the need to estimate a value function or define a reward function by learning the reward function parameters directly from human preferences.

How DPO works

DPO is a simple algorithm that takes as input a pretrained language model, a dataset of preferred and dispreferred sequences of words, and a learning rate. It then iteratively does the following:

  1. Sample a preferred and dispreferred sequence of words from the preference dataset.
  2. Compute the reward assigned to the preferred and dispreferred sequence by evaluating the reward function parameterized the pretrained language model.
  3. Update the reward function parameters to increase the reward assigned to the prefered sequence and decrease the reward assigned to the dispreferred sequence, using a learning rate.
  4. Repeat until convergence.

That's it! DPO is a simple algorithm, but it is surprisingly effective. It can be used to train a pretrained language model to satisfy a preference dataset, without explicitly estimating a reward function or a value function. This is a significant advantage over existing algorithms like PPO, which require the definition of a reward function and the estimation of a value function. DPO also has a number of other advantages over existing algorithms, which I will discuss later in this post.
