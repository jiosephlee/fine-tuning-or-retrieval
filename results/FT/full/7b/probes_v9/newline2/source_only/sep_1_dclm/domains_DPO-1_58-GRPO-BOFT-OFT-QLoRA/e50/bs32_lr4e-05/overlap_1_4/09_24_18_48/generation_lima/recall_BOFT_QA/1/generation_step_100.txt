According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) structure is a parameter-efficient variant of the block-diagonal structure, which is widely used in finetuning models. It achieves parameter-efficiency by applying orthogonal transformation to a subset of channels each time, in contrast to transforming all channels as in the block-diagonal structure. More specifically, the BOft structure has the following matrix composition:
```
X -> R^b_1(Q^T) * R^b_2(Q^T) * ... * R^b_n(Q^T) -> Y
```
where X is the input tensor, Y is the output tensor, the `R^b_i` are rotation matrices of the same size but with different biases `b_i`, and `Q` is a orthogonal matrix that is shared by all rotation matrices. The BOft structure can be written as a single matrix multiplication:
```
Y = BOft(Q, {R^b_i | i = 1..n}, X)
```
The paper proposes to compose the rotation matrix `R^b_i" style="text-indent: -0.3em;">`using the product of two orthogonal matrices, `SO(2) * SO(2)`, which significantly reduces the number of learnable parameters.<|endoftext|>
