According to the paper "QLoRA: Efficient Finetuning of Quantized LLMs", what is QLoRA?<|EOT|>The paper introduces a method for efficient finetuning of quantized large language models (LLMs). The method, which they name QLoRA, uses low-rank updates for weight matrices and adds low-rank adapters for new layer inputs. This approach reduces the memory requirements of finetuning by a factor of 8 while still achieving state-of-the-art performance on downstream tasks.

Here is a quote from the paper that explains the motivation behind the method:

"Finetuning all weights in a LLM of size 3B using standard methods requires 384 GB of memory, which is out of reach for most researchers and prohibitively expensive. To address this issue, we need to reduce the memory requirements of finetting without sacrificing performance. There are two key sources of memory usage in finetuning models: 
1. Computing the gradient of the loss with respect to the model parameters incurs additional memory requirements due to the storage of gradient checkpoints.
2. Applying gradient updates to the model parameters also incurs additional memory requirements because the parameters are duplicated to accommodate the parameter updates.
For weight matrices, we address these issues by applying a low-rank update to the parameters instead of performing a full-parameter update. Low-rank updates do not duplicate the parameters and can be efficiently differentiated through implicit differentiation of the low-rank update formula. For input embeddings, we apply a similar low-rank update where we add a low-rank adapter to the input embedding instead of performing a fullparameter update to change the embedding. This results in a method that we name QLoRA (Quantized LLM finetuning with Low-rank Adapters)."<|endoftext|>
