According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT) is a parameter-efficient orthogonal finetuning method. BOFT uses a butterfly structure to recursively construct larger orthogonal matrices from smaller ones. Specifically, for a matrix of size $d \times n$, BOFT first initializes it with $\text{Identity}(d,n)$, then updates it with
```
M = M @ Orthogonal(ceil(n/2), n, Rho) @ ConjugateTranspose(Orthogonal(floor(n/2), n,
Rho))
```
where `@` denotes matrix multiplication and `$\Rho$ > 0` is a hyperparameter. This process is repeated until `$n = 1$`. The key insight behind BOFT is that the product of multiple orthogonal matrices remains orthogonal, which enables efficient finetuning without requiring any learnable parameters.

The name "butterfly" comes from the fact that the update formula resembles a mathematical expression for a butterfly:
```
M = M * O1 * O2 * ... * On
   \ /     |     \
   / \     |      \
O1  O2    O3       On
 \ /     |      /
  \ /     |     /
   O2    O3   On+1
    \ /     |      \
     O1     O2      On
```
where `$On+1 = On * On$`.<|endoftext|>
