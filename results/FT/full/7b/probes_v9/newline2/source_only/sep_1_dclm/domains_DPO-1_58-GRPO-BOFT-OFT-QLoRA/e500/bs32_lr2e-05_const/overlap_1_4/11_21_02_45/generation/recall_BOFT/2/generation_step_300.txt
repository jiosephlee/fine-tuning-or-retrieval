Parameter-Efficient Finetuning

Standard finetuning is an effective yet simple method for adapting large pretrained models to downstream classification tasks. It works by iteratively updating a pretrained model with a small learning rate. Despite its simplicity, finetuning is far from optimal in terms of the number of trainable parameters. In fact, most of the parameters in a pretrained model are not changed during finetuning, i.e., they are simply copied over from the pretrained model. This means that the parameter budget of a pretrained model is not utilized efficiently, which motivates the study of parameter-efficient finetuning (PEFT) methods.

There are many PEFT methods, such as Low-rank Adapters (Li et al., 2021), Parameter Efficient Fine-Tuning (PEFT) (Chen et al., 2022), and Efficient Finetuning (EFF) (Sun et al., 2020). These methods typically represent the pretrained model with a small set of trainable parameters and then update the forward pass of the pretrained model with an additive or multiplicative weight. In contrast to these methods, Orthogonal Finetuning uses a small orthogonal matrix to transform the pretrained features.

Orthogonal Finetuning

Orthogonal Finetuning (Zhang et al., 202.2) is a parameter-efficient method for finetuning pretrained models. It works by updating the pretrained features with the product of the pretrained features and a small orthogonal matrix. Orthogonal Finetuning has several attractive properties. First, it is simple to implement and easy to use, e.g., you only need to add one line of code to enable Orthogonal Finetuning for any pretrained models and downstream tasks. Second, Orthogonal Finetune converges quickly and typically reaches the same accuracy as full finetuning after a small number of training iterations. Third, Orthogonal Finetunig is more parameter-efficient than standard finetuning, since it reuses the parameters of the pretrained model. Despite these advantages, Orthogonal Finetnue has one major drawback: it is less parameter-efficient than necessary. In fact, OFT uses a full orthogonal matrix for transforming the pretrained features, which results in a large number of trainable parameters. To address this shortcoming, a block-diagonal variant of OFT was proposed in (Zhang et al. 2022), which only updates a small set of neurons for each layer.

Block-Diagonal Orthogonal Finetuning

Block-diagonal Orthogonal Finetnuing (BOFT) (Zhang et al 2022) is a parameter efficient variant of OFT. BOft works by updating only a small set of neurons in each layer with the product of the corresponding neurons and a block-diagonal orthogonal matrix. BOFT addresses the main shortcoming of OFT, i.e., its low parameter-efficiency, while preserving its fast convergence and simplicity. Despite these advantages, BOFT has a number of drawbacks. First, the block-diagonal orthogonal matrix in BOFT must be learned from scratch, which makes BOFT more complex to implement and use than OFT. Second, the block-diagonal matrix in BOFT is learned for each layer separately, which makes BOFT less regularized than OFT. Third, the block-diagonal approach in BOFT does not fully exploit the parameter-efficiency of orthogonal matrices. In fact, orthogonal matrices can be multiplied with each other to obtain a more dense orthogonal matrix that transforms the same set of neurons. Motivated by these observations, we present a novel and more parameter-efficient way of generating block-diagonal matrices in this paper.
