What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as the name suggests, is an efficient variant of Orthogonal Finetuning. It achieves parameter efficiency by using a butterfly matrix structure, which is a particular way to construct a banded matrix from multiple dense matrices.

The key insight behind BOFT is that we can compose multiple dense layer weight matrices into a block-diagonal matrix with sparse blocks, and then stack these block matrices one below another to form a butterfly matrix. This composition can be written as a product of three matrices: a permutation matrix, a block-diagonal matrix, and the transpose of another permutation matrix. The permutation matrices are used to reindex the elements of the original weight matrices such that the resulting butterfly matrix has a specific block structure. The block-diagonal matrix arises from the fact that we only depend on a subset of neurons in the previous layer for each neuron in the current layer. The transpose of the first permutation matrix is used to restore the original index.
