2 Background

2.1 Orthogonal Finetuning

Orthogonal finetuning (OFT)[1] is a parameter-efficient finituing method that adapts pretrained language models to downstream tasks. OFT updates the weights of a pretrained model by adding a small orthogonal matrix multiplied by a learning rate. More specifically, OFT updates the weights $w\in\mathbb{R}^{d\times h}$ of a linear layer from a pretrained model $\bm{W}^0\in\mathbb {R}^{d\tim h}$ as follows:

$\bm{W}=\bm{W}^{\text{OFT}}(t)=\bm{W}^{}+\beta \bm{R}(t),\qquad(\star)$

where $\bm{R}(t)\in\mathbb{ R}^{d\times d}$ is an orthogonal matrix whose entries are drawn from a zero-mean unit-variance Gaussian distribution at each time step $t$, and $\beta$ is the scale hyperparameter. The orthogonality of $\bm{R}( t)$ ensures that the pretrained vector norm is preserved, and the small learning rate $\beta$ prevents catastrophic forgetting[2].

2.2 Block-Diagonal OFT

The block-diagonal OFT (B-DOFT)[3] is an extension of OFT that further reduces the number of learnable parameters. B-DOFT sets the off-diagonal blocks of the weight matrix in $(\star)$ to zero, resulting in a block-diagonal weight matrix. Formally, B-DOFT updates the weight matrix $\bm{W}^\text{B-DOFT}\in\mathbb{ {R}}^{b\times h}$ as follows:

\begin{equation}\label{eq:bdoft}
    \bm{W}^{}\leftarrow\bm{W}^\mathrm{B-DOFT}+\beta \bm{D}(t),
\end{equation} where $\bm{D}(t)\in\{0, I_{b}\}^{b\times b}$ is a block-diagonal matrix with $I_b$ being an identity matrix of size $b\times b$, and the other entries are set to zero. The block size $b$ determines the number of effective trainable parameters; smaller $b$ leads to fewer parameters. B-DOft has been shown to be more parameter-efficient than OFT while preserving the performance.[3]

3 Butterfly Structure

The butterfly structure is a sparse matrix factorization that has been used in various applications such as fast Fourier transform and image compression.[4][5][6] A butterfly matrix $\bm{B}\in\mathbb {C}^{n\times n}$ can be written as the product of two binary matrices $\bm{A},\bm{C}\in\mathbb C^{n\times m}$ with $m<n/2$ as follows:

\begin{salign}\label{eq:butterfly}
    \bm{B}=\bm{C}\bm{A}^{\top},\qquad (\dagger)
\end{salign} where $\bm{A}^*$ denotes the conjugate transpose of $\bm{A}$. The number of branches incident to a node $n$ is called the fan-out of the butterfly matrix $\BM{B}$.
