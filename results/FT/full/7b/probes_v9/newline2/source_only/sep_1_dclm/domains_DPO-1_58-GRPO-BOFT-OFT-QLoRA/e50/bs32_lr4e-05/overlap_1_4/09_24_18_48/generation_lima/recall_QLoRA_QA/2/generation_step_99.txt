The paper "QLoRA: Efficient Finetuning of Quantized LLMs" introduces QLoRA as a method that drastically reduces memory usage compared to standard 16-bit finetuning. What is QLoRA?<|EOT|>Sure, here is the executive summary:

* 16-bit finetunig is much more memory efficient than 32-bit finetuning, but it still requires a lot of memory, especially for large models.
* One reason why 16-bit finetunning requires so much memory is that most frameworks (TensorFlow, PyTorch) internally use double precision (32-bit floats) for all computations, even when 16-bit data is provided.
* QLoRA is a method that allows using 16-bit weights and 16-bit gradients, while still using TensorFlow or PyTorch in a straightforward way.
* The key idea of QLoRA is to separate the role of the weights: Some weights are used for computing the gradient (these are called gradient weights and stored in a gradient weight buffer, GWB)) and some weights are used for the actual forward and backward pass (these are called computation weights and stored in a computation weight buffer, CWB)).
* To compute the gradient, the gradient weights buffer is copied into the computation weights buffer, a gradient is computed the usual way (using double precision) and then the gradient is backpropagated.
* To allow for online learning, the buffers for the gradient weights and the computation weights have a fixed size, but new values overwriting the oldest ones.
* To avoid that the copying of the gradient weights into the computation weights messes up the covariance structure, the paper introduces a momentum term that is only applied to the gradient weights.
* In addition to the memory savings, the paper also reports that learning rates that are 4-8 times higher lead to the same validation loss.

The paper also reports that the procedure can be generalized to 4-bit weights with minor modifications.<|endoftext|>
