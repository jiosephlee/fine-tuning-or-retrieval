1. Mathematical Reasoning in OpenLanguage Models

Mathematical reasoning is an important but challenging task for language models. It requires models to understand the mathematical context, perform mathematical inference, and generate accurate and fluent mathematical texts.

There are mainly three types of mathematical reasoning tasks:

  • Multiple-choice question answering (MMLU-STEM, MATH)
  • Formulation-to-solution question answering (MATH)
  • Problem solving (MATH)

2. Reinforcement Learning from Human Feedback (RLHF)

Reinforcement learning from human feedback (RLHF) is a kind of reinforcement learning that trains language models using human feedback data. It has two phases:

  • Exploration phase: Generate data of positive and negative feedback for the model.
  • Training phase: Train the model using the data from the exploration phase.

3. PPO Algorithm

Proximal Policy Optimization (PPO) is an actor-critic reinforcement learning algorithm. It optimizes the parameter of the policy model using a surrogate objective function. The surrogate objective function is the sum of the advantage function and a clipping coefficient times of a per-timestep penalty term.

The advantage function is the expected reward minus the expected reward of the baseline policy. The baseline policy is usually the current policy model.

4. CLIPPO Algorithm

CLIPPO is an improved version of the PPO algorithm. It improves the stability of the PPO algorithm in the RLHF training process.

5. DPO Algorithm

Direct Preference Optimization (DPO) is a kind of RLHF algorithm that directly optimizes the parameter of a preference model using preference data. It doesn't need the intermediate step of generating positive and negative feedback for a language model.

6. Supervised Fine-Tuning (SFT)

Supervised Fine-Tuning (Sft) is a kind of model training method that fine-tunes a pre-trained language model using a training set of input-output pairs.

7. MathSFT Model

MathSFT is a kind of SFT model that is trained on a dataset of mathematical input-output pairs.

8. Meta SFT Model

Meta SFT is a kind of model that is trained on the output of SFT models on different datasets. It can be viewed as the distillation of a collection of SFT models.

9. Reinforcement Learning from Assistant (RLA)

Reinforcement Learning from Assistant (RAL) is a kind of training method that trains a language model using the feedback data generated by an assistant model.

10. RLHF+ Model

RLHF+ is a kind of model the is trained using a combination of RLA and SFT.

18. Training and Evaluating DeepSeekMath

DeepSeekMath is a kind of model with 7B parameters that is trained using a combinationof RLHA++++++, RLHF+++, and SFT. It achieves 84.2% accuracy on the MATH dataset and 82.9% accuracy on the GSM8K dataset.

19. More Results of DeepSeekMath

In addition to the results on the MATH and GSM8K datasets, DeepSeekMath also achieves 77.8% accuracy on the competition-level MMLU-STEM dataset and 84.2% correctness on the benchmark arXiv:math papers.

21. Limitations and Future Work

Although DeepSeekMath performs well on mathematical reasoning benchmarks, it still has some limitations. For example, it doesn't perform well on long-form mathematical texts. In the future, DeepSeek will continue to improve mathematical reasoning capabilities in our open language models. We will also explore different training strategies, such as training on instruction-tuned models and training with few-shot inputs.
