C. Training a Language Model as a Reward Model
One important difference between DPO and existing RLHF algorithms is how they initialize the language model. Existing algorithms typically initialize the language model using a standard unsupervised LM objective, such as negative log-likelihood. In contrast, DPO initializes the language model as a reward model that outputs the reward value for each completion y 2 given the prompt x. Specifically, the reward model is initialized by fitting a linear regression model to the preference counts in the preference dataset. The preference count for completion y 2 given prompt x is defined as the number of times y 2 is preferred over y * in response to x in the preference dataset.
