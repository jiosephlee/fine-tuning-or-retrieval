1. What is Text-to-Image Diffussion?

Text-to-image diffusion is a kind of generative adversarial network (GAN). It can generate images from text prompts. The text prompt is a short description of the image. For example, "a black and white photo of a man in a suit standing in front of a building".

The text prompt is usually very short, only a few words or even a single word. But the text-to-image diffusion model can still generate a high-quality image based on the text prompt.

The text-to-image diffusion model is composed of two parts: the generator and the discriminator. The generator is responsible for generating images based on the text prompt. The discriminator is responsible for judging whether the generated image is real or fake.

The text-to-image diffussion model is trained in an iterative way. In each iteration, the generator will generate some images based on the text prompts. The discriminator will judge whether these images are real or fake. Then the generator will update its parameters based on the feedback from the discriminator. After many iterations, the generator will become better and better at generating high-quality images based on the text promps.

2. How does Text-to-Image Diffuation work?

The text-to-image diffusion works in an iterative way. It has a few key components:

  • A pretrained text-to-image diffusion model
  • A set of text prompts
  • A finetuning rate
  • A noise vector

The pretrained text-to-image diffusion models are usually very large. They have millions or even billions of parameters. But we don't need to train them from scratch. We can use a small set of text prompts to finetune the pretrained model.

The finetuning rate is the learning rate of the finetuning process. It determines how much the finetuned model will deviate from the pretrained model.

The noise vector is a random vector that will be added to the input of the generator in each iteration. It helps to make the generated images more diverse.

In each iteration, the text-to-image diffusion works like this:

  1. Sample a noise vector
  2. Generate some images based on the noise vector and the set of text prompts
    • The number of generated images is usually a few hundred or a few thousand
  3. Run the binary cross entropy loss between the real images and the generated images
    • The real images are the images in the dataset
  4. Update the generator based on the gradient of the binary cross entropy loss
  5. Repeat steps 1 to 4 for a few epochs
  6. Save the finetuned generator model

After finetuning the generator model, we can use it to generate images based on the set of text prompts. We don't need the original pretrained model anymore.

3. What is Orthogonal Finetuning?

Orthogonal finetuning is a way to finetune the generator model. It uses Cayley parametrization to transform the generator model. The transformed model has the same capacity as the original model, but its weights are orthogonal matrices.

The orthogonal finetuning works like this:

  • Sample a random matrix from the standard normal distribution
  • Multiply the random matrix to the generator model
  • Get the finetuned model

The random matrix is usually very small, only a few hundred or a thousand elements. So the orthogonal finetuning will only slightly change the generator model. But it can still make the model better at generating images based on the set text prompts.
