Let me tell you all about this paper. The paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models" presents a novel and efficient method for improving mathematical capabilities in language models, Group Relative Policy Optimization (GRPO), instead of the standard memory-intensive PPO algorithm. Group Relative Policy Optimization (GRPO) is a variant of Proximal Policy Optimization (PPO) that reduces the memory requirement from per-policy-sample to per-group-of-policies. It achieves this by maintaining running averages of the advantage function and its gradient, where a group of policies is defined as policies trained with the same set of parameters but different learning rates. This allows us to train a mathemantly capable model, DeepSeekMath, with 7B parameters using only 48GB of memory on a single GPU, which is impossible using the standard PPO algorithm.

The DeepSeekMath model is initialized using the DeepSeek-Coder-v1 model, which is based on the open-source EleutherAI GPT-3 codebase and trained on a diverse dataset of more than 10T tokens, including code, web pages, books, and academic papers. After a warm-up phase of math-related pre-training, the model is fine-tuned using the High-Quality Mathematical Sequences (HQMS) dataset for 150B tokens. In the final stage, we combine Group Relative Policy Optimization ( GRPO) with a small set of math-specific datasets for 10T tokens, consisting of the MathPile v2 dataset, the MathInstruct dataset, and the Proof-Parsing dataset. evaluation results show that the DeepSeekMath model outperforms all open-source models (including the most recent 70B-parameter GPT-4 from OpenAI) on the MATH benchmark by a considerable margin. It also performs well on the GSM8K and MetaMath benchmarks. Most impressively, the DeepSeekMath model is the first open-source model to obtain a score of over 50% on the competition-level CEMSI benchmark, which is usually only accessible to proprietary models.
