Let's start with the problem statement. When we train a neural network from scratch, we need a lot of training data to avoid overfitting. To adapt a pretrained model to a specific task, we typically use finetuning, which is a simple training procedure where we keep the pretrained model weights fixed and only update a small portion of the weights, usually the fully connected layers or the top layer of a convolutional neural network. Finetuning has been proven to be very effective for adapting pretrained models to downstream tasks, but it also comes with a cost. Since we are modifying the weights of the pretrained model, we are increasing the number of model parameters, which can be a concern, especially for very large models. To address this, there have been several parameter-efficient finetuning approaches proposed, such as group normalization, layer normalization and block-diagonal finetuning. These methods zero out most of the weights of the pretrained models, which significantly reduces the number of trainable parameters.
