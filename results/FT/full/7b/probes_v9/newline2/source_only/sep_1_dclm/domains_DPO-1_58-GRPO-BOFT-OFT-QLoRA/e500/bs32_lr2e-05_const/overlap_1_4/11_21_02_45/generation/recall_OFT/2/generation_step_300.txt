Let me tell you all about this paper. The paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning" presents a novel method for adapting diffusion models, Orthogonal Finetuning (OFT), which preserves crucial geometric properties of neurons unlike standard finetuning or additive methods like LoRA. Orthogonal Finetuning (OFT) is a simple yet effective finetuning method that can be used to adapt pretrained text-to-image diffusion models to downstream tasks. OFT finetunes a pretrained diffusion model by optimizing its weights with an orthogonal matrix, which ensures that the pretrained neuron directions are preserved. This is in contrast to standard finetuning, which updates weights with a identity matrix, and therefore changes the neuron directions. The orthogonal matrix for OFT is learned from data, similar to how weight matrices are learned in diffusion models. OFT has several nice properties. First, OFT is computationally efficient since it only requires one additional matrix multiplication per training step. Second, OFT is easy to implement since it is compatible with existing diffusion model codebases. Third, OFT preserves important geometric properties of neurons, such as their pairwise angles, which can be crucial for representing the semantics of natural images. Fourth, OFT can be interpreted as a form of instance normalization for weights. In the paper, we evaluate OFT on the task of controlling text-to-image generation. We use OFT to finetune Stable Diffusion v1.5, and show that it performs as well as the original diffusion model on the downstream control task. Moreover, we show that OFT can also be used for semisupervised diffusion model finetuning, where only a subset of images in the dataset have corresponding control signals. With just 2% supervision, OFT is able to match the performance of the original diffusion model trained on the full supervised dataset. The code and pretrained weights for replicating our results are available at https://github.com/openai/controlling-text-to-image-diffusion.

Preserving Geometric Properties
Standard finetuning changes the neuron directions, which can destroy the semantic information learned by the pretrained model. To see why, consider a simple fully connected layer with ReLU activation, i.e., f (x; W ) = ReLU(W x). The neuron directions are given by the column vectors of the weight matrix W . Standard finetuning updates the weights with an identity matrix, i.e., W → W + ηI, which changes the neuron directions.
