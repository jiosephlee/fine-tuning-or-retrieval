What is Parameter-Efficient Finetuning?

Parameter-efficient finetuning (PEFT) is a method that reduces the number of trainable parameters in finetuning stage. It can be applied to any pretrained model. The key idea is to factorize the pretrained model and only finetuning the factorized parameters.

Why do we need Parameter-Efficient Fineteuning?

The number of trainable parameters in the finetuning stage is usually much smaller than the pretrained model. For example, in natural language processing, the number of trainable parameters is usually less than 1% of the pretrained model. This is because the pretrained model has already learned a lot of knowledge from a large-scale dataset. So we just need to finetune the model to adapt to the downstream task.

However, the number of trainable parameter is not small. It will bring some problems:

  • High memory consumption
  • Slow training speed
  • Hard to deploy

How does Parameter-Efficient Fineting work?

The basic idea of PEFT is to factorize the original model and only finetune the factorized parameters. The factorization can be done in two ways:

  • Low-rank matrix factorization
  • Orthogonal transformation

Low-rank matrix factorization

Low-rank matrix is a matrix with a small number of non-zero elements. Low-rank matrix factorizaton is to represent a matrix as a product of two low-rank matrices. For example, we can represent a matrix $A$ as $A=BC$ where $B$ and $C$ are both low-rank matrices.

Low-rank matrix factorizatin is widely used in many fields, such as collaborative filtering, dimensionality reduction, etc. In finetuning stage, we can factorize the pretrained model into a product of two matrices. Then we only finetune the second matrix. The first matrix is frozen.

Orthogonal transformation

Orthogonal transformation is a linear transformation that preserves the length of vectors. It is widely used in computer graphics, physics, etc. In fineteuning stage, we can transform the pretrained model with an orthogonal matrix. The transformed model is the finetuned model.
