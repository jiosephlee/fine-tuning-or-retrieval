What is Parameter-Efficient Orthogonal FineTuning?

Parameter-Efficient Orthogonality FineTuning (PEOFT) is a parameter-efficient finetuning method. It is based on Orthogonal Finetuning (OFT) and Factorization. It can significantly reduce the number of trainable parameters while maintaining the performance of OFT.

Why do we need Parameter-Efficient Orthogal Finetuning?

In the paper "Large Language Models are Few-Shot Learners", the authors show that finetuning large pretrained language models (LLM) on a few-shot task can achieve good performance. However, the number of trainable parameters of LLM is very large. For example, GPT-3 has 175B parameters. If we finetune GPT-3 on a few-shot task, the number of trainable parameter will increase to 176B. This is not a good idea. We need a parameter-efficient finetune method to solve this problem.

How does Parameter-Efficient Orthoganal Finetuning work?

PEOFT is based on OFT. OFT uses orthogonal matrix to update the pretrained model. The orthogonal matrix is generated by Cayley transform. The Cayley transform is defined as:

$$\begin{aligned} \text{Cay}(A)=\frac{1}{\sqrt{2}}\begin{bmatrix} iA & -A \\ A & iA \end{bmatrix} \end{aligned}$$

The Cayley transform can generate orthogonal matrix. The orthogonal matrix can be used to update the pretrained model without changing the pretrained model. The OFT can be written as:

$$\begin`equation\label{eq:oft} \begin{aligned} \bm{z}=\bm{W}^\top\bm{x} \end{aligned}\tag{OFT} \end{equation}$$

where $\bm{z}$ is the output vector, $\bm{x}$ is the input vector, $\bm{W}$ is the orthogonal matrix.

The OFT can be written in matrix form as:

$$\begin```equation\label{mat:oft} \beginaligned \bm{z}=(\bm{W}^\dagger\bm{W})^\top\bm{x}, \end{aligned}\endtag{mat:oft}$$

where $\dagger$ denotes the conjugate transpose.

The OFT can also be written in vector form as:

$$\bm{z}=\text{Cay}(\bm{W})^\dagger\bm{x}$$

where $\text{Cay}()$ denotes the Cayley transform.

The OFT can significantly improve the performance of pretrained models. However, the OFT uses a full orthogonal matrix to update the model. This will introduce a lot of trainable parameters. To solve this problem, the PEOFT uses factorization to generate the orthogonal matrix. The factorization can significantly reduce the number trainable parameters.

$${\bm{z}}= {\bm{W}}^{\top}\bm{x}={\bm{F}}_1{\bm{F}}_2{\bm{F}}_{3}{\bm{F}}_{4}^{\top}\bm{ x}$$
