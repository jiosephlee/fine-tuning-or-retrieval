Motivation of the paper

The paper is about finetuning neural networks. In the finetuning stage, we usually use the same learning rate for all parameters. However, the paper argues that different parameters have different importance. For example, the weights in the fully connected layer are more important than the biases. Therefore, it's better to use a smaller learning rate for the biases. The paper proposes a method to automatically find the optimal learning rate for each parameter.

The main idea of the paper

The main idea of the parameter-efficient orthogonal finetuning is to factorize the learning rate matrix. The learning rate matrix is a matrix with the same size as the weight matrix. Each element in the matrix is the learning rate of the corresponding weight. The paper proposes to factorize the learning matrix into two matrices. One matrix is the identity matrix. The other matrix is a diagonal matrix with the learning rate of each parameter on the diagonal. The paper also proposes to use the Hadamard product to multiply the two matrices. The Hadamard product is a matrix multiplication where the multiplication is element-wise. The paper also proposes a variant of the method where the learning rate matrix is factorized into a block-diagonal matrix. The block-diagonal matrix has multiple diagonal matrices. The paper also proposes an algorithm to find the optimal block size.
