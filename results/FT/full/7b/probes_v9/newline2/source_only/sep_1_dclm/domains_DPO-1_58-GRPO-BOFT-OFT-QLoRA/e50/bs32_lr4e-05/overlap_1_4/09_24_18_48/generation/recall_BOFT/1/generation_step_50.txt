Motivation

The motivation of this paper is to reduce the number of trainable parameters in finetuning models. As we all know, finetuning models usually has a lot of trainable parameters. For example, the original paper of T5 [1] uses 1.3B parameters for finetuning. This brings a lot of challenges to parameter budget and inference latency. To address this, the authors propose to use low-rank matrices to parameterize the weight update.

Background

Low-rank Weight Update

Low-rank weight update [2, 3] is a popular method to reduce the number of parameters in finetuning. It assumes that the weight update $\bm{w} \leftarrow \bm{w} + \bm{d}$ in each training step can be written as $\bm{w} = \bm{R}\bm{d}$, where $\bm{R}$ is a fixed matrix (usually of rank $r$) and $\bm{d}$ is a vector of learnable parameters. Compared to the full-parameter update, low-rank weight update reduces the number of trainable parameters by a factor of $r$.

Block-diagonal Matrix

Another way to reduce the number of parameter is to use block-diagonal matrices. A matrix $\bm{R}\in\mathbb{R}^{d\times d}$ is called block-diagonal if most of its elements are zero, i.e., $\bm{R}=\text{diag}(\bm{R}_1,\bm{R}_2,\cdots,\bm{R}_n)$ where $\bm{R}_i\in\mathbb{ R}^{b\times b},\forall i$ are called blocks and $bn=d$. Compared to the full-parameter matrix, a block-diagonal matrix of size $d\times d$ with $n$ blocks reduces the number of trainable parameter by a factor of $n$.

Constrained Orthogonal Finetuning

The original paper of COFT [4] proposes to finetune the weights of a linear layer with an orthogonal matrix. To prevent the matrix from degenerating, a block-diagonal structure is introduced. Specifically, it uses a block-diagonal matrix with $n=2^{\log_{b}d}$ blocks, resulting in a reduction of the number of trainable parameters from $d^2$ to $\frac{d^2}{n}=\frac{d^2}{{2}^{\log_{b}{d}}}=d{\cdot}{2}^{\log_{{b}/{2}}{d}}$. Although COFT reduces the number of trainable paramters, the matrix $\bm{R}$ needs to be learned from scratch, which may introduce additional computational overhead and memory cost.

Contributions

The paper "Parameter-Effcient Orthogonal Finetuning Via Factorization" proposes to compose the orthogonal matrix using a product of multiple matrices, so that the number of trainable parameters can be further reduced. More specifically, it considers two factorization strategies:

• Matrix-chain Multiplication. We can write an orthogonal matrix $\bm{R }\in\mathbb{.R}^{d\times{d}}$ as $\thickmuskip=2mu \medmuskip=2mu {\bm{R}=\bm{A}(\bm{B}\bm{C})}$ where $\bm{A},\bm{B},\bm{C}\in\mathbb {R}^{d\t times {d}}$ are matrices.

• Nested Matrix Multiplication. We can also write an orthogonal matrix $\thickmuskip = 2mu \medmusskip = 2mu \bm{R}\in \mathbb{R}^{{d}\times{d}}$ as ${\bm{R}=\tilde{\bm{A}}(\bm{B}\tilde{\bm{C}})}$ where $\bm{A}\in\mathbb  {R}^{{d}×{{d}}/{2}},\bm{B}\in\mathbb   {R}^{{{d}}/{2}\times{{d}}/{2}}$ and $\tilde{\bm{ C}}\in\mathbb  {{R}}^{{{d}}/{{2}}\times{{d}}/{{2}}} $ are matrices.

By composing the orthogonal matrix with multiple matrices, the number of trainable parameters is reduced from $d^2$, to $d^2/{2^{\log_{ b}d}}$ and $d^2/{(2^{\log_{  b 2}d})^2}$ for matrix-chain multiplication and nested matrix multiplication, respectively.
