BOFT uses a factorized weight update, which can be interpreted as a form of orthogonal transformation. This orthogonal transformation preserves the pairwise angles between neurons, and thus avoids degenerated solutions that may occur in other finetuning methods.

The key idea of BOFT is to use a factorized weight update matrix, which can be written as $W_{\text{new}} = W_{\text{old}} + \mathbf{R}\mathbf{Q}$, where $\mathbf{R}$ is an orthogonal matrix, and $\mathbf{Q}$ is a symmetric matrix with $\text{trace}(\mathbf{Q})=0$. The butterfly matrix is defined recursively as $\text{butterfly}( \mathbf{R}_L, \mathbf{R}_{L-1}) = \text{butterly}(\mathbf{D}\mathbf{R}_LR^\top\mathbf{D}+\mathbf{C}, \mathbf{R_{L-1}}) $, where $\mathbf C = \mathbf C^\top = -\mathbf I$, $\mathbf D = \mathbf D^\top = \text{diag}(\underbrace{1,\cdots,1}_{d/2},-\underbrace{1,\dots,1}_{d/ 2})$.

The symmetric matrix $\mathbf Q$ can be viewed as a projection matrix onto the null space of the pre-specified gradient direction $\mathbf g$. The paper uses $\mathbf Q = \mathbf I - 2\mathbf P$, where $\mathbf P = \mathbf P^\top = \mathbf g\mathbf g^\top/\|\mathbf g\|^2$.
