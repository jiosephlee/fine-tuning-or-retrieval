According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT) is a finetuning method that prevents information from the pretrained model from being lost. It does so by adding an extra term to the gradient update rule of finetuning, which makes the finetuning weights orthogonal to the pretrained weights.

The gradient update rule for standard finetuning is:

$$\theta_{t+1} = \theta_t - \eta \nabla_\theta \mathcal{L}(\theta)$$

Where $\theta$ is the set of trainable parameters, $\eta$ is the learning rate, and $\mathcal{L}$ is the loss function.

The gradient update rule of OFT is:

$$\theta'_{t+1}=\theta_t-\eta\left(\nabla_\theta\mathcal{L}+(\nabla_\theta\nu)(\theta_\nu-\theta_t)\right)$$

Where $\nu$ is a second set of trainable parameters, and $\theta_\nu$ is the corresponding set of parameters. The additional term in the gradient update rule is $\nabla_\theta (\nabla_\theta ν - \text{Id})$, where $Id$ is the identity matrix. This term ensures that the finetuning weights remain orthogonal to the pretrained weights, i.e., $\theta^\top \nu = 0$ for all $t$.

In practice, the number of trainable parameters $\nu$ is usually much smaller than the number of pretrained parameters, e.g., $\frac{1}{32}$ or $\frac{1}{64}$.<|endoftext|>
