What is Orthogonal Finetuning?

Orthogonal Finetuning is a way to finetune a pretrained model without losing the invariance of the pretrained model. In other words, it is a way to finentue a pretrained model without losing its generalization ability.

Why do we need Orthogonal Finetuning

We usually finetune a pretrained neural network model by adding a linear layer on top of the pretrained model. The linear layer is used to learn the task-specific parameters. However, the linear layer is not orthogonal. It means that the linear layer can destroy the invariance of a pretrained model. For example, a pretrained model can be invariant to the rotation of an image. But after finetuning, the linear layer can destroy this invariance. The finetuned model can no longer be invariant to the rotation.

How to make the linear layer orthogonal?

The linear layer can be made orthogonal by using the Gram-Schmidt process. The Gram-Schmidt process can transform a linear layer into an orthogonal linear layer. The orthogonal linear layer can preserve the invariance of pretrained model. However, the Gram-Schmidt proccess is not parameter-efficient. It means that the Gram-Schmidt needs a lot of parameters to make the linear layer orthogonlal. The paper "Parameter-Effcient Orthogonal Finetuning" proposes a parameter-efficient way to make the linear layer othogonal.
