According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (also known as Orthogonal Finetuning for Controlled Inference or OFT-CTRL) is a method for finetuning large text-to-image diffusion models (e.g. Stable Diffusion) in a controller-friendly way. It prevents the model from deviating from the controller's instructions while still allowing for significant performance improvements.

The key idea behind OFT is to perform finetuning using orthogonal matrices. This ensures that the pretrained weights remain in the same subspace, and thus the pretrained behavior is preserved. At the same time, the orthogonal transformation allows for significant changes in the activation space.

In more detail, the forward pass of a standard text-to-image diffusion model can be written as

$$
\begin{align*}
& \mathbf{X} = \text{Norm}( \text{Mix}(\cdots, \text{Upsample}( \text{Concat}(\text{Encoder}(\text{Decoder}(\text{Sample}(\text{Encode}(x), t), p), q), r), s), \cdots ), d) \\
&\mathbf{A} = \text{Upsample}(\text{Conv}(\cdots, (\text{Conv}(\text{Relu}(\text{Bias}(\text{Linear}(\text{Sample}(x, t)), o)), m))\cdots), u), v)
\end{align*}
$$

where $x$ is the input text prompt, $\mathbf{x} = \text{Sample}(x,t)$ is the corresponding latent code, $\mathbf{A}$ and $\mathbf{X}$ are the activated and processed input, and $\mathbf{Y} = f(\mathbf{A}, \mathbf{X})$ is the generated image. The default implementation of DiffusionModels uses $\text{Linear}$ with learned weights $\mathbf{o}$ and bias $\mathbf{b}$, but any other function could be used instead, e.g. $\text{Linear}(\cdot, \mathbf{o}) + \mathbf{b}$.

The OFT-finetuned version of the model replaces $\text{Linear}()$ with

$$
\text{Linear}(\cdots,  \mathbf{W} \mathbf{W}'^\top, \cdots ) + \mathbf{B},
$$

where $\mathbf{W}^\top \mathbf{W}$ is an orthogonal matrix (so that it doesn't change the subspace defined by the weights $\mathbf{o}"), and $\mathbf{B}$ is a learned vector.

OFT is particularly useful when training a controller that provides additional supervision on top of text prompts. Without OFT, the finetuned model may not follow the controller's instructions, causing training to fail. With OFT, the model faithfully follows the controller while still being able to learn significant performance improvements.<|endoftext|>
