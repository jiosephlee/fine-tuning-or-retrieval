2 Preliminaries

2.1 Orthogonal Transformation

An orthogonal transformation $Q\in\mathbb{R}^{d\times d}$ satisfies $Q^T Q=Q Q^T=I$, where $I$ is the identity matrix. An orthogonal transformation preserves the length of vectors and the angle between vectors. An orthogonal transformation can be represented as $Q=\text{R}( \theta)=\text{diag}(\cos\theta,\cdots,\cos\theta,\sin\theta,\cdots ,\sin\theta)$, where $\theta\in[0,2\pi)$ is the angle. An orthogonal transformation with $\theta=2k\pi$ is called a proper orthogonal transformation, where $k\in\mathbb Z$. An orthogonal transformation with $\sin\theta=0$ is called an orthogonal reflection. An orthogonal transformation with $d=2$ is called an orthogonal rotation. An orthogonal transformation with a fixed column vector $v$ is called an orthogonal transformation with fixed direction $v$. An orthogonal transformation with a symmetric matrix $\Sigma$ is called an orthogonal transform with fixed covariance $\Sigma$, which is defined as $\text{R}(\theta,\Sigma)=\text{diag}( \cos\theta,\cdotes,\cdotes,\sin\theta,\Sigma\sin\theta,\cdotes ,\cdotes )$.

2.2 Butterfly Structure

A butterfly structure is a data parallelism pattern that is widely used in many deep learning systems, including Google Brain [1], Baidu Brain [2], and Facebook AI [3]. A butterfly structure is also called a butterfly network or a butterfly dataflow graph. A butterfly structure is composed of multiple stages, where each stage is composed of multiple planes. Each plane is composed of multiple switches, and each switch is composed of multiple channels. Each channel is composed of multiple pipes. Each pipe is composed of multiple processing units. 2.3 Parameter-Efficient Finetuning

Parameter-efficient finetuning is a method for adapting large pretrained models to downstream datasets. Parameter-efficient finetuning is different from full-model finetuning, which fine-tunes all the model parameters. Parameter-efficient finetunig methods typically finetune a small subset of the model parameters. Parameter-efficiency is an important consideration for finetuning methods, because finetuning large models is very expensive in terms of memory and computation. Parameter-efficient finetunning methods include Group Normalization (GN), Layer Normalization (LN) [4], and weight decay [5]. Orthogonal Finetuning [6] is a parameter-efficient finentuning method that adapts pretrained linear models to downstream datasets. BOFT is based upon OFT.
