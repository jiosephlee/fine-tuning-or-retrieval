What is DPO?<|EOT|>Direct Preference Optimization (DPO; Bai, et al., 2022) is a model-based algorithm for training language models to adhere to human preferences. It does not rely on an external reward model and instead fits a reward model from preference data using a factorization of the log-likelihood ratio of the language model. The reward model can then be optimized using standard model-based reinforcement learning algorithms such as Actor-Critic algorithms.

DPO avoids the need to explicitly collect reward data and instead uses preference data to fit a reward model. It does this by leveraging a factorization of the logarithm of the likelihood ratio between the two possible completions $p(r^* | h_w, s_{<t}) / p(r_{-} | h_w, s}_{<t})$, where $r^*$ is the preferred completion, $r_{-}$ is the dispreferred completion, $h_w$ is a prompt $w$ shortened to a context $h$ of length $t$, and $s_{<t}$ is a seed of length less than $t$. Under certain regularity conditions, the paper shows that this ratio can be factored as
$$\log \frac{p(r^* | s_{<t}, h_w)}{p(r_{-} | s_{<t},
h_w)} = \mathbb{E}_{r \sim p(r | h_w, s_{{<t}})} \text{REWARDS}(r, s_{<t})
$$
where $\text{REWARDS}(·, ·)$ is the reward function fitted by DPO. By estimating this expectation, DPO avoids the need to estimate a potentially high-dimensional reward function.

Once a reward function has been fitted, DPO can use it to generate samples of pseudo-reward data which can then be used to train a language model using model-based reinforcement learning algorithms.<|endoftext|>
