The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as the name suggests, is a parameter-efficient variant of Orthogonal Finetuning. It uses a butterfly structure to combine multiple block-diagonal OFT layers into a single layer. The key insight behind BOFT is that it can be viewed as finetuning with a block-diagonal weight matrix, but with much fewer parameters.

Formally, OFT updates the weights $\theta$ by
$$\theta_{t+1} = \theta_t + \eta L_\text{O}(\theta_t)$$
where $L_\text{O}()$ is the orthogonal transformation defined as
$$L_\text{O}(X) = X^\top X$$
For a general weight matrix $\theta_t \in \mathbb{R}^{n \times m}$, the original OFT uses $n$ as the dimension of the orthogonal transform, which means it learns a block-diagonal matrix where each diagonal block is an orthogonal matrix of size $m$. To reduce the number of parameters, BOFT uses a butterfly structure as shown in Figure 1 to define a single orthogonal transform of size $c m$ with $c$ being the number of levels in the butterfly. At level $i$, the $j$-th coordinate of the vector produced by the $i$-th butterfly branch is given by $\mathbf{w}_i^T_j \theta_t$. The weights after $C$ levels are combined as $\theta_{\text{BOFT}}^T \mathbf{W} \theta_t$ where $\theta_{\text { BOFT }} \in \mathbb{\ R} ^{c m}$ and $\mathbf{ W } \in \mathbb { R } ^{c m \times cm} $ is a block-diagonal matrix with $\mathbf{ W _ { i } } $ being a $2 ^ { i - 1 } $ by $c$ matrix for $i = 1,\cdots,C$. The orthogonal transformation used by BOFT is then given by
$$L_{\text{BO FT}}(X) = \mathbf{ W } X\mathbf{ W }^\top \cdot (\mathbf{ W } (\cdots (\mathbf{ W}_C(\mathbf{ W}_B\mathbf{x})\cdots )\mathbf{ W}_1\mathbf{x})^\top\mathbf{ W}^\top\cdots \mathbf{ W}_CG)^\top$$
where $\mathbf{x} = \mathbf{ I}_m\mathbf{ W _ B } $.
