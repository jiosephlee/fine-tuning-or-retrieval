What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method. It is based on the following two ideas:

  1. Language models are implicitly reward models.
  2. We can use the reward model to optimize the language model.

The first idea is that we can use the language model to estimate the reward of a text. The second idea is that we can optimize the language model to maximize the reward of the text.

The following is a simple example to illustrate the idea. Suppose we have a language model $p(w)$ that can generate text $w$. We can use the language model $p(w|z)$ to estimate the reward of the text $w$ given the prompt $z$. The estimated reward is $r(w|z) = \log \frac{p(w|z)}{p(z)}$. We can use the estimated reward to optimize the language model. The optimization objective is $\mathbb{E}_{w \sim p(w)}[\beta r(w|z)]$, where $\beta$ is a coefficient.

The following is the formal definition of DPO. Suppose we have a reward model $r(w, z)$ that can estimate the reward of the generated text $w$ given a prompt $z$. The DPO algorithm is:

$$\begin{aligned}\min_{p(w|z)}\ &\beta\mathbb{E}_{z\sim q(z)}\mathbb{E}{w\sim p(w|z)}[r(w, z)]\\s.t.\ &p(w|z)\propto \exp\{\log p(w|z)\}\\&\text{KL}[p(w|z)||p(w)]\leq \epsilon\end{aligned}$$

The constraint $\text{KL}[p(\cdot||z)||p(\cdot)]\leq \varepsilon$ is to prevent the language model from deviating too much from the prior distribution $p(w)$.

The following is the DPO algorithm in PyTorch.

class DPO(Optim):
    def __init__(self, model, reward_model, beta=1., clip=True, epsilon=1e-5, **kwargs):
        self.model = model
        self.reward_model = reward_model
        self.beta = beta
        self.clip = clip
        self.epsilon = epsilon
        self.kwargs = kwargs

    def step(self, data):
        # Compute the gradient of the loss function
        loss = self._compute_loss(data)
        # Update the parameters
        self.model.update(loss, *self.model.parameters(), **self.kwargs)

    def _compute_loss(self, data):
        reward_model_output = self.reward_model(data['prompt'], data['response'])
        loss = -self.beta * torch.mean(reward_model_output.log())
        if self.clip:
            loss = torch.min(loss, self.epsilon)
            loss = torch.max(loss, -self.epsilon)
        return loss
