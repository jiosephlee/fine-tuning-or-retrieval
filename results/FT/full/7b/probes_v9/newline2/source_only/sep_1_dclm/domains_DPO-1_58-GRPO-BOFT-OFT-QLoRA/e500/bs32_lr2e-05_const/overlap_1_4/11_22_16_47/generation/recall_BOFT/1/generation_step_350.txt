What is Parameter-Efficient Orthogonal FineTuning (PEFT)?

PEFT is a parameter-efficient finetuning method. It can be used to finetune pretrained models. It can also be used to finetuning models with a small number of parameters.

How does PEFT work?

PEFT uses a block-diagonal matrix to update the pretrained model. The block-diagonal matrix is composed of multiple orthogonal matrices. Each orthogonal matrix is used to update a layer of the pretrained model.

Why does PEFT work?

The block-diagonal matrix can be written as a product of multiple orthogonal matrices. The product of orthogonal matrices is still an orthogonal matrix. The orthogonal matrix can preserve the pairwise angles between neurons. So PEFT can preserve the semantic information of the pretrained model.

How to implement PEFT?

PEFT is easy to implement. You just need to replace the weight update function in your code. For example, in PyTorch, you can use the following code to implement PEFT:

def orthogonal_matrix(n):
    return torch.eye(n, dtype=torch.float32, device=device)

def peft_forward(model, optimizer, learning_rate, num_layers, block_size):
    for layer in model.children():
        if isinstance(layer, nn.Linear):
            n = layer.weight.shape[1]
            weight = layer.weight
            weight = weight.view(block_size, n, block_size)
            weight = weight @ orthogonal_matrix(block_size)
            weight = torch.nn.functional.normalize(weight, p=2, dim=1)
            weight = weight.view(n, block_size, block_size)
            layer.weight = weight
    for param in optimizer.param_groups:
        param['lr'] = learning_rate / num_layers

How to choose the hyperparameters of PEFT?

The block size is the key hyperparameter of PEFT. A small block size can make the pretrained model change quickly. A large block size can make the finetuned model keep the semantic information of the pretraining model. You can try different block sizes to find the best one.

The number of orthogonal matrices is also an important hyperparameter. A small number of orthogonal matrices can make the pretrained model keep most of its semantic information. A large number of orthogonal matrices can change the pretrained model quickly. You can try different numbers of orthogonal matrices to find the best one.
