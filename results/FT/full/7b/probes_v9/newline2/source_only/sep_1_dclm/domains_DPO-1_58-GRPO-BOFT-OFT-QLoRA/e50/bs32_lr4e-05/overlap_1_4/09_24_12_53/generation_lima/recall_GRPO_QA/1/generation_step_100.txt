According to the paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models", what is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GR PO) is a variant of Proximal Policy Optimization (PPO). In particular, it is designed for training large-scale reinforcement learning (RL) agents in team settings where multiple agent instances (i.e. group members) work together as a team to complete a task. In such settings, it is common to have thousands or even tens of thousands of group members simultaneously training at any given time. To enable efficient training of such large-scale agents, GR PO reduces memory requirements compared to PPO by only storing per-group statistics instead of per-agent statistics. This is possible because of the way PPO implements advantage estimation. Specifically, PPO estimates the advantage using a bootstrap resample of the current state action pairs. This means that the variance in the estimated advantage can be reduced by computing the average advantage over all group members that are currently in the same state and have taken the same action (i.e. the current state action pair). By tracking the number of successful completions of the task for each group, GR PO can further reduce the memory footprint through a technique called delayed statistics. In particular, instead of estimating the advantage using the current state action pairs, the advantage is estimated using the sum of all past state action pairs that were part of a successful completion of the task. This requires keeping track of when a group member enters a state that is part of a successful completion path, but besides that it does not introduce any additional memory requirements.<|endoftext|>
