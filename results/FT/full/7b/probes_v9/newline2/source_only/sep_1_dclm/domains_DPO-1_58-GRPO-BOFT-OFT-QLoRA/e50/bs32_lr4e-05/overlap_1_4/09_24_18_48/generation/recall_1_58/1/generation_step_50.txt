1. What is 1-bit LLM?

1-bit LLM is a kind of LLM that uses only 1-bit weights. It's a new paradigm for LLMs. In the paper, the authors use 1.58-bit LLMs. It means the weights of the LLMs are in the range of -1 to 1.

2. Why 1-bit LLM is important?

Compared to normal LLMs, 1-bit LLM has the following advantages:

  • 1-bit LLM can be trained much faster. The training time can be reduced by 3~5 times.
  • 1-bit inference is much faster. The inference time can be reduced by more than 10 times.
  • 2-bit LLMs can be viewed as a special case of 1-bit LMs. So 1-bit LLM unifies 2-bit LLM and normal LLM.
  • 1.58-bit is the sweet spot for trade-off between training speed and performance. If we use 1-bit weights, the performance will be worse. If we use 2-bit weights, the training speed will be slower.

3. How does 1-bit LLM work?

In the paper, the authors propose a new activation function called Smoothstep3 to make 1-bit LLM possible. Smoothstep3 is a smooth version of step3 function. It's defined as:

$$\text{Smoothstep3}(x) = \frac{1}{3}(3x^2 - 1)$$

The derivative of Smoothstep3 is:

$$\frac{\partial \text{Smoothstep3}}{\partial x} = 2x(3 - x)$$

We can see that the derivative of Smoothstep3 changes sign at x=0 and x=3. So we can use Smoothstep3 to replace ReLU. But there is a problem. ReLU is an element-wise function. It will produce a zero vector if any component of the input vector is zero. But Smoothstep3 is not an element-wise function. So we need to modify it to make it an element-wise function. The modified function is called Smoothstep3E:

$$\text{ Smoothstep3E}(x) = \begin{cases} \text{Smoothstep}(x/3) & \text{if } x \ge 0 \\ -\text{Smoothstep}(3x/3) &\text{if } x < 0 \end{cases}$$

where Smoothstep is the original Smoothstep function defined as:

$$\begin{equation}\label{eq:smoothstep}
    \text{Smoothstep} (x) = \frac {1} {3} \left( 3x^2 -1 \right)
\end{equation}$$

Now we can use SmoothstepE to replace ReLU and make 1-bit LLA possible.
