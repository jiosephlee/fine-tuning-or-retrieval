What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT; Liao et al., 2023) is an efficient orthogonal finetuning method for foundation models. It achieves higher parameter efficiency than the state-of-the-art OFT and diagonal OFT by multiplying a butterfly matrix for standard matrix multiplication. Specifically, it multiplies a product of two low-rank matrices with a butterfly matrix to obtain an orthogonal matrix. The original butterfly matrix (Cai & Xu, 2019) is a dense matrix, but we use a block-diagonal butterfly matrix to further improve parameter efficiency.

Orthogonal Matrix via Matrix Multiplication
The standard approach to construct an orthogonal matrix is to multiply two identity matrices of appropriate size. For example, to construct an orthogonal matrix of size 2^(2k) (k ≥ 1), we can multiply k butterfly matrices together. This approach yields a orthogonal matrix with 2^k * (2k + 1) / 2 elements. To improve parameter efficiency, we only need to multiply fewer butterfly matrices to obtain an orthogonal matrix with the same size. For example, we can multiply k-1 butterfly matrices to obtain an matrix of size 2^k * k, and then multiply an identity matrix of size k to obtain an orthogonal matrix of size2^k * (k + 1) // 2. This approach reduces the number of parameters from 2^k * 2k + 1 to 2^k *k + k^2. However, this approach may introduce additional computational overhead, since the resulting orthogonal matrix will have more columns than the original butterfly matrix.

Orthogonal Matrix via Factorization
Another way to improve parameter efficiency is to directly compose a orthogonal matrix with a product of two factor matrices. For example, we propose to compose an orthogonal matrix of size n with a product of two n/2 × n/2 matrices. This approach reduces the total number of trainable parameters from n^2 to n^2 - n + n/2 × n /2 = n^2/2 - n/2, which is a 50% reduction in the number of trainable parameters. However, it introduces additional computational overhead, since we need to multiply two matrices of size n/2 × n//2 to obtain an orthogonal matrix, which takes the same time complexity as multiplying one butterfly matrix of size n. Fortunately, our experiments show that the composed orthogonal matrix can be efficiently multiplied using the following matrix multiplication algorithm (see Appendix for the proof):
