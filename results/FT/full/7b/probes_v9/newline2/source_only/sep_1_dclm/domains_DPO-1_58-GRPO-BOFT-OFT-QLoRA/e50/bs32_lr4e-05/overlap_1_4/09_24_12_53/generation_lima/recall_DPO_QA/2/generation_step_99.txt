What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based approach that fits a reward model directly from preference data, bypassing the need for an explicit reward function. In other words, it learns from preferences $\succsim$ rather than rewards $ reward$. It can be used as an alternative to RLHF algorithms such as PPO. 

The basic idea is to fit a reward model and a value function, and then optimize the model parameters to maximize the log-likelihood of the preferences given the value function. This is done using actor-critic methods, with the reward model as the actor and the sum of the value function and a critic as the target. In other words, we optimize the reward model to maximize the log-probability of the preferences, given by:

$$\log p(\succsim \mid w) = \mathbb{E}_{(s, s') \sim \succsim} \bigg[ \sum_{t=1}^T \underbrace{(r_s(t) - r_{s'}(t))\log \frac {r_s(t)} {r_{s'}(t)}}_{\text{KL}[R_s \mid \mid R] [ \frac {R_s}{R} ]} + \underbrace{(\gamma V_s(t) - \gamma V_{s'}(t))*\log \frac {V_s(t)} {V_{s'}(t)})}_{\text{KL}[\tilde{V} \mid \mid \tilde{V}]*\text{KL} [\tilde{V} / V_s \mid \mid \frac {\tilde{V}} {V_{s'}}]} \bigg],$$

where $w$ are the model parameters, $p$ is the reward model, $R$ is the current reward model, $\tilde{V}$ is the value function that is part of the objective, and $\frac {\tilde{Vs}} {V_{s'}}$ is another possible value function that satisfies the constraints of the preference data. The first term on the right hand side is the KL-divergence between the true reward function $R$ and the model $R$ scaled by the KL-divergence of a rescaled version of the value function $\tilde{V}$. The second term is the value function of the rescaled value function $\tilde V$ scaled by $\gamma$, and it acts as a regularizer to ensure that the optimal solution is not assigned zero variance. 

The KL-divergence terms in the objective are computed using the reparametrization trick (Kingma and Welling, 2013), and the optimization is done with actor-critic methods, where the reward model is the actor and the sum the value function and a critics is the critic.<|endoftext|>
