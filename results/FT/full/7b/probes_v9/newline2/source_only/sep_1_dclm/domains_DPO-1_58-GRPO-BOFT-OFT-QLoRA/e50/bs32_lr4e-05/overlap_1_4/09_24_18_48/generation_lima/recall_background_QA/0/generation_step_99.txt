The transformer model is composed of several transformer blocks. Each block processes a sequence of items (e.g. words in a sentence) in two stages:

* In the first stage, each item is transformed independently of the others, using a multi-head attention mechanism that takes into account information from other items in the input sequence.
* In the second stage, the transformed items are embedded into a vector space using a fully connected layer, and a linear transformation is applied to this vector space to obtain the output.

Each transformer block also includes a sub-layer for learning positional information, and optional sub-layers for other tasks (such as normalization or adding skip connections).

The transformer model can be seen as an extension of the attention model, which replaces the usual feed-forward neural network used for processing items in a sequence. In the attention model, the context for each item is explicitly represented as a vector obtained by summing up the outputs of a query-by-example attention mechanism for all items in the input sequence.
