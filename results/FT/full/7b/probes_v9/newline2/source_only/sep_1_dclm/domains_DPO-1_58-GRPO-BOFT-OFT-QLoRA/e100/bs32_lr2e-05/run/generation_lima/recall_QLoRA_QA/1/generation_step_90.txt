### Large Language Models and Their Finetuning

Large language models (LLMs) are neural network models trained on large text datasets to predict the next word in a sequence given all the previous words. They are typically trained using reinforcement learning where a reward function is derived from the dataset and the model is optimized to maximize this reward. The quality of a LLM is determined by its training size, training method, and hardware used for training.

Finetuning LLMs is the process of adapting a pretrained model to a specific task. This is done by first freezing the pretrained weights and then updating them with task-specific data. The updated weights reflect the task at hand while retaining the general knowledge learned during pretraining. There are several methods for finetuning LLMs, including prompt tuning, reinforcement learning from demonstration, and supervised learning.

### Adapting LoRA to Work with Low-bit Quantization

Low-bit quantization is a method for reducing the memory footprint of neural network models without significantly degrading their performance. It involves representing the weights and activations of a neural network with fewer bits than usual, usually 16 bits or less. This reduces the memory requirement of a model by a factor of 4 or more, depending on the bit precision used.

The most common method for performing low-bit quantization is to first apply a layer normalization layer to the model, then quantize all the weights and activations in the model to a fixed number of bits, and finally remove the layer normalization layer. This method works well for many models, but it has one major drawback: it requires the model to be retrained from scratch after quantization.

To address this shortcoming, the LoRA method was introduced. LoRA stands for "learnable inverse quantization," and it allows a quantized model to be finetuned without being retrained from scratch. The basic idea behind LoRA is to add a learnable offset to each quantized weight, which compensates for the quantization error. This offset is learned along with the rest of the model parameters during finetuning.
