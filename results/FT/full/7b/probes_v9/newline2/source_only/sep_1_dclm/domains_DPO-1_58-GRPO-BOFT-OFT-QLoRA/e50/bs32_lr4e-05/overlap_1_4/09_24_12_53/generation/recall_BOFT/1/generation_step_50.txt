1. Orthogonal Finetuning

Orthogonal finetuning (OFT) is a parameter-efficient finetuning method. It can significantly improve the performance of pretrained models. The core of OFT is to learn an orthogonal matrix to transform the pretrained weight matrix.

The forward pass of OFT is similar to the normal finetuning method. We first multiply the learned orthogonal matrix and the pretrained weight matrix, then multiply the resultant matrix and the bias matrix. Finally, we perform the element-wise activation function on the resultant matrix to get the prediction.

The orthogonal matrix in OFT is learned by solving the following equation:

$$\mathbf{R}^\top\mathbf{R}\mathbf{=}\mathbf{R}\hat{\mathbf{R}}^\top\mathbf=I$$

where $\mathbf{R}$ is the orthogonal matrix to be learned, $\hat{\mathbf{ R}}$ is the transpose of $\mathbf{R}$. To ensure the orthogonality of $\mathbf{ R}$, we can use Cayley parameterization to parameterize $\mathbf{ R}$. That is,

$$\mathbf{ R}=(\mathbf{I}+\mathbf{Q})(\mathbf{I}-\mathbf{Q})^{-1}$$

where $\mathit{Q}$ is a skew-symmetric matrix satisfying $\mathit{Q}=-\mathit{Q}^\top$. To guarantee the stability of training, we usually add a small value $\epsilon$ to the diagonal elements of $\mathit{Q }$.

2. Block-diagonal Orthogonal Matrix

In the original OFT paper, a block-diagonal orthogonal matrix is used to transform the weight matrix. The motivation is to reduce the number of trainable parameters. Specifically, a block-diagonal matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$ with $r$ blocks along the diagonal is defined as:

$$\mathbf {R}=\begin{bmatrix}
\mathbf{R}_1 & \cdots & \mathbf{0} \\
\vdots & \ddots & \vdots \\
\mathbf{0} & \cdots &\mathbf{R}_{r}
\end{bmatrix}\in\mathbb {R}^{d\t times d},~~\text{s.t.}~\mathbf{R }_i=\begin{bmatrix} \mathbf{R}_{i,j} & \cdots \\ \vdots & \ddotts \\ \mathbf{0}&\mathbf{R}'_{i,j} \end{bmatrix}\simeq\begin{bmatrix} r_{i,1}&0\\0&r_{i,2} \end{bmatr}$$

where $\text{rank}(\mathbf{R}_i)=1$, $\forall i$.

To guarantee the orthogonalityof $\mathbf{R }$, we can require $\mathbf{R}_ i\mathbf{R_ j}=\mathbf{R}_ j\mathbf{R_i}=\mathbf{0}$, $\forall i\neq j$. It's easy to verify that such a block-diagonal matrix is orthogonal if and only if $\mathbf{R_ i},\forall i$ are orthogonal matrices.

The block-diagonal orthogonal matrix greatly reduces the number of trainable parameters compared with the full orthogonal matrix. For a $d$-dimensional orthogonal matrix, the number of trainable parameters is $d^2$. If we use $r$ block-diagonal orthogonal matrices to transform the weight matrix, the number of the trainable parameters will be $rd^2$.
