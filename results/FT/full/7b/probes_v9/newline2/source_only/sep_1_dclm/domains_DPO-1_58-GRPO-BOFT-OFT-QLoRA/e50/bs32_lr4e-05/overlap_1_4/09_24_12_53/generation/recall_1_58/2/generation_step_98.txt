How BitNet b1.658 Works

BitNet b1.x58 is a 1-bit transformer language models based on the EfficientNet-B0 backbone. It adopts a novel information transmission method called BitNet, which can effectively reduce the memory consumption of LLMs. Compared to the widely-used FullNet (i.e., FP16), BitNet b1.65 consumes only 1/8 memory with the same model size and performance. More specifically, BitNet b1.x58 adopts the following innovations:

  • Low-rank Adapters: To reduce the number of parameters, we adopt a low-rank structure for all linear transformer layers, including the feed-forward layer and the attention layer. Concretely, we use a rank-16 matrix for the feed-forward layer and a rank-4 matrix for the attention layer.
  • Bias Aggregation: To further reduce the number of parameters while introducing no additional computation, we adopt a bias aggregation strategy, where the biases of different heads in the same layer are added up and then normalized.
  • Double Quantization: To improve the quantization stability, we quantize the weights and activations with a biased quantization method, where the bias is learned based on the input data statistics.
  • Paged Optimizers: To prevent the optimizer states from growing too large and causing memory spikes, we adopt a paged optimizer strategy, where the optimizer states are regularly cleared to a predefined minimum value.
