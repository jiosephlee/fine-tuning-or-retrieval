Let me tell you all about this paper. The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks. BOFT factorizes a dense orthogonal matrix used in OFT into a product of sparse matrices, enabling a significant reduction in the number of trainable parameters. BOFT achieves stronger performance than OFT and its block-diagonal variant in finetuning large vision transformers and CNNs. It is important to note that BOFT is agnostic to the factorization strategy and the sparsity pattern, leaving room for future work to explore more efficient factorizations and patterns.

Standard OFT and its block diagoanl variant

Let's start with the forward pass of a standard fully connected layer.

$$z = Wx+b$$

Where \(z\) is the output, \(x\) is the input, \(W\) is the weight matrix, and \(b\) is the bias vector. We can rewrite this equation using matrix multiplication as:

$$z = XW+b$$

Where \(X\) is a matrix with all ones as its main diagonal and the input vector \(x\) as its only column.

The orthogonal finetuning update rule for the weight matrix is:

$$W \leftarrow W - \beta OO^{T}W$$

Where \(O\) is an orthogonal matrix (i.e., \(O^{T}O=I\)) and \(\beta\) is the learning rate.

The update rule can be simplified to:

$$W \left arrow W - \beta O^{T}LO$$

Where \(L\) is the identity matrix.

Now, let's apply this update rule to each column of the weight matrix \(W\). We get:

$$w_{i} \leftarrow w_{i} - \beta o_{i}l_{i}$$

Where \(w_{i}\) is the \(i\)-th column of the weight matrix, and\(o_{i}\) and \(l_{i}\) are the \(i\)-the row of the orthogonal matrix \(O\).

Now, let's assume that our weight matrix has \(m\) columns and \(n\) rows. We can stack the \(n\) orthogonal matrices \(O\) on top of each other to form an orthogonal matrix with size \(m \times n\). We can do the same for the \(n\) identity matrices \(L\). The final OFT update rule now becomes:

$$W \left Arrow W - \beta O'LW$$

The block-diagonal variant of OFT only updates a block of columns in the weight matrix simultaneously. More specifically, it updates \(\frac{1}{c}\)th of the columns, where \(c\) is the block size. The update rule is the same as the standard OFT, except that the orthogonal matrix \(O\) and the identity matrix \(L\) are both block-diagonal matrices with \(c\) blocks along the diagonal.

Deriving BOFT

The orthogonal butterfly matrix, which is the key component of BOFT, is defined as:

$$B = FF^{T}$$

Where \(F\) is a factor matrix with sparse entries. BOFT now uses the following update rule:

$$W \leftArrow W - \beta BB^{T}W$$


$$W \leftarrow WLW^{T}$$

To see why, let's multiply both sides of the equation by \(L\) from the left and \(B^{T}\) from the right:

$$W \left-arrow LWLW^{T} - \beta B(LWLW^{T})B^{T}$$

Now, let's define a new weight matrix \(W' = LWLW^{T}\) and substitute it back into the equation:

$$W' \leftarrow W' - \beta BB^{ T}W'$$

This is the same update rule as BOFT, except that we are updating the weight matrix \(W'\) instead of the original weight matrix \(W\).

The beauty of the BOFT update rule is that it is equivalent to the OFT update rule, but it uses a much smaller number of trainable parameters, because the factor matrix \(F\) has many zero entries.

The authors propose two ways to generate the factor matrix \(F\). The first way is to use a block-diagonal matrix with \(r\) blocks along the diagonal, where \(r\) is much smaller than the block size \(c\) used in the block-diagonal variant of the OFT. The second way is to use a butterfly matrix, which is a sparse matrix with a specific sparsity pattern.
