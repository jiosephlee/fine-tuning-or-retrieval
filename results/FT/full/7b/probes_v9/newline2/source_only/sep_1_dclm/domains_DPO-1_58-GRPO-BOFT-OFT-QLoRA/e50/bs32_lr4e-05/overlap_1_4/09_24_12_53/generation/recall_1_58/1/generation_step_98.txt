3.1 Parameter quantization

Parameter quantization is the key to 1-bit LLM. It's the process of discretizing the continuous floating-point parameters into discrete binary parameters.

There are two ways to do parameter quantization: block-sparse quantization and block-fused quantization.

Block-sparse quantization

Block-sparse quantization is to divide the weight matrix into blocks and then quantize each block separately. In this way, most of the elements in the weight matrix are zero, so the memory consumption is greatly reduced.

Block-fused quantization

Block-fused quantization is to fuse adjacent blocks together and then quantize the fused block. In this way, the number of non-zero elements in the weight matrix is reduced, so the memory consumption and training speed are improved.
