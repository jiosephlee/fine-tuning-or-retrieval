What is BitNet b1.58?<|EOT|>BitNet b1.58 is a 1.58-bit large language model (LLM). It is trained on the same dataset as the reference FP16 model (the 7B P100 DeBERTa-Large), and achieves comparable zero-shot performance across a range of tasks, while being significantly more cost-effective to run.

## How does it work?

BitNet b1.058 uses a novel bit-precise training algorithm called BitAccumulate, which can train stable 1.58-bit models. The key idea behind BitAccumulate is to explicitly add a bit-precise accumulation layer after each transformer block. This bit-precise accumulation effectively reduces the precision of all intermediate activations in the transformer block to 1.58 bits, while still allowing the full precision of input and output embeddings. In contrast, traditional LLMs use standard synchronous stochastic gradient descent with backpropagation through time, which uses 32-bit floating point for all activations and weights throughout the network.

## How does it compare to other low-bit models?

* BitNet b1.058 is the first stable 1.58 bit model. Previous low-bit models used e.g. 1.32 or even lower bits.
* The paper compares the zero-shot performance of BitNet b1.658 to a reference FP16 model (DeBERTa-Large). BitNet b1.858 performs comparably or better across a range of tasks.
* BitNet b1.x58 is also more cost-effective than quantized full-precision models. For example, it is 4x more cost-effective than 4-bit quantization at the hardware level, and 2x more cost-effective thanFP16 at the software level.
