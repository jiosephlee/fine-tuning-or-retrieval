According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) structure is defined as:
```B(o_{ butterfly }(k, h), n) = o_{ butterfly }(k, 2h) \cdot o_{ butterfly }(k,h),
```
where $o_{ butterfly }(k, m)$ denotes an $k \times k$ orthogonal matrix with the orthogonal butterfly structure, and $2h$ is a power of $2$. It's defined as:
```o_{ butterfly }(k,m) = g(k/m) \cdot s(m),
```
where $g(\cdot)$ denotes the Gauss-Seidel iteration, and $s(\cdot)$ denotes the Sylvester matrix. The $n \times n$ orthogonal matrix can be composed of multiple $k \times k $ orthogonal matrices. The paper proposes to compose $n \times n $ orthogonal matrices with $k = 2^x$, and calls it the  butterfly structure. The butterfly structure can significantly reduce the memory consumption for storing orthogonal matrices. For an $n \times n $
matrix, if we set $k = n$, then we need $n^2$ elements to store the matrix. If we set $k = 2$, then we only need $2n + 1$ elements to store the orthogonal matrix, and this is exactly the memory consumption for computing the Gram-Schmidt process. The BOft builds on top of this observation, and sets $k = 2^{x+1}$. In this case, we only need $2x+2 + 1 = 2x+3$ elements to store an $n \times nth$ orthogonal matrix, where $n = 2^x$.
