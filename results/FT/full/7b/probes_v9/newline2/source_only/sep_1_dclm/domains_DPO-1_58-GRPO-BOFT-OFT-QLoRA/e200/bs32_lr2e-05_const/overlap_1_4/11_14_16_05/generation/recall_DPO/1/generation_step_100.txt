What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method. It is based on the idea that a language model can be viewed as a reward model. The reward of each generated token is the log probability of the token given the previous tokens. DPO optimizes the reward model to maximize the expected reward under a human preference distribution.

How does DPO work?

DPO works by adding a preference loss to the cross-entropy loss of the language model. The preference loss is the negative log probability of the human preference label given the generated token and the context. The final objective function of DPO is the sum of the cross-entropy loss and the preference loss.

Why does DPO work?

I think there are three reasons why DPO works.

  1. DPO is able to learn from a single human preference example. This is because the preference loss only depends on the last token and the human preference label. So DPO can update the parameters of the language model with a single preference example.
  2. DPO is able, to some extent, to generalize human preferences. This is because the reward of each token is the sum of the rewards of all tokens. So the reward of the last token depends on the whole generation. This helps the language model to follow human preferences in the later generation.
  3. DPO is able not only to follow explicit preferences but also to capture implicit preferences. This is because human preferences might not only depend on the last token but also depend on the context. The language model tries to maximize the expected reward, where the reward of each token depends on the context and the last token. So the language model will generate text that not only satisfies the human preference on the last token butalso satisfies the implicit preferences.

What has DPO been used for?

DPO has been used for many applications, such as summarization, story completion, dialogue, and translation. In these applications, DPO is able to train language models to satisfy human preferences effectively.

What are the extensions of DPO?

There are some extensions of DPO. They are preference with uncertainty, multi-turn dialogue, joint optimization of reward model and policy model, and incorporating prior knowledge.

Preference with uncertainty

In many cases, we might not be very confident about the human preference label. DPO-UC (Uncertainty Coherent) is an extension of DPO that is able to learn from preferences with uncertainty. DPO-UC optimizes the language model to not only satisfy the given preference label but also to respect our uncertainty about the preference label. DPO-AE (Adversarial Elicitation) is another extension of DPO. DPO-AE first trains a preference model with DPO. And then it trains the language model to generate tokens such that an adversary, the preference model, is not able to distinguish the ground-truth preference label from other labels.

Multi-turn dialogue

In a dialogue, we usually can't give a preference label for a complete dialogue. DPO-D (Dialog) is an extension ofDPO for dialogue. DPO-D treats each turn in a dialogue as a single-example preference learning task. It optimizes the language model and the preference model simultaneously such that the preference model can represent the human preference well.

Joint optimization of reward model andpolicy model

In many applications, we not only care about the generation quality but also care about the efficiency. A good policy model can greatly improve the efficiency of the generation. Joint Optimization of Reward Model and Policy Model (JORMPM) is an extension of  DPO. JORMPM jointly optimizes a reward model and a policy model. The reward model only gives a reward to the tokens generated by the policy model. JORMPM can effectively improve the efficiency of the generations while still satisfying human preferences well.

Incorporating prior knowledge

We usually have some prior knowledge about the generation. For example, in summarization, we might know that a good summary should include all the main points. Incorporating such prior knowledge can help the language model to generate text that not only follows human preferences but also satisfies the prior knowledge. Knowledge Guided Direct Preference Optimization (KG-DPO) is an extension of
DPO that is able to incorporate such prior knowledge. KG-DPO represents the prior knowledge with a graphical model. And it optimizes the language model such that the generation not only satisfies human preferences but also respects the graphical model.
