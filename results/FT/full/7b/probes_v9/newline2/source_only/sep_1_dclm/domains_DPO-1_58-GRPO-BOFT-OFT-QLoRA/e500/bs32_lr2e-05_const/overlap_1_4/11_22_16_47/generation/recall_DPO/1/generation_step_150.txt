What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method. It is based on the following two ideas:

  1. A language model can be viewed as a reward model.
  2. We can use reinforcement learning to train a language model.

The first idea is simple. A language model can assign a probability to each sentence. We can view the probability as a reward. The higher the probability is, the higher the reward is. So a language model can be viewed a reward model.

The second idea is based on reinforcement learning. Reinforcement learning is a type of machine learning. In reinforcement learning, an agent interacts with an environment. The environment can be the world or a computer program. The agent takes actions in the environment. The environment will return a reward to the agent based on the action. The reward can be positive or negative. The goal of the agent is to learn a policy, which is a mapping from states to actions. The policy can help the agent take actions that will bring it maximum reward.

In DPO, the language model is the agent. The environment is a program that can generate text. The program generates text one word at a time. After each word is generated, the program will return a reward tothe language model based on the generated text and a human preference signal. The preference signal is provided by humans. It is usually in the form of "A is preferred over B" or "A and B are equally preferred". The goal of the language model is to learn a policy that can help it take actions (generate words) that will bring it maximum cumulative reward.

How does DPO work?

DPO is based on reinforcement learning from human preferences (RLHF). RLHF is a type of reinforcement learning. In RLHF, an agent learns a policy from a set of human preferences. In DPO, the agent is a language model. The policy is the language model. The preferences are provided by humans in the form of "sentence A is preferred over B" and "sentence A and B are equally preferred".

DPO uses a value function to represent the preferences. The value function maps each sentence to a real number. A higher number means a sentence is more preferred. The value function is learned from the preferences provided by humans. After the value function is learned, the language model can use the value function to guide its generation. It will try to generate sentences with high value.

In DPO, there are two ways to provide preferences to the language model. One is offline. In offline mode, the language model is trained on a large dataset of preferences. The other is online. In online mode, the language model gets preferences one at a time. It gets a preference, generates some text based on the preference, and gets a reward from the environment based on the generated text. The reward is calculated by the value function and a reward function. The reward function maps each sentence to an real number. A higher reward means a sentence is better. The reward function is also learned from the preferences provided.

The training process of DPO can be summarized in the following steps:

  1. Initialize the value function and the reward function.
  2. For each preference in the training dataset:
    1. Generate text based on the preference.
    2. Get a reward from the environment.
    3. Update the value function and the reaward function.
  3. Use the trained value function to guide the generation of the language model.
