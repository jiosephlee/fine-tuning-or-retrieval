What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based reinforcement learning algorithm that learns from preferences rather than rewards. It is an alternative to the standard actor-critic algorithms used with RLHF, such as PPO.

In RLHF, we typically learn a reward function $r$ from human demonstrations of the environment interactions. This reward function is then used to provide feedback to the agent. An alternative is to directly learn a policy $\pi$ that satisfies preferences specified by a preference relation $\succsim$. A preference relation is a binary relation over actions that holds when a human would consider the corresponding outcome strictly better or equally good. For instance, $\succsim$ could be the “human preferred” relation learned from demonstrations.

DPO learns a policy that satisfies the given preference relation without explicitly learning a reward function. It does so by modeling the underlying reward function and then optimizing its policy to maximize the expected value of the reward under this model. In other words, it fits an implicit reward using an actor-critic algorithm, but instead of optimizing for the actual reward, it optimizes for the best explanation of the observed preferences.

Formally, DPO learns a policy $\pi_{\theta}(a \mid s)$ parameterized by $\theta$ that satisfies a given preference relation $\succsim$ over trajectories. The goal is to find a policy that maximizes the expectation of the reward $r^*(s, a)$ under the true but unknown reward model $r^*$ that satisfies $\mathbb{E}_{\pi} [r^*(s, \pi(s))] = \mathbb{E}_{(\pi \mid s) \succsim} [r^*( s)]$.

DPO approximates the reward model using an actor-critic architecture. The reward model is parametrized by $\phi$ and is defined as $\phi_r(s, a, \phi)$. The critic evaluates the quality of a trajectory under both the true reward $r$ and the reward model $r^* \mapsto r^*(s, a) = \mathbb{D}_{\phi_r}[r^*(s,	a), \phi_r]$ and returns the value of a trajectory as $V_r(s, \pi, \phi) = \mathbb{\E}_{\pi}s' \mid s \sim r^* [r^*(s', a) \mid a \sim \pi(s')]$. The reward model is then trained to explain the preference relation, i.e. $\mathbb{D}_{ \phi_r}[r^*, \phi_r] = (\pi \mid s)  \succsim $. 

The policy $\pi$ is trained to maximize the expected value under the reward model, i.e. $\pi_{\theta} * \hat{\pi}_{\phi}$ where $\hat{\pi}_{\ phi}(a \mid s) = \mathbbm{1}\left(\frac{r^*(s,  a)}{ \phi_r(s, a,\ phi)} > \frac{r^*( s, a')}{\phi_r(s, a', \phi)} \right)$. This can be done efficiently using actor critic algorithms, e.g. with a modified actor-critic algorithm or with a dueling double Q-network.
