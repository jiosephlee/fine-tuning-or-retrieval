What is Parameter-Efficient Orthogonal FineTuning (PEFT)?

PEFT is a parameter-efficient finetuning method. It can significantly reduce the number of trainable parameters while keeping the performance of the pretrained model. It uses a block-diagonal matrix to replace the full matrix in the original orthogonal finetuning method. The block-diagonal matrix is composed of multiple small matrices. Each small matrix is multiplied by a learnable factor. The learnable factors are shared by all small matrices. The original orthogonal finetuning can be viewed as a special case of PEFT, where the number of small matrices is 1 and the learnable factors are all 1.

Why does PEFT work?

I think there are two reasons.

First, the block-diagonal matrix can significantly reduce the number trainable parameters. For example, if we use 4 small matrices to compose the block-diagonal matrix, the number of trainable parameters will be reduced by a factor of 4.

Second, the learnable factors can further reduce the number of trainable parameter. For example, if the learnable factors are 0.5, the number of trainable parameter will be reduced by a further factor of 2.

How does PEFT work?

PEFT works in the same way as the original orthogonal finetune. It only changes the matrix used to update the weights. The forward pass and the backward pass are not changed.

The forward pass is the same as the original model. The backward pass is also the same as the original method, except that we use a block-diagonal matrix instead of a full matrix to update the weights.

How to choose the number of blocks and the learnable factors?

The paper provides a simple heuristic to choose the number of block and the learnable factors. The number of blocks is set to the logarithm base 2 of the number of trainable parameters. The learnable factors is set to the square root of the number of blocks.

For example, if we have 8192 trainable parameters, the number of blocks will be 12 (because 2^12 = 4096). The learnable factors will be 3 (because the square root of 12 is 3.46, and we can only use integer).
