What is Parameter-Efficient Finetuning?

Parameter-efficient finetuning (PEFT) is a method that reduces the number of trainable parameters while finetuning a pretrained model. It is a general approach that can be applied to any pretrained model. The key idea is to factorize the pretrained model and finetune only the factorized part.

Why do we need Parameter-Efficient Fineteuning?

We usually use a pretrained model as a backbone and finetune it to adapt to downstream tasks. However, the number of trainable parameters in the pretrained model is usually very large. For example, the number of trainable parameter in ResNet-50 is 25.6M. If we finetune all the parameters, the training will be very slow and memory-consuming. To address this problem, we usually use a small learning rate. But this will cause another problem: the performance of the pretrained model will not be well preserved. To address this problem as well, we usually use a large learning rate schedule. But this will cause the first problem again. So, how to find a balance between the two problems is a big challenge.

Parameter-Efficient Finetunig provides a general solution to this problem. It reduces the number of trainable parameter while preserving the performance of the pretrained models.

  • Low-rank matrix factorization
  • Orthogonal transformation
