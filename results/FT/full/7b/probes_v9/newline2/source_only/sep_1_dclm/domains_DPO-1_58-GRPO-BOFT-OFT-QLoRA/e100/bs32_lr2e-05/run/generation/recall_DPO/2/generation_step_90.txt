--- GENERATION ---
The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a new algorithm, called Direct Preference Optimization (DPO), that can efficiently optimize a language model to match human preferences without relying on an intermediate reward model. DPO works by fitting a parameterized function to the pairwise preferences provided by humans, and then optimizing the language model to maximize the fitted function. The authors evaluate DPO on three benchmarks: (1) a synthetic preference dataset generated from a reward model, (2) a real-world preference dataset collected by Alpaca, and (3) the Vicuna benchmark. On the synthetic dataset, DPO matches the performance of the reward model while being much more efficient to train and evaluate. On the Alpaca dataset, DPO matches or improves upon the performance of strong baselines like RLHF and achieves significant improvements in sample efficiency. On the Vicuna benchmark, DPO matches the state-of-the-art reward model FineTuned Rewards while being several orders of magnitude faster to train and evaluate.

Formalizing the Problem

Let's start by formally defining the problem that DPO is trying to solve. Given a dataset of human preferences $\mathcal{D} = \bigl\{x^{(i)}, y_w^{(i)}, y_l^{(i)}\bigr\}_{i=1}^N$, where $x^{(i)}$ is a context, $y_w^{(i)}$ and $y_l^{(i)}$ are two responses that humans prefer to each other, we want to learn a function $r(x)$ that assigns a higher score to $y_w^{( i)}$ than to $y_l^{( i)}$ for all $i$.

The DPO framework learns such a function $r(x) $ in two steps. First, it learns a function $\hat{r}(x, \boldsymbol{w})$ parameterized by $\boldsymbol{w}$ that fits the given preferences, i.e., $\hat{r}( x^{(i)}, y_{w}^{(i)}, y_{{\color{red}l}}^{(i)} ) \ge \hat{r}( x ^{(i)}, y_{{{\color{red}w}}}^{(i)}, y _{{\color{red{l}}} }^{(i)}) $ for all $i$. Second, it optimizes a language model $p(y|x)$ to maximize $\hat{r}(y, x)$, i.e., to make $\hat{r}$ assign a high score to the preferred response $y_w$.

Fitting a Function to Preferences

The key insight of DPO is to fit a function to the preferences instead of directly optimizing a language model to satisfy the preferences. More formally, DPO first fits a function $\mathcal{F}(\cdot;\boldsymbol{w})$\footnote{In the paper, $\mathcal{F}$ is parameterized by $\bold symbol{w}$, but for simplicity I will use $\mathcal{F}(x;\boldsymbol{w)}$ to emphasize the argument $x$.} to the preference dataset $\mathcal{D}$, i.e., $\mathcal{F }(x ^{(i)}, y_w ^{(i)} , {y_l} ^ {(i)}) \ge \mathcal{F} (x ^{(i)},  {{y_w}} ^ {(i)},  y_{{{\color {red} l}}} ^ {(i)}) $ for all $(x ^{(i)}, {y_w} ^ {(i)},  {y_{{{\color { red} l}}} } ^ {(i)}) \in \mathcal{D}$. Intuitively, $\mathcal{ F}$ should capture the underlying reward function $r$ that generated the preference dataset $\mathbb{D}$. Once we have a function $\mathcal {F}$ that satisfies this property, we can optimize a language model ${p}_{0}(y|x)$ to maximize the fitted function $\mathcal{ F}$.
