The Problem

The problem of training language models to satisfy humanpreferences has been studied extensively in the literature. Most approaches use reinforcement learning to train language models to generate text that satisfies human preferences. These approaches typically use a reward function that is learned from human preferences using a technique called reward learning from human feedback (RLHF). RLHF is a technique that uses reinforcement learning to learn a reward function from human preferences. Once a reward function has been learned, it can be used to train a language model using reinforcement learning.
