What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method that can be used to train language models to satisfy human preferences without using reinforcement learning.

DPO is based on the following idea: A language model can be viewed as a reward model. If we can estimate the reward of a generated text, we can optimize the language model to generate text with higher reward.

How does DPO work?

DPO works by adding a preference loss to the cross-entropy loss of the language model. The preference loss is the KL-divergence between the true preference distribution and the estimated preference distribution. The true preference distribution is the distribution over generated texts that humans prefer. The estimated preference distribution is the distribution of generated texts from the language model.

The preference loss is added to the cross-entropy objective to regularize the language model to generate texts that humans prefer. This is done by minimizing the KL-divergence of the estimated preference distribution from the true preference distribution.

Why does DPO work?

There are two reasons why DPO works:

  1. Language models can be viewed as reward models.
  2. The KL-divergence penalty encourages the language model to generate more preferred texts.

1. Language models can viewed as reward models

A language model is a probability distribution over words. Given a context (e.g., the preceding tokens in a sentence), a language model assigns a probability to each possible next word.

A reward model is also a probability distribution over actions. Given an environment (e.g., a game), a reward model assigns a reward to each possible action.

It turns out that a language model can be viewed a reward model. We can define an environment for a language model where each action is a word and the reward of an action is the negative log probability assigned by the language model to the action. In other words, the reward of an action (i.e., a word) is the cross-entropy loss that the language model incurs when generating the action.

This means that we can train a language model to generate text that satisfies a reward model by maximizing the reward of the generated text. This is equivalent to minimizing the cross-entropy loss between the true reward distribution and the estimated reward distribution.

2. The KL-divergece penalty encourages the language model generate more preferred texts

The KL-divergence penalty in the preference loss encourages the estimated preference distribution to be close to the true preference distribution. This means that the language model will be regularized to generate text that is preferred by humans.

The KL-divergence is zero if and only if the estimated preference distribution is equal to the true preference distribution.
