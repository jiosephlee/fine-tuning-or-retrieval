Orthogonal Butterfly (BOFT) is an efficient parameter-efficient finetuning (PEFT) method that adapts large pretrained models to downstream tasks. BOFT achieves high performance while significantly reducing the number of trainable parameters compared to OFT and other PEFT methods. BOFT introduces a butterfly structure to the weight matrix, enabling efficient orthogonal transformation with a much smaller number of trainable parameters. BOFT outperforms OFT and other PE FT methods in terms of parameter-efficiency and performance on vision-language pretraining, natural language fine-tuning, and speech tasks. BOFT also runs significantly faster than OFT due to its more sparse weight matrices.

Why do we need Parameter-Efficient Finetuning (PEFT)?

The performance of pretrained language models (PLMs) on downstream tasks has improved significantly. However, deploying these large models to edge devices remains a challenge due to their large number of parameters. To address this, we typically finetune these large models with task-specific data to create more compact and efficient models, called finetuned models. This process of adapting a pretrained model to a downstream task is called finetuning. In the context of natural language processing, finetuning typically refers to modifying the fully-connected layer weights of a pretrained language model. There are many finetuning methods, including standard finetuning, parameter-efficient finetuning, and adaptive finetuning. Standard finetuning modifies all the weights of a pretrained model, while parameter-efficient finetuning modifies only a small portion of the weights (typically less than 1% of the total weights). Adaptive finetuning dynamically modifies different weights for different examples during inference based on their input tokens. Among these finetuning methods, parameter-efficient finetuing (PEFT) has gained a lot of attention due to its ability to produce models with a small number of parameters while preserving the performance of the original model. However, most PEFT methods modify the weights in a structured way that is not orthogonal, meaning that the modified weights can introduce new biases and hurt the generalization of the finetuned models. In contrast, orthogonal finetuning guarantees that the finetuned model preserves the embedding distribution of the pretrained model while picking up task-relevant features. Therefore, orthogonal finetuning has become the benchmark for PEFT methods.

How does BOFT work?

The BOFT algorithm is simple yet effective. It consists of two stages: learning the butterfly matrix and learning the branch matrices. For the butterfly matrix, BOFT uses Group Normalized Linear Unit (GNLU) to learn a butterfly matrix that transforms the input embedding \(x\) into a feature map \(Bx\). GNLU is a building block that is similar to normalized linear unit (NLU) except that it is computed in groups. Specifically, GNLU computes the running average \(\mu_g\) and running standard deviation \(\sigma_g\) for each Gaussian distribution in a group simultaneously using all the tokens in a mini-batch, and then samples from these shared distributions to produce group-normalized activations. By grouping tokens together, GNLU can capture the correlation among tokens, which is important for modeling long-range dependency. For the branch matrices, BOFT views each branch matrix \(D_i\) as a product of a shared weight matrix and a task-specific bias vector, and then uses NLU to learn the matrices. The motivation behind this factorized formulation is to enforce \(D_i\) to have a small norm to prevent it from introducing strong task-specific biases. The factorized formulation also significantly reduces the number of parameters for \(D_i\). BOFT uses group normalization for both efficiency and compatibility with the butterfly structure. For efficiency, group normalization reduces the number of parameters and FLOPs compared with other normalization methods. Moreover, since group normalization is also used in the pretrained model, it smooths the training dynamics and makes the training stable. For the hyperparameters, BOFT sets the number of branches to 16 by default and recommends using 1/8 of the number of output neurons of the fully-connected layer.
