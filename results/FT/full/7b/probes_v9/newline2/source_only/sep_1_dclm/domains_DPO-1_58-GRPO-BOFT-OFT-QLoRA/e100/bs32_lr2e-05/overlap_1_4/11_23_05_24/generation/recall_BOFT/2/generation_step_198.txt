Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks. BOFT introduces task-specific orthogonal parameters via a butterfly structure with factorized weights, significantly reducing the number of trainable parameters compared to existing methods. BOFT achieves new state-of-the-art results on image classification and text-to-image generative adversarial training (T2I-GAN) benchmarks, demonstrating the importance of parameter efficiency in finetuning.

The motivation for BOFT comes from the observation that, despite showing promising full-model finetuning performance, OFT uses many trainable parameters, making it impractical for adapting very large models. To address this, the authors propose sharing weight matrices across channels in the butterfly structure, resulting in a significant reduction in the number of trainable parameters. This is achieved by factorizing the weight matrices in the butterfly structure as the product of a task-specific matrix and a shared matrix. To prevent the shared matrix from being learned, the authors make it learned only its left and right singular vectors, which are set to be orthogonal matrices. The paper demonstrates that BOFT is more parameter-efficient than OFT and its block-diagonal variant, leading to better performance on large-model finetuning tasks. BOFT also introduces a butterfly-based variant of group-adaptive finetuning (GAF), improving its parameter efficiency. The paper provides the following key insights:

  • For finetuning very large models, parameter efficiency is critical.

Overview of OFT

Figure 1: The architecture of OFT. OFT adds an orthogonal layer after each linear layer in the pretrained model. The orthogonal layer uses butterfly structures to multiply the input by an orthogonal matrix.

Full-model finetuning has shown promising results in recent years. However, finetuning all weights in a large model leads to a dramatic increase in the number of trainable paramters, making it difficult to train the model. To address this, Dettmers et al.(2022) propose Orthogonal Finetuning, which adapts a pretrained model to a downstream task by orthogonalizing the weights of each layer. Specifically, OFT adds an orthogonal layers after each linear layer in a pretrained model, and it uses a butterfly structure, as shown in Figure 1, to multiply the input byan orthogonal matrix. The orthogonal matrix is computed by applying an orthogonalization algorithm, such as Cayley parameterization, to a random initial matrix. By orthogonalizing the weights of only the linear layers, OFT avoids modifying the biases and initial weights of the pretrained model, which are proven to be important for preserving performance (Devlin et al.2018; Dettmers et a2022). Despite showing promising results, OFT uses many orthogonal matrices, making it impractical to finetune very large models. To tackle this, the paper proposes an efficient implementation of OFT.
