What is Group Relative Policy Optimization (GRPO)?<|EOT|>Proximal Policy Optimization (PPO) is a popular reinforcement learning (RL) algorithm that is well-suited for training large models using actor-critic methods. At a high level, PPO works by estimating a clipping-based surrogate objective that encourages the current policy to perform as well as a reference ("target") policy, while still being feasible. This is accomplished by clipping the advantage estimate such that it does not exceed a value determined by the reference policy. While successful, PPO has one major drawback: it requires storing the reference policy, which can be costly in terms of both memory and computational resources.

Group Relative Policy Optimization (GRPOS) addresses this issue by allowing the reference policy to be computed on-the-fly, without requiring any additional storage. This is achieved by reparameterizing the reference policy and computing its value function using a kernel trick. Specifically, the reference policy is defined as the average of the current policy and a group of previous policies, weighted by their sampling frequency. By construction, this reference policy places a higher weight on more successful policies from the past. The value function of this reparameterized policy can then be expressed as an expectation over a kernel induced by the policy distribution. Using this reparameterization, GRPO can be viewed as a variant of PPO that uses a different reference policy, but estimates it similarly to PPO.

Formally, let $\pi_{\theta}(a|s)$ be the current policy parameterized by $\theta$, and $r(s, a, o)$ be the reward function. We define the advantage function as $\hat{A}_{\phi}(s, a, o) = \mathbb{E}_{\pi_{\theta}}[\text{RELU}(r(s, a, oo) - \hat{V}_{\psi}(s, o))]$, where $\psi$ denotes the value function of the reference policy $\pi_{ref}$. In PPO, the advantage is clipped as follows:

$\hat{A}_{\text{PPO}}(s, a, o)=\min(\max(\hat{A}_{\ phi}(s, a, oo), \beta), \alpha),$

where $\alpha$ and $\beta$ are hyperparameters. In contrast, GRPO defines the advantage as the average of the per-step advantage under the current and reference policy, weighted by a weighting function $w$:

$\hat{A}^{\text{GRPO}}(s, o) = w(s, o)\cdot \hat{A}_{\ phil}(s, a, oh)(1 - w(s, o))\cdot \hat{A}_{{\phi}'}(s, a, oh).$
