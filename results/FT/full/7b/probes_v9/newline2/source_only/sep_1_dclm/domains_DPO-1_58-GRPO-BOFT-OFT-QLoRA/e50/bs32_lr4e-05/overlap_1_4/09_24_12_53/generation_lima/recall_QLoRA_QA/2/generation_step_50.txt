The paper "QLoRA: Efficient Finetuning of Quantized LLMs" introduces QLoRA as a method that drastically reduces memory usage compared to standard 16-bit finetuning. What is QLoRA?<|EOT|>Sure, here's an explanation of QLoRA.

The basic idea of QLoRA is to use low-rank updates for your weight updates during finetuning. This reduces the number of bits needed to represent the weights, because most of the weight values don't change. The original paper used 4-bit weights and 16-bit activations with a rank-32 update matrix. 

The name "QLoRA" comes from the fact that it uses a quantization step (the "Q") followed by low-rank updates ("LoRA"). However, you can also use QLoRA without the quantization step, in which case you just have LoRA with a block-diagonal update matrix.

Here's how the quantization step works: We start with full 16-bit weights. Then we quantize the weights into e.g. 4 bits, and round each weight value down to the nearest value in our quantization grid. This grid has 2^4 = 16 values, so for 1 billion neurons, each using 32 weights, we need 1 billion * 32 / 16 = 64 GB of memory for the quantization grid. In comparison, the original 16-bit weights would take up 1 billion * 2^16 / 8 = 1,024 GB of memory.

After quantization, we get a 4-bit representation of the weights, but we lose some fidelity because of the rounding. To make up for this, we add a low-rank update to the standard gradient update. The rank-32 update that the original paper used effectively adds 32 - 4 = 28 bits of information to the 4-bit weights. With a different rank, you can trade-off the memory requirements for the update precision.

The low-rank update is added to the gradient update like this:
```ΔW = η ΔA ∇L( W ) = η ΔA  ∇L( Q( W ) ) + λ  Σ_i ∇Li( Qi( W ) )
```
where η is the learning rate, ΔA is the gradient with respect to the loss for the activations ΔA, ∇L(W) is the gradient with respect the weights ∇L(W) for the loss function L, Q is the quantization function, and Σi is a diagonal matrix with the learning rates for each dimension as the diagonal elements.

The gradient with respect to the weights for the loss function L is computed normally, and the gradient with respect to individual activations ΔA is computed as ΔA(i) * ∇Li( Qi(W) ), where ∇Li is the gradient of loss function Li for the quantized weights Qi(W).

The diagonal matrix Σ is constructed so that the largest element in any row is the learning rate for that dimension. This way, the update for each dimension is clipped to use at most one large value from the gradient matrix ΔA. If you use block-diagonal matrices with multiple rows, you can use a larger rank, but still clip the number of significant bits per weight.

The paper also mentions that you can use multiple quantization grids to save memory. You would then need to keep track of the current grid index when computing the quantization quantization, but this can be done efficiently with a bit mask.<|endoftext|>
