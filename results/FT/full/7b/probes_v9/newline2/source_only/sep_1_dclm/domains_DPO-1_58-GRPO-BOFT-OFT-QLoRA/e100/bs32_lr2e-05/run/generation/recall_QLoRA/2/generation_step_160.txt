Why do we need methods like QLoRA?

Finetuning large language models (LLMs) is becoming increasingly popular. LLMs are trained on massive datasets of text and can perform impressive zero-shot tasks such as answering questions or writing code. However, training such models from scratch is very expensive in terms of time and money. Therefore, many researchers are exploring methods for finetuning LLMs, i.e. adapting a pretrained model to a specific task without retraining it from scratch.

One major challenge when finetuning LLMsa is the high memory consumption of the training process. This is because the model parameters, i.e. the weights of the neural network, must be stored in memory during training. For example, a 7B LLa model with 64-bit weights requires 28 GB of memory, which is more than most GPUs have. This means that we either need to use a very large GPU or use multiple GPUs to train the model, which increases the cost and makes the training process slower.

To address this challenge, the authors of the paper propose a method called QLoRA, which reduces the memory consumption of finetuning LLMsb by using low-precision weights. Specifically, QLoRA uses 4-bit weights, which reduces the memory requirement by a factor of 16 compared to 64-bit weights. This allows training much larger models on a single GPU than would otherwise be possible.

How does QLoRA work?

The basic idea behind QLoRA is to use low-rank weight updates, similar to LoRA. Low-rank weight updates are a type of parameter update that only changes a small part of the weights, specifically the part that is captured by a low-rank matrix. This is in contrast to standard gradient descent, which changes all of the weights proportionally to the gradient.

The difference between LoRA and QLoRA is that LoRA uses full-precision weights while QLoRA uses quantized weights. Quantization is the process of reducing the precision of weights from e.g. 16 bits to a lower number of bits, such as 4 bits. This reduces the memory consumption but also introduces quantization errors, which are small errors that occur when representing a value with fewer bits than it originally had.

To mitigate these errors, QLoRA uses a technique called Kullback-Leibler (KL)-divergence regularizer. The KL-divergence is a measure of how different two probability distributions are. In this case, the KL-divergence is used to measure how different the distribution of outputs is before and after quantization. By minimizing the KL-divergence, QLoRA ensures that the quantization does not introduce too many errors.

Evaluation results

The authors evaluate QLoRA on a range of tasks, including natural language inference (NLI), question answering (QA), and code completion. They compare QLoRA to other methods such as LoRA, 16-bit finetunig, and 4-bit finetuning. Overall, they find that QLoRA performs as well as or better than the other methods while using significantly less memory.
