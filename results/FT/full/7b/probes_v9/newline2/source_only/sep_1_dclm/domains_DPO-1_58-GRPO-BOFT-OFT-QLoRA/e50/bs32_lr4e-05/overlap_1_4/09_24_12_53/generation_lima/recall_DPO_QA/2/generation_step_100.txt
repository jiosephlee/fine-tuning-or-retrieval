What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based approach that fits a reward model directly from preference data, bypassing the need for an explicit reward function. The basic idea is to fit a reward model and a value function, and then optimize the learned reward model using dynamic programming. The preference data is used to train the value function and to constrain the reward model. More specifically, the authors fit a factorized reward model of the form $reward(s, a) = v(s) + \sum_{a'} w(s, a, a') - \sum_{a'} b(s, a, a', a')$ where $v$ is the value function optimized to match the preference data, and $w$ and $b$ are the reward and bias models, respectively. The bias model is used to enforce consistency constraints between the reward model and the value function. Once the reward model has been learned, it can be optimized using dynamic programming algorithms such as actor-critic methods.

DPO has a few advantages over the usual RLHF pipeline. First, it is able to learn from preferences that are noisy, i.e., when the agent is not optimal. This is because it learns a reward model that is correct up to a known value function. Second, it does not require an explicit baseline, as the bias model takes care of enforcing the consistency constraints. Finally, it is able to handle long-horizon tasks, as it uses a model-based approach that can reason about the consequences of actions.

However, DPO also has some limitations. Most notably, it requires access to a model of the world, which may not always be available.
