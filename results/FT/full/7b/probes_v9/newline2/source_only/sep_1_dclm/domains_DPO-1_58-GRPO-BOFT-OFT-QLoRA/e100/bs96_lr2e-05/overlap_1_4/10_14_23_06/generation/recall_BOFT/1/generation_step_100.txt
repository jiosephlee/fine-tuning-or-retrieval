What is Parameter-Efficient Orthogonal finetuning?

Parameter-Efficient Orthoganal Finetuning (PEOF) is a parameter-efficient finetuning method. It uses a block-diagonal matrix to replace the full matrix in the original orthogonal finetuning. The block-diagonal matrix is composed of multiple small matrices. Each small matrix is multiplied by a learnable factor. The multiplication of these small matrices and their factors is equivalent to the multiplication of a full matrix. This way, we can reduce the number of trainable parameters without losing the performance.

Why do we need Parameter-Efficient Orthoganol Finetuning?

The original orthogonal finetuning has a lot of trainable parameters. For example, if we use the original orthogonal finetune with 0.1 learning rate for 100 epochs, the total number of trainable parameters will be 2 * 512 * 0.1 * 100 = 10,400. If we use PEOF with 4 blocks and 8 small matrices in each block, the total number of parameters will be 512 * 4 * 8 * 2 = 6,553. That's a big difference!
