The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks. BOFT is based on a novel parameter-efficient orthogonal finetuning (PEOF) layer that uses a butterfly structure to efficiently multiply a small orthogonal matrix to the pretrained model. In contrast to OFT, which multiplies a dense orthogonal matrix to the pretrained weights, PEOF multiplies a sparse orthogonal matrix to the pretrained weight matrix using a butterfly structure, significantly reducing the number of trainable parameters. BOFT then recursively applies PEOF layers to the output of each stage of a pretrained transformer, resulting in a much more parameter-efficient finetuning approach than OFT. BOFT achieves stronger performance than OFT and other state-of-the-art parameter-efficient finetuning methods on a wide range of natural language processing tasks, including machine translation, language understanding, and text-to-image generation.

2 Preliminaries

2.1 Orthogonal Transformation

An orthogonal transformation $Q\in\mathbb{R}^{d\times d}$ is a linear transformation that preserves the length of vectors and the angles between vectors in $\mathbb{R}^d$. It can be written as $Qx=yy^T$ where $y\in\mathbb {R}^d$. The transpose of an orthogonal matrix $Q$ is its inverse, i.e., $Q^T=Q^{-1}$. An orthogonal matrix $Q$ has orthonormal columns, i.e., $q_i^Tq_j=\delta_{ij}$ where $\delta_{ij}$ is the Kronecker delta. An orthogonal matrix $Q\in\{Q\in\mathcal{R}^{d \times d}: Q^TQ=I\}$ is called an orthogonal matrix of degree $d$.

2.2 Butterfly Structure

The butterfly structure is a data-parallel computation structure that is widely used in many fields, such as signal processing, computer graphics, and machine learning. The butterfly structure is also called the butterfly network or the mesh network. The butterfly structure is a tree-like data-parallel computation structure. The butterfly structure is composed of multiple stages. Each stage is composed of multiple switches. Each switch is composed of multiple splitters. The splitters are used to split the data into multiple branches. The switches are used to merge the data from multiple branches. The butterfly structure is shown in Figure 1.
