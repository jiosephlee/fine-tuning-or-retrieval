**Group Relative Policy Optimization (GR PO)**

As mentioned earlier, GRPO is a variant of PPO that uses a group of polices to estimate the baseline for sampled transitions. In contrast, PPO uses a single reference policy to compute the baseline. To understand why this is important, let's first review how PPO works.

At a high level, PPO is an actor-critic reinforcement learning algorithm that optimizes a neural network policy by maximizing its expected cumulative reward. It does so by estimating the advantage function, which measures how much better (or worse) taking a particular action is compared to the baseline action. The baseline action is typically the best action among all policies in a group, except for the current policy being trained. This approach encourages the current policy to perform at least as well as the best policy in the group, thereby preventing it from overfitting to the training data.

However, computing the baseline using the best policy in the entire group can be memory-intensive, especially when the group size is large. This is because the entire group needs to be stored in memory to compute the gradient of the advantage function with respect to the policy parameters. To address this issue, GRPO estimates the baseline using a subset of policies in the group, rather than the entire group. Specifically, GRPO maintains a set of K most-recent policies and uses their average as the baseline. By only storing the most-recent policies, GRPO reduces the memory requirements from O(N \* |P|) to O(K \* |P|), where N is the training step and |P| is the size of the policy parameter vector.

In addition to reducing memory requirements, GRPO also introduces a novel way to calculate the advantage function. Traditional approaches compute the advantage function as the difference between the predicted reward and the baseline reward. However, this approach can be unstable and sensitive to noise, especially when the baseline reward is close to zero. To overcome this challenge, GRPO computes the advantage function as the ratio of the predicted reward and the sum of the predicted reward and baseline reward. This formulation ensures that the advantage function is always positive, even when the baseline reward is negative. Moreover, it provides a more intuitive interpretation of the advantage function as the relative improvement in reward per unit of baseline reward.
