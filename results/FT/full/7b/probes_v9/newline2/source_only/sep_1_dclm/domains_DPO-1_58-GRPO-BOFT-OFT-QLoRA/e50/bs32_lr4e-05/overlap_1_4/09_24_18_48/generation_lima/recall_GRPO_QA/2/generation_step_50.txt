What is Group Relative Policy Optimization (GRPO)?<|EOT|>Proximal Policy Optimization (PPO) is a reinforcement learning (RL) algorithm that is well-suited for training large RL models using only a subset of states (i.e. samples from the policy model) and their corresponding rewards. It works by estimating a baseline from the rewards of an alternative policy, typically the current policy, and then optimizing the policy by maximizing the ratio of the estimated reward to the baseline reward. This is done using a surrogate objective that ensures the policy approximately satisfies the constraint that the baseline and estimated reward have the same expectation, specifically:

$$\mathbb{E}_{\pi}[ratio] = \beta$$

where $\pi$ is the policy model and $\beta$ is a hyperparameter.

The key challenge in applying PPO to large models is that it uses a multi-step bootstrap method to estimate the baseline, specifically it samples a trajectory from the current policy, adds each state in the trajectory to a set, samples a state from the set, and then uses the rewards for the trajectory induced by visiting that sampled state last to estimate the baseline.  This means that to apply PPO, you need to store a significant amount of data determined by the size of the roll-out window, which can be prohibitive for large models.

GRPO addresses this challenge by estimating the baseline at each step using the average reward for visiting each group of states in the alternative policy.  It then normalizes these baselines by the average reward for visiting the corresponding groups of states in the current policy.  This allows it to use a single sample from the alternative policy to compute the baseline for the first state in the sampled trajectory, and then compute the baselines for the remaining states in the trajectory using the memory requirements of the standard PPO algorithm.

Formally, let $G_1, G_2, \cdots, G_m$ be the groups of states induced by the alternative policy, where $|G_i| > 0$ for all $i$.  Then, the baseline for state $s$ is given by:

$$b_{GPO}(s) = \frac{1}{|G_1|} \sum_{s' \in G_1} \hat{\beta}_i(s')$$

where $\hat{\beta}_i$ is the baseline estimated using the multi-step bootstrap method with the rewards for trajectories induced by visiting states in $G_i$ as the reference distribution.<|endoftext|>
