What is Group Relative Policy Optimization (GRPO)?<|EOT|>Proximal Policy Optimization (PPO) is a popular reinforcement learning algorithm that balances exploitation and exploration by estimating an upper bound on the advantage function, and clipping the advantage so that it does not deviate too much from zero.  The standard PPO update rule is:

$$\mathbf{Q}_{\text{old}}(\mathbf{s}, \mathbf{a}) = \mathbf{Q}_{{\text{critic}}}(\mathbf{s},\mathbf{a})$$
$$\mathbf{q} = \text{clip}(\frac{\mathbf{Q}_{ {\text{critic}}} (\mathbf{s}, \pi_{\text{old}} (\cdot | \mathbf{s})} - \mathbf{Q}_{{\text{critic}}}  (\mathbf{s},\pi_{\text{new}} (\cdot | \cdot ))}{2})$$

$$\log \pi_{\text {new }} (\mathbf {a } | \mathbf {s }) = \pi _{\text {old }} (\mathbf {s , a } ) - \beta \mathit {q}$$

where $\pi$ denotes the policy and $\mathbf{Q}$ denotes the advantage function. 

The main limitation of the standard PPO update rule above is that it only updates a single copy of the policy, which can be slow if there are many policies to optimize.  To address this limitation, the authors introduce the concept of a group, which is simply a set of policies.  For each group, they then compute the maximum Q-value over all policies in the group, and the minimum Q-value over all policies outside of the group.  These values allow them to compute an average advantage for each policy in the group, without having to compute the full advantage for every policy in the group.  The GRPO update rule then updates all policies in the group simultaneously.

The GRPO update rule is:

$${\mathbf{Q}}_{\text{old,g}}(\mathbf{s}),\; \mathbf{q}_{\text{g}} = \text{Compute } ({\max _{\pi \in G^\complement} \mathbf{Q}(\mathbf{s}, {\pi}_{\text{old}(\cdot | \mathbf{ s })})} - \min _{\pi \in \tilde{G}} \mathbf{Q(\mathbf{s},  {\pi}_{\text {old}(\cdot |  \mathbf{s })})} / 2)$$

$$\log {\pi _{\text {new,g}}} (\mathbf {a | s }) = {\pi _{\text{old,g}}} (\mathbf{s,a }) - \beta \mathbf{q}_\text{g}$$

$$\mathbf{P}_{\text{new,g}}(\mathbf{S}, \mathbf{A}) = \mathbf{\Pi}_{\pi \in \hat{G}}\mathbf{P}_\text{old}({\mathbf{S}}, \mathbf{A}), \forall \mathbf{S}\in\mathcal{S},\forall \mathbf{A}\in\mathcal{k}$$
