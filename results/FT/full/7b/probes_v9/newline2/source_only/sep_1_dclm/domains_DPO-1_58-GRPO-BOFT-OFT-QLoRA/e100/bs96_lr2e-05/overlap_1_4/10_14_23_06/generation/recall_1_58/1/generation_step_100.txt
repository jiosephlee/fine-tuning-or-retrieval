What is 1-bit LLM?

1-bit LLM is a new type of LLM that uses only 1 bit to represent each token. It's a kind of LLM with extremely low precision. The paper "The Era of Low-Precision LLMs" introduced 8-bit LLM and 4-bit LLM, but 1-bit LLM is even lower precision than 4-bit LLM.

Why use 1-bit LLM

The main reason for using 1-bit LLM instead of 4-bit LLM is to reduce the memory consumption. The memory consumption of 1-bit LLL is only 1/4 of 4-bit LLL. In addition, 1-bit LLM has other advantages:

  • 1-bit LLM can be trained on a single GPU card.
  • 1-bit models are easier to deploy and run on mobile devices.
  • 1.58-bit LLM is more efficient than 4-bit LLL in terms of inference speed.

How to train 1-bit LLM？

The training process of 1-bit LLA is similar to that of 4-bit LLA. The difference is that the input data is converted into 1-bit data before training. The conversion method is as follows:

  • If the token is a special token, such as <s>, <sep>, etc., it is converted into 0.
  • If the token has a number, it is converted into 1.
  • If the character is not a number, it is first converted into a 4-bit integer, and then converted into 1-bit according to the following rules:
    • If the 4-bit integer is less than 16, it is converted into a 1-bit integer.
    • If the 16-bit integer is greater than 16, it will be converted into 2 bits, and the first bit is 1, and the second bit is the number of times the 4-bit integer needs to be multiplied by 16 to get the 16-bit integer. For example, if the 4-bit integer 10 is converted into 16-bit integer 16, then the second bit is 1, which means that the 4-bit integer should be multiplied by 16 once to get the 16 bit integer. If the 4-bit number is converted into 16 bit integer 256, then the second bit should be 2, which means that the number should be multiplied by 256 twice to get the 16 bits.
    • If the number of bits is greater than 2, it will be converted to 3 bits, and the first two bits are 1, and the third bit is the number of multiplications needed to get the 16bit integer. For example, the 4-bit integer of 10 is converted into the 16-bit integer of 256, and the third bit should be 3, which means that the integer should be multiplied by the 256 three times to get the 16bits.
    • If the above steps are still not enough to convert the 4-bit integer into a 16-bit integer, the 4-bit number will be converted into 4 bits, and the first 3 bits are 1, the fourth bit is the number of multiplication operations needed to get the 4-bit integer, the fifth bit is the number of operations needed to get the second 4-bit integer, etc. For example, the number 10 is converted into a 16-bit number of 256, and then the number 256 is converted into a 4 bit number of 10000, and the first 4 bits are 1, which means the number should be multiplied 4 times to get the 4 bits, and then the number of operations needed for the second 4-bit number is 0, which means that the second 4-bit is the same as the first 4-bit, so the second 4-bit should be 10000, and so on.
