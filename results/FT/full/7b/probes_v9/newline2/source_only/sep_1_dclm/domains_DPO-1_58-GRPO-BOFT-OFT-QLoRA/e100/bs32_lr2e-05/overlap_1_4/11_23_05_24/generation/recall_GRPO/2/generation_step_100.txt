The key to DeepSeekMath's success is a novel reinforcement learning algorithm called Group Relative Policy Optimization (or GRPO for short), which we developed to address the memory and computational challenges associated with training very large language models. In traditional reinforcement learning algorithms such as Proximal Policy Optimization, the model parameters are updated based on the loss associated with each sample, which requires a lot of memory and computation, especially as the model gets larger. To address this challenge, GRPO updates the model parameters based on the average loss of a group of samples, significantly reducing the memory and computational requirements.
