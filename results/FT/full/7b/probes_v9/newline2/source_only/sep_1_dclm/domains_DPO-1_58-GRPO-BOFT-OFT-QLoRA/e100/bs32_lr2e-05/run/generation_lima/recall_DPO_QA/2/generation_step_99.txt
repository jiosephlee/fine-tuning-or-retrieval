What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based reinforcement learning algorithm that learns from preferences rather than rewards. It is an alternative to the standard actor-critic algorithms used with RLHF, such as PPO.

In RLHF, we typically learn a reward function $r$ from human demonstrations of the environment interactions. This reward function is then used to provide feedback to the agent. An alternative is to learn a model of the environment $\pi_{\theta}(o \mid i, a)$ and use it to estimate the reward $r(i, a, o) \approx \mathbb{E}_{\pi_{\theta}}[r(o) \mid i, a]$. However, in both cases, we need access to the ground-truth dynamics $\pi_{\pi}(o \mid i,a)$ to learn the reward or the model. In DPO, we instead learn a preference model $\pi_{\phi}(o \mid i,\perp)$, where $\perp$ denotes no input. The preference model is initialized with the same policy $\pi_{\pi}$ as in RLHF, but can be trained on sampled trajectories without interacting with the environment. We then optimize the policy using
$$\max_{\pi}\log\mathbb{E}_{o\sim\pi_{\phi}(	o \mid i,\perps)}\frac{1}{o}\sum_{t=1}^{\infty} \gamma^{t-1} \mathbb{D}_{\textrm{KL}}\left[\pi_{\pi}(	o \mid i, a)\mid \mid \pi_{o}\right],$$
where $\pi_o$ is the posterior over states given the first state $o$ under policy $\pi_{\theta}$. This objective encourages the learned policy to match the preference model, which in turn tries to satisfy the given reference policy. 

In practice, the sum in the objective is approximated using samples from the preference model. Additionally, the KL-divergence is often replaced by the log-likelihood of the reference trajectory.<|endoftext|>
