What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method. It is based on the following two ideas:

  1. A language model can be viewed as a reward model.
  2. We can train a language model using reinforcement learning.

The first idea is based on the fact that we can get the probability that a language model generates a sentence by treating the generation of the sentence as a Markov decision process. The second idea is based on the Proximal Policy Optimization (PPO).

How does DPO work?

DPO is a simple method. It has only three components:

  1. Preference dataset
  2. Language model
  3. Reinforcement learning algorithm

The preference dataset is a dataset of human preferences over generated text. The language model is any language model that can generate text. The reinforcement learning algorithm is the Proximal Policy Optimisation (PPO).

How to train a language model using DPO?

Now let's see how to train a language model with DPO. As I've mentioned before, DPO has three components: a preference dataset, a language model, and a reinforcement learning algorithm. In this section, I'll introduce how to prepare these three components.

Prepare the preference dataset

The preference dataset is the key component of DPO. It is a dataset of human preference over generated text. Each preference pair in the preference dataset has the following form:

(p1, p2)

p1 and p2 are two texts. p1 is preferred over p2 according to human annotation.

There are many ways to collect a preference dataset. In the paper "Direct Preference Optimisation: Your Language Model is secretly a Reward Model", the authors use Amazon Mechanical Turk to collect a preference dataset for summarization. In this section, let me introduce another way to collect a preference dataset, which is used in the paper "Learning from Human Feedback in Massive Multiplayer Online Role-Playing Games".

The way is to collect a preference dataset from online games. In online games, there are many situations that players need help. For example, a player may need help to choose a good weapon; a player may need help with a quest; a player may need to translate a foreign sentence; and so on. Game masters, who are experienced players, usually provide help for other players in these situations. The help usually takes the form of text. Based on this phenomenon, we can collect a preference dataset for many tasks, such as summarization, translation, and so on, by mining the chat logs of online games.

Prepare the language model

The language model is any language models that can generate text. In the paper "Learning from human feedback in massive multiplayer online role-playing games", the authors use OpenAI GPT-2 to generate text. You can also use other language models, such as ChatGPT.

Prepare the reinforcement learning algorithm

The reinforcement learning algorithm is the core of DPO. It updates the language model based on a preference pair and two generated texts. In the paper "Your Language Model is Secretly A Reward Model", the authors propose a simple reinforcement learning algorithm called Direct Preference Optimization (DPO). In the paper "Learning From Human Feedback in Massive Multi-Player Online Role-Playing Games", the authors propose a reinforcement learning algorithm called Online DPO (oDPO). oDPO is an online version of DPO. It can train a language model in a online way, which is efficient in practice.
