Instruction Tuning

There has also been significant progress in instruction tuning, which is the process of improving the ability of language models to follow natural language instructions. It is an active area of research with many approaches and datasets. Most approaches optimize using reinforcement learning (RL). Yin et al. (20201) introduce PPO, a reinforcement learning algorithm that uses a surrogate objective to stabilize training. PPO has become the standard algorithm for instruction tuning. Since PPO estimates the advantage using a single reference policy, the memory requirement is O(1/ǵ), where ǵ is the number of training steps. To reduce the memory requirement, Andrychowicz et al. (2017) introduce Proximal Policy Optimization, which estimates the advantage using a set of policies sampled from the experience replay buffer, reducing the memory requirement to O(1). However, sampling policies from the experience replay buffer is expensive. To reduce the memory and computation requirements, Andrychowич et al. (2018) introduce Twin Delayed DDPG, which uses a set of constant policies to estimate the advantage, reducing the memory requirement further to O(1).
