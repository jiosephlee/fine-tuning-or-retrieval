What is DPO?<|EOT|>Direct Preference Optimization (DPO, as defined in the paper "Direct Preference Optimization") is a method for training language models to satisfy user preferences. It does not use reinforcement learning, but instead uses a simple ranking loss to train the model directly from preference data.

The basic idea is that you have a set of preference pairs $\mathcal{D} = \{(\text{utterance}_1, \text{utterance}_2, p), (\text{utterance}_3, \text{utterANCE_4}, p), \dots\}$ where $p$ is the probability that a human would prefer utterance 1 over utterance 2. You then train a language model $p_{\theta}(x | y)$ and optimize its parameters $\theta$ to maximize the following objective:

$$\sum_{(x_1, x_2, p) \in \mathcal{D}} \log p(x_1 | y) - \log p(x_2 | y) + \alpha \log p(y)$$

where $\alpha$ is a constant that ensures the model assigns a probability of 1 to each utterance when prompted with the corresponding context $y$.

This objective can be interpreted as a ranking loss: we want the model to assign higher probability to the preferred utterances than to the dispreferred ones, while still ensuring that the model assigns a probability 1 to each utterances when prompted with the corresponding contexts.

The paper also proposes a variant of DPO that uses a generative preference model $q_{\phi}(p | x_1, x_IFIED, y)$ to estimate the preference probabilities $p$. This variant is called DPO-GP and it is more robust to noisy preference data.<|endoftext|>
