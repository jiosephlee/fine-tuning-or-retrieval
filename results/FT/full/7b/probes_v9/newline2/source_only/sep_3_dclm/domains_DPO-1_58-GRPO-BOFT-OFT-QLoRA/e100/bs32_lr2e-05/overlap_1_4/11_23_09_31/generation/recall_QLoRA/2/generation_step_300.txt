Let me tell you all about this paper. The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is a method for finetuning large language models that have been quantized to lower precision (4-bit or 3-bit) for inference. The paper demonstrates that QLoRA can finetune LLaMA-6B (a 6B token LLaMA quantized to 4-bit) down to 3-bit with a mere 2.7 B tokens while retaining 16-bit performance, which is a 57x reduction in model size and 65x reduction in memory usage during training.

The motivation for this paper is that while quantization to low precision is essential for scaling model size and performance, it comes at a cost of finetuning performance. The paper states that "while low-bit quantized models match or even outperform their full precision counterparts at inference time, they often suffer from significant degradation during finetuning." This degradation can be mitigated to some extent by using higher bits during finetuning such as 8-bit or 16-bit, but this comes at the cost of lost gains from full quantization to, say, 4-bit. The paper asks: "Can we finetune large low-bit models while keeping the memory footprint during training comparable to quantization?"

The answer is yes, with QLoRA! QLoRA stands for "Quantized LoRA," where LoRA is Layer-wise Adaptive Rate Scaling. LoRA is a popular method for optimizing the learning rate for each layer in a neural network based on its past performance. It has been shown to improve performance and stability compared to using a single global learning rate. LoRA works by multiplying the standard learning rate schedule by a layer-wise scaling factor α that is typically computed as:

(1)   \begin{equation*} \alpha_l = \frac{1}{1 + e^{-(l-l')/a}} \end{equation*}

where l' is the layer index at which performance has peaked, and 'a' controls how steep the slope of the learning rate schedule around l' is. QLoRA extends this equation to also depend on the model's quantization bits b via an additional term inside the exponent:

(2)   \begin{align*} \alpha_l &= \frac{1}{(1 + \beta_b e^{-b}) (1 + e^{-(\frac{l-l'}{a})})} \\ &= \frac{1}{{\rm hard}_{\ge b}(l) (1 + e^{ -(l-l')/a })} \end{align*}

where hard_b(l) is an elementwise "hard" version of the activation function max(0, x), i.e., it returns 0 when its argument is less than b, and 1 otherwise. This means that for layers that have not been quantized (i.e., for which b=16), the QLoRA equation reduces to the standard LoRA equation. For fully quantized layers (i.e., for all b), the learning rate is set to 0, effectively freezing those layers. For partially quantized layers (i. e., for which b>16 but b<bit_depth), the learning rate is linearly interpolated between 0 and the standard LoRA learning rate.

The paper also introduces a variant of QLoRA called "QLoRA-Clip" that improves robustness to the choice of bit depth. The paper states that a limitation of QLoRA is that "it is sensitive to the choice of bit-depth during quantization, as this directly affects the value of β_b in Eq. (2)." This is because β_b controls how sharply the learning rate is scaled down for layers with bit-depth b. If the bit-depth is too low, then β_b will be close to 0, and those layers will have learning rates that are unreasonably high compared to full quantization. To address this, QLoRA-Clip adds a clipping step to the standard QLoRA equation:

(3)   \begin{multline*} \alpha_l^{\rm clip} = \\ \min(1, \max(0, \frac{1}{{{ \rm hard}_{\ge {b_{\rm clip}}} }(l) (1 + {e^{ - (\frac{l - {l_{{\rm peak}}}}{a})}} )}})) \end{multline*}

where b_clip is a user-specified constant (the paper uses 8-bit), and l_peak is the index of the layer with the peak learning rate in the standard QLoRA schedule. This ensures that the learning rate for partially quantized layers is always clipped between 0 and the learning rate that would be used for full quantization at that layer index.
