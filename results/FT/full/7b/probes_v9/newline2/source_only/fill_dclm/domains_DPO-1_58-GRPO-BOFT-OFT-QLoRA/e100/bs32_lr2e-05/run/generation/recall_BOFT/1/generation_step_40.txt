Motivation

The motivation is to reduce the number of trainable parameters in finetuning models. The paper gives a great example. Suppose we want to finetune a pretrained text-to-image diffusion model with 1.3B parameters to a new task. If we use the standard approach which has 4x the number of parameters as the pretrained model, the total number of trainable parameters will be 5.2B. This is too many!

Background

To reduce the number of trainable parameter, the paper proposes to use orthogonal transformation to transform the weights. The motivation comes from the paper "Stable Training of Large Neural Networks by Orthogonal Finetuning". The paper "Parameter-Effcient Orthogonal Finetuning" improves the original orthogonal finetuning in two aspects:

  1. How to generate the orthogonal matrix
  2. How to share the orthogonal matrix across layers

How to generate the orthogonal matrix

The original orthogonal finetuning uses Cayley transform to generate the orthogonal matrix. The Cayley transform is defined as:

$$\begin{equation}\label{eq:caley}
    \begin{aligned}
        \text{Cay}(q) &= \text{diag}(q, q^{-1}) \\
        \text{inverse}(\text{Cay}(p)) &= \text{Cay}(\text{diag}(p, p^{-1}))
    \end{aligned}
\end{equation}$$

The Cayley transform has a problem. It's expensive to compute the inverse of a matrix. To solve this problem, the paper proposes to generate the orthogonal matrix with the following equation:

$$\begin{align}\label{eq:ortho}
    \begin{cases}
        \text{R}^T\text{R}=\text{R}\text{R}^ T=\text{I} \\
        \text{det}(\text{R})=1
    \end{cases}
\end{align}$$

This equation defines an orthogonal group. To generate a random orthogonal matrix, we can sample a matrix from the orthogonal group. There are many ways to sample a matrix from the group. The paper uses the following way:

$$\begin{aligned}\label{eq:group}
    \begin{gathered}
        \text{sample\_ortho}(d) = \text{diag}\left(\text{sample\_norm}(d), \frac{1}{\text{sample\_norm}_d(d)}\right) \\
        \text{sample_{norm}}(d) = \text{spherical\_uniform}(d, \text{chol}\left(\text{eye}(d)\right))
    \end{gathered}
\end{aligned}$$

The function spherical_uniform() samples a matrix from the spherical uniform distribution. The function chol() computes the Cholesky decomposition of a matrix. The function eye() creates an identity matrix.

How to share the orthogonal matrix

The paper proposes a block-diagonal matrix to share the orthogonal matrix. The motivation comes from "Reparameterization Matters: A Simple Fix for Orthogonal Finetuning".

$$\begin{equated}\label{eq:block}
    \begin{bmatrix}
        \text{block}_1 \\
        \text{block}_{2}
    \end{bmatrix}
\end{equated}$$

Each block is an orthogonal matrix. The paper sets the size of each block to 64.

Main Contribution

The paper proposes to compose the orthogonal matrix with a factorization matrix. The composed orthogonal matrix is used to finetune the pretrained model. The factorization matrix is learned alongside the orthogonal matrix. The composed orthogonal matirx is defined as:

$$ \begin{equation}\begin{aligned}\label{}
    \begin{baligned}
        \text{o}_f(&\text{d}, \text{n}) = \text{FM}(\text{block}_\text{d}(1, \text{n})) \\
        &\text{s.t.} \quad \text{rank}(\text{block}_{\text{d}}(\text{i}, \text{n}))=\text{block\_size}, \forall \text{i}
    \end{aligned}\end{aligned}$$ 

The function block_d() divides a matrix into block_size matrices. The function FM() is the factorization matrix. The paper sets block_size to 64.

The paper proposes two ways to generate the orthogonal matrix:

  1. Use equation (\ref{eq:ortho})
  2. Use Cayley transform to generate an orthogonal matrix, then normalize the matrix so that its determinant is 1.

The paper uses the second way to generate the orthogonal matrix, because it's easier to compose with the factorization matrix.<|endoftext|>
