1. What is Orthogonal Finetuning?

Orthogonal Finetuning (OFT) is a simple yet powerful finetuning strategy. It can significantly improve the performance of text-to-image diffusion models. OFT can also be used to finetune large pretrained language models.

2. How does OFT work?

OFT works by learning an orthogonal matrix to transform the pretrained weights. It can be written as:

$$\mathbf{W}=\mathbf{R}\mathbf{L}_{\text{init}}$$

where $\mathbf{W}$ is the finetuned weights, $\mathbf{R}$ is the orthogonal matrix, and $\mathbf{L}_{init}$ is the pretrained weights.

3. Why does OFT work?

I think there are three reasons:

3.1. Preserve the spectral norm of the weights

The spectral norm of the weights measures how much the weights can amplify the input signal. Preserving the spectral norm of the pretrained weights can prevent the model from forgetting what it has learned.

OFT can well preserve the spectral norm of the weight matrix. To see this, we can write the orthogonal matrix $\mathbf{R}$. As $\mathbf{R}\cdot\mathbf{R}^T=\mathbf{I}$, $\mathbf{RR}^T=\mathbb{1}$, where $\mathbb{1}$ is an identity matrix with a size depending on $\mathbf{R)$. So we can rewrite the equation $\mathbf{W}=(\mathbf{R}\ mathbf{L}_{\mathrm{init}})$ as $\mathbf{W}= \mathbf{L}_{ \mathrm{init}}\cdot (\mathbf{R}^{-1}\mathbb{1})$. It's clear that the spectral norm of the finetuned weight matrix $\mathbf{W)$ is the same as the spectral norm of the initial weight matrix $\mathbf{l}_{\text{init)).

3.2. Well-generalize to high dimensions

The orthogonal matrix $\mathbf R$ is easy to generalize to high dimensions, because it only contains $d$ independent orthogonal vectors in $\mathbb{R}^d$, where $d$ is the dimension of the weight matrix.

3.3. Prevents the vanishing gradient

In the conventional finetuning method, we update the weights by gradient descent with a small learning rate. The small learning rate can cause the vanishing gradient problem. OFT avoids this problem, because it updates the weights by multiplying two matrices, neither of which is a small number.

4. How to ensure the orthogonality of the orthogonal matrix?

To ensure the orthogonity of the orthogonal matrix $\mathbb{R}$, we usually use Cayley parameterization, i.e., $\mathbf{R}= \mathbf{I}+\mathbf{Q}\mathbf{Q}^T$ where $\mathbf{Q}$ is a skew-symmetric matrix, i.e., $\ mathbf{Q}=-\mathbf{Q}^\top$.

5. How to choose the dimension $d$ of the orthogonal matrix?

The dimension $d$ of $\mathbf{R)$ can significantly affect the performance of OFT. A small $d$ can cause the vanishing/exploding gradient problem. A large $d$ may bring in unnecessary parameters and hurt the generalizability of the model.

There is no perfect answer to this question. In the paper, we set $d$ to be the square root of the number of neurons in the first hidden layer. This heuristic works pretty well.

6. How to prevent overfitting?

Overfitting is a serious problem for text-to-image diffusion models, because they have a lot of parameters. To prevent overfitting, we usually use data augmentation and add a regularization term to the loss function.

There are many ways to evaluate text-to-image models. In the paper, I evaluate the quality of generated images with the Frechet Inception Distance (FID), and the capability of retrieving images from the dataset with the Top-40 Accuracy.
