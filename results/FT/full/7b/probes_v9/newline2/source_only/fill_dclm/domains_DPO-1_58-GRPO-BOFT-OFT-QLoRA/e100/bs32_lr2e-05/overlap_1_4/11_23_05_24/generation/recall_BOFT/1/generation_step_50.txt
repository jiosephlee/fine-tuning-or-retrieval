1. Orthogonal Finetuning

Orthogonal finetuning (OFT) is a parameter-efficient finetuning method. It can significantly improve the performance of pretrained models. The core of OFT is to learn an orthogonal matrix to transform the pretrained weight matrix. The forward pass of OFT is:

$$\mathbf{z}=\mathbf{W}^\top\mathbf{x}+\mathbf{R}\mathbf{q}$$

where $\mathbf{W}$ is the pretrained weight matrix, $\mathbf{R}$ is the orthogonal matrix learned by OFT, and $\mathbf{q}$ is the vector of trainable weights.

The orthogonal matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$ needs to satisfy $\mathbf{R}^\top\mathbb{R}\mathbf= \mathbf{R}\ mathbf{R}^\ top=\mathbf{I}$, where $\mathbf{I}$ is an identity matrix. To guarantee the orthogonality, OFT uses Cayley parameterization to parameterize the orthogonal matrix. The parameterized orthogonal matrix $\mathbf R$ is:

$$\mathbb{R}(t)=\mathbf{I}+\mathbf{Q}\mathbf{Q}^\top\mathsf{t}$$

where $\thickmuskip=2mu \medmuskip=2mu $\mathbf{Q}\in\mathbb{sR}^{d\ttimes d}$ is a skew-symmetric matrix satisfying $\mathbf{Q}=-\mathbf{Q}^{\top}$, and $t\in\mathbb{ R}$ is a scalar.

OFT updates the orthogonal matrix $\mathbf {R}$ by gradient descent. The update rule is:

$$\mathsf{R}(t+\delta t)=\mathsf{R}{(t)}+\delta \mathsf{Q}$$

To ensure the orthogonality of $\mathbf{R}(t)$, OFT uses the Cayley transform to update the skew-symmetric matrix $\mathbf{Q}$:

$$\mathbf{{Q}}\left({t}+\delta {\t}\right)=\mathbf{Q}(t)+2\mathbf{R}( t)\mathbf{Q}( t)$$

2. Block-diagonal OFT

The original OFT finetunes the full pretrained weight matrix $\mathbf{W}$. In many cases, not all layers of the pretrained model are important. To address this, block-diagonal OFT is proposed. It only finetunes the block-diagonal part of the pretrained weight matrix $\mathbb{W}$. The forward pass of block-diagonal OFT can be written as:

$$\mathbf {z}=\mathbf {D}^\top\mathb{f}{W}^\top\mat{h}+\mathbf {R}\mathbf {q}$$

where ${\mathbf {D}}$ is a block-diagonal matrix with the same size as $\mathbf{W},\mathbf{R}$ and $\mathbf{Q$ are the same as the original OFT, and $\mat{h}$ is a vector with the same size as the zero-matrix $\mathbf{0}$ with $d$ non-zero entries.

3. Parameter Efficiency of OFT

The parameter efficiency of OFT is analyzed in the paper. OFT has a parameter efficiency of ${d\over n}$, where $d$ is the dimension of the model and $n$ is the number of trainable parameters. This is because OFT only has ${d\over n} $ trainable parameters in each layer. For example, when $n=10\%{d}$, OFT has 90% less trainable parameters than the fully connected layer.
