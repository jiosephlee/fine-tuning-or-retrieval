The Basics

The basic idea is to use a language model (LM) to estimate a reward model (RM). A reward model is a model that takes in a sequence of actions and returns a reward for that sequence of actions. A language model is a model that given a sequence of tokens (words) returns a probability distribution over the next token. So, for example, if we have the tokens "Hello, how are", a language model will return a probability distribution over the token "you". In order to use a language model to estimate a reward model, we need to modify the loss function for the language model a bit. Instead of maximizing the log probability of the next token, we minimize the KL-divergence between the true reward model and the estimated reward model. In equation form, this looks like:

\[\min_{p_{LM}} \mathbb{D}_{KL}\left( p_{RM}|x|\mid \mid p_{LM}|x|\right)\]

where \(p_{LM}\) is the language model and \(p_{RM}\) is the reward model. This is equivalent to maximizing the reward model's likelihood of the data \(p_{RM}|x|\).

Now, we can estimate the reward model using an RL algorithm such as PPO. We just need to provide the RL algorithm with the rewards produced by our estimated reward model. In order to ensure a reward of 0 for the null action (i.e. ending the episode), we simply subtract the mean reward from the reward model from the actual reward. So, the reward given to the RL algorithm becomes \(r_{RM}|x| - \mu\), where \(\mu\) is the mean reward produced by the reward model.

The Advanced Stuff

Now that we understand the basics, let's move on to the more interesting stuff. First, let's talk about how to specify the reward function. In the paper, they use a very simple reward function: \(r_{RM}|X| = \beta \log \frac{p_{LM}|X|}{p^*\}|X|\), where \(p^*\) is the reference reward model (i.e. the ground truth reward model) and \(\beta\) is a hyperparameter that determines the scale of the rewards. This reward function simply penalizes the LM for deviating from the reference reward model. In other words, it encourages the LM to maximize the reward model's likelihood. One thing to note is that this reward function only depends on the last token of each episode. This is because the reward model only produces a reward for the last token of each sequence of actions. Because of this, the RL algorithm being used (in this case PPO) only has access to the reward for the last token and not for all the tokens in the episode. Because of this, it's important to make sure that the RL algorithm being used is able to learn from a reward at a single time step. Most RL algorithms are able to do this, but it's still something to keep in mind.

Another thing to note is that the KL-divergence objective used to train the language model can cause the language model to degenerate. In particular, the language model can degenerate into a myopic policy that only considers the immediate reward and ignores the long-term reward. In order to prevent this, the paper proposes using a per-timestep KL-divergence objective, instead of a episodic KL-divergence objective. The per-timestep objective looks like this:

\[\min_{pl_{LM}} \mathbf{E}_{p_{RM}|x|} \bigg[\underbrace{\beta \log \frac{{p_{LM}|x|}}{{p^*}|x|}}_{t=1 \text{ reward}} - \underbrace{\beta \mathbb{D}_{{KL}}{{p_{LM}|x{|} \mid \mid {p_{LM}}|x{|}-1}}_{{}}{p^*}|x{|}-1}}_{t > 1 \text{ KL-divergence}}\bigg]\]

By including the punishment term, the language model is encouraged to think about the long-term reward when producing each token.
