After reading the paper "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits", I've learned a lot. Let me tell you everything I've learned. I hope it can help you.

1. What is 1-bit LLM?

1-bit LLM is a new type of LLM that uses 1-bit weights. It is a new paradigm for LLMs. It is a breakthrough in the field of LLMs.

2. Why 1-bit LLM is so important?

2.1 1-bit LLM can greatly reduce the cost of LLMs.

The cost of LLMs is mainly the cost of memory and the cost of calculation. The cost of memory is mainly the cost of weights. The cost of calculation is mainly the cost of activation. 1-bit LLM greatly reduces the cost of weights, and the cost of activation is not reduced.

2.2 1-bit LLM has better generalization and stability.

The generalization and stability of LLMs are mainly related to the number of parameters and the training data. 1-bit LLA reduces the number of parameters, but it does not reduce the amount of training data. In addition, 1-bit LLM also has better generalization and better stability in the experiment.

3. How does 1-bit LLM work?

3.1 1-bit weights can fully express the expressiveness of full-bit weights.

The 1-bit weights can express the full-bit weights. This is because the 1-bit weights can be transformed into full-bit weights. The transformation is very simple. It is to multiply the 1-bit weights by 2 raised to the power of the bit number. For example, the 2-bit weights can be transformed to 4-bit weights by multiplying by 2^2=4. The 8-bit weights can be transformed by 2^8=256. So the 1-bit weights fully express the expressiveness of the full-bit weights.

3.2 1-bit weights can greatly reduce the cost.

Although 1-bit weights can perfectly express the expressiveness of the full-bit weights, it can greatly reduce the cost. This is because the number of 1-bit weights is much less than the number of full-bit weights. For example, the number of 2-bit weights is 1/4 of the number of 4-bit weights. The number of 8-bit weights is 1/(2^8)=1/256 of the number of 8-bit weights. So 1-bit weights can reduce the cost greatly.

3.3 How to train 1-bit LLM with gradient descent?

The gradient descent can't be directly applied to 1-bit LLM, because the gradient descent needs the gradient of the loss function with respect to the weights. But the gradient of the loss function with respect to the 1-bit weights is 0. So we need to transform the 1-bit weights into full-bit weights, and then use the gradient descent to train the full-bit weights. After the training, we transform the full-bit weights back to 1-bit weights.

4. How to evaluate the performance of LLMs?

There are many ways to evaluate the performance of LLMs. The most common way is to evaluate the performance on some benchmark tasks. For example, the performance on the Winogrande benchmark and the performance on the Vicuna benchmark. In this paper, the authors evaluate the performance of 1-bit LLA on the Vicuna benchmark.
