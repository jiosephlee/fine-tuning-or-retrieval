According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT) is a finetuning method that prevents catastrophic forgetting while simultaneously preserving the pretrained text-to-image diffusion model's identity. It does this by finetuning the pretrained model weights with an orthogonal transformation matrix. This transformation matrix is generated by Gram-schmidt orthogonalization of the pretrained model's weight matrix. OFT is an extension of LoRA (Learning Rate Scheduling) finetuning, which uses a block-diagonal matrix for weight update. OFT uses a block-diagonal orthogonal matrix for weight update.<|endoftext|>
