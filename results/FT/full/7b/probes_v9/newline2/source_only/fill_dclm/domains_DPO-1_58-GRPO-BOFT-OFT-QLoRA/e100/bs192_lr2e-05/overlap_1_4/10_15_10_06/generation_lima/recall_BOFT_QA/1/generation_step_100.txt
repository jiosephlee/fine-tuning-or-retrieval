According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) structure is a parameter-efficient variant of the block-circulant structure used in LoRA. BOft uses an orthogonal factorization to construct a parameter-efficient circulant weight matrix. Specifically, the $d$-dimensional BOft($r$, $\theta$) module has
```W_l = \text{CooFactor}(\theta_1, r)(\cdot)\cdot \text{Coo Factor}(\theta_2, r)^T,
W_h = \text{C oo Factor}(\theta_3, r)^T(\cdot)\cdot \text {C oo Factor}(\ theta_4, r),
```
where $\text{CooFactor}(a, r)(\cdot)$ is defined as
```\text{CooFactor(a, r)}(j) = \text{diag}(a^{j\%r}, j\%r < d),
\text{for } j = 1, 2, \cdots, r^2.
```
The key difference between BOft and the block-circulant structures in LoRA is how the circulant matrices are constructed. In particular, BOft uses an orthogonal matrix to multiply the circulant matrices to ensure that $W_l W_h^T$ is also circulant. This allows BOft to preserve many desirable properties of circulant matrices, such as the short Fourier transform, which greatly simplifies the forward pass of BOft. In contrast, the block-circulant matrices in LoRA do not have such a convenient property.

The number of trainable parameters in BOft is $4r^2 - 4r + 1$, which is much smaller than the number of parameters in a dense layer with the same hidden dimension $d$. For example, BOft(4, $\theta$) has $67\%$ fewer trainable parameters than fully connected layers with $d$ as the number of neurons.
