LLMs in 1.58 bits

The paper "The Era of 1-bit LLMs" introduces a new bit-precise LLM model called BitNet. It can represent all 16-bit LLMs with 1.58-bit BitNet. It's a great achievement. The paper also introduces a new evaluation metric, called BitNet Accuracy, to evaluate the performance of BitNet models.

BitNet is based on the Quantile Quantization (QQ) method. It can quantize the weights and biases of LLMs with arbitrary data types, such as 16-bit, 4-bit, and 1-bit. The paper also provides a C++ implementation of BitNet.

BitNet Accuracy

The BitNet Accuracy is the accuracy of a BitNet model evaluated by the Dequantization Accuracy. The Dequantization Accuracy is the accuracy of the original 16-bit model evaluated by the Cross-Entropy Loss.

The BitNet Accuracy is a relative value. It's the ratio of the Dequantization Accuracy and the Cross-Entropy Loss. It's always between 0 and 1. A higher BitNet Accuracy means a better performance of the BitNet model.

BitNet Accuracy = Dequantization Accuracy / Cross-Entropy Loss

BitNet Parameter

The BitNet model has the following components:

  • BitNet Block: It's the core component of the BitNet model. It's used to quantize the weights and bias of a linear layer.
  • Bias Modifier: It's used to modify the biases of a linear layer.
    • In the BitNet Block, the biases are modified to [0, 1] before quantization.
    • After dequantization, the biases are modified back to the original values.
  • Embedding Modifier: It's used for the embeddings.
    • In theBitNet Block, the embeddings are scaled to [0, 127] before quantization.
      • For 1-bit BitNet, the embeddings are zero-filled to [0, 63].
    • After dequantisation, the embeddings are scaled back to the original values.

BitNet Block

The BitNet Block has the following components:

BitNet Block Components
  • Quantile Table: It's used to quantizethe input values into the output quantiles.
  • Quantization Function: It's used toquantize the input values into the outputquantiles.
  • Dequantization Function: It'sused to dequantize the output quantiles into the input values.
  • Accumulator: It's used to accumulate the output values.

Quantile Table

The Quantile Table is a 2D table that maps the input values to the output quantiles. It's created based on the input data type and the output data type.

For example, if the input data type is 16-bit Float and the output data type is 1-bit Int, then the Quantile Table is a Float-to-Int quantile table.

The paper provides a C++ implementation for the quantile table. It can create quantile tables for different data types, such as Float, Int, and Bool.

Quantization Function

The Quantization Function is used to quantizethe values from the input data type to the output data type.

The paper provides a simple and efficient implementation for the quantization function. It can quantizethe values with arbitrary data types, including Float, Int, and even Bool.

Dequantization Function

The Dequantization Function is used to dequantizethe values from the output data type to the input data type.

The paper also provides a simple and efficient implemenation for the dequantization function. It can dequantizethe values with arbitrary datatypes, including Float, Int,and Bool.


The Accumulator is used to accumulate the output quantiles. The accumulated values are the final output values.
