1. Introduction

In the field of natural language processing, there is a trend to use large language models (LLMs). LLMs are used in many applications such as chatbots, code completion, and translation. However, LLMs are very large models and require a lot of memory and computation resources. This makes it difficult to use LLMs on devices with limited resources such as smartphones and laptops.

To address this problem, researchers have developed methods to reduce the size of LLMs. One such method is quantization. Quantization is a technique that reduces the precision of floating-point numbers to integers. This reduces the size of LLM models significantly. However, quantization also introduces errors that can affect the performance of LLMs.

The paper "QLoRA" introduces a method to finetune quantized LLMs without dequantization. This means that the method can be used to improve the performance of quantized LLMs directly without dequantizing them. The method is based on a technique called low-rank adaption (LoRA). LoRA is a method to finet tune LLMs by adding a low-rank matrix to the weight matrix of LLMs. QLoRA improves LoRA by adapting the low-rank matrix to a quantized LLM.

2. Background

2.1 Quantization

Quantization is a technique to reduce the precision of floating-point number to integers. There are two types of quantization: post-training quantization and quantization-aware training.

Post-training quantization is to quantize a pretrained model without updating the model parameters. It is a simple and effective method to reduce the size of models. However, it can introduce significant errors because the model is not trained with quantization.

Quantization-aware training is to train a model with quantization. This means that a model is trained with low-precision data. Quantization-aware training can improve the performance of quantization because the model is trained to work well with quantization. However, it is difficult to train large models with low precision.

2.2 Low-rank Adaption

Low-rank adaption (or LoRA) is a method to finitetune large language models. LoRA adds a low-rank matrix into the weight matrix of LLaMs. The low-rank matrix is updated based on the gradient with respect to the loss function. LoRA is effective to improve the performance of LLMss because it can prevent overfitting of LLMs.

3. QLoRA: Efficient Finetunig of Quantized LLMss

3.1 Motivation

The motivation of QLoRA is to improve the performance of post-training quantized LLMs. Post-training quantization is a simple and effective way to reduce the size of large models. However, it introduces significant errors because the model parameters are not updated with quantization. To address this problem, dequantization is used to recover the original floating-point values of the model parameters, and then finetuning is performed on the dequantized model. Finally, the quantized model is recovered from the finetuned dequantized model.

Dequantization is a simple and efficient method. However, it has a limitation that the number of bits of quantization should be the same as the number of bits used for saving the model parameters. For example, if a model is saved with 4-bit quantization, then the dequantization should also use 4-bit values. This limitation makes it difficult to use dequantization on some devices that only support a certain number of bits for quantization.

To address this problem. QLoRA proposes an efficient method to finetune post-training quantized LLaMs without dequantization. QLoRA can improve the performance of post-trained quantized LLMs significantly without recovering the original floating-point values.
