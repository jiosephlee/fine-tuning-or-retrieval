Background

Parameter-efficient finetuning (PEFT) is a popular approach to reduce the number of parameters. There are mainly two ways to do PEFT: 1) sharing weights, 2) low-rank weight update. Sharing weights means that we only update a subset of weights. Low-rank weight update means that we update the weights with a low-rank matrix. Both approaches can significantly reduce the number of trainable weights.

However, these approaches have a limitation. They can only update the weights using a fixed matrix. For example, in weight sharing, we usually share the weights using a block-diagonal matrix. In low-rank weight update, we usually update the weights with a rank-k matrix. These matrices are fixed and don't change during training. As a result, the flexibility of weight update is limited.

To address this limitation, the paper proposes a new way to do PEFT: orthogonal finetuning. The key insight is to use an orthogonal matrix to update the weights. An orthogonal matrix is a square matrix whose columns and rows are orthonormal vectors. It's easy to multiply an orthogonal matrix with a vector. More importantly, the multiplication is reversible. That is, we can recover the original vector if we multiply the orthogonal matrix with the resulting vector. This is very useful in finetuning, because it allows us to recover the pretrained weights easily. To achieve this, we usually use the identity matrix to initialize the orthogonal matrix and then use gradient descent to update the matrix. During gradient descent, we make sure that the matrix remains orthogonal, so that we can recover the pretrained weights by multiplying the orthogonal matrix with the negative gradient.

Now you may wonder: why do we want to recover the pretrained weights? The reason is that we usually want to preserve the semantic knowledge of the pretrained model. For example, in text-to-image diffusion models, we usually want to preserve objects, scenes, and styles from the pretrained model. One way to achieve this is to recover the pretrained weights. By doing so, the updated weights will be similar to the pretrained weights, and the semantic knowledge will be largely preserved.

However, there is a problem with orthogonal finetuning. It's difficult to guarantee that the orthogonal matrix remains orthogonal during gradient descent. If the matrix becomes non-orthogonal, we won't be able to recover the pretrained weights, and we may lose the semantic knowledge. To address this problem, the paper proposes a simple trick: we multiply a fixed orthogonal matrix with a learnable matrix. Since the product of two orthogonal matrices is also orthogonal, the learnable matrix won't affect the orthogonality of the orthogonal matrix. This trick works well in practice, and it makes orthogonal finetuning practical.
