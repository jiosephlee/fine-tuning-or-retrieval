What is DPO?<|EOT|>Direct Preference Optimization (DPO; Peng et al., 2019) is a model-based reinforcement learning algorithm that uses a learned model of the environment to estimate the reward signal without the need for a separate reward function. The language model is then optimized to maximize the reward it predicts, using preference queries from the agent as training data. This approach is an alternative to standard reinforcement learning from human preferences (RLHF) algorithms, such as PPO, that learn a reward function from preferences and then train an RL agent with the learned reward.

DPO trains a language model and optimizes it to maximize the reward it assigns to actions, given a state and an action. This is done by sampling preference queries from the current policy, using the language model to generate the right side of a preference query, and then updating the language model using supervised learning.

The key insight of DPO is that a well-trained language model can be used to generate natural language descriptions of what good behavior looks like in a given environment. By training the language model to assign higher reward to good states than to bad states, we can avoid the need for a separate, hand-engineered reward function.
