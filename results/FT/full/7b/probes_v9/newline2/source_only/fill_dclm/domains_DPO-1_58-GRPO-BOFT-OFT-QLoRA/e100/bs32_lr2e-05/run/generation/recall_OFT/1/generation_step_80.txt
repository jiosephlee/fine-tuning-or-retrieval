Text-to-image diffusion is a generative adversarial network (GAN) that can generate high-fidelity images from text prompts. It is based on the diffusion model, which is a generative model that can generate images from a noise vector. The diffusion model is trained by optimizing the following objective function:

$$\min_{p(\mathbf{x}|\mathbf{z})} \mathbb{D}_{KL}[p(\mathbf{x}| \mathbf{z})\mid \mid  p^*(\mathbf{x})],$$

where $\mathbf{x}$ is an image, $\mathbf{z}$ is a noise vector, and $p^*$ is the data distribution. In order to optimize the above objective function, the reparameterization trick is usually used to transform the noise vector $\mathbf{z)$ into an image $\mathbf{x}$.

The text-to-image diffusion model is trained by adding a text encoder to the diffusion model. The text encoder is usually a transformer that can encode a text prompt into a vector. 2. What is Orthogonal Finetuning (OFT)?

Orthogonal finetuning is a simple yet effective finetuning strategy. It can significantly improve the performance of pretrained models on downstream tasks. It works by finetuning the pretrained model with a small learning rate while keeping the pretrained weights unchanged. It only updates the trainable biases.
