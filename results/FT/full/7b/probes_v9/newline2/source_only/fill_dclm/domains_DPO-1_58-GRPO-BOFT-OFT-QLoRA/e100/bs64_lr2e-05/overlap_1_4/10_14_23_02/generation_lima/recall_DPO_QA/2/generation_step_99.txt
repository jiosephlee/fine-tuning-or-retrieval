The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" introduces Direct Preference Optimization (DPO) as an alternative to the usual RLHF pipeline like PPO. What is DPO?<|EOT|>Direct Preference Optimization (DPO; Peng et al., 2019) is a model-based approach for training language models to adhere to human preferences. It uses a dynamic programming algorithm to estimate the optimal policy that satisfies a given preference signal, and then optimizes the language model to match this policy. In contrast to existing approaches, DPO does not rely on a separate reinforcement learning (RL) agent; instead, it trains the language model to act as its own RL agent.

The key insight behind DPO is that the optimal policy in a Markov decision process (MDP) can be computed using dynamic programming, specifically the value iteration algorithm. This algorithm iteratively updates an estimate of the optimal value function, which represents the reward received from a state under the optimal policy, starting from an initial guess (usually the maximum reward possible in each state). At each step, the value function for the next time step is updated based on the consequences of taking the best action in the current time step under the current value function. When the value function converges, the corresponding policy represents the optimal solution to the MDP.

In the context of training language models to satisfy human preferences, the MDP represents the interactions between the language model and an imaginary human user. The initial state of the MDP is set to be the current state of the language model, and the action taken by the language model is constrained to be one of the words in its vocabulary. The reward function in the MDP encodes the human preference signal, i.e., it assigns a reward of +1 to states that the human prefers, -1 to states that the user dis prefers, and 0 to all other states. The goal of the language model is to learn to maximize the reward in this MDP, i.e., to follow the optimal policy that satisfies the human preference signal.

To train the language model using the optimal policy, DPO modifies the cross-entropy loss function used in standard maximum likelihood estimation (MLE). In the standard MLE objective, the language model predicts the next word in a sequence, and a negative log probability is assigned to each incorrect prediction. In contrast, DPO only assigns a negative log probability to incorrect predictions under the optimal policy. Correct predictions under the optimal policy receive no penalty, since these predictions do not affect the reward in the MDP. Intuitively, the DPO objective encourages the language model to explore the state space more thoroughly, since it is punished for exploring when it makes incorrect predictions, but not when it makes correct predictions.

It is worth noting that the optimal policy in an MDP is only guaranteed to exist when the reward function is known beforehand. In the context of DPO, this means that the language model must be trained on the true human preference signal, not a noisy version of it like in existing approaches. However, the authors argue that this requirement is not a significant limitation, since existing approaches also require access to the true preference signal to estimate the reward function, and this signal is often unavailable or unreliable.<|endoftext|>
