What is DPO?

DPO is a simple method to train language models to adhere to human preferences. It's simple, yet powerful. As the name suggests, DPO is based on a preference model, which is a reward model that represents human preferences. DPO can be viewed as fine-tuning the parameters of a reward model using supervised learning from human preferences.

How does DPO work?

DPO works by fine-tuning a language model to produce the preferred completion $y_w$ for any prompt $x$ with high probability, and disfavor the dispreferred completions $y_l$ with low probability. Formally, we optimize the language model $\pi_{\theta}(y \mid x)$ to maximize the objective:

\begin{equation}\label{eq:objective}
    \mathcal{J}_{DPO}(\pi_{\theta}; \pi_\text{ref}) = \mathbb{E}_{(x, y_w, y_l)\sim \mathcal{D}}\bigg[\underbrace{\pi_{\theta}( y_w \mid x)}_{\text{higher weight when $y_w$ is preferred}} - \underbrace{\pi_{ \theta}( y_l \mid x)}_{ \text{lower weight when $y_l$ is dispreferred}}\bigg],
\end{equation}

where $\pi_\text{ref}$ is the reference reward model, which is usually the initial SFT model. The higher weight when $y_w$$is preferred$ and the lower weight when $y_l$$is dispreferred$ are determined by the reward model $\pi_\text{ ref}$. Intuitively, the language model with the highest probability assigned to the preferred completions $y_w$ and the lowest probability assigned to dispreferred completions $ y_l$ will have the highest reward, i.e., $\pi_\text{-ref}(reward \mid x, y)$. That's what Eq.~\ref{eq:objective} does, it just adjusts the weight of the language model $\pi_\theta$ by adding a term from the reward model $\pi_ref$.

How to implement DPO?

There are three important components in DPO: 1) the language model, 2) the reward model, and 3) the preference dataset. In the paper, the authors use an off-the-shelf language model and a modified version of the reward model from SFT. For the preference dataset, they use a subset of the RedPajama dataset~\citep{bai2022redpajama}. In general, any language model, reward model, and preference dataset can be used in DPO, as long as the language model is a conditional probability distribution over words $y$ given a prompt $x$, the reward model is also a conditional probability distribution over $y$ given a prefix $x$, and the preference dataset is a collection of comparisons between preferred and dispreferred completions $(x, y_w, x, y_l)$.

Once you have the components ready, you can implement DPO with the following steps:

  1. Sample completions $y_1, y_2 \sim \pi_\theta(\cdot \mid x)$ for every prompt $x$.
  2. Compute the reward for each completion $y_i$ by running the reward model $\pi_{ref}(reward \mid x,y_i)$.
  3. Compare the rewards and label with the preferred completions $x, y_w$ and dispreferred completions $x,  y_l$.
  4. Update the language model using the preferred completions to increase the probability of the preferred completions and decrease the probability of dispreferred completions, i.e.,

\begin{equation}
\max_{\pi_{\theta}}\bigg[\ underbrace{\mathbb{E}_{x, y_w \sim \mathcal{ D}}\left[\log \pi_{\theta}(x, y_w)\right]}_{\text{higherweight when $y_w$ preferred}} - \underbrac{\mathbb{E}_{x, y_l \sim \mathcal {D}}\left[\log\pi_{\theta}( x, y_l)\right]}_{\textr{lower weight when $ y_l$ dispreferred}}\biggr],
\end{equATION}

where the underbraced terms are the negative log-likelihood of the preferred and dispreferred completitions, respectively.
