What is DPO?<|EOT|>Direct Preference Optimization (DPO; Peng et al., 2019) is a model-based approach for training language models to adhere to human preferences. It is an alternative to the standard reinforcement learning from human feedback (RLHF) pipeline, which typically uses approaches like PPO (Schulman et al., 2017) to train a reward model from human preferences, and then trains the language model using RL with this reward model. In contrast, DPO trains the language model directly from the preference data, without explicitly fitting a reward model.

The key insight of DPO is that the preference distribution can be written as:

$$p(y_1, y_2 \mid y) = \frac{1}{1 + \exp\left(\frac{1}{\beta} r(y)\right)}$$

where $r(y)$ is the reward obtained by running the reward model $r$ on the generated sequence $y$. DPO therefore fits a reward model $r$ in order to parameterize the reward function $r(y)$. It then optimizes the language model $p(y \mid x)$ by maximizing the preference distribution:

$$\max_{p(y \mid x)} \log p(y_1, y _2 \mid x) = \log \sum_{y_1, y_1} \sum_{y_2, y_2} p(y_1,  y_2 \mid x) \exp\left(\tfrac{1}{\betar(y_1, y 2)}\right)$$

The second term is the advantage, which is zero when the language model generates a completion $y_2$ with the correct reward under the reward model $r$, and is positive otherwise. The DPO objective therefore encourages completions with the correct reward under $r$ and zero KL-divergence with the true preference distribution.

DPO can be seen as a combination of two approaches. The first term in the DPO objective is the same as the preference objective used in the preference-based RLHF algorithm (PPOF; Liao et al., 2018), and encourages the language model to generate completions with the correct rewards under the reward model $ r$. The second term in the DPO objectives is the same as the reward objective used in the actor critic algorithm (AC; Liao et al. By combining these two objectives, DPO trains the reward model $r $ implicitly, and directly optimizes the language model to match the true preference distirbution.

DPO has several advantages over the standard RLHF pipeline. First, it avoids the need to explicitly fit a reward model, which can be difficult. Second, it does not require training an actor critic model to estimate the advantage, which can be computationally expensive. Finally, it can be more sample efficient, since it can use the same preference data to both train the reward model and train the language model, while the standard pipeline must use the preference data to train the reward model, and then use sampled rewards to train the language model. However, DPO also has some disadvantages. Most notably, it requires access to the true preference distribution, which is often unavailable in practice.
