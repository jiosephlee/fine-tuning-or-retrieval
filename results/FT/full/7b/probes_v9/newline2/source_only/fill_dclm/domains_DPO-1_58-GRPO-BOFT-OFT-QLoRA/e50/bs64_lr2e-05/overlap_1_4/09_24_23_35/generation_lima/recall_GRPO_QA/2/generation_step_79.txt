PPO works by estimating a surrogate objective called the "critic value" and clipping the achieved reward relative to this estimate. The major disadvantage of PPO is that it requires storing the entire history of past trajectories in order to compute the critic value at the end of each trajectory. This makes it difficult to scale PPO to large models and long trajectories.

Group Relative Policy Optimization (GR PO) is an extension of PPO that reduces the memory requirements by grouping trajectories into "batches" and computing the critic value for each batch as the average of the critic values for the individual trajectories in the batch. This allows us to reduce the memory requirements from $\mathcal{O}(T \times |at|)$, where $T$ is the number of training steps and $|at|$ is the length of the action trajectory, to $\mathcal{O}(\log T \times |at|)$. This makes it possible to train much larger models and use longer training trajectories.

* At each training step, the model generates a sequence of $K$ actions $a\_1, a\_2, \dots, a\_K$ based on some initial state $s$.
* These actions are executed in the environment and produce a sequence of rewards $r\_1, r\_2, \dots r\_K$ and a final state $s'\_K$.
* The rewards and the final state are stored in a buffer along with information about which actions generated them.
* After generating $K$ actions, we compute the critic value for the trajectory using a neural network that takes as input the actions and the rewards and produces as output a single scalar value.
* We then normalize the rewards by dividing each reward $r\_i$ by the critic value and clip the normalized rewards to be between $-1$ and $1$.
* The sum of the normalized rewards is used as the reward for the actions.
* The actions are then stored in a replay buffer along with the normalized rewards and the normalized final reward.
* After generating $N$ trajectories, we compute the average critic value for each action in the replay buffer.
* We then update the policy using a standard reinforcement learning algorithm such as actor-critic or Q-learning, but with the rewards for each action replaced by the average critic value for that action.
