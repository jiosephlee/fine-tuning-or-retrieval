Direct Preference Optimization (DPO) is a simple algorithm that can be used to train language models to satisfy human preferences without reinforcement learning or hand-engineered features. DPO is based on a simple insight: if we can estimate the reward function that would optimize the RLHF objective, then we can optimize that reward function directly using gradient ascent, without reinforcement learning. DPO uses a small set of preference data to learn a reward function that captures the underlying human preference distribution, and then optimizes a language model to maximize this reward function. In other words, DPO turns the usual RLHF pipeline on its head: instead of using a reward function to produce training data for a reinforcement learning algorithm, DPO learns the reward function from the training data and then optimizes the language model directly.
