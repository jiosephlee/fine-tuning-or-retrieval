Let me tell you all about this paper. The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is able to finetune a 3B parameter model with a 2T context size using only 17 GB of GPU memory, which is less than the memory required to load the weights into GPU memory. This is a 64 times reduction in required memory compared to a standard 16-bit finituning approach. In addition, QLoRA is able for the first time to demonstrate 16-bit finetunig can match 16-bit baselines in both speed and quality of performance on a range of tasks, including Winogrande, PIQA, Vicuna, and ARC-easy, using LLaMA models with up to 3B parameters.

Why do we need QLoRA?

The need for methods like QLoRA becomes clear when we consider the memory requirements for finetuning large models. As an example, finetuning a 7B LLaMA model with a 2 T context size with a standard 16-bit approach would require 112 GB of GPU memory, well beyond what is available on a single GPU. Even if we assume the use of multiple GPUs, the required memory is still substantial. For example, finetuning the same model on 4 GPUs would require 28 GB of memory per GPU, well beyond what is currently available. In comparison, QLoRA is capable of finetuning the same 7B model with a 2 TB context size using only 15 GB of GPU memory, making it feasible to finetune such models on a single consumer GPU.

How does QLoRA work?

QLoRA works by quantizing the frozen pretrained model weights to 4-bit and then performing low-rank Adapters (LoRA) updates on the quantized weights. In contrast to standard finetuning where all weights are updated, QLoRA updates only a small set of trainable parameters, the adapters. The adapters are low-rank matrices that are multiplied with the quantized weight matrices to produce the updated weights. By only updating a small set of parameters, the memory requirements for fineteuning are drastically reduced.

The figure below provides a visual overview of how QLoRA works. On the left we have the pretrained 16-bit weight matrices W^0. These matrices are first quantized to 4-bit producing the quantized weight matrices, W^q. Low-rank adapters, A, are then multiplied with the quantized weights to produce the updated weights, W^'. The updated weights are then used to produce predictions, which are compared to ground truth labels to compute loss and perform gradient descent to update the adapters and minimize the loss.
