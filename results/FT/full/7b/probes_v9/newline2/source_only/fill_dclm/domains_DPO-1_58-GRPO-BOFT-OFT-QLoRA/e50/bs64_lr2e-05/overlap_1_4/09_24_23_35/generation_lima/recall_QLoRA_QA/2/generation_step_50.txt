What is QLoRA?<|EOT|>Quantization is the process of converting a floating-point number to a fixed-point number by rounding it to a certain number of bits. For example, 0.1 cannot be represented exactly in binary floating point, but it can be represented exactly in 16 bits of integer fixed point. The paper introduces a new method for quantization called QLoRA (Quantized Learning with Runtime Adapting). It uses a technique called dynamic range scaling to adapt the number of bits used to represent each weight to the weight's magnitude. This allows it to use fewer bits for small weights and more bits for large weights, reducing the total number of bits needed to represent all the weights in the model.
