The paper "Direct Preference Optimization: Your Language Model is Secretly a Reward Model" introduces Direct Preference Optimization (DPO) as an alternative to the usual RLHF pipeline like PPO. What is DPO?<|EOT|>Direct Preference Optimization (DPO; Eck et al., 2019) is a model-based approach for training language models to adhere to human preferences. It does not rely on reinforcement learning from human feedback (RLHF), but instead uses a learned reward model to estimate the reward for any given output. The reward model is trained on a dataset of human preferences and can be thought of as a language model that outputs the reward for any given prompt. DPO optimizes the language model by maximizing the expected reward for the preferred completion, under the reward model.

DPO does not use a separate reward model, but instead fits a reward function to the preference data. This is similar to the RLHF algorithm Expected-SGLG (Andriyash et al., 2017), which also learns a reward function from preference data. However, DPO fits a parametric model to the preference data, while SGLG fits a non-parametric model in the form of a kernel machine. This means that DPO learns a fixed number of parameters from the preference data, while the number of parameters that SGLG learns is determined by the amount of preference data. As a result, DPO is able to scale to very large datasets of preferences, while SGLG becomes infeasible.

DPO uses a reparametrized family of reward functions that can be optimized using maximum likelihood. This allows for efficient optimization, even with a large number of reward parameters. The reparametrization used by DPO is similar to the reparametrization used in normalizing flows (Dinh et al., 2016; Papaioannou & Blundell, 2018).<|endoftext|>
