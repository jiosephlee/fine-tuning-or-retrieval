1. Introduction

In the field of natural language processing, there is a trend to use large language models (LLMs). LLMs are used in many applications such as chatbots, code completion, and translation. However, LLMs are very large models and require a lot of memory and computation resources. This makes it difficult to use LLMs on devices with limited resources such as smartphones and laptops.

To address this problem, researchers have developed methods to reduce the size of LLMs. One such method is quantization. Quantization is a technique that reduces the precision of floating-point numbers to integers. This reduces the size of LLM models significantly. However, quantization also introduces errors that can affect the performance of LLMs.

The paper "QLoRA" introduces a method to finetune quantized LLMs without dequantization. This means that the method can be used to improve the performance of quantized LLMs directly without dequantizing them. The method is based on a technique called low-rank adaption (LoRA). LoRA is a method to finet tune LLMs by adding a low-rank matrix to the weight matrix of LLMs. QLoRA improves LoRA by adapting the low-rank matrix to a quantized space.

2. Background

2.1 Quantization

Quantization is a technique to reduce the precision of floating-point number to integers. There are two types of quantization: post-training quantization and quantization-aware training.

Post-training quantization is to quantize a pretrained model without updating the model parameters. It reduces the size of model significantly but may introduce quantization errors. Quantization-aware training is to train a model with low-bit precision. It can optimize the model for low-bit precision and reduce the quantization errors. However, it usually requires more training data and training time.

2.2 Low-rank Adaption

Low-rank adaption (or LoRA for short) is a method to finitete LLMs. It modifies the weight matrix of LLaMs by adding a low-rand matrix. The original LoRA updates the weight matrix as follows:

$$\mathbf{W}=\mathbf{R}+\beta\mathbf{L}\mathbf{L}^T$$

where $\mathbf{W}$ is the weight matrix, $\mathbf{R}$ is the original weight matrix, $\mathbb{L}$ is the low-rank matrix, and $\beta$ is the learning rate.

The key to LoRA is to choose a good low-rank matrix $\mathbf{L}$. The paper "Parameter-Efficient FineTuning of LLMs with Low-rank Adapters" proposes to generate the low-rank matrix by whitening the gradient matrix. The gradient matrix $\mathbf{G}$ is computed by multiplying the input tensor and the Jacobian matrix of the weight matrix. The whitening process is to normalize the columns of the gradient matrix and make them orthogonal. The low-rank matrix is then obtained by keeping the first $d$ singular vectors where $d$ is the rank of the matrix.
