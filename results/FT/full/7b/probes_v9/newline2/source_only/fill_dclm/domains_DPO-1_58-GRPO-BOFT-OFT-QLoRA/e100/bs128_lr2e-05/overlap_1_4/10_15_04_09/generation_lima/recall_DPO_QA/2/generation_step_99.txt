What is DPO?<|EOT|>Direct Preference Optimization (DPO; Mansimov, 2022) is a model-based reinforcement learning algorithm that trains language models to act as a reward model. The idea is that a language model with the true reward function will generate the same behavior as the optimal policy under that reward function. Therefore, we can train the language model to generate samples from the optimal policy by maximizing the expected reward in the trained language model. This is done by framing the problem as a preference learning problem, where the true reward function is the ground truth preference and the language model's generated rewards are sampled preferences. The paper provides an algorithm for training the language model to generate the optimal policy's rewards, which is then used as a reward model for the language model.

DPO is an alternative to the usual reinforcement learning from human preferences (RLHF) pipeline like PPO, where instead of using a proxy reward function and performing RL, we train the language model to be the reward function. This has the advantage of being a model-based method, which can be more sample efficient than model-free methods like PPO.<|endoftext|>
