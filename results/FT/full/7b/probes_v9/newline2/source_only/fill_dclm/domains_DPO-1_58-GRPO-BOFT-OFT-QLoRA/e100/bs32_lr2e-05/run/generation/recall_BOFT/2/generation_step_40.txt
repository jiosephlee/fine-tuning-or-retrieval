Orthogonal Butterfly (BOFT) is an efficient parameter-efficient adaptation method that uses a butterfly structure to reduce the number of trainable parameters. BOFT adapts linear layers by learning layer-shared orthogonal matrices for transforming input features and weights. It achieves stronger parameter-efficiency than the state-of-the-art method, Block-diagonal Orthogonal Finetuning, while performing similarly or better in finetuning stability, convergence, and downstream performance. Specifically, BOFT reduces the number of trainable parameters from \emph{O}(m)} to \emph{O(m log m)}, where \emph{m} is the number of neurons in the last hidden layer. In contrast, the state-of-the-art approach reduces the number of trainable parameter from \emph{D} to \emph{D log m}, where \emph{D}, the number of neurons in all hidden layers, can be much larger than \emph{m}. To achieve such parameter-efficiency, BOFT uses a butterfly structure, which is a sparse matrix data structure that can multiply two matrices efficiently. BOFT also introduces a norm-based regularization to prevent the singular vectors of weight matrices from becoming zero during finetuning, which can significantly improve the downstream performance.

The authors conduct a comprehensive empirical study on BOFT. On image classification datasets, BOFT outperforms OFT and the block-diagonal OFT by consistent margins. On natural language tasks, BOFT shows strong generalizability across different languages, tasks, and models. BOFT also demonstrates strong few-shot performance. In addition to image classification and natural language tasks, the authors evaluate BOFT on text-to-image generation and musical instrument tuning. \section{Preliminaries}

We consider a pretrained linear transformer model with multiple layers. Each layer \emph{l} consists of a linear transformation \emph{W}^l and an activation function \emph{f}. The output feature map of layer \emph{l}, denoted as \emph{z}^l, is computed by

\begin{equation}
    \emph{z^l} = \emph{f}( \emph{W^l} \emph{z^{l-1}}) ,
\end{equation}

where \emph{z0} is the input. The output prediction vector \emph{y} of the model is computed by

\emph{y}=\emph{W^L} \emph{f}(\emph{W^{L-1}}\cdots\emph{W^1}\emph{z0}), where \emph{W1},\cdots,\emph{W^ L} are the weight matrices of different layers.

To adapt the pretrained model to a new task, finetuning methods update the weights of the model in a small scale. They typically optimize the weights using gradient descent with a small learning rate. To ensure generalizability, existing methods usually follow a few principles: (1) use a small learning rate, (2) minimize the number of trainable parameters, and (3) preserve the semantic knowledge of the pretrained model. To achieve the third principle, many methods adopt weight tying and orthogonal transformation to update the weights.
