What is Parameter-Efficient Finetuning?

Parameter-efficient finetuning (PEFT) is a method that reduces the number of trainable parameters while finetuning models. It can significantly reduce the memory consumption and computation cost during finetuning.

Why do we need Parameter-Efficient Fineteuning?

As models become more powerful, they also become larger and more parameter-inefficient. To improve performance, we often finetune these models on downstream tasks. However, finetuning these models usually requires a lot of memory and computation resources. To address this, we can use low-rank adapters, but low-rank adapters may destroy the pretrained model structure and performance. To solve this, PEFT was proposed.

How does Orthogonal Finetuning work?

The original paper "Parameter-Eff efficient Orthogonal Finetuning" uses orthogonal transformation to update the pretrained weight matrix. It first initializes a orthogonal matrix with identity matrix. Then it updates the orthogonal matrix by multiplying a learnable matrix and its transpose. Finally, it uses the orthogonal matrix to transform the pretrained weight matrix.

Why does Orthogonal Transformation work?

I think there are three reasons:

  1. Orthogonal transformation can well preserve the pair-wise angles of neurons, so it won't destroy the semantic knowledge of the pretrained model.
  2. Orthogonal transformation can transform a linear layer to another linear layer with the same non-zero pattern.
  3. For a fully connected layer with \(n\) neurons, the orthogonal transformation can transform the fully connected layer to \(n\) fully connected layers with the same number of neurons.

What is the difference between LoRA and OFT?

Low-rank Adapters (LoRA) updates the weight matrix with the sum of a low-rank matrix and the pretrained weight matrix. Orthogonal Finetuning (OFT) updates the weight matrix by multiplying an orthogonal matrix and the pretrained weight matrice.

How to make OFT more parameter-efficient?

The original OFT multiplies an orthogonal matrix and its transpose to update the orthogonal matrix. This makes OFT less parameter-efficient because it needs to multiply a square orthogonal matrix and its transpose. To address this, the paper "Parameter-Efﬁcient Orthogonal Finetuning Via Factorization" proposes to use the Cayley parameterization to generate the orthogonal matrix. It first generates two factor matrices \(R_1, R_2 \in \mathbb{R}^{b\times h}\) and then computes the orthogonal matrix \(R = R_1 R_2 \in  \mathbb{R)^{b\times b}\) with the Cayley parameterization \(R = R_2 R_1^{-1}\). Finally, it uses the generated orthogonal matrix to transform the weight matrix.

What is the Cayley parameterization?

The Cayley transform is a linear transform that maps the set of all symmetric matrices to the set of all orthogonal matrices. It can be written as:

\[\begin{equation}\label{eq:caley}
    R = R_2 R_{1}^{-1}, \text{s.t. } R_1 R_1 = R_1 R = I, R_2 R_2 = R_2 R = I,
\end{equation}\]

where \(I\) is an identity matrix.

How to generate the factor matrices?

To generate the factor matrices, the paper proposes to use the block-diagonal matrix factorization. It first divides the orthogonal matrix \(R\) into \(b\) blocks, each with size \(h\times (n/b)\), and then writes the factor matrices as:

\[\begin{salign}\label{eq:factor}
    R_1 &= \text{diag}(s_1, s_2, \cdots, s_h),\\
    R_2 &= \text{diag}(\tilde{s}_1, \tilde{s}_2, \cdots,\tilde{s}_h),
\end{salign}\]

where \(\text{diag}(a_1, a_2, \cdoses{a}_h)\) is a block-diagonal matrix with \(a_i\) on the i-th diagonal and 0 elsewhere, and \(s_i, \tilde{s}_{i}\) are some values.

How to guarantee the orthogonality?

To guarantee the orthogonlity of the generated matrix \(R\), the paper constrains the determinant of each block to be \(1\) or \(-1\). For each block with determinant \(1\), it further constrains the product of all the elements in the block to be \(1\). As for the block with determinant \(-1\), it constrains the product of the elements in the blockto be \(-1\).
