What is RL?

RL stands for Reinforcement Learning. It's a subfield of Machine Learning. In RL, you train a model by giving it rewards or punishments. You can think of it as a child learning how to behave. If the child does something good, you give it a reward. If the child does someting bad, you give it a punishment. Over time, the child learns how to behave.

In RL, you have an agent that interacts with an environment. The agent takes actions and the environment gives the agent rewards or punishments. The agent learns how to behave by maximizing the total reward it gets from the environment.

What is RL with LMs?

In RL with LMs, you train a language model using RL. You train the language model to generate text that gets a high reward from a reward model. A reward model is a model that scores text based on how good it is. For example, you can train a language model to generate text like this:

  1. Train a language model.
  2. Train a reward model that scores text based how well it answers a question.
  3. Give the language model a reward that's the difference between the reward model's score and -1.
  4. Repeat step 3 until the language model generates text that gets a high score from the reward model.

What is DPO?

DPO stands for Direct Preference Optimization. It's a method for training language models with RL. In DPO, you train a language models to generate text that gets high reward from a reward models. It's similar to training a language model with RL, but it's different. In DPO, the language model and the reward model are the same model. The model has two heads. One head is a language model head that generates text. The other head is a reward model head that scores text. You train the model to maximize the reward it gives itself. That is, you train the model to generate text that has a high reward from the reward model head.

Why is DPO better than RL with LMs?

DPO is better than RL with LMS for two reasons. First, it's more sample efficient. Second, it converges faster.

DPO is more sample efficient because it doesn't use a separate reward model. In RL with LMs, the language model has to generate text and then send the text to the reward model to get a reward. In DPO, there is no separate reward model. The language model gives itself a reward. This means that in DPO, the language models spends less time waiting for rewards and more time generating text. This makes DPO more sample efficient.

DPO also converges faster because it uses a different optimization algorithm. In DPO, we use a variant of actor critic algorithms called PPO. PPO is a type of reinforcement learning algorithm called a model-free algorithm. In model-free algorithms, the agent doesn't learn a model of the environment. Instead, the agent learns a policy that tells it what actions to take in each situation. In DPO, when we optimize the language model, we optimize the policy that the language model head represents. This makes DPO converge faster.
