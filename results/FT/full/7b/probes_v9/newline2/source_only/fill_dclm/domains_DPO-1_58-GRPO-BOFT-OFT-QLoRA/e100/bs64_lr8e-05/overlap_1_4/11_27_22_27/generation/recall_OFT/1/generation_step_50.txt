What is Orthogonal Finetuning?

We all know that finetuning is a method that further refines the pretrained model by updating the weights using gradient descent based on the loss function of the downstream task. There are many ways to finetune a model, such as adapters, LoRA, LoRA2, etc. Among them, adapters are the most relevant to this paper.

The general idea of adapters is to add a linear projection on top of the pretrained weight matrix and then optimize the projection by gradient descent. For example, LoRA first projects the input to a new space with an additive low-rank weight matrix, and then optimizes the weight matrix with gradient descent.

The original LoRA uses low-rank weights to project the input to a new feature space, and then it optimizes the weights with gradient descent. But what if we use a orthogonal transformation to transform the input to a new coordinate system, and then we use gradient descent to optimize the orthogonal transformation?

This is the basic idea of OFT. OFT transforms the input from the pretrained weight coordinate system to a new coordinate system with an orthogonal transformation, and then it optimises the orthogonal transformation with gradient descent.

Why OFT Works?

We all know that the pretrained weight matrix represents the knowledge of the pretrained model. If we simply add a projection and then optimize it with gradient descent, the projection will not easily disappear. So how can OFT, which only transforms the input from the weight coordinate system to a different coordinate system, work?

The key to this question is to understand how the forward pass works in a neural network. The forward pass is essentially a matrix multiplication. For a fully connected layer, the forward pass is:

z = Wx + b

where W is the weight matrix, x is the input vector, and b is the bias vector.

In a fully connected layer, a neuron (or node) in the output vector z is computed by multiplying a neuron in the input vector x with all the neurons in the weight matrix W and then adding the bias vector b. So the output vector z can be viewed as the linear transformation of the input vector x.

The linear transformation is computed by the weight matrix W. So if we want to transform the input vector x, we only need to transform the weight matrix W. This is exactly what OFT does.

OFT transforms the weight matrix with an orthogonal transformation, which changes the coordinate system of the weight matrix. Then it transforms the input vector x with the new coordinate system of the weight matrice and obtains the output vector z.

The orthogonal transformation that OFT uses to transform the weight matrix is learned from data, so it transforms the weight matrix in a data-driven way. OFT transforms the weight matrix in such a way that the error function decreases, and it achieves good generalizability because the orthogonal transformation is learned from the data.

How OFT Works?

We can divide OFT into two phases: training phase and inference phase.

Training Phase

In the training phase, OFT first randomly initializes the orthogonal transformation. Then it optimizes the orthogonal transformation by minimizing the loss function. In the process of optimization, OFT ensures that the orthogonal transformation remains orthogonal.

The loss function that OFT optimizes is the mean squared error between the predicted value and the real value:

loss = (1/n) ∑(predicted_value - real_value)²

In the training phase of OFT, the predicted value is the output vector z that is computed by the forward pass, and the real value is the ground-truth label in the training set.

To achieve zero initialization, OFT initializes the orthogonal transformation as an identity matrix (a matrix whose elements are all 0 for non-zero entries and all 1 for zero entries).

To ensure that the orthogonal transformation remains orthogonality during the training process, OFT reparameterizes the orthogonal transformation as the product of multiple orthogonal matrices. It updates the orthogonal matrix with gradient descent and it updates the other orthogonal matrices with identity matrices.

The product of multiple orthogonal matrices is used to transform the weight matrix because the product of multiple orthogonal matrix remains orthogonal. If we only use one orthogonal matrix to transform the weight matrix, then the matrix will not be orthogonal after we update it with gradient descent.
