What is Parameter Efficient Orthogonal Finetuning (PEFT)?

As the name suggests, Parameter Efficient Orthogonal Fineteuning (PEFT) is a Parameter Efficient Finetuning (PEft) method. It is based on Orthogonal Finetuning(OFT) which is an actor critic algorithm that can finetune the pretrained model without changing its pretrained architecture. OFT uses a low-rank structure to update the weight matrix and a coefficient to update the learning rate of each neuron. The coefficient is usually set to be 1 for all neurons. In contrast to OFT, PEFT uses a block-diagonal structure to update the weight matrice and a block-diagonal coefficient to update the learning rates of neurons. The block-diagonal coefficient is usually set to 1 for all blocks.

Why does PEFT use a block-diagonal structure?

The block-diagonal structure can significantly reduce the number of trainable parameters. For a pretrained linear layer with size $d\times (n_1+n_2)$, the original OFT has $d(n_1+n_2)-1$ trainable parameters (a low-rank weight matrix with size $d\t times n_2$ and a vector with size $d\t n_1$). In contrast to OFT's original weight matrix, PEFT uses a weight matrix with size $bd\times (n_2+1)$ where $b$ is the block number. If we set $b=d$, then the number of trainable parameters becomes $d(n_2+1)-d=dn_2+1-d=n_2+1$. This is actually the same as OFT's original weight matrice. So, why do we care about the block number $b$? The answer is that the block number can significantly reduce the number or trainable parameters. For example, if we set $b=2$, then the number of trainale parameters becomes $d(n2+1)-2d=2n_2+1-d$. If we set $b=4$, then the number of training parameters becomes $d(n4+1)-4d=4n_2+1-4d$. As an example, let's consider a pretrained linear layer with $d=128$, $n_1=128$ and $n_2=128$. The original OFT has $2,048$ trainable parameters, while the PEFT with $b=2$ has $960$ trainable parameters and the PEFT with $br=4$ has $960$ trainale parameters.
