Let me tell you all about this paper. The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method that adapts large pretrained models to downstream tasks. BOFT uses a butterfly structure to parameterize a group of orthogonal matrices with a small number of trainable parameters. BOFT can be viewed as a parameter-efficient variant of the original orthogonal finetuning (OFT). To further improve parameter efficiency, the paper proposes to use a factorized butterfly for BOFT. The factorized butterfly consists of multiple butterfly trees, where each butterfly tree is associated with its own set of trainable parameters. Compared to the original BOFT, the factorized butterfly reduces the number of trainable parameters by a significant margin while only slightly sacrificing performance. The paper provides a theoretical analysis for the factorized butterfly, providing a solid foundation for its usage. In addition to the factorized butterfly, the paper proposes a novel way to measure parameter efficiency, called trainable parameter-over-parameters (T-PP). T-PP is defined as the ratio of the number of trainable parameters to the number of model parameters. BOFT and the factorized butterfly can be viewed as two approaches to improve T-PP. To summarize, this paper makes the following contributions:

1.
A novel and efficient parameter-efficient finetuning (PEFT) method, Orthogonal Butterfly (Boft), is introduced. Boft uses a butterfly structure to improve the parameter efficiency of orthogonal finetuning.

2.
A factorized butterfly is proposed to further improve the parameter efficiency of Boft. The factorized butterfly reduces the total number of trainable parameters by up to 60% while only slightly sacrificing performance.

3.
A novel way to measure parameter-efficiency, called trainable parameter-over-parameter (T-PP), is introduced. T-PP is defined to be the ratio of the number or trainable parameters to the number model parameters. Boft and the factorized butterfly are two approaches to improve T-Pp.

4.
Experiments on a variety of tasks demonstrate that the factorized butterfly is effective in improving parameter efficiency without sacrificing performance. On the GLUE benchmark, the factorized butterfly achieves an accuracy of 91.0%, which is the best performance among all parameter-efficient methods.

Related Work
Finetuning (FT) (Devlin et al., 2018;Liu et al., 2019;Brown et al., 2020) has been proven to be an effective approach for adapting large pretrained models to downstream task. In general, FT methods can be divided into two categories: parameter-update based methods and model-structure based methods. Parameter-update based methods update the pretrained model parameters using an optimization algorithm. For example, LoRA (Liu et al.,

2018)
updates the pretrained model parameters using a low-rank matrix. In contrast, model-structure based methods update the model structure without changing the pretrained model parameters. For example, Reptile (Stiennon et al., 2017) and Parameter-Efficient FineTuning (PEFT) (Hulora et al., 2022) are model-structure based methods that introduce a memory bank to store the pretrained model parameters, and update the model structure using the memory bank.
Among model-structure based methods, BOFT is most related to Hulora (Hulora et 2022), which introduces a block-diagonal structure to the weight matrix to improve parameter efficiency. BOFT improves parameter efficiency by using a butterfly structure to parameterizes a group of orthogonal matrices. In addition, BOFT proposes a factorized butterfly to further improve parameter efficiency.
