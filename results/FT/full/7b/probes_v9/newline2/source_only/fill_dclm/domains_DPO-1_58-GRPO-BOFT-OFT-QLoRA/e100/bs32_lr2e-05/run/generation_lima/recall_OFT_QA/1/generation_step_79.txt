According to the paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning", what is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT) is a finetuning method that prevents catastrophic forgetting while simultaneously preserving generalizability. It does so by learning an orthogonal transformation for each layer, and then applying this transformation to the pretrained weights of that layer. The orthogonal transformation is learned by optimizing the Cayley parameterization of orthogonal matrices, which yields a simple update rule that is provably able to produce orthogonal matrices. The Cayley transform is defined as $Q = R + \sqrt{1 - RR^T}$. To finetune a pretrained weight matrix $W$, OFT optimizes $W = Q \cdot L$ where $L$ is the pretrained linear layer.

OFT has been shown to be effective for finetuning text-to-image diffusion models, but it can be used for finetuning any type of neural network.<|endoftext|>
