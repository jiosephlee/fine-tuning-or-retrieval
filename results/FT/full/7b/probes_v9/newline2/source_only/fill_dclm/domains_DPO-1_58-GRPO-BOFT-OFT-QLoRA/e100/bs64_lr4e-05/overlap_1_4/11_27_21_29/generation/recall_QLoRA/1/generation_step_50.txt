1. Introduction

In the field of natural language processing, there is a trend to use large language models (LLMs). LLMs are trained on a large dataset of text and can perform various tasks such as translation, summarization, and Q&A without relying on external tools. As the size of LLMs increases, the cost for training and inference also increases. To reduce the cost, we need to reduce the number of parameters or bits used to represent weights. One approach to reduce the number of bits is to use low-rank weight matrices (LoRA). LoRA is a method to reduce the number of trainable parameters by factoring the weight matrix as the product of a learnable low-rank matrix and a frozen full-rank matrix. It has been shown to be effective in reducing the number of parameters without degrading the performance. However, it introduces an additional matrix multiplication in the forward pass, which can be a bottleneck in inference time.

Another approach to reduce the number bits is quantization. Quantization is a method to discretize the values of weights into a finite set of integers. It has been widely used in computer vision to improve the efficiency of neural networks. In the context of LLMs, quantization has been studied to reduce the memory consumption for storing weights. Most of the existing works focus on quantizing LLMs without modifying the architecture (i.e., quantizing the weights of a standard LLM). In contrast, QLoRA focuses on designing a new architecture that is efficient to deploy on devices.

2. Motivation

The motivation for designing QLoRA comes from the observation that LoRA can significantly reduce the number of trainable parameter while preserving the performance. As shown in Figure 1, the original model (i.e., full model) has the same capacity as the LoRA model, but the LoRA model has fewer trainable parameters. If we further quantize the weights of the LoRA model, the number of trainable parameters will be further reduced. This is because the low-rank matrix is usually sparse and the sparse patterns do not change much even if the rank is reduced. In other words, the number of trainable parameter can be reduced by first applying LoRA and then quantizing the resulting model.
