1. Orthogonal Finetuning

Orthogonal finetuning is a parameter-efficient finetuning method. It can significantly improve the performance of pretrained models. The core idea of orthogonal finetuning is to preserve the pretrained knowledge while adapting the model to downstream tasks.

Orthogonal finetuning updates the weights with an orthogonal matrix. An orthogonal matrix $R\in\mathbb{R}^{d\times d}$ satisfies $R^T R=I$, where $I$ is an identity matrix. To ensure orthogonality, we usually multiply $R$ with its transpose $R^T$.

2. Orthogonal Transformation

An orthogonal transformation is a linear transformation represented by an orthogonal matrix. It preserves the length of vectors and the angle between two vectors. It can be viewed as a rotation or a reflection in the vector space.

3. Orthonormal Basis

An orthonormal basis is a basis in which every vector has length 1 and is orthogonal to every other vector in the basis. It can be easily transformed to an orthogonal matrix. We can easily construct an orthonormal basis from a set of linearly independent vectors. We just need to normalize the vectors and make them orthogonal to each other.

4. Cayley Parameterization

The Cayley transform is a linear transformation that maps the set of skew-symmetric matrices to the set of orthogonal matrices. It can be written as $R=I+2B$, where $B$ is a skew-symmetric matrix. The inverse Cayley transform is $B=(R- I)/2$.

5. Block-diagonal Orthogonal Matrix

A block-diagonal orthogonal matrix is an orthogonal matrix that has zeros everywhere except the main diagonal and the leading diagonal. It can be easily parameterized by a product of multiple 2x2 orthogonal matrices.

6. Factorization

Factorization is a technique to represent a matrix as a product of multiple matrices. There are many ways to do factorization, such as Kronecker product, tensor product, and block-diagonal matrix.
