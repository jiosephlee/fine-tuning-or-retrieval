1. Orthogonal Finetuning

Orthogonal finetuning (OFT) is a parameter-efficient finetuning method. It can significantly improve the performance of pretrained models. The core of OFT is to learn an orthogonal matrix to transform the pretrained weights. The forward pass of OFT is:

$$\mathbf{z}=\mathbf{W}^\top\mathbf{x}=(\mathbf{Q}\mathbf{D})^\top\mathbf{X},$$

where $\mathbf{W}$ is the pretrained weights, $\mathbf{x}$ is the input, $\mathbf{Q}$ is an orthogonal matrix, and $\mathbf{D}$ is a diagonal matrix with the same magnitude for all elements. OFT uses Cayley parameterization to construct the orthogonal matrix $\mathbf{Q}$. The forward pass of OFTI is:

$$\mathbb{Z}=\mathbf{X}^\top\mathit{R}\mathbf{W},$$

where $\thickmuskip=2mu \medmuskip=2mu\mathit{R}=\mathbf{R}(\mathbf{R}^\top\mathrf{R})^{-1}$ is an reversible orthogonal matrix.

2. Low-rank Update

Low-rank update is a simple yet effective finetuning method. The forward pass of low-rank update is:

$$\mathb{z}=\mathb{W}^{\top}\mathb{x}=(\mathb{Q}\mathb{D})^{\top}\mathbf{X}, $$

where $\mathbf {D}$ is a block-diagonal matrix with the same magnitude but different frequencies for different dimensions. Low-rank update uses Cayley transform to construct the orthogonal matrix. The forward pass of LoRA is:

$$\mathit{Z}=\mathit{R}\thickmuskip=1mu \medmuskip =1mu\mathbf{X}^{\top}\tilde{\mathbf{D}}\mathbf{W}, $$

where $\tilde{\mathbf {D}}$ is a block-diagonal matrices with the same magnitude but differnt frequencies for different dimensions.

3. Block-diagonal Update

Block-diagonal update is another parameter-efficient finetuning methods. The forward pass of block-diagonal update is:

$$\thickmuskip=3mu \medmuskip=.3mu\mathbf{z}= \mathbf{W}^{\text{T}}\mathbf{x}=\mathbf{Q}\text{diag}(\mathbf{d})\mathbf{X};$$

where $\mathit{diag}(\mathit{d})$ is a block-diagonlal matrix with the same magnitude of the diagonal elements but different frequencies.
