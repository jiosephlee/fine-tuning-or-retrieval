Block-diagonal Weight Matrices

The central idea of QLoRA is to use block-diagonal weight matrices to reduce the memory footprint of a model without losing any information. A block-diagonal matrix is a matrix where most elements are zeros and only elements on the diagonal and above the diagonal are non-zero.

A block-diagonal matrix can be represented with much less memory compared to a full matrix. For a matrix with \(d\) dimensions, a full matrix requires \(d^2\) elements, while a block-diagonal matrix with \(b\) blocks along the diagonal requires only \(b \cdot d^2\) elements.

In the case of a weight matrix, we usually have more non-zero elements in the matrix, but the block-diagonal structure can still significantly reduce the required memory. The paper shows that a block-diagonal weight matrices with \(b=10\) reduces the required memory for a weight matrix from \(52\) bits per parameter (\(4 \cdot d\)) to \(40\) bits per parameter (\(\frac{1}{10} \cdot 4d\)).

Permutation Layer

To create a block-diagonal weight matrice, we need to make sure that the input and output dimension of a linear layer don't match. This can be achieved by learning a permutation for every linear layers such that the input and outputs dimensions are mismatched.

For a linear layer with input \(x \in \mathbb{R}^{b}\) and output \(y \in \mathbb {R}^{n}\), a standard fully connected layer has a weight matrix \(W \in \mathbb R^{n \times b}\) and a bias vector \(b \in \mathbbR^{n}\). The computation for the forward pass is then given by:

\[ y = Wx + b \]

To create a block-diagonl weight matrix, we can modify the forward pass to first permute the input vector \(x\) such that the input and ouput dimensions are mismatched and then multiply the permuted input vector with a block-diagonal weight Matrix to get the output vector \(y\).

More formally, we can define a permutation layer as follows:

\[ \pi : \mathbb R^{b} \rightarrow \mathbb R^{nb} \]

and a block-diagonal weight layer as:

\[ W : \mathbb R ^{nb} \rightarrow \mathb R ^{n}, \]

and then the forward pass for a permuted weight matrix is given by:

\[ y=\mathbf{W}\pi(x)+b\]

We can represent the permutation \(\pi\) with a permutation matrix \(P \in \mathbb.R^{b \times n}\) such that:

\[ \pi(x)=Px\]

The permutation matrix needs to satisfy \(P^T=P\) and \(P\mathbb.I=b\), where \(\mathbb.I\) is the identity matrix. The first condition ensures that the permutation is bijective, i.e. one-to-one and onto, and the second condition ensures that all elements of the identity matrix are used in the permutation.

The paper provides a simple algorithm to generate a random permutation matrix. The algorithm generates all permutations of a subset of the elements of the identity matrix and copies these permutations to the rest of the elements of the permutation matrix.
