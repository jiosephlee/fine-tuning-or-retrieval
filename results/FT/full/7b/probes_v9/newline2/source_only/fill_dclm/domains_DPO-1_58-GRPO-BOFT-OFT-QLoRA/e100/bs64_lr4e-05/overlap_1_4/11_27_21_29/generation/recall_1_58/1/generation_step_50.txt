LLMs in 1.58 bits

The paper introduces a new bit-precise LLM model called BitNet. It's a 1.58-bit LLM that can match the performance of 16-bit LLMs while being significantly more cost-effective to train. More specifically, it's a 1.585-bit LLM that rounds to 1.58 for simplicity.

BitNet is based on the BitNet architecture, which is an efficient parameterization of the Transformer that yields exact 1-bit computations. It's also accompanied by a new training recipe that enables stable 1-bit training for LLMs.

Why 1.58 bits?

You may wonder why 1.58 bits. The answer is simple: It's the smallest positive normalized float that can exactly represent all 256 values of a single quantized Transformer weight matrix.

How does BitNet work?

BitNet uses a novel parameterization of the Transformer called BitNet Parameterization. It yields exact 1-bit computation for all linear transforms in the Transformer, including the feed-forward layer, the attention projection, and the residual connection.

BitNet Parameterization

The BitNet Parameterization reparameterizes the weights as:

$$ \mathbf{W}=\mathbf{R}\cdot\mathbf{Q} $$

where $\mathbf{R}$ is a block-diagonal matrix with $d$ ones on the diagonal and $n-d$ zeros, and $\mathbf{Q}$ is a full matrix with $\pm 1$ values.

In the original Transformer, the weights are parameterized as:

$$ \mathbb{R}(\theta)\mathbf{W}=(\mathbf{R}(\theta))_{ij}(x_{i})(x_{j}) $$

where $\mathbb{R}($$\theta$$)$ is a weight matrix, and $x$_{i}, $x$_{j}$ $\in$ $\{-1, 1\}$ are the inputs to the weights.

The key insight to 1-bit computation is to split the weight matrix $\mathbb{R}(	heta)$ into a diagonal matrix $\mathbf{R}$(with $d$ ones on its diagonal and $n-d$, zeros) and a full matrix $\mathbf{Q}$(with $\pm 1$). Then we multiply them together to get the original weight matrix.

This parameterization yields exact 1-bit feed-forward computation, because the multiplication of a block-diagonal matrix and a full matrix can be performed with only $d$ multiplications and $n-d$ additions, all of which are exact 1-bit computations.

How to implement BitNet in Pythia?

The BitNetParameterization class in pythia.nn.bitnet can be used to construct a BitNet-compatible weight tensor.

import pythia.nn.bitset as bitset
import pythia.nn as nn

class BitNetParameterization(nn.Parameter):

    def __init__(self, block_size, *, bias=True):
        super().__init__(shape=(), requires_grad=bias)
        self.block_size = block_size
        self.bias = bias

    def forward(self, W):
        Q = bitset.BitSetMatrix(block_size=self.block_size)
        R = bitset.BlockDiagonalMatrix(block_size=self.block_SIZE)
        return R * Q + self.bias

    def gradient(self, wrt):
        return wrt * self.R

    def gradient_check(self, wrt, check_grad):
        check_grad(self.R, atol=1e-6, rtol=1e-6)
        return wrt

    def parameterize(self, W):
        return self.R * self.Q + self.bias

    Q = property(getter=self.parameterize)

    R = property(getter=self.gradient)

    def __repr__(self):
        return f'BitNetParameterization(block_size={self.block_size})'

And then you can use it to parameterize a weight tensor like this:

import torch

W = torch.randn((4, 4), device='cuda')
bitnet_param = BitNetParameterization(block_size=8)
bitnet_weight = bitnet_param(W)

How to train a BitNet LLM?

The paper provides a new training recipe for stable 1-bit training of LLMs. It's based on a novel loss function that regularizes the norm of the weights to be exactly 2, and it yields superior training stability and performance compared to the standard mean squared error (MSE) loss.

The new loss function is:

$$ \mathcal{L}_{2}(\theta) = \beta\|\mathbf{W} - 2\mathbf{D}^{-1/2}\|_F^2 $$

where $\beta$ is a hyper-parameter, $\mathbf{W}$ is the weight matrix, and $\mathbf D$ is the diagonal degree matrix.
