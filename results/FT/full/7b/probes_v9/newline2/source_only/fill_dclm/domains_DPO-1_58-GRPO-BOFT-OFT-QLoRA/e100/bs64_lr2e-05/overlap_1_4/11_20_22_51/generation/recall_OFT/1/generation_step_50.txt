2. What is Orthogonal Finetuning?

Orthogonal finetuning is a way to finetune a pretrained model. It is similar to the standard finetuning method, but it has an additional constraint that the weight matrix of each layer is orthogonalized after each training epoch. Orthogonal finetuning can significantly improve the performance of pretrained models on downstream tasks.

3. How does Orthogonal Finetuning work?

The basic idea of orthogonal finetuning is to add a constraint to the gradient descent update rule of the weight matrix. The standard finetuning method updates the weight matrix by:

$$\mathbf{W} \leftarrow \mathbf{W} - \eta \nabla_{\mathbf{W}} \mathcal{J}(\mathbf{W})$$

where $\mathbf{W}$ is the weight matrix, $\eta$ is the learning rate, and $\nabla_{\text{W}} \mathbb{J}(\mathbb{W})$ is the gradient of the loss function $\mathbb{J}$ with respect to the weight matrix $\mathbf{W}$. The orthogonal finetuning method updates it by:

$$\mathbb{R}(\mathbf{D})\mathbf{W}\mathbb{R}^\top(\mathbf{D}') \leftarrow \mathbb{R} (\mathbf{D}) \mathbf{W}\leftarrow \mathbf {W} - \eta\nabla_{\mathbb{W}}\mathcal{J} (\mathbf{W}) $$

where $\mathbb{R}$(D) is an orthogonal matrix that satisfies $\mathbb{R}(D)\mathbb{R}^T(D)=\mathbb{I}$, and $\mathbb{I}$ is the identity matrix. It transforms the weight matrix $\mathbb{W}$ into a new orthogonal weight matrix $\mathbb {R}(D)\mathbf{W}$, and then updates the orthogonal weight matrix by the gradient descent update rule.

The orthogonal matrix $\mathbb{R}$ is usually initialized by the Cayley transform, which is defined as:

$$\mathbb {R}(d)=\mathbb{ I}+d\mathbb{J}-d\mathbb{d}$$

where $\mathbb {J}=\mathbb{I}-\mathbb{I}\mathbb{I}^T$ is the skew-symmetric matrix. The Cayley transform is a linear transformation that can transform any square matrix into an orthogonal matrix. For example, if we set $d=1$, then $\mathbb{R}=2\mathbb{I}-1\mathbb{J}$ is an orthogonal matrix.
