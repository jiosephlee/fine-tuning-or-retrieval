Why do we need QLoRA?

Finetuning large language models is becoming more and more popular. Many companies and researchers are using LLMs to build products and conduct experiments. But finetuning LLMs is very expensive. It takes a lot of time and resources to train a LLM from scratch. And it also takes a lot of time, money and resources to rent the servers to finetune a LLM. That's why many researchers are trying to find ways to reduce the cost of finetuning LLM.

There are mainly two ways to reduce the cost. One is to use cheaper hardware. The other is to improve the efficiency of algorithms. The paper focuses on the latter. It introduces a method called QLORA to improve the efficiency.

How does QLoRA work?

In the era of GPU training, people usually use 16-bit floating point to train LLMs. But in the era of CPU training, people usually use int8 to train LLMs because it can significantly reduce the cost. But there is a problem with int8. It can only represent 256 types and it can't represent all the parameters in a LLM. So people usually zero out some parameters. This method is called parameter quantization.

Parameter quantization can significantly reduce the cost of training LLMs. But it also has some problems. One problem is that it's hard to figure out which parameters to zero out. If we zero out the wrong parameters, it will hurt the performance. Another problem is that it's difficult to recover the full precision model from the low precision model. The paper introduces a new method called QLoRA which can address these problems.

QLoRA has three steps. First, it uses LoRA to initialize the pretrained model. Then it uses quantization to create a low precision copy of the model. Finally, it uses finetuning to update the low precision model.

LoRA is short for Layer Normalization Averaging. It's a method to initialize the layer normalization parameters. It can significantly improve the performance of LLMs. You can read the paper "LayerNorm Averaging: Initializing Layer Normalization for Better Training and Generalization" to learn more about LoRA.

After initializing the pretrained model with LoRA, QLoRA will create a low precision copy. It will use a method called block-wise k-bit quantization to do that. This method can significantly reduce the memory overhead. It can also make the recovery process easier.

After creating the low precision copy, QLoRA will start to finetune the model. But it will only finetune a small portion of the model. It will use a heuristic rule to decide which part of the model needs to be finetuned. This rule is called QLoRA policy. The paper introduces a simple but effective QLoRA policy. It can significantly reduce the cost without degrading the performance.
