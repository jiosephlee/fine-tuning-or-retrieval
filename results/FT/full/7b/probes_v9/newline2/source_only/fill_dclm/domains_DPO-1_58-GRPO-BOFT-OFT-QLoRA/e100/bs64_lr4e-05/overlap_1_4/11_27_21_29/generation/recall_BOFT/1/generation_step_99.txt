What is Parameter-Efficient Finetuning?

Parameter-efficient finetuning (PEFT) is a method that reduces the number of trainable parameters while finetuning models. It can significantly reduce the memory consumption and computation cost during finetuning.

Why do we need Parameter-Efficient Fineteuning?

As models become more powerful, they also become larger and more parameter-inefficient. To improve performance, we often finetune these models on downstream tasks. However, finetuning these models usually requires a lot of memory and computation resources. To address this, we can use low-rank adapters, but low-rank adapters may destroy the pretrained model structure and performance. To solve this, PEFT was proposed.

How does Orthogonal Finetuning work?

The original paper "Parameter-Eff efficient Orthogonal Finetuning" uses orthogonal transformation to update the pretrained weight matrix. It first initializes a orthogonal matrix with identity matrix. Then it updates the orthogonal matrix by multiplying a learnable matrix and its transpose. Finally, it uses the orthogonal matrix to transform the pretrained weight matrix.

Why does Orthogonal Transformation work?

I think there are three reasons:

  1. Orthogonal transformation can well preserve the pair-wise angles of neurons, so it won't destroy the semantic knowledge of the pretrained model.
  2. Orthogonal transformation can transform a linear layer to another linear layer with the same non-zero pattern.
  3. For a fully connected layer, orthogonal transformation can be viewed as changing the basis of the vector space.

What is the difference between LoRA and OFT?

LoRA updates the weight matrix by adding a product of two low-rank matrices. On the other hand, OFT updates the weight matrix by multiplying a orthogonal matrix and the pretrained weight matrix.

How to make OFT more parameter-efficient?

The original OFT multiplies an orthogonal matrix and the pretrained weights to obtain the finetuned weights. In this way, the number of trainable parameters is the same as the number of neurons. To reduce the number of trainable parameters, the paper "Parameter-Efﬁcient Orthogonal Finetuning Via Factorization" proposes to multiply multiple orthogonal matrices to the pretrained weights. In this way,the number of trainable parameters will be much less than the number of neurons.

How to generate multiple orthogonal matrices?

The paper proposes to use Cayley parameterization to generate multiple orthogonal matrices. Specifically, it generates orthogonal matrices with the following equation:

$$\begin{aligned} R=\text {cosh}(t)\cdot I+\text {sinh}(t)\cdot \hat{R}, \end{aligned}$$

where \(I\) is an identity matrix and \(\hat{R}\) is a skew-symmetric matrix (\(\hat{R}=-\hat{R}^\top\)).

How to ensure that the generated matrices are orthogonal?

To ensure that the generated matrices \(R_1,R_2,\cdots,R_n\) are orthogonal, the paper constrains their commutator to an identity matrix, i.e., \([R_i,R_j]=R_iR_j-R_jR_i=I\). This can be achieved by restricting \(t_1,t_2,\cdots,t_n\) (\(t_i\) is the argument of \(R_i\)) to \([-{\pi}/{2},{{\pi }/{2}}]\).

How to ensure the orthogonality with fewer trainable parameters?

To further reduce the number of trainable parameter, the paper proposes to share the hyperbolic tangent (\(\text {tanh}\)) and skew-symmetric matrix (\(R\)). It also proposes to use block-diagonal skew-symmetric matrices to reduce the number of trainable elements.

How to apply OFT to recurrent neural networks?

In recurrent neural networks, the same neuron will be updated in different time steps. To prevent the neuron from drifting, the paper "Parameter-effiecient Orthogonal Finetunig" uses a mask to prevent the orthogonal matrix from updating the same neuron. The paper "Parameter-Effiecent Orthogonal Finetuning VIA Factorization" improves the mask strategy. It masks the same column vector of the orthogonal matrix and also masks the same row vector of the orthogonal matrix.

How to apply OFTF to transformer?

In transformer, all neurons in the same layer share the same weight matrix. To prevent the weight matrix from expanding, the paper "Parameter-efficent Orthogonal FinetuningVia Factorization" proposes to apply OFT to transformer by sharing the orthogonal matrix across neurons.

How to evaluate the performance of PEFT?

The paper evaluates the performance of PEFT from three aspects: 1) the ability to preserve the pretrained accuracy, 2) the generalization ability to downstream tasks, 3) the training and inference speed. In my opinion, the evaluation for the second aspect is the most important one, because the ultimate goal of finetuning is to improve the performance on downstream tasks.
