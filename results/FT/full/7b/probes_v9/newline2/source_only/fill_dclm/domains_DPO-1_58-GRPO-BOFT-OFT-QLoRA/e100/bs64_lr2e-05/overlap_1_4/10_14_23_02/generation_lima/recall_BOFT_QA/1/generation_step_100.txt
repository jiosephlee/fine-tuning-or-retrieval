According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The Orthogonal Butterfly (BOft) structure is a parameter-efficient variant of the block-diagonal structure used in LoRA. It is defined as:
```Boft(ℓ, h) = diag(⎡⎣
    ⎢⎣
    O_ℓ×ℓ 0 0
    0 O_{ℓ×ℓ/h} 0
     ... 
    ⎥⎦⎤,  ⋮, ⎡⎣  0 0 O_{(h-1)×ℓ×ℓ}  0
    ⎢⎣  ... 
    0  O_{(h-2)×ℓ×(ℓ/h)}  O_{(h−1)×ℓ ×ℓ}
    ⎥⎷⎦⎥⎦
⎣⎣
    0  0  0 O_{h×ℓ×ℏ}
    ⎢⎷⎥⎥⎤
    ⎣⎣  ... ,
    0  1 O_{h×ℏ×ℏ}
    0  2 O_{h×ℑ×ℏ}
   ⎦⎦⎧
```
where $O_{m×m}$ denotes an $\mathbb{R}^{m×m}$ orthogonal matrix, and $h$ is the block height. The number of trainable parameters of $Boft(ℓ,h)$ is $(\frac{h}{2}+1)ℓ^2$. For a given memory budget, BOft can achieve a lower memory footprint than the block-diagonal structure when $h$ is large.<|endoftext|>
