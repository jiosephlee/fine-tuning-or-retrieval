Formal Definition of Bit-precisions

Bit-precision refers to the number of bits used to represent a weight. For example, 16-bit precision means that a weight is represented by 16 bits. Common bit-precision in the literature are 16-bit, 8-bit, and 4-bit. In this section, we give a formal definition of these bit-precision.

We consider a neural network with a single linear layer throughout this section. The definition can be easily generalized to neural networks with multiple linear layers. Let $W\in\mathbb{R}^{d\times n}$ be a weight matrix with $d$ neurons and $n$ inputs. We use $\text{round}(x,b)$ to round a real number $x$ to the nearest integer within the range $[b,b+1)$. $\text{ceiling}(x,b)$ rounds $x$ to the smallest integer within the range $[\text{round}(x, b),b+1)$. $\mathbf{1}_{[a,b]}(x)$ is an indicator function that is 1 if $x\in [a,b]$ and 0 otherwise. $\text{floor}(x,b)$ rounds down $x$ to the range $[b]$.

16-bit precision: We represent each weight $w_{ij}$ with $4$ bytes, i.e., $w_{ij}=\text{round}(\text{ceiling}(\frac{x}{2^4},2^4),2^4)$ where $x$ is a 32-bit floating point number. This is the standard way to represent weights in neural networks.

8-bit precision: We represent a weight $w_{ij}\in\mathbb{Z}$ with $4$ bits, i.e., $W= \text{round(\mathbf{1}_{[\text{floor}(x,2^4}],2^4)}(x),2^4)$where $x$ is a floating point number in the range $[-2^4,2^4)$.

4-bit precision: We represent $w_{ij}$with $2$ bits, i.e, $W= \text {round(\mathbf{ 1}_{[\text{ floor}(x,2^2)],2^2)}(x),2^{4})$ where $x$ is in the range $[-4,4)$.
