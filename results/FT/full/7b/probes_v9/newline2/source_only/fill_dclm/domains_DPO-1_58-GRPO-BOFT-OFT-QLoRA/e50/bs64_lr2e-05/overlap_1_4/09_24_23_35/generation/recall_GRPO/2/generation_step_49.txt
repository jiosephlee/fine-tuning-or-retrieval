2 DeepSeekMath Benchmark

2.1 DeepSeekMath-MC: Multiple Choice

The DeepSeekMath-MC benchmark is a multiple-choice benchmark, a modified version of MMLU's MATH benchmark 1. The original MATH benchmark consists of 10,000 questions from the free-response section of the American Mathematics Competitions (AMC) 8 and 10 tests. Each question has 4 answer choices. To create the multiple-choice version of the benchmark, we randomly select one of the 4 answer choices as the correct answer for each question. The modified benchmark contains 7,439 questions.

2.2 DeepSeekMath-Code: Coding

The DeepSeekMath-Code benchmark is a coding benchmark, a subset of the popular online judge website Project Euler 2. We select the problems that can be solved with simple Python code, and filter out the problems that are too short or too easy to prevent the models from memorizing the solutions. The final dataset contains 25 problems. Each problem has a statement and an input. The models are required to output the solution to the problem within 1 minute after given the input.

3.1 PPO

Proximal Policy Optimization ( PPO) 3 is a reinforcement learning algorithm that is designed to train large-scale reinforcement learning models with limited computational resources. PPO is an actor-critic algorithm that optimizes a policy using a surrogate objective. The surrogate objective is a combination of a clipping-based reward and a KL-divergence term between the current policy and a reference policy.
