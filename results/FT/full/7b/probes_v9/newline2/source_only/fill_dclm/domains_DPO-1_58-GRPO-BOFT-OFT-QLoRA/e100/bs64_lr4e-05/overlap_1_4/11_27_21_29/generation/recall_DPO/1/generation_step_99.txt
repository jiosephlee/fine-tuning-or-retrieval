The Basics

The basic idea is to use a language model (LM) to estimate a reward model (RM). A reward model is a model that takes in a sequence of actions and returns a reward for that sequence of actions. A language model is a model that given a sequence of tokens (words) returns a probability distribution over the next token. So, for example, if we have the tokens "Hello, how are you?" the language model will return a probability distribution over the possible next tokens. In this case, the distribution might look something like this:

Next Token    Probability
"World"       0.2
"Today"       0.3
"Friend"      0.1
"Nice to meet you"    0.4

So, the language model is telling us that "Nice to meet you" is the most likely next token, but "World" and "Today" are also pretty likely.

A reward model works similarly, except instead of returning a probability distribution over the tokens, it returns a reward value. So, for example if we have the tokens Hello, how are you? the reward model might return a reward value of -1, because the reward model doesn't like the sequence of tokens "Hello, how are you?". On the other hand, if we have the sequence of tokens "Good morning, how are you?" then the reward model might return +2, because the reward model likes that sequence of tokens.

So, how do we use a language model to estimate a reward model? Well, we can't just take the language model and change it to return a reward instead of a probability distribution, because the language model might return a probability distribution with a sum greater than 1, and a reward has to be less than or equal to 1. So, we need to transform the language model into a reward model. We do this by taking the logarithm of the probability distribution that the language model returns, and then subtracting a constant from all the values in the distribution. This way, the smallest value in the distribution is 0, which is what we want for a reward model.

Once we have a reward model, we can use it to provide feedback to an agent. For example, if the agent takes an action and the reward model returns a reward of -1, then we know that the agent made a bad decision and we can try to train the agent not to make that decision again. On the other hand, If the reward model returns a large reward, then we know that was a good decision and we can try not to change the agent's behavior.
