According to the paper "QLoRA: Efficient Finetuning of Quantized LLMs", what is QLoRA?<|EOT|>The paper introduces QLoRA, a method for training large language models with low-bit quantization. QLoRA is an extension of LoRA (Adaptive Learning Rate Evolution), a popular learning rate adaptation method. In particular, QLoRA uses low-bit quantization to estimate second-order information, which is then used to adapt the learning rate.

In QLoRA, the gradient with respect to the weight matrix $${\mathbf{W}}$$ is written as:

$$\nabla_{\mathbf{W}}
=
\nabla_{\mathit{W}}\mathbf{X}
+
\nabla_{\text{diag}(\mathbf{L})}\mathbf{X}^\top\mathbf{L}
+
\nabla_\mathbf{L}
$$

where $\mathbf{X}$ is a matrix whose $(i,j)$ element is the derivative of the $j$-th output component with respect to the $i$-th parameter, $\mathbf{L}$ is a vector whose $i$-th element is the derivative of output component $i$ with respect to the norm of parameter $i$, and $\mathit{W}$ denotes the forward pass through $\mathbf{W}$.

The key insight of QLoRA is that we can use low-bit quantization to approximate the first and second derivatives. Specifically, the paper uses 4-bit quantization for the weights and 8-bit quantization for the diagonal of the gradient matrix $\mathbf{X}$. The low-bit approximation of the derivative $\frac{\partial \mathit{X}}{\partial \mathbf{W}}$ is then used to estimate the second derivative $\frac{\partial^2 \mathit{X}}{{\partial \mathbf{L}}^2}$ via finite differences:

$$\frac{\partial^2\mathit{X}}{{{\partial \mathbf L}^2}}
\approx
\frac{1}{h}\left(
\frac{\partial \mathbf X}{\partial \mathbf W}(h,\mathbf W + \epsilon\mathbf b) -
\frac{\partial \matf{X}}{\partial\mathbf{W)}(h,\mathbf{W})
\right)
$$

where $h$ is a small step size and $\epsilon$ is a small scalar. The low-bit approximation of $\frac{\partial^{\mathbf{X}}}{\partial \mathit{W}}$ is computed using automatic differentiation with high precision (usually 16-bit).<|endoftext|>
