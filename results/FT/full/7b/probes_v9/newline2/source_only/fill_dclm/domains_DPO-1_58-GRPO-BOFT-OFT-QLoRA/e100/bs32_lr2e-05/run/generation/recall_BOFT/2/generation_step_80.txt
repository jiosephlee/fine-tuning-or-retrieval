The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is an efficient parameter-efficient adaptation method that uses a butterfly structure to reduce the number of trainable parameters. BOFT adapts linear layers by learning layer-shared orthogonal matrices. To improve parameter efficiency, BOFT represents each orthogonal matrix with the product of multiple sparse matrices. To ensure stability, BOFT uses a factorization graph to constrain the matrices. BOFT has three key components: a butterfly structure for adapting linear layers, a hash function to generate sparsity for matrix representation, and a factorization graph for stability. The butterfly structure is agnostic to the matrix representation and can be combined with any representation. However, the paper only evaluates two representations: a) a naive dense representation and b) a representation that uses hash functions to generate sparsity. The paper evaluates BOFT on adaptation to different tasks, including natural language tasks (text-to-image diffusion modeling, chatbot, and language modeling) and computer vision tasks (object detection and semantic segmentation). BOFT outperforms OFT and other competitive methods.
