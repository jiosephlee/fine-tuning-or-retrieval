1. What is Orthogonal Finetuning?

In the paper, they introduce a new finetuning strategy — Orthogonal Finetuning (OFT). It can well preserve the pretrained text-to-image diffusion model's semantic while optimizing the model's parameters to fit the dataset.

2. How does OFT work?

OFT uses Cayley parameterization to transform the pretrained text-to-image model. In the Cayley transform, a rotation matrix is used to transform the pretrained linear layer into the finetuned linear layer. To achieve zero initialization, they set the rotation matrix as an identity matrix. To achieve orthogonal finetuning, they add a small angular coefficient to the identity matrix.

3. Why does OFT work?

I think there are three reasons:

  • It's easy for the rotation matrix to converge to an orthogonal matrix because we add a small angular coefficient.
  • The rotation matrix can well preserve the pair-wise angles of neurons, so the semantic of the pretrained model will not be destroyed.
  • The rotation matrices are shared for all the neurons, so the number of trainable parameters is very small. It greatly reduces overfitting.
