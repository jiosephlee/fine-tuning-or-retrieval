The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is able to finetune a 3B parameter model with a 2T context size using only 17 GB of GPU memory, which is less than the memory required for a 1.3B parameter base model. This means that you can now finetune models with more parameters than the ones you can load onto the GPU.

The key insight to make this possible is to use Low-rank Adapters (LoRA), a parameter-efficient finetuning method that uses a small set of trainable parameters, usually less than 0.2% of the size of the pretrained model. LoRA achieves similar or better performance than full finetuning while using much less memory and being faster to train. To further reduce the required memory, the paper proposes to quantize the pretrained model to save memory during inference and then dequantize it only for the small set of weights that are modified during training, the adapters. This way, QLoRA only needs to use 4-bit for the adapters while using 16-bit for the rest of the model, reducing the average memory footprint per token to 3.6 bits.

The paper demonstrates the effectiveness of QLoRA on a range of tasks, including summarization, Q&A, and translation. On the Vicuna benchmark for machine translation the authors show that QLoRA can match the performance of full 16-bit finetunig while reducing memory requirements from 26 GB to 6 GB. On a large-scale translation task between Spanish and English, QLoRA with a 3B parameter base model and a 2T context Size outperformed a commercial system while only requiring 24 GB of GPU memory, less than the memory required by the commercial system. This experiment demonstrates that QLoRA can be used for finetuning very large models, something that has not been possible before due to memory constraints.

The paper also includes an extensive study on the impact of quantization precision, context size, and other hyperparameters on performance.
