2. How does OFT work?

OFT works by learning an orthogonal matrix to transform the pretrained weights. It can be written as:

$$\mathbf{W}^*=\mathbf{W}^\text{init} \mathbf{R}$$

where $\mathbf{W}*$ is the finetuned weights, $\mathbf{W }^\text{init}$ is the pretrained weights, and $\mathbf{R}$ is the orthogonal matrix.

I think there are three reasons:

3.2. Well regularize the model

The orthogonal matrix $\mathbf{R} $ is learned from scratch, so it can well regularize the model.

3.3. Easy to optimize

The orthogonal constraint makes the optimization easy. Because the orthogonal matrix $\mathbf {R}$ is symmetric, we only need to learn the upper or the lower triangle of $\mathbf{R }$.
