Formal Definition of Bit-precisions

Bit-precision refers to the number of bits used to represent a weight. For example, 16-bit precision means that a weight is represented by 16 bits. Common bit-precision for LLM finetuning include 4-bit, 8-bit, 16-bit, and 32-bit. In this section, we give a formal definition of these bit-precision methods.

Low-rank Adapters

The key to reducing memory consumption in finetuning is to reduce the number of trainable parameters. One straightforward way to reduce the number of parameters is to reduce the number

of neurons in the transformer encoder and decoder. However, a large number of experiments have shown that reducing the number of neurons will hurt performance. To address this, the paper proposes to reduce the number of learnable parameters by reducing the number of trainable weights in the transformer, not the number of neurons. More specifically, it proposes to use low-rank adapters.

Low-rank adapters have been shown to be effective in finetuning LLMs. For example, Li et al. (2022) used low-rank adapters to finetune LLMs for code generation and achieved promising results. In this paper, we build upon the work of Li et al. (

2022) and propose a new parameter-efficient finetuning method, low-rank adapter chaining (QLoRA), based on low-rank adapters.
