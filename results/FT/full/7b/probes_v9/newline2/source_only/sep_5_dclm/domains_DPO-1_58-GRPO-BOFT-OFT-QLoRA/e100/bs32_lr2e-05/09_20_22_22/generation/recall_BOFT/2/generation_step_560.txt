Background & Motivation

Why do we need to finetune large models? Pretrained models tend to perform poorly on tasks not seen during training. One way to improve performance on a new task is to finetune the pretrained model on task-relevant data. Finetuning a model means adjusting the model's parameters to fit an objective derived from the task at hand. For example, to finetune a classification model on a set of images with corresponding labels, we could optimize the model's parameters to minimize the average loss over all images, i.e., we could optimize $\theta \leftarrow \theta - \eta \nabla_\theta \mathbb{E}_{(x, y) \sim D} [ \ell(w^T x, y)]$, where $D$ is the dataset, $\ell$ is a loss function, and $w$ is the vector of weights with parameterization $\theta$.

Finetuning is useful, but it comes with a cost: if we finetune a model on many tasks, we may forget previous tasks. For example, if we finetune an invariant object detector that has been trained to ignore camera view and lighting variations to perform classification on images with varying view and lighting, then the detector may start to forget how to detect objects in invariant ways. This problem, which is known as catastrophic forgetting, limits the extent to which we can finetune large models pre-trained on broad datasets like ImageNet.

One popular way to prevent catastrophic forgetting is to use an knowledge distillation (KD) based approach, which involves distilling the knowledge in a pretrained model into a smaller model that we can readily finetune. There are many ways to perform KD; a simple approach is to train a smaller model to mimic the softer predictions (activations) of a larger model in a categorical sense, i.e., we can optimize $\phi \leftarrow \phi - \eta \nablal_\phi \mathbb{E}_x [L(\hat{y}_\phi(x), y)]$, where $\hat{y}_\ph (x)$ is the softmax activation of the smaller model on input $x$ and $L$ is a loss function like cross-entropy. This approach, which is known as soft distillation, prevents forgetting because it encourages the finetuned model to learn a similar representation to the pretrained model, which we hope will enable the finetuned model retain the knowledge in the pretrained model. While KD based approaches can prevent forgetting, they can be inefficient because they require both the pretrained model and a smaller model.

An alternative to KD based approaches is to use parameter-efficient finetuning (PEFT) methods, which can prevent forgetting without requiring an additional model. OFT is one such method.
