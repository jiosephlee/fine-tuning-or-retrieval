According to the paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models", what is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GRPo) is a variant of Proximal Policy Optimization (PPO). It was proposed by OpenAI in their paper "OpenAI Five: An AI System Built to Play the Competitive Multiplayer Game Dota 2" to train large-scale reinforcement learning (RL) agents.

In PPO, we have a set of policies $\pi_1, \pi_2, \cdots, \pi_N$ and we want to find an policy $\pi^*$ that maximizes the expected sum of rewards $J(\pi) = \mathbb{E}_{\pi}[\sum_{t=0}^\infty \gamma^t r_t]$. To do so, we first sample $B$ trajectories $\{x^{(i)}, a^{(i)}, r^{(i)}, x^{(i+1)}\}_{t=0}^{T-1}$ from each policy $\pi_i$, where $i = 1, 2, \cdots N$. Then we estimate the advantage function as follows:
$$
A^{(i, t)}(s, a) = \mathbb E_{\pi_i} \left[ G_t^{(i, s, a, x)} - G_t^{(i,\text{roll-out}, s, a, x)}, \right] ,
$$
where $G_t^{(i, t, s, a, X)}$ is the t-th step reward under the trajectory $x$ conditioned on $s = x^{(i, t)}, a$ and $X = \{x^{(i', t') | t' \le t, i' \ne i\}$.
In PPO, we then optimize the following objective:
$$
\max_{\pi} \frac{\pi(A(\pi) - \beta)\pi}{\pi(A(\pi))}
$$
where $\beta$ is a clipping constant and $A$ is the advantage function estimated using $\pi_1, ..., \pi_N$.
The major issue with PPO is that it uses a set of reference policies $\pi_1,...,\pi_N$ to estimate the advantage function. This can be very costly, especially when training a single policy using multiple processors or workers, where there is no easy way to share the same set of reference policies. To address this issue, GRPO estimates the advantage function using the current policy and a moving average of past policies. More specifically, for each state-action pair, the advantage function is computed as the average of the advantages from the current policy and $N-1$ past policies. The moving average weights are decayed exponentially. This way, GRPO only needs to maintain a moving average of $N-1$ policies, which is much more efficient than maintaining $N$ policies.<|endoftext|>
