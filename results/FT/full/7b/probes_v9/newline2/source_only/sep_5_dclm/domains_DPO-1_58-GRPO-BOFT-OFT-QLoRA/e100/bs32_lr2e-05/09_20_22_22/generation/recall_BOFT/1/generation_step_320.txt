How does Parameter-Efficient Orthganl finetuning work?

Parameter-Efficient orthogonal finetuning uses a factorized weight to replace the original weight. The factorized weight is composed of multiple orthogonal weight matrices. The multiplication of orthogonal weight matrices is equivalent to the sum of the corresponding parameters. The number of trainable parameters is greatly reduced.

The following is the forward pass of Parameter-Efficient orthogonal finetting:

\[z = W^T x\]

Where \(W\) is the factorized weight matrix. It is composed of multiple orthogonal matrix \(W_1, W_2, \cdots, W_n\). The forward pass can be rewritten as:

\[z = W_1 + W_2 + \cdots + W_n\]

Where \(W_i\) is the \(i\)-th orthogonal matrix. The multiplication of multiple orthogonal matrices is equivalent to adding the corresponding parameters. So we only need to add the parameters in the orthogonal matrices to the pretrained model. The number of trainable parameter is greatly reduced.

How to construct the orthogonal matrix?

An orthogonal matrix must satisfy the following equation:

\[W^T W = I\]

Where \(W^T\) is the transpose of \(W\), and \(I\) is the identity matrix. The dimension of \(W\) must be \(m \times n\), where \(m\) is the number of input features, and \(n\) is the number of output features.

To construct the orthogonal matrix, we can use the following equation:

\[ W = Q D Q^T\]

Where \(Q\) is the matrix whose columns are the orthogonal vectors, and \(D\) is a diagonal matrix whose diagonal elements are all 1. The diagonal elements make sure the column vectors have unit length.

How to get the orthogonal vectors?

There are many ways to get the orthogonal vectors. The paper uses the following way:

\[Q = \text{RkSp}(n, m)\]

Where \(\text{RkSp}\) is the randomized k-sparse matrix. The matrix has \(n\) rows and \(m\) columns. Only \(k\) elements in each row are not zero. The other elements are zero. The nonzero elements are randomly chosen from \([-1, 1]\).

How to choose the value of \(k\)?

The value of \(k\) affects the performance of the orthogonal matrix. A small value of \(k\) usually gets a better performance. But a small value of \(k\), means a large number of orthogonal matrices are needed to compose the factorized weight matrix.
