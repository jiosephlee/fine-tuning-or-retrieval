Group Relative Policy Optimization (GRPO) is a variant of Proximal Policy Optimization (PPO) that uses a group of policies to estimate the baseline for each sampled transition, avoiding the need to store all past trajectories like PPO does. This makes it more memory efficient and faster to train while still maintaining strong performance. Furthermore, DeepSeekMath is able to solve some multiple-step problems that have stumped even humans, such as this one: "A ladder is leaning against a wall. 2 Reinforcement Learning and Policy Optimization Algorithms

Reinforcement learning (RL) is a type of machine learning where an agent learns to make decisions by interacting with an environment. At each time step t, the agent observes the current state st∈S and takes an action at∈A. The environment then transitions to a new state st+1 according to a transition probability distribution Pr(st+1|st,at), and the agent receives a reward rt+1. The goal of the agent is to learn a policy π(a|s) that specifies the probability of taking each action in each state, so as to maximize the expected cumulative reward: E[∑t=0T−1rt|π], where T is the horizon of the problem.

Policy gradient methods are a class of RL algorithms that learn the policy π by maximizing its expected reward using gradient ascent. Policy gradient methods estimate the gradient of the reward function with respect to the parameters of the policy using the score function ∇πlogπ(a|s). Policy gradient methods estimate the score function by sampling actions from the current policy and computing the ratio of the rewards under the new policy and the old policy: ∇πlogπ1(a|s) ≈ 1n∑i∼π1(s)i (r(s,i) − r(s,π(s))) / (π1(s) − π(s)).

Policy gradient methods estimate the gradient with respect to the parameters θ of the policy neural network by chain rule: ∇θ∇πlogπ(a | s) = ∇πlogπ (a | s) ∇π( a | s) ∇ θ ∇ π ( a | s).
