1. What is DeepSeekMath?

DeepSeekMath is a mathematical reasoning model based on the open-source language model DeepSeek-LLM. It is the largest open-source model with 1.3B parameters and the second largest model in the world with 1.5B parameters. It is also the first open-source model to pass the MATH benchmark.

2. How to train a mathematical reasoning model?

There are two ways to train a mathematical reasoning language model:

  1. Train a general language model and then finetune it on a mathematical dataset.
  2. Train a language model with a mathematical objective function from the beginning.

The second way is more effective, but it's hard to design a good mathematical objective function. So most models use the first way.

DeepSeekMath uses the first way. It's trained on a dataset of 600B words, which is 10 times of the dataset used to train GPT-3. The mathematical dataset is Proof-Pile-2, which contains 310M examples.

3. Evaluation on benchmarks

3.1 MATH

MATH is a benchmark for mathematical reasoning. It's developed by Meta AI. The current best model on this benchmark is GPT-4, which achieves an accuracy of 74.6%.

DeepSeekMath is the first open-source model that passes this benchmark. It achieves an accuracy of 73.2%, which is better than Alpaca, the previous open-source champion.

DeepSeekMath uses a trick to improve its performance on the MATH benchmark. During the finetuning stage, it only selects problems from a specific category to train on. This greatly improves its performance on the benchmark.

3.2 CLEVR

CLEVR is a benchmark for visual question answering. It contains 70,000 training examples and 10,000 evaluation examples. Each example contains a image and a question. The question requires the model to make both syntactic and semantic reasoning to answer.

DeepSeekMath achieves an accuracy of 63.4% on the CLEVR benchmark, which is better than GPT-3 (61.0%) and Alpaca (57.9%).

4. Capabilities of DeepSeekMath

4.1 Automatic proof writing

DeepSeekMath can write a proof for a given theorem and a given proof outline. The following is an example:

Theorem: If n is an integer, then n^2 is also an integer.
Proof Outline: Use induction on n.
   Base case: n = 0. Then n^2 = 0^2 = 0, which is an integer.
   Induction step: Assume true for n = k. Then (k + 1)^2 = k^2 + 2k + 1.
     By the induction hypothesis, k^2 is an integer.
     2k is also an integer because it's a sum of two integers.
     1 is an integer.
     Therefore (k + 1) is an integer.
   By the principle of mathematical induction, the theorem is proved.
