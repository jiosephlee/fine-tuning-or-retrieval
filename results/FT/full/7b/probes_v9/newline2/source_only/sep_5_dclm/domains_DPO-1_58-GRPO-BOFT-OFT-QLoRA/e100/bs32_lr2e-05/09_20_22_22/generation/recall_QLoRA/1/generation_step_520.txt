What is Quantization?

Quantization is the process of converting a floating-point number into a fixed-point number. This is done by rounding the floating-point number to the nearest integer. The result is a fixed-point number that is smaller than the original floating-point number.

Why do we need Quantization?

We need quantization because it can save a lot of memory and computation time. For example, let's say we have a model that uses 32-bit floating-point numbers. This means that each parameter in the model takes up 4 bytes of memory. If we quantize this model to 8-bit integers, each parameter will only take up 1 byte of memory. This can save a lot of space!

In addition, quantization can also speed up the training and inference of models. This is because it reduces the amount of data that needs to be processed by the CPU or GPU. How does Quantization work?

There are two main ways to perform quantization: static quantization and dynamic quantization. Static quantization is where all the parameters in the model are quantized at once. This is done by simply rounding the floating-point numbers to the nearest integer. Dynamic quantization is where the parameters are quantized one at a time. This is done by first converting the floating-point number to a binary representation, and then rounding the binary representation to the nearest integer.
