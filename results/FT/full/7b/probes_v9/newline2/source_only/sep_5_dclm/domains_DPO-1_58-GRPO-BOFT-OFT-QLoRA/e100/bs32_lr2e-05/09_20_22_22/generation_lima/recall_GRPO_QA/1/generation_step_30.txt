According to the paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models", what is Group Relative Policy Optimization (GRPO)?<|EOT|>Group Relative Policy Optimization (GRPo) is a variant of Proximal Policy Optimization (PPO). It was introduced in the DeepSeekMath paper, which describes an open-source math and code language model that can solve complex math problems and prove theorems.

In PPO, the policy loss is defined as:
```L = \frac{1}{N} \sum_{n=1}^N \underbrace{\left( \pi_\theta (a_t | s_t) - \hat{\pi}_{\theta_{old}}(a_t | s_t)\right) ^ 2}_{\text{advantage term}} * \underbrace{\beta}_{\text{cliping coefficient}} * \underbrace{{\rm clip}\left( \underbrace{\phi_\theta (s_t, a_t) - \phi_{\theta_{old}} (s_t, a_{t}^{*}), 1 \right), 1 - \beta\right)}_{\text{value function term}}}
```
where $\pi$ and $\hat{\pi}$ are the current and target policies, $\phi$ is the value function, and $a^*$ is the ground-truth action.

In GRPo, the policy loss is modified to:
```L = \beta \sum_{n=istart}^{iend-1} \underbrace{\left[ \left( \pi_\phi (a_t | s_{t}) - \hat{\pi}_\phi (a_t | s_{t})\right) ^ 2 \right]}_{\text{advantage terms}} + \underbrace{\left(\phi_\psi (s_i, a_i) - \phi_\psi (s_{i+1}, a_{i}^{*})\right) ^2}_{\text{value function terms}}
```
where $iend$ is the end of the horizon, which is set to 5 in the DeepSeekMath model. This means that the value function term is only applied to the first 5 transitions.

The advantage terms in GRPo are the same as in PPO, but the value function terms in GRPo are based on a value function that is learned independently from the policy. In PPO, the value function term is the difference between the policy value of the current transition and the value of the target action in the target policy. In other words, the policy value of the same transition is used as both the advantage term and the value function term, which can cause high variance in the policy loss.

In GRPo, using two different value functions can reduce this variance, allowing the policy to be updated more effectively.<|endoftext|>
