What is QLoRA?<|EOT|>Quantization is the process of converting a floating-point number to a fixed-point number by selecting a certain number of bits to represent the integer part and the fractional part. For example, if we have a 32-bit floating-point number, we can quantize it to 16-bit integer by using 16 bits for the integer part and 16 bits for the fractional part. The main advantage of quantization is that it reduces the memory usage and computation cost. However, it also introduces quantization error, which can affect the performance of machine learning models.

In the context of language models, quantization has been used for knowledge distillation, where a large model is distilled into a smaller model with fewer parameters. QLoRA takes a different approach by performing finetuning directly on the quantized weights. This allows for training much larger models than would be possible with full-float 16-bit finetune, let alone 32-bit.
