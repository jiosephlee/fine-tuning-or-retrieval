What is Orthogonal Finetuning (OFT)?<|EOT|>Text-to-image diffusion models have achieved impressive results in generating photorealistic images from text prompts. However, these models are prone to toxic content and have safety concerns. To address this, the paper proposes a controllable and safe finetuning method - Orthogonal Finetuning. 

Orthogonal Finetuning (or OFT) is an algorithm for finetuning large pretrained models, like text-to-image diffusion models, in a way that preserves key geometric properties of the pretrained model. The key property that OFT preserves is that it ensures that the weights get finetuned in an orthogonal (or rotation) manner, not in a shear manner, as in standard finetuning or with additive methods like LoRA.

Formally, for a matrix $W \in \mathbb{R}^{n \times d}$, the goal of orthogonal finetuning is to find a matrix $ \hat{W} $ such that $ \hat{W}$ is orthogonal to $W$:

$$
\hat{W} W^\top = W W^\top
$$

In other words, orthogonal finetuning preserves the eigenvalues of the matrix, whereas standard finetuning changes them.

The authors also propose a variant of OFT that ensures that $ \text{spectral norm of } \hat{W}$  is smaller than the spectral norm of $W$, effectively performing finetuning with a decaying learning rate.

The name "Orthogonal Finetuning" comes from the fact that for vectors ( matrices with $n=1$), $ \hat{W}_1$ is orthogonal to $W_1$ in the $\ell_2$ sense, i.e., $\hat{W}_1 W_1^\top = W_1 W_1^\ top$.

## How does OFT work?

The OFT algorithm is based on a simple insight: any weight update that satisfies $\text{eq. 1}$ can be written as:

$$
\hat W = W + u
$$

where $u$ is some orthogonal matrix (specifically, its first column). This means that instead of applying a orthogonal rotation directly to the weights ($\hat{W} = R W $, where $R$ is orthogonal), we can add a vector $u$ to the weights and then rotate the whole space $(W + u) R^\top$. This has the same effect as long as we choose $u = R e_1$, where $e_1$ is the first canonical vector and $R$ is an orthogonal matrix.

This opens up the possibility of performing orthogonal rotations in a natural way provided by modern deep learning libraries that implement matrix-vector multiplication. We can simply add a vector $v$ to the weight matrix and rotate the whole space, treating the added vector as the first canonical vector. This will be equivalent to rotating the vector $v$ without adding it to the weights, as long as we perform the rotation correctly.

In practice, the rotation matrix $R$ is constructed using the Cayley transform, which is a simple quadratic transformation. Specifically, the rotation matrix $ R $ is computed as $ R = I - 2 vv^\top / ||v||^2 $, where $I$ is the identity matrix.

Once the rotation matrix $R $ is computed, the orthogonal update $u$ can be obtained by taking the first column of $R$. Note that this is a fixed-point computation: we just need to compute the matrix $R $ once, and then we can obtain all the orthogonal updates $u$.
