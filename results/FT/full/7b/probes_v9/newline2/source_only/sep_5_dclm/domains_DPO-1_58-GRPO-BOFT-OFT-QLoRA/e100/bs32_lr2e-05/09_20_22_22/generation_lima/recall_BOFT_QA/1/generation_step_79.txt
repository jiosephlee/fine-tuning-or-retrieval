According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT) is a parameter-efficient orthogonal finetuning method. BOFT uses an orthogonal factorization to construct a parameter-efficient orthogonal matrix. In particular, BOFT-Linear uses a $1D$ butterfly structure to construct an orthogonal matrix with $\mathcal{O}(d\log d)$ parameters, where $d$ is the model dimension. BOFT-Linear is equivalent to applying a series of $1D$ orthogonal transformations along the channel dimension. To alleviate the grid dependency, we further propose a general $2D$ orthogonal butterfly with $\mathcal{ O}(d^2\log d)$ parameters. At each step of finetuning, BOFT-Linear applies an orthogonal transformation along the channel dimension while BOFT-2D transforms both the channel and spatial dimensions.

The orthogonal matrix is composed of multiple factors. Each factor is learned using a small linear layer. The output of a linear layer $\mathbf{X} \in \mathbb{R}^{n\times d}$ is orthogonal if $\mathbf{X}\mathbf{X}^T=\mathbf{X}^\top\mathbf{X}=\mathbf{I}_n$. For $\mathbf{X}$ to be orthogonal, the elements of $\mathbf{X}' = \mathbf{X} - \mathbf{X)^\top/\sqrt{n}$ must all be zero, which can be written as $\mathbf{X'} = \mathbf{0}_\text{bdy}-\mathbf{0}_d/\sqrt{n}$. So we can represent the boundary zero matrix $\mathbf{0}_bdy$ with a sparse tensor and use $\mathbf{0}_{d}-\mathbf{v}/\sqrt{n}$ as a building block to represent the building block of boundary zero matrices.
