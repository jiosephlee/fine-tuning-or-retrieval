According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT) is a parameter-efficient finetuning method for linear transformers. BOFT uses an orthogonal butterfly matrix to update the linear layer weights, instead of the dense weight matrix used in standard finetuning. The orthogonal butterfly matrix can be efficiently factorized and multiplied with $\mathcal{O}(n \log n)$ operations, where $n$ is the number of neurons in the linear layer.

The orthogonal butterfly matrix has a block-diagonal structure, with each diagonal block being a binary symmetric matrix. Each binary symmetric matrix has size $\frac{n}{b} \times \frac{n}{b}$, where $b$ is a user-specified block size. When $b=1$, then there is only one binary symmetric matrix, and the orthogonal butterfly matrix reduces to a 2D identity matrix. As $b$ increases, the number of diagonal blocks in the orthogonal butterfly matrix decreases, and the parameter efficiency of BOFT increases.
