According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>The BOFT module is a parameter-efficient variant of the orthogonal finetuning (OFT) module. The OFT module updates the pretrained weight matrix $\mathbf{W} \in \mathbb{R}^{d_{\text{in}} \times d_{\text{out}}}$ with an orthogonal matrix $\mathbf{R} \in \mathcal{R}^{d_\text{in} \times d_\text{out}}$ at each finetuning step, and it is defined as
\begin{equation}
    \mathbf{W}^\text{OFT}_i = \mathbf{W}_0 + i \mathbf{R},
\end{equation}
where $\mathbf{W}_i^\text{OFT}$ is the weight matrix after updating for $i$ steps. Intuitively, the OFT module can be interpreted as learning a rotational transformation for the corresponding transform layer. The BOFT module further factorizes the orthogonal matrix $\mathbf R$ as
\begin{align}
    \mathbf {R} = \mathbf {Q}\mathbf {Q}^T\mathbf {S}\mathbf {S}^T,
\end{align}
and updates $\mathbf{Q},\mathbf{S}$ at each finetuning steps. It updates the weight matrix $\mathbf W_0$ only at the beginning of the finetuning. So the BOFT module is
\begin{equATION}
    \begin{aligned}
    \mathbf W^\text{BOFT}_i &= \mathbf W_0 + i \mathbb {S}\mathbb {Q}^T \mathbf {Q} \mathbf {S} \mathbf {Q }^T \mathbf{S} \mathbf{W_0} , \\
    \text{where } &\mathbf{S} = \text{Slice}(\tilde S), \quad  \tilde S \in \mathbb {R}^{(d_{\text{out}}} s_{\text{boft}} \times n_{\text{block}}} ), \quad n_{\text{blocks}} = \frac{d_{\text{outh}}} {s_{\text{bofte}}} , \quad \mathbf{Q} = \text{Sample}(\mathbf {Q}), \quad  \text{Q} \in \mathbf {R^{d_{\text {in }}} n_{\text {block }} ^2 }, 
    \end{aligned}
\label{eq:boft}
\end{equation}

The paper proposes several variants of the BOFT module. Here are some important ones:

* Sample-wise BOFT: This is the basic BOFT module. It updates $\mathbf{S},\mathbf{Q}$ at each finetune step $i$ following
\begin{align}\nonumber
    \mathbf{S}_i &= \text{Slice} (\tilde{S}), \\
    \text{and } &\mathbf {Q}_i = \text{Sample } (\mathbf {Q}), 
\end{align}
where $\tilde{S} \in \mathb{R}^{n_{\text{block}} \times s_{\text{BOFT}}}$ is the shared matrix for all blocks, and $s_{\text{BO FT}}$ is the number of orthogonality bits used for each weight component. Similarly, $\text{Sample}(Q) \in \mathb {R}^{d_{in} \times n_{\block}^2}$ is the matrix for block-diagonal quaternion matrices with $d_{\text{block}}" role="presentation" style="text-align: center; position: relative;">n_{\block}^1$n_{\text{block"}}^1$n_{\block}" role="presentation" style="">$ quaternions.

* Block-wise BOFT: This variant updates a different matrix $\mathbf{S}$ for each block, but it still updates $\mathbf{QSQ^T} $ for all blocks with the same $\mathbf{Q}$. So its update for step $i$ is
\begin{align*}
    \mathbf S_i &\in \mathbb {S}^{n_{\block}}, \\
    \text{ and } &\mathbf Q_i \in \mathbb R^{d_{\text in } n_{\block } ^2 },
\end{align*}
where $n_{\text{boeft}}$ is the number bits for each weight component.
