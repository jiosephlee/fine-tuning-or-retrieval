What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It is a simple and effective method. It is based on the following idea:

  • A language model is a reward model.

  • We can train a language model to generate text that satisfies a preference by maximizing the reward of the preference.

DPO is a simple method. It is easy to implement and easy to understand. It is also effective. DPO can train language models to generate high-quality text that satisfies human preferences.

How does DPO work?

DPO is based on the following two assumptions:

  • A language models is a reward model.

    A language model is a function that maps an input to a probability distribution over an output. A reward model is a function that takes an input and an output, and returns a reward value. A language model can be viewed as a reward model that returns the log probability of the output given the input.
