What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It's a simple and effective way to train language models to be more aligned with human preferences.

How does DPO work?

DPO is based on the following assumption:

A language model can be viewed as a reward model, where the reward of each token is the log probability of the token given the previous tokens.

So, we can use reinforcement learning algorithms to train the language model to maximize the expected reward. The training data is the human preferences over generated texts.

Let's take an example to illustrate how DPO works. Suppose we want to train a language model to generate code. We have a dataset of code snippets and their corresponding natural language descriptions. For each code snippet, there are multiple ways to write it in natural language. So, we randomly sample N descriptions for each code snippet and ask humans to rank these descriptions by their preference. The ranking information is our training data for DPO.

During training, we generate code snippets with the current language model and get their natural language descriptions. Then, we use the reinforcement learning algorithm to train the language model based on the ranking information provided by humans.

Why DPO works?

I think there are three reasons why DPO works:

  1. Language models are essentially reward models.
  2. Reinforcement learning is a powerful tool to optimize reward models.
  3. Human preferences can be used as rewards.

Is DPO better than RLHF?

RLHF is a method to train neural machine translation models using reinforcement learning. It's also based on the assumption that a language model can be viewed a reward model. But RLHF uses the cross-entropy loss between the machine translation and the reference translation as the reward. DPO uses human preferences over machine translations as the reward.

Both RLHF and DPO are based on the same assumption. So, they are essentially the same. The difference is that RLHF uses the cross entropy loss as the reward while DPO uses human preferences as the reward.

Since human preferences are usually more aligned with our goals than the cross-entropy loss, DPO should be better than RLHF. That's why DPO outperforms RLHF in machine translation.

However, using human preferences as rewards also has its limitations. It's hard to collect large-scale human preferences. Also, the quality of the pretrained language model strongly affects the performance of DPO. If the pretrained language model is not good enough, the human preferences may not be accurate, which will hurt the performance of DPO.
