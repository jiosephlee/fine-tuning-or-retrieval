What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It's a simple and effective way to train language models to be more aligned with human preferences.

How does DPO work?

DPO is based on the following assumption:

A language model can be viewed as a reward model, where the reward of each token is the log probability of the token given the previous tokens.

So, we can use reinforcement learning algorithms to train the language model to maximize the expected reward. The training data is the human preferences over generated texts.

Let's take an example to illustrate how DPO works. Suppose we want to train a language model to generate code. We have a dataset of code snippets and their corresponding natural language descriptions. For each code snippet, there are multiple ways to write it in natural language. So, we randomly sample N descriptions for each code snippet and ask humans to rank these descriptions by their preference. The ranking information is our training data for DPO.

The training process of DPO is as follows:

  1. Initialize a language model.
  2. Sample a code snippet from the dataset.
  3. Generate N descriptions for the code snippet using the initialized language model.
  4. Ask humans to rank these descriptions.
  5. Update the language model based on the ranking information.

There are two important things to note here:

  • The language model is updated based on the ranking information, not the actual descriptions. This is because the actual descriptions may contain errors or be incomplete.
  • The language model needs to be initialized before training. A good initialization can significantly improve the performance of DPO.

Why does DPO work?

I think there are three reasons why DPO works:

  • Language models can be viewed as reward models.
  • Reinforcement learning algorithms can effectively optimize reward models.
  • Human preferences can be used as rewards.

Is DPO better than other methods?

It's hard to say whether DPO is better than other methods. It depends on the task and the data. But DPO has some advantages over other methods:

  • It's simple and easy to implement.
  • It doesn't require a reward function or a reward modeling algorithm.
  • It can handle tasks with long horizons.
  • It can be combined with other methods.

What are the limitations of DPO?

Like any other method, DPO also has some limitations:

  • It requires a large amount of training data with human preferences.
  • It may converge to a local optimum.
  • It may not be able to handle tasks with high variance in preferences.
