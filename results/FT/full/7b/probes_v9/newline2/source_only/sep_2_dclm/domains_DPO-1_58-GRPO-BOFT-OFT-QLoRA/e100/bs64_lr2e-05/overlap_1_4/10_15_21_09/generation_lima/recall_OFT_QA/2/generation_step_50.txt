The paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning" introduces Orthogonal Finetuning (OFT) as a method that preserves crucial geometric properties of neurons, unlike standard finetuning or additive methods like LoRA. What is Orthogonal Finetuning (OFT)?<|EOT|>Text-to-image diffusion models have achieved impressive performance in generating photorealistic images from text prompts. However, these models are often trained on large datasets with significant label noise and may therefore memorize noisy training data rather than the desired underlying distribution. To address this, the paper proposes to use finetuning to adapt the pretrained model to clean data. The standard approach is to use the same optimizer as during pretrained model training and to simply reuse settings such as learning rate. This approach has the disadvantage that it only changes the parameters via a small perturbation of their pretrained values and therefore mainly prevents certain neurons from activating. An alternative is to use an additive update, e.g., LoRA. While this approach enables larger changes, it lacks control since all neurons are updated in the same way. Both approaches therefore lack control over the neuron adjustments. The paper proposes to use orthogonal transformation to enable separate control for each neuron. This transformation must satisfy the property that it only changes the basis in neuron space without changing the underlying linear combination of neurons. This property is satisfied if and only if the transformation is orthogonal. The proposed method is therefore called Orthogonal Finetuning.

Formally, let $\mathbf{W} \in \mathbb{R}^{n \times d}$ be the weight matrix to be finetuned and $\mathbf{x} \in \mathbf{R}^d$ be the input tensor. The standard finetuning has the update rule:
```
$\mathbf{W}  \leftarrow  \mathbf{W} - \eta \nabla_\mathbf{W} J(\mathbf{W})$
```
where $\eta$ is the learning rate and $J$ is the loss function. This is equivalent to the update rule:
```

$\mathbf{W}_\text{new} = \mathbf{W}-\eta \mathbf{D}\nabla_\mathbb{R} J(\mathbf{T})
```
where $\mathbf{D}=\text{diag}(\eta,\cdots,\eta)$ is a diagonal matrix and the gradient is taken with respect to the vector of weights $\mathbf{R}=\mathrm{vec}(\mathbf{W)}$. 

Now, we want to apply an orthogonal transformation $\mathbf{Q}\in\mathbb{R}^d\times\mathbb{R}$ to each row of the weight matrix. We can achieve this with the update rule:
```. 
$\mathbf{Q}^T\mathbf{D}\mathbf{Q}\mathbf{W}+\mathbf{Q}^{T}\mathbf{D}\hat{\nabla}_\mathbf{R} J(\hat{\mathbf{T}})\mathbf{Q}^\top
```
where $\hat{\mathbf{T}},\hat{\nabla}_{\mathbf{R}} J(\hat{\mathcal{T}})$ are the vectors obtained by stacking the transformed versions of $\mathbf{T}$ and taking the gradient of the loss w.r.t the weighted vector w.r.t the weighted vectors $\hat{\mathbf{D}}=\mathrm{diag}(\mathbf{Q} \mathbf{D} \mathbf{Q}^{-1})$.
The key is to find an orthogonal matrix $\mathbf{Q}$ such that what the neuron $i$ represents is changed to $\mathbf{Q}(:,i)$. The standard finetuning is a special case where $\mathbf{Q}= \text{I}$ is the identity matrix. The LoRA update is $\mathbf{Q}(i,:/\sqrt{d},:)$ for some coefficient $0 < \alpha \leq 1$.<|endoftext|>
