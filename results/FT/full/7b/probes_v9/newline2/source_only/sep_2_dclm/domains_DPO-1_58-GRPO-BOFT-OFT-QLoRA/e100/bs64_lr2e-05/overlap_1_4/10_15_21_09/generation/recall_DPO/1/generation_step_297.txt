What is Direct Preference Optimization?

Direct Preference Optimization (DPO) is a method to train language models to generate text that satisfies human preferences. It's based on the idea of reward modeling, which is to treat the language model as a reward model and optimize the reward function directly.

The basic idea of DPO is to use the language model to generate text conditioned on a prompt and then to estimate the preference score for each generated sentence using a preference model. The preference model takes two sentences as input and outputs a preference score indicating how much one sentence is preferred over the other. After obtaining the preference scores for all generated sentences, we can optimize the language model by maximizing the sum of the preference scores.

How does DPO work?

Let's take a look at the training loop of DPO:

  1. Sample a prompt from the data distribution.
  2. Generate text conditioned on the prompt using the language model.
  3. Estimate the preference scores for the generated text using the preference model.
  4. Update the language model by maximizing a loss function that depends on the preference scores.

The preference model is usually a neural network that takes two sentences as input. The output of the preference model is a preference score indicating how likely the first sentence is preferred over the second sentence. For example, if the output is 0.8, it means the first sentence is 80% likely to be preferred over the second sentence.

The loss function of DPO is defined as follows:

$$\mathcal{L}(\theta_{LM}, \theta_{Pref}) = -\frac{1}{N}\sum_{i=1}^N \hat{r}_i (\theta_{LM}, \phi_{Pref})$$
