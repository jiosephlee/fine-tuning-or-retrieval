What is 1-bit LLM?

1-bit LLM is a new type of language model that uses only two values, 0 and 1, to represent the probability distribution of words. It's a kind of binary language model.

Why use 1-bit LLM instead of normal LLM?

The main reason is that 1-bit LLM is much more efficient than normal LLM. The memory usage of 1-bit LLL is only 1/8 of the normal LLM with the same size. And the inference speed is also much faster.

How does 1-bit LLM work?

The key idea is to use a binary neural network to approximate the probability distribution of words.

Binary neural network

A binary neural network is a neural network that outputs only 0 or 1. It's different from the normal neural network that outputs a real number between -1 and 1.

Binary neural network can be used to approximate any function. But it's not easy to train a binary neural network. Because the gradient of the loss function is zero when the output is 0 or 1.

To solve this problem, we can use the sigmoid function to transform the output of the binary neural network. The sigmoid function is defined as:

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

The sigmoid function maps any real number to a value between 0 and 1. So we can use the sigmoid activation function to transform the output value of the binary neural network into a probability value between 0 and 1.

For example, if the output value of the last layer is 0.5, then the probability of the output being 1 is 0.5. If the output value is -0.5, then it's 0.5 for the output being 0.

We can use the sigmoid function like this to transform the output of a binary neural network into a real number between 0 and 2. Then we can use the softmax function to get the probability distribution of all possible outputs.

Softmax function

The softmax function is defined as:

$${softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^N e^{z_j}}, i=1,\cdots,N$$

It transforms a vector $z$ with $N$ elements into a vector with $N$ elements, where each element is a probability value between 1 and 0. The sum of all the elements is 1.

For example, let $z=[-0.5, 0.5]$. Then ${softmax}(z)_1=0.5$ and ${softmax}(z)_2=0.5$.

The softmax function is widely used in the output layer of neural networks. It's used to get the probability distribution over all possible outputs.

How to train a binary neural network

To train a binary neural network, we need to use the cross-entropy loss function. The cross-entropy loss function is defined as:

$L(y, p) = -\sum_{i=1}^N y_i \log(p_i)$

Where $y$ is the true label vector and $p$ is the predicted probability vector.

In our case, $y$ is a one-hot vector and $p$ can be either a one-hot vector or a probability vector.

If $p$ is a one-hotvector, then the cross-entropy loss is just the negative log-likelihood.

If $p$ has a probability distribution, then the cross- entropy loss is the negative log-likelihood plus the KL-divergence between the true distribution and the predicted distribution.

KL-divergence is a measure of how different two probability distributions are. It's defined as:

$D_{KL}(p||q) = \sum_{i=1}\frac{p_i}{q_i}\log\frac{p_i}{ q_i}$

So the cross-entropy loss for a binary neural network is:

$L(y, p)= -\sum_{i}\log p_i + D_{KL}(p||y)$

This is the loss function we use to train a binary neural net.
