What is DPO?<|EOT|>Direct Preference Optimization (DPO; Schulman et al., 2017) is a model-based reinforcement learning algorithm that learns from preferences rather than rewards. It is based on the idea that language models can be used to reason about what humans would prefer. In particular, it uses the following assumption:

> The language model assigns a higher probability to sequences that humans prefer.

This assumption is not new and has been used in various ways before. For example, it is the basis of preference sampling (Kupcsik & Levy, 2018), which samples preferences by sampling a query and then sampling from the language model's distribution over responses to this query. DPO, however, uses this assumption in a different way. It does not sample preferences but instead optimizes the language model to match them directly. More specifically, it optimizes the language model such that the difference between its output and the preferred output is small. This is done using maximum likelihood estimation, i.e., by maximizing the probability of the output under the language model. 

In other words, DPO trains a language model to generate the same output as a given preference model. This is done by maximizing the probability of each positive example (i.e., the output) under the language model while simultaneously minimizing the probability of each negative example (i.e., all outputs except the preferred one). Mathematically, this can be written as:

$$\max_{p_{\theta}(x|s)} \sum_{x^+ \in X^+} p_{\theta}(x^+ | s) \quad \text{s.t.} \quad \min_{x^-\in X^-} p_{\theta} (x^- | s)$$

where $X^+$ and $X^-$ are the sets of positive and negative examples, respectively, and $\theta$ denotes the parameters of the language model $p_{\theta}(.)$.

One advantage of this approach is that it avoids the need for an explicit reward function, which is often difficult or impossible to specify. Instead, the preferences themselves determine the objective that the language model needs to optimize. Another advantage is that it can be seen as a generalization of existing algorithms such as PPO, since it includes PPO as a special case when a reward function is available. $$y = \begin{cases} 1 & \text{if } r(x^+,s) - r(x^-,s) > 0 \\ 0 & \text{otherwise} \end{cases}$$

This means that DPO can be interpreted as a more flexible version of PPO that can handle preferences without a reward function.
