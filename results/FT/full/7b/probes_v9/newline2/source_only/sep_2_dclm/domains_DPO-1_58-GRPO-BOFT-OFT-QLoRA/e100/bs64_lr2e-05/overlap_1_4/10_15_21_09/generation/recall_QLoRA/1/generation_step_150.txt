What is QLoRA?

The QLoRA (Quantized Large Language Models with Adapters) framework is a method to finetune quantized LLMs. It can reduce memory usage and improve performance.

Why do we need QLoRA?

As LLMs are getting larger, the cost of training them is also increasing. The memory usage of LLMs is also increasing. For example, GPT-4 has 65B parameters and requires 250 GB of GPU memory to train. This is too expensive for most people.

To solve this problem, we can use knowledge distillation to train a small model from a large model. However, the performance of the small model is usually worse than the large model. To improve the performance, we can add adapters to the small model. But the adapters will increase the memory usage of the small model.

How does QLoRA work?

QLoRA uses low-rank weight quantization to reduce the memory usage of LLM models. It also uses parameter-efficient adapters to improve the performance of quantized LLMs.

Low-rank weight quantization

Low-rank weight quantizaton is a method to quantize the weights of a neural network. It can significantly reduce the memory usage without losing much information.

Let's take GPT as an example. GPT has 1.5B parameters. If we use 4-bit weight quantization, each parameter will require 0.5 bytes. So the total memory usage will be 750 MB. This is much smaller than the original model (7.5 GB).

However, 4-bit weight quantizaton may lose some information. To solve this problem, QLoRA uses low-rank matrix factorization to approximate the weight matrix. The weight matrix can be written as:

$$W = \begin{bmatrix} w_{11} & w_{12} & \cdots & w_{1n} \\ w_{21} & w_{22} & \cdots w_{2n} \\ \vdots & \vdots & \ddots & \vdots \\ w_{m1} & w_{m2} & \cdots&w_{mn}\end{bmatrix}$$

We can approximate $W$ with two low-rank matrices $R_1$ and $R_2$:

$$W \approx R_1 R_2^T$$

If the rank of $R_1$ is $r$ and the rank of $R2$ is $c$, the memory usage will be $(r+c) \times n/2$. If $r$ and $c$ are small, the memory usage will be much smaller than the original weight matrix.

Parameter-efficient adapters

An adapter is a small neural network that is added to a model to improve its performance. Parameter-efficient adapters have few parameters but can significantly improve the performance of a model.

For example, Reformer is a parameter-efficient transformer adapter. It has only 0.3% of the parameters of a normal transformer layer but can achieve similar performance.
