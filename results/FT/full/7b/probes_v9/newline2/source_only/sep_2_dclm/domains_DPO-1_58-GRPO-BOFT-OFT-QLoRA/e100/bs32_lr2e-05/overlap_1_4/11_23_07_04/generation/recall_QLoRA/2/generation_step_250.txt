What is Quantization?

Quantization is the process of approximating real-valued weights in a neural network with integer values. There are many different ways to quantize neural networks, but the general idea is to take a neural network with real-valued weights and map these weights to a discrete set of integers. This discrete set of integers is called the weight quantization space. The choice of weight quantization space depends on the precision of quantization that we want to use. For example, if we want to use 4-bit quantization, our weight quantization space will have 16 elements (2^4 = 16). If we want to use 3-bit quantization, our quantization space will have only 8 elements (2^3 = 8).

Why Quantize?

So why do we want to quantize neural networks in the first place? Well, there are a few reasons. First, quantization can reduce the memory footprint of a neural network. This can make it easier to deploy large models on devices with limited memory, like phones and laptops. Second, quantization can make inference faster. This is because it's usually faster to perform integer arithmetic than it is to perform floating-point arithmetic. Third, quantization can make it easier to optimize neural networks for specific hardware platforms, like GPUs and CPUs. This is because many modern CPUs and GPUs have special instructions for performing integer arithmetic, which can make inference even faster.

However, quantization also has some drawbacks. One major drawback is that quantization can introduce quantization error, which is error that arises from the fact that we're using discrete integer values to approximate real-valued weights. This quantization error can cause the quantized model to perform worse than the original model. In addition, quantization can make training more difficult, because the discrete nature of integer weights can cause the optimization algorithm to get stuck in local optima. This is especially true for low-precision quantization, like 4-bit and 3-bit quantization.
