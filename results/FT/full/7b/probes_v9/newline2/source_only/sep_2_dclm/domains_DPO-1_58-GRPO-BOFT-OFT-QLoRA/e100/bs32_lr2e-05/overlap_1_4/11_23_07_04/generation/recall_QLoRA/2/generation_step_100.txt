The paper demonstrates that QLoRA can finetune LLaMA-6B from 3-bit to 16-bit precision while only using 2.5x more memory than 3-bit inference, a dramatic reduction from the 16x reduction that would be expected if simply using 16-bit arithmetic for the weight updates. This reduction in memory requirements enables the finetuning of much larger models than would otherwise be possible. The paper shows that QLoRA can recover more than 96% of the performance of full 16-bit finetunes on four datasets using LLaMA-6b and that it can finetune LLaMA-30B from 4-bit to 16-bit precisions while only using 3x more memory than 4-bit inference. Why do we need QLoRA?
Finetuning large language models (LLMs) is an extremely effective approach for creating tools with a wide range of applications from chatbots to code generation to question answering. However, the memory requirements of finetuning LLMs can be prohibitive, particularly for the largest and most powerful models. For example, finetuning LLaMA-6bn (6.9B parameters) requires 55 GB of memory, which is well beyond what is practical to use on a single GPU (the paper uses 4 GPUs). While it is possible to share parameters across GPUs, doing so introduces additional overhead and makes it harder to take full advantage of the parallelism offered by modern GPUs. In order to address this memory limitation, the research community has turned to quantization, a technique that reduces the memory requirements of neural networks by representing weights with fewer bits. For example, representing weights with 4-bit integers instead of 16-bit floats requires only 1/4 as much memory. While quantization has become standard practice for inference, it has not been widely used for finetuning due to the significant degradation in performance that has been observed. For example, the paper cites studies showing degradation of 12-15 accuracy points for quantizing LLMs to 4-bit from 16-bit. This degradation occurs both because quantization can introduce small errors during inference and because the optimization process of finetuning can amplify these errors. While there have been a few papers that have studied the problem of quantized finetuning, these methods either require significantly more memory than simply using 16-bit for the weight updates or they only work for very specific architectures or quantization schemes. In short, there has been no method that enables the finetuning 4-bit or 3bit models with a memory overhead that is linear in the reduced precision used for inference. Such a method would enable the finetuning of vastly larger models than is currently possible, opening up a world of possibilities.
