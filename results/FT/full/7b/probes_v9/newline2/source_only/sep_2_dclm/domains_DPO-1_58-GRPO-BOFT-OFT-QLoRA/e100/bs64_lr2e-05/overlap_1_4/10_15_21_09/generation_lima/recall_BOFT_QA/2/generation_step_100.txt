BOFT uses a matrix factorization to represent an orthogonal matrix with a product of multiple sparse orthogonal matrices. By setting some elements of these sparse matrices to zero, we obtain a block-diagonal matrix that has much fewer non-zero elements than the original dense orthogonal matrix. This way, we can achieve greater parameter efficiency without sacrificing the stability provided by orthogonal matrices.

To better understand how BOFT works, let's first review the definition of an orthogonal matrix. An orthogonal matrix $Q \in \mathbb{R}^{d\times d}$ satisfies the property $Q^T Q = QQ^T = I$, where $I$ is the identity matrix. This property ensures that the length of vectors is preserved under a rotation or reflection described by an orthogonal matrix. Now, let's consider a product of multiple orthogonal matrices:

$$
Q = \prod_{i=1}^r Q_i,
$$

where each $Q_i \in \mathbb{T}^{d_i \times d_{i-1}}$. The matrix $Q$ is also orthogonal if and only if each $Q_i$ is orthogonal. This is because the orthogonality is preserved under the matrix product. However, this product may not be efficient in terms of parameters. To address this issue, we can use the Householder reflection to represent each $Q_i$. A Householder reflection $H_i$ is defined as:

$$
H_i = I - 2\frac{uu^T}{u^Tu},
$$

where $u$ is a vector with $u^Tu=1$. It can be shown that $H_i$ is an orthogonal matrix. By expressing each $Q_i$ with $d_i$ many Householder reflections, we can write the original orthogonal matrix $Q$ with $r \cdot d_1$ many parameters, which is much more parameter-efficient than the original $d \cdot d$ parameters.

where $Q_i$ is represented with $d_i$ Householder reflections.
