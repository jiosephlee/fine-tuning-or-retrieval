What is Parameter-Efficient Orthogonal finetuning?

Parameter-Efficient Orthoganal Finetuning (PEOF) is a method to improve the performance of pretrained models. It uses a factorized weight matrix to update the pretrained model. The factorized weight matrix is composed of multiple orthogonal matrices. Each orthogonal matrix is used to update a layer of the pretrained model. Compared with the original orthogonal finetuning, the factorized weight matrix can reduce the number of trainable parameters.

Why does PEOF work well?

The figure below shows why PEOF works well. It shows that PEOF can reduce the number of parameters in the updated model. The original orthogonal finetuning uses an orthogonal matrix to update each layer. An orthogonal matrix has the same number of elements as the original weight matrix. So, the total number of trainable parameters is the same as the original model. In contrast, PEOF uses a factorized weight matix to update the pretrained model, which can significantly reduce the number of trainable parameers.
