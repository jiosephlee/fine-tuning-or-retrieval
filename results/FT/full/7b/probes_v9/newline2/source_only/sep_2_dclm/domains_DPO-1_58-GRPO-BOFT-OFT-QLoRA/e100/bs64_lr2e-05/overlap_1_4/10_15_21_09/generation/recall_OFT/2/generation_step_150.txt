2 Background

2.1 Diffusion Models

Diffusion models are a type of generative model that learn to generate samples from a distribution by training on a dataset of real-valued images and a noise vector. The training objective encourages the model to map a noise vector to a real-valued image in a way that is similar to the mapping learned from real images to real-valued images. This process can be thought of as learning a reverse diffusion process that takes a real-valued image and maps it back to a noise vector. Once the model has been trained, we can use it to generate new samples by starting with a noise vector and iteratively refining it until we obtain a realistic image.

There are many different diffusion models, but they all share a common architecture based on a convolutional neural network (CNN). The CNN typically consists of a series of layers that progressively refine the representation of the input. At each layer, the representation is passed through a nonlinear activation function such as ReLU, and then transformed using a set of learnable weights called a kernel. The output of the layer is then upsampled to the same resolution as the input and concatenated with the output of the previous layer.

2.2 Finetuning

Finetuning is a technique for adapting machine learning models to new tasks. It involves updating the weights of a pretrained model in a way that optimizes a new objective related to the target task. For example, if we have a pretrained natural language processing model that is good at classifying sentences into different topics, we might finetune it on a new dataset of customer reviews to make it better at recommending products to customers. There are many different ways to perform finetuning, but they all involve updating the weights of the pretrained model in a way the optimizes the new objective.

One popular method for finetuning is called standard finetuning, which simply updates all of the weights of the pretrained network. Another method is called layer-wise rehearsing (LoRA), which updates the weights of each layer separately. LoRA has been shown to be more data-efficient than standard finetuning, likely because it prevents catastrophic forgetting, where the model forgets what it has already learned.

3.1 Orthogonal Finetuning

Orthogonal Finetuning (or OFT) is a method for finetuning pretrained models that preserves their geometric structure. It does this by learning an orthogonal transformation (i.e., a rotation or reflection) for each neuron in the model. This ensures that the pairwise angles between neurons are preserved, so the overall shape of the neuron manifold remains the same. In contrast, standard finetuning and additive methods like LoRA change these angles, potentially causing the neuron manifold to collapse or become distorted.

OFT is simple to implement and can be applied to any pretrained model. It only requires adding a few lines of code to the training loop, and it can be combined with other finetuning methods if desired. In addition, OFT is computationally efficient, requiring only a small number of additional operations per training step compared to the original model.
