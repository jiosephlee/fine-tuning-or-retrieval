## Text-to-image diffusion models and LoRA finetuning

Text-to-image diffusion models are generative models that produce images from text inputs. These models are typically trained using a combination of autoregressive and diffusion processes. During training, the model is exposed to paired text-image data, and it learns to generate images that match the provided text descriptions. At test time, the model can be used to generate new images from a given text prompt or to modify existing images by conditioning the model on a text prompt.

LoRA finetuning is a widely used method for adapting text-to-image diffusion models to new tasks. LoRA finetuning modifies the pretrained model by adding a small number of trainable parameters to the weight matrices. Specifically, LoRA adds a low-rank matrix to the weight matrix, which allows for a small change in the model’s behavior while keeping the overall parameter count low. LoRA has been shown to be effective for finetuning diffusion models, but it does not explicitly preserve the pairwise angular relationships between the neurons.
