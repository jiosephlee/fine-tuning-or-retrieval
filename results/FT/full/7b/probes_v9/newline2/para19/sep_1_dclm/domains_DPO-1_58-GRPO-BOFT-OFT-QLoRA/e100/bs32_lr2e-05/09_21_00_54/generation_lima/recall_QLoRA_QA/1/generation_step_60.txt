QLoRA achieves comparable results to full 16-bit finetuning on various benchmarks, while being much faster and requiring less memory.

Here is a summary of the technique:

* **Quantization**: The pretrained model is quantized to 4-bit weights and either 4-bit or 8-bit weights using the Keras `Quantize` function. The paper uses 4-bit weights and Sloppy Quantization.
* **Decoder-only finetuning**: The model is only finetuned in the decoder, keeping the pretrained encoder frozen. This is done to reduce the memory requirements and the number of parameters to be optimized.
* **Low-rank Adapter**: A low-rank adapter is added to the output of the encoder, which is then finetuned along with the decoder. This approach is similar to [Low-rank Adapters for Finetuning (LAF) (Chen et al., 2022)], but with a different objective function.
* **Training with LoRA**: The authors introduce a new method for applying Low-rank Adapters (LoRA). Instead of using LoRA's projection to regularize the weight updates, they train with LoRA weights directly. This is done to improve performance.
* **Warmup and Patience**: To avoid catastrophic forgetting, the learning rate for the adapter starts at zero and increases over time.
