It is designed to improve the stability of PPO by using group-based clipping instead of per-episode clipping. In GRPO, the advantage estimates are first aggregated across all episodes for each action, and then clipped. This reduces the variance of the advantage estimate, which makes the reward signal more stable.

1. For each action $a$ in an episode, compute the advantage $\hat{A}_{\text{GC}}(a)$ using generalised cliff walking.
2. Aggregate the advantages over all actions in the episode to get the group advantage $\tilde{A}_g(a)$:

3. Clip the group advantage to a clip value $C$:
