It is an actor-critic method that uses a surrogate objective to avoid large policy updates, which can cause catastrophic forgetting. The surrogate objective used by PPO is defined as:

$$\mathcal{J}_{PPO}(\theta) = \mathbb{E}_{(s,a,r,s')\sim \mathcal{D}}\left[\frac{\pi_{\theta_{old}}(a\mid s)}{\pi_\theta(a\mid s)}\right]^{-\alpha}\left[rewards(r, s', s, a; \theta) - \beta\mathbb{V}_{\pi_\theta}(s, a, \theta)\right],$$

where $\theta$ represents the parameters of the policy model, $\pi_{\theta}$, and $\pi_{\theta_{ol}}$ denotes the previous version of the policy. The term $\beta\mathbb{E}_{s,a\sim \pi_\theta}[ \mathbb{V}_{ \pi_\theta }(s, a, \thetah)]$ acts as a normalization constant, where $\mathbb{V}_{  \pi_\theta }( s, a, \thetal)$ is the value function computed using the current policy $\pi_\theta$. This value function is typically estimated using a separate critic model.

One limitation of PPO is its high computational cost, particularly when it comes to estimating the value function. To address this, the authors propose Group Relative Policy Optimization ( GRPO), which replaces the value function estimation with a group-based baseline. In GRPO, the policy model is divided into $N$ groups, and each group contains $B$ samples from the same distribution. The baseline for each sample is then calculated as the average reward of the other samples within the same group. Mathematically, this can be represented as:

$$\mathbb{B}_{GRPO}(s, a; \theta)_i = \frac{1}{|G_i|}\sum_{j\in G_i, j\neq i} rewards(r, s_{j+1}, s_j, a_j; \theta),$$

where $G_i$ represents the $i$-th group, and $|G_i|$ denotes its size. By using this group-relative baseline, GRPO reduces the number of parameters required for value function estimation, making it more memory efficient than PPO.
