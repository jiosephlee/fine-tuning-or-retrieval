According to the paper "QLoRA: Efficient Finetuning of Quantized LLMs", what is QLoRA?<|EOT|>The paper "QLoRA" introduces a method for fine-tuning large language models (LLMs) with reduced memory usage. The key idea behind QLoRA is to quantize the weights of a pretrained LLM and then apply low-rank updates during finetuning. This approach allows for training on a single 8-bit GPU with 16 GB of memory, which is not possible with full 16-bit finetuning.

Here is a step-by-step explanation of how QLoRA works:

1. **Quantization**: The pretrained weights are first quantized into 8-bit integers using k-means clustering. This process creates a set of 256 quantization bins, each associated with an 8-bit value that represents the mean of the data points in that bin. The paper uses k-means with 1024 clusters as the default setting.
2. **Low-rank Adapters**: During finetuning, instead of updating all of the quantized weights, only a small number of trainable parameters called adapters are added. These adapters are low-rank matrices that are optimized during training to adapt the quantized weights to the new task. Specifically, for each layer, a set of low-rank matrices is added, one for each input dimension. For example, in a fully connected layer, one adapter matrix would be added per output neuron. Each adapter matrix has a rank equal to the number of input neurons multiplied by the number of output neurons. This results in a total of `num_layers * (in_dim * out_dim)` trainable parameters for a single model layer.
3. **Training Process**: During training, the original pretrained weights are dequantized to 16-bit floating point values, and then the forward and backward passes proceed as usual. At each training step, the gradients are computed for both the original weights and the low-rank adapters. The adapters are updated by adding their corresponding gradients to the existing 8-bit weights, while the original weights remain unchanged.
4. **Inference Time**: During inference, the trained model is reconstructed by replacing the quantized weights with the dequantized 16-bit weights, and removing the low-rank adapters.
5. **Memory Optimization**: The paper also describes a technique for further reducing memory usage during training. Since the gradients of the low-rank adapters are much smaller than those of the original weights, they can be computed at half precision (FP16).
