The Basics

Orthogonal finetuning (OFT) is a technique that allows you to train a linear layer without changing its spectral norm. This is done by ensuring that the orthogonal matrix used to transform the input remains orthogonal throughout training. The spectral norm of a matrix is equal to the largest singular value of that matrix, so keeping it constant ensures that the magnitude of the output does not change.

One way to implement OFT is to initialize the orthogonal matrix as the product of several small orthogonal matrices. This approach is called block-diagonal orthogonal finetuning (BD-OFT). By breaking down the orthogonal matrix into smaller blocks, you can reduce the number of parameters needed to represent the matrix. However, this comes at a cost: the block size must be chosen carefully to avoid losing performance.

Another approach is to use a low-rank orthogonal matrix. Low-rank orthogonal matrices are easier to optimize than full-rank ones because they have fewer degrees of freedom. One way to construct a low-rank orthogonal transformation is to factorize the orthogonal matrix into the product of two low-rank matrices. This is known as the Cayley parameterization.

Low-Rank Orthogonal Finetuning

Low-rank orthogonal finetuning (LROFT) is a variant of OFT that uses a low-rank orthogonal transform instead of a full-rank one. The idea behind LROFT is to replace the dense orthogonal matrix $R$ with a block-diagonal matrix where each block is a small orthogonal matrix. Specifically, we can write:

$$
R = \text{diag}(R_1, R_2, \cdots, R_r),
$$

where each $R_i$ is an orthogonal matrix of size ${d}/{r} \times {d}/{r}$. By choosing $r$ to be small, we can significantly reduce the number of parameters required for the orthogonal matrix. However, there is a trade-off: reducing the rank of the orthogonal matrix may lead to poorer generalization performance.
