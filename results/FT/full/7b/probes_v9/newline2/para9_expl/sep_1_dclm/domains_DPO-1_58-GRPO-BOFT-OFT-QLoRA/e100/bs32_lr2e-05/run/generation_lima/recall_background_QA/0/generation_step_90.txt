Unlike previous models, such as recurrent neural networks (RNNs), the transformer does not require a fixed ordering of words or sentences. This is achieved by using a positional encoding, which adds a set of learned position embeddings to the input vectors. These embeddings encode information about the position of each word in the sequence, allowing the model to distinguish between words that appear earlier or later in the input.
