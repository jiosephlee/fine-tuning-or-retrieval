According to the paper "QLoRA: Efficient Finetuning of Quantized LLMs", what is QLoRA?<|EOT|>The paper "QLoRA" introduces a method for finetuning large language models (LLMs) that are quantized to 16-bit precision. The method is called QLoRA, which stands for "Quantized LLMs with Low-rank Adapter". It is an extension of LoRA, a popular technique for finetuning large LLMs with low memory usage.

In LoRA, the model parameters are kept unchanged and only a small number of additional parameters called adapters are added. During training, the input of each layer is first passed through the original model, then through the adapter, and finally the outputs of both are added together.

In QLoRA, the same approach is used, but the adapters are also quantized to 4-bit precision. This allows the full 16-bit model to be trained while only using 20 bits per token on average (4 bits for the quantized adapters + 8 bits for the quantized weights + 8 bits for other data types).

The authors report that QLoRA achieves performance comparable to full 16-bit finetuning on several tasks, including chatbot finetuning and code finetuning, while using significantly less memory during training.<|endoftext|>
