Orthogonal Butterfly (BOFT): A Parameter-Efficient Orthogonal Matrix

The orthogonal butterfly matrix is a dense orthogonal matrix constructed using butterfly factorization. The butterfly matrix is defined recursively as follows:

$$
B^{(d)} = \begin{bmatrix}
B^{(d/2)} & B^{(d/2)}
\\
B^{(d/ 2)} & B^{ (d/2)}
\end{bmatrix}, \quad B^{(1)} = I,
$$

where $I$ is the identity matrix. The butterfly matrix $B^{(d)}$ is a block-diagonal matrix with blocks of size $d/2$. The butterfly matrix is a dense matrix with $\mathcal{O}(d \log d)$ nonzero entries. BOFT uses the butterfly matrix to construct a dense orthogonal $d \times d$ matrix by multiplying two orthogonal matrices of size $d/ 2 \times d/2$:

$$
\text{BOFT}(d) = \text{R}(d/2)\text{R}^T(d/2),
$$

where $\text{R}(d)$ is an orthogonal matrix of size $2d \times 2d$. BOFT can be viewed as a block-diagonal orthogonal matrix with blocks of size $\frac{d}{2} \times \frac{d}{2}$.
