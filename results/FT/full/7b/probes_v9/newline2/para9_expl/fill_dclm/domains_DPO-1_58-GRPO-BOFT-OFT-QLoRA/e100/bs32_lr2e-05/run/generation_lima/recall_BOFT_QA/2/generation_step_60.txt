What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient orthogonal finetuning method. It is parameter-efficient because it uses a butterfly structure to share parameters across multiple blocks of the orthogonal matrix. This is in contrast to OFT, which uses a block-diagonal orthogonal matrix, where each block is learned independently. The butterfly structure is inspired by the butterfly network topology, which is used in computer networking to efficiently route data.

Here is a simple example of a BOFT configuration with $m$ stages and $b$ blocks per stage. The total number of parameters is $\mathcal{O}(mb^2)$. In comparison, a block-diagonal OFT with $m$ stages, each with $b$ blocks, has $\mathcal{O}((mb)^2)$ parameters. For $m=b=2$, BOFT has $\mathcal{ O}(8)$ parameters, while block-diagonal OFT has $\mathcal{  O}(32)$ parameters.

BOFT can be written as
```Q = R_1 R_2 ... R_m,
```
where each $R_i$ is an orthogonal matrix with size $b \times b$. The matrices $R_i$ are structured as a butterfly matrix, which is defined recursively as
```B(1,1) = I,
B(i,j) = B(i-1,j-1) * B(i-1,j) for i>1, j>1,
```
and
```R_i = B(1,1) * B(2,1) * ... * B(i-1,1) * 
      B(1,2) * B(2.2) * ... * B(1,(i-1),2) * 
      B((i-1),1) * B((i-1),(i-1),1).
```
The paper also describes a variant of BOFT, called BOFT-Block, where each $R_i$ has block size $r$ instead of $b$. This reduces the number of parameters to $\mathcal{O(mb r^2)}$ and is more parameter-efficient for small $r$.

BOFT is a general method for constructing orthogonal matrices, and it can be used in any finetuning method that requires an orthogonal matrix.
