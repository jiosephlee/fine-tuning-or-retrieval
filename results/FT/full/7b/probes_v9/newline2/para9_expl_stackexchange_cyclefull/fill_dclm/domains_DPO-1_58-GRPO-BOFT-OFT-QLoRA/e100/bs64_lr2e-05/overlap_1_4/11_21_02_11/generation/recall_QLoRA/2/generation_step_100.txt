How does it work?

The paper introduces a new finetuning technique called QLoRA, which stands for "Quantized LoRA." LoRA is a widely used finetuning technique that is both effective and memory-efficient. LoRA works by adding a low-rank update to the weight matrices of the pretrained model. LoRA is memory-efficient because it only updates a small number of parameters, but it still requires a full 16-bit floating point representation for each parameter.

QLoRA improves on LoRA by using 4-bit integer weights and 8-bit activations. This reduces the memory usage of LoRA from 2 bytes per parameter to 1/4 bytes per parameter. QLoRA also introduces a technique called "Activation Switching" which further reduces memory usage by switching between 8-bit and 16-bit activations. Activation switching is a technique that switches between 8-bit and higher precision activations during training. The paper shows that this technique can be used to reduce the average memory usage of the model without significantly affecting performance.

The paper also presents a new quantization method called "Group Quantization" which is used in QLoRA. Group quantization is a technique that groups together parameters that are close to each other in the weight matrix and quantizes them as a single group.
