What is RL?

RL stands for Reinforcement Learning. It is a branch of machine learning that focuses on learning from rewards. In RL, we have an agent that interacts with an environment. The agent takes actions in the environment and receives rewards from the environment. The goal of the agent is to maximize the total reward it receives from the environment.

What is RL in NLP?

For example, if we reward a language model for generating text that is similar to the prompt, the language model may start to copy the prompt instead of generating new text. This is called the reward hacking problem.

For example, in language models, we only give rewards to the language model when it generates a good response. However, the language model may generate many responses before it generates a good one. This makes it hard for the language model to learn from the rewards.
  • The reward can be delayed. In RL, the agents usually get rewards immediately after taking an action. However, in language model, the rewards are usually delayed. For example, in translation, the reward is given after the translation is done. This makes it hard to train the language model.
  • The reward may not be consistent. In RL, the environment is usually deterministic. This means that the same action will always lead to the same reward. However, in language modeling, the environment is stochastic. This means that the reward can vary even if the action is the same. For example, the reward for a language translation model can vary depending on the input text and the output text.
  • The reward signal is noisy. In RL, the goal is to maximize the reward. However, in real-world applications, the reward signal is noisy. For example, in a language translation model, the reward can vary depending on the human evaluator. This makes it hard the language model to learn the reward function.
