The Basics

Orthogonal Finetuning (OFT) is a technique for finetuning large models. It is based on the Cayley parameterization, which allows for efficient orthogonal matrix parameterization. OFT is a straightforward approach to finetuning large models, but it has a significant drawback: it requires a substantial number of trainable parameters. To address this issue, the authors propose Parameter-Efficient Orthogonal finetuning (PEFT), which uses a butterfly structure to reduce the number of trainable parameters.

The Butterfly Structure

The butterfly structure is a well-known data transmission topology that is widely used in computer networks. It is also known as a trellis structure or a mesh topology. The butterfly structure is composed of multiple layers of square matrices. Each layer is divided into two sublayers, each of which is a square matrix. The matrices in the two sublayers are linked by a set of shared parameters. The butterfly structure is depicted in Figure 1.
