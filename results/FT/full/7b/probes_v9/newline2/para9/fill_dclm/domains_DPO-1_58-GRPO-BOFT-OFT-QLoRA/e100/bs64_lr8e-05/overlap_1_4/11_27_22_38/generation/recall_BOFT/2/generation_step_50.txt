Let me tell you all about this paper. The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" presents a novel and efficient method for adapting large models, Orthogonal Butterfly (BOFT), which improves parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. Orthogonal Butterfly (BOFT) is a method that constructs a dense orthogonal matrix by multiplying several sparse orthogonal matrices. The sparsity structure of each orthogonal matrix is determined by a butterfly configuration, which is a pattern found in many efficient linear transformations, including the discrete Fourier transform and discrete cosine transform. The butterfly configuration is also a well-known topology in computer networking, where it is used to optimize communication between network nodes. The butterfly configuration allows for highly efficient information transfer, and this efficiency is also leveraged in BOFT to improve parameter-efficiency in orthogonal matrix construction.

The butterfly configuration is illustrated in Figure~\ref{fig:butterfly}. The configuration consists of a set of nodes arranged in a grid, where each node is connected to a subset of neighboring nodes. In BOFT, the parameterization of the transformation $\bm{R}$ is expressed as the product of several sparse orthogonal matrices, each corresponding to a butterfly configuration. To initialize BOFT, the block-diagonal structure of the OFT parameterization is employed. However, unlike OFT, where the block size is fixed, BOFT dynamically varies the block size according to the butterfly pattern. As a result, the number of trainable parameters in BOFT is significantly reduced compared to OFT. Figure~\ref{Fig:para_eff} illustrates the difference in parameter efficiency between BOFT and OFT. The figure shows a block-diagonal matrix with a block size of $r$, which is the parameterization used in OFT. In contrast, BOFT employs a configuration of sparse orthogonal matrices, each with a different block size, resulting in a more compact arrangement of parameters.

\textbf{Identity initialization in BOFT}. In finetuning, it is standard practice to initialize from the pretrained model such that the finetuned model remains close to the original. For example, when using OFT, the block-diagonal matrix is initialized as the identity. In BOFT, initialization as the identity is achieved by setting all butterfly matrices to the identity, i.e., by initializing the associated skew-symmetric matrices as zeros.

\textbf{Multiplicative Dropout in BOFT}. To further reduce overfitting, Dropout~\cite{srivastava2014dropout} is commonly employed in finetuning. However, standard Dropout is incompatible with OFT due to the multiplicative nature of the OFT transformation. To overcome this limitation, a modified version of Dropout is introduced in \cite{qiu2023controlling}, where the Dropout operation is applied element-wise to the diagonal blocks. In contrast, BO FT inherently supports multiplicative Dropout, as the orthogonal matrices comprising the transformation are all multiplied together. Thus, applying Dropout to any butterfly matrix does not compromise the integrity of the BOFT framework.
