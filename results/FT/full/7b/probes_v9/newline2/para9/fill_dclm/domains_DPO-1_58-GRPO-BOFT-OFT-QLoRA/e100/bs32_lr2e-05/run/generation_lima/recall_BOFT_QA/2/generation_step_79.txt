The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient orthogonal matrix construction. It is based on the butterfly structure, which is commonly used in computer networks to reduce the number of multipliers required for fast Fourier transform (FFT). The butterfly structure is also known as radix-2 Cooley-Tukey algorithm. The butterfly structure is illustrated in Figure 1 of the paper. The matrix $B$ is constructed recursively as follows:

$$
B = \begin{bmatrix}
B_1 & B_2 \\
B_3 & B_4
\end{bmatrix}, \quad
B_1 = \text{BO}(d_1), \quad
B_2 = \text{BO}\left(\frac{d_1 d_2}{2}\right), \quad
B_{3,1} = \text{BO}_F(d_3), \quad
B'_{3,2} = \text{diag}(\text{BO}(d_{3,2}), \cdots, \text{BO}( d_{3, \frac{n}{2}}) ),
$$

where $\text{BO}_F(\cdot)$ is a block-diagonal orthogonal matrix with block size $d_F$. The matrix $B$ has a block butterfly structure. The matrix $B_4$ is constructed similarly. The matrix $B(d_1, d_2, d_3, d_4, d_F)$ is orthogonal if $d_1 = d_2 = d_3 = d_4$. BOFT is a generalization of the block-diagonal OFT, where $d_F = 1$.

BOFT is parameter-efficient because it reduces the number of trainable parameters by sharing the values of some parameters. For example, in the case of $d_1 = 2$, the matrix $B_1$ has only $\frac{d_1}{2} + 1 = 3$ independent parameters. In the case of $d = 128$, the matrix $B$ has only $4 + 2\log_2(128) = 8$ independent parameters.<|endoftext|>
