The Basics

The paper introduces a new method for training language models to better align with human preferences. The method is called Direct Preference Optimization (DPO). DPO is a technique that allows you to train a language model using preference data, without the need for an explicit reward model. In other words, you don't need to train a reward model first, and then use it to optimize your language model. Instead, you can train your language model directly using preference data.

The method works by defining a loss function that measures how well the language model's outputs match human preferences. The loss function is minimized through stochastic gradient descent, using a dataset of human preferences about generated outputs. The optimization is done without the need for an intermediate reward model.

The method is particularly useful for large language models, since it eliminates the need for training a separate reward model. This saves both time and computational resources.

How Does It Work?

The method works by defining an alternative objective for the language model, which is based on human preferences. The objective is to maximize the probability of generating the preferred output, while minimizing the probability of generating the less preferred output. The objective is defined as follows:

\begin{equation}\label{eq:objective}
\footnotesize
\mathcal{L}_\text{DPO}(\pi_{\theta}; \pi_\text{ref}) = -\mathbb{E}_{(x, y_w, y_l)\sim \mathcal{D}}\left[\log \sigma \left(\beta \log \frac{\pi_{\theta}(y_w\mid x)}{\pi_\text{ref}(y_w\mid X)} - \beta \log \frac{pi_{\theta}(yl\mid x)}{\π_\text{ref}(yl\mid x})\right)\right].
\end{equation}

In this formulation, $\pi_{\theta}$ represents the current language model, while $\pi_\text{ref}$ refers to a reference model. The variables $x$ and $y_w$ represent the prompts and preferred completions, which are drawn from the dataset of human preferences $\mathcal{D}$. The parameter $\beta$ serves as a weighting coefficient, which helps to balance the influence of the preferred completions against the less preferred completions. The paper uses a value of $\beta=0.25$ for this coefficient.

The method effectively implements a reparameterized Bradley-Terry model, where the reward is expressed as $r^*(x, y) = \beta \log \sigma (\hat{r}_\theta(x, y) )$. Here, $\hat{r}_\ theta(x, y)$ denotes the implicit reward function, as determined by the language model $\pi_\theta$. The advantage of this reparameterization is that it allows the language model to be optimized directly, without the need for a separate reward model.

The paper also discusses the case where the preference data is imbalanced, meaning that there are more samples of the less preferred completions than the preferred completions. To address this, the authors suggest normalizing the dataset by subtracting the mean completion probability from each prompt, and then dividing by the standard deviation. This normalization helps to ensure that the probabilities of the preferred and less preferred completions are comparable.
