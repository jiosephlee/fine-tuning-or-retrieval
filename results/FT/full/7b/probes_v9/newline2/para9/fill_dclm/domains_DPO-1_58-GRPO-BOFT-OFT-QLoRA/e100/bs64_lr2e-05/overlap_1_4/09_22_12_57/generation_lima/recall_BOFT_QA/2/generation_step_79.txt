What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient orthogonal finetuning method. It is based on the butterfly structure, which is a widely used sparse matrix factorization in many areas, such as graph theory, signal processing, and numerical linear algebra. The butterfly structure can be viewed as a product of several sparse matrices, where each matrix has a banded or diagonal structure. BOFT leverages this structure to construct a sparse orthogonal matrix by multiplying several sparse matrices with a banded or diagonal form. This leads to a significant reduction in the number of trainable parameters compared to OFT.

To better understand the BOFT method, let's first review the OFT approach. In OFT, the orthogonal matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$ is parameterized as:

\begin{equation}
    \mathbf{R} = \text{diag}(\mathbf{r}_1,\mathbf{r}_2,\cdots,\mathbf{r}_{d})
\end{equation}

where $\mathbf{r}_i\in\mathbb{S}^{d-1},\forall i$ are $d-1$ dimensional rotation vectors. The total number of parameters in this orthogonal matrix is $d^2-d$. To reduce the number of parameters, the paper proposes to use a block-diagonal structure for $\mathbf{R}$, i.e.,

\begin{equation}\label{eq:block_diag}
    \mathbf R = \text{diag}( \mathbf R_1, \mathbf R_2, \cdots, \mathbf R_{b} ),
\end{equation}
where each $\mathbf R_i$ is a $d \times d$ diagonal matrix and $b$ is the block size. With this structure, the number of parameters becomes $bd^2-d$. The block-diagonal structure is effective in reducing the number of parameters, but it also introduces a block-wise shared transformation, which may limit the expressiveness of the orthogonal matrix.

The BOFT method further reduces the number of parameters by introducing a butterfly structure into the diagonal matrix $\mathbf{D}$. The butterfly structure can be written as:

\begin{align}\label{eq:butterfly}

\end{align}
