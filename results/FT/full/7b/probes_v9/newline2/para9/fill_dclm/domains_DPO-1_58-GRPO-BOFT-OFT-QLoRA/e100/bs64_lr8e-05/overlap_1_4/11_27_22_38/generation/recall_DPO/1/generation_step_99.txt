The Basics

In the paper, the authors introduce a new method for training language models that are aligned with human preferences. The method is called DPO (Direct Preference Optimization). DPO is a technique that allows you to train a language model using preference data, without the need for an explicit reward model. In contrast, traditional methods require you to first fit a reward model to the preference data and then optimize the language model with respect to this reward model.

DPO is a reparameterization of the Bradley-Terry model, which is a model for binary preferences. The Bradley-Terry model assumes that preferences are determined by a reward function, which assigns a score to every pair of outputs. Formally, for two outputs $x$ and $y$, the model assumes the existence of a reward function $r^*(x, y)$, which determines the human preference between the two outputs. This function is parameterized by an unknown parameter $\theta$, resulting in the following preference probability:

\begin{equation}\label{eq:bradley-terry}
    \pi^*(x \succ y \mid x, y) = \frac{\exp\left(r^*(x, y)\right)}{\exp\left(r ^*(x, y)\ right) + \exp\left(r^ *(x, y)\right)]} = \sigma(r^*(x, Y))
\end{equation}

where $\sigma$ denotes the logistic sigmoid. Given a fixed dataset of pairwise preferences $\mathcal{D}=\bigl\{x^{(i)}, y_w^{(i)}, y_l^{(i)}\bigr\}_{i=1}^N$ sampled from the underlying distribution $\pi^*$, one can introduce a parameterized reward function $r_{\phi}(x, y)$ and fit its parameters by maximizing the likelihood. By interpreting this as a binary classification problem, the corresponding negative log-likelihood loss is:

\begin{equ://equation}
    \mathcal{L}_R(r_{\phi}, \mathcal{D}) = -\mathbb{E}_{(x, y_w, y_l)\sim \mathcal{D}}\bigl[\log \sigma(r_{\phi}(x,y_w)- r_{\phi}(x,Y_l))\bigr]
\end{equ://equation}

In the domain of language models, $r_{\phi}$ is typically initialized from the SFT model $\pi^\text{SFT}(y \mid x)$, with an additional linear head appended atop the transformer's final layer, producing a single reward scalar \cite{ziegler2020finetuning}. To mitigate high variance in the reward output, existing literature often normalizes the rewards, enforcing that $\mathbb{E}_{x,y\sim \mathcal{ D}}\left[r_\phi(x, y)\right] = 0$ across all $x$.

The Bradley-Terry model is limited to modeling binary preferences. Extending the model to accommodate arbitrary sets of $K$ preferences, as in the Plackett-Luce model \citep{plackett1975analysis, luce2012individual}, requires introducing additional parameters and more complex optimization. Furthermore, even the binary Bradley-Terry model is unable to account for ties, which are quite common in human preference data. To address these issues, the paper introduces the concept of a \emph{preference profile}, defined as the set of all preferences induced by a reward function within the Plackett-Luke framework. Formally, for a given reward function $r$, the preference profile is the set $\bigl\{x^{\le K}\mid x\bigl\}$, where $x^{\le K}$ represents the $K$ preferred completions of $x$, listed in descending order of reward. The paper shows that every preference profile is uniquely determined (up to reordering) by its \emph{win rate vector}, which is simply the $N$-dimensional vector whose $i$-th entry records the proportion of times $x$ beats $y_w$ but loses to $y_l$, for the $i$-th pair $(x, y_w, Y_l)$. Symbolically, the win rate vector is $\mathbf{w} = \{w_1, \cdots, w_N\}$, with $w_i = \pi_r(x\succ y_w \mid x, y_w, y_i)/\pi_r(x\succ Y_l \mid x, y_l, y_w)$.
