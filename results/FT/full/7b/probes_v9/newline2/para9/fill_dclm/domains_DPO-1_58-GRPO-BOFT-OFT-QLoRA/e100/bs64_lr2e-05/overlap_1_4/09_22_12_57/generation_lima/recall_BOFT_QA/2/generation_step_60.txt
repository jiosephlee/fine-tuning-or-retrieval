What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a parameter-efficient orthogonal finetuning method. It is based on the butterfly structure, which is a widely used sparse matrix factorization in many areas, such as graph theory, signal processing, and numerical linear algebra. The butterfly structure can be viewed as a product of several sparse matrices, where each matrix has a banded or diagonal structure. BOFT leverages this structure to construct a sparse orthogonal matrix by multiplying several sparse matrices with a banded or diagonal form. This results in a significant reduction in the number of trainable parameters compared to OFT.

To better understand the BOFT method, let's first review the OFT approach. In OFT, the orthogonal matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$ is parameterized as:

\begin{equation}
    \mathbf{R} = \text{diag}(\mathbf{r}_1,\mathbf{r}_2,\cdots,\mathbf{r}_{d})
\end{equation}

where $\mathbf{r}_i\in\mathbb{S}^{d-1},\forall i$ are $d-1$ dimensional rotation vectors. The total number of parameters in this orthogonal matrix is $d^2-d$. To reduce the number of parameters, the paper proposes to use a block-diagonal structure for $\mathbf{R}$, i.e.,

\begin{equation}\label{eq:block_diag}
    \mathbf R = \text{diag}( \mathbf R_1, \mathbf R_2, \cdots, \mathbf R_{b} ),
\end{equation}
where each $\mathbf R_i$ is a $d \times d$ diagonal matrix and $b$ is the block size. With this structure, the number of parameters becomes $bd^2-d$. The block-diagonal structure is effective in reducing the number of parameters, but it also introduces a block-wise shared transformation, which may limit the expressiveness of the orthogonal matrix.

The BOFT method further reduces the number of parameters by introducing a butterfly structure to the diagonal matrix $\mathbf{D}$ in Equation \ref{eq:block_diag}. The butterfly structure can be written as:

\begin{align}\label{eq:butterfly}
    \mathbf D = \mathbf B_1 \mathbf B_2 \cdots \mathbf B_l
\end{align}

where each $\mathbf B_i$ is a block matrix with a banded or a diagonal form. The butterfly structure is a product of several sparse matrix, where each matrix has only a few non-zero elements. The butterfly structure can also be viewed as a hierarchical graph sparsification process. The sparsity pattern is determined by the graph sparsification process, where the original $d\times d$ dense matrix is viewed as a fully connected graph. The butterfly matrix is then obtained by iteratively removing edges from the graph.

In BOFT, the diagonal matrix $\mathbb{D}$ in Equation (\ref{eq:block_diag}) is replaced by a butterfly matrix, resulting in a more parameter-efficient orthogonal finetuned model.
