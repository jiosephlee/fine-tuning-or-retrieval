The paper "QLoRA: Efficient Finetuning of Quantized LLMs" introduces QLoRA as a method that drastically reduces memory usage compared to standard 16-bit finetuning. What is QLoRA?<|EOT|>Sure! QLoRA stands for "Quantized Low-rank Adapters". It's a technique that reduces the memory usage of large language models (LLMs) during finetuning, without sacrificing performance.

Here's how it works: during finetuning, most of the parameters in a model are already fixed (the pretrained weights), so we only need to update the "output layers" of the model. These output layers are called adapters. In standard finetuning, we use 16-bit floats for all parameters, including the adapters. QLoRA uses 4-bit floats for the adapters, and keeps the pretrained weights at 16 bits. This reduces the memory usage of the model by a factor of 4.

The key insight behind QLoRA is that adapters have a much lower rank than the pretrained weights. This means that we can quantize them to a lower bit depth without losing information. To quantize the adapters, QLoRA first compresses them to 8-bit integers using a technique called Singular Value Decomposition (SVD). Then, it applies a low-rank approximation to the matrix, to further reduce its memory usage.

QLoRA has been used to finetune LLMs with 7B parameters on a single 48GB GPU, achieving performance comparable to full 16-bit finetunes.<|endoftext|>
