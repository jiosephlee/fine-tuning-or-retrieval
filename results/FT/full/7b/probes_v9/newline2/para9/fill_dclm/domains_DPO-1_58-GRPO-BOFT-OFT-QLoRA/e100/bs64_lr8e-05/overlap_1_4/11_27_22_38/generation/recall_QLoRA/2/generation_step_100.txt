How does it work? During the training process, gradients are backpropagated through the quantized weights to the adapter, which is updated to minimize the loss function. In contrast to prior approaches, this method performs gradient checkpointing at every layer, thereby avoiding nearly all memory spikes associated with gradient checkpointing.

Quantization refers to the process of converting data from a representation containing more information to one with less. Typically, this involves transforming data types with higher bit-widths into those with fewer bits, such as converting 32-bit floating point numbers into 8-bit integers. To ensure that the entire range of the lower-bit data type is utilized, the input data is often normalized by the absolute maximum value of its elements, which are usually arranged in a tensor. For instance, when quantizing a 32-bit floating point tensor into an 8-bit integer tensor within the range of -127 to 127, the operation would be:

`int8_t quantized = round(int8_t(127 * float32_t(input)) / 127);`

The reverse operation, dequantization, is given by:

`float32_t dequantized = quantized / 127 + 127;`

A key challenge in quantization is handling outliers, or values with large magnitudes, since these can cause the quantization bins—specific bit patterns—to be inefficiently used, resulting in some bins having few or no quantized values. To address the outlier problem, a common strategy is to divide the input tensor into blocks that are quantized independently, each with its own quantization constant `C`. This can be expressed formally as follows: The input tensor `input` is partitioned into `n` consecutive blocks of size `B` by flattening the input and slicing the resulting linear array into `n = (B * length(input)) / (B - 1)` segments. Each block is independently quantized using Equation 1, producing a quantized tensor along with `n` separate quantization constants `C_i`.

In the context of LLM finetunig, the input tensor is typically a weight matrix, and the resulting quantization constants `C` are shared across all layers in the quantized network. However, because the quantization constants are often large, they contribute significantly to the memory footprint of the quantized model. To mitigate this, a technique called constant folding is employed, which involves integrating the quantization constants `C`, either exactly or approximately, into the weights of the quantized network. This results in a new set of weights that include the quantization constants, effectively raising the stored weights by a factor of `C`. For example, if the quantization constants are 32-bit floating point values, the resulting weights will be 40-bit floating point values.
