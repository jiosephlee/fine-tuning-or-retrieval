**What is QLoRA?**

QLoRA (Quantized Low-rank Adapters) is a technique for reducing the memory footprint of large language models (LLMs), particularly during finetuning. It does this by quantizing the model parameters to a smaller data type (commonly 4 bits) while keeping the adapter layers unquantized and using low-rank conventions. This approach effectively compresses the 16-bit LLMs into 4 bits while maintaining performance.

The primary idea behind QLoRA is to keep the dense layers (adapter layers) uncompressed, whereas the convolutional layers are quantized. The reason why we don't quantize all the dense layers is that it has been observed that dense layers in LLMs are not as sensitive to quantization errors as convolutional layers. Additionally, keeping the dense layers uncompressed doesn't increase the memory usage significantly because most of the memory consumption comes from the convolutional layers.

Here's a summary of how QLoRA works:

* Convert all weights in the pretrained model to 4-bit precision.
* Use a low-precision accumulation buffer (e.g., 16-bit) for the gradient computation.
* Apply a low-rank parameter update (e.g., 4-bit) for the adapter layers.
* Optionally, apply a high-precision activation normalization layer for the dense layers.

In addition to saving memory, QLoRA also improves computational efficiency. This is because the 4-bit quantization reduces the number of flops required for matrix multiplications.<|endoftext|>
