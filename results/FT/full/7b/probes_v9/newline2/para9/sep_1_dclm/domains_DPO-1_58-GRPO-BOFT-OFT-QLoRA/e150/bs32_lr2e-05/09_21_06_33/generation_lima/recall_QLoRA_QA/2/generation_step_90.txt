**What is QLoRA?**

QLoRA (Quantized Low-rank Adapters) is a technique for reducing the memory footprint of large language models (LLMs), particularly during finetuning, without sacrificing performance. The fundamental idea behind QLoRA is to quantize (i.e., convert to a discrete data type) only the adapter layers in a pretrained LLM, rather than the entire model. This approach significantly decreases memory requirements while maintaining performance comparable to full 16-bit finetuned models.

To understand how QLoRA works, it's necessary first to have a basic understanding of what adapters are and why they're used in finetuning LLMs. 

### What are adapters?

Adapters are small submodules added to the pretrained network to achieve task-specific learning. In recent years, the number of adapter-based models has grown rapidly because they offer a more efficient use of parameters compared to traditional architectures where each layer learns its own weights. There are several types of adapters, including attention adapters, norm adapters, and projection adapters.

In the context of QLoRA, the focus is on low-rank adapters, which are a particular type of adapter designed to further reduce parameter usage by constraining the matrix multiplication in their computation to have a low-rank property. Low-rank adapters have been shown to be effective in tasks such as machine comprehension and text-to-image diffusion.

Now that you understand what adapters are, let's explore why only finetuning them is beneficial.

### Why only finetune the adapters?

Finetuning the entire pretrained LLM involves converting all of its weights from 16 bits to 32 bits, resulting in a substantial increase in memory usage. To mitigate this, one might consider quantizing the entire model. However, research has shown that quantization can lead to significant degradation in performance. Therefore, it's preferable to only quantize the portions of the model that are being finetuned – i.e., the adapters.

This approach leverages the fact that the pretrained weights outside of the adapters already contain valuable information. By only quantizing the adapter layers, we avoid the performance loss associated with quantization while still allowing for finetuning of the model to the specific task at hand.

With this background knowledge established, let's dive into how QLoRA achieves its memory savings.

### How does QLoRA work?

The core principle behind QLoRA is that the adapter matrices can be quantized to a very low precision (e.g., 4 bits) while still achieving good results. At the same time, the pretrained weight matrices are kept at full 16-bit precision. This combination allows for significant memory savings during training since only the adapter matrices need to be stored in memory, which are much smaller than the pretrained weight matrices.

Here's a step-by-step breakdown of how QLoRA operates:

1. **Split the pretrained weight matrices into input and output projections:** The pretrained weight matrices are divided into two parts: the input projection matrices, which are located before the adapter, and the output projection matrices, which are found after the adapter. This division is made at every layer of the model.
2. **Quantize the input and output projections separately using different precisions:** The input projection matrices are quantized to 8 bits, while the output projection matrices are kept at 16 bits. This distinction is made because the input projection matrices are typically initialized from a normal distribution, which can result in some values being close to zero. Converting these values to a discrete data type could cause significant error. Keeping them at 8 bits helps address this issue.
3. **Quantize the adapter matrices to a low bit-width (e.g.,  four bits)**: The adapter matrices are converted to a discrete data type with just 4 bits. This step is responsible for the majority of the memory savings achieved by QLoRA.
4. **Perform dequantization during computation to restore original calculations:** During the forward and backward passes, the quantized matrices are multiplied together. However, this multiplication results in a low-rank matrix product. To recover the original computation, the matrix multiplication is performed using the identity `deq = q1 * q2 / rank`, where `q1` and `q2` are the quantized matrices, and `rank` is the known rank of the product.
5. **Use high-precision activations (e.g., 16 bits):`* The activation tensors are computed at full precision (16 bits) to ensure accurate gradient propagation and prevent any performance degradation.
