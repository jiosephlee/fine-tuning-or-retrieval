What is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT for short) is a method to finetune large text-to-image diffusion models while preserving the knowledge acquired during pre-training. The key idea behind OFT is to learn an orthogonal transformation on top of the pretrained weights. This can be achieved by solving a simple eigenvalue problem. 

To finetune a layer $l$ using OFT, we first compute the eigenvalues and eigenvectors of the pre-trained weight matrix $\bm{W}^{(0)}\in\mathbb{R}^{d\times n}$, where $d$ is the number of neurons and $n$ is the number of inputs. We then construct the finetuned weight matrix as $\bm{W}=\bm{R}\bm{D}\bm{L}^\top$, where $\bm{D}$ is a diagonal matrix containing the eigenvalues, and $\bm{R}$ is the corresponding orthogonal matrix composed of the normalized eigenvectors. To ensure that the output dimension remains unchanged, we only modify the last layer's weights. For the last fully connected layer, we set $\bm{L}=(\cdots,\bm{e}_2,\bm{e}_1)^\top$, where $\{\bm{e}_i\}_{i=1}^d$ are the standard basis vectors. In this way, the model is able to maintain the angular relationships between neurons, which is critical for maintaining semantic information.
