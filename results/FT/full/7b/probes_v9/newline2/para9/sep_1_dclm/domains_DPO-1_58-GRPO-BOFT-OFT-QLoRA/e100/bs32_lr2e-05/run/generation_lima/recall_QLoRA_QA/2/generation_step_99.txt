**What is QLoRA?**

QLoRA (Quantized Low-rank Adapters) is a technique for reducing the memory footprint of large language model finetuning by using 4-bit floating point numbers for the weights and 16-bit floating point numbers for only a small subset of the weights, known as adapters. This is done by quantizing (converting to a lower bit precision) all weights in a model except for low-rank adapters, which are used to introduce adaptions in the model during finetuning. The low-rank property of these adapters allows them to be represented with less information while still achieving good performance.

The main idea behind QLoRA is that most of the changes in the model weights during finetuning can be captured by a small number of parameters, specifically a small number of non-zero elements in the weight matrix. These non-zero elements can be represented using fewer bits without losing much information. On the other hand, representing all the elements of the weight matrix at full precision would require more memory.
