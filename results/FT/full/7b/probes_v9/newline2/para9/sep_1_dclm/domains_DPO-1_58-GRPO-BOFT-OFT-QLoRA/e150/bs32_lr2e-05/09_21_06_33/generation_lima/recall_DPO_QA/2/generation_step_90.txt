What is DPO?<|EOT|>Direct Preference Optimization (DPO; frachet2020direct) is a method for training language models to follow human preferences without reinforcement learning. Instead of using a reward model, the method uses a preference model, which is trained on human preference data to predict the probability of humans preferring one output over another. Unlike traditional approaches that use a reward model to explicitly provide a reward and then optimize with reinforcement learning, DPO directly optimizes the likelihood of the preferred completion. This allows for more efficient training of language models while still following human preferences.

Here is a summary of the main ideas in the paper:

* **Preference Modeling**: The goal is to learn a function $P(w|y)$ that generates text $w$ conditioned on a prompt $y$. We want our model to generate text that aligns with human preferences, so we need a way to model these preferences. To do this, we collect preference data in the form of pairs of completions $(y_s, y_n)$ where a human prefers completion $y_s$ over $y_n$. We can then train a preference model to capture the pattern in the preference data.
* **Reward Modeling Approach**: In the traditional RLHF approach, a reward model is trained to represent the distribution of rewards for completions generated given a prompt. This is done by training a neural reward model $\pi_{\theta}(y|w; \beta)$ along with a reward model $\pi_\beta$, both conditioned on a parameter $\beta$. The reward model is then used to generate rewards for completions, and the language model is trained to maximize these rewards using reinforcement learning, i.e., $\max_{\pi(\cdot | y)}\mathbb{E}_{\pi(\cdot |y)}[\beta(\log \pi_{\theta}(Y=y | w) - \log \pi_{\phi}(Y=y | w))]$. 
* **DPO Approach**: In DPO, instead of modeling a reward, we model the preference directly. We train a preference model $\pi_\phi(y_n | w, y)$ to estimate the probability that a human would prefer completion $y_n$ over $y_n$ for any pair of completions $(y, y_n)$ sampled from the language model $P_w$. This is done by providing the preference model with pairs of completions where a human has already indicated a preference. Once the preference model is trained, we can optimize the language model to increase the probability of the preferred completion, i.e., $\pi_{\phi}(y_1 | w, y_s)$.
