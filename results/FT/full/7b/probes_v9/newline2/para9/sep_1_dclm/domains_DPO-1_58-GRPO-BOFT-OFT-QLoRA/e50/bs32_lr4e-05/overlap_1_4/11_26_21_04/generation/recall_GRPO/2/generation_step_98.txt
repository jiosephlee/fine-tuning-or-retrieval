The paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models" presents a novel and efficient method for improving mathematical capabilities in language models, Group Relative Policy Optimization (GRPO), instead of the standard memory-intensive PPO algorithm. Group Relative Policy Optimization (GRPO) is a derivative of Proximal Policy Optimization (PPO), which is a reinforcement learning (RL) algorithm that is commonly used to train large language models. The RL approach is used to further enhance the mathematical reasoning skills of DeepSeekMath-Instruct 7B, a model that has already been pre-trained on a large-scale mathematical dataset. The RL training is conducted on a benchmark dataset for mathematical reasoning, GSM8K, and a benchmark dataset for geometry, MATH. The outcomes show that GRPO is a highly effective and resource-efficient RL algorithm, and it can substantially improve the mathematical reasoning capabilities of language models.

The DeepSeekMath Corpus

The DeepSeekMath Corpus is a large-scale mathematical dataset that is constructed from Common Crawl data. The dataset is pre-processed using a fastText model to extract web pages that are relevant to mathematics. The mathematical content is then further filtered using a rule-based approach. The filtering rules are based on the following criteria:

  • The text must contain mathematical symbols.
  • The text must be in English.
  • The text should be a question or an answer.
  • The text cannot be a code snippet.
  • The text is not a mathematical equation.

After the filtering process, the dataset contains 35.5M mathematical web pages. The dataset is then split into a training set (30.0M), a validation set (1.0M), and a test set (4.5M). The statistics of the dataset are shown in Table 1.

Model Training and Evaluation

The DeepSeekMath-Instruct model is a variant of DeepSeek-Coder-Base-v1.5 7B, which is further trained on a mathematical instruction-following dataset. The training data consists of 120B tokens, with 56.9% sourced from the DeepSeekMath Corpus, 3.2% from AlgebraicStack, 3.2 % from StackExchange, 33.9% from Codeforces, and 3.2% drawn from other sources. The training is conducted using a batch size of 10M tokens and a maximum context length of 4K tokens. The training is performed using a learning rate of 2e-5, a token-level KL penalty coefficient of 0.04, and a clip gradient value of 0.2.

The model’s mathematical reasoning capabilities are evaluated using two benchmarks: GSM8K and MATH. The GSM8K benchmark is a multiple-choice dataset that covers a wide range of mathematical topics, including elementary mathematics, high school mathematics, and some undergraduate mathematics. The MATH dataset is a multiple-choice dataset focused on geometry problems. For the evaluation, we use the open-source benchmark tools provided by the respective datasets. Reinforcement Learning with GRPO

Reinforcement learning (RL) is a powerful technique that can further enhance the mathematical reasoning capabilities of large language models. In this study, we use RL to train DeepSeekMath-Instruct on the GSM8K and the MATH benchmarks. We use the Proximal Policy Optimization algorithm (PPO) as the reinforcement learning algorithm. PPO is a well-established actor-critic reinforcement learning algorithm that is commonly used in the training of large language models. However, PPO is a memory-intensive algorithm, and it is not suitable for training large language models due to the high computational cost. To address this issue, we propose a new reinforcement learning algorithm, Group Relative Policy Optimization, which is a derivative of PPO. GRPO reduces the memory consumption of PPO by removing the need for a critic network. Instead, GRPO uses a group of policies to estimate the baseline, which is a key component of PPO. The baseline is used to calculate the reward signal for each policy. The reward signal is then used to update the policy parameters. The GRPO algorithm is described in Algorithm 1.
