**Orthogonal Finetuning (OF)**

The core idea behind OFT is to maintain the pairwise angles between neurons while adapting the text-to-image diffusion model. To achieve this, OFT learns an orthogonal transformation matrix for every neuron. For a neuron $z_i$ with dimension $d$, its transformed output is given by $\hat{z}_i = \text{Roz}(z_i)W$, where $\text{Roz}(.)$ denotes the rotation operation, and $W$ is the orthogonal transformation matrix. Since rotations preserve the pairwise angles between neurons, this approach effectively maintains the semantic structure of the initial model. However, applying a single global orthogonal transformation across all neurons may not be optimal, as it could lead to suboptimal local alignments within neuron groups. To address this limitation, OFT introduces a block-diagonal structure for the orthogonal matrix $W$, where each block corresponds to a neuron cluster. Specifically, if there are $c$ neuron clusters, then $W$ is a $d \times d$ block-diagonal matrix with $c$ blocks, each of size $d \times d$. Each block is independently learned to be orthogonal, resulting in a total of $c$ independent orthogonal transformations. This design allows for more flexible adaptation while still preserving the pairwise angles among neurons within the same cluster.

To ensure that the orthogonal matrix $W$ remains close to the identity, OFT incorporates a regularization term that penalizes large singular values in $W$. Mathematically, this is expressed as $\lambda \|W\|_F^2 = \lambda (\sum_{ij} |w_{ij}|^2)^{1/2}$, where $\lambda$ is a hyperparameter controlling the strength of the regularization. By minimizing this objective, OFT encourages $W$ to stay close to the identity matrix, thereby limiting the deviation from the original pretrained weights.

**Low-rank Adversarial Finetuning (LoRA)**

LoRA is a widely adopted finetuning technique that enhances stability by constraining the update to have low rank. In LoRA, the updated parameters $\theta'$ are defined as $\theta' = \theta - \alpha \mathbf{L}$, where $\mathbf{L}$ is a low-rank matrix, and $\alpha$ is a scalar hyperparameter. The authors propose a new interpretation of LoRA by viewing it as a special case of OFT. In particular, LoRA can be seen as a specific instance of OFT when the orthogonal matrix $W'$ is chosen to be block-diagonal with only one non-zero block, corresponding to the low-rank component $\mathbf{L}$. This perspective unifies both LoRA and OFT under a common framework, allowing for seamless integration of these two approaches. Moreover, it provides a clear explanation for why LoRA is effective: it reduces the number of trainable parameters by enforcing a low-rank constraint on the updates.
