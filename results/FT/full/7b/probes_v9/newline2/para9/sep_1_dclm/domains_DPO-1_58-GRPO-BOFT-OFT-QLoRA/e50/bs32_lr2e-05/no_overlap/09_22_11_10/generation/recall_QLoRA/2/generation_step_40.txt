2.1 Quantization

Quantization is a process that involves converting a set of floating-point values into a smaller set of integer values. This process is often used to reduce the memory requirements of neural networks, as it allows for the storage of weights and activations using fewer bits. There are two main types of quantization: weight quantization and activation quantization. Weight quantization involves converting the weights of a neural network from floating-point values to integer values, while activation quantization involves converting the activations of a neural network from float to int. In this paper, we focus on weight quantization.

There are several methods for quantizing weights, including binary, ternary, and floating-point quantization. Binary quantization involves converting weights from floating-point values to either 0 or 1, while ternary quantization involves converting weights to one of three values (-1, 0, or 1). Floating-point quantization involves converting weights into a fixed number of bits, such as 4 or 8 bits. In this paper, the authors use floating-point quantization with 4-bit precision.

2.2 LoRA

LoRA, or Low-Rank Approximation, is a technique for finetuning large language models (LLMs) with minimal memory usage. This approach allows for the finetuning of models with up to 1TB of parameters on a single 16GB GPU.
