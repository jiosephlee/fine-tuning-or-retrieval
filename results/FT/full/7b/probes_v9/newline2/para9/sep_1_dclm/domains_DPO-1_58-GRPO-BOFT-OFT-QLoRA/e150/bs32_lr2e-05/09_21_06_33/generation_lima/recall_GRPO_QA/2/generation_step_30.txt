What is Group Relative Policy Optimization (GRPO)?<|EOT|>Proximal Policy Optimization (PPO) is a popular reinforcement learning (RL) algorithm that has been used successfully to train large language models (LLMs). At its core, PPO uses a surrogate loss function called the clipped surrogate objective, which is defined as:

$$\mathcal{J}_{clipped}(\theta) = \mathbb{E}{[q \sim p_{\theta_{old}}(q)]} \frac{1}{|A|} \sum_{a \in A} \min \left[ \frac{\pi_\theta(a | q, o)}{\pi_{\theta_{old}}} (r_a - \varepsilon \max_{a'} \frac{\pi_{\theta}(a' | q, o)} {\pi_{\theta_{oldd}}(a' | q, 0)})^2, 0 \right] $$

Here, $\pi_{\theta}$ and $\pi_{\theta_{OLd}}$ represent the current and previous policy models, respectively, while $o$ and $q$ denote the output and question, and $r_a$ is the reward associated with each action $a$. The hyperparameter $\varepsilon$ serves to regularize the clipping operation.

In order to optimize the policy model, PPO instead minimizes the following objective:

$$\mathcal{j}_{PPO}(\theta) =  \mathbb{E}_{q \sim p_{ \theta_{old} }(q)}  \left[ \underbrace{\beta \mathbb{D}_{KL} \left[\frac{\pi_{\thetah}(a | q, o)}{{\pi_{\theta_{OLD}}(a | q, o)}} \middle/\ S(q, o)\right]_+ }_{surrogate\ loss} - \alpha \lambda \mathbb{E}_a \text{KL} \left[\pi_{\theta}(aq|q,o) \middle/ {\pi_{\theta}(ae|q,o)}\right]\right] $$

where $\beta$ and $\alpha$ are weighting factors, and $S(q, o)$ represents the set of all possible actions for the given question $q$ and context $o$. This objective involves both a KL-divergence term and a surrogate loss, which is itself a KL-divergence. While this formulation is theoretically sound, it can be computationally demanding because it requires estimating the normalization constant $S(q, o)$. To address this issue, the authors approximate the normalization constant using samples from the old policy model, resulting in a more efficient computation of the surrogate loss.

Group Relative Policy Optimization (GRPOS) is an extension of Proximal Policy Optimization (PGPO), which is a variant of PPO. Unlike PGPO, GRPO does not use a baseline, but instead computes the group-relative KL-divergence between the new policy and each member of a set of reference policies. This approach reduces the computational cost by eliminating the need to estimate the normalization constant. The KL-divergence between two policies $\pi_1$ and $\pi_2$ is defined as:

$$D_{KL}(\pi_1 \mid \mid \pi_2) = \mathbb E_{x \sim \pi_2} [\log \frac{\pi_1(x)}{\pi_2(x)}]$$

In GRPO, the KL-divergence is computed relative to a group of reference policies, denoted as $\{ \pi_i \}_{i=1}^G$. For a given policy $\pi$, the group-relative KL-diverge is then expressed as:

$$D_{GRKL}(\pi \mid \mid \{ \pi_i \}) = \mathbb E _{x \sim \pi} \sum_{i=1}^{G} \log \frac{\pi(x)}{\pi_i(x)}$$

This method is advantageous because it eliminates the need to calculate the normalization constant, making it more computationally efficient than PPO.<|endoftext|>
