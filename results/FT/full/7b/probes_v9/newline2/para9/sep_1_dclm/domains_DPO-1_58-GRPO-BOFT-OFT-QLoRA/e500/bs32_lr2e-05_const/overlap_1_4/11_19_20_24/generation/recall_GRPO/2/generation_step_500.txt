Now, let's delve into the Group Relative Policy Optimization ( GRPO ) algorithm. At its core, GRPO is a reinforcement learning ( RL ) technique designed for training large language models (LLMs). It is derived from the Proximal Policy Optimization  ( PPO ) algorithm, which is extensively employed for LLM fine-tuning. To clarify the differences between GRPO and PLO, we will first provide an overview of PPO. PPO is a actor-critic RL algorithm that enhances the parameters of the policy model (the actor) by optimizing it based on reinforcement signals. In PPO, the reinforcement signal is generated by comparing the policy model's output distribution to a baseline, which reflects the expected performance of the policy model. Mathematically, the reinforcement signal is formulated as follows:

signal = clip( advantage - baseline , -K , K )

where advantage denotes the advantage estimate, computed as the mean reward plus the mean discounted cumulative reward under the learned model, and baseline represents the baseline value. PPO typically employs a critic network to compute the baseline by estimating the mean reward of the current policy model relative to a sampled reference model. Given the nature of LLMs, the critic network in PPO must be at least as large as the policy model, leading to substantial memory usage. Additionally, the critic network necessitates its own optimization phase, which adds complexity to the overall training workflow. To address these issues, GRPO has devised a novel approach for baseline computation in PPO. Instead of relying on a critic network, GRPO determines the baseline using a group-based strategy. This method involves sampling multiple outputs from the policy model for each input and calculating the baseline as the average of these sampled outputs. Concretely, for an input x and a policy model with parameters θ, GRPO carries out the following operations:

1. Draw multiple samples {ŷ^i} from the policy model: {ŷ^i ∼ P(y|x ; θ)}
2. Compute the group mean as the baseline: baselinesample(x) = 1 |G| ∑\_{i∈G} ŷ^i

Here, G signifies the set of indices corresponding to the drawn samples. By employing this group relative baseline, GRPO eliminates the requirement for a separate critic network, thereby substantially reducing memory usage and streamlining the training process. Notably, although the name "Group Relative Policy Optimization" suggests a group-based training paradigm, GRPO actually performs single-instance training—each input is processed only once. Nevertheless, the method remains efficient in terms of memory consumption. It is also important to address how well GRPO scales in comparison to PPO. In theory, GRPO's memory usage grows linearly with the number of sampled groups, which could potentially limit its scalability. However, our empirical observations indicate that, for practical purposes, setting the number of groups to 1 recovers the standard PPO baseline estimation, whereas increasing the number of groups only marginally impacts training outcomes and resource requirements. Therefore, GRPO demonstrates strong scalability, making it suitable for training increasingly large language models.
