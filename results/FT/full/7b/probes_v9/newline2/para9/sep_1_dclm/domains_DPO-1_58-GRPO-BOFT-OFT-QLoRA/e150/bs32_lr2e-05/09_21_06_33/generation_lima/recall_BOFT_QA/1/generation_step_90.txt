According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal butterfly (BOFT) is a parameter-efficient orthogonal matrix generation method. It is based on the butterfly structure, which is widely used in computer networks for efficient communication. The key idea of BOFT is to construct an orthogonal matrix by multiplying several sparse orthogonal matrices. These sparse orthogonal matrices are then constructed using the Cayley transform, which transforms a skew-symmetric matrix into an orthogonal matrix. The sparsity of the resulting orthogonal matrices can be achieved through butterfly factorization of a special skew-symmetric matrix.

The Cayley transform of a skew-symmetric matrix $A$ is given by:

$$\text{Cayley}(A) = \text{I} - 2\text{Re}\left(\text{exp}(iA)\right)$$

where $\text{I}$ is the identity matrix. The matrix $\text{exp}(i*A)$ can be computed efficiently using the matrix exponential formula:

$$\text{exp}(i * A) = \sum_{k=0}^{\infty} \frac{(i*A)^k}{k!}$$

In the context of BOFT, the matrix $A$ is chosen to be a block-diagonal matrix with blocks of size $d$. This leads to a sparse orthogonal matrix of size $n = d^2$, where each column of the matrix is obtained by multiplying $d$ vectors of length $d$.<|endoftext|>
