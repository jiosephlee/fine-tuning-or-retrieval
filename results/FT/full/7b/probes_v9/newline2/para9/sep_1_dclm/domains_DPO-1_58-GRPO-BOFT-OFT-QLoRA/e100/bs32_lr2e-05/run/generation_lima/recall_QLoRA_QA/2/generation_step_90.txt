**What is QLoRA?**

QLoRA (Quantized Low-rank Adapters) is a technique for reducing the memory footprint of large language model finetuning by quantizing the adapter layers in LLMs, while keeping the rest of the model in full precision. This approach achieves results comparable to full 16-bit finetuned models, while only requiring 4-bit precision training.

The key idea behind QLoRA is that the parameter inefficiency of modern LLMs comes from their use of many dense, low-rank adapters, each with its own full set of parameters. By quantizing these low-rank adapter parameters, QLoRA can achieve significant memory savings without sacrificing performance.

Here are the main points about QLoRA:

* QLoRA is a method that allows you to train 4-bit LLMs that perform similarly to 16-bit trained models.
* QLoRA works by quantizing the low-rank adapter layers in a model to 4-bit precision, while keeping the rest (the inputs and the rest of the network) at 16-bit precision.
