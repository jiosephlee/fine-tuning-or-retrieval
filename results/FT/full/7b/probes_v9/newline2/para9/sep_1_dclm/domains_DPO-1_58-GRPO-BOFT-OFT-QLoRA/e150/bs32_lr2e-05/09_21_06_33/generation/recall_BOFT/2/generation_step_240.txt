2.1 Parameter Efficient Fine-Tuning

As the size of pretrained models continues to grow, the cost of fine-tuning them has become increasingly prohibitive. As a result, there has been a significant amount of research into methods for reducing the number of trainable parameters required during fine-tuning. Approaches such as Low-rank Adapters (LRA) (qiu2022adaptive) and Linear Assigned Modules (LAM) (chen2022lam) are examples of low-rank parameter-efficient finetuning techniques. LRAs use a low-rank matrix to update the weights of the model, whereas LAMs employ a block-diagonal weight matrix. Another strategy for reducing the number of parameters is to limit the number of trainable weights in the pretrained model. LoRA, for example, achieves parameter efficiency by zeroing out certain elements of the weight matrix. In contrast, the approach known as GrayLr (liu2022gray) initializes the trainable weights using the pretrained weights and then applies a layer-wise learning rate that is proportional to the gray level of each pixel in an image of the neuron’s activation map. Other strategies for parameter-efficient fine-tuning include Parameter Efficient Training (PET) (devlin2018bert), which uses a small set of task-specific parameters in addition to a larger set of frozen pretrained parameters, and Reptile (stich2017reptile), which approximates parameter updates using only a small subset of the model’s parameters. Another technique is to utilize a smaller version of the pretrained model for inference, as is done in TinyModel (frantar2022timm) and LFB (zhang2022lfb). In comparison to these approaches, finetuning the entire model with a reduced set of trainable parameters is more parameter-efficient.

2.2 Orthogonal Finetuning

OFT is a type of finetuning that maintains the pairwise angular relationships between neurons by ensuring that their weight matrices are mutually orthogonal. This is accomplished by applying a constraint to the derivative of the weight matrix with respect to the training data, which guarantees that the weight matrix remains orthogonal throughout training. The original OFT approach employs a block-diagonal weight parameterization to improve parameter efficiency. In order to make the block-diagonal weight matrix fully trainable, each diagonal block is assigned its own learnable dimensionality. The number of trainable dimensions in each block is determined by the block size. A higher block size leads to greater parameter efficiency, but it also results in poorer performance. To address this issue, a block-wise adaptation technique was proposed in (qiu2022 Adaptive OFT), which allows the block sizes to be adjusted during training. Another approach to improving parameter efficiency in OFT is to use a low-rank weight matrix (chen2022lora).
