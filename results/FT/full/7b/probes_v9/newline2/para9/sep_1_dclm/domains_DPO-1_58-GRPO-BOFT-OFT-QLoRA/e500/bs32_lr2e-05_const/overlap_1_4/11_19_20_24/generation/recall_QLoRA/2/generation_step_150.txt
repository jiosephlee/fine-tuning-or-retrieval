* **Bit-Depth**: When representing weights in neural networks, the weight values are typically stored using a fixed number of bits. Common bit-depths include 16 bits and 32 bits. Using fewer bits can save memory, but it also introduces quantization errors.
* **Low-rank Adapters (LoRA)**: LoRA is a technique for finetuning large pretrained models by adding a small number of trainable parameters called adapters. This approach is more memory-efficient than directly finetuning all the weights in the model.
* **Memory Requirement for Finetuning**: The memory needed for finetuning a model is determined by the size of the input mini-batch and the amount of weight data that must be stored in memory for computation.
