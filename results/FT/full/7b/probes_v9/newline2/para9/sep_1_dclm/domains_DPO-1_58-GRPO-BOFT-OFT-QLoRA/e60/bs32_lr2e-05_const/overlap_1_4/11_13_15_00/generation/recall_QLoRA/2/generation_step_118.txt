The paper "QLoRA: Efficient Finetuning of Quantized LLMs" presents a novel and efficient method for training large models, QLoRA, which drastically reduces memory usage compared to standard 16-bit finetuning. QLoRA is a technique that allows you to finetune a 7B parameter model on a single 48GB GPU while only using 3-bit precision for the weights. This is a significant improvement over the previous best method, LoRA, which required 4-bit weights to achieve comparable results.

The paper's authors are a group of researchers from OpenAI, Google, and the University of Washington. The paper was presented at the NeurIPS 2022 conference.

What is the issue?

Finetuning large language models (LLMs) is becoming increasingly popular. However, the cost of training these models is prohibitively high. As a result, the majority of LLMs are not finetuned. Finetuning a 70B parameter model on a 48GB GPU, for example, would take around 500 days.

The most effective strategy to reduce the cost of finetuning is to reduce the amount of memory required. LoRA is a technique that reduces memory usage by quantizing the weights. LoRA, on the other hand, is not memory efficient enough to allow for the finetuning of very large models on a single GPU.

How does QLoRA work?

The fundamental idea behind QLoRA is to use a small set of weights that are not quantized, known as the pivot weights, to represent a block of quantized weights. The weights are divided into blocks, and each block is quantized using 3-bit weights. The weights in each block are then multiplied by the pivot weights to restore the original values.

Pivot Weights

The pivot weights are a set of 8 32-bit weights that are used to restore the precision of the quantized weights. The most memory-efficient approach to generate the pivot weights is to use the original weights as the pivot weights. This method, however, is not effective. Because the weights are not randomly initialized, the same weights are used to restore the same blocks of quantized weights. As a result, there is no information gain, and the model does not learn.

To address this issue, the paper proposes a method for randomly initializing the pivot weights. The weights are initialized using a normal distribution with a mean of 0 and a standard deviation of 0.1. The weights are then normalized so that the sum of the weights in each block is 1. This method ensures that the pivot weights are randomly initialized and that the weights in each block are evenly distributed.
