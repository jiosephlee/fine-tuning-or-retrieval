What is Orthogonal Finetuning (OFT)?<|EOT|>Orthogonal Finetuning (or OFT) is a method for finetuning pretrained models that preserves the geometry of the pretrained weights. This is achieved by applying an orthogonal transformation to the pretrained weights, which is equivalent to multiplying the weights by an orthogonal matrix. The orthogonal transformation is applied to all neurons in a layer, and the same orthogonal matrix is used for all neurons in the layer. This ensures that the relative angles between neurons are preserved, which is important for maintaining the semantic meaning of the neurons.

OFT is similar to Layer-wise Relevance Propagation (LoRA), which also uses an orthogonal transformation to finetune pretrained models. However, OFT differs from LoRA in that it applies the orthogonal transformation to all neurons in a given layer, rather than to each neuron individually. This makes OFT more computationally efficient than LoRA, since it avoids the need to compute the relevance scores for each neuron.

OFT can be seen as a generalization of the standard finetuning approach, where the orthogonal matrix is set to the identity matrix. In this case, OFT reduces to the standard finetuning, where the weights are simply updated by adding a small multiple of the gradient of the loss with respect to the weights.
