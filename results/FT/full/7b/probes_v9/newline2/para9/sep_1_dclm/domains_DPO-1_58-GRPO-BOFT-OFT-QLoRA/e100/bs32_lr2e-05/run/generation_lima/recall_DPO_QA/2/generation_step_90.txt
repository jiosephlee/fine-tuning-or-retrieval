What is DPO?<|EOT|>Direct Preference Optimization (DPO; Daumé III & Bach, 2015; is a method for training language models to satisfy user preferences directly, without the need for an explicit reward model or reinforcement learning. The key idea is to use a pairwise comparison of samples from the model and a reference prompt as a signal for model training. This approach is conceptually simple, computationally efficient, and does not require any additional parameters.

In DPO, the objective function is defined as:

$$\mathcal{J}(\theta) = \mathbb{E}_{(x, y_w, y_l)\sim \mathcal{D}}\left[\log \sigma \left(\frac{\pi_{\theta}(y_w \mid x)}{\pi_{\theta }(y_l \mid x)}\right)\right]$$

where $\pi_\theta$ is the language model, and the dataset $\mathcal{D}$ consists of input-output pairs $(x, y_w, x, y_l)$. The main assumption behind this framework is that the preference data is generated by a latent reward model $r(x, y)$, such that $p(y_w \mid x, r(x, y_l) > r(x, y_l)) = p(y_l \mid x, r(r(x, y_l) \leq r(x, y_w)) = 1$.

In practice, the dataset $\mathcal{T}$ is constructed using human annotations of the form $(x, y_w)$, and a large corpus $\mathcal{C}$ of inputs and random samples $y_l \sim \pi_\theta$. The human preferences are then used to rank the outputs $y_w$ against the model's outputs $y_l \in \mathcal{C}$. The authors use a similar construction for the human preference dataset in the experiments, but note that the method is general and can be applied to other preference datasets as well.

This objective can be optimized efficiently using reparameterization tricks, and it has been shown to achieve performance comparable to RLHF methods.<|endoftext|>
