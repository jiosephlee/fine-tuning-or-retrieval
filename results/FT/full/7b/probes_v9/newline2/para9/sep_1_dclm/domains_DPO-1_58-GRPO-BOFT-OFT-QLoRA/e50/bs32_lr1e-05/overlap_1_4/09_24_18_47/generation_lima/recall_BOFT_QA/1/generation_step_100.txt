According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT) is a method for parameter-efficient orthogonal finetuning. It is a generalization of the Orthogonal Procrustes problem, which is a special case of BOFT with a block-diagonal matrix $Q$.

The Orthogonal Procrustus problem is defined as follows:

$$\min_{\mathbf{R}} \|\mathbf{R}\|_F^2 \quad \text{s.t.} \quad \mathbf{R}^\top \mathbf{R}\mathbf{Q} = \mathbf{I},$$

where $\mathbf{R}$ is an orthogonal matrix, $\mathbf{Q}$ is a symmetric matrix, and $\|\cdot\|_F$ denotes the Frobenius norm. The solution to this problem is given by

$$\mathbf{R} = \mathbf{T}^\top \mathcal{O}(\mathbf{Q}),$$

where $\mathcal{O}()$ denotes the orthogonal matrix that diagonalizes $\mathbf{Q}$. The matrix $\mathbf{T}$ is the solution to the following Sylvester equation:

$$\mathbf{T}^\ast \mathbf{Q} \mathbf{T} - \mathbf{R}_0 = \mathbf{0},$$

where $\ast$ denotes the conjugate transpose and $\mathbf{R}_\mathbf{0}$ is a given symmetric matrix. The matrix $\mathbf{R}(\mathbf{R}_1, \mathbf{R_0})$ is the unique solution to the above equation.

BOFT generalizes the Orthogonal Procrastus problem by allowing the matrix $\mathbf{Q$ to be block-diagonal:

$$\min_{(\mathbf{R}, \mathbf{Q})} \|\mathbf{Q}\|_F^{\frac{1}{2}} \|\mathbf{T}\|_F^4 + \|\mathbf{I} - \mathbf{T} \mathbf{R Q} \mathbf{T}\|_\infty^2 \quad \mathrm{s.t.} \mathbf{Q}\mathbf{R}=\mathbf{R}\boldsymbol{\Lambda},$$

where $\boldsymbol{\Lambda}$ is a diagonal matrix. The solution to this optimization problem is given by

$$(\mathbf{R},\mathbf{Q}) = (\mathbf{T}^\mathrm{T}\mathbf{R}_2\mathbf{R}_3\mathbf{T}, \mathbf{R}_{2}\mathbf{R}_{3}\mathbf{R}\mathrm{T}^\mathrm{T}),$$

where $\mathrm{R}_2$ and $\mathrm{R}_3$ are the solutions to the following Sylvester equations:

$$\mathrm{T}^\ast \mathrm{R}_2 \mathbf{Q}_2 \mathrm{T} - \mathbb{I} = \mathbf0,$$

$$\mathrm{T} \mathrm{R}_3 \mathbf{Q_3} \mathrm{T}^\ast - \mathbb{R}_0 = 0,$$

where $\mathbf{Q}_i$ is the $i$-th block of $\mathbf{Q$. The matrix $\mathbb{R}(\mathbb{R}_1, ..., \mathbb{R}_{n}, \mathbb{R_0}) is the unique solution to these equations.

BOFT can be used for parameter-efficient orthogonal finituning by setting $\mathbf{Q = \mathbf{W}^\top \mathbb{W}$, where $\mathbb{W$ is the pretrained weight matrix. The matrix $\mathrm{R}$ is then the orthogonal matrix that diagonalises $\mathbb{W}^\top\mathbb{W$.<|endoftext|>
