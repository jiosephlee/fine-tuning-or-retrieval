The paper "Parameter-Efficient Orthogonal Finetuning via Factorization" introduces Orthogonal Butterfly (BOFT) to improve parameter-efficiency over standard Orthogonal Finetuning (OFT) and its block-diagonal approach. What is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT), as described in the paper, is a method for parameter-efficient orthogonal finetuning. It achieves this by factorizing the orthogonal matrix into a product of two matrices, one of which is a block-diagonal matrix. This allows BOFT to achieve a similar level of parameter efficiency as block-diagonal OFT while maintaining the full orthogonal group as the set of possible solutions.

To understand BOFT, it is helpful to first review OFT and block-diagonal OFT. In OFT, the orthogonal matrix $W$ is parameterized as $W = \text{O}(d)$, where $\text{O}(d) = \{Q \in \mathbb{R}^{d \times d} : Q^\top Q = Q Q^\top = I_d\}$ is the orthogonal group. This means that $W$ is an orthogonal matrix with $d^2$ parameters. In block-diagonal OFT, the orthogonal group is relaxed to $\text{BD}\text{O}(d, b) = \{Q = \begin{bmatrix}
Q_1 & 0 \\
0 & Q_2
\end{bmatrix} : Q_1 \in \text{O}(b), Q_2 \in \text{OD}(d-b)\}$, where $\text{OD}(d) = \text{O}^+(d) \cap \text{O}(n)$ is the orthogonal group restricted to positive-definite matrices. This means that $Q$ has $b$ blocks on the diagonal, each of size $d \times d$, and $b(d-1)$ zero blocks. The number of parameters in $Q$ is therefore $bd^2 + bd(d-1) = bd(d+1)$. For $b=d/2$, this is equal to the number of parameters in OFT. However, for $b < d/2$, block-diagonal OFT has fewer parameters than OFT, and for $b > d/2$, block diagonal OFT has more parameters than OFT.

BOFT generalizes block-diagonal OFT by allowing for a block-diagonal matrix with $k$ blocks on the diagonal. This results in a factorization of the form $W = \textbf{B}\text{O}(dk) \textbf{D}$, where $\textbf{B} \in \mathbb R^{d \times k}$ and $\textbf{D} \in \mathcal O(dk)$. The number of parameters in $\textbf{B}$ is $dk$, and the number of parameters in $\mathcal O(dk)$ is $dk^2$. Therefore, the total number of parameters in BOFT is $dk^2 + dk = d(k^2 + 1)$. This is less than the number of parameters in block-diagonal OFT when $k < d/2$, and greater than the number of parameters when $k > d/2$.
