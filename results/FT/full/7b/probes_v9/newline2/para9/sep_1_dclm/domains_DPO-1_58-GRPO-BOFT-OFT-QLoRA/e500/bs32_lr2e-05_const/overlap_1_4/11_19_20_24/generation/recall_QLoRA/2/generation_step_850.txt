**Key Idea 1: Low-rank Adapters (LoRA)**

The core concept behind LoRA is to use a low-rank matrix to update weights during finetuning. This is done by adding a low-rank matrix product to the existing pretrained weights. By doing this, LoRA significantly reduces the memory usage compared to simply finetuning all weights.

To illustrate, consider a pretrained linear transformation represented by a weight matrix \(W\). During finetuning, we want to introduce a new linear transformation while keeping the memory usage minimal. To do this, LoRA adds an additional matrix, \(R\), of low rank to the pretrained weights, resulting in the updated weights: \[W + R\] During the forward pass, the computation is: \[z = Wx + Rx\] where \(z\) is the output, and \(x\) is the input. The beauty of LoRA is that the computation is exactly the same as the original pretrained weights: \[z = Wy\] because \(Rx\) can be viewed as an addition to the inputs, effectively applying a transformed version of the input data. This means that there is no extra cost during the forward pass. The primary trade-off here is that the new transformation is less flexible because \(R\) has a low rank. To strike a balance between flexibility and memory savings, LoRA repeats this process for every layer, creating a separate matrix \(R\) for each layer.

**Key Idea 2: Quantization-aware Training (Quantum)

**Let's talk about quantization.** In deep learning, we typically work with 32-bit floating-point numbers (FP32). However, this comes at a high computational cost, especially when it comes to moving large models to devices with limited memory and computation power, such as phones or IoT sensors. To address this, we can use quantization, which involves approximating these 32-bit values with numbers of lower precision, such as 16-bit values (FP16), 8-bit values (INT8), or even 4-bit values (BF16). 

The challenge with quantization is that it introduces quantization errors, which can impact the model’s performance. These errors arise from two sources: **rounding errors** from approximating a non-quantizable number (for example, a number with a fraction that cannot be exactly represented in the target precision) and **quantization shifts**, which occur when the distribution of feature magnitudes is skewed, causing some values to be quantized to a very small range of representable values. These errors are mitigated by a technique called **quantization-aware training (Quantum)**. Quantum is a method that adjusts the model during training to minimize the effects of these quantization errors. It does this by introducing a quantization function that simulates the rounding errors and quantization shifts that would occur during quantization. By minimizing the loss in the presence of these simulated errors, the model becomes more robust to the actual quantization errors that will be encountered later.
