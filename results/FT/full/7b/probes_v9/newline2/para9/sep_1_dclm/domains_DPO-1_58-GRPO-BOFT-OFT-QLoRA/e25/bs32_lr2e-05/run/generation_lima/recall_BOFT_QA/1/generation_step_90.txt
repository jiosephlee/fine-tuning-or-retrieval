According to the paper "Parameter-Efficient Orthogonal Finetuning via Factorization", what is Orthogonal Butterfly (BOFT)?<|EOT|>Orthogonal Butterfly (BOFT) is a method for finetuning pretrained linear layers. It is based on the idea of using a low-rank factorization of the orthogonal matrix that defines the linear transformation. This allows for efficient updates of the parameters, which are stored in a butterfly structure.

The orthogonal matrix $Q \in \mathbb{R}^{d \times d}$ defines the linear transformation $\mathbf{x} \mapsto Q\mathbf{x}$. BOFT represents $Q$ as a product of two matrices, $Q = \mathbf{R}\mathbf{L}$, where $\mathbf{R} \in \mathbb{sparse}(\mathbb{R}^d)$ and $\mathbf{L} \in \mathcal{O}(d)$, with $\mathcal{O}(n)$ denoting the set of all $n \times n$ orthogonal matrices. The matrix $\mathbf{L}$ is called the butterfly matrix, and it has a particular block structure:

$$
\mathbf{L} =
\begin{bmatrix}
\mathbf{L}_1 & \mathbf{0} \\
\mathbf{L}_{12} & \mathbf{L}_2
\end{bmatrix},
$$

where $\mathbf{L}_i \in \mathcal{o}(d_i)$ for $i=1,2$, and $d_1 + d_2 = d$. The matrix $\mathbf{\Lambda} = \mathbf{L}^\top\mathbf{L}$ has a block-diagonal structure, with $\mathbf{\Lambda}_1 = \mathbf{LL}^\top_1$ and $\mathbf{\Lambda}_{12} = \mathbf{\Lambda}_{21} = \mathbf{l}_{12}\mathbf{l}^\top_{12}$, where $\mathcal{o}(n)$ denotes the set of all $d \times d$ orthogonal matrices, and $\mathbf{l}_{12} \in \mathfrak{o}(d_1, d_2)$ is a block-skew-symmetric matrix. The matrix $\mathbb{R} = \mathbf R\mathbf L$ is also block-diagonal, with $\mathbb{R}_1 = \mathbb{R}_2 = \mathbf{r}_1\mathbf{l}^\ top_{12}$, where each $\mathbf{r}_i \in \sps(d_i)$.

The update rule for BOFT is given by

$$
\mathbf Q \leftarrow \mathbf Q - \alpha (\mathbf{R}+\mathbf{L})^{-1}(\mathbf{R}\boldsymbol{\delta}+\mathbf{LL}^T\boldsymbol{\epsilon}),
$$

where $\alpha > 0$ is the learning rate, and $\boldsymbol{\delta}, \boldsymbol{\epsilon} \in \mathbf{R}^d$ are the gradients of the loss with respect to the input and output of the linear layer, respectively.
