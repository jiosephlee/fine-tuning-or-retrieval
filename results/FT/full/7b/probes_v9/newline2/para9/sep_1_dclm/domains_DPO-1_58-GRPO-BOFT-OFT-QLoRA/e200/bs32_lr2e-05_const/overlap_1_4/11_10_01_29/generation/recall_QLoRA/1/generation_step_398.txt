What is Quantization?

Quantization is the process of converting data from a higher precision to a lower precision. This is done by rounding the data to the nearest value that can be represented in the lower precision. For example, converting a 32-bit floating point number to an 8-bit integer.

Why do we Quantize?

We quantize because it saves memory and computation time. A 32-bit floating point (FP32) number takes up 4 bytes of memory, while an 8-bit integer (INT8) only takes up 1 byte. This means that we can store 4 times as many numbers in the same amount of memory if we use INT8 instead of FP32.

Computation time is also reduced because INT8 operations are faster than FP32 operations. This is because INT8 operations can be performed using integer arithmetic, which is much faster than floating point arithmetic.
