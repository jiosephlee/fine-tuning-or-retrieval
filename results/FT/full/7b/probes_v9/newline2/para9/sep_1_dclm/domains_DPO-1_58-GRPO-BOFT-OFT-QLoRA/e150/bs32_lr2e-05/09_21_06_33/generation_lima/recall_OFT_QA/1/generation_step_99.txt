It is based on the observation that the pretrained diffusion model can be viewed as a transformation from latent space $z$ to image space $\mathbf{X}$, which can be written as $\mathbf{X} = \mathbf{D}(\mathbf{z})$, where $\mathbf{D}$ is the pretrained diffusion model. OFT learns a new transformation $\mathbf{X}_{\text{new}} = \mathbf{R}\mathbf{D} (\mathbf{z})$ with $\mathbf{R}$ being an orthogonal transformation. This is achieved by enforcing $\mathbf{R}^T\mathbf{R} = \mathbf {I}$ during training. The advantage of using orthogonal transformation is that it preserves the pairwise angular distance between data points, thus maintaining the semantic structure of the pretrained diffusion model. 

To finetune the text-to-image diffusion model for text-guided image synthesis, we can combine the input text token sequence $\mathbf{t}$ with the latent code $\mathbf{z}$ in latent space as $\mathbf{z} = \mathbf{T}(\mathbf{t})$, and then apply the OFT to get the finetuned model $\mathbf{X}_\text{new} = \mathbf D(\mathbf{T}(\ mathbf t)) = \mathbf{ D}( \mathbf{R} \mathbf{D}( \mathbf{z} ) )$.<|endoftext|>
