**What is QLoRA?**

QLoRA (Quantized Low-rank Adapters) is a technique for reducing the memory footprint of large language models (LLMs), particularly during finetuning, without sacrificing performance. The fundamental idea behind QLoRA is to quantize only the adapter layers present in Transformer blocks, rather than the entire model. This is possible because the weights of the pretrained LLM are not affected by finetuning, so they can be shared across processes and only the updates to these weights (the adapters) need to be stored.

To reduce the memory consumption, the adapter matrices are quantized to low-bit precision (e.g. 4 bits). To compensate for the quantization error introduced by this step, the method uses low-rank properties to estimate the value at each tensor coordinate. By combining both techniques, the overall memory requirement is significantly reduced.

In summary, QLoRA works by:

1. Quantizing the pretrained model to a low-precision storage format (e.g. 16-bit -> 4-bit).
2. Representing the trainable per-token adapters with a small number of bits (e.g. 128-bit -> 16-bit).
3. Employing low-rank properties to further decrease the memory usage of the quantized adapters.

This approach has been shown to achieve significant reductions in memory usage (up to 8x) while maintaining performance comparable to full 16-bit finetunings.<|endoftext|>
