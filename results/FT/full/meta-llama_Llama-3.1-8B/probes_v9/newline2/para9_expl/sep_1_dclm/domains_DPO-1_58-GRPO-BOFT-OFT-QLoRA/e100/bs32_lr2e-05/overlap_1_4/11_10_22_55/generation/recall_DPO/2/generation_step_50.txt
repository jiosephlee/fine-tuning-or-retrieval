# 2. Reinforcement Learning from Human Feedback

Reinforcement Learning from Human Feedback (RLHF) is a technique for training language models to produce text that aligns with human values and preferences. The standard RLHF workflow consists of three main stages: (1) collecting human preference data, (2) fitting a reward model to the data, and (3) fine-tuning the language model using reinforcement learning with the learned reward model. In the following subsections, we provide a more detailed description of each stage.

## 2.1 Data Collection

The first step in the RLHF process is to collect human preference data. This is typically done by prompting the language model with a given context $c$ and asking humans to select between two candidate responses $y_1$ and $y_2$. The resulting dataset of preference pairs $\mathcal{D} = \{c^{(i)}, y_w^{(i)}, y_l^{(i)}\}_{i=1}^N$ is used to fit a reward model, where $y_w$ denotes the preferred completion and $y_l$ the dispreferred one. To ensure diversity in the collected data, it is common practice to sample multiple candidate responses for each context, often using nucleus sampling with $p=0.9$ and a temperature of $0.7$.

## 2.2 Reward Modeling

Given the preference dataset $\mathcal{D}$, the goal is to learn a reward function $r(y\mid c)$ that assigns higher scores to preferred completions than to dispreferred ones. A straightforward approach is to parameterize the reward function as a neural network and optimize its parameters by maximizing the likelihood of the observed preferences. Formally, we define the reward model as $r_{\phi}(y\mid c)$, where $\phi$ represents the model parameters. The objective function is then given by:

\[
\mathcal{L}_R(r_{\phi}; \mathcal{D}) = -\mathbb{E}_{(c,y_w,y_l)\sim\mathcal{D}}\left[\log \sigma\left(r_{\phi}(y_w\mid c) - r_{\phi}(y_l\mid c)\right)\right],
\]

where $\sigma$ denotes the logistic sigmoid. In practice, it is common to initialize the reward model with a pre-trained language model, thereby leveraging the knowledge already present in the language model to improve the efficiency of reward learning.
