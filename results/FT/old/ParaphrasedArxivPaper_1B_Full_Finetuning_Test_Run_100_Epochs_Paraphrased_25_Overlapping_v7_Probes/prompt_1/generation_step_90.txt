The paper introduces a new method for training language models, called Direct Preference Optimization (DPO). DPO is based on the idea that we can represent the preferences of a human annotator as a reward function, and then train the language model to maximize this reward function. This is a very powerful idea, because it allows us to use the same optimization algorithm that is used for reinforcement learning, but with a different objective. In this post, I will explain how DPO works, and why it is able to produce better results than traditional methods like PPO.

At its core, reinforcement learning aims to solve the following problem: given an agent in an environment, and a set of actions available to the agent, how should the agent's policy be adjusted so that it maximizes some notion of cumulative reward? The standard approach to solving this problem is through the use of an optimal policy, which is defined as the policy that maximizes the expected return, or the sum of rewards over all possible states:

\begin{equation} \pi_{\theta}(s) = \frac{1}{Z(\theta)}\exp\left(\frac{1}{\theta^T s}\right) \end{equation}

Here, $s$ represents the state of the environment, $\theta$ is the parameter vector that defines the policy, and $Z(\theta)$ is a normalization factor that depends on the partition function, which is calculated using the Bellman equation:

\begin{equion} \label{eq:bellman} Z(\theta) = \sum_{s} \pi_{\thetas}(s) \exp\left(\frac 1{\theta^T s}\ right) \end{equion}

\begin{equiion} \label{equ:optimum} \pi_{\hat{\theta}}(s) = \frac 1 Z(\hat{\theta}) \exp\left(\hat{\theta}^T s\right) \end{eion}
