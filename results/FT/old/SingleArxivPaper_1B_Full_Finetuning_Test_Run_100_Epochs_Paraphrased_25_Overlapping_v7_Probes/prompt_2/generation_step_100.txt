The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a new family of algorithms for the problem of optimizing a language model with a direct reward from human preferences, under a generalization assumption on the reward model. Our algorithms are provably consistent, in the sense that they always produce a model with a strictly increasing reward function, and have low expected running time. We also present an empirical evaluation of several different algorithms, which shows that our direct preference optimization algorithms perform similarly or better than existing methods based on reinforcement learning from human preferences, while being simpler and more efficient.
We implement our algorithms as part of the Pythia language platform, an open-source toolkit for building scalable conversational AI systems.

Introduction
Machine learning models are often trained to maximize a reward function, which reflects the human preference for certain downstream tasks or quality of generated text. However, the reward function used to train the model is typically not known to the learner, and must be inferred from human preferences collected via crowdsourcing. This procedure is known as reward modeling. While existing methods for reward modeling use reinforcement learning algorithms, we consider a special case of reward modeling where the reward function is assumed to be a function of only the language model parameters, and not the history of the generation process. This setting is known as preference learning, and it is motivated by the fact that humans often express preferences about a piece of text using a language model rather than a reinforcement learning policy. In this paper, we study the problem of learning a language model with a given reward function, also known as preference learning or direct preference optimization (DPO).
The problem of DPO has several applications. One area of interest is conversational AI, where a language model is used to generate responses to user queries in order to provide assistance to users. In this setting, the reward function reflects the human preference for quality of the generated text, as well as the efficiency of the response generation process. Another application of DPO is in machine translation, where the reward function reflects the preference for high-quality translations, while also accounting for the computational cost of translation. In this setting, DPO can be used to efficiently select between multiple translation candidates, without the need for a human to review each candidate translation.
Existing methods for DPO can be broadly divided into two categories: methods based on reinforcement learning, and methods based on optimization. Methods based on reinforcement learning learn a reward function from human preferences using reinforcement learning algorithms, such as PPO or DDPG. These methods are generally more efficient than methods based on optimization, but they require access to a large number of human preferences, which may not always be available. In this paper, our goal is to develop an efficient method for DPO based on optimization. Our main contribution is a new class of algorithms for the DPO problem, which we call preference optimization algorithms (POAlgs). POAlgs are based on the principle that a reward function that is too high can be reduced by a small change to the model, while a reward function that is excessively low can be increased by a larger change. POAlgs therefore optimize a function that is guaranteed to increase, rather than decrease, and thus produce a model with a higher reward function. We theoretically analyze POAlgs, showing that they are consistent and have low expected running-time. We also evaluate several different POAlgs in the context of a real-world conversational AI application, and find that POAlgs are generally as effective as methods based on reinforcement learning.
2 Related Work

Reward Modeling
Many existing methods for reward modeling start with a language model that is learned from a dataset of human preferences, in order to produce a model with better human preferences. These methods can generally be divided into two categories: models that assume a static reward function, and models that learn a reward function that is estimated at run-time from a dataset of human judgments. Static reward models are typically learned using reinforcement learning algorithms, while runtime reward models typically use methods from optimization, such as gradient-based optimization or evolutionary algorithms. Static reward models include models such as PPO and its variants, as well as models such as CLIP and its variants, which are learned using image captioning frameworks. Runtime reward models include models such the Reward Learning from Experience (RLFE) framework (Wu et al., 2022), which learns a reward function using reinforcement learning from human preferences collected using the Experience-Driven Reward Optimization (EDRO) framework (Bai et al., 2023), and the Language Model Optimized Reward (LMORI) framework (Ott et al., 2024). A survey of reward modeling methods is given in (Korbak and Schwenk, 2023).
