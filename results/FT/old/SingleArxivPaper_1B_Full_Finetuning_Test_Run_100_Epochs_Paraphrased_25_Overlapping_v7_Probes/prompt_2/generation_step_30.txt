The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a new algorithm for optimizing the reward function used by DPO, the Direct Preference Optimization (DPO) algorithm. DPO uses a gradient-based optimization algorithm to find the parameters of a language model that maximize the reward function, but it requires the reward function to be differentiable, which is not always the case. In contrast, our method allows the reward function to be any differentiable function of the language model parameters, including those that are computationally expensive to optimize, such as neural networks. Our method is based on the observation that the gradient of the reward function with respect to the parameters can be expressed as the negative of the gradient of the logarithm of the reward function with the same derivative. We show that the gradient of the logarithmic reward function with respect to its derivative is zero, and therefore the gradient of the reward with respect to the parameters is the negative of the gradient with respect to the derivative. We call this new relationship the "gradient swap lemma," and it enables us to transform the optimization problem for the reward function into a standard unconstrained optimization problem, which can be solved using off-the-shelf algorithms such as gradient descent. Our experiments show that our method can improve the performance of language models on downstream preference estimation tasks, while being orders of magnitude faster than existing methods that optimize the reward function directly.
