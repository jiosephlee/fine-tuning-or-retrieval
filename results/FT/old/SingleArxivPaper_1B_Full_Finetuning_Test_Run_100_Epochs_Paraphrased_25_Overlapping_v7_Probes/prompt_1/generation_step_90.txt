After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the use of any reward function, not just RL rewards. In contrast to RL, DPO does not require the reward function to be known in advance. Instead, DPO uses an implicit reward signal that is extracted from the data using a language model. This reward signal is used to train a policy, which produces an optimal language model. The policy is optimized using an off-policy reinforcement learning algorithm, which takes advantage of the uncertainty in the reward function to prevent overfitting. With the help of a special language model, the reward function can be estimated from the data without requiring access to an explicit reward function.

The basic idea of DPO is simple: instead of optimizing the language model directly, we first optimize a proxy model that we call the preference model (PM). The PM represents the user's preferred distribution over language sequences, and we want to optimize it to match the data as well as possible. The language model is then optimized to minimize the difference between the data and the preferred distribution estimated from the language model. That is, we have the objective:

$$\max_{\pi} \mathbb{E}_{x \sim \pi(D)|Y=x} \bigg[\underbrace{r(x, y) - \mathbb{E}_y[y^* | x] for some reward function }_{\text{actual reward}} - \underbrace{\mathbb{E}_{y \sim \pi}[\reward(y, y*)]}_{\text{desired reward}}\bigg] \underbrace{d(y, y*)}_\text{distance between y and y*}\tag{1}$$

Here $\pi$ is the policy to produce language sequences from templates $y$, $D$ is the dataset of pairs $(x, y)$ where $x$ is a template and $y$ is a sequence of texts, $r$ is the actual reward function (e.g. the ground truth reward for a machine translation task), $y*$ is the optimal template $y$ for the reward function $r$, $\mathbb{E}_{\pi}[y^* | x]$ is the estimated reward from the language model $y$ for the template $x$, and $\mathbb{E}_\pi[y]$ is the expected reward from the distribution $\pi$.

In the context of LMs, the PM is the language model, the actual reward is the user's reward for reading a sequence of texts, the optimal template $y^*$ is the best possible language model for the given reward function, and the desired reward is the optimal machine translation (or other task-specific) model for the given reward. The difference between the actual and desired reward functions is the implicit reward function $\mathcal{R}(y, y^*)$ that the language model tries to match. The DPO objective (1) is to optimize the language model to match the data as closely as possible with the given implicit reward function, all while maximizing the probability of producing the target template $y*$.

The DPO algorithm

The DPO algorithm is based on the chain rule of probability and the Markov property of the language model. It consists of three main steps: 1) sampling from the policy $\pi$, 2) computing the implicit reward function $\cal{R}$, and 3) optimizing the language model to minimize $\cal{R}$ while maximizing the probability of the target template. The full algorithm is as follows:

  1. Sample $y_1 \sim \pi$
  2. Compute $y_2 = \mathbb{E}\_{y\sim \pi}\left[\cal{R}(y,y^*)\right]$
  3. Sample $y_3 \sim \pi$
    
  4. If $y_2 \neq y_1$ then go to step 2
  5. If $y_3 \neq y_2$ then go to step2
  6. Optimize $\pi$ to minimize $\mathbb{E}\_y[\cal{R}(x, y) - \cal{R}(x,y^*)]$ (Nash-Bber)

The algorithm terminates when the change in the distribution is small enough, typically after a certain number of steps.

The key insight of the DPO algorithm is that the language model can be optimized to match the data as efficiently as possible with the given reward function, all while trying to maximize the probability of the target sequence $y^*$, rather than the traditional RL approach of maximizing the expected reward $r(y, y^*)$. This is a major improvement over RL, which must explicitly maximize the reward in order to learn the highest reward template, which may not be the best for the given task.
