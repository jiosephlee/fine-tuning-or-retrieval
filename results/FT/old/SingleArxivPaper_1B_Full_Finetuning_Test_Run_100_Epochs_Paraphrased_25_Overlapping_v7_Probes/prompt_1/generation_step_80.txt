After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the optimization of arbitrary functions from rewards to policies. In contrast to RL, DPO does not require sampling from the reward function to evaluate the quality of policies, which can be expensive or even impossible. Instead, DPO uses a reward function implicitly, by optimizing it directly with a loss function. This way, DPO avoids the sampling step, while still achieving the same level of performance as RL algorithms. The basic idea is simple: instead of optimizing the reward function to produce a good policy, we optimize the reward produced by a policy to produce the best possible policy. This leads to a more powerful optimization objective, which can be used in a variety of scenarios. In this paper, the authors apply DPO to several natural language processing (NLP) problems, including machine translation, summarization, and question answering. In each problem, they solve an optimization objective of the form

R(y, π) - r(y, πy) < where r is a given reward function, and π is the policy to optimize. In this equation, y is an input sentence, and πy is the corresponding hidden state produced by a language model parameterized by π. The goal is to translate y into y such that the reward is increased. In other words, we want to write πy into a hidden state y* that produces the best possible reward from the given reward function r. In the context of machine translation, for example, the reward function r is typically the human evaluation of the translation, and the goal is to optimize the hidden state y* to produce the best possible human evaluation of the resulting translation y*. The NLP problems addressed in the paper include:
  • Machine translation: Given a source sentence y and a target sentence y*, what is the best hidden state to produce the target sentence y* with the given source sentence y?
  • Summarization: Given a paragraph of text and a summary sentence, what is the best hidden policy to produce the summary sentence with the given paragraph?
  • Question answering: Given a premise question and an answer sentence, what is the hidden policy to produce the best answer to the given premise question?
In all of these problems, the reward function r measures the difference between two possible hidden states, the source sentence y and the target sentence y*. The Future of AI: Part 2

In my last post, I discussed the current state of AI and outlined the three main approaches to AI: symbolic, connectionist, and hybrid. In this post, I will discuss the future of AI, focusing on the connectionist approach.

Connectionist AI

Connectionist AI is based on the idea that intelligence is the ability to learn from experience. Like the brain, connectionist networks are composed of nodes (also called units or neurons), which are connected by links (also called synapses). The network learns by adjusting the strength of the connections between the units. There are several types of connectionist networks, but the most popular is the multilayer perceptron (MLP). An MLP is a feedforward network with a single hidden layer. The units in the hidden layer are connected to all the units in the output layer, and each unit in the hidden layer is connected to all the units (except for a set of "guard nodes" that prevent the network from exploding or diverging to infinity). The network is trained by adjusting the strength of its connections. In supervised learning, the network is first presented with an input sequence x1, x2, ..., xN and a corresponding label sequence y1, y2, ..., yN. The network is then trained to produce as many correct outputs as possible. During training, the network is exposed to input sequences xk and their corresponding labels yk, where k = 1, 2, ..., N. The network's connections are adjusted in such a way as to increase the probability of the correct output sequence being produced in the future. In unsupervised learning, the network is instead exposed to an input sequence x1 and is asked to produce a clustering of the input. For example, the network might be presented with x1, x2,..., xN and asked to group the input into clusters based on their labels. In both supervised and unsupervised learning, an important consideration is the initialization of the network's weights. The network's weights are initialized randomly, but as the network is trained, they are updated to improve the accuracy of the network's predictions.
