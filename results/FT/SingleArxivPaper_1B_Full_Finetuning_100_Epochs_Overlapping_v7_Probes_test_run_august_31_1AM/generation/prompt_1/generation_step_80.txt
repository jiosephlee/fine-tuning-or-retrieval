After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the optimization of arbitrary functions from rewards to policies. In contrast to RL, DPO does not require sampling from the reward function, and thus can be performed in practice on large datasets. DPO can be used to solve a wide range of problems, including fine-tuning, code gen, and dialog management. In this post, I will focus on the use of DPO for language modeling, specifically fine-tuning language models (LMs) to generate high-quality text.

The basic idea behind DPO is simple: instead of optimizing the language model to achieve a given target distribution p(y | x), we optimize the language model to maximize a specified reward function r(x, y). This reward function can represent a human preference or a soft reward from a downstream task, such as a classification task. By maximizing a reward function, rather than a probability distribution, we can directly optimize for high-quality text without the need for sampling from the target distribution. In other words, with DPO we can solve language modeling problems using reinforcement learning algorithms, such as PPO.

To understand how DPO works, it is helpful to first review the standard RL approach to language modeling, which involves sampling from the language model and optimizing the model to maximize a given reward function. The standard RL approach to language modelling can be broken down into four main steps:

1. Sample an input sequence x from the LM.
2. Compute the reward r(x, y), which is a measure of the human preference for the sequence y generated by the LM x.
3. Update the LM to maximize the accumulated reward: L(x; s, t) = 1 T t=1 r(x, tys).
4. Repeat steps 1-3 until the model converges.

In the standard RL approach, the sequence of rewards obtained through step 3 provides a sequence of policy parameters π^r that optimize the given reward function r. However, the policy π^r is not a probability distribution, but rather a parametric distribution over sequences, typically represented as a neural network with input x and output y = π^r(x).

Now that we have a basic understanding of the standard RL approach to LM fine-tuning, let's see how DPO differs. With DPO, we start in the same way, by sampling from the LM and computing the reward function r(x,ys):

1. Sample an input x from the LM.
3. Update the language model to maximize the accumulated reward:
L(x; s, t)=1Tt=1r(x,ty)s+1Tt=1reward(s,t)

However, where DPO differs from standard RL is in the update rule for the language model parameter t in step 2. In the DPO update, we maximize the sum of two terms:

1. A term that restores the likelihood of the observed data: L(x; s,t) = 1 Tt=1reward(S, st)
2. A term that accounts for the human preference for downstream text y generated by the model x: L(x; s,Ty) = 1 Ty=1r(x, y)s + 1 Ty=1reward(S,t)

The addition of the second term to the update ensures that the language model is maintained in a high-quality distribution, while the first term ensures that the model remains well-approximated by the target distribution p(y |x). Intuitively, the second term on the right-hand side of the update encourages the language model to match the distribution of the observed data, while the first term encourages the language model to be high-quality, as measured by the human preference function r.

It is important to note that the reward function r used in the DPO update must satisfy certain properties, including non-negativity and the ability to sum to 1. In the context of language modeling, the reward function r can be chosen to represent a human preference for text, a soft reward from a classification task, or any other reward function that can be represented by a positive definite matrix. Some examples of reward functions used in the literature include:

* Human preference reward: r(x, y) = 1 T y=1p(y > x)
* Soft reward from a classification task: r(x, y)=\frac{1}{N} \sum_{t=1}^T w_t^T y^r(x, y)=w^T x^T r(x, y)
* Cross-entropy reward: r(x, ya) = -\log p(a|x)
