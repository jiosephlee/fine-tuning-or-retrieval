Reward Learning Algorithms
Reward learning algorithms are algorithms that learn a reward function from data. There are many different reward learning algorithms, but they all share the same basic idea: the reward learning algorithm takes a dataset of pairs of actions and their corresponding rewards, and learns a reward function that best explains the dataset. The reward function learned by the reward learning algorithm can then be used to generate predictions of rewards for new actions, or to optimize a model of rewards, such as a POMDP model. There are many different types of reward learning algorithms, including PPO, RLHF, and RLHF with reward shaping (RLHF-RS). We review each of these algorithms in turn.

PPO
PPO (Schulman et al., 2017) is a popular reward learning algorithm that is based on the theory of optimal control. PPO optimizes a reward function that is specified by a reward model, which is a function that maps actions to rewards. The reward model is typically a POMDP model, which is a model of the environment that includes a model of the agent's actions and a model of the environment's states. The reward function learned using PPO is then used to optimize the reward model. PPO uses a gradient-based optimization algorithm, such as Adam (Kingma and Ba, 2015), to optimize the reward model, which in turn optimizes the reward function. PPO is computationally expensive, because it requires solving a POMDP model for each action pair in the dataset. However, PPO is very effective at learning reward functions from datasets of high quality, such as those from the Atari games dataset (Williams et al., 2013).

RLHF
RLHF (Chen et al., 2018) is a reward learning algorithm that is similar to PPO, but it uses a reward model that is specified by a reinforcement learning (RL) algorithm, such as RLHF. RLHF is a reward learning algorithm based on the theory of reinforcement learning. It uses an RL algorithm to learn a reward function that is used to optimize a POMDP model of the environment. The reward function learned with RLHF is then used to optimize a model of the environment, such as a PDP model. RLHF is computationally efficient, because it uses an RL algorithm to optimize a reward model, rather than a POMDP model.
