After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the optimization of arbitrary functions from rewards to policies. In contrast to RL, DPO does not require sampling from the reward function, and thus can be performed in practice on large datasets. DPO can be used to solve a wide variety of problems, including fine-tuning, code gen, and dialog management. In this post, I will focus on the application of DPO to language modeling, specifically fine-tuning language models (LMs) to generate high-quality text.

At a high level, the DPO algorithm works as follows. First, we sample a reward function $r\_p$ from some distribution $p\_{reward, p}$, which may represent, for example, human quality or adherence to a given prompt. Next, we optimize a policy $\pi$ using DPO, using the update:

$$\pi \gets \frac{1}{Z} \sum\_{t}\mathbb{1}\{\text{output of } \pi \text{ satisfies prompt } t\} \mathbb{1}\{r\_{\pi(t)} \geq r\_{\pi( t)}\}$$

Here, $Z$ is a normalizing factor such that $\pi \in [0,1]$ and $\sum\_{t} \mathbb{I}\{\text{output satisfies prompt } t\}(1) = 1$. Intuitively, the update increases the weight of samples from policies that are both well-suited to the prompt $t$ and produce a high reward. However, without the distribution of rewards $p\_{reward,p}$, the update is not necessarily concave, and thus cannot be optimized using standard algorithms such as the conjugate gradient. To address this, the authors define a new function $r^*$ that is concave with respect to $\pi$, given by:

$$r^*(\pi) = \mathbb{E}_{\pi\mid X}\left[\log \pi(y\mid x)\highg{\mid \pi \text{ follows policy } \pi \text { on sample } x}\right] - \log \pi(y\highg{\mid x})$$

The key insight behind $r^*$ is that it is the logarithm of the expected log-likelihood of the true label given the generated text, minus the logarithm of the true likelihood of the label given generated text. Intuitively, the difference between $r^*$ and the original reward $r$ measures the quality of the label provided by the LM compared to the true label. We can then define the desired reward function $r^*$ as the logarithm of the maximum $r^*$ over all prompts. With the defined reward function, the DPO update becomes:

$$\pi \sim \frac{1}{\mathbb{D}}\mathbb{E}_{x\sim \mathbb{P}}\left[\log \pi(\text{output of } x\mid \text{input of } x)\right]$$

where $\mathbb{D} = \prod\_{i=1}^N \mathbb{P}(x\highg{\mid i})$. This update is a weighted average of the samples from the LM, with the weights being proportional to the quality of the labels provided by the LM for that sample. Importantly, the weights are positive, ensuring that the LM is encouraged to produce output that is correct with high probability.

Now that we have the DPO algorithm, let's see how it can be used to fine-tune a LM to produce high-quality text. The basic idea is to first initialize a LM with a pre-trained model, and then fine-tune the LM using DPO to produce a high-quality text generation model. There are several ways to initialize a LM. One simple approach is to use a pre-trained language model (e.g., BERT) on the same corpus that the fine-tuning will be performed on. Another approach is to use a dataset of human-written text paired with labels of human quality. A third approach is to use a model that is already optimized for high quality, such as GPT-J. Once an LM is initialized, the DPO algorithm can be applied to produce a text generation model that is well-suited to the given prompt and has high quality. While the DPO algorithm is general, in practice the reward function $r^*(\pi)$ is defined using the human evaluation dataset PREDICT. PREDICT is a dataset of human evaluations of the quality of generated text produced by LMs and other AI systems.
