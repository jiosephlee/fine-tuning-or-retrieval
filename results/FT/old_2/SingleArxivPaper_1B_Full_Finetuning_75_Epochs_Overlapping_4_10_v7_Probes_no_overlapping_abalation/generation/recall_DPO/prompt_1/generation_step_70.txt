The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of the well-known reinforcement learning (RL) paradigm of "reward learning". In reward learning, the objective is to learn a policy from a reward function, i.e., the reward at each state. In DPO, the objective is to optimize a preference function, i.e., a reward function with a specified preference structure. The preference function is often represented by a reward model, which is a reward function with a reward function reward function reward function reward assigned to each possible reward sequence. The preference function encodes the user's preferences over reward sequences, and the reward model is used to estimate the corresponding reward function. DPO can be viewed as a generalization of RL to the setting where the reward function is unknown, but the preference function is known. In this paper, the authors show that DPO can be solved using a simple off-policy RL algorithm, which they call "direct preference optimization" or DPO for short. The key insight of DPO is to use the preference function to define a loss function that can be optimized using standard RL algorithms, such as PPO. The resulting algorithm, DPO, is simple to implement and theoretically sound. In this paper, we focus on the theoretical analysis of DPO, including convergence guarantees and performance guarantees under certain assumptions on the reward model.

Reward Learning
Let Ω be a set of states, and let S : Ω × Σ → R be a reward function, where Σ is the set of actions. The goal of reward learning is to learn a policy π from the set of rewards R(π, ·). That is, given the set of rewards R = {r(s, a), s ∈ Ω}, the reward learning objective is to find πR such that π(s) ≥ r(s, s) for all s ∈ Ω. In other words, the reward learning objective seeks a policy that maximizes the expected reward starting from any state s. However, the reward function r is typically unknown, so we must learn from the available data, which is represented by the set of rewards R. There are several approaches to reward learning, including model-based and model-free methods. In a model-based approach, the reward function r(s, a) is assumed to be a function of two parameters, the state s and the action a, denoted by r(s, a; θ). The goal of model-based reward learning is to learn the parameterization θ that best represents the underlying reward function r. In a model-free approach, the reward function is assumed to be a random variable, and the goal is to learn a policy that maximizes a reward function estimate denoted by π r (s; θ). In other words, the model-free approach learns from a dataset of rewards R = {ri, πr(i, ·); i = 1, . . . , N }, where N is the number of samples in the dataset. The reward function estimate π r (s;θ) is a parametrized family of policies, where the parameter θ is learned from the dataset.
