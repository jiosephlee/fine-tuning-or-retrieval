What is the core contribution of the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model"?

DPO is a reinforcement learning method that trains a language model to maximize the reward it receives from human preferences. The reward is defined as the difference between the human preference and the model's preference. This is in contrast to traditional reinforcement learning methods, which train the model to maximize the expected reward. The main contribution of the paper is the development of a principled way to define the reward function, which is based on the difference between the human and model preferences. This reward function is then used to train the language model using reinforcement learning.
