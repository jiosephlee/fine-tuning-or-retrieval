After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the optimization of arbitrary functions from rewards to policies. In contrast to RL, DPO does not require sampling from the reward function to evaluate the quality of policies, which can be expensive or even impossible. Instead, DPO uses a reward function implicitly defined by the user, who provides a dataset of preferences between candidate policies and the true optimal policy. With this dataset, the user can define a reward function that best captures their preferences, and then optimize it using DPO. In this post, I will explain the main ideas behind DPO, and then apply them to language modeling.

The DPO algorithm
The DPO algorithm consists of three main steps: 1) defining the reward function, 2) optimizing the reward function, and 3) applying the optimized reward function to find the optimal policy. I will describe each step in turn.

Defining the reward function
In the first step of the DPO algorithm, the user defines the reward function that they want to optimize. This function takes as input a candidate policy π and returns a scalar representing the user's preference between π and the true optimal policy, denoted by π*. The reward function must satisfy the following properties: 1) non-negativity, 2) sum to 1, and 3) monotonicity. These properties are required to ensure that the reward function defines a valid notion of "quality" for policies. For example, the reward function could be the cross-entropy loss between the distribution of the policy and the target distribution, but this would not be a valid reward function because cross-entropy loss is not monotonically increasing. Optimizing the reward function
The second step of the DPO procedure is to optimize the reward function (2) using an optimization algorithm. In the DPO paper, the reward function is optimized using a variant of the actor-critic RL algorithm, called the preference-based actor-critic (PAC) algorithm. The basic RL algorithm updates the policy using the reward function as a measure of quality, but does not update the parameters of the policy to improve the reward function. The PBC algorithm introduced in the DPO paper extends the basic RL algorithm with a second stage that updates the policy parameters to further improve the reward function.
