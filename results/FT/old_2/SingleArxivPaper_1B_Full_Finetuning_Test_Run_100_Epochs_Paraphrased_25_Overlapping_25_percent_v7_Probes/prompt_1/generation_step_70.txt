After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the use of any reward function, not just RL rewards. In contrast to RL, DPO does not require the reward function to be known in advance. Instead, DPO uses an additional "knowledge source" that provides a sequence of rewards obtained by applying the reward function to some input sequences. This knowledge source can be a human, a neural network, or even a language model. In this way, DPO enables us to learn a policy from preferences rather than rewards.
The basic idea of DPO is as follows: 1) Sample an input sequence $x_1,\dots, xN$ from some source, 2) Apply the reward function $r(x)$ to obtain a reward sequence $r_1,\dots, rN$, 3) Use the knowledge source to compute a sequence of rewards $s_1,\dots, sN$, 4) Use the policy $\pi$ to produce an output sequence $o_1,\dots, oN$, 5) Compute the difference $y_1,\dots, yN$ between the output sequence produced by $\pi(o_i|s_i)$ and the input sequence $x_i$, 6) Use the reward function $r$ to compute the discrepancy $D(r,y) = \sum_{i=1}^N r(y_i)-r(s_i)$, 7) Maximimize $D(r,y)$ with respect to $\pi$ using an off-policy reinforcement learning algorithm, such as PPO.
At first glance, this procedure may seem somewhat mysterious. However, upon closer examination, it becomes clear that it is simply a generalization of the well-known method of maximum likelihood estimation. In particular, the procedure can be thought of as a way of finding the maximum likelihood estimate of the reward function $r$. To see this, let $r^*$ denote the reward function that maximizes the given reward sequence $s_1,\ldots, sN$ with respect to $\pi$. That is, $r^*(x_i) = \mathbb{E}_{\pi\mid s_i}[r(x \mid s_i)]$. Then the reward function $r = \mathbb{D}(r, r^*)$ is the maximum likelihood estimate of $r$ with respect to the distribution $\pi$. That is,
$$
\mathbb{E}_{x\sim\pi}\bigg[\underbrace{r(x) - r^*}_\text{discrepancy} \underbrace{\vphantom{\sum} \pi\mid s\middle| r^*\middle| x\middle|}_\text{policy}\bigg].
$$
