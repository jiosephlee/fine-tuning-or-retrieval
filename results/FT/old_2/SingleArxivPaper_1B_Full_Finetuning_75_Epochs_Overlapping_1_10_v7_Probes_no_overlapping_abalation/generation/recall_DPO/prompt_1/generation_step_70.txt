After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new optimization paradigm called "direct preference optimization" (DPO). DPO is a generalization of reinforcement learning (RL) that allows for the use of any reward function, not just RL rewards. DPO can be used to train models that satisfy human preferences directly, without first being trained to perform some other task and then having its reward modified. DPO is also more efficient than standard RL algorithms, as it can reuse the vast body of RL algorithms already developed. In this paper, the authors introduce two DPO algorithms, one for single-agent settings and one for multi-agent settings. The single-agent algorithm is simple to state: given a reward function $r^*(x, y)$ that represents a preference relation $y \preceq^* x$, the algorithm optimizes $\mathbb{E}_{x\sim \mathcal{D}}[r^*(x, \pi^*(x)) - \mathbb{E}_{y\sim \mathcal {D}}[r^* (x, y)]]$ where $\pi^*(x)$ is the policy induced by $\pi$. The multi-agent algorithm is similar, but instead of optimizing for a single agent policy, we optimize for a joint policy $\pi^*(x_1, x_2, \ldots, x_n)$. The authors also present a theoretical analysis of the algorithms, showing that they always achieve the same regret as RL with the given reward function. In this post, I want to focus on the single-agent DPO algorithm, as it is the one most relevant to language models. Before getting into the details of the algorithm, let's take a step back and think about what we're trying to do. We have a dataset $\mathcal{D} = \bigl\{x^{(i)}, y^{(i)}\bigr\}_{i=1}^N$ of examples $(x^{(i)},y^{(i)})$ where $x^{(i)}$ are examples from some latent space $x$ and $y$ is a label chosen from some preference relation $y \prec^* x$. Our goal is to learn a policy $\pi$ from $x$ to $y$. However, we also have a human preference function $r^*$ that we want to translate into a reward function $w^*$ for our policy $\pi$. That is, we want to learn $\pi^*$ such that $y \precequex^* \Leftrightarrow y \succ_w x$. We can write this mathematically as $\mathbb{E}_x[\underbrace{r^*(x, z) - w^*(z) for z \in \mathcal{D}_x}_w\ \mathbb{1}_{y\in S} \propto \mathbb{P}_x [y \in S] ] = 0$ for some reference distribution $\mathcal{D}_z$. In other words, we want to minimize the difference between the reward under the true preference relation and the reward under the reference distribution, where the reference distribution is chosen so that the probability of the desired event is maximized. This is the general framework for using preference learning to improve models, and the DPO algorithm simply applies this framework to the language model setting. With these ideas in mind, here is the DPO algorithm: 1. Sample $N$ pairs of texts $x,y \sim \mathcal{ D}$ 2. Compute the reward function $w^*(x,y) = r^*(x, y) - \frac{1}{N}\sum_{i=1}^NR(x, y)$. 3. Learn a policy $\pi^*$ from $x$ to $\frac{1}{N} \sum_{i=1 N}^NR(x, \pi^*( x))$. 4. Update the model as $\hat{w} = w^* - \alpha R(\pi^*, \text{1}_YS)$, where $\alpha$ is a scalar controlling the strength of the update. That's it! This algorithm is very simple, but it achieves impressive results. In particular, in the experiments presented in the paper, DPO was able to improve F1 scores of LLMs by 5.1% relative to a reference LM with no training prompts, and by 12.8% relative to a LM trained only with self-attention without any human feedback.
