Introduction

In the RL framework, an agent interacts with its environment by taking actions, and the agent receives rewards from the environment. The goal of the agent is to maximize the expected cumulative reward over time. However, the RL problem is generally non-differentiable, which makes it difficult to train the agent directly. To address this issue, reinforcement learning with preference (RLP) [4] was proposed, which allows the agent to specify a preference relation between the actions and the rewards. The preference relation is used to guide the agent to take actions that maximize the expected reward. In the RLP framework, the preference relation is usually represented by a preference function, which maps the actions to a scalar value. The preference function is typically defined as a linear function, i.e., f (x) = Ax + b, where x is the action, A is the action-value function, and b is the bias term. The preference function is often assumed to be convex, which ensures that the preference relation is a strict preference relation. However, the preference function is not necessarily convex, and it may be difficult to find a convex preference function that satisfies the preference relation. To address this issue in the RLP framework, preference optimization algorithms have been proposed, which aim to find a preference function that satisfies the given preference relation.
