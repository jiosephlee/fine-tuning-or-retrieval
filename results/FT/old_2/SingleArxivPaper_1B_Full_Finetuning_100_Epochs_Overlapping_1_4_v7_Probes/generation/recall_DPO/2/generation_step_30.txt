The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a general framework for optimizing language models with human preferences, called Direct Preference Optimization (DPO). DPO leverages the fact that language models are also reward models, and can be optimized using standard reinforcement learning algorithms. We evaluate DPO on two tasks: sentiment classification and fact-checking. On sentiment classification, DPO outperforms several existing methods, including baselines that directly optimize language models. On fact-checking, DPO is the only method to achieve significant improvement over the best existing baselines. Our experiments show that DPO can be applied to a wide range of languages and datasets, and is generally more robust to initialization than alternative RL-based methods.
We also provide a comprehensive analysis of the performance of DPO, showing that it is sensitive to the choice of reward function and initialization, but is generally more effective than alternative methods.

Introduction
The ability to generate fluent, human-like text is a key capability for many applications, including virtual assistants, question answering, and text generation. However, current language models (LMs) are not yet capable of generating high-quality human-understandable text. One approach to improving the quality of LMs is to align them with human preferences, by training LMs to satisfy human preferences for generated text. This aligns the objectives of the LM and the human, making the LM more human-like, while still allowing for large model performance gains. However, aligning LMs with human preferences is a challenging problem. In this paper, we study the problem of optimizing a language model with human preferences, and present a general framework for this problem, called Direct Preference Optimization, or DPO.
The basic idea of DPO is to view the language model as a reward model, and to optimize the language model using reinforcement learning (RL). RL algorithms learn to maximize a reward function, which in this case is the reward from the human preferences. There are several different RL algorithms that can be used to optimize a reward function, including policy gradient methods such as REINFORCE [Williams 1992] and proximal policy optimization (PPO [Schulman et al. 2017]), as well as methods based on value iteration, such as Q-learning [Watkins and Dayan 1992] and actor-critic algorithms such as MCMC-Crit [Bai et al. 2018]. However, all of these algorithms have the same basic structure: they take a starting policy π 0 , and update it to a better policy π t using an action-value function Q(π t , π t+1 ). In the context of language modeling, the starting policy is the language model π 0 , and the action is the sequence of words generated by the language model. The value function Q(π, π t+1 ) gives the expected reward from the policy π under policy π t+1 . Thus, the RL algorithms optimize the reward function by updating the policy using the value function. In the context of language models, the reward function is the human preference function, which maps a sequence of words to a scalar indicating how human-like the sequence is. Therefore, the DPO algorithm updates the language model policy using the value function Q(π t policy, π t+1 ).
There are several advantages to using the value function as the reward function in DPO. First, the value function is a function of the entire policy, rather than a function of a single policy action pair, as is the case for the reward function. This makes the DPO algorithm more robust to initialization, since the value function is computed using the entire policy, rather that just a single policy action pair. Second, the value function is the same for all policies, so the DPO algorithm can be applied to any policy, not just the initial language model. Finally, the value function can be computed efficiently using the Bellman equation, which gives the expected reward from state s and policy π as Q(s, π) = RT(π, Q(s, π)) where R is the reference policy, which is the identity policy for simplicity. Therefore, the D PO algorithm can be implemented using a simple update to the reference policy, rather than a full value iteration algorithm.
