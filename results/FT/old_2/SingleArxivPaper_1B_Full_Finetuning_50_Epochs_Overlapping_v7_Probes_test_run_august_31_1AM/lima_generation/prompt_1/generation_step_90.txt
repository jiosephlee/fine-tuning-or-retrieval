### What is the problem that DPO solves?

The goal of RL for language generation is to learn a policy $\pi$ from a dataset of pairs of inputs $(x, y)$, where $x$ is an input sentence and $y$ is the corresponding output sentence. The policy $\pi$ is a mapping from inputs to outputs, i.e., $\pi : \mathcal{D} \to \mathcal{X}^*$, where $\mathcal{D}$ is the dataset and $\mathcal{X} = \mathcal{X}_\text{input} \times \mathcal{X}_{\text{output}}$ is the set of possible outputs. The policy $\pi(\cdot | x)$ is also known as the language model or the generative model. The objective of the RL algorithm is to learn a policy that maximizes the expected return $R(\pi, y, x)$, which is defined as follows:

\begin{equation}
    R(\pi, y, z) = \mathbb{E}_{x \sim \mathcal{D}}\bigg[\underbrace{y \mid \pi(x)}_{\text{language model}}\mid \underbrace{z \mid \mathcal{D}\bigg]\bigg]
\end{equation}

In other words, the reward function $R(\cdot, \cdot, \cdot)$ measures how well the language model $\pi$ generates the input $z$. The goal of the RL algorithm is then to learn a policy $\hat{\pi}$ that maximizes the expected reward $R(\hat{\pi}, y, x)$.

### How does DPO work?

This is done by defining a new reward function $R_{\pi}(y, z)$ that is proportional to the KL-divergence between the true reward function $R$ and the language model $\pi$. Specifically, the reward function $r(y, z)$ is defined as:

\begin{equations}

\end{equations}

where $\mathbb{D}_{\text{KL}}$ is the Kullback-Leibler (KL) divergence. Intuitively, the reward function $ r(y, z)$ encourages the language model $\pi(y)$ to be close to the true reward function $ R(y, z)$. This is because the KL-divergence measures how far apart two probability distributions are, and a smaller KL-divergence indicates that the two distributions are more similar. Therefore, the reward function $ R_{\pi}(y,z)$ encourages the language model to generate sentences that are similar to the true reward function.
