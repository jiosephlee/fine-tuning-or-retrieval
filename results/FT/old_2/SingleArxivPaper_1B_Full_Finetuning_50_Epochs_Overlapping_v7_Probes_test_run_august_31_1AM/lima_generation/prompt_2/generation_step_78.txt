## Introduction

### What is RL?

RL is a machine learning paradigm that trains a model to perform a task by providing it with feedback on its performance. The model learns to optimize a reward function, which measures the quality of its performance. The most common RL algorithms are Q-learning (Watkins & Dayan, 1992) and RL-DL (Schulman et al., 2015). Q-learning is a simple algorithm that uses a policy gradient to update the model's policy. RL-DL is a more sophisticated algorithm that uses a value function to update the model's value function. Both algorithms are based on the Bellman optimality equation, which states that the optimal policy for a given reward function is the one that maximizes the expected return, i.e., the sum of the discounted rewards.

### What is RL with a reward function?

RL with a reward function is a machine learning paradigm in which a model is trained to optimize a reward function. The reward function measures the quality of the model's performance, and the model is trained to maximize the reward. This is different from RL without a reward function, in which the model is trained to optimize the expected return, which is the sum of the discounted returns. The difference between RL with a reward function and RL without a reward function is subtle, but important. In RL with a reward function, the model is trained to perform well, while in RL without a reward function the model is trained to minimize the expected return. This difference has important implications for the performance of the model. For example, in RL without a reward, the model will tend to overfit to the training data, leading to poor generalization performance. On the other hand, in RL with a reward, the model is trained not to overfit, but to generalize well to new data. Therefore, RL with a reward is generally considered to be a better approach than RL without a reward.

### What is RL without a reward function?

RL without a reward function is a type of RL in which the model is not trained to optimize a reward. Instead, the model is trained on a dataset of actions and rewards, and the model learns to predict the reward for a given action. This is different from supervised learning, in which the model learns to predict a label for a given input. The main advantage of RL without a reward function over supervised learning is that it does not require any labels, making it easier to train models on large datasets. However, the main disadvantage of RL without a reward is that the model does not learn to optimize a reward, which can lead to poor performance on downstream tasks. For example, in supervised learning, the model learns to maximize the likelihood of the correct label, which is a reward. On the other hand in RL without a reward the model learns to maximize its own reward, which is not necessarily a reward.
