Introduction
The goal of language modeling is to learn a model that can generate text that is similar to the text in a large corpus. This task is challenging because the training data is typically not annotated with explicit preferences, and the model must learn to generate text that is preferred by humans. One way to address this problem is to use a reward function to guide the training of the language model. The reward function is typically defined as the difference between the probability of the target text and the probability of the reference text, where the reference text is typically a randomly sampled sentence from the training data. The goal is to maximize the reward, which encourages the language model to generate text that is similar in meaning to the reference text.
There are many different ways to define the reward function, and the choice of reward function can have a significant impact on the performance of the language model. In this paper, we focus on the so-called "direct preference" reward function, which is defined as the difference between two probabilities: the probability of the target sentence and the probability of the ground truth reference sentence. This reward function is widely used in practice, and it has been shown to be effective in many applications, including summarization (Kiros et al., 2015), question answering (Zhang et al., 2019), and machine translation (Liu et al., 2018). However, it is not always straightforward to define the reward function using the direct preference approach. In particular, it can be difficult to determine the probability of the reference sentence, especially when the reference sentence is not directly available. This is because the reference sentence is typically not sampled from the training data, but rather from a distribution that is unknown to the model. In this case, it is necessary to use a proxy for the reference sentence, such as the average probability of the reference sentence over all possible reference sentences. This approach is known as the "language model as a reward model" (LMARM) framework (Bai et al., 2017;Liu et al., , 2018. In this framework, the reward function is defined as the difference in probabilities between the target sentence and the language model's output, where the language model is trained using the LMARM objective. The LMARM framework has been shown to be successful in many applications, but it is not always straightforward or easy to implement. Related Work
Language modeling has been a popular topic in machine learning research for several decades. Early work focused on developing algorithms for generating text that is similar to a given reference text (Marcus, 1986;Marcus and Miller, 1986;Schmidhuber, 1990). More recently, language models have been trained using large-scale corpora, and they have been shown to be effective for a variety of tasks, including machine translation (Peters et al., 2014), question answering (Zhou et al., 2016), and summarization (Kiros, 2015;Radford et al., 2013;Liu et al. 2018). One common approach for training language models is to use a reward-based objective, where the reward is defined as the difference of the probability of the target output and the probability of the gold reference output. This approach is known variously as the "reward-based objective" (RBO) (Kiros et al. 2015), the "language model as reward model" (LMR) (Bai et al. 2017;Luo et al. 2019), and the "language model as an implicit reward model" (LMIRM) (Liu et al. , 2018. The LMIRM framework is based on the idea, first proposed by Liu et al. (2018), that the language model can serve as a proxy for human judgment.
