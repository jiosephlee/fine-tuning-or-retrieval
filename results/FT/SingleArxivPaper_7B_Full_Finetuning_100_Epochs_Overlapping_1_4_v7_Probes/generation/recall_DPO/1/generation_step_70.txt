The basics

The basic idea of DPO is to use a language model as a reward model. In other words, the language model is used to produce a reward value for a given completion x of a prompt p. The reward function is simply the negative log-likelihood of the completion x under the language model L(p, x). So, the reward function is:

$$\text{reward}(p, x) = -\mathbb{E}_{x \sim L(p, \cdot)}\bigl[\log \sigma(z^{(L)} / x)\bigr]$$

where \(z^{(L)}\) is the last layer of the language model and \(\sigma\) is the logistic function.

The language model is fine-tuned on the completions with the highest reward under the same language model, but with an added reward term \(\beta\) times the reward computed by the reward model. The coefficient \(\beta\) is chosen to maximize the reward on a held-out set of completions. This process is repeated for a maximum of \(T\) steps.
