The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a generalization of the well-known reinforcement learning approach to reward maximization, known as RLHF (reward learning from examples), to the setting of preference learning. This generalization is achieved by introducing a new objective, called the direct preference optimization (DPO) objective, which is a convex combination of the RLHF objective and a reward function that is learned from human preferences. The DPO objective is shown to be equivalent to the RLHF objective under certain assumptions, and it is also shown to be more robust to model misspecification than the RLHF objective. The DPO objective can be efficiently solved using a gradient-based method, and the resulting policy is shown to generalize well to unseen data. Experiments on two large-scale preference learning datasets demonstrate that the DPO objective can achieve comparable or better performance than the RLHF objective, while being easier to train and more stable to model misspecification.

Related Work
In this section, we review the related work on both preference learning and reward learning from human feedback. Preference learning aims to learn a model that maps inputs to human preferences, while reward learning aims to learn a policy that maximizes a reward function. In this work, we focus on the reward learning setting, where the goal is to learn a policy that matches human preferences. There are two main approaches to learning reward functions from human preferences: reinforcement learning and supervised learning. In reinforcement learning, the reward function is learned by maximizing the expected return of the policy, which is defined as the integral of the reward over all possible actions. In contrast, in supervised learning, the reward function can be learned from labeled data, where the reward is given for each input-output pair. In the context of learning reward functions from human preference data, the most common approach is to use reinforcement learning, as it has been successfully applied to various domains, such as robotics [1], game playing [2], and language modeling [3]. However, reinforcement learning is computationally intensive, and it is not always possible to collect sufficient preference data. In this work, instead of using reinforcement learning, we propose a method that directly optimizes the reward function using human preference data, without the need for reinforcement learning.
