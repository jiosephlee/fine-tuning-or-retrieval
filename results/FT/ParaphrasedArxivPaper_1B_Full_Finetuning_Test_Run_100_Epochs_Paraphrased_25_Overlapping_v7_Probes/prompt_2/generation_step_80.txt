The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a generalization of the well-known RLHF algorithm to the case where the reward function is not explicitly defined, but rather is inferred from observed preferences. This allows the use of language models trained on large corpora, which are typically unavailable for fine-tuning with explicit rewards. The method is based on the observation that the optimal policy for the reward model can be computed using a straightforward optimization, and that the policy gradient for this optimal policy can be used to update the language model. We refer to this approach as DPO, for "Direct Preference Optimization." DPO is shown to be equivalent to the RLHF algorithm, and is more efficient in practice, requiring only a single pass over the preference data. Experiments on several preference datasets demonstrate that DPO can align language models with human preferences as well as or better than existing approaches, while requiring no hyperparameter tuning and no access to the reward function.
We also present a variant of DPO that uses a different approach to optimize the reward model. This method, which we call "Indirect Preference Optimization" (IPO), is based on the observation (also made in the RLHF literature) that the optimal reward function can be expressed as a linear combination of the preference pairs. We show that the policy gradient for the reward function can be computed using a simple linear regression, and that this gradient can be used to update a language model. We refer this method as IPO, for "Indirect Preference Optimization." Preliminary results indicate that IPO outperforms DPO in some scenarios, but the full experimental evaluation is beyond the scope of this work.
The rest of the paper is organized as follows. In Section 2, we introduce the problem of aligning language models with preferences, and discuss related approaches. In Section 3, we present the DPO algorithm, which optimizes the language model using the policy gradient for the inferred reward function. In Section 4, we describe the implementation of DPO and present experimental results. Section 5 presents the results of an experiment comparing DPO to other methods, and Section 6 draws some conclusions. The code for the experiments in this paper is available at https://github.com/CarperAI/DPO.

Related Work
Language model fine-tuning with human feedback is a relatively new area of research, with the first studies appearing in 2020 [1,2]. These studies typically involve training a language model on a large corpus, and then using human preference data to fine-tune the model to better match the preferences of a target audience. In this section, we review the related work in two main areas: approaches for aligning language models using human preferences, and approaches for learning reward functions from preference data.

Aligning Language Models with Preferences
The goal of aligning language models is to create a model that is both accurate and in line with human preferences. In this section, our focus is on approaches that use human preference data to train language models, rather than approaches that use explicit reward functions to train language models. There are a number of different ways to collect human preference data, but the most common approach is to use a crowdsourcing platform such as Amazon's Mechanical Turk (MTurk) to ask participants to rate how well a given model matches a set of prompts. This type of preference data is referred to as human evaluation data, and it is typically collected using the prompt-response format, where each prompt is paired with a set of responses from the language model. The preference data is then used to train a model that predicts the likelihood of a given prompt being preferred over a given model. This model is referred to as a preference model, and it is typically trained using a supervised learning approach, such as reinforcement learning from human feedback (RLHF) [3,4], reinforcement learning with human feedback (RLWHF) [5], or a combination of the two [6,7]. In the RLHF approach, the preference model is trained to maximize the reward function, which is defined as the difference between the likelihood of the preferred response and the likelihood of the less preferred response. In the RLWHF approach, the reward function is instead defined as the difference between two reward functions, one for each model, and the preference model is trained using a reward maximization objective. In both approaches, the preference model is used to train a language model, which is then evaluated using human preference data to assess its performance. In this work, we focus on the RLHF approach, which is the most commonly used method for aligning language model with human preferences.
There are a number of different algorithms for training the preference model, but the most common is the maximum likelihood (ML) approach, which involves maximizing the likelihood of the preference data given the preference model and the language model. A related approach is the maximum a posteriori (MAP) approach, which involves finding the model that maximizes the probability of the preference data, given the preference model and language model.
