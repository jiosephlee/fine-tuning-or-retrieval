After reading the paper "Direct Preference Optimization: Your Language Model is a Secret Reward model", I've learned a lot. Let me tell you everything I've learned. The paper introduces a new method for training language models, called Direct Preference Optimization (DPO). DPO is based on the idea that we can represent the preferences of a human annotator as a reward function, and then train the language model to maximize this reward. This is a very powerful idea, because it allows us to use the same optimization algorithm that is used for reinforcement learning, but with a different objective. In particular, the authors show that the standard policy gradient method can be used to optimize the reward function, leading to a new algorithm called DPO.

The basic idea behind DPO is as follows. Suppose we have a dataset of human preferences $\mathcal{D} = \{x^{(i)}, y_w^{(i)}, y_l^{(i)}\}_{i=1}^N$ where $x^{(i)}$ is an input sentence and $y_w$ and $y_l$ are two outputs from a language model. We want to learn a language model $p_{\theta}(y \mid x)$ that maximizes the human preferences, i.e., we want to solve the following optimization problem:

\begin{equation}\label{eq:main}
    \max_{\pi_{\theta}} \mathbb{E}_{\pi_{\theta} \mid \mathcal{D}}\left[ \underbrace{\beta\log p_{\theta}(y\mid x)}_{\text{reward model}} - \underbrace{\sigma(\nabla_\theta\log p(y\mid x, \theta))}_\text{policy gradient}\right]
\end{equation}

Here, $\beta$ is a scaling factor that controls how much we weight the reward compared to the policy gradient. The reward model is defined as:

\begin{equatio}\label{eq:reward_model}
    r(y, x; \theta) = \mathbb{E}_\pi \left[\underbrace{1-y^2\log\frac{1}{p(y\mid x,\theta)}}_{\text{regret}} - \underbrace{2\beta\log p(y\middle| x, \theta)}_{\text{log likelihood}}\right]
\end{eqnarray}

The intuition behind this reward model is that we want to encourage the language model to output the correct answer with high probability, while still allowing some errors in the output. The term $1 - y^2\log\left(\frac{1}{p}(y\mid x, \thetahat)\right)$ is the regret term, which measures how much the model is underperforming the true ground truth $y^*$. On the other hand, the log likelihood term $2\beta\log\frac{p(y\mid x,\theta)}{p(y\mid \text{true}, \theta)}$ is the reward term, which reflects the reward provided by the model to the correct output $y^*$.

Now, let's discuss the policy gradient step in Eq. \ref{eq:main}. The standard approach is to use the KL-divergence between the true distribution $p$ and the target distribution $q$, i.e., $\nabla_\theta \mathbb{E}\left[\log \frac{p(y\middle| x,\theta)}{q(y\middle| x,y^*)\mid y\right] \right]$, where $q$ is the reference distribution, which is typically the true distribution $p$. However, in the context of language models, the reference distribution $q$ is often the reference distribution $p$, since we are using the same model to generate both the correct and incorrect outputs. Therefore, the policy gradient simplifies to:

\begin{equations}\label{eq:gradient}
    \nabla_\theta r(y, x; θ) = \beta \nabla_\θ \log p(y\mid x, \theta)
\end{equations}

This is the policy gradient used in DPO. It is important to note that the reward model in Eq. \ref {eq:reward_model} is not necessarily the reward function used in previous studies, such as REINFORCE or PPO. In fact, the reward model used in DPO is derived from the reward model used in the original RLHF paper, which is based on the reward function $r_{\phi}(y, x; \theta)$ defined as:

\begin {equation}\label{equ:reward_model}
    \mathbb{E}[1-y^2\ln\frac{1}{\phi(y\mid x, θ)}]
\end{equjaime}

where $\phi$ is a neural network that maps the input $x$ to a probability $p(y\mid x)$.
