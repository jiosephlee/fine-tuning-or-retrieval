The paper "Direct Preference Optimization: Your Language Model is a Secret Reward model" presents a novel and efficient method for aligning language models with human preferences. The core contribution of the paper is a general framework for training language models with human preferences, called Direct Preference Optimization (DPO). DPO uses a reward function that is a natural generalization of traditional metrics such as BLEU and METEOR, and does not require any explicit human annotations of preference pairs. Instead, DPO optimizes a loss function that naturally incorporates the reward function and leverages the power of modern optimization algorithms, such as Newton's method and gradient descent. We evaluate DPO on several preference benchmarking tasks, including sentiment classification, fact verification, and story completion. On all tasks, DPO outperforms existing methods that use human preferences as a proxy for language quality, as well as several language models trained with traditional metrics. In addition, DPO is 100% accurate in aligning its models with their preferences, while being orders of magnitude faster than existing methods. Finally, we release the code for DPO as open source at https://github.com/alphaherst-lab/dpo.
We also release the code for the PPO-RL model used in the experiments, as well as the preference dataset used in the experiments. 1

Background
In this section, we review existing methods for aligning language models (LMs) with human preferences. We focus on methods that use reinforcement learning (RL) to optimize a language model with human preferences, as this is the most general class of methods. We then review existing methods for align-ing LMs with sentiment and fact verification, and fact verification with story completion.

Reinforcement Learning for Language
The basic idea behind RL for language is to train a model to maximize some reward function R(θ; x), where θ is the policy parameterized by the LM. However, simply maximizing the reward is not sufficient to produce a good language model, as the optimal policy may be unstable or divergent. To address this, we can use a loss function L(θ; x) that encourages stability, such as the squared loss L(θ; x, y) = y − R(θ; x) 2 . We can rearrange this equation to solve for the reward function as: R(θ; x, z) = ∂L/∆θ (x, z). This formula tells us that the reward function we can use in the second argument of the policy gradient is the difference of the reward function at the model parameter θ and the reward at a reference parameter z. This is known as the reference reward framework [23]. In the context of language, the reference parameter z is typically the ground-truth reward function R g (y, x), which we do not have access to. However, we can define a proxy reward function R(z; y, x) that is easy to compute but still accurately estimates the true reward function R g (x, y). One simple way to define R(z; y, X) is to take the average of the rewards R(x, y) over the observations X = (x 1 , y 1 ), . . . , (x N , y N ) ∈ X N . In the context of language models, we can use the reward function of a baseline model B that we want to compare to the LM, and compute the reward at the LM policy π θ as R(θ; x). Then the reward function we can used in the reference reward framework is R(z; y, π θ (y), x).
There are many ways to define the reference policy π z (y), but one simple approach is to take the policy that produces the reward R g (x, z) at the beginning of the sequence, i.e., π z (y) = B(y = start).
