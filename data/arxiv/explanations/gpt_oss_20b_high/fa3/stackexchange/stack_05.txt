Below is a short sketch showing how one could turn an arbitrary plaintext document
that contains “Unicode‐style” mathematical symbols (`π`, …
`)`) into clean TeX markup according to the rules you asked for.
It demonstrates how every offending construct is detected,
how undone Unicode symbols are translated,
and how every mathematical fragment gets wrapped in either
inline (`$…$`) or display (`$$…$$`) delimiters
without touching anything else in the source material.



--------------------------------------------------------------------

## High‑level idea

```text
1. Scan the file line‑by‑line.
2. Whenever an ordinary‐looking symbol sequence looks
   like "`〈unicode_math〉"` translate it via a lookup map.
3. Detect classic TeX delimiters "\(...\)"   → replace one pair
      "`$\textit{expr}$"`  
   Detect classic TeX delimiters "\[...\]"   → replace one pair
      "`$$\textit{expr}$$"` .
4. For every remaining fragment surrounded by brackets "`(` `"`.
   If bracketted items look “mathy”  
      (they contain digits + letters + `_^{}/.`),
      wrap the whole thing immediately before/after brackets
      with `$…$`.
5. All other parts stay untouched.
```

--------------------------------------------------------------------

## Reference implementation (inferred Python)

```python
import re


# ---------- Step 1 : Unicode → canonical tex ----------
unicode_repl = {
    'π': r'\pi',
    # add more mappings here …
}

# build regex looking for ONE OF THE SPECIFIC unicode symbols
unicode_pat = re.compile('|'.join(map(re.escape, unicode_repl)))

def repl_unicode(match):
    return f"${unicode_repl[match.group(0)]}$"


# ---------- Step 2 : Legacy TeX delimiters ----------
inline_pat     = re.compile(r'\\\(((?:[^\\]|\\.)*?)\\)', re.S)
display_pat    = re.compile(r'\\\[([^\\]*?)\\]',     re.S)

def replace_inline(m):
    return f"${m.group(1)}$"

def replace_display(m):
    return f"$${m.group(1)}$$"


# ---------- Step 3 : Bracketed fragments ----------
# heuristic “mathy” fragment → guard it in $
mathy_fragment_pat = re.compile(
    r'\(([^()]*)?\)',          # '(' … ')'
    flags=re.S)

mathy_cond_pat = re.compile(r'[A-Za-z0-9_\^\/\.]')
def guard_mathy(match):
    frag = match.group(1)
    return f'$({frag})$'


# ---------- Main routine ----------
def clean_tex(txt):
    txt = unicode_pat.sub(repl_unicode, txt)
    txt = inline_pat.sub(replace_inline, txt)
    txt = display_pat.sub(replace_display, txt)
    txt = mathy_fragment_pat.sub(
        lambda m: guard_mathy(m) if mathy_cond_pat.search(m.group(1))
        else m.group(0),
        txt)
    return txt


if __name__ == "__main__":
    # read file name passed on command line …
    import sys
    src_fn = sys.argv[1]
    dst_fn = sys.argv[2]
    inp = Path(src_fn).read_text()
    Path(dst_fn).write_text(clean_tex(inp))
```

## Why this works



| Condition | Regex behaviour |
|-----------|------------------|
| Match sequence “π” | `unicode_repl['π'] == '\pi’` → wrapped \$ \
| Match legacy “\( … \)” | Replaced `<bt>\([\ldots]\)\<\/bt>` ⇒ `[$…$]`. |
| Match legacy “\[ … \]” | Replaced `<bt>\[\ldots]\<\/bt>` ⇒ `[$$\ldots$$]`. |
| Bracket-enclosed “mathy” fragments (`(`…) | If inner contains letters/digits/equivalent → put surrounding `$(`…`)$`. |
| Any other parenthesised non-mathy -> untouched |

The helper predicate `(A-Za-z0-9_\^\/\.])`
keeps food‐like cases (`\(S_next ready)` et al.) safe –
they become ordinary parentheses while execution syntax remains intact.
