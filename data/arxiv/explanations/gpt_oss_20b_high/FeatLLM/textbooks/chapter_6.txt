\title{A Textbook about the Paper: "Large Language Models Can Automatically Engineer Features for Few-Shot Tabular Learning"}

Chapter 6: Rule–Based Binary Features And Lightweight Classifier  

---

# Rule Pool  
In FeatLLM every few‑shot training instance is turned temporarily into natural‑language text and fed together with concise task information into a large language model (LLM).  
From these prompts the LLM produces *rules*, i.e., concise logical conditions written in English such as “*age > 50 and smoker*”.  
Once a set of rules is obtained for every target class \(c=1,\dots ,C\), each rule acts like a Boolean guard that can be evaluated against every table entry and thereby yields a **binary feature** indicating whether the entry satisfies this guard or not.  
For one sample \(x^{\,i}\) and one target class \(c\), let  

\[
\mathbf{z}_{c}^{\,i}\;\in\;\{0,\tfrac12,\dots,\,1\}^{R}
\]

denote the resulting vector whose component
\(z_{c,r}^{\,i}\) equals \(1\) if the sample satisfies rule \(r\), otherwise \(0\).
Here \(R=\texttt{numberOfRulesPerClass}\) is fixed (the authors chose ten)
and consequently every outcome has exactly \(R\) binary descriptors.
These vectors comprise what we call the **rule pool** – they form an intermediate
feature bank that isolates out-of-sample predictive structure inferred by
the LLM before any downstream supervised learning takes place.
Because every component simply records satisfaction of a human‑synthetic condition,
the resulting bank inherits clear semantic meaning freely interpretable
by end users or domain experts while simultaneously reducing memory footprint
compared to raw tabular columns.



# Positive Weighting Scheme  
Having constructed a high‑dimensional Boolean matrix
\(Z=\bigl[\,z_{c,r}^{\,i}\,\bigr]\),
we wish an inexpensive predictor able to convert these indicators into an estimate
of how probably a row belongs to each target.
A conventional approach would multiply independent.Weights however,
if left free could learn negative coefficients,
thereby **suppressing** evidence that has been confirmed.
In FeatLLM we deliberately enforce **monotonicity** through projection:
for every target \(c\),

\[
w'_{c,j}= \max(w_{c,j},\, 0)\quad(j=1,\dots,R)
\]

which simply keeps positive coefficients unchanged while clipping any negative
values at zero.
Consequently every learned coefficient always *raises* support for its
associated rule,
consistent with our intuition that confirmation should never worsen
a target’s likelihood when expressed through logical guards.
This clamping also keeps parameter sparsity desirable when data are scarce,
avoiding spurious dampening effects induced by weak samples.



# Softmax Over Logits  
With positively projected weights available,
the single‑shot predictor proceeds via an elementary linear map followed by
probabilistic normalization.
For sample \(x^{\,i}\) and target \(c\),

the logit is computed as  

\[
l^{\,i}_{c}=w'_{c}\!\cdot\, \mathbf{z}_{c}^{\,i}
          = \sum_{j=1}^{R} w'_{c,j}\;\!z^{\,i}_{c,j},
\]

where “·’’ denotes inner product;
here each application reduces essentially to summation weighted by learned confidences.
To transform these raw scores into coherent posterior estimates,
they pass through the soft‑max operator,

\[
p^{\,i}_{c}= \frac{\exp(l^{\,i}_{c})}
                 {\sum_{t=1}^{C}\exp(l^{\,i}_{t})}
             .
\]

After normalization we obtain a valid probability vector
\(p^{\,i}=(p^{\,i}_{1},…,p^{\,i}_{C})^\top\)
whose entries clearly represent how plausible each class is given the presence
or absence of every rule.
This probabilistic view provides well‑known calibration properties,
insuring comparability even when different numbers of Rules arise during
bagged repetitions.



# Training Regime  
The only parameters learned during supervised training are the vectors \(w'_c\)
for every target.
Feasible optimization is achieved adaptively following established best practices:
Adam optimizer sits on top,
run with learning rate \(\eta=0 .01\),
and trained until convergence or up until a cap of two hundred epochs 
(both limits were chosen experimentally without large tuning effort).
Loss minimization uses categorical cross‑entropy,
which computes discrepancy between predicted distribution \(p^{\,i}\)
and ground‑truth one‑hot labels exposed through those small few‑shot training set;
cross‑entropy faithfully penalises confident yet wrong predictions,
thus driving gradients toward correct coefficient adjustments.
Because rule shapes are deterministic once sampled,
no further fine‑tuning or back-propagation through LLM calls occurs;
once coefficients stabilize, inference system reduces entirely 
to inexpensive matrix multiplication plus soft‑max operation.



# Alternative Naïve Scoring  
Before resorting towards coefficient optimisation steps,
one could directly employ **unweighted summation** over satisfied rules:
for sample \(x^{\,i}\),

and target \(c:\)

here count\( _{c}^{\, i}= \sum_{j=1}^{R} z^{\, i}_{c,j}. 

This plain score treats every extracted guard equally potent;
a pivotal mild threshold can transform it into indicator predictions.
The authors carried out controlled comparisons (the ablative evaluation),
demonstrating that while naïve counting provides acceptable performance
on very coarse problems,
omitting coefficient learning systematically underperforms especially when
spurious associations between unrelated columns arise.
Consequently their final design preserves minimal computation cost yet offers notably higher driven accuracy thanks "
to statistical preferences captured by learned non‑negative weights.



---  

By structuring knowledge furnished by large language models into **binary rule features**, constraining their linear combination through “positive attribution’’ penalties, normalising outcomes via **soft‑max**, and optimising coefficients solely on sparse labelled sets,
FeatLLM achieves powerful yet extremely lightweight inference –
a key building block enabling trustworthy tabular policy applications in few-shot regimes._END_
