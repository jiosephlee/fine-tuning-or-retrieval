\title{Stack Exchange of the Paper: "Direct Preference Optimization: Your Language Model is Secretly a Reward Model"}

### "Equivalence classes of reward functions" – why do different rewards trigger identical preferences?
Question:
"Lemma 1 states that if two rewards differ only by a function of x,
a(r−r')=f(x), then they induce identical preferences…"
How does this under‑specification arise from Plackett–Luce/Bradley–Terry assumptions, and why doesn’t it affect which optimal policy we recover?
Answer:
**Why do different rewards trigger exactly the same preferences?**

In both Bradley–Terry and Plackett–Luce models the human observer does not look at an absolute “utility’’ $r(x,y)$.  
Instead they observe *differences* between two responses that are generated for the *same*
prompt $x$.  
For two completions $y_1$ and $y_2$,  

$$p^*(y_1\succeq y_2|x)=
\sigma(r^*(x,y_1)-r^*(x,y_2)),           
\tad\sigma(z)=\frac{1}{1+e^{-z}},$$  

so everything that enters this expression is a difference.  
Consequently if we add any function that depends only on the prefix $x$,  

$$ r'(x,y)=r^*(x,y)+f(x),$$  

the two utilities seen by the human change by exactly the *same*
amount $f(x)$, no matter which completion we evaluate.  
Because the logistic function $\sigma(\cdot)$ is invariant under adding
a common constant,

$$
\sigma(r^*(x,y_1)+f(x)-[\, r^*(x,y_2)+f(x)])
=\sigma(r^*(x,y_1)-r^*(x,y_2)),
$$

the induced distribution over pairwise preferences is unchanged.
This simple fact expresses **Lemma 1** in the paper:
two rewards belonging to the same *equivalence class*
$\Bigl(\{\, r:\;\dotsc=r-r'=f(\cdot)\,\Bigr)$ generate exactly  
the same Bradley–Terry (and thus Plackett–Luce)
preferences.
Intuitively, guessing absolute scores is impossible when only ordinal information is available—the log‑linear choice model merely encodes relative ordering, so adding a common offset has no effect.



--------------------------------------------------------------------

**Why doesn’t this ambiguity hurt us when recovering an optimal policy?**

When training language‑model policies one solves a *KL‑constrained*
reward maximisation

$$J(\pi)=
\E_\pi[r(x,y)]
-\beta\,D_{\mathrm{KL}}\!\bigl(\pi\,||\,\pi_{\mathsf ref}\bigr).            \tag{1}$$

For any fixed reference policy $\pi_{\mathsf ref}$ its Lagrange multiplier enforces exactly the form  

$$
\nu_r(y|x)
=
\dfrac{
    \nu_{\mathsf ref}(y|x)\,
    e^{\, r(x,y)/\beta}}
     {Z_{\mathsf ref,r}( x)},
      \\[
 Z_{\mathsf ref,r}( x)=
     \sum_{y'}
        {\nu_{\mathsf ref}(y'\mid x)\,
         e^{\, r(x , y')/\beta}}
      ]                                          ,
     \\tag{2}
$$  

Adding $f(x)$ multiplies every exponent by $e^{\, f(x)/\beta}$;
however this factor appears both inside every numerator and within every summand of $Z_{\mathsf ref,r}$.
Hence  

$$
\nu_{\, r+f }(y| x)= 
\nu_r(y| x).\tag{3}
$$

Thus **Lemma 2** follows immediately:
any two members of an equivalence class generate *identical optimal policies*.  
The optimisation problem cares only about ratios between exponents,
not about their absolute magnitudes.



--------------------------------------------------------------------

**What does this mean for Direct Preference Optimisation (DPO)?**

By combining Equations $(2)$ and $(3)$ one can rewrite any admissible reward $r^\*$ belonging to an equivalence class as  

$$ 
r^\*(x , y )
=
    \beta   
        \log 
        {{\nu^\ast(y| x)}%
         {{}/{}/{}}{{}/{ }\nu_{\mathsf ref}( y| x)} }
    +c^\star ( x ),
\\quad 
c^\star ( x )
=
-\Bigl[\log  
        Z_{\mathsf ref,r^\ast }( x ) 
         + O(1)\Bigr].                 \\tag{4}
$$ 

Equation $(4)$ shows precisely which member of an equivalence class DPO’s reparameterisation picks:
it chooses the representative whose exponentials already sum up to one under 
the reference distribution—i.e.\ its softmax normalising term vanishes automatically.
Because every “true’’ reward lies somewhere in some equivalence class,
using **this particular representative guarantees no loss in expressivity –
every best–achievable policy can still be represented.

### Summary

• Under‑specification arises naturally because human pairwise choices depend only on differences between utilities;
shifting every utility by a context‐only function leaves choice probabilities unchanged.  
  
• Any two rewards differing by such a shift give exactly  
the same Bradley–Terry / Plackett–Luce preference distribution – formalised in Lemma 1.\medskip
  
• The KL‐constrained optimisation used in RLHF respects this symmetry;
adding a shift merely rescales numerator(s) and denominator(s), cancelling out,
so schedule every member produces precisely **the same optimal policy**, i.e.\ Lemma 2.\medskip
  
• DPO’s reparameterisation picks one canonical representative per equivalence class—
namely $\hat r=\beta\,§‎$\log {\frac{\nu^\ast(y|{x})}{ϳixed y}}$
—ensuring learning either an explicit reward or fitting directly with DPO successfully targets exactly the same set of desirable policies.\medskip


In short, although many distinct reward functions give rise only marginal differentiation shown purely thy preferences datum,
none influence ultimately returned behavioural policy—the space collapses along directions invisible through choice data—so learning either touching explicit reward or fitting via DPO converges onto identical verses optimal policies.$$
