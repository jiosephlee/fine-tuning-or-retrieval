# Counting Trainable Entries versus Full \(d \times d\) Matrices  

Orthogonal Finetuning (OFT) replaces the frozen weight matrix \(\bm W^0 \in \mathbb R^{d\times n}\) with a product
\[
\bm W = \bm R\, \bm W^0,
\]
where \(\bm R \in \mathbb R^{d\times d}\) is constrained to be orthogonal (\(\bm R^\top \bm R=\bm I_d\)).  
A naïve implementation would assign every element of \(\bm R\) a learnable variable and learn an arbitrary
orthogonal transformation during fine‑tuning.  Because an unconstrained \(d\times d\) matrix consists of \(d^2\)
entries while an orthogonal constraint reduces its degrees of freedom by roughly \(d(d+1)/2\), practitioners typically consider only phrased **trainable** variables – those entries that are actually free under the constraint set *and* updated during training.  

The original OFT scheme introduces a **block‑diagonal** parametrisation:
\[
\bm R = \operatorname{diag}
   (\underbrace{\bm R_1}_{b\times b},
    \underbrace{\bm R_2}_{b\times b},
    \ldots ,
    \underbrace{\bm R_r}_{b\times b}), 
   \qquad      br=d .
\]
Each small block \(\bm R_i\) belongs to \(O(b)\), i.e.\ its set of feasible values is itself an orthogonally constrained subset.
The sheer number of **trainable** entries becomes
\[
|\mathcal P_{\text{block}}|
   = r\,|\,O(b)\,\!|
   = r\,\frac{b(b-1)}{2}
   = \frac12\,d\, (b-1).
   \tag{1}
\]

# Effect on Recovering Classic Linear Transforms  

Classic fast linear transforms—including Discrete Cosine Transform (DCT),
Hadamard Transform, Fast Fourier Transform—are realised through specific dense orthogonal matrices.
Their defining feature is **global coupling**:
each output coefficient depends on *all* input components through a distinct weighting pattern.
For instance, an \(N\times N\)
DFT matrix contains non–zero entries at every position:
\(F_{k,\ell}=\exp(-i\, 2\pi k \ell /N)\).
Same holds for real versions such as DCT or Hadamard:
every entry admits a non‑zero contribution,
obtained from exponentials or alternating signs spread uniformly over the whole space.
These dense patterns guarantee short–circuit propagation
(energy spanning most directional modes),
facilitating efficient representation learning when fine‑tuning downstream tasks.


Vanishingly few affine combinations allow a global reach through only 
directed interactions among neurons 
compacted into disjoint blocks,
as formalised by Figures~\ref{fig:block_diag}.
Because each block manipulates its internal coordinates exclusively,
any vector travelling inside one group never mixes
information captured in another group.
Consequently,
the product decomposition in Eq.~(3)
cannot span key directions
present globally—such as sinusoidal basis functions whose harmonics rely upon superpositions over multiple blocks.
This barrier shows up concretely:
if one attempts to recover a classical transformation
whose toolset requires responsibilities distributed uniformly over index positions,
a single‐layer let–the–product-of-blocks structure fails disastrously—
unless one chooses \(b=d,\;
r=1,\;
dr=d,\)
which recovers trivial identity behaviour detrimental under limited budget.



# Drawbacks Stemming From Fixed Sparsity Partition  

Block–diagonal sparsity is introduced *by design*, splitting neurons strictly according to their index ordering.
Such imposed static partition presumes that localisation purely reflects underlying data geometry,
yet practical self‑attention mechanisms often expose correlations straddling any arbitrary split.
When ignored during training:
* **Coupling deficiency** — A channel required simultaneously 
to fuse features belonging naturally together 
is artificially divided between two separate optimisation trajectories;
the lack of direct interaction curtails task‑specific harmonics.
* **Underexplored synergies** — Since gradient backpropagation propagates through independent intra‑block pathways,
the capacity built up within one block never informs another.
This rigidity dampens any potential expansions afforded by deeper weight reconfiguration spaces;
the network remains trapped within isolated “miniarchitectures” patchworked onto pretrained backbone weights.
* **Hyperparameter brittleness** — Determining an optimal value for \(b\)
exhaustively becomes expensive because repetitions entangle training budgets,
as illustrated empirically when moving away from convenient powers-of-two values;
size allocation must juggle competing needs—smaller blocks → little interaction space
vs larger blocks → rising parameter count without commensurate expressive benefit.
* **Inductive bias misfit** — AB effects induced through fixed partitions functionally resemble stacking fewer attention heads 
or smaller kernel footprints;
they impose unintended priors unsuitable for generic vision or language downstream tasks,
as shown experimentally when evaluating Maximum Improvement Rate metrics post finetuning.



Collectively these drawbacks confine original OFT’s practical applicability:
while model storage shrinks dramatically,
a rigid sparsity stylized architecture frustrates distinct forms of representation needed by state‑of‑the‐art sight & language adaptation pipelines.
