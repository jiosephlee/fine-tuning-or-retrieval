\title{A Textbook about the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

Chapter 3: 3 Rotary Position Embedding (RoPE)

Large language models rely on transformers whose attention mechanism treats every token independently unless an explicit notion of order is supplied through positional information. The most common strategy before rotary positional embeddings was a static lookup table of positional vectors appended element‑wise to each token embedding (“absolute” encoding). While simple, this construction requires discretising every possible position up to the maximum supported sequence length, leading both to memory bloat and numerical instability when a transformer never observes fresh positions during training—as soon as a new positional index appears that has never been seen during training an activation pattern far outside train‑time distribution (‘catastrophic’ values) arises.\[\]  Rotational embeddings solve this issue by letting each token’s position enter directly into trigonometric signals whose arguments grow linearly with the position index \(n\). Because adding extra tokens simply means evaluating trigonometric functions at larger arguments \(n\theta_i\), these signals preserve their statistical distribution regardless of how far apart two positions are in token space.\(\)

### # Formulation equation

Let \(d\) denote the embedding dimensionality allocated for queries or values inside every transformer layer (the total hidden size being \(d_{h}\)). Rotational embeddings pair half‑the‑dimensional axes into complex plane vectors,
each axis representing either a cosine or sine component:
\[
\boxed{
\left[
\cos( n \theta_0 ),\, \sin( n \theta_0 ),
\, \cos( n \theta_1 ),\, \sin( n \theta_1 ),
\, \dots ,
\, \cos( n \theta_{d/2-1} ),\, \sin( n \theta_{d/2-1} )
\right]
}
\tag{1}
\]
where \(n\in [0,\dots]\) enumerates token positions along a sequence.
The rotation angles themselves are determined through a progressive frequency schedule
\[
\theta_i=
\theta^{-\,{2i}/{d}}, 
\quad i=0,\dots,\frac{d}{2}-1 ,
\]
with a default base value \(\theta=10{000}\).  
For each low‑index dimension \(i=0\), the angle grows slowly (\(\theta_0=\theta^{0}=1\)), while higher dimensions receive progressively larger negative exponents meaning substantially higher angular speed along those axes.\(\)
By inserting these rotated vectors into query or key matrices,
the inner product between two keys becomes proportional to
\(e^{i\,(\Delta n)\,\cdot\,(\text{frequency vector})}\),
thereby encoding pairwise distances between compressed phase angles instead
of discrete indices.\(\)

### # Rotation frequency choice

Frameworks such as LLaMA adopt a *base* reciprocal exponential scheme for frequency selection.
Choosing
\(f_i = \frac{1}{\sqrt{\beta^i}}\)
with
\(\beta=\theta^{\,{2}/{d}}\)
ensures exponentially decreasing frequencies.
This structure means nearby tokens differ wildly along the first few (\(i < d/4\)) dimensions yet change very little along higher‑dimensional ones.
Consequently two types of algebraic interactions arise:
high‑frequency axes emphasise short‑range contextual cues,
while low‑frequency axes retain signal even when two tokens are thousands apart.\(\)
This contrasts sharply with what would happen were all frequencies set identically,
where distant token pairs would collapse onto nearly identical angle vectors,
rendering their rank‑wise relationships indistinguishable.\(\)

The final implication is that model weights trained on relatively short documents learn useful geometry over *all* dimensions once they encounter any measure \(\Delta n=n_j-n_k\).
Because no weights depend explicitly upon an arbitrary upper bound on sequence length,
the rope embedding formulation remains well‑behaved even when extrapolated beyond its pretraining window;
refining retinal layer growth amounts merely pulling down essential rotational speeds via an additional multiplicative *rescale* factor \(λ≥1.\)(See § # Non‑uniformity below.)

### # Relation between \(θ_i\) and dimensionality

Because each index’s corresponding pair has one cosine and one sine term,
the effective number of distinct angular components doubles per global embedding dimension.
Equation (1) gives us exactly one ‘pair’ per half‑dimension.
When moving through layers incrementally increase \(i\),
the exponentiation division feature scale halts back toward zero:
Each succeeding dimension receives an argument smaller by
\(β^{-1}\).
Thus lower dimension signals alternate frequently while higher ones progress slowly.
A crucial result discovered empirically is that *high‑frequency* components tend towards more regular spacing regardless how long the document becomes—
they help capture strict syntax close-ups,
whereas *low‑frequency* components manage broader topic drift laterality:
precisely those directions preserve inter‐token synergy once distances grow enormously.\(\)
Hence preserving key dimensions during interpolation—as LongRoPE does—keeps far‑apart token interactions inside numerical safety limits
while still delivering descriptive capacity where needed.\(\)

### # Benefits over sinusoidal absolute encodings

Absolute positional encodings normally construct an \(L×d/2×2\) table once at initialization:
each row holds either
\(0,\dots,L-1\)
directly fed into a cosine/sine formula:
if this table were collapsed into `sin(i·n)` style functions then global frequency would still be uniform;
one would still encounter numerically explosive behavior beyond pretraining bounds because positional identifiers conjugate differently per column.
Rotaries circumvent two principal problems:

1. **No precomputed lookup table** — Because each new index can instantly compute its own angle vector internally,
deployment does not require storing billions of constants—an impossible load for memory‑constrained GPUs—
and new lengths emerge without further model modifications;
this “statelessness” perfectly aligns with Latent Variable Model theory where self‐attention layers remain stable under unseen contexts.[^†]

2. **Smooth ordering structure** — Rotations generate continuous changes in angles linearly proportional unto distance.
For example adjacent tokens change negligibly along low‑frequency axes under mild rotations;
separated tokens maintain measurable separation regardless of overall chain length.[^♠]
If positional encodings were purely additive random noise or fixed one–hot complements—for instance adding fixed integer scalars—the model had learned arbitrary biases tightly intertwined with particular early indices.
Those biases collapse catastrophically once one steps outside distribution—a situation especially urgent when extending beyond four thousand tokens,’’

In practice:
Comparisons in LongRoPE’s ablation studies show naive “linear” interpolation obtained through shared rescaling across *all* dimensions (akin almost identically to simple uniform sinusoid stretching),
produces severe perplexity spikes already beyond twice its baseline support.
In contrast retraining only selective dimensions thanks partly allied angular magnitude preservation delivered consistent perplexities up through eight times longer sequences—even without re‑training.\(^††\)
These results validate that underlining potence above static sine/cos added tables lies fundamentally within rotational geometry itself rather than just remembering deterministic scalars.\(^‡§§§^‡^\)

---

Together, these insights lay cheap root reason why oscillatory rotational embeddings become core bedrock behind recent works—including LongRoPE—that push context lengths beyond several million tokens while keeping efficient adaptation cost low.\
