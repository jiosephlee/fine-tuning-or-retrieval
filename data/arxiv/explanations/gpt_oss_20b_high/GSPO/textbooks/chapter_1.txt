\title{A Textbook about the Paper: "Group Sequence Policy Optimization"}

Chapter 1: Fundamental Notions – Policies, Likelihoods & Rewards  

Large‑scale reinforcement learning (RL) techniques apply directly to language models whose parameters are denoted \( \theta \).  In every formulation that follows the language model acts as an **autoregressive policy** \( \pi_\theta \); it produces an output sequence one token at a time while conditioning on all previously generated tokens together with an input query \(x\).  Understanding how these policies are mathematically characterized is therefore prerequisite for interpreting any subsequent objective function or gradient calculation presented later in this book chapter or related research papers.\n\n\n# Redefining \( \boldsymbol{\pi_\theta (y\,\vert\,x)} = \displaystyle\prod_{t=1}^{|\!y|\!} \pi_\theta( y_t\,\vert\,x,\,
            y_{<t}) \)

The core building block of any autoregressive language model is its *sequence likelihood*.  
For a specific dialogue pair consisting of a user prompt \(x\) and an algorithmically generated response \(y=(y_1,\dots ,y_{|y|})\), the probability that policy \( \pi_\theta\) assigns jointly to all tokens equals the product over every token probability conditioned on every preceding token:
\[
    \pi_\theta( y\,\vert\,x )
    = \prod_{t=1}^{|\!y|\!}
      \pi_\theta( y_t\,\vert\,x,\,
                  y_{<t} ),
    \qquad
    y_{<t}\equiv (y_1,\dots ,y_{t-1}) .
\]
This decomposition implements two canonical assumptions together:\n\n* **Autoregressivity**—the probability mass assigned to future symbols depends exclusively on past symbols;\n* **Conditional factorization**—whereby elementwise conditionals multiply without interference.\n\nBecause every forward‑pass through an autoregressive network performs precisely this factorisation—one softmax output per token—the mathematical form above reflects exactly what is implemented during forward inference.\n\nIt is important—and frequently misinterpreted—that *token‑level* probabilities do **not** carry independent information functionally beyond their conditional kernelised formulation above.  Consequently any quantity derived from these individual probabilities should respect their compositional origin when applied during optimisation.\n\n\n# Query \(x\) Sampled From Dataset \( \boldsymbol{\mathcal{D}} \)

Reinforcement‑learning agents learn behaviour based on interactions collected under some *environmental* distribution \(p_{\mathcal{E}}\). In large‑scale language‑model fine‑tuning experiments this environment consists simply of user prompts sourced randomly from a curated background corpus \( \mathcal{D}\). Thus during optimisation we diffuse uniformly:\[
    p_{\text{env}}(x)\;\propto\;\mathbf{1}\!\bigl[x\in\mathcal{D}\bigr] .
\]\nIn practice one repeatedly draws queries \(x^{(i)}\sim p_{\text{env}}\), rolls out one or several responses distributed according to an *old* policy \( \pi_{\theta_{\text{old}}}\), obtains corresponding rewards \(r(x^{(i)},\,y)\), then performs policy updates towards improving expected returns under \(p_{\text{env}}\). Sampling directly from \( \mathcal{D}\) guarantees that optimisation outcomes generalise faithfully over the very distribution that deployed users ultimately observe.\n\n\n# Reward Function \( r(x,y)\)

Whenever reinforcement learning interacts with natural‑language tasks it requires an *evaluation signal* specifying how desirable an utterance is under its serving objective—be it factual accuracy atop mathematics problems or stylistic alignment upon creative dialogues.\nFrom an implementation standpoint every query–response pair receives a single scalar rating:\[
    r : (\mathcal{Q},\,\mathcal{\Theta})  \longrightarrow [0,\!1],
    \qquad
    r(x,y)\;\in[0,\!1].
\]\nTwo salient properties make such reward functions especially amenable herein:\n\n* **Boundedness** guarantees that gradient magnitudes remain finite even when responses grow arbitrarily long.\n* **Unit consistency** allows later normalisation against local statistics instead of relying import residual comparisons between disparate domains.\n\nPractically these scores arise either through automatic verification modules—comparing generated texts against gold solutions—or through sophisticated cost functions embedding deeper linguistic heuristics.\n\n\n# Normalised Advantage Estimator via Mean / Standard Deviation Over Groups

Rough quantification alone would fail whenever “good” answers vary wildly between distinct prompts: one problem’s maximum attainable score could top seventy percent while another’s ceiling sits near forty percent merely because easier questions allow bigger outstanding points statistics would screw up relative comparisons across prompts.If direct expected returns were optimised word‑by‑word without reference points an early prompt whose arbitrary reward hook happened accidentally inflate would dominate learning dynamics.\nInstead Group Sequence Policy Optimization introduces **group‑based standardisation**:\[
    A_i
    = 
    {\widetilde A}_{i}
    :=
      {
      {\displaystyle 
        {r(x,\!y_i)
          -
          {\rm mean}
            _{{j=1}}^G r(x,\!y_j)}
      }\over{
        {\rm std}
          _{{j=1}}^G r(x,\!y_j)}
      }
     ,
     \
     G=\text{\#samples generated for one query}.     
     \
     {\rm (i.e.\ }\, A_i=\widehat A_i).
  }
   For fixed \( G>10 \) these statistics converge reliably while remaining inexpensive––one pass through stored scores per rollout.\n\nBecause every response belonging one prompt contributes equally sized elements into numerator/denominator it follows easily that expected advantage always centres around zero:\(\mathbb E[A_i]=0\), while unit variance guarantees balanced scaling regardless differences among prompts’ absolute reward levels.\nThis stabilisation property eliminates large magnitude fluctuations arising particularly when handling longer responses—a point underscored empirically later when comparing GRPO against GSPO practices.\n\n--- End Chapter ---
