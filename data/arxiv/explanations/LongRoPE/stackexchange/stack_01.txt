\title{Stack Exchange of the Paper: LongRoPE}

### What exactly is the rescaling formula for RoPE in LongRoPE (notation confusion around \(\lambda\), \(\hat{\lambda}\), and \(\beta\))?
Question:
I'm confused by the unified RoPE expression used in the paper. The standard RoPE for position \(n\) uses angles \([\cos(n\theta_0), \sin(n\theta_0), \ldots]\) with \(\theta_i = \theta^{-2i/d}\) and \(\beta = \theta^{2/d}\), so the per-dimension angle can be written as \(\frac{n}{\beta^i}\).

For interpolation, the paper writes something like \(\cos\big(\frac{n}{\lambda(\beta)^i}\big)\) and later defines per-dimension factors \(\lambda_i\) and also uses \(\hat{\lambda}_i = 1/\lambda_i\), and a position gating function \(\mathbb{I}(\hat{\lambda}_i, \hat{n})\). Can someone clarify the exact angle used per dimension/head/layer? Is it:
- \(\cos\big(\frac{n}{\lambda_i\,\beta^i}\big)\) for \(n \ge \hat{n}\) and \(\cos\big(\frac{n}{\beta^i}\big)\) for \(n < \hat{n}\), or
- \(\cos\big(\mathbb{I}(\hat{\lambda}_i,\hat{n})\cdot \frac{n}{\beta^i}\big)\) with \(\mathbb{I}\) either 1 or \(1/\lambda_i\)?
Also, is \(\lambda\) ever a function of \(\beta\), or is it always dimension-specific constants \(\{\lambda_i\}\)?
Answer:
Short answer: the paper uses the per-dimension RoPE angle
$\theta_{n,i} = I(\hat{\lambda}_i, \hat{n}) * (n / \beta^i)$,
where $I(\hat{\lambda}_i, \hat{n}) = 1$ for $n < \hat{n}$ and $I(\hat{\lambda}_i, \hat{n}) = 1 / \lambda_i$ for $n \ge \hat{n}$. Equivalently, for dimension $i$

- if $n < \hat{n}$: angle = $n / \beta^i$ (original RoPE),
- if $n \ge \hat{n}$: angle = $n / (\lambda_i * \beta^i)$.

Thus the active rescale multiplies the whole original fraction by $1/\lambda_i$ (or, viewed as changing the denominator, divides $\beta^i$ by $\lambda_i$). The paper also defines $\hat{\lambda}_i = 1 / \lambda_i$ (so $\hat{\lambda}_i$ is the multiplicative factor applied to the angle), and searches directly over the set $\{\lambda_i\}$.

Explanation and how to read the notation in the paper
- The classic RoPE angle is written as $n / \beta^i$ (paper uses $\beta = \theta^{2/d}$ so the per-dim base is $\beta^i$). Position Interpolation (PI) or NTK variants can be written in the same form by picking particular $\lambda$ patterns (e.g., PI uses a uniform $\lambda = s$ across all $i$; dynamic-NTK gives different $\lambda$ as a function of $i$).
- In Eq. (3) the paper first wrote a unified form $\cos(n / \lambda(\beta)^i)$ to show that different methods are just different rescalings across dimensions. That expression is a high-level shorthand to indicate a per-dimension rescaling; it should not be read as a literal function $\lambda(\beta)$ that depends on $\beta$. Later they make the rescale explicit and per-dimension by introducing $\lambda_i$ and its reciprocal $\hat{\lambda}_i$.
- Concretely, the paper parameterizes the RoPE used during search as $\cos\big( I(\hat{\lambda}_i, \hat{n}) * (n / \beta^i) \big)$ and $\sin\big( I(\hat{\lambda}_i, \hat{n}) * (n / \beta^i) \big)$ with $I(\cdot)$ defined piecewise. They search over $\lambda_i$ (allowed range and monotonicity constraint), and use $\hat{\lambda}_i$ only as the multiplicative factor in the indicator function ($\hat{\lambda}_i = 1/\lambda_i$).

Which of your two options matches the paper?
The paper uses the first option you wrote, but expressed via the multiplicative indicator: for $n < \hat{n}$ use $\cos(n / \beta^i)$; for $n \ge \hat{n}$ use $\cos\big( n / (\lambda_i * \beta^i) \big)$. Equivalently it is $\cos\big( I * (n / \beta^i) \big)$ with $I \in \{1, 1/\lambda_i\}$.

Is $\lambda$ ever a function of $\beta$?
No. In the paper $\lambda$ (and the per-dimension $\lambda_i$) are treated as dimension-specific constants to be searched/found. The early notation $\lambda(\beta)^i$ is a notational shorthand to unify different interpolation formulas; operationally, LongRoPE searches a vector of scalars $\{\lambda_i\}$ (subject to monotonicity constraints) and a token threshold $\hat{n}$.

Intuition
Viewing rescaling as multiplying the original angle by $1/\lambda_i$ makes it clear what happens: larger $\lambda_i$ compresses angles for tokens beyond $\hat{n}$ in that dimension (positions become “closer” on the unit circle), while $\lambda_i = 1$ is pure extrapolation (no compression). The token threshold $\hat{n}$ encodes the second non-uniformity: early tokens ($n < \hat{n}$) keep the original angles because they tend to be most critical to attention, and only later positions get rescaled.

Wrap-up formula (explicit)
For RoPE dimension $i$ and token position $n$, with $\beta$ defined as in the paper:

$$
\theta_{n,i} =
\begin{cases}
n / \beta^i, & \text{if } n < \hat{n};\\[6pt]
n / (\lambda_i * \beta^i), & \text{if } n \ge \hat{n}.
\end{cases}
$$

and the embedding uses $\cos(\theta_{n,i})$, $\sin(\theta_{n,i})$. Hat-$\lambda_i$ in the paper notation is $\hat{\lambda}_i = 1 / \lambda_i$ and is the multiplicative factor applied to the original $n/\beta^i$.
