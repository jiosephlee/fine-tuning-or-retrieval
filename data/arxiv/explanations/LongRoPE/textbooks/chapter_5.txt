\title{A Textbook about the Paper: LongRoPE}

Chapter 5: LongRoPE: Problem Formulation

# Context extension ratio s = $L'/L$ and unified RoPE representation

Transformer models do not have a built‑in notion of token order, so positional encodings are added so the model can distinguish token positions. LongRoPE builds on the widely used Rotary Positional Embedding (RoPE). If a token is at position index $n$, the canonical RoPE encoding across the embedding's paired sine/cosine components can be written in the usual compact form as
\[
\left[\cos(n\theta_0),\ \sin(n\theta_0),\ \cos(n\theta_1),\ \sin(n\theta_1),\ \ldots \right],
\]
where the per‑dimension rotary angles satisfy $\theta_i=\theta^{-2i/d}$ for embedding dimension $d$ and a base constant $\theta$ (commonly $\theta=10000$ in many implementations). It is convenient to reparameterize the rotary angle for the $i$‑th (paired) component so that the angle is written as
\[
n\theta_i = \frac{n}{\beta^i},
\qquad\text{with}\qquad
\beta = \theta^{2/d}.
\]
This representation highlights that higher indexed dimensions correspond to progressively lower rotation frequencies (larger denominators).

When we talk about extending an LLM's context window, we compare the original (pretrained) maximum context length $L$ with a desired extended length $L'$. The context extension ratio is defined as
\[
s = \frac{L'}{L}.
\]
Intuitively, if we want tokens that previously occupied positions up to $L$ to map meaningfully into positions up to $L'$, we must adjust how position indices are converted into rotation angles. A common and simple approach is to uniformly scale down the effective position index (so that new positions map into the angular range the model was trained on). LongRoPE places such adjustments into a single, unified mathematical representation of RoPE rescaling that can express many prior methods as special cases and also enable more flexible, per‑dimension, per‑position schemes.

# Per‑dimension rescale factors $\lambda_i$ and position threshold $\hat{n}$ for early tokens

To capture the two important forms of non‑uniformity the paper identifies, LongRoPE introduces two degrees of freedom:

1. A per‑dimension rescale factor $\lambda_i$ for each RoPE dimension index $i$. Each $\lambda_i$ controls how much the rotation angle for that particular frequency is reduced (interpolated) when mapping to the extended range. Larger $\lambda_i$ means stronger downscaling (more interpolation), while $\lambda_i=1$ means no scaling (extrapolation).

2. A position threshold $\hat{n}$ that designates a prefix of the input sequence whose rotary angles are left unchanged. The idea is that the first $\hat{n}$ tokens (the "early tokens") often receive strong attention and are thus especially important to preserve exactly; for these positions, the original pretrained RoPE should be used without interpolation.

Concretely, LongRoPE expresses the new rotary angle for token position $n$ and RoPE dimension $i$ as
\[
\text{angle}(n,i) \;=\; \mathbb{I}(\hat{\lambda}_i,\hat{n})\times\frac{n}{\beta^i},
\]
where the indicator/scaling function $\mathbb{I}$ depends on both the chosen per‑dimension rescale and the token position. The per‑dimension rescale values are parametrized by $\lambda_i$ (with $\hat{\lambda}_i=1/\lambda_i$ in the paper's notation), and the threshold $\hat{n}$ decides whether to apply the rescaling to a given token position. This formulation lets us treat each RoPE frequency independently, and also gives the option of protecting the earliest token positions from any rescaling.

# Indicator $\mathbb{I}(\hat{\lambda}_i,\hat{n})$: original RoPE for $n<\hat{n}$; rescaled angles for $n\ge\hat{n}$

The indicator function in LongRoPE is defined simply and deterministically to combine the two non‑uniformities. For a chosen per‑dimension rescale $\lambda_i$ and a prefix length $\hat{n}$, the function is
\[
\mathbb{I}(\hat{\lambda}_i,\hat{n}) \;=\;
\begin{cases}
1 & \text{if } n < \hat{n},\\[4pt]
\displaystyle \frac{1}{\lambda_i} & \text{if } n \ge \hat{n}.
\end{cases}
\]
Thus, for positions in the preserved prefix ($n<\hat{n}$) the angle remains exactly $\frac{n}{\beta^i}$, i.e., the original pretrained RoPE. For positions beyond the prefix the angle becomes $\frac{1}{\lambda_i}\cdot\frac{n}{\beta^i} = \frac{n}{\lambda_i\beta^i}$ — equivalently, the effective token index has been scaled down by $\lambda_i$. This scaling reduces the angular magnitude for large positions so that angles remain inside the range the model has been exposed to during pretraining.

Some important implementation and interpretive remarks follow:

- The per‑dimension $\lambda_i$ values are allowed to vary across $i$ so that high‑frequency (low index) dimensions can be scaled less (smaller $\lambda_i$) than low‑frequency (high index) dimensions. This respects the intuition that different RoPE frequencies encode positional information at different granularities; preserving high‑frequency components helps the model distinguish closely spaced tokens.

- The prefix threshold $\hat{n}$ is typically chosen much smaller than $L$; it is a way to preserve a small set of highly attended positions exactly. The optimal $\hat{n}$ is task‑ and extension‑dependent, and LongRoPE treats it as an explicit search parameter.

# Optimization target: minimize next‑token loss (perplexity) over long documents $|\mathbf{x}|\ge L'$

Having specified how the rotary angles are parameterized by the set of variables $\{\lambda_i\}$ and $\hat{n}$, LongRoPE frames the design of those variables as a search/optimization problem. The ultimate goal is to choose rescale factors and the prefix threshold so that the resulting LLM with modified RoPE behaves well on long sequences. Concretely, given a corpus of long text samples $\mathbf{X}$ where each sample $\mathbf{x}\in\mathbf{X}$ has length at least $L'$, we want to minimize the standard next‑token prediction loss (cross‑entropy) or equivalently the perplexity of the language model on these long inputs.

If we denote the language model loss on a set of inputs when using a particular RoPE instantiation as $\mathcal{L}(\text{LLM}(\text{RoPE},\mathbf{X}))$, then the optimization problem is expressed as
\[
\arg\min_{\{\lambda_i\},\,\hat{n}}\ \mathcal{L}\big(\text{LLM}(\text{RoPE}(\{\lambda_i\},\hat{n}),\mathbf{X})\big),
\]
subject to the RoPE mapping
\[
\text{RoPE}(n,i) = \left[\cdots,\ \cos\!\Big(\mathbb{I}(\hat{\lambda}_i,\hat{n})\cdot\frac{n}{\beta^i}\Big),\ \sin\!\Big(\mathbb{I}(\hat{\lambda}_i,\hat{n})\cdot\frac{n}{\beta^i}\Big),\ \cdots\right].
\]
This objective directly aligns the search for interpolation/rescaling parameters with the model's final metric of interest: how well the model predicts tokens when it must process sequences of length $L'$.

Because evaluating $\mathcal{L}$ requires running the LLM on long inputs and computing perplexity, LongRoPE treats selection of $\{\lambda_i\}$ and $\hat{n}$ as a black‑box search (the paper uses an evolutionary search) rather than attempting to derive closed‑form optimal settings. The search leverages empirical perplexity on held‑out long sequences as the fitness signal.

# How PI, NTK, and YaRN fit into the unified framework as special cases

One of the benefits of the unified rescaling formulation is that several previously proposed interpolation/extrapolation schemes appear as simple settings of the same parameters. Understanding this correspondence clarifies both the flexibility of LongRoPE and why more expressive, non‑uniform solutions can outperform earlier methods.

- Linear positional interpolation (PI). PI uniformly scales every rotary angle by the extension ratio $s$. In the LongRoPE parametrization, PI corresponds to choosing a single scalar $\lambda_i = s$ for every RoPE dimension $i$ and choosing $\hat{n}=0$ (so no prefix is preserved). Then for all positions
  \[
  \text{angle}(n,i) = \frac{1}{\lambda_i}\cdot\frac{n}{\beta^i} = \frac{n}{s\beta^i},
  \]
  which is exactly linear downscaling of positional indices across all frequencies.

- NTK‑based interpolation / extrapolation. NTK‑inspired schemes distribute the interpolation pressure non‑uniformly across RoPE dimensions: lower‑index (higher frequency) dimensions are adjusted less, while higher‑index (lower frequency) dimensions are scaled more. In the unified notation, NTK corresponds to a monotone sequence of $\lambda_i$ such that $\lambda_0 \le \lambda_1 \le \cdots$, often expressed in theories as a dimension‑dependent formula (e.g., $\lambda_i = s^{f(i)}$ for some increasing mapping $f$). Setting $\hat{n}=0$ yields a pure per‑dimension interpolation/extrapolation pattern. The NTK viewpoint gives the theoretical motive for per‑dimension monotonicity: preserving high frequencies reduces crowding of nearby positions.

- YaRN (three‑group strategy). YaRN partitions RoPE dimensions into three frequency groups and applies different strategies per group: aggressive extrapolation (no scaling) for the highest frequencies, NTK‑style dimension‑adaptive scaling for the middle group, and linear interpolation (PI) for the lowest frequencies. In LongRoPE terms, YaRN picks piecewise constant or piecewise monotone values of $\lambda_i$ across ranges of $i$ (for example $\lambda_i=1$ for a high‑frequency block, $\lambda_i=s$ for a low‑frequency block, and intermediate $\lambda_i$ in the middle block), typically with $\hat{n}=0$. This shows YaRN is an instance of per‑dimension rescaling restricted to three groups.

Viewing these prior techniques as special cases highlights the core flexibility LongRoPE introduces: instead of committing to a single global scalar or a coarse grouping, LongRoPE allows an arbitrary monotone (or more general) per‑dimension profile $\{\lambda_i\}$ together with an optional early‑token protection $\hat{n}$. This richer family can preserve critical components of the pretrained RoPE while still mapping far‑away positions into a familiar angular range for the model, which the paper empirically shows leads to substantial improvements in perplexity and downstream retrieval/generation tasks when extending context windows to very large sizes.

In summary, the LongRoPE problem formulation unifies positional interpolation as a search over per‑dimension scale factors and an early‑token threshold, with the optimization objective of minimizing next‑token loss on long documents. This unified view both explains existing methods as constrained instances and provides the parameterization that LongRoPE searches over to find high‑quality, non‑uniform rescalings suitable for extremely large context extensions.
