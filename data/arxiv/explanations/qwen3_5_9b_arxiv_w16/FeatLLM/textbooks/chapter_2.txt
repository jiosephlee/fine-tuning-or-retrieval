# Problem Definition: Formalizing the Classification Task with Labeled Samples

The foundation of any machine learning task begins with a precise mathematical definition of the problem at hand. In the context of tabular learning and classification, this involves a dataset composed of $N$ distinct samples, denoted as $\mathcal{D} = \{(\mathbf{x}^i, \mathbf{y}^i)\}_{i=1}^{N}$. Each sample $\mathbf{x}^i$ represents a single instance of the data and is mathematically formulated as a $d$-dimensional vector containing $d$ input features. These features are not merely numerical values; they are semantically defined by a set of natural language descriptions, represented as $F = \{f_j\}_{j=1}^{d}$, which provide crucial metadata such as the data type (e.g., categorical vs. numerical) and domain-specific definitions. The relationship between these features and the target outcome is captured by the label $\mathbf{y}^i$, which belongs to a predefined finite set of classes. This formulation allows us to treat the task as a standard supervised learning problem where the goal is to map an input vector $\mathbf{x}$ to a specific class label $\mathbf{y}$.

In this framework, a critical concept for "few-shot" learning scenarios is the distinction between the full dataset available for analysis and the limited subset used for training. In low-data regimes, one cannot rely on large volumes of labeled examples; instead, only a small number $k$, where $k < N$, are randomly sampled to form the training set. This constrained environment necessitates model architectures that can generalize from minimal information while leveraging external prior knowledge. The formalization establishes that every sample possesses explicit feature definitions ($F$) alongside its observed values ($\mathbf{x}^i$), setting the stage for converting these heterogeneous data types into a structured format suitable for computational processing. Furthermore, recognizing that real-world datasets vary significantly in dimensionality—with some containing over 100 attributes—the problem definition must account for scenarios where $d$ is large, which historically poses challenges for methods dependent on fixed context windows in language models.

# From Natural Language to Boolean Logic: Translating Heuristic Rules into Binary Indicators

A pivotal innovation in bridging the gap between human reasoning and machine inference is the transformation of natural language rules into computable binary indicators. Traditional machine learning models operate directly on raw feature vectors, whereas this approach introduces an intermediate step where an interpretable model (such as an LLM) generates "rules" based on prior knowledge and data observations. These rules are human-readable logical conditions that describe specific criteria under which a particular class should be identified—for instance, "If age is greater than 50 AND blood pressure exceeds 140, then High Risk." To make these linguistic insights machine-processable, they must be translated from semantic text into Boolean logic operators (AND, OR, NOT) and mathematical comparisons (greater than, less than).

The theoretical mechanism behind this translation relies on parsing strategies that convert textual descriptions into executable code or direct logical evaluations. Since large language models often generate syntactic variations—such as writing "greater than" instead of "$>$"—the system employs an automated parsing procedure using the LLM itself to generate Python code based on these inferred rules. This code represents the semantic intent of the rules without requiring manual engineering or complex custom parsers for every dataset variant. Once parsed and executed against each sample in the dataset $\mathcal{D}$, these logic gates yield binary outcomes for each rule relative to each class. Specifically, for any given sample $\mathbf{x}^i$ and class $k$, if sample $i$ satisfies rule $r$, it produces a binary value; otherwise, it does not. This process effectively projects the high-dimensional semantic space of natural language descriptions onto a discrete Boolean space, creating new intermediate variables derived solely from logical operations rather than raw data patterns alone."
