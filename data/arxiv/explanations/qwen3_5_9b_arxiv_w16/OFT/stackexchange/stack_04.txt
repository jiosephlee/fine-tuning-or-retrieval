\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### How does OFT handle layers with different input/output dimensions compared to block-diagonal decomposition?
Question:
In Section 3.2, the authors discuss parameter efficiency using a block-diagonal matrix $R`=`diag(R_1, ..., R_r)` where each block is `O(d/r). However, standard diffusion models often have layers with mismatched dimensions (e.g., Convolution layers or Attention mechanisms where Query/Key/Value dimensions differ). If `d` represents feature dimension and `n` represents number of channels/neurons, how exactly do we construct an orthogonal matrix `R` when applying OFT to a Transformer's attention weight matrix which might be `d_q x d_k` or applied to multiple head dimensions simultaneously? Does the block size depend on `d` or `n`, and what happens if `d` cannot be evenly divided by `r`?
Answer:
The paper distinguishes between applying OFT to standard fully connected layers and its application to architectures like Transformers with mismatched dimensions by addressing two separate but related mechanisms: the construction of the orthogonal matrix $R$ based on the feature dimension $d$, and the strategy for handling specific layer types like attention or convolutions where input-output shapes differ.

Fundamentally, OFT constructs a layer-specific orthogonal transformation $R \in \mathbb{R}^{d \times d}$, where $d$ represents the dimension of the neuron vectors (the number of rows in a fully connected weight matrix). The block-diagonal decomposition $R = \text{diag}(R_1, \dots, R_r)$ is explicitly proposed to improve computational efficiency; each block $R_i$ operates on a subspace of dimension $d/r$. Consequently, if you are applying OFT to a softmax attention weight matrix of size $d_q \times d_k$, the relevant orthogonal transformation acts on the embedding space $d_k$ (since the weights map from space $k$ to space $q$, preserving energy within the source space neurons while transforming their directions relative to the input). The block size in this context is therefore determined by $d_k$, not the output dimension $d_q$. If the number of embedding dimensions cannot be evenly divided by a chosen integer $r$, the paper implies that one should choose an appropriate integer divisor or adjust the block structure, but strictly speaking, standard linear algebra requires square blocks for orthogonality in this specific sum-of-squares hyperspherical energy formulation; however, in practice for neural networks, one would typically redefine the base block size to be an integer divisor of $d$. The paper notes that equity is not strictly required in their description but highlights that choosing a small number of large blocks reduces parameters at $\mathcal{O}(d^2/r^2)$ or adjusts accordingly.

More critically for your question regarding Query/Key/Value mismatches and Convolutional layers, Section "OFT is agnostic to different architectures" clarifies that OFT is applied independently to each weight matrix $\bm{W}$ within a layer. For an attention mechanism involving distinct Query ($Q$) and Key ($K$) projections with different dimensions (e.g., $\bm{W}_Q: H_{in} \to d_q$ and $\bm{W}_K: H_{in} \to d_k$), OFT does not construct a single large permutation matrix covering both spaces. Instead, it learns two separate orthogonal matrices: one $\bm{R}_Q \in \mathbb{R}^{d_q \times d_q}$ applied via $\bm{W}_Q' = \bm{R}_Q\bm{W}_Q$ and another $\bm{R}_K \in \mathbb{R}^{d_k \times d_k}$ applied similarly to $\bm{W}_K$. This works because hyperspherical energy is defined per neuron vector; maximizing the preservation of angles among Q-neurons requires an operator on Q-space only, and similarly for K-neurons. The mismatch between dimensions ($d_q \neq d_k$) does not violate orthogonality because these matrices are not applied to each other's vector spaces directly but rather to self-transform their respective weight matrices.

Furthermore, when dealing with Convolutional layers where spatial dimensions vary or depth differs across feature maps (channels), the paper suggests interpreting these layers through a channel-wise lens. If one has an arbitrary mismatch such as input channels differing from output channels in a non-linear context, standard OFT in its primary formulation applies to square weight matrices representing linear mappings between equal-dimension feature spaces (or specifically within heads). However, extensions like Re-scaled OFT introduce diagonal scaling matrices $\bm{D}$ which can help manage magnitude differences if dimensions or channel groups are non-uniform. For convolutional filters, which can have varying kernel sizes or depths, OFT is applied within specific filter banks or treated such that each distinct set of neurons (e.g., all filters for a specific channel output) forms a group transformed by its own defined orthogonal block-diagonal structure aligned with that feature dimension.
