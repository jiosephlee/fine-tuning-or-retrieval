# Preliminaries on OFT Reparameterization and Cayley Transform

To understand the proposed framework, we must first ground our understanding in the foundational mechanics of Orthogonal Finetuning (OFT). In this paradigm, when adapting a pretrained foundation model to a downstream task, the method seeks to modify the existing weight matrices rather than training them from scratch. Specifically, consider a pretrained linear layer characterized by a weight matrix $\bm{W}^0 \in \mathbb{R}^{d \times n}$, where $d$ represents the input feature dimension and $n$ represents the output dimension. The standard forward pass computes the output vector $\bm{z} \in \mathbb{R}^{n}$ given an input vector $\bm{x} \in \mathbb{R}^{d}$ as $\bm{z} = (\bm{W}^0)^\top\bm{x}$. OFT introduces a learnable transformation to this process by inserting an orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ into the forward pass. The modified forward computation becomes $\bm{z} = (\bm{R}\bm{W}^0)^\top\bm{x}$. It is important to distinguish this multiplicative approach from low-rank adaptation methods like LoRA, which add a low-rank matrix additively; OFT instead rotates the feature space via multiplication.

The motivation for enforcing orthogonality on $\bm{R}$ stems from a desire to preserve the intrinsic geometric structure of the pretrained weights during adaptation. The core insight is that neural layers function by transforming neurons such that pairwise angles between them remain informative. If we were to train a generic weight matrix, we might distort these angles, effectively erasing some of the semantic knowledge embedded in the pretraining phase. However, if $\bm{R}$ is orthogonal ($\bm{R}\bm{R}^\top = \bm{I}_d$), it acts as an isometry, rotationally transforming vectors in $\mathbb{R}^d$ without altering their lengths or the angles between them. Consequently, the relative relationships between neurons defined by the columns of $(\bm{W}^0)^\top$ are preserved exactly throughout the finetuning process. This preservation ensures that the model retains its ability to handle tasks related to its pretraining while acquiring new task-specific capabilities through rotation.

To make this orthogonal matrix learnable without violating its orthogonality constraint during gradient-based optimization, direct updates like standard stochastic gradient descent (SGD) cannot be used because they typically push non-orthogonal matrices off the Stiefel manifold (the set of orthogonal matrices). Instead, we utilize an analytical parameterization strategy known as Cayley transform (or Cayley parameterization). This method maps any parameter-free skew-symmetric matrix to a unique orthogonal matrix. Specifically, if we define a learnable matrix $\bm{Q}$ such that it is skew-symmetric (\emph{i.e., } $\bm{Q} = -\bm{Q}^\top$, meaning $Q_{ij} = -Q_{ji}$ for all scalars $i,j$), then the matrix $\bm{R}$ can be computed as:
$$
\bm{R} = (\bm{I}_d + \bm{Q})(\bm{I}_d - \bm{Q})^{-1}.
$$
Because $\bm{Q}$ is skew-symmetric and initialized to zero (representing an identity transformation), this formulation guarantees that for any value of $\bm{-Q}$ within the stable region of convergence, $(\bm{I}_d + \bm{-Q})(\bm{-I}_d - (-\boldsymbol Q)^{-1})^{-1}$ will always produce a valid orthogonal matrix $\hat{\textbf R}} {\mathcal R}}$ where 9 result uniquely determined by these same constraints$. Unlike constrained optimization approaches that require projection steps at every iteration or use complex retraction operations on manifolds beyond 9 result uniquely determined by these same constraints$. The major advantage here is computational simplicity: we can simply update $\hat{\textbf R}} {\mathcal R}}$ directly using standard optimizers while rigorously ensuring mathematical correctness. This setup forms the critical foundation upon which further structural sparsity can be overlaid.

# Formulating Matrix Factorization as Information Transmission on Grid Graphs

The central theoretical contribution of this work involves shifting perspective from raw algebraic factorization to information theory and graph connectivity. When composing a $d$-dimensional dense orthogonal matrix $\hat{\textbf R}} {\mathcal R}}$ using multiple sparse matrices multiplied together ($\hat{\textbf R}} {\mathcal R}} = (\frac{\hat{\textbf B}_m}{(\boldsymbol B'}))$, one might intuitively view it merely as multiplying smaller matrices to achieve density. However, this paper reframes such factorizations as information transmission problems defined on grid-structured graphs. In this analogy, constructing a dense connection between input nodes and output nodes is equivalent to ensuring that information originating from every source node can successfully traverse intermediate layers to reach every destination node by level $m+1$.
