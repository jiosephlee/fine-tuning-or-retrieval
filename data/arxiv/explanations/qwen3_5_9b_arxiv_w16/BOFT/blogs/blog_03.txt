\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# From Grids to Graphs: Visualizing How BOFT Transmits Information

Large foundation models like GPT-3 and Stable Diffusion have revolutionized artificial intelligence, but their sheer size makes training them from scratch prohibitively expensive. Consequently, the field has shifted toward parameter-efficient finetuning (PEFT), allowing researchers to adapt these powerful models to new tasks without retraining billions of parameters. While methods like Low-Rank Adaptation (LoRA) and Orthogonal Finetuning (OFT) have shown promise, they often struggle to balance the number of trainable parameters with the model's expressivity. In the paper "Parameter-Efficient Orthogonal Finetuning via Factorization," the authors introduce a novel method called Orthogonal Butterfly (BOFT). At the heart of BOFT is a clever conceptual shift: they treat the construction of a dense orthogonal matrix not as a pure linear algebra problem, but as an information transmission problem on a grid-structured graph.

To understand this shift, one must first grasp why standard Orthogonal Finetuning (OFT) faces efficiency challenges. OFT works by applying an orthogonal matrix $\bm{R}$ to transform neurons within a layer, ensuring that the pairwise angles between neurons remain preserved during training. Mathematically, if we have a pretrained weight matrix $\bm{W}^0$, OFT modifies the forward pass from $\bm{z}=(\bm{W}^0)^\top\bm{x}$ to $\bm{z}=(\bm{R}\bm{W}^0)^\top\bm{x}$. A standard dense orthogonal matrix requires $\mathcal{O}(d^2)$ parameters, where $d$ is the dimensionality. To reduce this cost, previous versions of OFT used block-diagonal structures, splitting the matrix into smaller independent blocks. While this reduces parameters to $\mathcal{O}(bd)$, it imposes rigid sparsity patterns that prevent the model from approximating classic linear transforms like Fourier or Hadamard transforms effectively. The core challenge posed by the paper is how to construct a *dense* orthogonal matrix that is still parameter-efficient.

The authors solve this by reframing matrix factorization as information flow on a graph. Imagine constructing a $d \times d$ dense matrix as connecting every node in a source set to every node in a target set. Each non-zero element $R_{ij}$ in the matrix can be visualized as a directed edge from input node $j$ to output node $i$. If we decompose this large dense matrix into multiple sparse matrices, say $\bm{R} = \bm{B}_m \cdot \bm{B}_{m-1} \cdots \bm{B}_1$, this process becomes equivalent to transmitting information through layers of nodes in a grid-structured graph with $(m+1) \times d$ nodes total. Information flows sequentially through these layers, where each sparse matrix $\bm{B}_i$ governs connectivity between adjacent levels.

For example, consider a minimal example with $d=4$. If we try to generate a dense output using just one sparse factorization step, we create many isolated paths where information gets stuck because there are missing edges between specific nodes across levels. This lack of connectivity implies that certain non-zero values in the resulting matrix would mathematically be forced to zero. The information transmission view reveals that for our decomposed matrices to produce a truly dense result, every node in the first level must possess at least one path leading to every node in the final level after sequential multiplication through all intermediate layers. This graphical perspective allows us to count exactly how many "free edges" are needed and where they should be placed to satisfy orthogonality constraints while minimizing trainable parameters.
