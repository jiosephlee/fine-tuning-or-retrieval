# The Secret Sauce of xLSTM: Exponential Gating and Scalar Mixers

## Why Old LSTMs Stall

For decades, the Long Short-Term Memory (LSTM) was the king of sequence modeling. Its core innovation, introduced in the 1990s, relied on a clever mechanism called the "constant error carousel." Imagine a highway where information about the past flows forward with almost no loss, controlled by gates that decide what to keep and what to forget. While this architecture revolutionized text generation until 2017, it hit a fundamental wall.

The standard LSTM suffers from a significant flaw known as the "inability to revise storage decisions." To understand this, consider a task where you must compare the current input against everything seen so far to find the most similar one. In a standard LSTM, once a piece of information is written to memory via an input gate, it stays there. Even if a much better or more relevant piece of information arrives later, the old data cannot be easily erased or updated. The model is locked into its initial decisions, leading to degradation in tasks requiring dynamic state tracking or complex conditional logic like nearest neighbor search.

## Enter sLSTM: A New Way to Remember

This is where xLSTM steps in. The paper introduces a specific variant called sLSTM (scalar LSTM), which deals directly with this rigidity. Instead of keeping memory locked behind sigmoid gates that strictly output values between 0 and 1, xLSTM introduces **exponential gating**.

In traditional LSTMs, gates use a sigmoid activation function $\sigma$. This function bounds the gate value $f_t$ or $i_t$ between 0 and 1 essentially freezing updates if they become too small or too large. sLSTM replaces these sigmoid gates with exponential activation functions $\exp$. An exponential function ranges from zero to infinity ($0$ to $\infty$). This seemingly simple change acts as an unbounded mechanism for control. If the network determines that new information is crucial, it can drive the input gate to effect massive changes immediately rather than leaking tiny updates over time. This allows the model to effectively "overwrite" old memories when necessary, solving the revision problem inherent in classic LSTMs.

## The Stability Problem and the Normalizer State

One might assume that switching from bounded sigmoids to unbounded exponentials would solve everything instantly. However, raw exponentials can produce astronomically large numbers, causing numerical overflow and instability during training. While some previous works suggested using an additive bias to stabilize gates, xLSTM proposes a neurobiologically inspired solution: the **normalizer state**.

To implement exponential gating without losing stability, sLSTM introduces an auxiliary variable called the normalizer state $n_t$. The update rule for this state runs in parallel with the standard cell state $c_t$:
\begin{align}
n_t \ &= \  f_t \ n_{t-1} \ + \ i_t 
\end{align}
Here, $f_t$ acts as a decay factor for past accumulation, while $i_t$ adds new weight contributions.
