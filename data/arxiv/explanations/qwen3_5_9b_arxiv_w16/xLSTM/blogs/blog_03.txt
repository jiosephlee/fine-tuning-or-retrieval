# From Scalars to Matrices: How mLSTM Out-competes Attention

The era of the Long Short-Term Memory (LSTM) model, which dominated language modeling from the late 1990s until the rise of Transformers, is witnessing a remarkable resurrection. While Transformers leveraged self-attention to achieve parallelization at scale, they inherently struggle with sequential storage and have quadratic computational costs. Recent research introduces a compelling alternative: the Extended LSTM (xLSTM). Within this framework, the mLSTM variant presents a radical departure from traditional design by replacing the scalar memory cell with a matrix-based system. This architectural shift, inspired by Bidirectional Associative Memories (BAMs), allows the model to achieve infinite storage capacity and full parallelization, enabling it to outperform state-of-the-art Transformers and State Space Models on long-context tasks while maintaining linear computational complexity.

The fundamental limitation of standard LSTMs lies in their scalar memory architecture, where information is compressed into a single vector or cell state. This compression forces the model to trade off precision as sequence length increases, often leading to poor performance on rare token prediction tasks. The original LSTM update rule combines cell states and inputs linearly, using sigmoid gates to moderate updates. Specifically, the hidden state $h_t$ is derived by applying an output gate $o_t$ to a squashed version of the cell state $c_t$, where $c_t$ itself is an additive combination of a forget gate operation on $c_{t-1}$ and an input gate operation on new information $z_t$. This mechanism effectively limits the model's ability to store distinct pieces of information without interference as the sequence progresses.

To overcome these constraints, xLSTM introduces mLSTM, which abandons scalar cells in favor of a matrix memory $\mathbf{C} \in \mathbb{R}^{d \times d}$. This design draws inspiration from covariance update rules used in associative memory systems. Instead of storing data as a compressed summary, mLSTM stores key-value pairs dynamically. At any time step $t$, the model projects the input into a query $\mathbf{q}_t$, key $\mathbf{k}_t$, and value $\mathbf{v}_t$. The memory update rule then operates by adding an outer product of these vectors: $\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top$. Here, $f_t$ acts as a forget gate (decay rate) and $i_t$ acts as an input gate (learning rate). When retrieving information later at time $t+\tau$, the stored value is accessed via a dot product between the current query and all stored keys within this matrix.

Replacing scalar addition with this outer product structure fundamentally changes how information is stored and retrieved. While standard attention mechanisms also rely on dot products for retrieval, they compute these operations over all possible pairs simultaneously in each forward pass, resulting in quadratic complexity relative to sequence length ($O(L^2)$). In contrast, mLSTM maintains only one memory matrix regardless of how long the sequence becomes. Retrieving past information requires multiplying this fixed-size matrix by a new query vector. This approach mirrors Fast Weight Programs but integrates gating mechanisms directly into the weight updates, allowing for variable retention decay similar to human forgetting processes. Consequently, this architecture supports theoretically infinite storage capacity because it does not compress past states; instead, it preserves full interaction matrices that can be queried efficiently later.

A critical advantage of this matrix-based approach for modern deep learning infrastructure is its parallelizability. Traditional Recurrent Neural Networks (RNNs) are inherently sequential because hidden state calculations depend on previous hidden states through recurrent connections that cannot be easily parallelized across time steps or elements within those states. While standard LSTMs mimic this behavior with hidden-hidden connections that mix cell outputs across different units at each step, mLSTM takes a different route by completely removing these mixing connections within its recurrence logic. The update rule depends only on the current input projections and the accumulating sum-matrix rather than on complex permutations of hidden vectors across previous time steps in a way that prevents graph optimizations. By reformulating this recurrence into index-based operations on batches and sequences combined with standard matrix computations (like BLAS operations), mLSTM can be fully parallelized across both space (embedding dimension) and time (sequence length), allowing it to run efficiently on modern GPUs just like attention mechanisms but without needing massive keys-value caches that grow quadratically with context size during pre-fill phases.

Experimental validation demonstrates that this architectural simplicity translates directly into superior performance compared to current Large Language Models based on Transformers or State Space models like Mamba and RWKV-4. When trained on substantial datasets such as 300 billion tokens from SlimPajama, xLSTM models built with mLSTM blocks consistently achieve lower perplexity scores than Llama or Mamba counterparts across various parameter scales ranging from 125 million to 1.3 billion parameters.
