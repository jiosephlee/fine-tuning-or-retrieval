xLSTM: Extended Long Short-Term Memory

# Foundations: The Legacy and Limitations of LSTMs

The journey of deep learning sequence modeling is deeply rooted in the architecture of the Long Short-Term Memory (LSTM). Introduced in the 1990s by Hochreiter and Schmidhuber, the LSTM was designed to overcome the persistent vanishing gradient problem that had plagued earlier Recurrent Neural Networks (RNNs). By incorporating a sophisticated gating mechanism and a dedicated cell state to manage information flow, LSTMs enabled neural networks to learn long-term dependencies, effectively solving problems where distant elements in a sequence needed to influence one another. For decades, LSTMs stood as the gold standard for sequence modeling, powering early Large Language Models (LLMs) and achieving remarkable success in domains ranging from text generation and machine translation to hydrological forecasting and reinforcement learning. They excelled at learning abstractions, such as syntax neurons for natural language and number neurons for arithmetic tasks, demonstrating a robust capacity to store semantic information. However, despite their historical dominance and qualitative strengths, modern scaling laws have revealed inherent structural limitations within the original LSTM framework. As the architectural community embarked on scaling models to billions of parameters using techniques like attention mechanisms found in Transformers, it became clear that the classical LSTM design was hitting a ceiling. Specifically, three fundamental issues were identified that hindered further performance gains when scaled: an inability to revise previously made storage decisions, a limited capacity due to scalar memory constraints, and a lack of parallelizability enforced by memory mixing. Addressing these specific bottlenecks required a reimagining of the core LSTM components, leading to new innovations such as exponential gating and novel memory structures that allow for matrix-based storage and efficient parallel computation.

# History of Recurrent Neural Networks and the Vanishing Gradient Problem

To understand the necessity of LSTMs, one must first examine the challenge they were built to solve: the vanishing gradient problem inherent in standard RNNs. In a traditional RNN, information is passed from one time step to the next through a hidden state $h_t$, which is typically a function of the current input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. Mathematically, this involves backpropagating errors through time to update weights based on how far back in the sequence those weights influenced the current output. As sequences become long, this gradient is multiplied by derivatives repeatedly at each time step. If these derivatives are less than one on average—a common situation with standard activation functions like tanh or sigmoid—the gradient diminishes exponentially as it travels backward through time. This phenomenon prevents the network from learning meaningful updates for weights governing events that occurred many steps ago, effectively breaking the connection between distant parts of the sequence. The LSTM proposal was revolutionary because it introduced two central ideas to combat this decay: gate-based regulation of information flow and what is known as a "constant error carousel." These mechanisms allowed gradients to flow backward without attenuation over long sequences, making deep temporal reasoning possible for an entire generation of AI research until more powerful architectures emerged.

# 2. Evolving the Architecture: Exponential Gating and Memory Mixing

The evolution from the standard LSTM to the xLSTM framework begins with a fundamental reassessment of how information is stored and revised within a neural network's memory cell. Historical iterations of Recurrent Neural Networks (RNNs), particularly the original LSTM, were designed to mitigate the vanishing gradient problem through gating mechanisms that clipped updates to a bounded range using sigmoid functions. While effective for maintaining long-term dependencies, these bounded gates introduced a limitation known as the "inability to revise storage decisions." In real-world scenarios, such as reasoning tasks or dynamic environment modeling, a model may need to overwrite an entire memory slot because it has since encountered more relevant information. The standard LSTM adds new information but struggles to erase old information because the forget gate operates in isolation from the input gate; if an old piece of information was never forgotten, new but conflicting information cannot fully overwrite it. This chapter details the introduction of sLSTM (Scalar LSTM), which resolves this architectural bottleneck by integrating exponential gating with a novel normalization mechanism. By allowing gates to grow without bound and subsequently normalizing their effect through a dedicated memory state, sLSTM gains the ability to completely revise stored values, thereby enabling robust state tracking capabilities that were previously absent in recurrent architectures.

## Introduction to sLSTM (Scalar LSTM) Concept

To empower LSTMs with the ability to dynamically revise stored decisions based on context, the sLSTM architecture introduces a modification where input and forget gates utilize exponential activation functions rather than sigmoid activations. This shifts the fundamental nature of how data flows into and out of the cell state vector, $c_t$. In traditional formulations, gates like $i_t$ and $f_t$ are constrained between 0 and 1, limiting their capacity to "blow up" or suppress specific components of the memory relative to others simultaneously in a multiplicative manner that doesn't change their magnitude relative to the overall scale. The sLSTM concept posits that if inputs can take on arbitrarily large values via exponential activation, $\exp(\tilde{i}_t)$ and $\exp(\tilde{f}_t)$, then provided these magnitudes are correctly normalized, they can physically annihilate old data or amplify new data without issue. Unlike previous attempts at exponential gating where gradient instability was a major concern, sLSTM achieves this by coupling these unbounded gates with auxiliary states—the normalizer state—that are updated in lockstep with the primary memory cell. This allows the ratio of input signal strength to cumulative forget magnitude to be optimized at every time step, effectively allowing the network to store vectors in high-dimensional space where non-linear separations are easier to achieve (invoking Cover's Theorem) while still updating them sequentially via hidden-hidden connections known as memory mixing.

## Exponential Gating: Replacing Sigmoids with Exp Activations

The core algebraic shift in sLSTM involves replacing the standard sigmoid function $\sigma(x) = 1/(1+\exp(-x))$ used for gating with the natural exponential function $\exp(x)$. Specifically, in equation \ref{eq:slstmforward}, both the input gate $i_t$ and optionally the forget gate $f_t$ are defined as $\exp(\tilde{i}_t)$ and $\sigma(\tilde{f}_t)$ (or alternatively $\exp(\tilde{f}_t)$). This change allows for an asymmetry where registers for new information ($\text{Input}$) and registers for saving old information ($\text{Forget}$) operate on different scales. In an ideal scenario required for revising storage decisions at arbitrary timescales apart (e.g., one timestep versus thousands), one mechanism must remain high while dropping off rapidly until monitored again by another mechanism; this dynamism is best achieved by exponential processes rather than saturated sigmoid thresholds. However, simply applying exponentials creates immediate numerical instability issues where massive values can cause overflow or underflow during forward propagation and_backpropagation_, creating gradients that approach zero or infinity rather than providing meaningful updates. Consequently, naive implementation fails due to computational constraints preventing such large value dynamics from being trained effectively within standard IEEE floating-point formats used in modern hardware.

# 3. Expanding Capacity: The Matrix Memory mLSTM

To truly understand the revolutionary nature of the xLSTM framework, one must delve into the specific architectural modifications that enable it to outperform not only traditional LSTMs but also modern State Space Models and Transformers in specific regimes of information density. While standard LSTMs have served as the backbone of deep learning for nearly three decades, their reliance on a scalar cell state imposes a fundamental bottleneck: they can only store a single weighted value at any given time step. This limitation is mathematically analogous to trying to store an entire encyclopedia in a single digit; information must be aggressively compressed, leading to poor performance on rare token prediction tasks where unique associations are required. The solution proposed in this research is the Matrix Memory Long Short-Term Memory, or mLSTM. By elevating the memory cell from a scalar $c_t \in \mathbb{R}$ to a matrix $\mathbf{C}_t \in \mathbb{R}^{d \times d}$, the mLSTM fundamentally changes how information is stored and retrieved, utilizing principles derived from Bidirectional Associative Memories (BAMs) and optimized covariance update rules. This transition allows the model to maintain dense associations between vectors without the need for hidden-to-hidden recurrence rings, thereby achieving full parallelizability equivalent to efficient self-attention mechanisms. In this chapter, we will dissect how this matrix-centric approach resolves storage limitations while preserving the sequential modeling strengths of recurrent networks.

### From Scalars to Matrices: Conceptualizing Matrix Memory

The primary conceptual shift introduced by the mLSTM lies in reconceptualizing what it means to "remember" within a recurrent neural network. In standard architectures like the vanilla LSTM or even state-of-the-art State Space Models (SSMs), the memory at time $t$ is effectively a point in a vector space or a compression thereof. When you feed an input $\mathbf{x}_t$, the network updates this scalar memory, and crucially, because this memory is just a single scalar value per dimension, you lose all structural relationship between that value and others stored previously unless you rely on external attention or complex mixing mechanisms that themselves often incur sequential costs. The mLSTM addresses this by defining the cell state not as a simple accumulation of past inputs, but as a high-dimensional matrix that explicitly encodes relationships between keys and values.

Imagine the memory not as a stack of receipts where each item sits alone, but rather as a vast library where every shelf has both an address tag (the key) and a book placed upon it (the value). A scalar LSTM is akin to having only one shelf where you have to overwrite old books or crumple up old receipts before placing new ones. The mLSTM, however, maintains a full covariance matrix where dimensions interact directly through matrix multiplication during retrieval. This architectural decision transforms the memory capacity from being linearly dependent on dimensionality alone (as in sparse models) to being capable of storing quadratic amounts of information relative to dimensions via the matrix structure itself. However, simply increasing dimensions would lead to trivial solutions if not constrained by physics; if we could store arbitrary data in arbitrary locations without cost, we would need infinite dimensions for long sequences. The mLSTM introduces optimal constraints via its update rule. It leverages vector pairs represented as keys ($\mathbf{k}_t$) and values ($\mathbf{v}_t$), which are derived from the current input $\mathbf{x}_t$. The intuition here is similar to how large language models learn attention: instead of computing pairwise similarity for every token at inference time (which leads to quadratic complexity), these similarities are stored proactively within the matrix structure during training or sequence generation using an inner product operation. This pre-computation of relationships within the matrix allows for instant retrieval later using only dot products, effectively decoupling storage complexity from retrieval cost while maintaining linear computational efficiency with respect to sequence length.

### Bidirectional Associative Memories (BAMs) in Modern Contexts

The theoretical foundation for this matrix memory architecture is heavily rooted in Bidirectional Associative Memories (BAMs), first proposed by researchers such as Kohonen and Anderson in the 1970s. While modern deep learning emphasizes backpropagation and differentiable programming, BAMs introduced earlier concepts of content-addressable memory that resonate strongly with xLSTM's design philosophy. In a classic BAM system presented bidirectionally between cells $R_1$ and $R_2$, presenting one vector retrieves its associated partner vector from another storage unit. The original BAMs often relied on hard energy minimization dynamics or specific training procedures that were not directly compatible with modern gradient-based optimization over long auto-regressive sequences without modification. However, xLSTM revitalizes this framework by embedding these associative properties directly into a differentiable recurrent cell that runs seamlessly alongside standard deep learning stacks like ResNet layers or Transformer blocks.
