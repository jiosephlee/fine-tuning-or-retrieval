\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### What is the precise definition of 'Process Supervision' versus 'Outcome Supervision' in terms of how $\\hat{A}_{i,t}$ is computed?
Question:
The paper distinguishes between Outcome Supervision RL (OS) and Process Supervision RL (PS) using GRPO. For OS, it says $\hat{A}_{i,t}$ is set to the normalized final reward for all tokens. For PS, it provides rewards at specific indices ($index(j)$). The formula given is $\hat{A}_{i,t} = \sum_{index(j) \ge t} \\widetilde{r}_i^{index(j)}$. This looks like an n-step return or cumulative sum. In standard Reinforcement Learning theory, wouldn't we need a discount factor $\\gamma$ here? The paper doesn't explicitly mention a discount factor in these summations. Is it assumed to be 1 (no discounting)? If so, does this cause instability if reasoning steps are very long chains, effectively giving equal weight to errors near start vs end of computation? Also, how does this differ fundamentally from computing advantages using a learned Value Function in standard RL?
Answer:
In the context of the DeepSeekMath paper, the distinction between Process Supervision and Outcome Supervision lies fundamentally in **when** the learning signal is provided during generation and **how** that signal is propagated backward to optimize every token in the chain of thought.

For **Outcome Supervision (OS)**, the reward model evaluates only the final correctness of an output. Consequently, the advantage $\hat{A}_{i,t}$ assigned to every single token $t$ within that output is simply set to the normalized final reward $\widetilde{r}_i$. Mathematically, if an output receives a normalized score of $0.8$, every token in that sequence gets an advantage update based on $0.8$. This treats all reasoning steps as equally critical solely because they contribute to a successful final answer; intermediate errors that were later "fixed" by subsequent steps receive the same positive gradient as correct steps.

**Process Supervision (PS)** aims to provide finer-grained control by leveraging a Process Reward Model (PRM) that assigns a score at specific reasoning steps. If we denote the end token indices of these steps as $index(1), index(2), \dots$, the PRM produces rewards $\mathbf{R} = \{r_1^{index(1)}, r_2^{index(2)}, \dots\}$. When these are normalized to get $\widetilde{r}_i^{index(j)}$, they represent how well each specific step performed. To calculate the advantage for any token $t$, the paper employs a formulation equivalent to an $n$-step return in standard RL:
$$ \hat{A}_{i, t} = \sum_{j: index(j) \ge t} \widetilde{r}_i^{index(j)} $$
This formula sums up all future process rewards from token $t$ onward, implying that a token's quality is judged by its contribution to all subsequent reasoning milestones, not just the very end.

You correctly identified that standard RL typically includes a discount factor $\gamma < 1$ to prioritize immediate rewards over distant ones. In this specific formulation, it is indeed implicitly assumed that $\gamma = 1$. While this might seem risky for long chains—potentially giving equal weight to an early setup step and a late-stage calculation—it serves a specific purpose here: mathematical correctness often requires strict adherence at *every* intermediate step. By setting $\gamma=1$, the method ensures robust learning signals propagate forward without attenuation, reinforcing that skipping or erring at any point in a rigorous proof invalidates future successes just as severely as an early error does.

Furthermore, this approach differs fundamentally from using a learned Value Function ($V_\psi$) found in traditional PPO. In standard PPO, advantages are calculated relative to such a value function (often using GAE), which attempts to estimate how good a state is *before* seeing the full return, serving as a baseline for variance reduction. The paper replaces this second model entirely with group-relative statistics (subtracting mean and dividing by standard deviation across a group of outputs). By combining Group Relative estimation with PS ($\gamma=1$), DeepSeekMath eliminates the memory cost of training a critical value network while using step-level rewards to guide policy gradients more precisely than outcome-only signals could ever achieve on complex reasoning tasks.
