\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### How does GRPO handle varying output lengths within a group for advantage estimation?
Question:
When sampling a group $\\{o_1, o_2, \\cdots, o_G\\}$ from Equation (3), these outputs may have different lengths ($|o_i|$ varies). The advantage calculation involves summing over tokens $t$. In PPO with a critic, we usually pre-compute $V(o)$ at the end of each sequence to normalize advantages at each step. GRPO uses relative rewards within the group. If one output in the group has length 100 and another has length 500, how exactly are their token-wise advantages aligned? Does GRPO pad shorter sequences with zero-reward tokens? If so, how does that affect the gradient calculation compared to PPO where we have a specific baseline value function $V_\\psi(o)$?
Answer:
The mechanism of handling varying output lengths in GRPO relies on normalizing advantages **per group per prompt**, rather than attempting to align token sequences across different group members. The paper presents this by sampling a fixed number of outputs, $G$, for a single question $q$, forming the set $\{o_1, o_2, \cdots, o_G\}$, where each output $o_i$ can naturally possess a different length $|o_i|$. Crucially, the algorithm does not pad these sequences or truncate shorter ones to match a common length; instead, it treats each sampled output as an independent trajectory within the context of that specific question.

The advantage calculation $\hat{A}_{i,t}$ is derived entirely from the statistical properties of rewards within this specific group. For outcome supervision, GRPO computes the total reward $r_i$ for each completed sequence $o_i$ using the reward model. It then calculates the mean $\text{mean}(\mathbf{r})$ and standard deviation $\text{std}(\mathbf{r})$ specifically over these $G$ scalars. The normalized reward for any sequence $i$ is determined solely by $\frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$. Consequently, if one sequence has length 100 and another has length 500, their respective normalized rewards are two distinct values used to define their internal advantage curves. For process supervision, this logic extends step-wise: the algorithm identifies specific token indices defining reasoning steps for each output and normalizes the rewards at those indices relative to all other step-rewards in the group before summing them up to establish $\hat{A}_{i,t}$ for every token present in that specific sequence.

This approach fundamentally differs from PPO's reliance on a global critic model $V_{\psi}(q)$. In standard PPO, $V_{\psi}(q)$ is a scalar predicted by a separate value network that represents the baseline expected return for question $q$, independent of how many samples were generated or what their lengths were. The advantage in PPO is calculated as $A_t = r_t - V_{\psi}(q)$ (simplified), requiring the value estimate to be consistent across all sampling attempts. In contrast, GRPO obviates the need for this external model entirely by using the "group score" as its own baseline. By subtracting the group mean from individual rewards before dividing by standard deviation, GRPO effectively centers each sequence's reward distribution relative to its peers in that batch. This ensures that the gradient update for a token in a short prominent answer accounts for how much better or worse it performed compared to answers (of varying lengths) generated by the same policy at that moment. Because there is no attempt to align tokens across different output lengths via padding or truncation in GRPO itself—those sequences are processed as distinct entities within a single gradient step—the computational graph is straightforward: we optimize over the sum of per-token contributions where each contribution comes from its own unique length-based trajectory relative to its group's average performance. This design choice eliminates the memory overhead associated with maintaining a learned value function and simplifies implementation since one need not worry about complex masking strategies required to handle variable-length padding when comparing sequences against a static critic baseline.
