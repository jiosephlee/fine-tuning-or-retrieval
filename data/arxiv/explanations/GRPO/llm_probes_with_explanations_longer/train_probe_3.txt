According to the paper 'DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models', initializing the model from a general LLM rather than from a code-initialized checkpoint such as DeepSeek-Coder would most likely lead to decreased math performance. The paper explicitly motivates initializing DeepSeekMath-Base 7B from DeepSeek-Coder-Base-v1.5 7B because starting from a code-trained model “is a better choice compared to a general LLM,” and then backs this up with ablation studies showing that prior code training measurably boosts downstream mathematical reasoning. In two-stage experiments, “Code Training for 400B Tokens → Math Training for 150B Tokens” produces stronger results on GSM8K and MATH than a matched pipeline that replaces the first-stage code tokens with general tokens. Moreover, code pretraining substantially enhances program-aided reasoning (PoT) and also improves chain-of-thought performance without tools, leading to the best outcomes after subsequent math training. These empirical results indicate that replacing the code-initialized starting point with a general LLM baseline would remove a key source of improvement and thus reduce final math performance.

This observation is also conceptually grounded in how code pretraining shapes the model’s inductive biases and skill set for mathematical tasks. Code corpora expose the model to strictly structured syntax, algorithmic patterns, and stepwise problem decomposition, which align well with mathematical reasoning and with formats like chain-of-thought and program-of-thought. Concretely, exposure to executable procedures and libraries (e.g., Python with “math” and “sympy”) strengthens the model’s ability to translate a problem into computable steps, a capability the paper shows to be beneficial when solving math via tool integration. In contrast, general-language pretraining emphasizes surface-level semantics and broad world knowledge, but provides fewer signals for symbolic manipulation, formal reasoning, and precise state tracking. The paper’s results on mixing code and math tokens further suggest that code tokens help retain and synergize computational skills during math training, whereas general tokens do not provide the same scaffolding. Taken together, both the empirical comparisons and the reasoning about learned structure support the claim that starting from a general LLM rather than a code-initialized checkpoint would likely degrade mathematical performance.
