# Overview of the Feature-First Inference Paradigm

The paradigm shift offered by the \textsf{FeatLLM} framework represents a fundamental departure from conventional approaches to Large Language Models (LLMs) in tabular learning. Traditional methods, often referred to as end-to-end inference approaches, treat the LLM as a black-box classifier. In these standard pipelines, every single input sample is serialized into natural language and passed directly through the LLM, which processes the entire dataset for every prediction. This design suffers from significant computational overhead at inference time, as it requires repetitive LLM queries for each observation. Furthermore, these methods are often constrained by the context window limits of the model; as the number of features in a tabular dataset expands, the serialized data quickly becomes too large to process efficiently, often necessitating dropout or truncation that degrades performance.

\textsf{FeatLLM}, in contrast, adopts a "feature-first" inference paradigm. Instead of using the LLM to output a probability distribution directly for a given sample, it assigns the LLM the specific role of an expert feature engineer. The goal is not prediction itself but the discovery of high-quality decision boundaries or rules that separate classes based on input features. The core intuition behind this approach is that if an LLM can identify the critical conditions under which a specific class occurs—formulated as logical rules—then these rules can be evaluated deterministically on new data without further interaction with the complex language model. This permission to shift capability allows \textsf{FeatLLM} to bypass the heavy computational cost of individual sample queries during inference.

Once these rules are extracted and formalized into deterministic binary features (indicating whether a sample satisfies a specific condition), the task of inferring class likelihood is offloaded to a simple machine learning model, such as linear regression with non-negative weights. This downstream model learns to compute a weighted sum of these binary features plus a softmax activation to produce probability estimates. By decoupling rule generation from final prediction, \textsf{FeatLLM} achieves two major advantages: first, it maintains low inference latency because rule evaluation is computationally inexpensive compared to LLM query generation; and second, it eliminates scalability issues regarding prompt size. Even if an original dataset contains hundreds or thousands of columns, only the generated rules and their corresponding evaluation code need to be processed during inference, effectively expanding the effective context window beyond native model limitations through code execution rather than token consumption. This architecture ensures that \textsf{FeatLLM} remains feasible for real-world applications where label collection is costly and computational efficiency at runtime is paramount.

# Two-Step Reasoning Process: Causal Inference and Rule Derivation

To achieve high-quality feature engineering without requiring heavy fine-tuning, \textsf{FeatLLM} employs a structured reasoning process designed to mimic the deductive capabilities of an expert analyst. The framework prompts an LLM to follow a rigorous two-step derivation path for each target class: causal feature inference followed by decisive rule extraction. This disaggregation prevents the model from prematurely committing to spurious correlations and ensures that only features with genuine relational strength are converted into hard constraints for subsequent modeling.

The first step focuses on causal inference or tendency identification. In this phase, the LLM is instructed to analyze the relationship between input features and the target class definition without relying on any specific training examples provided in a few-shot fashion at this moment alone. Instead, it leverages its extensive prior knowledge derived from vast text corpora to hypothesize which features are theoretically relevant to the problem domain—for instance, understanding that age might be relevant for disease prediction based on general medical knowledge rather than just statistical correlation in noisy limited data. By separating this stage from example-dependent reasoning, \textsf{FeatLLM} mitigates overfitting patterns present in small datasets and encourages adherence to known scientific principles embedded within pre-training data.
