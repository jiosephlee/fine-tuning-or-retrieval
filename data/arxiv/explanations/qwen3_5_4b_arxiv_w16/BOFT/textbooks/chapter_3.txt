# Sparsity Patterns: Perils of Independent Block Processing

In the landscape of parameter-efficient fine-tuning (PEFT), the seminal work on Orthogonal Finetuning (OFT) introduced a paradigm shift by preserving the angular relationships between neurons rather than merely adding low-rank perturbations. To handle the prohibitive cost of training a full $d \times d$ orthogonal matrix—which scales quadratically with dimension, requiring $\mathcal{O}(d^2)$ parameters—early implementations relied on decomposing this high-dimensional task into $r$ smaller, independent sub-tasks. This approach introduced a block-diagonal structure to the orthogonal matrix $\bm{R}$, defined as $\text{diag}(\bm{R}_1, \bm{R}_2, \dots, \bm{R}_r)$, where each block $\bm{R}_i$ has dimensions $b \times b$ and the total dimension $d$ is partitioned such that $br=d$.

The intuition behind this block-diagonal strategy is straightforward: if we can learn a locally invertible transformation within small blocks, we can stitch these together to form a global permutation-like update. This drastically reduces the trainable parameters to $\mathcal{O}(bd)$, effectively trading memory for parameter count. However, this pinching of the high-dimensional space into rigid sub-problems creates immediate theoretical and practical hurdles. The most intrinsic issue lies in the arbitrariness of this partitioning. In standard linear algebra and data representation theory, there is no inherent property that justifies dividing the $d$ dimensions of a neuron into $r$ specific groups based solely on their index. The indices themselves are arbitrary labels assigned during model initialization and pretraining; therefore, enforcing a separation where dimensions $1$ through $b/2$ interact only with other dimensions in that same range, while ignoring all cross-group interactions (e.g., between index 1 and index $b+1$), imposes an artificial constraint on the model's representational capacity.

From an information theory perspective, this limitation becomes starkly obvious when visualizing the flow of data through these matrices. Consider a vector input that needs to be fully transformed across its entire dimensionality to capture downstream task nuances. In a dense orthogonal matrix, information flows freely from every source dimension to every destination dimension according to the optimal transformation learned for the specific task. In contrast, the block-diagonal structure creates "silos." If an information unit resides in dimension ten and needs to be rotated into direction twenty-five by finetuning parameters residing in dimension five's block, it cannot happen independently; however, if step 8 falls in dim 5's block and step 2 falls into dim 2's block (assuming sorted indices for simplicity), they still cannot mix effectively without inter-block coupling. This structural decoupling means that while the model maintains sparsity in terms of non-zero entries relative to a full matrix ($O(d)$ vs $O(d^2)$), it fails to capture true correlations between distant dimensions because those correlations are physically impossible under the fixed sparsity pattern unless they happen by chance within a specific block alignment.

Consequently, while OFT with block-diagonal structures provides a baseline for stability and parameter efficiency compared to full finetuning, it suffers from restricted expressivity. The model is forced to approximate complex transformations using only local moves within predetermined slots. This rigidity suggests that simply scaling up these small blocks does not necessarily improve performance quadratically; rather, it raises the threshold difficulty for approximation if those small blocks remain disconnected from parts of the space they should influence but do not inhabit due to their fixed boundaries. To overcome this barrier without sacrificing parameter efficiency legally (i.e., truly minimizing parameters), one must abandon static partitioning altogether and instead seek factorizations where sparsity arises dynamically from graph topologies that naturally allow dense connectivity while keeping edge counts minimal. The solution to this puzzle lies not in rearranging indices into blocks, but in discovering a communication protocol—a graph topology—that allows every node to talk to every other node using far fewer edges than a direct link would suggest. This leads us directly to studying how random sparse connections fail and how specific structured connections succeed.

# The Inductive Bias Problem in Fixed-Structure Finetuning

The concept of *inductive bias* refers to assumptions made by an algorithm regarding solutions good enough for future tasks before those problems are even encountered or observed during training. In deep learning models like vision transformers or large language models (LLMs), architecture choices often imbue these models with biases that constrain what kinds of data they can learn most easily without explicit regularization costs.
