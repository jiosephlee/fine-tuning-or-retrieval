### Reframing Matrix Multiplication as Data Flow

In the realm of deep learning, particularly within the context of orthogonal finetuning, standard approaches often treat matrix operations through purely algebraic lenses. One might simply observe that a dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ requires $\mathcal{O}(d^2)$ parameters to store explicitly. However, the fundamental challenge in parameter-efficient finetuning is not merely finding *any* orthogonal matrix, but constructing one that is dense (capable of expressing complex transformations) while minimizing the number of trainable parameters. Traditional strategies like Orthogonal Finetuning (OFT) attempt to solve this by imposing rigid structural assumptions, such as block-diagonal sparsity, which inevitably sacrifice expressivity. The core difficulty lies in reconciling the requirement for density with the desire for sparsity without violating the mathematical constraint of orthogonality.

To resolve this tension, we introduce a novel conceptual lens: the **Information Transmission View**. This framework reframes the problem of generating a dense orthogonal matrix from a product of sparse matrices as an information flow problem on a grid-structured graph. Instead of viewing $\bm{R}$ solely as a collection of numbers satisfying geometric constraints, we interpret it as a system where information travels from source nodes to destination nodes across intermediate stages. Consider the factorization $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$, where each $\bm{B}_i$ is a sparse square matrix. We can visualize this sequence as a pipeline connecting $d$ input dimensions (nodes at level 0) to $d$ output dimensions (nodes at level $m$). Each matrix $\bm{B}_i$ acts as a switchboard or router operating between adjacent levels of this pipeline—specifically, it defines how information flows from the nodes at level $i$ to the nodes at level $i+1$.

Under this interpretation, every non-zero element in a matrix $\bm{B}_i$ represents an active communication channel or edge allowing data transfer between two specific dimensions at consecutive steps. Conversely, every zero element signifies a blocked link where information cannot propagate directly from one node to another during that specific transformation step. Consequently, constructing a dense final matrix $\bm{R}$ is equivalent to designing a series of interconnected routers such that *every* piece of initial information originating from any source node eventually reaches *every* destination node after passing through all layers. If even a single path exists between two nodes that never activates regardless of how many times we multiply by subsequent matrices (due to structural zeros blocking all routes), the resulting product will remain sparse rather than dense. Thus, the algebraic property of density emerges naturally from topological completeness: for $\bm{R}$ to be dense ($\mathcal{O}(d^2)$), the underlying communication graph must be fully connected in terms of reachability from start to finish.

This shift in perspective offers profound advantages for analyzing parameter efficiency. By mapping matrices to graphs, we can decompose complex optimization problems into manageable sub-problems regarding network topology and edge selection. The "information transmission" metaphor allows researchers and practitioners to reason about what constitutes an efficient representation not just by counting parameters statically, but by evaluating dynamic connectivity requirements. It clarifies why arbitrary random sparse products fail to produce dense matrices—they likely lack sufficient paths for complete information propagation—and guides us toward structured designs that guarantee reachability while keeping edge counts minimal. Furthermore, this view bridges fields outside pure mathematics; concepts derived from computer networking and signal processing regarding optimal routing and broadcasting become directly applicable tools for designing neural network architectures that balance computational cost with functional capacity.

### Nodes as Dimensions, Edges as Connections

To rigorously operationalize this framework, we must precisely define how neurons correspond to nodes and how weight updates correspond to edges within our grid-structured graph model. Let us consider a linear layer in a neural network with an input dimension $n$ and an internal feature dimension $d$. In orthogonal finetuning paradigms like OFT or BOFT, we aim to learn an orthogonal transformation $\bm{R} \in \mathbb{R}^{d \times d}$ applied post-multiplication (or pre-multiplication depending on convention) to preserve angular relationships between features while adapting them for downstream tasks. Within our information transmission view, let us assume without loss of generality that we are interested in transforming signals residing in $d$ distinct dimensions into another set of $d$ dimensions via a chain of transformations involving $m$ sparse matrices: $\bm{R} = \prod_{j=1}^m \bm{B}_j$.

Here, each dimension $k \in \{1, 2, ..., d\}$ serves as both an origin and a destination point in our communication network. Imagine arranging these dimensions vertically across time steps or processing stages labeled by integers $0$ through $m$. At stage 0 (input), there are $d$ active nodes representing the initial state vectors; similarly, at stage $m+1$ (output), there are corresponding target nodes waiting for incoming signals. Between any two adjacent stages $i$ and $i+1$, exactly one transition occurs governed entirely by the specific sparse matrix $\bm{B}_{i+1}$. The entries within this transition matrix dictate which nodes communicate with which others during this hop. Specifically, if we examine the element located at row index $(u,v)$ within matrix $\bm{B}_{i+1}$—denoted hereafter as $(\bm{B}_{i+1})_{uv}$—this scalar value represents whether there is an active directed edge connecting node $v$ at stage $i$ to node $u$ at stage $i+1$. If $(\bm{B}_{i+1})_{uv} > 0$, it implies that whatever signal resides at node $v$ entering stage $i$ will successfully traverse into node $u$ emerging from stage $i+1$. If $(\bm{B}_{i+1})_{uv} = 0$, then no direct connection exists; signal flow between these specific pairings is severed for this particular step in the sequence.

It is crucial to distinguish between "direct connections" provided by individual matrices and "indirect paths" formed by sequences thereof. A single non-zero entry guarantees immediate transmission capability between two adjacent levels' nodes but says nothing about long-range dependencies unless combined with other matrices in the product chain.
