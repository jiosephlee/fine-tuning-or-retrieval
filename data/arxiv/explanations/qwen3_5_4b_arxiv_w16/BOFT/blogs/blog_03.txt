\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# From Block-Diagonal to Butterfly Factorization: Solving the Parameter Efficiency Paradox

Large foundation models have revolutionized fields ranging from natural language processing to computer vision, but their sheer scale—often comprising hundreds of billions of parameters—makes training them from scratch prohibitively expensive. To bridge the gap between pre-training and downstream task adaptation, researchers have turned to parameter-efficient finetuning methods. Among these, Orthogonal Finetuning (OFT) has gained attention for its ability to preserve the semantic knowledge of pretrained models by maintaining the angles between neurons through orthogonal transformations. However, a significant bottleneck remains: OFT typically requires a large number of trainable parameters due to the high dimensionality of orthogonal matrices, limiting its practicality compared to methods like LoRA.

The core issue with standard OFT lies in how it represents these orthogonal matrices. To achieve computational efficiency without sacrificing performance, the original approach relies on a block-diagonal structure. This structure divides the dimensions of a neuron into groups, applying different orthogonal transformations independently within each block. While this reduces the parameter count from $\mathcal{O}(d^2)$ (where $d$ is the dimensionality) to $\mathcal{O}(bd)$ with $b \ll d$, it introduces a rigid assumption that treats neuron dimensions as independent silos. Because the sparsity pattern is fixed based on index groups rather than learned data dynamics, this approach sacrifices the model's expressivity and fails to approximate classic linear transforms effectively. The fundamental question becomes: can we construct a dense orthogonal matrix that supports complex interactions between neuron layers while still being parameter-efficient?

To answer this, we can reframe matrix factorization as an information transmission problem visualized through graph theory. In this view, a dense orthogonal matrix represents a grid-structured graph where every node in the source set must be able to transmit information to every node in the destination set via directed edges generated by sequential matrix multiplications. A naive single dense matrix creates $\mathcal{O}(d^2)$ connections, which is both computationally heavy and parameter-inefficient. The block-diagonal method creates fewer edges by design, but these connections are strictly localized, preventing global flow between certain nodes. We need a topology that connects all nodes efficiently using far fewer edges than a full dense connection but more connectivity than fixed blocks.

This is where butterfly factorization offers an elegant solution. Inspired by the Cooley-Tukey algorithm for fast Fourier transforms, butterfly structures provide a graph topology capable of densely connecting $d$ source nodes and $d$ receiver nodes with only $\mathcal{O}(d \log d)$ edges. By constructing an orthogonal matrix as a product of $m = \log d$ sparse orthogonal butterfly factors, we drastically reduce the number of trainable parameters with minimal loss in expressivity. This approach allows us to treat the generation of a dense orthogonal matrix not as a static algebraic constraint but as a dynamic process of information exchange across levels in our graph.

The mathematical formulation leverages this structural insight by decomposing a large orthogonal matrix into multiple smaller blocks followed by permutations that coordinate their interactions across the grid levels. Specifically, if we define $m = \log(d/b)$ for some block size $b$, we can form an efficient parameterization known as Orthogonal Butterfly (BOFT). Contrary to what one might expect with repeated sparse operations potentially degrading accuracy or convergence properties during finetuning, theoretical analysis confirms that BOFT maintains strong expressivity and training stability within the orthogonal group $O(d)$. More importantly, this structured approach naturally facilitates interpolation between general orthogonal transforms and identity matrices, offering better generalization guarantees than unstructured methods without relying on rigid block assumptions that hinder architectural flexibility.

The shift from block-diagonal decomposition to butterfly factorization represents more than just a reduction in variable count; it signifies a change in how we constrain hypotheses for downstream learning tasks. While various techniques reduce parameters—for example, by freezing entire layers or using low-rank updates—they often struggle with preserving complex relational structures necessary for high-performance task adaptation. BOFT addresses this by introducing structural priors derived from efficient network topologies found in signal processing and computer science. By leveraging permutations derived from butterfly factors at each level of recursion, we ensure that information flows are maximally connected despite sparsity constraints imposed at construction time ($\bm{R} = \prod_{i=1}^m \tilde{\bm{B}}_{(d,i)}$). This generalized framework effectively optimizes over all possible sparsity patterns rather than being limited by predetermined blocks—an essential capability when moving beyond specific tasks like controllable text-to-image generation to broader adaptation scenarios in language and vision domains
