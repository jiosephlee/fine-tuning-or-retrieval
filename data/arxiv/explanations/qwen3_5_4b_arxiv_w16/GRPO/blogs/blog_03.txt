# Simplifying Reinforcement Learning: The Case for Group Relative Policy Optimization (GRPO)

If you have followed the recent surge in large language model (LLM) performance, you likely know the struggle associated with training them. While Supervised Fine-Tuning (SFT) teaches models to follow instructions, pushing them to solve complex mathematical problems often requires Reinforcement Learning from Human Feedback (RLHF) or its variants. The gold standard for this has been Proximal Policy Optimization (PPO), an algorithm that excels but is notoriously heavy. To stabilize training, PPO relies on a "critic" model—a separate neural network that must be trained alongside the policy model to estimate values and calculate advantages. This architecture demands significant memory and computational resources, making it a bottleneck for developers running experiments. Today's research introduces **DeepSeekMath**, which utilizes **Group Relative Policy Optimization (GRPO)**, a streamlined variant designed to strip away the critic while maintaining, and even improving upon, mathematical reasoning capabilities. The result is a training paradigm that is more efficient, cheaper to run, and surprisingly effective on benchmarks like the competition-level MATH dataset.

At its core,研究生的 traditional RL approach struggles because it tries to predict the absolute error of a response against a learned value function. In practice fine-tuning LLMs, this hallucinates noise or fails to capture nuance because the value function itself is another large model that needs updating. GRPO flips this script by eliminating the critic entirely. Instead of predicting where a solution ends up relative to an external yardstick, GRPO looks inward at a group of diverse answers generated by the same policy model in response to a single question. Imagine asking an AI graduate math problem; instead of expecting one perfect answer, the AI generates six different drafts ($o_1$ through $o_6$). Within this specific group, some answers are clearly better than others based on their final score from a reward model. GRPO uses these internal comparisons—specifically the average and standard deviation of rewards within that group—to normalize future steps as if there were an absolute baseline. This allows it to distinguish between "very good" and "slightly good" without ever needing a separate critic network running in parallel during training.

The mathematical elegance of GRPO lies in how it calculates these advantages using only relative rewards within each generated group $G$. The objective function simplifies PPO's complexity by removing terms related to global value estimation and complex KL penalties during the reward calculation phase. Instead, it directly incorporates an unbiased estimator for KL divergence into the loss function itself, ensuring stability without adding massive overhead. When normalized using group statistics ($\hat{A}_{i,t}$), the algorithm updates the policy based on how each token in one output compares favorably or unfavorably against its peers in the same cohort. This relative approach aligns naturally with how reward models already operate; they are typically trained on comparisons rather than absolute scores, meaning GRPO creates a smoother gradient update that requires less aggressive constraints to prevent "model collapse." By foregoing the resource-intensive critic model, researchers reported that DeepSeekMath could enhance its instruction-tuned version on MATH and GSM8K datasets using fewer computational passes and significantly lower memory footprints in memory usage during training operations \citep{deepseek-math}.

The practical impact of this simplification is immediately apparent when we look at performance metrics without sacrificing robustness. Previous studies showed that dropping from heavy PPO训练 leads to stagnation, but DeepSeekMath demonstrates that GRPO can significantly boost performance even when starting from strong instruction-tuned baselines like DeepSeekMath-Instruct 7B \citep{deepseek-math}. On benchmarks ranging from elementary arithmetic to advanced college-level calculus problems in English and Chinese variants like CMATH \citep{wei2023cmath}, the model consistently outpaces previous open-source iterations \citep{wizardmath}. Specifically on the MATH benchmark combining chain-of-thought reasoning with tool usage where external python execution is allowed via program-of-thought prompting \citep{pot}, the accuracy reaches approximately 51.7\%, approaching proprietary closed-source models like GPT-4 while staying lightweight itself \citep{deepseek-math}. More importantly for open research communities small teams who might not have clusters capable of running full PPO pipelines can now iterate faster on RL strategies for math problems because bulk data gathering and running baselines has been streamlined by removing redundant components like value network training \citep{deepseek-math}.

However relying solely on relative outcomes within groups ($\hat{A}_{i,t} = \widetilde{r}_i$) presents challenges regarding whether it truly drives deeper reasoning improvements rather than just selection bias toward specific valid outputs found in fine-tuning examples \citep{deepseek-math}.
