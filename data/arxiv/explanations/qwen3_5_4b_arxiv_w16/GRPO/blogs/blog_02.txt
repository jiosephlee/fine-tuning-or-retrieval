# Why 'Code Training' Might Be the Secret Ingredient Your Model Needs

In the fast-evolving landscape of large language models, the question of whether coding training improves general reasoning has long been a subject of debate. The hypothesis suggested that exposure to structured logic in code would naturally transfer benefits to mathematical deduction. However, a new study by DeepSeekMath challenges previous findings, presenting compelling evidence that code training acts as a critical catalyst for mathematical reasoning, particularly when applied before math-specific training.

DeepSeekMath introduces a fascinating experimental design that isolates and validates this relationship. The authors utilized an efficient 7-parameter model to test two distinct training scenarios. In the first scenario, known as two-stage training, the base model was exposed to 400 billion tokens of code data followed by 150 billion tokens of math data. In the second scenario, an identical process was repeated using general language tokens instead of code tokens at the initial stage. The results were unequivocal: models pre-trained on code demonstrated significant improvements in solving mathematical problems using tools or Python programming libraries alone, whereas models initialized with general tokens failed to achieve the same level of performance.

This advantage was not limited to tool-assisted reasoning. Even when solving problems solely through step-by-step text explanations without external calculators or code execution, models that underwent code prior training consistently outperformed their counterparts trained only on general web data. The study further explored whether this benefit could be achieved in a single-stage approach by mixing code and math tokens. While this mixture successfully mitigated catastrophic forgetting—preventing the model from losing reasonable coding skills while learning math—it slightly compromised performance on pure mathematical reasoning compared to the highly specialized two-stage approach.

The findings suggest a specific mechanism behind this improvement: code training appears to enhance the model's ability to structure complex logical flows efficiently. Unlike general language data which can be coherent yet structurally loose, code requires rigorous syntax and logical consistency even for trivial operations. This likely trains the underlying transformer architecture to handle multi-step dependencies with higher precision, a skill directly transferable to solving complex word problems or formal proofs in mathematics.

Furthermore, the research provides clarity on a common pitfall in model architecture design often referred to as catastrophic forgetting.
