Chapter 3: From PPO to GRPO: Value-Free RL for Language Models

# PPO objective with token-level importance ratios and value-function advantages

Proximal Policy Optimization (PPO) is a widely used policy-gradient method adapted to autoregressive language models by treating the model as a policy $\pi_{\theta}$. In the language-generation setting, a query $x$ from a dataset $\mathcal{D}$ is answered by sampling a response $y$ token-by-token under the model, and a verifier provides a scalar reward $r(x,y)\in[0,1]$ for the whole response. PPO updates the policy parameters $\theta$ using samples drawn from an older policy $\pi_{\theta_{\text{old}}}$ while constraining the update so the new policy does not move too far from the old one.

Concretely, PPO for autoregressive generation commonly uses a token-wise objective with importance sampling ratios applied at each token position. If a response $y$ has length $|y|$ and tokens $y_1,\dots,y_{|y|}$, PPO forms an objective of the form
\[
\mathcal{J}_{\text{PPO}}(\theta)
= \mathbb{E}_{x\sim\mathcal{D},\,y\sim\pi_{\theta_{\text{old}}}(\cdot\mid x)}
\left[
\frac{1}{|y|}\sum_{t=1}^{|y|}
\min\bigl(w_{t}(\theta)\,\widehat{A}_{t},\ \mathrm{clip}(w_{t}(\theta),1-\varepsilon,1+\varepsilon)\,\widehat{A}_{t}\bigr)
\right],
\]
where the per-token importance ratio is
\[
w_{t}(\theta)=\frac{\pi_{\theta}(y_t\mid x,y_{<t})}{\pi_{\theta_{\text{old}}}(y_t\mid x,y_{<t})},
\]
and $\widehat{A}_{t}$ is an estimate of the advantage at token position $t$, typically produced by a learned value function. The clipping operator prevents extremely large or small importance ratios from excessively influencing the gradient, enforcing a proximal update.

Intuitively, PPO uses per-token importance ratios because generation is autoregressive: the model defines a conditional distribution for each next token, and the full-sequence likelihood factorizes into the product of these token-level conditionals. The advantage estimates $\widehat{A}_t$ (produced by a value model) tell the optimizer whether increasing the probability of the observed token at position $t$ under the new policy is expected to increase long-term return. Together, the importance ratios and advantages implement an off-policy correction with a safety mechanism (clipping) to stabilize updates.

# Practical limitations of PPO for LLMs: value model cost and reliability on long sequences

Applying PPO in practice to large language models reveals two major practical limitations tied to its reliance on an explicit value model and the token-level structure of the objective.

First, the value model itself is a substantial practical burden. In large-scale setups the value model is often comparable in size to the policy model; maintaining, training, and evaluating a value network at the same scale multiplies memory and compute requirements. This increases the engineering and infrastructure costs of RL fine-tuning. Moreover, the value model must be trained reliably to produce accurate advantage estimates, and that training is not trivial at large scale.

Second, even if a value model is available, producing reliable advantage estimates for long responses is hard. Language-model RL often targets tasks requiring long, complex outputs (e.g., multi-step reasoning or long programs). Estimating token-level advantages across long sequences makes the optimization heavily dependent on the fidelity of the learned value function over long horizons. Errors in the value estimates can inject bias and high variance into policy updates, and these problems typically amplify with increasing sequence length. Thus, PPO's dependence on a strong value model and token-level advantage signals becomes a bottleneck when scaling RL to large models and long responses.

Because of these issues, researchers have sought alternatives that remove or reduce the reliance on an explicit value function while still providing meaningful advantage information for policy updates.

# GRPO objective: group-based advantages from multiple responses per query

Group Relative Policy Optimization (GRPO) is a value-free alternative that avoids training a separate value model by computing relative advantages from multiple responses generated for the same query. The key idea is simple: instead of estimating an absolute value or advantage function, GRPO measures how each sampled response compares to other responses to the same query and uses that relative standing as the learning signal.

In GRPO, for each query $x$ we sample a group of $G$ responses $\{y_i\}_{i=1}^G$ from the behavior policy $\pi_{\theta_{\text{old}}}(\cdot\mid x)$. Each response $y_i$ receives a scalar reward $r(x,y_i)$ from the verifier. GRPO computes a group-normalized advantage for each response by standardizing the group's rewards:
\[
\widehat{A}_i = \frac{r(x,y_i) - \mathrm{mean}\bigl(\{r(x,y_j)\}_{j=1}^G\bigr)}{\mathrm{std}\bigl(\{r(x,y_j)\}_{j=1}^G\bigr)}.
\]
This transforms the raw responses' rewards into zero-mean, unit-variance relative advantages within the group: positive values indicate above-average responses and negative values indicate below-average responses for that particular query batch.

Using these group advantages, GRPO formulates a PPO-like objective that still applies importance weights and clipping at the token level, but replaces the value-model-produced advantage with the within-group relative advantage:
\[
\mathcal{J}_{\text{GRPO}}(\theta)
= \mathbb{E}_{x\sim\mathcal{D},\,\{y_i\}\sim\pi_{\theta_{\text{old}}}(\cdot\mid x)}
\left[
\frac{1}{G}\sum_{i=1}^G \frac{1}{|y_i|}\sum_{t=1}^{|y_i|}
\min\bigl(w_{i,t}(\theta)\widehat{A}_i,\ \mathrm{clip}(w_{i,t}(\theta),1-\varepsilon,1+\varepsilon)\widehat{A}_i\bigr)
\right],
\]
where
\[
w_{i,t}(\theta)=\frac{\pi_{\theta}(y_{i,t}\mid x,y_{i,<t})}{\pi_{\theta_{\text{old}}}(y_{i,t}\mid x,y_{i,<t})}.
\]

This objective retains the per-token importance ratios and clipping structure familiar from PPO, but replaces the need for an external value model with a self-contained, within-group signal.

# How GRPO removes the value model via within-group normalization

The central benefit of GRPO is that it replaces the learned value function with a purely empirical estimate of advantage derived from multiple responses to the same query. By forming a group and standardizing rewards across the group, GRPO produces an advantage estimate that captures the relative quality of each sampled response. This has two important consequences.

First, it eliminates the memory and compute cost of maintaining and training a separate value network. The advantage signal is computed directly from the verifier scores of the sampled responses; there is no need to fit a value function or maintain replay buffers for value learning. This simplification can be significant in large-scale RL setups where adding a second large model is expensive.

Second, group standardization yields a local, query-conditioned advantage estimate that is less sensitive to absolute reward calibration across queries. Since the mean and standard deviation are computed per-group, GRPO focuses the update on promoting responses that are better than other samples for the same prompt, rather than on matching a global expected return. This relative signal can be especially useful when the absolute reward scale varies across queries or when the verifier provides sparse or noisy absolute scores: the within-group ranking is often sufficient to indicate which generated responses to upweight or downweight.

Mechanistically, the standardized advantage $\widehat{A}_i$ plays the same role in the GRPO objective as a value-model-produced advantage would in PPO: it guides whether the policy should increase or decrease the likelihood of the tokens in $y_i$. But because $\widehat{A}_i$ is computed directly from observed rewards in the sampled group, GRPO decouples advantage estimation from an explicit function-approximation process.

# Operational details: group size, advantage standardization, token-level clipping in GRPO

Putting GRPO into practice requires a few operational choices that affect learning dynamics and stability. The most important are the group size $G$, the standardization procedure for advantages, and the clipping applied to importance ratios.

Group size $G$ determines how many responses are sampled per query and therefore how fine-grained the relative comparisons can be. A larger $G$ provides a richer empirical distribution of responses for computing within-group statistics (mean and standard deviation), which can reduce variance in the standardized advantages and give a more robust ordering of responses. However, larger $G$ also increases the sampling and evaluation cost per query because more responses must be generated and scored. In GRPO experiments it is typical to select a modest group size that balances statistical stability and compute budget; the algorithmic formulation assumes $G\ge 2$ so that meaningful comparisons are possible.

The advantage standardization step is central to GRPO. For a group of rewards $\{r(x,y_i)\}_{i=1}^G$, the standardized advantage
\[
\widehat{A}_i = \frac{r(x,y_i) - \overline{r}}{\sigma_r},
\]
where $\overline{r}$ and $\sigma_r$ are the mean and standard deviation of the group rewards, produces a zero-mean, unit-variance advantage vector. Two practical consequences follow. First, the zero mean ensures that, on average across the group, positive and negative updates balance, which tends to stabilize learning and prevent runaway shifts for a single query. Second, the unit variance normalizes the scale of the gradient contributions across different queries and groups, making the effect of the clipping parameter $\varepsilon$ more consistent across batches.

Token-level clipping in GRPO mirrors PPO's proximal constraint, but it is applied to each token's importance ratio $w_{i,t}(\theta)$:
\[
\mathrm{clip}(w_{i,t}(\theta),1-\varepsilon,1+\varepsilon).
\]
Because the GRPO objective distributes the advantage $\widehat{A}_i$ uniformly across all tokens in $y_i$, the clipped per-token weights determine the per-token contribution to the gradient. The per-token averaging factor $\frac{1}{|y_i|}$ is commonly included so that responses of different lengths contribute comparably to the loss.

Finally, in real large-scale RL workflows it is common to partition a large rollout batch into multiple mini-batches when computing gradients. This practice introduces an off-policy element because updates are computed on subsets of samples generated under older policies. The clipping mechanism is intended to mitigate the potential high variance from such off-policy samples. GRPO retains this clipping at the token level to constrain how far the token-level conditional probabilities of the new policy can move relative to the old policy for each token in the sampled responses.

In summary, GRPO replaces an explicit value function by leveraging within-group reward statistics to produce standardized, relative advantages. It keeps token-level importance ratios and clipping in the optimization, and requires sensible choices of group size and standardization to function well in practice. This value-free approach reduces model complexity and addresses some practical bottlenecks of PPO, motivating its adoption as a pragmatic alternative for RL fine-tuning of large language models.
