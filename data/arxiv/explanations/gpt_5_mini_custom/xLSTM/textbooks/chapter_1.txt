\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 1: From LSTMs to xLSTM: The Landscape of Sequence Modeling

# Sequence modeling overview: RNNs, LSTMs, State Space Models, Transformers
Sequence modeling studies how to process ordered data: time series, token streams in language, control signals in reinforcement learning, or any data where past events influence future ones. Historically, Recurrent Neural Networks (RNNs) were a natural fit because their architecture iteratively updates an internal state as new inputs arrive, thereby compactly representing past context. However, vanilla RNNs suffered from optimization difficulties on long dependencies, which motivated architectural advances.

Long Short-Term Memory (LSTM) networks introduced two core ideas that addressed these difficulties: the constant error carousel and gating. These ideas created a memory cell whose additive update avoids the severe vanishing gradient problems of simple RNNs, enabling learning of long-range dependencies. Over many years LSTMs were applied successfully across sequence domains, becoming the default choice for a wide range of problems that require remembering, forgetting, and selectively exposing stored information.

More recently other families of sequence models have risen to prominence. State Space Models (SSMs) formulate sequence processing in terms of linear state-update equations whose discretization and parameterization can give linear-time algorithms with strong empirical performance on long contexts. Transformers replaced recurrence with self-attention: each position computes a weighted sum of all positions' representations using learned attention weights. Self-attention is naturally parallelizable across sequence positions and, combined with large-scale training, produced the modern class of Large Language Models (LLMs). The Transformer’s parallelizable self-attention and the engineering that enabled massive scale have substantially outpaced LSTMs in many large-scale language-modeling benchmarks.

xLSTM asks a targeted question in this landscape: if we take the core LSTM ideas and bring them up to date with modern techniques — mitigating known LSTM limitations and scaling to model sizes comparable to current LLMs — how well can an LSTM-derived model perform? The paper’s answer is to modify the LSTM design in two ways (exponential gating and richer memory structures) and to embed the modified cells inside residual stack backbones, yielding xLSTM blocks and full xLSTM architectures that compete well with state-of-the-art Transformers and SSMs.

# Vanishing gradients and the constant error carousel
To understand why LSTMs were a breakthrough, we must recall the vanishing gradient problem that plagues RNNs. In a standard recurrent update where the new hidden state is a non-linear function of the previous hidden state and the current input, gradients propagated backward through many time steps tend to decay exponentially. This makes it extremely difficult for gradient-based learning to assign credit to events far in the past.

The LSTM solved this by introducing a memory cell that is updated additively rather than multiplicatively across time steps. The key idea can be compactly written as

\[
c_t \;=\; f_t\, c_{t-1} \;+\; i_t\, z_t,\qquad
h_t \;=\; o_t\,\psi(c_t).
\]

Here $c_t$ is the cell (memory) state at time $t$ and the update is an additive combination of a decayed previous cell $f_t c_{t-1}$ and a new candidate contribution $i_t z_t$. The multiplicative gates $f_t$ (forget gate) and $i_t$ (input gate) control how much of the previous memory to keep and how much new content to incorporate; $o_t$ (output gate) controls how the normalized cell is exposed as the hidden state $h_t$ after applying a squashing/normalizing function $\psi$. Because $c_t$ accumulates contributions additively, the gradient can flow along the additive path for many steps, which is known as the constant error carousel: there is a path through which gradients are preserved instead of being repeatedly multiplied by small Jacobians.

This structural change — replacing pure multiplicative recurrence with an additive memory updated under gating control — is the essence of why LSTMs survive as a foundational recurrent model for long dependencies. The gates themselves are learned functions of inputs and previous hidden states, enabling the model to learn when to write, forget, and read memory.

# LSTM gates and the cell/hidden state update
The original LSTM formalism refines the idea above with explicit parameterized gates and a parameterized candidate input. The standard scalar-cell LSTM (extended to vector form by stacking many scalar cells) uses the following update equations at time $t$:

\[
\begin{aligned}
c_t &= f_t \, c_{t-1} + i_t \, z_t &&\text{(cell state)}\\[4pt]
h_t &= o_t \,\tilde{h}_t,\qquad \tilde{h}_t = \psi(c_t) &&\text{(hidden state)}\\[4pt]
z_t &= \varphi(\tilde{z}_t),\qquad \tilde{z}_t = \mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z &&\text{(cell input)}\\[4pt]
i_t &= \sigma(\tilde{i}_t),\qquad \tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i h_{t-1} + b_i &&\text{(input gate)}\\[4pt]
f_t &= \sigma(\tilde{f}_t),\qquad \tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f h_{t-1} + b_f &&\text{(forget gate)}\\[4pt]
o_t &= \sigma(\tilde{o}_t),\qquad \tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o h_{t-1} + b_o &&\text{(output gate)}
\end{aligned}
\]

In these equations, $\mathbf{x}_t$ is the input at time $t$. The vectors $\mathbf{w}_\bullet$ are input-to-gate weight vectors, $r_\bullet$ are recurrent scalars (or matrices in vector-cell formulations) that connect the previous hidden state $h_{t-1}$ to gate pre-activations, and $b_\bullet$ are biases. The activation functions $\varphi$ and $\psi$ are typically squashing functions like $\tanh$; $\sigma$ denotes the sigmoid function so each gate lies in $(0,1)$.

When LSTMs are implemented with multiple scalar memory cells collected into a vector $\mathbf{c}_t \in \mathbb{R}^d$, recurrent weight matrices $\mathbf{R}$ can be used to mix the hidden outputs across cells. This mixing allows different memory cells to interact across time via the hidden state, enabling richer dynamics than independent scalar cells.

Intuitively, the three gates give the network control over the life-cycle of information in the cell: $i_t$ decides how much new input to write, $f_t$ moderates how much prior memory to retain, and $o_t$ determines how much of the (possibly normalized) memory to reveal to the downstream computation. The additive memory update is what preserves gradient flow; the learned gates determine the timescales and content of storage.

# Historical successes of LSTMs in language and control tasks
LSTMs have enjoyed a long record of practical successes across many domains that require sequence understanding and generation. In language and generation tasks, LSTMs powered advances in text generation, were used to build the first large language models (in the pre-Transformer era), and supported sequence-to-sequence machine translation systems. Their ability to model sequences also made them effective for handwriting generation and for generating image captions. Beyond language, LSTMs proved useful in scientific and environmental modeling tasks such as rainfall–runoff prediction and hydrological models for flooding warnings.

In reinforcement learning and control, LSTMs provided strong sequence-modeling inductive biases for agents operating in partially observable environments. They were central components in models for complex games and control systems, including high-profile systems for real-time strategy and competitive games, and were used in learning controllers for challenging physical systems. One persistent strength of LSTMs is their aptitude for extracting and storing abstractions from sequences: researchers have identified neurons corresponding to high-level features such as number or syntax, linguistic phenomena, and sentiment inside trained LSTM representations. These observations illustrate that the LSTM memory can learn interpretable and task-relevant internal representations.

All of these successes underscore that the LSTM design — a gated additive memory that can learn to store and manipulate semantically meaningful information — remains a strong inductive bias when tasks require explicit state tracking or hierarchical temporal structure.

# Transformers and self-attention scalability
The Transformer architecture introduced a different mechanism for handling dependencies: self-attention. Rather than iterating a hidden state through time, Transformer layers compute, for each position, linear projections into query, key, and value vectors and then compute weighted sums of values where the weights are obtained by comparing queries to keys. This mechanism permits every position to attend directly to every other position within a layer.

A crucial practical advantage of self-attention is parallelizability: because attention at different positions can be computed simultaneously, Transformers can exploit massive parallel hardware to process long contexts efficiently in wall-clock time. This parallelism, together with engineering advances for large-scale training and inference, has enabled Transformers to scale to billions and trillions of parameters and to achieve state-of-the-art results across NLP tasks. In many large-scale language-modeling regimes, Transformer-based LLMs have outpaced recurrent architectures such as LSTMs.

However, self-attention typically has quadratic time and memory complexity in the context length (each attention layer forms an all-pairs interaction across positions). This has motivated many modifications (linearized attention, approximations, or state-space formulations) to reduce the asymptotic cost for very long sequences. Nonetheless, the combination of parallelism and representational power of attention has been a decisive force in modern LLMs.

# Motivation to revisit LSTMs at modern LLM scale
Given the historical importance of LSTMs and the empirical dominance of Transformers at scale, the paper asks a concrete and practical question: if we update the LSTM family with modern techniques, mitigate its known limitations, and scale it to the size of current large models, how well can it perform on language modeling? Several motivations drive this inquiry.

First, classical LSTMs have three main limitations that constrain their effectiveness at scale or on specific tasks. The first limitation is an inability to easily revise storage decisions. In tasks like a Nearest Neighbor Search over a stream, an LSTM may store an initial candidate and struggle to overwrite that memory properly when a better (more similar) candidate appears later in the stream. That is, the multiplicative gating mechanisms and scalar memory dynamics make revision of previously stored content difficult in some scenarios.

Second, LSTMs have limited storage capacity per cell because each memory element is scalar (or a modest-dimension vector), which requires compressing potentially complex information into few dimensions. This limited capacity shows up in tasks that require remembering many diverse items or rare tokens: LSTMs tend to perform worse on rare-token prediction tasks because the scalar memory must compress many token-specific details.

Third, LSTMs with memory mixing (i.e., hidden–hidden recurrent connections that mix states across cells) are inherently sequential: the dependence of gate pre-activations on the previous hidden state enforces a step-by-step computation that is not trivially parallelizable across time. This sequential nature limits throughput in wall-clock time compared to parallelizable architectures like Transformers.

These limitations suggest concrete directions for remedy within the LSTM design. The paper proposes two principal modifications that together form the xLSTM family.

The first modification is exponential gating with appropriate normalization and stabilization. Replacing sigmoid gates by exponential activations (for input gates, and optionally for forget gates) gives the network multiplicative control in the positive real line rather than the sigmoid's bounded $(0,1)$ range. To make exponential gating numerically stable and well-behaved, xLSTM introduces a normalizer state that accumulates the effective weight of past inputs (the product of input gate and future forget gates) and a stabilizer state that prevents overflow. Intuitively, exponential gating enables more flexible, fine-grained updates where stored contributions can be scaled up or down multiplicatively in a way that better supports revising storage decisions.

The second modification is richer memory structure. The paper introduces two new LSTM variants. The sLSTM retains a scalar memory but adopts exponential gating and new patterns of memory mixing (including multi-head designs that permit controlled mixing within heads). The mLSTM elevates the memory to a matrix $\mathbf{C}\in\mathbb{R}^{d\times d}$ and uses a covariance (outer-product) update rule

\[
\mathbf{C}_t \;=\; f_t\,\mathbf{C}_{t-1} \;+\; i_t\,\mathbf{v}_t\,\mathbf{k}_t^\top,
\]

storing key–value pairs via outer products. Retrieval is then a matrix-vector product $\mathbf{C}_t \mathbf{q}_t$ normalized by a suitable scalar derived from a normalizer state. The covariance update mirrors ideas from associative memory and fast-weight programmers: adding outer products is a natural way to accumulate associations between keys and values. Because the mLSTM can forgo hidden–hidden recurrence (no memory mixing), its recurrence can be reformulated to allow parallel computation across sequence positions, bringing LSTM-type memories closer to the parallelism benefits of attention-based models.

Embedding these modified cells into residual block backbones yields xLSTM blocks (with either pre- or post-upprojection designs depending on whether the block contains mLSTM or sLSTM) that are stacked residually to form full xLSTM architectures. These architectures inherit favorable inductive biases from LSTMs (stateful memory and gating) while gaining expressivity and, in the case of mLSTM, parallelizability and larger effective memory capacity.

Finally, there are practical trade-offs to acknowledge. The mLSTM’s matrix memory increases computation (updates and retrievals of $d\times d$ matrices), and the sLSTM’s memory mixing retains sequential dependence, making it less trivially parallelizable. The xLSTM proposal therefore balances different design choices (sLSTM vs. mLSTM, numbers of heads and cells, block placement) to achieve good empirical performance while controlling computational cost. The experiments in the paper show that with exponential gating and matrix memory, xLSTM variants perform favorably compared to state-of-the-art Transformers and SSMs in language modeling and scaling behavior, suggesting that revisiting and modernizing LSTMs is a promising pathway in the current landscape of sequence modeling.
