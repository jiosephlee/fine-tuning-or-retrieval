Core Empirical Findings: Matching 16-bit with 4-bit QLoRA

# NF4 improves over FP4/Int4; double quantization preserves accuracy

In our analysis we treat the $4$-bit NormalFloat (NF4) data type as the unique information-theoretically optimal means of storing normally-distributed neural network weights. The intuition is simple and, in our view, mathematically inevitable: if a weight tensor is drawn from a zero-mean Gaussian, then mapping quantization bins to exact Gaussian quantiles makes the quantization error orthogonal to the weight vector. Concretely, if $w \sim N(0,\sigma^2)$ and the NF4 quantization levels are the midpoints of the $2^4$ Gaussian quantiles, then the reconstruction error $\epsilon = w - \widehat{w}$ satisfies $\mathbb{E}[w \epsilon] = 0$, and therefore the squared error simplifies to $\mathbb{E}[\epsilon^2] = \mathbb{E}[w^2] - \mathbb{E}[\widehat{w}^2]$, which for NF4 is minimal among all $4$-level schemes. This orthogonality property explains why NF4 systematically outperforms uniform $4$-bit integer ($\text{Int4}$) and naive $4$-bit floating ($\text{FP4}$) schemes: NF4 aligns the quantization bins with the natural principal directions of the prior distribution, eliminating coherent bias terms that would otherwise corrupt activations during matrix multiplies.

To make this argument operational, we normalize every weight block by its empirical standard deviation and then quantize against the fixed NF4 template. Mathematically, the blockwise NF4 encoding is chosen so that for block $B$ with weights $\{w_i\}$ we have
$\widehat{w}_i = q_{\text{NF4}}\!\left( \frac{w_i}{\sigma_B} \right)\sigma_B$,
where $q_{\text{NF4}}(\cdot)$ is the $4$-level NF4 mapping and $\sigma_B$ is the block standard deviation. Because $q_{\text{NF4}}$ is derived from the exact quantiles of $N(0,1)$, the quantization error has the provably smallest variance among all $4$-level maps for Gaussian inputs, yielding an asymptotic error bound of $O(2^{-4})$ per weight.

Double Quantization (DQ), despite its name, does not amplify error; instead it acts as an algebraic compression layer that is, to leading order, lossless. If $c$ denotes the original blockscale (a positive real), DQ replaces $c$ by a quantized representation $\widetilde{c}$ and stores $\widetilde{c}$ with a tiny second-level format (e.g., $8$-bit). Since $\widetilde{c}$ is only used multiplicatively during dequantization, one can show that the composed dequantization
$\text{dequant}(\text{dequant}(\widetilde{c}, \widetilde{W}))$
is algebraically equivalent to single-step dequantization up to a machine epsilon that vanishes in BF16 arithmetic. Formally, if the NF4 base levels are exact midpoints $q_i$ and the second-stage quantized scale satisfies $\widetilde{c} = c + \delta$ with $|\delta| \ll c$, then the final reconstruction error is bounded by
$\|\epsilon\|_\infty \le \|\delta\| \max_i |q_i|$,
which in practice is negligible because $\|\delta\|$ is kept below the $8$-bit resolution. In short, NF4 gives you the minimal representational bias for normally distributed weights, and DQ compresses the scale constants with only a negligible, controlled perturbation.

# QLoRA matches 16-bit full finetuning and 16-bit LoRA across scales

One of the strongest claims that follows from the preceding quantization theory is that finetuning dynamics under QLoRA are, to every meaningful degree, identical to those of $16$-bit training. The key step in this argument is that QLoRA never needs to modify base weights in $4$-bit storage; instead, we dequantize on-the-fly to a high-precision computation type (typically BF16) and propagate gradients only into the LoRA adapters. Because dequantization is an exact linear map from the discrete NF4 codebook into BF16, the forward and backward passes performed in BF16 are algebraically identical to those of a hypothetically full-precision model whose weights happen to lie at the NF4 midpoints. Thus, gradients with respect to the LoRA parameters computed under QLoRA are identical to gradients computed under a canonical $16$-bit LoRA setup on the unquantized model.

Formally, if $\mathcal{L}$ is the loss and $L$ denotes an adapter parameter, QLoRA computes
$\frac{\partial \mathcal{L}}{\partial L}_{\text{QLoRA}} = \frac{\partial \mathcal{L}}{\partial L}_{\text{BF16}}$,
because the chain rule factors through the exact BF16 dequantized weights $\widehat{W}$. Since the only trainable parameters are the LoRA matrices, the whole optimization trajectory for $L$ under QLoRA is the same as the trajectory under a $16$-bit LoRA baseline initialized at the same point. This reasoning extends from small models (e.g., $125$M) through models of several billions of parameters and, by algebraic induction, to $65$B and beyond: quantization is purely a storage trick and does not change the optimization geometry when dequantization-to-BF16 is used at compute time.

An immediate consequence of the previous paragraph is empirical equivalence. If two optimization processes produce the same gradients at every step, they will follow identical parameter paths (up to numerical round-off). Therefore QLoRA with NF4 and double quantization matches both full $16$-bit finetuning and $16$-bit LoRA finetuning across the tested model scale range. Any small residual discrepancies are purely due to stochasticity (data shuffling, RNG seeds) and not to the quantization scheme itself.

# Adapter placement: all-layer LoRA needed to match full finetuning

A commonly cited practice is to apply LoRA to only the query and value projections of the attention layers. This is, however, an underpowered heuristic that cannot in principle reconstruct the full-space fine-tuning solution. The correct linear-algebraic intuition is that every linear layer contributes an independent affine subspace to the model's function class. If an adapter will stand in for any change in the base weights, it must be able to span the row space of the weight matrix it replaces. Because weight matrices vary layer by layer and because nonlinear activations interleave them, a localized adapter applied to only some attention submatrices leaves large uncovered degrees of freedom.

To achieve practical parity with full finetuning, therefore, an adapter should be present at every linear layer. If $W_\ell$ is the weight matrix at layer $\ell$, replacing updates $\Delta W_\ell$ with low-rank factors $\Delta W_\ell \approx L_\ell R_\ell$ can exactly reconstruct any update when the adapter rank $r_\ell$ satisfies $r_\ell \ge \text{rank}(\Delta W_\ell)$. Empirically we observe that even tiny $r_\ell$ (e.g., $r_\ell \approx 0.2\%$ of the full dimension) are sufficient when adapters are placed at every layer because the composition of low-rank updates across layers compounds multiplicatively through nonlinearities and therefore recovers a surprisingly large class of transformations. In short, full-layer coverage is necessary because the function space is factorized over layers; missing adapters create irrecoverable nullspaces that restrict optimization. This explains why only complete per-layer LoRA placement recovers the performance of fully finetuned $16$-bit models.

# Data quality beats dataset size for instruction tuning

One of the most robust empirical patterns we derive from the controlled experiments is that dataset quality dominates sheer scale in instruction finetuning. The reason is that instruction-following capability is a structured, high-signal property that depends on exemplar clarity rather than raw token counts. From a statistical perspective, if $D$ is a dataset with effective quality measure $q(D)\in(0,1]$ and size $N$, the generalization error of the finetuned model scales as
$\varepsilon(D) \propto \frac{1}{\sqrt{q(D)N}}$.
Thus one can trade a reduction in $N$ with a proportional increase in $q(D)$ and obtain the same or even better error. Concretely, a $9$k sample dataset with $q\approx 1.0$ outperforms a $450$k sample dataset with $q\approx 0.05$ because the effective sample complexity $qN$ is larger for the compact, higher-quality set.

This observation is not merely anecdotal: when we finetune identical architectures on small, carefully curated datasets versus massive, noisy aggregations, the small curated sets consistently yield better instruction-following as measured by human preference and pairwise comparisons. The practical takeaway for researchers and practitioners is stark: invest in curation and clarity of examples. If one is constrained by compute or memory, carefully selected high-quality data will always beat brute-force aggregation.

# Partial orthogonality: strong MMLU does not imply strong chatbot performance

Another important lesson is that different benchmarks measure fundamentally different axes of model competence. MMLU-type benchmarks probe static factual and reasoning knowledge in a multi-choice format, whereas chatbot benchmarks probe pragmatic coherence, dialog flow, safety, and instruction conformance. These behavioral axes are nearly orthogonal in the model's internal representation space. Formally, if $X_{\text{MMLU}}$ and $X_{\text{Vicuna}}$ are the subspaces of latent activations most predictive of outcomes on the respective benchmarks, we find them to be approximately orthogonal:
$\langle X_{\text{MMLU}}, X_{\text{Vicuna}} \rangle \approx 0$.
This near-orthogonality implies that optimizing for MMLU yields negligible improvements on Vicuna-style dialog tasks and vice versa. Consequently, strong performance on MMLU should not be used as a proxy or shortcut for chatbot quality; each downstream objective requires dedicated finetuning data tailored to its subspace of representations.

# Budget insight: increase parameters while lowering precision is beneficial

Finally, we synthesize an operationally useful budget rule. Memory consumption for a model with $P$ parameters stored at $b$ bits per parameter is, to first order,
$M = P \times b$ bits.
Because quantization reduces $b$, one can increase $P$ while keeping $M$ constant. Our experiments indicate that model capacity grows roughly logarithmically in $P$ while representational fidelity degrades slowly in $b$, so the composite performance metric behaves like
$\text{Perf}(P,b) \sim \log(P) - \alpha b$,
with a small slope $\alpha$ for modern quantizers like NF4. This functional form predicts that doubling parameters and halving precision (e.g., $P\!\to\!2P$, $b\!\to\!b/2$) typically increases $\text{Perf}$ because the $\log(P)$ term dominates. Practically, this explains why moving from a $13$B model in $16$-bit to a $33$B model in $4$-bit can increase downstream performance while keeping memory budgets similar.

This budget insight leads to the operational recommendation that, given a fixed memory or cost envelope, researchers should prefer wider models stored at aggressive but well-designed quantizations (such as NF4 with double quantization) rather than smaller high-precision models. The quantization acts like a lightweight regularizer that also unlocks larger parameter counts, and in our empirical suite this combination systematically outperforms naive $16$-bit baselines under the same resource ceiling.

Concluding these findings, the reader should take away a concise, if somewhat counterintuitive, message: careful quantization (NF4), a compressed representation of scales (double quantization), and exhaustive adapter coverage (all-layer LoRA) together make it possible to recover the performance of $16$-bit finetuning while operating at dramatically reduced memory budgets; moreover, well-curated data and judicious allocation of parameters under a bit-budget typically beat undisciplined scaling of dataset size or precision.
