# 3. Add LoRA adapters to every linear layer
from peft import get_peft_config, get_peft_model, LoraConfig

peft_config = LoraConfig(
    r=64,                    # LoRA rank
    lora_alpha=32,           # scaling
    target_modules=["q_proj", "v_proj", "k_proj", "o_proj", "down_proj", "up_proj"],
    lora_dropout=0.05,
    bias="none",
)
model = get_peft_model(model, peft_config)
```

This code:

  • Quantizes weights to 4 bits (NF4) plus double quant  
  • Uses BFloat16 internally for computations  
  • Freezes the base model and only trains LoRA parameters

## 7. Common Pitfalls

1. **Out of Memory (OOM)**  
   – Reduce batch size or sequence length  
   – Use paged optimizers via `model.hf_config.use_cache = False` and Accelerate paging  
2. **Wrong Precision**  
   – Ensure your GPU supports `bf16`. If not, switch to `fp16` and adjust `Accelerate` config.  
3. **Under-tuned LoRA**  
   – If performance lags, try increasing `r` to 128 or adding adapters to more layers.  
4. **Data Formatting Bugs**  
   – Check that your JSON/CSV mapping matches the script’s `train_file` arguments.  
5. **Reproducibility**  
   – Set all seeds (Python, NumPy, Torch) inside the training script for consistent results.
