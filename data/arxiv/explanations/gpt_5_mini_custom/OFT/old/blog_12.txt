# During forward: W = R @ W0
```

### 4.3 Orthogonality and Identity Initialization

- We initialize each Q to zero, so initially R=I and W=W0.  
- We enforce RᵀR=I by using the Cayley parametrization, which guarantees exact orthogonality.  
- Optionally, for Constrained OFT (COFT), we project Q back to a small Frobenius-norm ball ∥Q∥≤ε after each gradient step. This limits how far you stray from the pretrained model.

## 5. Finetuning with OFT

With the data and OFT layers in place, it’s time to train:

1. **Hyperparameters**  
   - Learning rate: 1e-4  
   - Batch size: 1–2 images  
   - Steps: 400–800 (we observe stable convergence well before 1000)  
   - Weight decay: 0  
   - Optimizer: AdamW  

2. **Loss Function**  
   Use the standard DreamBooth reconstruction loss and prior-preservation term. For each step:
   - Encode your images to latents.  
   - Add noise at a random timestep.  
   - Predict noise with the finetuned UNet (now containing R blocks).  
   - Compute MSE against the true noise.  

3. **Training Loop**

```python
for step, batch in enumerate(dataloader):
    images, captions = batch
    latents = vae.encode(images)
    noise = torch.randn_like(latents)
    t = torch.randint(0, num_timesteps, [latents.size(0)])
    noisy_latents = scheduler.add_noise(latents, noise, t)

    # UNet forward with OFT layers
    pred = unet_with_oft(noisy_latents, t, text_encoder(captions))
    loss = F.mse_loss(pred, noise)

    loss.backward()
    optimizer.step()
    optimizer.zero_grad()

    if step % 100 == 0:
        print(f"Step {step}, Loss {loss.item():.4f}")
    if step >= max_steps:
        break
```

4. **Checkpointing**  
   Save your OFT parameters (all Q matrices) and the updated UNet weights every 200 steps. This lets you roll back in case of overfitting.

## 7. Best Practices and Tips

- **Balance Flexibility and Stability**  
  OFT naturally preserves the model’s pretrained semantics. If you want even stronger identity preservation, enable COFT with a small ε (e.g., 0.1).  
- **Data Augmentation**  
  Random crops, flips, and color jitter help your five images cover more visual variety.  
- **Prompt Diversity**  
  Write at least 4–6 captions per image covering wardrobe, environment, and mood.  
- **Iteration Count**  
  OFT tends to converge stably by 400 steps. You can safely run up to 800 without collapse.  
- **Inference Overhead**  
  Once finetuned, multiply each R into its W0 and export a consolidated checkpoint. There’s no extra cost at inference time.
