According to the paper 'Controlling Text-to-Image Diffusion by Orthogonal Finetuning', as the COFT parameter ε approaches zero, the finetuned model tends toward the behavior of the pretrained model. COFT constrains the learned orthogonal transform to lie within an ε-ball around the identity, i.e., it optimizes an orthogonal matrix R subject to R^⊤R = I and ||R − I|| ≤ ε, and applies it multiplicatively to the pretrained weights: W = R W^0. This yields the forward pass z = (R W^0)^⊤ x. By submultiplicativity of operator norms, the deviation of the finetuned weights from the pretrained weights is bounded as ||W − W^0|| = ||(R − I) W^0|| ≤ ||R − I|| · ||W^0|| ≤ ε · ||W^0||. Hence as ε → 0, we have R → I and W → W^0, which implies the finetuned network’s outputs converge to those of the pretrained network for any input x. In the exact limit ε = 0, the feasible set forces R = I, so COFT reproduces the pretrained model exactly.

Moreover, COFT maintains the hyperspherical energy of each layer because any orthogonal transform preserves pairwise angles among normalized neurons. Thus, even for small but nonzero ε, COFT keeps the relational angular structure intact while only allowing an infinitesimal rotation around the pretrained canonical basis. Using the Cayley parameterization R = (I + Q)(I − Q)^{-1} with a skew-symmetric Q and the Neumann-series approximation R ≈ I + 2Q + O(Q^2), the deviation constraint ||R − I|| ≤ ε can be enforced by keeping ||Q|| ≤ ε′ for a suitably chosen ε′, ensuring that angular changes are second-order small. Combining the explicit deviation bound with angle preservation means both the Euclidean and semantic differences from the pretrained model are tightly controlled; therefore, as ε shrinks, COFT increasingly mimics the pretrained model’s generative behavior.
