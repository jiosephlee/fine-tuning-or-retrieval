\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 10: Applying OFT to Controllable Generation

# Control signals: Canny edges, segmentation maps, facial landmarks

Controllable generation tasks augment a text prompt with an additional, structured signal that constrains the geometry, layout, or semantic content of the generated image. In the OFT experiments these control signals fall into three representative categories. Canny edges provide sparse geometric cues: a binary or thin-boundary map that outlines major object contours and strokes. Segmentation maps provide dense semantic region labels that indicate which pixels belong to which object classes or parts; they specify a region-by-region template the generator should fill with appropriate texture and appearance. Facial landmarks are a compact geometric control signal: a set of keypoints (e.g., eyes, nose, mouth positions) that encode pose and facial configuration and thus tightly constrain the generated face geometry.

Each control type stresses a different aspect of the generative model. Canny edges require the model to hallucinate plausible content consistent with crude lines; segmentation maps require semantic fidelity and correct spatial arrangement across regions; facial landmarks require precise geometric adherence to keypoint positions and pose. The experimental design in the paper uses all three signal types to demonstrate that OFT is a broadly applicable finetuning strategy that improves adherence to external controls across sparse, dense, and compact control modalities.

# Datasets: COCO (C2I), ADE20K (S2I), CelebA-HQ (L2F)

To evaluate controllability under realistic conditions, OFT is applied to three standard datasets paired with the corresponding control task names used in the paper. For Canny-edge-to-image (C2I), the COCO dataset is used; COCO provides complex, diverse scenes where edges must be mapped to coherent objects and backgrounds. For segmentation-map-to-image (S2I), ADE20K supplies diverse scene segmentation maps and labels, testing semantic compliance and region consistency. For landmark-to-face (L2F), CelebA-HQ is used; it contains high-quality face images with diverse poses and identities, ideal for assessing fine-grained pose control from landmark inputs.

In the experiments the pretrained base model is Stable Diffusion v1.5. Each dataset-task pair is used to finetune the same latent diffusion backbone, allowing apples-to-apples comparison between finetuning strategies (OFT / COFT, LoRA, ControlNet, T2I-Adapter). For these control tasks the paper finetunes for 20 epochs in the main comparisons, which is sufficient to expose differences in convergence speed, stability, and final control quality.

# Training setup vs ControlNet and T2I-Adapter

The experimental setup deliberately compares OFT to the dominant adapter-style controllers and to LoRA, which is a popular parameter-efficient additive update. ControlNet and T2I-Adapter both introduce additional controller networks that are trained to condition the pretrained diffusion model on the control signal; these controllers add new model components and parameters and, at inference time, are invoked alongside the base diffusion model. In contrast, OFT takes a finetuning viewpoint: it adapts the pretrained weights by learning layer-shared orthogonal transformations (and optional diagonal rescaling), typically applied to the same attention or linear layers targeted by LoRA. This yields a multiplicative update of the form

\[
\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}, \quad \text{s.t. } \bm{R}^\top\bm{R} = \bm{I},
\]

where $\bm{W}^0$ is the pretrained weight submatrix and $\bm{R}$ is an orthogonal matrix learned per layer (with block-diagonal parameterizations for efficiency). The constrained variant COFT adds an explicit proximity constraint to the identity,

\[
\|\bm{R}-\bm{I}\| \le \epsilon,
\]

which further reduces deviation from the pretrained model and improves finetuning stability.

For fairness, when comparing to LoRA the paper applies OFT to the same layers that LoRA modifies. Unlike ControlNet, OFT does not add separate controller networks; it finetunes the base weights themselves (but in a parameter-efficient way). Practically, OFT and COFT use a comparable or smaller number of trainable parameters than LoRA and far fewer than ControlNet or large adapter networks. The orthogonal matrices are parameterized with a Cayley transform and optionally block-diagonal structure to reduce parameter count and computational cost during training.

# Faster, smoother convergence and data efficiency

One of the main empirical claims in the paper is that OFT converges faster, more smoothly, and with fewer training samples than controller networks and additive finetuning methods. There are two conceptual reasons for this behavior grounded in the OFT design.

First, OFT focuses updates on neuron directions (angles) while preserving the pairwise angular relationships across neurons (the hyperspherical energy). Because angular relationships encode semantic structure strongly, rotating the neuron basis is an efficient way to change model behavior toward the control objective without discarding pretrained semantic priors. In other words, OFT modifies the part of the representation most relevant to semantic changes while leaving structural relations intact, which produces more effective updates per parameter and per gradient step.

Second, by constraining updates to an orthogonal manifold (and to a small neighborhood for COFT) the optimization traverses a smoother, lower-complexity parameter subspace. This yields steadier learning dynamics. Empirically, the paper shows that in the landmark-to-face task (L2F) OFT reaches a given landmark error substantially earlier than LoRA: LoRA requires about 20 epochs to reach a performance that OFT attains in roughly 8 epochs. ControlNet also exhibits a different dynamic: its controllability often emerges suddenly after several epochs (a sharp transition), whereas OFT and COFT show gradual, stable improvement across epochs. This stability reduces the difficulty of tuning epoch counts and learning rates.

Data efficiency is demonstrated by experiments where OFT converges well with only a small fraction of the training set. For example, on the ADE20K segmentation-to-image task, OFT produces strong controllability with only 5% of the dataset, whereas other methods require more data to stabilize and reach comparable control fidelity. This makes OFT attractive when labeled control datasets are small or costly to collect.

# Qualitative comparisons: structure adherence and realism

Qualitatively, OFT and its constrained variant COFT achieve two goals simultaneously: adherence to the supplied control and photorealistic, semantically coherent outputs. Across the three control modalities the paper reports consistent advantages:

- For Canny edges (C2I on COCO), OFT hallucinates plausible structures that align with the input lines. The model can convert sparse strokes into coherent objects and backgrounds, producing images that are not only structurally consistent but also visually detailed and realistic. Competing methods such as T2I-Adapter and LoRA often produce less faithful or lower-quality hallucinations under crude edge inputs.

- For segmentation maps (S2I on ADE20K), OFT maintains semantic correspondence between labeled regions and image content. The method generates region-appropriate textures and respects boundary alignment. The paper notes that LoRA can fail in this task—sometimes producing images that do not follow the segmentation map—while ControlNet, OFT, and COFT preserve the input layout, with OFT producing sharper details and more geometrically coherent compositions.

- For facial landmarks (L2F on CelebA-HQ), OFT attains precise pose and landmark adherence: the generated faces match the target keypoint configuration closely while preserving high-fidelity facial appearance. The landmark error curves in the paper show steady improvement for OFT and COFT and a more abrupt and less stable trajectory for ControlNet. Qualitative samples corroborate that OFT-generated faces both follow the control and exhibit realistic shading, expression, and identity cues.

Across these tasks, the qualitative advantage of OFT stems from its ability to change semantic properties by rotating neuron directions while preserving pretrained inter-neuron relationships. That constrained change helps the model respect structural constraints (edges, segmentation regions, landmarks) without collapsing into degenerate or overly biased outputs.

# No added inference-time compute compared to controller networks

A practical engineering advantage of OFT is that it introduces no additional inference-time overhead beyond the original pretrained model. Controller architectures such as ControlNet and T2I-Adapter add separate network components that are evaluated alongside the base diffusion model during generation, increasing memory footprint and computation at inference time. By contrast, OFT learns multiplicative orthogonal transforms that can be folded into the pretrained weight matrices before or during deployment. Concretely, after learning the orthogonal matrix $\bm{R}$, the adapted weight is simply

\[
\bm{W} = \bm{R}\bm{W}^0,
\]

so the runtime forward pass is identical to the original model with $\bm{W}$ in place of $\bm{W}^0$. Because the orthogonal transform does not require an auxiliary controller network at inference, OFT maintains the same inference speed and computational pattern as the frozen baseline model. This property is particularly valuable for deployment scenarios where latency and memory are constrained, yet improved controllability is desired.

# Putting it together: why OFT outperforms controller networks with fewer parameters

Combining the theoretical and empirical points clarifies why OFT outperforms controller networks while often using fewer trainable parameters. The main mechanisms are:

1. Hyperspherical-preserving updates. Orthogonal transforms preserve pairwise neuron angles (and thus hyperspherical energy). This retains the pretrained semantic structure that underlies high-fidelity generation, avoiding the destructive effects that unconstrained updates can cause.

2. Directional focus. OFT targets neuron directions, which experiments in the paper show capture most of the semantic information. Changing directions is an efficient lever to adapt semantics to control signals.

3. Manifold regularization. Limiting optimization to orthogonal matrices (and optionally constraining deviation from identity) reduces overfitting and yields smoother learning, which accelerates convergence and enhances stability.

4. Parameter efficiency via block structure. Block-diagonal or shared-block parameterizations of $\bm{R}$ drastically reduce the number of learned parameters while keeping orthogonality; this enables OFT to be compact yet expressive enough for control tasks.

5. No runtime cost. Folding learned transforms into base weights removes any inference penalty, unlike controller networks that pay a runtime price.

These properties collectively make OFT a compelling finetuning approach for controllable text-to-image diffusion: it achieves accurate structural adherence to external controls (edges, segmentation, landmarks), produces realistic images, converges faster and more stably, is data-efficient, and does so without increasing inference-time computation. The paper’s empirical results across COCO (C2I), ADE20K (S2I), and CelebA-HQ (L2F) concretely demonstrate these advantages relative to ControlNet, T2I-Adapter, and LoRA.
