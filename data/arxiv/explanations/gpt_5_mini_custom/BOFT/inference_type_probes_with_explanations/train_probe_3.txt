According to the paper 'Parameter-Efficient Orthogonal Finetuning via Factorization', the proposed multiplicative Dropout randomly replaces a percentage of the butterfly components and diagonal blocks in each butterfly component with identity matrices $\bm{I}$, relying on the implicit property that replacing these blocks by $\bm{I}$ keeps the model valid, namely that this operation preserves orthogonality. This is sensible because each butterfly component $\tilde{\bm{B}}^b(d,k)$ is orthogonal by construction (via Cayley parameterization of $2b\times 2b$ blocks), and the components can be permuted into a block-diagonal form whose blocks are orthogonal; replacing some blocks with $\bm{I}$ leaves the component orthogonal since a block-diagonal matrix is orthogonal if and only if each block is orthogonal, and $\bm{I}$ is orthogonal because $\bm{I}^\top\bm{I}=\bm{I}$. Further, the full BOFT transform $\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$ remains orthogonal when some factors are set to $\bm{I}$, as the orthogonal group is closed under multiplication: if $\bm{A}$ and $\bm{B}$ are orthogonal, then $(\bm{AB})^\top(\bm{AB})=\bm{B}^\top\bm{A}^\top\bm{A}\bm{B}=\bm{B}^\top\bm{I}\bm{B}=\bm{I}$, and similarly $\bm{I}$ acts as a neutral orthogonal element. Therefore, the multiplicative Dropout’s identity replacements preserve the orthogonality constraints that underpin OFT/BOFT’s stability and generalization.
