\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: Orthogonal Finetuning (OFT): Principles, Variants, and Limitations

# OFT forward pass: z = (R W^0)^T x; zero-initialization via R = I

Orthogonal Finetuning (OFT) is a reparameterization-based finetuning strategy that modifies a pretrained linear layer by left-multiplying the frozen pretrained weights with a learned orthogonal matrix. Concretely, let the pretrained weight matrix be $\bm{W}^0\in\mathbb{R}^{d\times n}$ (columns are the neurons). A standard forward pass through that layer produces output
\[
\bm{z} = (\bm{W}^0)^\top \bm{x},
\]
for input $\bm{x}\in\mathbb{R}^d$. OFT replaces the layer weight with $\bm{R}\bm{W}^0$ where $\bm{R}\in\mathbb{R}^{d\times d}$ is constrained to be orthogonal, so the finetuned forward pass becomes
\[
\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}.
\]

The key idea is multiplicative adaptation: instead of adding a low-rank update (as in additive schemes) OFT applies a global, left-sided orthogonal transform to the layer’s input-space basis. This multiplicative form is intended to preserve geometric relations among neurons (pairwise angles) and to retain pretrained spectral properties of $\bm{W}^0$ while allowing controlled adaptation for downstream tasks.

To keep the finetuned model initially identical to the pretrained model, OFT initializes $\bm{R}$ to the identity matrix:
\[
\bm{R} = \bm{I}_d \quad\text{(initially)}.
\]
This zero-change initialization is important for stable finetuning: at the start of training the transformed weights equal the pretrained weights, and learning proceeds by gradually rotating that basis via $\bm{R}$. The orthogonality constraint and identity initialization together provide a principled way to limit how far the finetuned model departs from the pretrained one.

# Cayley parameterization for R and skew-symmetric Q

Enforcing exact orthogonality of $\bm{R}$ during optimization is nontrivial if $\bm{R}$ is parameterized naively. OFT follows the approach used in prior work to guarantee orthogonality throughout training by parameterizing $\bm{R}$ with the Cayley transform of a skew-symmetric matrix. Let $\bm{Q}\in\mathbb{R}^{d\times d}$ satisfy $\bm{Q}^\top = -\bm{Q}$ (skew-symmetric). The Cayley parameterization sets
\[
\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}.
\]
Because $\bm{Q}$ is skew-symmetric, it can be shown that $\bm{R}$ defined this way is orthogonal (when $(\bm{I}-\bm{Q})$ is invertible). The Cayley map provides a smooth parameterization of (most of) the orthogonal group and has two properties that make it attractive for finetuning:

1. Orthogonality by construction. Every allowed $\bm{Q}$ produces an $\bm{R}$ with $\bm{R}^\top \bm{R} = \bm{I}$, so no projection or constrained optimization is needed during gradient steps.

2. Identity initialization via zero skew-symmetric matrix. Setting $\bm{Q}=\bm{0}$ yields $\bm{R}=\bm{I}$, so the initial model is exactly the pretrained model. Thus OFT naturally implements the “zero-change” initialization often desired in PEFT schemes.

Parameterizing $\bm{R}$ through $\bm{Q}$ moves the optimization into the skew-symmetric space: instead of directly optimizing the $d\times d$ orthogonal matrix, one optimizes the strictly fewer independent entries of $\bm{Q}$ (the upper or lower triangle), and the Cayley transform maps them to an orthogonal $\bm{R}$ each step. This is the standard way OFT ensures orthogonality and stable zero initialization.

# Block-diagonal OFT: structure, parameter budget, and expressivity

A fully general orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ has \(\mathcal{O}(d^2)\) entries and, when parameterized via a skew-symmetric $\bm{Q}$, about $d(d-1)/2$ degrees of freedom. For large layers this is prohibitively many trainable parameters for parameter-efficient finetuning. To reduce the parameter budget, OFT commonly restricts $\bm{R}$ to be block-diagonal:
\[
\bm{R} = \operatorname{diag}(\bm{R}_1,\bm{R}_2,\ldots,\bm{R}_r),
\]
where each block $\bm{R}_i\in\mathbb{R}^{b\times b}$ is orthogonal and $br = d$. This block-diagonal parameterization is the principal practical variant of OFT used to trade off expressivity for parameter efficiency.

Counting effective trainable parameters in the block-diagonal OFT depends on how each block is parameterized. Using the Cayley parameterization for each block, a single $b\times b$ orthogonal block has $b(b-1)/2$ independent parameters (the independent entries of its skew-symmetric generator). With $r = d/b$ blocks, the total effective parameter count is
\[
\text{params}_{\text{block-OFT}} = r\cdot \frac{b(b-1)}{2} = \frac{d(b-1)}{2}.
\]
Asymptotically this is $\mathcal{O}(bd)$, i.e. linear in $d$ when $b$ is fixed. Two extreme cases illustrate the trade-offs:

- If $b=d$ (one block), block-diagonal OFT reduces to full OFT (a full orthogonal matrix) with $\mathcal{O}(d^2)$ parameters.
- If $b$ is small (e.g. $b=2$ or $4$), parameter count is small ($\mathcal{O}(d)$) but representational flexibility is reduced.

Expressivity: a block-diagonal orthogonal $\bm{R}$ can only mix coordinates within each block; it cannot create linear combinations across blocks. Thus, block-diagonal OFT can rotate subspaces internally but cannot permute or mix information across block boundaries. This limited mixing reduces the subset of orthogonal transformations accessible to the finetuning process and constrains the hypothesis class to block-wise rotations.

# Inductive biases of block sparsity: fixed partitioning and loss of cross-block mixing

The block-diagonal parameterization introduces a concrete inductive bias by imposing a fixed partition of the $d$ input dimensions into $r$ non-overlapping groups. The orthogonal transform that the finetuning process may learn is restricted to act only inside these groups. This has several implications:

- Arbitrary partitioning by index: The grouping is usually determined by contiguous index chunks (first $b$ coordinates, next $b$, etc.). There is no canonical reason to believe these index-based groups align with meaningful semantic substructures of the pretrained representation. As a consequence, the block partition may split dimensions that should be mixed or group dimensions that are best left distinct, producing an arbitrary bias.

- No cross-block mixing: Any component of downstream adaptation that requires forming linear combinations of features spanning different blocks is impossible under a block-diagonal $\bm{R}$. This prevents the finetuning from learning transformations akin to permutations, global rotations, or many classical dense transforms (e.g., discrete Fourier or other global orthogonal transforms) that require mixing across the entire vector.

- Fixed sparsity pattern: The block-diagonal pattern is rigid. If the best adaptation for a task requires a different sparsity or global mixing, that flexibility is not available without increasing block size (and thus parameter count).

These characteristics can hurt expressivity and prevent the model from approximating certain desirable orthogonal transforms. The paper explicitly notes that the block-diagonal orthogonal matrix "reduces expressiveness and cannot approximate classic linear transforms", and that "it makes no sense to divide the dimensions of a neuron into $r$ groups based on their indices", motivating the search for parameterizations that can produce dense orthogonal matrices while keeping parameter cost low.

# Empirical pros and cons of OFT vs LoRA

OFT and LoRA represent two different philosophies for parameter-efficient finetuning. LoRA is additive and low-rank: it updates the pretrained weight by adding a product of two low-rank matrices. OFT is multiplicative and orthogonality-constrained: it left-multiplies the pretrained weight by an orthogonal matrix.

Empirical strengths of OFT (reported in the paper):

- Generalization and stability: OFT is motivated by preserving relational geometry among neurons (pairwise angles), connected to hyperspherical energy arguments. Empirically, OFT has shown stronger generalization and more stable training behavior in finetuning text-to-image diffusion models. The orthogonal update preserves singular values of $\bm{W}^0$ (left-multiplying by orthogonal $\bm{R}$ does not change singular values), which helps preserve spectral properties of the pretrained layer—this preservation is associated with stable training dynamics.

- Conceptual simplicity: OFT performs a single structured transform shared across neurons in the layer, which is easy to reason about and initializes to identity for safe fine-tuning.

Empirical downsides and trade-offs compared to LoRA:

- Parameter cost: A full orthogonal $\bm{R}$ requires many parameters ($\sim d^2/2$ degrees of freedom). Although block-diagonal OFT reduces this cost to $\mathcal{O}(bd)$ (with effective parameter count $\tfrac{d(b-1)}{2}$), OFT still generally uses more trainable parameters than LoRA for typical PEFT budgets. LoRA’s additive low-rank form commonly yields a very small parameter footprint (rank times input and output dims), often smaller than block-OFT at comparable performance.

- Loss of expressivity for parameter-efficient variants: To be practical, OFT often uses block-diagonal structure; that restores efficiency but removes the ability to do cross-block mixing. LoRA’s low-rank updates, while constrained, can still introduce cross-dimension coupling via the product of the rank factors and the downstream layer connections.

- Unknown good sparsity: The block-diagonal sparsity pattern is a hand-chosen design; how to pick an optimal sparsity pattern (which coordinates to group) is unclear. The paper uses this observation to motivate alternative factorizations (butterfly) that aim to produce dense orthogonal transforms with fewer effective parameters and less arbitrary sparsity.

In short, OFT trades the benefits of orthogonality-preserving multiplicative updates (angle preservation, spectral stability, provable orthogonality) against the raw parameter efficiency of low-rank additive updates like LoRA. Block-diagonal OFT is a pragmatic compromise, but it brings a rigid inductive bias and misses the ability to represent dense global transforms unless block size is increased (incurring higher parameter cost). These trade-offs motivate extensions and alternative parameterizations (for example, factorizing $\bm{R}$ as a product of sparse orthogonal factors) that aim to combine dense expressivity with parameter parsimony.
