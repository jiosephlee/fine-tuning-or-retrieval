\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 6: BOFT: Orthogonal Butterfly Finetuning

# BOFT definition: R(m,b) = product of m orthogonal butterfly components

BOFT (Orthogonal Butterfly Finetuning) reparameterizes the multiplicative finetuning matrix as a product of a small number of structured, sparse, orthogonal factors. Concretely, for a layer with hidden dimension $d$ BOFT represents the orthogonal transform $\bm{R}$ used to modify the pretrained weights as

\[
\bm{R}(m,b) \;=\; \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)},
\]

where each factor $\tilde{\bm{B}}^b_{(d,i)}\in\mathbb{R}^{d\times d}$ is a block-wise butterfly component of block-size parameter $b$, and $m$ is the number of such components multiplied together. Each component is constrained to be orthogonal:

\[
\big(\tilde{\bm{B}}^b_{(d,i)}\big)^\top \tilde{\bm{B}}^b_{(d,i)} \;=\; \tilde{\bm{B}}^b_{(d,i)} \big(\tilde{\bm{B}}^b_{(d,i)}\big)^\top \;=\; \bm{I}_d,
\qquad \forall i\in\{1,\dots,m\}.
\]

The forward pass of a pretrained linear layer with weight matrix $\bm{W}^0\in\mathbb{R}^{d\times n}$ is modified by BOFT to

\[
\bm{z} \;=\; \big(\bm{R}(m,b)\bm{W}^0\big)^\top \bm{x}.
\]

Intuitively, BOFT builds $\bm{R}$ by composing a sequence of sparse orthogonal exchanges (the butterfly components). Each component is itself block-structured and sparse, so the overall representation trades the quadratic parameter cost of an unconstrained orthogonal matrix for a much smaller, structured set of parameters while still enabling dense information mixing across coordinates when multiple components are multiplied.

# Special cases: BOFT(1,b) = block-diagonal OFT; BOFT(1,d) = full OFT

BOFT forms a family of parameterizations that subsumes earlier orthogonal finetuning choices as special cases. Two important special cases are:

- BOFT(1,b). When $m=1$ the product contains just a single block butterfly component. In that case $\bm{R}(1,b)=\tilde{\bm{B}}^b_{(d,1)}$ is block-diagonal with block size $b$ (the construction of the block butterfly component at the smallest decomposition level yields a direct block-diagonal orthogonal matrix). This exactly recovers the block-diagonal Orthogonal Finetuning (OFT) used previously: the layer dimensions are partitioned into blocks of size $b$, and each block is rotated independently by its own orthogonal matrix.

- BOFT(1,d). If we set the block size equal to the full dimension ($b=d$) and keep $m=1$, the single component is an unconstrained $d\times d$ orthogonal matrix. This recovers the original, full OFT parameterization where an arbitrary dense orthogonal matrix is learned (with the full $\mathcal{O}(d^2)$ parameter cost).

Because these cases appear as settings of $(m,b)$ inside the BOFT family, BOFT literally subsumes OFT: by varying $m$ and $b$ we can move continuously between the extremes of block-diagonal sparsity and fully dense orthogonal transforms.

# Dense with fewer parameters: m = \log(2d/b), b ≥ 2; b=2 gives classic butterfly

One of BOFT's key properties is that by stacking a logarithmic number of sparse components one can obtain a dense orthogonal transform. If $d$ is a power of two (or is handled by padding/permutations in practice) and we choose the number of components

\[
m \;=\; \log\!\left(\frac{2d}{b}\right),
\qquad b \ge 2,
\]

then the product of those $m$ block-butterfly components yields a block-butterfly matrix that mixes information across all coordinates and produces a dense $d\times d$ orthogonal matrix. In the canonical and most compact setting $b=2$ (the radix-2 case), this choice gives

\[
m \;=\; \log d,
\]

and the composite matrix becomes the classic butterfly factorization familiar from the Cooley–Tukey FFT: a product of $\log d$ sparse stages where each stage contains only $\mathcal{O}(d)$ active entries. The important point is that density of the final $\bm{R}$ (every input coordinate can influence every output coordinate) is achieved not by a single dense parameter matrix, but by composing a small number of sparse orthogonal stages. This composition is what allows BOFT to produce dense transforms while keeping the parameter count much smaller than $\mathcal{O}(d^2)$.

# Parameter budget: 0.5 (b−1) d m effective trainable parameters

BOFT’s parameter budget grows linearly in $d$ times the number of stages $m$, with a modest multiplier depending on block size $b$. The paper gives the effective number of trainable parameters used by BOFT($m,b$) for a layer of width $d$ as

\[
\text{parameters}_{\text{BOFT}(m,b)} \;=\; \tfrac{1}{2}(b-1)\,d\,m.
\]

This expression captures the intuition that each butterfly component contributes roughly $\tfrac{1}{2}(b-1)d$ free parameters, and these contributions add across the $m$ components. Two useful sanity-check consequences follow immediately: when $b$ is small (e.g., $b=2$), each stage contributes only $\tfrac{1}{2}d$ parameters, and when $m$ is logarithmic in $d$ the total becomes on the order of $d\log d$ parameters. Conversely, letting $b$ grow to $d$ and $m=1$ recovers the dense case with a cost on the order of $d^2$.

It is useful to view this budget as an effective budget: orthogonality and the block-butterfly structure impose parameter sharing and other dependencies, so the raw count reflects the number of independent trainable degrees of freedom in the BOFT parameterization rather than just the number of nonzero entries. The main take-away is that BOFT converts the quadratic parameter scaling of a dense orthogonal matrix into a near-linear (up to a logarithmic factor) scaling by trading multiply-add compute (the sequential application of sparse components) for storage/optimization variables.

# Comparison of budgets: full OFT O(d^2), block-OFT O(b d), BOFT O(d log d)

Putting the budgets side-by-side clarifies the advantages of BOFT:

- Full OFT (unconstrained dense orthogonal matrix) requires on the order of $\mathcal{O}(d^2)$ parameters. This is expressive but expensive for large $d$.

- Block-diagonal OFT with block size $b$ uses independent orthogonal blocks and therefore needs on the order of $\mathcal{O}(b d)$ parameters (intuitively: $d/b$ blocks each of size $b\times b$). This saves parameters compared to the full case but cannot mix across block boundaries, limiting expressivity.

- BOFT achieves an intermediate and generally preferable scaling. In the common radix-2 setting ($b=2$) with $m=\log d$ stages, BOFT uses on the order of $\mathcal{O}(d\log d)$ parameters; more generally BOFT($m,b$) uses $\tfrac{1}{2}(b-1) d m$ parameters. Thus BOFT gives a parameter-efficient route to dense or near-dense transforms: with modest $b$ and $m=\mathcal{O}(\log d)$ the model can realize dense orthogonal transforms while keeping parameters sub-quadratic, often much smaller than full OFT and at similar or better expressivity than block-diagonal OFT with comparable parameter budgets.

This trade-off is the core practical advantage: BOFT allows one to choose an $(m,b)$ pair to navigate between strong regularity (small $m$, large $b$ approaching block-diagonal) and strong information mixing (larger $m$, smaller $b$ approaching classic butterfly), picking a point that matches the parameter budget and generalization needs of the downstream task.

# Identity initialization: composing identities at start preserves pretrained model

A standard desideratum for parametrized finetuning is that initialization should reproduce the pretrained model exactly, so that initial outputs are identical and learning proceeds by controlled, small deviations. BOFT satisfies this by initializing every orthogonal butterfly component to the identity matrix. Practically this is achieved by parameterizing each orthogonal block via a Cayley transform (or other skew-symmetric-to-orthogonal map) and initializing the underlying skew-symmetric parameters to zero; the Cayley transform of the zero skew-symmetric matrix is the identity. With all components initialized to identity the composite $\bm{R}(m,b)$ is identity and the finetuned model initially matches the pretrained model exactly.

This identity initialization has two favorable consequences. First, training starts from the pretrained predictor, avoiding sudden destructive changes. Second, because the parameterization is multiplicative, small parameter changes in the low-dimensional factors lead to controlled rotations of the original weight matrix, which helps preserve pretrained structure (angles and spectral properties) and stabilizes optimization.

# Zero inference cost: folding R into W^0 after training

Although BOFT applies a multiplicative sequence of orthogonal components at training time (which adds some runtime cost during finetuning), there is no inference-time cost penalty. After finetuning completes, the learned orthogonal matrix $\bm{R}(m,b)$ can be multiplied into the frozen pretrained weights to produce a single updated weight matrix

\[
\bm{W}^{\text{finetuned}} \;=\; \bm{R}(m,b)\,\bm{W}^0,
\]

and this multiplication is a one-time update of stored parameters. At inference, only $\bm{W}^{\text{finetuned}}$ is needed: the factorization into multiple components is no longer required. Therefore BOFT introduces zero additional inference-latency compared to the original model. This property keeps BOFT attractive for deployment: it provides parameter-efficient, stable finetuning while preserving the runtime characteristics of the pretrained model at inference time.

# Summary and practical implications

BOFT is a structured family of orthogonal finetuning parameterizations indexed by $(m,b)$ that interpolates between block-diagonal and fully dense OFT, while enabling dense information mixing with far fewer parameters by leveraging butterfly-style sparse stages. The governing formulas are:

- Representation: \(\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}\) with each \(\tilde{\bm{B}}^b_{(d,i)}\) orthogonal.

- Special cases: BOFT(1,b) = block-diagonal OFT; BOFT(1,d) = full OFT.

- Dense mixing with few parameters: choose \(m=\log(2d/b)\); the radix-2 case \(b=2\) and \(m=\log d\) recovers the classic butterfly, which yields dense mixing with \(\mathcal{O}(d\log d)\) parameters.

- Parameter count: \(\text{params}=\tfrac{1}{2}(b-1)\,d\,m\). Comparisons: full OFT \(\mathcal{O}(d^2)\), block-OFT \(\mathcal{O}(b d)\), BOFT (radix-2) \(\mathcal{O}(d\log d)\).

- Initialization and deployment: initialize each component as identity to preserve the pretrained model at the start; after finetuning fold the learned \(\bm{R}\) into \(\bm{W}^0\) so inference has zero extra cost.

These properties make BOFT a principled, parameter-efficient way to obtain orthogonal finetuning that keeps desirable spectral and geometric properties from the pretrained model while enabling expressive, dense transformations with far fewer trainable degrees of freedom.
