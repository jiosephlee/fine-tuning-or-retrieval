\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 2: Mathematical Foundations for Orthogonal Finetuning

# Orthogonal matrices: angle and norm preservation; spectral properties

An orthogonal matrix is a square matrix $\bm{R}\in\mathbb{R}^{d\times d}$ that satisfies
\[
\bm{R}^\top \bm{R} = \bm{R}\bm{R}^\top = \bm{I}_d,
\]
where $\bm{I}_d$ is the $d\times d$ identity matrix. Two fundamental and directly useful consequences follow from this defining property: preservation of Euclidean norms and preservation of inner products (hence angles) under left or right multiplication by $\bm{R}$.

If $\bm{u}\in\mathbb{R}^d$ is any vector, then
\[
\|\bm{R}\bm{u}\|_2^2 = (\bm{R}\bm{u})^\top(\bm{R}\bm{u}) = \bm{u}^\top (\bm{R}^\top\bm{R}) \bm{u} = \bm{u}^\top \bm{u} = \|\bm{u}\|_2^2.
\]
Thus orthogonal multiplication preserves the Euclidean norm $\|\cdot\|_2$. Similarly, for any two vectors $\bm{u},\bm{v}\in\mathbb{R}^d$,
\[
(\bm{R}\bm{u})^\top(\bm{R}\bm{v}) = \bm{u}^\top(\bm{R}^\top\bm{R})\bm{v} = \bm{u}^\top\bm{v},
\]
so inner products and therefore pairwise angles are preserved.

Spectral properties of orthogonal matrices are also simple and useful. Orthogonal matrices are normal and their singular values are all equal to $1$. If a matrix $\bm{W}^0$ has singular value decomposition (SVD)
\[
\bm{W}^0 = \bm{U}\bm{\Sigma}\bm{V}^\top,
\]
with $\bm{U},\bm{V}$ orthogonal and $\bm{\Sigma}$ diagonal with non-negative singular values, then left-multiplying by an orthogonal $\bm{R}$ yields
\[
\bm{R}\bm{W}^0 = (\bm{R}\bm{U})\bm{\Sigma}\bm{V}^\top,
\]
so the singular values (the diagonal entries of $\bm{\Sigma}$) are unchanged. In particular the spectral norm (largest singular value) satisfies
\[
\|\bm{R}\bm{W}^0\|_2 = \|\bm{W}^0\|_2.
\]
This invariance of the singular value spectrum under orthogonal transformations is central to later discussions about stability and generalization in finetuning.

# Cayley transform: enforcing orthogonality via skew-symmetric parameters

When one wishes to parametrize an orthogonal matrix for optimization, a convenient construction is the Cayley transform. The paper uses Cayley parameterization to ensure orthogonality of the finetuning transform throughout training. Given a skew-symmetric matrix $\bm{Q}\in\mathbb{R}^{d\times d}$ (so $\bm{Q}^\top = -\bm{Q}$), the Cayley transform maps $\bm{Q}$ to an orthogonal matrix $\bm{R}$ by
\[
\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}.
\]
This expression guarantees $\bm{R}^\top \bm{R} = \bm{I}$ provided $(\bm{I}-\bm{Q})$ is invertible, because algebraic manipulation using $\bm{Q}^\top = -\bm{Q}$ yields orthogonality. As an optimization strategy, the skew-symmetric $\bm{Q}$ carries fewer independent parameters than an unconstrained matrix (due to the antisymmetry), yet optimizing over $\bm{Q}$ and mapping through the Cayley transform produces a valid orthogonal $\bm{R}$ at every step.

Two practical points relevant to finetuning arise from this parameterization. First, it supports identity initialization by choosing $\bm{Q}=\bm{0}$, which yields $\bm{R}=\bm{I}$. Starting from the identity is useful because it yields zero change to the pretrained model at initialization and therefore a conservative starting point for finetuning. Second, enforcing orthogonality via Cayley transform avoids drifting away from the orthogonal manifold during gradient updates; the optimization is performed in the unconstrained skew-symmetric parameter space but the forward model always sees an orthogonal matrix.

In the BOFT (Orthogonal Butterfly) framework the same Cayley idea is applied blockwise: each sparse factor used in the butterfly factorization is constrained to be orthogonal, and those orthogonal blocks can be obtained by Cayley transforms of small skew-symmetric blocks. This makes it straightforward to enforce orthogonality of each factor while keeping the whole product orthogonal.

# Neurons as column vectors: preserving pairwise angles during finetuning

In the finetuning setting considered in the paper, a linear layer's pretrained weight matrix is denoted $\bm{W}^0\in\mathbb{R}^{d\times n}$. The columns of $\bm{W}^0$ are the neuron vectors (each column is a neuron in the layer). Let $\bm{w}^0_i$ denote the $i$-th column of $\bm{W}^0$. The OFT family of methods (including BOFT) finetunes by left-multiplying the pretrained weight by an orthogonal matrix $\bm{R}$, so the finetuned weights become $\bm{R}\bm{W}^0$. The forward pass for an input $\bm{x}\in\mathbb{R}^d$ therefore changes from
\[
\bm{z} = (\bm{W}^0)^\top \bm{x}
\]
to
\[
\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}.
\]

Because orthogonal multiplication preserves inner products and norms, the pairwise inner products between neuron vectors are preserved up to numerical precision:
\[
(\bm{R}\bm{w}^0_i)^\top(\bm{R}\bm{w}^0_j) = (\bm{w}^0_i)^\top(\bm{w}^0_j).
\]
Equivalently, the pairwise angles between columns of the weight matrix remain unchanged. The intuition behind this design choice is that the relational geometry among neurons—how neurons are oriented relative to one another—encodes semantic information learned during pretraining. By restricting finetuning to orthogonal left-multiplication, OFT and BOFT aim to adjust the linear layer while preserving that relational geometry. This is more structured than the common heuristic of merely using small learning rates: it enforces a concrete geometric invariance.

This view also clarifies why multiplicative updates of the form $\bm{R}\bm{W}^0$ differ qualitatively from additive updates (e.g., adding a low-rank matrix). An additive update can change pairwise angles and singular values of the matrix, whereas an orthogonal multiplicative update leaves those quantities intact.

# Spectral norm and training stability: why preserving \|\bm{W}\|_2 matters

Preservation of the spectral norm under orthogonal left-multiplication is a direct consequence of the SVD argument in the orthogonal matrices section. If
\[
\bm{W}^0 = \bm{U}\bm{\Sigma}\bm{V}^\top,
\]
then left-multiplying by orthogonal $\bm{R}$ yields the same singular value diagonal $\bm{\Sigma}$. Thus the spectral norm $\|\bm{W}^0\|_2$ (the largest singular value) is unchanged by OFT / BOFT.

Why is this important for finetuning? The spectral norm controls how large outputs of a linear layer can become relative to its inputs; large spectral norms can amplify small variations in activations and gradients, potentially destabilizing training. By preserving the spectral norm of pretrained weights, orthogonal finetuning methods maintain the scale behavior the pretrained model already exhibited. The paper cites this preservation as a beneficial property for both training stability and generalization: orthogonal finetuning avoids introducing large changes to the operator norm of the layer, which helps keep optimization well-conditioned and reduces risk of overfitting associated with uncontrolled amplification.

This contrasts with some additive reparameterizations (like unconstrained low-rank updates) that can alter singular values and thereby change Lipschitz properties of layers during finetuning. OFT/BOFT's multiplicative orthogonal constraint provides a principled way to preserve these spectral characteristics.

# Complexity notions: parameter count O(d^2), O(d \log d), memory vs compute trade-offs

A central practical concern in finetuning large foundation models is parameter efficiency: how many trainable parameters must be introduced to adapt the model to a downstream task. Different parameterizations of the orthogonal transform induce different parameter counts.

A dense unconstrained orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ nominally requires on the order of $d^2$ parameters to represent, so full OFT with a dense orthogonal matrix is an $\mathcal{O}(d^2)$ parameter method. To improve parameter-efficiency, the original OFT introduced a block-diagonal structure: $\bm{R}=\mathrm{diag}(\bm{R}_1,\dots,\bm{R}_r)$ with blocks of size $b$ satisfying $br=d$. In that case, the number of trainable parameters is proportional to $bd$ (formally $\mathcal{O}(bd)$), which is linear in $d$ when $b$ is fixed and much smaller than $d^2$.

BOFT replaces the block-diagonal sparsity by representing $\bm{R}$ as a product of $m$ sparse, orthogonal "butterfly" components:
\[
\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}.
\]
For BOFT($m,b$) the paper gives an effective parameter count of
\[
\frac{1}{2}(b-1)\,d\,m
\]
trainable parameters for a layer of size $d\times n$. A commonly interesting choice is $b=2$ (the radix-2 butterfly), and taking $m=\log d$ yields the classical butterfly factorization that achieves dense connectivity with only $\mathcal{O}(d\log d)$ parameters. Thus BOFT can realize a dense orthogonal transform with parameter complexity that scales subquadratically in $d$.

This parameter saving comes at a compute trade-off. Representing $\bm{R}$ as a product of multiple sparse factors reduces memory footprint for trainable parameters but requires evaluating the product (and its gradient propagation) during each forward/backward pass. The paper emphasizes this as a trade-off: BOFT trades runtime computation for a smaller parameter set (space). Practically, the training runtime overhead is slightly larger than a single dense factor OFT because the sparse factors must be multiplied repeatedly, but after finetuning these learned orthogonal matrices can be multiplied into the pretrained model once so that inference has no additional latency.

From the information-transmission perspective introduced in the paper, each sparse factor corresponds to edges in a layered graph; orthogonality requires at least $d$ structural connections per factor to be full-rank, and the design goal is to achieve dense end-to-end connectivity while keeping the total number of free (trainable) edges small. The butterfly graph achieves dense connectivity between input and output nodes with approximately $O(d\log d)$ edges, which explains its favorable parameter-count scaling.

Finally, expressivity and representational capacity must be considered along with parameter counts. The paper proves that BOFT is strictly more expressive than block-diagonal OFT with the same block size, and a generalized composition of many butterfly matrices (a kaleidoscope hierarchy) can represent the entire orthogonal group when allowed sufficient components. But greater expressivity is not always better for finetuning; the best practical behavior comes from a balance (regularity versus expressivity). BOFT provides a middle ground: substantially reduced parameter count compared to dense OFT while retaining enough structure to represent many useful transforms and to preserve desirable spectral and geometric invariants during finetuning.
