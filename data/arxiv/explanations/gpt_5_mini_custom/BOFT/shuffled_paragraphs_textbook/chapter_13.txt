First, orthogonality itself confers stability. Multiplying a pretrained weight matrix $\bm{W}^0$ on the left by an orthogonal matrix preserves singular values, because if $\bm{W}^0=\bm{U}\bm{\Sigma}\bm{V}^\top$ then $\bm{R}\bm{W}^0=(\bm{R}\bm{U})\bm{\Sigma}\bm{V}^\top$ and $\bm{R}\bm{U}$ is orthogonal. Thus BOFT (like OFT) preserves the spectral norm and overall singular value profile of the pretrained layer, which is associated with improved training stability and better generalization behavior.

Chapter 13: Summary and Key Takeaways

- If you want the densest representation with the smallest parameter count that still yields a dense orthogonal matrix, use the butterfly extreme with $b=2$ and set $m\approx \log d$ (the classical radix-2 butterfly). In this regime BOFT uses $\mathcal{O}(d\log d)$ parameters.
- If you prefer the original block-diagonal OFT behavior, set $m=1$; BOFT($1,b$) exactly recovers block-diagonal OFT with block size $b$ and the same parameter count.
- To trade between expressivity and parameter count, vary $b$ and $m$: increasing $m$ or decreasing $b$ generally increases expressivity for the same or smaller parameter budget, while decreasing $m$ or increasing $b$ biases toward more regular (block-wise) transforms.

Note: the paper provides the formal counts and structural guidance for setting $(m,b)$; it does not prescribe single fixed numerical values for all tasks. The appropriate tradeoff depends on model dimension $d$ and the desired parameter budget; the above rules summarize how to map those goals into BOFT choices.

- Exploring other network topologies. The butterfly graph is one topology that efficiently transmits information (dense connectivity) with $\mathcal{O}(d\log d)$ edges. The information-transmission framework invites looking at other topologies studied in networking and sparse linear-algebra that might yield alternative parameter/compute trade-offs or even better empirical performance on specific tasks.
- Automated structure discovery. Rather than fixing a topology by hand, one could imagine algorithms that search over sparse factorization patterns (within the orthogonality constraint) to automatically discover the structure most appropriate for a given model or dataset.
- Deeper theoretical and empirical understanding of expressivity vs. generalization. BOFT sits between the extremes of block-diagonal OFT and full orthogonal OFT. Future work can more precisely characterize the trade-off between the representational capacity of a factorized orthogonal family and its inductive bias for downstream adaptation.

Concluding remark
BOFT provides a conceptually clean and practically effective way to get the stability and spectral-preserving benefits of orthogonal finetuning while dramatically reducing the parameter footprint needed to represent dense orthogonal updates. Its information-transmission perspective, butterfly factorization, and practical mechanisms (identity initialization, multiplicative Dropout, and post-training fusion) make it a compelling option when adapting very large foundation models under a strict parameter budget.

This parameter saving comes from trading space for time: BOFT represents a dense connectivity (every input index can influence every output index) by composing a small number of sparse connectivity layers. From the information-transmission perspective the paper develops, each sparse factor defines a level-to-level set of edges in a $d\times(m+1)$ grid; the butterfly topology transmits information from every source node to every sink node using only $\mathcal{O}(d\log d)$ edges, whereas a single dense factor would require $\mathcal{O}(d^2)$ edges.

BOFT opens a principled direction for parameter-efficient orthogonal updates by connecting matrix factorization to information transmission on a grid graph. The paper highlights several avenues for future work that follow directly from this viewpoint:

The core idea of Orthogonal Butterfly (BOFT) is to preserve the benefits of Orthogonal Finetuning (OFT) — namely, finetuning by left-multiplying a pretrained weight matrix by an orthogonal matrix — while drastically reducing the number of trainable parameters by parameterizing that orthogonal matrix as a product of sparse, structured factors. Instead of directly learning a dense orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ (which requires on the order of $d^2$ parameters), BOFT writes
\[
\bm{R} \;=\; \tilde{\bm{B}}_{(d,1)}^b \,\tilde{\bm{B}}_{(d,2)}^b \cdots \tilde{\bm{B}}_{(d,m)}^b,
\]
where each component $\tilde{\bm{B}}_{(d,i)}^b$ is a block-wise butterfly component and each component is constrained to be orthogonal. These components are sparse (each component has only $\mathcal{O}(d)$ nonzero blocks) and, when composed, can yield a dense matrix. BOFT therefore replaces a single large orthogonal layer with a short sequence of sparse orthogonal layers that together achieve the same functional effect.

Finally, the paper notes a practical limitation to keep in mind: BOFT increases training-time work because of the multiplicative factors, though inference remains unchanged after fusion. Any future improvements that reduce training-time overhead (for example, algorithmic acceleration of the sparse multiplications or learned sparsity schedules) would make BOFT even more attractive in practice.

For initialization, follow the identity initialization described in the paper (initialize the Cayley skew-symmetric parameters to zero so each component starts as identity). For regularization, use the multiplicative Dropout mechanism introduced: during training randomly replace some butterfly components (or some diagonal blocks within components) by identity to limit overfitting of the multiplicative chain. After finetuning, fuse the learned orthogonal composition into the pretrained weights by multiplying the factors into $\bm{W}^0$; this fusion eliminates extra inference-time computation so BOFT incurs zero-latency cost at inference.

BOFT was developed with the practical goal of adapting large foundation models without retraining them from scratch. The paper reports an extensive empirical study applying BOFT to adapt large vision transformers, large language models, and text-to-image diffusion models, across tasks in both vision and language. BOFT consistently demonstrates strong parameter-efficiency and generalization, outperforming existing parameter-efficient finetuning baselines in the authors’ experiments. Two practical properties make BOFT appealing:

- Zero-latency inference after fusion. Although BOFT composes multiple sparse orthogonal factors during training (which increases training-time computation modestly), the learned composition can be multiplied into the pretrained weight matrix after finetuning, so there is no additional inference-time latency or architectural change.
- Initialization and regularization that match finetuning practice. Identity initialization keeps the finetuned model initially identical to the pretrained model, matching the common practice of small initial deviation. Multiplicative Dropout offers a principled way to regularize multiplicative updates.

Two technical choices enable this factorization in a stable, zero-initialization way. First, each sparse factor is parameterized as an orthogonal block (for example by Cayley parameterization or explicit 2D rotations), which guarantees orthogonality of the factor and preserves the model’s spectral properties across training. Second, BOFT initializes every butterfly factor to the identity (zero skew-symmetric in Cayley), ensuring the finetuned model starts exactly at the pretrained weights and only departs from them through the learned orthogonal factors. The paper also introduces a multiplicative Dropout adapted to this multiplicative update: randomly replace some butterfly components or some diagonal blocks within them by identity during training to regularize the multiplicative composition.

Second, the butterfly factorization introduces a structured inductive bias. The class of orthogonal matrices realizable by a short product of butterfly components is a structured subset of the full orthogonal group. That smaller hypothesis class reduces overfitting risk compared to full finetuning while remaining expressive enough to capture many useful transforms: butterfly factorizations (and permutations thereof) can exactly represent many classical fast linear transforms, such as the discrete Fourier transform or Hadamard transform. This match between the parameterization and commonly useful linear transforms provides a useful prior for learning, enabling BOFT to find good finetuned models with far fewer parameters. The paper’s simulations show that for the same parameter budget BOFT often attains smaller approximation error to random orthogonal targets than block-diagonal OFT — formally, BOFT is more expressive than OFT with the same block size (see Theorem in the paper), and with modest depth it can closely approximate dense orthogonal matrices with far fewer parameters.

Practically, BOFT subsumes the block-diagonal OFT as a special case: BOFT with $m=1$ reduces to block-diagonal OFT with block size $b$. Therefore BOFT yields a continuum of parameter/expressivity trade-offs controlled by $(m,b)$: increasing $m$ (more sparse stages) or decreasing $b$ (smaller blocks) increases the compositional depth and hence expressivity for the same or fewer parameters.
