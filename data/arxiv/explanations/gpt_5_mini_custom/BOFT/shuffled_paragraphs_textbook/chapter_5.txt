A key design requirement for orthogonal finetuning is that every multiplicative factor used to transform the pretrained weight matrix must itself be orthogonal, so that the overall transform preserves the spectral norm and the pairwise angle relationships in the pretrained parameters. The paper ensures orthogonality of each butterfly component by parameterizing the small building blocks in a way that guarantees orthogonality throughout training.

Intuitively, what the butterfly graph accomplishes is rapid global mixing using only local, repeated interactions. At each stage of the FFT recursion, pairs of values are combined (a local operation), then the results are permuted, and the process repeats. After roughly \(\log N\) such stages, each input coordinate has had a path that reaches every output coordinate. In other words, information initially concentrated in one input slot is able to flow to all output slots after a small number of sparse, local interactions. This is the core reason the butterfly topology is so attractive when one wants dense connectivity (every input influences every output) without paying the dense \(O(N^2)\) cost.

Concretely, in the block version each \(\bm{d}_i\) becomes a vector of \(b\times b\) blocks, so each local interaction is a \(2b\times 2b\) block coupling rather than a \(2\times 2\) scalar coupling. This generalization yields two practical benefits. First, it allows the parameterization to align with natural block sizes arising in layers (for example, when layer dimensions are multiples of some block size \(b\)). Second, it increases expressivity per stage: a larger block admits a richer local orthogonal transform (a \(2b\times 2b\) orthogonal matrix instead of a 2-by-2 rotation), which can improve approximation quality with the same number of stages.

Given the small-scale factor \(\bm{B}^F(k)\), we use it to build larger matrices through block-diagonal assembly and recursion. The central object is the butterfly component \(\tilde{\bm{B}}(d,k)\), defined for a dimension \(d\) that is a power of two (or decomposed into powers of two). The block structure encodes a set of independent 2-by-2 interactions across the \(k\) coordinates: each diagonal entry in the four diagonal blocks corresponds to a small 2-by-2 coupling between two coordinates at that stage. Viewed graphically, \(\bm{B}^F(k)\) implements a layer of pairwise connections between the current set of nodes and the next-level nodes, and those pairwise connections are repeated \(k/2\) times in parallel.

For the purposes of parameter-efficient matrix factorization, the same property is valuable. If we can express a dense linear map as a product of a small number of sparse factors arranged with a butterfly topology, we can maintain dense effective connectivity while drastically reducing the number of independent trainable parameters. In the parameterization developed in the paper, the Cooley–Tukey butterfly graph becomes the blueprint for composing a dense orthogonal matrix from a sequence of sparse orthogonal components. The resulting factorization achieves global mixing in \(O(\log d)\) stages rather than a single dense stage, which underlies the parameter-efficiency of the Orthogonal Butterfly (BOFT) approach.

There are two complementary parameterization strategies discussed. For the smallest building block, the scalar 2-by-2 interactions can be made orthogonal by using 2D rotations or by Cayley parameterization of a \(2\times 2\) orthogonal matrix. More generally, for the block-butterfly case, each \(2b\times 2b\) block is directly parameterized to be orthogonal. Chapter 5: Butterfly Structures: From FFT to Efficient Orthogonal Parameterization

The paper gives a concrete parameter count for the block-butterfly BOFT construction: BOFT with parameters \((m,b)\) (meaning \(m\) components and block half-size \(b/2\)) uses approximately

\[
\tilde{\bm{B}}(d,k) = \operatorname{diag}\big(\bm{B}^F_1(k),\; \bm{B}^F_2(k),\; \dots,\; \bm{B}^F_{d/k}(k)\big).
\]

The Cooley–Tukey fast Fourier transform (FFT) is one of the most famous algorithms in numerical computation because it converts the naive \(O(N^2)\) discrete Fourier transform into an \(O(N\log N)\) algorithm. Beyond the arithmetic savings, the recursive Cooley–Tukey decomposition exposes a very particular sparse connectivity pattern between the input and output coordinates. That sparse pattern is commonly referred to as a butterfly graph.

Because the nonzero sparsity patterns of \(\tilde{\bm{B}}^b(d,k)\) are block-wise permutations of the \(\tilde{\bm{B}}^b(d,2)\) pattern, ensuring orthogonality on the basic \(2b\times 2b\) blocks suffices to make every component orthogonal. Practically, this means each block is updated in a parameterization that enforces orthogonality at every training step; the product of orthogonal factors is then orthogonal as well, ensuring the orthogonal finetuning property is preserved.

Two points are important here. First, each \(\tilde{\bm{B}}(d,k)\) is sparse and structured, so the product consists of a small number of sparse stages. Second, the nonzero pattern of \(\tilde{\bm{B}}(d,k)\) can be seen as a permutation of the pattern of \(\tilde{\bm{B}}(d,2)\), which means that the same small 2-by-2 orthogonal building blocks can be reused and permuted across stages to form the larger factorization. This observation underpins how orthogonality and sparsity interplay in the construction.

Two practical remarks follow directly from this choice. First, initializing each skew-symmetric parameter to zero yields identity initializations for all components, which aligns with the standard finetuning practice of starting close to the pretrained model. Second, because orthogonality is built into the parameterization, the method preserves spectral properties (e.g., singular values) of the pretrained weight matrix up to orthogonal left-multiplication, which helps training stability.

Why this particular form? There are two useful properties. First, because each block is diagonal rather than fully dense, the number of free entries in \(\bm{B}^F(k)\) is linear in \(k\) rather than quadratic. Second, the diagonal-block form naturally supports orthogonality when each 2-by-2 interaction is parameterized as an orthogonal transformation (e.g., a rotation). This local orthogonality is what allows the whole factor to be orthogonal when assembled properly, which is critical for preserving the spectral properties of the pretrained weight matrix in orthogonal finetuning.

In the recursive interpretation, each factor \(\tilde{\bm{B}}(d,k)\) introduces local interactions at scale \(k\), and the sequence of components progressively mixes information across exponentially larger subsets of coordinates. After composing all components down to \(k=2\), the product achieves dense connectivity from inputs to outputs even though every component individually is sparse. Graphically, this mirrors how the FFT mixes frequency bands across \(\log d\) stages.

The upshot is that the butterfly design provides a smooth, tunable trade-off between expressivity and parameter cost: by increasing \(m\) (more stages) and decreasing \(b\) (smaller blocks), one can reach dense effective connectivity with far fewer independent parameters than a naive dense matrix, while staying within the orthogonal finetuning paradigm. This is precisely the mechanism by which BOFT attains parameter efficiency without resorting to block-diagonal sparsity patterns that prevent global mixing.

One of the central advantages of the butterfly factorization is its parameter and storage complexity compared to a dense factor. A single dense \(d\times d\) orthogonal matrix has \(O(d^2)\) entries and therefore requires \(O(d^2)\) independent parameters to represent in the generic case. In contrast, a butterfly factorization represents (when using radix-2 style components) a dense effective mapping as a product of \(O(\log d)\) sparse components, and each component has \(O(d)\) nonzeros. Consequently, the total number of nonzero trainable entries and independent parameters can be as small as \(O(d\log d)\).
