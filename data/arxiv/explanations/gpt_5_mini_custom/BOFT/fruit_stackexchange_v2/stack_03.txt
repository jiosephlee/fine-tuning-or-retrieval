### Why does dense connectivity in the information-transmission graph imply a dense product matrix?
Question:
The paper reframes factorizing $\mathbf{R}=\mathbf{B}_m\cdots\mathbf{B}_1$ as information transmission on a $d\times (m+1)$ grid and states that if every source node has a path to every sink node, then the product can be dense. But a path existing only guarantees it is possible for an entry to be nonzero, not that it must be. Couldn't different paths cancel out and produce zeros? Under what assumptions does "dense connectivity" imply a dense nonzero pattern of $\mathbf{R}$? Is the claim that, for generic continuous parameters, the set of cancellations yielding extra zeros has measure zero?
Answer:
Short answer: the paper is relying on the usual “generic parameter” fact: an entry of the product $R = B_m \cdots B_1$ is a polynomial in the free parameters of the factors; if the graph (i.e. the set of paths) allows a nonzero polynomial term, then that polynomial is not identically zero, so random continuous choices of the parameters will almost surely make it nonzero. Thus “dense connectivity” (a path from every source to every sink) permits a dense $R$ for generic parameters; the set of parameter choices that produce extra cancellations (making some allowed entry exactly zero) is an algebraic variety of strictly lower dimension and therefore has Lebesgue measure zero.
