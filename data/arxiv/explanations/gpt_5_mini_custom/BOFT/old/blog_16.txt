## 4. Interoperability with PEFT Libraries

The popular PEFT APIs expect adapter modules to live under `model.peft`. We can register our BOFT wrappers as a custom adapter by:

## 5. Exporting Merged Weights

Once finetuning is done, you may want to fold $\bm{R}$ into the original weight for fast inference:

```python
def merge_boft_weights(model: nn.Module):
    for module in model.modules():
        if isinstance(module, BOFTLinear):
            with torch.no_grad():
                R = module._build_orthogonal()
                # overwrite weight and remove BOFT parameters
                module.weight.data.copy_(R @ module.W0)
                # drop the BOFT-specific params
                del module.W0
                del module.skews
                module.__class__ = nn.Linear  # revert to normal Linear
```

After you call `merge_boft_weights(model)`, your model only has merged `weight` and `bias`. Save it normally:

```bash
python -c "from your_script import merge_boft_weights; \
model = AutoModelForCausalLM.from_pretrained('./boft_ckpt'); \
merge_boft_weights(model); model.save_pretrained('./merged_model')"
```

## 6. Testing Correctness and Orthogonality

Finally, always sanity‐check:

1. **Shape and forward consistency**  
   Compute outputs before/after merging with the same input:
   ```python
   model_before = ...
   model_after = ...
   x = torch.randn(1, seq_len, model.config.hidden_size)
   y1 = model_before(x).logits
   merge_boft_weights(model_after)
   y2 = model_after(x).logits
   assert torch.allclose(y1, y2, atol=1e-6)
   ```
2. **Orthogonality**  
   For each BOFT wrapper, verify $R^\top R = I$:
   ```python
   for module in model.modules():
       if isinstance(module, BOFTLinear):
           R = module._build_orthogonal()
           I = torch.eye(R.size(0), device=R.device)
           error = torch.norm(R.T @ R - I)
           assert error < 1e-5, f"Orthogonality failed (err={error})"
   ```

If both checks pass, you can be confident that your BOFT integration is correct.

## 7. Conclusion

Integrating BOFT into Hugging Face and PyTorch takes just a few steps: patch your Linear layers, train as usual, optionally merge and export. This engineering pattern gives you the spectral‐preserving, parameter‐efficient finetuning benefits of BOFT without disrupting your favorite training loops or tooling. Happy finetuning!
