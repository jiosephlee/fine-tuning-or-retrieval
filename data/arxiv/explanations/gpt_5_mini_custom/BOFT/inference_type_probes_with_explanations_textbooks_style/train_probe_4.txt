Parameter Efficiency in Orthogonal Butterfly Finetuning

# Orthogonal Finetuning and the Need for Parameter Efficiency
Orthogonal Finetuning (OFT) is a principled approach to adapting pretrained models that preserves geometric relationships between neurons during finetuning. In OFT, a learnable orthogonal matrix is applied to the neurons of a layer, so that pairwise angles are provably preserved throughout training. Concretely, for a pretrained linear layer with weight matrix $\bm{W}^0\in\mathbb{R}^{d\times n}$, OFT learns an orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ and modifies the forward pass from $\bm{z}=(\bm{W}^0)^\top\bm{x}$ to $\bm{z}=(\bm{R}\bm{W}^0)^\top\bm{x}$, where $\bm{x}\in\mathbb{R}^{d}$ and $\bm{z}\in\mathbb{R}^{n}$. To ensure orthogonality during training, Cayley parameterization is used: $\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$ with a skew-symmetric matrix $\bm{Q}=-\bm{Q}^\top$. OFT is initialized at identity so that the finetuned model initially matches the pretrained model.

While OFT has demonstrated strong generalization and training stability, a dense $d$-dimensional orthogonal matrix typically requires $\mathcal{O}(d^2)$ parameters if one naively parameterizes it. The original OFT improves parameter efficiency by constraining $\bm{R}$ to be block-diagonal, i.e., $\bm{R}=\text{diag}(\bm{R}_1,\bm{R}_2,\cdots,\bm{R}_r)$ with block size $b$ so that $br=d$. This reduces parameters but introduces a fixed sparsity pattern with independent transformations per block. Such a pattern can reduce expressiveness and cannot approximate classic dense linear transforms. Moreover, dividing neuron dimensions into groups purely by index is an undesirable inductive bias. This highlights a central challenge: how to construct a dense orthogonal matrix for finetuning that is markedly more parameter-efficient than a full dense parameterization.

# From Information Transmission to Butterfly Factorization
A key insight is to compose a dense orthogonal matrix as a product of multiple sparse orthogonal matrices. This can be viewed through an information transmission lens: writing $\bm{R}=\bm{B}_m\bm{B}_{m-1}\cdots\bm{B}_1$ corresponds to transmitting information across a grid with $d\times (m+1)$ nodes. Each factor $\bm{B}_i$ defines directed edges between adjacent levels of the grid, and the product is dense if every source node in the first level can reach every receiver node in the last level through some path. Under this view, two desiderata emerge for efficient composition: dense connectivity (paths from all sources to all receivers) and a minimal number of free edges (trainable nonzero entries) subject to orthogonality constraints.

A single dense orthogonal matrix consumes $\mathcal{O}(d^2)$ trainable entries (ignoring the constraints that orthogonality imposes), whereas the information transmission perspective reveals that structured sparse factorizations can achieve dense connectivity with significantly fewer edges. Among such structures, the butterfly topology from the Cooley–Tukey fast Fourier transform enables information mixing across dimensions with only $\mathcal{O}(d\log d)$ edges. This suggests an efficient path: use butterfly factorization to parameterize $\bm{R}$ as a product of sparse, orthogonal components that together yield a dense orthogonal transformation.

# BOFT($m$,$b$): Definition and Parameterization
Orthogonal Butterfly (BOFT) instantiates this idea by constructing $\bm{R}$ as a product of orthogonal butterfly components. The building block is a butterfly factor,
\[
\bm{B}^F(k)=
\begin{bmatrix}
\text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\
\text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4)
\end{bmatrix}\in\mathbb{R}^{k\times k},
\]
where $\bm{d}_i\in\mathbb{R}^{\frac{k}{2}}$ for $i=1,\dots,4$. A $d$-dimensional butterfly matrix $\bm{B}(d)\in\mathbb{R}^{d\times d}$ is defined recursively by multiplying block-diagonal “butterfly components” $\tilde{\bm{B}}(d,k)$ of size $d\times d$, each composed of blocks $\bm{B}^F(k)$:
\[
\bm{B}(d)=\tilde{\bm{B}}(d,d)\tilde{\bm{B}}(d,\tfrac{d}{2})\cdots\tilde{\bm{B}}(d,2).
\]
To increase capacity per connection, BOFT generalizes to block butterfly components $\tilde{\bm{B}}^b(d,k)$ where each scalar entry of $\bm{B}^F(k)$ is replaced by a $b\times b$ matrix. Orthogonality of each butterfly component is ensured by parameterizing each $2b\times 2b$ block using Cayley transform (or equivalently via $2\times 2$ or $2b\times 2b$ orthogonal constructions), and the remaining components are orthogonal by block-wise permutation.

The forward pass in BOFT is
\[
\bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x},\quad
\text{with}\quad \bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)},\quad
\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top\tilde{\bm{B}}^b_{(d,j)}=\bm{I}_d\ \ \forall j\in[1,m],
\]
where $\tilde{\bm{B}}^b_{(d,i)}=\tilde{\bm{B}}^b\!\big(d,2^{\,m-i+1}\big)$ and $\bm{I}_d$ is the identity matrix. For convenience, BOFT with $\bm{R}(m,\frac{b}{2})$ is denoted as BOFT($m$,$b$), with $b\geq 2$. Special cases recover familiar baselines: BOFT($1$,$b$) reduces to block-diagonal OFT with block size $b$; BOFT($1$,$d$) reduces to original OFT with a full orthogonal matrix; and BOFT$\big(\log \tfrac{2d}{b},\,b\big)$ uses the block butterfly matrix to yield a dense orthogonal $\bm{R}$ for any $b$.

# Counting Trainable Parameters and the Role of $b$
A central property of BOFT is its parameter efficiency. For a linear layer of size $d\times n$, BOFT($m$,$b$) uses
\[
\frac{1}{2}(b-1)dm
\]
effective trainable parameters. This count reflects how many degrees of freedom are available in the orthogonal butterfly components once orthogonality constraints are enforced. It shows that the parameter budget scales linearly with $d$ and $m$, and linearly with $(b-1)$.

The consequence for design is immediate: for fixed $d$ and $m$, the number of parameters is minimized by decreasing $b$. In other words, reducing the block size directly reduces the trainable parameter count. The smallest feasible choice is $b=2$, which yields the classic butterfly structure. In that case, BOFT achieves $\mathcal{O}(d\log d)$ parameters when $m=\log d$, a significant improvement over the $\mathcal{O}(d^2)$ required by an unconstrained dense orthogonal parameterization. In contrast, original OFT needs $b=d$ to produce a dense orthogonal matrix, whereas BOFT can produce a dense orthogonal matrix for any $b$ by increasing $m$ appropriately.

This formula also clarifies trade-offs when allocating a parameter budget across layers or tasks. If the practitioner is constrained to a fixed $m$ (e.g., due to runtime considerations associated with multiplying more factors), then lowering $b$ is the most straightforward way to reduce the parameter count while retaining the same number of butterfly components. Conversely, if $b$ must remain large to allocate more capacity per local mixing, increasing $m$ grows the budget linearly and enhances information transmission depth.

# Trade-offs: Expressivity, Regularity, and the Choice of $b$ and $m$
Parameter efficiency is not the only consideration; expressivity and regularity determine how well finetuning generalizes. BOFT defines a structured subset of the orthogonal group via butterfly factorization, which induces an inductive bias. This structure can recover many classic fast linear transforms via permutations, while block-diagonal OFT cannot recover any such dense transforms. Consequently, BOFT is more expressive than OFT with the same block size. Indeed, BOFT with smaller $b$ and larger $m$ is generally more parameter-efficient, and empirical approximation results show that configurations like BOFT($6$,$4$) can achieve similar approximation error to BOFT($2$,$16$) with far fewer parameters, while BOFT($9$,$2$) can outperform BOFT($1$,$16$) at a much smaller parameter budget.

There is also a theoretical perspective: multiplying butterfly matrices in a kaleidoscope hierarchy can approximate the entire orthogonal group. Specifically, by composing factors as $\bm{B}_{d-1,1}(d)\bm{B}^\top_{d-1,2}(d)\cdots\bm{B}_{1,1}(d)\bm{B}^\top_{1,2}(d)$, one can span all orthogonal matrices in size $d$ when the hierarchy is sufficiently deep. BOFT therefore provides a smooth interpolation between identity matrices (strong regularity) and the full orthogonal group (high expressivity). However, greater expressivity is not always better in finetuning; the best performance typically arises from a careful trade-off between expressivity and regularity. BOFT’s structured parameterization helps locate a smaller, well-regularized hypothesis class within the orthogonal group that generalizes more robustly.

Choosing $b$ and $m$ reflects this trade-off. Decreasing $b$ reduces parameters and enforces a stronger structure, which can improve regularization and generalization by aligning with patterns found in fast linear transforms. Increasing $m$ deepens the mixing across dimensions, improving expressivity without resorting to dense parameterizations. The choice of $(b,m)$ should balance the parameter budget with the desired level of structure and mixing depth. Within this design space, the fact that BOFT achieves dense orthogonal matrices for any $b$ by adjusting $m$ gives flexibility to minimize parameters by decreasing $b$ while preserving connectivity.

# Spectral Properties and Stability
Multiplying an orthogonal matrix on the left preserves the spectral norm of the pretrained weight matrix. Writing $\bm{W}^0=\bm{U}\bm{\Sigma}\bm{V}^\top$ via singular value decomposition, both OFT and BOFT produce finetuned weights $\bm{R}\bm{U}\bm{\Sigma}\bm{V}^\top$, which leave the largest singular value unchanged. Preserving the spectral norm benefits training stability and generalization. In BOFT, this stability is maintained regardless of how $b$ and $m$ are chosen, so parameter efficiency via decreasing $b$ does not compromise spectral norm preservation.

# Practical Considerations: Initialization and Dropout
BOFT initializes all butterfly components as identity matrices, ensuring the finetuned model initially matches the pretrained one. Because BOFT updates weights multiplicatively, conventional Dropout is not directly applicable. BOFT introduces a multiplicative Dropout that randomly selects a fraction of butterfly components and a fraction of the diagonal blocks within each component, replacing those blocks with identity matrices during training. This helps prevent overfitting while respecting the multiplicative and orthogonal structure.

# Summary
Orthogonal Butterfly Finetuning composes a dense orthogonal matrix from a product of sparse, orthogonal butterfly components, achieving parameter efficiency while preserving the geometric relationships central to OFT. For a layer of size $d\times n$, BOFT($m$,$b$) uses $\frac{1}{2}(b-1)dm$ effective trainable parameters. Therefore, when $d$ and $m$ are fixed, the most direct way to minimize the parameter count is to decrease $b$. Choosing smaller $b$ enhances parameter efficiency and regularization, while increasing $m$ provides additional expressivity through deeper information transmission. This structured approach yields a smooth interpolation between identity and the full orthogonal group, preserves spectral properties that stabilize training, and enables dense transformations at $\mathcal{O}(d\log d)$ parameter cost when $b=2$ and $m=\log d$.
