Chapter: Structured Orthogonal Factorizations and Generalization in Parameter-Efficient Finetuning

# Background: From Orthogonal Finetuning to Parameter Efficiency

Adapting large pretrained models efficiently hinges on preserving pretrained knowledge while introducing just enough flexibility to solve new tasks. Orthogonal Finetuning (OFT) is a principled approach that does so by transforming neurons in a layer with a shared orthogonal matrix. Given a pretrained weight matrix $\bm{W}^0 \in \mathbb{R}^{d \times n}$ for a linear layer, OFT replaces the forward computation $\bm{z} = (\bm{W}^0)^\top \bm{x}$ with $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$, where $\bm{R} \in \mathbb{R}^{d \times d}$ is orthogonal. This multiplicative update preserves pairwise angles between neurons, encouraging the finetuned model to remain close to the pretrained model in a relational sense. Orthogonality over the left factor also preserves the spectral norm of $\bm{W}^0$, a property associated with stable training and better generalization.

While OFT is attractive, parameter efficiency is a central challenge. A dense $d \times d$ orthogonal matrix carries $\mathcal{O}(d^2)$ degrees of freedom, which is excessive for large $d$. A block-diagonal parameterization of $\bm{R}$ reduces parameters to $\mathcal{O}(bd)$ when the block size is $b$, but this comes at the cost of expressivity and a rigid, index-based sparsity pattern that can induce undesirable inductive biases. The crux is how to realize a dense orthogonal transformation with far fewer parameters without falling into the drawbacks of block-diagonal structure.

# An Information Transmission View of Matrix Factorization

A key conceptual shift enables principled design of parameter-efficient orthogonal parameterizations. Consider writing a dense matrix $\bm{R} \in \mathbb{R}^{d \times d}$ as a product of $m$ factor matrices,
\[
\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1.
\]
This factorization can be viewed as information transmission on a grid with $d \times (m+1)$ nodes. Each matrix $\bm{B}_i$ encodes directed edges that transmit information from level $i$ to level $i+1$. An entry $(\bm{B}_i)_{j_1,j_2} \neq 0$ is an edge from node $j_2$ at level $i$ to node $j_1$ at level $i+1$. The product $\bm{B}_m \cdots \bm{B}_1$ is dense if and only if every source node at level $1$ has at least one path to every sink node at level $m+1$.

This viewpoint isolates two desiderata for designing sparse factorizations that yield a dense $\bm{R}$:

1) Dense connectivity: Every source node must reach every sink node through directed paths across the levels.

2) Minimum free edges: The number of trainable edges should be as small as possible, under orthogonality constraints.

Orthogonality imposes constraints at each level. For each $\bm{B}_i$ to be orthogonal, it must be full-rank and, in effect, realize a bijection across levels with $d$ essential edges. These edges are not free parameters in the same way arbitrary entries of a dense matrix are, because orthogonality strongly couples entries and forces specific dependencies (e.g., values constrained to maintain orthogonality, and zero patterns that imply further zeros). Under this lens, the design problem becomes: how do we select sparse, orthogonal connectivity patterns across levels that allow global information mixing with as few trainable degrees of freedom as possible?

Naively, a single dense orthogonal matrix uses $\mathcal{O}(d^2)$ entries, incurring a large parameter footprint. In contrast, appropriate sparse factorizations can achieve dense end-to-end connectivity with significantly fewer trainable entries. This motivates butterfly structures, which are known to mix information globally using only $\mathcal{O}(d \log d)$ nonzeros across layers.

# Butterfly Factorization: Structure for Dense Mixing with Few Parameters

Butterfly structures originate in the Cooley-Tukey fast Fourier transform algorithm. They are designed to transmit information efficiently so that local changes at one end can influence the entire output. Concretely, assume $d = 2^N$. Define a butterfly factor of size $k$ as
\[
\bm{B}^F(k) = 
\begin{bmatrix}
\mathrm{diag}(\bm{d}_1) & \mathrm{diag}(\bm{d}_2) \\
\mathrm{diag}(\bm{d}_3) & \mathrm{diag}(\bm{d}_4)
\end{bmatrix} \in \mathbb{R}^{k \times k}, \quad k \geq 2,
\]
where $\bm{d}_i \in \mathbb{R}^{k/2}$. A butterfly component at dimension $d$ and block size $k$ is a block-diagonal matrix
\[
\tilde{\bm{B}}(d,k) = \mathrm{diag}(\bm{B}^F_1(k), \ldots, \bm{B}^F_{d/k}(k)) \in \mathbb{R}^{d \times d}.
\]
The butterfly matrix $\bm{B}(d)$ is then defined recursively by stacking such components,
\[
\bm{B}(d) = \tilde{\bm{B}}(d,d) \, \tilde{\bm{B}}(d,\tfrac{d}{2}) \cdots \tilde{\bm{B}}(d,2).
\]
Each component has a sparse pattern that, when composed across $\log d$ levels, yields dense end-to-end connectivity with only $\mathcal{O}(d \log d)$ nonzeros. To ensure orthogonality, each component is parameterized as orthogonal. This is straightforward because each component is a block-diagonal permutation of $\tilde{\bm{B}}(d,2)$, and each $2 \times 2$ block can be parameterized orthogonally via a Cayley transform. A block version extends each scalar entry to a $b \times b$ block, leading to block butterfly components $\tilde{\bm{B}}^b(d,k)$; each $2b \times 2b$ block is made orthogonal, and larger components are formed by permutations of these.

Orthogonal Butterfly (BOFT) composes $m$ such orthogonal butterfly components to yield
\[
\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}, \quad \text{with } \left(\tilde{\bm{B}}^b_{(d,i)}\right)^\top \tilde{\bm{B}}^b_{(d,i)} = \bm{I}_d.
\]
This realizes a dense, orthogonal $\bm{R}(m,b)$ with only $\tfrac{1}{2}(b-1) d m$ effective trainable parameters for a $d \times n$ linear layer. Choosing $m = \log d$ and $b = 2$ recovers the butterfly matrix and gives $\mathcal{O}(d \log d)$ parameters, a substantial reduction from the $\mathcal{O}(d^2)$ parameters of a dense orthogonal matrix.

BOFT subsumes OFT as a special case. BOFT$(1,b)$ reduces to block-diagonal OFT with block size $b$, and BOFT$(1,d)$ reduces to full OFT with a dense orthogonal matrix. Crucially, BOFT$(\log \tfrac{2d}{b}, b)$ achieves a dense $\bm{R}$ for any $b \ge 2$, while block-diagonal OFT can only be dense when $b = d$.

# Expressivity, Regularity, and Structured Inductive Bias

Expressivity and regularity are two sides of an essential trade-off in finetuning. Larger hypothesis classes capture more functions but risk overfitting; smaller classes regularize more strongly but risk underfitting. In orthogonal finetuning, this trade-off is controlled by how we parameterize $\bm{R}$.

BOFT introduces a structured subset of the orthogonal group through butterfly factorization. On one hand, it is provably more expressive than block-diagonal OFT for the same block size. In fact, compositions of butterfly matrices and their transposes can span the entire orthogonal group when enough layers are stacked, showing that butterfly-based parameterizations can be made arbitrarily expressive:
\[
\bm{B}_{d-1,1}(d)\bm{B}_{d-1,2}^\top(d)\cdots \bm{B}_{1,1}(d)\bm{B}_{1,2}^\top(d),
\]
with appropriately chosen butterfly matrices $\bm{B}_{i,j}(d)$, can represent all $d \times d$ orthogonal matrices.

On the other hand, BOFT generally operates in a regime that is significantly more constrained than the full orthogonal group. A small number of factors and small block sizes enforce strong structure, forming a smaller hypothesis class with an inductive bias tied to fast linear transforms. Butterfly structures can recover classic transforms such as discrete Fourier, discrete cosine, and Hadamard transforms. This alignment with well-structured, global mixing operators serves as an implicit prior that favors transformations known to generalize well across a variety of tasks.

This structured inductive bias is in stark contrast to the block-diagonal parameterization in OFT, which reflects an arbitrary index-based partitioning and cannot approximate many classic transforms. By interpolating smoothly between the identity (via identity initialization of each factor) and a rich class of structured global mixers (via the product of sparse orthogonal factors), BOFT offers a calibrated path from regularity to expressivity.

# Why Replacing Structure with Unstructured Dense Orthogonality Hurts Generalization

Consider replacing BOFT’s product of structured sparse orthogonal factors by a single dense orthogonal matrix while holding the effective number of trainable parameters fixed. This scenario yields a parameter budget comparable to BOFT but dispenses with the structural constraints and inductive biases of butterfly factorization.

From the perspective developed above, such an unstructured parameterization expands the local freedom of individual entries while discarding the global patterning that butterfly factors impose. The information transmission view makes this concrete: butterfly layers realize dense end-to-end connectivity through carefully orchestrated sparse connectivities at each level, ensuring that information is routed and mixed across dimensions in a globally coherent, hierarchical manner. The orthogonality constraints are satisfied locally within each sparse factor, and the composition induces a global mixing topology reminiscent of efficient fast transforms.

An unstructured dense orthogonal parameterization with the same parameter budget cannot realize the same hierarchical, globally consistent mixing pattern without paying the full $\mathcal{O}(d^2)$ cost. With fewer effective parameters, any attempt to compress a dense orthogonal matrix will necessarily select a subset of entries or impose ad hoc constraints that are not aligned with the butterfly topology. This removes the implicit bias toward classic, well-behaved transforms and replaces it with a largely arbitrary coupling among dimensions. In practice, this shifts the trade-off between expressivity and regularity toward brittle expressivity: the model can fit training peculiarities within its limited parameter budget but lacks the principled global mixing and smooth interpolation that BOFT supplies. The result is a greater propensity to overfit and, therefore, worse generalization.

BOFT’s structure addresses this by:

1) Constraining the hypothesis class to a structured subset of orthogonal matrices tied to fast transforms, which embodies a beneficial inductive bias.

2) Enforcing a smooth path from the identity via identity initialization of each factor, ensuring the finetuned model remains close to the pretrained model at the start of training.

3) Preserving spectral properties of $\bm{W}^0$ by left-multiplication with an orthogonal $\bm{R}$, stabilizing training.

Replacing these ingredients with an unstructured dense orthogonal matrix parameterized under the same budget would discard the structured inductive bias and smooth interpolation while retaining only the orthogonality constraint. The paper’s broader analysis of expressivity versus regularity, and its emphasis on structured priors, therefore supports the conclusion that such a replacement is likely to generalize worse.

# Spectral Preservation and Stability Under Orthogonal Reparameterization

A salient benefit shared by OFT and BOFT is spectral norm preservation. If $\bm{W}^0 = \bm{U}\bm{\Sigma}\bm{V}^\top$ is the singular value decomposition of the pretrained weight, then replacing it by $\bm{R}\bm{W}^0$ yields $\bm{R}\bm{U}\bm{\Sigma}\bm{V}^\top$, which has the same singular values as $\bm{W}^0$ because $\bm{R}$ is orthogonal. This preserves the spectral norm and thus stabilizes optimization. BOFT maintains this benefit while adding structured inductive bias through its parameterization.

Crucially, BOFT does not merely rely on orthogonality. Its sparse factorization and global mixing topology provide additional regularization beyond spectral constraints, guiding learning toward well-behaved transformations. An unstructured dense parameterization with the same effective parameter count keeps spectral preservation but loses the structural benefits, again suggesting inferior generalization relative to BOFT.

# Practical Mechanisms: Identity Initialization and Multiplicative Dropout

BOFT is initialized at the identity by setting each orthogonal butterfly component to the identity (equivalently, initializing the skew-symmetric parameters in the Cayley transform to zero). This ensures the initial finetuned model matches the pretrained model exactly, controlling deviation during early training and reinforcing regularity.

To further curb overfitting, BOFT introduces a multiplicative Dropout tailored to its multiplicative update. Since $\bm{R}(m,b)$ is a product of orthogonal components that can be permuted to $2b \times 2b$ block-diagonal form, multiplicative Dropout randomly selects a fraction of butterfly components and a fraction of their diagonal blocks and replaces the selected orthogonal blocks by identity. This stochastically enforces additional structure and regularization during training, consistent with BOFT’s design philosophy. Such a mechanism is naturally compatible with BOFT’s factorized structure and would not translate in a straightforward or principled way to an unstructured dense orthogonal parameterization under the same parameter budget.

# Synthesis: Structure as the Bridge Between Efficiency and Generalization

BOFT demonstrates that orthogonal finetuning can be both parameter-efficient and general by embodying a principled structure: a product of sparse orthogonal butterfly components that achieve dense global mixing. This design yields:

1) Efficiency: $\mathcal{O}(d \log d)$ parameters can realize dense orthogonal transformations.

2) Expressivity: With modest depth and block sizes, BOFT surpasses block-diagonal OFT; with sufficient composition, it can represent the entire orthogonal group.

3) Regularity and Inductive Bias: The structure aligns with classic fast transforms, biases learning toward globally coherent mixing, and enables smooth interpolation from identity.

4) Stability: Spectral norm preservation and identity initialization stabilize training, and multiplicative Dropout provides additional regularization.

Under a fixed parameter budget, substituting this structured product with an unstructured dense orthogonal matrix discards the most valuable elements—structured inductive bias and globally coordinated mixing—while preserving only orthogonality. The information transmission perspective makes clear that BOFT’s sparse factors orchestrate information flow in a way that is both efficient and aligned with well-understood transforms. Consequently, an unstructured alternative with the same number of effective parameters is likely to generalize worse, lacking the principled structure that makes BOFT effective.
