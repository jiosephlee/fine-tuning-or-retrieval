According to the paper 'The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits', if embeddings were quantized to the same 1.58-bit scheme instead of remaining full precision (e.g., FP16), BitNet's memory advantage over FP16 LLaMA would most likely increase. The paper explains that BitNet b1.58 uses ternary weights in the main Transformer blocks, yielding per-parameter storage of approximately 1.58 bits, while FP16 baselines store parameters at 16 bits. The total parameter memory for a model is roughly proportional to the sum over components of parameter count times precision: for FP16, this is about 16 bits per parameter across all components; for BitNet b1.58, core layers are at 1.58 bits, but embeddings are kept at full precision. Letting the embedding memory be M_emb and the non-embedding memory be M_core, the total memory is approximately M_total ≈ M_core + M_emb for FP16, and M_total ≈ (1.58/16) M_core + M_emb for BitNet b1.58. The paper notes that the embedding stays full precision and its proportion is smaller for larger models, which implies that at current settings the full-precision embeddings dilute BitNet’s relative savings. If embeddings were also quantized to 1.58 bits, the BitNet total would become (1.58/16)(M_core + M_emb), eliminating that dilution and thus increasing the ratio of FP16 memory to BitNet memory.

This effect is especially pronounced for smaller to mid-sized models where the embedding table can be a substantial fraction of total parameters, e.g., of size V × d with memory Vd × precision. Quantizing embeddings reduces both capacity and bandwidth demands, further improving end-to-end inference efficiency because weight transfers from DRAM scale with total bits moved. Since the paper’s measured memory and latency advantages already grow with model size as the fraction of nn.Linear increases, removing the remaining full-precision component (embeddings) would yield a uniform multiplicative reduction across the parameter memory footprint: the expected memory ratio becomes roughly 16/1.58 ≈ 10.1× on all parameterized components, compared to a smaller effective ratio when embeddings remain FP16. Thus, by quantizing embeddings to the same ternary scheme, BitNet’s memory advantage over FP16 LLaMA would most likely increase, and the associated bandwidth and latency benefits from reduced weight loading would also strengthen.
