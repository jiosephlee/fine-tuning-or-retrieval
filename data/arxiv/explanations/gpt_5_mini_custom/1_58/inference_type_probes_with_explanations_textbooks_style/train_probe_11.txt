Activation Quantization in BitNet b1.58 and the Role of Zero-Point Quantization
# Background: 1-bit LLMs and BitNet b1.58
Large Language Models have historically relied on high-precision floating-point arithmetic, with most open-source baselines using FP16 or BF16. This design affords flexible numerical representation but incurs substantial costs in energy, memory bandwidth, and latency due to the dominance of floating-point addition and multiplication in matrix multiplications. Recent work on 1-bit model architectures, notably BitNet, has shown that much of the cost associated with floating-point operations can be eliminated by moving to integer arithmetic. Building on this direction, BitNet b1.58 proposes a ternary parameterization for weights, where each parameter takes a value from the set $\{-1, 0, 1\}$. Despite the extreme reduction in precision to 1.58 bits in the binary system, BitNet b1.58 matches full-precision Transformer LLMs in perplexity and end-task performance once models reach a sufficient scale, while being markedly more cost-effective in latency, memory usage, throughput, and energy consumption.

The architecture adopts LLaMA-alike components such as RMSNorm, SwiGLU, rotary embeddings, and the removal of biases, making it straightforward to integrate into widely used open-source ecosystems. Crucially, BitNet b1.58 introduces a training recipe that is compatible with its ternary weights and 8-bit activations, yielding both computational and system-level benefits. Among the most consequential choices in the design is how activations are quantized and scaled, as this directly impacts the complexity of quantization, the efficiency of the arithmetic kernels, and the ease of moving data between memory hierarchies.

# Weight Quantization via Absmean and Ternary Parameters
BitNet b1.58 constrains all weights to be ternary by a specific quantization function. Given a weight matrix $W \in \mathbb{R}^{n \times m}$, the average absolute value $\gamma$ is computed as
\[
\gamma = \frac{1}{nm} \sum_{ij} |W_{ij}|.
\]
The matrix is then scaled by $\gamma + \epsilon$ and each element is rounded and clipped to the ternary set $\{-1, 0, 1\}$:
\[
\widetilde{W} = \mathrm{RoundClip}\!\left(\frac{W}{\gamma + \epsilon}, -1, 1\right),
\]
\[
\mathrm{RoundClip}(x, a, b) = \max\!\left(a, \min\!\left(b, \mathrm{round}(x)\right)\right).
\]
This procedure yields $\widetilde{W}$ whose entries are exactly $-1$, $0$, or $1$. The inclusion of $0$ not only expands representational capacity beyond strictly binary values but also enables explicit feature filtering, which strengthens modeling capability relative to the original 1-bit BitNet. As importantly, it preserves the computational paradigm dominated by integer addition, allowing matrix multiplications to avoid floating-point multiplications almost entirely and thereby saving orders of energy cost.

# Activation Quantization Ranges and Per-Token Scaling
The quantization of activations is equally central to the system-level performance of BitNet b1.58. While the original BitNet implementation scales activations before nonlinear functions to the range $[0, Q_b]$, BitNet b1.58 adopts a different strategy: it scales activations per token to the symmetric range $[-Q_b, Q_b]$ and does so without introducing zero-point quantization. This choice is motivated by convenience and simplicity in both implementation and system-level optimization, and in experiments it introduces negligible effects on performance.

Concretely, using the symmetric interval $[-Q_b, Q_b]$ means that the representable activation values are centered around zero, and the representation of zero is exact without an additional offset. The per-token scaling ensures that activations for each token are normalized consistently within this symmetric bound, which harmonizes with integer arithmetic kernels and minimizes the need for extra parameters or conversion steps. Because matrix multiplication constitutes the bulk cost of LLM inference, keeping activations in an efficient, symmetric integer form magnifies the downstream benefits of ternary weights by aligning both operands of the core computation with integer addition.

# Zero-Point Quantization: Why Symmetric Scaling Removes It
A pivotal benefit of scaling activations to $[-Q_b, Q_b]$ is that it “gets rid of the zero-point quantization.” If activations were instead scaled to the asymmetric interval $[0, Q_b]$, the extra quantization complication that would reappear is zero-point quantization. In the context of BitNet b1.58, this complication arises because the range $[0, Q_b]$ is not centered at zero. When the activation dynamic range is asymmetric and does not include negative values symmetrically, representing the value $0$ requires a nonzero offset, often referred to as a zero point. Managing this offset adds complexity to the quantization pipeline, the arithmetic used in matrix multiplications, and the data movement between memory hierarchies.

By choosing $[-Q_b, Q_b]$, BitNet b1.58 avoids introducing such an offset, allowing activations to map directly to integer representations centered at zero. This eliminates auxiliary handling associated with zero-point parameters and any additional corrections in computation. As a result, the implementation is simpler and more convenient, and the system-level optimization path is cleaner. The paper explicitly notes that this change to symmetric scaling is more convenient and simple for both implementation and system optimization, while the performance impact in experiments is negligible. Thus, the symmetric range does not sacrifice accuracy but meaningfully reduces quantization overhead.

# Implementation Simplicity and System-Level Optimization
The broader significance of removing zero-point quantization in BitNet b1.58 is practical. Inference in LLMs is constrained not only by arithmetic throughput but also by memory bandwidth and latency in moving parameters and activations from DRAM to on-chip memory like SRAM. The reduced memory footprint that follows from 1.58-bit weights and 8-bit activations already lowers the bandwidth and capacity demands. When activations are symmetrically scaled to $[-Q_b, Q_b]$ and avoid zero-point quantization, the implementation burden on kernels is decreased. Integer additions can be executed without additional offset adjustments, which streamlines code paths and can help compilers and runtime systems perform optimizations more effectively.

This simplification complements the computational paradigm in BitNet b1.58, where matrix multiplication involves mostly integer addition. Since the fundamental limit to compute performance in many chips is power, eliminating extraneous quantization steps and offsets further enhances the energy efficiency gains already achieved by avoiding floating-point multiplications. Additionally, symmetric scaling aids in consistent per-token handling of activations, which fits well with the dataflow and buffering strategies used in optimized inference frameworks, and reduces the time spent converting representations at boundaries between components.

# Empirical Observations: Negligible Performance Effects and Overall Cost Advantages
The paper reports that adopting symmetric scaling to $[-Q_b, Q_b]$ per token introduces negligible effects on performance in experiments. In practice, BitNet b1.58 matches the full-precision LLaMA baseline starting from the 3B model size in terms of perplexity and zero-shot end-task accuracy, while offering significant reductions in latency and memory consumption. For example, at 3B parameters, BitNet b1.58 is 2.71 times faster and uses 3.55 times less GPU memory than FP16 LLaMA, and a 3.9B BitNet b1.58 is 2.4 times faster with 3.32 times less memory while performing better than the 3B full-precision baseline.

These findings extend across scales. The speed-up increases with model size, reaching 4.1 times faster at 70B, largely because the cost of the linear layers grows with scale, and BitNet b1.58’s integer-addition-dominated compute becomes even more advantageous. Memory consumption trends similarly, as embeddings remain full precision but constitute a smaller fraction of the total for larger models. Energy estimates focusing on matrix multiplications show that BitNet b1.58 saves 71.4 times arithmetic operations energy consumption relative to the FP16 baseline on 7nm chips, and end-to-end energy cost becomes increasingly favorable as model size scales. Throughput also improves significantly; at 70B parameters, BitNet b1.58 supports up to 11 times the batch size and yields an 8.9 times higher throughput compared to FP16 LLaMA under the tested conditions.

# Broader Implications of Symmetric Activation Quantization
Avoiding zero-point quantization by using symmetric activation scaling aligns with several broader goals outlined in the paper. First, it helps enable a new scaling law with respect to model performance and inference cost, under which larger BitNet b1.58 models can be more efficient than much smaller full-precision models in latency, memory usage, and energy consumption. Second, it contributes to native support for longer sequences, since activations are already reduced from 16 bits to 8 bits, effectively doubling context length given the same resources, with the possibility of further lossless compression in 1.58-bit LLMs left for future work. Third, it aids deployment on edge and mobile devices by simplifying kernels and reducing energy and memory load, increasing compatibility with CPU-dominated environments and expanding the range of practical applications.

Finally, the simplification underscores the potential for new hardware and systems optimized for 1-bit LLMs. With the computation dominated by integer addition and quantization made simpler by symmetric activation scaling, the path is clearer for architectures and accelerators tailored to these workloads. In sum, the choice to scale activations to $[-Q_b, Q_b]$ is a small design decision with outsized effect: it removes the need for zero-point quantization, reduces implementation and optimization complexity, and integrates seamlessly with the efficiency gains achieved by ternary weights and integer arithmetic, all while maintaining strong empirical performance.
