According to the paper 'The Era of 1-bit LLMs: All Large Language Models are in $1.58$ Bits', if embeddings were quantized to the same $1.58$-bit scheme instead of remaining full precision (e.g., $\text{FP16}$), BitNet's memory advantage over $\text{FP16}$ LLaMA would most likely increase. This follows because the paper explicitly notes that embeddings remain full precision and that memory and bandwidth are dominant costs that 1.58-bit weights substantially reduce, with the observed memory gap already growing with model size as the embedding’s share diminishes; mathematically, if $N_{\text{emb}}$ and $N_{\text{other}}$ are the embedding and non-embedding parameter counts, then the FP16 baseline requires memory proportional to $16\,(N_{\text{emb}}+N_{\text{other}})$ (in bits), whereas the current BitNet uses $16\,N_{\text{emb}}+1.58\,N_{\text{other}}$, yielding an advantage factor $\frac{16\,(N_{\text{emb}}+N_{\text{other}})}{16\,N_{\text{emb}}+1.58\,N_{\text{other}}}$; if embeddings were also quantized to $1.58$ bits, BitNet’s memory would become $1.58\,(N_{\text{emb}}+N_{\text{other}})$ and the advantage factor increases to $\frac{16}{1.58}$, which is strictly larger because $N_{\text{emb}}>0$, thereby further reducing both DRAM capacity and bandwidth needs and amplifying the already observed memory and latency benefits.
