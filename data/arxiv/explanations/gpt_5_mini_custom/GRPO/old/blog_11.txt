## Libraries You Need: math and sympy

- `math`: Great for basic arithmetic, factorials, powers, trigonometry, logarithms, and more. Its functions are fast and reliable.  
- `sympy`: A symbolic mathematics library. It can solve equations exactly, manipulate expressions, and integrate or differentiate symbolically.

Combining them lets you handle everything from simple grade-school arithmetic to more advanced algebra or calculus problems. For instance, if you need an exact fraction rather than a floating-point approximation, `sympy.Rational` can help.

## Debugging and Iteration

Sometimes the first code draft won’t run cleanly. Here’s how to debug:

- Read the error message. If it’s a missing import, add the appropriate `import` line.  
- If a function name is wrong (e.g., `math.fact` instead of `math.factorial`), correct it and rerun.  
- For symbolic solutions, ensure you call `solution[0]` or iterate over all solutions, depending on the problem.  
- If the model uses an incorrect approach (say, trying to multiply instead of divide), ask it to revise only the mistake. You can prompt:  
  “I got an error or wrong result. Please fix the code to correctly solve the problem.”

By iterating in this manner, you turn a one-shot code snippet into a reliable, working script.

## Tips for Getting Better Answers

• Use temperature close to zero for deterministic code generation.  
• Provide clear, high-quality examples in your prompt.  
• If you need multiple potential solutions, sample several code variants and pick the best after execution (self-consistency).  
• Keep your prompt concise: too many examples can confuse the model.
