# Equations: 2L + 2W = 30 and L = 2W
eqs = [
    Eq(2*L + 2*W, 30),
    Eq(L, 2*W)
]
sol = solve(eqs, (L, W))
length, width = sol[L], sol[W]
area = length * width
print(area)
```
Running this code yields `50`, so the rectangle’s area is 50.
