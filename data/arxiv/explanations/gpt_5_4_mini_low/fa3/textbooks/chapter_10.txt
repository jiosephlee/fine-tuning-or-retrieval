\title{A Textbook about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

Chapter 10: 10. Making FP8 Accurate: Block Quantization and Incoherent Processing

# Numerical limitations of FP8 $e4m3$

The paper’s FP8 attention method is built around the $e4m3$ format, and its starting point is a simple fact: FP8 is much less numerically precise than FP16 or BF16. In the paper’s discussion, this lower precision comes from the limited number of bits available to represent numbers, with only $3$ bits for the mantissa and $4$ bits for the exponent. Because of this restricted representation, FP8 introduces larger quantization error than the higher-precision formats that are more commonly used in attention kernels.

This matters especially in attention, where the computation is not just one matrix multiplication but a sequence of operations that depends on intermediate values being accurate enough to preserve the final distribution produced by softmax. The paper emphasizes that moving from FP16 to FP8 is not just a matter of using the same algorithm at lower precision. The lower-precision format changes the numerical behavior of the computation, so the algorithm must be adapted to keep the error under control.

# Why outlier activations are problematic in large language models

A major difficulty identified in the paper is the presence of outlier values in large models. These are entries whose magnitude is much larger than the typical values in the same tensor. The paper notes that large language models often contain such outliers, and that these outlier features make quantization difficult. The reason is intuitive: if most values are moderate but a few are very large, then a quantization scheme must choose a scale that can represent the large values without overflow or severe distortion. That choice often reduces the effective resolution available for the many ordinary values.

In attention, these outliers are especially problematic because the query, key, and value matrices all participate in a computation that is sensitive to how their entries are represented. If a few unusually large activations dominate the scale, then the rest of the tensor may be represented too coarsely. The paper treats this as a central obstacle to using FP8 directly for attention.

# Baseline per-tensor scaling and its weaknesses

The paper describes the standard baseline approach to FP8 quantization as per-tensor scaling. In this method, one scalar is kept for each tensor, such as one scale for $\mathbf{Q}$, one for $\mathbf{K}$, and one for $\mathbf{V}$. This is a natural first strategy because it is simple and easy to apply: each tensor is quantized using a single global scale.

However, the paper presents this baseline as too coarse for attention with outlier features. A single scale must cover the entire tensor, which means that unusual large values can force the scale to be set conservatively. That reduces precision for the rest of the values, since the quantizer has to preserve the extreme entries too. In the paper’s numerical evaluation, this baseline serves as the comparison point for the more accurate FP8 FlashAttention-3 method.

The paper’s main message here is that per-tensor scaling ignores the structure of attention. Attention is already organized around blocks, and the distribution of values can vary significantly across those blocks. Using one scale for the whole tensor therefore throws away useful locality information that could otherwise improve accuracy.

# Block quantization with one scale per $Q$, $K$, and $V$ block

To address this, the paper introduces block quantization. Instead of using one scalar for an entire tensor, the tensor is split into blocks and each block gets its own scale. For $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$, the paper describes splitting them into blocks of size $B_r \times d$ or $B_c \times d$, depending on the dimension being tiled, and quantizing each block separately.

The intuition is that values within a smaller block are more likely to have a similar scale than values across the whole tensor. By reducing the scope of each scale, block quantization makes the quantizer more adaptive. A large outlier in one block no longer needs to distort the representation of values in another block. This is exactly the kind of locality-aware design that fits the paper’s broader philosophy for FlashAttention-3.

The paper also points out that block quantization can be fused with an operation that happens right before attention, such as rotary embedding, with no additional slowdown. This is important because it means the accuracy improvement does not necessarily come with a separate overhead step. The quantization can be inserted into existing preprocessing work rather than added as a new cost.

# How block quantization aligns naturally with tiled attention

A key reason block quantization works well in FlashAttention-3 is that the attention algorithm itself is already tiled. FlashAttention processes the matrices in blocks rather than materializing the full attention matrix in high precision. The paper exploits this fact directly: because the algorithm naturally operates on blocks, it is easy to attach a separate scale to each block.

This alignment is more than a convenience. It means the same block structure used to improve memory efficiency can also be used to improve numerical fidelity. The paper emphasizes that the algorithm can scale each block of the score matrix $\mathbf{S}$ to account for block quantization “at no computation cost.” In other words, the blockwise organization of the algorithm allows the quantization correction to be absorbed into the existing tiled processing logic.

This is an important design principle in the paper: accuracy improvements are most effective when they are integrated into the same tiled pipeline that already defines the kernel. Rather than treating quantization as an external preprocessing step, FlashAttention-3 makes it part of the attention computation itself.

# Scaling score blocks without extra compute cost

The paper explains that once $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$ are block quantized, the score blocks in attention can be adjusted accordingly. Since attention computes scores through $\mathbf{Q}\mathbf{K}^\top$, the effect of the per-block quantization scales must be reflected in the score computation. The paper states that this can be done without extra computation cost because the algorithm already processes the matrices block by block.

This is an important subtlety. The paper is not merely proposing a more accurate way to store inputs; it is showing how the blockwise structure of the entire attention kernel lets the scale factors be handled naturally inside the computation. This makes the method practical, because accuracy improvements that require major extra work would be far less attractive in a performance-critical kernel.

# Incoherent processing as outlier spreading

Block quantization improves the scale granularity, but the paper also introduces a second technique called incoherent processing. The goal here is to reduce the impact of outliers before quantization happens. The paper’s idea is to multiply $\mathbf{Q}$ and $\mathbf{K}$ by a random orthogonal matrix $\mathbf{M}$ prior to quantization. This does not change the attention output, but it changes how the information is distributed across coordinates.

The paper describes this as “spreading out” the outliers. Instead of a few coordinates carrying very large values, the transformed vectors become sums of many entries, so the magnitude is more evenly distributed across dimensions. This makes quantization easier because the extreme values are less concentrated in specific positions. The result is lower quantization error after FP8 rounding.

The term “incoherent processing” reflects this goal of making the representation less aligned with the original outlier structure. The transform does not remove information; it redistributes it so that the FP8 representation can preserve it more faithfully.

# Orthogonal transforms that preserve $\mathbf{Q}\mathbf{K}^\top$

A crucial property of the incoherent-processing transform is that it preserves the attention scores. The paper uses the fact that $\mathbf{M}$ is orthogonal, so $\mathbf{M}\mathbf{M}^\top = I$. Therefore,
\[
(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{M}\mathbf{M}^\top\mathbf{K}^\top = \mathbf{Q}\mathbf{K}^\top.
\]
This means multiplying both $\mathbf{Q}$ and $\mathbf{K}$ by the same orthogonal matrix changes the intermediate representation but not the final dot products that drive attention.

This identity is the mathematical reason incoherent processing is safe. The paper is careful to preserve the exact attention computation while changing only the coordinate system in which the tensors are represented. That is why the method can improve numerical behavior without altering the model’s output in principle.

# Using random diagonal sign matrices and Hadamard transforms

The paper follows prior work and chooses $\mathbf{M}$ to be a product of random diagonal matrices of $\pm 1$ and a Hadamard matrix. This choice is important because it gives the benefits of a random orthogonal transform while remaining computationally efficient. The paper notes that this form of transform can be multiplied in $O(d \log d)$ time rather than $O(d^2)$ time.

The random diagonal sign matrices introduce randomness in the signs of coordinates, and the Hadamard transform mixes the values across dimensions. Together, they provide a structured way to spread out the outliers. The paper’s emphasis is not merely on randomness for its own sake, but on using a transform that is both orthogonal and fast enough to be practical in a GPU kernel.

This specific construction is also convenient for integration with the rest of the attention pipeline. The paper points out that it can be fused with rotary embedding at no extra computation cost, which helps keep the overall method efficient.

# Fast $O(d \log d)$ incoherent transforms

One reason the paper chooses the random-sign-plus-Hadamard construction is that it is much faster than a dense orthogonal transform. A general orthogonal matrix would be too expensive to apply inside an attention kernel, especially in a setting where performance matters. The Hadamard-based approach keeps the transform lightweight enough to be used alongside FP8 attention.

The paper frames this efficiency as necessary for practical deployment. Incoherent processing is not meant to be a separate expensive preprocessing stage; it is meant to be a low-overhead modification that supports the FP8 pipeline. The $O(d \log d)$ complexity is what makes that possible.

This efficiency also matters because the paper’s broader contribution is about using hardware aggressively. Since FlashAttention-3 already aims to maximize throughput through asynchronous execution and tiling, the accuracy-preserving transform must fit into that same high-performance design philosophy.

# Fusion opportunities with rotary embedding

The paper notes that both block quantization and incoherent processing can be fused with rotary embedding. This is significant because rotary embedding is already a preprocessing step in many attention pipelines. By fusing the FP8-related transforms with it, FlashAttention-3 avoids introducing an extra pass over the data.

The paper repeatedly emphasizes this kind of fusion as a practical advantage. In a memory-bound setting, any additional kernel or additional movement of data can be costly. Fusing the transform with an existing step reduces that overhead and helps the FP8 path remain efficient.

This also reinforces the paper’s overall methodology: numerical accuracy is improved not by adding isolated corrective stages, but by integrating the corrections into the existing structure of the attention computation.

# Why these methods improve FP8 attention accuracy

The paper’s overall argument is that FP8 attention becomes accurate when two sources of error are addressed together. First, block quantization reduces the damage done by using a single scale for a large tensor. By assigning a scale to each block, the method adapts to local variation and keeps outliers from dominating the entire tensor’s representation. Second, incoherent processing reduces the concentration of outliers by redistributing the energy across dimensions before quantization.

These methods are complementary. Block quantization improves the granularity of scaling, while incoherent processing makes the values easier to quantize in the first place. The paper validates their combined effect experimentally and reports that FP8 FlashAttention-3 is up to $2.6\times$ more accurate than a baseline FP8 attention method that uses per-tensor quantization in the presence of outlier features.

The key takeaway is that low precision does not have to imply poor accuracy, but it does require algorithmic support. In FlashAttention-3, the paper uses the structure of tiled attention and the mathematical invariance of orthogonal transforms to make FP8 practical for attention while preserving much better numerical behavior than a naive baseline.
