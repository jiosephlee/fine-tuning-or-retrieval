\title{A Textbook about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

Chapter 14: 14. Numerical Accuracy Evaluation

# Why numerical error matters for attention kernels

The paper emphasizes that improving attention speed is not the only goal when designing a new kernel. Attention is used inside Transformer models, and if a faster implementation changes the computed values too much, then the speedup may come at the cost of degraded model behavior. This concern becomes especially important in low-precision settings, where arithmetic is intentionally compressed to gain throughput. In \textsc{FlashAttention-3}, the authors therefore treat numerical accuracy as a first-class evaluation criterion alongside performance.

This is particularly relevant because the paper’s main algorithmic advances target Hopper GPUs and include an FP8 implementation. FP8 provides much higher throughput, but it also increases the risk of quantization error. The authors frame their accuracy study as a way to confirm that the performance improvements do not come from sacrificing too much numerical fidelity. In other words, the kernel should still behave like attention, not just like a fast approximation that happens to run on the same inputs.

# Using FP64 attention as a reference

To evaluate accuracy, the paper compares \textsc{FlashAttention-2}, \textsc{FlashAttention-3}, and a standard attention implementation against a reference implementation in FP64. This reference serves as the high-precision baseline from which numerical error is measured. Using FP64 is a standard way to isolate the effect of finite-precision computation: if a method differs from the FP64 result, that difference can be attributed to numerical error introduced by the algorithm and datatype choices.

The paper does not present FP64 as a practical deployment format; rather, it is used as the anchor for the error analysis. By comparing all methods to the same reference, the authors can make a controlled statement about how much precision is lost in each implementation. This is especially useful because the different attention kernels vary not only in precision but also in how intermediate values are stored and rescaled.

# Synthetic outlier distribution used to stress-test quantization

To simulate the kinds of outlier features and activations that appear in large language models, the paper constructs a synthetic distribution for the entries of $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$. Each entry is sampled from

$$
\mathcal{N}(0, 1) + \mathcal{N}(0, 100) \cdot \mathrm{Bernoulli}(0.001).
$$

This means that most entries come from a normal distribution with standard deviation $1$, but with probability $0.001$ an additional independent term with much larger variance is added. The effect is that a tiny fraction of entries become much larger in magnitude than the rest. The paper uses this setup to mimic the “outlier” behavior that makes quantization difficult in real large models.

The reason this is a meaningful stress test is that quantization schemes often work well when values are relatively uniform, but can behave poorly when a few extreme values dominate the dynamic range. By injecting rare large-magnitude values, the authors can measure whether their FP8 method remains stable under conditions that resemble the difficult cases encountered in practice.

# RMSE as the reported accuracy metric

The paper reports root mean squared error, or RMSE, as the main numerical accuracy metric. RMSE compares the computed output from each attention implementation to the FP64 reference and summarizes the average magnitude of the error. A lower RMSE indicates that the output is closer to the high-precision baseline.

This choice is appropriate for the paper’s goal because it provides a direct scalar summary of output deviation. Rather than focusing on a single element or a qualitative comparison, RMSE measures the overall discrepancy across the full attention output. The paper uses this metric in its table of numerical error results to compare standard attention, \textsc{FlashAttention-2}, and \textsc{FlashAttention-3} under both FP16 and FP8 settings.

# Why FlashAttention-2 and FlashAttention-3 improve FP16 accuracy over standard attention

In FP16, the paper reports that both \textsc{FlashAttention-2} and \textsc{FlashAttention-3} achieve $1.7\times$ lower RMSE than the standard attention implementation. The key reason given is that intermediate results, especially in the softmax computation, are kept in FP32. This matters because the softmax is numerically sensitive: rescaling and exponentiation can amplify small errors if the intermediate values are stored in lower precision.

The standard attention implementation materializes intermediate matrices and does not benefit from the same fused structure. In contrast, the FlashAttention family performs the attention computation in a fused way that preserves higher-precision intermediate values where they matter most. As a result, the paper concludes that FlashAttention’s design is not only faster but also more numerically stable in FP16 than the standard baseline.

The important point is that this accuracy gain is not attributed to the new Hopper-specific asynchrony in \textsc{FlashAttention-3}. Instead, the paper states that \textsc{FlashAttention-3} matches the FP16 numerical error of \textsc{FlashAttention-2}. The accuracy improvement comes from the FlashAttention approach itself, especially from the way it handles intermediate computations.

# Role of FP32 intermediates in stable softmax computation

A central reason for the strong FP16 accuracy results is that intermediate softmax-related computations are kept in FP32. The paper specifically points to the softmax rescaling steps as examples of quantities that remain in higher precision. This matters because softmax involves exponentials and normalization, both of which can be sensitive to rounding and underflow or overflow if handled too aggressively in low precision.

In the paper’s framing, maintaining FP32 intermediates allows the kernel to compute the local softmax more stably while still using FP16 inputs and outputs. This is one reason that both FlashAttention methods outperform the standard attention implementation in numerical error. The authors present this as a design advantage of the FlashAttention family: it reduces memory traffic while also improving the stability of the core attention computation.

# FP8 baseline with per-tensor scaling

For FP8, the paper compares \textsc{FlashAttention-3} against a baseline attention implementation that uses per-tensor scaling. In that baseline, a single scaling factor is used for each tensor, such as one for $\mathbf{Q}$, one for $\mathbf{K}$, and one for $\mathbf{V}$. The paper notes that this is the standard way to manage FP8 quantization, but it can be vulnerable when the tensor contains outlier values.

The baseline also keeps the matmul accumulator in FP32 and the intermediate softmax results in FP16. Even with these protections, the paper reports that the baseline is less accurate than \textsc{FlashAttention-3} in the presence of outliers. This shows that the main challenge in FP8 is not simply having a high-precision accumulator; it is also the quality of the quantization strategy used for the inputs.

# Accuracy gains from block quantization and incoherent processing

To reduce FP8 error, the paper introduces two techniques: block quantization and incoherent processing. Block quantization replaces a single scale per tensor with one scale per block. Instead of quantizing all of $\mathbf{Q}$, $\mathbf{K}$, or $\mathbf{V}$ using one global scale, the tensor is split into blocks of size $B_r \times d$ or $B_c \times d$, and each block is quantized separately. The authors note that this fits naturally with the block structure of \textsc{FlashAttention-3}, so the required scaling can be incorporated without additional computation cost.

The second technique, incoherent processing, multiplies $\mathbf{Q}$ and $\mathbf{K}$ by a random orthogonal matrix $\mathbf{M}$ before quantization. Because $\mathbf{M}$ is orthogonal, multiplying both sides by $\mathbf{M}$ does not change the attention scores:

$$
(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{K}^\top.
$$

The purpose of this transformation is to “spread out” outliers so that no single coordinate dominates the quantization error. The paper follows prior work in choosing $\mathbf{M}$ as a product of random diagonal sign matrices and a Hadamard matrix, which can be applied efficiently. These two techniques together make FP8 quantization much more robust in the presence of large-magnitude entries.

# The reported 2.6x reduction in FP8 numerical error

The paper’s main numerical accuracy claim for FP8 is that \textsc{FlashAttention-3} is $2.6\times$ more accurate than the baseline FP8 attention with per-tensor quantization. This improvement is reported in the RMSE results and is attributed specifically to block quantization and incoherent processing. The synthetic outlier experiment is designed to make this comparison meaningful, since the outlier-heavy input distribution is exactly where quantization methods differ most.

This result is important because it shows that FP8 does not have to be synonymous with poor accuracy. The paper does not claim that FP8 matches FP16 in error, but it does show that careful algorithmic design can significantly narrow the gap relative to a straightforward per-tensor quantization baseline.

# Practical implications for low-precision deployment

The accuracy results support the paper’s broader claim that low-precision attention can be practical if it is designed with the right numerical safeguards. In FP16, the FlashAttention family already improves accuracy over standard attention by keeping key intermediate values in FP32. In FP8, the more aggressive quantization would normally increase error, but the use of block quantization and incoherent processing substantially reduces that penalty.

For deployment, this means that low-precision attention is not merely a speed optimization. According to the paper, it can be made accurate enough to be a realistic option, especially when paired with techniques that address outlier-heavy data. The overall message of the accuracy study is that performance and numerical fidelity need not be in opposition: with the right kernel design, the same attention implementation can be both fast and stable.
