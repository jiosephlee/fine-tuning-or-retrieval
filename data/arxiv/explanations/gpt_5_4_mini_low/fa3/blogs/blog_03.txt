\title{Blogs about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

# FP8 Without the Accuracy Nightmare: How FlashAttention-3 Makes Low-Precision Work

FP8 is attractive for the same reason every low-precision format is attractive: it can make attention faster and more efficient. On Hopper GPUs, FlashAttention-3 shows that this is not just a theoretical benefit. By targeting FP8 Tensor Cores, it reaches close to 1.2 PFLOPs/s.

But there is a catch. Lower precision usually means higher numerical error, and attention is especially sensitive to that. Large language models often contain outlier values, which are much larger than the rest of the activations. Those outliers make naive quantization harder, because a single large value can force the scale to stretch too far and reduce effective precision for everything else.

FlashAttention-3 addresses that problem with two ideas: block quantization and incoherent processing. Together, they make FP8 attention substantially more accurate than a baseline FP8 approach, while still preserving the performance gains of low precision.

## Why FP8 is appealing

The hardware motivation is straightforward. Hopper GPUs have FP8 Tensor Cores, and those Tensor Cores can deliver roughly 2x the throughput of FP16 or BF16. For attention, that matters a lot, because attention is already a major bottleneck in transformer models.

FlashAttention-3 uses that hardware to push attention much further than previous versions. In the paper’s measurements, FP8 FlashAttention-3 gets close to 1.2 PFLOPs/s on H100. That is an enormous amount of throughput for a kernel that sits in the inner loop of transformer workloads.

The problem is that speed is only useful if the results are still reliable.

## Why low precision is risky for attention

FP8 uses only 8 bits, with just 3 bits for the mantissa and 4 bits for the exponent in the e4m3 format used here. That gives much less representational range and precision than FP16 or BF16.

In attention, this is not a minor detail. The computation depends on dot products, softmax, and repeated rescaling across blocks. Small numerical errors can accumulate. And if the model has outlier features, the issue gets worse.

The paper points out that large models often have outliers in $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$. Those rare but large values can dominate tensor ranges and make per-tensor scaling too coarse. If one scale is shared across an entire tensor, a few extreme entries can reduce precision everywhere else.

That is why baseline FP8 attention can be fragile.

## Block quantization: scale smaller pieces, not the whole tensor

FlashAttention-3 reduces quantization error by moving from per-tensor scaling to block quantization.

Instead of using one scale for all of $\mathbf{Q}$, $\mathbf{K}$, or $\mathbf{V}$, the tensor is split into smaller blocks, and each block gets its own scale. In the paper, those blocks are sized to match the algorithm’s tile structure, such as $B_r \times d$ or $B_c \times d$ blocks.

This helps because each block is more locally homogeneous. A few outliers in one region no longer force the entire tensor to use the same conservative scale. The result is better use of FP8’s limited dynamic range.

Another advantage is that FlashAttention-3 already operates on blocks internally, so the quantization fits naturally into the algorithm. The paper also notes that block quantization can be fused with a preceding operation such as rotary embedding, so it does not add extra slowdown.

## Incoherent processing: spread out the outliers

Block quantization helps, but it does not completely solve the outlier problem. FlashAttention-3 adds a second technique called incoherent processing.

The idea is to multiply both $\mathbf{Q}$ and $\mathbf{K}$ by the same random orthogonal matrix $\mathbf{M}$ before quantization. Since $\mathbf{M}\mathbf{M}^\top = I$, this transformation does not change the attention scores:

$$
(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{K}^\top.
$$

So the math stays the same, but the distribution of values changes. The transformation mixes the entries, which tends to “spread out” outliers instead of letting them remain concentrated in a few coordinates. That makes quantization easier and reduces error.

In practice, the paper follows prior work and uses $\mathbf{M}$ as a product of random diagonal $\pm 1$ matrices and a Hadamard matrix. This keeps the transformation efficient, since it can be applied in $O(d \log d)$ time rather than $O(d^2)$.

The key point is that this is not an approximation to attention. It is a reparameterization that preserves the exact attention output in real arithmetic, while making the low-precision path behave better.

## Why the implementation details matter

FP8 is not just a matter of changing the datatype. The paper also explains that Hopper’s FP8 WGMMA instructions have stricter layout requirements than FP16.

In particular, FP8 WGMMA expects certain operands to be laid out in k-major format. That creates a problem for attention, where the usual tensor layouts are not always compatible with the desired compute path. FlashAttention-3 solves this with an in-kernel transpose using LDSM and STSM instructions, so the data can be rearranged without costly extra passes over memory.

There is also a layout mismatch between the FP32 accumulator produced by one WGMMA and the operand layout expected by the next one. The implementation uses byte permutation instructions to bridge that gap. These are the kinds of low-level details that determine whether FP8 is practical in a real fused attention kernel.

## What the paper shows experimentally

The paper evaluates FP8 FlashAttention-3 on an H100 SXM5 GPU. The headline result is that FP8 reaches close to 1.2 PFLOPs/s.

On the accuracy side, the paper compares FP8 FlashAttention-3 against a baseline FP8 attention method that uses per-tensor scaling. To make the test realistic, it simulates outlier-like values using a mixture distribution with rare large-magnitude entries.

Under those conditions, block quantization plus incoherent processing reduces numerical error by 2.6x compared to the baseline FP8 approach.

That is the important takeaway: FlashAttention-3 does not trade accuracy away blindly in exchange for speed. It shows that with the right algorithmic and hardware-aware choices, FP8 attention can be both fast and noticeably more stable.

## The bigger lesson

FlashAttention-3 is a good example of how low precision should be approached in modern accelerators. The answer is not “use fewer bits and hope for the best.” The answer is to redesign the algorithm around the hardware and around the numerical structure of the problem.

For FP8 attention, that means:

- exploiting the GPU’s FP8 Tensor Cores,
- limiting the damage from outliers with block quantization,
- smoothing the value distribution with incoherent processing,
- and integrating all of this into a fused attention kernel rather than a slow, memory-heavy implementation.

The result is a kernel that is both faster and more accurate than a naive FP8 baseline. That combination is exactly what makes FP8 practical instead of risky.

FlashAttention-3 is not just showing that FP8 can be fast. It is showing how FP8 can be made usable for attention without turning numerical stability into an afterthought.
