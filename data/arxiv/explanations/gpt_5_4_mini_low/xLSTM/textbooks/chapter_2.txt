\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 2: 2. Foundations: The Original LSTM Revisited

# Recurrent neural networks and the vanishing gradient problem

Long Short-Term Memory, or LSTM, was introduced as a way to address a central difficulty in recurrent neural networks: the vanishing gradient problem. In an ordinary recurrent network, information is passed from one time step to the next through repeated nonlinear transformations. While this gives the model a notion of state or memory, it also makes learning long-range dependencies difficult, because gradients propagated backward through many steps can shrink and become ineffective. The paper frames LSTM as a direct response to this problem.

The key idea is that a recurrent model should have a mechanism for storing information over time without repeatedly transforming it in a way that destroys the gradient signal. LSTM accomplishes this by introducing a memory cell and gating mechanisms that regulate how information enters, remains in, and leaves the memory. In the paper’s notation, the central conceptual update is expressed as
\[
c_t = f_t c_{t-1} + i_t z_t, \quad h_t = o_t \psi(c_t).
\]
This formulation already shows the basic departure from a plain recurrent update: instead of overwriting memory entirely at each time step, the cell state $c_t$ combines a previous memory state with a new candidate update.

# The constant error carousel as the key LSTM innovation

The paper describes the “constant error carousel” as the central LSTM innovation. The intuition is that the cell state provides a path along which information, and therefore gradient signal, can persist over time. Rather than forcing all information to pass through repeatedly squashed nonlinear transitions, LSTM uses an additive update to the cell state. This additive structure is crucial, because it allows the network to preserve relevant information more directly.

In the paper’s explanation, the previous cell state $c_{t-1}$ is updated by adding a candidate input $z_t$, with the contribution of each term controlled by gates. The forget gate $f_t$ decides how much of the previous cell state is retained, while the input gate $i_t$ controls how much new information is written. This update is what the paper refers to when describing the constant error carousel. The important point is not just that information can be stored, but that storage is mediated in a way that supports stable learning over long sequences.

# Standard LSTM update equations for cell state and hidden state

The paper gives the standard LSTM update equations in a fully explicit form. At time step $t$, the cell state is computed as
\[
c_t = f_t c_{t-1} + i_t z_t.
\]
This is the memory update. It says that the new cell state is a combination of the old memory and a new candidate input. The hidden state is then defined by
\[
h_t = o_t \tilde{h}_t, \quad \tilde{h}_t = \psi(c_t),
\]
where $\psi$ is a squashing or normalization function, typically $\tanh$. Thus the hidden state is not the memory itself, but a gated view of it.

The paper also writes out how each gate and the cell input are computed from the current input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. The cell input is
\[
z_t = \varphi(\tilde{z}_t), \quad \tilde{z}_t = \mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z,
\]
and similarly for the gates,
\[
i_t = \sigma(\tilde{i}_t), \quad \tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i h_{t-1} + b_i,
\]
\[
f_t = \sigma(\tilde{f}_t), \quad \tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f h_{t-1} + b_f,
\]
\[
o_t = \sigma(\tilde{o}_t), \quad \tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o h_{t-1} + b_o.
\]
This makes clear that the standard LSTM is not just a memory buffer. It is a learned dynamical system that uses both the current input and its own previous output to decide how to update itself.

# Input, forget, and output gates: meanings and functions

Each gate in the LSTM has a distinct role, and the paper emphasizes that all of them are important. The input gate $i_t$ controls how much of the new candidate value $z_t$ is written into memory. If $i_t$ is close to $0$, the model mostly ignores the new input; if it is close to $1$, the candidate is allowed to influence the memory strongly. The forget gate $f_t$ controls retention of the previous cell state. If $f_t$ is near $1$, past memory is preserved; if it is near $0$, the previous state is largely discarded. The output gate $o_t$ controls how much of the cell state is exposed as the hidden state.

This division of labor is important because it lets the model make separate decisions about writing, keeping, and reading memory. The paper stresses that the gates are sigmoid-valued, so each gate produces a number between $0$ and $1$. That choice makes the gates interpretable as soft switches or soft masks. In the original LSTM, the gates are driven by the current input and the previous hidden state, so each decision can depend on both what the model sees now and what it has already accumulated.

# Cell input activation and hidden-state squashing

The paper distinguishes between the activation used for the cell input and the activation used to normalize or squash the cell state. The candidate cell input $z_t$ is produced through a function $\varphi$, typically $\tanh$, applied to a linear combination of input and recurrent terms. This keeps the candidate update in a bounded range. Then the memory state $c_t$ is passed through another squashing function $\psi$, again typically $\tanh$, before it is exposed through the hidden state.

This design serves two purposes in the original LSTM. First, it allows the cell state itself to remain a flexible internal storage variable. Second, it prevents the output from becoming unbounded, since the memory can accumulate over time. The paper explicitly notes that $\psi$ is used to normalize or squash the cell state, which would otherwise be unbounded. So the hidden state is not simply the cell state itself, but a controlled, output-gated transformation of it.

# Scalar memory cells versus vectorized modern LSTM formulations

In the original formulation, the paper presents a scalar memory cell, with $c_t \in \mathbb{R}$ for a single cell. Later formulations generalize this to multiple scalar memory cells collected into a vector $\mathbf{c}_t \in \mathbb{R}^d$. This vectorized version allows the use of recurrent weight matrices rather than just scalars, which enables the outputs of different memory cells to be mixed through learned recurrent connections.

The paper notes that this later, more general formulation permits the use of recurrent weight matrices $\mathbf{R} \in \mathbb{R}^{d \times d}$ to mix cell outputs. This is an important step in moving from a single memory unit to a system of interacting memory units. In the xLSTM paper, this vectorized view matters because it sets up the distinction between scalar-memory designs and the later matrix-memory design. But the baseline LSTM idea remains the same: a memory state is updated over time through gated additive dynamics.

# Memory mixing through recurrent hidden-to-hidden connections

A key feature of the standard LSTM formulation in the paper is that the gates and cell input depend not only on the current input $\mathbf{x}_t$ but also on the previous hidden state $h_{t-1}$. These hidden-to-hidden connections mean that the model does not treat each time step independently. Instead, the current computation is conditioned on the network’s previous output.

The paper refers to this as memory mixing when multiple memory cells are used and their outputs are combined through recurrent weight matrices. This mixing is a way of letting different memory components influence one another. It can improve expressiveness, since the model is not restricted to isolated memory slots. At the same time, this dependence on the previous hidden state is exactly what makes processing sequential: the update at time $t$ cannot be computed until the state from time $t-1$ is available.

# Why classic LSTMs remained effective for many tasks

Despite later developments in Transformers, the paper emphasizes that LSTMs remained successful across many domains for a long time. They were used in text generation, handwriting generation, sequence-to-sequence translation, program evaluation, image captioning, source code generation, rainfall-runoff modeling, and hydrological forecasting. They also played a major role in reinforcement learning systems such as AlphaStar and OpenAI Five.

The reason for this durability, according to the paper, is that LSTMs are good at learning abstractions and storing semantic information in their memory cells. The paper points to observations such as number and syntax neurons, linguistic neurons, and sentiment neurons as evidence that LSTMs can form meaningful internal representations. In other words, the model is not merely memorizing sequences mechanically; it can distill information into its memory in ways that capture structure relevant to the task. This ability helped LSTMs remain strong and useful even as other sequence models appeared.

# Limitations of standard LSTMs that motivate xLSTM

The paper identifies three main limitations of standard LSTMs, and these limitations motivate the xLSTM extension. First, standard LSTMs have difficulty revising storage decisions. Once a value is stored, it can be hard for the model to update or replace it when later evidence suggests a better choice. The paper illustrates this with nearest neighbor search, where the model must scan a sequence and keep track of the most similar item. A standard LSTM struggles to revise a previously stored value when a more similar vector appears later.

Second, the paper argues that standard LSTMs have limited storage capacity because information must be compressed into scalar cell states. This becomes visible in rare token prediction, where performance degrades on infrequent tokens. The model simply has less room to preserve detailed information. Third, standard LSTMs are not well parallelizable because memory mixing introduces hidden-to-hidden dependencies across time. Since each step depends on the last, sequential processing is required.

These limitations are exactly what xLSTM is designed to address. The paper’s broader argument is that by revisiting the original LSTM ideas and modifying gating and memory structure, one can overcome these bottlenecks while keeping the strengths that made LSTMs effective in the first place.
