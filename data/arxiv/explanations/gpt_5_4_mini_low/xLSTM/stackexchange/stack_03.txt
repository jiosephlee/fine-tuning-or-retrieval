\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How can the stabilization with $m_t$ leave both the forward outputs and the gradients unchanged?
Question:
For sLSTM and mLSTM, the paper introduces a stabilizer state

$ m_t = \max(\log(f_t) + m_{t-1}, \log(i_t)) $

and then defines stabilized gates

$ i'_t = \exp(\tilde{i}_t - m_t), \quad f'_t = \exp(\log(f_t) + m_{t-1} - m_t). $

The paper claims that replacing $i_t, f_t$ by $i'_t, f'_t$ in the forward pass does not change the network output or the derivatives with respect to parameters. I can believe this is some kind of rescaling trick, but I do not see how the hidden state remains exactly the same rather than only approximately the same numerically.

Could someone show the algebra for why the transformed recurrence is equivalent to the original one? I am especially confused because $m_t$ depends on a non-smooth $\max$, so I would have expected gradient differences.
Answer:
The key point is that the paper is not changing the model, only changing the *representation* of the same recurrence.

For the sLSTM, the unstabilized states are
$$
c_t = f_t c_{t-1} + i_t z_t, \qquad n_t = f_t n_{t-1} + i_t,
$$
and the output is
$$
h_t = o_t \frac{c_t}{n_t}.
$$

Now introduce a time-dependent scaling factor $e^{-m_t}$ and define the rescaled states
$$
\bar c_t := e^{-m_t} c_t, \qquad \bar n_t := e^{-m_t} n_t.
$$
This is just a change of variables. If you multiply both numerator and denominator of the hidden state by the same factor, nothing changes:
$$
h_t = o_t \frac{c_t}{n_t} = o_t \frac{e^{-m_t} c_t}{e^{-m_t} n_t} = o_t \frac{\bar c_t}{\bar n_t}.
$$
So as long as the recurrence for $\bar c_t$ and $\bar n_t$ is algebraically equivalent to the original one, the network output is exactly the same.

That is what the stabilized gates do. Using
$$
m_t = \max\bigl(\log(f_t)+m_{t-1},\, \log(i_t)\bigr),
$$
we get
$$
f'_t = \exp(\log(f_t)+m_{t-1}-m_t), \qquad i'_t = \exp(\log(i_t)-m_t).
$$
Then
$$
\bar c_t
= e^{-m_t}(f_t c_{t-1} + i_t z_t)
= e^{\log(f_t)+m_{t-1}-m_t}\,\bar c_{t-1} + e^{\log(i_t)-m_t} z_t
= f'_t \bar c_{t-1} + i'_t z_t,
$$
and similarly
$$
\bar n_t = f'_t \bar n_{t-1} + i'_t.
$$
So the stabilized recurrence is exactly the original recurrence written in scaled coordinates. The role of $m_t$ is simply to keep the numbers near order $1$, avoiding overflow/underflow when $i_t$ and $f_t$ are exponential gates.

The gradient statement is the same story. Since the stabilized system computes exactly the same function of the parameters as the unstabilized one, the derivatives of the loss with respect to the parameters are the same wherever the function is differentiable. The fact that $m_t$ uses a $\max$ does not change that; it only means the representation is piecewise-defined. At points where the two branches of the max tie, the derivative is not unique, but that is a measure-zero situation and the same issue exists in the original piecewise formulation. In practice, autodiff follows one branch consistently.

So the intuition is: $m_t$ is not an extra modeling choice, it is a numerically stable renormalization of the hidden state and normalizer. Because the same scale factor is applied to both, the ratio $c_t/n_t$ is unchanged, and therefore the forward output is unchanged exactly, not approximately.
