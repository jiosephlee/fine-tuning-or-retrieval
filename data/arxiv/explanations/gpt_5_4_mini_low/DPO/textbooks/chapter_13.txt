\title{A Textbook about the Paper: "Direct Preference Optimization: Your Language Model is Secretly a Reward Model"}

Chapter 13: 13. Results on Summarization and Dialogue

# Summarization Setup with Reddit TL;DR and Human Preferences

The summarization experiment in the paper is designed to test DPO on a realistic preference-learning task where the model must produce a concise, useful summary of a longer input. The input $x$ is a forum post from Reddit, and the target output $y$ is a summary of the main points in that post. The authors use the Reddit TL;DR summarization dataset, along with human preference data gathered by prior work. In other words, rather than asking annotators to write the ideal summary from scratch, the dataset contains comparisons between two candidate summaries, and humans indicate which one is better.

This setup is important because it matches the paper’s central premise: in many practical settings, relative judgments are easier to obtain than full demonstrations. The summarization task therefore serves as a strong test of whether DPO can learn directly from preference data in a setting where the true reward function is unknown. The paper uses an SFT model fine-tuned on human-written forum post summaries as the starting point for this task. That SFT model provides the reference policy used by both PPO and DPO during preference optimization.

The paper emphasizes that this is not a toy task. Summarization is one of the canonical domains where RLHF has been shown to help, and where automatic metrics like ROUGE can fail to capture what humans actually prefer. This makes the TL;DR setup especially suitable for testing whether DPO can improve the practical quality of generations under human judgments.

# Dialogue Setup with Anthropic HH and Preferred/Dispreferred Responses

The dialogue experiment evaluates DPO on single-turn conversation. Here the input $x$ is a human query, and the model must generate a response $y$ that is helpful and engaging. The paper uses the Anthropic Helpful and Harmless dialogue dataset, which contains a large set of human-assistant interactions. Each transcript ends with a pair of responses from a language model, together with a human preference label indicating which response was preferred.

This task differs from summarization in an important way: there is no standard supervised fine-tuned reference model already provided for the experiment. Instead, the paper constructs a starting point by fine-tuning an off-the-shelf language model on only the preferred completions. That approach gives the method a reference policy that is within the same general distribution as the preference data. The paper later uses this setup to test whether DPO can improve over a model already biased toward preferred answers.

The dialogue task is especially useful for evaluating DPO because the responses are open-ended and subjective, so a win-rate style evaluation is more meaningful than a task-specific automatic metric. The paper treats this as a direct test of whether DPO can scale beyond controlled or synthetic preference settings to genuine conversational alignment.

# Using Preferred-FT to Build a Reference Model When No SFT Model Exists

In the DPO framework, the reference policy $\pi_\text{ref}$ is a crucial part of the objective. In the ideal case, the reference is the SFT model used to generate the preference dataset. However, the paper also addresses the practical situation in which no such SFT model is available. This is the case for the dialogue experiment.

To handle that situation, the paper introduces Preferred-FT. This is a simple supervised model trained only on the chosen completions $y_w$ from the preference dataset. In effect, it learns from the preferred answers alone, without explicitly using the dispreferred ones. The resulting model is then used as the reference policy for DPO. The authors describe this as a way to make the reference model more in-distribution with respect to the preference data, thereby reducing the mismatch between the true data-generating reference process and the model used inside DPO.

This step matters because DPO relies on the ratio between the learned policy and the reference policy. If the reference policy is too far from the preference data distribution, the optimization problem becomes less well matched to the data. Preferred-FT is therefore a practical workaround that lets DPO be applied even when a pretrained SFT reference is unavailable.

# DPO Versus PPO on TL;DR Summarization

The paper compares DPO directly against PPO on the TL;DR summarization task. Both methods are evaluated on the test split by sampling completions and measuring win rates against reference summaries. The key result is that DPO achieves stronger performance than PPO in this setting. In particular, DPO reaches an average win rate of approximately $61\%$ at temperature $0.0$, while PPO reaches about $57\%$ at its best sampling temperature, also $0.0$.

This comparison is especially meaningful because both methods are optimizing the same underlying kind of preference signal. PPO is the standard RLHF baseline, but DPO obtains better results while avoiding the complexity of reinforcement learning. The paper presents this as evidence that the direct objective is not merely simpler, but also more effective in practice.

Another important detail is that the authors do not claim to have exhaustively tuned DPO. They note that the reported results may underestimate DPO’s potential because the $\beta$ hyperparameter was not meaningfully tuned. Even with that conservative setup, DPO still outperforms PPO on the summarization task. The implication is that the method is robust enough to work well without extensive task-specific optimization.

# DPO’s Approximate 61% Win Rate and PPO’s Lower Peak Performance

One of the clearest numerical findings in the paper is the approximate $61\%$ win rate achieved by DPO on TL;DR summarization at temperature $0.0$. This is compared to PPO’s peak performance of around $57\%$, also at temperature $0.0$. The paper uses this result to argue that DPO can not only match but surpass a strong RLHF baseline on a real preference dataset.

The win rate metric is important here because the true reward function is unknown. Since the model is generating summaries rather than optimizing a known synthetic score, the evaluation must be based on preference judgments. The paper therefore measures how often a model’s output is preferred over the reference completion. A win rate above $50\%$ indicates improvement over the baseline, and DPO’s margin over PPO shows that the direct optimization approach is effective.

The authors also compare DPO to a Best-of-$N$ baseline. In the summarization setting, DPO achieves a higher maximum win rate than that baseline as well. That means DPO is not just better than PPO; it is also competitive with a computationally expensive method that can select the best among many candidate generations using a learned reward model.

# Robustness of DPO to Sampling Temperature

A notable empirical finding in the paper is that DPO is more robust to sampling temperature than PPO. The experiments evaluate completions at temperatures ranging from $0.0$ to $1.0$, and DPO maintains relatively strong performance across this range. By contrast, PPO’s quality can degrade substantially at higher temperatures, in some cases falling back toward the base model’s performance.

This matters because temperature is a proxy for how sensitive a model is to generation settings. A method that only works well under a narrow set of decoding parameters is less practical than one that remains effective across a broader range. The paper uses this observation to suggest that DPO produces a policy that is not only better on average, but also easier to use in practice.

The authors interpret this as evidence that DPO fine-tuning leads to a policy that generalizes more smoothly over sampling settings. That robustness is especially relevant for open-ended generation tasks, where users often vary decoding parameters depending on whether they want more conservative or more diverse outputs.

# Preferred-FT as a Weaker Baseline Despite Using Preferred Completions

Preferred-FT is intended as a straightforward baseline: train a model by supervised learning only on the preferred completions. Since it directly imitates the selected responses, one might expect it to be strong. However, the paper finds that Preferred-FT does not improve significantly over the SFT model in the summarization setting.

This is an important result because it shows that simply training on chosen outputs is not enough to capture the full structure of the preference data. The preferred completions are informative, but the dispreferred completions also matter. DPO makes use of both sides of each comparison, and this appears to matter for achieving better performance.

The contrast between Preferred-FT and DPO helps clarify what DPO is doing differently. DPO is not just imitation of human-chosen answers. It is a direct optimization method that uses preference comparisons to shift probability mass toward preferred outputs while explicitly accounting for the reference policy. The paper presents this as a more effective way to learn from preference data than one-sided supervised learning.

# Comparison to Best-of-$N$ Under a Learned Reward Model

The paper also compares DPO to a Best-of-$N$ baseline. In this setup, the model samples $N$ candidate responses from the SFT model, scores them using a learned reward model, and returns the highest-scoring one. This approach can perform well because it decouples reward modeling from policy optimization, but it is computationally expensive at inference time.

In the summarization results, DPO achieves a higher maximum win rate than the Best-of-$N$ baseline. This is notable because Best-of-$N$ can exploit multiple samples and a reward model at evaluation time, which makes it a strong competitor. Despite that advantage, DPO still performs better or comparably while requiring only a single forward generation from the final policy.

The paper uses this comparison to emphasize efficiency. Best-of-$N$ can be effective, but it is not a practical deployment strategy for many applications because every query requires many sampled completions. DPO, by contrast, trains a single policy that directly internalizes the preference structure.

# Dialogue Results Relative to Prompted Base Models and Best-of-128

In the dialogue task, the paper compares DPO against several alternatives: a prompted base model, Preferred-FT, and a Best-of-128 baseline. The prompted base model is included to show how much can be done without fine-tuning. The Best-of-128 baseline is especially strong because it selects the best response from many samples, which makes it a computationally demanding but high-performing method.

The paper finds that DPO performs as well as or better than the best-performing temperatures for these competing methods. It also reports that DPO provides similar or better performance than the Best-of-128 baseline, while being far more efficient. This is a strong result because Best-of-128 is a difficult benchmark to beat: it gives the model many chances to produce a good response and then picks the best one under a learned reward model.

The dialogue experiment thus supports the paper’s broader claim that DPO is not just a simplification of RLHF, but a competitive alternative in realistic assistant-style generation settings. The method appears capable of improving over a well-initialized baseline while avoiding the expensive search procedure used by Best-of-$N$ methods.

# Failure of a Known PPO-Based HH Model to Outperform the Base Model in This Evaluation

The paper also evaluates an RLHF model trained with PPO on the Anthropic HH dataset, using a known public implementation. However, in their evaluation, the authors are unable to find a prompt or sampling temperature that gives this PPO-based model performance better than the base Pythia-2.8B model.

This is a striking result because it shows how sensitive PPO-based RLHF systems can be to evaluation details such as prompting and temperature. Even when a PPO-trained model exists, it may not outperform the base model under the specific evaluation setup used in the paper. The authors therefore treat Best-of-128 as a rough proxy for PPO-level performance in this dialogue setting, based on their TL;DR findings and the fact that both methods optimize the same reward function.

The key takeaway is not that PPO never works, but that its performance can be difficult to realize reliably in practice. DPO’s advantage is that it avoids this fragility: the paper reports that DPO is the only computationally efficient method that improves over the preferred completions in the Anthropic HH dataset and remains competitive with the stronger but much more expensive alternatives.

# Convergence Speed and Computational Efficiency of DPO

Another important empirical point in the paper is that DPO converges relatively quickly. In the dialogue results, the authors note that DPO reaches its best performance in a relatively short training time. This suggests that the optimization landscape is easier to work with than the one encountered by PPO-based RLHF methods.

Computational efficiency is one of the core motivations for DPO throughout the paper, and the experiments support that motivation. DPO does not require sampling from the model inside a reinforcement learning loop, nor does it require training a separate reward model and then optimizing a policy against it. Instead, it uses a single classification-style objective over the preference data. That simplicity appears to translate into practical training benefits.

The paper’s broader empirical message is that DPO reduces the implementation and tuning burden substantially. In the reported experiments, the authors emphasize that DPO works with very little hyperparameter tuning, yet still performs on par with or better than more complicated RLHF pipelines.

# The Broader Empirical Claim: DPO Matches or Exceeds RLHF Performance with Much Less Complexity

Taken together, the summarization and dialogue experiments support the paper’s central empirical claim: DPO can match or exceed the performance of PPO-based RLHF on real preference tasks, while being much simpler to train. The paper repeatedly contrasts DPO’s direct binary-classification-style objective with the more complex RLHF pipeline involving reward modeling, reinforcement learning, and careful tuning.

The significance of the results is not only that DPO works, but that it works in settings that are close to actual use cases. The summarization task tests quality improvement under human preferences, and the dialogue task tests helpfulness in open-ended assistant behavior. In both cases, DPO is competitive with or better than strong baselines, including PPO and Best-of-$N$ methods.

The overall conclusion drawn by the paper is that preference learning does not need to be routed through a full reinforcement learning procedure in order to be effective. DPO shows that, with the right reparameterization, the language model itself can be trained directly from preference data. The experiments in summarization and dialogue are the paper’s main evidence that this idea is not only elegant in theory, but also effective in practice.
