\title{Stack Exchange of the Paper: "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits"}

### Why does adding the value $0$ to 1-bit weights improve modeling capacity so much?
Question:
The paper argues that moving from binary weights to ternary weights $\{-1,0,1\}$ gives stronger modeling capability because the value $0$ supports "feature filtering." I think the idea is that a binary model with weights $\{-1,1\}$ can only flip signs or keep contributions, while a ternary model can also ignore some contributions entirely.

But I am not sure whether this is the right interpretation. In a large matrix product, why is the ability to set many weights to exactly $0$ especially important? Is this mostly about sparsity, regularization, representational power, optimization stability, or some combination of these? I would appreciate an explanation at the level of linear layers in transformers.
Answer:
The paper’s “feature filtering” claim is best understood at the level of a linear layer, not as generic sparsity regularization.

In a transformer block, a linear map computes something like $y = Wx$, where each output coordinate is a weighted sum of input features. If the weights are constrained to $\{-1,1\}$, then every input feature must contribute to every output feature with the same magnitude after scaling; the only thing the model can decide is whether a contribution is added or subtracted. That means a binary layer can change the sign of a feature, but it cannot truly *turn it off*. Every input channel is always “in the mix,” which makes the layer relatively rigid.

Once you add $0$, the weight matrix can choose among three behaviors for each connection: pass it positively, pass it negatively, or remove it entirely. That third option is what the paper calls feature filtering. It is important because many useful linear transformations in a transformer are not “use everything equally,” but rather “use these few signals, suppress the rest.” In attention projections, MLP projections, and output heads, it is often beneficial for each neuron to ignore irrelevant or noisy coordinates. With ternary weights, the model can represent that kind of selective routing directly.

So the gain is not mainly about sparsity as a compression trick or a regularizer, although sparsity is a side effect. The main point is representational power. Compared with $\{-1,1\}$, the ternary alphabet makes the set of possible weight matrices much richer: it greatly increases the number of distinct linear maps you can realize at a fixed parameter count. This is especially helpful in low-bit settings, because when the weight magnitudes are heavily quantized, losing the ability to zero out entries is a big restriction. The model then has to encode selection indirectly through cancellations between positive and negative weights, which is much less flexible and often much less stable.

Intuitively, think of a binary layer as forcing every neuron to listen to every input channel, while a ternary layer can decide, per connection, “listen,” “listen with opposite sign,” or “do not listen.” That extra “do not listen” option is what lets BitNet b1.58 behave much more like a real transformer layer and less like a coarse sign pattern. The paper’s empirical result—that this is enough to match FP16 baselines from around 3B parameters onward—suggests that this extra selectivity matters a lot in practice.
