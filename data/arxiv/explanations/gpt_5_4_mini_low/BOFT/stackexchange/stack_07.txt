\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why does BOFT($1$, $b$) reduce to block-diagonal OFT, and what exactly do the parameters $m$ and $b$ control?
Question:
The paper says that BOFT($1$, $b$) is the same as the original block-diagonal OFT with block size $b$, BOFT($1$, $d$) recovers the full orthogonal OFT, and BOFT($\log \frac{2d}{b}$, $b$) gives a dense orthogonal matrix.

I'm getting lost in the notation here, especially because they define the actual orthogonal matrix using $\mathbf{R}(m,b)$ and then say that "for convenience" BOFT with $\mathbf{R}(m, \frac{b}{2})$ is denoted BOFT($m$, $b$).

Could someone unpack this notation carefully? In particular:

1. What is the difference between the block size in the butterfly components and the $b$ shown in BOFT($m$, $b$)?
2. Why does setting $m=1$ make the whole thing block diagonal?
3. Why is the dense case reached at $m = \log \frac{2d}{b}$ rather than simply $\log d$?
Answer:
The notation is a bit overloaded, but the paper’s intent is actually simple once you separate two different “sizes” that appear in the butterfly construction.

In BOFT, the final orthogonal matrix is written as a product
$$
\mathbf{R}(m,b)=\prod_{i=1}^m \tilde{\mathbf{B}}^{\,b}_{(d,i)},
$$
where each factor $\tilde{\mathbf{B}}^{\,b}_{(d,i)}$ is a block-diagonal matrix built from small butterfly blocks. The key point is that the paper uses $b$ in BOFT$(m,b)$ as the *user-facing block size parameter*, but internally the actual butterfly components are written with block size $\frac{b}{2}$. That is why they say “for convenience, we denote BOFT with $\mathbf{R}(m,\frac{b}{2})$ as BOFT$(m,b)$.” In other words, the symbol $b$ in the BOFT name is not the same as the literal block size of $\tilde{\mathbf{B}}^b$; it is twice that. This is just a notational shift so that the smallest interesting case is $b=2$, corresponding to $2\times 2$ orthogonal building blocks.

Now to your first question: the block size in the butterfly components is $\frac{b}{2}$, while the $b$ in BOFT$(m,b)$ is the paper’s shorthand for twice that. So BOFT$(m,2)$ means the factors are built from $\tilde{\mathbf{B}}^{1}_{(d,i)}$, i.e. $1\times 1$ blocks in the internal notation, which is the minimal case. BOFT$(m,4)$ corresponds to internal block size $2$, and so on. The important takeaway is that $b$ controls the size of the local orthogonal mixing inside each butterfly component, while $m$ controls how many such mixing stages you compose.

For the second question, $m=1$ gives block-diagonal OFT because with only one butterfly component there is no “butterfly” inter-block mixing across stages at all. You just have a single structured orthogonal factor, and by the way the paper defines the family, that factor is exactly the block-diagonal orthogonal matrix used in original OFT, with block size $b$. So BOFT$(1,b)$ is just original block-diagonal OFT. Intuitively, the butterfly structure only becomes genuinely more expressive when you stack multiple sparse orthogonal components; one component alone is just a sparse blockwise transformation.

For the dense case, the reason the threshold is $m=\log \frac{2d}{b}$ rather than $\log d$ is that the number of butterfly stages depends on how far the recursive factorization can keep splitting until it reaches the base block size. In the paper, the effective base block size is $\frac{b}{2}$, so the recursion stops when
$$
2^m = \frac{d}{b/2} = \frac{2d}{b}.
$$
Equivalently,
$$
m=\log \frac{2d}{b}.
$$
At that depth, the butterfly factorization has propagated information across the full $d$-dimensional space, giving a dense orthogonal matrix. If you set $b=2$, this becomes $m=\log d$, which is the familiar full butterfly depth. So $\log d$ is only the special case when the internal block size is the minimum one. For larger $b$, you need fewer stages because each stage operates on larger local blocks.

So the short version is: $m$ is the number of butterfly layers, $b$ is the effective block-size parameter in the BOFT naming convention, and dense connectivity happens when the recursive butterfly splitting reaches the base scale, which in the paper’s notation is $m=\log \frac{2d}{b}$.
