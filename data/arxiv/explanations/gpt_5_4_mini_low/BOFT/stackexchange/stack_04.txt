\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### In the information transmission view, why does a nonzero entry $R_{ij}$ mean information flows from node $j$ to node $i$?
Question:
The paper interprets factorizing a dense matrix $\mathbf{R}$ as an information transmission problem on a layered graph. It says that if $R_{ij} \neq 0$, then information from source node $j$ can flow to destination node $i$.

I think this comes from viewing matrix multiplication as combining coordinates, but I am struggling to make the graph interpretation precise. If
$$
\mathbf{R} = \mathbf{B}_m \mathbf{B}_{m-1} \cdots \mathbf{B}_1,
$$
what exactly are the nodes and edges, and how does the existence of a path correspond to a nonzero entry of the product matrix?

Is this statement literally true in general, or only generically? For example, couldn't two different paths produce contributions that cancel out algebraically and still give $R_{ij} = 0$ even though a path exists?
Answer:
In the paper, the graph picture is best understood as a statement about the **support pattern** of the matrices, not as a literal theorem that “a path exists if and only if the entry is nonzero” for every possible choice of numerical values.

If you write
$$
\mathbf{R}=\mathbf{B}_m\mathbf{B}_{m-1}\cdots \mathbf{B}_1,
$$
then the “unrolled” graph has $m+1$ layers of $d$ nodes each. The node $j$ in layer $\ell$ represents the $j$-th coordinate of the intermediate vector after multiplying by $\mathbf{B}_1,\ldots,\mathbf{B}_{\ell-1}$. An entry $(\mathbf{B}_\ell)_{ab}\neq 0$ is drawn as a directed edge from node $b$ in layer $\ell$ to node $a$ in layer $\ell+1$. So the graph is just the matrix multiplication diagram: each sparse factor tells you which coordinates can mix at that stage.

Now expand an entry of the product. For the simplest case $m=2$,
$$
R_{ij}=(\mathbf{B}_2\mathbf{B}_1)_{ij}=\sum_{k=1}^d (\mathbf{B}_2)_{ik}(\mathbf{B}_1)_{kj}.
$$
Each summand corresponds to a length-2 path $j\to k\to i$. For general $m$, $R_{ij}$ is a sum over all length-$m$ paths from node $j$ in the first layer to node $i$ in the last layer, with each path contributing the product of its edge weights. That is the precise algebraic meaning of “information can flow along a path.”

So the right interpretation is:

- if there is **no path at all** from $j$ to $i$, then $R_{ij}=0$ for purely structural reasons;
- if there is **at least one path**, then $R_{ij}$ is a sum of contributions from those paths, and it may be nonzero or zero depending on the values.

That means your cancellation objection is absolutely valid in general. A path existing is **not sufficient** to guarantee $R_{ij}\neq 0$, because different path contributions can cancel exactly. The paper is aware of this kind of distinction and is using the graph as an **information-transmission intuition for sparsity patterns and connectivity**, not as a universal algebraic equivalence. In other words, the graph tells you what is *possible* structurally; the actual matrix values determine whether the final entry survives cancellation.

So, when the paper says “if $R_{ij}\neq 0$, information from node $j$ can flow to node $i$,” it is using “flow” in the loose sense that there is a nonzero input-output influence in the composed linear map. But the more precise statement is the converse one: a nonzero entry means some combination of paths survives in the sum, while a zero entry may arise either because there is no path or because the path contributions cancel. In practice, for the butterfly-type parameterizations they care about, the goal is to choose sparsity patterns that make dense connectivity structurally possible, not to prove a pathwise equivalence for arbitrary numeric matrices.
