\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: An Information Transmission View of Matrix Factorization

# From dense matrices to connectivity patterns

A central idea in the paper is to stop thinking of an orthogonal matrix only as a numerical object and instead view it as a pattern of connectivity. In ordinary linear algebra, a dense matrix is one whose entries are mostly nonzero, so every output coordinate can in principle depend on every input coordinate. The paper turns this into a graph-theoretic intuition: a dense square matrix of size $d \times d$ can be interpreted as a dense connectivity pattern between $d$ source nodes and $d$ receiver nodes.

This shift in viewpoint is especially useful for orthogonal finetuning, because the paper is not trying to learn an arbitrary dense matrix for its own sake. It is trying to construct a dense orthogonal matrix with as few trainable parameters as possible. If we only look at the matrix entries, it is hard to reason about how a sparse factorization might still generate a dense result. By viewing each nonzero as a possible connection, the question becomes more intuitive: how can we wire together a sequence of sparse transformations so that information can still travel from every input dimension to every output dimension?

# Interpreting nonzero matrix entries as channels of information flow

The paper’s information transmission view assigns a precise meaning to zero and nonzero entries. If $R_{ij}=0$, then information from the $j$-th node cannot flow to the $i$-th node through the matrix $\bm{R}$. If $R_{ij}\neq 0$, then such information can be transmitted. This is not meant as a literal communication system, but as a mental model for understanding how linear transformations propagate signal across dimensions.

This interpretation becomes clearer when $\bm{R}$ is used in the forward pass of a layer. In OFT and BOFT, the pretrained weight matrix is transformed by left-multiplying an orthogonal matrix, so the resulting layer can be seen as taking the original neuron representations and redistributing them. Under the transmission view, every nonzero entry in the transformation matrix represents a possible pathway by which one component of the original representation can influence another. The point of the factorization is therefore not only to reduce parameter count, but also to organize these pathways in a way that still permits full communication across the layer.

# Factorizing a matrix as sequential information exchange across levels

The paper considers a matrix factorization of the form $\bm{R}=\bm{B}_m\bm{B}_{m-1}\cdots \bm{B}_1$. Instead of thinking of this as a single matrix being written as a product, the paper interprets it as a sequence of information exchanges. Each factor $\bm{B}_i$ is one stage of transmission, and information passes through these stages one after another. In that sense, factorization is not just an algebraic decomposition; it is a staged communication process.

This sequential interpretation matters because each factor can be sparse even if the product is dense. A sparse factor does not need to connect every input to every output directly. It only needs to exchange information locally with the next stage. Over multiple stages, these local exchanges can accumulate into global connectivity. The paper uses this idea to motivate why composing sparse matrices can still produce a dense orthogonal transformation, provided the pattern of sparse connections is chosen carefully.

# Grid-structured graphs induced by matrix products

To formalize the transmission view, the paper unrolls the product $\bm{R}=\bm{B}_m\cdots \bm{B}_1$ into a grid-structured graph with $d \times (m+1)$ nodes. Each column corresponds to one level of the factorization, starting from the input level and ending at the output level. Each matrix $\bm{B}_i$ is then viewed as the connectivity between level $i$ and level $i+1$.

In this graph, a directed edge is allowed only between adjacent levels. The $(j_1,j_2)$ entry of $\bm{B}_i$ indicates whether there is a directed edge from node $j_2$ in level $i$ to node $j_1$ in level $i+1$. A zero entry means no edge; a nonzero entry means a connection exists. This makes the product structure concrete: multiplying matrices corresponds to propagating information through a layered network, where each layer implements one round of message passing.

The grid picture is useful because it exposes the structural constraints of factorization. A matrix product is dense only if the graph contains enough routes from the first level to the last level. If some nodes cannot reach others through the intermediate layers, then the final matrix will necessarily contain zeros in the corresponding positions. So the graph is not merely a visualization; it is a way to reason about which factorizations can possibly produce dense matrices.

# How matrix multiplication unrolls into a transmission network

The paper illustrates this with an example such as $\bm{R}=\bm{B}_5\bm{B}_4\bm{B}_3\bm{B}_2\bm{B}_1$. In the unrolled graph, each factor $\bm{B}_i$ becomes the connectivity matrix between the $i$-th and $(i+1)$-th levels. Following the product from right to left corresponds to information moving from the first level toward the last. The rightmost factor acts first on the input, then the next factor, and so on until the final output is reached.

This is important because the paper does not treat sparsity as a property of the final matrix alone. Instead, it tracks how sparsity in each factor affects whether a path exists through the network. For example, if one considers a shorter product such as $\bm{R}=\bm{B}_4\bm{B}_3\bm{B}_2\bm{B}_1$, the paper notes that some source nodes may fail to reach certain receiver nodes. In the example discussed, information from node $1$ cannot be transmitted to node $3$, which corresponds to a zero entry in the final matrix. Thus the final sparsity pattern can be understood by tracing paths through the layered graph.

This unrolling also highlights the repeated role of adjacency. Since each factor only connects neighboring levels, the question becomes whether a chain of local connections can assemble into global communication. That is the basic combinatorial challenge the paper aims to solve.

# Dense connectivity as the requirement that every source can reach every target

The paper’s main criterion for a factorization to generate a dense matrix is dense connectivity: every node in the first level must be able to transmit information to every node in the last level. In other words, for the final matrix $\bm{R}$ to be dense, there must be at least one path from every source node to every target node in the layered graph.

This is the graph-theoretic restatement of density. Instead of asking whether every entry of $\bm{R}$ is nonzero, one asks whether the network supports a path from every input coordinate to every output coordinate. The condition is intuitive: if some source cannot reach some target, then the corresponding matrix entry must be zero. Conversely, if the graph is richly connected enough, then the factorization can in principle produce a dense result.

The paper emphasizes that this requirement is not enough by itself. One also wants the factorization to use as few effective trainable edges as possible. This leads to a second desideratum: minimum free edges. The challenge is therefore to balance two goals at once. The graph must be connected enough to allow dense communication, but sparse enough to keep the parameter count low.

# Understanding sparsity patterns through paths in the graph

A major advantage of the information transmission view is that sparsity patterns can be understood through the existence or absence of paths. If a particular pair of source and target nodes has no path through the graph, then the final matrix entry must be zero. The paper uses this to explain why some sparse structures, such as the block-diagonal structure used in original OFT, cannot naturally produce a dense matrix.

The layered graph makes this limitation visible. Block-diagonal sparsity effectively isolates groups of dimensions from one another, so information is transformed separately within blocks. That means the graph breaks into disconnected or weakly connected regions, which can limit the set of reachable input-output pairs. By contrast, a factorization pattern with better global mixing can still remain sparse at each stage while allowing information to spread across all dimensions after multiple layers.

The paper also notes that orthogonality adds further constraints to these paths. The factors are not arbitrary sparse matrices; they must be orthogonal. This introduces dependencies among edges, so the allowed patterns are more restricted than in an unconstrained sparse network. The information transmission framework is useful precisely because it abstracts away from the exact values of the matrix entries and focuses instead on the nonzero structure, which is what matters for reasoning about connectivity under the orthogonality constraint.

# Why this perspective is useful for orthogonal finetuning

The reason this framework matters is that orthogonal finetuning is about preserving useful pretrained structure while adapting the model efficiently. In the paper, orthogonal matrices are attractive because they preserve pairwise angles and maintain the spectral norm of the pretrained weight matrix. But a full dense orthogonal matrix has too many parameters to be practical. The paper’s conceptual move is to ask how to keep the benefits of orthogonality while reducing the parameter burden.

The information transmission view provides a principled way to search for such parameterizations. Once dense orthogonal matrix construction is seen as a communication problem on a graph, the task becomes one of designing a sparse network that still supports full source-to-target reachability. This opens the door to structured factorizations, especially the butterfly structure, which the paper adopts because it can achieve dense connectivity with only $\mathcal{O}(d \log d)$ edges.

This perspective is valuable not only for deriving BOFT, but also for understanding why BOFT is meant to improve over block-diagonal OFT. Block-diagonal sparsity is a simple way to save parameters, but it hard-codes a rigid partition of dimensions. The graph view shows why this may be undesirable: it imposes a particular connectivity pattern that may be too restrictive and may not approximate the kinds of dense linear transformations that arise naturally in practice. BOFT instead uses a factorization pattern that still controls parameter count but allows information to circulate more globally through the matrix product.

In short, the information transmission view turns the problem of learning a dense orthogonal matrix into a question about graph connectivity. That reframing is the conceptual foundation for the paper’s butterfly-based orthogonal finetuning method.
