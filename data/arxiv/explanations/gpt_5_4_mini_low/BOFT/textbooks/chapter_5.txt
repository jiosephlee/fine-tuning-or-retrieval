\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 5: 5. Design Goals for Parameter-Efficient Orthogonal Factorizations

# Dense connectivity across the factorization graph

The paper’s information transmission view turns the problem of constructing a dense orthogonal matrix into a graph problem. Instead of thinking only in terms of matrix entries, we interpret a factorization $\bm{R}=\bm{B}_m\bm{B}_{m-1}\cdots \bm{B}_1$ as a sequence of information exchanges across $m+1$ layers of nodes. In this picture, each factor $\bm{B}_i$ connects the nodes at level $i$ to the nodes at level $i+1$, and the product is dense only if information from every source node in the first level can eventually reach every receiver node in the last level.

This leads directly to the first desideratum: the factorization graph must have dense connectivity. Dense connectivity means that, for every node in the first level, there is at least one path to every node in the final level. If this condition fails, then some entries of the resulting matrix $\bm{R}$ must remain zero, and the matrix cannot be dense. In other words, even if each factor is individually sparse, the factorization as a whole must still allow all-to-all communication after composition.

The intuition is that sparsity is only useful if it is arranged so that information can still propagate broadly through the network of factors. A sparse pattern that blocks communication between some input and output coordinates defeats the purpose of constructing a dense orthogonal matrix. The paper emphasizes that dense connectivity is not just a desirable property in an abstract sense; it is the structural condition that makes sparse factorization compatible with expressiveness.

# Minimum free edges for parameter efficiency

The second desideratum is to use as few free edges as possible while still maintaining dense connectivity and orthogonality. Here “free edges” correspond to trainable nonzero entries in the factorization graph. The goal is not merely to achieve density, but to do so with minimal parameter count. This is the central efficiency problem: we want a dense orthogonal matrix without paying the full $\mathcal{O}(d^2)$ parameter cost of an unconstrained dense matrix.

The paper frames this as a trade-off between connectivity and economy. A factorization with too many edges may be expressive, but it sacrifices parameter efficiency. A factorization with too few edges may be efficient, but it may fail to connect the graph densely. The challenge is therefore to find a sparse pattern that is still sufficiently expressive to generate dense orthogonal matrices.

This perspective also clarifies why matrix factorization is attractive in the first place. By composing several sparse matrices, we can reduce the number of trainable parameters in exchange for additional computation during training. That is, instead of storing a large dense orthogonal matrix directly, we store a structured product of simpler factors. The paper’s goal is to make this trade-off as favorable as possible.

# Why orthogonality changes how we count effective parameters

A subtle point in the paper is that orthogonality changes what counts as a trainable parameter. In an ordinary dense matrix, one might count every nonzero entry as a degree of freedom. But orthogonal matrices are constrained by the condition $\bm{R}^\top \bm{R}=\bm{I}$. This means the entries are not independent: the choice of some nonzero entries restricts the others.

Because of this, the paper distinguishes between edges that are structurally necessary and edges that are actually trainable. Some nonzero entries are required simply to satisfy orthogonality, but they do not represent additional freedom in the model. The paper notes, for example, that for a $d\times d$ orthogonal matrix with exactly $d$ nonzero entries, those entries can only be $\pm 1$. Such entries are necessary for the matrix to be full-rank and orthogonal, but they do not provide meaningful trainable flexibility.

This is why the paper does not equate “number of nonzero entries” with “number of effective parameters” in a naive way. Orthogonality reduces the number of independent choices available, and therefore the efficiency analysis must account for these constraints. The information transmission framework helps by focusing on the pattern of nonzeros and how they enable communication, rather than on the exact numerical values themselves.

# Full-rank requirements and bijective connections between adjacent levels

A key structural requirement in the paper is that each factor matrix must be full-rank. Since orthogonality implies full-rank, every factor in the product must satisfy this condition. In the graph interpretation, this means that the connections between adjacent levels cannot be arbitrarily sparse; they must be sufficient to support a bijection between the nodes on one level and the nodes on the next.

The paper explains that for a $d\times d$ orthogonal factor, we need $d$ edges between adjacent levels to create a bijection between the $d$ nodes on one level and the $d$ nodes on the next. These $d$ edges are not considered trainable freedom in the same way as additional edges, because they are already required by the orthogonality constraint. They are part of the unavoidable structure needed for a valid orthogonal transformation.

This requirement is important because it shows that orthogonality is not simply a regularizer layered on top of sparsity. It actively shapes the graph. Even before we ask how to make the matrix dense, we must ensure each factor is structurally capable of being orthogonal. The adjacent-level connections therefore serve as the basic backbone of the factorization graph.

# How orthogonality induces dependencies among nonzero entries

Orthogonality introduces dependencies among entries, and the paper highlights that this can affect the sparsity pattern itself. A zero in one position may force another zero elsewhere because the rows and columns must remain mutually orthonormal. The paper gives the simple example of a $2\times 2$ orthogonal matrix: if one entry is zero, another entry may be forced to be zero as well. This shows that one cannot treat each nonzero location independently when orthogonality is imposed.

This dependency matters because it complicates the design of sparse patterns. In a general sparse matrix, one might freely choose a pattern of nonzeros and then fit their values. In an orthogonal matrix, however, the pattern and the values interact more tightly. Some patterns are simply incompatible with orthogonality, while others severely limit how much freedom remains after the constraints are enforced.

The paper’s framework is particularly useful here because it abstracts away from the exact values and concentrates on whether the nonzero pattern can support information flow. Since orthogonality can add or remove effective edges through its constraints, the graph view helps organize the design problem in a way that value-level reasoning alone cannot.

# Why some edges are structurally necessary but not trainable

The paper repeatedly distinguishes between edges that are necessary for the matrix to exist and edges that contribute trainable parameters. This distinction is crucial for understanding parameter efficiency in orthogonal factorization.

Structurally necessary edges are those required for full-rank orthogonality. For example, the $d$ connections between adjacent levels are needed so that each factor can act as a valid orthogonal transformation. But these edges do not automatically represent extra freedom. They are part of the minimum structure that any orthogonal factorization must carry. The paper emphasizes that these should not be counted as trainable edges in the efficiency analysis.

Trainable edges, by contrast, are the additional degrees of freedom beyond this minimum structure. The goal is to minimize these while preserving dense connectivity. This is why the paper speaks of “minimum free edges”: the useful measure of efficiency is not the total number of occupied positions, but the number of positions that actually introduce extra parameter freedom beyond the orthogonality baseline.

This distinction is one of the subtle but important conceptual contributions of the paper. It explains why a factorization can be sparse without being parameter-efficient in the relevant sense, and why a careful accounting of orthogonality is needed when designing structured finetuning methods.

# Comparing naive dense parameterization with sparse factorized alternatives

A naive dense parameterization of a $d\times d$ orthogonal matrix would require $\mathcal{O}(d^2)$ parameters. The paper uses this as the baseline against which sparse factorized designs are compared. In the information transmission view, such a matrix corresponds to a fully connected bipartite graph between the input and output levels, which is expressive but expensive.

The paper’s main idea is to replace this single dense matrix with a product of multiple sparse matrices. This trades space for computation: the factorization must be multiplied repeatedly during training, but it can drastically reduce the number of trainable parameters. The information transmission framework makes this trade-off visible by turning the matrix into a graph whose edges can be counted and organized.

The paper also gives an example where a factorization uses fewer edges than a single dense orthogonal matrix. This illustrates that factorization can be beneficial even before introducing the butterfly structure. But the key question is not merely whether a factorization uses fewer edges than the dense case; it is whether it can do so while still maintaining the dense connectivity needed for expressiveness and the orthogonality needed for stable finetuning.

# Why the original OFT block-diagonal graph fails to achieve dense connectivity

The original Orthogonal Finetuning method, OFT, uses a block-diagonal orthogonal structure to reduce the number of trainable parameters. While this makes OFT more efficient than a fully dense orthogonal parameterization, the paper argues that this structure has a fundamental limitation: it cannot construct a dense matrix in the same way a more globally connected factorization can.

In the graph interpretation, a block-diagonal matrix breaks the nodes into separate groups that are transformed independently. This means that information cannot freely move between blocks. As a result, the factorization lacks dense connectivity. Some source nodes can only reach a restricted subset of receiver nodes, which means the resulting matrix cannot approximate the kind of dense mixing desired for a general orthogonal transformation.

The paper points out that this block structure introduces a fixed sparsity pattern, and that the pattern itself creates an inductive bias. While this may reduce parameters, it also reduces expressiveness and makes the choice of sparsity pattern a difficult design problem. In particular, the block-diagonal structure cannot recover classic linear transforms in the way the butterfly structure can. This is one of the main reasons the paper seeks a denser yet still parameter-efficient alternative.

In summary, the original OFT graph succeeds in sparsity but fails in global connectivity. The paper’s information transmission perspective makes this failure easy to see: independent blocks impede communication across the full set of nodes, so the factorization cannot realize the dense mixing that motivates orthogonal finetuning in the first place.
