\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 8: 8. The BOFT Method: Formulation, Special Cases, and Complexity

# BOFT forward-pass equation

BOFT, short for Orthogonal Butterfly, is a finetuning method in which the pretrained linear layer is modified by left-multiplying it with a learnable orthogonal matrix. If the frozen pretrained weight matrix is $\bm{W}^0 \in \mathbb{R}^{d \times n}$ and the input is $\bm{x} \in \mathbb{R}^d$, then the original forward pass is

\[
\bm{z} = (\bm{W}^0)^\top \bm{x}.
\]

BOFT replaces this with

\[
\bm{z} = \big(\bm{R}(m,b)\bm{W}^0\big)^\top \bm{x},
\]

where $\bm{R}(m,b) \in \mathbb{R}^{d \times d}$ is an orthogonal matrix constructed from butterfly components. This means BOFT does not change the layer architecture itself; instead, it changes the effective weights by applying a structured orthogonal transformation before the frozen weights are used in the forward pass.

The key idea is that $\bm{R}(m,b)$ is not represented as a single dense orthogonal matrix. Instead, it is built from a product of sparse orthogonal factors. This is what makes BOFT parameter-efficient while still preserving the orthogonality constraint.

# Notation for $\bm{R}(m,b)$ and stacked butterfly components

The BOFT orthogonal matrix is written as a product of $m$ orthogonal butterfly components:

\[
\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}.
\]

Each factor $\tilde{\bm{B}}^b_{(d,i)}$ is an orthogonal butterfly component. The paper uses the notation $\tilde{\bm{B}}^b(d,2^{m-i+1})$ and abbreviates it as $\tilde{\bm{B}}^b_{(d,i)}$ for convenience. Every factor in the product must itself be orthogonal, so each one satisfies

\[
\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top \tilde{\bm{B}}^b_{(d,j)} = \tilde{\bm{B}}^b_{(d,j)} \big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top = \bm{I}_d,
\qquad \forall j \in [1,m].
\]

The paper builds these components recursively from butterfly matrices. At the smallest scale, the butterfly factor is defined as a $k \times k$ matrix of the form

\[
\bm{B}^F(k)=
\begin{bmatrix}
\text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\
\text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4)
\end{bmatrix},
\]

where each $\bm{d}_i \in \mathbb{R}^{k/2}$. The full butterfly matrix $\bm{B}(d)$ is then built recursively from smaller butterfly matrices and butterfly components. This recursive structure is what gives BOFT its compact parameterization.

The paper also generalizes this construction to block butterfly components, where the scalar entries in the butterfly factors are replaced by $b \times b$ blocks. This generalization is important because it creates a family of models indexed by the depth parameter $m$ and block size $b$.

# BOFT as a generalized orthogonal finetuning framework

BOFT is presented as a generalized orthogonal finetuning framework because it includes the original OFT as a special case while also allowing denser and more expressive orthogonal parameterizations. The point of the framework is to interpolate between two extremes: highly structured, parameter-efficient orthogonal transformations and fully dense orthogonal transformations.

The original OFT uses a single orthogonal matrix, often with a block-diagonal structure for parameter efficiency. BOFT replaces that single factor with a product of multiple sparse orthogonal butterfly components. As a result, BOFT can represent more expressive orthogonal transformations without requiring a full $d \times d$ dense parameterization.

The paper emphasizes that BOFT is not merely a heuristic modification. It is a structured orthogonal parameterization that subsumes OFT and provides a broader family of models. In this sense, BOFT is a general framework for orthogonal finetuning rather than just a specific architecture.

# Special case: BOFT$(1,b)$ as block-diagonal OFT

When the number of butterfly factors is $m=1$, BOFT reduces to a block-diagonal orthogonal finetuning method. In the paper’s notation, BOFT$(1,b)$ becomes the block-diagonal OFT variant with block size $b$.

This special case is important because it shows that BOFT contains the original parameter-efficient orthogonal finetuning idea as a limiting instance. With only one factor, there is no deep butterfly composition; the orthogonal matrix is constrained to the block structure used in OFT. Thus, BOFT does not abandon OFT, but rather extends it.

The paper also notes that BOFT$(1,b)$ corresponds to the block-diagonal structure described in the original OFT work. In other words, if one uses only a single orthogonal block structure, BOFT is exactly the same as block-diagonal OFT.

# Special case: BOFT$(1,d)$ as full dense OFT

Another key special case occurs when $m=1$ and $b=d$. In that setting, BOFT$(1,d)$ reduces to the original OFT with an unconstrained full orthogonal matrix.

This case represents the opposite end of the spectrum from the block-diagonal version. When the block size grows to the full dimension, the orthogonal matrix is no longer sparsely structured in the same way; it becomes a dense orthogonal transformation. Therefore, BOFT naturally includes both the highly structured and the fully dense versions of OFT within one formulation.

This inclusion is conceptually important because it shows that BOFT can be viewed as a continuum between regularity and expressivity. Small block sizes yield stronger structural constraints and fewer parameters, while larger block sizes move toward the full orthogonal group.

# Dense orthogonal construction with logarithmic depth

A major advantage of BOFT is that it can build dense orthogonal matrices using only logarithmic depth in the butterfly case. The paper states that BOFT$(\log \frac{2d}{b}, b)$ uses the block butterfly matrix $\bm{B}^{b/2}(d)$ as $\bm{R}$ and yields a dense orthogonal matrix.

The intuition is that repeated butterfly factorization allows information to propagate across all dimensions through multiple sparse steps. Rather than using one dense orthogonal matrix directly, BOFT composes many sparse orthogonal components so that the final product becomes dense. This is what makes the method parameter-efficient without sacrificing the ability to express rich transformations.

When the butterfly matrix itself is used, meaning $m=\log d$ and $b=2$, BOFT achieves the advertised $\mathcal{O}(d \log d)$ scaling. This is the central efficiency result of the method. The paper’s construction shows that dense orthogonal behavior does not require dense parameterization.

# Effective trainable parameter count: $\frac{1}{2}(b-1)dm$

For a linear layer of size $d \times n$, the paper gives the effective trainable parameter count of BOFT$(m,b)$ as

\[
\frac{1}{2}(b-1)dm.
\]

This formula quantifies the benefit of factorization. The number of trainable parameters depends linearly on the dimension $d$, the butterfly depth $m$, and the block size $b$. The factor $\frac{1}{2}(b-1)$ reflects the internal structure of the orthogonal blocks used in the butterfly components.

This count is much smaller than the $d^2$ parameters needed for a full dense orthogonal matrix when $d$ is large. It is also a useful way to compare different BOFT settings, since changing $m$ or $b$ directly changes the parameter budget.

# When BOFT achieves $\mathcal{O}(d \log d)$ complexity

BOFT reaches $\mathcal{O}(d \log d)$ complexity in the butterfly setting, namely when the factorization uses $m=\log d$ and $b=2$. In that case, the parameter count becomes proportional to $d \log d$, which is substantially smaller than the $\mathcal{O}(d^2)$ cost of a dense orthogonal matrix.

This is the regime that most clearly demonstrates the value of the butterfly construction. The product of $\mathcal{O}(\log d)$ sparse matrices can still yield a dense orthogonal transformation, but the number of trainable parameters grows only quasi-linearly in $d$ rather than quadratically.

The paper contrasts this with the original OFT formulation. The dense orthogonal version of OFT requires $\mathcal{O}(d^2)$ parameters, while the block-diagonal OFT has complexity on the order of $\mathcal{O}(bd)$, depending on the block size. BOFT achieves a more favorable trade-off because it can produce dense orthogonal matrices without forcing the block size all the way up to $d$.

# Comparison of parameter complexity: full OFT, block-diagonal OFT, and BOFT

The paper positions BOFT as a middle ground between two existing extremes. Full OFT, with an unconstrained dense orthogonal matrix, is expressive but expensive, using $\mathcal{O}(d^2)$ parameters. Block-diagonal OFT is more efficient, but it imposes a fixed sparsity pattern and reduces expressiveness.

BOFT improves on both by using butterfly factorization. Like block-diagonal OFT, it exploits structure to reduce the number of effective parameters. But unlike block-diagonal OFT, its structure is not confined to independent blocks. Instead, the repeated butterfly composition allows information to flow globally across the matrix, making dense orthogonal matrices possible with far fewer parameters.

The paper’s comparison shows that original OFT must effectively set the block size to $b=d$ to obtain a dense orthogonal matrix. BOFT, by contrast, can achieve density for a range of settings, including the butterfly case. This makes BOFT a more flexible and general orthogonal finetuning scheme.

# Trading off depth, block size, expressivity, and efficiency

A central theme of BOFT is the trade-off between depth, block size, expressivity, and efficiency. Increasing the depth $m$ generally allows the product of more sparse orthogonal components, which can increase expressivity. At the same time, the block size $b$ controls the granularity of each component, and smaller blocks lead to fewer trainable parameters.

The paper’s discussion of approximation experiments supports this trade-off. BOFT with smaller $b$ and larger $m$ is generally more parameter-efficient. In the reported simulations, configurations with more butterfly depth often achieve similar approximation errors using fewer parameters than shallow block-diagonal settings with larger block sizes.

This is the main design principle behind BOFT. Instead of relying on one large orthogonal matrix or a fixed block-diagonal sparsity pattern, BOFT uses a factorized butterfly structure to navigate between regularity and expressivity. The result is a family of orthogonal finetuning methods that can be tuned to fit different parameter budgets while preserving the structural advantages of orthogonal updates.
