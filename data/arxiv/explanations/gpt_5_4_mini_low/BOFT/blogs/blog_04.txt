\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# An Information Highway for Neural Networks: BOFT’s Clever View of Matrix Updates

Fine-tuning large foundation models is expensive if you update everything, so the field has been looking for ways to adapt models with only a small number of trainable parameters. One appealing approach is orthogonal finetuning, or OFT, which updates a pretrained weight matrix by multiplying it with a learnable orthogonal matrix. The key idea is that orthogonal transformations preserve pairwise angles between neurons, which helps retain pretrained knowledge.

The downside is that a dense orthogonal matrix is expensive to learn: it has too many parameters. The original OFT paper reduced that cost with a block-diagonal structure, but that comes with a strong limitation. The matrix is no longer fully dense, and different blocks are transformed independently. That makes the structure efficient, but also somewhat rigid.

This paper takes a different route. Instead of thinking about the problem purely as matrix algebra, it asks a more practical question: how can information move through a matrix?

## Thinking of a Matrix as a Network

The authors reframe orthogonal matrix factorization as an information transmission problem. Imagine a matrix as a directed network connecting input nodes to output nodes. If an entry in the matrix is non-zero, information can flow along that connection. If it is zero, that route is blocked.

Now suppose we do not build the final matrix all at once. Instead, we factor it into a product of several sparse matrices. In the network view, each factor becomes one layer of routing. Information moves from one level of nodes to the next, step by step.

This perspective is useful because it turns the design problem into a graph problem:

- Every input node should be able to reach every output node.
- The number of trainable connections should be as small as possible.
- The factors still need to satisfy orthogonality constraints.

This is a much more concrete way to reason about sparsity patterns than treating them as arbitrary matrix shapes.

## Why Block-Diagonal Structure Is Not Enough

The original OFT uses block-diagonal orthogonal matrices to save parameters. In the network interpretation, that is like splitting the nodes into separate groups and only allowing communication within each group.

That saves memory, but it also creates a hard barrier: information cannot easily move across blocks. So even though the matrix is orthogonal, its connectivity is limited. The paper argues that this kind of sparsity is restrictive and introduces an awkward inductive bias, because the grouping is based only on index positions rather than any meaningful structure in the data.

The problem is not just efficiency. It is expressiveness. A block-diagonal orthogonal matrix cannot approximate the kinds of dense linear transforms that many models would benefit from.

## Butterfly Structure as an Efficient Routing Scheme

To get around this, the authors borrow an idea from the Cooley-Tukey fast Fourier transform: the butterfly structure. In FFT, the butterfly graph is a classic way to move information efficiently across many nodes using only a small number of sparse operations.

That makes it a natural fit for this setting.

Instead of using one sparse block-diagonal matrix, BOFT constructs the orthogonal update as a product of several sparse orthogonal factors arranged in a butterfly pattern. Each factor is still sparse, but together they form a dense transformation. In graph terms, the butterfly topology provides a low-cost way for every source node to reach every destination node.

This matters because it gives a better tradeoff between two competing goals:

- **Regularity**, meaning the update stays close to the pretrained model.
- **Expressivity**, meaning the update can still represent rich transformations.

BOFT uses the butterfly structure to move smoothly between those two extremes.

## Why This Helps Parameter Efficiency

The benefit of factorizing a dense orthogonal matrix is that each factor only needs a small number of non-zero entries. The paper shows that with butterfly factorization, a dense $d \times d$ orthogonal matrix can be built from $\mathcal{O}(\log d)$ sparse matrices, each with $\mathcal{O}(d)$ non-zero entries. That leads to $\mathcal{O}(d \log d)$ parameters, which is much smaller than the $\mathcal{O}(d^2)$ parameters needed for a full dense orthogonal matrix.

The authors also point out that BOFT subsumes the block-diagonal OFT as a special case. So BOFT is not just a new method with a different shape; it is a more general orthogonal finetuning framework.

## More Expressive Than Block Diagonal

A central claim in the paper is that the butterfly structure is more expressive than block-diagonal structure at the same block size. Intuitively, this makes sense in the network picture.

A block-diagonal matrix isolates groups. A butterfly factorization, by contrast, repeatedly mixes information across groups through multiple layers of sparse routing. That repeated mixing is what makes dense connectivity possible.

The paper backs this up with both theory and a simulation where BOFT approximates random dense orthogonal matrices more effectively than block-diagonal OFT under comparable parameter budgets. Smaller block sizes and more butterfly stages generally improve parameter efficiency.

The key point is that sparsity does not have to mean isolation. With the right structure, sparse factors can still generate rich global interactions.

## Why This Perspective Is Useful

The most interesting contribution of the paper is not just the butterfly parameterization itself, but the way the authors arrived at it. By treating matrix factorization as information routing, they turn a difficult algebraic design problem into a network design problem.

That gives them a useful design principle: choose sparse structures that allow efficient communication across the whole matrix, not just within local blocks.

In practice, this leads to a few advantages:

- Better parameter efficiency than full orthogonal finetuning.
- More expressivity than block-diagonal orthogonal updates.
- No additional inference latency, since the learned orthogonal matrices can be merged into the pretrained weights after finetuning.
- A general framework that works across vision, language, and diffusion models.

## Takeaway

BOFT’s main insight is that a learnable orthogonal matrix does not need to be dense in its parameterization to be dense in effect. If you organize the update as a carefully designed information network, sparse factors can cooperate to produce a powerful global transformation.

That shift in viewpoint is the real contribution. It turns orthogonal finetuning from a question of “how do we store a large matrix cheaply?” into “how do we route information efficiently?” And once you ask that question, the butterfly structure becomes a very natural answer.
