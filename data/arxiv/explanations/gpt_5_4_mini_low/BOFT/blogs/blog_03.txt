\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# From FFT to Foundation Models: How Butterfly Math Makes AI Finetuning Efficient

Finetuning large foundation models is attractive because it lets us reuse pretrained knowledge instead of training from scratch. But even when we only want to adapt a model to a new task, the number of parameters can still be very large. This paper tackles that problem through a surprisingly elegant idea: use butterfly factorization, a structure inspired by the fast Fourier transform, to build dense orthogonal updates from a sequence of sparse ones.

The result is a new finetuning method called Orthogonal Butterfly, or BOFT. It keeps the key benefits of orthogonal finetuning while making it much more parameter-efficient.

## Why orthogonal finetuning?

The starting point is Orthogonal Finetuning, or OFT. Instead of adding a low-rank update like LoRA, OFT multiplies a pretrained weight matrix by a learnable orthogonal matrix. This matters because orthogonal transformations preserve pairwise angles between neurons, which helps preserve pretrained structure and tends to improve stability and generalization.

If a pretrained linear layer uses weight matrix $W^0$, OFT changes the forward pass from

$$
z = (W^0)^\top x
$$

to

$$
z = (RW^0)^\top x,
$$

where $R$ is orthogonal.

The problem is that a full $d \times d$ orthogonal matrix still has a lot of parameters, roughly $\mathcal{O}(d^2)$. OFT reduces this by using a block-diagonal orthogonal matrix, but that comes with a cost: the model can only mix information within blocks, not across the full space. That makes the structure efficient, but also restrictive.

## The key question: can we get dense and efficient?

The paper asks a simple but important question: can we construct a dense orthogonal matrix without paying the full quadratic parameter cost?

The answer is yes, by factoring the matrix into a product of sparse orthogonal matrices. Instead of storing one dense matrix, BOFT stores several sparse ones and multiplies them together. This trades extra computation during training for a much smaller number of trainable parameters.

To reason about this more cleanly, the paper introduces an information transmission view. Think of each matrix factor as a layer in a graph. A non-zero entry means information can flow from one node to another. A dense final matrix means every input dimension can eventually influence every output dimension. So the goal becomes: design sparse factorization patterns that still allow complete information flow.

## Why butterfly structure?

This is where the butterfly structure comes in.

The butterfly pattern is best known from the Cooley-Tukey fast Fourier transform. In FFT, global mixing is achieved through a sequence of local pairwise operations arranged in a recursive, layered pattern. That same idea is useful here: a butterfly network can connect all inputs to all outputs using only $\mathcal{O}(d \log d)$ edges.

That is the core insight behind BOFT. Instead of using a block-diagonal pattern, BOFT uses a butterfly factorization to compose a dense orthogonal matrix from multiple sparse orthogonal components.

In practical terms, this gives a much better parameter count. A full orthogonal matrix needs $\mathcal{O}(d^2)$ parameters. BOFT, with the butterfly structure, can get down to $\mathcal{O}(d \log d)$.

## How BOFT is built

BOFT parameterizes the orthogonal update as a product of butterfly components. Each component is sparse, but the product can become dense.

The paper defines butterfly factors recursively, and then ensures orthogonality by parameterizing the smallest blocks with orthogonal transformations, such as Cayley parameterization. The important point is that every factor remains orthogonal, so the product is orthogonal too.

BOFT also generalizes the block-diagonal OFT setup. In fact, OFT becomes a special case of BOFT when the butterfly depth is reduced. This makes BOFT a more general orthogonal finetuning framework, not just a separate trick.

## Why this helps in finetuning

The paper argues that BOFT gives a better balance between expressivity and regularity.

A full orthogonal matrix is very expressive, but too unconstrained. A block-diagonal matrix is regular and efficient, but too limited. Butterfly structure sits in between. It is structured enough to reduce parameters and impose a useful inductive bias, but flexible enough to mix information across the whole layer.

This matters because many classic linear transforms, such as the Fourier transform, discrete cosine transform, and Hadamard transform, have butterfly-like structure. So BOFT is not just compressing the update; it is biasing the update toward a family of transformations that has already proven useful in signal processing and numerical computation.

## A few extra details

The paper adds two practical pieces that help BOFT work as a finetuning method.

First, BOFT uses identity initialization, so the finetuned model starts exactly at the pretrained model. This is a common and useful property in parameter-efficient finetuning.

Second, the authors introduce a multiplicative dropout scheme for BOFT, since standard dropout does not directly fit a multiplicative orthogonal update. Their version randomly replaces selected butterfly components or blocks with identity matrices during training.

## What the experiments show

The paper evaluates BOFT on a broad set of tasks, including large vision transformers, large language models, and text-to-image diffusion models. The authors report that BOFT outperforms current state-of-the-art methods by a substantial margin in these settings.

That is an important result because orthogonal finetuning had previously been shown mainly in the context of controllable text-to-image generation. This paper argues that the method is much more general than that, and the experiments support that claim.

The paper also shows that BOFT can approximate dense orthogonal matrices more efficiently than the original OFT setup, especially when using smaller blocks and deeper butterfly factorizations.

## The big takeaway

The main idea in this paper is simple to state but powerful in practice:

Instead of learning one dense orthogonal matrix directly, learn a product of sparse orthogonal matrices arranged in a butterfly pattern.

That move preserves the benefits of orthogonal finetuning while dramatically reducing parameter count. It also creates a cleaner connection between finetuning and structured linear algebra, borrowing a classic idea from FFT to make modern foundation models easier to adapt.

BOFT does introduce some extra training-time overhead because the factors must be multiplied repeatedly during optimization. But after finetuning, the learned orthogonal update can be folded into the pretrained weights, so there is no added inference latency.

In short, this paper shows that a carefully designed sparse structure can give us much of the power of dense orthogonal finetuning, at a fraction of the parameter cost.
