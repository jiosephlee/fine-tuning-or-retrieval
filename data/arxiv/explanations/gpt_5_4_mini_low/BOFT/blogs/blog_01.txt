\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Why Finetuning Giant AI Models Is So Expensive—and How BOFT Cuts the Cost

Large foundation models are impressive, but they come with a practical problem: once a model has hundreds of billions of parameters, retraining it from scratch is unrealistic for most teams. The real challenge is not just building these models, but adapting them to new tasks efficiently.

This paper focuses on that adaptation problem. It asks a simple but important question: how can we finetune a pretrained model without paying the full cost of updating all of its weights?

## The core problem: adapting without starting over

A pretrained model already knows a lot. A language model, vision transformer, or diffusion model has learned general representations that are useful across many tasks. Finetuning lets us reuse that knowledge for a new domain or objective.

But standard finetuning is expensive because every updated parameter adds memory, compute, and training cost. For very large models, updating everything can be overkill. That is why the field has turned toward **parameter-efficient finetuning** (PEFT): methods that adapt the model while changing only a small fraction of the parameters.

The paper groups the main PEFT approaches into three families. In **model finetuning**, the original architecture stays the same and only a subset of the existing weights is trained. In **adapter tuning**, extra trainable modules are inserted into the network. In **prompt tuning**, trainable prefix tokens are added to the input side instead of changing the model weights directly.

Each approach tries to reduce cost, but they make different trade-offs. Prompt tuning changes how the model is conditioned. Adapters add extra components that can affect inference structure. Model finetuning is attractive because it is simple and introduces no inference latency if done well.

## Why orthogonal finetuning is interesting

The paper builds on a more principled version of model finetuning called **Orthogonal Finetuning** (OFT). The main idea is to transform a pretrained weight matrix by multiplying it with a learnable orthogonal matrix.

Why orthogonal? Because orthogonal transformations preserve angles between vectors. In the context of neural networks, that means the relationships learned during pretraining are less likely to be destroyed during adaptation. This is a more structured alternative to using a small learning rate and hoping the model does not drift too far.

Concretely, if a pretrained linear layer uses weights $\bm{W}^0$, OFT replaces it with $\bm{R}\bm{W}^0$, where $\bm{R}$ is an orthogonal matrix learned during finetuning. This keeps the pretrained weights in place but rotates them in a controlled way.

That sounds elegant, but there is a catch: a dense orthogonal matrix of size $d \times d$ has a lot of degrees of freedom. So while OFT is principled, it can still be expensive.

## The limitation of standard OFT

To make OFT cheaper, the original approach uses a **block-diagonal** orthogonal matrix. This reduces the number of trainable parameters by splitting the dimensions into independent blocks.

The downside is that this creates a fixed sparsity pattern. Different groups of dimensions are transformed separately, which can limit expressiveness. The paper points out two issues with this:

First, the block structure may introduce an odd inductive bias, since dimensions are grouped purely by index rather than by any semantic relationship. Second, it is unclear how to choose a good sparsity pattern in the first place.

So the authors wanted something better: a way to keep orthogonal finetuning parameter-efficient without relying on rigid block structure.

## BOFT: orthogonal finetuning with butterfly factorization

Their answer is **Orthogonal Butterfly** or **BOFT**.

BOFT takes a different route to parameter efficiency. Instead of directly learning one large dense orthogonal matrix, it represents that matrix as a product of multiple sparse orthogonal matrices arranged in a **butterfly structure**. This idea is inspired by the Cooley-Tukey fast Fourier transform, where butterfly graphs enable efficient information exchange.

The intuition is nice: rather than paying for all-to-all connectivity in one shot, BOFT lets information flow through a sequence of sparse mixing steps. Over multiple factors, those sparse matrices can still produce a dense orthogonal transformation.

This matters because the final orthogonal matrix is much cheaper to parameterize. The paper shows that BOFT can use only $\mathcal{O}(d \log d)$ parameters in the butterfly case, compared with $\mathcal{O}(d^2)$ for a fully dense orthogonal matrix.

## An information transmission view

One of the paper’s main contributions is a way to think about the factorization problem as **information transmission**.

In this view, the orthogonal matrix is not just a matrix; it is a way for information to move from source dimensions to target dimensions. The authors model matrix factorization as a graph on a grid, where each sparse factor defines connections between adjacent layers.

This framing gives two design goals:

- Every input dimension should be able to reach every output dimension.
- The number of trainable connections should be as small as possible, subject to orthogonality.

The butterfly structure fits these goals well. It gives dense connectivity with relatively few edges, which is exactly what the authors want from a parameter-efficient orthogonal parameterization.

## How BOFT relates to OFT

BOFT is not a completely separate method; it generalizes OFT.

If BOFT uses just one factor, it reduces to the block-diagonal version of OFT. If it uses the right butterfly configuration, it can produce a dense orthogonal matrix. In other words, BOFT gives a spectrum of designs between simple block structure and richer dense orthogonal transformations.

This is useful because it creates a smoother trade-off between regularity and expressiveness. The paper argues that this kind of structure can help generalization by imposing a useful inductive bias, rather than simply maximizing flexibility.

## Why orthogonality is still attractive

BOFT keeps one of OFT’s most appealing properties: orthogonality preserves the spectral norm of the pretrained weight matrix. In the paper’s discussion, this is one reason orthogonal finetuning can be more stable than methods like LoRA.

That does not mean larger expressiveness is always better. The paper explicitly notes that full finetuning is the most expressive option, but it often does not give the best downstream performance. The point is to find a good balance: enough flexibility to adapt, but enough structure to preserve what pretraining already learned.

## Practical details: initialization and dropout

The paper also includes some implementation choices that help BOFT behave like a standard finetuning method.

BOFT uses **identity initialization**, so the model starts exactly at the pretrained weights and only moves away as training begins. This mirrors the zero initialization style used in LoRA.

It also introduces a **multiplicative dropout** variant. Regular dropout is not a natural fit for a multiplicative orthogonal update, so the authors define a dropout scheme that randomly replaces some butterfly blocks with identity matrices during training.

## What the experiments show

The paper evaluates BOFT on a broad set of tasks, including:

- large vision transformers,
- large language models,
- text-to-image diffusion models.

The important result is not just that BOFT works, but that it works as a **generic** finetuning method. This is the first time, according to the paper, that orthogonal finetuning is applied beyond controllable text-to-image generation to a wider range of adaptation problems.

The experiments show that BOFT outperforms current state-of-the-art methods by a considerable margin in these settings, supporting the claim that it improves both parameter efficiency and generalization.

## The main takeaway

BOFT’s contribution is conceptually simple but powerful: instead of learning a huge dense orthogonal matrix directly, learn a product of structured sparse orthogonal factors arranged in a butterfly pattern.

That gives three benefits at once. It reduces trainable parameters, preserves the useful geometry of orthogonal transformations, and offers a structured inductive bias that can help downstream performance.

There is still a trade-off. BOFT introduces some extra training-time overhead because multiple factors must be multiplied during optimization. But after finetuning, the learned orthogonal matrices can be folded into the pretrained model, so there is no added inference latency.

That makes BOFT a strong candidate for practical model adaptation: it keeps the finetuning cost under control without giving up the benefits of orthogonal updates.

## What to remember

If you only remember one thing, make it this: BOFT is a way to make orthogonal finetuning scalable.

It keeps the core idea of OFT—adapt by preserving structure instead of overwriting it—but replaces the expensive dense orthogonal matrix with a butterfly factorization. The result is a more parameter-efficient method that works across vision, language, and generative modeling tasks.

For anyone trying to adapt giant models without paying giant training costs, that is a meaningful step forward.
