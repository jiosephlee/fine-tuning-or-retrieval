# Why Finetuning Giant AI Models Is So Expensive—and How BOFT Cuts the Cost

Large foundation models are impressive, but they come with a practical problem: once a model has hundreds of billions of parameters, retraining it from scratch is unrealistic for most teams. The real challenge is not just building these models, but adapting them to new tasks efficiently.

This paper focuses on that adaptation problem. It asks a simple but important question: how can we finetune a pretrained model without paying the full cost of updating all of its weights?

## The core problem: adapting without starting over

A pretrained model already knows a lot. A language model, vision transformer, or diffusion model has learned general representations that are useful across many tasks. Finetuning lets us reuse that knowledge for a new domain or objective.

But standard finetuning is expensive because every updated parameter adds memory, compute, and training cost. For very large models, updating everything can be overkill. That is why the field has turned toward **parameter-efficient finetuning** (PEFT): methods that adapt the model while changing only a small fraction of the parameters.

The paper groups the main PEFT approaches into three families. In **model finetuning**, the original architecture stays the same and only a subset of the existing weights is trained. In **adapter tuning**, extra trainable modules are inserted into the network. In **prompt tuning**, trainable prefix tokens are added to the input side instead of changing the model weights directly.

Each approach tries to reduce cost, but they make different trade-offs. Prompt tuning changes how the model is conditioned. Adapters add extra components that can affect inference structure. Model finetuning is attractive because it is simple and introduces no inference latency if done well.

## Why orthogonal finetuning is interesting

The paper builds on a more principled version of model finetuning called **Orthogonal Finetuning** (OFT). The main idea is to transform a pretrained weight matrix by multiplying it with a learnable orthogonal matrix.

Why orthogonal? Because orthogonal transformations preserve angles between vectors. In the context of neural networks, that means the relationships learned during pretraining are less likely to be destroyed during adaptation. This is a more structured alternative to using a small learning rate and hoping the model does not drift too far.

Concretely, if a pretrained linear layer uses weights $\bm{W}^0$, OFT replaces it with $\bm{R}\bm{W}^0$, where $\bm{R}$ is an orthogonal matrix learned during finetuning. This keeps the pretrained weights in place but rotates them in a controlled way.

That sounds elegant, but there is a catch: a dense orthogonal matrix of size $d \times d$ has a lot of degrees of freedom. So while OFT is principled, it can still be expensive.

## The limitation of standard OFT

To make OFT cheaper, the original approach uses a **block-diagonal** orthogonal matrix. This reduces the number of trainable parameters by splitting the dimensions into independent blocks.

The downside is that this creates a fixed sparsity pattern. Different groups of dimensions are transformed separately, which can limit expressiveness. The paper points out two issues with this:

First, the block structure may introduce an odd inductive bias, since dimensions are grouped purely by index rather than by any semantic relationship. Second, it is unclear how to choose a good sparsity pattern in the first place.

So the authors wanted something better: a way to keep orthogonal finetuning parameter-efficient without relying on rigid block structure.

## BOFT: orthogonal finetuning with butterfly factorization

Their answer is **Orthogonal Butterfly** or **BOFT**.

BOFT takes a different route to parameter efficiency. Instead of directly learning one large dense orthogonal matrix, it represents that matrix as a product of multiple sparse orthogonal matrices arranged in a **butterfly structure**. This idea is inspired by the Cooley-Tukey fast Fourier transform, where butterfly graphs enable efficient information exchange.

The intuition is nice: rather than paying for all-to-all connectivity in one shot, BOFT lets information flow through a sequence of sparse mixing steps. Over multiple factors, those sparse matrices can still produce a dense orthogonal transformation.

This matters because the final orthogonal matrix is much cheaper to parameterize. The paper shows that BOFT can use only $\mathcal{O}(d \log d)$ parameters in the butterfly case, compared with $\mathcal{O}(d^2)$ for a fully dense orthogonal matrix.

## An information transmission view

One of the paper’s main contributions is a way to think about the factorization problem as **information transmission**.

In this view, the orthogonal matrix is not just a matrix; it is a way for information to move from source dimensions to target dimensions. The authors model matrix factorization as a graph on a grid, where each sparse factor defines connections between adjacent layers.

This framing gives two design goals:

- Every input dimension should be able to reach every output dimension.
- The number of trainable connections should be as small as possible, subject to orthogonality.

The butterfly structure fits these goals well. It gives dense connectivity with relatively few edges, which is exactly what the authors want from a parameter-efficient orthogonal parameterization.

## How BOFT relates to OFT

BOFT is not a completely separate method; it generalizes OFT.

If BOFT uses just one factor, it reduces to the block-diagonal version of OFT. If it uses the right butterfly configuration, it can produce a dense orthogonal matrix. In other words, BOFT gives a spectrum of designs between simple block structure and richer dense orthogonal transformations.

This is useful because it creates a smoother trade-off between regularity and expressiveness. The paper argues that this kind of structure can help generalization by imposing a useful inductive bias, rather than simply maximizing flexibility.

## Why orthogonality is still attractive

BOFT keeps one of OFT’s most appealing properties: orthogonality preserves the spectral norm of the pretrained weight matrix. In the paper’s discussion, this is one reason orthogonal finetuning can be more stable than methods like LoRA.

That does not mean larger expressiveness is always better. The paper explicitly notes that full finetuning is the most expressive option, but it often does not give the best downstream performance. The point is to find a good balance: enough flexibility to adapt, but enough structure to preserve what pretraining already learned.

## Practical details: initialization and dropout

The paper also includes some implementation choices that help BOFT behave like a standard finetuning method.

BOFT uses **identity initialization**, so the model starts exactly at the pretrained weights and only moves away as training begins. This mirrors the zero initialization style used in LoRA.

It also introduces a **multiplicative dropout** variant. Regular dropout is not a natural fit for a multiplicative orthogonal update, so the authors define a dropout scheme that randomly replaces some butterfly blocks with identity matrices during training.

## What the experiments show

The paper evaluates BOFT on a broad set of tasks, including:

- large vision transformers,
- large language models,
- text-to-image diffusion models.

The important result is not just that BOFT works, but that it works as a **generic** finetuning method. This is the first time, according to the paper, that orthogonal finetuning is applied beyond controllable text-to-image generation to a wider range of adaptation problems.

The experiments show that BOFT outperforms current state-of-the-art methods by a considerable margin in these settings, supporting the claim that it improves both parameter efficiency and generalization.

## The main takeaway

BOFT’s contribution is conceptually simple but powerful: instead of learning a huge dense orthogonal matrix directly, learn a product of structured sparse orthogonal factors arranged in a butterfly pattern.

That gives three benefits at once. It reduces trainable parameters, preserves the useful geometry of orthogonal transformations, and offers a structured inductive bias that can help downstream performance.

There is still a trade-off. BOFT introduces some extra training-time overhead because multiple factors must be multiplied during optimization. But after finetuning, the learned orthogonal matrices can be folded into the pretrained model, so there is no added inference latency.

That makes BOFT a strong candidate for practical model adaptation: it keeps the finetuning cost under control without giving up the benefits of orthogonal updates.

## What to remember

If you only remember one thing, make it this: BOFT is a way to make orthogonal finetuning scalable.

It keeps the core idea of OFT—adapt by preserving structure instead of overwriting it—but replaces the expensive dense orthogonal matrix with a butterfly factorization. The result is a more parameter-efficient method that works across vision, language, and generative modeling tasks.

For anyone trying to adapt giant models without paying giant training costs, that is a meaningful step forward.



# Orthogonal Finetuning, Explained: Teaching AI New Tricks Without Erasing What It Learned

Large foundation models are powerful, but fine-tuning them efficiently is a constant challenge. If you change too much, you risk overwriting useful pretrained knowledge. If you change too little, the model may not adapt well to the new task. Orthogonal finetuning is a neat idea that tries to balance those two goals by changing the model in a very structured way.

The paper behind BOFT, or Orthogonal Butterfly, takes that idea further and makes it much more parameter-efficient. The core trick is to transform a pretrained layer with an orthogonal matrix. Instead of adding a new low-rank update like LoRA, orthogonal finetuning multiplies the original weights by a learned rotation-like matrix. BOFT then uses a butterfly factorization to represent that matrix with far fewer trainable parameters.

## Why rotate weights at all?

The intuition starts with geometry. In a neural network layer, neurons can be thought of as vectors in a high-dimensional space. If you apply an orthogonal transformation, you preserve angles between vectors. That matters because the paper argues that preserving these relationships helps retain the structure learned during pretraining.

In other words, orthogonal finetuning tries to adapt the model without “distorting” the geometry of the pretrained weights too much. This is different from a small learning rate, which only indirectly encourages small changes. Here, the constraint is built into the update itself.

The paper describes this for a pretrained linear layer $\bm{W}^0$ by replacing the usual forward pass with

$$
\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x},
$$

where $\bm{R}$ is a learned orthogonal matrix. Because $\bm{R}$ is orthogonal, it preserves the pairwise angles between the transformed neurons. It also preserves the spectral norm of the pretrained weight matrix, which the paper connects to stable training and better generalization.

## The problem with standard orthogonal finetuning

Orthogonal matrices sound elegant, but there is a catch: a full $d \times d$ orthogonal matrix still has a lot of degrees of freedom. So while orthogonal finetuning is principled, it can be expensive in terms of trainable parameters.

The original OFT approach reduced this cost by using a block-diagonal orthogonal matrix. That helps, but it also introduces a rigid sparsity pattern. Each block is transformed separately, which limits expressivity and imposes an arbitrary partition on the neuron dimensions.

The paper’s key question is simple: can we keep the benefits of orthogonal finetuning while making it practical at larger scale?

## A better way to build a dense orthogonal matrix

BOFT’s answer is to build a dense orthogonal matrix from a product of sparse orthogonal matrices.

This is where the paper introduces an information transmission view. Think of the matrix product as a multi-layer graph. Each sparse factor controls how information flows from one layer of nodes to the next. For the final matrix to be dense, information from every input dimension must be able to reach every output dimension through the sequence of factors.

That framing turns the problem into one of graph design: how do you connect nodes efficiently while keeping the overall transformation orthogonal?

The paper argues that the butterfly structure is a particularly good answer.

## Why butterfly structure?

Butterfly patterns are best known from the Cooley-Tukey fast Fourier transform. They are designed to move information across a system efficiently using only local sparse interactions. That same structure also appears in networking and other fast linear transforms.

BOFT borrows that idea and uses a butterfly factorization to represent orthogonal matrices. The payoff is large: instead of needing $\mathcal{O}(d^2)$ parameters for a dense orthogonal matrix, BOFT can use only $\mathcal{O}(d \log d)$ parameters in the butterfly case.

More generally, BOFT represents the orthogonal matrix as a product of several sparse orthogonal butterfly components. Each component is structured so that orthogonality is maintained, and the product can still become dense. This gives the model enough flexibility to adapt, while keeping the parameter count far below that of full orthogonal finetuning.

## How BOFT relates to OFT

BOFT is not a completely separate method from OFT. In fact, the paper shows that OFT appears as a special case of BOFT.

If you use only one butterfly component, BOFT reduces to the block-diagonal OFT-style structure. If you use the full butterfly factorization, BOFT can produce dense orthogonal matrices with much better parameter efficiency. So BOFT can be seen as a generalized orthogonal finetuning framework, with OFT sitting inside it.

That matters because it gives the method a continuum of trade-offs between simplicity, parameter count, and expressivity.

## What makes BOFT appealing in practice?

The paper highlights a few practical properties beyond parameter efficiency.

First, BOFT uses identity initialization. That means finetuning starts from the exact pretrained model, which is standard practice in parameter-efficient methods.

Second, it introduces a multiplicative dropout scheme tailored to the structure of BOFT. Standard dropout does not naturally fit multiplicative orthogonal updates, so the paper proposes randomly replacing some butterfly components or sub-blocks with identity matrices during training.

Third, BOFT preserves the spectral norm of the pretrained weights because the update is orthogonal. This aligns with the paper’s argument that orthogonal finetuning can offer more stable optimization than methods that freely add new weights.

## Does the structure actually help expressivity?

A natural worry is that adding structure might make the model too rigid. The paper addresses this by studying how well BOFT can approximate a random dense orthogonal matrix.

The result is that BOFT is more parameter-efficient than OFT for similar approximation quality, especially when using smaller block sizes and more butterfly stages. The paper also proves that BOFT is more expressive than OFT with the same block size. So the butterfly factorization is not just cheaper; it is also a stronger way to cover useful transformations within the orthogonal family.

At the same time, the authors are careful not to overclaim. They note that more expressivity is not always better in finetuning. The goal is not to represent every possible transformation, but to find a good balance between flexibility and regularity.

## What does this mean for downstream tasks?

The paper’s broader contribution is that orthogonal finetuning is not just for one niche setting. BOFT is evaluated on large vision transformers, large language models, and text-to-image diffusion models across downstream tasks. The authors report that BOFT outperforms current state-of-the-art methods by a considerable margin in their experiments.

That is important because it suggests the orthogonal finetuning idea is more general than the earlier OFT work, which had mainly been shown for controllable text-to-image generation.

## The big picture

BOFT is really about a simple but powerful principle: if you want to adapt a pretrained model without destroying what it already knows, constrain the update to preserve useful geometry. Orthogonal transformations do that by preserving angles and spectral properties. But to make the approach practical, you need a parameterization that is much cheaper than a full dense matrix.

The butterfly factorization is the paper’s answer to that challenge. It gives BOFT a way to build dense orthogonal updates from sparse pieces, with a strong inductive bias and a much smaller parameter budget.

There is still a trade-off. The paper notes that training runtime is slightly higher because the orthogonal matrix is composed of multiple factors. But at inference time, the learned update can be merged into the pretrained model, so there is no extra latency.

In short, BOFT shows that you do not always need to rewrite a model to teach it something new. Sometimes, a careful rotation in weight space is enough.



# From FFT to Foundation Models: How Butterfly Math Makes AI Finetuning Efficient

Finetuning large foundation models is attractive because it lets us reuse pretrained knowledge instead of training from scratch. But even when we only want to adapt a model to a new task, the number of parameters can still be very large. This paper tackles that problem through a surprisingly elegant idea: use butterfly factorization, a structure inspired by the fast Fourier transform, to build dense orthogonal updates from a sequence of sparse ones.

The result is a new finetuning method called Orthogonal Butterfly, or BOFT. It keeps the key benefits of orthogonal finetuning while making it much more parameter-efficient.

## Why orthogonal finetuning?

The starting point is Orthogonal Finetuning, or OFT. Instead of adding a low-rank update like LoRA, OFT multiplies a pretrained weight matrix by a learnable orthogonal matrix. This matters because orthogonal transformations preserve pairwise angles between neurons, which helps preserve pretrained structure and tends to improve stability and generalization.

If a pretrained linear layer uses weight matrix $W^0$, OFT changes the forward pass from

$$
z = (W^0)^\top x
$$

to

$$
z = (RW^0)^\top x,
$$

where $R$ is orthogonal.

The problem is that a full $d \times d$ orthogonal matrix still has a lot of parameters, roughly $\mathcal{O}(d^2)$. OFT reduces this by using a block-diagonal orthogonal matrix, but that comes with a cost: the model can only mix information within blocks, not across the full space. That makes the structure efficient, but also restrictive.

## The key question: can we get dense and efficient?

The paper asks a simple but important question: can we construct a dense orthogonal matrix without paying the full quadratic parameter cost?

The answer is yes, by factoring the matrix into a product of sparse orthogonal matrices. Instead of storing one dense matrix, BOFT stores several sparse ones and multiplies them together. This trades extra computation during training for a much smaller number of trainable parameters.

To reason about this more cleanly, the paper introduces an information transmission view. Think of each matrix factor as a layer in a graph. A non-zero entry means information can flow from one node to another. A dense final matrix means every input dimension can eventually influence every output dimension. So the goal becomes: design sparse factorization patterns that still allow complete information flow.

## Why butterfly structure?

This is where the butterfly structure comes in.

The butterfly pattern is best known from the Cooley-Tukey fast Fourier transform. In FFT, global mixing is achieved through a sequence of local pairwise operations arranged in a recursive, layered pattern. That same idea is useful here: a butterfly network can connect all inputs to all outputs using only $\mathcal{O}(d \log d)$ edges.

That is the core insight behind BOFT. Instead of using a block-diagonal pattern, BOFT uses a butterfly factorization to compose a dense orthogonal matrix from multiple sparse orthogonal components.

In practical terms, this gives a much better parameter count. A full orthogonal matrix needs $\mathcal{O}(d^2)$ parameters. BOFT, with the butterfly structure, can get down to $\mathcal{O}(d \log d)$.

## How BOFT is built

BOFT parameterizes the orthogonal update as a product of butterfly components. Each component is sparse, but the product can become dense.

The paper defines butterfly factors recursively, and then ensures orthogonality by parameterizing the smallest blocks with orthogonal transformations, such as Cayley parameterization. The important point is that every factor remains orthogonal, so the product is orthogonal too.

BOFT also generalizes the block-diagonal OFT setup. In fact, OFT becomes a special case of BOFT when the butterfly depth is reduced. This makes BOFT a more general orthogonal finetuning framework, not just a separate trick.

## Why this helps in finetuning

The paper argues that BOFT gives a better balance between expressivity and regularity.

A full orthogonal matrix is very expressive, but too unconstrained. A block-diagonal matrix is regular and efficient, but too limited. Butterfly structure sits in between. It is structured enough to reduce parameters and impose a useful inductive bias, but flexible enough to mix information across the whole layer.

This matters because many classic linear transforms, such as the Fourier transform, discrete cosine transform, and Hadamard transform, have butterfly-like structure. So BOFT is not just compressing the update; it is biasing the update toward a family of transformations that has already proven useful in signal processing and numerical computation.

## A few extra details

The paper adds two practical pieces that help BOFT work as a finetuning method.

First, BOFT uses identity initialization, so the finetuned model starts exactly at the pretrained model. This is a common and useful property in parameter-efficient finetuning.

Second, the authors introduce a multiplicative dropout scheme for BOFT, since standard dropout does not directly fit a multiplicative orthogonal update. Their version randomly replaces selected butterfly components or blocks with identity matrices during training.

## What the experiments show

The paper evaluates BOFT on a broad set of tasks, including large vision transformers, large language models, and text-to-image diffusion models. The authors report that BOFT outperforms current state-of-the-art methods by a substantial margin in these settings.

That is an important result because orthogonal finetuning had previously been shown mainly in the context of controllable text-to-image generation. This paper argues that the method is much more general than that, and the experiments support that claim.

The paper also shows that BOFT can approximate dense orthogonal matrices more efficiently than the original OFT setup, especially when using smaller blocks and deeper butterfly factorizations.

## The big takeaway

The main idea in this paper is simple to state but powerful in practice:

Instead of learning one dense orthogonal matrix directly, learn a product of sparse orthogonal matrices arranged in a butterfly pattern.

That move preserves the benefits of orthogonal finetuning while dramatically reducing parameter count. It also creates a cleaner connection between finetuning and structured linear algebra, borrowing a classic idea from FFT to make modern foundation models easier to adapt.

BOFT does introduce some extra training-time overhead because the factors must be multiplied repeatedly during optimization. But after finetuning, the learned orthogonal update can be folded into the pretrained weights, so there is no added inference latency.

In short, this paper shows that a carefully designed sparse structure can give us much of the power of dense orthogonal finetuning, at a fraction of the parameter cost.



# An Information Highway for Neural Networks: BOFT’s Clever View of Matrix Updates

Fine-tuning large foundation models is expensive if you update everything, so the field has been looking for ways to adapt models with only a small number of trainable parameters. One appealing approach is orthogonal finetuning, or OFT, which updates a pretrained weight matrix by multiplying it with a learnable orthogonal matrix. The key idea is that orthogonal transformations preserve pairwise angles between neurons, which helps retain pretrained knowledge.

The downside is that a dense orthogonal matrix is expensive to learn: it has too many parameters. The original OFT paper reduced that cost with a block-diagonal structure, but that comes with a strong limitation. The matrix is no longer fully dense, and different blocks are transformed independently. That makes the structure efficient, but also somewhat rigid.

This paper takes a different route. Instead of thinking about the problem purely as matrix algebra, it asks a more practical question: how can information move through a matrix?

## Thinking of a Matrix as a Network

The authors reframe orthogonal matrix factorization as an information transmission problem. Imagine a matrix as a directed network connecting input nodes to output nodes. If an entry in the matrix is non-zero, information can flow along that connection. If it is zero, that route is blocked.

Now suppose we do not build the final matrix all at once. Instead, we factor it into a product of several sparse matrices. In the network view, each factor becomes one layer of routing. Information moves from one level of nodes to the next, step by step.

This perspective is useful because it turns the design problem into a graph problem:

- Every input node should be able to reach every output node.
- The number of trainable connections should be as small as possible.
- The factors still need to satisfy orthogonality constraints.

This is a much more concrete way to reason about sparsity patterns than treating them as arbitrary matrix shapes.

## Why Block-Diagonal Structure Is Not Enough

The original OFT uses block-diagonal orthogonal matrices to save parameters. In the network interpretation, that is like splitting the nodes into separate groups and only allowing communication within each group.

That saves memory, but it also creates a hard barrier: information cannot easily move across blocks. So even though the matrix is orthogonal, its connectivity is limited. The paper argues that this kind of sparsity is restrictive and introduces an awkward inductive bias, because the grouping is based only on index positions rather than any meaningful structure in the data.

The problem is not just efficiency. It is expressiveness. A block-diagonal orthogonal matrix cannot approximate the kinds of dense linear transforms that many models would benefit from.

## Butterfly Structure as an Efficient Routing Scheme

To get around this, the authors borrow an idea from the Cooley-Tukey fast Fourier transform: the butterfly structure. In FFT, the butterfly graph is a classic way to move information efficiently across many nodes using only a small number of sparse operations.

That makes it a natural fit for this setting.

Instead of using one sparse block-diagonal matrix, BOFT constructs the orthogonal update as a product of several sparse orthogonal factors arranged in a butterfly pattern. Each factor is still sparse, but together they form a dense transformation. In graph terms, the butterfly topology provides a low-cost way for every source node to reach every destination node.

This matters because it gives a better tradeoff between two competing goals:

- **Regularity**, meaning the update stays close to the pretrained model.
- **Expressivity**, meaning the update can still represent rich transformations.

BOFT uses the butterfly structure to move smoothly between those two extremes.

## Why This Helps Parameter Efficiency

The benefit of factorizing a dense orthogonal matrix is that each factor only needs a small number of non-zero entries. The paper shows that with butterfly factorization, a dense $d \times d$ orthogonal matrix can be built from $\mathcal{O}(\log d)$ sparse matrices, each with $\mathcal{O}(d)$ non-zero entries. That leads to $\mathcal{O}(d \log d)$ parameters, which is much smaller than the $\mathcal{O}(d^2)$ parameters needed for a full dense orthogonal matrix.

The authors also point out that BOFT subsumes the block-diagonal OFT as a special case. So BOFT is not just a new method with a different shape; it is a more general orthogonal finetuning framework.

## More Expressive Than Block Diagonal

A central claim in the paper is that the butterfly structure is more expressive than block-diagonal structure at the same block size. Intuitively, this makes sense in the network picture.

A block-diagonal matrix isolates groups. A butterfly factorization, by contrast, repeatedly mixes information across groups through multiple layers of sparse routing. That repeated mixing is what makes dense connectivity possible.

The paper backs this up with both theory and a simulation where BOFT approximates random dense orthogonal matrices more effectively than block-diagonal OFT under comparable parameter budgets. Smaller block sizes and more butterfly stages generally improve parameter efficiency.

The key point is that sparsity does not have to mean isolation. With the right structure, sparse factors can still generate rich global interactions.

## Why This Perspective Is Useful

The most interesting contribution of the paper is not just the butterfly parameterization itself, but the way the authors arrived at it. By treating matrix factorization as information routing, they turn a difficult algebraic design problem into a network design problem.

That gives them a useful design principle: choose sparse structures that allow efficient communication across the whole matrix, not just within local blocks.

In practice, this leads to a few advantages:

- Better parameter efficiency than full orthogonal finetuning.
- More expressivity than block-diagonal orthogonal updates.
- No additional inference latency, since the learned orthogonal matrices can be merged into the pretrained weights after finetuning.
- A general framework that works across vision, language, and diffusion models.

## Takeaway

BOFT’s main insight is that a learnable orthogonal matrix does not need to be dense in its parameterization to be dense in effect. If you organize the update as a carefully designed information network, sparse factors can cooperate to produce a powerful global transformation.

That shift in viewpoint is the real contribution. It turns orthogonal finetuning from a question of “how do we store a large matrix cheaply?” into “how do we route information efficiently?” And once you ask that question, the butterfly structure becomes a very natural answer.



# BOFT vs. LoRA: Two Different Philosophies for Lightweight AI Adaptation

Large foundation models are powerful, but adapting them to new tasks is expensive if you retrain everything from scratch. That is why parameter-efficient finetuning has become such an important area: instead of updating all model weights, we change only a small subset of parameters or add a small number of new ones.

Two notable approaches take very different views of what “lightweight adaptation” should mean. LoRA adds a compact low-rank update to the pretrained weights. BOFT, the method proposed in the paper we are discussing, instead learns an orthogonal transformation that rotates the pretrained weights while preserving their geometry. These are both efficient, but they reflect different philosophies.

## Two ways to adapt a pretrained model

LoRA works by adding a low-rank matrix to a frozen weight matrix. In simple terms, it says: keep the original weights, and learn a small correction that lives in a restricted subspace. This is attractive because the new parameters are few, and the update is easy to apply.

BOFT takes a multiplicative approach instead. Rather than adding a new matrix, it left-multiplies the pretrained weight matrix by a learnable orthogonal matrix. If the original layer is represented by $\bm{W}^0$, BOFT changes it to $\bm{R}\bm{W}^0$, where $\bm{R}$ is orthogonal. This matters because orthogonal transformations preserve angles between vectors. In the paper’s framing, that helps preserve the relational structure learned during pretraining.

So the contrast is not just architectural. It is conceptual:

- **LoRA:** learn a compact additive correction.
- **BOFT:** learn a structured multiplicative transformation that keeps the model’s geometry intact.

## Why orthogonal updates are interesting

Orthogonal finetuning comes from the idea that the pretrained model already contains useful knowledge, and adaptation should disturb it as little as possible. A small learning rate can do this in an ad hoc way, but orthogonal transformations offer a more principled constraint.

The key property is that orthogonal matrices preserve inner products, so they preserve pairwise angles between neurons. The paper argues that this helps retain the semantic structure encoded in the pretrained weights. Another important consequence is spectral stability: if $\bm{W}^0$ is decomposed as $\bm{U}\bm{\Sigma}\bm{V}^\top$, then multiplying by an orthogonal matrix on the left does not change the singular values in a way that harms the spectral norm of the pretrained weight matrix. The paper connects this kind of preservation to training stability and generalization.

This gives BOFT a different bias from LoRA. Instead of saying “learn a small corrective direction,” BOFT says “learn a structured transformation that stays close to the geometry of the original model.”

## The parameter-efficiency problem

There is a catch, of course. A full dense orthogonal matrix has $\mathcal{O}(d^2)$ parameters, which can still be a lot. The original OFT method addressed this using a block-diagonal structure, but that introduces its own limitation: the transformation is applied independently within fixed blocks. The paper points out that this sparsity pattern can be restrictive and may not capture the kinds of transforms we would like.

BOFT improves parameter-efficiency by factorizing a dense orthogonal matrix into a product of sparse orthogonal matrices with a butterfly structure. This reduces the number of effective parameters to $\mathcal{O}(d\log d)$ in the butterfly setting.

The important point here is that BOFT is not just “smaller OFT.” It is a different parameterization that keeps the orthogonal constraint while using a more expressive sparse structure.

## Additive low-rank vs. multiplicative orthogonal

The LoRA and BOFT updates behave differently in practice because they modify the pretrained weights in different ways.

LoRA’s additive update changes the weight matrix by adding a learned low-rank term. This is flexible and simple, and it has become popular because it works well in many settings.

BOFT’s multiplicative update changes the basis of the pretrained layer itself. It does not add a new direction to the model in the same way; instead, it transforms existing directions while preserving orthogonality.

That difference leads to distinct trade-offs:

- **LoRA** is naturally compact and widely used.
- **BOFT** is designed to better preserve the pretrained geometry.
- **LoRA** is easy to interpret as a learned residual.
- **BOFT** is better viewed as a structured reorientation of the layer.

If you care most about learning a small correction, LoRA is a natural fit. If you care most about preserving the structure of the pretrained representation while still adapting the model, BOFT offers a compelling alternative.

## Why butterfly structure matters

The paper’s main technical contribution is the use of butterfly factorization to make orthogonal finetuning parameter-efficient. Butterfly structures are inspired by the Cooley-Tukey fast Fourier transform, where information is exchanged efficiently through a layered pattern of sparse connections.

The paper reinterprets the problem of building a dense orthogonal matrix as an information transmission problem. In that view, the goal is to connect every input node to every output node using as few trainable edges as possible, while still respecting orthogonality. Butterfly graphs provide an efficient way to do that.

This is not just an implementation trick. It gives BOFT a structured inductive bias. Because butterfly patterns can recover many classic fast linear transforms, the authors argue that this structure is a reasonable prior for learning, especially when we want both expressiveness and regularity.

## Stability and expressiveness are both part of the story

One reason orthogonal updates are attractive is stability. Since the update is orthogonal, it preserves certain geometric properties of the weight matrix. That can make training more stable than methods that modify the weights more freely.

But stability alone is not enough. The update also needs to be expressive enough to solve downstream tasks. The paper explores this trade-off and shows that BOFT is more expressive than the block-diagonal OFT with the same block size. In other words, the butterfly parameterization gives you a richer family of orthogonal transformations without giving up the parameter savings.

The paper also emphasizes that more expressiveness is not always better in finetuning. Fully unconstrained finetuning is maximally expressive, but it often performs worse because it loses the beneficial structure of the pretrained model. BOFT aims for the middle ground: enough flexibility to adapt, but enough structure to generalize well.

## When preserving geometry may be more useful than adding new weights

So when should you think about BOFT instead of LoRA?

The paper suggests BOFT is especially appealing when you want to adapt a pretrained model while preserving its internal geometry and maintaining strong stability. This can be useful in settings where the pretrained representation is already valuable and the task shift is not so large that you need a completely new subspace of parameters.

LoRA, on the other hand, is a strong choice when a simple additive low-rank correction is enough and you want a very practical, widely adopted PEFT method.

A good way to summarize the difference is this:

- Use **LoRA** when you want a compact residual update.
- Use **BOFT** when you want a compact orthogonal transformation that respects the pretrained model’s structure.

## What the paper shows in practice

The authors evaluate BOFT on large vision transformers, large language models, and text-to-image diffusion models. Their claim is that BOFT outperforms current state-of-the-art methods by a considerable margin in the tested adaptation settings, showing that orthogonal finetuning can be a general-purpose finetuning strategy rather than a niche method for one domain.

The paper also notes that BOFT can be merged into the pretrained model after finetuning, so it does not add inference latency. The main overhead is during training, because the final orthogonal matrix is built from multiple factors.

## Final takeaway

LoRA and BOFT are both parameter-efficient, but they optimize for different values.

LoRA compresses adaptation into a low-rank additive correction. BOFT compresses it into a structured orthogonal transformation. If LoRA is about learning a small update, BOFT is about learning a small but geometry-preserving reorientation.

That distinction matters. For some downstream tasks, preserving the pretrained model’s relational structure may be more valuable than simply adding a compact set of new weights. BOFT is a strong example of that idea, and the paper makes a convincing case that orthogonal structure is worth taking seriously as a general finetuning principle.



# One Finetuning Method for Vision, Language, and Diffusion? What BOFT’s Results Suggest

Finetuning large foundation models is now a central engineering problem. Training a model from scratch is expensive, but adapting a pretrained model to a new task is much more practical. The challenge is doing that without giving up too much of the pretrained model’s knowledge, and without adding a large number of new parameters.

The BOFT paper takes a fairly elegant route: instead of changing the model with a low-rank update like LoRA, it uses an orthogonal transformation with a butterfly structure. That gives a parameter-efficient way to finetune while preserving useful geometric properties of the pretrained weights.

What makes the paper especially interesting is not just the method itself, but where it was tested. BOFT was evaluated across three very different model families: large vision transformers, large language models, and text-to-image diffusion models. That breadth matters, because it suggests BOFT is not just a technique tuned to one architecture or one task family. It may be a more general finetuning strategy.

## Why cross-domain evaluation matters

A lot of parameter-efficient finetuning methods look strong in one setting and much less compelling in another. That is not surprising: the structure that helps in language modeling, for example, may not transfer cleanly to vision or generative modeling.

BOFT is notable because the paper does not stop at the domain where orthogonal finetuning was originally introduced for controllable text-to-image generation. The authors explicitly extend the evaluation to broader adaptation problems, including computer vision and natural language processing. In other words, they are testing whether orthogonal finetuning is a niche idea or a more general way to adapt pretrained models.

According to the paper, BOFT performs strongly across these settings and outperforms current state-of-the-art methods by a considerable margin. That result is important because it supports the paper’s main claim: orthogonal finetuning can be a generic finetuning framework, not just a specialized trick for one model type.

## What BOFT is actually changing

BOFT stands for Orthogonal Butterfly. The core idea is to finetune a pretrained linear layer by multiplying its weights with a learnable orthogonal matrix. Orthogonal updates are attractive because they preserve pairwise angles between neurons and keep the spectral norm of the pretrained weights unchanged, which the paper links to stable training and better generalization.

The problem with earlier Orthogonal Finetuning (OFT) is that a dense orthogonal matrix is expensive to learn. BOFT fixes that by factorizing the orthogonal transformation into a product of sparse butterfly components. This reduces the number of trainable parameters substantially while still allowing the final transformation to be dense.

So BOFT is trying to hit a useful middle ground:

- more structured and stable than a fully free finetuning update,
- more expressive than a simple block-diagonal orthogonal parameterization,
- and much more parameter-efficient than learning a full dense orthogonal matrix.

That combination is what makes the experimental results across different domains especially compelling.

## The three application areas the paper covers

The paper evaluates BOFT on:

### Vision transformers
Vision transformers are a good test case because they are large, heavily parameterized models where efficient adaptation matters. The paper reports that BOFT works well here, showing that the method is not limited to language-style sequence modeling.

### Large language models
Language models are another strong test of generality. Many PEFT methods were originally popularized in NLP, so a method that works here still needs to compete with established baselines. The paper reports that BOFT performs strongly in this setting as well.

### Text-to-image diffusion models
This is the domain where orthogonal finetuning originally showed promise. BOFT keeps that strength, while improving parameter efficiency through butterfly factorization. Importantly, the method does not sacrifice the practical benefit that motivated OFT in the first place.

Taken together, these experiments suggest that the method’s value is not tied to one representation type. The same finetuning principle seems to transfer across discriminative and generative models, which is a strong signal of general utility.

## Why this is more than a parameter-count story

It is easy to reduce BOFT to a “fewer parameters” result, but that would miss the point. The paper’s broader claim is that the structure of the update matters.

BOFT uses a butterfly factorization to build a dense orthogonal matrix from sparse components. This gives it an inductive bias that is smoother than a block-diagonal scheme, while still being constrained enough to avoid overfitting in the way a fully unconstrained update can.

That balance seems to matter in the experiments. The method is not just smaller; it is designed to preserve useful geometry while remaining flexible enough for downstream adaptation. The fact that this works across vision, language, and diffusion tasks suggests that the bias is useful in a fairly broad range of settings.

## What the results imply for practical finetuning

The paper’s cross-domain results point to a simple takeaway: orthogonal finetuning may be a viable general-purpose PEFT strategy.

That does not mean BOFT replaces every other method. The paper also notes a trade-off: because the final orthogonal matrix is composed of multiple factors, training runtime is slightly higher than OFT. But this is a training-time cost, not an inference-time cost. After finetuning, the learned orthogonal matrices can be multiplied into the pretrained model, so BOFT adds no extra inference latency.

For practitioners, that makes BOFT attractive in cases where:

- preserving pretrained structure is important,
- inference overhead is undesirable,
- and a parameter-efficient method needs to transfer across model families.

## The bigger message

The most interesting part of BOFT’s experimental story is the pattern, not any single benchmark. A method that works on vision transformers, large language models, and text-to-image diffusion systems is saying something broader about finetuning: that the right structured update can be reusable across very different kinds of foundation models.

That is what makes BOFT stand out. It is not just a new parameterization. It is evidence that orthogonal finetuning, when made efficient with butterfly factorization, can function as a general adaptation tool rather than a domain-specific workaround.
