\title{Stack Exchange of the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

### What is the exact form of the unified RoPE interpolation equation (Eq. 2) and how do \(\lambda(\beta)^i\) relate to the extension ratio \(s\)?
Question:
In Eq. 2 the authors write:

```
[cos(n/λ(β)^0), sin(n/λ(β)^0), cos(n/λ(β)^1), … , sin(n/λ(β)^{d/2-1})]
```
They also define \(β = θ^{2/d}\). I am confused about how \(λ\), \(β\), and \(s\) interact mathematically. Is \(λ\) simply set equal to \(s\), or does it vary per dimension according to some rule? How would one compute \(λ(β)^i\) for a given target window length?
Answer:
The rotary‑position embedding used in most recent LLMs can be written compactly in terms of a single “base’’ number  

$$
\beta=\theta^{\,2/d},
$$

where \(d\) is the hidden size that participates in RoPE and  
the pretrained base‑value is usually \(\theta =10\,000.\)

For a token at position \(n\) the original angular frequency of the
\(i^\text{th}\) RoPE pair (\(i=0,\dots , d/2-1\)) is  

$$
\phi_{i}(n)=\frac{n}{\beta^{\,i}}\qquad
(\text{i.e.\ }   n\,\theta^{-\,2 i/d}= n/\!\bigl(\theta^{\,2/d}\bigr)^{ i}). 
$$
(tag A)

When we want to use the model beyond its trained context length,
the angles have to be **scaled** so that an index larger than the old
maximum still produces a meaningful rotation.  
All existing methods achieve this by multiplying every denominator in
(A) by a *rescaling factor*.  
If we denote those factors collectively by a vector  

$$
{\boldsymbol{\lambda}}=(\lambda _0,\dots ,\lambda _{d/2-1}),
\qquad     \lambda _i>0,
$$

the intervening expression becomes  

$$
E_{\text {RoPE}}^\text{new}(n)
=
[\;
    \cos\tfrac{n}{\,(\lambda _0\,\beta )},
    \sin\tfrac{n}{\,(\lambda _0\,\beta )},
    \cos\tfrac{n}{\,(\lambda _1\,\beta )},
    \sin\tfrac{n}{\,(\lambda _1\,\beta )},
    \dots ,
    \sin\tfrac{n}{\,(\lambda _{{d}/{2}-1}\,\beta )}
]\!.
$$
(tag B)

In the manuscript this compact notation was printed as  

``` 
[$[\,\cos\bigl(n/\lambda(\beta)^0\bigr),\
   \sin\bigl(n/\lambda(\beta)^0\bigr),\
   …,\
   \sin\bigl(n/\lambda(\beta)^{d/2-1}\bigr)]$
``` 

which should be read exactly as **Eq.​ (B)** – “/, ” divides \(n\)
by an *effective* base value equal to $\bigl(\lambda_{i}\bigr)\,\beta$
raised implicitly to power \(i.\)

---

### How does ${\boldsymbol{\lambda}}$ relate to the extension ratio \(s?\)

The quantity  

``` 
$s = L'/L                                    $(extension ratio)
``` 

is a *global* description of how far we want to stretch the context.
What happens at the level of individual dimensions depends on which
positional‑interpolation scheme one adopts:

| scheme | definition of ${\boldsymbol{\lambda}}$ | intuition |
|--------|-------------------------------------------|-----------|
| **Linear PI** | \( \displaystyle  \forall i:\;\;\boxed{\;\;   \lambda_i=s   }\) | All frequencies are compressed equally; every angle becomes $n/(s\,\beta)$. |
| **NTK‑based** | \( \displaystyle  \boxed{\;\;\lambda_i=s^{\,p(i)} }\) with an increasing exponent \(p(i)\in[0,1]\) | Low‑frequency dimensions (\(i~large)\) are scaled more aggressively than high‑frequency ones; this spreads out nearby positions without destroying long‑range information. |
| **YaRN** | Three groups are formed; for group g one fixes a constant $c_g∈[1,s]$. Hence $\square\square\square\square\square≈c_g$. | Human‑chosen piecewise constants give extrapolation for very high frequencies ($c_g≈１)$, linear PI for very low ones ($c_g≈ｓ)$ and NTK‑style scaling for those in‑between. |
| **LongRoPE** (search‑based) | Each entry **is free**, constrained only by <em>monotonicity</em> and <em>bounds</em>.<br>*Monotonicity*: $1≤λ_0≤λ_1≤⋯≤λ_{d/2-1}≤s$.<br>*Bounds*: $1≤λ_i≤s$. |

In practice one lets the optimizer choose suitable values subject
to these constraints.
