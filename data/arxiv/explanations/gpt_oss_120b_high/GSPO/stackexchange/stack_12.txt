\title{Stack Exchange of the Paper: "Group Sequence Policy Optimization"}

### How should GSPO be adapted for multi‑turn RL where rewards may be assigned after each turn rather than only at episode end?
Question:
GSPO-token is introduced as a way to adjust advantages per token, but multi‑turn conversations often have turn‑level feedback (e.g., after each system response). Would it make sense to compute separate advantages per turn while still using a sequence‑level importance ratio? How would one correctly formulate such an objective without breaking the theoretical justification provided for Eq.~(7)?

**Answer**

In GSPO the only place where off‑policy correction appears is the *sequence‑level* importance ratio  

$$
s_i(\theta)=
   \Bigl(
      \tfrac{\pi_{\theta}(y_i\,|\,x)}
            {\pi_{\theta_{\text{old}}}(y_i\,|\,x)}
   \Bigr)^{\,1/|y_i|},
$$  
(9)

which is multiplied by a single scalar advantage $\widehat A_i$ that comes from the group‑wise normalisation of the total reward $r(x,y_i)$.  
Because $s_i(\theta)$ already measures how far the *entire* trajectory generated by the old policy deviates from the new policy, any change in how we **assign** the return does not affect the correctness of the importance weight: the expectation  

$$
\E_{y\,∼\,π_{\theta_{\text{old}}}}\!\Bigl[s(y;\θ)\,\widehat R(y)\Bigr]
   = 
\E_{y\,∼\,π_\θ}\!\bigl[\widehat R(y)\bigr]
$$  

holds as long as $\widehat R(y)$ is an unbiased estimate of the return under the target policy.  
Consequently we can keep $s_i(\θ)$ unchanged and only modify the *advantage* term so that it reflects that a multi‑turn dialogue receives intermediate feedback after every system turn.

---

### Turning a conversation into “sub‑episodes”

Let a sampled rollout be written as a concatenation of turns  

$$
y_i = u^{(1)}_i\,∥\,u^{(2)}_i\,∥\,⋯ ∥\,u^{(K)}_i,
$$  

where $u^{(k)}_i$ are the token sequences produced in the $k$‑th system response (the user utterances can be treated analogously or omitted if they are fixed).  
Assume that after each system response we obtain a scalar feedback  
$r^{(k)}(x,y_i)\in[0,1]$; e.g., a quality score returned by a verifier,
or a human rating collected online.

For every turn we can construct a **group‑relative** advantage exactly as in
the original GSPO definition but *restricted* to that turn:

$$
\widehat A^{(k)}_i =
   \frac{
          r^{(k)}(x,y_i)
          -
          \operatorname{mean}_{j=1}^{G}
                \bigl(r^{(k)}(x,y_j)\bigr)
        }{
          \operatorname{std}_{j=1}^{G}
                \bigl(r^{(k)}(x,y_j)\bigr)
        } .
$$  
(15)

The mean and standard deviation are taken over all $G$ responses generated
for the same query $x$, exactly as in Eq.(8).  This step gives us an
advantage that is zero‑mean and unit‑variance **per‑turn**, which helps keep
the gradient variance low without any extra value model.

---

### Plugging per‑turn advantages into GSPO

The loss function now becomes

$$
\mathcal J_{\text{multi‐turn}}(\θ)=
\E_{\substack{x∼𝒟\\
            {y_1,…,y_G}∼π_{\θ_{\text{old}}}(.|x)}} 
   \Biggl[
   \frac1G 
   ∑_{i=1}^{G}
   \frac1{|y_i|}
   ∑_{t=1}^{|y_i|}
   \min⟨
        s_i(\θ)\,\widehat A^{({turn(t)})}_i,
        {\rm clip}\!\bigl(s_i(\θ),1-\varepsilon,1+\varepsilon\bigr)
        • $\widehat A^{({turn(t)})}_i$
      ⟩
   ⟩ .
   $$  
$(16)$

where ``turn(t)’’ tells us which dialogue turn token $t$ belongs to.
Because  

$$
s_{i,t}(\θ)=
   {\rm sg}\!\bigl[s_i(\θ)\bigr]\,
   \frac{\π_\θ(y_{i,t}|x,y_<t)}
        {{\rm sg}\!\bigl[\π_\θ(y_{i,t}|x,y_<t)\bigr]}
   = s_i(\θ),
$$  

the loss above is exactly the **GSPO‑token** objective (Eq.(11)) once we set
the token‑wise advantages to their corresponding turn‑wise values.
Hence no additional gradient paths are introduced—the stop‑gradient operator guarantees that only $s_i(\θ)$ appears in the weight,
while the per‑turn advantages simply re‑scale those gradients.
All derivations presented in §4.2 remain valid because they rely only on
the identity  

$$
∇_\θ s_i(\θ)
     = s_i(\θ)\,\frac1{|y_i|}
       ∑_t ∇_\θ log π_\θ(y_{i,t}|x,y_<t),
$$  

which holds irrespective of how many different scalars multiply it later on.

---

### Why this does not break Eq.(7)

Equation (7) is an instance of an *off‑policy* policy‐gradient estimator where
the **weight** equals an unbiased estimator of  
$dP_\θ/dP_{\θ_{\text{old}}}$.
Changing from a single global advantage to a piecewise constant one merely
changes the *baseline* used for variance reduction – baselines do not affect
the expectation under either distribution.
Formally,

$$
\E_{\π_{\θ_{\text{old}}}}\!\Bigl[s(y;\θ)(R(y)-b(y))\Bigr]
 = 
\E_{\π_\θ}\!\Bigl[R(y)-b(y)\Bigr],
``` 

for any function $b(y)$; here we let  

$b(y)=0,\;
 R(y)=∑_k r^{(k)}(x,y)$,

and replace “$R(y)-b(y)$’’ by our normalised per‑turn term.
Therefore Eq.(7)’s theoretical guarantee – namely that clipping yields an unbiased estimator up to first order – stays intact.

---

### Practical considerations

* **Turn definition** – In practice one treats every system utterance as a turn;
  if user messages are stochastic they can be incorporated into the same segment because they share the same conditioning context.
* **Reward aggregation** – If one prefers a discounted return,
  multiply each partial reward by a discount factor before computing (15);
  scaling does not alter the zero‑mean/unit‑variance normalisation.
* **Clipping range** – Since $s_i(\θ)$ has unchanged magnitude,
  the clipping bounds used for plain GSPO (e.g., $3\times10^{-4},4\times10^{-4}$)
  are still appropriate.
* **Implementation** – From code perspective one merely adds a mask that maps
  tokens → their turn index, looks up the corresponding pre‑computed advantage vector,
  and uses the existing GSPO‐token loop. No extra likelihood recomputation
  is needed because all tokens share exactly the same $s_i(\θ)$.

---

### Summary

To handle multi‐turn reinforcement learning where feedback arrives after each system response:

1. Keep the **sequence‑level** importance ratio $s_i(\θ)$ exactly as in GSPO (Eq.(9)).
2. Compute **per‐turn** group‐relative advantages (Eq.(15)) using the reward that becomes available at that point.
3. Plug those advantages into the **GSPO‑token** loss (Eq.(11)/(16)), which reduces mathematically to multiplying $s_i(\θ)$ by different constants for different token blocks while preserving all gradients derived for plain GSPO.

This extension respects the original theoretical derivation behind Eq.(7), because it only changes unbiased baseline terms while leaving off‐policy weight untouched. Consequently one obtains fine‐grained credit assignment at dialogue turn level without sacrificing stability or requiring any additional value model—exactly what multi‐turn RL needs.
