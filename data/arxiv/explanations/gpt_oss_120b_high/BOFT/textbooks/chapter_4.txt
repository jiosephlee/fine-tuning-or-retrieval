Chapter 4: Information‑Transmission View of Orthogonal Matrix Factorizations  

# Grid Representation with $d$ Source Nodes → $d$ Target Nodes over $m\!+\!1$ Layers  

When we seek to replace a dense orthogonal transformation by a product of several sparse factors, it is useful to imagine the computation as a flow of information across a layered graph.  Consider a linear layer of dimension $d$ that we would like to transform by an orthogonal matrix  
\[
\bm{R}\;=\;\bm{B}_{m}\,\bm{B}_{m-1}\cdots \bm{B}_{2}\,\bm{B}_{1},
\]  
where each factor $\bm{B}_{i}\in\mathbb{R}^{d\times d}$ is sparse and will be learned during finetuning.  The product can be visualised as a grid consisting of $m+1$ vertical levels (or “columns’’) and $d$ horizontal positions (“nodes’’) at each level.  The leftmost column contains the **source nodes**—the original coordinates of the input features—while the rightmost column contains the **target nodes**, i.e., the coordinates after applying the full transformation $\bm{R}$.  

At level $0$ we place a copy of each source node indexed by $j\in\{1,\dots,d\}$.  At level $i\;(1\le i\le m)$ we place another copy of the $d$ nodes; these represent intermediate representations after multiplication by $\bm{B}_{i}$.  Finally, at level $m$ we have the $d$ target nodes after all factors have been applied.  Traversing from left to right corresponds exactly to sequential left‑multiplication by $\bm{B}_{1},\,\bm{B}_{2},\dots,\bm{B}_{m}$.  

Because every factor is linear, information can travel only along directed edges that link a node at level $i-1$ to a node at level $i$.  The overall layout therefore forms a **grid‑structured directed acyclic graph** whose connectivity is dictated by the sparsity patterns of the matrices $\{\bm{B}_{i}\}$ (see Figure \ref{fig:info_trans} for an illustrative example with $d=4$, $m=5$).  This graphical picture provides an intuitive scaffold for reasoning about how many parameters are truly needed to realise any dense orthogonal matrix.



# Edges ↔ Non‑Zero Entries in Factor Matrices $\boldsymbol B_{1},\dots,\boldsymbol B_{m}$  

In linear algebra, an entry $[\bm B_i]_{pq}=0$ means that component $p$ receives no contribution from component $q$ during multiplication by $\bm B_i$.  In the graph view this translates directly into *absence* of an edge from node $q$ at level $i-1$ to node $p$ at level $i$. Conversely, any non‑zero entry corresponds to a *directed edge* carrying information from one level’s node to another’s.  Hence **the set of all directed edges across all levels is identical to the union of all non‑zero positions** in the factor matrices:
\[
E \;=\;\bigcup_{i=1}^{m}\bigl\{\,(p,q)\mid [\bm B_i]_{pq}\neq0\,\bigr\}.
\]  

Because each factor is square ($d\times d$), there are at most $d^{2}$ possible directed connections per layer.  When every entry were non‑zero we would obtain a fully connected bipartite graph between successive layers—a case that corresponds precisely to using a single dense matrix $\bm R$, i.e., $m=1$, $\bm B_{1}=\bm R$.  In practice we deliberately enforce sparsity so that only a small subset of those potential connections remains trainable; those surviving connections become our **free edges**, i.e., parameters we must learn during finetuning.



# Dense Connectivity Requirement and Minimal Free Edges Principle  

Two desiderata emerge naturally from the information‑transmission perspective:

1. **Dense connectivity** – For the final product $\bm R=\prod_{i=1}^{m}\bm B_i$ to be dense (no zero entry), every source node must possess *at least one directed path* that reaches **every** target node.  In graph terms this means that for any pair $(s,t)$ with source index $s\in[1,d]$ and target index $t\in[1,d]$, there exists a sequence $(s=v_0,v_1,\dots,v_m=t)$ such that each successive pair $(v_{k-1},v_k)$ belongs to an edge set contributed by $\bm B_k$.  If some pair lacks such a path then the corresponding entry $(t,s)$ in $\bm R$ will inevitably be zero, violating density.

2. **Minimal free edges** – Among all edge configurations satisfying dense connectivity we wish to minimise the total number of *trainable* connections (i.e., those not forced by structural constraints).  A smaller number of free edges translates directly into fewer learnable parameters and thus higher parameter efficiency—a primary goal when adapting gigantic foundation models.

Together these conditions define an optimisation problem over graph topologies: find a set of sparsity patterns for $\{\bm B_i\}$ such that every source can broadcast its signal throughout all levels using as few transmissible links as possible.



# Implications of Orthogonality on Edge Constraints  

Orthogonality imposes additional algebraic constraints on each factor matrix beyond mere sparsity.  By definition an orthogonal matrix satisfies  
\[
\bm B_i^\top \,\bm B_i = \bm I_d,
\]  
which immediately forces two crucial properties:

* **Full rank** – Each $\bm B_i$ must be nonsingular, meaning it establishes a bijection between its input and output nodes.  

* **Exactly $d** distinct “mandatory’’ connections per layer – To achieve full rank while preserving orthogonality, every row must contain exactly one non‑zero entry whose magnitude equals one (up to sign), and similarly each column must contain exactly one such entry.  In graphical terms this enforces a *perfect matching* between nodes at consecutive levels: there are precisely $d$ directed edges whose weights are fixed (\(\pm1\)) solely by necessity, not by learning choice.

Because these mandatory \(d\) edges are completely determined by orthogonality—they cannot be altered without breaking invertibility—they are conventionally **excluded from our count** of free parameters.  The remaining entries may still be zero or learnable non‑zero values; their pattern constitutes the *degrees of freedom* we can exploit for information transmission.

Orthogonality also introduces **dependency among optional edges**.  For instance consider a \(2\times2\) orthogonal block:
\[
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix},
\quad
a^{2}+c^{2}=b^{2}+d^{2}=1,
\quad 
ab+cd=0.
\]
If we set \(a=0,\) then orthonormality forces \(c=\pm1,\) which in turn mandates \(b=0,\) leading \(d=\pm1.\) Thus forcing a zero at any position automatically determines zeros elsewhere—a phenomenon clearly visible when visualising edge patterns in Figure \ref{fig:blk_diag}. Consequently any feasible set of free edges must respect these algebraic couplings: removing one transmissible connection may automatically remove another due purely to orthogonal constraints.



# Comparison of Naïve Dense Factorization versus Structured Factorizations  

A naïve approach would dispense with intermediate layers altogether and learn a single dense orthogonal matrix \(\bm R.\) In graph language this corresponds directly to connecting every source node to every target node using \(d^{2}-d = d(d-1)\) *free* directed edges (the diagonal entries belong to mandatory matches).   For moderate dimensions this leads quickly toward quadratic parameter budgets—e.g., when \(d=4,\) there are \(12\) free parameters required just for density.

Structured factorizations achieve dramatic savings by spreading connectivity across multiple sparse layers while preserving overall density through paths rather than direct links:

* **Block–diagonal OFT** – The original OFT imposes that each factor \(\bm R = \operatorname{diag}(\!\bm R_{1},\,\dots,\!\bm R_{r})\) consist exclusively of independent blocks \(\bm R_{i}\in \mathbb R^{b\times b}\) where \(br=d.\) Graphically this restricts communication within disjoint “clusters’’ so no cross‑cluster paths exist; consequently many source–target pairs become unreachable unless \(b=d.\) While dramatically reducing parameters (\(\mathcal O(bd)\)), this design sacrifices expressive power because dense connectivity cannot be realised unless each block spans all dimensions—precisely what defeats parameter efficiency.

* **Butterfly factorization** – Inspired by Cooley–Tukey’s fast Fourier transform topology, butterfly graphs connect nodes across levels using patterned sparse matrices known as butterfly factors.   A butterfly construction generates exactly \(\mathcal O(d\,\log d)\) free edges while guaranteeing that every source can reach every target through logarithmic‑length paths.   For example Figure \ref{fig:info_trans} shows an explicit construction with five factors ($m=5$) achieving dense output using only ten free edges—already fewer than what would be needed by any single dense factor (twelve for $d=4$).   Importantly these ten free connections obey orthogonality because each butterfly component can itself be rendered orthogonal via Cayley transforms applied on its small blocks (\(2\times2,\) or more generally \(b\times b.\))

Thus moving from naïve density (\(\mathcal O(d^{2})\)) toward structured sparse decompositions yields two key benefits:
  
* A substantial reduction in trainable parameters – from quadratic down to near‐linear (\(\mathcal O(d\,log d)\)).  
* Retention—or even enhancement—of expressive capability because information may still flow freely via multi‑step pathways mandated by graphs such as butterflies or other well‑designed topologies.


Together these observations justify recasting Orthogonal Finetuning as an **information transmission problem** on layered graphs: By engineering sparsity patterns that obey both dense connectivity and minimal free-edge principles under algebraic ortho­gonal constraints, one can obtain compact yet powerful parameterizations suitable for adapting massive foundation models without sacrificing performance.



---  

In summary, representing an orthogonal matrix factorisation as information flow across a grid clarifies why certain sparsity patterns succeed while others fail.  The mapping “edge ⇔ non‑zero entry’’ makes it easy to reason about required connections; dense connectivity guarantees that no destination remains blind; minimal free‑edge designs minimise learnable parameters; and orthogonality imposes exact matchings plus subtle dependencies among admissible edge sets.  This framework not only explains why block‑diagonal OFT struggles with expressivity but also illuminates why butterfly factorizations—by virtue of their carefully crafted sparse graphs—achieve remarkable parameter efficiency without losing density, paving the way for practical large‑model adaptation techniques such as BOFT introduced later in the paper.

# Butterfly Structures from Fast Fourier Transform

The butterfly structure that lies at the heart of the Cooley–Tukey fast Fourier transform (FFT) is a powerful tool for constructing dense orthogonal transformations while keeping the number of trainable parameters modest. In this chapter we develop an intuition for why butterfly factorizations are ideally suited for **information‑efficient transmission** across a layer, we formalize their algebraic construction, and we survey how these matrices have been employed in machine‑learning contexts—most notably as a building block for the **Orthogonal Butterfly Finetuning** (BOFT) method. Throughout we stay faithful to the definitions and observations presented in the original research article.

---

## Recap of Radix‑2 Cooley–Tukey Algorithm

The discrete Fourier transform (DFT) maps a length‑$N$ signal $\mathbf{x}\in\mathbb{R}^{N}$ to its frequency representation $\hat{\mathbf{x}}\in\mathbb{R}^{N}$. A naïve matrix multiplication would require $\mathcal{O}(N^{2})$ operations. The **radix‑2 Cooley–Tukey algorithm** reduces this cost dramatically by recursively splitting an $N$‑point DFT into two $(N/2)$‑point DFTs. Concretely, if $N=2^{L}$ is a power of two, one writes

\[
\hat{\mathbf{x}}[k]
=
\sum_{n=0}^{N-1} x[n]\;e^{-2\pi i kn/N}
=
\sum_{n=0}^{N/2-1}
\bigl(x[2n]+e^{-2\pi i k/N}\;x[2n+1]\bigr)\,
e^{-2\pi i k n/(N/2)} .
\]

The first term inside the parentheses mixes each pair of even and odd samples via a **butterfly operation**, while the outer sum is itself a DFT of half the size. By repeatedly applying this decomposition $L=\log_{2} N$ times, one obtains a factorization of the original DFT matrix into $L$ sparse factors. Each factor couples only pairs of indices that differ in a single binary digit – exactly the pattern depicted by a classic **butterfly graph**. The algorithm therefore achieves an overall computational complexity of $\mathcal{O}(N\log N)$ because each stage contributes only $\mathcal{O}(N)$ elementary additions and multiplications.

From a conceptual standpoint this recursion emphasises two crucial ideas:

1. **Local mixing** – at every stage only a small subset (typically two entries) exchange information.
2. **Global propagation** – after $\log_{2} N$ stages every output coordinate has indirectly received contributions from all input coordinates because information has been passed along a binary tree‑like network.

These two ideas will reappear when we reinterpret butterfly factorizations as dense information pathways within neural networks.

---

## Definition of Butterfly Factor $\mathbf{B}^{F}(k)$ and Recursive Construction of $\mathbf{B}(d)$

To translate the FFT’s computational graph into a matrix language suitable for neural‑network finetuning, the paper introduces a **butterfly factor** parameterised by a dimension $k$ that is itself a power of two:

\[
\boxed{
\mathbf{B}^{F}(k)=
\begin{bmatrix}
\operatorname{diag}(\mathbf{d}_{1}) & \operatorname{diag}(\mathbf{d}_{2})\\[4pt]
\operatorname{diag}(\mathbf{d}_{3}) & \operatorname{diag}(\mathbf{d}_{4})
\end{bmatrix}
\in \mathbb{R}^{k\times k}.
}
\tag{1}
\]

Here each $\mathbf{d}_{i}\in \mathbb{R}^{k/2}$ is an arbitrary vector that fills the diagonal blocks with scalar entries. When all entries are set to $1$, $\mathbf{B}^{F}(k)$ reduces to the binary connectivity pattern used in a single FFT stage: every row contains precisely two non‑zero entries – one per half‑column – thus establishing exactly one directed edge from each source node at level $i$ to two target nodes at level $i+1$.

The full **butterfly matrix** $\mathbf{B}(d)\in \mathbb{R}^{d\times d}$ for $d=2^{N}$ is built recursively by stacking such factors at multiple scales:

\[
\boxed{
\mathbf{B}(d)
=
\tilde{\mathbf{B}}(d,d)\,
\begin{bmatrix}
\mathbf{B}_{1}\!\!\left(\tfrac d 2\right) & \mathbf0\\[4pt]
\mathbf0 & \mathbf{B}_{2}\!\!\left(\tfrac d 2\right)
\end{bmatrix}
=
\tilde{\mathbf{B}}(d,d)\,\tilde{\mathbf{B}}\!\left(d,\tfrac d 2\right)\,\cdots\, 
\tilde{\mathbf{B}}(d,2).
}
\tag{2}
\]

In this expression:

* $\tilde{\mathbf{B}}(d,k)$ denotes a **butterfly component**, namely a block‑diagonal matrix whose blocks are copies of $\mathbf B^{F}(\cdot)$ with block size $k$:
  \[
  \tilde{\mathbf B}(d,k)=
  \operatorname{diag}\!\bigl(\,\underbrace{\mathbf B_{1}^{F}(k),\, \dots,\,
  \mathbf B_{d/k}^{F}(k)}_{d/k~\, \text{blocks}}\,\bigr).
  \]
* $\mathbf B_{1}(\tfrac d 2)$ and $\mathbf B_{2}(\tfrac d 2)$ are themselves butterfly matrices defined on half the dimension.
* The recursion terminates when $k=2$, where each component reduces to a $2\times 2$ block that can be interpreted as a rotation in a two‑dimensional subspace.

Thus $\mathbf B(d)$ is explicitly written as a product of $\log_2 d$ sparse matrices, each having exactly $d$ non‑zero entries (one per row). The sparse pattern at successive levels reflects precisely the connections described by an FFT butterfly graph.

---

## Graphical Interpretation: $\mathcal O(d\,\log d)$ Edges Achieve Full Connectivity

The paper proposes an **information‑transmission viewpoint**: consider $d$ source nodes (the columns of an input vector) at level $0$, and $d$ destination nodes at level $m$, where $m$ denotes the number of factor matrices used in a factorisation
$\displaystyle \mathbf R = \mathbf B_m\, \mathbf B_{m-1}\cdots \mathbf B_1$.
Each intermediate level contains $d$ nodes as well; an edge from node $j$ at level $\ell-1$ to node $i$ at level $\ell$ exists if entry $(i,j)$ in $\mathbf B_\ell$ is non‑zero. The whole product therefore describes how information propagates from sources to sinks through **directed edges across adjacent levels**.

For an arbitrary dense matrix $\mathbf R$, achieving full connectivity would require all possible $d^2 - d$ edges (the diagonal entries correspond to trivial self‑loops that do not need learning). A naïve dense factorization thus incurs
$\Theta(d^{\,2})$
trainable parameters—precisely what makes traditional Orthogonal Finetuning (OFT) parameter‑inefficient when using unrestricted orthogonal matrices.

The butterfly construction dramatically reduces this count while still guaranteeing:
* **Dense connectivity** – every source node can reach every sink node after traversing all layers.
* **Sparsity optimality** – each factor contributes exactly $d$ edges (one per row), amounting to 
$\displaystyle m\,d = \mathcal O(d\,\log d)$
edges when we pick 
$m=\log_2 d$
as dictated by Eq.~(2).

Figure 3 in the source material visualizes such a graph for $d=8$. The picture shows that after only three stages ($m=\log_28=3$), any node on the leftmost column can route its signal to any node on the rightmost column via successive pairwise exchanges defined by the butterfly factors. Hence with only 
$\mathcal O(d\,\log d)$ trainable scalar values—the diagonal entries inside each factor—we realize every possible dense orthogonal transformation required for finetuning applications.

## Historical Uses of Butterfly Matrices in Machine Learning

Although invented initially as an algorithmic shortcut for computing DFTs, butterfly matrices have found several influential roles across machine learning:

| Domain | Representative Use | Insight |
|--------|-------------------|---------|
| **Fast linear transforms** | Parameterising structured linear layers as products of butterfly components (e.g., DAO 2019; Chen 2022) | Allows learning customized linear maps that retain fast multiplication speed |
| **Stability of recurrent networks** | Embedding butterfly blocks within RNN transition matrices (Jing 2017) | Orthogonal parts prevent exploding/vanishing gradients |
| **Kernel approximation** | Approximating shift‑invariant kernels via randomized butterfly matrices (Munkhoeva 2018) | Leverages fast multiplication for scalable kernel methods |
| **Sparse training & network compression** | Using butterfly factorizations to impose data-sparse patterns on learned weight matrices (Parker 1995; DAO 2020) | Sparse factors reduce storage while preserving expressive power |

These precedents demonstrate that butterfly structures are not merely computational tricks but also provide *regularizing inductive biases*: their sparsity pattern mirrors many classical transforms—Fast Fourier Transform (FFT), Hadamard transform, discrete cosine transform—each known for efficiently mixing information globally after only logarithmic depth. Consequently they have become natural candidates for *parameter-efficient* reparameterizations like BOFT where we wish to retain rich expressive capacity without paying quadratic parameter costs.

## Key Properties Relevant to Orthogonal Parameterisation

When applying butterflies within Orthogonal Finetuning we must satisfy strict algebraic constraints: each factor must be orthogonal so that their product remains an element of the orthogonal group $\mathcal O(d)$. The paper enumerates several properties that make butterflies especially suitable:

1. **Local Orthogonality via Cayley Transform**  
   Each elementary block—particularly those with size $k=2$—can be rendered orthogonal using the Cayley parameterisation:
   \[
   \mathbf R=(\mathbf I+\mathbf Q)(\mathbf I-\mathbf Q)^{-1},
   \qquad
   \mathbf Q^\top = -\,\mathbf Q .
   \]
   For a $2\times 2$ block this reduces to an ordinary rotation angle; higher‐dimensional blocks ($b>1$) are formed by embedding multiple such rotations into larger submatrices while preserving overall orthogonality.

| Factor size | Non‑zero entries per row | Trainable parameters |
|-------------|--------------------------|----------------------|
| $k=2$, block size $b=1$ | 1 | $(b-1)/2 =0$, i.e., identity initialization |
| General $(m,b)$ BOFT | $(b-1)/2\,dm$ effective scalars | $\displaystyle \frac12(b-1)d\,m = \mathcal O(d\,m)$ |

   Because each completed block contributes only $(b-1)/2$d free scalar variables (the remaining degrees are fixed by orthogonality), BOFT achieves
   \[
   |\Theta_{\text{trainable}}|\;=\;\frac12(b-1)d\,m .
   \]
   Choosing {\small$m=\log_{{ } }(d/b)+ {\rm const}$} yields
   $
   |\Theta|\;
    =%
    \mathcal O(d\,\log d)
   $
   parameters—substantially fewer than OFT’s quadratic budget even when OFT opts for dense blocks ($b=d$).

2. **Identity Initialization Guarantees Zero Perturbation**  
   All butterfly components may start as identity matrices simply by initializing their underlying skew–symmetric matrices $\mathbf Q$ as zero. Consequently,
   \[
   \bm R(m,b)=
   \prod_{\ell=1}^{m}\tilde{\bm B}^{\,b}_{(d,\ell)} = \bm I_d ,
   \]
   replicating OFT’s “start close to pretrained” philosophy without sacrificing expressive potential later on.

3. **Structured Expressivity Beyond Block Diagonal OFT**  
   Theorem 4 from the article asserts:
   
   > *BOFT is more expressive than OFT with the same block size.*  
   
   Specifically, composing multiple alternating products
   $
      \bm B_{i,j}(d)\bm B_{i,j}^{\top}(d)
   $
   over indices $(i,j)$ yields any element of $\mathcal O(d)$. In practice, modest depths—
     e.g., BOFT$(6,4)$ versus OFT$(1,16)$—already approximate random dense orthogonal matrices far more accurately while using fewer free parameters (see Figure 5). Thus BOFT balances *expressivity* against *regularity*: it retains strong inductive bias from its structured sparsity yet can still span large swaths of the orthogonal group when needed.

4. **Preservation of Spectral Norms & Training Stability**  
   Multiplying an existing pretrained weight matrix $\bm W^{0}$ on its left by an orthogonal matrix does not alter singular values:
   $
      (\bm R\bW^{0})^\top (\bm R\bW^{0})
      = (\bW^{0})^\top\bW^{0}.
    $
    Hence both OFT and BOFT inherit spectral norm preservation—an attribute linked empirically with stable optimisation and better generalisation in deep networks (\cite{krylov2006review}, although specific citation omitted per instruction).

5. **Compatibility with Multiplicative Dropout**  
   Because BOFT’s transformation is multiplicative rather than additive like LoRA’s low‑rank updates, dropout must be applied *to whole components*. The paper proposes selecting randomly:
    * some fraction $p_{1}$ of entire butterfly components;
    * within each selected component some fraction $p_{2}$ of its diagonal blocks;
     
    These selected parts are replaced by identity operators during training iterations—a “multiplicative dropout” mechanism that mitigates overfitting while respecting orthogonality constraints throughout training epochs.

Collectively these properties make butterflies an ideal vehicle for constructing dense orthogonal transformations under tight parameter budgets—a central requirement when fine‑tuning massive foundation models where naïve full‐matrix optimisation would be prohibitive both in storage and compute.

### Summary

The Cooley–Tukey radix‑2 FFT illuminates how local pairwise exchanges can be cascaded logarithmically to achieve global mixing—a principle captured formally by *butterfly factorizations*. By defining elementary factors $\displaystyle\bm B^{F}(k)$ and recursively assembling them into $\displaystyle\bm B(d)$, we obtain:
* A deterministic sparsity pattern involving only $\mathcal O(d\,\log d)$ nonzero entries.
* A clear graphical model wherein every source node can reach every sink node after traversing all layers.
* A mathematically tractable way to enforce orthogonality via per‐block Cayley parametrisation.
* Proven expressive superiority over naïve block-diagonal orthogonal finetuning while retaining strong regularising inductive bias stemming from classic linear transforms (DFT, Hadamard etc.).

These insights underpin BOFT—the novel “Orthogonal Butterfly” finetuning framework presented in the research article—showing how one can efficiently adapt huge vision transformers, language models and diffusion models without incurring substantial inference overhead or sacrificing training stability. The remainder of this textbook will later explore how BOFT integrates into full model pipelines and compares empirically against other PEFT techniques such as LoRA and adapter tuning.
