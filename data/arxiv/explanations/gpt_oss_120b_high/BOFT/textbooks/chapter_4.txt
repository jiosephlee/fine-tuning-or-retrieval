\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: **Information Transmission View on Sparse Orthogonal Factorizations**

# Motivation for an Information Transmission Perspective  

The central goal of *orthogonal finetuning* (OFT) is to adapt a pretrained linear layer while preserving the relational geometry encoded in its weight matrix.  Concretely, given a frozen pretrained weight matrix \(\mathbf{W}^{0}\in\mathbb{R}^{d\times n}\), OFT replaces it by the transformed matrix  
\[
\mathbf{W}=\mathbf{R}\,\mathbf{W}^{0},
\qquad 
\mathbf{R}\in\mathbb{R}^{d\times d},\;\;\mathbf{R}^{\!\top}\!\mathbf{R}=\mathbf{I}_{d},
\]  
so that every column vector (“neuron”) of \(\mathbf{W}^{0}\) undergoes the same orthogonal rotation \(\mathbf{R}\).  This rotation guarantees that all pairwise angles among neurons remain unchanged, thereby protecting the semantic knowledge obtained during pretraining.

Although this principle is theoretically appealing, directly learning an unrestricted dense orthogonal matrix \(\mathbf{R}\) would require \(\Theta(d^{2})\) trainable parameters—far too costly when \(d\) reaches several thousands as in modern vision transformers or large language models.  Early work therefore imposed a *block‑diagonal* pattern on \(\mathbf{R}\), partitioning its rows into \(r\) groups each transformed independently:
\[
\mathbf{R}= \operatorname*{diag}\bigl(\mathbf{R}_{1},\dots,\mathbf{R}_{r}\bigr), 
\qquad 
\mathbf{R}_{i}\in\mathbb{R}^{b\times b},\;\; br=d .
\]
While this reduces parameter count dramatically (\(\Theta(bd)\)), it also introduces an undesirable inductive bias: dimensions belonging to different blocks never exchange information during finetuning.  

A natural question arises: *Can we obtain a fully dense orthogonal transformation while still keeping the number of free parameters small?*  The answer emerges when we reinterpret the multiplication  
\[
\mathbf{R}= \mathbf{B}_{m}\,\mathbf{B}_{m-1}\cdots \mathbf{B}_{1}
\tag{1}
\]  
as an **information‑transmission process** on a layered graph.  By examining how sparsity patterns propagate through successive multiplications, we acquire a principled way to design factor matrices \(\{\mathbf B_i\}\) that achieve dense overall connectivity yet require few trainable entries.



# Mapping Matrix Products onto Multi‑Level Graphs  

Consider a product of \(m\) square matrices as in (1), each \(\mathbf B_i \in \mathbb R^{d\times d}\).  We associate this product with a *grid graph* consisting of \(m+1\) horizontal layers (or “levels”), numbered \(0,\dots,m\), where each layer contains \(d\) nodes indexed by \(1,\dots,d\).  The nodes at level \(i-1\) represent the input dimensions before applying \(\mathbf B_i\); those at level \(i\) represent intermediate dimensions after application of that factor.

Formally, let us denote by \(b_{ij}^{(k)}\) the entry in row \(i\), column \(j\) of factor \(\mathbf B_{k}\).  A non‑zero entry (\(b_{ij}^{(k)} \neq 0\)) creates a **directed edge** from node \(j\) at level \(k-1\) to node \(i\) at level \(k\).  In this way each factor defines an adjacency matrix between two consecutive levels:
\[
A^{(k)} = (\ldots , b_{ij}^{(k)} , \ldots)\in \mathbb R^{d\times d}.
\]
The overall product (1) corresponds exactly to composing these adjacency relations along directed paths that traverse successive levels.  Consequently,
the entry \(r_{pq}\) of the final matrix \(\mathbf R=\prod_k \mathbf B_k\) is non‑zero **iff** there exists at least one directed path from node \(q\) in level 0 to node \(p\) in level \(m\).  This observation translates algebraic sparsity into combinatorial reachability.



# Nodes, Levels, Edges: Interpreting Non‑Zero Entries as Communication Links  

From the viewpoint just described:

| Element | Graph Interpretation |
|--------|----------------------|
| A node            | One coordinate (dimension) of a vector at a specific stage of multiplication |
| A level           | A stage between successive factors – there are exactly \(m+1\) levels |
| A directed edge   | A permissible linear combination enabled by a non‑zero entry in some factor |
| A path            | A chain of multiplications that moves information from an input coordinate to an output coordinate |
| Reachability      | Determines whether an output entry can be influenced by a given input entry |

If we think of each vector component as a “message” that needs to be relayed across stages, then every non‑zero entry functions as a communication link capable of transmitting that message forward one step. The topology induced by all factors simultaneously determines which messages can ultimately reach which destinations after all stages have been applied.



# Dense Connectivity Requirement for Full‑Rank Transformation  

A *dense* orthogonal matrix has no zero entries; equivalently, every output dimension may depend on every input dimension. In our graph picture this translates into the following **dense‑connectivity** requirement:

> **Requirement (i):** For any pair of nodes \((q,p)\), where \(q\) lies on the source level 0 and \(p\) lies on the sink level \(m,\) there must exist *at least one* directed path from \(q\) to \(p.\)

If this condition holds then every entry \(r_{pq}\neq0.\) Moreover, because each intermediate factor is constrained to be *orthogonal*, every intermediate mapping is invertible; thus any collection of paths satisfying Requirement (i) also ensures that the overall transformation has full rank (\(=d.\)). In practice this condition prevents “isolated” groups such as those produced by block‑diagonal sparsity—their graph consists of several disconnected sub‑graphs so many source–sink pairs have no connecting path.



# Minimal Free Edges under Orthogonality Constraints  

Even when Requirement (i) is satisfied, we want to keep the total number \(E_{\text{free}}\) of *trainable* non‑zero entries as low as possible. Not all non‑zeros contribute independent degrees of freedom because **orthogonality** imposes strong algebraic dependencies:

* For any single factor \(\mathbf B_k,\) being orthogonal means its columns form an orthonormal basis. Consequently each column must contain exactly one unit norm element along with possibly additional values that satisfy mutually perpendicular constraints.
* In particular, any full‑rank square orthogonal matrix must induce a **bijection** between its input nodes and output nodes—a permutation behavior when viewed only through support (positions where entries may be non‑zero). Thus each factor requires at least \(d:\)" one edge per output node" to maintain bijectivity.
* These mandatory edges are *forced*: their values are determined up to sign (\(\pm1)\); therefore they do not consume trainable parameters.
* Remaining non‑zeros—the **free edges**—are those whose magnitudes are free variables subject only to the global orthogonality condition across all factors. Minimizing \(E_{\text{free}}\)
corresponds directly to reducing parameter count while preserving expressive power.

Hence our second desideratum becomes:

> **Requirement (ii):** The total number \(E_{\text {free}}\)
of freely learnable edges across all levels should be **minimal** while still guaranteeing Requirement (i).

A naïve solution would place all possible edges at every layer producing a single dense factor (\(E_{\text {free}}=d^{2}-d)\), which respects Requirement (i) but violates Requirement (ii); its parameter budget scales quadratically as \(\Theta(d^{2}) .​


# Graphical Comparison Between Block‑Diagonal Sparsity and Potential Alternatives  

### Block–Diagonal Structure  

In the original OFT formulation the orthogonal matrix takes a block‐diagonal form:
\[
   \mathbf R_{\text {blk}} = 
   {\rm diag}(\underbrace{\mathbf R_{1}}_{b\times b},
                \underbrace{\mathbf R_{2}}_{b\times b},
               \,\,\,…,\,\,\, 
                \underbrace{\mathbf R_{r}}_{b\times b}),
   \quad br=d .
}
In graph terms this corresponds precisely to **\(r$ isolated sub‑graphs**, each containing only the $b$ nodes belonging to one block.
Edges exist solely within each sub‑graph; there are no connections crossing between different blocks at any stage.
Consequently many source–sink pairs belong to different blocks and have no directed path connecting them.
The resulting adjacency pattern fails Requirement (i): most pairs $(q,p)$ lie in disjoint components → zero entries remain permanently zero.
Even though each individual block can be made orthogonal with only $\tfrac12 b(b-1)$ trainable parameters,
the overall transformation is far from dense; expressivity suffers dramatically.


### Dense Single Factor  

Placing all information into one dense factor $\mathbf B_1=\mathbf R_{\text {dense}}$
creates exactly one layer ($m=1$).  
Every source vertex connects directly to every sink vertex,
so Requirement (i) holds trivially.
However $E_{\text {free}} = d^{2}-d$, i.e., almost all $d^{2}$ possible
edges become independent learnable parameters.
The parameter budget scales quadratically,
rendering this option impractical for large models.


### Butterfly Factorizations  

A striking compromise comes from adopting **butterfly factorizations**, originally studied in the Cooley–Tukey FFT algorithm.
When $d=2^{N}$,
a butterfly factorization expresses $\mathbf R$ as
a product
$\displaystyle 
    \mathbf R_{\text {bf}} = 
    \tilde{\mathbf B}(d,k_N)\,
    \tilde{\mathbf B}(d,k_{N-1})\, 
    \dots\, 
    \tilde{\mathbf B}(d,k_1),
$
where each intermediate component $\tilde{\mathbf B}(d,k_i)$ is block‐diagonal with block size~$k_i$,
and adjacent components are permuted relative
to one another so that information continually mixes across blocks.
In graph language,

* Each layer still contains exactly $d$ mandatory bijective edges,
corresponding essentially either to identity or signed permutations;
these do **not** contribute trainable variables.
* The additional learnable degrees arise from within-block rotations (e.g., $2\times2$ rotation matrices).
There are only $\frac12(b-1)d$ learnable scalars per component when using block size $b$,   
so after $\log_2 d$ components we obtain
\[   
    E_{\text {free}}
    = O(d\,\<log_2 d\<),
    % ~roughly~ 
    % perhaps multiplied by constant proportional 
    %   depending on chosen block size b
        .
   }
Consequently Requirement (ii)—minimal free edges—is satisfied up
to logarithmic overhead.
Nevertheless because successive permutations ensure that during
the $\log_2 d$ stages every input dimension eventually meets every
output dimension via distinct paths,
Requirement (i)—dense connectivity—is also fulfilled.
Hence butterfly factorizations deliver exactly what standard OFT’s block diagonal approach lacks:
a **dense** overall transformation together with **parameter efficiency** scaling near linearly rather than quadratically.


### Visual Metaphor  

Imagine arranging eight source nodes horizontally atop column 0,
and eight sink nodes below them at column 5.
A block‐diagonal design draws three vertical stacks:
each stack links three source nodes exclusively among themselves—
the walkers never cross stacks—so many destinations remain unreachable.
Conversely,
a butterfly design first couples adjacent pairs,
then couples resulting groups across larger spans,
and finally mixes everything globally;
the walker’s trajectory zigzags akin to how data spreads through an FFT computation tree,
reaching every destination after just three mixing stages.


# Summary  

Recasting sparse orthogonal factorizations as information transmission over layered grid graphs brings two powerful insights:

1. **Dense Connectivity:** An effective finetuning transform must enable every source dimension eventually influencing every target dimension—a purely graph‐theoretic condition corresponding algebraically to a fully dense final matrix.
2. **Parameter Economy:** Orthogonality forces each intermediate layer's adjacency matrix into a bijective pattern; therefore only *extra* off‐bijective edges count toward learnable parameters. Minimizing these “free” edges yields $\mathcal O(d)$ or $\mathcal O(d\,\<log\:d\<)$ parameter budgets rather than $\mathcal O(d^{2})$.

The prevailing block‐diagonal scheme fulfills neither criterion simultaneously—it preserves cheap parametrization but sacrifices global mixing—whereas butterfly factorizations satisfy both by exploiting hierarchical permutations over multiple sparse layers.
This graph–theoretic lens therefore motivates **Orthogonal Butterfly** finetuning (BOFT), wherein an entire dense orthogonal rotation is constructed from $\log_2 d$ sparse components whose learnable degrees scale only linearly with model width.
Understanding these desiderata equips us with a systematic foundation for designing new sparse factorizations beyond butterflies—any topology meeting Requirements (i) and (ii)
will inherit similar benefits in terms of expressivity, stability and training efficiency.
