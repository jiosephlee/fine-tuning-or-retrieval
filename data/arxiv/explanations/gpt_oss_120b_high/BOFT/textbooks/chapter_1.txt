\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 1: Foundations of Parameter‑Efficient Model Adaptation  

# The Rise of Large Foundation Models and Their Training Costs  

In recent years a new class of machine learning systems—large foundation models—has emerged as a dominant force in both natural language processing and computer vision. Exemplary instances such as ChatGPT \cite{brown2020language,chen2021evaluating} and Stable Diffusion \cite{rombach2022high} display striking generalization abilities across a wide spectrum of downstream problems. The remarkable capabilities of these systems are tied directly to their massive scale: contemporary language models now contain on the order of hundreds of billions of parameters (for example, GPT‑3 comprises roughly $1.75\times10^{11}$ parameters).  

Training such models from scratch demands an astronomical amount of compute, data, and engineering effort. The required GPU‑hours grow superlinearly with model size because both forward–backward passes and optimizer state updates increase with the number of parameters. Consequently, only a handful of organizations possess the resources necessary to create new foundation models at this scale, while most researchers must rely on pretrained checkpoints released by these entities. This economic reality creates a clear imperative: after a foundation model has been trained once on massive corpora, it should be possible to adapt it efficiently to many downstream tasks without re‑training it entirely.

# Why Adapting Pretrained Models Is Essential  

The central premise behind leveraging pretrained foundation models is that they encode rich structural knowledge about language or visual data that can be transferred to new problems. However, downstream tasks often differ substantially from the pretraining objectives—consider sentiment classification versus next‑word prediction, or object detection versus image synthesis. Directly using a frozen pretrained model on such tasks would typically yield suboptimal performance because the model’s output heads or intermediate representations are not aligned with the specific target distribution.  

Fine‑grained adaptation is therefore required to adjust the model’s internal mappings while preserving the bulk of its pretrained knowledge. A naïve approach would be full fine‑tuning: updating every parameter on a task‐specific dataset through gradient descent. While this method can achieve high accuracy when sufficient labeled data are available, it is prohibitively expensive for large models because each downstream task would entail storing a full copy of all parameters and incurring high computational cost during training. Moreover, full fine‑tuning discards much of the original parameter budget that could otherwise be shared across many tasks.

Parameter‑efficient adaptation methods address these concerns by limiting the number of trainable variables while still allowing meaningful task‐specific adjustments. By keeping most weights frozen, they retain the semantic structure learned during pretraining, reduce storage footprints for multiple tasks (since only a small set of “delta” parameters need be saved per task), and lower compute requirements during adaptation.

# Model Fine‑Tuning Versus Adapters Versus Prompts  

Three primary families dominate current research on parameter‑efficient fine‑tuning (PEFT): (i) **model fine‑tuning**, (ii) **adapter tuning**, and (iii) **prompt tuning**.

**Model fine‑tuning** keeps the original architecture unchanged but updates a selected subset—or sometimes all—of its weight matrices during downstream training \cite{hulora2022,zaken2022bitfit,guo2020parameter,raffel2020exploring,qiu2023controlling,zhang2022adaptive,chavan2023one}. Because no additional components are introduced at inference time, model fine‑tuning incurs zero extra latency compared to the original frozen model. In practice many works adopt a small learning rate so that the fine‑tuned weights stay close to their pretrained values; this heuristic aims to preserve pretrained knowledge by limiting divergence between pretraining and fine‐tuned regimes.

**Adapter tuning** augments each layer with small trainable modules inserted either before or after the existing linear transformations \cite{rebuffi2017learning,houlsby2019parameter,pfeiffer2020adapterfusion,lin2020exploring,he2021towards}. These modules typically consist of a down‑projection followed by an up‑projection (a bottleneck), thereby introducing relatively few extra parameters per layer while leaving the original weights untouched. The added adapters increase inference cost modestly because each forward pass must evaluate them in addition to the original computation graph.

**Prompt tuning** attaches learnable tokens—often called “prefixes” or “soft prompts”—to the input embedding sequence \cite{li2021prefix,lester2021power}. During adaptation only these prompt vectors are updated; all backbone weights remain frozen. Prompt tuning is especially popular in language models because it retains zero architectural change beyond extending the input context length. Nevertheless it still introduces marginal additional compute as each forward pass concatenates extra token embeddings.

Each family trades off three central desiderata for PEFT methods:

1. **Parameter budget** – how many additional or modified parameters need to be stored per downstream task.
2. **Inference latency** – whether extra computation is required at test time.
3. **Knowledge preservation** – how well the method retains representations learned during pretraining.

Model fine‑tuning scores highest on inference latency (none) but often requires more trainable parameters than adapters or prompts when many layers are updated simultaneously. Adapter tuning reduces storage cost at modest inference overhead; prompt tuning minimizes both storage and added compute but may be less expressive because only input embeddings are altered.

# Desired Properties for PEFT Methods  

When designing a new PEFT technique it is useful to articulate explicit criteria that capture practical constraints encountered in real deployments:

* **Compactness** – A PEFT method should involve as few trainable parameters as possible while still achieving competitive performance on target tasks. This compactness directly translates into lower memory consumption for storing multiple task‐specific checkpoints.
* **Zero Additional Inference Cost** – Ideally adaptation should not increase runtime latency during deployment; users should benefit from improved task performance without paying extra computational price.
* **Preservation of Pretrained Knowledge** – Since foundation models have been trained on vast datasets capturing rich statistical regularities, any adaptation should avoid destroying this knowledge wholesale. Techniques that enforce similarity between pretrained and adapted weights—for instance through orthogonal transformations that preserve pairwise angles among neuron vectors—exhibit increased stability and generalization \cite{qiu2023controlling}.
* **Expressivity Within Structured Constraints** – A method must retain enough capacity to capture task‐specific variations despite its parametric restrictions; otherwise underfitting will occur.
* **Scalability Across Model Types** – The approach should apply uniformly to vision transformers, large language models, and diffusion architectures rather than being confined to a single modality or architecture family.

The work examined in this chapter seeks precisely these properties by building upon Orthogonal Fine‑tuning (OFT) \cite{qiu2023controlling}—a principled variant that multiplies each weight matrix $\mathbf{W}^{0}\in\mathbb{R}^{d\times n}$ by an orthogonal matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$ so that $\mathbf{z}= (\mathbf{R}\mathbf{W}^{0})^{\!\top}\mathbf{x}$ replaces the original linear mapping $\mathbf{z}= (\mathbf{W}^{0})^{\!\top}\mathbf{x}$. Because orthogonal matrices preserve inner products,
the angle between any pair of neuron vectors remains unchanged after adaptation,
which empirically yields more stable training dynamics compared with additive low–rank updates such as LoRA \cite{hulora2022}.

A practical obstacle arises however: representing an arbitrary $d$-dimensional dense orthogonal matrix naively requires $\mathcal O(d^{2})$ parameters—far more than many contemporary PEFT budgets permit. Existing OFT mitigates this cost by enforcing a block‑diagonal structure on $\mathbf{R}$,
partitioning dimensions into $r$ groups each handled by an independent $b\times b$ orthogonal block ($br=d$). While this reduces parameter count dramatically,
it also imposes strong inductive biases—in particular it forces inter–group interactions to remain static—which limits expressivity relative to full orthogonal transformations.

Thus an improved PEFT strategy must reconcile *dense* interaction capability with *parameter efficiency*. The remainder of this chapter outlines one such solution introduced by “Parameter‐Efficient Orthogonal Finetuning via Factorization”.

# High‑Level Contribution Overview  

The paper proposes **Orthogonal Butterfly Fine‑tuning (BOFT)**—a novel PEFT method that retains OFT’s theoretical advantage (preservation of pairwise neuron geometry) while dramatically lowering its parameter footprint through *butterfly factorization*. Its contributions can be grouped into four themes:

1. **Information Transmission Perspective** –  
   The authors reconceptualize constructing a dense orthogonal matrix $\mathbf{R}$ as an *information transmission* problem over a grid graph comprising $d$ source nodes and $d$ target nodes across multiple intermediate layers. Each factor matrix $\mathbf{B}_{i}$ contributes directed edges between adjacent layers; dense connectivity (every source can reach every target) together with minimal free edges defines an efficient sparsity pattern under orthogonality constraints.
   
2. **Butterfly Factorization for Orthogonal Parameterization** –  
   Drawing inspiration from the Cooley–Tukey fast Fourier transform algorithm’s butterfly network \cite{cooley1965algorithm}, they build $\mathbf{R}$ as a product of $\mathcal O(\log d)$ sparse matrices each containing only $\mathcal O(d)$ nonzero entries:
   \[
   \mathbf{R}(m,b)=\prod_{i=1}^{m}\tilde{\mathbf B}^{\,b}_{(d,i)},
   \]
   where each component $\tilde{\mathbf B}^{\,b}_{(d,i)}$ is block‐diagonal with $b\times b$ butterfly factors $\mathbf B^{F}(k)$ defined in Equation \eqref{eq:but_factor}. By enforcing orthogonality on every component (via Cayley transforms applied locally to $2\times2$ rotations), $\mathbf{R}(m,b)$ remains orthogonal despite being assembled from highly sparse pieces.
   
   As a result BOFT needs only 
   \[
   \frac12(b-1)\! d\, m
   \]
   effective trainable parameters for a linear layer of size $d\times n$. When $b=2$ and $m=\log_{2} d$, this scales as $\mathcal O(d\log d)$—a drastic reduction relative to OFT’s $\mathcal O(d^{2})$ cost.
   
3. **Theoretical Insights & Weight Interpolation** –  
   The authors prove that BOFT’s hypothesis class strictly contains that of block‐diagonal OFT given identical block sizes; formally,
   *BOFT is more expressive than OFT with the same block size* (Theorem \ref{thm:exp_boft}). Moreover,
   repeated multiplication allows smooth interpolation between identity and arbitrary dense orthogonal matrices,
   furnishing an intuitive “weight interpolation” curve useful for regularizing training.
   
4. **Empirical Validation Across Modalities** –  
   Leveraging BOFT they adapt large vision transformers, massive language models, and text‑to‑image diffusion pipelines on diverse downstream benchmarks spanning computer vision (e.g., classification, detection) and natural language processing (e.g., instruction following). In every setting BOFT outperforms state‑of‑the‑art PEFT baselines—including LoRA and block diagonal OFT—while requiring substantially fewer tunable parameters.
   
Collectively these contributions establish BOFT as a generic parameter‑efficient fine‐tuning framework that marries strong theoretical foundations (orthogonality preserving geometry), practical sparsity via butterfly factorization (low storage & computation), and empirically robust performance across heterogeneous foundation models.
