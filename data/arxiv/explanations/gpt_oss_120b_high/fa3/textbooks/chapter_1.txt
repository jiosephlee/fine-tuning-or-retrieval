\title{A Textbook about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

Chapter 1: Motivation and Context for Faster Attention  

# Recap of the Transformer Encoder–Decoder Structure  

The Transformer architecture introduced by \citet{vaswani2017attention} reshaped modern machine‑learning pipelines by dispensing with recurrent operations and instead relying entirely on an attention mechanism surrounded by feed‑forward neural networks. A typical Transformer stacks several identical layers both in an encoder and a decoder. Each encoder layer receives an input sequence represented as a matrix of token embeddings, adds positional encodings, then applies two main sub‑layers: first a multi‑head self‑attention block and second a position‑wise feed‑forward network. The self‑attention block allows every token to attend to every other token in the same sequence, capturing long‑range dependencies directly through inner products of learned query, key, and value vectors. The decoder mirrors this structure but augments its self‑attention with an additional cross‑attention sub‑layer that attends over the encoder’s hidden states, enabling sequence‑to‑sequence mappings such as translation or summarization. Crucially, all heads across all layers operate in parallel: each head projects the input tokens into its own query (\(\mathbf{Q}\)), key (\(\mathbf{K}\)), and value (\(\mathbf{V}\)) spaces before performing the core attention computation described next. Because every token must be processed jointly across heads, any inefficiency inside one self‑attention step propagates throughout the entire model—making attention the performance “bottleneck” of today’s large Transformers.

# Self‑Attention Formula and Its Quadratic Complexity \(O(N^{2})\)  

For a single head let \(N\) denote the sequence length and \(d\) denote the head dimension (the dimensionality of each query, key, or value vector). Given matrices  

\[
\mathbf{Q},\;\mathbf{K},\;\mathbf{V}\in\mathbb{R}^{N\times d},
\]

the scaled dot‑product self‑attention computes three intermediate quantities:

\[
\begin{aligned}
\mathbf{S} &= \alpha\,\mathbf{Q}\,\mathbf{K}^{\top}\in\mathbb{R}^{N\times N},\\
\mathbf{P} &= \operatorname{softmax}(\mathbf{S})\in\mathbb{R}^{N\times N},\\
\mathbf{O} &= \mathbf{P}\,\mathbf{V}\in\mathbb{R}^{N\times d},
\end{aligned}
\]

where \(\alpha=1/\sqrt d\) scales dot products to improve numerical stability~\citep[Sec.~2]{vaswani2017attention}. The softmax is applied row‑wise after subtracting the rowwise maximum of \(\mathbf S\) to avoid overflow when exponentiating `exp`.  

Both matrix multiplications—first forming \(\mathbf S = \alpha\,\mathbf Q\,\mathbf K^{\!\top}\) and then applying \(\mathbf P\,\mathbf V\)—operate on \(N\times N\) intermediate matrices. Consequently each multiplication requires \(O(N^{2}d)\) floating‑point operations, yielding an overall computational cost proportional to \(N^{2}\). Memory traffic mirrors this cost because naïve implementations materialize the full score matrix \(\mathbf S\) in global device memory before applying softmax. As \(N\) grows modestly—e.g., from a few hundred tokens typical of early language models up to tens of thousands required by modern applications—the quadratic term quickly dominates both runtime and bandwidth consumption on GPUs. This scaling behavior provides the central motivation for research into faster or more memory‑efficient attention kernels.

# Long‑Context Use Cases  

Large language models trained on massive corpora already exhibit impressive capabilities when operating on ordinary context windows of a few thousand tokens~\citep{katharopoulos2020transformers}. Extending context further unlocks qualitatively new behaviors described throughout recent literature:

* **Modeling extended documents** – Papers such as \citet{guo2021longt5} demonstrate that processing entire scientific articles or books without truncation improves summarization fidelity.
* **Multimodal high‑resolution inputs** – High‑resolution images demand thousands of spatial patches~\citep{chen2022scaling}, while audio signals at fine sampling rates yield similarly long sequences~\citep{gulati2020conformer}.
* **Video understanding** – Video frames across many seconds introduce sequence lengths far beyond natural language contexts~\citep{ho2022video}.
* **Codebase navigation** – Large code repositories contain tens of thousands of tokens per file, prompting works such as \citet{roziere2023code} and \citet{li2023starcoder} to explore full code context.
* **User interaction histories** – Dialogue agents that recall years-long conversational histories benefit from long‐term memory mechanisms~\citep{sun2019bert4rec}.
* **Agent planning horizons** – Reinforcement learning agents capable of reasoning over many timesteps require unrolled attentional reasoning across extended horizons~\citep{yao2022react}.

All these scenarios share a common thread: they require an *exact* representation of pairwise interactions across very long sequences because downstream reasoning often depends delicately on subtle alignment patterns (§ “Approximate Attention Techniques”). When attentional scores are degraded—either numerically or algorithmically—the quality loss becomes evident in downstream generation or prediction tasks, reinforcing the demand for high‑throughput yet mathematically faithful implementations of self‑attention.

# Approximate Attention Techniques  

Before hardware‐centric optimizations were explored extensively, researchers sought algorithmic shortcuts that reduce the \(O(N^{2})\) cost while preserving most of its expressive power:

* **Linearizing attentional kernels** – The work of \citet{katharopoulos2020transformers} observes that if one replaces softmax by a kernel function admitting a low‐rank decomposition, then the two matrix multiplications collapse into two linear passes over tokens (\(O(Nd)\)).
* **Random feature expansions** – Building on ideas from kernel approximation, \citet{choromanski2020rethinking} introduce “performer” style random feature maps which replace hard exponentials by inner products between randomly projected queries and keys.
* **Sparse patterns or low‑rank factorisations** – Methods surveyed by \citet{tay2020efficient} explore fixed sparsity masks or adaptive low‑rank factorizations that restrict interactions only to a subset of token pairs.
* **Alternative recurrent‐like recurrences** – Recent designs such as RWKV~\citep{peng2023rwkv}, Retentive Networks~\citep{sun2023retentive}, or Mamba~\citep{gu2023mamba} replace full quadratic attention altogether while retaining stateful dynamics mimicking self−attention behavior.

These approximations dramatically lower FLOP counts at the expense of *exactness*: they introduce bias depending on how well their underlying assumptions hold for a given data distribution. For many large language model training pipelines—especially those involving outliers or rare patterns—the introduced bias can degrade final model quality noticeably~\citep{sahoietc}. Consequently there remained strong interest in preserving exact attention while still reducing its runtime overhead through smarter engineering rather than mathematical relaxation.

# Software Optimization Approaches Before FlashAttention  

Parallelism inherent in GPUs invites clever tiling strategies that shrink traffic between slow off‑chip memory (global DRAM) and fast on‑chip storage (shared memory or registers). Early works leveraged these ideas without altering algorithmic semantics:

* **Memory‐bound kernels** – Implementations such as those described by \citet{rabe2021self} construct custom CUDA kernels where intermediate results are streamed directly from shared memory into registers during computation.
* **Fused kernels** – As demonstrated by \citet{spector2024thunder}, fusing matrix multiplication (`GEMM`), softmax scaling, and final projection into a single GPU launch eliminates redundant reads/writes at each stage.
* **Tile‐level parallelism across sequence dimension** – In `FlashAttention`~\citep[Sec.~1]{dao2022flashattention}, Dong et al.~propose partitioning both queries (`Q`) and keys/values (`K`,`V`) into blocks sized so that all three operations fit entirely inside shared memory before being written back once per block.
* **Hopper‐specific instruction usage** – The follow–up `FlashAttention‑2` refines this approach further by parallelizing over additional sequence tiles (“inner loop”), thereby improving occupancy on newer GPUs~\citep[Sec.~1]{dao2023flashattention2}. Nonetheless empirical measurements reported only about \(35\,%\) utilization on Hopper’s H100 accelerator—a clear signal that even highly tuned GEMM kernels were underexploited compared with vendor libraries attaining \(80{-}90\,%\).

These software advances highlighted two crucial facts relevant throughout this chapter:
1) Substantial speedups are achievable simply by *restructuring data movement*, i.e., keeping intermediate matrices resident on chip during an entire forward pass.
2) Existing frameworks still left considerable headroom when targeting recently released GPU microarchitectures whose execution model supports asynchronous computation units beyond standard CUDA cores.

# Motivation for Exact High‑Throughput Attention Kernels  

The confluence of demanding applications requiring long context windows—described earlier—and observed underutilization even after aggressive tiling motivates an engineering agenda focused on *exact* yet *fast* attention kernels:

1. **Preserving model quality** – By keeping every element exactly as defined by Eq.\;(1), developers avoid approximation errors that could compound during multi‐layer training phases or cause instability when handling outlier features common in large language models~\citep{sundseth...}.
2. **Exploiting modern Tensor Cores** – Hopper’s Tensor Core units support asynchronous warpgroup-wide matrix multiplication (`WGMMA`) directly from shared memory and provide dedicated Tensor Memory Accelerators (`TMA`) for moving data between global DRAM (`GMEM`) and shared memory (`SMEM`). These primitives enable pipelines where data loading overlaps arithmetic without stalling CUDA cores.
3. **Leveraging low‑precision formats** – New FP8 tensor cores double throughput relative to FP16/BF16 while still supporting FP32 accumulation needed for numerically stable softmax reductions.
4. **Closing performance gaps relative to optimized GEMM libraries** – Since vendor‐optimized GEMM (`cuBLAS`/`cuDNN`) achieve near theoretical peak FLOPs/s despite working purely on matrix multiplication primitives, an *exact* self-attention implementation must match their utilisation levels (> 70 %) while also handling softmax’s nonlinearities efficiently.
5. **Providing foundations for future research** – A high‐throughput baseline offers developers stable building blocks upon which advanced transformer variants (e.g., multi-query attention or grouped query structures cited earlier) can be layered without reintroducing quadratic overheads again.

The development path traced through `FlashAttention` → `FlashAttention‑2` → `FlashAttention‑3` reflects iterative progress toward these goals: initial tile fusion eliminated global intermediate storage; subsequent parallelization across sequence tiles broadened occupancy yet revealed asymmetries between Tensor Core instructions and data movement units; finally `FlashAttention‑3` introduces producer–consumer warp specialization together with overlapping GEMM–softmax pipelines—and adds FP8 support through block quantization—to achieve close to optimal hardware utilization (§ later chapters detail these mechanisms). Thus this chapter establishes why speeding up exact self-attention became both an urgent practical necessity—to enable emerging long-context applications—and an intellectually appealing challenge aligning algorithmic design tightly with modern GPU capabilities.
