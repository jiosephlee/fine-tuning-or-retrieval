Chapter Title: Memory Efficiency in BitNet b1.58 and the Role of Embedding Precision

# Introduction

This chapter explores how memory efficiency arises in 1.58-bit Large Language Models, focusing on BitNet b1.58 as introduced in “The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits.” We will examine the specific design choices that drive BitNet b1.58’s memory advantage over full-precision Transformer baselines (e.g., FP16 LLaMA), with particular attention to the precision of embeddings. Drawing solely on the paper’s descriptions and reported results, we will build the intuition for why keeping embeddings in full precision limits the memory savings and why quantizing embeddings to the same 1.58-bit scheme would most likely increase BitNet’s memory advantage even further.

# What Drives Memory Cost in LLMs

For inference, memory consumption in Large Language Models is dominated by two primary factors: storing and moving model parameters, and managing activations. Parameters include all learnable tensors such as the weights in linear layers and the embeddings. Activations arise during forward computation and include intermediate features as well as cache structures for attention (e.g., KV caches). In standard FP16 Transformer LLMs, all of these components are represented at 16 bits, making both storage and transfer from DRAM to on-chip memory relatively costly.

The paper emphasizes that moving parameters from DRAM to on-chip memory is itself a significant cost during inference. Even when attempts are made to enlarge SRAM to improve throughput, DRAM remains more cost-effective to provision at scale, and traffic between DRAM and compute accelerators can become a bottleneck. Reducing the precision of stored tensors alleviates both capacity and bandwidth pressures. This reduction is exactly what BitNet b1.58 targets by quantizing weights to ternary values in $\{-1, 0, +1\}$, represented in $1.58$ bits in the binary system, and by using $8$-bit activations.

# BitNet b1.58: Weights and Activations

BitNet b1.58 constrains every parameter in the model’s linear transformations to ternary values. Concretely, it applies an absmean quantization function that scales a weight matrix $W$ by its average absolute value $\gamma$ and rounds each entry to the nearest integer in $\{-1, 0, +1\}$:
\[
\widetilde{W} = \mathrm{RoundClip}\!\left(\frac{W}{\gamma + \epsilon}, -1, 1\right),
\quad
\gamma = \frac{1}{nm}\sum_{ij} |W_{ij}|,
\quad
\mathrm{RoundClip}(x, a, b) = \max(a, \min(b, \mathrm{round}(x))).
\]
This yields 1.58-bit weights and avoids floating-point multiplications in matrix multiplication. The bulk of computation in BitNet b1.58 therefore centers on integer additions, which, according to the energy model cited in the paper, are orders of magnitude cheaper in energy than floating-point multiplications.

For activations, BitNet b1.58 uses $8$-bit values and scales them per token to $[-Q_b, Q_b]$, avoiding zero-point quantization. This choice simplifies implementation and system-level optimization while having negligible impact on performance, based on the experiments reported.

# Embeddings Remain Full Precision in Reported Results

Although BitNet b1.58 uses 1.58-bit weights in its linear layers and $8$-bit activations, the paper explicitly notes that embeddings remain full precision in the reported measurements. This choice matters for memory because embeddings are large parameter matrices that map token indices to dense vectors and are present at both the input and output of the model. When embeddings stay in FP16, they contribute a fixed full-precision component to the model’s total memory footprint.

The paper provides a key observation about scaling: as the model size increases, the proportion of memory attributable to the embedding decreases. In other words, for larger models, embeddings form a smaller fraction of the total parameters relative to the many linear layers that grow with depth and width. Consequently, BitNet b1.58’s memory advantage increases with model size even when embeddings remain in FP16, because an increasing fraction of the total parameters are stored at 1.58 bits instead of 16 bits.

# Scaling Behavior and Memory Advantage

Empirically, the paper reports that BitNet b1.58 is substantially more memory-efficient than FP16 LLaMA across sizes, and that this advantage grows with scale. For example, at around 3B to 3.9B parameters, BitNet b1.58 uses roughly $3.32$ to $3.55$ times less GPU memory while also being faster. At 70B parameters, BitNet b1.58 is $4.1$ times faster than FP16 LLaMA, and memory exhibits a similar improving trend because embeddings occupy a smaller proportion of the total memory footprint at larger scales. These measurements were obtained with kernels optimized for low-bit computation and with embeddings kept in full precision.

This pattern provides the intuition that memory savings are driven by two effects that compound with scale. First, more of the model’s parameters are in low-bit form, which reduces both capacity and bandwidth requirements. Second, as the embedding proportion shrinks with model size, the residual “full-precision island” inside an otherwise low-bit model contributes less to the total memory burden, allowing the low-bit benefits in the rest of the model to dominate.

# Why Quantizing Embeddings Would Increase the Memory Advantage

Given the above, consider the role of embedding precision in total memory. When embeddings are full precision, they introduce a fixed-cost component that does not benefit from the 1.58-bit quantization used elsewhere. This fixed-cost component limits the overall memory reduction achievable by BitNet b1.58. The paper’s own analysis highlights that this component becomes less proportionally important for larger models, but it is still a part of the measured memory.

Therefore, if embeddings were quantized to the same $1.58$-bit scheme, the fixed-cost full-precision component would be reduced to low-bit as well. Because the paper shows that memory and latency advantages grow as more of the computation and storage shift to low-bit representations, removing the remaining full-precision embeddings would most likely increase BitNet’s memory advantage over FP16 LLaMA. This conclusion follows directly from the paper’s rationale: memory footprint improves as precision decreases, DRAM bandwidth costs fall when moving fewer bits, and the benefits compound with scale. Since embeddings are currently an exception to low precision in the reported measurements, making them low precision would push the memory advantage even further.

# System-Level Intuition: Capacity and Bandwidth

The paper emphasizes that transferring model parameters from DRAM to on-chip memory is expensive, and that lower-bit representations reduce both capacity and bandwidth requirements. In practice, an LLM’s embeddings must be read from memory during inference in a manner similar to other parameters. Keeping them in FP16 increases the number of bits transferred compared to 1.58-bit representations.

The authors’ measurements already show a strong memory reduction when only the linear-layer weights are quantized and activations reduced to $8$ bits. Because embeddings remain FP16 in those measurements, quantizing embeddings would decrease the total bits that need to be moved and stored even more. As the paper points out, such reductions translate into lower inference latency, higher throughput, and energy savings, all under the same theme that lower precision reduces the cost of moving and processing data.

# Caveats Within the Paper’s Scope

The paper’s reported results use kernels and configurations that keep embeddings at full precision, and the memory, latency, and energy measurements are taken under that assumption. It also notes that both latency and memory were measured with a 2-bit kernel, and that there is room for further optimization. Within this experimental scope, the paper does not present explicit embedding quantization results. However, its analysis provides the necessary ingredients to reason about the impact of embedding precision on memory: embeddings contribute a full-precision portion to the overall footprint, and the advantage of BitNet b1.58 increases as more of the model’s components are represented in low-bit formats.

# Conclusion

BitNet b1.58 achieves its memory advantage through 1.58-bit weights and $8$-bit activations, significantly reducing the capacity and bandwidth requirements relative to FP16 LLaMA. In the reported measurements, embeddings remain full precision, and the paper notes that their proportional contribution decreases as model size grows. Because the memory advantage increases as more of the model is represented in low-bit form, quantizing embeddings to the same 1.58-bit scheme would most likely further increase BitNet’s memory advantage over FP16 LLaMA. This conclusion aligns with the paper’s core observations about how precision reductions translate to system-level efficiency in both storage and data movement.
