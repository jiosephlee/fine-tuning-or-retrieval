Chapter 4: **Butterfly Factorization: Theory and Construction**

# Cooley‑Tukey FFT and Butterfly Graphs  

The celebrated Cooley‑Tukey algorithm provides the first fast method for computing the discrete Fourier transform (DFT).  For an input vector $\mathbf{x}\in\mathbb{R}^{d}$ with $d=2^{N}$, the DFT is the linear map  
\[
\mathbf{y}= \mathbf{F}_{d}\,\mathbf{x},\qquad 
\mathbf{F}_{d}[k,\ell]=\exp\!\bigl(-2\pi i k\ell /d\bigr),
\]  
which would naïvely require $O(d^{2})$ arithmetic operations.  Cooley and Tukey observed that the DFT can be decomposed recursively into two DFTs of half the size, yielding the recurrence  
\[
\mathbf{F}_{d}= \underbrace{\begin{bmatrix}
\mathbf{I}_{d/2}& \mathbf{I}_{d/2}\\[2pt]
\mathbf{I}_{d/2}& -\mathbf{I}_{d/2}
\end{bmatrix}}_{\text{butterfly}}\;
\bigl(\mathbf{F}_{d/2}\oplus \mathbf{F}_{d/2}\bigr)\;
\underbrace{\begin{bmatrix}
\operatorname{diag}(\omega^{0}) & \\ & \operatorname{diag}(\omega^{1})\\[-4pt]
 & \ddots \\[-4pt]
 & & \operatorname{diag}(\omega^{d/2-1})
\end{bmatrix}}_{\text{twiddle factors}},
\]  
where $\omega=\exp(-2\pi i/d)$ and $\oplus$ denotes block‑diagonal concatenation.  The central $2\times 2$ block matrix is called a **butterfly** because it connects each pair of “even’’ and “odd’’ indices, exactly as a butterfly’s wings cross.  

If we draw each stage of the recursion as a layer of nodes, edges exist only between nodes belonging to adjacent layers, and every edge corresponds to a non‑zero entry in the matrix that implements that stage.  The resulting layered digraph is known as a **butterfly graph**.  A key property of this graph is that a source node at the first layer can reach any sink node at the final layer using exactly $N=\log_{2} d$ edges; consequently, the total number of edges scales as $O(d\log d)$.  This sparsity pattern underlies the reduction from $O(d^{2})$ to $O(d\log d)$ arithmetic complexity in the FFT.

# Definition of Butterfly Factors and Recursive Butterfly Matrices  

Motivated by the FFT graph, we formalize a family of sparse matrices that can be multiplied together to obtain a dense transformation while retaining only $O(d\log d)$ trainable parameters.

### Butterfly factor  

For an even integer $k$, define a **butterfly factor** $\mathbf{B}^{F}(k)\in\mathbb{R}^{k\times k}$ as  
\[
\mathbf{B}^{F}(k)=
\begin{bmatrix}
\operatorname{diag}(\mathbf{d}_{1}) & \operatorname{diag}(\mathbf{d}_{2})\\[4pt]
\operatorname{diag}(\mathbf{d}_{3}) & \operatorname{diag}(\mathbf{d}_{4})
\end{bmatrix},
\tag{1}
\]  
where each $\mathbf{d}_{i}\in \mathbb{R}^{k/2}$ supplies independent scalar entries for a diagonal block.  The matrix consists of four diagonal blocks arranged in a $2\times 2$ pattern; all off‑diagonal entries are zero, which yields exactly $k$ non‑zero elements.

### Recursive butterfly matrix  

Let $d=2^{N}$ and let $\tilde{\mathbf B}(d,k)$ denote a block‑diagonal matrix whose blocks are butterfly factors of size $k$:  
\[
\tilde{\mathbf B}(d,k)=
\operatorname{diag}\bigl(\underbrace{\mathbf B^{F}_{1}(k),\,\dots,\, \mathbf B^{F}_{d/k}(k)}_{d/k\; \text{blocks}}\bigr)\in \mathbb {R}^{d\times d}.
\tag{2}
\]  
Using these components we define the **butterfly matrix** recursively:
\[
\begin{aligned}
\mathbf B(d) &=
 \tilde{\mathbf B}\!\bigl(d,d\bigr)
 \begin{bmatrix}
   \mathbf B(d/2) & \mathbf 0\\[2pt]
   \mathbf 0      & \mathbf B(d/2)
 \end{bmatrix} \\[4pt]
&= \tilde{\mathbf B}(d,d)\,
   \tilde{\mathbf B}\!\bigl(d,d/2\bigr)\,
   \tilde{\mathbf B}\!\bigl(d,d/4\bigr)\,
   \cdots\, 
   \tilde{\mathbf B}(d,2).
\end{aligned}
\tag{3}
\]  
Each multiplication introduces a new set of edges between two consecutive layers of the information‑transmission graph; after $\log_{2} d$ stages every source node can reach every sink node.  Because each $\tilde{\mathbf B}(d,k)$ contains only $d$ non‑zero entries (one per row), the total number of stored scalars after $\log_{2} d$ stages is $O(d\,\log d)$.

# Block‑Butterfly Components and Permutation Structure  

The formulation above uses scalar entries in each diagonal block.  To increase flexibility without breaking sparsity we replace each scalar by a small dense matrix of size $b\times b$.  Let $b$ divide $d$, and define a **block butterfly factor** $\mathbf B^{F,b}(k)$ by substituting each scalar $\; d_{i,j}$ in (1) with an independent trainable matrix $\;\mathbf D_{i,j}\in \mathbb {R}^{b\times b}$:
\[
\mathbf B^{F,b}(k)=
\begin{bmatrix}
\operatorname{blockdiag}(\!\mathbf D_{1,1},\, … ,\, \mathbf D_{1,k/2}\!) &
\operatorname{blockdiag}(\!\mathbf D_{1,k/2+1},\, … ,\, \mathbf D_{1,k}\!)\\[6pt]
\operatorname{blockdiag}(\!\mathbf D_{2,1},\, … ,\, \mathbf D_{2,k/2}\!) &
\operatorname{blockdiag}(\!\mathbf D_{2,k/2+1},\, … ,\, \mathbf D_{2,k}\!)
\end{bmatrix},
\]  
where each block diagonal term contains $b\times b$ sub‑matrices placed along its diagonal.  The resulting $\tilde{\mathbf B}^{b}(d,k)$—the block‑diagonal stacking analogue of (2)—has exactly $d/b$ blocks, each of size $k$, and therefore still contributes only $O(d)$ trainable parameters per stage.

A crucial observation is that all butterfly components differ from one another only by **permutations of rows and columns**.  When we move from $\tilde{\mathbf B}^{b}(d, k)$ to $\tilde{\mathbf B}^{b}(d, k/2)$ we essentially regroup the existing blocks according to a perfect shuffle permutation (the same permutation used in the FFT).  Consequently, once we have learned the set of small matrices $\{\mathbf D_{i,j}\}$ for one stage, later stages reuse them with systematic index shuffling; this is why the overall parameter budget grows only linearly with the number of stages.

# Ensuring Orthogonality of Each Component  

Our ultimate goal is to construct a dense orthogonal matrix $\mathbf R$ as a product of several sparse orthogonal factors:
\[
\boxed{\displaystyle 
   \mathbf R = 
   \prod_{\ell=1}^{m}\tilde{\mathbf B}^{b}_{(\ell)} },
   \qquad 
   (\tilde{\mathbf B}^{b}_{(\ell)})^{T}\tilde{\mathbf B}^{b}_{(\ell)}=
   \tilde{\mathbf B}^{b}_{(\ell)} (\tilde{\mathbf B}^{b}_{(\ell)})^{T}= 
   \mathbf I_{d}.
   } 
   \tag{4}
]  

Because orthogonal matrices form a group under multiplication, it suffices to enforce orthogonality on each factor individually.  Two standard constructions are used:

### (i) Cayley transform on each sparse factor  

Every real skew‑symmetric matrix $\boldsymbol Q=-\boldsymbol Q^{T}$ defines an orthogonal matrix via the Cayley map
\[
   \mathcal C(\boldsymbol Q)= (\boldsymbol I+\boldsymbol Q)(\,\boldsymbol I-\boldsymbol Q)^{-1}.
   \tag{5}
]  
In practice we apply (5) separately to each dense block inside a butterfly factor (or to each $2\times 2$ scalar factor).  The transformation preserves differentiability and guarantees exact orthogonality throughout training.

### (ii) Direct parameterization as $2\times 2$ rotations  

When $b=1$, every butterfly factor reduces to a collection of independent $2\times 2$ blocks
%
\[
   \begin{bmatrix}
      c & -s\\[2pt]
      s & c
   \end{bmatrix},
   \qquad c=\cos \theta,\; s=\sin \theta,
   \tag{6}
]  
%
parameterized by an angle $\theta$.  Enforcing this structure automatically yields an orthogonal block because any rotation matrix satisfies $\boldsymbol R^{T}\boldsymbol R=\boldsymbol I$.  For larger blocks $(b>1)$ we embed an arbitrary orthogonal matrix (e.g., via QR decomposition or successive Givens rotations) inside each $2b\times 2b$ sub‑block, again guaranteeing orthogonality.

Both strategies share two practical advantages: they keep the number of trainable scalars equal to the number of free entries in the sparse factor (i.e., roughly $(b-1)d/2$ per stage), and they guarantee that gradient updates never leave the orthogonal manifold.

# Parameter Count Analysis  

Consider a linear layer with input dimension $d$ and output dimension $n$.  In naïve Orthogonal Finetuning (OFT) we would learn a *full* orthogonal matrix $\boldsymbol R'\in O(d)$ directly; storing an arbitrary element of $O(d)$ requires $(d^{2}-d)/2$ independent parameters because orthogonal matrices have $\frac12 d(d-1)$ degrees of freedom.  Hence OFT’s parameter budget scales as
%
\[
    |\Theta_{\text {full OFT}}| = O(d^{\,2}). 
    \tag{7}
]  

A common remedy is **block‑diagonal OFT**, which partitions $\boldsymbol R'$ into $r = d/b$ blocks of size $b\times b$.  Each block contributes $(b^{\,2}-b)/2$ trainable scalars, giving
%
\[
    |\Theta_{\text {blk}}| = r\, O(b^{\,2})
    = O(b d).
    \tag{8}
]  
When $b$ is modest (e.g., $8$), this yields substantial savings but at the cost of severely constrained expressivity: rows belonging to distinct blocks never interact.

The **Butterfly Orthogonal Finetuning (BOFT)** construction replaces one dense block by a product of $m=\log_{k/(k/2)}(d/k_{\min}) = O(\log d)$ sparse factors, each with exactly $d/b$ non‑zero *trainable* entries. Consequently,
%
\[
    |\Theta_{\text {BOFT}}|
    = m\, O(b d)
    = O( d\, b\, \log d).
    \tag{9}
]  
If we set the smallest block size to its minimal value $b=2$, then
%
\[
    |\Theta_{\text {BOFT}}|
    = O( d\, \log d),
    ] 
which is dramatically smaller than both full OFT ($O(d^{\,2})$) and block‑diagonal OFT with any fixed block size ($O(b d)$).  

To summarize:

| Method | Parameter growth | Typical expressive power |
|--------|------------------|--------------------------|
| Full OFT | $\displaystyle O(d^{\,2})$ | Can represent any orthogonal transformation |
| Block‑diagonal OFT | $\displaystyle O(b d)$ (fixed \(b>1)\) | Limited to independent intra‑block rotations |
| BOFT | $\displaystyle O(d\, b\, \log d)$ → \(O(d\,\log d)\) for \(b=2$\) | Dense orthogonal matrices with structured sparsity; substantially more expressive than block‑diagonal while remaining highly parameter efficient |

Thus butterfly factorization offers an elegant middle ground: it retains enough degrees of freedom to approximate arbitrary orthogonal maps while requiring only logarithmically many extra parameters compared with naïve dense parametrizations.

In this chapter we have traced butterfly matrices from their origin in fast Fourier transforms through their graph‑theoretic interpretation as information‑transmission networks. By defining butterfly factors, recursing over them, and enforcing orthogonality via either Cayley transforms or explicit rotations, we obtain **Orthogonal Butterfly**—a compact yet expressive parameterization that underpins modern parameter‑efficient finetuning methods such as BOFT. The subsequent chapters will explore how this construction integrates into large‑scale vision and language models and why its structured inductive bias translates into superior generalization on downstream tasks.
