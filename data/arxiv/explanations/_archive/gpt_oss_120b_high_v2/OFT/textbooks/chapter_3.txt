# Mathematical formulation of subject‑driven generation  

The starting point for any text‑to‑image diffusion model is a pretrained parametric distribution  
\(p_{\theta^{0}}(\mathbf{x}\mid\mathbf{y})\), where \(\mathbf{x}\in\mathbb{R}^{H\times W\times C}\) denotes an image,
\(\mathbf{y}\) denotes a textual prompt, and \(\theta^{0}\) aggregates all weight matrices,
biases and other learnable tensors of the model (e.g., the UNet backbone of Stable Diffusion).  

During training a forward‐noising Markov chain is introduced  
\(q(\mathbf{x}_{t}\mid\mathbf{x}_{0})=\mathcal N(\mathbf{x}_{t};\sqrt{\bar{\alpha}_{t}}\mathbf{x}_{0},
(1-\bar{\alpha}_{t})\mathbf I)\),
where \(t=1,\dots,T\) indexes timesteps,
the variance schedule is encoded by scalars \(\beta_{t}\in(0,1)\)
and their cumulative products are written as  
\(\bar{\alpha}_{t}= \prod_{s=1}^{t}(1-\beta_{s})\).
The reverse process predicts either the added noise or the denoised image;
the training objective is an instance‑wise denoising loss commonly called  
the *diffusion loss*  
\[
\mathcal L_{\mathrm{diff}}(\theta;\,\mathbf{x}_{0},\,\mathbf y)
=
\E_{t,\epsilon}
   \Bigl[
      \bigl\|
        \epsilon-\epsilon_{\theta}
          (\sqrt{\bar{\alpha}_{t}}\!\mathbf{x}_{0}
            +\sqrt{1-\bar{\alpha}_{t}}\epsilon,
           t,
           \mathbf y)
      \bigr\|^{2}
   \Bigr],
   %%%%
   % where epsilon_theta is the predicted noise
   %%%
   . 
\tag{1}
\]  

In **subject‑driven generation** one is given a very small collection  
\(\mathcal D_{\mathrm{subj}}=\{(\mathbf x^{(k)},\,c^{(k)} )\}_{k=1}^{N}\)
of images (\(N {\approx} 3{-}5)\) depicting a single object or person,
plus a textual token that identifies this *subject*.  
The goal is to adapt the pretrained model so that it can render the same
subject under arbitrary novel prompts while retaining all other “general”
generation capabilities learned during pretraining.  

Let each linear layer \(l\) of the UNet be represented by a weight matrix
\(W^{0}_{l}\in\mathbb R^{d_{l}\times n_{l}}\).
Orthogonal Finetuning (OFT) proposes to replace every such matrix by an
orthogonally transformed counterpart
\(W_{l}=R_{l}W^{0}_{l}\),   
with an orthogonal matrix \(R_{l}\in O(d_{l})=\{R~|~R^{\!\top}R=I_{d_{l}}\}\).
The *hyperspherical energy* (HE) of a layer,
defined in Eq.~(2) of the original work,
captures all pairwise angular relationships among its normalized neurons:
\[
    {\rm HE}(W)=
    \sum_{i\neq j}
        \Bigl(
           \bigl\|\hat{\bm w}_{i}-\hat{\bm w}_{j}\bigr\|
        \Bigr)^{-1},
    \
    {\rm where}\;
    \hat{\bm w}_{i}= 
    {\displaystyle 
      {\frac{\bm w_{i}}{\|\bm w_{i}\|}}
    } .

]
Because any common orthogonal transformation leaves every inner product
(and therefore every cosine similarity) unchanged,
we have  
\( {\rm HE}(R\,W^{0})={\rm HE}(W^{0})     ~~     (\forall\,R^\top R=I).\)

Subject‑driven finetuning is then posed as an optimization over the set 
of orthogonal matrices
\( {\cal R}= \{ R_{l}\}_{l=1}^{L}\):
%
\[
   \min_{\mathcal R}
        \
        {\underbrace{
            \sum_{k=1}^{N}
            \mathcal L_{\mathrm{diff}}

                {\bf x}^{(k)},

            {\rm data~fitting}}
        }

        {\underbrace{
            \lambda_{\!{\rm HE}}

            \sum_{l=1}^{L}
                \bigl|
                {\rm HE}(R_{l}W^{0}_{l})
                -
                {\rm HE}(W^{0}_{l})
                |
                ^2

            {\rm hyperspherical~energy~preservation}}

Here 
\(θ_{\!\mathcal R}\)
denotes *all* parameters obtained after applying every orthogonal transform;
the scalar  λ​HE balances fitting vs structure preservation.
When one wishes additionally to keep each transform close to identity,
the **Constrained Orthogonal Finetuning** variant enforces an explicit radius bound:
%
\( 	‖R_{l}-I‖_F 	≤ ε,\)
which yields Eq.~(5) in the source text.  

The final finetuned model produces images conditioned on any novel prompt
by feeding forward through those transformed layers while keeping every other
component—including cross‑attention between text embeddings and visual features—
unchanged from pretraining.

### Mathematical formulation of subject‑driven generation  

A pretrained text‑to‑image diffusion model is denoted by parameters  
`\(\theta^{0}``, which contains all weight matrices `\(W^{0}_l∈ℝ^{d_l×n_l}`` at every layer `\(l`„ .  
During denoising training it minimizes the standard diffusion loss  

```
ℒ_diff(θ;x₀,y)=Eₜ,ε∥ε−ε_θ(
√α̅ₜ·x₀+√(1−α̅ₜ)·ε,t,y
 )∥² ,                                    (1)
```  

where `α̅ₜ=∏ₛ≤ᵗ(1−β_s)` comes from the variance schedule `β₁,…,β_T`.  

In **subject‑driven generation** we are given only a few photographs  
`\({𝔛_subj={x⁽ᵏ⁾}_{k=1}^{N}}` `` (`N≈3–5`) together with a textual token that identifies
the subject (e.g., “a photo of *person*”).  
The learning goal is to adapt `θ⁰` so that new prompts produce images that contain **the same visual identity** while preserving all other generative capabilities learned during pretraining.

OFT solves this by learning **layer‑wise orthogonal transformations** `\(R_l∈O(d_l)\)` (`O(d)` = set of orthogonal matrices):
```
W_l = R_l·W⁰_l ,    s.t.  R_lᵀR_l = I .                         (2)
```  

Since an orthogonal matrix preserves every inner product among neurons,
the **hyperspherical energy**  

```
HE(W)= Σᵢ≠ⱼ ∥ŵ_i−ŵ_j∥⁻¹ ,    ŵ_i = w_i / ∥w_i∥               (3)
```  

remains exactly unchanged:
`HE(R·W⁰)=HE(W⁰)` . Consequently OFT guarantees that finetuning does **not**
alter pairwise neuron angles – a property observed empirically to correlate with semantic preservation (§ “Why Does Orthogonal Transformation Make Sense?”).

For subject adaptation we therefore minimise a joint objective

```
min_R  Σ_k ℒ_diff(θ_R ; x⁽ᵏ⁾ , y_subj )
       + λ_HE Σ_l ∥ HE(R_l·W⁰_l ) − HE(W⁰_l )∥²                  (4)
s.t.  R_lᵀR_l = I .
```    

Here `y_subj` denotes the prompt containing both a class description and the learned identifier token.
`λ_HE≥0` balances fidelity against deviation from pretraining structure.
When additional stability is required one adds an explicit radius constraint —the **Constrained Orthogonal Finetuning** (COFT):

```
‖R_l − I‖_F ≤ ε ,                                            (5)
```  

which forces every transform to stay within an `ε`‑ball around identity while still being orthogonal.

### Mathematical formulation of controllable generation  

Controllable generation supplies an extra spatial condition `c` (e.g., canny edges,
segmentation map or facial landmark heatmap).  
A training example consists of `(x⁽ᵏ⁾ , c⁽ᵏ⁾ , y⁽ᵏ⁾)` where `y⁽ᵏ⁾` is a textual prompt.
The underlying diffusion model already accepts multiple conditioning inputs –
the usual cross‑attention pipeline processes tokens `y`, whereas an auxiliary branch
injects `c`.  During finetuning only the backbone weights are altered via OFT;
the conditioning modules remain frozen.

The optimisation mirrors Eq.(4), simply augmenting the data term with conditioning on `c`:

```
min_R  Σ_k ℒ_diff(θ_R ; x⁽ᵏ⁾ | c⁽ᵏ⁾ , y⁽ᵏ⁾ )
       + λ_HE Σ_l ∥ HE(R_l·W⁰_l ) − HE(W⁰_l )∥²                  (6)
s.t.  R_lᵀR_l = I   ,    ‖R_l−I‖_F ≤ ε   (optional COFT).
```  

The conditional diffusion loss `ℒ_diff(... | c , y )` has exactly the same form as Eq.(1); its only difference lies in feeding both signals into the denoiser at each timestep.
Thus COFT/OFT provide a unified finetuning scheme applicable both when only textual prompts change (subject-driven case) **and** when extra geometric guidance must be obeyed.

### Evaluation metrics: CLIP‑I/DINO similarity, CLIP‑T score, LPIPS diversity  

To assess whether finetuning preserves **pretrained generative quality**, three families of metrics are employed throughout the experiments.

* **Image–image semantic similarity**  
  *CLIP‑I* computes cosine similarity between CLIP visual embeddings `[radford2021learning]` extracted from a generated image `ĥx` and those from real reference images `{x_real}` depicting the target subject:
  ```
  CLIP‑I = E_x_real[ cos( f_CLIP_img(ĥx), f_CLIP_img(x_real) ) ] .
  ```  
  *DINO* follows exactly the same recipe but replaces CLIP’s encoder by ViT‐S/16 trained under self‑supervised DINO objectives `[caron2021emerging]`. Both scores reflect how well identity‐specific details survive finetuning.
* **Text–image alignment**  
  *CLIP‑T* measures cosine similarity between a CLIP text embedding of the prompting sentence `y` and a CLIP image embedding of its output:
  ```
  CLIP‑T = cos( f_CLIP_txt(y), f_CLIP_img(ĥx) ) .
  ```  
  High values indicate faithful adherence to semantic instructions.
* **Diversity across samples**  
  *LPIPS* `[zhang2018unreasonable]` evaluates perceptual distance between two images drawn from the same conditional distribution (`same y`, identical subject token). The average LPIPS value over many pairs quantifies intra‑class variety; larger values denote more diverse generations without sacrificing realism.


All four scores are reported per method after repeating finetuning with many random seeds so that stochastic effects are averaged out—exactly as described in Table 2 of the original manuscript.

### Control consistency metrics for Canny edges, segmentation maps, facial landmarks  

Controllable generation requires not only realistic output but also **faithful obedience** to its auxiliary signal. For each downstream task a dedicated quantitative consistency measure is defined by first extracting an estimated control signal from a generated image using off‑the‑shelf detectors, then comparing this estimate with its ground truth counterpart.

| Control modality | Extraction pipeline | Consistency measure |
|------------------|--------------------|---------------------|
| **Canny edge → image** (`C2I`) | Apply classic Canny detector on `ĥx`. | Intersection‑over‑Union (IoU) between detected edge map and input edge map; additionally F₁ score computed from pixelwise precision/recall. |
| **Segmentation map → image** (`S2I`) | Feed `ĥx` through a pretrained semantic segmentation network (e.g., DeepLabV3). | Mean IoU across semantic categories plus per‑pixel *mean accuracy* and *overall accuracy* averaged over all classes. |
| **Facial landmarks → image** (`L2F`) | Run a landmark detector such as FAN or MediaPipe on `ĥx`. | Average Euclidean (`ℓ₂`) distance between predicted landmarks `{ℓ̂}` and supplied landmarks `{ℓ}` after aligning coordinate systems. |

These metrics directly quantify how much information embedded in `c` survives through generations powered by OFT or COFT. Higher scores (= larger IoU/F₁ or smaller ℓ₂ error) indicate stronger controllability. They underpin Table 3 where OFT attains markedly better values than LoRA, ControlNet or T2I‑Adapter.

### α/β hyperparameters in diffusion sampling  

The forward noising process hinges on two scalar sequences:

```
β_t ∈ (0,1)             – variance added at step t,
α_t = 1 − β_t           – complementary “signal” coefficient,
α̅_t = ∏_{s=1}^{t} α_s   – cumulative product governing overall signal decay.
```  

At timestep `t` an intermediate noisy latent obeys

```
x_t = √α̅_t · x_0 + √(1−α̅_t) · ε ,      ε ∼ N(0,I).               (7)
```  

During inference one runs a reverse chain guided by predictions produced by
the finetuned denoiser (`θ_R`).  
The scalars `α_t` & `β_t` therefore dictate how aggressively noise is removed at each step,
and they also appear inside classifier–free guidance formulas where one trades off unconditional versus conditional predictions via a guidance scale γ (“strength” parameter). While those sampling‐time knobs are inherited unchanged from standard DDPM / Stable Diffusion pipelines `[ho2020denoising]`, their exact numerical schedule (`β₁,…,β_T`) influences final fidelity—particularly when new conditioning signals have been introduced through OFE/C​OFT finetuning. Consequently experimental protocols keep these schedules identical across baselines so that observed improvements stem solely from better weight adaptation rather than altered sampling dynamics.

#### Summary  

By formulating both **subject‑driven** and **controllable** finetuning as constrained optimisation problems over orthogonal transforms, OFT preserves hyperspherical energy—an angle‐preserving invariant empirically linked to semantic stability—and simultaneously adapts models to new downstream requirements. Rigorous evaluation leverages four complementary metrics—CLIP‑I/DINO for identity retention, CLIP‑T for prompt alignment, LPIPS for diversity—and three task–specific consistency scores that directly assess obedience to auxiliary signals such as edges, segmentations or facial landmarks. Together these formal problem statements and evaluation criteria provide a principled foundation for studying future fine‑tuning strategies in large text–to–image diffusion systems.
