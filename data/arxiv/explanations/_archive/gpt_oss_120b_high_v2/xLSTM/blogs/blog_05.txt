# Scaling LSTMs to Billions of Parameters: **xLSTM**’s Performance on Language Modeling Benchmarks  

*How does an “old‑school” recurrent network fare when we crank its size up to the billions‑parameter regime?* The recent **xLSTM** paper gives us a compelling answer: with a few clever tweaks—exponential gating and richer memory structures—scaled‑up LSTMs can compete with, and often surpass, state‑of‑the‑art Transformers and State‑Space Models (SSMs) on a suite of language‑modeling benchmarks.  

Below is a concise walk‑through of the experiments that back this claim, focusing on three key evaluation fronts:

1. **Validation perplexity on massive web‑text corpora**  
2. **Long‑range reasoning (Long Range Arena)**  
3. **Domain‑specific token prediction (PALOMA benchmark)**  

---

## 1️⃣ Validation Perplexity – The Gold Standard Metric  

### Setup  
* **Training data:** *SlimPajama* – a curated mix of open‑source web text.  
* **Training budgets:**  
  * **15 B** token run (≈ GPT‑3 scale) – all models share the same compute budget.  
  * **300 B** token run – pushes models toward true Large Language Model (LLM) regimes.  
* **Model families compared:**  
  * Classic Transformers (GPT‑3 sized, LLaMA)  
  * SSMs (H3, Mamba)  
  * Recurrent baselines & linear Transformers (RWKV‑4/5/6, GLA, HGRN2)  
  * **xLSTM** variants – mixtures of *sLSTM* (scalar memory + mixing) and *mLSTM* (matrix memory + covariance update), denoted e.g., `xLSTM[7:1]` (7 mLSTM blocks / 1 sLSTM block).  

### What the numbers tell us  

| Tokens | Model family | Relative validation perplexity |
|--------|--------------|------------------------------|
| **15 B** | GPT‑3 size Transformer | Baseline |
|        | LLaMA | Higher than baseline |
|        | SSMs (H3 / Mamba) | Higher than baseline |
|        | Linear RNNs (RWKV‑4…) | Higher than baseline |
|        | **xLSTM** (`xLSTM[7:1]` & `xLSTM[1:0]`) | **Lowest** among *all* listed methods |

*Even though absolute numbers are omitted for brevity, the paper reports that both `xLSTM[7:1]` and `xLSTM[1:0]` achieve a **clear perplexity win** over every competing architecture at this token budget.*  

#### Ablation insights  

A stepwise transformation from vanilla LSTM → pre‑LayerNorm residual backbone → post up‑projection block → exponential gating → matrix memory reveals:

| Added component | Perplexity impact |
|-----------------|------------------|
| Residual backbone    | Modest drop |
| Post up‑projection    | Further reduction |
| **Exponential gating** | Largest single gain |
| **Matrix memory (`mLSTM`)** | Additional improvement |

Both exponential gating *and* matrix memory are essential; removing either erodes the advantage substantially.

### Scaling up to **300 B** tokens  

When we crank the data budget up twentyfold:

* Models from **125 M** up to **1.3 B** parameters were trained.
* Across every size class,
  * `xLSTM[1:0]` and `xLSTM[7:1]` again attained the *best* validation perplexities.
  * The gap widens as model size grows—mirroring the classic “scaling law” behavior where an improved offset translates into better performance at any scale.
* In side‐by‐side plots of loss vs. model size (“power‑law fits”), **xLSTMs sit below Transformers and SSMs**, indicating that a future 10 B or even 100 B‐parameter xLSTM would retain this lead.

---

## 2️⃣ Long Range Arena – Do Recurrent Networks Still “Forget”?

The Long Range Arena (LRA) aggregates tasks that demand handling sequences up to several thousand timesteps (e.g., ListOps, Retrieval–QA). Historically RNNs fell behind because they lack explicit long‑range attention mechanisms.

### xLSTM’s performance

* On *all* seven LRA tasks, an xLSTM configuration achieved scores that were:
  * Comparable to top SSMs such as Mamba.
  * Superior to vanilla LSTMs and most pure Transformer baselines run under identical compute constraints.
* The standout factor is the combination of:
  * **Exponential forget gates**, which allow rapid attenuation or reinforcement of past information.
  * **Matrix memory (`mLSTM`)**, which stores key–value pairs directly inside a learned covariance matrix—effectively providing a “fast weight” attention that scales linearly with sequence length.
* Consequently, xLSTMs exhibit **linear compute & constant memory cost w.r.t sequence length**, making them naturally suited for very long contexts without blowing up GPU memory—a practical advantage over quadratic attention.

## 3️⃣ PALOMA Benchmark – Domain Adaptability in the Wild  

The PALOMA suite evaluates next‑token prediction across **571 distinct textual domains**, ranging from news sites (`nytimes.com`) to Reddit communities (`r/depression`). It’s an excellent proxy for real‐world robustness.

### Head‑to‑head results

| Model family / variant | # Domains where it wins against others |
|------------------------|----------------------------------------|
| **xLSTM[1:0]** (**matrix memory only**) | Beats Mamba on **568 / 571** domains (**99.5 %**) |
|                        | Beats LLaMA on **486 / 571** domains (**85 %**) |
|                        | Beats RWKV‑4 on **570 / 571** domains (**99.8 %**) |
| **xLSTM[7:1]** (**mostly mLSTM + one sLSTM**) | Similar dominance but slightly less pronounced than `xLSTM[1:0]`. |

Across all domains the *average token prediction perplexity* of `xLSTM[1:0]` was lower than any other method tested—including high‑capacity Transformers—showing that richer internal memory translates into tangible gains on heterogeneous corpora.

> **Takeaway:** Even when confronted with niche vocabularies or highly specialized styles, an appropriately sized matrix‐memory recurrent model can outperform attention‐based giants that have orders of magnitude more parameters per token processed.

---

## 4️⃣ Putting It All Together – Why Does Scaling Work?  

### Core innovations that unlock performance

1. **Exponential gating:**  
   * Replaces sigmoid gates with $\exp(\cdot)$ while keeping numerical stability via a “stabilizer state”.  
   * Enables drastic revisions of stored information—a crucial ability for tasks like nearest-neighbor search where later inputs may need to overwrite earlier ones.
2. **Memory structure upgrades:**  
   * **sLSTM:** Keeps scalar cells but introduces a normalizer state $n_t$ so hidden states are computed as $h_t = o_t \,\frac{c_t}{n_t}$—a form of dynamic scaling that reduces saturation.
   * **mLSTM:** Stores a full $d\times d$ matrix $\mathbf{C}_t$, updated by an outer product $\mathbf{v}_t \mathbf{k}_t^\top$ modulated by exponential input/forget gates—essentially a learned fast weight cache akin to associative memories.
3. **Residual block backbones with up‑projection:**  
   * Aligns with modern pre‑LayerNorm transformer stacks while providing high‐dimensional non‑linear embeddings per block—leveraging Cover’s theorem for better separability of histories.
4. **Parallelizability where possible:**  
   * The $m\!$ variant’s recurrence can be rewritten as a purely feed‑forward scan; s\! variant retains some sequential mixing but still runs at <2× slower than its parallel counterpart thanks to custom CUDA kernels.

### Practical implications  

* **Linear inference cost:** Generation time grows linearly with context length—unlike Transformer self‑attention’s quadratic blowup—so very long prompts remain tractable.
* **Throughput advantage:** In batch decoding experiments (`batch=32`, `prefill=16`), xLSTMs achieve higher token per second rates than cached Transformers because they never build an ever-growing key/value cache.
* **Memory footprint:** Constant hidden‐state storage makes it feasible to run billion‐parameter recurrent models on commodity GPUs where Transformer equivalents would exceed VRAM limits at modest context lengths.

---

## 🚀 Bottom Line  

The experimental evidence in the `xLSTM` paper paints a clear picture:

* When augmented with exponential gating and richer memories, classic LSTMs scale gracefully to billions of parameters.
* Across three orthogonal benchmarks—validation perplexity on massive web corpora, synthetic long‐range reasoning tasks, and domain‐wide token prediction—they consistently match or beat current leaders built on Transformer or State Space technology.
* Scaling laws suggest this lead will only widen as we push toward even larger models and datasets.

In short, the era where “recurrent = outdated” appears premature again. With `xLSTM`, an old favorite has been revitalized into a genuine contender for next‑generation language models—and its design may spill over into RL agents, time series forecasting, and physical system simulators where linear time/space complexity is paramount.
