\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### What is the exact parameter count for BOFT($m,b$) and how does it compare to block‑diagonal OFT?
Question:
In Section 4 the authors state that BOFT($m,b$) uses \(\frac{1}{2}(b-1)dm\) effective trainable parameters for a layer of size \(d\times n\). I would like a step‑by‑step derivation of this formula. Also, how does this count compare numerically to a block‑diagonal OFT with block size \(b\) (i.e., \(r = d/b\) blocks)? A concrete example with \(d=1024\), \(b=8\), and \(m = \log_2 d = 10\) would be helpful.
Answer:
**Answer**

In BOFT the orthogonal matrix that is applied to a frozen linear layer is written as a product of $m$ sparse “butterfly components’’,
$$
\mathbf R(m,b)=\prod_{i=1}^{m}\tilde{\mathbf B}^{\,b}_{(d,i)}\;,
\qquad
\tilde{\mathbf B}^{\,b}_{(d,i)}\in\mathbb R^{d\times d},
$$
where each component $\tilde{\mathbf B}^{\,b}_{(d,i)}$ is a block‑diagonal matrix whose blocks have size $b\times b$.  
Inside every $b\times b$ block we place a **$2b\times 2b$ orthogonal factor** (the usual Cayley‑parameterised rotation).  
Because an orthogonal $b\times b$ matrix lives on the Stiefel manifold $\mathcal O(b)$, it has

$$
\underbrace{\frac{b(b-1)}{2}}_{\text{degrees of freedom}}
$$

independent parameters: the skew‑symmetric matrix $\mathbf Q$ in the Cayley transform $(\mathbf I+\mathbf Q)(\mathbf I-\mathbf Q)^{-1}$ has exactly $\frac{b(b-1)}{2}$ free entries.

A butterfly component contains **$d/b$** such blocks (the block‑diagonal matrix repeats the same sparsity pattern along its diagonal).  
Hence the number of trainable parameters contributed by a *single* component is

$$
\frac{d}{b}\times\frac{b(b-1)}{2}
   \;=\;
   \frac{(b-1)d}{2}.
$$

The factor $m$ components are independent, so the total number of *effective* trainable parameters for BOFT($m,b$) is

$$
\boxed{\;\frac{1}{2}(b-1)\,d\,m\; } .
$$

This is precisely the expression reported in the paper.

---

### Comparison with block‑diagonal OFT  

Block‑diagonal OFT corresponds to the special case $m=1$ where the only factor is a plain block‑diagonal orthogonal matrix with block size $b$.  
If we write $r=d/b$ for the number of blocks, each block again contributes $\frac{b(b-1)}{2}$ free parameters, so

$$
\#\text{params}_{\text{blk‑diag}} = r\,\frac{b(b-1)}{2}
      = \frac{d}{b}\,\frac{b(b-1)}{2}
      = \frac{(b-1)d}{2}.
$$

Thus **block‑diagonal OFT uses exactly the same number of parameters as BOFT with $m=1$**; adding more butterfly layers ($m>1$) multiplies this count by $m$.

---

### Concrete example  

Take a layer with input dimension $d=1024$, a butterfly block size $b=8$, and choose  

* **$m=1$** → ordinary block‑diagonal OFT,  
* **$m=\log_{2} d = 10$** → BOFT that yields a dense orthogonal matrix.

Plugging the numbers into the formulas:

| Method | Parameters |
|--------|------------|
| Block‑diagonal OFT ( $m=1,\;b=8$ ) | $\displaystyle \frac{(8-1)\times1024}{2}= \frac{7\times1024}{2}=3584.$ |
| BOFT($m=10,\;b=8$) | $\displaystyle \frac{(8-1)\times1024\times10}{2}= 10\times3584 = 35\,840.$ |
| Full dense OFT (no sparsity, $b=d=1024,\;m=1$) | $\displaystyle \frac{(1024-1)\times1024}{2}\approx 523\,776.$ |

So with the same block size $b=8$

* a single block‑diagonal factor needs only **3.5 k** trainable scalars,
* ten butterfly factors inflate this to **≈36 k** – still two orders of magnitude smaller than a full dense orthogonal matrix (**≈5.2 × 10⁵** parameters).

The extra parameters are precisely what allow BOFT to generate a *dense* orthogonal transformation while remaining far more parameter‑efficient than the naïve dense parametrisation.

---

#### Take‑away

*The formula $\frac12(b-1)dm$ comes from counting the degrees of freedom in each $b\times b$ orthogonal block and multiplying by the number of blocks ($d/b$) and by the number of butterfly components ($m$).*
For a fixed block size, increasing $m$ linearly raises the parameter budget, but even with $m=\log_2 d$ (the setting that guarantees dense connectivity) BOFT’s cost grows only as $\mathcal O(d\,b\,\log d)$, which is dramatically smaller than the quadratic cost of an unrestricted orthogonal matrix and only modestly larger than plain block‑diagonal OFT.
