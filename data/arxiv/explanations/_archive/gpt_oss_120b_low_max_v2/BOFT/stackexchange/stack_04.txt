\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How is multiplicative dropout implemented for the product of butterfly components?
Question:
BOFT introduces a "multiplicative Dropout" where a percentage of butterfly components and a percentage of diagonal blocks within each component are replaced by identity matrices. I am confused about (a) whether the dropout mask is sampled per training step or per layer, (b) how gradients flow through the remaining (non‑dropped) components, and (c) if there is any need to renormalize the orthogonal matrix after dropout.
Answer:
**Answer**

In BOFT the orthogonal matrix that is applied to a frozen pretrained weight is written as a product of $m$ *butterfly components*  

\[
\mathbf R=\tilde{\mathbf B}_{(d,1)}^{\,b}\;\tilde{\mathbf B}_{(d,2)}^{\,b}\;\dots\;\tilde{\mathbf B}_{(d,m)}^{\,b},
\qquad 
\tilde{\mathbf B}_{(d,i)}^{\,b}\in\mathbb R^{d\times d},
\]

each component being a block‑diagonal matrix whose non‑zero blocks are themselves orthogonal (they are obtained with a Cayley or a 2‑D rotation parametrisation).  
The **multiplicative dropout** described in Section 4.2 of the paper is a simple way of forcing some of those blocks to become the identity during training.  

Below we answer the three concrete points you asked about.

---

### (a) When is the dropout mask sampled?

The mask is **sampled independently at every training step** (i.e. every forward pass).  
For each step the algorithm proceeds as follows:

1. For every butterfly component $\tilde{\mathbf B}_{(d,i)}^{\,b}$ draw a Bernoulli variable with probability $p_{1}$.  
   If it is 1, replace the *whole* component by $\mathbf I_{d}$; otherwise keep the component unchanged.
2. Inside each component that is kept, each diagonal block (the $2b\times 2b$ orthogonal sub‑matrix) is also subject to an independent Bernoulli draw with probability $p_{2}$.  
   Blocks that are “dropped’’ are set to $\mathbf I_{2b}$, while the remaining blocks stay as the learned orthogonal matrices.

Because the mask changes each iteration, different subsets of blocks are active throughout optimisation, which acts exactly like standard dropout: it reduces co‑adaptation of parameters and provides regularisation.

The mask is **not static per layer**; it would defeat the purpose of stochastic regularisation and would be equivalent to permanently pruning those blocks, something the authors explicitly avoid.

---

### (b) How do gradients flow through the surviving parts?

Let us write the forward computation for a single input vector $\mathbf x$:

\[
\mathbf z = \bigl(\mathbf R_{\text{drop}}\;\mathbf W^{0}\bigr)^{\!\top}\!\mathbf x,
\qquad
\mathbf R_{\text{drop}} = \prod_{i=1}^{m}\bigl(\mathbf D_{i}^{\,\text{comp}}\odot \tilde{\mathbf B}_{(d,i)}^{\,b}\bigr).
\]

Here $\mathbf D_{i}^{\,\text{comp}}$ is a binary block‑diagonal mask (with entries 0 or 1) that records which whole components and which internal blocks survive; “$\odot$” denotes element‑wise multiplication restricted to the block structure.  

During back‑propagation the chain rule is applied exactly as for any product of matrices:

* If a component (or a block inside it) has been replaced by an identity matrix, its corresponding mask entry is 0. Consequently that factor contributes **no gradient** to its parameters – they are effectively frozen for that step.
* All **non‑dropped** factors receive gradients that are computed from the usual product rule. In practice automatic‑diff frameworks propagate a gradient through each surviving block just as they would through any ordinary linear layer.
* Because every surviving block remains orthogonal (the Cayley transform enforces orthogonality at every update), the gradient w.r.t. its underlying skew‑symmetric parameter matrix $\mathbf Q$ respects the orthogonal constraint; no extra projection step is required.

Thus gradients flow only through the blocks that are active in that forward pass, exactly mirroring standard dropout behaviour but applied multiplicatively on matrix factors.

---

### (c) Is any renormalisation needed after dropout?

No. The procedure already guarantees that **the overall matrix stays orthogonal in expectation**, and every realised matrix used in a forward pass is itself orthogonal:

* Whole components that are dropped become $\mathbf I_{d}$, which is trivially orthogonal.
* Blocks that are dropped become $\mathbf I_{2b}$; when they are re‑assembled into their parent component they preserve orthogonality because an identity block does not affect the unitary property of the surrounding block‑diagonal matrix.
* The remaining blocks retain orthogonality because they are parametrised via a Cayley transform (or an explicit 2‑D rotation), which maps any skew‑symmetric parameter to an exact orthogonal matrix.

Therefore no additional scaling or “renormalisation” (such as dividing by $1-p$ in classic dropout) is required. The stochasticity only changes *which* orthogonal factors participate; it never destroys the orthogonal nature of any factor that participates.

---

#### Intuition

Think of each butterfly component as a “layer of switches’’ that redirects information between groups of neurons. Multiplicative dropout randomly turns some switches off (by replacing them with wires that simply pass their input unchanged). The network still shuffles information correctly because those wires are identity operations, and learning continues through the switches that remain on. Over many steps each switch gets a chance to be trained, preventing any single switch from becoming overly dominant—exactly what conventional dropout achieves for scalar activations, now lifted to the level of matrix factors.

In summary:

* The dropout mask is sampled anew at every training iteration.
* Gradients propagate only through the butterfly components and blocks that survive the mask; dropped parts receive zero gradient for that iteration.
* Because every surviving part remains strictly orthogonal and dropped parts become identities, no extra renormalisation of $\mathbf R$ is necessary.

This design gives BOFT regularisation without compromising its core guarantee—that the finetuned weight matrix stays an orthogonal transformation of the pretrained one.
