Chapter 9: # 9. Reward–KL Trade‑off in Controlled Settings

In many applications of language‑model fine‑tuning an important practical concern is **how much the updated model should deviate from the original policy** while increasing performance on a desired objective.  The RLHF pipeline introduces an explicit **Kullback‑Leibler (KL) penalty** that keeps the new policy close to a safe, benign reference.  A good fine‑tuning algorithm should therefore discover a *reward–KL frontier*: for every acceptable level of divergence from the reference, it should achieve as high a reward as possible, and conversely, for any desired reward it should minimize deviation.  In this chapter we investigate the behavior of **Direct Preference Optimization (DPO)** in precisely such a controlled setting, comparing it with the state‑of‑the‑art reinforcement learning baseline **PPO‑GT** (PPO trained with the ground truth reward) and with a naïve “unlikelihood” objective that ignores KL regularization.

## 9.1 Background: Rewards, KL, and the Constrained Optimization Problem

Let us first restate the **constrained objective** that underlies RLHF and DPO:

\[
\max_{\pi_{\theta}} \;\; \mathbb{E}_{x\sim \mathcal{D},\, y\sim \pi_{\theta}} \bigl[r_{\phi}(x,y)\bigr]
      \;-\; \beta \;\mathbb{D}_{\text{KL}}\!\bigl[\pi_{\theta}(\,\cdot\,|x)\,\|\,\pi_{\text{ref}}(\,\cdot\,|x)\bigr].
\tag{9.1}
\]

The first term rewards the model for producing data that a learned reward function \(r_{\phi}\) would value; the second term discourages large changes from the reference policy \(\pi_{\text{ref}}\).  In practice we set \(\beta >0\) to control how “conservative” we want the update to be: a large \(\beta\) places heavy weight on staying close to \(\pi_{\text{ref}}\).

In *ground‑truth* settings such as sentiment control, we can replace \(r_{\phi}\) with an analytic reward \(r^{*}(x,y)\).  For example, we could assign each response an exact sentiment score using a commercial classifier.  This gives us an uncontaminated yardstick for measuring each model’s performance on “reward”.  We can then plot reward against KL for every training configuration as they evolve over time, yielding a visual frontier.

## 9.2 Experimental Toolkit

### 9.2.1 Controlled Sentiment Generation

- **Dataset**: Movie reviews from IMDb.  
- **Prompt**: The first few sentences of each review form a context \(x\).  
- **Desired Behavior**: Generate continuation \(y\) whose overall *sentiment* is strongly positive.  
- **Ground Truth Reward**: Sentiment classifier score \(r^{*}(x,y)\), continuous in \([-1, +1]\).

### 9.2.2 Algorithms Compared

| Method | Core Idea | Reference | Key Hyper‑parameter |
|--------|-----------|-----------|---------------------|
| **DPO** | Cross‑entropy over pairwise preferences derived from \(r^{*}\); incorporates per‑example weighting via internal “implicit rewards.” | N/A – uses SFT policy as reference | \(\beta\): weight of KL term |
| **PPO‑GT** | Classic PPO on latent policy; reward = true \(r^{*}\). | SFT policy as reference | Target KL (soft schedule) |
| **Unlikelihood** | Jointly maximize probability of chosen ends and minimize probability of undesirable ends (no explicit reward). | N/A – uses SFT policy as reference | Auxiliary coefficient \(\alpha\) scaling negative term |

Each method begins from an identical *supervised fine‑tuned* baseline so that any divergence reflects only the difference in adaptation strategy.

### 9.2.3 Hyperparameter Sweeps

We perform exhaustive sweeps over:

- DPO’s **\( \beta \in \{0.05,\;0.1,\;1,\;5\}\)**.
- PPO’s **target KL distribution** \(=3,\,6,\,9,\,12\).
- Unlikelihood’s auxiliary weight \(\alpha \in \{0.05,\;0.1,\;0.5,\;1\}\).

This yields \(4 + 4 + 4 =12\) distinct training runs per method (though some combinations are omitted due to training instability). Altogether we obtain roughly twenty two points on each frontier.

## 9.3 Visualizing Reward–KL Frontiers

For each training run we evaluate after every batch (every ~100 steps) on a hold–out validation set of prompts.
We record:

- **Expected Reward**:
  
  \[
    R = \frac{1}{|\mathcal{V}|}\sum_{(x,y)} r^{*}(x,y),
  \]
  
  where each generated completion \(y\) is left‐shifted by one token when computing \(r^{*}\).

- **Cumulative KL Divergence**:
  
  Using Eqn (9.1)’s penalty term, we compute
  
  \[
    D = -\,\beta
        \;\frac{1}{|\mathcal{V}|}
        \sum_{(x,y)} 
          r^{*}(x,y)
          - 
          r^{*\text{ref}}(x,y)
      = 
      -\,\mathbb{D}_{\text{KL}}\!\bigl[\pi_{\theta}(\cdot|x)\,\|\,\pi_{\text{ref}}(\cdot|x)\bigr],
  \]
  
  where `ref` denotes the SFT distribution.

Plotting all validation points in the two–dimensional space yields clear “frontier curves.”  

Notably:

- Every method starts at roughly the same point (SFT baseline).
- With more aggressive hyperparameters (e.g., larger β or target KL), each curve climbs “upward” (higher reward) while moving “rightward” (larger KL).
- DPO’s curve sits far left of PPO’s for comparable rewards: at β = 1 DPO attains an average salary of about +0.42 vs PPO’s +0.30 while keeping KL below ­—0.20.

A meaningful summary metric is therefore *area under the frontier*, capturing how efficiently a method translates changes in regularization into gains in agent performance.

## 9.5 Intuition Behind DPO’s Superior Frontier

The theoretical derivation underlying DPO affords two operational advantages:

1. **Exact Policy Extraction from Rewards** – Instead of learning an abstract scalar reward and then maximizing it via RL, DPO *implicitly* constructs a sub‑policy that already satisfies the optimality condition `π∝π_ref·exp(r/β)` by introducing per‑token log‐ratios internally within its loss function.

2. **Self‐Normalised Importance Weighting** – The gradient expression contains terms
   ```
   σ(ĥat_r_l − ĥat_r_w)
   ```
   where `ĥat_r` is exactly the implicit reward derived from current logits minus ref logits.
   This weight equals zero when both completions are ordered correctly according to current implicit rewards, zeroing out their contribution until improved ordering is needed.
   Importantly this avoids large gradient spikes that destabilise training—an issue empirically observed when removing this weighting factor.

Because every update directly pushes probability mass towards preferred completions ***and simultaneously pulls back via proportional penalty***, DPO finds better trade–offs early on than iterative RL approaches that separately estimate value functions and approximate actor updates.

## 9.6 Practical Takeaways for Practitioners

1. **Hyperparameter Simplicity**
   - DPO distils its tunability into only one scalar (\(\beta\)), no learning rate schedule for KL or discount factors.
   - Empirical sweeps reveal a narrow sweet spot around β ≈ 1 for most controlled settings; beyond this range plateauing is seen but no catastrophic drift occurs.

2. **Computational Cost**
   - Each gradient step merely evaluates two logit predictions between selected references—no Monte Carlo sampling or interleaved actor–critic loop needed.
   - Consequently training time per epoch drops below one half of equivalent PPO runs while retaining stability even out to ~6B parameter models.

3. **Robustness to Distribution Shift**
   - Because DPO explicitly retains proximity to π_ref through its loss, policies generalise more reliably than PPO variants trained on same data but heavily reliant on value estimation leaks.
   - Empirical cross‑dataset evaluations confirm this; see Table X in Appendix for further details.

4. **Extensibility**
   - Replace binary preference labels with multiple ranking or Plackett–Luce style samples; derivations extend naturally.
   - Spiral into self‑supervised domains where generating fresh label pairs online may be expensive but can be cheaply reinterpreted via DPO losses.

## Chapter Summary

By visualizing and quantitatively analysing REWARD versus KLD trade-offs across exhaustive hyperparameter sweeps, we conclude that Direct Preference Optimization consistently produces a *dominant frontier*: it achieves higher sentiment scores while maintaining smaller deviations from its safety baseline compared to both standard PPO trained on ground truth rewards and naïve unlikelihood models that ignore controlled exploration/exploitation balances.

This superiority emerges because:

- The loss structure directly encodes optimality conditions;
- A highly informative per-example weighting prevents pathological loss signals;
- The approach eliminates costly sampling loops inherent in RLHF workflows while demanding no additional hyperparameter tuning beyond selecting β.

Consequently, for controlled settings where ground truth rewards exist—or where sample confidence scores sufficiently approximate them—DPO offers an inexpensive yet highly effective path toward aligning language models with human-defined objectives while safeguarding against deviant behaviours."
