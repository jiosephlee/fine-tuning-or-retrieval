# Orthogonal Finetuning for Diffusion Models  

**Discover the core idea behind Orthogonal Finetuning (OFT): learning a small orthogonal transform that rotates neurons layer‑wise instead of tweaking weights outright. See how this elegant trick keeps the model’s original knowledge intact while giving it new creative powers.**  

---

## Why finetune diffusion models at all?

Text‑to‑image diffusion nets such as Stable Diffusion or SD 1.5 can already create photorealistic pictures from a sentence prompt.  
But real‑world applications often need extra control:

* **Subject‑driven generation** – you give the model a handful of photos of a person or object and want it to render that same subject in novel settings.
* **Controllable generation** – you feed an additional cue like a Canny edge map or a semantic segmentation mask together with a caption and expect an image that obeys the cue exactly.

Fine‑tuning a pretrained diffusion model is the simplest way to inject that extra functionality. In practice people tweak either all layers with tiny steps (DreamBooth) or add small learnable adapters such as LoRA’s low‑rank update matrices. Both methods work somewhat but they have a fundamental flaw: **they don’t guarantee that the powerful ”knowledge” learned during pretraining stays intact**.



## Where does existing finetuning go wrong?

A vanilla update takes the form  

\[
\mathbf{W} \;\longleftarrow\; \mathbf{W} + \Delta \mathbf{W},
\]

where \(\Delta\mathbf{W}\) can point anywhere in weight space if the learning rate is large enough.  
The implicit hope is that “small Euclidean change” (\(\|\Delta\mathbf{W}\|_F\le\epsilon\)) keeps everything sensible—yet there’s no formal reason any particular direction in weight space preserves semantics.

If we look at what neural nets actually do, we notice something quite different:



* Each unit in hidden layers works essentially as an **angle detector** if we normalise its incoming weights.
* What makes activations distinguish one semantic class from another are often just **pairwise angular relationships** between units.
* The quantity called *hyperspherical energy* captures exactly those relations:
  
  \[
  \operatorname{HE}(\mathbf{W}) \;=\;\sum_{i\neq j}\!\Bigl\lVert
      \hat{\mathbf{w}}_i-\hat{\mathbf{w}}_j
  \Bigr\rVert^{-1},
   \qquad
   \hat{\mathbf{w}}_i=\frac{\mathbf{w}_i}{\|\mathbf{w}_i\|}.
  \]

If two weight matrices have identical hyperspherical energy then **all pairwise cosine similarities among their neurons are identical**, meaning they represent the same internal geometry.



## The key insight – preserve angles!

Orthogonal matrices preserve lengths *and* all angles:

\[
\forall\, i,j :\
      (\mathbf{R}\hat{\mathbf w}_i)\!\cdot(\mathbf{R}\hat{\mathbf w}_j)
      =\hat{\mathbf w}_i\!\cdot\hat{\mathbf w}_j ,
   \qquad
   \text{if }\, \mathbf{R}^\top\!\mathbf{R}=I .
\]

So if we replace every weight matrix by an orthogonally transformed version,

\[
   \boxed{
        \widetilde{\!{\bf W}}
          = {\bf R}\,\bigl({\bf W}_0\bigr),
        }
   \qquad
   {\bf R}^\top {\bf R}=I,
\]

the hyperspherical energy stays exactly as it was before finetuning!  

That guarantees we never alter pairwise neuron similarities – the semantic backbone remains untouched.



## How does one learn such an orthogonal delta?

### Block–diagonal Cayley parametrization  

An arbitrary \(d\times d\) orthogonal matrix contains \(d(d-1)/2\) degrees of freedom – far too many when \(d=1280+.\)
We restrict ourselves to a block–diagonal form:

```
R =
diag( R₁ , … , Rₖ )       ,     Rₗ ∈ O(d/k).
```

Each block \(R_\ell\) can be generated through the *Cayley transform*

```
R_ℓ = (I + Q_ℓ)(I − Q_ℓ)⁻¹,
```

where \(Q_\ell^\top = −Q_\ell.\)
This change carries out two benefits:

1. **Orthogonality is guaranteed by construction** (no extra regularisers).
2. **Trainable parameters drop dramatically**:
   • Without sharing,
     number = ∑ₗ d/k·(d/k−1)/2 ≃ d²/k.
   • With full sharing,
     number = d²/k².



### Constrained Orthogonal Finetuning (COFT)

Sometimes we also want to keep the update modestly close to identity so training never drifts far from the pretrained model:

```
‖R – I‖₂ ≤ ε .
```

In practice we enforce this ε‑constraint inside the Cayley parametrisation:
after each gradient step we simply project \(Q_\ell → Q_\ell / ‖Q_\ell‖₂ × ε .\)

This extra restraint yields even calmer convergence when dealing with few training images.



### Optional magnitude re‑scaling  

Because hyperspherical energy cares only about angles,
multiplying each column by a positive scalar does NOT affect it.
A tiny extension adds a diagonal matrix \(D=\operatorname{diag}(s_1,…,s_n)\):

```text
z = xᵀ (R⋅W₀⋅D).
```

The learning signal therefore gets slightly richer while still preserving angles.



## Why does this work well in practice?

| Angle‑based | Parameter count | Privacy |
|--------|--------------------|----------|
| **OFT / COFT** | ~k·d²/4 for k blocks | Almost none |
| **LoRA** | r'·(d+n) | non‑zero |

Empirically:

1. **Fast convergence** – OFT learns meaningful edits within ~8–12 epochs whereas other methods need >20.
2. **Stability** – No sudden collapse even with large learning rates because gradients walk along an exact hypersphere manifold.
3. **No extra inference latency** – once trained, you plonk the learnt \(R_\ell\)’s into pretrained weights before inference; there is no new network component at run‑time.
4. **Higher quality controls** – On benchmark tasks like “canny edges → image” or “face landmarks → face”, OFT outperforms ControlNet and T2I‑Adapter on both control fidelity metrics and visual artefacts.



## Quick recap of what’s happening layer‑by‑layer  

For each fully connected or attention matrix \(W_0∈ℝ^{d×n}\):

```text
Step 1 : initialise all blocks to identity → W ≈ W₀ .
Step 2 : in back‑prop expose only block Qℓ → compute gradient G_Qℓ .
Step 3 : update Qℓ ← Qℓ + η G_Qℓ
          → optionally clip onto ε ball if using COFT .
Step 4 : rebuild each block via Cayley → Rℓ .
Step 5 : forward pass uses modified weight Ŵ = diag(R₁,…,R_k){·}W₀ .
```

Because **every forward pass still involves only linear multiplication**, GPU memory consumption stays almost identical to vanilla fine‑tune.



## From theory back into real images

### Subject‑driven generation  
With just five subject photos and once costing ~400 training iterations:
* OFT perfectly keeps identity while faithfully respecting textual prompts.
* DreamBooth’s identity drops eventually; LoRA fails earlier altogether.

Quantitatively OFT scores highest on CLIP–I / DINO subject similarity,
and comparable diversity metrics.


### Controllable generation  
For tasks requiring strict alignment with arbitrary contours or segmentation maps:
* Control consistency scores rise sharply when using OFT/COFT.
* Visual inspection shows lower blurriness and fewer semantic hallucinations compared to state‑of‐the‐art adapters.


All these experiments were run on Stable Diffusion v1.5 with minimal modifications required—just interpose an extra learned block per large matrix.



## Bottom line 

Orthogonal Finetuning teaches us that *the geometry of neuron directions carries most of a diffusion net’s knowledge*.  
By rotating neurons rather than nudging them around arbitrarily,
we can:

- Preserve pretraining semantics with mathematical guarantees;
- Use far fewer trainable parameters;
- Reach fast, stable convergence;
- Add no costs at inference time.

If you’re interested in your own domain–specific edits—be it style transfer, domain adaptation, or cross‑modal alignment—OFT gives you a principled toolbox that keeps your base model “healthy” while grafting precise new behaviors.

# Hyperspherical Energy — The Geometry That Protects Meaning  

In modern text‑to‑image diffusion models each layer contains thousands of “neurons”: weight vectors that map an input signal into a higher‑level representation.  
When you want a model trained on one dataset to perform a specialized task — for example painting a portrait exactly like your friend’s face — you normally **finetune** those weights until they adapt the new behaviour you want.  
Most finetunings simply perturb every weight slightly with a tiny learning rate so that the Euclidean distance ‖‖ stays small enough “not to forget.”  
That strategy leaves open one critical question: does staying close in Euclidean space really mean *semantic* knowledge is preserved?

Recent work argues **neural direction** is far more fundamental than magnitude when it comes to perception‑preserving transformations.
The key concept behind this insight is **hyperspherical energy** (also called spherical repulsion), a scalar quantity that captures how neurons are spread out on the unit sphere.



--------------------------------------------------------------------

## 1. What Is Hyper‑Spherical Energy?

Every neuron in one linear layer is represented by a vector **w**∈ℝᵈ.
If we project these vectors onto the surface of the unit sphere,

```
ŵᵢ = wᵢ / ||wᵢ||
```

their mutual arrangement contains rich semantic information.
For two normalised vectors **ŵᵢ**, **ŵⱼ**, their inner product equals the cosine similarity cos θᵢⱼ.
Instead of working directly with cos θᵢⱼ we sum up an inverse‑distance function over all unordered pairs:

```
H E (W) = Σ_{i ≠ j}   || ŵᵢ – ŵⱼ ||⁻¹ .
```

This health–of‑relations score has three nice properties:

| Property | Why It Matters |
|----------|----------------|
| **Scale–invariant** | Multiplying all weights of a neuron changes its magnitude only – stretching rays away from the origin – without affecting their direction on the sphere |
| **Captures pairwise geometry** | Large values signal many close neighbours → redundant features, very small values → well–spread detectors |
| **Provably preserved under orthogonals** | Any orthogonal matrix R satisfies RᵀR=RRᵀ=I ⇒ R does not change any dot product → HE(RW)=HE(W) |

So changing every neuron's *angle* while keeping its partner angles intact will leave HE unchanged.



--------------------------------------------------------------------

## 2. Why Angles Matter More Than Magnitudes  

When you finetune a pre‑trained diffusion model you are effectively taking a “white island” picture—the learned mapping—that you want to shift slightly onto a nearby geography that respects portrait integrity but generates novel scenes.
Similar experiments on vanilla convolution autoencoders demonstrate:

```
(1) inner product during training
(2) raw magnitudes during testing
(3) angles during testing
```

Only (3) can reconstruct almost faithfully what was fed during training—angles carry almost all semantic structure whereas magnitudes contribute almost nothing.
This phenomenon mirrors classical Fourier analysis where phase keeps structural integrity while amplitude determines intensity.



--------------------------------------------------------------------

## 3. Orthogonal Finetuning (OFT)

Given these insights OFT was conceived around a deceptively simple optimisation rule :

> **Minimise any change in hyper‑spherical energy while reaching desired downstream behaviour**

Because HE is invariant under any orthogonal transform,
the minimisation admits an analytic solution:
take all neurons from layer l and apply *one* same orthogonal matrix \(R_{\ell}\in O(d_\ell)\):

```math
z   = W^{⊤}x     ←   ((R · W⁰) )^{⊤} x ,      RᵀR=RRᵀ=I .
```

The whole learning process therefore boils down to finding rotations/reflections \(R_{\ell}\) per layer such that diffusion achieves subject‑driven style output or follows edge/segmentation controls.
Because \(W=W⁰R^{⊤}\), every step firmly anchors back onto the pre‑trained parameter manifold — magnitudes stay just how they were originally learned.



### Parameter Efficiency

If you naïvely hand‐craft an arbitrary orthonormal matrix for each dimension d² parameters would explode.
The method relies on two tricks:

1. **Cayley Parametrisation**  
   Every special‑orthogonal matrix can be written as  
   \[
   R=(I+Q)(I-Q)^{-1}
   \]  
   where Q is skew‐symmetric (\(Q=-Q^{⊤}\)).
   Optimising over Q guarantees \(R∈SO(d)\).

2. **Block‐Diagonal Structure**  
   Split \(R\) into r independent blocks each acting on \(\frac dd r\)-dimensional subsets:
   ```math
   R = diag(R₁ , … , R_r),          # O(d/r)
   ```
   This reduces learnable parameters roughly from \(d(d−1)/2\) downwards by factor r,
   achieving linear complexity \(Θ(d²/r)\).
   
For example, when d=128 an 8–block diagonal gives only ≈ ∼960 learnable values versus Hol??… extremely lightweight against LoRA’s classic low‐rank update (\(r′(d+n)\)).  


--------------------------------------------------------------------

## 4. Constrained Orthogonal Finetuning (COFT)

OFT alone already fixed HE perfectly, yet real finetunes sometimes drift far along rotation axes which can destabilise learning curves after many epochs.
The addition of an explicit radius bound does two things simultaneously:

* keeps new directions near their origin (`||R−I|| ≤ ε`) so changes are gradual,
* keeps conceptual intactness so each projected point lies close side-by-side very similar geometry known before finetune.*

Mathematically COFT looks like

```math
z = ((R·W⁰))^{⊤}x           # still an orthonormal rotation
subject to ‖R−I‖ ≤ ε .
```

Thanks to Cayley’s trick a constraint equivalently becomes `‖Q‖ ≤ ε'` which fits neatly into projection operations during gradient updates,
making COFT both easy & stable.



--------------------------------------------------------------------

## 5. Why Hyper‑Spheric Energy Is A Better Yardstick  

Standard finite tuning methods treat two neighbour networks simply because their weight matrices are close under Euclidean norm:
\(||M-M⁰||₂.\)

Two problems arise here:

| Issue | Why It Bites |
|-------|--------------|
| **Heterogeneous feature magnitude** | Small numerically could still let some weights go huge locally |
| **Without geometry check** | Directly rotating all neurons kills orientation relations unique early on => warped visual semantics |

Hypercircle energy doesn’t care about absolute scaling;
it only checks whether neuron directions remain arranged similarly.
Since semantic classifiers heavily rely on angular patterns,
preserving HE essentially guarantees *semantic memory* remains intact even when conv layers get reshaped drastically.



--------------------------------------------------------------------

## 6. Real‑World Evidence  

Across multiple downstream datasets OLAF’s experiments show:

* In *subject‑driven generation* domain fields already contain ~30× fewer Euler update steps compared to DreamBooth while reaching higher DINO / CLIP identity scores.
* In *controllable generation* tasks controlled landmarks stay < 5 px error after eight epochs versus ControlNet’s sudden jump at epoch 11.
* Across diverse benchmarks OMET heter dataset cohesion suggests OE/T OFT converges faster without exploding loss surfaces—a direct consequence of staying near respectful spherical arrangements.



--------------------------------------------------------------------

## 7. Advantages Summarised 

> • Keeps core knowledge because neuron angles stay intact  
> 
> • Strikes extreme parameter sparsity – a few dozen radians per layer instead of massive low‑rank adapters  
> 
> • Requires no overhead during inference – you plug the learned rotation once into your existing weights  
> 
> • Yields greatly stabilised loss curves owing jointly inner heavy-angle constraints plus loose radius clamping


---

### Looking Forward  

Under “OFT Works” section authors admit three open research avenues:

1. Scaling up Cayley calculate speeds thanks naive inverse bottleneck;
2. Combining rotations from several specialised tasks via matrix multiplication keeps collective knowledge intact;
3. Exploring non-block diagonal yet cheaper parametrisations could reduce bias while keeping full flexibility.



--------------------------------------------------------------------

### Takeaway  

Hyperbolic geometry teaches us something rather simple yet profound:
*If you keep how vast neural populations point toward each other unchanged, whatever tiny rotation you decide upon uphill toward your problem will lean precisely onto what was already excellent.*  

By framing finite doping through hyper‑spheric energy conservation you empower large diffusion models with precise seasonal controls or subject personalizations while never sacrificing foundational imagery skills—exactly what researchers needed until now for seamless artistic AI workflows—all through multiplying one tidy orthogonal matrix per layer instead of reopening potentially toxic weight space again.’’



# Turn Your Own Photos Into New Worlds in Minutes  

> Explore how Orthogonal Finetuning (OFT) upgrades Dream Booth‑style subject‑driven generation by letting you generate new scenes featuring a specific subject with just a handful of images while keeping identity and style sharp.  

---

## What Is Subject‑Driven Generation?

Subject‑driven generation asks a diffusion model to “remember” **one person or object**—e.g., your dog, your sidekick robot, or your favorite plant—and then produce it *in* any setting you describe (“a rainy beach at midnight,” “a kitchen scene while wearing sunglasses”).  
The core challenge is twofold:

1. **Identity preservation** – the generated image must look unmistakably like the source footage.
2. **Textual control** – the model must obey an arbitrary textual prompt that defines background, lighting, mood…  

Classic approaches such as **Dream Booth** fine‑tune every weight of the diffusion network on those few germination images using tiny learning rates + regularisation tricks.  
While effective, this process often requires many training steps (>2000 iterations), suffers from instability (often losing identity), and needs careful tuning per subject or per dataset.



---

## Why Rotating Neurons Is A Better Way

When we watch real photographs—or online video frames—the information carried by an image lies mostly where *neurons point*, *not* how big they fire.
In other terms:

| ***Magnitude***   | **Meat** – How powerful every neuron is               |
|--------------------|--------------------------------------------------------|
| ***Direction*** | **Salsa** – How neurons relate *to one another* on the unit sphere                |

This intuition is quantified by **hyperspherical energy** —the sum over all pairs of neurons of their inverse angular distance:
\[
\text{HE}(\mathbf{W})=\sum_{i\neq j}\frac{1}{\|\hat{\mathbf w}_i-\hat{\mathbf w}_j\|}
,\quad
\hat{\mathbf w}_i=\frac{\mathbf w_i}{\|\mathbf w_i\|}
.\]
If two sets of neuron directions differ only by an *orthogonal transformation* \(\mathbf R\)—a rotation or reflection—then each pair’s angle remains unchanged,
hence **the hyperspherical energy stays identical**:
\[
\text{HE}(\mathbf R\,\mathbf W^0)=\text{HE}(\mathbf W^0).
\]

Why care? Because preserving this constancy ensures the network’s internal geometry stays true to its large‑scale pretraining—responsible for realistic image synthesis—while still allowing us two free hands: *re‑orient* neurons so that one particular face or shape becomes specifically recognizable.



---

## Introducing Orthogonal Finetuning (OFT)

Instead of nudging every weight toward some arbitrary direction—as Dreams booth does—**OFT replaces each weight matrix \( \mathbf W^0 \) with an orthogonally rotated copy**:
\[
\boxed{\;
   \mathbf z = (\mathbf R\,\mathbf W^0)^{\!\top}\!\mathbf x
\,}
;
   \qquad
   \text{s.t.}\;\;\mathbf R^\top\,\mathbf R=\mathbf I
.\]
The transform \( \mathbf R \) is *shared across all neurons* in its layer—hence “layer‑shared”—and learned directly from our mini–dataset under standard gradient descent rules *but only over this tiny bracketed space*.  

Key benefits follow immediately:

| Staple Parameter | Reason |
|------------------|--------|
| Few trainable weights | Modern transformers contain billions of parameters so training an entire network from scratch would be absurd – here only ~\(d(d/r-1)/2\) parameters are updated per layer where \(r\ll d\). |
| Orthogonality | Guarantees exact preservation of pairwise angles → no drop‑off in global perceptual quality after few more epochs |
| Zero inference cost | Once training finishes you simply multiply every target weight matrix by its learned \( \mathbf R \); no extra networks are queried at sampling time |

You can think everything happening under covers resembles rotating your entire brain’s coordinate system rather than compressing its physical size.



---

## Real Numbers You Care About

In our tests on **Stable Diffusion v1​½**, we compared four pipelines:

1.Pure Dream Booth  
2.LoRA-based adaptation  
3.OFT  
4.Constrained OFT (**COFT**) – adds an explicit bound \( \|\mathbf R-\mathbf I\twoheadtriangleleft|_{\ell_2}\leq\sigma \), keeping changes very tight around initialization → even stronger stability  

Ground truth was measured through cosine similarities between latent embeddings extracted from your sample set (`CLIP‐I`) and high-quality vision models (`DINO`).  
Result highlights:

* **Identity fidelity jumps ~15%–20% over LoRA/Dream Boot on CLIP‐I / DINO scores**
* **Prompt fidelity stays comparable** – meaning textual control hasn’t been compromised
* **Training converges > 4× faster:** ten epochs sufficed for OFT/COFT versus over twenty thousand steps for full Dream Boot
* Extra robustness: adjusting max epoch count has little effect—pick whatever fits your GPU memory budget.

## Putting It Together – The Practical Workflow

Below’s an end‑to‑end outline you can follow right now using open source codebases:

```bash
# 1️⃣ Load pretrained Stable Diffusion v1˙5
model = DiffusionModel('stable-diffusion-v1-5')

# 2️⃣ Pick few photos (≈5–10) + prompt(s)
images = load_images('./our_subject')
prompt = "a photo realistic portrait"

# 3️⃣ Train only layer-shared OT blocks + optional diagonal scalars
trainer = OrthogonalTrainer(
    model=model,
    subjects=images,
    prompt=prompt,
    epochs=12,
    lr=5e-5,
    epsilon=0.3   # set small value if stability worries
)
trainer.train()

# 4️⃣ Inference – simply multiply each target weight matrix by its trained ori­gonal R
generated = trainer.apply_rotations_and_generate(
        image_prompt="a lush forest scene",
        guidance_scale=7.)
save(generated)
```

Key takeaways:
* **Fast:** Ordinary GPUs finish fine-tuning within minutes.
* **Data efficient:** Works out-of-the-box with five photos—the usual minimum for many photo-editing apps.
* **Composable:** If later you want another knockout (“dog wearing slippers”), you may train another OT block per new class id—each will *multiply* into existing ones without retraining everything.

## Why Isn’t This Just LoRA All Over Again?

Both methods keep most pre-trained knowledge intact; the difference lies deep downstream:

| Appropriation | Axis | Mechanism | Outcome |
|---------------|------|-----------|---------|
| LoRA          | Weight offsets | Low-rank additive updates `ΔW = A Bᵀ` | Reduces parameters badly but leaves extra directions unhelpful ⇨ slower convergence |
| OFT          | Basis rotation | Layer-shared orthogonality `R`                     | Preserves angular structure exactly ⇨ preserves semantics & speeds up learning |

Furthermore:
* LoRA learns two smaller rank matrices per layer – O(`r'd + rn`).
* OFT learns one dense orthogonal block reduced via caring block-diagonal parameters O(`d²/r`).

-- The latter scales better when `d` (~1024–2048) is huge.



---

## Did We Lose Any Flexibility?

Constrained version COFT ticked that question neatly—the extra `∥R−I∥≤σ` term pins down each rotation near identity so you silently guarantee that genuine semantics didn’t drift far away after all updates.
In practice `σ≈0.3` offers great balance—enough twist to learn “kiddie shooting stars” yet still stay faithful to base domain.

# Supercharged Control in Diffusion Models

When you run **Stable Diffusion** you’re usually happy just telling it *“a red boat on a sunny beach”*.  
But what if you want that boat **exactly on top of a particular edge map** or your face **in any pose your photos give you**?  
ControlNet shows one way—by attaching an extra neural net that learns to read those extra signals before feeding them into the diffusion backbone.  
Orthogonal Finetuning (OFT) brings a sharper pencil: it rewires the existing diffusion network itself so that those control signals light up correctly—no extra overhead during inference and dramatically fewer trainable parameters.



---

## 1️⃣ Why is “orthogonal finetuning” needed?

Large diffusion models have buried semantic knowledge inside thousands of neuron weights.  
Trying to nudge these weights with an ordinary gradient step is risky:

* The huge number of degrees‑of‑freedom means that even tiny weight changes can erase critical semantics.
* A low learning rate shrinks training time but still doesn’t respect *how* those changes affect relationships among neurons.
* Existing adapters such as LoRA add small rank‑1 updates—good for language models but not always enough when we need precise visual control.

OFT takes a different angle: instead of **tweaking individual weights**, it **rotates every neuron vector in a layer** by an orthogonal matrix \(\mathbf{R}\).

\[
\mathbf{z} = (\mathbf{R} \mathbf{W}^0)^\top \! \mathbf{x}
\]

\(\mathbf{W}^0\) is the original weight matrix of that layer and \(\mathbf{R}\) is learned from scratch during finetuning but is always constrained to satisfy \(\mathbf{R}^\top \mathbf{R} = \mathbf{I}\).

> **Key claim** – rotating all neurons together keeps *pairwise angles* intact.  
> Those angles encode semantic similarity among neurons on a unit hypersphere; changing them can alter what image features are produced.



---

## 2️⃣ Hyperspherical energy – the preservation metric

Mathematically we care about **hyperspherical energy**,
\[
E(\mathbf{W})=\sum_{i\ne j} \|\hat{\mathbf w}_i-\hat{\mathbf w}_j\|^{-1},
\qquad\hat{\mathbf w}_i=\frac{\mathbf w_i}{\|\mathbf w_i\|}.
\]

If two sets of neuron vectors differ only by an orthogonal transform,
their pooled pairwise cosine similarities are identical → \(E(\cdot)\) stays exactly the same.
Thus ONET training reduces to solving  
\[
\min_{\mathbf R}\;\bigl| E(\mathbf R\,\! \mathbf W^0)\!-E(\mathbf W^0)\bigr|=0 .
\]
This *structural regularity* guarantees that diffused images keep their global style and content fidelity while giving us room to nudge them toward new prompts.



---

## 3️⃣ From OFT to COFT – tightening global update

Sometimes we also want OA’s linear freedom bounded so that we never drift too far from what was pre‑trained:

\[
\|\mathbf R-\mathbf I\|_F \;\le\;\epsilon .
\]

That is **Constrained Orthogonal Finetune (COFT)**.\*  
In practice we implement this by starting \(\mathbf R=\mathbf I\) (zero matrix via Cayley transform) and projecting back onto an \(F_2-\)ball during gradient descent.  

Result? Even calmer optimization curves—fewer collapsed generations after many epochs.



---

## 4️⃣ Fast, cheap, and clean

| Method | Trainable parameters | Memory overhead | Inference speed |
|--------|---------------------|-----------------|----------------|
| LoRA   | \(r'(d+n)\) | Same fan‑in/out pattern | Slight overhead because we add at runtime |
| ControlNet | Extra network (~6M params) | Extra weights stored | Minimal extra compute |
| OFT   | \(O(d)\) parameters per block | Whole model not touched | Identical speed as base diffusion |

Using block‑diagonal orthogonal matrices reduces parameter count from \(d(d{-}1)/2\) down toward linear scale \(O(d)\). A single 128 × 128 weight layer jumps from ~2k LoRA params to fewer than 1k OFT params—yet we still see *smooth convergence* in just 200 epochs.



---

## 5️⃣ In action – subject driven & controllable generation

### Subject‑Driven Generation

You feed in < 10 photographs of an object/animal/actor + text “a portrait of me”.  

* **DreamBooth** keeps the picture recognizable but struggles when prompts diverge significantly from training texts—often losing detail after ~2000 updates.\*
* **LoRA** may happily forget identity earlier (~400 iterations), producing fuzzy caricatures.\*
* **(O)FT** preserves both subject identity *and* follows divergent prompts faster—stable after < 400 steps and still stable up to > 2000 steps because all updates live on a unit sphere.*

Metrics measured:
```
DINO/CLIP Image similarity   : 80‑90% higher than LoRA
Prompt fidelity (CLIP Text): ≈ same as DreamBooth
LPIPS diversity: comparable or slightly better
```

Visuals show perfect hair texture + pose changes you asked for—no blur or missing limbs.



### Controllable Generation

Add arbitrary signals:
- **Canny edges → image** (C2I)
- **Segmentation map → image** (S2I)
- **Facial landmarks → face** (L2F)

We stack one OFT per attention layer used by Stable Diffusion’s cross‑modal guidance encoder so that it only needs ~3 % trainable weight relative to base code size, yet learns clean mappings from each signal into channels used by diffusion steps.

#### A new evaluation metric – *control consistency*

For each generated sample we run an off‑the–shelf extractor again:

```
Canny : IoU / F1 between original edges vs extracted ones from image
Segmentation : pixel IoU + overall accuracy vs ground truth mask
Landmarks : L2 distance between reference landmarks vs predicted ones
```

OFT outperforms:
*ControlNet*: Accuracy ↑10–15% at similar sample quality  
*T2I‑Adapter*: Consistency ↑20% while staying faster  

Across all tasks workshops tune hyperparameters once and see smooth learning curves versus ControlNet’s erratic early plateau.

# Fast + Stable + No Extra Overhead – Why **OFT** Beats **LoRA** & Beyond

## The finetuning bottleneck in text‑to‑image diffusion  

State‑of‑the‑art diffusion models such as Stable Diffusion or Imagen can turn natural language descriptions into stunning images without any user interaction beyond a prompt.  
Yet those pre‑trained pipelines are generic beasts: they do **not** know how to keep the face of a single person intact when new clothing is added, or how to follow a hand‑drawn edge map while still looking realistic.  
Typical solutions address this by retraining a small part of the model on a handful of task‑specific images:

* **DreamBooth** adapts a few images of a person using a likely “few‑shot” control loss.
* **LoRA** injects two small matrices \(A,B\) so that the effective weight becomes \(W^\circ + A B^\top\).
* **ControlNet** mirrors this approach by adding an auxiliary network that sits side‑by‑side with the base diffusion module during sampling.

While these tricks recover some control capacity they come with costs:

| Property | DreamBooth | LoRA | ControlNet | Orthogonal Finetuning (OFT) |
|----------|------------|------|------------|------------------------------|
| Trainable parameters | High (nearly full model) | Low/medium | Low/medium | Low |
| Convergence time | Long            | Slow                  | Slow           | Very fast |
| Stability        | Prone to collapse if epochs > threshold | Sensitive | Sensitive × multi‑stage optimisation | Highly stable |
| Inference overhead | None          | None                 | Significant      | None |

The last column above is crucial for real deployments where latency matters as much as image fidelity.

## What is **Orthogonal Finetuning**?  

### Keeping neurons on their “semantic straight line”

Large networks learn *directions* more than magnitudes:

* Each neuron weight vector \(\mathbf{w}_i\in\mathbb{R}^d\) defines an angle sweet spot on the unit sphere.
* On this sphere we can compute **hyperspherical energy**

\[
\E_H(\mathbf{W})=\sum_{i\neq j}\bigl\|\hat{\mathbf w}_i-\hat{\mathbf w}_j\bigr\|^{-1},
\quad 
\hat{\mathbf w}_i=\frac{\mathbf w_i}{\|\mathbf w_i\|}
\]

which aggregates all pairwise angles between neurons in one layer.
Small energy means uniformly spread directions – an excellent property discovered in classification work.  
For generative models we actually want something different: *preserve* the pattern of angles learned during pretraining so that semantic meaning does not evaporate when we adjust weights.



### Orthogonality == angle preservation  

If the new weight matrix \(\mathbf W = \mathbf R\, \mathbf W^0\) is obtained by left–multiplying every neuron of the pretrained matrix \(\mathbf W^0\) with an orthogonal matrix \(\mathbf R\), then

* Every neuron stays on its unit sphere because \(\|\hat{\mathbf R\,w}\|=1\).
* All pairwise cosine similarities stay exactly the same because 

\[
(\hat{\mathbf R\,w}_i)\!\cdot(\hat{\mathbf R\,w}_j)=
     (\hat{\mathbf w}_i)\!\cdot(\hat{\mathbf w}_j).
\]

In other words,

> **Any orthogonal transform leaves hyperspherical energy untouched**—the metric that encodes semantic relationships among neurons.



### Block–diagonal compact parametrisation  

A naïve orthogonal matrix is huge (\(d\times d\)).  
OFT splits it into smaller blocks:

```math
\bR = \mathrm{diag}(\bR_1,\dots,\bR_r),   \quad   \bR_k \in O(d/r)
```

Each block acts only on its own subset of channels—akin to depth‑wise convolution—reducing trainable parameters from \(O(d^2)\) down into roughly \(O(d)\) even when many blocks are shared across layers.



---

## How does this beat adding a low‑rank adapter?

### Parameter efficiency vs flexibility 

LoRA writes the update as \(A B^\top\); it has two sizes \(r'\) controlling rank, giving parameter count \(r'(d+n)\).  
OFT’s single block–diagonal orthonormal matrix gives count \(d(d/r -1)/2\).  
With similar choices of hyperparameters,

```text
LoRA   —≈2·10⁵ params   (for d≈128, r'=8)
OFT     ≈9·10⁴ params   (for d≈128, r=8)
```

so **half as many learnable weights**.



### Faster convergence & smoother learning curves 

Because every step is simply rotating all neurons together,
the optimisation stays **well conditioned**:
updates move points along great circles on the unit sphere instead of pulling them across arbitrary directions.
This translates directly into:

* **Subject–driven generation** — target images converge in ~400 iterations while DreamBooth or vanilla finetune would need >2000 iterations before collapsing.
* **Controllable generation** — landmark‐to‐face task reaches comparable accuracy after just 8 epochs versus 20 epochs required by LoRA.



### Training dynamics explained  

Close inspection of loss curves reveals three key differences:

1. **Gradients remain bounded** — no wild spikes that can destabilise early learning stages found in some adapter methods.
2. **Monotonic progress** — once improvement starts it never crashes back toward random generations.
3. **Less sensitivity to learning rate** — because we stay near an “energy‐neutral” manifold, moderate LR already provides short stable paths.



### Preservation of original semantics  

During finetune we wanted two separate notions:
1️⃣ Keep neurons’ relative angles → preserve what magic managed during pretraining.\n\n2️⃣ Keep the weight vector itself close enough so numerical drift does not die out training.\n\nOrthonormality guarantees (1), while adding an explicit radius constraint

```math
\|\bR-\bI\bigr\rVert_2 \;\leqslant\,\epsilon 
```

keeps drift bounded → this is Constrained Orthogonal Finetuning (COFT).  
COFT tends to be even safer especially when you do not want fine grained control over how far you deviate from the baseline.



---

## No extra runtime cost during inference  

Orthogonally rotating neurons changes nothing about *how* decoding proceeds once trained:

```
Pretrained weight → Ŵ              # baseline SD U-net weight tensor
After training -> Ŵ' = R · Ŵ       # simple matrix multiplication executed offline
Deploy Ŵ' exactly like original model # no added ops or modules
```

Contrast this with ControlNet where every denoising step must feed both prompt features and an auxiliary “control map” through an extra neural subnet—doubling GPU memory consumption during sampling.

## Closing thoughts & future directions  

Orthogonal Finetuning marries several wisdoms discovered across machine learning communities:

* The geometry of high‐dimensional weight space matters more than sheer magnitude shifts.\n\n* Preserving radial symmetry keeps almost all pretraining knowledge alive.\n\n* Compact block‑diagonal matrices let us flexibly “spin” neurons without blowing up memory.*

Open problems we could look into next without violating anything from this work include:
> * Providing differentiable routines that replace Cayley inverse for very high dimensions.*  
> * Using multiple learned orthogonals together (“composition”) while proving union preservation properties.*  
> * Exploring re‑scaled versions where each neuron’s magnitude receives its own scalar—this minor tweak boosts visual fidelity yet adds negligible load.*

All told, if your goal is still‑editable diffusion models today without slower sampling or extra memory hits,
or if you simply need robust finite training episodes,
orthogonally rotating neurons offers rigourously grounded performance gains over legacy low-rank adapters like LoRA or heavy control nets alike.
