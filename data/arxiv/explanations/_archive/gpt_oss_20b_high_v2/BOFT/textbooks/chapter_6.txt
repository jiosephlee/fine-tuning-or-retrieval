\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 6: Butterfly Graphs From Fast Fourier Transforms

# Introduction  

The Cooley‑Tukey algorithm is one of the most celebrated algorithms in scientific computing because it reduces the naive $\mathcal{O}(n^2)$ discrete Fourier transform (DFT) into a sequence of simpler operations that cost only  
$\mathcal{O}(n \log n)$.  While its original motivation was to accelerate spectral analysis of time‑series data, the underlying graph‑theoretic structure that it reveals is far more general.  Every linear transform that can be computed by Cooley‑Tukey is represented as a product of sparse matrices whose non‑zero pattern forms a characteristic “butterfly” network.  In this chapter we unpack that network: how it arises from recursive splitting, how a single butterfly unit is built from four small diagonal blocks, and why the resulting sparse adjacency enables every input element to mix with every output element while using only $O(n\log n)$ edges.

# Recursive split → two $\,\theta/2$‑factors per level  

Suppose we wish to compute an $N$‑point DFT where $N$ is a power of two, i.e., $N=2^K$.  The Cooley‑Tukey recursion begins by partitioning an input vector $\mathbf{x}\in\mathbb{C}^{N}$ into its even and odd indices:
\[
\mathbf{x}_{\text{even}}=\bigl(x_0,x_2,\dots,x_{N-2}\bigr),\qquad
\mathbf{x}_{\text{odd}}=\bigl(x_1,x_3,\dots,x_{N-1}\bigr).
\]
Applying the DFT separately to these two halves gives two $(N/2)$‑point transforms and then mixes their results using twiddle factors $\omega_N^{k}=\exp(-2\pi i k/N)$.  
In matrix form this mixing step is encoded in an $N\times N$ matrix whose non‑zero entries occupy precisely two disjoint “halves”:
each row has two non‑zero entries that involve one element from $\mathbf{x}_{\text{even}}$ and one from $\mathbf{x}_{\text{odd}}$.  
This matrix can be seen as a product of two $\,N/2$‑dimensional orthogonal-like matrices—one handling the left half and one handling the right half—conjoined by identity connections between them.  

Repeating this decomposition at every recursion level produces $K=\log_2 N$ stages, each time halving the block size but doubling the number of factors needed.  As a result every stage introduces exactly two sparse matrices acting on vectors of size $N/2$, $N/4$,\, … down to size 1.  Because each such factor only touches pairs of elements from adjacent halves, it introduces so-called “fan‑out” connections that link two inputs into one output or vice versa.  This recursive splitting with two $\theta/2$‑factors per level is precisely what underpins the fan‑out diagram we will now describe in more detail.

# Butterfly unit = diagonal × diagonal + diagonal × diagonal blocks  

At any given stage let us examine what one basic operation looks like on a block of size $k=2^m$.  Cooley–Tukey groups every pair {\em(inside)} that block into “butterfly” interactions:
an even element participates together with an odd element via multiplicative twiddle factors before being summed and subtracted back into even/odd positions.
Matrixwise this interaction is captured by a $k\times k$ *butterfly factor* $\boldsymbol{B}^{F}(k)$ defined as
\[
\boldsymbol{B}^{F}(k)=
\begin{bmatrix}
    \operatorname{diag}(\mathbf{d}_1) & \operatorname{diag}(\mathbf{d}_2)\\[4pt]
    \operatorname{diag}(\mathbf{d}_3) & \operatorname{diag}(\mathbf{d}_4)
\end{bmatrix},
\tag{1}
\]
where $\mathbf{d}_i \in \mathbb{R}^{k/2}$ are scalar vectors (for complex DFTs they contain twiddle phases).  
Each row–block contains only two non‑zero columns—one on the left side ($\operatorname{diag}(\mathbf{d}_1)$ or $\operatorname{diag}(\mathbf{d}_3)$), one on the right side ($\operatorname{diag}(\mathbf{d}_2)$ or $\operatorname{diag}(\mathbf{d}_4)$).  
Hence every input index feeds into exactly two output indices inside that block, while coupling its paired index through multiplication by scalars housed inside the four diagonals.

For larger matrices we stack these butterfly factors recursively:
for an overall dimension $n=2^K$, we define
\[
\boldsymbol B(n)=
\tilde{\boldsymbol B}(n,n)\,
      \tilde{\boldsymbol B}\!\Bigl(n,\tfrac n 2 \Bigr)\,
      \cdots
      \tilde{\boldsymbol B}\!\Bigl(n,\,2 \Bigr),
      \tag{2}
\]
where each component
$\tilde{\boldsymbol B}(n,k)=
     \operatorname{diag}\!\bigl(\boldsymbol B^{F}(k),\, 
                             \boldsymbol B^{F}(k),\, 
                             \dots,\,
                             \boldsymbol B^{F}(k)\bigr)
$
places copies of a single butterfly factor along its main diagonal.
Thus $\tilde{\boldsymbol B}(n,k)$ has block size $k$; there are $(n/k)$ such copies side by side.
Each copy implements one independent butterfly operation on its $k$ rows.
Because every copy operates on mutually exclusive indices, all rows remain orthogonal **within** their blocks, while also permitting inter‑block communication through subsequent levels.

Notice carefully that equation (1) presents not just any pairwise coupling but a specific *spatial* pattern:
the left diagonals interact exclusively with one half of the subsequent column indices while excluding the other half; likewise for the right diagonals.
When several such layers are chained as indicated in equation (2), these local couplings reproduce exactly all pairwise interactions between any input location and any output location—though never explicitly forming a dense matrix in memory during forward evaluation.

# Resulting sparse adjacency supporting efficient communication  

To visualise how data propagate through these matrices let us write down an example with $n=8$ ($K=3$).  
At stage 0 our input vector has eight entries.
We apply $\tilde{\boldsymbol B}\!\bigl(8,8\bigr)$ which essentially does nothing because it corresponds to an unpartitioned block—the initial identity connections.
The next stage carries out $\tilde{\boldsymbol B}\!\bigl(8,4\bigr)$:
two disjoint butterfly factors each serve four rows;
each factor connects every row in its upper half to every row in its lower half via two non‑zero entries.
Graphically we can draw rows as nodes plotted on discrete horizontal levels:
at level 0 we start with eight input nodes; 
a directed edge from node $i$ at level $p$ points toward node $j$ at level $p+1$
if $(i,j)$ is non-zero in any intermediate factor.
In our toy example this yields eight directed edges at level 0→1 linking node pairs,
and another eight at level 1→2 after applying both copies’ butterflies simultaneously.
Thus after proceeding through all three levels we have exported eight destination nodes—one per output element—and every starting node finds itself connected to *every* ending node along at least one directed path.
This guarantees global mixing while keeping edges far fewer than those necessary for full density: each stage only contributes twice as many edges as there are nodes traversed so far.

Quantitatively counting edges clarifies this observation.
At stage $r$, where block size shrinks from $n/2^{\,r-1}$ to $n/2^{\,r}$,
every butterfly copy contains exactly $n$ non-zero entries because there are $(n/(n/2^{r-1}))*(n/(n/2^{r})) = 4*(n/(n)) =4$ directed connections per emitting node across both halves—two per offset—but since each copy has $(n/(n/2^{r}))= 2^{r-1}$ copies totalling $4(n/ ( n / 2^{ r}))= 8\,?$
Let us simplify: In practice each butterfly factor has exactly twice as many secrets as rows,
so altogether at level $r$ we insert precisely $n\,r$ edges cumulatively over all levels when unrolled fully.
Hence over all recursion depths ($K=\log_20 n$) we use
$\sum_{r=1}^{K}{nr}= n\,K = n\,\log_20 n$
edges—a major reduction from $n^2-n = O(n^２)$ edges required by an arbitrary dense orthogonal matrix.
Because edges correspond directly to parameters,
the product-of-sparse-orthogonal-matrices formulation embedded in BOFT carries at most about 
$\tfrac12 (b-1)nK$
effective trainable scalars if each cardiac `butterfly` employs block size $b$, giving rise to an overall parameter budget proportional to `$O(n\bigsqcup b)\!·​{\rm log}_20 n'`.  

The same sparsity pattern naturally supports fast algorithms beyond FFT:
once coefficients $\mathbf d_i$ are replaced by generic trainable scalars or small matrices (as done in BOFT),
we obtain structured orthogonal transforms capable of universal approximation when combined across multiple levels,
yet still preserve extremely low communication cost thanks to this underlying “butterfly” topology.

In conclusion, Cooley–Tukey’s elegant recursive decomposition delivers not only algorithmic speed but also a powerful architectural motif—a bipartite network where local doublet interactions staged across logarithmically many layers fuse global information using only `$O(n﹤∀﹂log_n)`’ edges. This motif lies at heart both classic spectral transforms and modern parameter-efficient finetuning techniques such as BOFT discussed throughout this text suite.
