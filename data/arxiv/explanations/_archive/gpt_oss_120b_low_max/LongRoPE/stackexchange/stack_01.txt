\title{Stack Exchange of the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

### How does the unified RoPE interpolation formula in Eq. (2) relate to the original RoPE definition in Eq. (1)?
Question:
In the paper, Eq. (1) defines the RoPE embedding as \([\cos(n\theta_0), \sin(n\theta_0), \dots, \cos(n\theta_{d/2-1}), \sin(n\theta_{d/2-1})]\). Later, Eq. (2) rewrites the embedding with a rescale factor \(\lambda(\beta)^i\). I am confused about how the term \(\frac{n}{\lambda(\beta)^i}\) is derived from the original \(n\theta_i = n/\beta^i\). Specifically, what is the meaning of \(\lambda(\beta)^i\) and how does it incorporate the extension ratio \(s\)?
Answer:
In the original RoPE definition (Eq.\ (1)) the rotary angle that is applied to the *i*‑th sub‑space of the embedding at token position **n** is  

\[
\theta_{i}^{(n)} = n\,\theta_{i}= \frac{n}{\beta^{\,i}}\;,
\qquad 
\beta = \theta^{2/d}.
\]

The factor \(\beta^{\,i}\) is decreasing with the dimension index \(i\); low‑index dimensions correspond to high‑frequency sinusoids, high‑index dimensions to low‑frequency ones.  
When we want to use the same pretrained model on a longer sequence we cannot simply feed it positions larger than the original maximum because the angles become *much* larger than the range that the model has ever seen during pre‑training.  The usual remedy is to **compress** the new positions so that they lie inside the interval \([0,L]\) that the model was trained on.  

--------------------------------------------------------------------

### From \(\displaystyle \frac{n}{\beta^{i}}\) to \(\displaystyle \frac{n}{\lambda(\beta)^{\,i}}\)

All existing interpolation schemes can be written as a *scale* that multiplies the original angle:

\[
\theta_{i}^{(n)} \;\longrightarrow\; \frac{1}{\lambda_{i}}\;\frac{n}{\beta^{\,i}}
          = \frac{n}{\bigl(\lambda_{i}^{1/i}\,\beta\bigr)^{\,i}} .
\]

If we define a **single scalar function of the base**  

\[
\lambda(\beta)\;:=\;\lambda_{i}^{1/i},
\]

the rescaled angle becomes  

\[
\theta_{i}^{(n)} =  \frac{n}{\lambda(\beta)^{\,i}} .
\]

Thus Eq.\ (2) is simply a compact way of writing

\[
\bigl[\cos(\tfrac{n}{\lambda(\beta)^{0}}),\, 
      \sin(\tfrac{n}{\lambda(\beta)^{0}}),\, 
      \cos(\tfrac{n}{\lambda(\beta)^{1}}),\, 
      \dots,\,
      \sin(\tfrac{n}{\lambda(\beta)^{d/2-1}})\bigr],
\]

which reduces to Eq.\ (1) when every \(\lambda_{i}=1\).

--------------------------------------------------------------------

### What does \(\lambda(\beta)^{\,i}\) represent?

For a given **extension ratio**  

\[
s = \frac{L'}{L},
\]

different interpolation methods choose a concrete value for each per‑dimension scale factor \(\lambda_{i}\):

| method | per‑dimension scale \(\lambda_{i}\) | intuition |
|--------|-----------------------------------|-----------|
| **PI** (linear interpolation) | \(\lambda_{i}=s\) for **all** \(i\) | every sinusoid is compressed by exactly the same factor. |
| **NTK** | \(\lambda_{i}=s^{\,i}\) | low‑frequency (large‑\(i\)) dimensions are compressed more heavily, high‑frequency dimensions are left almost untouched – this follows the NTK analysis that low frequencies need more “room”. |
| **YaRN** | three groups: \(1,\; s^{-a},\; s^{b}\) (different exponents for each group) | a hand‑crafted piecewise version of NTK + extrapolation. |

All of those can be expressed by setting  

\[
\lambda(\beta)= s^{\,c},   \qquad c=\frac{\log \lambda_i}{ i\,\log s } .
\]

When \(c=0\) we obtain PI (\(\lambda_i=s^0=1\)).  More generally, any choice of per‑dimension scales can be captured by an appropriate function \(\lambda(\beta)\).  In practice LongRoPE does not force a simple analytic form; it **searches** for a vector \((\lambda_0,\dots,\lambda_{d/2-1})$) subject to the monotonicity constraint  

\[
1=\lambda_0 \le \lambda_1 \le \dots \le \lambda_{d/2-1} .
\]

The monotonicity follows from the NTK observation that higher dimensions (lower frequencies) may tolerate larger compression.

--------------------------------------------------------------------

### Where does the extension ratio \(s\) appear?

During the search we bound each individual factor:

```
λ_i ∈ [ 1.0 ,  s × 1.25 ]
```

The lower bound corresponds to *no interpolation* (pure extrapolation), while the upper bound allows slightly more compression than naïve linear PI (the factor \(1.25\,s\)).  
Thus \(s\) acts as a **global budget** – it tells us how much total “shrinkage” we may apply, but the algorithm decides how to distribute that budget across dimensions.

--------------------------------------------------------------------

### Summary

* Eq.\ (1) uses raw angles \(n/\beta^{i}\).  
* Extending the context requires scaling those angles by a per‑dimension factor \(1/\lambda_{i}\).  
* By defining a scalar function \(\lambda(\beta)\) such that  
  \[
  \frac{1}{\lambda_{i}} = \frac{1}{[\lambda(\beta)]^{\,i}},
  \]
  we can write all interpolations compactly as Eq.\ (2).  
* The term \(s=L'/L\) does not appear explicitly in Eq.\ (2); it limits the admissible range of each \(\lambda_i\).  Different prior methods correspond to particular choices of the sequence \((\lambda_i)\); LongRoPE discovers a *non‑uniform* sequence that better preserves important high‑frequency dimensions while still fitting the longer positions.

Consequently, Eq.\ (2) is a unified notation for any RoPE interpolation, and “the rescale factor \(λ(β)^i” simply encodes how much each frequency dimension’s angle has been compressed (or extrapolated) relative to its original value, with the overall compression budget determined by the desired extension ratio \(s\).
