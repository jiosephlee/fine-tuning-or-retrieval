\title{Blogs about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

# Controlling Images with a Light Touch: How OFT Outperforms ControlNet and T2I‑Adapter  

*When you want a diffusion model to obey a sketch, a segmentation map, or a set of facial landmarks, you usually reach for heavyweight adapters like ControlNet or T2I‑Adapter.  A recent paper shows that a much lighter finetuning trick—**Orthogonal Finetuning (OFT)**—can give you tighter control **without any extra cost at inference time**. In this post we unpack the idea, the new control‑consistency metric, and what the experimental results actually mean for practitioners.*

---  

## Why finetuning matters (and why it’s hard)

Large text‑to‑image diffusion models (Stable Diffusion, Imagen, DALL‑E 2…) already know how to turn a prompt into a photorealistic picture.  
Adding an extra conditioning signal (edges, masks, landmarks) is essentially a **finetuning problem**: we must tweak the pretrained weights so the model learns a new mapping while still retaining its original knowledge.

Existing approaches fall into two camps:

| Method | How it adapts the model | Typical drawbacks |
|--------|------------------------|-------------------|
| **Low‑rank adapters (LoRA)** | Adds a low‑rank matrix \(\Delta W = BA^\top\) to each layer. | The added parameters are still *extra* at inference; control often lags behind the baseline. |
| **ControlNet / T2I‑Adapter** | Trains an auxiliary network that injects control features alongside the backbone. | Requires additional parameters and forward passes → slower inference and larger memory footprint. |

Both strategies change **Euclidean** distances between the finetuned and pretrained weights, but that metric does not capture how semantically meaningful the model’s internal geometry remains.

---

## The key insight: keep the **angles**, not just the magnitudes  

Neurons in deep nets can be thought of as vectors lying on a unit hypersphere.  Their *pairwise angles* encode much of the semantic structure (a fact backed by decades of work on hyperspherical similarity). If we rotate all neurons in a layer **together**, those angles stay exactly the same; only their *orientation* changes.

Mathematically, for a weight matrix \(W^0\) we replace it with  

\[
W = R\,W^0,\qquad R^\top R = I,
\]

where \(R\) is an orthogonal matrix (a rotation or reflection). Because orthogonal transformations preserve inner products, the **hyperspherical energy**—the sum of inverse distances between normalized neurons—remains unchanged.  

**Orthogonal Finetuning (OFT)** therefore enforces two things:

1. **Semantic preservation** – the pretrained relational structure of neurons stays intact.  
2. **Controlled flexibility** – only the *direction* of every neuron can change, which is exactly what we need to steer generation toward a new conditioning signal.

A constrained variant (COFT) adds \(\|R - I\|\le\epsilon\), ensuring the rotation stays close to identity and further stabilizing training.

---

## No extra cost at test time  

During training we learn \(R\) with cheap parameterizations (Cayley transform + block‑diagonal factorization). At inference we simply pre‑multiply \(R\) into the original weight matrix once:

```python
W_finetuned = R @ W_pretrained   # done offline
```

The forward pass thereafter is identical to vanilla Stable Diffusion—no extra branches, no additional memory, no latency penalty. This is a stark contrast to ControlNet where a full extra UNet runs side‑by‑side with the base model.

---

## Measuring “control” more rigorously  

Previous papers mostly reported visual examples or indirect scores (FID, CLIP similarity). The OFT authors introduced a **control‑consistency metric** that directly quantifies how well the generated image respects its conditioning:

| Task | Signal extracted from output | Metric |
|------|-----------------------------|--------|
| **Canny → Image** | Re‑run Canny edge detector on generated image | Intersection‑over‑Union (IoU) & F1 |
| **Segmentation → Image** | Feed generated image into a pretrained segmentation network | Mean IoU & pixel accuracy |
| **Landmarks → Face** | Detect facial landmarks on output (e.g., using dlib) | Mean \(\ell_2\) distance to input landmarks |

Because these metrics compare *input control* ↔ *predicted control*, they give an absolute gauge of controllability rather than relying on subjective inspection.

## What the numbers say  

Below is a distilled view of the results on three representative datasets (Coco for Canny, ADE20K for segmentation, CelebA‑HQ for landmarks). All methods fine‑tune Stable Diffusion v1.5 for 20 epochs; parameter counts are comparable between OFT/COFT and LoRA, while ControlNet uses many more parameters.

| Task | Method | Params (M) | Control Consistency ↑ | Image Fidelity (CLIP‑I) ↓ |
|------|--------|------------|-----------------------|----------------------------|
| Canny → Image | ControlNet | 52 | 0.71 IoU / 0.78 F1 | 0.86 |
|               | LoRA      | 0.4 | 0.58 / 0.63          | 0.84 |
|               | **OFT**   | 0.4 | **0.78 / 0.84**      | **0.88** |
| Segmentation → Image | ControlNet | 52 | 0.63 mIoU / 71 % acc | 0.84 |
|                      | LoRA      | 0.4 | 0.48 / 62 %          | 0.81 |
|                      | **COFT**   | 0.4 | **0.71 / 78 %**      | **0.86** |
| Landmarks → Face    | ControlNet | 52 | 3.9 px error          | 0.83 |
|                     | LoRA      | 0.4 | 5.6 px error          |\( \approx \)0.80 |
|                     | **OFT**   | 0.4 |\(**3.1 px error**\)   |\(**0.87**\) |

*Higher IoU/F1 or lower landmark error means stronger adherence to the control signal; lower CLIP‑I indicates better image quality.*

Key takeaways:

* **OFT/COFT consistently win on control consistency**, sometimes beating ControlNet despite using >100× fewer trainable parameters.
* Image fidelity stays on par or improves, showing that preserving hyperspherical energy really does protect generative quality.
* Convergence is dramatically faster: OFT reaches its final performance after ~8 epochs whereas ControlNet needs all 20 epochs and still exhibits sudden “jumps” in quality.

## Intuitive examples (what you would see)

### Canny‐to‐Image  
A rough hand sketch of a cat’s outline is fed to the model along with “a photorealistic cat portrait”.  
- **ControlNet:** early epochs produce blurry blobs; only after many steps does the cat’s silhouette match the edges—often with misplaced ears.
- **OFT:** from the first few thousand steps, cat fur follows every edge; details such as whisker placement align perfectly with the stroke pattern.

### Segmentation‐to‐Image  
A semantic map showing “sky / building / road”.  
- **LoRA:** mixes up interior/exterior colors; buildings sometimes appear in sky regions.
- **OFT/COFT:** every pixel class respects its mask; windows appear where expected and sky texture looks natural without any extra decoder.

### Landmark‐to‐Face  
Five facial keypoints describing a side view pose are given together with “studio portrait”.  
- **ControlNet:** often produces frontal faces regardless of landmarks until later epochs; occasional distortion when it finally aligns.
- **OFT:** pose matches landmarks from the start; eyes, nose tip, and chin sit exactly where prescribed while skin texture remains high fidelity.

These visual trends line up with the quantitative consistency scores above.

## Practical implications  

1️⃣ **Deployable models stay slim** – Because OFT folds into the original weights, you can ship one standard `.ckpt` file and run it on any existing Stable Diffusion pipeline without modifying inference code.

2️⃣ **Faster prototyping** – Training converges in fewer epochs and is less sensitive to learning‑rate schedules; you can experiment with new control signals (e.g., depth maps) using far less GPU time.

3️⃣ **Stable fine‑tuning across subjects** – The paper also shows that OFT works well for DreamBooth style subject personalization; that same stability carries over to arbitrary control tasks.

4️⃣ **Composable control?** – Since orthogonal matrices multiply into another orthogonal matrix, one could imagine stacking multiple OFT modules (e.g., edges + pose) while retaining overall orthogonality—a promising direction for multitask controllability.

---

## Limitations & open questions  

* The current implementation relies on Cayley transforms which need a matrix inverse; scaling to gigantic transformer layers may still be costly despite block‑diagonal tricks.
* Orthogonal transformations preserve *pairwise* angles but cannot directly enforce higher‑order geometry that might be relevant for some fine-grained tasks.
* Real‑world pipelines often need variable‑resolution conditioning (e.g., high‑res sketches). Extending OFT’s block design to handle heterogeneous feature maps is left for future work.

---

## Takeaway  

Orthogonal Finetuning demonstrates that you don’t need heavyweight adapters to add precise control signals to powerful diffusion models. By rotating neurons as a whole—preserving their angular relationships—we obtain:

* Stronger alignment with edges, segmentation masks, or landmarks,
* No extra inference overhead,
* Faster and more stable convergence.

If you’re looking to equip your text‑to‑image generator with “light touch” controllability, give OFT (or its constrained variant COFT) a try—you’ll likely see sharper results with fewer resources than with ControlNet or T2I‑Adapter.
