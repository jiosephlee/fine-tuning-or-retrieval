\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: **Information Transmission Perspective on Orthogonal Matrices**

In this chapter we reinterpret the task of building dense orthogonal transformations as an information‑transmission problem on a grid‑structured graph.  This viewpoint, introduced in the paper *Parameter‑Efficient Orthogonal Finetuning via Factorization*, provides a clear and intuitive way to reason about how a dense orthogonal matrix can be assembled from a small number of sparse factors while preserving orthogonality.  By treating the entries of a matrix as potential communication channels between “source” and “receiver’’ nodes, we can formalize the desiderata for a parameter‑efficient factorization and understand why butterfly‑type factorizations succeed where naïve sparsity patterns (e.g., block‑diagonal) fail.

---

### Dense connectivity as a graph problem

Consider a linear layer with a weight matrix \(\mathbf{W}^{0}\in\mathbb{R}^{d\times n}\) that has been pretrained on a massive corpus.  In orthogonal finetuning (OFT) we replace the forward pass

\[
\mathbf{z}= (\mathbf{W}^{0})^{\!\top}\mathbf{x}
\]

by

\[
\mathbf{z}= (\mathbf{R}\,\mathbf{W}^{0})^{\!\top}\mathbf{x},
\qquad \mathbf{R}\in\mathbb{R}^{d\times d}, \ \mathbf{R}^{\!\top}\mathbf{R}= \mathbf{I}_{d},
\]

where \(\mathbf{R}\) is an orthogonal matrix learned during adaptation.  The matrix \(\mathbf{R}\) can be regarded as a **connectivity map** from the \(d\) input dimensions (the “source’’ nodes) to the \(d\) output dimensions (the “receiver’’ nodes).  In this interpretation:

* A non‑zero entry \(R_{ij}\neq 0\) means that information can flow from source node \(j\) to receiver node \(i\).
* A zero entry blocks that flow.

Thus, the full dense orthogonal matrix corresponds to a **fully connected bipartite graph**: every source is linked (directly or indirectly) to every receiver.  Our goal is to reproduce this dense connectivity using far fewer *trainable* edges.

---

### Factorizing a matrix into a product of sparse matrices

A convenient way to obtain many edges from few trainable parameters is to compose several **sparse** matrices:

\[
\mathbf{R}= \underbrace{\mathbf{B}_{m}}_{\text{sparse}}\,
           \underbrace{\mathbf{B}_{m-1}}_{\text{sparse}}\cdots
           \underbrace{\mathbf{B}_{1}}_{\text{sparse}} .
\tag{1}
\]

Each factor \(\mathbf{B}_{k}\in\mathbb{R}^{d\times d}\) can be seen as an adjacency matrix between two consecutive “levels’’ of nodes in a layered graph.  If we unfold the multiplication in (1), we obtain a **grid graph** with \(d\) nodes on each of the \(m+1\) levels (see Figure 2 in the paper).  An edge exists from node \(j\) on level \(\ell\) to node \(i\) on level \(\ell+1\) exactly when the entry \((i,j)\) of \(\mathbf{B}_{\ell+1}\) is non‑zero.  

When we multiply all factors, information propagates level by level: first according to \(\mathbf{B}_{1}\), then \(\mathbf{B}_{2}\), and so on until \(\mathbf{B}_{m}\).  The overall product \(\mathbf{R}\) therefore describes whether *any* path exists from a source node on level 0 to a receiver node on level \(m\).  If for every pair of source and receiver there exists at least one directed path, then the resulting matrix \(\mathbf{R}\) is dense (all entries potentially non‑zero).  

Consequently, designing sparse factors is equivalent to designing **edge patterns** on this layered grid such that every source can reach every sink.

---

### Directed edges, levels, and path‑based dense connectivity

Formally, let the vertices be indexed as  
\(v^{(\ell)}_{i},\, i=1,\dots,d,\; \ell=0,\dots,m\).  
An edge from \(v^{(\ell-1)}_{j}\) to \(v^{(\ell)}_{i}\) is present iff \((\mathbf{B}_{\ell})_{ij}\neq0\).  A **directed path** of length \(m\),

\[
v^{(0)}_{j} \rightarrow v^{(1)}_{i_{1}} \rightarrow v^{(2)}_{i_{2}} 
   \rightarrow \dots \rightarrow v^{(m)}_{i},
\]

corresponds to the product of entries  
\( (\mathbf{B}_{1})_{i_{1}j} (\mathbf{B}_{2})_{i_{2} i_{1}}\cdots (\mathbf{B}_{m})_{i\, i_{m-1}}.\)

If at least one such product is non‑zero, then entry \(R_{ij}\) in the final matrix is non‑zero.  Therefore:

> **Dense connectivity condition.**  
> For every pair \((j,i)\), there must exist at least one directed path from \(v^{(0)}_{j}\) to \(v^{(m)}_{i}\).

This condition translates directly into a graph‑theoretic requirement: the union of edges across all levels must induce a **strongly connected bipartite network** between the first and last layers.

---

### Desiderata: dense connectivity and minimal free edges

When seeking parameter efficiency we must respect two competing desiderata:

1. **Dense connectivity** – as defined above, ensuring that the product matrix can represent any dense orthogonal transformation.
2. **Minimal free edges** – each trainable non‑zero entry corresponds to an adjustable weight in one of the sparse factors.  To keep the total number of learnable parameters low we want as few *free* edges as possible.

In addition, each factor must be orthogonal (or at least full rank), which imposes structural constraints on permissible edge patterns: an orthogonal factor cannot arbitrarily drop edges without breaking invertibility.

The paper points out an important baseline: if we used a single dense orthogonal matrix as a factor, we would have \(d^{2}-d = O(d^{2})\) free edges (subtracting the inevitable \(d\) fixed magnitude‑one entries required for orthogonality).  The butterfly construction dramatically reduces this count to \(O(d\log d)\).

---

### ω‑edge counting under orthogonality constraints

Orthogonality means that each factor satisfies  

\[
\mathbf{B}_{k}^{\!\top}\mathbf{B}_{k}= \mathbf{I}_{d},
\qquad k=1,\dots,m .
\tag{2}
\]

Equation (2) forces each factor to be **bijective** between its input and output levels; consequently each level must contain exactly \(d\) edges that form disjoint perfect matchings (for binary sparsity patterns these are permutations).  These mandatory edges are *not* learnable because in any orthogonal permutation they are forced to be either \(+1\) or \(-1\).  We therefore count only those entries that are adjustable – the **free edges**, denoted by \(\omega_k\).

For any feasible sparse factorization:

* The total mandatory edge count across all levels is at least \(d\,m.\)
* The total free edge count satisfies  

  \[
  \sum_{k=1}^{m} \omega_k = O(d\,m).
  \]

If each factor contains only \(O(d)\) free entries—as is true for butterfly factors—then the overall number of trainable parameters scales as  

\[
O(d\,m)= O(d\,\log d)
\]

when we set \(m = \log_2 d,\) precisely what the butterfly construction achieves.

In contrast, block‑diagonal OFT forces each factor to have a fixed sparsity pattern where blocks are completely isolated; this yields dense connectivity only within each block and therefore fails the dense‑connectivity condition unless many small blocks are used, which dramatically increases parameter count or harms expressivity.

---

### Summary

By reframing orthogonal finetuning as an information transmission problem on a layered grid graph, we obtain a clear criterion for building dense orthogonal matrices from sparse pieces: every source node must be able to reach every sink node through directed paths while using as few adjustable edges as possible.  The butterfly topology satisfies both criteria elegantly—it provides logarithmic depth (\(m = O(\log d)\)) and each layer contributes only linear (\(O(d)\)) free parameters, yielding an overall parameter budget of \(O(d\,\log d)\).  This perspective not only explains why butterfly factorization yields far more parameter‑efficient orthogonal finetuning than naïve block‑diagonal schemes but also opens the door to exploring alternative network topologies from computer networking or coding theory that might further improve sparsity–expressivity trade‑offs.
