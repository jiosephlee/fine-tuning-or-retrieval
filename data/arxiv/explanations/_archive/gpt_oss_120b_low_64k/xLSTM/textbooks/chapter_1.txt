Chapter 1: # Motivation and Historical Context of LSTMs  

## Vanishing Gradients in Recurrent Neural Networks  

Recurrent neural networks (RNNs) process sequences by applying the same transformation at each time step, feeding the hidden state forward so that information can be accumulated over time.  Early RNNs, however, suffered from a fundamental training difficulty known as the *vanishing (or exploding) gradient* problem.  When back‑propagating errors through many time steps, the chain rule multiplies many Jacobian matrices together.  If the spectral norm of these matrices is smaller than one, gradients shrink exponentially; if it is larger than one, they blow up.  In either case, learning long‑range dependencies becomes impossible because the contribution of distant inputs to the loss either disappears or overwhelms the update.  The problem was formally identified in the seminal works on RNN learning \citep{Hochreiter:91,Hochreiter:00book} and motivated a search for architectures that could preserve error signals over arbitrarily long horizons.

## Constant Error Carousel (CEC) and Gating  

The breakthrough that addressed vanishing gradients was the *Constant Error Carousel* (CEC), introduced together with a set of multiplicative gates.  The CEC is an additive memory update that allows the cell state to retain its value unchanged across many steps, thereby transporting error signals backward without attenuation.  At each time step \(t\) the cell state \(c_t\) is updated according to  

\[
c_t \;=\; f_t \, c_{t-1} \;+\; i_t \, z_t ,
\tag{1}
\]  

where \(i_t\) (input gate) and \(f_t\) (forget gate) are scalars in \([0,1]\).  The term \(z_t\) denotes a candidate content generated from the current input and previous hidden state.  Because the update is a convex combination of the previous cell value and a new candidate, gradients can flow through many steps unchanged when \(f_t\approx 1\).  This additive path constitutes the *constant error carousel*.  

Gating serves two complementary purposes.  The input gate controls how much new information is written into memory, while the forget gate determines how much of the existing memory should be retained.  A third gate, the output gate \(o_t\), modulates how much of the transformed cell state is exposed as the hidden output

\[
h_t \;=\; o_t \,\psi(c_t),
\tag{2}
\]  

where \(\psi(\cdot)\) is typically a hyperbolic tangent that squashes the raw cell value into a bounded range before emission.  These three gates—input, forget, and output—are learned functions of both the current input \(\mathbf{x}_t\) and the previous hidden state \(h_{t-1}\).  Their multiplicative nature allows the network to *selectively* remember or discard information on a per‑time‑step basis, a capability that plain RNNs lack.

## Mathematical Formulation of the Original LSTM  

Putting all components together yields the full set of recurrence equations for a standard LSTM cell:

\[
\begin{aligned}
c_t &= f_t \, c_{t-1} + i_t \, z_t , \\[4pt]
h_t &= o_t \,\tilde h_t , \qquad
\tilde h_t = \psi(c_t), \\[4pt]
z_t &= \varphi(\tilde z_t), 
\qquad
\tilde z_t = \mathbf{w}^{\top}_{z}\,\mathbf{x}_t + r_z\, h_{t-1} + b_z , \\[4pt]
i_t &= \sigma(\tilde i_t),
\qquad
\tilde i_t = \mathbf{w}^{\top}_{i}\,\mathbf{x}_t + r_i\, h_{t-1} + b_i , \\[4pt]
f_t &= \sigma(\tilde f_t),
\qquad
\tilde f_t = \mathbf{w}^{\top}_{f}\,\mathbf{x}_t + r_f\, h_{t-1} + b_f , \\[4pt]
o_t &= \sigma(\tilde o_t),
\qquad
\tilde o_t = \mathbf{w}^{\top}_{o}\,\mathbf{x}_t + r_o\, h_{t-1} + b_o .
\end{aligned}
\]  

Here each gate pre‑activation (\(\tilde i_t,\tilde f_t,\tilde o_t,\tilde z_t\)) consists of an affine transformation of the external input \(\mathbf{x}_t\) plus a recurrent contribution from the previous hidden state \(h_{t-1}\).  The sigmoid function \(\sigma(x)=1/(1+e^{-x})\) restricts gates to the unit interval, while activation functions \(\varphi,\psi\) are usually chosen as hyperbolic tangents to keep values bounded.  This formulation captures both *input‑dependent* gating (through \(\mathbf{w}\)-terms) and *hidden‑dependent* gating (through \(r\)-terms), enabling rich dynamics that adapt both to current observations and to internal context.

When multiple scalar cells are stacked into a vector \(\mathbf{c}_t\in\mathbb{R}^d\), recurrent weight matrices replace scalar recurrence coefficients, allowing communication across cells via hidden‑hidden connections (“memory mixing”).  Ablation studies such as those in \citet{Greff:15} have demonstrated that every component—additive update, three gates, recurrent connections—is essential for achieving high performance.

## Successes of LSTMs Across Domains  

The introduction of constant‑error carousel and gating transformed sequential modeling.  LSTMs quickly became a workhorse for tasks requiring long‑range dependency capture:

* **Natural language generation and modeling** – Early works demonstrated fluent text synthesis from character‑level LSTMs (\citep{Graves:13}) and later word‑level generation (\citep{Karpathy:15blog}).  
* **Handwriting generation** – By coupling an LSTM with mixture density outputs, realistic stroke sequences were produced (\citep{Graves:13}).  
* **Sequence‑to‑sequence translation** – Encoder–decoder architectures built on stacked LSTMs achieved competitive machine translation results (\citep{Sutskever:14nips}).  
* **Program evaluation** – LSTMs learned to execute short programs in synthetic languages (\citep{Zaremba:14arxiv}).  
* **Image captioning and code generation** – Joint visual–text models leveraged LSTM decoders to articulate image content or source code (\citep{Karpathy:15}, \citep{Hossain:19}).  
* **Hydrological forecasting** – In environmental modeling, LSTMs captured complex rainfall–runoff relationships (\citep{Kratzert:18}, \citep{Kratzert:19}) and contributed to flood warning systems (\citep{Nearing:24}).  
* **Reinforcement learning agents** – High‑performing agents such as AlphaStar for StarCraft II (\citep{Vinyals:17short}) and OpenAI Five for Dota 2 (\citep{OpenAI:19}) embedded LSTM cores to maintain strategic memory over long episodes.  

Beyond these examples, analyses have uncovered *semantic neurons*—individual units whose activations correlate strongly with interpretable concepts such as number syntax (\citep{Lakretz:19}), sentiment (\citep{Radford:17arxiv}), or linguistic categories (\citep{Bau:19}).  These discoveries highlight that LSTM memories can learn abstract representations useful across disparate downstream tasks.

## Emergence of Transformers and the Challenge to LSTMs  

Despite their strengths, LSTMs retain three notable drawbacks that eventually motivated a paradigm shift toward attention‑based models:

1. **Inability to revise storage decisions** – Once an element has been written into a scalar cell it cannot be efficiently overwritten without explicit gating tricks.  In tasks like Nearest Neighbor Search where newer evidence should replace older stored values, vanilla LSTMs exhibit high mean‑squared error because they cannot retroactively edit earlier writes.

2. **Limited storage capacity** – Each cell stores a single scalar value; even with many parallel cells this compression can hinder representation of rare events or high‑dimensional features (e.g., rare token prediction on WikiText‑103 suffers higher perplexity).

3. **Sequential processing bottleneck** – Hidden‑to‑hidden recurrences enforce strict time‑step ordering; parallel hardware cannot accelerate inference or training beyond linear time in sequence length.

The *Transformer* architecture introduced in 2017 (\citep{Vaswani:17}) circumvented these issues by replacing recurrence with self‑attention—a mechanism that computes pairwise interactions between all tokens in parallel.  Self‑attention provides:

* **Direct revision** of any earlier token’s contribution during each layer’s computation,
* **Unbounded storage capacity** through learned attention weight matrices,
* **Quadratic parallelizability**, allowing modern GPUs/TPUs to process very long contexts efficiently.

These advantages led Transformers to dominate large language modeling benchmarks and become the foundation of contemporary large language models (LLMs) such as GPT‑3 (\citep{Brown:20short}) and LLaMA (\citep{Touvron:23arxiv}).  Nonetheless, Transformers incur quadratic memory costs with respect to sequence length, prompting ongoing research into linear attention approximations and alternative recurrent structures.

The historical trajectory—from vanishing gradients in early RNNs → constant error carousel & gating in LSTMs → transformer self‑attention—sets the stage for recent attempts to revive recurrent ideas at scale.  By extending LSTM gating (exponential gates), augmenting memory structures (scalar vs.\ matrix memories), and embedding these units in residual blocks (the xLSTM framework), researchers aim to combine the interpretability and linear-time benefits of recurrence with performance competitive with modern Transformers.
