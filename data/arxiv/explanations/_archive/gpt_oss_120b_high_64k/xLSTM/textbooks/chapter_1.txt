\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 1: xLSTM: Extended Long Short‑Term Memory – Introduction & Motivation

# Historical development from simple RNNs → vanishing gradients

The earliest recurrent neural networks attempted to model sequential data by feeding the hidden state at time \(t\!-\!1\) back into the network alongside the current input \(\mathbf{x}_t\). In its most basic form a recurrent unit computes 
\[
\mathbf{h}_t = \phi(\mathbf{W}_{xh}\mathbf{x}_t + \mathbf{W}_{hh}\mathbf{h}_{t-1} + \mathbf{b}_h),
\] 
where \(\phi\) is a pointwise non‑linearity such as \(\tanh\) or \(\sigma\). Although this formulation is conceptually simple, training it with gradient‑based methods quickly ran into a severe obstacle known as the *vanishing (or exploding) gradient* problem \citep{Hochreiter:91,Hochreiter:00book}. Because gradients are repeatedly multiplied by the Jacobian of \(\phi\) at each time step, signals that should propagate information from far‑away timesteps either shrink exponentially toward zero or grow without bound. As a result, naive recurrent units could only learn short‑range dependencies even though the model architecture itself allowed arbitrarily long histories. This limitation motivated a wave of research focused on stabilising gradient flow through time, culminating in the design of more sophisticated recurrent cells that could preserve information over long horizons.

# Key ideas behind the original LSTM (constant‑error carousel, three gating mechanisms)

The Long Short‑Term Memory network was introduced precisely to address gradient degradation by redesigning how information is stored and updated across time steps \citep{Hochreiter:91,Hochreiter:97nips,Hochreiter:97}. Its core consists of a *cell state* \(c_t\) that runs through the network via an additive pathway often called the **constant‑error carousel**. Unlike the multiplicative hidden‑state dynamics of simple RNNs, the cell state evolves according to
\begin{align}
c_t &= f_t\,c_{t-1} + i_t\,z_t,
    &&\text{cell update} \label{eq:lstm_cell}\\
h_t &= o_t\,\psi(c_t),
    &&\text{hidden output},
\end{align}
which appears as Equation~\eqref{eq:lstm_idea} in the original formulation. Three gates modulate this process:

* The **input gate** \(i_t = \sigma(\tilde{i}_t)\) decides how much of the candidate input \(z_t = \varphi(\tilde{z}_t)\) should be written into the cell.
* The **forget gate** \(f_t = \sigma(\tilde{f}_t)\) determines how much of the previous cell content \(c_{t-1}\) should be retained.
* The **output gate** \(o_t = \sigma(\tilde{o}_t)\) controls how strongly the normalized cell state \(\psi(c_t)\) contributes to the hidden output \(h_t\).

Each pre‑activation \(\tilde{i}_t,\tilde{f}_t,\tilde{o}_t,\tilde{z}_t\) is an affine combination of the current input \(\mathbf{x}_t\) and the previous hidden state \(h_{t-1}\), for example
\[
\tilde{i}_t = \mathbf{w}^{\top}_{i}\mathbf{x}_t + r_i\,h_{t-1}+b_i,
\]
with analogous expressions for the other gates and candidate input. The sigmoid non‑linearity \(\sigma(x)=1/(1+\exp(-x))\) constrains gate activations to lie between zero and one, thereby enabling smooth interpolation between “open” and “closed” states. This gating mechanism together with additive updates yields gradients that propagate unchanged through long sequences—hence “constant error”—and therefore mitigates vanishing gradients. The final non‑linearity \(\psi(\cdot)\), typically a hyperbolic tangent, normalises or squashes the potentially unbounded cell state before it contributes to downstream layers.

# Success stories of LSTMs across NLP, reinforcement learning, scientific modeling

Since their inception LSTMs have become a workhorse for any task requiring sequential reasoning. In natural language processing they powered early breakthroughs such as character‑level text generation (\citep{Graves:13}) and handwriting synthesis (\citep{Graves:13}), demonstrating an ability to capture long‑range syntax from raw data streams. Sequence‑to‑sequence translation systems (\citep{Sutskever:14nips}) relied on bidirectional LSTMs to encode source sentences before decoding target language tokens—a paradigm that persisted well after attention mechanisms arrived. Their expressive memory also made them suitable for program evaluation (\citep{Zaremba:14arxiv}), image captioning (\citep{Karpathy:15,Hossain:19}), source‐code generation (\citep{Karpathy:15blog}), and even hydrological forecasting (\citep{Kratzert:18,Kratzert:19,Nearing:24}). 

In reinforcement learning deep recurrent policies have consistently outperformed feed‑forward baselines on temporally extended tasks. Notable examples include AlphaStar’s strategic reasoning in StarCraft II (\citep{Vinyals:17short}) and OpenAI Five’s coordination in Dota 2 (\citep{OpenAI:19}), where LSTMs learned to store game state over hundreds of timesteps. A particularly striking application lies in controlling magnetic confinement fusion reactors (\citep{Degrave:22short}), wherein recurrent networks maintain stability under rapidly changing plasma dynamics.

Beyond these high‑profile achievements LSTMs have shed light on *interpretability*: neurons selectively encoding number semantics (\citep{Lakretz:19}), syntax (\citep{Bau:19}) or sentiment (\citep{Radford:17arxiv}) emerge spontaneously when training on large corpora. This suggests that LSTMs are capable of forming abstract internal representations that go beyond rote memorisation—a property still coveted by modern large language models.

# The Transformer breakthrough and its consequences for large‑scale language modelling

The landscape shifted dramatically with the advent of self‑attention based Transformers \citep{Vaswani:17}. By replacing recurrence with pairwise attention between all tokens in a sequence, Transformers achieved two decisive advantages:

1. **Full parallelism**—the entire sequence can be processed simultaneously during training because each layer’s computation depends only on matrix multiplications rather than sequential hidden‑state updates.
2. **Quadratic expressive capacity**—attention weights capture pairwise interactions directly, enabling richer context modelling especially when scaled up with many layers and heads.

These properties allowed Transformers to scale efficiently across massive datasets and model sizes, culminating in powerful Large Language Models such as GPT‑3 (\citep{Brown:20short}) and subsequent variants from diverse research groups worldwide. As a result, for many benchmark tasks transformers supplanted LSTMs entirely; document-level language modelling shifted from RNN‑centric pipelines toward wholly attention‐driven architectures after 2017.\footnote{The transition was accelerated also by hardware developments favouring dense matrix operations over recursions.}

Nevertheless, Transformers inherit their own limitations—quadratic memory cost with respect to sequence length—and they obscure an explicit notion of persistent memory that was central to classic RNNs. This prompted researchers to ask whether recurrent cells could be revisited at massive scales while retaining their intrinsic ability to store information over long horizons without incurring prohibitive computational overheads.\

# The central research question addressed by the paper

Motivated by this tension between *scalability* (a Transformer strength) and *persistent explicit memory* (an LSTM strength), the authors pose a succinct yet profound query:

> **How far can language modelling performance advance if we scale Long Short‑Term Memory networks to billions of parameters while mitigating their known shortcomings?**

In other words, instead of discarding recurrence entirely, can one retain or even enhance its core mechanisms—constant error carousel plus gated updates—and enrich them sufficiently so that an LSTM‑based model competes head‑to‑head with contemporary Transformer or State Space Model approaches? Addressing this requires overcoming three documented drawbacks of vanilla LSTMs:

1. **Inability to revise storage decisions**, exemplified by nearest neighbour search tasks where previously stored values cannot be replaced when more relevant evidence arrives later.
2. **Limited storage capacity**, caused by compressing all information into a single scalar per cell; this manifests as poor rare token prediction because nuanced contexts cannot be faithfully encoded.
3. **Sequential bottleneck due to hidden–hidden connections**, which prevents parallel computation over timesteps and thus hampers scalability on modern hardware.\

The paper therefore frames these three obstacles as *research challenges* whose resolution could unlock high‑performance recurrent language models at scales comparable to today's Transformers.\

# Overview of the proposed solution – extended LSTMs (xLSTMs)

To answer this question, the authors introduce **Extended Long Short‑Term Memory (xLSTM)** architectures that augment both gating dynamics and memory representation:

* **Exponential gating** replaces—or optionally augments—the traditional sigmoid activations on input and forget gates with an exponential function \(\exp(\cdot)\). By doing so gates can express multiplicative scaling far beyond [0, 1] while still being controllable through an auxiliary normaliser state that tracks cumulative gate magnitudes.
* Two novel memory structures are proposed:
    - **Scalar LSTM (sLSTM)** retains a single scalar per cell but adds *memory mixing* across cells using recurrent weight matrices together with exponential gating; this enables revision of stored contents while preserving compatibility with residual block circuitry.
    - **Matrix LSTM (mLSTM)** expands each cell’s state from a scalar \(c_t\in\mathbb R\) to a full matrix \(\mathbf C_t\in\mathbb R^{d\times d}\). Storage follows a *covariance update rule* akin to bidirectional associative memories:
      \[
      \mathbf C_t = f_t\,\mathbf C_{t-1} + i_t\,\mathbf v_{t}\mathbf k_{t}^{\!\top},
      \]
      where key–value vectors \((\mathbf k_t,\mathbf v_t)\) arise from linear projections of the current input, and retrieval uses a query vector \(\mathbf q_t\). This matrix formulation dramatically enlarges storage capacity while remaining fully parallelisable because no hidden–hidden recurrence is required.
  
Both sLSTM and mLSTM are wrapped inside **xLSTM blocks**, which are residual modules equipped either with *post up-projection* (for sLSTM) or *pre up-projection* (for mLSTM). Stacking these blocks using standard pre–LayerNorm residual backbones yields deep **xLSTM architectures** capable of handling hundreds of millions—or even billions—of parameters.\ 

In sum, xLSTMs aim to preserve what made classic LSTMs attractive—a principled mechanism for long‐term memory—while eliminating their historical impediments through exponential gating, richer matrix memories, and modern residual design patterns borrowed from transformer engineering.\  

The rest of this textbook will explore each component—starting from historical context—to build intuition about why these modifications matter for large‐scale language modelling.\
