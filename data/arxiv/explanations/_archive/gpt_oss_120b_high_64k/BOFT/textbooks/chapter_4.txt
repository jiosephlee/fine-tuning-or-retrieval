\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: Information‑Transmission View of Orthogonal Matrix Factorizations  

# Grid Representation with $d$ Source Nodes → $d$ Target Nodes over $m\!+\!1$ Layers  

When we seek to replace a dense orthogonal transformation by a product of several sparse factors, it is useful to imagine the computation as a flow of information across a layered graph.  Consider a linear layer of dimension $d$ that we would like to transform by an orthogonal matrix  
\[
\bm{R}\;=\;\bm{B}_{m}\,\bm{B}_{m-1}\cdots \bm{B}_{2}\,\bm{B}_{1},
\]  
where each factor $\bm{B}_{i}\in\mathbb{R}^{d\times d}$ is sparse and will be learned during finetuning.  The product can be visualised as a grid consisting of $m+1$ vertical levels (or “columns’’) and $d$ horizontal positions (“nodes’’) at each level.  The leftmost column contains the **source nodes**—the original coordinates of the input features—while the rightmost column contains the **target nodes**, i.e., the coordinates after applying the full transformation $\bm{R}$.  

At level $0$ we place a copy of each source node indexed by $j\in\{1,\dots,d\}$.  At level $i\;(1\le i\le m)$ we place another copy of the $d$ nodes; these represent intermediate representations after multiplication by $\bm{B}_{i}$.  Finally, at level $m$ we have the $d$ target nodes after all factors have been applied.  Traversing from left to right corresponds exactly to sequential left‑multiplication by $\bm{B}_{1},\,\bm{B}_{2},\dots,\bm{B}_{m}$.  

Because every factor is linear, information can travel only along directed edges that link a node at level $i-1$ to a node at level $i$.  The overall layout therefore forms a **grid‑structured directed acyclic graph** whose connectivity is dictated by the sparsity patterns of the matrices $\{\bm{B}_{i}\}$ (see Figure \ref{fig:info_trans} for an illustrative example with $d=4$, $m=5$).  This graphical picture provides an intuitive scaffold for reasoning about how many parameters are truly needed to realise any dense orthogonal matrix.



# Edges ↔ Non‑Zero Entries in Factor Matrices $\boldsymbol B_{1},\dots,\boldsymbol B_{m}$  

In linear algebra, an entry $[\bm B_i]_{pq}=0$ means that component $p$ receives no contribution from component $q$ during multiplication by $\bm B_i$.  In the graph view this translates directly into *absence* of an edge from node $q$ at level $i-1$ to node $p$ at level $i$. Conversely, any non‑zero entry corresponds to a *directed edge* carrying information from one level’s node to another’s.  Hence **the set of all directed edges across all levels is identical to the union of all non‑zero positions** in the factor matrices:
\[
E \;=\;\bigcup_{i=1}^{m}\bigl\{\,(p,q)\mid [\bm B_i]_{pq}\neq0\,\bigr\}.
\]  

Because each factor is square ($d\times d$), there are at most $d^{2}$ possible directed connections per layer.  When every entry were non‑zero we would obtain a fully connected bipartite graph between successive layers—a case that corresponds precisely to using a single dense matrix $\bm R$, i.e., $m=1$, $\bm B_{1}=\bm R$.  In practice we deliberately enforce sparsity so that only a small subset of those potential connections remains trainable; those surviving connections become our **free edges**, i.e., parameters we must learn during finetuning.



# Dense Connectivity Requirement and Minimal Free Edges Principle  

Two desiderata emerge naturally from the information‑transmission perspective:

1. **Dense connectivity** – For the final product $\bm R=\prod_{i=1}^{m}\bm B_i$ to be dense (no zero entry), every source node must possess *at least one directed path* that reaches **every** target node.  In graph terms this means that for any pair $(s,t)$ with source index $s\in[1,d]$ and target index $t\in[1,d]$, there exists a sequence $(s=v_0,v_1,\dots,v_m=t)$ such that each successive pair $(v_{k-1},v_k)$ belongs to an edge set contributed by $\bm B_k$.  If some pair lacks such a path then the corresponding entry $(t,s)$ in $\bm R$ will inevitably be zero, violating density.

2. **Minimal free edges** – Among all edge configurations satisfying dense connectivity we wish to minimise the total number of *trainable* connections (i.e., those not forced by structural constraints).  A smaller number of free edges translates directly into fewer learnable parameters and thus higher parameter efficiency—a primary goal when adapting gigantic foundation models.

Together these conditions define an optimisation problem over graph topologies: find a set of sparsity patterns for $\{\bm B_i\}$ such that every source can broadcast its signal throughout all levels using as few transmissible links as possible.



# Implications of Orthogonality on Edge Constraints  

Orthogonality imposes additional algebraic constraints on each factor matrix beyond mere sparsity.  By definition an orthogonal matrix satisfies  
\[
\bm B_i^\top \,\bm B_i = \bm I_d,
\]  
which immediately forces two crucial properties:

* **Full rank** – Each $\bm B_i$ must be nonsingular, meaning it establishes a bijection between its input and output nodes.  

* **Exactly $d** distinct “mandatory’’ connections per layer – To achieve full rank while preserving orthogonality, every row must contain exactly one non‑zero entry whose magnitude equals one (up to sign), and similarly each column must contain exactly one such entry.  In graphical terms this enforces a *perfect matching* between nodes at consecutive levels: there are precisely $d$ directed edges whose weights are fixed (\(\pm1\)) solely by necessity, not by learning choice.

Because these mandatory \(d\) edges are completely determined by orthogonality—they cannot be altered without breaking invertibility—they are conventionally **excluded from our count** of free parameters.  The remaining entries may still be zero or learnable non‑zero values; their pattern constitutes the *degrees of freedom* we can exploit for information transmission.

Orthogonality also introduces **dependency among optional edges**.  For instance consider a \(2\times2\) orthogonal block:
\[
\begin{bmatrix}
a & b\\
c & d
\end{bmatrix},
\quad
a^{2}+c^{2}=b^{2}+d^{2}=1,
\quad 
ab+cd=0.
\]
If we set \(a=0,\) then orthonormality forces \(c=\pm1,\) which in turn mandates \(b=0,\) leading \(d=\pm1.\) Thus forcing a zero at any position automatically determines zeros elsewhere—a phenomenon clearly visible when visualising edge patterns in Figure \ref{fig:blk_diag}. Consequently any feasible set of free edges must respect these algebraic couplings: removing one transmissible connection may automatically remove another due purely to orthogonal constraints.



# Comparison of Naïve Dense Factorization versus Structured Factorizations  

A naïve approach would dispense with intermediate layers altogether and learn a single dense orthogonal matrix \(\bm R.\) In graph language this corresponds directly to connecting every source node to every target node using \(d^{2}-d = d(d-1)\) *free* directed edges (the diagonal entries belong to mandatory matches).   For moderate dimensions this leads quickly toward quadratic parameter budgets—e.g., when \(d=4,\) there are \(12\) free parameters required just for density.

Structured factorizations achieve dramatic savings by spreading connectivity across multiple sparse layers while preserving overall density through paths rather than direct links:

* **Block–diagonal OFT** – The original OFT imposes that each factor \(\bm R = \operatorname{diag}(\!\bm R_{1},\,\dots,\!\bm R_{r})\) consist exclusively of independent blocks \(\bm R_{i}\in \mathbb R^{b\times b}\) where \(br=d.\) Graphically this restricts communication within disjoint “clusters’’ so no cross‑cluster paths exist; consequently many source–target pairs become unreachable unless \(b=d.\) While dramatically reducing parameters (\(\mathcal O(bd)\)), this design sacrifices expressive power because dense connectivity cannot be realised unless each block spans all dimensions—precisely what defeats parameter efficiency.

* **Butterfly factorization** – Inspired by Cooley–Tukey’s fast Fourier transform topology, butterfly graphs connect nodes across levels using patterned sparse matrices known as butterfly factors.   A butterfly construction generates exactly \(\mathcal O(d\,\log d)\) free edges while guaranteeing that every source can reach every target through logarithmic‑length paths.   For example Figure \ref{fig:info_trans} shows an explicit construction with five factors ($m=5$) achieving dense output using only ten free edges—already fewer than what would be needed by any single dense factor (twelve for $d=4$).   Importantly these ten free connections obey orthogonality because each butterfly component can itself be rendered orthogonal via Cayley transforms applied on its small blocks (\(2\times2,\) or more generally \(b\times b.\))

Thus moving from naïve density (\(\mathcal O(d^{2})\)) toward structured sparse decompositions yields two key benefits:
  
* A substantial reduction in trainable parameters – from quadratic down to near‐linear (\(\mathcal O(d\,log d)\)).  
* Retention—or even enhancement—of expressive capability because information may still flow freely via multi‑step pathways mandated by graphs such as butterflies or other well‑designed topologies.


Together these observations justify recasting Orthogonal Finetuning as an **information transmission problem** on layered graphs: By engineering sparsity patterns that obey both dense connectivity and minimal free-edge principles under algebraic ortho­gonal constraints, one can obtain compact yet powerful parameterizations suitable for adapting massive foundation models without sacrificing performance.



---  

In summary, representing an orthogonal matrix factorisation as information flow across a grid clarifies why certain sparsity patterns succeed while others fail.  The mapping “edge ⇔ non‑zero entry’’ makes it easy to reason about required connections; dense connectivity guarantees that no destination remains blind; minimal free‑edge designs minimise learnable parameters; and orthogonality imposes exact matchings plus subtle dependencies among admissible edge sets.  This framework not only explains why block‑diagonal OFT struggles with expressivity but also illuminates why butterfly factorizations—by virtue of their carefully crafted sparse graphs—achieve remarkable parameter efficiency without losing density, paving the way for practical large‑model adaptation techniques such as BOFT introduced later in the paper.
