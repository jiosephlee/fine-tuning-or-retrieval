\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why can a butterfly graph connect every source node to every sink node using only $O(d \log d)$ edges? A simple example would help.
Question:
"The paper says that a butterfly topology achieves dense connectivity with just $8$ edges for $d=4$ (or similar)." Could anyone provide an explicit construction for, say, $d=8$, showing the sequence of sparse matrices and how information from node 1 eventually reaches node 7 after three stages?
Answer:
Below is a compact way of seeing why the **butterfly graph** gives an all‑to‑all connection while using only  
$d=8$.  
The notation follows the definitions in the paper (“butterfly factor’’ $\mathbf B^{F}(k)$,
“butterfly component’’ $\tilde{\mathbf B}(d,k)$, etc.).

---------------------------------------------------------------------

### Why $O(d\log d)$?

Write $d=2^{N}$.  
A butterfly factor $\mathbf B^{F}(k)\in \mathbb R^{k\times k}$ consists of four diagonal
blocks ($\operatorname{diag}(\mathbf d_i)$) whose total number of non‑zero entries is
exactly $k$.  
When we tile these factors along the diagonal as  

$$
\tilde{\mathbf B}(d,k)=\operatorname{diag}\bigl(\,\mathbf B^{F}_1(k),
   \dots,\mathbf B^{F}_{\,d/k}(k)\bigr),
$$  

each component contains **exactly $d$** train‑able numbers – one per column –
and hence represents a *perfect matching* between two consecutive levels
of the $d\times(m+1)$ grid introduced in Section 3 (“information transmission”).
Because an orthogonal matrix must be full rank,
every component needs at least this matching; no extra trainable entry can be saved
inside a single layer.

Now consider $m=N=\log_{2}d$ such components,
with decreasing block sizes
$k=N,N/2,\dots,k=2.$  
The product  

$$
\mathbf R   =
   \tilde{\mathbf B}(d,k_N)\,
   \tilde{\mathbf B}(d,k_{\,N-1})\,\cdots\, 
   \tilde{\mathbf B}(d,k_1)
   ,           \qquad k_{\ell}= 2^{\,N-\ell},
$$  

contains exactly $N\times d = d\log_{2} d$ trainable parameters.
Each layer contributes **$d$** directed edges
and there are **$(N=\log_{2} d)$** layers,
hence the whole graph has only
$O(d\log d)$ edges.

The crucial combinatorial fact about the butterfly topology
(isomorphic to an *$N$‑dimensional hypercube*) is:

> **Every vertex on level 0 can reach every vertex on level $N$**
> via a walk whose length never exceeds $N.$

Indeed, write the index of a vertex in binary,
$i=i_{\,N-1}\dots i_{0}$.
In layer $\ell∈[N]$ the matching flips precisely the bit $\ell{-}1.$
Consequently a walk that flips bits according to the binary difference
between source and destination visits exactly those layers whose bit must change.
Hence there always exists a walk – actually many walks – joining any pair
of vertices. Because each layer performs an *orthogonal* linear mixing inside every pair,
the contribution of every walk adds linearly;
for generic choices of the internal angles none of these sums cancels out,
so **every entry** of the final product matrix $\mathbf R=\prod_{\ell}\tilde{\mathbf B}_\ell$
is non‑zero with probability one.
That is exactly what the paper calls “dense connectivity”.

---------------------------------------------------------------------

### A concrete construction for $d=8$

Take $N=\log_{2}8 =3.$  
We build three sparse orthogonal components  
$\tilde{\mathbf B}^{(\ell)}:=\tilde{\mathbf B}(8,k_\ell)$  
with block sizes $k_1=8,\;k_2=4,\;k_3=2.$

For simplicity let every $k_\ell\times k_\ell$ block be a **rotation**
by angle $\theta_\ell=\pi/4,$
so that inside a pair  

$$
R_{\!(\theta)}=
   \begin{pmatrix}
      c& -s\\[4pt] s& c
   \end{pmatrix},
   \qquad c=s=\tfrac{\sqrt{2}}{2}.
$$

---

#### First stage ($\;\!\;\;\;\!\!\!\;\;\!\!\;\;\;\;\;\;\;$ $\displaystyle \tilde{\mathbf B}^{(3)}:$ blocksize $8$")
Because it is already size eight it consists simply of four independent rotations
acting on neighbour pairs:
```
pairs : (0–<->  ARA)+‑clockwise---     …
```
Written as an eight‑by‑eight matrix,
the pattern contains non‑zeros only on positions  
$(i,i)$,$(i,i± 1)$ inside each pair,
e.g.~$(B^{(3)}_{01})=(c,-s;\ s,c).$

#### Second stage ($\displaystyle \tilde{\mathbf B}^{((₂)}:\!k_=4$")
Here we regroup the eight coordinates into four groups of size two:
$(00|01),(10|11),(100|101),(110|111)$.
The four $4×4$ butterfly factors therefore couple indices whose **second**
least significant bit differs:
pairs : $(0,$ ⇄  02)$,$(01⇄03)$,$(04⇄06)$,$(05⇄07)$.  
Again every factor is a copy of $R_{\!(π/4)}.$

#### Third stage ($\displaystyle \tilde{\mathbf B}^{(¹)}:\!k_=₂$")
Now we couple the two halves:
pairs : $(00⇄04)$,$(01⇄05)$,$(02⇄06)$,$(03⇄07)$,
again with rotation angle $\pi/4.$

Putting them together gives  

```text
Level    connections (undirected view)
---------------------------------------------------------
stage 3 : {(0↔১),(২↔3),(৪↔5),(৬↔7)}
stage ২ : {(۰↔۲),(۱↔۳),(৪↔６),(۵↔۷)}
stage ১ : {(۰↔۴),(۱↔۵),(২↔৬),(৩↔৭)}
```

If vertices are labelled $\sigma(i)=i+1$ (the usual one‑based counting),
the three layers read  

```
S₃ : { (¹–²), (³–⁴), (⁵–⁶), (⁷–⁸)}
S₂ : { (¹–³),   (²–⁴),   (⁵–⁷),   (⁶–⁸)}
S₁ : { (¹–⁵),   (۲–۶),   (۳–۷),   (۴–۸)}
```

---

### How does information travel from “node ¹” to “node ۷”?

Write indices in binary (`000` … `111`).  
Node ¹ corresponds to `001`; node ۷ corresponds to `110`.

*Stage III* flips **bit$_0$** (`…·$_0`) – move from `001` → `000` or stay `001`.  
Choose the edge that toggles this bit: `001 → 000`.

*Stage II* flips **bit$_1$** – turn `000 →010`.

*Stage I* flips **bit$_2$** – turn `010 →110`, which is precisely node ७.

Thus there exists a walk  

$$001\xrightarrow[\text{stage III}]{}000\xrightarrow[\text{stage II}]{}010\xrightarrow[\text{stage I}]{}110.$$

Because every rotation mixes the two endpoints equally,
the contribution travelling along this walk appears in the entry
$\displaystyle R_{7,\,1}$: after multiplying out,

```math
R =
   \underbrace{\tilde{\!B}^{(¹)}}_{\text{$k=２$: flip high bit}}
   \underbrace{\tilde{\!B}^{(۲)}}_{\text{$k=４$: flip middle bit}}
   \underbrace{\tilde{\!B}^{(۳)}}_{\text{$k=８$: flip low bit}}
```

the coefficient multiplying input~$x_1$ inside output~$y_7=(R x)_7$
gives  

$$R_{7,\,1}=c^{3}s^{\,2}c+s^{3}c^{\,}
           +\dots\simeq\tfrac14>0.$$  
(The exact expression contains six terms corresponding precisely to
the six possible walks between these two vertices.)  
Since none cancel when we pick generic rotation angles,
the entry cannot be zero – so information injected at neuron ① indeed reaches neuron ７ after three stages.


---------------------------------------------------------------------

### Summary

A butterfly graph consists of  

* **$m=\log_{₂} d$** layers;
* **$d»** directed edges per layer**, forming perfect matchings between consecutive levels;
* an orthogonal linear operation inside every matched pair.

Consequently it supplies exactly **$d\,m = O(d\log d)** trainable parameters while guaranteeing a path between any source and any sink.
For $d=8$ this means three sparse factors described above;
by following the flips of binary digits one sees explicitly how signal flow from node ١ reaches node ٧.
Because each factor mixes its two incident vertices linearly,
the contributions of all possible walks add up and render every entry 
of the final product dense.
This explains the statement made in Section 5 of the paper that “a butterfly topology achieves dense connectivity with just eight edges for $d＝４”’’ — more generally it needs only $O(d\times\nicefrac12\,m)=O(d\log d)$ trainable elements.
