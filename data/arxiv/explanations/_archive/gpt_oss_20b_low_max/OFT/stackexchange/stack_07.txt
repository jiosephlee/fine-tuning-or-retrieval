\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### Could multiple orthogonal matrices from different tasks be composed safely?
Question:
The paper mentions that orthogonal matrices from separate finetuning tasks can be multiplied together while remaining orthogonal. If we have trained OFT models A → B and C → D separately, would composing their R matrices yield a model that retains knowledge from both tasks? Are there theoretical guarantees about preserving all downstream capabilities when chaining these transformations?
Answer:
**Short answer**

Yes, the product of two orthogonal matrices is again orthogonal, so you can safely compose the *R* matrices that are learned on separate downstream tasks without losing orthogonality.  
However, there is no theoretical guarantee that the resulting model will retain the full set of abilities (i.e., the “knowledge”) that each individual fine‑tuned model had.  The paper only proves that hyperspherical energy is preserved when an *individual* OFT update is applied; it does not argue that concatenating several such updates keeps the pre‑trained semantics intact.  In practice the composed model will usually preserve most of the pre‑trained behavior and add **some** of the new functions, but it may lose or distort aspects that were specific to each task.

---

### Why orthogonality is preserved

Orthogonal matrices satisfy \(Q^\top Q = I\).  
If \(R_1\) and \(R_2\) are orthogonal, then

\[
(R_2 R_1)^\top (R_2 R_1)
= R_1^\top R_2^\top R_2 R_1
= R_1^\top I R_1
= I,
\]

so \(R_{\text{composed}} = R_2 R_1\) is again orthogonal.  
This fact holds regardless of whether the matrices come from different fine‑tune runs or were learned jointly.

### What happens to the network weights

For a given layer with pretrained weights \(W^0\), OFT replaces them by  
\(W = R W^0\).  Suppose we fine‑tune two tasks sequentially:

1. **Task A → B**: learn \(R_{AB}\), obtain \(W^{AB} = R_{AB} W^0\).
2. **Task C → D**: learn \(R_{CD}\), apply to *the same* pretrained
   weights and produce \(W^{CD} = R_{CD} W^0\).

Now compose both transformations:

\[
W^{AB \circ CD} = (R_{CD} R_{AB}) W^0 .
\]

The forward pass uses a single weight matrix obtained by a single
orthogonal rotation of the original weights.  The neural network’s
hyper‑spherical energy remains unchanged because any orthogonal rotation
preserves pairwise angles among neurons.

### Why there is no safety guarantee for preserving *all* downstream
capabilities

In OFT, the intuition is that changing only directions preserves the
semantic structure learned during pretraining, while small magnitude changes
are still tolerated.  Yet fine‑tuning along one direction (say,
\(R_{AB}\)) can rotate a subspace of neurons in a way that encodes the
specialization to task B.  Another rotation \(R_{CD}\) may interfere with
that subspace: it can rotate it into a different location or even partially undo it.
The paper’s proof only shows that *each individual rotation* keeps
hyperspherical energy constant; it does **not** prove that rotations
commute with respect to their semantic effects.

Empirically, many papers (including this one’s ablations) observe that

* The composed model often reproduces most of the pre‑trained generative
  quality, because hyperspherical energy is preserved.
* It also shows some signal from both tasks, but there can be **conflicts**—
  e.g., mixing a subject–driven task with a style–controlling task can lead to artifacts or loss of identity.

Thus, while you can multiply orthogonal matrices safely in an algebraic sense,
the *information-theoretic* guarantees (“retain every downstream capability”)
are absent unless additional constraints are imposed (e.g., ensuring that the rotations act on disjoint subspaces or adding regularizers on their interaction).

### Practical implications

- **If you only need to keep general generation quality**, composing –
  e.g., `R_total = R_{CD} @ R_{AB}` – will usually keep the model working.
- **If you need both fine‑tuned behaviours simultaneously**, you should verify:
  - Does the composed model still generate images resembling both subjects?
  - Does it obey both control signals?
  - If not, consider training a joint (“composite”) OFT with a combined loss or using techniques such as block‑diagonal splits so each task changes separate neuron groups.

### Bottom line

Orthogonal finetuning matrices from different tasks can be composed without breaking orthogonality, and in practice this often preserves much of the pre-trained generative ability.  However, OFT doesn’t provide a formal theorem guaranteeing that every downstream capability survived; trying several compositions empirically and measuring downstream metrics is still necessary.
