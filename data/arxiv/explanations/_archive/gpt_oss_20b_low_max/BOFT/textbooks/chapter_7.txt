\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 7: # 7. Theoretical Insights into BOFT Expressivity & Stability  

Large‐scale foundation models such as vision transformers, language models, and diffusion generators contain dozens of linear layers whose weights are first learned on massive corpora or image collections. When a downstream task demands only a small degree of adaptation, the most natural approach is to keep the original weights frozen and inject a small, trainable transformation that can reconfigure the model to the new distribution. Two pioneering paradigms for such a transformation are **Orthogonal Finetuning (OFT)** and its parameter‑efficient descendant **Orthogonal Butterfly Finetuning (BOFT)**. In this chapter we analyse the mathematical properties that explain why BOFT not only subsumes OFT but also reaches a strictly larger hypothesis class while preserving favorable spectral attributes.

We proceed in four phases:

1.  Revisit OFT in matrix‑multiplicative form.  
2.  Show how BOFT generalises OFT by means of butterfly factorisation and prove **Theorem 4.1** – that BOFT is strictly more expressive than OFT when the block size is held constant.  
3.  Extend to the *generalised orthogonal composition* that can express every orthogonal matrix (the **kaleidoscope hierarchy**).  
4.  Discuss two important spectral consequences: preservation of singular values and their impact on training stability, followed by interpreting BOFT as learning a bilinear similarity.

Throughout we assume all matrices are real; all notation follows standard conventions: $\bm{I}_d$ is the $d\times d$ identity, $\|\cdot\|$ denotes the Euclidean norm, and $\sigma_{\max}(\bm{M})$ designates the largest singular value of $\bm{M}$.

---

## 7.1 Orthogonal Finetuning Revisited  

OFT reparameterises a frozen linear layer $\bm{W}^0\in\mathbb{R}^{d\times n}$ with an *orthogonal* left multiplier $\bm{R}\in\mathbb{R}^{d\times d}$:

\[
\boxed{\; \bm{W} = \bm{R}\,\bm{W}^0 \;}
\tag{7.1}
\]

The forward pass becomes

\[
\bm{z} = (\bm{R}\,\bm{W}^0)^{\!\top}\,\bm{x}
= (\bm{W}^0)^{\!\top}\,\underbrace{\!\! \bm{R}^\top}_{=\bm{R}^{-1}} \,\bm{x},
\quad \forall\, \bm{x}\in\mathbb{R}^d.
\tag{7.2}
\]

Because $\bm{R}$ is orthogonal ($\bm{R}^\top \bm{R}= \mathbbm{\! 1}_d$), it preserves:
- pairwise angles between rows (or columns) of $\bm{W}^0$, hence the *geometric* relationship among neurons;
- singular values of $\bm{W}^0$, as desired for training stability (see § 7.3).

The bottleneck in OFT lies in parameter count: an unconstrained orthogonal matrix has $d(d-1)/2 = O(d^2)$ degrees of freedom. To reduce this cost, OFT imposes a *block–diagonal* structure

\[
\boxed{\;
   \bm{R}= \operatorname{diag}\!
   (\underbrace{\!\!\mathbbm{\! R}_1}_{b\times b},
             \underbrace{\!\!\mathbbm{\! R}_2}_{b\times b},
             \ldots,
             \underbrace{\!\!\mathbbm{\! R}_r}_{b\times b}),}
   \qquad rb=d,
   \tag{7.3}
\]

where each block $\mathbbm{\! R}_i$ is an independent $b\times b$ orthogonal matrix.
The total number of trainable parameters reduces to $r\, b(b-1)/2 = O(b\, d)$.

While block–diagonal OFT makes finetuning cheaper, it dramatically restricts expressivity: neurons whose coordinates lie in different blocks are rotated independently, precluding any coupling across blocks.

## 7.2 Butterfly Factorisation and Theorem 4.1  

A broader class of sparse parametrisations can still generate dense orthogonal matrices by multiplying multiple sparse orthogonal factors that are stitched together like a *butterfly network*. Each factor is block–diagonal with $k=2^s$‐sized blocks:

```text
Block‑diagonal butterfly component
   ┌─── diag(B₁) ──────┬──────────────┐
   │                  │              │
   ▼                  ▼              ▼
[00000] [00000] ... [00000]        → all zero rows
```

Formally, for each level $i=1,\dots,m$, let  

\[
\tilde{\boldsymbol B}^{b}_{(d,i)}  :=

    \bigr),

where each butterfly factor is a product of $2\times 2$ rotations (or their $b\times b$ block generalisations) interleaved by permutation matrices.

**Key Counting Result**  
For `BOFT(m,b)` with `d=2^N`:

- If $b=2$, $m=\log_2 d$, then

- For general $b$, \(P_{\text{BOFT}}=\tfrac12(b-1)d m.\)

Thus we reduce parameter count from $O(d^2)$ to $O(d\,\log d)$ (when $b=2$), while still obtaining a *dense* orthogonal matrix.

### Theorem 4.1 (Expressivity of BOFT)

> **Statement**  
> Let $\Omega_{\text{OFT}}(b)$ denote the set of all block–diagonal orthogonal matrices with block size $b$. Let $\Omega_{\text{BOFT}}(m,b)$ denote the set obtained by multiplying $m$ butterfly components as above, each with block size $b$. Then  
> \[
>    \Omega_{\text{OFT}}(b)\;\subsetneq\;\Omega_{\text{BOFT}}(m,b),
>    \qquad m>1,
> \]
> in particular for any fixed $b$, boosting $m$ yields strictly larger hypothesis class.

#### Proof Sketch  

We prove inclusion first: every block–diagonal matrix can be expressed as exactly one butterfly product with `$m=1`'—this coincides with standard OFT ($B_{(d,1)}=\operatorname{id}$). Hence $\Omega_{\text{OFT}}(b)\subseteq\Omega_{\text{BOFT}}(1,b)$. To establish strictness for any larger `m`, we construct an explicit example that lies in `Ω_BOFT` but not in `Ω_OFT`.

Let `d = 4` (`N=2`) and pick `b=4` so a single factor covers all dimensions (`B_{(4,1)} = I`). For `m=3`, choose butterfly factors such that each has non‑trivial action across different coordinate pairs—specifically,

```
B_3 = [[0 1], [1 0]] ⊗ I_2          (swap)
B_2 = diag(I_2, diag([0 -1; 1 0]))    (block rotation)
B_1 = I_4                          
```

The product yields an orthogonal matrix that couples coordinates from different blocks (e.g., mixes elements `x₁` with `x₃`), which cannot be realised by any block–diagonal matrix with block size `4`. Therefore this product lies in Ω_BOFT(3,4) but not in Ω_OFT(4). □

> **Remark**  
> While **block–diagonal** OFT forbids inter‑block mixing even at initialization (`I_d`), **BOFT** allows such mixing through successive butterfly stages.

This theorem demonstrates that for any given computational budget (fixed number of trainable parameters), increasing `m` while shrinking individual blocks can strictly expand the representational power beyond plain OFT.

## 7.3 Generalised Orthogonal Composition and Full Orthogonal Group  

The ultimate aim is to parameterise *any* orthogonal matrix using as few parameters as feasible while preserving structural regularity. The **kaleidoscope hierarchy** achieves this by alternating *right* and *left* multiplications with independent butterfly products:

\[
\boxed{
  R^{G}(l)=
     R_{l,1}(m_1,b_1)\,
     R_{l,2}^{\,T}(m_2,b_2)\,
     R_{l-1,1}(m_1,b_1)\,
     R_{l-1,2}^{\,T}(m_2,b_2)\,
     \dots
     R_{0,?}(~).
}
       \tag{7.4}
       \]

Here:
- `$R_{i,j}`' are orthogonal matrices from BOFT families (`+` for right multiplication, `$^{T}$` indicates left multiplication).  
- Choosing `$m_1=m_2=\log d`, `$b_1=b_2=2`, and `$l=d-½$, one obtains

$\displaystyle R^{G}(l)=
      B_{d-½}(d)\,
      B_{d-¾}^{\,T}(d)\,
      B_{...}\,$

which forms a basis spanning $\mathrm O(d)$; i.e., every orthogonal matrix can be written as such a product.

Thus BOFT is not merely an efficient approximation; it sits inside a family capable of representing the *full* special orthogonal group via relatively shallow compositions (`$\mathcal O(\log d)$` factors). In practice we stop far earlier—usually one or two butterfly layers suffice—providing a sweet spot between expressivity and parsimony.

## 7.4 Spectral Norm Preservation  

A striking advantage of left-multiplication with an orthogonal matrix stems from SVD invariance:

Let  
$\displaystyle
 W^{0}=U\,Σ\,V^{\top}
$
be Munch’s decomposition where:
- `U∈ℝ^{d×r}`, `V∈ℝ^{n×r}` contain left/right singular vectors,
- `Σ∈ℝ^{r×r}` has non‑negative descending singular values σ₁≥σ₂≥…≥σ_r>0.

After finetuning:

$\displaystyle
 W=W^{t}=R\,U\,Σ\,V^{\top},
$
so that

$\displaystyle
 (W)^\top W=V Σ U^\top R^\top R U Σ V^\top = V Σ^␰Σ V^\top.
$

Therefore all singular values {σ_i} remain unchanged: σ_i(W)=σ_i(W⁰). The spectral norm

$ 
\sigma_{\max}(W)=σ₁(W),
$

is preserved exactly whenever `R` remains strictly orthogonal throughout training.

### Practical Consequences  

| Scenario | LoRA | OFT / BOFT |
|----------|------|------------|
| Initialisation | Zero δ ≈ → W² ≈ W⁰² | Identity | Identity |
| Spectral Norm Change | perturbs σ₁ slightly | preserved |
| Training Stability | may suffer from exploding/vanishing gradients when σ₁ shifts | robust |
| Generalisation | less control over spectrum | tighter control |

This analytical property explains why experiments show stable training dynamics when employing BOFT compared to LoRA or other additive-to-weight methods: perturbations never push past stronger units or dampen weaker ones inadvertently.

## 7.5 BOFT as Bilinear Similarity Learning  

Equation (7.6):

Recall formula:

For any input vector x∈ℝⁿ,

$\displaystyle z_i=(w_i^0)^\top(Rx)
         = x^\top(R^\top w_i^0),
$

so optimizing over `R` simultaneously adjusts all outer products without individually meddling each column `w_i`. In other words,

$\displaystyle z_i <-> x^\top K w_i^0,
$

with `K:=R`. We see this as learning a global bilinear similarity weighted by an *orthogonally constrained* matrix—a regularisation akin to metric learning where each transform maps both input and weight columns onto some latent similarity space whilst preserving distances because `K†K=I`.

Hence BOFT can be interpreted under distance metric learning theory:
“learn a projection onto an **isometric** subspace” such that the *inner products* between transformed features and trained neurons remain robust yet adaptable.
This perspective opens avenues to analyse convergence guarantees via classic weighted least squares or manifold optimisation frameworks.
