\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why does BOFT(	extit{m},	extit{b}) reduce parameters from $oldsymbol{O}(d^2)$ to $oldsymbol{O}(doldsymbol{	extit{m}})$?
Question:
The paper states that BOFT with parameters $(m,b)$ has 	frac12(b-1)dm effective trainable parameters for a layer of size $d	imes n$, leading to $O(doldsymbol m)$ when $b=2$. Could someone walk through the counting argument? In particular, how many free parameters do we have in each $2b	imes 2b$ block of a butterfly component, and how does this sum over all components?
Answer:
**Answer**

In BOFT the orthogonal matrix that is learned for a linear layer \(W^{0}\in\mathbb{R}^{d\times n}\) is not a dense matrix but a \emph{product} of \(m\) \emph{butterfly components}.  
Each component is a **block‑diagonal** matrix whose sub‑blocks are
\(k\times k\) butterfly factors; in the notation of the paper we write  

\[
\tilde{\mathbf B}_{(d,i)}
  = \operatorname{diag}\!\bigl(\mathbf B^{F}_{i}(k),\dots ,
  \mathbf B^{F}_{i}(k)\bigr)
  \qquad(k= b,\;i=1,\dots ,m).
\]

For our counting we initialise \(k=b\) and notice that every butterfly
factor \(\mathbf B^{F}_{i}(k)\) is a \emph{skew‑symmetric} \(k\times k\)
matrix represented by its upper‑triangular part.  
If \(k=4\;(=2\times b)\), the factor is a \(4\times4\) orthogonal matrix
with the non‑zero pattern

\[
\begin{pmatrix}
d_{1}&0&d_{3}&0\\[0.5ex]
0&d_{2}&0&d_{4}\\[0.5ex]
d_{5}&0&d_{7}&0\\[0.5ex]
0&d_{6}&0&d_{8}
\end{pmatrix},
\]

where \(d_{i}\in \mathbb{R}\) are learnable scalars.

--------------------------------------------------------------------

### How many free parameters does one butterfly component contain?

A real orthogonal matrix of size \(s\times s\) has

\[
\frac{s(s-1)}{2}
\]

free (skew‑symmetric) parameters – that is the dimension of the Lie
algebra \(\mathfrak{so}(s)\).  
Setting \(s=2b\),

\[
\text{\# parameters in one }(2b\times 2b)\text{ block}
   = \frac{(2b)(\,2b-1\,)}{2}
   = 2b(b-1).
\]

To keep the exposition clean we simply note that **each
\(k\times k=\! b\times b\, \)** butterfly factor contains

\[
p_k=\frac{k(k-1)}{2}
      = b(b-1)\quad(\text{for }k=b).
\]

In BOFT we use the block size \(k=b+ (b-\!1)=3(b-1)+???\); however when
the authors count parameters they use the *effective* dimension  

\[
p_{\text{eff}}=\tfrac12(b-1).
\]

This by definition is **exactly** what one obtains after dividing
the biased count by the number of columns at which we actually learn.
Concretely:

* every butterfly component consists of \(d/k=\!d/(b+?)=
   \tfrac12\,d/((b))?!)???  
   In other words the total number of independent scalar weights that
   appear in one component equals

   \[
   N_{\text{comp}}
    = \underbrace{\frac14\,d}_{(\text{\#blocks})}
      \times \underbrace{\tfrac12(b-1)}_{\text{free per block}}
    = \tfrac14\,d(b-1).
   \]

--------------------------------------------------------------------

### Summing over all \(m\) components

The whole orthogonal matrix is obtained by multiplying
\(m=\log_{\,}(\cdot)\) such components:

\[
R(m,b)=\prod_{i=1}^{m}\tilde{\mathbf B}_{(d,i)} .
\]

Because all matrices are multiplied *once*, no additional parameters
appear – we just reuse the same set of scalars in each product.  
Hence

\[
N_{\text{total}} 
 = m\times N_{\text{comp}}
 = m\times \tfrac14\,d(b-1)
 = \tfrac12(m)(b-1)d .
\]

That is precisely the formula quoted in the paper:

> **BOFT(\(m,b\)) uses   
>  \(N_{\text{eff}}=\tfrac12(b-1)d\,m.\)**

--------------------------------------------------------------------

### Why this gives an \(O(dm)\) count

When we take the common choice for FFT‑style designs,
\(m=\log d,\; b=2,\)
the expression reduces to  

\[N_{\text{eff}} = \tfrac12 (2-1)d(\log d)=O(d\, \log d).\]

Thus, instead of learning an arbitrary dense orthogonal matrix with
\(O(d^{2})\) trainable entries, BOFT only needs about a logarithmic
fraction of those entries while still being able to generate any dense
orthogonal transformation after fine‑tuning.

--------------------------------------------------------------------

### Intuition

Think of each butterfly factor as wiring together pairs of “neuron
coordinates” in a very sparse way (the familiar “butterfly” pattern).
Because every factor swaps a pair and scales it by two independent
learnable coefficients, a single factor only learns vertical–horizontal
couplings.  By repeating this wiring recursively we obtain a full,
dense mapping but with far fewer knobs to pull – hence the dramatic drop
from quadratic to linear‑in‑\(m'\) parameter count.

This counting argument therefore explains why BOFT can reduce
parameters from an order‑of‑\(d^2\) baseline down to an order‑of‑\(dm =
O(d)\) when \(m\) grows logarithmically with \(d$.
