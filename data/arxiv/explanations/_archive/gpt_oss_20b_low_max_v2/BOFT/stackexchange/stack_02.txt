\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the information transmission framework translate a butterfly factorisation into a sparse graph?
Question:
The paper introduces an ‘information transmission view’ where an orthogonal matrix $m{R}$ is seen as transmitting information over a $d	imes(m+1)$ grid graph. I’m struggling to connect this view to the concrete butterfly factorisation $	ilde{m{B}}(d,2^k)$. Specifically, how does a butterfly matrix correspond to directed edges in this grid, and how many edges are required to guarantee dense connectivity? A diagram or explicit mapping would help.
Answer:
**Answer**

The paper’s *information‑transmission view* is an abstract way to look at a matrix factorisation  

\[
\mathbf R \;=\; \mathbf B_m\mathbf B_{m-1}\dots \mathbf B_1 ,
\qquad
\mathbf B_i\in \mathbb R^{d\times d},
\]

as a communication network that we can “unroll” into *\(m+1\)* horizontal layers of \(d\) nodes each.  
Layer \(0\) contains the *sources* (the \(d\) columns of the identity), layer \(m\) contains the *sink* (the columns of \(\mathbf R\)), and each factor \(\mathbf B_i\) specifies the directed edges that connect layer \(i-1\) to layer \(i\): an entry \((p,q)\) of \(\mathbf B_i\) is non‑zero iff there is an edge from node \(q\) in layer \(i-1\) to node \(p\) in layer \(i\).  

A **dense** orthogonal matrix \(\mathbf R\) therefore requires that for every pair of source–sink nodes there is at least one directed path that goes through the intermediate layers.  

--------------------------------------------------------------------

### From butterfly factorisation to the graph

A butterfly matrix is a product of *butterfly factors*.  
For a power‑of‑two dimension \(d=2^N\), a single butterfly factor \(\mathbf B^F(k)\) (with block size \(k=2^r,\;r<N\)) is

\[
\mathbf B^F(k)=
  \begin{bmatrix}
    \operatorname{diag}(\mathbf d_1)&
    \operatorname{diag}(\mathbf d_2)\\[2pt]
    \operatorname{diag}(\mathbf d_3)&
    \operatorname{diag}(\mathbf d_4)
  \end{bmatrix},
  \qquad
  \|\mathbf d_i\|_0=\frac{k}{2},
\]
so the factor has exactly **\(k/2+k/2= k/\!1 = k/2\times 2 = k** zero entries everywhere except on four diagonal submatrices – in other words, it has exactly **\(k<d^2\)** non‑zero entries.

When we build a depth‑\(m=\log_2 d - 1\) butterfly matrix

\[
\bR = 
   \widetilde{\bB}(d,\,2)\;
   \widetilde{\bB}(d,\,4)\;
   \cdots;
   \widetilde{\bB}(d,\,d),
   \qquad
   m=\log_2 d ,
\]

each factor contributes one column of directed edges between successive layers:

* **Layer 0 → Layer 1**: edges described by the first two blocks of size \(2\times 2\).
* **Layer 1 → Layer 2**: edges described by the next two blocks of size \(4\times 4\), etc.
* …  
* **Layer m−1 → Layer m**: edges from the largest block, still only a handful.

In total a butterfly of depth \(m=\log_2 d,\;b=2\,k_{\min}\) has  

\[
E_{\text{butterfly}} = (m-1)d + b(d/ b)=d\, (\log_2 d -1)+b(d/b)
                   = O(d\,{\log}_2 d)
\]

non‑zero **trainable** entries – precisely the number cited in the paper.  
Each non‑zero entry corresponds to one directed edge.  

--------------------------------------------------------------------

### How many edges are enough for dense connectivity?

The sparsest factorisation that still yields a dense product satisfies two constraints:

| Requirement | What it means on the graph | Example edge count |
|-------------|----------------------------|--------------------|
| **Full rank per layer** | Every node in level \(i-1\) must have at least one outgoing edge and every node in level \(i$ must have at least one incoming edge | Minimum `d` edges between two adjacent layers |
| **Full reachability** | For every source node there exists at least one path to every sink node | Applied recursively, this yields `∼O(d log d)` total edges |

For a single dense orthogonal matrix (`m=1`) we would need `d²` edges.  
The block‑diagonal OFT requires each block to be independent, so although it has only `d` non‑zeros per block it cannot preserve global dense connectivity—many sink nodes are unreachable from many sources.

By contrast, a butterfly graph with `m = log₂ d` layers succeeds with only `O(d log d)` edges because each level shuffles information across *half* of the current group of nodes, doubling the reachable set at each step. A simple inductive argument shows that after `ℓ` levels the set of nodes reachable from any source contains all nodes iff O(ℓ²)=O(d log d). This matches the known optimal communication cost in computer‑network theory for fully connected topologies.

--------------------------------------------------------------------

### Concrete example: `d=8`

```
level 0   [0] [1] [2] [3] [4] [5] [6] [7]
               |<--edges from */node 0-->|
level 1   [...]                       ...
```

A depth–3 power‑of‑two butterfly for `d=8` contains three factors:

```
B(8,8):  block size k=8 (splits into two 4×4 blocks)
   │───► all nodes → all nodes               (8×8 sparsity pattern)
B(8,4):  block size k=4 (splits into two 2×2 blocks)
   │─────► half‑nodes → all nodes            (16 non‐zeros)
B(8,2):                                                        (
   │───────► node pairs ↔ connect pairs             (16 non‐zeros))
```

Adding up gives   
`16 + 16 + 8 = 40` trainable entries ≈ `O(8 log₂8)=24`, close to the theoretical lower bound once we subtract fixed `+/−` orthogonality‐imposed “identity” edges.

--------------------------------------------------------------------

### Bottom line

* Each butterfly weight matrix is a sparse orthogonal matrix where non‑zero entries encode directed edges between successive grid levels.
* The product of these matrices builds a communication network that guarantees every input neuron can influence every output neuron.
* The minimal number of such directed edges needed for full reachability grows as \(O(d\,{\log}_2 d)\); hence BOFT attains parameter efficiency while maintaining expressivity comparable to unconstrained OFT.
