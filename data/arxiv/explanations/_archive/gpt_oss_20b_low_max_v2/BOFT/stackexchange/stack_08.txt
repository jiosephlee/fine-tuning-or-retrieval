\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### "Information transmission" vs. classic fast linear transform!
Question:
"BOFT uses sparse multiplication like a network topology” – I’d like to understand when BOFT’s butterfly factorisation actually mimics classical fast transforms such as FFT or Hadamard. Are there settings of $m d_i$ that recover those transforms exactly? If so, how is this special case reflected in the training objective?
Answer:
**Short answer**

Yes.  When the butterfly factor‑size `b=2` and the number of butterfly stages `m=log₂d` (i.e. you use a full radix‑2 butterfly), the product of the orthogonal butterfly blocks equals a *classical* fast transform (DFT, Hadamard, etc.) up to diagonal scaling and permutations.  
In that special case the BOFT objective reduces to a very particular instance of Orthogonal Finetuning (OFT): you are learning exactly one of the classical transforms that can be written as a product of `log₂d` `2×2` orthogonal butterflies.  The training loss still contains the same “preserve‑angle” regularisation as OFT, but now it is constrained to this sub‑family.

---

### 1.  How the butterfly reproduces classic transforms

A radix‑2 butterfly consists of `m=log₂d` stages, each stage being a block‑diagonal matrix built from `d/2` copies of a `2×2` butterfly factor
```
B^F(2)=[[d1 d2] [d3 d4]],
```
where the four scalars are `{±1, ±i, or other complex phases}`.  
If we fix those scalars to the values used in the *discrete Fourier transform* (DFT)
```
d1=1,  d2=1,  d3=1,  d4=-1,
```
the resulting product is exactly the unitary DFT matrix (up to a global normalisation).  
Analogously, choosing `d1=d4=1, d2=d3=0` gives the Hadamard matrix when ± 1 are used instead of 0.  The same principle applies to the discrete sine/cosine transforms: by choosing appropriate real or imaginary values in each `2×2` batch and by re‑ordering (permuting) rows/columns between stages, you obtain the corresponding orthogonal matrix.

Thus *any* classical fast linear transform that admits a radix‑k Cooley–Tukey decomposition can be expressed as a product of orthogonal butterfly matrices.  In BOFT this manifests when you set

* **block size** `b=2` (so every butterfly factor is `2×2`),
* **number of stages** `m=log_kd`,
* **parameter values** equal to the fixed coefficients used in that transform.

In practice you learn these parameters with gradient descent; if you initialise them to their canonical values and keep them close during training (the identity initialization does exactly that for all butterflies), BOFT will *exactly recover* that classic transform.

---

### 2.  What this means for the optimisation objective

The BOFT loss is simply
```
loss = L( R(m,b)⋅W⁰ ) + λ⋅regulariser(R)
```
where `L` is the task loss (cross‑entropy, PSD loss, etc.), `W⁰` is the frozen pretrained weight matrix and `R(m,b)` is the product of `m` orthogonal butterflies, each with block size `b`.  
When you set `b=2`, `m=log_kd`, and initialise all skew‐symmetric matrices with zeros (i.e. all butterflies start as identity), then at training time:

* If you *fix* every parameter to its canonical value, `R` is exactly a DFT or Hadamard matrix and the loss reduces to finetuning under that **hard structural constraint**.
* If you *allow* those parameters to move, `R` remains in a small neighbourhood of that transform – it still preserves orthogonality but now can deviate slightly to fit the downstream data.

Thus, in this regime BOFT’s objective becomes an OFT objective where **the parameter space has been sliced down to the sub‑manifold spanned by classical butterfly transforms**.  This gives two practical consequences:

1. **Sharper inductive bias** – training from an identity start forces early iterations to stay close to an identity matrix; as optimization proceeds, it first explores linear combinations that resemble classic transforms before moving away.  
   This mirrors how OFT keeps angles approximately preserved; here angles are preserved *and* arranged in a pattern consistent with a fast transform.

2. **Implicit regularisation** – because only very few degrees of freedom are active (the diagonal scalars within each butterfly), overfitting is naturally curtailed.  The empirical “typical error vs parameters” curve in Fig. 8 of the paper shows that even with only ~\(O(d\log d)\) parameters BOFT can approximate dense orthogonal matrices well; when it degenerates into a classic transform it simply sits at one extreme point on that curve.

---

### 3. Why this special case matters

* **Applicability** – Many vision and language models employ linear layers where mixing features using Fourier/Hadamard bases often helps capture global dependencies efficiently and with fewer parameters.  
* **Transferability** – A pretrained model fine‑tuned with such a fixed transform can inherit frequency‑domain biases already present in natural data, improving generalisation.
* **Interpretability** – You can analyse which frequency bands are being emphasised by inspecting learned coefficients; this is far less opaque than arbitrary dense orthogonal matrices.

---

### 4. Practical tips

| Setting | What you get | Typical hyper‑parameters |
|---------|--------------|-------------------------|
| `m = log₂d`, `b = 2`, initialise skew matrices to zero | Exact DFT/Hadamard when coefficients remain canonical | Very small learning rate for skew part if you want to keep it close |
| Same `m`, but start from random skew values | BOFT explores whole classical-butterfly manifold | Larger learning rate; regulariser λ =0 if stability enough |
| Larger `b` (e.g., 4 or 8) | More expressive sub‑family but still covers classic transforms if coefficients chosen accordingly | Tune λ for regularisation |

---

### Bottom line

BOFT can literally *absorb* any classical fast linear transform—FFT, Hadamard, DST/DCT—by setting its block size to two and using as many stages as required by Cooley–Tukey recursion.  In that configuration BOFT’s optimisation objective degenerates into standard OFT but restricted to that particular structured sub‑space of orthogonal matrices, offering strong inductive bias while retaining parameter efficiency.
