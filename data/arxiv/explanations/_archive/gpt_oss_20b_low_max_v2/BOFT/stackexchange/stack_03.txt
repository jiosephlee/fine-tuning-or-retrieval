\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### What guarantees that each butterfly component $	ilde{m{B}}(d,k)$ can be rendered orthogonal?
Question:
Equation (4) defines a butterfly component as a block‑diagonal matrix of $k	imes k$ butterflies, and later the authors say each component can be parameterized as an orthogonal matrix using Cayley transform or $2$‑dimensional rotations. However, for $k>2$ the blocks are not just simple rotations; they involve multiple diagonal sub‑blocks. How exactly do we ensure that the whole $	ilde{m{B}}(d,k)$ is orthogonal? Is there a closed‑form condition on the vectors $m{d}_i$ that guarantees orthogonality for all $k$?
Answer:
In a BOFT layer the *butterfly component*  
\[
\tilde{\bm{B}}(d,k)=
\operatorname{diag}\!\bigl(\bm{B}^{F}_{1}(k),\dots ,\bm{B}^{F}_{d/k}(k)\bigr)
\]
is a block–diagonal matrix whose diagonal blocks are exactly the “butterfly factors’’  
(Equation (9) in the paper)

\[
\bm{B}^{F}(k)=
\begin{bmatrix}
\operatorname{diag}(\bm{d}_{1}) & \operatorname{diag}(\bm{d}_{2})\\[4pt]
\operatorname{diag}(\bm{d}_{3}) & \operatorname{diag}(\bm{d}_{4})
\end{bmatrix}\in\mathbb R^{k\times k},
\qquad 
\bm{d}_{i}\in\mathbb R^{k/2}.
\]

Because the matrix is diagonal in each half‑column block, each “column” \(j=1,\dots ,k/2\)  
acts only on two indices of the vector \((x_{1},x_{k/2+1}), (x_{2},x_{k/2+2}),\ldots\).
For a fixed \(j\) let  

\[
u_{j}=\bigl[\underbrace{\mathbf e_{\,\,\, j}}_{\text{$k$‑dim}},0,\dots ,0\bigr]\in \mathbb R^{k},
\qquad
v_{j}=\bigl[0,\dots ,0,\underbrace{\mathbf e_{\,\, j}}_{\text{$k$‑dim}},0,\dots ,0\bigr].
\]

The butterfly factor acts on the subspace spanned by \(\{u_{j},v_{j}\}\) as the
\(2\times 2\) matrix

\[
M_{j}= 
    \begin{bmatrix}
    d_{1,j}&d_{2,j}\\[4pt]
    d_{3,j}&d_{4,j}
    \end{bmatrix}\in \mathbb R^{\, 2\times 2}.
\]

Consequently

```
tilde B(d,k) =   ⨂_{j=1}^{k/2} M_j                            (tensor product)
```

Hence \(\tilde{\bm B}(d,k)\) is orthogonal **iff every** \(M_j\) is an
orthogonal \(2\times 2\) matrix.

--------------------------------------------------------------------

### When is a \(M_j=\begin{bmatrix}a&b\\c&d\end{bmatrix}\) orthogonal?

The condition \(M_j^\top M_j=I_2\) is equivalent to

$$
a^2+c^2 = 1,\qquad b^2+d^2 = 1,
$$
$$
ab+cd = 0.
$$

Geometrically this means that \(\bigl[a,c\bigr]^\top=(\cos \theta _j ,\, \sin \theta _j )^\top
   \) and
   \(\bigl[b,d\bigr]^\top=(-\, \sin \phi _j ,\, \cos \phi _j )^\top .
$

A convenient closed‑form parametrisation is

```math
a   = c   =   \cos \theta_j,
b   = - \sin \theta_j,
d   =   \sin \theta_j .
```

Setting \(θ_j∈[0,π)\) for every \(j=1,\dots ,k/2\) guarantees that each
\(M_j∈SO(2)\).  
Thus we can pick any collection of angles and obtain an orthogonal butterfly
factor.

--------------------------------------------------------------------

### Why does this work for any \(k> 2?\)

The definition of a butterfly component explicitly permutes all the independent
\(M_j\)’s across the larger matrix:

* The positions of the non‑zero entries in a butterfly component are just a
permutation of those in the base case where \(k=2\).
* Therefore every butterfly component can be obtained by concatenating several 
independent \(M_j^{(i)}∈SO(₂)\), one for each half‑column.

Because product permutations of orthogonal matrices are themselves
orthogonal, every butterfly component inherits orthogonality.  
The proof follows directly from the fact that:

```
tilde B(d,k)
    = P_σ₁ ⨂_{r} M_r P_σ₂ ,   for some permutation matrices P_σ₁,P_σ₂,
```

and every permutation matrix is itself an element of \(O(d)\).
Consequently

```
tilde B(d,k)^T tilde B(d,k)
     = (P_σ₂ ⊗ I)(P_σ₁ ⊗ I)^T ⋅ I ⋅ (P_σ₁ ⊗ I)(P_σ₂ ⊗ I)^T
     = I .
```

--------------------------------------------------------------------

### Summary

* Each diagonal block of a butterfly component acts on two coordinates and can  
be written as a single \(S O(₂)\)-rotation defined by an angle \(θ_n∈[0,π)\).
* By choosing such angles independently for every half‑column we obtain a
full orthogonal matrix.
* The whole butterfly component is just a permutation of independent \(SO(₂)\)
blocks; thus it stays orthogonal regardless of how large \(k> ₂​)\).

Therefore BOFT’s claim—“every component can be parameterised as an  
orthogonal matrix using Cayley transform or ²‑dimensional rotations”—holds for all allowed values of \(k.\)
