\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### "Exponential gating" versus “mixing via ReLU or tanh” – could we replace exp with other nonlinearities?
Question:
"Exponential gating" seems unique to xLSTM but other recent models use gated ReLU/LU activation functions (e.g., GLU). How would replacing $	extexp(	ilde{i})$ by say $	extit{relu}(	ilde{i})$ or even a learned temperature scale affect performance? Are there theoretical reasons why only exponentials are suitable when combining with covariance update rules?
Answer:
**Short answer**

Replacing the exponential gates used in xLSTM with a ReLU or a tanh (or any other bounded, monotone function) would break two key properties that the designers engineered:

1. **Unboundedness and multiplicative scaling** – Exponential gates allow the gate value \(g_t=\exp(\tilde g_t)\) to grow arbitrarily large, which means that an input can be *amplified* linearly with time.  This is what gives the sLSTM its ability to “revise” earlier storage decisions: when a more relevant context appears, the current input gate can carry a very large weight and overwrite (or heavily “forget”) earlier entries by multiplying the memory state with a large reset factor.

2. **Analytic relation to covariance decay/learning‑rate** – In mLSTM the forget gate plays exactly the role of a decay rate in a covariance‑update rule \(\mathbf C_t = f_t\,\mathbf C_{t-1} + i_t\,\mathbf v_t\mathbf k_t^{\!\top}\).  If \(f_t\) were bounded by \((0,1]\) as for a sigmoid or tanh, the decay would be capped and could never exceed its previous value; consequently the memory would be unable to *forget* older key–value pairs quickly enough across long horizons.  The same behaviour is needed for sLSTM where the normalizer \(n_t\) relies on an unbounded \(f_t\) to sum future forget contributions.

Because of these two points, an exponential gate is not just a convenient choice—it is mathematically required for the memory‑updating schemes that xLSTM uses. Replacing it with ReLU or tanh would make the model struggle on tasks that require rapid revision of past content (e.g., Nearest‑Neighbor Search) and would worsen performance on associative‑recall tasks, as shown by the ablation studies in Table 5 of the paper.

---

### Why exponentials work

* **Unboundedness**  
  The gate values can become arbitrarily large.   In sLSTM’s normalizer
  \[
    n_t = f_t n_{t-1} + i_t ,
  \]
  an aggressively large \(f_t\) pushes forward all *future* forget contributions, effectively acting as a learnable scaling factor for how long past information should survive.

* **Multiplicative updating**  
  In mLSTM we store keys and values by outer‑product updates
  \[
    \mathbf C_t = f_t\,\mathbf C_{t-1} + i_t\,\mathbf v_t\,\mathbf k_t^{\!\top}.
  \]
  Here \(f_t\) literally multiplies all old contents by itself at every step.   If \(f_t>1\), forgetting is accelerated; if \(f_t<1\), it is annealed slowly.  A bounded gate would prevent this dynamic range.

* **Stability tricks**  
  The authors note that exponentials can overflow, so they introduce a stabilizer state \(m_t\) (Equation 14).  With a bounded activation this trick is unnecessary; however, bounding also forces the network to operate in a smaller range of values which limits expressiveness and makes it harder to learn selective forgetting.

---

### What would happen with ReLU or tanh

| Gate | Value range | Effect on forgetting | Suitability (xLSTM) |
|------|-------------|---------------------|---------------------|
| σ(·) (sigmoid) | (0, 1] | Can never amplify; only dampen | Poor for *revise*-type updates |
| tanh(·) | [‑1, 1]   | Sign change possible but bounded | Unstable & cannot support rapid decay |
| ReLU(·) | [0, ∞)   | Non‑negative but not multiplicative unless followed by exp | Reduced capacity to learn fast decay |
| exp(·) | (0, ∞)     | Fully multiplicative & unbounded | Ideal for covariance update & memory mixing |

The experiments in Table 5 (“Gating ablations”) precisely back this up: when only sigmoid gates are used (i.e., gated by σ instead of exp), validation perplexity degrades from 40.4 to 43.6 on a 15B‑token benchmark—a noticeable drop. Adding learned temperature scaling to exponentials surpasses this even further.

---

### Theoretical justification

From an information‑theoretic perspective, exponential gating directly implements an *adaptive forgetting factor* similar to what is used in Kalman filtering or online learning algorithms:
\[
    f_{t} = \exp(\tilde f_{t}) = e^{W_f x_t + b_f}.
\]
The log‑forget term \(\tilde f_{t}\) can be seen as a learnable energy that controls how much past evidence should be retained versus discounted.  
By exponentiating we obtain
\[
    \log f_{t+1} = \tilde f_{t+1},
\]
so that after summing over time one gets
\[
    \log C_{\tau} = \sum_{t<\tau}\tilde f_{t},
\]
which matches exactly the form derived in earlier Fast Weight Programmers papers (e.g., Schmidhuber 1992).  
If we replaced `exp` with any other nonlinear function, this additive property in log‑space disappears and the update no longer has an exact closed‑form interpretation as exponential discounting.

---

### Bottom line

While one could certainly implement sLSTM/mLSTM with ReLU or tanh gates for experimental curiosity, doing so would erase two essential design motives of xLSTM:

* **Fast learning / aggressive revision** via unbounded multiplier gates,
* **Exact covariance/forgetting dynamics** via multiplicative updates.

Consequently, replacing `exp` with another nonlinearity consistently hurts performance on both synthetic tasks (state tracking, associative recall) and real language‑model benchmarks, as evidenced by both ablation studies and quantitative comparison tables in the paper. If you still want to try alternative activations you’ll need to re‑derive your memory update equations or add extra learnable parameters that mimic exponential scaling—otherwise you will lose the benefits that make xLSTM competitive against Transformers and SSMs.
