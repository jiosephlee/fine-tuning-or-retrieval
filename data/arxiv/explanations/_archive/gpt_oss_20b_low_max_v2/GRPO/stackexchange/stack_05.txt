\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### What is meant by “baseline from group scores” in GRPO and how is it computed?
Question:
"Baseline” usually refers to a value function in actor‑critic algorithms. In GRPO they say it is estimated from group scores. Does this mean simply taking 
\(\hat A_{i,t} = \frac{r_i- \bar r}{\sigma}\) for each token in a sampled group 
\(\{o_1,…,o_G\}\)? How does this compare to using a learned value network like PPO?
Answer:
**What the “baseline from group scores” means in GRPO**

In Proximal Policy Optimization (PPO) the advantage
\(A_t\) used in the surrogate objective is usually computed with a value‑function
\(V_{\psi}\) that estimates the expected return from each token.  
Training a separate critic of comparable size to the policy network is a
significant add‑on in memory and compute cost, and it is especially
problematic for language‑model training because the reward signal is only
available at the last token of a generated answer.

GRPO eliminates that critic altogether.  
Instead of learning a value function, it constructs a *group‑based* baseline
directly from the rewards of several outputs sampled for the *same question*.
For every question \(q\) the algorithm draws a group
\(\{o_{1},\dots ,o_{G}\}\) from the current (old) policy \(\pi_{\theta_{\mathrm{old}}}\).
Each member \(o_i\) is scored by a reward model \(r_{\varphi}\), yielding
\(G\) scalar rewards \((r_1,\dots ,r_G)\).

The baseline used in GRPO is simply the **average** of these rewards:

\[
b_q \;=\; \frac{1}{G}\sum_{i=1}^{G} r_i .
\]

The advantage for every token in every output is then defined as the
centered and normalized reward:

\[
\hat A_{i,t}
   = \frac{r_i - b_q}{\sigma_q},
   \qquad 
   \sigma_q=\operatorname{std}\!\big(\{r_1,\dots,r_G\}\big).
\]

Because all tokens belonging to the same output share that same advantage,
the policy update behaves exactly like PPO’s advantage signal, but it does
not require any extra neural network or forward pass.

---

**Why this works and how it compares to a learnt value network**

1. **Relative rewards fit naturally to how LLM reward models are trained.**  
   Reward models for LLMs are most often trained on *pairwise* comparisons
   of two answers to the same question (a “better‑than” judgment).  
   The group‑based baseline therefore mirrors exactly the comparison
   setting that produced the reward model: it is comparing each answer’s
   score against its peers on that same prompt.

2. **High variance reduction while remaining cheap.**  
   The mean over a small group (typically \(G=8\)–\(64\)) captures most of the
   long‑term return signal needed for policy gradient.  
   In practice, experiments in the paper show that GRPO attains similar or even better gains than PPO while using far less GPU memory—no extra critic network, no GAE computation.

3. **Simplified dynamics at long horizons.**  
   For language generation only the last token receives an external reward.
   A learned value function would have to infer how earlier tokens contribute,
   which leads to noisy estimates and unstable training. The group baseline,
   conversely, gives every token in an answer an equal credit or blame,
   which is adequate for shaping step‑by‑step generation.

4. **Slightly slower convergence but more stability.**  
   Because GRPO discards any temporal structure beyond equal product,
   it can be slower per epoch than PPO with a good critic, but it never suffers
   from catastrophic over‑fitting of the value network or from having to tune an extra set of hyper‑parameters (learning rate, GAE lambdas, etc.).  In DeepSeekMath’s experiments,
   GRPO achieved an 88 % GSM8K score and 51.7 % MATH score using only SFT data,
   while PPO would have demanded a large critic model and far more GPU hours.

---

**Summary**

*Baseline from group scores* in GRPO is not an abstract concept; it is literally
the arithmetic mean of rewards obtained for several independently sampled outputs on *the same question*.  
This simple statistic replaces the learned value function used in PPO,
allowing reinforcement learning of large language models to be performed with almost half the hardware resources while still providing effective advantage estimates for policy updates.
