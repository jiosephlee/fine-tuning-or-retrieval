\title{A Textbook about the Paper: xLSTM}

Chapter 11: Empirical Results: Capabilities, Comparisons, and Scaling

# Formal language results: parity and other state-tracking tasks

A central claim of the xLSTM work is that exponential gating combined with memory mixing restores the kind of state-tracking power that classical recurrent models (like LSTMs) can provide, and that models without memory mixing (standard Transformers and many State Space Models) fundamentally lack. The formal-language experiments in the paper were designed to test exactly this: tasks that require maintaining and updating discrete state across long sequences (for example parity and other regular-grammar style tasks). These are canonical examples where exact state tracking rather than soft pattern-matching is needed.

Empirically, xLSTM variants that include sLSTM (which permits memory mixing and uses exponential gates) achieve high accuracy on these formal languages and can extrapolate to sequence lengths beyond those seen during training. By contrast, Transformers and SSMs that do not perform memory mixing fail on these tasks. Intuitively, the ability to mix memory across cells and to apply exponential gating gives sLSTM the capacity to implement stable, revisable counters or discrete state machines: exponential gates permit rapid, multiplicative revision of stored contributions and the new normalizer/stabilizer states avoid numerical blowup while preserving differentiability. The experiments show that this combination recovers the kind of stateful behavior required for parity and similar tasks, matching theoretical expectations that memory mixing increases expressivity for state-tracking problems.

# Associative recall: memory capacity across many key–value pairs

To evaluate memory capacity in a more content-addressable sense, the authors extended the Multi-Query Associative Recall task to be substantially harder: they increased the number of random key–value pairs up to $256$ and extended contexts up to length $2048$. This task tests storing many distinct pairs and later retrieving values conditioned on queries, which is the regime where matrix-style memories or attention-like mechanisms typically excel.

Here the matrix-memory mLSTM shines. The mLSTM implements a covariance-style outer-product update, storing $\mathbf{v}_t \mathbf{k}_t^\top$ into a matrix memory and retrieving with matrix–vector multiplication. Among non-Transformer methods, xLSTM configurations that include mLSTM (for instance xLSTM[1:1]) perform best on recall accuracy across a broad range of difficulties. Notably, adding sLSTM blocks does not reduce capacity — rather, the presence of sLSTM often leverages the matrix memory to improve recall at the hardest settings (e.g., $256$ pairs). This indicates a complementary interaction: mLSTM brings raw associative capacity, while sLSTM brings flexible state-mixing that helps organize or route stored information.

The intuitive reason is that the covariance update gives an efficient dense encoding of pairwise associations, while the normalization mechanisms and exponential gates prevent dominance by early or late items and keep the retrieval signal-to-noise favorable. Although pure Transformers can achieve large effective memory (because attention can be exponentially expressive in code dimension), xLSTM recovers much of that associative power within a recurrent, linear-in-length framework.

# Long Range Arena: handling long sequences

The Long Range Arena (LRA) benchmark probes a model’s ability to manage long contexts with varied signal types (text-like, algorithmic, image-derived, etc.). xLSTM demonstrates consistently strong performance across the LRA tasks. This shows that the combination of exponential gating, stabilized normalizers, and the two complementary memory designs (scalar sLSTM with mixing and matrix mLSTM without mixing) yields robust long-context behavior.

Why does xLSTM handle long sequences well? There are several contributing factors. First, the constant-error-carousel style updates (inherited and extended from LSTM) avoid vanishing gradients over long horizons. Second, exponential gating plus stabilizers allows the model to maintain and revise stored contributions multiplicatively, which is important for emphasizing or attenuating long-past information without catastrophic numerical issues. Third, the matrix memory provides content-addressable recall for many items, so the model does not need to compress every detail into a small scalar state. Together these mechanisms provide both durable state maintenance and scalable associative recall, which the LRA tasks exercise.

# 15B-token comparisons: xLSTM vs Transformers, SSMs, and RNNs

To assess practical language-model performance, the authors trained multiple methods on the same $15\,$B-token SlimPajama corpus in an autoregressive setting and compared validation perplexities for models sized to match a GPT-3–style baseline (approximately $350$M parameters, embedding dimension $1024$, $24$ residual blocks). The methods compared included Transformers (GPT-3, Llama), State Space Models (H3, Mamba), recurrent or linearized models (RWKV variants, HGRN, HGRN2, GLA, RetNet, Hyena), and two xLSTM configurations (xLSTM[1:0] and xLSTM[7:1]).

xLSTM outperforms all existing methods in validation perplexity in this controlled $15\,$B-token regime. This is a strong empirical statement: when bringing LSTM-derived ideas up to contemporary residual-backbone architectures and augmenting them with exponential gating and matrix memories, the resulting models can beat matched-size Transformers and SSMs on next-token prediction after the same data budget. The scaling curve for these experiments also suggests xLSTM retains a favorable margin as models grow within this regime.

# Ablation studies: residual backbones, exponential gating, matrix memory, gate inputs

The paper includes systematic ablation studies that morph a vanilla LSTM architecture into xLSTM, isolating the contribution of each design change. The morphing proceeds by (1) integrating LSTM layers into pre-LayerNorm residual backbones, (2) implementing a post up-projection residual block, and (3) adding exponential gating plus matrix memory. The ablations show that both exponential gating and the matrix memory provide substantial, separable improvements in perplexity. In other words, neither modification alone explains the full gain; together they are synergistic.

Additional gate-related ablations show that letting each gate be input-dependent and learnable yields incremental positive effects. That is, making gates more expressive (input- and bias-driven rather than fixed scalars) steadily improves performance. These findings emphasize that gating itself remains a crucial inductive bias; refining the gating functions (exponential activations plus stabilizers in sLSTM/mLSTM) is central to the improved empirical behavior.

Intuitively, the residual backbone and up-projection blocks provide the larger representational canvas (higher-dimensional embeddings and nonlinear transforms) on which the memory mechanisms operate; exponential gates determine how aggressively new information overrides or adds to stored memory; and the matrix memory increases the capacity for storing diverse content-addressable items. Ablations confirm that removing any of these elements degrades language-model performance.

# 300B-token results: length extrapolation to 16k and validation perplexities

To test large-data behavior, the authors trained models on a much larger $300\,$B-token SlimPajama budget and evaluated several model sizes ($125$M, $350$M, $760$M, $1.3$B). A critical test was context-length extrapolation: models trained with context length $2048$ were evaluated up to $16384$ (i.e., $16\,$k) tokens. xLSTM models maintain low perplexities at these extrapolated context lengths in contrast to the competing architectures tested. This demonstrates that the recurrent xLSTM memory mechanisms generalize to longer contexts without retraining or architectural changes.

On validation perplexity for next-token prediction across the range of model sizes, xLSTM configurations (both xLSTM[1:0] — only mLSTM blocks — and xLSTM[7:1] — majority mLSTM plus some sLSTM) are the best-performing models. That consistent superiority across sizes indicates that the improvements are not a narrow artifact of a particular capacity regime, but translate across practical LLM sizes.

# Downstream tasks: broad wins with some ARC exceptions

Beyond perplexity, the authors evaluated downstream tasks that capture common-sense reasoning and benchmark-style problem solving. Across the majority of these tasks and across model sizes, xLSTM achieves the best performance among the compared methods. The one notable exception is ARC (a particular reasoning benchmark), where in some cases Mamba (an SSM variant) outperforms xLSTM. This nuanced result underscores that while xLSTM provides generally superior language-modeling representations, some task-specific inductive biases in other architectures can still be advantageous in narrow settings.

Overall, the downstream-task results reinforce the link between improved next-token modeling (lower perplexity) and better performance on many practical language tasks, while reminding us that no single architecture dominates every benchmark.

# PALOMA: domain-wise perplexity gains across 571 text domains

The PALOMA benchmark evaluates next-token prediction across a broad suite of $571$ real-world text domains (news, forums, technical, social, etc.). The paper reports domain-level perplexities grouped by language-modeling and fine-grained domain benchmarks. On this challenging and diverse suite, xLSTM[1:0] (pure mLSTM blocks) demonstrates marked improvements: it achieves lower perplexity than Mamba on $568$ out of $571$ domains ($99.5\%$), lower than Llama on $486$ out of $571$ domains ($85.1\%$), and lower than RWKV-4 on $570$ out of $571$ domains ($99.8\%$). These counts show that xLSTM’s gains are not limited to a few domains but are pervasive across very different text distributions. The matrix memory plus normalization and gating appear particularly effective at modeling rare or domain-specific patterns that would otherwise be hard to compress into scalar memories or short attention windows.

# Scaling laws: favorable offsets indicating continued gains at larger scales

The authors analyzed scaling behavior by plotting power-law fits (in the spirit of the Kaplan–Haffner style analyses) over different model sizes and training budgets. All models exhibit similar power-law exponents, meaning their error decreases with model size according to comparable slopes. However, xLSTM enjoys a favorable offset: for the same parameter counts and data budgets, xLSTM sits at a lower perplexity than SSMs and Transformers. Practically, this offset implies that as models scale further, xLSTM is likely to remain competitive and possibly extend its advantage, because the scaling exponent is shared but the constant is better. In short, xLSTM buys you a consistent headroom at every scale rather than a fleeting advantage at a single size.

# Inference speed and throughput vs Llama, Mamba, and RWKV

Inference efficiency is a critical practical concern. The paper measures text generation time and maximal decoding throughput for $1.3\,$B–scale models, comparing xLSTM variants to Llama (Transformer), Mamba (SSM), and RWKV (RNN). Two empirical patterns stand out.

First, generation time as context length increases: xLSTM and the other recurrent models (Mamba, RWKV) scale linearly with context length, whereas Llama’s generation time scales quadratically when it must recompute or use large key–value caches. In the specific generation experiments (batch size $1$, prefill $=16$ to favor the Transformer), xLSTM demonstrates linear runtime scaling and remains competitive in absolute wall-clock time.

Second, maximal decoding throughput (tokens/sec across batch sizes): because xLSTM’s memory usage is constant with respect to context length, it can operate with much larger batch sizes than Llama before exhausting GPU memory. This yields higher end-to-end throughput; empirically xLSTM achieves the highest throughput among the compared methods in the reported measurements. These results highlight a key systems advantage of the xLSTM design: constant-memory, linear-time recurrence permits higher parallelism at decode time and makes the model more suitable for high-throughput serving scenarios.

There are practical caveats reported in the paper. The mLSTM CUDA kernels in the authors’ implementation are not fully optimized and run about four times slower than highly optimized FlashAttention kernels; better kernels would reduce this gap. The sLSTM variant cannot be parallelized across time due to its memory-mixing recurrent connections, but the authors implemented an optimized CUDA kernel for it that runs typically less than two times slower than their parallel mLSTM implementation. These implementation-level facts suggest that with further engineering (kernel optimization and compilation), xLSTM’s wall-clock performance could be improved even further.

# Synthesis and takeaways

Across a suite of synthetic and large-scale language experiments, xLSTM demonstrates that carefully modernized LSTM ideas — exponential gating with stabilizers, a scalar sLSTM with memory mixing, and a matrix mLSTM with covariance-style updates — produce a recurrent architecture that is both expressive and scalable. On synthetic state-tracking tasks, exponential gating plus memory mixing restores the ability to implement discrete state behavior absent in many non-recurrent architectures. For associative recall, the matrix memory supplies strong content-addressable capacity. On practical language-modeling benchmarks trained with realistic data budgets ($15\,$B and $300\,$B tokens) and across sizes up to $1.3\,$B parameters, xLSTM attains lower perplexities, robust domain-wise gains across PALOMA, good downstream-task performance, reliable context-length extrapolation to $16\,$k tokens, and competitive inference throughput thanks to its linear-time, constant-memory recurrence.

The empirical picture supports the paper’s core message: when LSTM-derived designs are extended with modern architectural practices and targeted memory/gating innovations, recurrent models can again be competitive with — and in many respects surpass — state-of-the-art Transformer and SSM approaches in language modeling and related sequence tasks.
