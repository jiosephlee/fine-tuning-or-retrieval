\title{A Textbook about the Paper: xLSTM}

Chapter 13: Theory and Intuition: Why xLSTM Works

# Revisable storage via exponential gates and running normalizers

One of the core limitations of classical LSTMs identified in the paper is their difficulty to revise prior storage decisions: once information is written into the scalar cell state, it is hard to re-weight that information later in the sequence. xLSTM addresses this limitation by replacing bounded sigmoid gates (which yield values in $(0,1)$) with exponential gates for the input (and optionally forget) paths, combined with a running normalizer that explicitly tracks gate strength over time.

To see how this enables revisable storage, compare the sLSTM forward equations (Equation (3) in the paper):

c_t = f_t \, c_{t-1} + i_t \, z_t,
n_t = f_t \, n_{t-1} + i_t,
\tilde{h}_t = c_t / n_t,
h_t = o_t \, \tilde{h}_t,

with i_t given by i_t = \exp(\tilde{i}_t) (and f_t either \sigma(\tilde{f}_t) or \exp(\tilde{f}_t)). Because i_t is an exponential, it is strictly positive and unbounded above. The normalizer n_t accumulates the same gate weights used to form the cell content: it is a running sum of the contributions i_t, discounted by future forget factors f_t. The hidden representation is then formed by dividing the accumulated content c_t by the accumulated weight n_t, i.e. by computing a normalized (weighted) average \tilde{h}_t = c_t / n_t.

This construction makes storage revisable in two ways. First, because forget gates f_t can scale prior contributions multiplicatively, the effective weight of an earlier write can be decreased (or, with exponential f_t, even increased relative to a simple decay), so later inputs can attenuate prior memory contributions. Second, the input gate i_t being unbounded allows a newly arriving input to assert arbitrarily large influence relative to earlier writes. Together, these mechanisms let the network both amplify important late observations and demote earlier ones — a form of online, sequential re-weighting that is not achievable when gates are restricted to the interval (0,1) and the hidden state is not normalized by cumulative gate strength.

The running normalizer n_t is the bookkeeping device that makes these multiplicative re-weightings well-defined. By carrying the same multiplicative history of gates as the numerator c_t, the quotient c_t / n_t yields a stable normalized readout that reflects current relative importance of stored contents, not simply an absolute sum that cannot be easily rebalanced later.

Numerical stability is essential when gates are exponential. The paper introduces a stabilizer state m_t (Equation (4)) that is effectively a running log-sum-exp of the gate magnitudes, and then rescales i_t and f_t to avoid overflow. Crucially, this rescaling leaves the effective normalized output and gradients unchanged, so the model can safely exploit exponential gates without numerical breakdown.

# Normalizer as an implicit normalization akin to attention’s denominator

The normalizer in xLSTM plays the same conceptual role as the denominator in attention mechanisms: it converts a raw, potentially unbounded aggregate into a normalized readout that represents a weighted average rather than an unbounded sum. In the mLSTM, this connection is explicit.

For mLSTM the paper defines the matrix memory and normalizer as

\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top,
\mathbf{n}_t = f_t \mathbf{n}_{t-1} + i_t \mathbf{k}_t,

and the retrieved unnormalized vector is \mathbf{C}_t \mathbf{q}_t. The readout used for the hidden state divides this by a scalar normalization factor:

\tilde{\mathbf{h}}_t = \mathbf{C}_t \mathbf{q}_t \, / \, \max\{ |\mathbf{n}_t^\top \mathbf{q}_t|, 1 \}.

This denominator \mathbf{n}_t^\top \mathbf{q}_t is the running sum of key-query compatibilities (weighted by the input gates and decayed by forget gates). Dividing by it makes the retrieved vector behave like an attention-weighted average of stored values: the numerator aggregates value vectors scaled by their key similarity to the query, and the denominator scales out the total key mass so the result reflects relative contributions. The absolute value and lower bound protect against near-zero denominators.

Viewed this way, mLSTM implements attention-like retrieval without re-computing all pairwise key-query scores at query time. Instead, it incrementally accumulates an associative memory via outer products and maintains the corresponding normalizer. This yields a running, memory-efficient mechanism that approximates the normalization behavior of standard softmax attention, but with linear time accumulation instead of quadratic time pairwise re-evaluation.

The normalizer is therefore not just a numerical trick: it is the structural element that converts a compressive cumulative memory into a normalized discriminator of which stored items should influence the current read. In sLSTM the same idea appears in scalar form: \tilde{h}_t = c_t / n_t is a normalized scalar memory readout.

# Memory capacity and separability in covariance-based fast weights

mLSTM upgrades the scalar LSTM cell to a matrix memory \mathbf{C}_t \in \mathbb{R}^{d\times d} and updates it with outer products (covariance updates) of the form \mathbf{v}_t \mathbf{k}_t^\top. This is the classic fast weight or covariance update rule:

\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top.

Intuitively, each stored pair (\mathbf{k}_t,\mathbf{v}_t) deposits a rank-1 contribution into \mathbf{C}_t. When a later query \mathbf{q} arrives, the matrix multiplies the query to produce a linear combination of stored values:

\mathbf{C}_t \mathbf{q} = \sum_{\tau \le t} \left( \text{(gating product for }\tau)\cdot \mathbf{v}_\tau (\mathbf{k}_\tau^\top \mathbf{q}) \right).

That is, each stored value \mathbf{v}_\tau contributes with weight proportional to its key's dot product with the query, exactly the behavior one wants for associative retrieval. The normalizer \mathbf{n}_t plays the role of the total key mass, and dividing by \mathbf{n}_t^\top \mathbf{q} yields a relative weighting among values.

From a separability perspective, the paper cites the covariance update rule's optimality (Dayan; Sejnowski) for maximizing separability of retrieved binary vectors, which can be interpreted as maximizing signal-to-noise in retrieval when keys have zero mean. In practice this means that, within the representational bandwidth of a $d$-dimensional key and value space, the covariance update is an efficient way to store many associations: keys project queries to scalars that gate contributions of corresponding values, and the matrix aggregates these contributions compactly.

There is an important trade-off: covariance updates store pairwise key-value associations (a rank-1 deposit per stored item), which can be accumulated linearly over time. In contrast, full attention re-evaluates all pairwise interactions between stored tokens and the current query at each step, at quadratic cost, enabling more complex forms of separability. The paper notes that higher separability is possible when limiting retrieval to pairwise interactions and conceding quadratic complexity like attention. Thus covariance-based fast weights provide a powerful, linear-time, compressive memory that captures many associative scenarios, but they are not a free substitute for the full combinatorial power of quadratic attention in every setting.

# Expressivity and state tracking: RNNs vs Transformers/SSMs

A recurrent architecture that includes memory mixing — that is, hidden-to-hidden recurrent connections that allow the content of one time step's state to influence gate decisions in the next — can implement forms of stateful computation that architectures without such mixing struggle to emulate. The paper emphasizes that memory mixing, together with exponential gating, allows sLSTM to solve state-tracking problems that Transformers and many State Space Models (SSMs) cannot.

Memory mixing enables conditional writes and conditional control flow: the hidden state can carry compressed summary information that influences which future inputs are stored, forgotten, or emphasized. Exponential gates make these decisions flexible in scale, and the normalizer maintains coherent retrievals. In the synthetic experiments reported, models without memory mixing (e.g., vanilla Transformers or SSMs) fail on formal languages that require precise state updates (such as parity-style or certain regular-grammar tasks). By contrast, xLSTM variants that retain memory mixing (sLSTM or sLSTM components inside blocks) can maintain and update discrete-like internal states, which is essential for algorithmic tasks and stateful sequence understanding.

Thus expressivity here is not only about representational width but about the ability to implement sequential control and iterative state updates over time. The LSTM tradition — additive cell updates, gating, and recurrent mixing — remains particularly well-suited to such computations. xLSTM preserves and strengthens these core mechanisms (via exponential gating and novel memory designs), enabling both richer associative storage (mLSTM) and robust state tracking (sLSTM).

# Limits of pairwise interactions vs quadratic attention

It is important to be explicit about what the covariance (outer-product) memory can and cannot do compared to full attention. The covariance update stores pairwise key-value structure: each stored item contributes a rank-1 matrix \mathbf{v}\mathbf{k}^\top that, when multiplied by a query, yields contributions weighted by \mathbf{k}^\top \mathbf{q}. This produces the familiar attention-like weighting of values by key-query similarity, but implemented incrementally and with linear time per time step.

Quadratic attention, however, recomputes all pairwise similarities between the current query and every stored key in the context window at query time and (typically) applies a softmax normalization. That recomputation enables richer, possibly non-linear combinations of stored items because attention can dynamically reweight any stored item according to the exact current context and can leverage softmax non-linearities to produce sparse, competitive selection. The paper acknowledges that higher separability — meaning the ability to disambiguate many stored patterns — can be achieved if one is willing to pay the quadratic cost of attention (e.g., by limiting retrieval to pairwise interactions and incurring quadratic complexity).

Covariance-based fast weights represent an attractive compromise: they capture the essential pairwise interaction between key and query in a compressed, incremental way, and when combined with normalization they approximate attention-like retrieval with linear scaling in sequence length. But for problems where the highest degree of discriminative separability between many similar stored items is required, quadratic attention retains an advantage.

# Cover’s Theorem and the role of up-projection in separating contexts

Cover’s Theorem states that a nonlinearly separable pattern in a low-dimensional space is more likely to become linearly separable when mapped nonlinearly into a higher-dimensional space. The xLSTM architecture leverages this insight in the design of its residual blocks: each block first (or last) applies linear up-projection to a higher-dimensional latent space, lets the recurrent memory summarize the past nonlinearly in that high-dimensional space, applies nonlinearities there, and then projects back. Two variants are used in the paper: a post up-projection residual block (nonlinear summarize in original space, then up-project and nonlinearity) and a pre up-projection block (project up first, then summarize nonlinearly in the high-dimensional space). The paper prescribes using post up-projection for sLSTM blocks and pre up-projection for mLSTM blocks.

Why does up-projection help? Intuitively, mapping inputs into a higher-dimensional latent space creates more degrees of freedom to encode distinctions among past histories. Memory operations performed in that higher-dimensional space can therefore separate contexts that would be conflated in a smaller-dimensional memory. For mLSTM in particular, placing the matrix memory in the higher-dimensional space enlarges the expressive capacity of the covariance memory: each stored outer product then lives in a larger matrix space, allowing more complex associative patterns to be represented and separated. For sLSTM, post up-projection means that the scalar memories operate on features that have already been expanded and nonlinearly mixed, permitting the scalar normalization and re-weighting to operate on more expressive summaries.

In practice, this use of up-projection aligns with the block design choices in modern large models: up-projecting into a "wider" latent space before a powerful nonlinear/computational unit often improves the ability to linearly separate different sequence histories when the unit finally maps back down. The experiments in the paper — notably language-modeling and associative recall results — indicate that combining these up-projection strategies with the modified LSTM memories leads to markedly improved separability of contexts and better retrieval behavior in long sequences.

# Closing intuition and how the pieces fit together

xLSTM brings three tightly coupled design ideas together to address concrete LSTM shortcomings and to approach the strengths of attention-based systems while keeping linear time and constant working memory:

1. Exponential gates plus running normalizers make stored contents immediately comparable and re-weightable. They provide a principled mechanism for later inputs to revise the effective contribution of earlier writes, while the stabilizer m_t prevents numerical issues.

2. Covariance-based matrix memory (fast weights) accumulates associative key-value outer products so that retrieval via matrix-vector multiplication yields attention-like weighted sums, but computed incrementally with linear per-step cost. The normalizer here plays the exact role of an attention denominator, converting a sum into a relative weighting.

3. Up-projection into higher-dimensional latent spaces (before or after the memory operation depending on the memory type) implements an application of Cover’s Theorem: it increases the chance that different past histories become separable by a linear readout, thereby improving predictive power.

These elements interact: exponential gating enables flexible write strengths and decay behaviors that the covariance memory uses to sculpt the stored associative matrix; the normalizer ensures those sculpted contents are read as normalized, relative combinations (as in attention); and up-projection supplies the representational capacity needed for fine-grained separations. Empirically, the paper shows that this combination yields improved performance on state-tracking formal tasks, associative recall benchmarks, and large-scale language modeling and extrapolation experiments, indicating that the theoretical motivations above translate into practical gains.
