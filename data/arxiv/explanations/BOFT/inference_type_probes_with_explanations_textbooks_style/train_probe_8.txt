Chapter: Dense Orthogonal Finetuning via Butterfly Factorization: Balancing Depth and Block Size

# From Orthogonal Finetuning to Orthogonal Butterfly

Adapting large pretrained models to downstream tasks efficiently requires reusing as much of the pretrained knowledge as possible while modifying the model with a minimal number of trainable parameters. Orthogonal Finetuning (OFT) is a principled approach to this end. It modifies a linear layer with pretrained weights $\bm{W}^0 \in \mathbb{R}^{d \times n}$ by left-multiplying an orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$, so the layer output is updated from $\bm{z} = (\bm{W}^0)^\top \bm{x}$ to $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$. Because $\bm{R}$ is orthogonal, it preserves pairwise angles between neurons, which is desirable for preserving pretrained knowledge.

However, a dense $d \times d$ orthogonal matrix has $\mathcal{O}(d^2)$ degrees of freedom, making OFT potentially parameter-inefficient. A block-diagonal structure reduces parameters by setting $\bm{R} = \mathrm{diag}(\bm{R}_1, \dots, \bm{R}_r)$ with $r = d/b$ blocks of size $b \times b$. This reduces parameters to $\mathcal{O}(bd)$, but at the cost of a fixed sparsity pattern and a loss of expressivity: transformations across blocks are disallowed. Moreover, the block-diagonal pattern cannot recover many classic dense linear transforms.

Orthogonal Butterfly (BOFT) replaces the single dense orthogonal matrix with a product of sparse orthogonal matrices organized via butterfly factorization. This enables dense transformations to be composed from sparse components, maintaining parameter efficiency while avoiding the rigid inductive bias and expressivity limitations of block-diagonal OFT. BOFT defines a family of orthogonal parameterizations $\bm{R}(m,b)$ indexed by the number of multiplicative factors $m$ and the block size $b$, allowing one to smoothly trade off expressivity and regularity.

# An Information Transmission View of Matrix Factorization

To understand how a dense orthogonal matrix can be composed from sparse factors, it is useful to view matrix factorization as information transmission on a layered graph. Consider a factorization
$\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$,
where each $\bm{B}_i \in \mathbb{R}^{d \times d}$ is sparse and orthogonal. Unrolling the multiplication induces a directed graph on a $d \times (m+1)$ grid of nodes. Each layer of $d$ nodes represents a vector space at an intermediate multiplication stage; edges between layer $i$ and $i+1$ are specified by the nonzero pattern of $\bm{B}_i$. An entry $(\bm{B}_i)_{j_1 j_2} \neq 0$ means there is a directed edge from node $j_2$ at layer $i$ to node $j_1$ at layer $i+1$.

In this view, a dense matrix $\bm{R}$ corresponds to the property that every source node (at layer 1) can transmit information to every sink node (at layer $m+1$) through at least one path, so that no entry in $\bm{R}$ is forced to zero by the sparsity pattern. This leads to two desiderata for designing a parameter-efficient factorization:

First, dense connectivity: every source must reach every sink via some path through the layers. This ensures the product $\bm{R}$ can be dense even if each factor is sparse.

Second, minimal free edges: subject to orthogonality constraints, the total number of trainable nonzeros across all factors should be as small as possible. Orthogonality already imposes that each factor is full rank, which requires at least $d$ nonzero entries per layer as a bijection between the $d$ nodes in adjacent layers. These necessary nonzeros are not freely parameterizable in arbitrary ways since orthogonality ties their values together (e.g., in $2 \times 2$ orthogonal blocks many entries are determined by others). Thus we count only the effective trainable parameters beyond those forced by orthogonality.

This transmission perspective clarifies how one might replace a single dense orthogonal matrix (costing $\mathcal{O}(d^2)$ parameters) with a sequence of sparse, orthogonal factors, still achieving dense end-to-end connectivity but with far fewer total trainable parameters.

# Butterfly Factorization and Orthogonal Components

The butterfly structure from the Cooley–Tukey fast Fourier transform provides a natural way to achieve efficient dense connectivity. Butterfly matrices achieve dense mixing by composing $\mathcal{O}(\log d)$ sparse factors, each with $\mathcal{O}(d)$ nonzeros, yielding total complexity $\mathcal{O}(d \log d)$.

At the core is the butterfly factor of size $k$,
$\bm{B}^F(k) \in \mathbb{R}^{k \times k}$,
defined as
$\bm{B}^F(k) =
\begin{bmatrix}
\mathrm{diag}(\bm{d}_1) & \mathrm{diag}(\bm{d}_2) \\
\mathrm{diag}(\bm{d}_3) & \mathrm{diag}(\bm{d}_4)
\end{bmatrix}$,
where $\bm{d}_i \in \mathbb{R}^{k/2}$ for $i=1,2,3,4$. For $d = 2^N$, a butterfly matrix $\bm{B}(d)$ is defined recursively as
$\bm{B}(d) = \tilde{\bm{B}}(d,d)\,\tilde{\bm{B}}(d,d/2)\cdots \tilde{\bm{B}}(d,2)$,
where each butterfly component $\tilde{\bm{B}}(d,k)$ is a block-diagonal matrix with $d/k$ blocks, each block equal to a butterfly factor of size $k$:
$\tilde{\bm{B}}(d,k) = \mathrm{diag}(\bm{B}^F_1(k), \dots, \bm{B}^F_{d/k}(k))$.

To make the butterfly product orthogonal, each butterfly component must be orthogonal. This is achieved by parameterizing each $2 \times 2$ block within $\tilde{\bm{B}}(d,2)$ with an orthogonal parameterization such as the Cayley transform. Since the nonzero pattern of every other component $\tilde{\bm{B}}(d,k)$ is a permutation of $\tilde{\bm{B}}(d,2)$, these too can be parameterized orthogonally by permuting the same $2 \times 2$ orthogonal blocks into the appropriate positions.

BOFT generalizes this scalar butterfly to a block butterfly with block size $b$. In the block butterfly, each scalar entry in the diagonal vectors $\bm{d}_i$ becomes a $b \times b$ matrix, and each $2 \times 2$ scalar block is lifted to a $2b \times 2b$ block. The corresponding butterfly components, denoted $\tilde{\bm{B}}^b(d,k)$, are orthogonal by parameterizing each $2b \times 2b$ block as an orthogonal matrix. The full BOFT parameterization of the finetuned layer is
$\bm{z} = \big(\bm{R}(m,b)\,\bm{W}^0\big)^\top \bm{x}$,
where
$\bm{R}(m,b) = \prod_{i=1}^{m} \tilde{\bm{B}}^b_{(d,i)}$,
and each factor $\tilde{\bm{B}}^b_{(d,i)}$ is an orthogonal block butterfly component. Identity initialization is achieved by initializing the skew-symmetric parameter in the Cayley transforms to zero, so each factor starts as the identity and the initial finetuned model exactly matches the pretrained model.

# When Is the Product Dense? The Roles of m and b

A key question is: under what conditions on $m$ and $b$ does $\bm{R}(m,b)$ become dense? The information transmission perspective gives a precise intuition. Each butterfly component enables structured mixing across pairs of coordinates (or blocks of coordinates when $b>1$). Applying more components increases the “reach” of information across indices layer by layer, widening the set of reachable sinks from any given source. If we apply sufficiently many stages, every source can reach every sink, making the product dense.

For scalar butterflies ($b=2$), using the full butterfly matrix with $m = \log d$ components yields a dense matrix with $\mathcal{O}(d \log d)$ parameters. When $b > 2$, each factor operates on larger $2b \times 2b$ orthogonal blocks, effecting broader mixing in a single stage. Consequently, fewer stages are required to propagate information across all coordinates.

This relationship is formalized in the observation that BOFT with $m = \log \frac{2d}{b}$ and block size $b$ yields a dense orthogonal matrix. In other words, increasing $b$ reduces the number of multiplicative stages needed to achieve dense end-to-end connectivity. At the extremes:
- When $m=1$, BOFT($1$,$b$) reduces to the block-diagonal OFT with block size $b$, which is not dense unless $b=d$.
- When $b=d$, BOFT($1$,$d$) is the original OFT with a full dense orthogonal matrix.
- For intermediate $b$, increasing $b$ increases the span of each stage, so fewer stages $m$ are needed to achieve density.

This leads directly to the central practical insight: to obtain a dense $\bm{R}$ using fewer sequential multiplications (smaller $m$), one should increase the block size $b$. The butterfly structure guarantees that increasing $b$ expands intra-stage connectivity in a way that preserves orthogonality and compatibility with efficient composition.

# Parameter Efficiency: Counting the Cost

BOFT controls parameter count through the pair $(m,b)$. The effective number of trainable parameters used to finetune a $d \times n$ linear layer with BOFT($m$,$b$) is
$\frac{1}{2}(b-1) d m$.
This formula highlights two levers:

- Depth $m$: each additional butterfly component adds a linear-in-$d$ number of $2b \times 2b$ orthogonal blocks, contributing linearly to parameter count.

- Block size $b$: larger blocks increase parameters per stage via the $(b-1)$ term, but simultaneously reduce the required number of stages to reach density.

For a dense $\bm{R}$ with scalar butterflies, BOFT($\log d$, $2$) uses $\mathcal{O}(d \log d)$ parameters, versus $\mathcal{O}(d^2)$ for a single dense orthogonal matrix. The original OFT must set $b=d$ to generate a dense matrix in one stage, incurring $\mathcal{O}(d^2)$ parameters. In contrast, BOFT can achieve a dense matrix for any $b \ge 2$ by choosing $m = \log \frac{2d}{b}$, with total parameter count
$\frac{1}{2}(b-1)d \log \frac{2d}{b}$.
Thus, if one desires fewer sequential multiplications (smaller $m$), increasing $b$ is the principled way to compensate without abandoning parameter efficiency, because the total parameter count still scales as $\mathcal{O}(d \log d)$ across a wide range of $(m,b)$ that achieve density.

# The Trade-off Between Expressivity and Regularity

Expressivity in BOFT increases with $m$ and $b$. Larger $m$ and $b$ enlarge the reachable subset of the orthogonal group. With $m=1$, BOFT($1$,$b$) matches the block-diagonal OFT and is strictly less expressive than multi-stage BOFT with the same $b$. Moreover, BOFT with a given $b$ is more expressive than OFT with the same block size because the multiplicative composition allows cross-block mixing across stages. In fact, with an appropriate alternation of butterfly matrices and their transposes in a kaleidoscope hierarchy, one can represent the entire orthogonal group with bounded stage-wise butterfly factors, albeit at the cost of many stages; however, universal expressivity is not the goal in finetuning, where regularity and inductive bias support generalization.

BOFT provides a smooth interpolation between identity (maximal regularity) and the full orthogonal group (maximal expressivity) by adjusting $(m,b)$. For a fixed parameter budget, one can select $(m,b)$ to occupy a more suitable hypothesis class for the downstream task. Increasing $b$ to reduce $m$ preserves the ability to reach dense matrices while controlling the total number of parameters and the inductive bias introduced by the butterfly structure.

# Stability and Initialization

Orthogonal finetuning has favorable spectral properties: left-multiplying by an orthogonal matrix preserves the spectral norm of the pretrained weight matrix. Writing $\bm{W}^0 = \bm{U}\bm{\Sigma}\bm{V}^\top$, both OFT and BOFT produce finetuned weights $\bm{R}\bm{U}\bm{\Sigma}\bm{V}^\top$, leaving the largest singular value unchanged. This preservation contributes to training stability and generalization.

BOFT initializes each butterfly component to the identity by setting the skew-symmetric parameters in the Cayley transforms to zero. This ensures that the initial finetuned model exactly matches the pretrained model, aligning with standard finetuning practices that avoid large initialization-induced perturbations.

Because BOFT updates weights multiplicatively, conventional additive dropout is not directly applicable. Instead, BOFT introduces a multiplicative dropout that randomly selects a fraction of butterfly components and a fraction of their diagonal blocks and replaces those blocks with identity matrices during training. This preserves the multiplicative structure and orthogonality while regularizing the finetuning process.

# Practical Guidance: Fewer Stages via Larger Blocks

Within the BOFT framework, achieving a dense $\bm{R}$ requires sufficient cross-coordinate mixing across stages. The butterfly structure reveals a clear mechanism to trade off the number of stages against the block size:

- For small block size $b$ (e.g., $b=2$), achieving density requires more stages, approximately $m = \log d$.

- For larger block size $b$, each stage mixes larger contiguous groups, so fewer stages are needed. In particular, BOFT with $m = \log \frac{2d}{b}$ yields a dense $\bm{R}$.

Therefore, to obtain a dense $\bm{R}$ using fewer sequential multiplications (smaller $m$) without abandoning parameter efficiency, one should increase the block size $b$. This preserves the desirable $\mathcal{O}(d \log d)$ scaling of total parameters over a broad range of $(m,b)$ and avoids the rigidity and expressivity limitations of purely block-diagonal OFT.

# Concluding Perspective

BOFT reframes the challenge of parameter-efficient, dense orthogonal finetuning as an information transmission problem. Butterfly factorization provides a principled way to compose dense transformations from sparse, orthogonal components with strong parameter efficiency. The two key hyperparameters, number of stages $m$ and block size $b$, jointly determine connectivity, density, and parameter count. The core insight is that increasing $b$ allows one to reduce $m$ while still achieving dense end-to-end connectivity, maintaining efficiency, and preserving the inductive biases associated with butterfly structures that have been successful in classic fast transforms.
