### How does Cayley parameterization translate into the stated parameter count for BOFT?
Question:
The paper uses the Cayley transform $\mathbf{R}=(\mathbf{I}+\mathbf{Q})(\mathbf{I}-\mathbf{Q})^{-1}$ with $\mathbf{Q}^\top=-\mathbf{Q}$ to parameterize each orthogonal block. For BOFT($m,b$), it claims an "effective trainable parameter" count of $\tfrac{1}{2}(b-1)dm$ for finetuning a $d\times n$ layer.
- Could someone derive this formula step by step? For a single $2b\times 2b$ Cayley-parameterized block, how many independent parameters are there (should it be $b(2b-1)$ or $2b(2b-1)/2$?), and how many such blocks appear per butterfly component and per depth $m$?
- What exactly does "effective" mean here relative to the full number of nonzeros in the product?
Answer:
Short answer: the counting comes from (a) each orthogonal $2b$-by-$2b$ block is Cayley-parameterized by a skew-symmetric matrix, which has $s(s-1)/2$ independent entries for $s=2b$, (b) there are $d/(2b)$ such independent blocks in each butterfly component, and (c) there are $m$ independent butterfly components. Plugging these together and doing the simple algebra (and noting the paper’s notational shift of $b$) yields the stated effective parameter count $\tfrac{1}{2}(b-1) d m$. Below I show the steps and clarify what “effective” means.

Step‑by‑step derivation
1. Cayley parameterization of an $s\times s$ orthogonal block. If $R = (I + Q)(I - Q)^{-1}$ with $Q^T = -Q$, then $Q$ is skew‑symmetric and the independent degrees of freedom in $Q$ are exactly the independent entries above (or below) the diagonal. For an $s\times s$ skew matrix the number of independent parameters is
$$
\frac{s(s-1)}{2}.
$$

2. The block used in the paper. BOFT constructs orthogonal butterfly components from blockwise $2\times 2$ (or blockwise $2b\times 2b$) orthogonals. If a single orthogonal block has size $2b\times 2b$, set $s = 2b$. The number of independent parameters per such block is therefore
$$
\frac{(2b)(2b-1)}{2} = b(2b-1).
$$

3. How many blocks per butterfly component? Each butterfly component is block-diagonal, covering the whole $d\times d$ matrix by repeating that $2b\times 2b$ block along the diagonal. The number of independent $2b\times 2b$ blocks in one component is $d/(2b)$. So parameters per butterfly component equals
$$
\frac{d}{2b}\cdot b(2b-1)=\frac{d(2b-1)}{2}.
$$

4. Multiply by the number of components $m$. The full BOFT orthogonal $R(m,\cdot)$ is the product of $m$ such butterfly components, each with independent parameters, so total trainable parameters is
$$
m\cdot\frac{d(2b-1)}{2}=\frac{1}{2}dm(2b-1).
$$

5. Reconciling notation in the paper. The paper defines BOFT$(m,b)$ in a slightly confusing way (they earlier use a $2b\times 2b$ block and then state BOFT$(m,b/2)$ is denoted BOFT$(m,b)$). If you replace $b\to b/2$ in the last formula (i.e. interpret the paper’s final “$b$” as twice the block half-size used in the intermediate derivation) you obtain
$$
\frac{1}{2}dm\big(2\cdot\frac{b}{2}-1\big)=\frac{1}{2}dm(b-1),
$$
which is the formula reported in the paper:
$$
\text{effective trainable parameters}=\tfrac{1}{2}(b-1)dm.
$$
So the numerical factor and the linear dependence on $d$ and $m$ come directly from the skew-symmetric counting and the number of repeated blocks per component.

Answering your subquestions directly
- Number of independent parameters in one $2b\times 2b$ Cayley block: exactly $(2b)(2b-1)/2=b(2b-1)$. If you interpreted the block size as $s$, in general it is $s(s-1)/2$.
- Number of such blocks per butterfly component: $d/(2b)$. Number of butterfly components (depth) = $m$. Multiply per-block parameters by blocks-per-component and by $m$ to get the total.
- What “effective” means: it counts trainable degrees of freedom (i.e., independent scalar parameters in the skew-symmetric $Q$ blocks that you optimize). It is not the same as the number of nonzero entries in the final dense product $R = B_m\cdots B_1$. The product $R$ can be much denser (many nonzero entries) even though the number of independent trainable parameters is small because those dense entries are deterministic nonlinear functions of the (far fewer) $Q$ entries in the blocks. In short, “effective” = number of free/trainable parameters (independent entries in the $Q$s), not the number of non-zeros in the composed matrix or its final memory footprint.

Intuition and broader view
The Cayley map converts a skew matrix (with $O(s^2)$ entries reduced by skew symmetry) to an orthogonal matrix; the butterfly factorization repeats small orthogonal blocks across the layer and composes $m$ such sparse factors so that after multiplication you can achieve dense $R$ while having only $O(d m b)$ free parameters. This is exactly the space/time tradeoff the paper exploits: fewer parameters (space) at the cost of extra factor multiplications (time), with the orthogonality constraint drastically reducing the number of independent parameters relative to an unconstrained dense orthogonal matrix (which would need $O(d^2)$ degrees of freedom).
