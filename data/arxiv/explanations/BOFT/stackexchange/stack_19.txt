### How does orthogonal left-multiplication interact with residual connections and LayerNorm?
Question:
If we replace $\mathbf{W}^0$ by $\mathbf{R}\mathbf{W}^0$, this changes the mapping from inputs to outputs. Given residual connections and LayerNorm, does left-multiplying by an orthogonal $\mathbf{R}$ have any special effect on activation scales or gradient norms? Since $\mathbf{R}$ preserves the $\ell_2$ norm, is there a theoretical reason to expect better stability compared to additive updates like LoRA?
Answer:
Short answer: Left-multiplying a pretrained weight by an orthogonal matrix $R$ mostly acts like a rotation of the layer’s input/neuron space and therefore preserves Euclidean lengths and singular values of the frozen weight; that gives a structural reason why orthogonal finetuning (OFT/BOFT) tends to be more stable than unconstrained additive updates (LoRA). However, residual connections and LayerNorm interact nontrivially with that rotation: LayerNorm removes (or rescales) much of any pure scale change, and residuals add the original signal back so the net effect seen by the network is a mixture of rotated and identity paths. Thus orthogonality helps with stability in an important, but not absolute, way.

Why $R$ “helps” (intuitive + a bit of math). Consider a linear layer with pretrained weights $W^0$ and an orthogonal update $R$, so the new forward is
$z = (R W^0)^T x = (W^0)^T (R^T x)$.
Because $R$ is orthogonal, $R^T R = I$, so $R$ preserves Euclidean norms: for any $v$, $\|R v\|_2 = \|v\|_2$. Equivalently, if $W^0 = U \Sigma V^T$ is the SVD, then
$R W^0 = (R U) \Sigma V^T$,
so the singular values $\Sigma$ (and hence the spectral norm $\|W^0\|_2$) are unchanged. Preserving the singular values is important: it prevents the layer from introducing larger operator norms that can amplify activations or gradients, which is a common source of instability. This is the paper’s key spectral-property argument: multiplicative orthogonal updates preserve spectral norm and pairwise angles between neurons, and that contributes to training stability and better generalization.

How LayerNorm affects this. LayerNorm (as commonly used in transformers) normalizes activations across features to zero mean and unit variance (then applies an affine scale+shift). An orthogonal left-multiplication preserves the variance (because orthogonal transforms preserve second moments up to permutation/rotation) but can change the mean of the pre-normalized vector (rotation mixes coordinates). If LayerNorm is applied after the linear map, the normalization will remove any pure scale change and mostly hide effects that are only scaling; it will not, however, remove changes in the directional geometry that affect relative coordinates after normalization. In short, orthogonality makes the layer’s contribution less likely to blow up variance; LayerNorm further reduces sensitivity to residual scaling differences, so the combination is doubly stabilizing for scale-related problems.

How residual connections interact. Residual connections add (often) the input or previous activations back to the layer output. If the layer produces $z$ and the residual adds $x_{\text{res}}$, the network sees $z + x_{\text{res}}$. There are two typical placements: Pre-LN (LayerNorm before the sublayer) and Post-LN (LayerNorm after the sublayer). The interactions differ:

- If the network uses pre-LN (LayerNorm before linear), the linear sees normalized inputs. $R$ acting on the weights is equivalent to rotating those normalized inputs; because the inputs are norm-controlled, the effect of $R$ is constrained and unlikely to produce exploding activations. The residual path still mixes the rotated output with the identity path, which tends to lessen extreme deviations.

- If the network uses post-LN (LayerNorm after addition), the LayerNorm will renormalize $z + x_{\text{res}}$, so again pure scale changes are suppressed. Orthogonality helps because it keeps $z$’s scale consistent with the pretrained model; the residual prevents the model from relying solely on the rotated sublayer output and thus acts as a regularizer.

In all cases, residuals + LayerNorm make the network robust to moderate changes; orthogonality reduces the chance of introducing large operator norms in the first place, so the three mechanisms act together to improve stability.

Gradients: preservation vs amplification. Because orthogonal left-multiplication preserves singular values of $W^0$, the linear mapping’s operator norm remains the same; therefore, at least for the linear part, orthogonal updates do not increase the worst-case amplification of gradients back through that layer. Put differently, for the linear map $y = (R W^0)^T x$ the Jacobian norm w.r.t. $x$ is bounded by the same spectral norm as the pretrained weight. Additive updates like LoRA change $W^0$ to $W^0 + \Delta$ where $\Delta$ is low-rank; $\Delta$ can change singular values (potentially increasing the largest singular value) and thus may increase gradient magnitudes or change the conditioning. That is the theoretical reason to expect improved gradient-scale stability from multiplicative orthogonal updates versus additive unconstrained updates.

Caveats and limits. Orthogonality helps but is not a panacea. First, orthogonal $R$ is a rotation/mixing only — it cannot change the singular values of $W^0$, so if the pretrained weights have problematic conditioning for the new task, OFT cannot fix that by scaling singular values (LoRA could). Second, nonlinearities, LayerNorm’s affine parameters, attention softmax, and downstream layers can still amplify or damp gradients; orthogonality only controls one piece of the whole computational graph. Third, orthogonal constraint reduces degrees of freedom and so may sacrifice expressivity compared to unrestricted additive updates; that trade-off can be good for generalization but may limit fit in some tasks. Finally, in practice BOFT uses Cayley parameterization with identity initialization (so the initial model is unchanged) and a structured parameterization (butterfly), which balances the stability benefits of orthogonality with parameter efficiency.

Summary. Left-multiplying by orthogonal $R$ is equivalent to a rotation that preserves activation norms and singular values of the pretrained layer; this gives a principled reason for improved stability of training and gradient norms compared to unconstrained additive methods like LoRA. Residual connections and LayerNorm further reduce sensitivity to scale and stabilize training, so the combination of orthogonality + residuals + LayerNorm is a natural and effective design for stable finetuning. Nonetheless, orthogonality cannot change singular-value spectrum to fix conditioning and reduces the parameter space, so practical trade-offs between stability, expressivity, and parameter-efficiency remain.
