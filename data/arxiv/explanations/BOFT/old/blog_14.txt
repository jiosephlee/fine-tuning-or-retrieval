# Plugging BOFT into Hugging Face and PyTorch: An Engineering Guide

In this guide, we’ll walk through how to integrate BOFT (Orthogonal Butterfly Finetuning) into your existing PyTorch and Hugging Face training pipelines. BOFT lets you finetune large pretrained models by wrapping each Linear layer with a compact, orthogonal parameterization built from butterfly‐structured factors. Our walkthrough will cover:

  * Monkey‐patching PyTorch `nn.Linear` modules  
  * Defining BOFT parameter storage and forward pass  
  * Saving and loading custom BOFT checkpoints  
  * Interoperating with PEFT libraries  
  * Merging BOFT into full weights for export  
  * Verifying correctness and orthogonality  

Whether you’re finetuning a Transformer or a vision backbone, by the end you’ll have a drop‐in BOFT solution that slots right into `Trainer` or your custom training loop.

## 2. Monkey‐Patching `nn.Linear`

BOFT wraps each Linear layer to replace its weight update with a multiplicative orthogonal adapter $\bm{R}(m,b)$. We’ll define a custom `BOFTLinear` module that holds:

  1. The frozen pretrained weight `W0`  
  2. A sequence of $m$ orthogonal butterfly components (each of block size $b$) stored as skew‐symmetric parameters via Cayley transform  

### 2.1 Implementing `BOFTLinear`

```python
import torch
import torch.nn as nn

class BOFTLinear(nn.Module):
    def __init__(self, orig_linear: nn.Linear, m: int = 4, b: int = 2):
        super().__init__()
        # Freeze original weight and bias
        self.W0 = nn.Parameter(orig_linear.weight.data.clone(), requires_grad=False)
        self.bias = orig_linear.bias
        d, n = self.W0.shape

        # Store m Cayley skew-symmetric blocks of shape (num_blocks, 2b, 2b)
        self.m, self.b = m, b
        self.skews = nn.ParameterList()
        for i in range(m):
            # #blocks along the diagonal
            num = d // (2*b)
            # initialize zeros -> identity after Cayley transform
            skew = torch.zeros(num, 2*b, 2*b)
            self.skews.append(nn.Parameter(skew))

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        R = self._build_orthogonal()
        # Apply R multiplicatively: (R W0)^T x
        W = R @ self.W0
        return nn.functional.linear(x, W, self.bias)

    def _build_orthogonal(self) -> torch.Tensor:
        """
        Build R = B_m B_{m-1} ... B_1 using Cayley transform on each block.
        Each B_i is block-diagonal with num_blocks of size 2b.
        """
        d, _ = self.W0.shape
        R = torch.eye(d, device=self.W0.device)
        for skew in self.skews:
            # Cayley map: (I + Q)(I - Q)^{-1} for each block
            blocks = []
            for Q in skew:
                I2 = torch.eye(2*self.b, device=Q.device)
                Bi = (I2 + Q) @ torch.linalg.inv(I2 - Q)
                blocks.append(Bi)
            # assemble block-diagonal B_i
            B = torch.block_diag(*blocks).to(x.device)
            R = B @ R
        return R
```

### 2.2 Patching the Model

We can recursively replace every `nn.Linear` with `BOFTLinear`:

```python
def apply_boft(model: nn.Module, m: int = 4, b: int = 2):
    for name, module in model.named_children():
        if isinstance(module, nn.Linear):
            setattr(model, name, BOFTLinear(module, m, b))
        else:
            apply_boft(module, m, b)
    return model

model = apply_boft(model, m=6, b=4)
```

After this patch, any forward pass will go through your BOFT wrappers.
