\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### What exactly is the sLSTM normalizer state $n_t$, and why is the hidden state defined as $h_t = o_t (c_t / n_t)$?
Question:
The sLSTM introduces an extra recurrence $n_t = f_t n_{t-1} + i_t$ and then uses $\tilde{h}_t = c_t / n_t$ before output gating. I am confused about what $n_t$ is supposed to represent. If I unroll the recurrence, it looks like both $c_t$ and $n_t$ accumulate past terms with the same gate products, so $c_t / n_t$ seems like some kind of weighted average of past inputs $z_\tau$. Is that the correct interpretation? If so, why is that preferable to the usual LSTM approach of applying something like $\tanh(c_t)$ to keep the state bounded?
Answer:
Yes — in the sLSTM, $n_t$ is best thought of as a *normalization mass* or *running total weight* for the memory, not as another piece of semantic content. The paper says exactly that it “sums up the product of the input gate times all future forget gates,” and that it “keeps record of the strength of the gates.” If you unroll the recurrences, you get

$$
c_t \;=\; \sum_{\tau \le t} \left(i_\tau z_\tau \prod_{j=\tau+1}^t f_j\right), 
\qquad
n_t \;=\; \sum_{\tau \le t} \left(i_\tau \prod_{j=\tau+1}^t f_j\right),
$$

assuming zero initial state for simplicity. So when all gates are positive, $c_t / n_t$ really is a weighted average of the past cell inputs $z_\tau$, with weights proportional to the same gate products that determine how much each past input survives to time $t$. In that sense, your interpretation is correct: $n_t$ is the denominator that turns the raw accumulated memory into a normalized readout.

That is precisely why the hidden state is defined as

$$
h_t = o_t \left(\frac{c_t}{n_t}\right).
$$

The cell state $c_t$ stores the weighted sum, while $n_t$ stores the total effective weight. Dividing by $n_t$ removes the dependence on absolute gate scale and makes the readout comparable across time. This is analogous to how attention produces a normalized weighted average rather than an unnormalized sum: the numerator carries content, and the denominator carries strength.

This is preferable to applying something like $\tanh(c_t)$ for a different reason. A $\tanh$ nonlinearity keeps the state bounded, but it does so by *saturating* the value. Once $c_t$ is large in magnitude, different underlying memories all look almost the same after $\tanh$, so information about relative strength is lost. In the xLSTM paper, the point of exponential gating is to let the model revise storage decisions more flexibly; normalization via $n_t$ preserves the relative contributions of past inputs instead of crushing them into a fixed range. So the model does not just ask “is the memory large?” but “what is the average content after accounting for how strongly each thing was written?”

So the short answer is: $n_t$ is a bookkeeping variable that normalizes the memory, and $c_t / n_t$ is a normalized, weighted summary of past inputs. The output gate $o_t$ then decides how much of that normalized memory to expose. The separate stabilization state $m_t$ in the paper is only there to make the exponential gates numerically safe; it is not the conceptual normalizer.
