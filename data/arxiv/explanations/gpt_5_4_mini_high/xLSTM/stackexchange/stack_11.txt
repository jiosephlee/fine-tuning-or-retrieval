\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### Is mLSTM fundamentally different from linear attention or RetNet, or mostly a gated reparameterization of the same idea?
Question:
The mLSTM equations look very similar to several linear-attention-style models: there is a recurrent matrix state that accumulates outer products, a query-based readout, and a normalization term. The related work section also mentions Retention, Linear Transformer, RWKV-5/6, and HGRN2 as using similar covariance-style updates. So what is the conceptual difference between mLSTM and those models? Is the novelty mainly the LSTM-style gating and how it is integrated into a residual stack, or is there a deeper distinction in what functions the model can represent?
Answer:
At the level of the raw recurrence, mLSTM is very close to the linear-attention / RetNet / RWKV / fast-weight family, and the paper explicitly says so. Its core memory update is

$$
\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top,
$$

with a query-based readout

$$
\tilde{\mathbf{h}}_t = \mathbf{C}_t \mathbf{q}_t \big/ \max\{|\mathbf{n}_t^\top \mathbf{q}_t|, 1\}.
$$

That is the same basic pattern as a covariance-style associative memory: accumulate outer products of keys and values, then retrieve with a query. The paper even notes that this update is equivalent to Fast Weight Programmers and that related methods such as Retention, Linear Transformer, RWKV-5/6, and HGRN2 use similar covariance-style mechanisms. So if by “fundamentally different” you mean “does it compute something qualitatively unlike those models?”, the answer is mostly no.

What mLSTM adds is not a new algebraic primitive so much as an LSTM-style parameterization and stabilization of that primitive. The forget gate acts like a learned decay rate, the input gate like a learned learning rate, the output gate controls what is exposed, and the normalizer state $\mathbf{n}_t$ keeps track of gate mass so the retrieval stays numerically well behaved. The paper also uses exponential gating with stabilization, which is one of its main architectural changes. In that sense, mLSTM is best thought of as a gated, stabilized fast-weight/linear-attention mechanism packaged as an LSTM memory cell, not as a wholly different attention model.

The deeper distinction in the paper is actually elsewhere: the authors’ stronger expressivity claim is tied to memory mixing, which they discuss for sLSTM, not mLSTM. For mLSTM, “multiple heads and multiple cells are equivalent as there is no memory mixing.” That means mLSTM is mainly about higher storage capacity and associative retrieval, as shown by their key-value recall experiments, while the broader xLSTM story is about combining this with residual blocks and, in sLSTM, memory mixing for state-tracking-like problems. So I would summarize it this way: mLSTM is mostly a gated reparameterization of the same core idea as linear attention/RetNet-style associative memories, with the novelty coming from the LSTM framing, exponential gating, normalization, and its use inside xLSTM blocks, rather than from a fundamentally new memory computation.
