\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 9: xLSTM in the Landscape of Modern Sequence Models

# Linear attention methods and their goal of avoiding quadratic attention cost

A useful starting point for understanding xLSTM is to look at the pressure that shaped many recent sequence models: the cost of standard Transformer self-attention grows quadratically with context length. That makes long sequences expensive to process, especially when the goal is large-scale language modeling. Several families of methods were therefore proposed to preserve the usefulness of attention-like sequence modeling while reducing this cost.

The paper places methods such as the Synthesizer, Linformer, Linear Transformer, Performer, Structured Global Convolution, and the Hyena hierarchy in this category. These approaches do not all do the same thing, but they share a common aim. Some, like the Synthesizer, learn synthetic attention weights without direct token-to-token interactions. Others, like Linformer, use a low-rank representation to approximate attention. Linear Transformer rewrites attention in a form that scales linearly, Performer approximates the softmax with positive orthogonal random features, and SGConv and Hyena replace attention with fast long convolutions. The unifying intuition is that the model should still be able to process long sequences, but without paying the full quadratic cost of comparing every token to every other token.

xLSTM is motivated by the same efficiency problem, but it answers it in a different way. Rather than approximating attention, it returns to recurrence and asks how far an LSTM can be scaled if its memory and gating are redesigned. In the paper’s framing, xLSTM retains the long-sequence efficiency goal that motivated linear attention methods, while pursuing it through recurrent memory cells, exponential gating, and a residual-block architecture.

# State Space Models such as S4, S5, H3, and Mamba

State Space Models became prominent for much the same reason as linear attention methods: they are linear in context length and therefore avoid the quadratic scaling of standard attention. In the paper, the sequence-modeling landscape includes S4, DSS, GSS, S5, BiGS, H3, and Mamba. These models attracted attention because they offer a different route to long-context processing, one based on structured state evolution rather than pairwise token comparisons.

The broad intuition behind this family is that the model carries an internal state forward through the sequence, updating it at each step so that it summarizes the past in a compact form. This makes them attractive when one wants long-context capability without the cost of full attention. In the paper’s terminology, they are one of the main modern alternatives to Transformers, and they have shown promising performance in language modeling.

xLSTM belongs to the same broader conversation, but it does not simply adopt the state-space approach. Instead, it preserves the basic LSTM idea of gated memory while modifying the memory structure itself. The paper’s mLSTM is fully parallelizable and uses a matrix memory, while the sLSTM keeps recurrent memory mixing and uses exponential gating. This is why xLSTM can be read as a recurrent family that is competing directly with state-space sequence models, not as a minor variant of them. The paper’s experiments are designed to test that claim by comparing xLSTM favorably with Mamba, H3, and related models on both synthetic and large-scale language tasks.

# Recent recurrent alternatives such as RWKV, HGRN, and HGRN2

Recurrent neural networks never disappeared from sequence modeling; rather, they were revisited in new forms once it became clear that recurrence naturally scales linearly in context length. The paper identifies RWKV, HGRN, HGRN2, and related models as part of this newer recurrent line. It also mentions Deep Linear Recurrent Units as another example of recurrence regaining relevance for language modeling.

RWKV is especially notable in the paper because it is presented as a well-known recurrent approach to large language modeling with competitive performance relative to Transformers. HGRN and HGRN2 likewise represent attempts to modernize recurrence with gates and architectural choices that fit current language-modeling practice. The common motivation here is not just efficiency, but also the hope that recurrence can retain expressive sequential structure while remaining trainable at scale.

xLSTM sits close to these methods in spirit, but it tries to push the recurrent idea further. The paper’s central question is whether scaling LSTMs to billions of parameters, while using modern training and architecture techniques, can recover strong language-modeling performance. In the experiments, xLSTM is compared directly to RWKV variants and HGRN2, and it performs strongly enough that the authors argue it is competitive with the best current recurrent alternatives. What distinguishes xLSTM is not simply that it is recurrent, but that it revises the LSTM memory design itself.

# Gating as a recurring idea across modern sequence models

Gating is one of the most important ideas inherited from the original LSTM. In the classical LSTM, the input gate controls how much new information is written, the forget gate controls how much of the previous cell state is retained, and the output gate controls how much of the memory is exposed as the hidden state. This mechanism was introduced to address vanishing gradients and to make memory updates additive rather than purely multiplicative.

The paper emphasizes that gating has reappeared in many later sequence models. It explicitly points to HGRN, HGRN2, GLA, GSS, BiGS, MEGA, RWKV, and Mamba as examples where gating plays a central role again. This recurrence is not accidental. Gating gives a model the ability to regulate information flow, which is crucial when sequence data contains both relevant and irrelevant signals and the model must decide, step by step, what to keep.

xLSTM extends this theme by using exponential gating. In the sLSTM and mLSTM variants, input and forget gates can be exponential rather than purely sigmoid. The paper stresses that exponentials can become numerically unstable, so xLSTM introduces a stabilizer state $m_t$ and stabilized gates that preserve the output of the network and the derivatives of the loss. This matters because it shows that xLSTM is not merely replacing one activation by another; it is redesigning gating so that the model can revise storage decisions more flexibly while remaining numerically sound. The paper’s ablation studies also support the importance of gating: making each gate learnable and dependent on the input gives an incremental benefit.

# Covariance-style memory updates across different model families

One of the most distinctive changes in xLSTM is the move from a scalar memory to a matrix memory in mLSTM. Instead of storing only a single value at each step, the model stores associations between a key vector $\mathbf{k}_t$ and a value vector $\mathbf{v}_t$ in a matrix $\mathbf{C}_t \in \mathbb{R}^{d \times d}$. The update rule is

$\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top$,

which is a covariance-style outer-product update. The paper interprets this as a fast associative memory: the key-value pair is written into the matrix, and later a query vector $\mathbf{q}_t$ can retrieve the stored information through matrix multiplication.

This idea is not unique to xLSTM. The paper connects it to Fast Weight Programmers and to newer methods such as RWKV-5, RWKV-6, Retention, Linear Transformer, and HGRN2. The shared intuition is that the model should accumulate a memory of past associations using an update that looks like a weighted outer product. In xLSTM, the forget gate acts like a decay rate, the input gate acts like a learning rate, and the output gate scales the retrieved result. That mapping makes the relation to the broader literature especially clear: these models all use some variant of gated accumulation to build a fast memory over time.

The paper also explains why this can work well. It notes that the covariance update rule is optimal for maximal separability of retrieved binary vectors, which is equivalent to maximizing signal-to-noise ratio. In other words, this type of update is a principled way to store associations that can later be recovered by a query. xLSTM’s contribution is to integrate that idea into an LSTM framework with gates, normalization, and a memory state that can be used inside a modern residual architecture.

# Why Retention, RWKV, and HGRN2 are especially close to xLSTM

Among the models discussed in the paper, Retention, RWKV, and HGRN2 are described as the closest to xLSTM conceptually. The reason is that they already share some of xLSTM’s central ingredients: matrix-like memory accumulation, gating, or both. They also live in the same design space of efficient sequence models that try to replace the quadratic cost of attention with some form of recurrent or recurrent-like state.

At the same time, the paper highlights a crucial difference. These closer models do not allow memory mixing in the way sLSTM does. That absence matters because memory mixing is what lets information from one hidden state influence later memory updates in a richer way than simple accumulation. The authors argue that this is precisely why xLSTM is more expressive in the settings they care about. In the paper’s view, memory mixing is the missing ingredient that helps solve state-tracking problems.

The distinction is especially clear in the mLSTM and sLSTM split. mLSTM is fully parallelizable and uses a matrix memory, while sLSTM keeps sequential memory mixing. Retention, RWKV, and HGRN2 are close because they resemble one side or the other of that design, but xLSTM combines the ideas with explicit LSTM-style memory control and, in the sLSTM case, genuine memory mixing across cells. That combination is what makes xLSTM more than a simple rewrite of existing efficient recurrent models.

# The distinctive role of memory mixing in sLSTM

Memory mixing is the mechanism that makes the sLSTM different from approaches that merely accumulate a running memory. In the original LSTM, the cell state is updated additively, but the update itself depends on the previous hidden state through recurrent weights. The paper reminds us that later formulations even combine multiple scalar memory cells into a vector and use recurrent weight matrices to mix the outputs of those cells. In xLSTM, that general idea is carried forward and adapted to the new architecture.

The paper’s sLSTM can have multiple memory cells and multiple heads. Within each head, memory mixing occurs across cells, but not across heads. This is a new design choice: the introduction of heads together with exponential gating creates a different way of mixing memory than in standard LSTMs. Because the hidden state influences the gates and cell input at the next step, the model can revise what it has stored rather than only deciding whether to keep or forget a value once and for all.

This is also why sLSTM is not parallelizable. The hidden-hidden connections force the computation to proceed sequentially, step by step. The paper treats that as a cost, but also as a feature, because it is the mechanism that helps the model solve tasks requiring state tracking. In the nearest-neighbor search example discussed in the paper, a standard LSTM struggles to revise a stored value when a more similar vector is encountered later, whereas xLSTM can do better because its exponential gating makes revision easier. So memory mixing is not just a structural detail; it is the source of a qualitatively different kind of sequence processing.

# Expressivity arguments about state tracking in RNNs versus Transformers and SSMs

A central claim in the paper is that memory mixing makes LSTMs more expressive than State Space Models and Transformers for certain kinds of sequence reasoning. The paper cites prior work arguing that memory mixing enables state tracking, and that state tracking is required for tasks such as evaluating code or following entities through a long narrative. Put simply, state tracking means that the model must maintain an internal abstract state that updates in response to each new input symbol.

The paper’s formal-language experiments are meant to make this point concrete. It reports that models without memory mixing, including Transformers and State Space Models, cannot solve some regular grammars such as the parity task. This is presented as evidence that simply having long-context efficiency is not enough. A model must also be able to revise and coordinate its state in the right way. That is where recurrent memory mixing matters.

xLSTM is designed to address this expressivity gap. Its exponential gating and modified memory structures are intended to make it easier to update storage decisions and to keep track of evolving state over long sequences. In the paper’s experiments, this pays off on formal languages, associative recall, and longer-context evaluations. The broader lesson is that efficiency and expressivity are separate problems: many modern models have made progress on the first, but xLSTM is trying to improve both at once.

# When compressive memory is an advantage and when it is a limitation

xLSTM’s memory is compressive, and the paper treats that as both a strength and a tradeoff. On the positive side, xLSTM networks have linear computation and constant memory complexity with respect to sequence length. That means they do not need to store an ever-growing cache of past tokens, which makes them attractive for industrial settings and for edge deployment. The paper also reports favorable generation-time scaling and high throughput, precisely because memory use does not grow with the context length in the same way it does for a Transformer.

At the same time, compression can limit what the model can keep. This is the problem that the paper illustrates with rare-token prediction: the original scalar LSTM compresses information into scalar cell states, and that limited storage capacity hurts performance on rare tokens. mLSTM addresses this by using a matrix memory, which gives much greater storage capacity. The paper’s Multi-Query Associative Recall results are meant to show that this richer memory improves retrieval on more difficult key-value tasks, and that the sLSTM block does not reduce capacity but can actually help leverage it.

There is still a tradeoff. The matrix memory of mLSTM requires $d \times d$ storage and computation, which is more expensive than a scalar state. The paper argues that this cost is acceptable because the update and retrieval can be parallelized with standard matrix operations, so the wall-clock overhead remains manageable. It also notes a possible limitation: because the memory is independent of sequence length, very long contexts could eventually overload it, although the reported experiments did not find this to be a problem up to contexts of $16{,}384$. In this sense, xLSTM shows both sides of compressive memory very clearly. It is powerful because it is compact, but it must be designed carefully so that compactness does not become a bottleneck.
