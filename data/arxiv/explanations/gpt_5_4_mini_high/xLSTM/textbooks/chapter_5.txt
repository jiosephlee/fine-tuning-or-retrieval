\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 5: sLSTM: Revisable Scalar Memory with New Memory Mixing

# The sLSTM Forward Pass Step by Step

The scalar sLSTM keeps the central LSTM idea of a recurrent memory cell, but it changes the gate dynamics and the way the cell state is turned into the hidden state. In the paper’s notation, a single time step begins with the current input vector $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. These are linearly projected to form the cell input and the three gates, and then the memory is updated. The key point is that the memory update is still additive, as in the original LSTM, but the new gate parameterization and the extra normalizer state make the memory revisable.

The forward pass is
\[
c_t = f_t c_{t-1} + i_t z_t, \qquad
n_t = f_t n_{t-1} + i_t, \qquad
h_t = o_t \tilde{h}_t, \qquad
\tilde{h}_t = \frac{c_t}{n_t}.
\]
The cell input and gates are computed from affine transforms of $\mathbf{x}_t$ and $h_{t-1}$:
\[
z_t = \varphi(\tilde{z}_t), \qquad
\tilde{z}_t = \mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z,
\]
\[
i_t = \exp(\tilde{i}_t), \qquad
\tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i h_{t-1} + b_i,
\]
\[
f_t = \sigma(\tilde{f}_t)\ \text{or}\ \exp(\tilde{f}_t), \qquad
\tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f h_{t-1} + b_f,
\]
\[
o_t = \sigma(\tilde{o}_t), \qquad
\tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o h_{t-1} + b_o.
\]
This is the entire update in compact form: compute gates and candidate content, update the scalar memory, normalize it with the normalizer state, and finally expose part of it through the output gate.

The sequencing matters. The current hidden state $h_{t-1}$ influences the current candidate content and all three gates, so the model does not simply store the input stream; it also conditions its next decision on what it has already summarized. In the paper’s framing, this is the mechanism that lets the model revise earlier storage decisions rather than only accumulate them.

# Cell State Update with Exponential Input Gating

The cell state update remains additive, just as in the original LSTM:
\[
c_t = f_t c_{t-1} + i_t z_t.
\]
What changes in sLSTM is the form of the gates. The input gate is exponential,
\[
i_t = \exp(\tilde{i}_t),
\]
instead of being restricted to a sigmoid. This matters because the input gate is no longer limited to values between $0$ and $1$. In the paper’s design, the model can therefore write a new piece of information with variable strength, rather than only deciding whether to pass it through or suppress it.

This is one of the main ways sLSTM departs from the vanilla LSTM. In a standard LSTM, the input gate mostly acts as a soft on/off switch. In sLSTM, the exponential input gate is part of a broader change in the gate algebra: the model can make stronger write decisions when the current evidence is more relevant. The paper uses this as one of the mechanisms that helps the model revise storage decisions in sequence problems.

The candidate content $z_t$ itself is still produced by a nonlinear transform of the current input and previous hidden state,
\[
z_t = \varphi(\mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z),
\]
so the model still follows the basic LSTM pattern of separating “what content to write” from “how strongly to write it.” The novelty lies in letting the write strength be exponential rather than sigmoid-bounded.

# Normalizer State and Hidden State Computation as $c_t$ Divided by $n_t$

The normalizer state is the second key addition to sLSTM:
\[
n_t = f_t n_{t-1} + i_t.
\]
The paper describes it as a state that “sums up the product of the input gate times all future forget gates.” That description becomes clear if one expands the recursion. The current normalizer contains the current input gate, plus older input gates discounted by the forget gates that came after them. In other words, $n_t$ keeps track not only of what has been written, but also of how much that content has been preserved over time.

The hidden state is then formed by normalizing the cell state:
\[
\tilde{h}_t = \frac{c_t}{n_t}, \qquad h_t = o_t \tilde{h}_t.
\]
This ratio is the central normalization idea in sLSTM. Instead of directly squashing $c_t$ with a fixed nonlinearity, as in the original LSTM, the model divides by a learned, time-dependent normalizer. The result is that the exposed memory content is scaled relative to the total strength of the gating history. The paper’s intuition is that the network should not only remember content, but also remember how strongly that content has been selected.

A useful way to read this is that $c_t$ stores the accumulated evidence, while $n_t$ stores the accumulated confidence with which that evidence was admitted into memory. The quotient $c_t/n_t$ therefore acts like a normalized summary of the past. This is what allows sLSTM to preserve the additive memory update while changing the behavior of the memory readout.

# Output Gating in sLSTM

The output gate in sLSTM keeps the familiar role from the original LSTM:
\[
o_t = \sigma(\tilde{o}_t), \qquad h_t = o_t \tilde{h}_t.
\]
It controls how much of the normalized memory is exposed as the hidden state. Because the hidden state is also fed into the recurrent projections at the next time step, the output gate influences not only what the model emits at time $t$, but also what information becomes available for future gating and content computation.

This preserves an important LSTM intuition. The memory cell is not forced to reveal everything it stores. Instead, the cell computes an internal normalized summary, and the output gate decides how much of that summary should become visible. In sLSTM, this mechanism works on top of the new ratio $c_t/n_t$, so the output gate is controlling a normalized memory representation rather than a directly squashed cell state.

The paper keeps the output gate sigmoid-valued, unlike the input gate and optionally the forget gate. That choice matters because the output gate is not the part of the architecture that is responsible for revising storage decisions; its role is to regulate exposure. The revision mechanism comes from the combination of exponential gating and normalization in the state update itself.

# Optional Sigmoid or Exponential Forget Gating

The forget gate in sLSTM is allowed to be either sigmoid or exponential:
\[
f_t = \sigma(\tilde{f}_t)\ \text{or}\ \exp(\tilde{f}_t).
\]
This flexibility is part of the paper’s “exponential gating” modification. The forget gate still serves the same conceptual role as in the original LSTM: it determines how much of the previous memory is retained. But with the exponential option, the gate is no longer restricted to a bounded range.

That flexibility comes with a numerical challenge. Exponential values can grow very large, so the paper introduces a stabilization state $m_t$:
\[
m_t = \max\bigl(\log(f_t) + m_{t-1}, \log(i_t)\bigr),
\]
\[
i_t' = \exp(\log(i_t) - m_t) = \exp(\tilde{i}_t - m_t),
\]
\[
f_t' = \exp(\log(f_t) + m_{t-1} - m_t).
\]
The paper states that replacing $f_t$ with $f_t'$ and $i_t$ with $i_t'$ in the forward pass does not change the output of the whole network and does not change the derivatives of the loss with respect to the parameters. So the stabilized form is not a different model; it is a numerically safer representation of the same computation.

This stabilization is important because it lets the model use exponential gates without losing control of scale. In the paper’s design, the extra state $m_t$ is what makes the new gating scheme practical rather than merely expressive in theory.

# How sLSTM Differs from Vanilla LSTM in Behavior and Intuition

The original LSTM uses the additive cell update
\[
c_t = f_t c_{t-1} + i_t z_t, \qquad h_t = o_t \psi(c_t),
\]
with sigmoid gates and a squashing or normalization function $\psi$ applied to the cell state before output. sLSTM keeps the additive memory update, but changes two things at once: the gates can be exponential, and the cell state is normalized by the separate normalizer state $n_t$ before being exposed.

That difference changes the model’s behavior in an important way. In a vanilla LSTM, the cell state is passed through a fixed nonlinearity, so the output is controlled mainly by the magnitude of $c_t$ itself. In sLSTM, the output depends on the relationship between the accumulated cell content and the accumulated gate strength. This makes the memory more explicitly revisable, because the model is not just storing content; it is also tracking how strongly and how consistently that content has been accepted into memory.

The paper uses the nearest-neighbor-search example to illustrate the limitation of standard LSTM behavior. When a better match appears later in the sequence, a vanilla LSTM struggles to revise what it has already stored. sLSTM is designed to address that specific issue through exponential gating and normalization. So the intuition is not that sLSTM abandons LSTM memory, but that it makes the memory easier to revise when new evidence is stronger than older evidence.

# Why Exponential Gating Helps Revise Earlier Storage Decisions

The most direct intuition for exponential gating is that it gives the model a larger dynamic range for writing and forgetting. A sigmoid gate can only attenuate or pass through within a bounded interval, whereas an exponential gate can scale memory contributions much more flexibly. That matters in problems where later observations should replace earlier ones rather than merely blend with them.

The paper’s nearest-neighbor-search example captures this idea well. A sequence is scanned for the most similar vector to a reference vector, and the associated value must be retrieved at the end. The challenge is not only storing an item, but also revising that stored item when a later, more relevant vector appears. With exponential gating, a later input can have enough influence to dominate earlier content, while the normalizer state keeps the representation from becoming arbitrarily scaled. In this sense, the network can revise its storage decision instead of merely refining it.

This is why the paper presents exponential gating as a remedy for one of the classic limitations of LSTMs. The model still uses a recurrent memory cell, but the memory is now governed by a gate system that can express stronger selection pressure. That makes the update process more responsive to new evidence, which is exactly what revisable memory is supposed to do.

# Multiple Memory Cells in sLSTM

Although the basic equations are written for a scalar cell, the paper notes that sLSTM can also have multiple memory cells, just like later formulations of the original LSTM. In that case, the scalar states are combined into a vector, and the recurrent connection becomes matrix-valued. The result is that the outputs of different memory cells can interact through recurrent weight matrices.

In the paper’s notation, this means recurrent matrices $\mathbf{R}_{\mathbf{z}}$, $\mathbf{R}_{\mathbf{i}}$, $\mathbf{R}_{\mathbf{f}}$, and $\mathbf{R}_{\mathbf{o}}$ can connect the hidden-state vector to the cell input and the gates. This is the mechanism the paper calls memory mixing. Instead of each cell evolving in isolation, the cells can influence one another through the previous hidden state.

This matters because it gives the scalar memory structure more expressive power than a set of independent scalar registers. The memory is still built from scalar cells, but those cells are no longer separate. Their interaction is what lets sLSTM behave as a richer recurrent system while keeping the scalar nature of the basic cell state.

# Heads in sLSTM and Within-Head versus Across-Head Mixing

The paper extends the multiple-cell design by allowing sLSTM to have multiple heads. The important detail is that memory mixing happens within each head, but not across heads. So heads partition the memory into groups, and each group can mix internally while remaining separate from the others.

This is presented as a new way of memory mixing. In the paper’s terminology, the introduction of heads together with exponential gating is not just a bookkeeping choice; it changes the structure of how memory can be organized. Within a head, the recurrent matrices can mix the cells, so each head can maintain its own internal recurrent state. Across heads, however, there is no direct memory mixing.

The distinction is useful because it clarifies the role of heads in sLSTM. They are not merely copies of the same memory cell. They are separate memory subspaces, each with its own internal dynamics. That gives the architecture a structured way to represent different histories or contexts while still preserving the recurrent nature of the model.

# Why sLSTM Is Expressive on State-Tracking and Formal Language Tasks

The paper uses formal language tasks to test whether exponential gating with memory mixing actually helps with state tracking. This matters because a sequence model often has to do more than remember tokens; it has to keep track of an evolving latent state that determines what comes next. The paper argues that models without memory mixing, such as Transformers and State Space Models, cannot solve some regular grammars like parity, while xLSTM’s recurrent state-tracking mechanism is designed for exactly these kinds of problems.

The formal language experiments are constructed to assess this ability directly. The paper extends the tasks from the cited work so that models can be trained on multiple sequence lengths and then evaluated for extrapolation. Accuracy is measured on the tokens that matter for the task, and the score is scaled from $0$ to $1$. In this setting, the purpose of the model is not just to predict the next symbol locally, but to maintain the correct abstract state of the sequence over time.

That is the core reason sLSTM is expressive on these tasks. Exponential gating helps the model revise stored decisions, and memory mixing lets the model combine information across cells through recurrent matrices. Together, these features support the kind of long-range latent-state computation that formal language recognition requires. In the paper’s framing, this is what makes sLSTM a strong candidate for sequence problems where correct prediction depends on keeping track of the state of the process, not just the most recent input.
