\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 2: LSTM Foundations: Constant Error Carousel and Gating

# Why vanilla recurrent neural networks suffer from vanishing gradients

A recurrent neural network processes a sequence one step at a time, carrying a hidden state forward from the past into the present. That design is natural for language and other sequences, because later elements often depend on earlier ones. The difficulty is that information has to survive many time steps before it can still matter. In practice, the paper frames this as the vanishing gradient problem: when training signals have to propagate through a long chain of recurrent steps, it becomes hard for the model to learn long-range dependencies reliably.

The original LSTM was introduced specifically to overcome this problem. Its central idea was not to make recurrence disappear, but to give recurrence a dedicated memory path that can preserve information more cleanly than a plain recurrent update. Instead of forcing everything to pass through the same transformation at every step, LSTM separates storage from exposure and lets gates decide what to keep, what to write, and what to reveal. That simple structural change is what made LSTMs a major step beyond vanilla recurrent networks.

# The constant error carousel as the core LSTM idea

The paper identifies two core LSTM ideas: the constant error carousel and gating. The constant error carousel is the additive update of the cell state. In the simplest form, the memory is updated as

\[
c_t = f_t c_{t-1} + i_t z_t .
\]

This equation is the heart of the model. The previous memory $c_{t-1}$ is not discarded and replaced all at once. Instead, it is carried forward, scaled by the forget gate $f_t$, and combined with new information $i_t z_t$. That additive path is the reason the cell state serves as a stable memory channel.

The intuition is that the cell state can keep moving forward through time without being repeatedly overwritten. The gates control the amount of retention and the amount of new writing, so the model can preserve useful history when needed and revise it when the current input demands it. The paper calls this direct, gated additive pathway the constant error carousel because it provides a route through which information, and therefore learning signal, can circulate over long spans.

# Cell state, hidden state, and additive memory updates

The paper treats the memory cell as the central processing and storage unit. The cell state $c_t$ is where the long-term information is stored, while the hidden state $h_t$ is what is exposed to the rest of the network. These two quantities are related, but they play different roles. The memory can accumulate information internally, and the hidden state can decide how much of that internal information should be visible at the current step.

That distinction is made explicit by the output equation

\[
h_t = o_t \, \psi(c_t) .
\]

Here the cell state is first normalized or squashed by $\psi$, and only then is it filtered by the output gate $o_t$. The paper emphasizes that $\psi$ is needed because the cell state would otherwise be unbounded. So the cell state is the storage medium, while the hidden state is the controlled output of that storage. This separation is one of the reasons LSTMs are easier to use for long sequences than simpler recurrent architectures.

The additive memory update itself is also important conceptually. The current state is not built by replacing the old state with a fresh nonlinear transform. Instead, old information and new information are combined in a way that allows the network to decide how much of each should survive. That is what makes the LSTM memory feel more like a controlled accumulation process than a simple feedforward transformation repeated over time.

# Input, forget, and output gates

The original LSTM memory cell contains three gates: input, forget, and output. Each gate is a learned control signal that depends on the current input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$, together with a bias term. The paper writes the gate preactivations as affine functions of these quantities, and then applies a sigmoid nonlinearity. The forget gate was introduced later, but in the formulation used here all three gates are part of the memory cell.

The input gate $i_t$ determines how much new information enters the cell state. The forget gate $f_t$ determines how much of the old memory survives into the next step. The output gate $o_t$ determines how much of the cell state is exposed as the hidden state. This division of labor is central to the LSTM design. Rather than forcing a single update rule to do everything, the model learns separate decisions for writing, preserving, and reading memory.

Because the gates are data-dependent, the model can behave differently in different contexts. For example, when a piece of information should be kept for a long time, the forget gate can stay open enough to preserve it. When the current input contains something important, the input gate can open to let new content into the cell. And when the model should expose only part of its internal memory to the rest of the network, the output gate can regulate that exposure. The paper’s view is that this gated control is exactly what makes LSTMs robust sequence models.

# The roles of sigmoid and tanh activations

The gates in the LSTM use the sigmoid function,

\[
\sigma(x) = \frac{1}{1 + \exp(-x)} .
\]

The paper uses sigmoid for all gates because it naturally produces values that act like soft switches. A gate value near $0$ closes a pathway, while a value near $1$ opens it. This makes the gate outputs easy to interpret as fractions of information that should be allowed through. In other words, the gates are not hard binary decisions, but continuous control variables.

The other nonlinearities are typically $\tanh$, written in the paper as $\varphi$ for the cell input activation and $\psi$ for the hidden-state activation. The cell input $z_t$ is passed through $\varphi$ after the affine transformation, which shapes the content that can be written into memory. The hidden-state activation $\psi$ is applied to the cell state before the output gate uses it, and the paper explicitly notes that this squashes or normalizes the state so that it does not grow without bound. Together, these nonlinearities make the memory update both expressive and controlled.

This choice of activations is not incidental. The sigmoid gates provide bounded control, while the $\tanh$-style transforms provide a nonlinear representation for the content itself. The result is a memory mechanism that can both store information and keep it numerically well behaved.

# Full scalar LSTM update equations

For a single scalar memory cell, the paper gives the complete LSTM update as

\[
\begin{aligned}
c_t &= f_t c_{t-1} + i_t z_t, \\
h_t &= o_t \tilde{h}_t, \qquad \tilde{h}_t = \psi(c_t), \\
z_t &= \varphi(\tilde{z}_t), \qquad \tilde{z}_t = \mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z, \\
i_t &= \sigma(\tilde{i}_t), \qquad \tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i h_{t-1} + b_i, \\
f_t &= \sigma(\tilde{f}_t), \qquad \tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f h_{t-1} + b_f, \\
o_t &= \sigma(\tilde{o}_t), \qquad \tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o h_{t-1} + b_o .
\end{aligned}
\]

This set of equations makes the architecture very explicit. The current input $\mathbf{x}_t$ and previous hidden state $h_{t-1}$ are transformed separately for the cell input and for each gate. Each of these pathways has its own weights and bias: $\mathbf{w}_z$, $\mathbf{w}_i$, $\mathbf{w}_f$, $\mathbf{w}_o$, the recurrent weights $r_z$, $r_i$, $r_f$, $r_o$, and the biases $b_z$, $b_i$, $b_f$, $b_o$.

The model first computes a candidate cell input $z_t$ and gate values $i_t$, $f_t$, and $o_t$. Then it updates the memory state $c_t$, and finally it turns that memory into the hidden state $h_t$. The key point is that the memory update is additive and gated, not a pure overwrite. That is the mechanism that lets the cell carry information across many steps while still being able to adapt to new data.

# From a single memory cell to vector-valued multi-cell LSTMs

The paper notes that later formulations combine multiple scalar memory cells into a vector, written as $\mathbf{c}_t \in \mathbb{R}^d$. This changes the memory from a single scalar storage variable into a collection of interacting memory components. Once the memory becomes vector-valued, recurrent weight matrices $\mathbf{R} \in \mathbb{R}^{d \times d}$ can be used instead of scalar recurrent weights.

This extension matters because it allows the outputs of different memory cells to be mixed with one another. In the scalar version, one cell stores one stream of memory. In the vector-valued version, multiple cells can be organized together, and the recurrent matrices can combine their outputs. The paper presents this as a natural generalization of the original LSTM idea. It preserves the same basic logic of gated storage, but increases representational capacity by allowing several memory cells to operate as a coordinated system.

The paper also states that all components of the memory cell are crucial, which is consistent with the way the vector formulation is built. The architecture is not just about increasing the number of units. It is about preserving the gating and memory-update logic while scaling the memory structure to more expressive settings.

# Hidden-to-hidden recurrent connections and memory mixing

A defining feature of the original LSTM is that the current computation depends on the previous hidden state $h_{t-1}$. The paper’s equations show this directly: the previous hidden state contributes to the cell input and to all three gates. These hidden-to-hidden recurrent connections are what make the model genuinely sequential. Each step can condition its update on what the model has already processed.

When there is only one scalar memory cell, this dependence is straightforward. When multiple cells are combined into a vector, the recurrent connections can become matrix-valued and can mix the outputs of the different cells. The paper refers to this as memory mixing. In that setting, the hidden state is not just a passive readout of memory. It becomes a channel through which different memory components influence one another across time.

This mixing is part of what makes the original LSTM so expressive. It allows the network to build richer internal summaries of the past than a strictly independent memory bank would permit. At the same time, it keeps the core LSTM logic intact: memory is written, forgotten, and read through gates, and the hidden state carries the consequences of those decisions forward into the next step.

# Why classical LSTMs remained effective across many domains

The paper argues that LSTMs have stood the test of time because they are very good at learning abstractions. In the paper’s terms, they can extract semantic information and store it in their memory cells. That makes them useful whenever a task requires a model to carry structured information across time rather than merely react to the latest input. The paper cites evidence in the form of number and syntax neurons, linguistic neurons, and sentiment neurons, all of which suggest that LSTMs can organize information in meaningful ways inside their memory.

Their practical record is broad. The paper lists successful applications in text generation, handwriting generation, sequence-to-sequence translation, evaluating computer programs, image captioning, source code generation, rainfall-runoff modeling, hydrological models for flooding warnings, and reinforcement learning systems such as AlphaStar, OpenAI Five, and a magnetic controller for nuclear fusion. Before the Transformer era, LSTMs were also the first Large Language Models, and they prevailed over text generation until 2017.

That history helps explain their continued relevance. LSTMs are not just an old architecture that was replaced and forgotten. They are a mature sequence model with a well-understood memory mechanism, explicit gating, and a strong track record in both scientific and industrial settings. The paper’s conclusion is that these ideas were powerful enough to shape early language modeling and remain important enough to motivate new extensions.
