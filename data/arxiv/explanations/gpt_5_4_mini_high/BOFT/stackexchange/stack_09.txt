\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why does BOFT subsume block-diagonal OFT as a special case?
Question:
The paper says BOFT generalizes OFT and that BOFT\((1,b)\) is exactly block-diagonal OFT with block size \(b\). I do not see this immediately because BOFT is introduced as a product of butterfly components, while OFT is described as a single block-diagonal orthogonal matrix. Is the idea that when \(m=1\), the only factor is already block diagonal, so nothing is mixed across blocks? If so, how do the block sizes in the BOFT notation line up exactly with the block sizes in OFT?
Answer:
Yes — the special case is exactly a consequence of the notation shift the paper introduces.

The clean way to see it is to separate the “internal” butterfly block parameter from the “final” block size of the orthogonal matrix. The paper defines a block butterfly component $\tilde{\mathbf{B}}^b(d,k)$ by replacing each scalar entry in the basic butterfly factor with a $b \times b$ block. For the coarsest butterfly level, $k=2$, this gives a block-diagonal matrix whose diagonal blocks are of size $2b \times 2b$. In other words, the basic butterfly component at level $2$ is already block diagonal; the only question is what size those diagonal blocks are.

That is why the paper then says, “for convenience, we denote BOFT with $\mathbf{R}(m,b/2)$ as $\mathrm{BOFT}(m,b)$.” This is just a reparameterization so that the second BOFT argument matches the block size you would usually talk about in OFT. If you want a final block size of $b$, you set the internal butterfly parameter to $b/2$, because the level-$2$ butterfly block has size $2 \cdot (b/2)=b$.

So when $m=1$, BOFT has only one factor:
\[
\mathbf{R}(1,b)=\tilde{\mathbf{B}}^{b/2}(d,2).
\]
Since this is a single level-$2$ butterfly component, it is block diagonal, with blocks of size $b \times b$ and exactly $d/b$ such blocks. That is precisely the OFT block-diagonal form
\[
\operatorname{diag}(\mathbf{R}_1,\mathbf{R}_2,\ldots,\mathbf{R}_{d/b}), \qquad \mathbf{R}_i \in \mathbb{R}^{b \times b}.
\]

So your intuition is right: with $m=1$, there is no mixing across blocks, only within each block. The extra butterfly factors for $m>1$ are what create the cross-block permutations and allow BOFT to become denser and more expressive than block-diagonal OFT. In that sense, OFT is the “one-stage” case of the butterfly factorization, and BOFT generalizes it by stacking more stages.
