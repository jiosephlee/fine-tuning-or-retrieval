\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### In the paper's information-transmission view, when does a path in the factor graph actually imply a nonzero matrix entry?
Question:
The paper interprets a factorization \(R = B_m \cdots B_1\) as information transmission on a grid, where nonzero entries in each \(B_i\) are edges between adjacent levels. I understand that if there is no path from source node \(j\) to target node \(i\), then \(R_{ij} = 0\). But is the converse always true? If there is at least one path, couldn't contributions from different paths cancel numerically so that \(R_{ij} = 0\) anyway? I am trying to understand whether the graph argument is exact, or whether it only describes the support pattern generically while ignoring measure-zero cancellations.
Answer:
A path only implies that the corresponding entry can be nonzero, not that it must be nonzero for every numerical choice of the factors.

If you expand a product like $R = B_m \cdots B_1$, each entry is a sum over all intermediate index choices,
$$
R_{ij} = \sum_{k_1,\dots,k_{m-1}} (B_m)_{i k_{m-1}} (B_{m-1})_{k_{m-1} k_{m-2}} \cdots (B_1)_{k_1 j}.
$$
Each sequence $(j \to k_1 \to \cdots \to i)$ is exactly a path in the unrolled graph, and each path contributes one product term. So if there is no path, every term is absent and $R_{ij}=0$ exactly. But the converse is not exact in general: if there is at least one path, $R_{ij}$ is just a sum of one or more path contributions, and those contributions can cancel algebraically, giving $R_{ij}=0$ even though the graph is connected.

So the graph argument in the paper is really a support-pattern argument. It tells you which entries are structurally possible to be nonzero, or, more precisely, which entries are generically nonzero. The “measure-zero cancellation” caveat you mention is real, but it is not the focus of the paper. In fact, the paper explicitly says that “we only care about the non-zero trainable elements of $\bm{R}$ and their specific values do not matter,” which is exactly the viewpoint of ignoring such fine-tuned cancellations.

There is one special case where a path does imply a nonzero entry exactly: if there is a unique path from $j$ to $i$ and all edge weights on that path are nonzero, then $R_{ij}$ is just the product of those weights, so it cannot cancel with anything else. But once there are multiple paths, exact zero entries can occur by cancellation even though the graph has connectivity.

So the short answer is: no, the converse is not always true algebraically; the paper’s graph picture is about generic sparsity/support, not a strict iff statement for every possible parameter assignment.
