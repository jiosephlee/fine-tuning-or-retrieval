\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### What exactly is more expressive about BOFT than OFT with the same block size?
Question:
The paper states in Theorem 1 that BOFT is more expressive than OFT with the same block size, and the approximation experiment seems to support that. My current intuition is that a single block-diagonal OFT can never create interactions across blocks, while multiple butterfly factors can mix coordinates across blocks through structured permutations and local orthogonal transforms. Is that the formal reason? Is there a precise inclusion relation between the set of matrices representable by block-diagonal OFT and the set representable by BOFT for fixed \(b\)?
Answer:
Yes — that intuition is essentially the right one, and the paper’s “more expressive” claim can be made precise in set-inclusion terms.

If we write the block-diagonal OFT hypothesis class for block size $b$ as
$$
\mathcal H_{\mathrm{OFT}}(b)=\left\{\operatorname{diag}(R_1,\dots,R_r)\;:\;R_i\in O(b),\; br=d\right\},
$$
then this is exactly the $m=1$ special case of BOFT in the paper: “when $m=1$, BOFT$(1,b)$ reduces to the block-diagonal OFT with block size $b$.” So at the level of representable matrices,
$$
\mathcal H_{\mathrm{OFT}}(b)=\mathcal H_{\mathrm{BOFT}}(1,b).
$$

For $m>1$, BOFT uses a product of several orthogonal butterfly components,
$$
R(m,b)=\prod_{i=1}^m \tilde B^b_{(d,i)},
$$
where each factor is sparse, but the sparsity pattern changes across factors in a butterfly/permutation-like way. This is the key difference: a block-diagonal OFT matrix preserves the coordinate groups defined by its blocks, so it cannot create any coupling between different blocks. In contrast, BOFT repeatedly mixes coordinates at different scales, so information from one block can flow into others after multiplication. That is why BOFT can represent dense orthogonal matrices, while block-diagonal OFT cannot.

So the precise relation is that BOFT strictly contains block-diagonal OFT as a special case:
$$
\mathcal H_{\mathrm{OFT}}(b)\subsetneq \mathcal H_{\mathrm{BOFT}}(m,b)\qquad \text{for } m>1,
$$
with the understanding that the paper does not give a full algebraic characterization of $\mathcal H_{\mathrm{BOFT}}(m,b)$, only this inclusion and the fact that sufficiently deep butterfly factorizations can approximate very rich classes of orthogonal matrices. Theorem 1 is therefore not saying merely “BOFT has more parameters,” but that its factorized structure allows cross-block interactions that a single block-diagonal orthogonal matrix never can.
