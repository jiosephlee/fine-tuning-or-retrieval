\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why does a sparse orthogonal matrix with exactly \(d\) nonzero entries have to be a signed permutation matrix?
Question:
In the parameter-counting discussion, the paper says that for a \(d \times d\) orthogonal matrix, the minimum \(d\) edges needed for a bijection between adjacent levels should not be counted as trainable, because with exactly \(d\) nonzero entries those values can only be \(\pm 1\). I do not immediately see why orthogonality forces this. Is the claim that any real orthogonal matrix with one nonzero per row and one nonzero per column must be a signed permutation matrix? If so, could someone show the argument explicitly?
Answer:
Yes. In the real case, a $d \times d$ orthogonal matrix with exactly $d$ nonzero entries must be a signed permutation matrix, and that is exactly why the paper says those entries are not trainable.

The cleanest way to see it is to use the defining property of orthogonality. If $Q \in \mathbb{R}^{d \times d}$ is orthogonal, then its columns are orthonormal, so every column has Euclidean norm $1$. In particular, no column can be all zeros. Since there are $d$ columns and only $d$ nonzero entries total, each column must contain exactly one nonzero entry. The same argument applies to rows: every row of an orthogonal matrix also has norm $1$, so no row can be all zeros, and with only $d$ nonzeros total, each row must also contain exactly one nonzero.

So the support pattern of $Q$ is a permutation matrix: in each row and each column there is exactly one occupied position. That already means $Q$ has the form
$$Q = P D$$
or equivalently $Q = D P$, where $P$ is a permutation matrix and $D$ is diagonal.

Now look at the actual nonzero values. If a given row has only one nonzero entry, say it is $a$, then that row must have norm $1$, hence
$$|a| = 1.$$
Since we are over $\mathbb{R}$, this forces $a \in \{+1,-1\}$. So every nonzero entry is $\pm 1$.

Therefore $Q$ is a signed permutation matrix: it permutes the standard basis vectors and possibly flips some signs.

This is why the paper excludes those $d$ “minimum” edges from the trainable parameter count. They are not continuous degrees of freedom at all; once you insist on orthogonality and only $d$ nonzeros, the only possible weights are discrete signs.

One small caveat: over $\mathbb{C}$ the analogous statement would be “phased permutation matrix,” because the nonzero entries could be any complex unit-modulus numbers $e^{i\theta}$ rather than just $\pm 1$. But in the paper’s real-valued setting, the conclusion is exactly signed permutation.
