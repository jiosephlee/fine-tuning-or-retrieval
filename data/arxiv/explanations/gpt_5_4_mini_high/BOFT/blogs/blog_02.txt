\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Why Orthogonal Finetuning Helps AI Learn New Tasks Without Forgetting Old Ones

When we finetune a large foundation model, the goal is not to relearn everything from scratch. The goal is to adapt the model while keeping the useful structure it already learned during pretraining. That is exactly the motivation behind **orthogonal finetuning**.

The key idea is surprisingly simple: instead of freely rewriting a weight matrix, we **rotate** it with an orthogonal matrix. This preserves geometric relationships inside the layer, which helps the model keep its pretrained knowledge while still adapting to a new task.

## The basic idea: rotate the weights, don’t rebuild them

For a pretrained linear layer with weight matrix $\bm{W}^0$, orthogonal finetuning replaces the usual forward pass with

$$
\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x},
$$

where $\bm{R}$ is a learnable orthogonal matrix satisfying

$$
\bm{R}^\top \bm{R} = \bm{I}.
$$

If you think of a neural network layer as a set of directions in a high-dimensional space, then multiplying by an orthogonal matrix is like rotating or reflecting that space. It changes the orientation of the layer, but it does **not** stretch or distort it.

That matters because orthogonal transformations preserve:

- lengths of vectors,
- angles between vectors,
- and the overall spectral norm of the weight matrix.

So instead of letting finetuning freely change the geometry learned during pretraining, orthogonal finetuning keeps that geometry intact and only adjusts how it is used.

## Why preserving angles helps

The paper’s main intuition is that pretrained models already contain useful structure. In a layer, the relative angles between neurons can be thought of as part of that structure. Orthogonal finetuning preserves these pairwise angles, which means the model can adapt without destroying the relationships that pretraining established.

This gives orthogonal finetuning a strong inductive bias. The finetuned model is still flexible, but its updates are restricted to transformations that are geometrically well-behaved. That can help with:

- **training stability**, since orthogonal transformations preserve the spectral norm;
- **generalization**, because the model is not allowed to drift too far from the pretrained geometry;
- **knowledge retention**, because the pretrained representation is transformed rather than rewritten.

This is one reason the paper argues that orthogonal finetuning can be a more principled alternative to simply using a small learning rate.

## How this differs from LoRA

A popular parameter-efficient method like LoRA works in a very different way. LoRA adds a low-rank update to the pretrained weights. That is efficient, but it is an **additive** change:

$$
\bm{W}^0 \mapsto \bm{W}^0 + \Delta \bm{W}.
$$

Orthogonal finetuning is **multiplicative**:

$$
\bm{W}^0 \mapsto \bm{R}\bm{W}^0.
$$

The distinction is important. LoRA is designed to keep the update small in a low-rank subspace, while orthogonal finetuning is designed to preserve the geometry of the pretrained layer. In the paper, this geometric preservation is part of why orthogonal finetuning can be more stable and can generalize well.

There is also a trade-off. A full orthogonal matrix is expensive to learn, because a $d \times d$ orthogonal matrix can still be very large. So the original Orthogonal Finetuning (OFT) introduced a block-diagonal structure to reduce the number of trainable parameters. But block-diagonal sparsity comes with a cost: it limits expressiveness and imposes a rigid sparsity pattern.

## Making orthogonal finetuning practical with BOFT

The paper’s main contribution is to make orthogonal finetuning more parameter-efficient through **butterfly factorization**, leading to **Orthogonal Butterfly (BOFT)**.

Instead of learning one huge dense orthogonal matrix directly, BOFT writes it as a product of several sparse orthogonal matrices arranged in a butterfly pattern. This is inspired by the Cooley-Tukey fast Fourier transform, where butterfly structures allow information to be mixed efficiently across many nodes.

The result is a much smaller parameterization:

- full OFT uses $\mathcal{O}(d^2)$ parameters for a dense orthogonal matrix,
- BOFT can reduce this to $\mathcal{O}(d \log d)$ with butterfly structure.

Crucially, BOFT still stays within the orthogonal family, so it keeps the same geometric benefits as OFT while being far more efficient.

## Why this is useful in practice

The paper evaluates BOFT on large vision transformers, large language models, and text-to-image diffusion models. The main message is not just that BOFT is cheaper, but that it is a good trade-off between **expressivity** and **regularity**.

That trade-off is the heart of orthogonal finetuning. If the update is too unconstrained, the model may overfit or drift away from the pretrained solution. If it is too rigid, it may not adapt well. Orthogonal finetuning tries to stay in the middle: flexible enough to learn a new task, but structured enough to preserve what was already learned.

## Takeaway

Orthogonal finetuning works because it changes a model in a way that respects the geometry of its pretrained representations. By learning an orthogonal transformation, the model can adapt while preserving angles, norms, and spectral properties that support stable training and generalization.

The paper’s BOFT method makes this idea practical by factorizing the orthogonal matrix into a butterfly structure, cutting the parameter cost without giving up the core benefit.

If you want a short version: **orthogonal finetuning does not ask a model to forget its old geometry and learn a new one from scratch. It asks the model to rotate what it already knows into a better shape for the new task.**
