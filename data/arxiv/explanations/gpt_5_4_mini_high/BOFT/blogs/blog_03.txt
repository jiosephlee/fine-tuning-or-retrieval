\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# From Fast Fourier Transforms to Better AI Finetuning: The Butterfly Trick

Large foundation models are powerful, but adapting them to new tasks is still expensive. Full finetuning can be heavy on parameters and memory, while many parameter-efficient methods trade away some flexibility. This paper takes a different path: it starts from **Orthogonal Finetuning** (OFT), a method that updates weights with an orthogonal transformation, and then asks a practical question: can we make that update much cheaper without losing the benefits?

The answer is **yes**, by using a structure borrowed from one of the most elegant algorithms in computing: the **butterfly pattern** behind the Cooley-Tukey Fast Fourier Transform.

## Orthogonal finetuning, in plain terms

OFT updates a pretrained weight matrix $\mathbf{W}^0$ by multiplying it with a learnable orthogonal matrix $\mathbf{R}$. In other words, instead of changing the weights arbitrarily, it rotates them in a way that preserves pairwise angles between neurons. That matters because it helps retain the pretrained model’s structure and can improve stability and generalization.

The issue is that a general $d \times d$ orthogonal matrix is still large: it has on the order of $\mathcal{O}(d^2)$ parameters. OFT reduces this burden with a block-diagonal structure, but that comes with a cost. The blocks are independent, which makes the update less expressive and imposes a fairly rigid sparsity pattern.

So the challenge becomes: how do you get something that behaves like a dense orthogonal matrix, but is much cheaper to train?

## Dense behavior from sparse pieces

The paper’s key insight is to build a dense orthogonal matrix as a **product of several sparse orthogonal matrices**. This turns matrix design into an information-flow problem: if you think of matrix entries as connections between nodes, then multiplying sparse factors is like passing information through a layered graph.

For the final matrix to be dense, information must be able to flow from every source dimension to every output dimension. At the same time, the parameter budget should stay small. That means we want sparse factors that are still able to mix information broadly across coordinates.

This is where the butterfly structure comes in.

## Why the butterfly pattern works

The butterfly topology is famous because it powers the Cooley-Tukey FFT. In that algorithm, information is mixed recursively in a highly structured way, so a global transformation can be computed efficiently from many small local operations.

The same idea turns out to be useful for finetuning. A butterfly matrix is built from a product of sparse factors, and each factor only contains $\mathcal{O}(d)$ non-zero entries. With about $\mathcal{O}(\log d)$ such factors, you can create a dense transformation while using only $\mathcal{O}(d \log d)$ parameters.

That is the crucial win: you get dense mixing without paying the full $\mathcal{O}(d^2)$ cost.

The paper makes this work for orthogonal finetuning by ensuring that each butterfly factor is itself orthogonal. The result is a parameterization that stays within the orthogonal group, but is much more efficient than a fully dense orthogonal matrix.

## BOFT: Orthogonal Butterfly Finetuning

The method the authors propose is called **Orthogonal Butterfly**, or **BOFT**. It applies the butterfly factorization to orthogonal finetuning, giving a general framework that includes OFT as a special case.

In BOFT, the finetuned layer is written as

$$
\mathbf{z} = (\mathbf{R}(m,b)\mathbf{W}^0)^\top \mathbf{x},
$$

where $\mathbf{R}(m,b)$ is a product of orthogonal butterfly components. The parameters $m$ and $b$ control the factorization structure. When $m=1$, BOFT reduces to block-diagonal OFT. When the butterfly structure is expanded enough, it can represent dense orthogonal updates.

This gives BOFT a useful middle ground. It is more flexible than the block-diagonal form, but still far more parameter-efficient than a fully dense orthogonal matrix.

The paper also keeps the finetuning setup practical. BOFT uses identity initialization so the model starts from the pretrained weights, and it introduces a multiplicative dropout variant that fits the multiplicative nature of the update. After finetuning, the learned orthogonal matrices can be merged into the model, so there is no extra inference latency.

## Why this is more than just compression

The butterfly structure is not only a way to save parameters. It also changes the inductive bias of the finetuning process.

Because butterfly matrices are structured, they form a smaller hypothesis class than an unconstrained orthogonal matrix. That can be beneficial: the model is still expressive enough to adapt, but it is also constrained enough to avoid overfitting. The paper argues that this is one reason BOFT generalizes well.

There is also a nice theoretical angle. Orthogonal updates preserve the spectral norm of the pretrained weights, which is often associated with better stability. The paper further shows that BOFT is more expressive than OFT with the same block size, and that butterfly structures can recover classic fast transforms such as the FFT and Hadamard transform.

## What the experiments show

The authors evaluate BOFT on a broad set of tasks, including large vision transformers, large language models, and text-to-image diffusion models. Across these settings, BOFT is reported to outperform existing methods by a substantial margin, while using parameters more efficiently than OFT.

That breadth matters. Orthogonal finetuning was originally studied in the context of controllable text-to-image generation, but this paper shows that the approach is much more general. The butterfly parameterization makes orthogonal finetuning practical across multiple model families.

## The main takeaway

The core idea in this paper is simple but powerful: **a dense transformation does not have to be parameterized as a dense matrix**. By composing many small sparse orthogonal transformations in a butterfly pattern, BOFT creates an efficient update that remains expressive, stable, and easy to apply across different foundation models.

If you like the elegance of FFT-style algorithms, BOFT is a great example of that mindset applied to modern AI finetuning: use structure, exploit sparsity, and let a clever factorization do the heavy lifting.
