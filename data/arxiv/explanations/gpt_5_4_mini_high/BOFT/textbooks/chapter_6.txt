\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 6: BOFT: Orthogonal Butterfly Finetuning

# Making each butterfly component orthogonal

BOFT begins with a simple but important requirement: if the finetuning transform is built from several factors, then each factor must itself be orthogonal so that their product remains orthogonal. The paper starts from the butterfly matrix viewpoint and then turns it into an orthogonal parameterization. In the scalar setting, a butterfly factor is written as
\[
\bm{B}^F(k)=
\begin{bmatrix}
\mathrm{diag}(\bm d_1) & \mathrm{diag}(\bm d_2)\\
\mathrm{diag}(\bm d_3) & \mathrm{diag}(\bm d_4)
\end{bmatrix}\in \mathbb{R}^{k\times k},
\]
where each $\bm d_i\in\mathbb{R}^{k/2}$. A larger butterfly matrix is then assembled recursively from these factors. The key intuition is that the butterfly construction does not try to make a single large dense orthogonal matrix directly. Instead, it builds the matrix from a sequence of structured pieces whose sparsity patterns are arranged so that information can pass through the whole space in stages.

This staged construction is what makes orthogonal factorization feasible. The paper defines the full butterfly matrix recursively as a product of butterfly components, and then requires each multiplicative component to be orthogonal. Once that is true, the final product is orthogonal automatically. In other words, BOFT turns a difficult global constraint into a collection of local constraints. Rather than searching over all dense orthogonal matrices, it searches over products of sparse orthogonal matrices whose patterns are carefully chosen to compose into a much richer transform.

# Orthogonal $2 \times 2$ rotations and their blockwise generalization

The smallest nontrivial butterfly unit is a $2 \times 2$ orthogonal transform. In the paper, this can be realized either as a $2$-dimensional rotation or through the Cayley parameterization. This matters because a $2 \times 2$ orthogonal block is the atomic unit from which the larger butterfly structure is built. Once the smallest stage is orthogonal, the higher stages can be viewed as rearrangements and repetitions of the same local orthogonal mixing pattern.

BOFT then generalizes this idea from scalar entries to blocks. In the block butterfly setting, each scalar entry in the butterfly factor is replaced by a $b \times b$ matrix, so the smallest orthogonal unit becomes a $2b \times 2b$ block matrix. The paper notes that the non-zero pattern of every butterfly component is a block-wise permutation of the pattern of the smallest component. That means the same orthogonality idea used for the base $2 \times 2$ stage can be lifted to the block setting: if the base block is orthogonal, then the larger components can be parameterized orthogonally as well.

# Using Cayley parameterization inside butterfly blocks

To keep each component orthogonal during optimization, BOFT uses the Cayley parameterization. The paper writes an orthogonal matrix as
\[
\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1},
\]
where $\bm{Q}$ is skew-symmetric, meaning $\bm{Q}=-\bm{Q}^\top$. This is a useful device because orthogonality is enforced by construction rather than by an external constraint or projection step. As the parameters change, the resulting matrix stays on the orthogonal manifold.

BOFT initializes these Cayley parameters at zero, which means $\bm{Q}=\bm{0}$ at the start. Then $\bm{R}=\bm{I}$, so the finetuned model initially matches the pretrained model exactly. This identity initialization is important because it gives a clean starting point for finetuning: BOFT does not perturb the pretrained network at the beginning, but instead learns a gradual orthogonal deviation from it. Within each butterfly block, the Cayley transform provides the orthogonal parameterization that makes this possible.

# Constructing the final BOFT transform $\bm{R}(m,b)$

The full BOFT transform is a product of multiple orthogonal butterfly components. The paper writes this as
\[
\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)},
\]
where each $\tilde{\bm{B}}^b_{(d,i)}$ is an orthogonal butterfly component. The notation $\tilde{\bm{B}}^b_{(d,i)}$ is a shorthand for the stage-$i$ butterfly factor at dimension $d$ and block size $b$. Because each factor is orthogonal, their product is orthogonal as well. So $\bm{R}(m,b)$ stays inside the orthogonal group while still being built from sparse pieces.

The role of the two main design parameters is easy to interpret. The number of factors $m$ controls how many rounds of butterfly mixing are applied, while the block size $b$ controls the local granularity of each factor. Smaller blocks mean more sparsity and fewer parameters per factor; more factors mean more opportunities for information to travel across the full dimension. BOFT is therefore not just a single matrix form, but a family of orthogonal transforms indexed by how deep and how coarse the butterfly decomposition is.

# The BOFT forward pass for a pretrained linear layer

BOFT is inserted into a pretrained linear layer by left-multiplying the pretrained weight matrix with the orthogonal transform. If the pretrained layer is $\bm{W}^0\in\mathbb{R}^{d\times n}$, then the original forward pass is
\[
\bm{z}=(\bm{W}^0)^\top \bm{x},
\]
for input $\bm{x}\in\mathbb{R}^d$. BOFT changes this to
\[
\bm{z}=\big(\bm{R}(m,b)\bm{W}^0\big)^\top \bm{x}.
\]
So instead of adding a separate adapter or a low-rank correction, BOFT reparameterizes the existing weight matrix by an orthogonal transformation.

This is a layer-shared update: the same orthogonal matrix is applied to all neurons in the layer, and the paper emphasizes that a neuron corresponds to a column vector of $\bm{W}^0$. The motivation is to preserve the geometric relations among neurons, especially their pairwise angles, while still allowing the model to adapt to a downstream task. In this sense, BOFT is a multiplicative finetuning method: it changes the weight matrix by composing it with an orthogonal factor rather than by adding a new module.

# Notation for $b$, $m$, and BOFT variants

The paper uses BOFT$(m,b)$ to denote the method with $m$ butterfly factors and block size $b$. The corresponding orthogonal transform is $\bm{R}(m,b)$. When the authors refer to a specific factor, they write $\tilde{\bm{B}}^b_{(d,i)}$, which indicates the $i$-th orthogonal butterfly component at dimension $d$ with block size $b$. This notation is designed to make the structure of the factorization explicit: one can read off both the depth of the butterfly composition and the local block structure of each stage.

This notation also helps track how BOFT interpolates between different orthogonal parameterizations. At one extreme, the model has only one factor and behaves like a block-diagonal orthogonal update. At the other extreme, sufficiently many butterfly stages can produce a dense orthogonal transform. The parameters $m$ and $b$ therefore control the position of BOFT along a spectrum between simplicity and expressivity.

# Special case: BOFT with one factor equals block-diagonal OFT

If $m=1$, BOFT reduces to a single orthogonal butterfly component. In the paper, this is exactly the block-diagonal OFT form with block size $b$. So the shallowest BOFT is not a separate method from OFT; it is the block-diagonal OFT parameterization already used there. This is one reason the paper presents BOFT as a general framework rather than a completely unrelated design.

This special case is important conceptually because it shows that BOFT strictly contains the earlier block-diagonal orthogonal finetuning approach. The butterfly structure is not replacing OFT’s orthogonal update; it is extending it. When $m=1$, the structure is still sparse and block-separated, but the broader BOFT formalism already describes it.

# Special case: one full block equals unconstrained OFT

If $m=1$ and the block size is set to $b=d$, then the block-diagonal restriction disappears because the entire matrix is a single block. In that case, BOFT becomes the original OFT with a full dense orthogonal matrix. The paper explicitly identifies this as another special case of its framework.

This limit is useful because it shows that BOFT is not tied to block sparsity. The same notation can represent a fully dense orthogonal update when the block size is large enough, while also representing a sparse block-diagonal update when the block size is small. So BOFT spans both the low-parameter and high-expressivity ends of the orthogonal finetuning spectrum within one unified construction.

# Special case: enough butterfly factors yields a dense orthogonal matrix

The main advantage of the butterfly construction is that it can produce a dense orthogonal matrix without needing a full $\mathcal{O}(d^2)$ parameterization. The paper states that BOFT with enough factors, specifically BOFT$\big(\log \frac{2d}{b}, b\big)$, uses the block butterfly matrix $\bm{B}^{b/2}(d)$ as $\bm{R}$ and yields a dense orthogonal matrix. In the pure butterfly setting, taking $m=\log d$ and $b=2$ gives the classic butterfly depth.

The intuition is that each butterfly stage exchanges information across a larger scale. Early stages mix nearby coordinates, later stages mix progressively farther-apart coordinates, and after enough stages every coordinate can influence every other coordinate. This is the same basic logic that makes the Cooley-Tukey fast Fourier transform efficient: local interactions, repeated recursively, can create global mixing. BOFT borrows this structure to get dense orthogonal behavior from sparse orthogonal factors.

# Effective parameter count and why BOFT scales as $\mathcal{O}(d \log d)$

The paper summarizes the effective trainable parameter count of BOFT$(m,b)$ for a linear layer of size $d \times n$ as
\[
\frac{1}{2}(b-1)dm.
\]
This is the key efficiency statement behind the method. The count is far smaller than the $\mathcal{O}(d^2)$ parameters needed for a full dense orthogonal matrix in original OFT. It is also more flexible than a plain block-diagonal scheme because the butterfly structure can achieve dense connectivity with only logarithmically many factors.

In the pure butterfly case, where $m=\log d$ and $b=2$, the scaling becomes $\mathcal{O}(d\log d)$. The paper contrasts this with the original OFT and with block-diagonal OFT, emphasizing that BOFT gets a much better tradeoff between expressivity and parameter efficiency. The important point is not just that there are fewer parameters, but that the parameters are organized in a way that still allows dense orthogonal mixing when enough factors are stacked.

# How BOFT generalizes OFT into a broader orthogonal finetuning framework

BOFT generalizes OFT by replacing a single orthogonal update with a structured product of orthogonal butterfly factors. This gives a larger family of admissible transforms while preserving the core OFT principle: the finetuning update should remain orthogonal so that the geometry of the pretrained representation is not arbitrarily distorted. In the paper’s framing, BOFT creates a smoother interpolation between regularity and expressivity than the block-diagonal structure alone.

This broader framework is the real conceptual contribution of BOFT. The block-diagonal structure of OFT reduces parameters, but it also hard-codes a fixed sparsity pattern that the paper argues is limiting. BOFT instead uses butterfly factorization, which can recover many classic fast linear transforms and can also represent dense orthogonal matrices. As a result, BOFT acts like a structured subset of the orthogonal group: it is restrictive enough to provide an inductive bias, but flexible enough to include OFT as a special case and to move beyond it when the downstream task needs more expressive power.
