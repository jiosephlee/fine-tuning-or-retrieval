\title{Stack Exchange of the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

### Why does LongRoPE allow $\lambda_i > s$ if PI already uses $\lambda = s$ to fit the new context window?
Question:
In the search space, the paper allows each $\lambda_i$ to range from $1.0$ up to $1.25s$, where $s = \frac{L'}{L}$ is the target extension ratio.

This confused me. My naive understanding was that PI uses $\lambda = s$ so that positions from $[0, L')$ get compressed into roughly the original range $[0, L)$. If some dimensions use $\lambda_i > s$, then those dimensions are being compressed even more than PI.

Wouldn't that make the positional information even more crowded and therefore worse? What benefit is there in searching beyond $s$ at all?

Is the idea that some low-frequency dimensions can afford to lose resolution if that helps preserve other dimensions?
Answer:
Yes — that is essentially the point, but with an important nuance.

In PI, all RoPE dimensions use the same scale $\lambda = s = L'/L$, so every frequency band is compressed uniformly. LongRoPE does **not** assume that this uniform choice is optimal. Instead, it treats each RoPE dimension as having different importance and different sensitivity to interpolation, and it searches for the best $\lambda_i$ per dimension, with the constraint $\lambda_i \le \lambda_{i+1}$ to reflect the usual NTK intuition that lower-frequency dimensions can tolerate more interpolation than higher-frequency ones.

That is why the search range goes up to $1.25s$. The paper is not claiming that “more than PI” is inherently better. It is simply leaving room for the optimizer to explore solutions where some dimensions are compressed more than PI if that improves the overall embedding geometry. This can make sense because RoPE dimensions are not equally informative: some carry fine local position differences, while others are coarser and can afford to lose more resolution. The paper explicitly says that positional embeddings have “complex non-uniform information entropy,” and its search is meant to exploit that non-uniformity rather than force every dimension to behave like PI.

So the right intuition is indeed close to what you suggested: some dimensions can be “spent” more aggressively if that helps preserve the dimensions and token positions that matter more. The crucial point is that the objective is not to make every coordinate as un-crowded as possible; it is to minimize perplexity of the whole model. A slightly larger-than-$s$ scale in some low-sensitivity dimensions can be part of a better global tradeoff, even though a uniform $\lambda > s$ would usually be worse.

In other words, PI is just one special case of the broader search space. LongRoPE allows $\lambda_i > s$ because the best long-context solution is not necessarily “compress everything exactly by $s$,” but “allocate interpolation non-uniformly across dimensions and positions so the model loses as little useful positional information as possible.”
