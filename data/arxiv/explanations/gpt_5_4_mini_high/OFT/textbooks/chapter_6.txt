\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 6: Efficient Orthogonal Parameterization for Large Models

# Why Naive Orthogonalization Methods Are Too Expensive in Practice

Orthogonal Finetuning is built around a simple idea: instead of changing a pretrained layer arbitrarily, learn a transformation that preserves pairwise neuron angles. The challenge is that, for a large diffusion model, an orthogonal transformation must still be trainable at scale. A direct approach would be to optimize a dense matrix and then enforce orthogonality with a standard procedure such as Gram-Schmidt. The paper notes that although such orthogonalization methods are differentiable, they are often too expensive to use in practice.

The underlying issue is that a large layer already contains many parameters, and an unconstrained orthogonal matrix of size $d \times d$ still has substantial complexity. OFT therefore needs a parameterization that does two things at once: it must guarantee orthogonality by construction, and it must do so with a manageable number of trainable parameters. This is the motivation for using a skew-symmetric parameterization together with the Cayley transform, and then further reducing the burden with a block-diagonal structure.

# Skew-Symmetric Matrices and Their Role in Parameterizing Orthogonal Transforms

The paper introduces a skew-symmetric matrix $\bm{Q}$ as the actual learnable object behind the orthogonal transform. A matrix is skew-symmetric when it satisfies $\bm{Q} = -\bm{Q}^\top$. Instead of learning the orthogonal matrix $\bm{R}$ directly, OFT learns $\bm{Q}$ and maps it into an orthogonal matrix through a deterministic transformation.

This matters because the orthogonality requirement is built into the parameterization rather than enforced after the fact. In other words, the optimization happens over $\bm{Q}$, but the resulting transformation automatically satisfies the constraint $\bm{R}^\top \bm{R} = \bm{R}\bm{R}^\top = \bm{I}$. The paper also points out that identity initialization is straightforward: if $\bm{Q}$ is initialized to the zero matrix, then the resulting transform starts from the identity, so the finetuned model begins exactly at the pretrained weights.

# The Cayley Transform $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$

The key mechanism used by OFT is the Cayley transform,
\[
\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1},
\]
where $\bm{Q}$ is skew-symmetric. This transform converts the learned skew-symmetric matrix into an orthogonal matrix. The paper uses this to define the finetuned weight matrix as
\[
\bm{W} = \bm{R}\bm{W}^0,
\]
so the pretrained layer is not replaced, but transformed by a learned orthogonal map.

Intuitively, the Cayley transform is attractive because it allows OFT to optimize a relatively unconstrained matrix $\bm{Q}$ while guaranteeing the structural property OFT needs. The transform is also compatible with the paper’s finetuning philosophy: the pretrained model is preserved at initialization, and training then learns how to reorient the neuron space without breaking the orthogonal relation among neurons in the same layer.

# What the Cayley Transform Can and Cannot Represent

The paper is explicit about one limitation of the Cayley parameterization: it can only produce orthogonal matrices with determinant $1$. In the paper’s terminology, this means that it covers a restricted subset of orthogonal transforms, not the full set of all orthogonal matrices. Even so, the authors report that this restriction does not hurt performance in practice.

From a practical perspective, this limitation is acceptable because the goal is not to enumerate every possible orthogonal matrix. Instead, the goal is to find a transformation that is expressive enough to adapt the model while still protecting the pretrained structure. The paper also notes, in its concluding discussion, that the matrix inverse in the Cayley transform slightly limits scalability, which is part of why additional efficiency tricks are needed for large diffusion networks.

# Block-Diagonal Orthogonal Matrices for Parameter Reduction

To make OFT practical for large layers, the paper does not always use one dense orthogonal matrix. Instead, it proposes a block-diagonal form,
\[
\bm{R} = \mathrm{diag}(\bm{R}_1, \bm{R}_2, \ldots, \bm{R}_r),
\]
where each block $\bm{R}_i \in \mathrm{O}(d/r)$ is itself orthogonal. This means that the full transform is still orthogonal, but it is built from smaller orthogonal pieces. The transform remains able to reorient the layer, but it does so in a more structured and parameter-efficient way.

The main effect of the block-diagonal design is to reduce the number of free parameters. Rather than learning a full $d \times d$ orthogonal matrix at once, OFT learns several smaller orthogonal blocks. The paper emphasizes that this does not sacrifice the key property OFT cares about: because the full matrix is still orthogonal, the pairwise angles among neurons are preserved, and therefore the hyperspherical energy is preserved as well.

# The Block Count $r$ as a Trade-Off Between Flexibility and Efficiency

The number of blocks, $r$, controls how fine-grained the orthogonal transform is. When $r$ is small, each block is larger, so the transform has more flexibility but also more parameters. When $r$ is larger, each block is smaller, so the model becomes more parameter-efficient and more strongly regularized.

The paper frames this as an important regularization mechanism. A block-diagonal structure is not just a convenience for reducing memory; it also restricts the space of allowed transforms. This restriction can be helpful because it keeps the finetuned model closer to the pretrained geometry while still allowing enough freedom to adapt to a downstream task. In the paper’s terms, the block-diagonal parameterization is a stronger regularization of the orthogonal matrix.

In the extreme case $r = 1$, there is only a single block, so the parameterization reduces to an ordinary orthogonal matrix of size $d \times d$. As $r$ grows, the transform becomes more structured and more compact. The paper also notes that for convolution layers, the same idea has useful interpretations: different blocks can act on different channels, or the same block can be shared across channels.

# Optional Block Sharing and Its Effect on Parameter Complexity

The paper further proposes an optional block-sharing strategy, where the blocks are tied so that
\[
\bm{R}_i = \bm{R}_j \quad \forall i \neq j.
\]
This means that instead of learning $r$ distinct orthogonal blocks, the same block is reused across the diagonal structure. The transform remains orthogonal, but the number of distinct parameters drops even further.

This sharing is a stronger form of compression than the basic block-diagonal design. Since all blocks are identical, the model uses fewer degrees of freedom while still preserving the orthogonal structure. The paper states that this reduces the parameter complexity to $\mathcal{O}(d^2/r^2)$, compared with $\mathcal{O}(d^2/r)$ without sharing. In the context of OFT, this is another way to control the balance between efficiency and flexibility without giving up the core hyperspherical-energy preservation property.

# Parameter Counts and Asymptotic Complexity of OFT

The paper provides explicit parameter-count formulas to show why OFT is lightweight. A full orthogonal matrix of size $d \times d$ has $d(d-1)/2$ parameters, which gives a complexity of $\mathcal{O}(d^2)$. By contrast, an $r$-block diagonal orthogonal matrix has
\[
\frac{d(d/r - 1)}{2}
\]
parameters, which yields complexity $\mathcal{O}(d^2/r)$.

The paper also considers a scaling regime where the block count grows with the width, for example $r = \alpha d$ with $0 < \alpha \leq 1$. In that case, the block-diagonal OFT parameterization becomes $\mathcal{O}(d)$, which is much smaller than the cost of a dense orthogonal transform. If block sharing is used as well, the cost drops further to $\mathcal{O}(d^2/r^2)$.

The important point is that these reductions do not come at the expense of the orthogonality constraint. Regardless of whether the transform is dense, block-diagonal, or block-shared, the resulting matrix is still orthogonal, so the hyperspherical energy preservation property remains intact.

# A Concrete Comparison of OFT and LoRA Parameter Efficiency

The paper compares OFT to LoRA because LoRA is one of the most relevant parameter-efficient finetuning baselines. LoRA adds a low-rank update to a weight matrix, and its trainable parameter count is
\[
r'(d+n)
\]
for a weight matrix of size $d \times n$, where $r'$ is the LoRA rank. This is an additive update mechanism, whereas OFT uses a multiplicative orthogonal transform.

The paper argues that these two methods represent different kinds of efficiency. LoRA relies on a low-rank structure in the update itself, while OFT exploits the sparsity structure of a block-diagonal orthogonal matrix. If both methods use rank-like hyperparameters that scale with width, the paper notes that LoRA has complexity $\mathcal{O}(d^2 + dn)$, while OFT has complexity $\mathcal{O}(d)$. This makes OFT especially attractive when large layers need to be adapted without introducing a large number of new parameters.

The paper gives a concrete example with a $128 \times 128$ weight matrix. With $r' = 8$, LoRA uses $2{,}048$ trainable parameters. With $r = 8$ and no block sharing, OFT uses $960$ trainable parameters. This example makes the efficiency gain easy to see: OFT is not only structurally different from LoRA, but also more compact in this setting. Just as importantly, the orthogonal parameterization preserves the layer’s hyperspherical energy, which the paper argues is crucial for maintaining the pretrained generative ability of the diffusion model.

Together, these design choices make OFT practical for large diffusion networks: the Cayley transform guarantees orthogonality, the block-diagonal structure keeps the parameter count small, and the optional block-sharing variant pushes efficiency even further.
