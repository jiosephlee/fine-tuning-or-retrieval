\title{Stack Exchange of the Paper: "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits"}

### What exactly does the paper mean by "feature filtering" from the extra $0$ weight value?
Question:
One claimed advantage over the original binary BitNet is that ternary weights explicitly support "feature filtering" because a weight can be $0$. I am not sure how to interpret that. Does a zero weight act like a learned gate that suppresses certain input channels, or is it more like unstructured sparsity? Why would adding the option of $0$ improve modeling ability so much compared with forcing every connection to be either $-1$ or $1$?
Answer:
In the paper, “feature filtering” is best read in the ordinary linear-algebra sense: if a weight matrix entry can be $0$, then that particular input feature contributes nothing to that particular output feature. For a linear layer $y = Wx$, a ternary weight $w_{ji} \in \{-1,0,1\}$ means each output coordinate is a signed sum of some inputs, with some inputs simply omitted. That is different from binary weights $\{-1,1\}$, where every connection must either add or subtract the input, so nothing can be truly turned off.

So yes, it is essentially a learned “off” state for individual connections, but not a separate gate module or MoE-style router. It is closer to unstructured sparsity at the weight level: the model can decide that some input channels are irrelevant for some outputs and set those connections to zero. The paper’s phrase “feature filtering” is a high-level way of saying that the model can suppress features rather than only invert them.

Why does that help? Because ternary quantization gives the model a much larger and more flexible set of linear maps than binary quantization. With only $\{-1,1\}$, the model must approximate every full-precision weight by either positive or negative influence, even when the best approximation would be “almost no influence.” Allowing $0$ lets small or unimportant weights collapse to exactly zero instead of being forced to the wrong sign, which reduces quantization error and improves expressiveness. In practice, that extra degree of freedom matters a lot in large transformers, where many connections are weak or redundant.

So the short version is: the paper is not claiming some exotic new gating mechanism. It is saying that ternary weights can explicitly drop connections, which makes the quantized linear layers more selective and easier to train. That extra selectivity is what they call “feature filtering,” and it is one of the reasons BitNet b1.58 can match FP16 performance better than the original binary BitNet.
