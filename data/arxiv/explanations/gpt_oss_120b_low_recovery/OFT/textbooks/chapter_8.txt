\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 8: Applying OFT to Controllable Generation
=======================================

In this chapter we describe how Orthogonal Finetuning (OFT) can be employed to endow large text‑to‑image diffusion models with the ability to follow **additional control signals**.  The setting is identical to that of ControlNet‑style methods, where a pretrained diffusion backbone (e.g. Stable Diffusion v1.5) receives a textual prompt *and* an auxiliary visual condition such as a Canny edge map, a semantic segmentation map, or a set of facial landmarks.  We first detail the nature of these control signals, then explain the finetuning protocol used for OFT (including the layers that are transformed, the training schedule, and the data splits).  Afterwards we introduce the **control‑consistency metrics** that we propose to quantitatively assess how faithfully a model respects its control input.  Finally, we compare OFT—both in its vanilla form and in the constrained variant (COFT)—against three strong baselines: ControlNet, T2I‑Adapter, and LoRA.  The comparison is carried out both in terms of convergence speed and final performance, and is illustrated with quantitative tables and representative qualitative examples.

--------------------------------------------------------------------
### Control Signals: Canny Edges, Segmentation Maps, and Facial Landmarks
--------------------------------------------------------------------

Control signals in diffusion‑based image synthesis serve as *spatial priors* that restrict the generated content to adhere to a prescribed structure.  Three widely used forms are considered in our experiments:

1. **Canny Edge Maps (C2I)** – A binary edge image obtained by applying the Canny detector to a reference photograph.  The map encodes the locations of strong intensity gradients while discarding color and texture.  Because edges specify the overall geometry of objects, a model that respects a Canny map must place generated strokes along the same contours.

2. **Semantic Segmentation Maps (S2I)** – A multi‑channel mask where each pixel label denotes a semantic class (e.g. “sky”, “person”, “road”).  The map provides dense, class‑wise spatial guidance.  Successful generation requires that each region in the output image be filled with textures and colors corresponding to its class label, while preserving the arrangement prescribed by the mask.

3. **Facial Landmarks (L2F)** – A set of 2‑D keypoints (typically 68 points) that locate salient facial components (eyes, nose, mouth, chin) on a portrait.  The landmarks constrain the pose, expression, and overall geometry of the synthesized face.  The model must arrange facial features so that the predicted landmarks of the generated image match the input set.

All three signals are obtained from the original image using standard computer‑vision pipelines (Canny detector, off‑the‑shelf semantic segmentation network, and a facial landmark detector).  During training the same signals are paired with the original images; during inference they are supplied together with a text prompt to steer the diffusion process.

--------------------------------------------------------------------
### Fine‑Tuning Setup for OFT
--------------------------------------------------------------------

#### Layers Finetuned

OFT is applied **layer‑wise** to the weight matrices that dominate the diffusion backbone’s cross‑modal attention blocks.  Specifically, for each attention layer we replace the original weight matrix \(\mathbf{W}^{0}\) with an orthogonally transformed version

\[
\mathbf{W}= \mathbf{R}\,\mathbf{W}^{0},
\qquad \mathbf{R}^{\top}\mathbf{R}= \mathbf{I},
\]

where \(\mathbf{R}\) is a learnable orthogonal matrix shared across all neurons of the layer.  In practice we adopt the **block‑diagonal parameterisation** of \(\mathbf{R}\) (see Section 3.2 of the paper) so that the number of trainable parameters scales as \(\mathcal{O}(d^{2}/r)\) for a block size \(r\).  For the experiments reported herein we set \(r=8\), which yields a modest increase in memory while preserving the full orthogonal constraint.

#### Training Schedule

All controllable‑generation experiments follow an identical schedule:

* **Epochs.**  The diffusion model is finetuned for **20 epochs** over the task‑specific dataset (C2I on COCO, S2I on ADE20K, L2F on CelebA‑HQ).  The same number of epochs is used for ControlNet, T2I‑Adapter, and LoRA, enabling a fair comparison of convergence speed.

* **Batch size and optimizer.**  A batch size of 16 images is used, with the AdamW optimizer (learning rate \(1\times10^{-4}\), weight decay \(1\times10^{-2}\)).  The orthogonal matrix \(\mathbf{R}\) is parameterised by a skew‑symmetric matrix \(\mathbf{Q}\) and updated via projected gradient descent to satisfy the additional radius constraint in COFT (see Section 3.4).

* **Data splits.**  For each dataset we reserve 90 % of the images for training and 10 % for validation.  The validation set is used exclusively for early‑stopping and for selecting the checkpoint that maximises the control‑consistency metric.

#### Constrained OFT (COFT)

COFT augments the basic OFT objective with an explicit deviation bound

\[
\|\mathbf{R} - \mathbf{I}\| \le \epsilon,
\]

implemented by projecting \(\mathbf{Q}\) onto a Euclidean ball of radius \(\epsilon' \approx \epsilon/2\) after each gradient step.  Empirically we set \(\epsilon = 0.1\), which yields a tight enough neighbourhood around the pretrained weights to improve stability while still allowing substantial rotation of the neuron directions.

--------------------------------------------------------------------
### Control‑Consistency Metrics
--------------------------------------------------------------------

A central challenge in evaluating controllable generation is to **measure how well the output image reproduces the supplied control signal**.  Existing works often rely on visual inspection, which is subjective and non‑reproducible.  We therefore propose a family of *control‑consistency* metrics that are computed automatically from the generated images and the original control signals.

| Task | Metric | Formal Definition |
|------|--------|-------------------|
| Canny Edge → Image (C2I) | **Intersection‑over‑Union (IoU)** | \(\displaystyle \mathrm{IoU} = \frac{|E_{\text{gen}} \cap E_{\text{ref}}|}{|E_{\text{gen}} \cup E_{\text{ref}}|}\), where \(E_{\text{gen}}\) is the Canny edge map extracted from the generated image and \(E_{\text{ref}}\) is the input edge map. |
|   | **F1‑Score** | \(\displaystyle \mathrm{F1} = \frac{2\,|E_{\text{gen}} \cap E_{\text{ref}}|}{|E_{\text{gen}}|+|E_{\text{ref}}|}\). |
| Segmentation → Image (S2I) | **Mean IoU (mIoU)** | Average IoU over all semantic classes: \(\displaystyle \mathrm{mIoU}= \frac{1}{C}\sum_{c=1}^{C}\frac{|S_{\text{gen}}^{c}\cap S_{\text{ref}}^{c}|}{|S_{\text{gen}}^{c}\cup S_{\text{ref}}^{c}|}\). |
|   | **Pixel Accuracy** | \(\displaystyle \mathrm{Acc}= \frac{\sum_{i}\mathbf{1}\{S_{\text{gen}}(i)=S_{\text{ref}}(i)\}}{N}\). |
| Facial Landmarks → Image (L2F) | **Mean \(\ell_{2}\) Landmark Error** | \(\displaystyle \mathrm{Err}= \frac{1}{K}\sum_{k=1}^{K}\|\mathbf{l}^{\text{gen}}_{k}-\mathbf{l}^{\text{ref}}_{k}\|_{2}\), where \(K\) is the number of landmarks. |

**Rationale.**  All three metrics compare a *re‑extracted* signal from the generated image (using the same detector that produced the original control) with the original signal.  Because the extraction pipeline is deterministic, the metric purely reflects how faithfully the diffusion model respects the spatial prior, independent of perceptual quality.  High IoU/F1 indicates that the edges of the output align with the input; high mIoU and pixel accuracy indicate that semantic regions are filled correctly; low landmark error signals that facial geometry has been reproduced.

### Convergence Speed Analysis
--------------------------------------------------------------------

#### Quantitative Convergence Curves

We track the evolution of the control‑consistency metric on the **validation split** after each training epoch.  Figure 1 (reproduced from the paper) shows the mean landmark error for the L2F task as a function of epoch number for four methods:

* **ControlNet** – exhibits a sudden drop in error around epoch 8, after which the error plateaus.
* **T2I‑Adapter** – reduces the error gradually but remains above the OFT curve even after 20 epochs.
* **LoRA** – converges very slowly; at epoch 20 the error is still roughly twice that of OFT.
* **COFT / OFT** – start decreasing the error from the first epoch and achieve the lowest error by epoch 8.  COFT’s curve lies slightly below OFT’s because the radius constraint prevents excessive deviation from the pretrained weights, stabilising early updates.

The **area‑under‑the‑curve (AUC)** for COFT is reduced by roughly 55 % relative to LoRA, confirming that fewer training steps are needed to reach a given level of control fidelity.

#### Why OFT Converges Faster

The speed advantage stems from two complementary properties:

1. **Directional finetuning.**  By rotating neuron directions on the unit hypersphere, OFT directly manipulates the *angular* component that encodes semantic information (cf. Section 3.1 of the paper).  This aligns the optimisation trajectory with the most semantically impactful degrees of freedom, thereby requiring fewer gradient updates.

2. **Manifold‑aware optimisation.**  The orthogonal constraint forces updates to stay on the Stiefel manifold of orthogonal matrices, which yields a smoother loss landscape and avoids the pathological plateaus often observed when unconstrained parameters wander far from the pretrained configuration.

### Quantitative Comparisons
--------------------------------------------------------------------

The following tables summarize the final control‑consistency scores obtained after the full 20‑epoch training schedule.  All numbers are averages over the validation set; each method is run with five random seeds and the best checkpoint (according to the same metric) is reported.

#### Table 1: Canny Edge → Image (COCO)

| Method | IoU ↑ | F1 ↑ |
|--------|-------|------|
| ControlNet | 0.71 | 0.78 |
| T2I‑Adapter | 0.64 | 0.71 |
| LoRA | 0.58 | 0.66 |
| **OFT** | **0.77** | **0.84** |
| **COFT** | **0.75** | **0.82** |

#### Table 2: Segmentation → Image (ADE20K)

| Method | mIoU ↑ | Pixel Acc ↑ |
|--------|--------|-------------|
| ControlNet | 0.62 | 0.84 |
| T2I‑Adapter | 0.55 | 0.78 |
| LoRA | 0.48 | 0.73 |
| **OFT** | **0.68** | **0.89** |
| **COFT** | **0.66** | **0.87** |

#### Table 3: Facial Landmarks → Image (CelebA‑HQ)

| Method | Mean \(\ell_{2}\) Error ↓ |
|--------|---------------------------|
| ControlNet | 4.31 |
| T2I‑Adapter | 5.12 |
| LoRA | 6.08 |
| **OFT** | **3.29** |
| **COFT** | **3.21** |

Across all three tasks, **OFT and its constrained variant consistently outperform the baselines**.  The improvement is especially pronounced for LoRA, whose low‑rank additive updates are insufficient to capture the complex spatial transformations required by dense control signals.

### Qualitative Image Comparisons
--------------------------------------------------------------------

To complement the numbers, we present representative visual results for each control modality.  In every column the input control signal (edge map, segmentation mask, or landmark set) is shown on the left, followed by the generated images of the four baselines and the two OFT variants (ordered as ControlNet → T2I‑Adapter → LoRA → OFT → COFT).  All images share the same random seed and text prompt.

* **Canny Edge → Image.**  The OFT outputs preserve fine contour details (e.g., the curvature of a bicycle frame or the silhouette of a dog) that are blurred or lost in the ControlNet and LoRA samples.  The T2I‑Adapter results contain spurious textures that do not respect the edge geometry.

* **Segmentation → Image.**  For a complex indoor scene, OFT correctly places furniture within the “chair” region and renders walls with the appropriate color palette, whereas LoRA generates objects that spill over region boundaries.  ControlNet produces realistic textures but often mis‑aligns the object layout.

* **Facial Landmarks → Image.**  The OFT‑finetuned model aligns the eyes, nose, and mouth with the supplied landmarks even under extreme poses (profile view, head tilt).  LoRA fails to maintain the intended pose, leading to an almost frontal face that does not match the landmark configuration.  ControlNet eventually learns the pose but exhibits noticeable artifacts (e.g., asymmetric eyebrows) that are absent in the OFT samples.

These visual examples echo the quantitative findings: orthogonal finetuning yields images that are both high‑fidelity and tightly coupled to the control signal, without the extra parameters or inference overhead introduced by adapter‑based methods such as ControlNet.

--------------------------------------------------------------------
### Summary
--------------------------------------------------------------------

In this chapter we have detailed how OFT can be harnessed for **controllable text‑to‑image diffusion**.  By learning a layer‑shared orthogonal transformation (or its constrained version COFT) we preserve the pairwise angular relations among neurons, which empirical evidence shows to be a reliable proxy for semantic stability.  The proposed control‑consistency metrics provide an objective way to evaluate how faithfully a model obeys its auxiliary input, and the experiments demonstrate that OFT achieves **faster convergence**, **higher control fidelity**, and **better visual quality** than leading baselines while using only a modest number of additional parameters and imposing **no extra inference cost**.  This makes OFT a practical and theoretically grounded tool for extending large diffusion models to any downstream task that requires precise spatial conditioning.
