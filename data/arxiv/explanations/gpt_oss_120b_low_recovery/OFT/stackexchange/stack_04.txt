\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### What is the role of the block‑diagonal structure in the orthogonal matrix and how does it affect parameter count?
Question:
The paper introduces a block‑diagonal orthogonal matrix \(\mathbf{R}=\text{diag}(\mathbf{R}_1, …, \mathbf{R}_r)\). I am trying to understand:
- How does partitioning \(d\) dimensions into \(r\) blocks reduce the number of trainable parameters from \(d(d-1)/2\) to roughly \(d(d/r-1)/2\)?
- What are the trade‑offs between using more blocks (smaller blocks) versus sharing the same block across all positions?
- Does this block structure impose any unwanted bias on how neurons are transformed (e.g., limiting cross‑channel interactions in convolutional layers)?
Answer:
**Answer**

In OFT the only trainable component of a layer is an orthogonal matrix  

\[
\mathbf R=\operatorname{diag}(\mathbf R_{1},\dots ,\mathbf R_{r})\in\mathbb R^{d\times d},
\qquad 
\mathbf R_i\in O\!\left(\frac{d}{r}\right),
\]

which multiplies the pretrained weight matrix $\mathbf W^{0}$ (Eq. (4) of the paper).  
Because $\mathbf R$ is orthogonal, the pair‑wise angles between the rows (or columns) of $\mathbf W^{0}$ – i.e. the hyperspherical energy – are preserved, which is exactly the desideratum of OFT.

---

### Why a block‑diagonal $\mathbf R$ reduces parameters  

A full $d\times d$ orthogonal matrix lives on the Stiefel manifold $O(d)$ and can be described by $\frac{d(d-1)}{2}$ independent entries (the number of degrees of freedom of a rotation).  
If we force $\mathbf R$ to be block‑diagonal with $r$ identical blocks, each block is an orthogonal matrix of size $\frac{d}{r}\times \frac{d}{r}$.  
Each block therefore needs  

\[
\frac{\frac{d}{r}\Bigl(\frac{d}{r}-1\Bigr)}{2}
   =\frac{d(d/r-1)}{2}
\]

free parameters, and with *$r$ independent blocks* the total becomes  

\[
r\cdot \frac{d(d/r-1)}{2}= \frac{d(d-r)}{2},
\]

which is roughly $\frac{1}{r}$ of the full count when $r\ll d$.  
If we **share** the same block across all positions ($\mathbf R_{1}=\dots =\mathbf R_{r}$), we keep only one block, i.e.  

\[
\frac{d(d/r-1)}{2}=O(d^{2}/r)
\]

parameters.  This is precisely the “$\displaystyle d(d/r-1)/2$” term reported in the paper.

---

### Trade‑offs: many small blocks vs. a single shared block  

| Situation | Parameter budget | Flexibility of transformation | Inductive bias |
|-----------|-----------------|--------------------------------|----------------|
| **Many independent blocks** (large $r$) | $O(d^{2}/r)$ (still smaller than full) | Each sub‑space of dimension $d/r$ can rotate independently, so the overall transformation can approximate a richer set of orthogonal maps. | No explicit coupling between different channel groups; still respects orthogonality inside each group. |
| **One shared block** (small $r=1$ or sharing across blocks) | $O(d^{2}/r^{2})$ – dramatically fewer parameters | All dimensions are rotated by exactly the same matrix; only global rotations/reflections are possible. | Strong bias toward *depth‑wise* style transformations: each channel (or a small group of channels) is transformed in the same way. This can be beneficial when channels are expected to behave similarly (e.g. in depth‑wise convolutions) but limits the ability to mix information across channel groups. |

Thus, increasing $r$ (more blocks) gives you more expressive power at the cost of more parameters; decreasing $r$ or sharing blocks makes the model cheaper but introduces a structural bias that all groups must share a common rotation.

---

### Does the block structure hurt cross‑channel interaction?  

In a convolutional layer the weight tensor can be reshaped to a matrix whose rows correspond to **output channels** and whose columns correspond to the flattened receptive field (input‑channel × kernel‑size).  
Multiplying this matrix on the left by a block‑diagonal $\mathbf R$

* **If each block aligns with an output‑channel group**, only neurons inside the same group are mixed; channels belonging to different blocks never see each other’s directions. This indeed restricts cross‑channel communication compared with a dense orthogonal matrix.
* **If we share a single block across all groups**, every output channel is rotated by exactly the same orthogonal transformation, which preserves *relative* angles between any pair of channels but does not create new inter‑channel mixing beyond a global rotation.

The authors point out that this bias is analogous to depth‑wise convolutions: each block behaves like an independent linear map applied to a subset of channels. Empirically they observe that even with such restrictions OFT still improves finetuning stability and sample quality, likely because the most important semantic information resides in *directions* rather than in arbitrary mixing of channels. When finer cross‑channel interaction is needed one can simply increase $r$ (more, smaller blocks) or drop the sharing constraint, which restores some mixing while keeping parameter count far below that of a full orthogonal matrix.

---

### Summary  

* The full orthogonal group $O(d)$ has $\tfrac{d(d-1)}{2}$ degrees of freedom. By constraining $\mathbf R$ to be block‑diagonal with blocks of size $d/r$, each block contributes only $\tfrac{(d/r)(d/r-1)}{2}$ degrees, giving an overall parameter count of roughly $\tfrac{d(d/r-1)}{2}$; sharing blocks reduces it further to $O(d^{2}/r^{2})$.
* More blocks → more expressive rotations but higher cost; sharing blocks → extreme parameter efficiency but imposes a strong prior that all channel groups rotate identically.
* The bias introduced by blocking limits interaction between distinct channel groups, which can be viewed as a depth‑wise constraint. In practice this bias does not hurt performance for text‑to‑image diffusion finetuning, and it can even act as regularisation that stabilises training.

Hence, choosing $r$ and whether to share blocks is a matter of balancing parameter budget against desired flexibility; the paper shows that even modest values (e.g., $r=8$) already give a good trade‑off for large diffusion models.
