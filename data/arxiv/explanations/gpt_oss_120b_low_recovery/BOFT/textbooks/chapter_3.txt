\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: **Orthogonal Finetuning (OFT) Revisited**

# OFT Objective and Forward‑Pass Modification  

The central idea of Orthogonal Finetuning (OFT) is to adapt a pretrained linear transformation while preserving the geometric relations among its neurons.  Consider a frozen pretrained weight matrix  
\[
\mathbf{W}^{0}\in\mathbb{R}^{d\times n},
\]  
which maps an input vector \(\mathbf{x}\in\mathbb{R}^{d}\) to an output \(\mathbf{z}\in\mathbb{R}^{n}\) through the canonical forward computation  
\[
\mathbf{z}= (\mathbf{W}^{0})^{\!\top}\mathbf{x}. 
\]  
OFT replaces the original weight matrix by a left‑multiplication with a learnable orthogonal matrix \(\mathbf{R}\in\mathbb{R}^{d\times d}\).  The modified forward pass becomes  
\[
\mathbf{z}= (\mathbf{R}\mathbf{W}^{0})^{\!\top}\mathbf{x}
          = (\mathbf{W}^{0})^{\!\top}\mathbf{R}^{\!\top}\mathbf{x}.
\]  
Because \(\mathbf{R}\) is orthogonal \((\mathbf{R}^{\!\top}\mathbf{R}= \mathbf{I}_{d})\), the transformation preserves inner products and, consequently, the pair‑wise angles between the column vectors (neurons) of \(\mathbf{W}^{0}\).  Preserving these angles guarantees that the relational structure learned during pretraining is retained after finetuning, an inductive bias that often translates into better generalisation on downstream tasks.

To enforce orthogonality throughout training, OFT adopts the **Cayley parameterisation**.  Any skew‑symmetric matrix \(\mathbf{Q}\) (\(\mathbf{Q}=-\mathbf{Q}^{\!\top}\)) can be mapped to an orthogonal matrix via  
\[
\mathbf{R}= (\mathbf{I}+\mathbf{Q})(\mathbf{I}-\mathbf{Q})^{-1}.
\]  
Optimising over the free entries of \(\mathbf{Q}\) automatically guarantees that \(\mathbf{R}\) remains orthogonal for all optimisation steps.  This multiplicative update differs fundamentally from additive low‑rank schemes such as LoRA, which modify \(\mathbf{W}^{0}\) by adding a low‑rank matrix \(\Delta\mathbf{W}= \mathbf{A}\mathbf{B}^{\!\top}\).  While LoRA changes the absolute direction of each neuron, OFT rotates the entire subspace spanned by the neurons, keeping the spectrum of \(\mathbf{W}^{0}\) unchanged.

# Block‑Diagonal Orthogonal Matrices: Construction and Parameter Count  

A naïve implementation of OFT would allocate a full \(d\times d\) orthogonal matrix \(\mathbf{R}\).  Such a matrix contains \(\mathcal{O}(d^{2})\) free parameters, which defeats the purpose of parameter‑efficient finetuning.  The original OFT paper therefore introduced a **block‑diagonal orthogonal structure**.  

Let the dimension \(d\) be factored as \(d = b r\) where \(b\) denotes the block size and \(r\) the number of blocks.  The orthogonal matrix is then constrained to the form  
\[
\mathbf{R}= \operatorname{diag}\bigl(\mathbf{R}_{1},\mathbf{R}_{2},\dots ,\mathbf{R}_{r}\bigr),
\]  
where each block \(\mathbf{R}_{i}\in\mathbb{R}^{b\times b}\) is itself an orthogonal matrix, i.e. \(\mathbf{R}_{i}^{\!\top}\mathbf{R}_{i}= \mathbf{I}_{b}\).  The Cayley transform is applied independently to each block, requiring a skew‑symmetric matrix \(\mathbf{Q}_{i}\in\mathbb{R}^{b\times b}\) per block.  Because a skew‑symmetric \(b\times b\) matrix has \(\frac{b(b-1)}{2}\) independent entries, the total number of trainable parameters for the block‑diagonal OFT becomes  

\[
\underbrace{r}_{\text{blocks}}\times\underbrace{\frac{b(b-1)}{2}}_{\text{per‑block free entries}}
= \frac{d}{b}\,\frac{b(b-1)}{2}
= \frac{(b-1)d}{2}.
\]  

When the block size equals the full dimension (\(b=d\)), the parameter count recovers the dense case \(\frac{(d-1)d}{2}\).  Conversely, setting a small block size drastically reduces the number of trainable parameters, at the cost of imposing a rigid sparsity pattern on \(\mathbf{R}\).

# Zero‑Initialization via Identity and Training Dynamics  

A crucial practical aspect of OFT is the choice of initialization.  Since finetuning is intended to start from a model that already performs well on the pretraining task, the orthogonal matrix should begin as the identity transformation.  In the Cayley parameterisation this translates to initializing the skew‑symmetric matrix \(\mathbf{Q}\) (or each \(\mathbf{Q}_{i}\) in the block‑diagonal case) to the zero matrix.  Substituting \(\mathbf{Q}=\mathbf{0}\) yields  

\[
\mathbf{R}= (\mathbf{I}+\mathbf{0})(\mathbf{I}-\mathbf{0})^{-1}= \mathbf{I},
\]  

so the forward computation at the outset coincides exactly with the frozen pretrained linear layer.  During optimisation the entries of \(\mathbf{Q}\) evolve slowly, producing an orthogonal matrix that remains close to the identity for a substantial number of steps.  This **zero‑initialisation** confers two benefits:

1. **Stability** – By staying in the neighbourhood of the identity, the optimisation landscape is smoother and the risk of catastrophic drift from the pretrained representation is mitigated.  
2. **Regularisation** – The orthogonal matrix can be interpreted as a learned rotation of the latent space; starting from the identity enforces a prior that only modest rotations are needed, which is analogous to applying a small learning rate in conventional finetuning.

Empirically, OFT exhibits stable training dynamics, converging reliably even with relatively large learning rates on the skew‑symmetric parameters, a property that is not guaranteed for additive low‑rank methods which may introduce uncontrolled changes in the spectrum of the weight matrix.

# Empirical Advantages over Low‑Rank Methods (e.g., LoRA)  

In standard low‑rank finetuning such as LoRA, the update \(\Delta\mathbf{W}= \mathbf{A}\mathbf{B}^{\!\top}\) adds a matrix of rank \(r\) to the pretrained weights.  Although this reduces the number of trainable parameters to \(\mathcal{O}(rd)\), it fundamentally alters the singular value spectrum of \(\mathbf{W}^{0}\).  By contrast, OFT’s multiplicative orthogonal update preserves the **spectral norm** of \(\mathbf{W}^{0}\).  To see this, perform the singular value decomposition (SVD) of the pretrained weight matrix:  

\[
\mathbf{W}^{0}= \mathbf{U}\,\boldsymbol{\Sigma}\,\mathbf{V}^{\!\top},
\]  

with orthogonal \(\mathbf{U},\mathbf{V}\) and diagonal \(\boldsymbol{\Sigma}\).  The OFT‑updated weight becomes  

\[
\mathbf{R}\mathbf{W}^{0}= \mathbf{R}\mathbf{U}\,\boldsymbol{\Sigma}\,\mathbf{V}^{\!\top}.
\]  

Since \(\mathbf{R}\mathbf{U}\) is still orthogonal, the singular values of the product equal those of \(\boldsymbol{\Sigma}\); therefore the largest singular value (the spectral norm) is unchanged.  This preservation has been linked to improved **training stability** and **generalisation** in prior work on spectral regularisation.

Beyond spectral considerations, several empirical observations reported in the original OFT study highlight its advantages:

* **Faster convergence** – OFT reaches comparable downstream performance in fewer epochs than LoRA, indicating that the orthogonal constraint provides a more informative search direction.
* **Higher robustness to hyper‑parameter choices** – The method is less sensitive to the exact learning rate or rank hyper‑parameter, largely because the orthogonal manifold imposes a strong geometric regulariser.
* **Better performance on vision‑language tasks** – When applied to large vision transformers and text‑to‑image diffusion models, OFT consistently outperformed LoRA‑style low‑rank updates, especially in settings where preserving the pretrained relational structure is critical (e.g., controllable image generation).

These empirical strengths motivate a deeper examination of OFT’s expressivity, particularly when the block‑diagonal sparsity is introduced.

# Analysis of Expressivity Loss Due to Block Sparsity  

The block‑diagonal restriction simplifies the orthogonal matrix by forcing a **partition** of the hidden dimension into \(r\) independent subspaces of size \(b\).  Within each subspace, any orthogonal rotation is permissible, but **no interaction** is allowed between distinct blocks.  Mathematically, for any input vector \(\mathbf{x}\) split as \(\mathbf{x}= \bigl[\mathbf{x}_{1}^{\!\top},\dots ,\mathbf{x}_{r}^{\!\top}\bigr]^{\!\top}\) with \(\mathbf{x}_{i}\in\mathbb{R}^{b}\), the block‑diagonal \(\mathbf{R}\) yields  

\[
\mathbf{R}\mathbf{x}= \bigl[\mathbf{R}_{1}\mathbf{x}_{1}^{\!\top},\dots ,\mathbf{R}_{r}\mathbf{x}_{r}^{\!\top}\bigr]^{\!\top}.
\]  

Consequently, any linear combination that would require mixing components across different blocks cannot be represented.  This limitation manifests in several concrete ways:

1. **Reduced ability to capture cross‑channel correlations** – In convolutional or transformer layers, important information is often distributed across all channels.  A block‑diagonal rotation cannot align features that reside in different blocks, potentially leaving useful interactions untouched.
2. **Inability to emulate classic dense transforms** – Many useful linear operators (e.g., the full discrete Fourier transform) are dense and cannot be decomposed as a direct sum of independent small orthogonal matrices.  Hence, the block‑diagonal family cannot approximate such transforms regardless of the values within each block.
3. **Expressivity bound** – The set of block‑diagonal orthogonal matrices forms a strict subgroup of the full orthogonal group \(\mathcal{O}(d)\).  Its cardinality grows as \(\bigl|\mathcal{O}(b)\bigr|^{\,r}\) instead of \(\bigl|\mathcal{O}(d)\bigr|\).  When \(b\ll d\), the measure of this subgroup inside \(\mathcal{O}(d)\) shrinks exponentially, indicating a substantial loss of representational capacity.

Empirically, this expressivity loss is reflected in a performance gap between the dense OFT variant (full orthogonal matrix) and its block‑diagonal counterpart when the downstream task demands rich cross‑feature interactions.  Nevertheless, for many tasks the block‑diagonal version still outperforms LoRA, suggesting that even a limited set of rotations can provide a useful inductive bias while dramatically decreasing the parameter budget.

In summary, Orthogonal Finetuning introduces a principled way to adapt large pretrained models by learning a single orthogonal transformation per layer.  The method preserves angular relationships and spectral norms, enjoys stable training dynamics via identity initialization, and empirically outperforms low‑rank additive schemes.  However, the original block‑diagonal parameterisation, while parameter‑efficient, sacrifices expressivity because it blocks information flow across subspaces.  This insight motivates the development of more sophisticated factorizations—such as butterfly‑based parameterisations—that retain dense connectivity with far fewer parameters, a direction explored in subsequent chapters.
