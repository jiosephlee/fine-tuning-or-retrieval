\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### What is the purpose of the stabilizer state $m_t$ in sLSTM?
Question:
I'm reading the section on sLSTM and I see that they introduce exponential activation functions for the input and forget gates. The paper mentions that these can lead to overflows and introduces a stabilizer state $m_t$ defined as $m_t = \max ( \log ( f_t ) + m_{t-1} , \log ( i_t ) )$. I don't quite understand how subtracting $m_t$ from the log-gates in the stabilized versions $i'_t$ and $f'_t$ prevents overflow without changing the actual output of the network.
Answer:
The purpose of the stabilizer state $m_t$ in sLSTM is to prevent numerical overflow that occurs when using exponential activation functions for the input and forget gates. In a standard sLSTM, the gates are defined as $i_t = \exp(\tilde{i}_t)$ and $f_t = \exp(\tilde{f}_t)$. Because the exponential function grows extremely rapidly, even moderately large values of $\tilde{i}_t$ or $\tilde{f}_t$ can quickly exceed the maximum value representable by floating-point precision (e.g., float32), resulting in $\text{NaN}$ or $\text{Inf}$ values that crash the training process.

To solve this, $m_t$ acts as a running tracker of the maximum "log-scale" of the memory. This is conceptually very similar to the "Log-Sum-Exp" trick used to stabilize the softmax function. The state is updated as $m_t = \max(\log(f_t) + m_{t-1}, \log(i_t))$. By tracking the maximum of the current input gate and the accumulated forget gate history, $m_t$ identifies the largest exponent present in the cell state update. When we compute the stabilized gates $i'_t = \exp(\log(i_t) - m_t)$ and $f'_t = \exp(\log(f_t) + m_{t-1} - m_t)$, we are effectively subtracting the maximum value from the exponents. Since the exponent of any value $\le 0$ is guaranteed to be between 0 and 1, these stabilized gates are numerically bounded and cannot overflow.

The reason this does not change the actual output of the network lies in the normalization step. The sLSTM computes a hidden state $\tilde{h}_t = c_t / n_t$, where $c_t$ is the cell state and $n_t$ is the normalizer state. Both $c_t$ and $n_t$ are governed by the same exponential gates: $c_t = f_t c_{t-1} + i_t z_t$ and $n_t = f_t n_{t-1} + i_t$. By introducing $m_t$, we are essentially factoring out $\exp(m_t)$ from both the numerator ($c_t$) and the denominator ($n_t$). Because this common scaling factor $\exp(m_t)$ appears in both terms, it cancels out during the division $c_t / n_t$. Consequently, the final hidden state $\tilde{h}_t$ remains mathematically identical to what it would have been without stabilization, but the intermediate computations remain within a numerically safe range.
