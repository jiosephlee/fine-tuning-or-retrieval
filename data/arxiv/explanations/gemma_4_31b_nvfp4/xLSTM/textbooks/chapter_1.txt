Chapter 1: Introduction to Recurrent Architectures and the Original LSTM

# The Vanishing Gradient Problem in RNNs

Recurrent Neural Networks (RNNs) were designed to process sequential data by maintaining a hidden state that evolves over time. However, a fundamental challenge plagued these early architectures: the vanishing gradient problem. In standard RNNs, as the sequence length increases, the gradients used during backpropagation can shrink exponentially. This happens because the network repeatedly multiplies gradients by the weight matrices associated with the recurrent connections. When these weights are small, the gradient effectively vanishes before it can reach the earlier steps of the sequence.

The practical consequence of this phenomenon is that the network "forgets" information from the distant past. The model becomes unable to learn long-term dependencies, meaning it cannot correlate an input from the beginning of a long sentence with an output at the end. To address this failure, the Long Short-Term Memory (LSTM) was introduced. By changing how the network updates its internal state, LSTMs provide a mechanism that allows gradients to flow through time without disappearing, enabling the model to learn relationships across much longer sequences.

# The Constant Error Carousel (CEC) concept

The central innovation that allows LSTMs to overcome the vanishing gradient problem is the Constant Error Carousel (CEC). In a traditional RNN, the state update is typically multiplicative, which is the primary cause of gradient decay. The CEC replaces this with an additive update rule for the internal memory. Instead of the state being completely overwritten at each time step, the LSTM maintains a cell state that acts as a high-speed conveyor belt, allowing information to flow through the sequence with minimal interference.

The additive nature of the CEC is mathematically represented by the way the cell state $c_t$ is updated. By adding new information to the existing state rather than simply multiplying the old state by a weight matrix, the network creates a path where the error signal can remain constant. This "carousel" effect ensures that the gradient does not vanish as it propagates backward through time, allowing the model to maintain a stable memory of important events that occurred many time steps ago.

# The anatomy of a classic LSTM cell: Cell state and Hidden state

A classic LSTM cell is defined by two distinct states: the cell state and the hidden state. The cell state, denoted as $c_t$, serves as the primary internal memory. It is a scalar value (or a vector of scalars in multi-cell implementations) that stores the long-term information of the sequence. The cell state is modified incrementally via the CEC, meaning it only changes when the network explicitly decides to add or remove information.

The hidden state, denoted as $h_t$, is the external representation of the cell. While the cell state is the internal "storage," the hidden state is the "output" that is passed to the next layer or the next time step. The hidden state is derived from the cell state, but it is not a direct copy. Instead, the cell state is first passed through a normalization or squashing function $\psi$ and then filtered by an output gate. This separation ensures that the internal memory can remain complex and unbounded, while the output remains controlled and normalized.

# The role of Gating: Input, Forget, and Output gates

To manage the information flowing into and out of the cell state, LSTMs utilize a system of sigmoid gates. These gates act as valves that control the flow of information, allowing the network to decide what is worth remembering and what should be discarded.

The forget gate $f_t$ determines which information from the previous cell state $c_{t-1}$ is no longer relevant and should be removed. It produces a value between 0 and 1; a value near 0 means "forget this," while a value near 1 means "keep this." Following this, the input gate $i_t$ controls the addition of new information. It decides which parts of the new cell input $z_t$ are important enough to be stored in the cell state. The combined effect of these two gates results in the cell state update: $c_t = f_t c_{t-1} + i_t z_t$.

Finally, the output gate $o_t$ controls what information is extracted from the cell state to produce the hidden state $h_t$. Since the cell state $c_t$ contains all the accumulated memory, the output gate allows the model to selectively share only the specific information needed for the current time step. This gating mechanism allows the LSTM to be highly flexible, adjusting its memory dynamically based on the input sequence.

# Activation functions in LSTMs: Sigmoid and Tanh

The functionality of the LSTM depends heavily on its choice of activation functions. The gates—input, forget, and output—all use the sigmoid function, $\sigma(x) = 1 / (1 + \exp(-x))$. The sigmoid function is essential for gating because it squashes any input into a range between 0 and 1. This range is intuitively treated as a percentage of information allowed to pass through the gate, making it perfect for "opening" or "closing" the flow of data.

In contrast, the cell input $z_t$ and the normalization of the cell state $\psi$ typically use the $\tanh$ (hyperbolic tangent) function. The $\tanh$ function squashes values into a range between -1 and 1. For the cell input, this ensures that the values being added to the memory are centered around zero and do not grow uncontrollably. For the hidden state calculation, $\psi(c_t)$ is used to squash the potentially unbounded cell state before it is multiplied by the output gate, ensuring the resulting hidden state $h_t$ remains stable for the subsequent layers of the network.

# Historical success stories of LSTMs in sequence modeling

Before the rise of Transformers, LSTMs were the dominant architecture for nearly all sequence-related tasks. Their ability to learn abstractions and extract semantic information allowed them to excel in text generation and sequence-to-sequence translation. They were used to generate handwriting, evaluate computer programs, and produce image captions and source code. Beyond linguistics, LSTMs proved invaluable in scientific modeling, such as rainfall-runoff modeling and creating hydrological models for flooding warnings.

LSTMs also achieved significant breakthroughs in reinforcement learning. They served as the core of high-profile models such as AlphaStar for StarCraft II and the OpenAI Five for Dota 2, as well as models used to control magnetic controllers for nuclear fusion. A key reason for this success was the LSTM's capacity to develop specialized "neurons." Researchers discovered that LSTMs could evolve specific neurons dedicated to tracking number, syntax, linguistics, and sentiment, demonstrating their power to represent complex, high-level concepts within their memory cells.
