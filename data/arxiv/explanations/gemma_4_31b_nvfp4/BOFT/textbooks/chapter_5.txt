Chapter 5: Practical Implementation and Training Stability

# Maintaining Orthogonality via the Cayley Transform

A core requirement of Orthogonal Butterfly (BOFT) is that the transformation matrix $\bm{R}$ must remain orthogonal throughout the entire finetuning process. Orthogonality is not merely a mathematical curiosity; it is fundamental to the method's success because it preserves the pairwise angles between neurons and the spectral norm of the pretrained weight matrix $\bm{W}^0$. If the matrix $\bm{R}$ were to lose its orthogonality during gradient descent, the model would lose the stability and generalization benefits that define the orthogonal finetuning paradigm. However, ensuring that a matrix remains orthogonal during optimization is challenging because the set of orthogonal matrices forms a manifold rather than a simple linear space.

To solve this, BOFT employs the Cayley Transform, a method that allows the optimization of an orthogonal matrix by instead optimizing a skew-symmetric matrix. A skew-symmetric matrix $\bm{Q}$ is defined by the property $\bm{Q} = -\bm{Q}^\top$, meaning its transpose is its own negative. The Cayley Transform maps such a skew-symmetric matrix $\bm{Q}$ to an orthogonal matrix $\bm{R}$ using the formula $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$. 

The intuition behind this approach is that any matrix $\bm{R}$ generated via this transform is guaranteed to be orthogonal, regardless of the specific values within $\bm{Q}$, provided that the inverse $(\bm{I} - \bm{Q})^{-1}$ exists. By parameterizing the butterfly components through $\bm{Q}$, the training process can use standard gradient-based optimization on $\bm{Q}$ without ever needing to explicitly constrain $\bm{R}$ to be orthogonal. This transforms a constrained optimization problem into an unconstrained one, ensuring that the structural integrity of the orthogonal transformation is maintained across every training iteration.

# Identity Initialization Strategies for Weight Preservation

In the context of adapting large foundation models to downstream tasks, it is critical that the finetuning process begins from the exact state of the pretrained model. This prevents the model from deviating too sharply from the powerful representations it learned during pretraining, which helps avoid catastrophic forgetting and ensures faster convergence. In many parameter-efficient finetuning methods, such as LoRA, this is achieved through zero initialization of the additive low-rank weights, effectively making the initial update an identity operation.

Because BOFT uses a multiplicative weight update rather than an additive one, zero initialization is not applicable. Multiplying the pretrained weights $\bm{W}^0$ by a zero matrix would destroy all pretrained knowledge. Instead, BOFT employs identity initialization. The goal is for the initial orthogonal matrix $\bm{R}$ to be the identity matrix $\bm{I}$, such that the initial forward pass $(\bm{R}\bm{W}^0)^\top\bm{x}$ is identical to the original pretrained forward pass $(\bm{W}^0)^\top\bm{x}$.

This is implemented through the Cayley Transform. To make $\bm{R} = \bm{I}$, the corresponding skew-symmetric matrix $\bm{Q}$ must be initialized as a zero matrix. When $\bm{Q} = \bm{0}$, the formula $(\bm{I} + \bm{0})(\bm{I} - \bm{0})^{-1}$ simplifies directly to $\bm{I}$. By initializing all the butterfly components as identity matrices, BOFT ensures that the finetuning process starts exactly at the pretrained model's weights, providing a stable baseline for adaptation.

# Multiplicative Dropout: Adapting Dropout for Multiplicative Weight Updates

Regularization is essential in finetuning to prevent the model from overfitting to the often smaller datasets used in downstream tasks. Traditional dropout techniques, which randomly set individual elements of a weight matrix to zero, are highly effective for additive updates. However, such an approach is incompatible with the multiplicative structure of BOFT. Zeroing out an element in a product of orthogonal matrices would not only break the orthogonality of the resulting transformation but could also completely block the flow of information through the butterfly network.

To address this, BOFT introduces a specialized multiplicative Dropout. Instead of replacing elements with zeros, this method replaces specific structural components with identity matrices. Because the final orthogonal matrix $\bm{R}(m,b)$ is composed of $m$ orthogonal butterfly components, the multiplicative Dropout operates at two levels of granularity. First, it randomly selects a percentage $p_1$ of the entire butterfly components and replaces them with identity matrices. Second, it randomly selects a percentage $p_2$ of the diagonal blocks within each butterfly component and replaces those blocks with identity matrices.

The intuition here is that by replacing a component with an identity matrix, the dropout mechanism effectively "bypasses" that specific transformation. The information flows through the network as if that particular layer or block were not present, forcing the model to distribute its learning across other components. This encourages redundancy and robustness in the learned transformations, providing the benefits of regularization while strictly preserving the orthogonality of the overall matrix $\bm{R}$.

# The Training Pipeline: From Frozen Pretrained Weights to Learned Butterfly Components

The practical implementation of BOFT follows a structured pipeline designed to maximize parameter efficiency while eliminating inference latency. The process begins with a frozen pretrained weight matrix $\bm{W}^0$ of size $d \times n$. Unlike full finetuning, where all elements of $\bm{W}^0$ are updated, BOFT keeps $\bm{W}^0$ completely static throughout the training process.

During the forward pass, the model learns a transformation matrix $\bm{R}(m,b)$, which is parameterized as the product of $m$ orthogonal butterfly components: $\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$. The input vector $\bm{x}$ is processed by the modified linear layer as $\bm{z} = (\bm{R}\bm{W}^0)^\top\bm{x}$. The only trainable parameters in this setup are the skew-symmetric matrices $\bm{Q}$ used to construct each butterfly component $\tilde{\bm{B}}^b_{(d,i)}$. By using the butterfly structure, the number of parameters is reduced from the $\mathcal{O}(d^2)$ required for a dense orthogonal matrix to $\mathcal{O}(d \log d)$ when using the standard butterfly matrix configuration ($m=\log d, b=2$).

A significant advantage of this pipeline is the transition from training to inference. Once the finetuning stage is complete and the optimal butterfly components have been learned, the final orthogonal matrix $\bm{R}$ is computed. This matrix can then be pre-multiplied into the frozen weights to create a new weight matrix: $\bm{W}_{final} = \bm{R}\bm{W}^0$. Because $\bm{W}_{final}$ has the same dimensions as the original $\bm{W}^0$, the final model architecture is identical to the original. Consequently, BOFT introduces zero additional latency during inference, as the complex product of butterfly matrices is collapsed into a single weight matrix before the model is deployed.
