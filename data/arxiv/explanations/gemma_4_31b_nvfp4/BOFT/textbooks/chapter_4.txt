\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: Orthogonal Butterfly (BOFT) Parameterization

# Inspiration from the Cooley-Tukey Fast Fourier Transform (FFT)

To understand the mechanism behind Orthogonal Butterfly (BOFT), one must first understand the challenge of parameter efficiency in Orthogonal Finetuning (OFT). In OFT, a pretrained weight matrix $\bm{W}^0$ is updated by multiplying it with a learnable orthogonal matrix $\bm{R}$. While the use of orthogonal matrices preserves the pairwise angles between neurons—thereby protecting the semantic knowledge acquired during pretraining—a dense orthogonal matrix $\bm{R}$ of dimension $d \times d$ requires $\mathcal{O}(d^2)$ parameters. This dimensionality makes full orthogonal finetuning prohibitively expensive for large models.

The researchers propose viewing the construction of this orthogonal matrix as an information transmission problem. In this framework, multiplying a series of sparse matrices to create a dense result is analogous to transmitting information across a grid-structured graph. For a final matrix $\bm{R}$ to be dense, every node in the input level must have a path to every node in the output level. A simple block-diagonal structure, as used in previous versions of OFT, fails this requirement because it separates dimensions into independent groups, preventing information from flowing between different blocks.

The inspiration for solving this comes from the Cooley-Tukey fast Fourier transform (FFT) algorithm. In the FFT, a large discrete Fourier transform is recursively broken down into smaller transforms. This process induces a "butterfly" structure where a local change in the frequency domain can result in a global change in the spatial domain. This global connectivity is exactly what is needed for parameter-efficient finetuning: a way to achieve dense connectivity (where every input node can influence every output node) using a very small number of edges. By adopting this butterfly topology, BOFT can generate a dense orthogonal matrix through the product of several sparse orthogonal matrices, effectively trading a small amount of computation time during training for a massive reduction in parameter space.

# Defining the Butterfly Factor and the Recursive Butterfly Matrix

The technical construction of BOFT begins with the definition of a butterfly factor, denoted as $\bm{B}^F(k)$. Assuming $k$ is a power of 2, the butterfly factor is a $k \times k$ matrix defined as:
$$\bm{B}^F(k)=\begin{bmatrix} \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\ \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4) \end{bmatrix}$$
where each $\bm{d}_i \in \mathbb{R}^{k/2}$ is a vector. This structure ensures that the matrix is sparse, containing only a few non-zero entries, yet it provides the necessary connectivity to shuffle information across the dimensions of the matrix.

To scale this to a $d$-dimensional matrix, the butterfly matrix $\bm{B}(d)$ is defined recursively. For a dimension $d = 2^N$, the butterfly matrix is constructed as:
$$\bm{B}(d)=\tilde{\bm{B}}(d,d) \cdot \begin{bmatrix} \bm{B}_1(\frac{d}{2}) & \bm{0} \\ \bm{0} & \bm{B}_2(\frac{d}{2}) \end{bmatrix}$$
By expanding this recursion, the butterfly matrix can be written as a product of butterfly components: $\bm{B}(d) = \tilde{\bm{B}}(d,d)\tilde{\bm{B}}(d,\frac{d}{2})\cdots\tilde{\bm{B}}(d,2)$. A butterfly component $\tilde{\bm{B}}(d,k)$ is defined as a block-diagonal matrix $\text{diag}(\bm{B}^F_1(k),\cdots,\bm{B}^F_{d/k}(k))$, where each block is a butterfly factor of size $k$.

To ensure that the resulting product $\bm{R}$ remains orthogonal throughout the finetuning process, each individual butterfly component must be orthogonal. This is achieved using the Cayley transform, which parameterizes an orthogonal matrix as $\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$, where $\bm{Q}$ is a skew-symmetric matrix ($\bm{Q}=-\bm{Q}^\top$). By applying this to the $2 \times 2$ blocks within the butterfly components, the researchers ensure that the product of these sparse matrices remains a valid orthogonal transformation.

# Block Butterfly Components and Their Construction

To further generalize the framework and provide more flexibility in the trade-off between expressivity and parameter count, BOFT introduces block butterfly components. In the basic butterfly factor, the elements of $\bm{d}_i$ are scalars. In a block butterfly component $\tilde{\bm{B}}^b(d,k)$, each entry in $\bm{d}_i$ is replaced by a $b \times b$ matrix. This means that instead of rotating individual dimensions, the model rotates blocks of dimensions.

To maintain orthogonality in this block-based setup, the researchers parameterize each $2b \times 2b$ block matrix within the butterfly component to be orthogonal. Since the non-zero pattern of every other butterfly component is essentially a block-wise permutation of the non-zero pattern of the initial $\tilde{\bm{B}}^b(d,2)$ component, they can all be parameterized as orthogonal matrices using the same principles.

The complete forward pass in BOFT is then expressed as:
$$\bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x}$$
Here, $\bm{R}(m,b)$ is the final orthogonal matrix, formed by the product of $m$ orthogonal butterfly components: $\bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$. This construction allows the model to start from the pretrained weights (by initializing the skew-symmetric matrices in the Cayley transform to zero, resulting in an identity matrix) and gradually learn the necessary orthogonal transformation to adapt to the downstream task.

# Complexity Analysis: $\mathcal{O}(d^2)$ vs. $\mathcal{O}(d)$ vs. $\mathcal{O}(d \log d)$ Parameters

One of the primary motivations for BOFT is the drastic reduction in the number of trainable parameters. To appreciate this, we can compare it to other orthogonal parameterization strategies. A full, dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ requires $\mathcal{O}(d^2)$ parameters. For large-scale models where $d$ is high, this is computationally impractical. 

The original version of OFT attempted to solve this using a block-diagonal structure. In a block-diagonal OFT with block size $b$, the matrix consists of $r$ independent blocks where $br = d$. This reduces the parameter complexity to $\mathcal{O}(bd)$. If $b$ is small, this is very efficient, but it limits the expressivity because dimensions in different blocks cannot interact. To achieve a dense orthogonal matrix using the block-diagonal approach, one would have to set $b=d$, returning to the $\mathcal{O}(d^2)$ complexity.

BOFT provides a middle ground by using the butterfly structure. For a configuration where $m = \log d$ and $b = 2$, BOFT can generate a dense orthogonal matrix using only $\mathcal{O}(d \log d)$ parameters. More generally, BOFT($m, b$) utilizes $\frac{1}{2}(b-1)dm$ effective trainable parameters. This represents a significant improvement: BOFT can achieve the expressivity of a dense matrix (which traditionally requires $\mathcal{O}(d^2)$) while maintaining a parameter count closer to the efficiency of a block-diagonal matrix. While this requires performing more matrix multiplications during the training phase, it introduces no additional latency during inference, as the learned $\bm{R}$ can be pre-multiplied into the frozen weights $\bm{W}^0$.

# Generalizing BOFT: From Block-Diagonal OFT to Full Orthogonal Matrices

BOFT is designed as a generalized framework that subsumes original Orthogonal Finetuning as a special case. This relationship can be understood by varying the number of butterfly components $m$ and the block size $b$. For instance, when $m=1$, BOFT($1, b$) is mathematically identical to the block-diagonal OFT with block size $b$. If we further set $m=1$ and $b=d$, BOFT reduces to the original OFT using a full, unconstrained dense orthogonal matrix.

Beyond these cases, BOFT can be extended into what is known as a kaleidoscope hierarchy. While a single butterfly matrix is highly efficient, researchers have found that multiplying multiple butterfly matrices—specifically using the form $\bm{R}^G = \bm{R}_{l,1}\bm{R}_{l,2}^\top \dots \bm{R}_{1,1}\bm{R}_{1,2}^\top$—can represent the entire orthogonal group if the number of layers $l$ is sufficiently large (e.g., $l = d-1$). 

This hierarchy illustrates the trade-off between expressivity and regularity. While a full orthogonal matrix has universal expressiveness, it often lacks the regularization needed to prevent overfitting during finetuning. By restricting the hypothesis class to a structured subset of the orthogonal group via butterfly factorization, BOFT introduces a beneficial inductive bias. This bias is rooted in the fact that the butterfly structure is shared by many classic linear transforms, such as the discrete Fourier and Hadamard transforms, allowing BOFT to find a more stable and generalizable solution for downstream tasks.
