\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 2: Foundations of Orthogonal Finetuning (OFT)

# The Concept of Preserving Pairwise Angles Between Neurons

In the context of adapting large foundation models to downstream tasks, a primary challenge is to update the model's parameters without destroying the vast amount of semantic knowledge acquired during pretraining. Conventional finetuning often relies on an ad hoc approach, such as employing a very small learning rate, to ensure that the finetuned model does not deviate too drastically from the pretrained version. However, a more principled approach involves preserving the relational information embedded within the weight matrices of the model. Specifically, the relational information is characterized by the pairwise angles between neurons.

Neurons in a linear layer can be viewed as vectors. The geometric relationship—the angles—between these vectors represents the structural knowledge the model has learned. If these angles are preserved during the adaptation process, the model is more likely to retain its generalizability and the fundamental knowledge captured during its initial training. Orthogonal Finetuning (OFT) is built upon this insight. By applying an orthogonal transformation to the neurons in a layer, OFT ensures that the pairwise angles between neurons are provably preserved. This prevents the "catastrophic" loss of pretrained knowledge and provides a more stable foundation for adapting the model to a specific new task.

# Mathematical Formulation of OFT: The Multiplicative Orthogonal Update

To understand the mathematical implementation of OFT, we must first consider a standard pretrained linear layer. Let $\bm{W}^0 \in \mathbb{R}^{d \times n}$ represent the frozen pretrained weight matrix. In a standard forward pass, given an input vector $\bm{x} \in \mathbb{R}^{d}$, the output vector $\bm{z} \in \mathbb{R}^{n}$ is calculated as $\bm{z} = (\bm{W}^0)^\top \bm{x}$. While other parameter-efficient methods, such as LoRA, update the weights by adding a low-rank matrix to the original weights, OFT employs a multiplicative update strategy.

In OFT, a learnable orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ is optimized to transform the neurons of the layer. The forward pass is modified to $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$. In this formulation, the orthogonal matrix $\bm{R}$ acts on the weights of the pretrained model before the input $\bm{x}$ is processed. To ensure that $\bm{R}$ remains strictly orthogonal throughout the training process—meaning $\bm{R}^\top \bm{R} = \bm{I}$—OFT utilizes the Cayley parameterization. This method defines the orthogonal matrix as $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$, where $\bm{Q}$ is a skew-symmetric matrix such that $\bm{Q} = -\bm{Q}^\top$. By optimizing the entries of the skew-symmetric matrix $\bm{Q}$, the resulting matrix $\bm{R}$ is guaranteed to be orthogonal, thereby maintaining the preservation of the pairwise angles between neurons.

# The Role of the Identity Matrix in Zero Initialization

A critical requirement for any finetuning method is that it should start from the exact state of the pretrained model. This ensures that the adaptation process begins with the full knowledge of the foundation model and only deviates as the training data guides the optimization. In additive methods like LoRA, this is achieved through "zero initialization," where the trainable low-rank matrices are initialized to zero, making the initial update term vanish.

In the case of OFT, the equivalent of zero initialization is achieved by initializing the learnable orthogonal matrix $\bm{R}$ as an identity matrix $\bm{I}$. Within the Cayley parameterization framework, this means initializing the skew-symmetric matrix $\bm{Q}$ as a zero matrix. When $\bm{Q} = \bm{0}$, the formula $\bm{R} = (\bm{I} + \bm{0})(\bm{I} - \bm{0})^{-1}$ simplifies to $\bm{R} = \bm{I}$. Because the identity matrix does not alter the pretrained weights ($\bm{I}\bm{W}^0 = \bm{W}^0$), the model starts the finetuning process exactly as it was after pretraining. This starting point is essential for maintaining training stability and ensuring that the model does not deviate into an unstable parameter space before it has begun to learn the downstream task.

# Limitations of Block-Diagonal Structures in OFT: Parameter Efficiency vs. Expressivity

While a dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ provides maximum expressivity, it comes with a significant computational cost. A full dense orthogonal matrix requires $\mathcal{O}(d^2)$ trainable parameters, which can be prohibitively large for the high-dimensional layers found in foundation models. To mitigate this, original OFT implementations introduce a block-diagonal structure. In this setup, the orthogonal matrix $\bm{R}$ is parameterized as $\text{diag}(\bm{R}_1, \bm{R}_2, \dots, \bm{R}_r)$, where each $\bm{R}_i \in \mathbb{R}^{b \times b}$ is a small orthogonal matrix and $br = d$.

This block-diagonal approach significantly improves parameter efficiency, as the number of trainable parameters is reduced to a fraction of the original $d^2$. However, this efficiency introduces a restrictive inductive bias. Specifically, it assumes that the dimensions of a neuron—which is a column vector of the weight matrix $\bm{W}^0$—can be divided into $r$ groups based on their indices, and that dimensions in different groups should be transformed independently. This is an arbitrary division that does not account for the actual semantic relationship between different dimensions of the neuron. 

Consequently, the block-diagonal structure limits the expressivity of the model. It cannot approximate a general dense orthogonal matrix and is unable to recover classic linear transforms. This creates a tension between parameter efficiency and expressivity: smaller block sizes $b$ lead to fewer parameters but further restrict the transformation's ability to adapt to the task, while larger block sizes increase the parameter count. This limitation highlights the need for a method that can generate a dense orthogonal matrix while maintaining a low number of trainable parameters.
