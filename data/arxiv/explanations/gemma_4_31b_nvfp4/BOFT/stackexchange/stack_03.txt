\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the 'information transmission' view map to matrix multiplication?
Question:
The authors introduce a grid-structured graph where $\bm{B}_i$ is viewed as the connectivity matrix from level $i$ to $i+1$. They state that for $\bm{R} = \bm{B}_m \dots \bm{B}_1$ to be dense, every node in the first level must have a path to every node in the $(m+1)$-th level. I'm trying to reconcile this with linear algebra: does this imply that the product of these sparse matrices results in a matrix where almost all entries $R_{ij}$ are non-zero, and how does the butterfly topology specifically satisfy this 'dense connectivity' requirement more efficiently than other sparse patterns?
Answer:
To understand how the "information transmission" view maps to matrix multiplication, it is helpful to think of matrix multiplication not as a series of dot products, but as a process of summing paths across a graph.

In the paper, the authors represent the orthogonal matrix $\bm{R}$ as a product of $m$ sparse matrices: $\bm{R} = \bm{B}_m \bm{B}_{m-1} \dots \bm{B}_1$. If we view each matrix $\bm{B}_i$ as an adjacency matrix for a bipartite graph connecting $d$ nodes at level $i$ to $d$ nodes at level $i+1$, then an entry $(\bm{B}_i)_{jk} \neq 0$ represents a directed edge from node $k$ in level $i$ to node $j$ in level $i+1$. When we multiply these matrices, the entry $R_{ij}$ of the resulting matrix $\bm{R}$ is the sum over all possible paths starting at node $j$ in the first level and ending at node $i$ in the $(m+1)$-th level. Specifically, $R_{ij} = \sum_{k_1, \dots, k_{m-1}} (\bm{B}_m)_{i, k_{m-1}} (\bm{B}_{m-1})_{k_{m-1}, k_{m-2}} \dots (\bm{B}_1)_{k_1, j}$. If there is no path between node $j$ and node $i$ through the sequence of sparse matrices, the sum is zero, and $R_{ij}$ will be $0$. Therefore, for $\bm{R}$ to be a "dense" matrix (meaning $R_{ij} \neq 0$ for all $i, j$), every node in the first level must have at least one path to every node in the final level.

The butterfly topology satisfies this requirement efficiently by utilizing a recursive structure similar to the Cooley-Tukey Fast Fourier Transform (FFT). In a standard block-diagonal structure, information is trapped within independent blocks; if a node starts in block $A$, it can never reach a node in block $B$, resulting in a sparse product $\bm{R}$. In contrast, the butterfly structure uses a series of "butterfly factors" $\bm{B}^F(k)$ that mix information across different groups of nodes. By layering $\mathcal{O}(\log d)$ such sparse matrices, the butterfly structure ensures that information from any single input node is distributed across the entire width of the graph by the final level.

The efficiency gain is significant: a fully dense orthogonal matrix requires $\mathcal{O}(d^2)$ parameters. However, the butterfly factorization achieves the same "dense connectivity" (global information flow) using only $\mathcal{O}(d \log d)$ parameters. This allows the model to maintain the expressivity of a dense transformation—enabling any neuron to potentially influence any other—while drastically reducing the number of trainable parameters required during finetuning.
