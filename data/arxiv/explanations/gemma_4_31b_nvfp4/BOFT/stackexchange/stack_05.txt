\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### What is the intuition behind the 'multiplicative Dropout' in BOFT?
Question:
The paper proposes a multiplicative Dropout that replaces randomly selected butterfly components or diagonal blocks with identity matrices, rather than using standard dropout which sets elements to zero. Is this necessary because setting elements of an orthogonal matrix to zero would destroy the orthogonality property? If we used standard dropout on the skew-symmetric matrix $\bm{Q}$ instead, would that achieve a similar effect without breaking the orthogonal constraint?
Answer:
The intuition behind multiplicative Dropout in BOFT stems from the fact that BOFT uses a multiplicative weight update, whereas standard Dropout is designed for additive updates. In a standard additive update, such as in LoRA, the model learns a weight $\Delta \bm{W}$ and adds it to the original weights. Setting an element of $\Delta \bm{W}$ to zero via standard Dropout effectively "turns off" that specific parameter's contribution to the sum, as $0$ is the identity element for addition.

In BOFT, however, the pretrained weights are transformed by an orthogonal matrix $\bm{R}$ that is composed of a product of sparse orthogonal matrices: $\bm{R} = \prod \tilde{\bm{B}}^b_{(d,i)}$. To "turn off" a component in this multiplicative chain, one must replace it with the identity matrix $\bm{I}$, because $\bm{I}$ is the identity element for matrix multiplication. Replacing a butterfly component or a diagonal block with $\bm{I}$ ensures that the information simply passes through that stage of the transformation unchanged, which is the multiplicative equivalent of setting an additive weight to zero.

You are correct that applying standard Dropout by setting elements of an orthogonal matrix to zero would destroy the orthogonality property. If $\bm{R}$ is no longer orthogonal, the fundamental goal of Orthogonal Finetuning (OFT)—preserving the pairwise angles between neurons and the spectral norm of the pretrained weights—would be lost. This would undermine the training stability and generalization benefits that BOFT is designed to provide.

Regarding your question about the skew-symmetric matrix $\bm{Q}$, while applying dropout to $\bm{Q}$ (provided that skew-symmetry $\bm{Q} = -\bm{Q}^\top$ is maintained) would technically yield an orthogonal matrix via the Cayley transform, it would not achieve the same regularization effect as the proposed multiplicative Dropout. Setting elements of $\bm{Q}$ to zero modifies the values within a rotation block, but it does not "bypass" the block. Replacing a block in the butterfly structure with $\bm{I}$ (which corresponds to setting the corresponding block in $\bm{Q}$ to $\bm{0}$) effectively removes an entire structured component of the information transmission path. This allows the model to regularize by randomly omitting specific stages of the butterfly factorization, rather than just perturbing the values of the rotations.
