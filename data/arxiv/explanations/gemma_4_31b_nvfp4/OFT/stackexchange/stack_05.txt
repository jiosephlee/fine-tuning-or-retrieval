\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### Does OFT effectively perform a low-rank update similar to LoRA?
Question:
The paper claims that OFT can be rewritten as $\bm{z}=(\bm{W}^0+(\bm{R}-\bm{I})\bm{W}^0)^T\bm{x}$, and suggests that if $\bm{R}-\bm{I}$ is low-rank, it's analogous to LoRA. 

However, LoRA explicitly learns a low-rank matrix $\bm{B}\bm{A}$ to add to the weights. In OFT, $\bm{R}$ is an orthogonal matrix. If $\bm{R}$ is an orthogonal matrix, can $\bm{R}-\bm{I}$ actually be low-rank? I thought orthogonal matrices were by definition full-rank. I'm confused about how OFT can be viewed as a 'sparsity' alternative to the 'low-rank' approach of LoRA.
Answer:
To understand how Orthogonal Finetuning (OFT) relates to LoRA, it is first necessary to distinguish between the properties of the transformation matrix $\bm{R}$ and the properties of the update matrix $(\bm{R}-\bm{I})$.

You are correct that an orthogonal matrix $\bm{R}$ must be full-rank by definition; if it weren't, it couldn't satisfy $\bm{R}^\top\bm{R} = \bm{I}$. However, the "low-rank" claim does not refer to $\bm{R}$ itself, but to the difference $\bm{R}-\bm{I}$. While $\bm{R}$ is full-rank, $\bm{R}-\bm{I}$ can indeed be low-rank. A classic example is a Householder reflection, where $\bm{R} = \bm{I} - 2\bm{v}\bm{v}^\top$ for some unit vector $\bm{v}$. In this case, $\bm{R}$ is a full-rank orthogonal matrix, but $\bm{R}-\bm{I} = -2\bm{v}\bm{v}^\top$, which is a rank-1 matrix.

In the context of the paper, the analogy to LoRA comes from the way the weights are modified. LoRA approximates a weight update as $\bm{W} = \bm{W}^0 + \bm{B}\bm{A}$, where $\bm{B}\bm{A}$ is a low-rank matrix. OFT defines the weights as $\bm{W} = \bm{R}\bm{W}^0$. By rewriting this as $\bm{W} = \bm{W}^0 + (\bm{R}-\bm{I})\bm{W}^0$, the term $(\bm{R}-\bm{I})\bm{W}^0$ acts as the additive update $\Delta \bm{W}$. If $\bm{R}-\bm{I}$ is low-rank, then the resulting update to the weights is also low-rank, mirroring the mechanism of LoRA.

The paper describes OFT as a "sparsity" alternative to the "low-rank" approach of LoRA because of how they achieve parameter efficiency. LoRA reduces the number of trainable parameters by explicitly constraining the rank of the update matrix. OFT, however, achieves parameter efficiency by imposing a structural constraint on $\bm{R}$—specifically, using a block-diagonal structure. Instead of learning a full $d \times d$ matrix, they learn $r$ smaller blocks. This is a form of structural sparsity (many elements of the matrix are forced to be zero), which reduces the parameter complexity from $\mathcal{O}(d^2)$ to $\mathcal{O}(d^2/r)$ or even $\mathcal{O}(d^2/r^2)$ with block sharing.

Intuitively, while LoRA restricts the *expressive dimension* of the update, OFT restricts the *degree of freedom* of the rotation while ensuring the "energy" (the pairwise angles between neurons) is perfectly preserved. This is further reinforced in Constrained OFT (COFT), where the constraint $\|\bm{R}-\bm{I}\| \leq \epsilon$ ensures that the orthogonal transformation remains a small perturbation of the identity, keeping the finetuned model close to the pretrained weights to maintain stability.
