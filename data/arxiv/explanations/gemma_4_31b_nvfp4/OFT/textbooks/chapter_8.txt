\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 8: Comparative Analysis and Future Directions

# OFT vs. LoRA: Low-Rank vs. Sparse Orthogonal Structures

When adapting large-scale pretrained models to downstream tasks, the primary objective is to find a balance between flexibility—the ability of the model to learn new information—and regularity—the ability to preserve the original generative capabilities. Two prominent approaches to achieving this are Low-Rank Adaptation (LoRA) and Orthogonal Finetuning (OFT). While both are designed to be parameter-efficient, they rely on fundamentally different mathematical constraints to prevent the model from deviating too far from its pretrained state.

LoRA operates on the assumption that the update to the weights can be represented by a low-rank matrix. In this framework, the difference between the finetuned weight matrix $\bm{M}$ and the pretrained weight matrix $\bm{M}^0$ is constrained such that $\text{rank}(\bm{M} - \bm{M}^0) = r'$, where $r'$ is a small constant. This prevents the information in the pretrained weights from shifting dramatically by limiting the degrees of freedom available for the update. In essence, LoRA uses an additive low-rank structure to modify the model.

In contrast, OFT utilizes a multiplicative approach based on orthogonal transformations. Instead of adding a low-rank matrix, OFT transforms the pretrained weights using an orthogonal matrix $\bm{R}$, where $\bm{W} = \bm{R}\bm{W}^0$. This approach is grounded in the principle of preserving hyperspherical energy, which characterizes the pairwise angles between neurons. Because an orthogonal transformation preserves these angles, OFT ensures that the intrinsic semantic structure of the pretrained model remains intact. While LoRA exploits the low-rank structure of the weight update, OFT exploits a sparsity structure through the use of block-diagonal orthogonal matrices.

Interestingly, these two methods are not entirely unrelated. The forward pass of OFT can be rewritten as $\bm{z} = (\bm{W}^0 + (\bm{R} - \bm{I})\bm{W}^0)^\top \bm{x}$. In this formulation, the term $(\bm{R} - \bm{I})\bm{W}^0$ acts as the weight update, similar to the low-rank update in LoRA. Therefore, if the matrix $\bm{R} - \bm{I}$ is low-rank, OFT effectively performs a low-rank weight update. The key difference remains that while LoRA restricts the rank of the update directly, OFT restricts the transformation to be orthogonal, which provides a more structured way to preserve the pretrained knowledge.

# Architectural Agnosticism: Applying OFT to Transformers and Convolutions

A significant advantage of the OFT framework is that it is agnostic to the specific architecture of the neural network. Because it operates on the weight matrices of individual layers, it can be applied to any layer that can be represented as a matrix multiplication, including the attention weights in Transformers and the kernels in convolutional layers.

In Transformer architectures, OFT is typically applied to the attention weights. This allows for a fair comparison with methods like LoRA, which are also frequently applied to these specific layers. By learning a layer-shared orthogonal matrix for the attention weights, OFT can modify the model's behavior for downstream tasks while ensuring that the attention mechanism's pretrained structural properties are not destroyed.

The application of OFT to convolutional layers provides further interesting interpretations. In a convolutional layer, the block-diagonal structure of the orthogonal matrix $\bm{R}$ can be tuned to control the transformation of neuron channels. For instance, if the number of blocks in the diagonal matrix $\bm{R}$ is set to be equal to the number of input channels, each block transforms a unique neuron channel. This is conceptually similar to the operation of depth-wise convolution kernels. Alternatively, if the blocks in $\bm{R}$ are shared across the diagonal, the neurons are transformed by a single orthogonal matrix shared across all channels. This flexibility allows OFT to be adapted to the specific spatial and channel-wise requirements of different vision tasks.

# Zero Inference Overhead: The Weight-Merging Advantage

One of the most practical benefits of Orthogonal Finetuning is that it introduces zero additional computational overhead during the inference stage. This stands in stark contrast to other controllable generation frameworks, such as ControlNet, which introduce additional trainable components that must be computed during every forward pass of the model.

The efficiency of OFT stems from the fact that the orthogonal transformation is a linear operation applied to the weights. During the training phase, the model learns the orthogonal matrix $\bm{R}$ and uses it to transform the pretrained weights $\bm{W}^0$ to produce the finetuned weights $\bm{W} = \bm{R}\bm{W}^0$. However, once training is complete, the learned matrix $\bm{R}$ can be multiplied into the pretrained weight matrix $\bm{W}^0$ a single time.

The result of this multiplication is a standard weight matrix $\bm{W}$ that is identical in shape and function to the original pretrained weights. Consequently, the finetuned model can be deployed as a standard diffusion model without any modified architecture or additional parameters. This "weight-merging" advantage ensures that the inference speed and memory requirements of an OFT-finetuned model are exactly the same as those of the original pretrained model, making it highly suitable for efficient deployment in real-world applications.

# Open Problem: Scaling Matrix Inverses in Differentiable Frameworks

Despite its effectiveness, OFT faces a challenge regarding scalability due to the way the orthogonal matrix $\bm{R}$ is parameterized. To ensure that $\bm{R}$ remains strictly orthogonal throughout the training process, OFT employs Cayley parameterization. In this method, the orthogonal matrix is constructed as $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$, where $\bm{Q}$ is a skew-symmetric matrix such that $\bm{Q} = -\bm{Q}^\top$.

The primary bottleneck of this approach is the requirement of a matrix inverse, $(\bm{I} - \bm{Q})^{-1}$. Computing the inverse of a large matrix is computationally expensive and can become a limiting factor as the dimension $d$ of the layers increases. To mitigate this, OFT utilizes a block-diagonal parameterization, which breaks the large $d \times d$ matrix into $r$ smaller blocks of size $d/r \times d/r$. This reduces the complexity of the inversion process significantly.

However, the need for a matrix inverse in a differentiable framework remains an open research problem. While block-diagonal structures provide a temporary solution by reducing the size of the matrices being inverted, they introduce their own biases and potentially limit the flexibility of the finetuning. Finding a way to speed up the matrix inverse or develop a different differentiable orthogonalization strategy that scales more efficiently without sacrificing the orthogonal property is a key direction for future improvement.

# The Potential for Compositionality through Orthogonal Matrix Multiplication

A compelling theoretical property of the OFT framework is its potential for compositionality. This potential arises from a fundamental property of the orthogonal group: the product of two orthogonal matrices is itself an orthogonal matrix.

In a typical finetuning scenario, a model might be adapted for several different downstream tasks, each resulting in a unique orthogonal matrix—for example, $\bm{R}_A$ for subject-driven generation and $\bm{R}_B$ for a specific controllable generation task. Because these matrices are orthogonal, they can be multiplied together, and the resulting matrix $\bm{R}_{combined} = \bm{R}_A \bm{R}_B$ will still be an orthogonal matrix.

This suggests a possible path toward creating a single model that possesses the capabilities of multiple downstream tasks without needing to train a separate model for every combination of tasks. If the orthogonal matrices can be composed through multiplication, it may be possible to combine the knowledge gained from different finetuning tasks into one unified transformation. Whether this compositionality preserves the specific semantic knowledge of all the individual tasks remains an open question, but it presents an intriguing direction for studying how to modularly combine different learned behaviors in large-scale generative models.
