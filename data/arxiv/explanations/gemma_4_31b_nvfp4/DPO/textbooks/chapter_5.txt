Chapter 5: Theoretical Foundations and Analysis

# Reward Equivalence Classes: When two reward functions are functionally identical

To understand how Direct Preference Optimization (DPO) works, we must first establish the concept of reward equivalence. In the context of training language models to follow human preferences, we often work with a reward function $r(x, y)$ that assigns a scalar value to a completion $y$ given a prompt $x$. However, it is important to realize that the specific absolute value of a reward is often less important than the relative difference between two rewards.

Two reward functions, $r(x, y)$ and $r'(x, y)$, are considered equivalent if the difference between them is solely a function of the prompt $x$. Formally, we say they are equivalent if $r(x, y) - r'(x, y) = f(x)$ for some function $f$. This means that for any given prompt $x$, the two reward functions differ only by a constant offset. This equivalence relation partitions the set of all possible reward functions into classes. 

This concept is critical because of how preference models, such as the Bradley-Terry model, operate. The Bradley-Terry model determines the probability that one completion is preferred over another based on the difference between their rewards: $p^*(y_1 \succ y_2 \mid x) = \sigma(r^*(x, y_1) - r^*(x, y_2))$. Because the model only cares about the difference $r^*(x, y_1) - r^*(x, y_2)$, any two reward functions from the same equivalence class will induce the exact same preference distribution. If we add $f(x)$ to both rewards, the term $f(x)$ cancels out during subtraction, leaving the preference probability unchanged.

Furthermore, this equivalence extends to the optimal policy derived from these rewards. In a constrained reinforcement learning problem where we aim to maximize reward while minimizing the Kullback-Leibler (KL) divergence from a reference policy, any two reward functions belonging to the same equivalence class will result in the same optimal policy. This implies that for the purpose of alignment, we do not need to find the "exact" reward function, but rather any representative member of the correct equivalence class.

# The 'Language Model as Reward Model' Theorem

The central insight of DPO is that we can bypass the explicit training of a reward model and the subsequent reinforcement learning phase by treating the language model policy itself as the reward model. This is formalized in the "Language Model as Reward Model" theorem, which suggests that the optimal policy and the reward function are analytically linked.

Specifically, the theorem states that under mild assumptions, any reward class consistent with the Bradley-Terry or Plackett-Luce models can be represented using a specific reparameterization: $r(x, y) = \beta \log \frac{\pi(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$. In this expression, $\pi(y \mid x)$ is the policy we are optimizing, $\pi_{\text{ref}}(y \mid x)$ is a fixed reference policy (typically the supervised fine-tuned model), and $\beta$ is a parameter that controls the strength of the KL constraint.

This reparameterization is powerful because it turns the policy $\pi$ into an implicit reward model. Instead of training a separate neural network to predict a reward scalar and then using that scalar to update the policy via reinforcement learning, we can optimize the policy directly. By substituting this reparameterized reward into the preference model, we can express the probability of human preferences directly in terms of the policy. This allows us to use a simple binary cross-entropy loss to align the model with human preferences, effectively treating the language model as if it were secretly a reward model.

# Proof of Generality: Why DPO doesn't restrict the class of learnable rewards

A natural question arises when introducing a specific reparameterization: does forcing the reward to take the form $r(x, y) = \beta \log \frac{\pi(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$ limit the types of rewards the model can learn? If this form were too restrictive, DPO would be unable to represent certain complex human preferences that a general reward model could capture. However, the theoretical framework of DPO proves that there is no loss of generality.

To prove this, we consider any arbitrary reward function $r(x, y)$ and its corresponding optimal policy $\pi_r(y \mid x)$, defined as $\pi_r(y \mid x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x, y)\right)$, where $Z(x)$ is the partition function. The proof employs a projection operator $f$ that normalizes the arbitrary reward function $r$ by subtracting the logarithm of its partition function: $f(r; \pi_{\text{ref}}, \beta)(x, y) = r(x, y) - \beta \log \sum_{y} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x, y)\right)$.

Because the term being subtracted depends only on the prompt $x$, the resulting projected reward is in the same equivalence class as the original reward $r(x, y)$. By rearranging the definition of the optimal policy, it can be shown that this projected reward is exactly equal to $\beta \log \frac{\pi_r(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$. Thus, for any possible reward function, there exists a corresponding policy that represents a reward in the same equivalence class. This confirms that DPO can represent any reward class consistent with the Bradley-Terry model, ensuring that the simplification does not hinder the model's ability to learn complex preferences.

# Diagnosing Actor-Critic Instability: The Role of the Partition Function and Baselines

To appreciate why DPO is a significant improvement, it is helpful to analyze the instabilities inherent in traditional actor-critic algorithms used for RLHF, such as Proximal Policy Optimization (PPO). In these frameworks, the goal is to maximize a reward function $r_{\phi}$ while constraining the policy $\pi_{\theta}$ to stay close to a reference policy $\pi_{\text{ref}}$.

When viewed through the lens of "control as inference," the optimization objective involves a term that can be interpreted as the soft value function of the reference policy. This term is the logarithm of the partition function: $\beta \log \sum_{y} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r_{\phi}(x, y)\right)$. While this normalization term does not change the theoretical optimal solution, it is crucial for the stability of the gradient. 

In practical RLHF implementations, this partition function is extremely difficult to compute because it requires summing over all possible completions $y$. To manage this, researchers often use a learned value function or a baseline, such as a single Monte-Carlo sample of a human completion, to estimate the normalization term. However, these estimates are often noisy or difficult to optimize. When the normalization is inaccurate, the policy gradients can exhibit high variance, leading to the instability and sensitivity to hyperparameters frequently observed in PPO-based training.

# Why DPO avoids the variance issues of PPO

DPO eliminates the variance and instability issues of PPO by fundamentally changing how the reward is integrated into the training process. Instead of attempting to maximize an explicit reward function through an iterative RL loop—which requires estimating the aforementioned partition function and managing a separate value function—DPO uses the closed-form analytical mapping between the reward and the optimal policy.

By reparameterizing the reward as a function of the policy, the partition function $Z(x)$ effectively cancels out. In the DPO objective, the preference probability depends on the difference between the log-ratios of the policy and the reference policy for the preferred and dispreferred completions: $\beta \log \frac{\pi_{\theta}(y_w \mid x)}{\pi_{\text{ref}}(y_w \mid x)} - \beta \log \frac{\pi_{\theta}(y_l \mid x)}{\pi_{\text{ref}}(y_l \mid x)}$.

Because this formulation relies on a simple binary cross-entropy loss over a static dataset of preferences, there is no need to sample from the language model during the fine-tuning loop. The "baseline" is implicitly handled by the reference policy $\pi_{\text{ref}}$, and since there is no need to estimate a value function or a partition function, the high-variance gradients associated with actor-critic methods are completely avoided. This makes DPO computationally lightweight, stable, and far less dependent on the meticulous hyperparameter tuning required by PPO.
