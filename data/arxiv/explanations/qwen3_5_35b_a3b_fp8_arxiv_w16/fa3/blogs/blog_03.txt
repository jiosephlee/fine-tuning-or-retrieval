\title{Blogs about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

# FP8 Made Safe: How Block Quantization and Random Rotations Keep Your AI Accurate

The race to build faster Large Language Models (LLMs) has pushed the industry toward lower-precision arithmetic. While FP16 became the standard for years, modern hardware like NVIDIA's Hopper architecture now champions FP8, promising roughly double the throughput for the same power and silicon area. However, this leap comes with a catch: reducing bit-width from 16 to 8 increases the risk of numerical errors, particularly when dealing with "outlier" values—rare but massive numbers that frequently appear in neural network activations. If not handled correctly, these outliers can cause catastrophic quantization errors, degrading model intelligence despite the speed gains. Enter FlashAttention-3, a new algorithm that solves this dilemma through two ingenious techniques: block quantization and incoherent processing.

At its core, standard attention mechanisms suffer from quadratic scaling with sequence length, making them the primary bottleneck for long-context applications. Previous optimizations like FlashAttention-2 successfully reduced memory traffic by fusing operations into single GPU kernels, yet they still struggled to fully utilize the asynchronous capabilities of modern Tensor Cores. FlashAttention-3 addresses this by leveraging hardware asynchrony to overlap computation and data movement, but its most critical innovation lies in how it handles low-precision math safely. Instead of applying a single scaling factor to an entire tensor—a method known as per-tensor quantization—the authors introduce **block quantization**. This technique splits tensors into smaller blocks and assigns a unique scaling scalar to each block. Because outliers are often localized rather than uniformly distributed across a whole layer, giving each block its own scale prevents large values from forcing the entire block into a low-resolution range where subtle details would be lost.

While block quantization manages local variations effectively, it does not fully solve the problem of extreme outliers dominating the dynamic range of a specific block. To tackle this head-on, FlashAttention-3 employs **incoherent processing**, which involves multiplying the Query ($\mathbf{Q}$) and Key ($\mathbf{K}$) matrices by a random orthogonal matrix $\mathbf{M}$ before quantization occurs. Mathematically, because $\mathbf{M}$ is orthogonal ($\mathbf{M}\mathbf{M}^\top = I$), multiplying both sides preserves the final dot-product result exactly: $(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{K}^\top$. However, computationally, this rotation acts as a diffusion process. By mixing all entries of $\mathbf{Q}$ and $\mathbf{K}$ together randomly before quantization, any single massive outlier is spread out across many elements in the transformed vectors. This "smearing" effect ensures that no single element remains excessively large relative to others during the quantization step, significantly reducing rounding errors without altering the mathematical outcome of the attention mechanism.

The combination of these strategies yields remarkable empirical results on H100 GPUs. When tested against standard attention implementations using per-tensor scaling with outlier features simulated via mixed Gaussian distributions, FlashAttention-3 achieved a 2.6$\times$ reduction in numerical error for FP8 operations compared to baselines. Furthermore, by maintaining intermediate calculations in higher precision (like FP32) wherever possible and utilizing these smart preprocessing steps, FP16 FlashAttention-3 matches the accuracy of previous versions while delivering 1.5 to 2.0$\times$ speedups over FlashAttention-2. For FP8 specifically, the system reaches close to 1.2 PFLOPs/s, demonstrating that we no longer have to sacrifice accuracy for raw performance when pushing hardware limits.

Ultimately, FlashAttention-3 proves that hardware acceleration is not just about running existing algorithms faster; it requires rethinking how algorithms interact with physical constraints like memory layout and precision limits. By decoupling scaling factors via block quantization and decorrelating data distributions via random rotations, this work provides a robust blueprint for safe low-precision deep learning. As we move toward even shorter precisions like FP4 on future architectures like Blackwell, these principles will likely remain essential for ensuring that our AI systems remain both fast and reliable enough for production environments.
