\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### How is the control consistency metric defined and why is it reliable for evaluating controllable generation?
Question:
The paper introduces a new control consistency metric that compares the control signal extracted from the generated image to the original input control signal. For example, for the Canny‑to‑image task they compute IoU and F1. Could a reader explain the exact pipeline: which off‑the‑shelf detector or segmentation model is used, how the loss is computed, and why this metric is a better indicator of controllability than standard qualitative inspection?
Answer:
**Answer**

The *control consistency* metric is the authors’ concrete way of quantifying how faithfully a diffusion model follows a supplied control signal (e.g., a sketch, an edge map or a segmentation map).  
Instead of asking a human to judge “does the picture look like the sketch?”, they reconstruct a *predicted* control signal from the generated image and compare it directly with the *input* control signal.   
The closer the two signals are, the stronger the evidence that the model actually used the control signal during generation.

Below is the exact pipeline used in the paper, followed by a short discussion of why this assessment is more reliable than visual inspection.

----------------------------------------------------------------

### 1.  Pipeline for the Canny‑to‑Image (C2I) task  

| Step | What is used | Why |
|------|--------------|-----|
| **1.  Input** | A Canny edge map \(c_{\text{in}}\) (binary image) is fed to the fin‑tuned Stable Diffusion together with the text prompt. | This is the control signal that the model is supposed to honor. |
| **2.  Generation** | The diffusion model runs for the standard number of sampling steps (e.g., 50) and outputs a color image \(I_{\text{gen}}\). | Fixed inference setting so comparisons are fair. |
| **3.  Edge extraction** | `Canny` from OpenCV (or any fast edge detector) is applied to \(I_{\text{gen}}\) to produce a binary edge map \(c_{\text{out}}\). | The detector is the same algorithm used in the training stage of the Canny‑to‑image dataset, ensuring that the extracted edges are comparable to the input ones. |
| **4.  Metric computation** | The two binary maps are compared with the standard segmentation metrics:  
  * **IoU (Jaccard Index)**  
  \[
    \text{IoU} = \frac{|c_{\text{in}} \cap c_{\text{out}}|}{|c_{\text{in}} \cup c_{\text{out}}|}
  \]  
  * **F1 score** (also called Dice coefficient)  
  \[
    \text{F1} = \frac{2|c_{\text{in}} \cap c_{\text{out}}|}{|c_{\text{in}}| + |c_{\text{out}}|}
  \]  
  * **Pixel accuracy** (overall correctness) – optional. | These are standard, fully quantitative, rate‑free metrics that indicate how well the output edges line up with the input ones. |

The authors report the mean IoU / F1 over the validation set; higher values mean better control.

----------------------------------------------------------------

### 2.  General form for other control modalities  

| Modality | Detector / Recognizer | Output | Metric |
|----------|----------------------|--------|--------|
| **Segmentation‑to‑Image (S2I)** | A pre‑trained segmentor (e.g., BiSeNet, DeepLab‑v3+, or the SegFormer model fine‑tuned on ADE20K) applied to \(I_{\text{gen}}\). | Predicted class‑label masks \(\hat{s}_{\text{out}}\). | *Mean IoU*, *Mean Accuracy* (per–class), *Overall Accuracy* – exactly analogous to image segmentation benchmarks. |
| **Landmark‑to‑Face (L2F)** | Face‑landmark detector (e.g., MediaPipe or dlib) applied to \(I_{\text{gen}}\). | Predicted landmark set \(\hat{\ell}_{\text{out}}\). | Mean \(\ell_2\) distance to the input landmark set, optionally normalized by face size. |

The same logic applies: a detector that is widely used in the community (and therefore well‑behaved) is run on both the input control and the output image so that errors are purely due to the diffusion model.

----------------------------------------------------------------

### 3.  Why this is a more reliable indicator than visual inspection  

| Conventional qualitative test | Limitation | Control‑Consistency advantage |
|-------------------------------|------------|------------------------------|
| “Does the picture *look* like the sketch?” | Human judgement is subjective, low repeatability; hard to compare across methods or datasets. | *Objective*, numerically reproducible across runs and evaluations. |
| Inspect a handful of samples | Ignores statistical variation; a single good example can hide systematic failure. | Averages over the whole validation set reveal the true performance distribution. |
| Use a perceptual similarity (e.g., LPIPS) | Measures realism, not adherence to the control signal. | Directly measures the *faithfulness* of the generated control signal. |
| Rely on text‑prompt alignment (CLIP‑T) | Ties control to the text only, not to the control modality. | Is modality‑agnostic: works for edges, masks, landmarks, depth, etc. |

Because the same detector is applied both before and after generation, any bias in the detector (e.g., its own precision/recall) cancels out when measuring the *difference* between the two signals. Thus the metric directly quantifies how much of the original control structure survived the diffusion process.

----------------------------------------------------------------

### 4.  Summary  

1. **Pick an off‑the‑shelf detector** that best matches the control type (Canny = edge detector, segmentation = a segmentation network, landmark = a landmark detector).  
2. **Run the detector on both the input control and the generated image.**  
3. **Compute the usual segmentation metrics** (IoU, F1, accuracy etc.) between the two binary/label maps.  
4. **Average over all validation samples** to obtain the control‑consistency score.

This pipeline is deterministic, fully quantitative, and directly proportional to how well the model obeys the input control. It therefore serves as a robust benchmark for comparing controllable‑generation methods, and, as the paper shows, it consistently discriminates the superior performance of OFT/COFT over prior baselines.
