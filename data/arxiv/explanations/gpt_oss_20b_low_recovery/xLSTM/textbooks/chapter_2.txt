\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 2: **Foundations of the Long Short‑Term Memory Cell**  

The long‑short‑term memory (LSTM) unit, introduced in the early 1990s, has become the bedrock of every recurrent sequence model that has survived the age of self‑attention.  The LSTM’s analytical simplicity and its powerful biological intuition – a memory cell that can be updated, forgotten, and read without suffering exponential decay – is why it continues to pop up in every textbook on deep learning.  In this chapter we do more than just copy the textbook equations.  We dissect each algebraic ingredient, we translate the gates into intuitive mental images, and we trace the flow of gradients through the constant error carousel (CEC).  We then generalise the scalar cell to a vectorised, recurrent‑matrix version, showing explicitly how the algebra switches from element‑wise to matrix multiplication.  Finally we test the limits of the design by ablating individual gates and demonstrating what each component truly delivers.  

---  

## 1.  Mathematical Formulation of the LSTM Cell  

An LSTM cell processes an input vector \(\mathbf{x}_t \in \mathbb{R}^{d_x}\) at each discrete time step \(t\) and maintains two vectors: the **cell state** \(\mathbf{c}_t \in \mathbb{R}^{d_h}\) and the **hidden state** \(\mathbf{h}_t \in \mathbb{R}^{d_h}\).  The hidden state is emitted to downstream layers, while the cell state is a slowly changing memory that is guarded by gates.  

The canonical LSTM equations are  

\[
\begin{aligned}
\tilde{\mathbf{z}}_t &\;=\;\mathbf{W}_z^\top \mathbf{x}_t + \mathbf{U}_z^\top \mathbf{h}_{t-1} + \mathbf{b}_z  &&\text{pre‑activation of cell input} \\
\mathbf{z}_t &\;=\;\varphi(\tilde{\mathbf{z}}_t) &&\text{cell input (usually }\tanh{}) \\
\tilde{\mathbf{i}}_t &\;=\;\mathbf{W}_i^\top \mathbf{x}_t + \mathbf{U}_i^\top \mathbf{h}_{t-1} + \mathbf{b}_i &&\text{pre‑activation of input gate} \\
\mathbf{i}_t &\;=\;\sigma(\tilde{\mathbf{i}}_t) &&\text{input gate (range }[0,1]) \\
\tilde{\mathbf{f}}_t &\;=\;\mathbf{W}_f^\top \mathbf{x}_t + \mathbf{U}_f^\top \mathbf{h}_{t-1} + \mathbf{b}_f &&\text{pre‑activation of forget gate} \\
\mathbf{f}_t &\;=\;\sigma(\tilde{\mathbf{f}}_t) &&\text{forget gate (range }[0,1]) \\
\tilde{\mathbf{o}}_t &\;=\;\mathbf{W}_o^\top \mathbf{x}_t + \mathbf{U}_o^\top \mathbf{h}_{t-1} + \mathbf{b}_o &&\text{pre‑activation of output gate} \\
\mathbf{o}_t &\;=\;\sigma(\tilde{\mathbf{o}}_t) &&\text{output gate (range }[0,1]) \\
\mathbf{c}_t &\;=\;\mathbf{f}_t \odot \mathbf{c}_{t-1} \;+\; \mathbf{i}_t \odot \mathbf{z}_t &&\text{CEC cell update} \\
\mathbf{h}_t &\;=\;\mathbf{o}_t \odot \psi(\mathbf{c}_t) &&\text{hidden state}
\end{aligned}
\tag{1}
\]

Here, \(\odot\) denotes element‑wise multiplication.  The matrices \(\mathbf{W}_{\{z,i,f,o\}}\in\mathbb{R}^{d_x\times d_h}\) couple the current input to each gate, \(\mathbf{U}_{\{z,i,f,o\}}\in\mathbb{R}^{d_h\times d_h}\) couple the previous hidden state into the gates, and \(\mathbf{b}_{\{z,i,f,o\}}\in\mathbb{R}^{d_h}\) are biases.  The activation function \(\varphi\) is often \(\tanh\) and \(\psi\) is again \(\tanh\) or an equivalent squashing function to keep the cell state bounded.

### 1.1  Gate Pre‑activations and Biases  

The gate pre‑activations \(\tilde{\mathbf{i}}_t\), \(\tilde{\mathbf{f}}_t\), and \(\tilde{\mathbf{o}}_t\) are simple affine combinations of the current input and the previous hidden state.  The linearity implies that each gate can decide, locally, whether to pass information through or to block it.  Because the sigmoid activation \(\sigma(x) = 1/(1+\exp(-x))\) squashes its argument to \([0,1]\), the gate outputs can be interpreted as soft switches: a value close to 0 means “do not let this piece of information through,” and a value close to 1 means “let it fully pass.”

The cell input pre‑activation \(\tilde{\mathbf{z}}_t\) shares the same structure.  Its output \(\mathbf{z}_t\) is the new candidate content that could be mixed into the cell state, but the actual rate of mixing is controlled by the time‑varying input gate \(\mathbf{i}_t\).

### 1.2  Constant Error Carousel (CEC)  

The key to the LSTM’s ability to remember long‑range dependencies lies in the **CEC**:  

\[
\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \mathbf{z}_t.
\tag{2}
\]

The forget gate \(\mathbf{f}_t\) directly multiplies the previous cell state \(\mathbf{c}_{t-1}\).  If a component of \(\mathbf{f}_t\) is equal to 1, that component of the cell state passes through unchanged; if it is 0, that component is completely erased.  By learning to set \(\mathbf{f}_t\) close to 1 for crucial information and to values near 0 for irrelevant information, the cell prevents gradients from vanishing: the derivative of \(L\) w.r.t.\ \(\mathbf{c}_{t-1}\) contains the same term \(\mathbf{f}_t\), ensuring that information can propagate backwards in time unmodulated.

The addition by \(\mathbf{i}_t \odot \mathbf{z}_t\) supplies fresh content.  The two gates together allow the cell to be **write‑controlled** (through \(\mathbf{i}_t\)) and **read‑controlled** (through \(\mathbf{f}_t\)).  In classical terms, we can view \(\mathbf{c}_t\) as memory that is updated by a **write** (scaled by \(\mathbf{i}_t\)) and a **retain** (scaled by \(\mathbf{f}_t\)).  

The hidden state \(\mathbf{h}_t = \mathbf{o}_t \odot \psi(\mathbf{c}_t)\) is the output you see at each time step.  It is derived from the cell content, damped (through \(\psi\)) to stay within a manageable range, and filtered again by the output gate \(\mathbf{o}_t\).

## 2.  Interpretation of Input, Forget, and Output Gates  

Each gate has a distinct semantic role.  Visualising the LSTM cell as a **memory palace** can help:  

* **Input gate \(\mathbf{i}_t\):** a lock on the door that allows new information into the palace. If the lock is opened (value close to 1), new input flows in; if it is closed (value close to 0), the palace ignores new visitors.  
* **Forget gate \(\mathbf{f}_t\):** a janitor who decides which old memories to prune. A value close to 1 preserves what was stored, a value close to 0 erases it.  
* **Output gate \(\mathbf{o}_t\):** a window: it decides how much of the internal state is shown to the outside world. If it is closed (0), the LSTM keeps its content private; if it is open (1), it reveals everything.  

Because each gate is differentiable, the network learns *when* to open, close, or temper each of these three switches.  The gates are **input‑dependent** (via \(\mathbf{W}\mathbf{x}_t\)) and **hidden‑state‑dependent** (via \(\mathbf{U}\mathbf{h}_{t-1}\)), giving the model the ability to condition its memory dynamics on both the current observation and the past context.

## 3.  Cell State Update and the Importance of Squashing Activations  

An LSTM can, in principle, store unbounded numbers in \(\mathbf{c}_t\).  If the squashing function \(\psi\) were omitted, \(\mathbf{c}_t\) could grow arbitrarily large, causing numerical instability and vanishing or exploding gradients.  A squasher such as \(\tanh\) maps real values to the interval \([-1,1]\), preventing the cell from drifting too far away from zero.  

From a functional standpoint, the squashing operation also serves **non‑linear feature extraction**.  Substituting \(\psi\) with a larger‑range function such as \(\operatorname{relu}\) would massively change the dynamics: the cell could hold arbitrarily large positive values without being capped, which is rarely useful for sequence modelling.  Empirically, \(\tanh\) is the most common choice because it preserves the sign of the state while limiting its magnitude.

## 4.  Multiple Cell Variants and Recurrent Weight Matrices  

The vanilla scalar cell can be **vectorised** so that every time step updates a vector \(\mathbf{c}_t \in \mathbb{R}^d\).  In this form, the gates are no longer scalars but vectors of the same dimension.  Thus equations (1) remain valid component‑wise, but the recurrent matrices \(\mathbf{U}_{\{z,i,f,o\}}\) become \(d\times d\) matrices and can **mix** information across different memory cells.  

This mixing is sometimes called *memory mixing* or *hidden‑hidden connections*.  Since the recurrent matrices appear in the pre‑activations of all gates, the hidden state at time \(t-1\) can influence how all gates are modulated in the next time step.  Researchers have observed that this mechanism gives RNNs higher expressive power: it allows them to solve more intricate state‑tracking tasks than models that rely purely on point‑wise gating.  

**Extending to multiple rectangular weight matrices** leads to the **SRU** or **GRU**-like simplifications, but the essential CEC remains.  In advanced LSTM families such as sLSTM and mLSTM, the memory mixing is explicitly designed or deliberately removed to trade expressive power for parallelism.

## 5.  Empirical Sanity Checks: What Happens When Each Gate is Ablated  

A simple but revealing experiment is to **disable** one gate, i.e. force it to a constant value, and observe the performance deterioration on a language modelling benchmark such as Penn‑Treebank or WikiText‑103.  The results consistently match the intuition outlined earlier.  

| Ablated Gate | Setup | Expected Behaviour | Empirical Observation |
|--------------|-------|---------------------|-----------------------|
| **Input gate** fixed to 0 | No new information can enter the cell | Model forgets to write, performance collapses rapidly | Test accuracy plummets to random, training loss explodes |
| **Forget gate** fixed to 1 | Memory never decays | Model accumulates noise, can overfit | Accuracy degrades slowly but steadily |
| **Output gate** fixed to 1 | Hidden state always shows full cell | Model can exhibit high variability, but often still solves tasks | Minor performance hit compared to fully gated case |
| **All gates disabled** | Cell reduces to a linear recurrent network | Loss of expressive gating | Worse than any single gate ablation |

These ablation studies highlight that the *forget gate* is the most critical to prevent runaway growth, the *input gate* is essential for learning new facts, and the *output gate* mainly modulates the information exposed but does not change the underlying store.  The synergy of all three gates is what makes LSTM a robust memory system.

## 6.  Gradient Flow Through the CEC  

To understand why the CEC solves gradient vanishing, consider the partial derivative of a loss \(L\) with respect to the cell state at an earlier time \(\mathbf{c}_k\).  Unrolling the recurrence, we find  

\[
\frac{\partial L}{\partial \mathbf{c}_k} = \left(\prod_{t=k+1}^{T} \mathbf{f}_t\right) \frac{\partial L}{\partial \mathbf{c}_T}.
\tag{3}
\]

Because each \(\mathbf{f}_t\) contains sigmoid outputs bounded between 0 and 1, the product can be close to zero or close to one, but never vanishes exponentially with the depth \(T-k\).  This is the primary technical difference between an LSTM and a vanilla RNN: in the former, gradients can survive through long sequences, whereas in the latter the multiplication by small recurrent weights forces gradients to decay to zero.

---

## 7.  Summary  

The LSTM cell is a carefully engineered algebraic device.  Its four gates are not arbitrary layers; they are functional remotes that control **when to write**, **when to forget**, and **when to reveal** information.  The constant error carousel ensures that backward‑time gradients stay intact.  Squashing functions keep the state bounded while allowing rich non‑linear transformations.  Vectorised cells add memory mixing via recurrent weight matrices, boosting expressive power.  Empirical ablation confirms that all gates contribute meaningfully.  Understanding these details equips a student not only to implement LSTMs from scratch but also to extend them – as later chapters will show with exponential gating, matrix memories, and the generalisation to “xLSTM” – while still respecting the core principles that made the LSTM a cornerstone of recurrent neural networks.
