\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### How does the block-diagonal structure reduce parameters while maintaining orthogonality?
Question:
The OFT paper proposes using a block-diagonal orthogonal matrix $\bm{R}=\text{diag}(\bm{R}_1,\bm{R}_2,\cdots,\bm{R}_r)$ to reduce the number of trainable parameters from $\mathcal{O}(d^2)$ to $\mathcal{O}(d^2/r)$.

I understand that a block-diagonal matrix composed of orthogonal blocks is still orthogonal overall. But what does this mean for the transformation being applied? If I have 8 blocks instead of 1, does each block only transform a subset of the neuron dimensions? Does this mean neurons in different blocks cannot interact with each other through the transformation? What are the practical implications of this restriction?
Answer:
You've correctly identified the key trade-off of the block-diagonal structure. Let me clarify what this means both mathematically and practically.

**Yes, each block transforms an independent subset of dimensions.** With $r$ blocks, your $d$-dimensional space is partitioned into $r$ subspaces of dimension $d/r$. The transformation $\bm{R}$ applies a separate orthogonal transformation $\bm{R}_i$ to each subspace independently. Dimensions belonging to different blocks have no interaction—rotation in block 1 cannot affect dimensions in block 2.

**This is indeed a restriction on expressiveness.** A full orthogonal matrix can rotate any direction to any other direction, mixing all dimensions freely. With block-diagonal structure, you can only rotate within each $d/r$-dimensional subspace. The paper acknowledges this limitation in Section 6: "the parameter efficiency of OFT is largely dependent on the block diagonal structure which inevitably introduces additional biases and limits the flexibility."

**Why does this trade-off work well in practice?**

The key insight is that the paper applies OFT to weight matrices $\bm{W}^0 \in \mathbb{R}^{d \times n}$, transforming them as $\bm{W} = \bm{R}\bm{W}^0$. Each row of $\bm{W}^0$ corresponds to one input dimension. When you apply the block-diagonal $\bm{R}$, you're effectively saying: groups of input dimensions can be rotated together, but different groups rotate independently.

The paper notes an interesting interpretation for convolution layers in Section 6: "When we use the same number of blocks as the number of input channels, each block only transforms a unique neuron channel, similar to learning depth-wise convolution kernels."

**The practical significance is that orthogonality is preserved globally despite local structure.** Since each $\bm{R}_i$ satisfies $\bm{R}_i^\top\bm{R}_i = \bm{I}$, the full matrix satisfies $\bm{R}^\top\bm{R} = \bm{I}$. This means hyperspherical energy—the pairwise angular relationships between neurons—is still preserved exactly, which is OFT's core theoretical guarantee. What you sacrifice is the ability to rotate neurons from different blocks relative to each other, but the *relative angles within each block* remain invariant.

**The parameter reduction is substantial.** For $d=1024$ with $r=8$ blocks: a full orthogonal matrix needs $\frac{1024 \times 1023}{2} \approx 524,000$ parameters, while the block-diagonal version needs $\frac{1024 \times (128-1)}{2} \approx 65,000$ parameters—an $8\times$ reduction.
