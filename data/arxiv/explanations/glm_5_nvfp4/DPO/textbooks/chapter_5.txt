\title{A Textbook about the Paper: "Direct Preference Optimization: Your Language Model is Secretly a Reward Model"}

Chapter 5: # Experimental Evaluation

# Task 1: Controlled Sentiment Generation

The first experimental task explores controlled sentiment generation using the IMDb dataset, which provides a well-controlled setting for evaluating how efficiently algorithms can optimize the RLHF objective. In this experimental setup, the input $x$ represents a prefix of a movie review from the IMDb dataset, and the policy must generate a completion $y$ with positive sentiment. This task is particularly valuable for controlled evaluation because the researchers can generate preference pairs using a pre-trained sentiment classifier, where the preferred completion $y_w$ has a higher probability of being classified as positive than the dispreferred completion $y_l$, formally expressed as $p(\text{positive}\mid x,y_w) > p(\text{positive}\mid x,y_l)$. This automated preference generation allows for rigorous evaluation without the noise inherent in human preference labeling.

For the supervised fine-tuning phase, the researchers fine-tune GPT-2-large until convergence on reviews from the train split of the IMDb dataset. This creates the reference policy $\pi_\text{ref}$ from which preference pairs are sampled. The controlled nature of this task provides access to a ground-truth reward function—the sentiment classifier—which enables precise computation of the reward-KL frontier. This frontier is critical for understanding how effectively each algorithm balances the fundamental trade-off in RLHF: maximizing reward while minimizing divergence from the reference policy. The sentiment task thus serves as a clean testbed where the optimal policy can be characterized precisely, allowing for detailed analysis of algorithm behavior.

# Task 2: Summarization

The second experimental task addresses abstractive summarization using the Reddit TL;DR dataset, which presents a more realistic and challenging application of preference learning. In this setting, the input $x$ consists of a forum post from Reddit, and the policy must generate a summary $y$ that captures the main points of the post. This task follows the experimental protocol established in prior work, using the Reddit TL;DR summarization dataset along with human preferences gathered by Stiennon et al. This human preference data reflects genuine judgments about summary quality, making the task more representative of real-world preference learning scenarios.

The experimental setup for summarization uses an SFT model fine-tuned on human-written forum post summaries using the TRLX framework. Notably, the human preference dataset was gathered on samples from a different, but similarly-trained, SFT model, introducing a distribution shift that tests the robustness of the algorithms. For evaluation, the researchers sample completions on the test split of the TL;DR dataset and compute the average win rate against reference completions in the test set. This win rate metric captures whether the model's outputs align with human preferences more effectively than baseline approaches. The completions for all methods are sampled at temperatures varying from 0.0 to 1.0, allowing for analysis of how sampling temperature affects model performance.

# Task 3: Single-Turn Dialogue

The third experimental task examines single-turn dialogue using the Anthropic Helpful and Harmless dialogue dataset, which tests a model's ability to engage in helpful conversational interactions. In this setting, the input $x$ represents a human query, which may range from questions about astrophysics to requests for relationship advice. The policy must produce an engaging and helpful response $y$ to the user's query, requiring not just linguistic fluency but also the ability to provide relevant, useful information. The Anthropic HH dataset contains approximately 170,000 dialogues between a human and an automated assistant, providing a substantial preference dataset for training.

Each transcript in the Anthropic HH dataset ends with a pair of responses generated by a large language model along with a preference label denoting the human-preferred response. Importantly, in this setting, no pre-trained SFT model is available, which necessitates a different initialization strategy. The researchers therefore fine-tune an off-the-shelf language model on only the preferred completions to form the SFT model. This procedure, referred to as Preferred-FT, ensures that the reference policy generates completions within the distribution of the preference data. The lack of a standard SFT model for this task reflects real-world scenarios where practitioners may need to adapt generic language models to specific preference datasets.

# Evaluation Metrics

The experimental evaluation employs multiple complementary metrics to assess model performance comprehensively. The first metric, the reward-KL frontier, is used specifically in the controlled sentiment generation setting where access to the ground-truth reward function enables precise analysis. This frontier plots the achieved reward against the KL-divergence from the reference policy, characterizing how efficiently each algorithm trades off reward maximization against deviation from the original model. For each algorithm, multiple training runs are executed with different hyperparameters controlling policy conservativeness: target KL values of $\{3, 6, 9, 12\}$ for PPO, $\beta$ values of $\{0.05, 0.1, 1, 5\}$ for DPO, and varying $\alpha$ values for unlikelihood. After each 100 training steps until convergence, policies are evaluated on test prompts to compute average reward and average sequence-level KL, defined as the sum of the per-timestep KL-divergences.

For the summarization and dialogue tasks, where ground-truth reward functions are not available, the evaluation uses GPT-4 win rates as a proxy for human judgment. In the summarization setting, the win rate is computed against reference summaries in the test set, while in the dialogue setting, it is computed against the preferred response in the test dataset. To validate the reliability of GPT-4 as an evaluator, the researchers conducted a human study comparing GPT-4 judgments with human judgments. Two different GPT-4 prompts were evaluated: GPT-4 (S), which simply asks which summary better summarizes the important information, and GPT-4 (C), which also asks about conciseness. The results showed that with both prompts, GPT-4 tends to agree with humans about as often as humans agree with each other, suggesting that GPT-4 serves as a reasonable proxy for human evaluations. The GPT-4 (C) prompt was found to provide win rates more representative of humans and was therefore used for the main results.

# Baseline Methods

The experimental evaluation compares DPO against a comprehensive set of baseline approaches that represent the spectrum of methods for training language models to adhere to human preferences. The simplest baselines explore prompting strategies: zero-shot prompting with GPT-J in the summarization task and 2-shot prompting with Pythia-2.8B in the dialogue task. These baselines establish performance without any preference-based training. The SFT model itself serves as another baseline, representing performance from supervised fine-tuning on high-quality demonstrations without explicit preference learning.

The Preferred-FT baseline represents a model fine-tuned with supervised learning on the chosen completion $y_w$ from either the SFT model or a generic language model. This pseudo-supervised approach treats preference learning as a standard supervised learning problem. A related baseline is Unlikelihood, which optimizes the policy to maximize the probability assigned to $y_w$ while minimizing the probability assigned to $y_l$, using an optional coefficient $\alpha \in [0, 1]$ on the unlikelihood term. The PPO baseline trains using reinforcement learning with a reward function learned from the preference data, representing the standard RLHF approach. In the controlled sentiment setting, PPO-GT serves as an oracle that learns from the ground truth reward function, providing an upper bound on PPO performance. Two implementations of PPO-GT are used: an off-the-shelf version and a modified version with normalized rewards and tuned hyperparameters. Finally, the Best of $N$ baseline samples $N$ responses from the SFT model and returns the highest-scoring response according to a learned reward function. While this method decouples reward model quality from the PPO optimization, it is computationally impractical for deployment as it requires sampling $N$ completions for every query at test time.

# Results Analysis: Reward-KL Trade-off Efficiency

The analysis of the reward-KL frontier in the controlled sentiment generation task reveals DPO's superior efficiency in optimizing the RLHF objective. The results show that DPO produces by far the most efficient frontier, achieving the highest reward while maintaining low KL-divergence from the reference policy. This finding is particularly notable for several reasons. First, DPO and PPO optimize the same objective, yet DPO's reward/KL tradeoff strictly dominates PPO, demonstrating that the direct optimization approach is fundamentally more effective than the reinforcement learning approach. Second, DPO achieves a better frontier than PPO even when PPO has access to ground truth rewards through the PPO-GT oracle. This suggests that the advantages of DPO extend beyond simply avoiding the need to learn a reward model; the direct optimization paradigm itself offers computational advantages.

In the summarization experiments, DPO achieves a win rate of approximately 61% at temperature 0.0, exceeding PPO's performance of approximately 57% at its optimal sampling temperature of 0.0. DPO also achieves a higher maximum win rate compared to the Best of $N$ baseline. Notably, the researchers did not meaningfully tune DPO's $\beta$ hyperparameter, suggesting that these results may underestimate DPO's potential. Furthermore, DPO demonstrates much greater robustness to sampling temperature than PPO, whose performance degrades to that of the base GPT-J model at high temperatures. The Preferred-FT baseline does not improve significantly over the SFT model, indicating that naive supervised approaches are insufficient for preference learning.

For single-turn dialogue, DPO performs as well or better than the Best of 128 baseline, which serves as a rough proxy for PPO-level performance since both methods optimize the same reward function. DPO is the only computationally efficient method that improves over the preferred completions in the Anthropic HH dataset. The training dynamics show that DPO converges to its best performance relatively quickly, offering practical advantages for real-world deployment.

# Out-of-Distribution Generalization

To evaluate how DPO and PPO policies perform under distribution shift, the researchers tested models trained on the Reddit TL;DR summarization dataset on a different distribution: news articles from the CNN/DailyMail dataset. Using the best sampling temperatures from the TL;DR experiments (0 for PPO and 0.25 for DPO), policies were evaluated on the test split of CNN/DailyMail. The GPT-4 win rate was computed against ground-truth summaries using the same prompt structure, with "forum post" replaced by "news article" to match the new domain.

The results demonstrate that DPO continues to outperform the PPO policy by a significant margin on this new distribution. This experiment provides initial evidence that DPO policies can generalize similarly well to PPO policies, which is particularly noteworthy because DPO does not use the additional unlabeled Reddit TL;DR prompts that PPO uses during training. The PPO training procedure typically samples from the policy during training, which could potentially provide exposure to a broader distribution of prompts, yet DPO nonetheless matches or exceeds PPO's generalization capability. This finding suggests that the direct preference optimization paradigm does not sacrifice generalization ability despite its simpler training procedure, addressing a potential concern about whether bypassing explicit reward modeling might limit policy robustness.
