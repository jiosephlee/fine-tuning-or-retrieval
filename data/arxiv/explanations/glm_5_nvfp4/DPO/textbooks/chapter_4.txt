Chapter 4: # Theoretical Analysis of DPO

This chapter provides the theoretical foundations that justify Direct Preference Optimization. We will explore the mathematical structure that allows DPO to bypass explicit reward modeling while still optimizing the same objective as traditional RLHF methods. The key insight is that there exists a fundamental equivalence between certain reward functions, and DPO's reparameterization cleverly exploits this structure to obtain an analytically tractable optimal policy.

#
Understanding the relationship between different reward functions requires us to first establish what it means for two reward functions to be "equivalent." Intuitively, if two reward functions lead to the same behavioral outcomes—the same preference probabilities and the same optimal policies—they should be considered interchangeable for our purposes. This intuition motivates the formal definition of equivalence classes of reward functions.

We say that two reward functions $r(x, y)$ and $r'(x, y)$ are equivalent if and only if their difference is solely a function of the prompt $x$. Mathematically, this means $r(x, y) - r'(x, y) = f(x)$ for some function $f$. This definition captures an important property: adding a prompt-dependent offset to a reward function does not change the relative ordering of responses for any given prompt. Since preference models like Bradley-Terry only care about differences between rewards for the same prompt, such offsets become irrelevant.

To verify this is indeed an equivalence relation, we note that it satisfies the three required properties. Reflexivity holds trivially since $r(x, y) - r(x, y) = 0$, which is a function of $x$ (the constant zero function). Symmetry follows because if $r - r' = f(x)$, then $r' - r = -f(x)$, which is also a function of $x$. Transitivity holds because if $r - r' = f(x)$ and $r' - r'' = g(x)$, then $r - r'' = f(x) + g(x)$, the sum of two functions of $x$. This equivalence relation partitions the set of all possible reward functions into distinct equivalence classes.

#
The significance of this equivalence relation becomes clear when we consider two fundamental lemmas that establish the behavioral equivalence of reward functions within the same class.

The first lemma states that under the Plackett-Luce preference framework, and in particular the Bradley-Terry model, two reward functions from the same equivalence class induce the same preference distribution. This result follows directly from the structure of these preference models. In the Bradley-Terry model, the probability that response $y_1$ is preferred over $y_2$ is given by $p^*(y_1 \succ y_2 \mid x) = \sigma(r^*(x, y_1) - r^*(x, y_2))$, where $\sigma$ is the logistic function. If we replace $r^*$ with an equivalent reward $r' = r + f(x)$, the difference $r'(x, y_1) - r'(x, y_2) = (r(x, y_1) + f(x)) - (r(x, y_2) + f(x)) = r(x, y_1) - r(x, y_2)$. The offset term $f(x)$ cancels out, leaving the preference probability unchanged.

This lemma reveals a well-known under-specification issue with the Plackett-Luce family of models. Given only preference data, we cannot uniquely identify the reward function—there are infinitely many reward functions within each equivalence class that would produce identical preference probabilities. This under-specification typically requires imposing additional identifiability constraints to achieve guarantees on maximum likelihood estimates.

The second lemma establishes that two reward functions from the same equivalence class induce the same optimal policy under the constrained reinforcement learning problem. Recall that the RLHF objective optimizes a policy to maximize expected reward while staying close to a reference policy via a KL-divergence constraint. The optimal solution to this constrained problem takes the form $\pi_r(y \mid x) = \frac{1}{Z(x)}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}r(x, y)\right)$, where $Z(x)$ is the partition function. When we substitute an equivalent reward $r' = r + f(x)$, we obtain $\pi_{r'}(y \mid x) = \frac{1}{Z'(x)}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}(r(x, y) + f(x))\right)$. Since $\exp\left(\frac{1}{\beta}f(x)\right)$ depends only on $x$, it can be absorbed into the partition function, and the resulting optimal policy $\pi_{r'}$ equals $\pi_r$. This lemma is crucial: it tells us that for our final objective of finding the optimal policy, we only need to recover any single representative from the correct equivalence class of reward functions.

#
These lemmas naturally lead to the central theorem that justifies the DPO reparameterization. The theorem states that under mild assumptions, all reward classes consistent with the Plackett-Luce (and Bradley-Terry in particular) models can be represented with the reparameterization $r(x, y) = \beta \log \frac{\pi(y \mid x)}{\pi_\text{ref}(y \mid x)}$ for some model $\pi(y \mid x)$ and a given reference model $\pi_\text{ref}(y \mid x)$.

To understand why this theorem holds, consider any arbitrary reward function $r(x, y)$. This reward function induces a corresponding optimal model $\pi_r(y \mid x)$ according to the optimal policy equation. The key insight is to define a projection operator $f$ that maps $r$ to a specific member of its equivalence class. This projection is defined as $f(r; \pi_\text{ref}, \beta)(x, y) = r(x, y) - \beta\log\sum_{y}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}r(x, y)\right)$.

The projection operator works by subtracting the logarithm of the partition function from the original reward. Since the partition function $\sum_{y}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}r(x, y)\right)$ depends only on $x$, this subtraction produces a reward function in the same equivalence class as $r$. Now, using the relationship between the optimal policy and the reward function, we can rewrite the projected reward. Substituting the optimal policy expression into the projection formula yields $f(r; \pi_\text{ref}, \beta)(x, y) = \beta \log \frac{\pi_r(y \mid x)}{\pi_\text{ref}(y \mid x)}$. This shows that the projection produces exactly the DPO reparameterization form.

The theorem guarantees that the DPO reparameterization does not constrain the class of learnable reward models. Any reward function consistent with the preference model can be expressed in this form after an appropriate projection into its equivalence class. This is a powerful result: it means that by optimizing the policy directly using the DPO objective, we are effectively learning an implicit reward function that captures the preferences encoded in the data.

#
An alternative interpretation of the theorem clarifies exactly which reward function DPO selects within each equivalence class. The DPO reparameterization yields the unique reward function whose corresponding optimal policy $\pi(y \mid x)$ is a valid probability distribution—that is, it satisfies $\sum_{y}\pi(y \mid x) = 1$ with positive probabilities. This constraint corresponds to choosing the reward function for which the partition function in the optimal policy equation equals one.

This interpretation connects directly to the main insight of the DPO algorithm. The under-constrained nature of Plackett-Luce preference models means there are infinitely many reward functions compatible with any set of preference data. DPO imposes a specific constraint on this under-constrained problem: it selects the reward function that makes the optimal policy analytically tractable. Rather than requiring estimation of the intractable partition function, DPO's choice ensures the optimal policy can be expressed directly in terms of the policy and reference model alone.

This is why DPO can bypass explicit reward modeling entirely. The policy network $\pi_\theta$ serves a dual purpose: it generates text as a language model, and it implicitly defines a reward function through the relationship $\hat{r}_\theta(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_\text{ref}(y \mid x)}$. When we train the policy using the DPO loss function, we are simultaneously fitting an implicit reward model and optimizing the policy to maximize that reward under the KL constraint.

#
The theoretical advantages of DPO become particularly apparent when analyzing the instabilities inherent in actor-critic algorithms like PPO that are commonly used for RLHF. Understanding these instabilities helps clarify why DPO's simpler approach can actually produce better results.

Following the standard RLHF pipeline, the reinforcement learning fine-tuning step optimizes a parameterized policy $\pi_\theta(y \mid x)$ to minimize the KL-divergence from the optimal policy induced by a learned reward function $r_\phi$. When we formulate this objective using the control as inference framework, we obtain an expression that reveals a critical structural component: $\max_{\pi_{\theta}}\mathbb{E}_{\pi_{\theta}(y \mid x)}\left[r_{\phi}(x, y) -\beta\log\sum_{y}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}r_{\phi}(x, y)\right) - \beta\log\frac{\pi_{\theta}(y \mid x)}{\pi_\text{ref}(y \mid x)}\right]$.

The middle term in this objective, the normalization $-\beta\log\sum_{y}\pi_\text{ref}(y \mid x)\exp\left(\frac{1}{\beta}r_{\phi}(x, y)\right)$, can be interpreted as the negative soft value function of the reference policy. While this term does not affect the optimal solution—it is a constant with respect to the policy parameters—its presence has significant implications for the optimization process.

Without proper handling of this normalization term, the policy gradient of the objective can exhibit high variance. The gradient estimator must account for the baseline provided by this soft value function to achieve stable learning. In practice, actor-critic algorithms like PPO must learn a value function approximation to serve as this baseline. However, learning an accurate value function alongside the policy introduces additional complexity and potential failure modes. An poorly estimated value function can destabilize training, causing the policy to diverge or converge to suboptimal solutions.

Prior work has addressed this challenge through various approximations. Some approaches normalize rewards using a human completion baseline, essentially a single-sample Monte Carlo estimate of the normalizing term. While this can reduce variance, it introduces noise from the sampling process and requires additional human annotation. Other approaches learn neural network value function approximators, but these require careful tuning and additional computation.

#
DPO fundamentally sidesteps these instability issues by eliminating the need for value function approximation and reward normalization entirely. The key insight is that the DPO reparameterization automatically produces a reward function that is self-normalized.

Under DPO's reparameterization, the implicit reward function $\hat{r}_\theta(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_\text{ref}(y \mid x)}$ corresponds to a projected reward from the correct equivalence class. By construction, this reward function satisfies the property that the corresponding optimal policy $\pi_\theta$ is a valid probability distribution without requiring any additional normalization. The partition function is implicitly handled through the constraint that $\pi_\theta$ must sum to one over all possible responses.

This eliminates the need for a learned value function baseline. The DPO loss function directly compares the likelihood of preferred versus dispreferred responses, weighted by how incorrectly the current implicit reward model orders them. The gradient of the DPO loss has the form $\nabla_\theta \mathcal{L}_\text{DPO} = -\beta\mathbb{E}\left[\sigma(\hat{r}_\theta(x, y_l) - \hat{r}_\theta(x, y_w))\left[\nabla_\theta\log \pi(y_w \mid x) - \nabla_\theta\log\pi(y_l \mid x)\right]\right]$.

The weighting term $\sigma(\hat{r}_\theta(x, y_l) - \hat{r}_\theta(x, y_w))$ provides an adaptive importance weight. When the implicit reward model correctly orders the completions—assigning higher reward to the preferred response—this weight is small, reducing the gradient magnitude. When the model incorrectly assigns higher reward to the dispreferred response, the weight is large, amplifying the gradient to correct this error. This dynamic weighting emerges naturally from the mathematical structure of DPO and requires no explicit baseline computation.

In contrast to the high-variance policy gradient estimates in PPO, DPO provides a stable, low-variance optimization objective. The gradient directly increases the likelihood of preferred completions while decreasing the likelihood of dispreferred ones, with appropriate scaling to prevent model degradation. This explains why DPO can achieve better reward-KL frontiers than PPO even without access to ground truth rewards, and why it requires substantially less hyperparameter tuning—the optimization landscape is simply more benign.
