\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### Why does GRPO remove the critic/value function from PPO?
Question:
I'm trying to understand Group Relative Policy Optimization (GRPO) from the DeepSeekMath paper. The paper mentions that GRPO 'foregoes the critic model, instead estimating the baseline from group scores.'

I understand that in PPO, there's a value function that serves as a baseline for computing advantages. GRPO apparently removes this. But isn't the value function important for variance reduction? How can GRPO work effectively without it?

Also, what exactly are 'group scores' and how do they serve as a substitute for the learned value function?
Answer:
**Why GRPO Removes the Critic and How Group Scores Replace It**

In PPO, the value function $V_\psi$ serves as a baseline for computing advantages via Generalized Advantage Estimation (GAE), which reduces variance in policy gradient estimates. However, the DeepSeekMath paper identifies two significant problems with this approach in the LLM setting.

**The Problem with PPO's Value Function**

First, the value function is typically another model of comparable size to the policy model, creating substantial memory and computational burden. Second, in LLM RL training, the reward model typically only assigns a reward score to the last token of the output, making it difficult to train an accurate token-level value function. As the paper notes, this sparse reward structure "may complicate the training of a value function that is accurate at each token."

**How GRPO's Group Scores Work**

GRPO eliminates the value function by using a different baseline strategy. For each question $q$, GRPO samples a group of $G$ outputs $\{o_1, o_2, \ldots, o_G\}$ from the old policy $\pi_{\theta_{\text{old}}}$. The reward model scores each output, yielding rewards $\mathbf{r} = \{r_1, r_2, \ldots, r_G\}$.

The key insight is that these rewards are normalized within the group:

$$\widetilde{r}_i = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$$

This normalized reward serves as the advantage $\hat{A}_{i,t}$ for all tokens in output $o_i$. The group mean $\text{mean}(\mathbf{r})$ acts as the baseline, effectively replacing the learned value function.

**Why This Maintains Effective Variance Reduction**

The paper explains that "the group relative way that GRPO leverages to calculate the advantages, aligns well with the comparative nature of rewards models, as reward models are typically trained on datasets of comparisons between outputs on the same question."

Since reward models are fundamentally comparative—they learn to distinguish better outputs from worse ones—using the group average as a baseline naturally captures this comparative structure. Outputs that score above average receive positive advantages, while those below receive negative ones. The standard deviation normalization ensures the magnitude of these advantages remains stable across different groups.

This approach essentially treats the problem as a within-group ranking task, which sidesteps the need to estimate absolute values while still providing the variance reduction benefits of having a baseline. The result is a more memory-efficient algorithm that maintains effectiveness for mathematical reasoning tasks.
