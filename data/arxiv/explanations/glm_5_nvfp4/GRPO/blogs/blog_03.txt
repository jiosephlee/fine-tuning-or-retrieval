\title{Blogs about the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

# Does Coding Make You Better at Math? Surprising Lessons from DeepSeekMath

The relationship between coding and mathematical reasoning in Large Language Models (LLMs) has long been a subject of debate. Does training a model on code genuinely improve its ability to reason, or does it just make the model better at writing Python scripts? The recent DeepSeekMath paper provides compelling answers to this question through rigorous ablation studies, while simultaneously challenging some entrenched assumptions about other data sources.

DeepSeekMath 7B is a model that approaches the performance of GPT-4 on the competition-level MATH benchmark. However, the lessons learned during its development—particularly regarding pre-training data—are just as valuable as the model itself.

## The Code Connection: A Foundation for Reasoning

A popular hypothesis in the AI community suggests that code training improves general reasoning capabilities. DeepSeekMath puts this to the test specifically within the mathematical domain. The researchers found that initializing the model with DeepSeek-Coder-Base-v1.5 7B was superior to starting with a general LLM.

The paper details experiments comparing different training regimes, such as two-stage training (Code $\rightarrow$ Math) versus one-stage training (Code + Math mixture). The findings reveal that code training offers a distinct advantage.

First, code training benefits program-aided mathematical reasoning. This is intuitive; if a model understands code syntax and logic, it can better utilize tools like Python to solve mathematical problems. However, the surprising discovery is that code training also improves mathematical reasoning *without* tool use.

In the two-stage training setting, an initial phase of code training resulted in moderate enhancements in solving math problems purely through text. More importantly, it boosted the efficiency of the subsequent math training phase, eventually leading to the best performance. The researchers observed that code training improves the model's ability to solve problems both with and without tools, offering a partial answer to the long-standing question: code training does, in fact, improve reasoning abilities, at least for mathematics.

## The ArXiv Anomaly: Quality Over Quantity

While the benefits of code training align with some intuitions, the paper's findings regarding ArXiv papers are counter-intuitive. It is common practice to include scientific papers from ArXiv in mathematical pre-training data, under the assumption that high-quality scientific text leads to better reasoning.

DeepSeekMath challenges this assumption. The researchers experimented with different corpora, including MathPile (over 85% ArXiv content) and ArXiv-RedPajama. They trained DeepSeek-LLM 1.3B and DeepSeek-Coder-Base-v1.5 7B on these datasets.

The results were striking. When trained on an ArXiv-only corpus, models displayed no notable improvements or even deterioration across various mathematical benchmarks. This held true for quantitative reasoning datasets like GSM8K and MATH, multiple-choice challenges like MMLU-STEM, and formal mathematics tasks like miniF2F.

This suggests that simply feeding a model "math-related" text does not guarantee improved mathematical reasoning. The researchers hypothesize that while ArXiv is vast, it may not provide the specific type of reasoning signals required to solve the benchmarks used for evaluation. However, the authors note that this conclusion has limitations; they did not test specific tasks like theorem informalization or the effect of ArXiv data at much larger model scales.

## Conclusion

The DeepSeekMath paper provides two critical lessons for building math-capable models. First, code training is a powerful precursor to math training, enhancing the model's logical faculties and improving outcomes even when tools are not involved. Second, more data is not always better; the common reliance on ArXiv papers may need re-evaluation, as they showed no notable benefits on standard mathematical benchmarks.

The success of DeepSeekMath was largely driven by the construction of a high-quality corpus from Common Crawl using a meticulously engineered data selection pipeline. This demonstrates that when it comes to pre-training data, careful curation often trumps sheer volume.
