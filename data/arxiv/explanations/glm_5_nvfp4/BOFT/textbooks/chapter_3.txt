Chapter 3: # An Information Transmission Framework

## Matrix Factorization as Information Transmission

The quest for parameter-efficient orthogonal finetuning leads us to a fundamental question: can we construct a dense orthogonal matrix without sacrificing parameter efficiency? At first glance, this might seem infeasible, since a $d$-dimensional dense orthogonal matrix typically requires $\mathcal{O}(d^2)$ parameters. However, the key insight lies in composing a dense orthogonal matrix through the product of multiple sparse matrices. To develop intuition for this approach and to establish a principled framework for designing such factorizations, we introduce an information transmission perspective that reframes the problem of generating dense orthogonal matrices.

Consider the task of generating a dense matrix $\bm{R} \in \mathbb{R}^{d \times d}$ through the product of $m$ square matrices: $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$. We can interpret this matrix factorization as an information transmission problem on a grid-structured graph. The motivation stems from a simple yet powerful observation: a $d$-dimensional dense square matrix represents dense connectivity from $d$ nodes to another $d$ nodes. When we examine the individual elements of matrix $\bm{R}$, each element carries semantic meaning in terms of information flow. Specifically, if the element $R_{ij}$ equals zero, this indicates that information from the $j$-th node cannot flow to the $i$-th node. Conversely, if $R_{ij}$ is non-zero, information transmission between these nodes becomes possible.

This interpretation allows us to view the factorization $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$ as a sequential process of information exchange. Rather than allowing information to flow directly from source to destination in a single hop, we route it through intermediate stages, with each stage governed by a factor matrix $\bm{B}_i$. The information flows following $\bm{B}_1$ first and $\bm{B}_m$ last, creating a cascade of transformations that ultimately determines which source-destination pairs remain connected. This framework transforms the abstract algebraic problem of matrix factorization into an intuitive graphical problem of network connectivity, enabling us to leverage insights from graph theory and computer networking to design efficient factorizations.

## Grid-Structured Graph Representation of Matrix Multiplication

To make the information transmission framework concrete, we construct a formal correspondence between matrix factorization and graph structure. The graph is the result of unrolling the matrix multiplication, creating a layered grid structure with $d \times (m+1)$ nodes, where $d$ is the matrix dimension and $m$ is the number of factor matrices. Each layer of nodes corresponds to a stage in the matrix multiplication process.

Within this grid-structured graph, each factor matrix $\bm{B}_i$ serves as the connectivity matrix from the $i$-th level nodes to the $(i+1)$-th level nodes. More specifically, the $(j_1, j_2)$ element of $\bm{B}_i$ encodes the presence or absence of a directed edge from the $j_2$-th node in the $i$-th level to the $j_1$-th node in the $(i+1)$-th level. A zero element indicates no edge exists, while a non-zero element indicates an active connection. This one-to-one correspondence between matrix entries and graph edges provides a powerful visualization tool for understanding how sparsity patterns affect information flow.

As a concrete illustration, consider the factorization $\bm{R} = \bm{B}_5 \bm{B}_4 \bm{B}_3 \bm{B}_2 \bm{B}_1$ for a matrix of dimension $d = 4$. For the final composed matrix $\bm{R}$ to be dense, every node in the first level must be able to transmit information to every node in the sixth level. However, examining intermediate products reveals how information propagates through the network. For instance, considering only $\bm{R} = \bm{B}_4 \bm{B}_3 \bm{B}_2 \bm{B}_1$, we might find that information from node 1 cannot reach node 3, corresponding to a zero element at position $(3, 1)$ in this intermediate product. This demonstrates that the sparsity pattern of any intermediate product can be directly read from the graph connectivity between the corresponding levels.

The general principle emerges clearly: for a matrix $\bm{R} \in \mathbb{R}^{d \times d}$ to be dense, the $m$ factorization matrices must correspond to a set of directed edges on a $d \times (m+1)$ grid where each directed edge connects only two nodes between adjacent levels. The constraint that edges span only adjacent levels reflects the sequential nature of matrix multiplication—information cannot skip levels. The connectivity requirement demands that information from every node in the first level can reach every node in the $(m+1)$-th level through some path.

## Desiderata for Efficient Factorization: Dense Connectivity and Minimum Free Edges

The information transmission framework provides clear criteria for designing efficient orthogonal matrix factorizations. To achieve our goal of composing a dense orthogonal matrix using multiple sparse orthogonal matrices with minimal trainable parameters, we establish two fundamental desiderata.

The first desideratum is **dense connectivity**: every node in the first level must have at least one path to every node in the last level. This requirement ensures that the final composed matrix $\bm{R}$ has no zero entries—it is truly dense. Dense connectivity guarantees that every source node can influence every destination node, preserving the full representational capacity we seek. Without dense connectivity, the composed matrix would contain zeros, limiting its expressiveness and potentially introducing undesirable inductive biases.

The second desideratum is **minimum free edges**: the total number of edges should be as small as possible under the orthogonality constraint. This criterion directly addresses parameter efficiency, as each edge beyond those mandated by orthogonality represents a trainable parameter. Minimizing free edges while maintaining dense connectivity captures the essence of efficient factorization—achieving maximal information transmission with minimal parameter cost.

The orthogonality constraint introduces subtle but important restrictions on edge patterns. For each factor matrix $\bm{B}_i$ to be orthogonal (and thus full-rank), we require $d$ edges forming a bijection between all nodes in level $i$ and all nodes in level $(i+1)$. This means the number of edges between adjacent levels must be at least $d$. These $d$ edges are necessary for orthogonality and should not be counted as trainable parameters because their values are constrained—for a $d \times d$ orthogonal matrix with exactly $d$ non-zero entries, these entries can only be $\pm 1$, leaving no degrees of freedom for learning.

Beyond this minimal set, orthogonality creates additional dependencies among edges that complicate the counting. For example, in a $2 \times 2$ orthogonal matrix, a zero at position $(1,1)$ forces a zero at position $(2,2)$—one missing edge implies another missing edge due to orthogonality constraints. Conversely, adding certain edges may necessitate adding others to maintain orthogonality. These dependencies mean that simply counting edges does not directly translate to counting trainable parameters, but the framework still provides valuable intuition about the relative efficiency of different factorization patterns.

To appreciate the potential efficiency gains, consider that a naive dense connection between two levels requires $\mathcal{O}(d^2)$ edges, yielding $d^2 - d$ trainable edges for $d = 4$, this equals 12 edges. However, a carefully designed factorization can achieve the same dense connectivity with fewer edges. The example factorization presented in the paper takes only 10 edges in total, fewer than a single dense orthogonal matrix. This demonstrates that matrix factorization can genuinely reduce parameter requirements while maintaining expressivity.

## Analyzing Block-Diagonal Sparsity via Information Flow

The information transmission framework illuminates the limitations of the block-diagonal structure employed in the original Orthogonal Finetuning (OFT) method. Block-diagonal OFT parameterizes the orthogonal matrix $\bm{R}$ as $\text{diag}(\bm{R}_1, \bm{R}_2, \cdots, \bm{R}_r)$, where each $\bm{R}_i \in \mathbb{R}^{b \times b}$ is a small orthogonal matrix and $br = d$. This structure reduces the number of trainable parameters by decomposing the high-dimensional orthogonal transformation into independent low-dimensional transformations.

Viewing this structure through the lens of information transmission reveals its fundamental limitation: the block-diagonal structure cannot construct a dense matrix $\bm{R}$. Consider what this means in graphical terms. The block-diagonal sparsity pattern partitions the $d$ nodes into $r$ disjoint groups, with each group containing $b$ nodes. Information can only flow within each group—nodes in different groups remain isolated from each other. This partitioning means that source nodes in one group cannot send information to destination nodes in another group, resulting in large zero blocks in the final composed matrix.

The block-diagonal structure introduces a strong assumption: the dimensions of a neuron (represented as a column vector of the weight matrix $\bm{W}^0$) are divided into $r$ groups, and dimensions in different groups are transformed independently using different orthogonal matrices. Despite the empirical effectiveness of this approach, this assumption lacks justification. There is no principled reason to divide the dimensions of a neuron into groups based purely on their indices—this arbitrary partitioning may not reflect any meaningful structure in the underlying problem.

Moreover, the block-diagonal orthogonal matrix reduces expressiveness and cannot approximate classic linear transforms. Many important transformations, such as discrete Fourier transforms or discrete cosine transforms, require information exchange across all dimensions—transformations that the block-diagonal structure fundamentally cannot represent. The question of how to find a good sparsity pattern thus remains a mystery, motivating the search for alternative structures that can achieve dense connectivity more naturally.

## The Need for Dense Orthogonal Matrices

The limitations of block-diagonal sparsity motivate our pursuit of dense orthogonal matrices. Dense matrices are desirable for several compelling reasons that extend beyond mere parameter counting.

First, dense orthogonal matrices eliminate the arbitrary partitioning assumption inherent in block-diagonal structures. When dimensions are grouped arbitrarily, we implicitly assert that certain dimensions share more computational affinity than others—a claim that lacks theoretical justification. Dense matrices allow all dimensions to interact, preserving the full relational structure of the original weight matrix without imposing artificial constraints.

Second, dense orthogonal matrices possess greater expressiveness. Theorem 1 establishes that BOFT is more expressive than OFT with the same block size, meaning the butterfly matrix represents a more structured subset of the orthogonal group compared to the block-diagonal structure. This expressiveness is not merely theoretical—butterfly structures can perfectly recover many classic fast linear transforms including the discrete Fourier transform, Hadamard transform, and discrete sine/cosine transform. The block-diagonal structure cannot recover any of these transforms, highlighting a fundamental gap in representational capacity.

Third, dense matrices enable smoother interpolation between different transformations. BOFT uses the butterfly structure to construct a smoother interpolation between matrices from the full orthogonal group (expressivity) and identity matrices (regularity). This interpolation property is crucial for finetuning, where we want to balance preserving pretrained knowledge (staying close to identity) with adapting to new tasks (expressivity). The block-diagonal structure, with its hard partitioning, creates discontinuities in this interpolation.

The challenge, of course, is achieving density without sacrificing parameter efficiency. A naive dense orthogonal matrix requires $\mathcal{O}(d^2)$ parameters, defeating the purpose of parameter-efficient finetuning. This apparent dilemma leads us to the key insight: we can achieve density through clever factorization rather than direct parameterization.

## Trading Computation Time for Parameter Space

The resolution to the density-efficiency trade-off lies in a fundamental insight: the number of trainable parameters can be reduced by trading computation time for space. This trade-off is foundational in computer science, appearing in contexts from algorithm design to hardware architecture. Here, we apply it to matrix parameterization.

The key observation is that representing an orthogonal matrix as a product of sparse matrices shifts the computational burden. Instead of storing a dense matrix with $\mathcal{O}(d^2)$ parameters, we store multiple sparse matrices, each with $\mathcal{O}(d)$ parameters. However, this compact storage comes with a computational cost: the matrix multiplications must be performed repeatedly during each training iteration. During forward propagation, we must multiply through the sequence of sparse matrices to obtain the effective transformation.

This trade-off is highly favorable for finetuning scenarios. Training time is abundant—models undergo many iterations during finetuning. Memory, on the other hand, is the critical constraint: we want to adapt large models while keeping trainable parameters minimal. By accepting more computation per forward pass, we dramatically reduce storage requirements from $\mathcal{O}(d^2)$ to $\mathcal{O}(d \log d)$ when using butterfly factorization.

The information transmission framework helps us understand why this trade-off works. A single dense orthogonal matrix represents a "direct" information transmission scheme—all possible source-destination connections are explicitly stored. This is like having a complete graph with all $\mathcal{O}(d^2)$ edges present. Factorization into sparse matrices instead represents an "indirect" routing scheme—information takes multiple hops through intermediate nodes to reach its destination. Each hop requires only local connectivity (sparse matrices), but the composition of multiple hops achieves global connectivity (dense matrix).

The butterfly structure, borrowed from the Cooley-Tukey fast Fourier transform algorithm, represents an optimal design for this routing problem. The butterfly network achieves dense connectivity with only $\mathcal{O}(d \log d)$ edges, far fewer than the $\mathcal{O}(d^2)$ required for direct connectivity. For example, when $d = 4$, a naive dense orthogonal matrix requires 12 trainable parameters beyond the mandatory edges, while a butterfly network achieves the same connectivity with only 8 edges. As dimensionality increases, this advantage grows: for large $d$, the butterfly structure offers exponential savings in parameters while maintaining the ability to construct dense matrices.

Importantly, this computational overhead exists only during training. After finetuning, the learned orthogonal matrices can be directly multiplied into the pretrained model, eliminating any additional inference latency. The product of sparse matrices yields a single dense matrix that replaces the original weight transformation, ensuring that the efficiency gains during training do not impose costs during deployment.
