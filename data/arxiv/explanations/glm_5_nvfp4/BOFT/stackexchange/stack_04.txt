\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why can't the block-diagonal structure in OFT recover classic linear transforms?
Question:
The paper states that 'the block-diagonal orthogonal matrix... cannot approximate classic linear transforms' while 'the butterfly structure can easily recover many classic linear transforms.' I understand that block-diagonal matrices apply transformations independently within blocks, but why exactly does this prevent them from representing transforms like the discrete Fourier transform? What is it about the butterfly structure that enables this recovery?
Answer:
The key insight lies in understanding how information flows through the matrix structure, which the paper elegantly explains through its information transmission framework.

## Why Block-Diagonal Cannot Recover Transforms Like DFT

A block-diagonal orthogonal matrix has the form $\text{diag}(\bm{R}_1, \bm{R}_2, \ldots, \bm{R}_r)$ where each $\bm{R}_i$ is a small orthogonal matrix operating on a subset of dimensions. The fundamental limitation is that **entries connecting different blocks are permanently zero**.

Consider what this means for transforms like the Discrete Fourier Transform (DFT). The DFT matrix $\bm{F}$ is completely dense—every frequency component depends on **every** input coordinate. Specifically, the $(k, j)$-th entry of the DFT matrix is $\omega^{kj}/\sqrt{d}$ where $\omega = e^{-2\pi i/d}$, which is non-zero for all $(k, j)$ pairs.

A block-diagonal structure fundamentally cannot represent such dense mixing because information from dimension $j$ can only affect dimensions within its assigned block. There's no mechanism for information to flow across block boundaries—dimensions in different groups are transformed completely independently.

## Why Butterfly Structure Succeeds

The butterfly structure, inspired by the Cooley-Tukey FFT algorithm, overcomes this by using a **product of sparse matrices with different sparsity patterns**:

$$\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$$

Each butterfly component $\tilde{\bm{B}}^b_{(d,i)}$ is block-diagonal, but critically, **the block structure shifts between successive factors**. This is where the magic happens.

In the information transmission view from the paper, this creates a multi-layer graph where:
- Each factor corresponds to connections between adjacent layers
- The shifting block pattern ensures that over $\mathcal{O}(\log d)$ layers, **every node eventually connects to every other node**

For example, at layer 1, dimension $j$ might only connect to dimensions $\{j, j+1\}$. But at layer 2, those dimensions connect to a different set, and so on. After $\log d$ layers, there exists a path from any source node to any destination node.

This is precisely how the Cooley-Tukey algorithm achieves the DFT in $\mathcal{O}(n \log n)$ operations: it decomposes the transform into a sequence of smaller transforms that progressively mix information across larger spans of the input. The butterfly structure **naturally encodes this hierarchical mixing pattern**.

## Summary

The block-diagonal structure imposes permanent separation between dimension groups, making it impossible to achieve the dense, global mixing required by transforms like DFT. The butterfly structure achieves dense connectivity through sequential multiplication of matrices with different sparsity patterns—each multiplication "mixes" information a bit further, and after $\log d$ steps, all dimensions have potentially interacted with all others. This is why the paper emphasizes that "the butterfly structure can easily recover many classic linear transforms" while the block-diagonal structure "cannot approximate classic linear transforms."
