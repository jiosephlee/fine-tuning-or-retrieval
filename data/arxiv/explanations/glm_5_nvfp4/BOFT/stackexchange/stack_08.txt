\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### What is the relationship between BOFT($1$,$b$) and block-diagonal OFT?
Question:
The paper states that 'BOFT($1$,$b$) reduces to the block-diagonal OFT with the block size $b$.' I'm trying to verify this. If $m=1$, then $\bm{R}(1,b) = \tilde{\bm{B}}^b_{(d,1)} = \tilde{\bm{B}}^b(d,2^m) = \tilde{\bm{B}}^b(d,2)$. The paper defines $\tilde{\bm{B}}(d,k)$ as 'a block-diagonal matrix of size $d \times d$ with block size $k$'. But I'm confused about the relationship between $b$ and the block size in the resulting block-diagonal OFT. Could someone walk through this reduction step by step?
Answer:
You're on the right track, but there's a key notational convention that resolves this. Let me walk through the reduction step by step.

The crucial detail is in how the paper defines the BOFT notation: "For convenience, we denote BOFT with $\bm{R}(m,\frac{b}{2})$ as $\mathrm{BOFT}(m, b)$."

This means $\mathrm{BOFT}(m, b)$ actually uses $\bm{R}(m, \frac{b}{2})$, not $\bm{R}(m, b)$. So when $m=1$:

$$\bm{R}(1, \tfrac{b}{2}) = \tilde{\bm{B}}^{b/2}_{(d,1)} = \tilde{\bm{B}}^{b/2}(d, 2^{1-1+1}) = \tilde{\bm{B}}^{b/2}(d, 2)$$

Now, what is $\tilde{\bm{B}}^{b/2}(d, 2)$? The block butterfly component $\tilde{\bm{B}}^b(d,k)$ is defined such that "each entry in $\bm{d}_i,\forall i$ becomes a $b\times b$ matrix."

For $k=2$, the butterfly factor $\bm{B}^F(2)$ is a $2\times 2$ matrix where each entry is a scalar (since $\bm{d}_i \in \mathbb{R}^{k/2} = \mathbb{R}^1$). With the block generalization $\tilde{\bm{B}}^{b/2}(d, 2)$, each scalar entry becomes a $\frac{b}{2} \times \frac{b}{2}$ matrix. Since there are 4 entries arranged in a $2\times 2$ grid, the resulting block butterfly factor has size:
$$2 \times \tfrac{b}{2} = b$$

So each block in $\tilde{\bm{B}}^{b/2}(d, 2)$ is a $b \times b$ matrix, and there are $\frac{d}{b}$ such blocks. This is precisely a block-diagonal orthogonal matrix with block size $b$, which matches the definition of block-diagonal OFT.

To summarize the relationship between $b$ in $\mathrm{BOFT}(1, b)$ and the block size:
- $\mathrm{BOFT}(1, b)$ uses the superscript $\frac{b}{2}$ in the block butterfly component
- The butterfly factor has 4 entries (a $2\times 2$ structure)
- Each entry is a $\frac{b}{2} \times \frac{b}{2}$ matrix
- Effective block size: $2 \times \frac{b}{2} = b$

This confirms the paper's statement that "$\mathrm{BOFT}(1, b)$ reduces to the block-diagonal OFT with the block size $b$." The notation is designed so that the block size of the resulting orthogonal matrix matches the parameter $b$ in $\mathrm{BOFT}(m, b)$.
