Chapter 2: # Foundations: The Original LSTM Architecture

The Long Short-Term Memory (LSTM) architecture represents one of the most influential developments in the history of deep learning. Introduced in the 1990s, LSTMs addressed fundamental limitations that had plagued recurrent neural networks, particularly the vanishing gradient problem. Understanding the original LSTM architecture provides essential background for appreciating the extensions and modifications introduced in modern variants. This chapter provides a comprehensive review of the standard LSTM architecture, establishing the baseline knowledge required for understanding subsequent developments in sequence modeling.

## The Constant Error Carousel and Gating Mechanisms

The central innovation of the LSTM lies in two key ideas: the constant error carousel and gating. These mechanisms work in concert to enable the network to learn long-range dependencies in sequential data, overcoming the fundamental limitations of earlier recurrent architectures.

The constant error carousel refers to the additive update structure of the cell state. In traditional recurrent neural networks, information is transformed through repeated applications of non-linear functions, causing gradients to either vanish or explode during backpropagation through time. The LSTM circumvents this issue through a clever architectural choice: the cell state is updated additively rather than being directly transformed. The equation governing this update is:

$$c_t = f_t c_{t-1} + i_t z_t$$

This deceptively simple equation encapsulates the essence of the constant error carousel. The cell state $c_{t-1}$ from the previous time step is preserved and scaled by the forget gate $f_t$, rather than being passed through a non-linear transformation. The new information $z_t$ is added to this preserved state, moderated by the input gate $i_t$. This additive structure ensures that the gradient can flow backward through time without being repeatedly multiplied by potentially small derivatives, which is the root cause of vanishing gradients.

The gating mechanism provides the network with fine-grained control over information flow. Gates act as learnable filters that determine what information should be stored, forgotten, or output at each time step. The use of sigmoid activation functions for gates ensures that their outputs are bounded between zero and one, allowing them to act as multiplicative filters. A gate value close to zero effectively blocks information flow, while a value close to one allows information to pass through largely unimpeded.

The beauty of the gating mechanism lies in its adaptability. The gates are not fixed thresholds but rather learnable parameters that are computed based on the current input and the previous hidden state. This means the network learns over time what information is relevant to keep and what can be discarded, adapting its behavior to the specific requirements of the task at hand. The forget gate, for instance, learns to identify when previously stored information is no longer relevant and should be purged from memory.

## Mathematical Formulation of the Standard LSTM Forward Pass

A precise understanding of the LSTM requires examining the complete mathematical formulation of its forward pass. The LSTM maintains a cell state $c_t$ and a hidden state $h_t$ at each time step, which together form the memory of the network. The cell state serves as the internal memory that can maintain information over long time periods, while the hidden state represents the output that is exposed to other layers or used for predictions.

The cell state update follows the equation:

$$c_t = f_t c_{t-1} + i_t z_t$$

Here, $f_t$ represents the forget gate, $i_t$ the input gate, and $z_t$ the cell input. The forget gate determines how much of the previous cell state should be retained, while the input gate controls how much new information should be added. The cell input $z_t$ is the candidate information to be stored, computed as:

$$z_t = \varphi(\tilde{z}_t)$$

where $\varphi$ is typically the $\tanh$ activation function, and $\tilde{z}_t$ is the pre-activation:

$$\tilde{z}_t = \mathbf{w}^\top_{z} \mathbf{x}_t + r_{z} h_{t-1} + b_{z}$$

The weight vector $\mathbf{w}_{z}$ connects the input $\mathbf{x}_t$ to the cell input, while $r_{z}$ is the recurrent weight connecting the previous hidden state $h_{t-1}$ to the cell input. The bias term $b_{z}$ provides an additional learnable offset.

The hidden state is derived from the cell state through:

$$h_t = o_t \tilde{h}_t$$

where $o_t$ is the output gate and $\tilde{h}_t$ is the normalized cell state:

$$\tilde{h}_t = \psi(c_t)$$

The function $\psi$ serves to squash or normalize the cell state, which would otherwise be unbounded. This is typically implemented as a $\tanh$ function, bounding the normalized state between negative one and positive one. The output gate $o_t$ then determines how much of this normalized state should be exposed as the hidden state output.

The three gates each follow a similar computational pattern. The input gate is computed as:

$$i_t = \sigma(\tilde{i}_t)$$

with pre-activation:

$$\tilde{i}_t = \mathbf{w}^\top_{i} \mathbf{x}_t + r_{i} h_{t-1} + b_{i}$$

Similarly, the forget gate follows:

$$f_t = \sigma(\tilde{f}_t)$$

$$\tilde{f}_t = \mathbf{w}^\top_{f} \mathbf{x}_t + r_{f} h_{t-1} + b_{f}$$

And the output gate is given by:

$$o_t = \sigma(\tilde{o}_t)$$

$$\tilde{o}_t = \mathbf{w}^\top_{o} \mathbf{x}_t + r_{o} h_{t-1} + b_{o}$$

In all three cases, $\sigma$ denotes the sigmoid function:

$$\sigma(x) = \frac{1}{1 + \exp(-x)}$$

This function smoothly maps its input to the range $(0, 1)$, making it ideal for gating purposes. Each gate receives input from both the current external input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$, allowing the network to make context-dependent decisions about information flow.

## The Role of the Input, Forget, and Output Gates

Each gate in the LSTM architecture serves a distinct and crucial purpose. Understanding the role of each gate provides insight into how the LSTM manages its internal memory and controls information flow.

The input gate $i_t$ controls the extent to which new information flows into the cell state. When the input gate is close to zero, the cell blocks new information from being stored, preserving its existing content. When the input gate is close to one, the network readily accepts new information. This mechanism allows the LSTM to be selective about what it learns, focusing on inputs that are relevant to the task while ignoring irrelevant noise. The input gate essentially answers the question: "Is the current input worth remembering?"

The forget gate $f_t$, introduced after the original LSTM formulation, provides the complementary ability to remove information from the cell state. By scaling the previous cell state, the forget gate determines how much of the existing memory should be retained. A forget gate value close to one preserves the existing memory largely intact, while a value close to zero effectively erases the cell state, making room for entirely new information. This is particularly important for tasks where the network must learn to forget information that is no longer relevant, such as when processing a new sentence in a paragraph or a new sequence element. The forget gate answers the question: "Should I keep what I previously remembered?"

The output gate $o_t$ controls the extent to which the cell state influences the hidden state and, consequently, the network's output. Even if valuable information is stored in the cell state, it only affects the network's behavior if the output gate allows it to pass through. This provides an additional layer of control, enabling the network to maintain internal state that may be useful later but should not influence current predictions. The output gate essentially decides: "Should I reveal my memory right now?"

The interaction between these gates creates a sophisticated memory management system. Consider processing a long document: the input gate might open to store important names or concepts, the forget gate might close to preserve this information across many time steps, and the output gate might selectively expose relevant memories when answering questions about the document. This coordinated gating enables the LSTM to maintain and manipulate information over extended sequences.

## Understanding Memory Mixing via Hidden-Hidden Recurrent Connections

A fundamental aspect of the LSTM architecture is the concept of memory mixing, which occurs through the hidden-hidden recurrent connections. In the basic formulation presented above, each gate and the cell input receive input from the previous hidden state $h_{t-1}$ through recurrent weights. This creates pathways through which information from one memory cell can influence another, enabling complex interactions within the network's memory.

When multiple memory cells are combined in a vector $\mathbf{c}_t \in \mathbb{R}^{d}$, the architecture naturally extends to use recurrent weight matrices $\mathbf{R} \in \mathbb{R}^{d \times d}$ to mix the cell outputs of different memory cells. This means that each memory cell's gates can be influenced not only by its own previous state but also by the hidden states of other cells. This cross-cell communication enriches the representational capacity of the network, allowing it to develop specialized but interconnected memory units.

The memory mixing mechanism serves several important functions. First, it enables the network to develop distributed representations, where information is stored across multiple cells rather than being confined to individual units. Second, it allows for complex state transitions, where the activation patterns across cells can capture sophisticated patterns in the input sequence. Third, it facilitates the learning of hierarchical representations, where higher-level cells can build upon information stored in lower-level cells.

However, this memory mixing comes with a computational cost: it enforces sequential processing. Because each time step's computation depends on the hidden state from the previous time step, the network cannot process multiple time steps in parallel. This inherent sequentiality, while beneficial for modeling temporal dependencies, creates a limitation in terms of computational efficiency, particularly on modern hardware that excels at parallel computation. This trade-off between representational power and computational efficiency has motivated various extensions and modifications to the original LSTM architecture.

## The Vanishing Gradient Problem and How LSTMs Address It

To fully appreciate the significance of the LSTM architecture, one must understand the vanishing gradient problem that plagued earlier recurrent neural networks and how the LSTM's design specifically addresses this issue.

The vanishing gradient problem arises during training when gradients are propagated backward through time. In traditional recurrent neural networks, the hidden state at time $t$ depends on the hidden state at time $t-1$ through a non-linear transformation. When computing gradients with respect to parameters at earlier time steps, the chain rule requires multiplying derivatives through each time step. If these derivatives are consistently less than one, their product shrinks exponentially as the number of time steps increases. This means that gradients from distant time steps become vanishingly small, making it extremely difficult for the network to learn long-range dependencies.

The LSTM addresses this problem through the constant error carousel. The key insight is that the cell state update $c_t = f_t c_{t-1} + i_t z_t$ is additive rather than fully transformative. When computing the derivative of the cell state at time $t$ with respect to the cell state at time $t-k$, the gradient flows through the forget gate multiplications rather than through repeated non-linear transformations. If the forget gate maintains values close to one, the gradient can flow backward through time with minimal attenuation.

This is fundamentally different from standard recurrent networks where the hidden state is transformed by a non-linear activation function at each step. Each transformation introduces a derivative that must be multiplied into the gradient chain, and these derivatives are often less than one, causing the gradient to vanish. The LSTM's additive structure, combined with the learned gating, allows the network to maintain gradient flow over arbitrarily long sequences when appropriate.

The gates play a crucial role in this process. During training, the network learns to set the forget gate to values that preserve important information, effectively creating paths where gradients can flow. The input gate controls when new information should be integrated, and the output gate determines when stored information should influence predictions. Together, these mechanisms enable the LSTM to learn which information is worth preserving and for how long, directly addressing the core challenge that motivated its design.
