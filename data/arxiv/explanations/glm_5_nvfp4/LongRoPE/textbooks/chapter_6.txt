\title{A Textbook about the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

Chapter 6: # Experimental Evaluation and Results

Understanding how to evaluate methods for extending language model context windows requires a comprehensive examination of both the experimental methodology and the empirical findings. This chapter provides a detailed analysis of the experimental validation of LongRoPE, covering the complete evaluation framework from setup through results. By examining these experiments carefully, we gain insight not only into the effectiveness of the specific method but also into the broader principles of how context window extension should be assessed.

The experimental evaluation of context window extension methods must address several distinct challenges. First, we need to verify that the extended model can actually process and utilize longer sequences effectively. Second, we must ensure that extending the context window does not degrade performance on shorter sequences within the original context window. Third, we need to understand whether the theoretical benefits of non-uniform positional interpolation translate into practical improvements. The experimental design we examine here addresses all of these concerns through a carefully constructed set of evaluation tasks.

# Experimental Setup: Models and Baselines

The experimental framework centers on two widely-used large language model architectures: LLaMA2-7B and Mistral-7B. These models serve as representative examples of modern LLMs that employ Rotary Position Embedding (RoPE), making them suitable testbeds for evaluating positional interpolation methods. LLaMA2-7B has an original context window of 4096 tokens, while Mistral-7B also operates within a similar range. The choice of these models is particularly meaningful because they represent different design philosophies in modern LLM development, and demonstrating effectiveness across both architectures provides strong evidence for the generalizability of the method.

The fine-tuning process differs between the two model families, reflecting their distinct training dynamics and architectural considerations. For LLaMA2, the fine-tuning employs a learning rate of $2 \times 10^{-5}$ with linear decay and a global batch size of 32. The training proceeds in two phases: an initial 400 steps on the Redpajama dataset, which is chunked into 128k segments and properly bounded with beginning-of-sequence and end-of-sequence tokens, followed by an additional 600 steps to reach the target 256k context window. The computational requirements scale with the target context length, where training for 128k context size requires 8 A100 GPUs, while the 256k extension demands 16 A100 GPUs. This staged approach to training proves more efficient than directly fine-tuning to 256k, as it allows the model to gradually adapt to longer sequences.

For Mistral, the fine-tuning configuration takes a different approach suited to that model's characteristics. A constant learning rate of $1 \times 10^{-6}$ is employed alongside a larger global batch size of 64. Following the methodology established in prior work on YaRN, both the 128k and 256k models undergo 400 training steps on Together Computer's Long-Data Collections, using a sequence length of 16k. This configuration requires 4 A100 GPUs for training. The use of a 16k training length, while shorter than the target extension, reflects practical considerations in training efficiency, though as we shall see, this choice has implications for the ultimate extension capability.

The search algorithm for identifying optimal RoPE rescale factors operates with carefully chosen hyperparameters. For target context window sizes within 256k, the evolutionary search uses a population size $P=64$, with mutation and crossover sizes $N_1 = N_2 = 16$. The mutation probability $p$ is set to 0.3, and the algorithm runs for a maximum of $\mathcal{T}=40$ iterations, selecting the top-32 individuals for mutation and crossover in each iteration. The perplexity metric guiding the search is calculated using 5 random samples from the PG19 validation set, with each sample meeting a minimum length requirement equal to the target context length. For context windows exceeding 512k tokens, the population, mutation, and crossover sizes are halved to manage computational costs, and perplexity evaluation uses 3 random samples from the Pile-Books3 validation set.

The baselines against which LongRoPE is compared represent the state-of-the-art in context window extension methods. These include Together-32k, which represents a production-quality extended context model; Code LLaMA, which achieves context extension through large-scale fine-tuning; LongLoRA-full-FT-100k, demonstrating efficient fine-tuning approaches; and various implementations of positional interpolation methods including PI, NTK, Dynamic-NTK, and YaRN applied to both LLaMA and Mistral. The LongRoPE models are specifically designated as LongRoPE-2048k (ft=128k) and LongRoPE-2048k (ft=256k) for LLaMA2 and Mistral respectively, indicating the fine-tuning length used before the final extension to 2048k.

The evaluation itself encompasses three distinct categories of tasks, each designed to probe different aspects of extended context capability. First, perplexity evaluation on long documents directly measures the language modeling capability of the extended models. Second, passkey retrieval provides a synthetic but precise measure of the effective context window—the maximum length at which the model can reliably extract information. Third, standard benchmarks evaluated within the original context window size ensure that extension does not compromise performance on typical tasks.

# Perplexity Analysis on Long Documents

Perplexity serves as a fundamental metric for evaluating language model quality, measuring how well a probability model predicts a sample. In the context of extended context windows, perplexity analysis reveals whether the model can effectively leverage longer context to improve its predictions. A well-functioning extended model should show decreasing perplexity as context length increases, indicating that additional context provides useful information for prediction.

The evaluation employs three distinct datasets, each chosen to provide different perspectives on model performance. The PG19 dataset provides a comprehensive test of long-document language modeling, using the entire test split of 100 documents. The Proof-pile dataset, which contains mathematical and scientific texts, follows the established evaluation protocol of randomly selecting 10 samples, each with at least 128k tokens in length. For the extremely long context evaluation beyond 2000k tokens, the Books3 dataset is employed, with 20 books selected that each exceed 2048k tokens. The use of a sliding window approach—with window size 256 for shorter evaluations and 256k for the longest contexts—ensures consistent measurement across different context lengths.

The results within the 256k context window range demonstrate clear patterns of effectiveness. The extended models show an overall decreasing perplexity trend from 4k to 256k evaluation lengths, providing strong evidence that these models can successfully leverage longer context. This pattern of decreasing perplexity is particularly significant because it indicates that the model is not merely tolerating longer sequences but actually benefiting from the additional context information. A model that simply accepts longer inputs without degrading would maintain constant perplexity; the observed decrease suggests genuine utilization of extended context.

Even with a context window 16 times longer than typical—a condition that normally challenges the preservation of shorter-length performance—the LongRoPE-2048k models outperform state-of-the-art baselines within the 256k context length. This result is remarkable because it demonstrates that achieving extreme extension does not require sacrificing performance at intermediate lengths. The non-uniform positional interpolation preserves critical positional information even when scaling to very long contexts.

The evaluation beyond 2000k tokens reveals both the successes and limitations of the extension approach. LongRoPE successfully extends both LLaMA2-7B and Mistral-7B's context windows to 2048k tokens while achieving perplexity comparable to or superior than baselines operating at much shorter lengths of 8k-128k. This result validates the central claim of achieving context windows beyond 2 million tokens while maintaining competitive performance.

However, the two model families exhibit notably different behavior patterns at extreme lengths. LLaMA2's performance aligns with theoretical expectations: perplexity decreases gracefully with longer contexts, showing only marginal increases at 1024k and 2048k. This pattern suggests that LLaMA2 successfully leverages the extended context throughout the full range of evaluated lengths. The slight perplexity increases at the extreme end are consistent with the model operating near the boundary of its effective context window.

Mistral presents a different profile. While it outperforms baselines at shorter lengths, its perplexity exceeds 7 beyond 256k tokens. This behavioral difference can be traced back to the different fine-tuning configurations employed. For Mistral, the fine-tuning used a 16k sequence length rather than the full target length, which affects the model's ability to extend its context window after fine-tuning. This finding highlights an important principle: the training sequence length during fine-tuning influences the ultimate extension capability, and shorter training sequences may limit how far the context window can be pushed.

The comparison between LongRoPE-2048k models fine-tuned at different lengths further illuminates these dynamics. For LLaMA2, the model fine-tuned at 256k performs better than the one fine-tuned at 128k. This advantage stems from the smaller secondary extension ratio—extending from 256k to 2048k represents an 8$\times$ extension, while extending from 128k to 2048k requires a 16$\times$ extension. The smaller extension ratio proves easier for the non-uniform positional interpolation to handle, resulting in better preservation of positional information.

# Passkey Retrieval: Validating the Effective Context Window

While perplexity provides a continuous measure of language modeling quality, the passkey retrieval task offers a more direct assessment of what researchers call the "effective context window"—the practical limit within which a model can reliably retrieve specific information from a long context. This task has become a standard benchmark in context window extension research precisely because it provides unambiguous, binary outcomes: either the model successfully retrieves the hidden passkey or it does not.

The passkey retrieval task operates through a carefully designed synthetic evaluation protocol. A random passkey, defined as a five-digit number, is hidden somewhere within a long document composed primarily of irrelevant text. The model must identify and extract this passkey when prompted. The task is performed across 10 iterations, with the passkey placed at a random location uniformly distributed across the evaluation context length. This randomization ensures that the evaluation tests retrieval capability across the entire context window rather than focusing on specific positions.

The results reveal a stark contrast between LongRoPE and existing methods. Existing models' retrieval accuracy rapidly drops to 0 beyond 128k tokens, indicating that their effective context window ends around that threshold. In contrast, LongRoPE-LLaMA2-2048k (ft=256k) maintains retrieval accuracy at or above 90% from 4k all the way to 2048k tokens. This sustained high accuracy across such an extreme length range demonstrates that the extended context window is genuinely functional—the model can actually access and retrieve information from any position within the 2-million-token context.

The Mistral variant shows similarly impressive, though slightly different, behavior. LongRoPE-Mistral-2048k (ft=128k) maintains perfect 100% accuracy up to 1800k tokens, with accuracy dropping to 60% at the full 2048k length. This performance profile aligns with the perplexity observations discussed earlier, where Mistral showed slight increases in perplexity at the extreme 2048k length. The drop to 60% at 2048k, while not perfect, still represents a dramatic improvement over baseline methods that cannot function at all beyond 128k.

The passkey retrieval results carry significant implications for practical applications. A model that can retrieve specific information from anywhere in a 2-million-token context opens possibilities for tasks that were previously infeasible. For example, processing entire codebases, analyzing complete books or document collections, or maintaining coherent conversations over extended interactions all become tractable with such extended context windows.

# Performance on Standard Benchmarks Within the Original Context Window

A critical concern in context window extension is whether achieving longer contexts compromises performance on shorter, standard tasks. This concern arises because positional interpolation fundamentally modifies how position information is encoded, and these modifications might not be neutral with respect to performance on sequences within the original context window. The evaluation therefore includes standard benchmarks designed for the original 4096-token context window to assess this potential degradation.

The evaluation uses the Hugging Face Open LLM Leaderboard, a widely-recognized benchmark suite, in both zero-shot and few-shot settings. The specific tasks include 25-shot ARC-Challenge, which tests reasoning about scientific concepts; 10-shot HellaSwag, evaluating common sense reasoning about physical situations; 5-shot MMLU, covering diverse academic and professional knowledge; and 0-shot TruthfulQA, measuring the model's tendency to generate truthful versus hallucinated responses.

The results demonstrate that LongRoPE-2048k models achieve comparable results on these original benchmarks. This finding is significant because it addresses one of the primary concerns about context window extension: that modifying positional embeddings might introduce systematic biases or artifacts that degrade general performance. The preservation of benchmark performance indicates that the non-uniform positional interpolation successfully extends the context window while leaving the underlying language model capabilities intact.

An especially notable result is that LongRoPE-Mistral-2048k actually outperforms the original Mistral on TruthfulQA by 0.5 percentage points. This improvement, while modest, suggests that the extension process does not merely preserve capabilities but may in some cases enhance them. The mechanism behind this improvement remains an interesting question for future research, though it may relate to better calibration of position information across the model's computations.

The LongRoPE-LLaMA2-2048k model fine-tuned at 256k shows slightly more performance degradation on some benchmarks compared to its 128k fine-tuned counterpart, but the differences remain within reasonable ranges for most tasks. This slight degradation represents a trade-off: better performance at extreme lengths comes with marginal cost in short-context performance. The practical significance of this trade-off depends on the specific use case—applications requiring the full 2048k context may accept small short-context performance variations, while applications primarily working within standard context lengths might prefer configurations optimized for that regime.

# Ablation Studies: Impact of the Second Interpolation and Non-uniformities

Ablation studies serve to isolate the contribution of individual components to overall performance, providing insight into which design choices matter and why. The LongRoPE ablation experiments examine three key aspects: the effectiveness of the second positional interpolation, the recovery mechanism for shorter context lengths, and the contribution of each form of non-uniformity.

The progressive extension strategy employs a second non-uniform positional interpolation on the already fine-tuned extended model. To validate this approach, experiments extend the fine-tuned LLaMA2-256k model to 512k, 1024k, and 2048k using both the proposed method and comparison methods (PI and YaRN). The results demonstrate that non-uniform positional interpolation sustains a consistent level of perplexity across these extension ratios, while the comparison methods show perplexity that quickly increases as the extension ratio grows. This finding validates the central insight that non-uniform interpolation, discovered through evolutionary search, handles large extension ratios more gracefully than methods based on fixed formulas or human-designed rules.

The recovery mechanism for shorter context lengths addresses the observation that extending to extremely long contexts can degrade performance on shorter sequences. The mechanism performs an additional evolutionary search specifically for short context lengths (4k and 8k), decreasing the maximum allowable scale factors to encourage less interpolation. The perplexity comparison of LongRoPE-LLaMA2-2048k on Proof-pile at 4k and 8k lengths, combined with average benchmark accuracy measurements, demonstrates significant performance improvements at short context lengths. This result confirms that the recovery mechanism successfully mitigates the crowding effect that positional interpolation can introduce at shorter lengths.

The analysis of the two forms of non-uniformities examines their individual and combined contributions. Experiments extend LLaMA2-7B to short lengths (16k and 32k) using three approaches: standard PI, searching only for RoPE dimension non-uniformity, and searching for both non-uniformities together. Additional experiments extend the fine-tuned 256k LLaMA2 to 2048k using the same procedure.

The results reveal that non-uniformity in RoPE dimension significantly reduces perplexity compared to PI's linear interpolation. This finding confirms that different RoPE dimensions require different treatment—a uniform approach loses information that can be preserved through dimension-specific rescaling. Non-uniformity in token position—the differential treatment of initial tokens—clearly improves performance at 16k and 32k lengths. However, at the extreme 2048k length, the token position non-uniformity does not show the same impact. This difference may occur because preserving only initial tokens without interpolation becomes less useful when the sequence spans such extreme lengths. The practical importance of initial tokens may be diluted when the context contains millions of tokens. This observation points to a limitation of the current approach and suggests directions for future research: understanding how different non-uniformities scale with extension ratio could lead to even more effective interpolation strategies.

# Comparative Analysis with State-of-the-Art Extension Methods

Placing the experimental results in context requires a systematic comparison with existing approaches to context window extension. The comparative analysis reveals both the relative strengths of different methods and the specific advantages that non-uniform positional interpolation provides.

Position Interpolation (PI), which serves as a foundational baseline, applies linear scaling across all RoPE dimensions with rescale factor $\lambda = s$ equal to the extension ratio. This uniform approach introduces the "crowded positions" problem, where position information becomes compressed as all positions are scaled down uniformly. The experimental results consistently show PI underperforming at high extension ratios, with perplexity degrading and retrieval accuracy falling as extension increases. PI requires fine-tuning to function at any extension ratio beyond very small increases.

NTK-based methods, including dynamic NTK, introduce the principle of differential treatment across dimensions. By scaling lower (high frequency) dimensions less and higher (low frequency) dimensions more, these methods avoid some crowding effects. Dynamic NTK adjusts the extension ratio at each position based on current sequence length. While these methods can extend context windows without fine-tuning up to approximately 4$\times$, they struggle beyond that threshold. The experimental comparisons show that while NTK approaches outperform PI at moderate extension ratios, both are eventually surpassed by methods that more carefully optimize the interpolation.

YaRN represents the state-of-the-art prior to LongRoPE, dividing RoPE dimensions into three frequency-based groups with different interpolation strategies for each. The grouping depends on human-designed rules based on empirical observations. The experiments reveal that YaRN sometimes underperforms even PI and NTK at certain evaluation points, particularly when it does not reach the target context window length for non-fine-tuned models. For instance, YaRN's perplexity spikes after 7k tokens in an 8k context size evaluation. This finding suggests that human-designed groupings may not be optimal for all models and extension ratios.

LongRoPE addresses these limitations through automated search rather than human-designed rules. The evolutionary search discovers optimal rescale factors for each dimension and identifies the optimal token position threshold $\hat{n}$ for initial token preservation. The comparative results demonstrate that this automated, data-driven approach consistently outperforms methods based on theoretical principles alone. The 8$\times$ extension achieved without fine-tuning represents a substantial improvement over the approximately 4$\times$ limit of previous methods.

The comparison also reveals practical advantages beyond raw performance metrics. The LongRoPE approach maintains model architecture with only minor modifications to positional embeddings, allowing reuse of existing optimizations and infrastructure. Models extended via LongRoPE can leverage most pre-existing implementations, making deployment more straightforward than approaches requiring architectural changes.

The progressive extension strategy, while adding complexity to the training pipeline, proves essential for achieving extreme extension ratios. Direct fine-tuning to 2048k tokens would face prohibitive computational costs and convergence challenges. The progressive approach—extending to 256k with fine-tuning, then applying a second interpolation to reach 2048k—balances computational efficiency with effective extension. The experimental validation shows that this approach achieves results comparable to what one might expect from direct training, had such training been feasible.
