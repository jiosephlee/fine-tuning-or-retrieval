\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### What exactly is exponential gating in sLSTM and why does it help with revising stored information?
Question:
I understand that in sLSTM the input and forget gates can use an exponential activation instead of the usual sigmoid. The forward equations (eq. 5) show that the normalizer state $n_t$ is updated with the same gates, and the hidden state uses $c_t/n_t$. I am still unclear on two points: (1) How does gating with $	ext{exp}$ allow a previously stored value to be overwritten by a later, more relevant key? (2) What is the role of the normalizer state – why is it necessary for exponential gating, and how does it maintain numerical stability during long sequences?
Answer:
**Short answer**

Exponential gating turns the forget and input gates from bounded values in $(0, 1)$ into *unbounded* multiplicative scalars.  
Because the memory updates are linear—$c_t=f_t\,c_{t-1}+i_t\,z_t$—an exponential forget gate can *fully erase* any part of the previous memory (by making $f_t$ very small) while an exponential input gate can inject a new value with *any* magnitude.  
The normalizer state $n_t$ keeps a running sum of all past input‑gate coefficients; it is used to scale the hidden state $h_t=o_t\,c_t/n_t$.  This normalisation guarantees that the hidden output stays in a reasonable range even when $c_t$ has been amplified or attenuated by many exponentials, preventing overflow/underflow over arbitrarily long sequences.

### 1.  Why exponential gating lets a new key overwrite an old one

In a plain LSTM the gates are sigmoid outputs $\sigma(\tilde f),\sigma(\tilde i)\in(0,1)$.  Thus

$$
c_t=f_t\,c_{t-1}+i_t\,z_t
    = f_{t}\bigl(f_{t-1}c_{t-2}+i_{t-1}z_{t-1}\bigr)+i_tz_t,
$$

so $c_{t-2}$ is always multiplied by a factor in $(0,1)$.  
No matter how many time steps pass, the contribution of an earlier cell is *never completely eliminated*; it can only be diminished to a tiny fraction but never reconstructed to its original magnitude.  Consequently, once a key has been written into the cell, later occurrences of the same or a more relevant key add on top of it instead of replacing it.

With exponential gates we replace $\sigma$ by $\exp$, so

$$
f_t = e^{\tilde f_t}, \qquad i_t = e^{\tilde i_t},
$$

and each gate can take any positive value.  Let us consider two consecutive writes of the same key $\mathbf{k}$:

* At time $t_1$: $c_{t_1}=f_{t_1}c_{t_0}+i_{t_1}\mathbf{k}$.
* At time $t_2>t_1$: $c_{t_2}=f_{t_2}c_{t_1}+i_{t_2}\mathbf{k}
                        = (f_{t_2}f_{t_1})c_{t_0}
                          + (f_{t_2}i_{t_1}+i_{t_2})\,\mathbf{k}$.

If at $t_2$ we set $f_{t_2}\ll 1$ (e.g. from a very negative $\tilde f_{t_2}$) and give $i_{t_2}$ a large value, the coefficient of the old contribution $(f_{t_2}f_{t_1})c_{w_0}$ becomes negligible while the new coefficient satisfies

### 3.  Intuition from probabilistic models

You can think of an exponential gate as defining a *multiplicative random walk* instead of an additive one:

* The standard sigmoid forget gate only allows shrinking memory; it behaves like a decay factor.
* An exponential forget gate allows **both decay and amplification**, turning the memory into a *Markov chain with unbounded transition weights*.  
  This flexibility mirrors that used in associative memories such as BAMs or Fast Weight Programmers: key‑value pairs are stored by outer‑product updates whose magnitude may grow unboundedly until later overwritten.



Because recall depends on relative alignment rather than absolute magnitude (the denominator normalises), this multiplicative structure is perfectly suited for memorising useful tokens while being able to discard outdated ones on demand.



### 4.  Practical outcome

Empirically (see §4.3–4.5), models that use exponential gating together with normalization (`xLSTM`) outperform vanilla LSTMs on:

* **Nearest‑neighbor search** – they can overwrite earlier approximations with later better matches.
* **Long‑range associative recall** – they can store many key/value pairs without interference.
* **Language modeling at scale** – they yield lower perplexities than Transformers and SSMs on billions‑token corpora.



The normalizer plays an essential role: without it overflow would make inference useless even in short sequences; with it sLSTM behaves like a stable associative memory capable of revising its content online.



**Bottom line:** Exponential gating gives sLSTM extra control over how much influence previously stored items exert on future states; combined with the running normalizer that matches this influence you obtain an RNN capable of both amplifying important signals and safely discarding irrelevant ones—exactly what is required for “revising stored information’’ in long sequential tasks.
