Answer:
**Deriving the GSPO gradient from Eq.~(10) to Eq.~(11)**  
(We keep the notation of the paper throughout.)  

---------------------------------------------------------------------

### 1.  GSPO objective (Eq.~(10))

\[
\mathcal{J}_{\text{GSPO}}(\theta)\;=\;
\E_{\,x\sim \mathcal{D},\,\{y_i\}\sim \pi_{\theta_{\text{old}}}}
\Bigg[
  \frac{1}{G}\sum_{i=1}^{G}
  \min \bigl(
      s_i(\theta)\,\widehat A_i,\;
      \texttt{clip}\bigl(s_i(\theta),\,1-\varepsilon,\,1+\varepsilon\bigr)\,\widehat A_i
    \bigr)
\Bigg].
\]

For the derivation we drop the clipping (its gradient is structurally identical) and write

\[
\mathcal{J}(\theta)=
\E_{\,x,\{y_i\}}\!
 \Big[ 
   \frac{1}{G}\sum_{i=1}^{G} s_i(\theta)\,\widehat A_i 
 \Big].
\]

> **Why \(s_i(\theta)\) contains \(|y_i|\) in the denominator?**  
> In the definition of the *sequence‑level* importance ratio we normalize by the length of the response so that values for different‑length sequences are comparable and its variance is reduced (see section 3). Concretely,
> \[
> s_i(\theta)=
>   \Bigl(\frac{\pi_\theta(y_i|x)}{\pi_{\theta_{\text{old}}}(y_i|x)}\Bigr)^{1/|y_i|}
> = \exp\!\Bigl(
>   \tfrac{1}{|y_i|}\sum_{t=1}^{|y_i|}
>       \log\frac{\pi_\theta(y_{i,t}\mid x,y_{i,<t})}
>              {\pi_{\theta_{\text{old}}}(y_{i,t}\mid x,y_{i,<t})}
>                               \Bigr).
> \]
> The factor \(1/|y_i|\) turns a product of \( |y_i|\) individual ratios into an average in log‑space, exactly what appears in Eq.~(11).

---------------------------------------------------------------------

### 2.  The log‑gradient trick

Notice that \(s_i(\theta)=\exp (\log s_i(\theta))\). For any differentiable function \(f(\theta)\) we have

\[
\nabla_\theta f(\theta) =
f(\theta)\,\nabla_\theta\log f(\theta).
\]

Applied to \(s_i\), this yields

\[
\nabla_\theta s_i(\theta)=
s_i(\theta)
\,\nabla_\theta \log s_i(\theta).
\]

Using that rule inside the expectation gives

\[
\nabla_\theta \mathcal J
=
\E_{\,x,\{y_i\}}
   \Big[
     \frac{1}{G}
     \sum_{i=1}^{G}
     s_i(\theta)\,\widehat A_i
     \;\nabla_\theta \log s_i(\theta)
   \Big].
        \tag{A}
\]

Equation (A) is already identical to the first line after “=” in Eq.~(11) of the paper.

---------------------------------------------------------------------

### 3.  Computing \( \nabla_\theta \log s_i(\theta)\)

From the definition of \(s_i\),

\[
s_i(\theta)
= 
e^{\,g_i(\theta)}, 
\qquad 
g_i(\theta)
= 
\tfrac{1}{|y_i|}
    \sum_{t=1}^{|y_i|}
      \log
      \frac{\pi_\theta(y_{i,t}\mid x,y_{i,<t})}
           {\pi_{\!\!\!_{\!\text{old}}}(y_{i,t}\mid x,y_{i,<t})}.
      }
\]

The only \(\theta\)-dependent part inside the logarithm is  
\( \pi_\theta(y_{i,t}\mid x,y_{i,<t})\).  
Therefore

\[
\nabla_\theta g_i(\theta)
=
\tfrac{1}{|y_i|}
   \sum_{t=1}^{|y_i|}
     \nabla_\theta
       \log
       \pi_\theta ( y_{i,t} | x, y_{i,<t} ).
        }                                       
        .
\]

Because \(g_i = \log s_i\), we immediately get

\[
\nabla_\theta \log s_i(\theta)
=
\tfrac{1}{|y_i|}
   \sum_{t=1}^{|y_i|}
     \nabla_\theta
       \log
       \pi_\theta ( y_{i,t} | x, y_{i,<t} ).
        }                                       
        .
       

Therefore, substituting these expressions into (A) gives

\[
\nabla_\theta {\cal J}_{GSPO} (\theta)
=
\E_{\,x,\{y_i\}}
   [
     {1}/{G}
     {

                                  {\pi_{\!\!{\!θ_{\!old}}}( y_n | x)} }

           {A_n}\;\;
          {\displaystyle{\frac{1}{ | y_n | }}
            }
            {\displaystyle 
              {

             }

    } ]

(Here ``simplify notation`` refers to restricting to a single response index.)

This matches exactly Eq.~(11):

```
∇_θ J_GSPO(θ) =
E[  1/G ∑_i (
          (π_θ(yᵢ|x)/π_θ_old(yᵢ|x))^(1/|yᵢ|)
          · ĤAᵢ
          · ( 1/|yᵢ|
                ∑_t ∇_θ log π_θ(yᵢ,t | x, yᵢ,<t) ) ) ].
```

---------------------------------------------------------------------

### 4. Intuition behind every term

* **\( (\pi_\θ(yᵢ|x)/π_{\mathrm old}(yᵢ|x))^{1/|yᵢ|}\)** – this is a *length‑normalised* sequence‑level importance ratio: we raise the ordinary likelihood ratio to a power inversely proportional to length so that responses of different lengths have comparable scaling.

* **\(ĤAᵢ\)** – group‑based advantage; it is constant across all tokens of \(yᵢ$, reflecting that the reward is attached to the whole sequence.

* **\(½{|yᵢ}|∑_t ∇_θ log π_θ(...) )** – an average of per‑token log‑likelihood gradients; since each token shares the same advantage, weighting by this average yields a gradient that points in roughly the same direction as a token‑wise update would but with far less variance.

---------------------------------------------------------------------

Thus, starting from Eq.~(10), applying the standard “score‑function” trick, inserting the specific form of \(sₙ(θ)\) and its logarithmic derivative, and carefully accounting for length normalisation give Eq.~(11). The division by \( | yᵢ|\) comes directly from normalising the sequence importance ratio, while all other terms appear naturally through the log‑gradient transformation.
