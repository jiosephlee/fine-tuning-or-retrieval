\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 5: # Information‑Transmission View of Orthogonal Matrix Factorization

Orthogonal Finetuning (OFT) proposes to adapt a frozen foundation model by left‑multiplying each linear layer with an orthogonal matrix \( \mathbf{R}\in\mathbb{R}^{d\times d} \).  
Although this transformation preserves the pair‑wise angles between neurons and therefore the semantic structure learned during pre‑training, a dense orthogonal matrix typically incurs \(O(d^{2})\) trainable parameters.  Farsighted designers have therefore sought sparse factorizations that keep the number of effective trainable parameters modest while still allowing the product to span the dense orthogonal group.  
The paper *Parameter‑Efficient Orthogonal Finetuning via Factorization* proposes an elegant perspective: constructing a dense orthogonal matrix can be viewed as **transmitting information through a grid‑structured graph**.  By formalising this view, we can formulate clear requirements on the sparsity pattern of the factor matrices and uncover principled ways, such as butterfly factorization, to meet those requirements with a minimal number of free parameters.

Below we unpack this viewpoint in four stages.  First we interpret a dense matrix as a complete communication graph.  Then we see how a factorization unfolds this graph into successive layers.  Then we expose the edge‑based connectivity constraints that guarantee full transmission.  Next we explore the extra rigidity injected by orthogonality and why it forces us to count only the truly “free” edges.  Finally we illustrate how to visualise these grid graphs and connect the dots back to the original problem of parameter‑efficient finetuning.

---

# Dense matrix as a fully connected graph

A \( d\times d \) real matrix \( \mathbf{R}\) can be regarded as the weight matrix of a directed graph whose vertices are arranged in two layers \( \{v_{1},\dots,v_{d}\}\) (inputs) and \( \{u_{1},\dots,u_{d}\}\) (outputs).  The entry \( R_{ij}\) indicates the weight of the directed edge from input \(v_{j}\) to output \(u_{i}\).  In this representation, a *dense* matrix has an edge between every pair of vertices, i.e. the adjacency matrix contains \(d^{2}\) entries, all potentially nonzero.  
When this adjacency is a full graph, an arbitrary signal injected at an input node can propagate directly to any output node in a single step.

In the context of model finetuning, the dense graph embodies an orthogonal transformation that mixes all neurons of a layer indiscriminately.  While perpetuating this direct mixing preserves all learned relationships, it also yields a quadratic number of parameters: a naïve way to implement \( \mathbf{R}\) requires storing every entry.  The challenge is to emulate the same degree of expressiveness but without storing all \(d^{2}\) weights.

---

# Matrix factorization as sequential graph layers

Consider factorising \( \mathbf{R}\) into a product of \(m\) matrices,
\[
\mathbf{R} \;=\; \mathbf{B}_m \mathbf{B}_{m-1} \cdots \mathbf{B}_1 , \qquad \mathbf{B}_i \in \mathbb{R}^{d\times d}.
\]
Each factor \( \mathbf{B}_i\) is viewed as a **layer** of edges connecting the nodes of layer \(i\) to layer \(i+1\).  The multiplication of successive layers is equivalent to traversing the graph sequentially: first the signal is propagated from the first input layer to the second by \(\mathbf{B}_1\), then the intermediate representation is relayed through \(\mathbf{B}_2\), and so on until the signal finally reaches the last output layer after \(\mathbf{B}_m\).  Consequently, the combined graph becomes a directed acyclic graph (DAG) with \(m+1\) horizontal rows of vertices.

The *sparsity pattern* of a factor \( \mathbf{B}_i\) dictates which edges exist between layers \(i\) and \(i+1\).  A fully dense \(\mathbf{B}_i\) would defeat the point of factorisation, because it introduces \(d^{2}\) parameters.  By imposing an explicit sparse structure on each factor, we reduce the number of trainable parameters while still seeking that the overall product remains dense.  The information‑transmission framework asks: **Given a fixed number of intermediate layers, which sparsity patterns guarantee that every input can still reach every output?**

---

# Edge‑based connectivity constraints for full transmission

To answer that question we translate the requirement “every input node must be able to reach every output node” into an *edge‑based connectivity condition*.  Let us denote the set of nodes in row \(k\) by \(V_k=\{v_k^{(1)},\dots,v_k^{(d)}\}\).  Between row \(k\) and row \(k+1\) only a subset of the possible directed edges are retained, as specified by the non‑zero pattern of \(\mathbf{B}_k\).  We say that a directed walk exists from a node \(v_1^{(i)}\) in the first row to a node \(v_{m+1}^{(j)}\) in the last row if there is a sequence of edges \(e_1, e_2, \dots, e_m\) where each \(e_k\) goes from some node in row \(k\) to a node in row \(k+1\).

The *full‑transmission* condition then reads:
\[
\forall \, i,j \in \{1,\dots,d\}, \;\; \exists \; \text{a walk } v_1^{(i)}\to v_2^{(\cdot)}\to \cdots \to v_{m+1}^{(j)}.
\]
This can be expressed graph‑theoretically: the directed bipartite graph constituted by all edges of all layers must yield a directed spanning subgraph that connects every source node to every sink node.  In particular, this imposes that the adjacency matrix of the concatenated graph (obtained by unrolling the matrix multiplication) be dense, i.e. \(\mathbf{R}\) is full.

A constructive way to satisfy this is to give each \(\mathbf{B}_i\) enough non‑zero entries so that no source node is isolated at any hop.  For instance, in a graph with \(d=4\) nodes the paper shows an example where a 5‑layer factorization uses only 10 edges to achieve full connectivity—still fewer than the 12 edges that a single dense matrix would use.  The takeaway is that *we may globally reduce the number of edges while still guaranteeing full information flow*, as long as each hop touches sufficiently many nodes.  The exact shape of the sparsity pattern will dictate the number of trainable parameters.

---

# Orthogonality constraints and minimum free edges

When each factor must also be orthogonal, the sparsity patterns are not arbitrary.  
An orthogonal matrix \(\mathbf{Q}\in\mathbb{R}^{d\times d}\) satisfies \(\mathbf{Q}^{\top}\mathbf{Q}=\mathbf{I}\).  In a sparse orthogonal matrix, the characteristic two-row sparsity—a pair of rows being orthogonal vectors—forces a *combinatorial coupling* of non‑zero positions.  For a \(2\times 2\) orthogonal block, a single zero in the upper‑left corner forces a zero in the bottom‑right corner, because the two rows must remain orthogonal.  Extending to larger \(d\), each full set of \(d\) columns (or rows) must map to a permutation of themselves multiplied by \(\pm 1\).  Consequently, a sparse orthogonal matrix inevitably has **\(d\) fixed edges**: for each column, exactly one non‑zero element (with magnitude one) is prescribed by the orthogonality constraint.  These edges are *not* free parameters because they are determined by the choice of basis permutation and sign; the remaining entries are the truly learnable degrees of freedom.

Therefore, we distinguish between *total edges*—the number of non‑zero entries in the product graph—and *free edges*, which count only the entries that may be tuned during finetuning.  The goal in an efficient factorization is to minimise the free edges while satisfying the full‑transmission requirement.  The paper argues that the butterfly structure achieves a near‑optimal trade‑off: with \(\log d\) layers of \(2\times 2\) butterfly blocks, the total number of free edges is \(\frac{1}{2}(b-1)d\log d\) for block size \(b\), which gives \(\mathcal{O}(d\log d)\) parameters.  In contrast, a block‑diagonal orthogonal matrix with block size \(b\) requires only \(\mathcal{O}(bd)\) parameters, yet cannot support the rich expressiveness of a full dense orthogonal matrix.

---

# Visualizing and interpreting grid‑graph structures

To make these ideas concrete, one can visualise the grid‑graph as a two‑dimensional lattice.  In the paper’s Figure \(X\) (reproduced conceptually here), each row of vertices is a dot, and directed edges are drawn as arrows connecting successive rows.  A dense matrix corresponds to a solid lattice: every dot in the first row points to every dot in the second row.  A factorisation into \(\mathbf{B}_1, \dots, \mathbf{B}_m\) corresponds to thinning the lattice: at each hop only a few arrows remain.  The beautiful property of the butterfly topology is that, despite its thinness, every node in the first row still has a path—made of \(m\) hops—to every node in the last row, and these paths are *faithfully structured* (they involve a sequence of nested pairwise “butterfly” interactions).  The lattice thus looks like a series of interlocking pairs, much like the arms of a butterfly, hence the name.

In a visual comparison between a block‑diagonal structure and the butterfly structure, one sees that the former partitions the lattice into disjoint cliques that never interact across blocks, whereas the butterfly lattice interlaces edges so that information is eventually mixed across all dimensions.  This intuitive picture clarifies why block‑diagonal OFT can preserve local angular relationships within a group but cannot generate a globally dense transformation.

Moreover, the effect of orthogonality on the lattice can be seen: the fixed edges appear as a guaranteed scaffold of cross‑bars; every other arrow may be tweaked during training.  The grid‑graph thus becomes not only a computational metaphor but also a diagnostic tool: counting the number of free arrows tells you precisely how many learnable parameters you have, and ensuring that every arrow is part of a valid path guarantees that the final product remains full.

---

In summary, the **information‑transmission view** reframes the core challenge of parameter‑efficient orthogonal finetuning as a graph‑theoretic design problem: choose a sparse, orthogonal factorisation that still yields a dense directed graph connecting every input to every output with as few free edges as possible.  The butterfly structure satisfies this problem elegantly, generating a dense orthogonal matrix with only \(O(d\log d)\) parameters—an order‑of‑magnitude reduction from naively storing a full orthogonal matrix—while preserving the desirable angle‑preserving property of OFT and thereby improving generalisation for foundation model adaptation.
