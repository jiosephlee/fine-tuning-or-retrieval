# Low‑Rank Adapter Algebraic Form  
The core idea behind low‑rank adapter (LoRa) finite‑tuning is reformulating an existing linear projection $\mathbf{W}\in\mathbb R^{h\times o}$ so that its trainable portion occupies far fewer degrees of freedom than $\mathbf{W}$ itself has. If $h$ denotes the hidden dimensionality and $o$ denotes the output dimensionality—as occurs throughout transformer layers—then directly optimizing $\mathbf{W}$ would demand $h\times o$ weights and incurs exact same update costs and storage overheads as fully fine‑tuned training.  

A typical linear call computes  
\[
\mathbf{Y}\leftarrow \mathbf{X}\mathbf{W},
\]
with $\mathbf{X}\in\mathbb R^{b\times h}$ representing $b$ tokens batched together \(b\) being sequence length plus potentially multi‑turn dialogue contribution).  
In loRa fashion an extra “adapter” term is superimposed on top of the primal computation:
\[
\boxed{
    \mathbf{Y}
    ~=~
    \underbrace{\mathbf{X}\mathbf{W}}_{\text{Frozen pre‑trained}}
    ~=~
    \underbrace{\bigl(\mathbf{X}\mathbf{W}\bigr)}_{\text{fixed}}
    ~=~
    \underbrace{\bigl(\mathbf{X}\bigr)
                +s\,\bigl(\,\mathbf{X}\,\underbrace{\mathbf {L}_{1}}_{\in\,\mathbb R^{h\times r}}\,
                \underbrace{\mathbf {L}_{2}}_{\in\,\mathbb R^{r\times o}}\bigr)}_{\text{$s$ scales $\boldsymbol{s}$},
}
\]
where $r$ (\emph{$r \ll h,o$}) is called the rank and $s$ is an optional scalar that serves either as an initial scaling factor or simply absorption control for magnitude corrections if desired (\emph{s}=0 would nullify the adapter). The product $\mathbf {L}_{1}\mathbf {L}_{2}$ supplies precisely $h\times r+r\times o$ learnable coefficients—potentially two orders smaller than even a compressed version ($8$‑bit) representation would require—yet provides nontrivial flexibility for adapting an otherwise dormant tensor appropriately toward task data distributions without unfreezing heavy core parameters.  

Mathematically this decomposition relies upon standard matrix identities – any matrix product can trivially be represented with one higher-dimensional intermediate vector – viewed here through low dimensional mapping windows $(h\times r)$ and $(r\times o)$. Crucially, during back‑propagation scan directions go entirely through frozen $\mathbf W$, which stays untouched while computing gradients that flow straight into $\partial E/\partial \!\boldsymbol L_{1}$ and $\partial E/\partial \!\boldsymbol L_{2}$ alone (where $E$ represents loss). This backward path eliminates any run-time dependency on large cache demands concerning $\partial E/\partial \!\boldsymbol W$.  

Within *QLoRa* every oscillator employs this lowest rank augmentation over **every** transform layer uniformly – both query/key/value projection heads inside attention cells and ordinary feed‑forward positionwise fully connected maps – avoiding any layer where inherent representation freedom is sacrificed while keeping adapter capacities compact enough that modern GPUs can gently host them in parallel along existing advancement streams.
