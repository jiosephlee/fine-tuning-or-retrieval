\title{Stack Exchange of the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

### How does Equation 4 mathematically implement the 'initial token retention' mechanism?
Question:
In Equation 4 (Eq.~\ref{eq:problem}), the indicator function $\mathbb{I}(\hat{\lambda}_{i}, \hat{n})$ is defined as:
$$
\mathbb{I}(\hat{\lambda}_{i},
abla{n})=\\begin{cases}
	1&\\mbox{\\;  $n<\\hat{n}$}\\
{\\frac{1}{\\lambda}_{i}}&\\mbox{\\; $n\\geq\\hat{n}$}
	
end{cases}
$$

Wait, looking at the LaTeX source provided in the paper, it says `{\\frac{1}{\\lambda}_{i}}`. However, earlier in Section 2.1 (Eq.~2), the unified formula uses terms like `cos(n / (λβ)^k)`. 

If $n < \hat{n}$, the multiplier is 1. This means the angle remains $n/\beta^i$. This implies no interpolation for the first $\hat{n}$ tokens.
But if $n \ge \hat{n}$, the multiplier is $1/\lambda_i$. So the angle becomes $(1/\lambda_i) \times (n/\beta^i)$.

My confusion lies in how this interacts with standard Linear Interpolation (PI). In PI, we usually multiply by a factor like $L/L'$ to compress positions. Here, if we want to extend from 4k to 256k ($s=64$), shouldn't we be dividing by something large?
The paper defines search space for $\lambda_i$ from 1.0 to $s \times 1.25$. If I pick a large $s$, say 64, and find an optimal large $\lambda_i$, then multiplying by $1/64$ compresses the angle significantly.
But what happens at exactly position $ar{n}$? Is there a discontinuity in the derivative of the position embedding at $ar{n}$? How does this sudden switch from slope 1 to slope $1/\lambda_i$ affect gradient flow during fine-tuning?
Answer:
Your intuition regarding the compression of the angular frequency is correct, but the apparent discontinuity at $n = \hat{n}$ is actually a deliberate feature of the **Initial Token Retention** mechanism described in Finding 2 of Section 2.1, rather than a bug that hinders gradient flow.

Mathematically, let us examine the argument inside the cosine and sine functions in Equation 4. For a specific RoPE dimension $i$, the angle $\phi_n$ is defined piecewise:
$$
\phi_n = \begin{cases} 
\frac{n}{\beta^i} & \text{if } n < \hat{n} \\
\frac{n}{\lambda_i \beta^i} & \text{if } n \geq \hat{n}
\end{cases}
$$
You correctly identified that for $n < \hat{n}$, the multiplier is 1, meaning these initial tokens preserve their original high-frequency rotary angles exactly as they were in the pre-trained model. This aligns with the paper's observation that initial tokens often receive high attention scores and are critical for immediate context understanding; distorting their position encoding could degrade performance on short-context tasks or early-sequence dependencies.

Regarding your concern about continuity at $n = \hat{n}$: strictly speaking, yes, there is a discontinuity in the *derivative* (the slope) of the position embedding with respect to $n$. The slope changes abruptly from $1/\beta^i$ to $1/(\lambda_i \beta^i)$ at the threshold $\hat{n}$. However, this does not imply a discontinuity in the *value* of the embedding itself if we consider how $\lambda_i$ behaves relative to standard interpolation. In standard Linear Interpolation (PI), every token's angle is scaled by $1/s$, creating a continuous but compressed line from $0$ to $L'$. In LongRoPE, we are essentially stitching together two lines: an uncompressed segment from $0$ to $\hat{n}$ and a compressed segment starting from $\hat{n}$.

Crucially, at exactly $n = \hat{n}$, both formulas yield slightly different values unless $\lambda_i = 1$. Specifically:
- Left limit ($n \to \hat{n}^-$): Angle $\approx \frac{\hat{n}}{\beta^i}$
- Right limit ($n = \hat{n}$): Angle $= \frac{\hat{n}}{\lambda_i \beta^i}$

Since $\lambda_i > 1$ for extended contexts (e.g., $\lambda_i \approx s$), there is indeed a jump in the angle value at $\hat{n}$. You might wonder how this affects gradients. The key insight from the paper's methodology (Section 3.2) is that LongRoPE treats this as an **evolutionary search problem**, not a differentiable optimization problem solved via backpropagation on $\lambda_i$ or $\hat{n}$. The parameters $\lambda_i$ and $\hat{n}$ are discrete hyperparameters selected via an evolutionary algorithm based on perplexity on a validation set (PG19/Pile). Once these optimal discrete values are found, they are fixed constants during fine-tuning. Therefore, during the fine-tuning phase where gradients flow through the network weights, $\lambda_i$ and $\hat{n}$ are static scalars; no gradients need to flow through the "switch" point itself because we are not optimizing over it via gradient descent. The "discontinuity" exists in the forward pass definition of positional encodings but does not impede backpropagation through the neural network layers because those layers treat the position embeddings as inputs derived from fixed constants.

Furthermore, this piecewise definition serves a functional purpose similar to "extrapolation" strategies found in NTK-aware methods but localized to specific dimensions and token ranges. By keeping the first $\hat{n}$ tokens unscaled (slope 1), we ensure that short-range relationships remain sharp and distinct, avoiding the "crowding" effect mentioned in Section 2.1 where linear interpolation compresses all positions too tightly for high frequencies. Only tokens beyond $\hat{n}$ undergo compression (slope $1/\lambda_i$) to accommodate the massive extension ratio (up to $512\times$). This hybrid approach allows LongRoPE to maintain fidelity for local context while stretching capacity for long-range dependencies. The empirical results in Table 2 confirm that retaining these initial tokens without interpolation significantly improves performance compared to uniform scaling ($\hat{n}=0$), validating that this non-smooth transition is beneficial for language modeling tasks despite its mathematical irregularity.
