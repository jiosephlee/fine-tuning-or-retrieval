## Preliminaries: Reparameterizing Weights with Orthogonal Matrices

Before we can appreciate the novelty of the information transmission framework, we must first establish the foundational mechanics of Orthogonal Finetuning (OFT). The core challenge in adapting large foundation models lies in updating the massive weight matrices without destroying the rich semantic knowledge acquired during pretraining. Standard approaches like Low-Rank Adaptation (LoRA) address this by adding a low-rank update matrix to the pretrained weights. In contrast, OFT adopts a multiplicative strategy. Instead of adding a perturbation, OFT reparameterizes the new weight matrix as the product of a learnable orthogonal matrix and the frozen pretrained weight matrix. Consider a pretrained linear layer represented by a weight matrix $\bm{W}^0 \in \mathbb{R}^{d \times n}$. In standard inference, an input vector $\bm{x} \in \mathbb{R}^{d}$ produces an output $\bm{z} = (\bm{W}^0)^\top \bm{x}$. Under OFT, this forward pass is modified to $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$, where $\bm{R} \in \mathbb{R}^{d \times d}$ is an orthogonal matrix learned during fine-tuning.

The choice of an orthogonal matrix is not arbitrary; it is driven by a desire to preserve the geometric relationships inherent in the pretrained model. Specifically, orthogonal transformations preserve pairwise angles between neurons (columns of $\bm{W}^0$). By maintaining these angles, OFT ensures that the relative orientation of features learned during pretraining remains intact, thereby preserving semantic knowledge while allowing for task-specific adaptation. To implement this mathematically while ensuring numerical stability and ease of optimization, OFT employs Cayley parameterization. Rather than optimizing $\bm{R}$ directly, which would require enforcing complex orthogonality constraints at every step, we optimize a skew-symmetric matrix $\bm{Q}$ (where $\bm{Q} = -\bm{Q}^\top$) and map it to the orthogonal group via the formula $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$. This guarantees that $\bm{R}$ remains orthogonal throughout training regardless of the values in $\bm{Q}$, provided $(\bm{I}-\bm{Q})$ is invertible.

However, a dense $d$-dimensional orthogonal matrix contains $d(d-1)/2$ independent parameters (degrees of freedom), leading to a computational cost of $\mathcal{O}(d^2)$ for storage and updates. For modern foundation models where $d$ can reach thousands or tens of thousands, this parameter count is prohibitive compared to low-rank methods like LoRA. To mitigate this, early iterations of OFT introduced a block-diagonal structure for $\bm{R}$, decomposing it into smaller independent blocks such as $\text{diag}(\bm{R}_1, \dots, \bm{R}_r)$. While this successfully reduced the parameter count to roughly proportional to $bd$ (where $b$ is the block size), it imposed severe structural limitations. The block-diagonal assumption implies that dimensions within different blocks never interact; information cannot flow across block boundaries. This creates rigid inductive biases that may hinder expressivity and fail to approximate essential linear transforms that require global mixing of dimensions. Consequently, we face a critical dilemma: how can we construct a *dense* orthogonal matrix—one that allows full interaction between all dimensions—without succumbing to the high parameter cost associated with density? The answer lies not in looking at matrices as static grids of numbers, but dynamic systems for moving information.

## The Information Transmission Analogy: Grid Graphs and Connectivity

To resolve the tension between density and efficiency, we shift our perspective from linear algebra to network theory by framing matrix factorization as an information transmission problem. Imagine we wish to generate a dense target matrix $\bm{R}$ by multiplying together $m$ sparse matrices: $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$. If we were to analyze this purely algebraically, determining which entries must be non-zero in each factor to yield a dense product would be computationally opaque. However, if we view each multiplication step as a stage in a communication network, the problem becomes visually intuitive and structurally clear. We can conceptualize this process as transmitting information across a grid-structured graph consisting of $d$ rows and $m+1$ columns (levels).

In this graphical representation, each row index corresponds to one of the $d$ dimensions (nodes) at any given level. The initial level (column 0) represents the input nodes corresponding to the source dimensions before any transformation occurs. The final level (column $m+1$) represents the destination nodes after passing through all $m$ transformations. Each intermediate level corresponds to the state of information after passing through one specific sparse factor matrix $\bm{B}_i$. The transition from level $i$ to level $i+1$ is governed entirely by the connectivity pattern defined by the sparse matrix $\BMathbf B_{i+1}. If an entry $(j_1, j_2)$ in matrix $\BMathbf B_{i+1}$ is non-zero ($(\BMathbf B_{i+1})_{j_1 j_2} \neq 0$), it signifies that there exists a directed edge allowing information to flow from node $j_2$ at level $i$ to node $j_1$ at level $i+1$. Conversely, if $(\BMathbf B_{i+1})_{j_1 j_2}$ is zero, no direct path exists between those specific nodes at that specific stage; information cannot jump directly from source dimension $j_2$ to target dimension $j_1$ in this single step.

This analogy transforms abstract matrix multiplication into a physical routing problem on a layered graph. When we compute the product $\BMathbf R = BMathbf B_m BMathbf B_{m-1} cdots BMathbf B_1$, we are essentially asking: "Is there at least one valid path from every node in Level 0 to every node in Level m+1?" For instance, consider a scenario where we want $(\BMathbf R)_{31}$ (information flowing from dimension 3 at input to dimension 3 at output? No wait let's correct indices for clarity). Let us say we want information from node 3 at Level 0 to reach node 5 at Level m+1. Even if there is no direct edge from node 3 at Level 0 to node 5 at Level 1 (perhaps $(\BMathbf B_1)_{53}=0$), there might be an indirect path: Node 3 connects to Node 7 at Level 2 via some intermediate steps involving other matrices like $(\BMathbf B_2)$ and $(\BMathbf B_3)$ eventually reaching Node 5 at Level m+1. If such paths exist for all pairs $(source\_node\_at\_L0$, destination\_node\_at\_L(m+1)), then the resulting product matrix will be fully dense; every output dimension receives aggregated information from every input dimension through some chain of dependencies across layers.

Therefore, constructing a dense orthogonal matrix via sparse factors becomes equivalent to designing a multi-layer network topology where global connectivity emerges from local interactions. A single dense orthogonal matrix corresponds trivially to having direct edges connecting every pair of nodes between two levels—a complete bipartite graph requiring $\mathcal O(d^2)$ edges per layer—and thus suffers from poor scalability regarding trainable parameters because almost every edge carries learnable weights under standard assumptions unless constrained otherwise . But crucially , our goal here isn't simply connectivity ; it's achieving full connectivity using minimal resources while respecting strict orthogonality rules governing what kinds of connections are permissible simultaneously within each layer-matrix pair . This reframing allows us leverage decades-old insights from computer science regarding optimal broadcast topologies rather than reinventing wheel solely within context pure linear algebra manipulations alone .
