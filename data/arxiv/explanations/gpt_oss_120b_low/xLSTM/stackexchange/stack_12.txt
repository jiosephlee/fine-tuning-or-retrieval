\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How does xLSTM compare to Retention or RWKV on formal language tasks requiring state tracking?
Question:
Figure 3 shows xLSTM solving parity-like tasks while Transformers/SSMs fail. The caption mentions "state tracking" as a key advantage. Could someone elaborate on why exponential gating plus memory mixing gives xLSTM an edge over Retention or RWKV, which also have gating mechanisms?
Answer:
**Answer**

The parity‑like experiments in Figure 3 are a canonical “state‑tracking’’ benchmark: the network has to remember a binary counter that is toggled whenever the input symbol `1` appears, and it must output the current parity at the end of the sequence.  
A model can solve this task only if two conditions are satisfied

1. **the hidden state can be revised arbitrarily** – when a new `1` arrives the previously stored parity must be *overwritten* (or “flipped’’) without being diluted by older contributions, and  
2. **different hidden units can exchange information** – the update that flips the parity may have to use a combination of several scalar cells (e.g. one cell storing the sign, another storing a mask).

Standard LSTMs fulfil (1) only weakly because their forget gate is bounded by a sigmoid, so the old cell value can be attenuated but never *removed* in one step.  Consequently an early `1` leaves a tiny residue that accumulates over long sequences and destroys perfect parity tracking.  

Both **Retention** [Sun et al., 2023] and **RWKV** [Peng et al., 2023] adopt the same “fast‑weight’’ or “linear‑RNN’’ formulation as xLSTM’s mLSTM: they maintain a matrix (or vector) memory that is updated by an outer‑product of a key and a value, and they use an exponential or sigmoid decay for the forget term.  However, these models **do not contain any hidden‑to‑hidden recurrent connections** (the *memory mixing* of Eq.~(1) in the paper).  Their recurrence is entirely described by

\[
\mathbf{C}_{t}=f_t\,\mathbf{C}_{t-1}+i_t\,\mathbf{v}_t\mathbf{k}_t^{\!\top},
\]

where every gate depends only on the current input (and possibly a static bias).  Because of this, each *cell* evolves independently of the other cells; there is no way for one cell’s state to influence another cell’s gate computation at the next time step.

### Why exponential gating + memory mixing matters

1. **Exponential gating gives unbounded overwriting.**  
   In sLSTM (the scalar variant used for parity) the input gate is defined as  

   \[
   i_t = \exp(\tilde i_t),\qquad 
   f_t = \exp(\tilde f_t)\ \text{or}\ \sigma(\tilde f_t),
   \]

   with a stabiliser that rescales both gates so that their product never overflows (Eqs.~(2)–(3)).  Because $\exp(\cdot)$ can grow arbitrarily large, a single step can set $i_t\gg f_t$ and therefore *completely replace* the old cell value:

   \[
   c_t = f_t\,c_{t-1}+i_t\,z_t
        \approx i_t\,z_t \quad\text{if }i_t\gg f_t.
   \]

   This is precisely what is needed for parity: when a `1` arrives we want $c_t = -c_{t-1}$.  The exponential gate can generate a negative sign (through $z_t$) and simultaneously make $i_t$ dominate $f_t$, erasing any trace of the previous count.

2. **Memory mixing lets cells cooperate.**  
   The sLSTM extends the classic LSTM with *hidden‑to‑hidden* recurrent matrices $\mathbf R_{\!*}$ that connect all hidden units at time $t-1$ to every gate at time $t$.  In practice this looks like

   \[
   \tilde i_t = \mathbf w_i^\top x_t + \mathbf R_i h_{t-1} + b_i,
   \]

   with analogous terms for $f_t$, $o_t$, $z_t$.  When several scalar cells are present, the term $\mathbf R_i h_{t-1}$ mixes their hidden activations before computing each gate.  Consequently a flip that is detected on *any* cell can instantly drive the input gate of another cell, allowing a compact encoding of “parity’’ as a **single joint linear combination** of many cells rather than requiring each cell to store its own copy of the counter.

   Retention and RWKV lack this mixing: their update rule treats every key–value pair independently, so even if one pair learns to flip a sign it cannot directly influence another pair’s gate.  The result is an effective *feed‑forward* memory that can store many distinct key–value associations (hence excellent performance on associative‑recall tasks) but struggles with tasks where the *relationship* between successive inputs matters.

3. **Normalization stabilises long‑range accumulation.**  
   Both sLSTM and mLSTM introduce an auxiliary normalizer $n_t$ that tracks the cumulative product of forget gates (Eqs.~(4)–(5)).  The hidden state is computed as  

   \[
   h_t = o_t\,\frac{c_t}{n_t},
   \]

   so any exponential growth in $i_t$ or $f_t$ is automatically re‑scaled by $n_t$.  This prevents gradients from exploding while preserving the ability to *exactly* overwrite old content when needed—a balance that pure sigmoid gating cannot achieve.

### Connecting back to Figure 3

In Figure 3 the parity task error curves show:

* **Transformers/SSMs:** error stays near random because their self‑attention or linear kernels lack any mechanism to overwrite earlier context; each token contributes additively with a fixed decay, so after many steps the parity signal is drowned in noise.
* **Retention / RWKV:** error improves slightly thanks to exponential forgetting, but without memory mixing they cannot propagate a flip across cells; consequently they converge to a sub‑perfect accuracy (~0.7–0.8).
* **xLSTM (sLSTM):** error drops to zero even for lengths far beyond training because each new `1` triggers an exponential input gate that fully replaces the stored scalar while hidden‑to‑hidden mixing distributes this decision across all cells, guaranteeing exact state reversal.

Thus, *the edge comes from two synergistic ingredients*:  

1. **Exponential gates** give unlimited capacity to erase or dominate previous state in one timestep;  
2. **Memory mixing** (the hidden‐to‐hidden recurrent matrices) allows those powerful updates to be coordinated across multiple cells.

When both are present—as in sLSTM—the model attains true “state tracking’’ ability that matches formal language theory results stating that RNNs with unrestricted hidden‑to‑hidden connections are strictly more expressive than linear SSMs or Transformers on regular languages such as parity.  Retention and RWKV inherit many benefits of fast‑weight memories but remain limited to *purely associative* storage; they excel at recall tasks but cannot reliably perform stateful transformations required by formal language benchmarks.
