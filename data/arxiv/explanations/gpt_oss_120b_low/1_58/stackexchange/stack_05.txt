\title{Stack Exchange of the Paper: "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits"}

### Why does adding a zero value to the weight set improve ‘feature filtering’?
Question:
The authors claim that adding the zero weight improves modeling capability because it enables explicit feature filtering. I am not clear on how a zero weight can act as a filter in transformer attention or feed‑forward layers. Can someone provide an intuitive explanation or a simple example illustrating this effect?
Answer:
In a transformer every linear layer (the *Q*, *K*, *V* projections, the‑wise feed‑forward and the output projection) computes a matrix‑vector product  

\[
y = Wx ,
\]

where each column of **W** tells the model how a particular input feature contributes to the output feature.  
If **W** is constrained to the binary set $\{-1,+1\}$ every input dimension is forced to either *add* or *subtract* its value from the output. Consequently the model can never **turn a connection off completely** – it must always either reinforce or invert the signal.  

Adding the third value 0 gives the weight matrix a *sparse* structure:

\[
\widetilde{W}_{ij}\in\{-1,0,+1\}.
\]

Whenever $\widetilde{W}_{ij}=0$ the $j$‑th input component does not participate at all in the computation of the $i$‑th output component. In other words, that weight behaves exactly like an explicit *feature filter*: it masks out a particular feature for that particular neuron.

### How this looks in attention

In multi‑head self‑attention each head computes

\[
A = \text{softmax}\!\bigl(QK^{\top}/\sqrt{d}\bigr) V .
\]

The matrices **Q**, **K**, **V** are produced by three linear layers with ternary weights in BitNet b1.58.  
Suppose the element $\widetilde{W}^{Q}_{pq}=0$. Then the $p$-th component of every query vector is exactly zero, no matter what the input token is. Consequently every dot‑product $q_i^{\top}k_j$ never receives any contribution from that component, and the attention score for any pair of tokens becomes *insensitive* to that feature. The same argument holds for zeros in **K** and **V**. Hence a zero weight can “switch off” an entire dimension of the similarity computation, which is equivalent to dropping a linguistic cue (e.g., a positional or syntactic feature) for that head.

### How this looks in a feed‑forward layer

A standard transformer feed‑forward block computes  

\[
h = \text{SwiGLU}\!\bigl( \sigma(W_{1}x)\odot (W_{2}x)\bigr),
\]

with two linear maps $W_{1},W_{2}$. If a row of $W_{1}$ contains many zeros, the corresponding hidden unit receives almost no signal from its input; if a column is zeroed, that input dimension is ignored by all hidden units that depend on that column. Thus zeros act as *hard masks* that can prune irrelevant dimensions on‑the‑fly during training, something that pure $\{-1,+1\}$ weights cannot do because they are forced to either add or subtract something.

### Why this improves modelling capacity

1. **Selective gating** – With only $\pm1$ each neuron must always participate, which limits how finely the network can shape its representation space. Zero introduces an extra degree of freedom: a neuron can be *inactive* for some inputs while still being able to flip signs when it is active.

2. **Effective sparsity without extra parameters** – The proportion of zeros can be substantial (the authors report that sparsity emerges naturally during training). Sparse connections reduce interference between unrelated features and make optimization easier, similar to why pruning improves generalisation.

3. **Expressivity beyond sign patterns** – The space of functions realizable by matrices with entries in $\{-1,+1\}$ is a subset of those realizable by matrices in $\{-1,0,+1\}$. Formally, any ternary matrix can be written as a binary matrix plus an element‑wise mask; this mask enables piecewise‑linear regions that would otherwise be impossible.

4. **Compatibility with integer arithmetic** – Even though zeros add another symbol, they do not introduce multiplications; multiplication by 0 is just a bypass operation. Hence hardware can still exploit the “almost‑no‑multiply” property while gaining the expressive benefit of masking.

### Simple illustration

Take a one‑dimensional example:  

$x = [x_{1}, x_{2}]^{\top}$,  
$W = \begin{bmatrix} +1 & -1 \\ 0 & +1 \end{bmatrix}$.

The output is  

\[
y_{1}= x_{1} - x_{2}, \qquad
y_{2}= 0\cdot x_{1} + x_{2}=x_{2}.
\]

If we were forced to use only $\pm 1$, the second row could be either $[+1,+1]$, $[+1,-1]$, $[-1,+1]$ or $[-1,-1]$; none of those would ever ignore $x_{1}$. The zero entry lets the second output depend *only* on $x_{2}$, i.e., it has filtered out $x_{1}$.

In an attention head this means a particular key/query dimension can be completely ignored for all token pairs; in a feed‑forward layer it means an intermediate neuron can be turned off for certain input channels.

### Connection to broader concepts

The idea mirrors classic *masking* or *gating* mechanisms (e.g., dropout masks, ReLU activations, sparsity‑inducing regularizers). What is novel here is that the mask is baked into the weight quantisation itself, so during inference there is no extra computational overhead – the hardware simply skips adding contributions from zero‑valued weights.

Thus, adding the zero symbol to the ternary weight set gives BitNet b1.58 an explicit way to filter out unhelpful features while retaining its ultra‑low‑bit arithmetic advantages, which explains the reported modelling improvements.
