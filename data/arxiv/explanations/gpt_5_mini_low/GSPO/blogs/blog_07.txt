# When You Need Finer Control: Introducing GSPO-token

In Group Sequence Policy Optimization (GSPO) we replaced noisy token-level importance weights with a sequence-level importance ratio, clipped and applied at the response level. That change fixes a core instability in GRPO and PPO-style objectives for long responses and sparse (MoE) models. But sometimes you still want finer-grained control over which parts of a response should get credit or blame — for example, in multi-turn RL where different tokens correspond to different turns, or when you want to shape learning at a token or segment granularity. GSPO-token is the variant that gives you that granular control while retaining GSPO’s stable, sequence-level importance weighting.

## The idea in one sentence

GSPO-token keeps the sequence-level importance ratio from GSPO as the off-policy correction and clipping anchor, but allows advantages to be specified (and applied) at the token level. Numerically, if all token advantages in a response are identical, GSPO-token reduces exactly to GSPO; when token advantages differ, GSPO-token provides a principled way to adjust training signals per token without reintroducing the high-variance, invalid token-level importance ratios that caused instability in GRPO.

## Recap: why sequence-level weighting matters

GSPO defines the sequence importance ratio as a length-normalized ratio of sequence likelihoods:

s_i(θ) = (π_θ(y_i | x) / π_{θ_old}(y_i | x))^{1/|y_i|}
       = exp( (1/|y_i|) ∑_{t=1}^{|y_i|} log ( π_θ(y_{i,t}|x,y_{i,<t}) / π_{θ_old}(y_{i,t}|x,y_{i,<t}) ) ).

This single scalar s_i(θ) correctly measures how far the whole sampled response y_i (drawn from π_{θ_old}) deviates from the current policy π_θ, which matches the fact that rewards r(x,y) are given at sequence level. Using s_i(θ) for clipping and weighting avoids the invalid application of token-level importance weights computed from single next-token samples — the source of large variance and collapse in GRPO.

## GSPO-token: formulation

GSPO-token uses the same sequence-level correction s_i(θ) but allows a per-token advantage \widehat{A}_{i,t}:

J_{GSPO-token}(θ) = E_{x, {y_i}∼π_{θ_old}} [
  (1/G) ∑_{i=1}^G (1/|y_i|) ∑_{t=1}^{|y_i|}
    min( s_{i,t}(θ) · \widehat{A}_{i,t}, clip( s_{i,t}(θ), 1-ε, 1+ε ) · \widehat{A}_{i,t} )
].

GSPO-token defines s_{i,t}(θ) so it is numerically equal to s_i(θ) but constructed to stop gradients through the per-token scaling:

s_{i,t}(θ) = sg[s_i(θ)] · ( π_θ(y_{i,t}|x,y_{i,<t}) / sg[ π_θ(y_{i,t}|x,y_{i,<t}) ] ).

Because the ratio ( π_θ(y_{i,t}|...) / sg[π_θ(y_{i,t}|...)] ) evaluates to 1 numerically, s_{i,t}(θ) is numerically s_i(θ). The sg[·] denotes the stop-gradient (detach) operator.

## Why this is principled and stable

- Off-policy correction remains sequence-level. The single scalar s_i(θ) is the meaningful importance sampling correction for a whole-sequence reward. That preserves the theoretical grounding and the low-variance behavior that makes GSPO stable for long responses and MoE models.
- Token-level advantages are simply multipliers of the same sequence-level correction. You can upweight or downweight specific tokens (or turns) without reintroducing token-level importance ratios computed from single-token samples.
- Gradient flow is controlled: the construction of s_{i,t}(θ) detaches the per-token likelihood numerators so that you do not obtain independent importance-weight gradients per token. The effective gradient (see the paper) becomes
  E[ (1/G) ∑_i s_i(θ) · (1/|y_i|) ∑_t \widehat{A}_{i,t} ∇_θ log π_θ(y_{i,t}|x,y_{i,<t}) ],
  i.e., the same s_i(θ) multiplies the average token log-gradient for that response.

This avoids the problematic behavior of GRPO, whose gradient is weighted by token-specific ratios w_{i,t}(θ) = π_θ(y_{i,t}|...)/π_{θ_old}(y_{i,t}|...), which vary independently across tokens and introduce large, cumulative variance and clipping interactions.

## When GSPO-token is the right tool

- Multi-turn RL: different turns or utterances within the same response may deserve different credit assignments. You can set token/turn-level advantages to reflect that structure (for example, higher advantage for tokens generated in later turns or for tokens in a particular segment).
- Mixed supervision: you may combine a sequence-level reward with localized token-level signals (e.g., token-level error indicators or heuristics). GSPO-token lets you apply these localized signals while keeping a stable global correction.
- Fine-grained curriculum or shaping: you might want to encourage a model to be better at certain token spans (e.g., factual statements, code correctness markers) without destabilizing whole-response optimization.

## When GSPO and GSPO-token are identical

If you assign the same advantage to every token in a response, i.e. \widehat{A}_{i,t} = \widehat{A}_i for all t, GSPO-token reduces exactly to GSPO. Both the numerical objective and the theoretical gradient coincide. Thus GSPO-token is a strict generalization: it adds flexibility without sacrificing GSPO’s stability when you do not need per-token granularity.

## Practical notes for implementation

- Compute s_i(θ) as in GSPO (length-normalized sequence likelihood ratio). Use that scalar both for sequence clipping and as the multiplier across tokens.
- Normalize token-level advantages within each group to keep scales stable (the paper uses group mean/std normalization for sequence advantages; you can analogously standardize \{\widehat{A}_{i,t}\} across tokens in the group).
- Ensure the detach/stop-gradient usage matches s_{i,t}(θ) construction so that per-token likelihood numerators do not introduce additional gradient paths for importance weights.
- Clipping ranges for s_i(θ) are different in magnitude from token-level PPO clipping: because s_i(θ) is length-normalized, choose ε consistent with the length-normalized scale. The paper reports much smaller numerical clipping ranges for sequence-normalized ratios versus token-level ratios.

## Takeaway

GSPO-token gives you per-token (or per-turn) advantage control while preserving the sequence-level importance correction that makes GSPO stable and efficient for long responses and MoE models. Use plain GSPO when a single sequence advantage suffices; switch to GSPO-token when you need principled, low-variance, per-token shaping of the learning signal.
