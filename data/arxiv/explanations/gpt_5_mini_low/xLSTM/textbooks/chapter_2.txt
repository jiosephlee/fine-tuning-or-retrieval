\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 2: LSTM Foundations: Constant Error Carousel and Gating

# Vanishing gradients in RNNs and the LSTM solution
Recurrent neural networks (RNNs) process sequences by repeatedly applying the same transition to propagate information through time. A well-known difficulty for vanilla RNNs is the vanishing (and exploding) gradient problem: when gradients are backpropagated through many time steps, multiplicative effects of the transition Jacobians cause gradients to decay exponentially (or blow up), preventing reliable learning of long-range dependencies. The paper frames this historical motivation as the reason the Long Short-Term Memory (LSTM) architecture was introduced in the 1990s: to overcome vanishing gradients and permit learning of long-term dependencies in sequential data.

The central LSTM solution is to provide an internal memory that is updated additively rather than purely multiplicatively. Additive updates enable a path through time along which gradients can flow without repeated multiplicative attenuation. This design principle directly addresses the vanishing gradient problem by creating what is called the constant error carousel: a memory state that can carry error signals across many time steps with controlled modification.

# Constant error carousel: additive memory updates
The constant error carousel refers to the LSTM's central memory update mechanism: the cell state is a stored quantity that evolves by addition of a (gated) new input to a (gated) retained previous state. Concretely, the simplified conceptual form introduced in the paper is

$c_t \ =\ f_t\ c_{t-1} \ +\ i_t\ z_t,$

which expresses the cell state $c_t$ at time $t$ as a combination of the previous cell state $c_{t-1}$ moderated by a forget factor $f_t$ and a newly produced candidate contribution $z_t$ scaled by an input factor $i_t$. This additive structure is the constant error carousel: gradients that flow back through time can pass through the addition path, attenuated only by the forget gates rather than being repeatedly multiplied by arbitrary transition matrices. Because $f_t$ is typically constrained by a gating nonlinearity, this allows gradients to be preserved over long time scales when appropriate.

This additive update contrasts with recurrent updates that only apply multiplicative transformations to hidden states; the additive term provides a route for storing and retrieving content and for stable gradient flow. The cell state, being updated additively and gated, can function as a memory with controllable retention and replacement.

# Gates and activations: input, forget, output; tanh/sigmoid roles
LSTM memory operations are controlled by three principal gates: the input gate $i_t$, forget gate $f_t$, and output gate $o_t$. Each gate modulates a different aspect of how the cell interacts with incoming information and the outside world.

The input gate $i_t$ scales the candidate input contribution $z_t$ before it is added to the cell. The forget gate $f_t$ scales the previous cell state $c_{t-1}$, deciding which parts of memory to retain. The output gate $o_t$ controls how much of the (typically squashed) cell state is exposed as the hidden state $h_t$. In the conceptual form given in the paper, the hidden state is

$h_t \ =\ o_t\ \psi(c_t),$

where $\psi$ is an activation used to normalize or squash the cell state prior to output. Common choices for the squashing function $\psi$ (and for the candidate input activation $\varphi$ producing $z_t$) have been hyperbolic tangent or similar bounded nonlinearities. The gates themselves are produced by affine transforms followed by sigmoid nonlinearities $\sigma(x)=1/(1+\exp(-x))$ in classical LSTM formulations, ensuring gates take values in $(0,1)$ and thus act as soft selectors.

The roles of these activations are important: sigmoidal gates provide smooth, differentiable control over retention and addition, while the squashing $\psi$ keeps the exposed hidden state bounded and stable. Together they form an architecture in which memory content is both preserved and made accessible in a stable manner.

# Standard LSTM equations and parameterization
The paper presents the standard LSTM equations used as a reference point for the xLSTM developments. In that formulation the scalar cell update and gate computations at time $t$ are written as

c_t \ = \ f_t\ c_{t-1} \ + \ i_t\ z_t
h_t \ = \ o_t\ \tilde{h}_t, \quad \tilde{h}_t \ =\ \psi(c_t)

z_t \ =\ \varphi(\tilde{z}_t), \quad \tilde{z}_t \ =\ \mathbf{w}_z^\top \mathbf{x}_t + r_z\ h_{t-1} + b_z

i_t \ =\ \sigma(\tilde{i}_t), \quad \tilde{i}_t \ =\ \mathbf{w}_i^\top \mathbf{x}_t + r_i\ h_{t-1} + b_i

f_t \ =\ \sigma(\tilde{f}_t), \quad \tilde{f}_t \ =\ \mathbf{w}_f^\top \mathbf{x}_t + r_f\ h_{t-1} + b_f

o_t \ =\ \sigma(\tilde{o}_t), \quad \tilde{o}_t \ =\ \mathbf{w}_o^\top \mathbf{x}_t + r_o\ h_{t-1} + b_o.

This parameterization makes clear how inputs $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$ influence the candidate input and each gate via learned affine transforms. The vectors $\mathbf{w}_z,\mathbf{w}_i,\mathbf{w}_f,\mathbf{w}_o$ are input weight vectors (mapping current input to respective preactivations), the scalars $r_z,r_i,r_f,r_o$ are recurrent (hidden-to-preactivation) weights in the scalar-cell case, and $b_z,b_i,b_f,b_o$ are biases. The functions $\varphi$ and $\psi$ are activation functions for the candidate input and the exposed cell content, respectively.

This set of equations captures the classic LSTM cell behavior: it constructs a candidate input, gates it, decides how much previous memory to keep, and controls what is emitted as the hidden state. The gates are typically sigmoid-activated, ensuring bounded multiplicative factors, and $\varphi,\psi$ are often chosen as $\tanh$ to keep candidate and exposed values within a stable range.

# Vectorized multi-cell LSTM and memory mixing via recurrent matrices
Practical LSTM implementations extend the scalar cell to a vector of cells $\mathbf{c}_t \in \mathbb{R}^d$. This vectorization allows richer distributed memory representations and enables mixing between memory cells through recurrent weight matrices. In the multi-cell setup, the affine recurrent contributions to gates and candidate inputs become matrix-vector products involving the previous hidden state vector, replacing scalars like $r_z h_{t-1}$ with terms such as $\mathbf{R}_z\ \mathbf{h}_{t-1}$ where $\mathbf{R}_z \in \mathbb{R}^{d\times d}$.

Memory mixing refers to these hidden-to-gate or hidden-to-candidate recurrent matrices that allow the contents and outputs of different scalar memory cells to influence each other across time steps. Through recurrent matrices $\mathbf{R}_{z},\mathbf{R}_{i},\mathbf{R}_{f},\mathbf{R}_{o}$, the vectorized LSTM gains the capacity to reallocate, transform, and entangle information across memory channels as sequences evolve. This increases expressivity compared to independent scalar cells, and is a core reason LSTMs can perform complex sequence-processing tasks that require combining and updating multiple stored factors.

The paper highlights that such mixing (hidden-hidden connections) is also the source of sequential dependence that prevents certain parallelization strategies: memory mixing enforces a temporal dependence that must be computed step by step. Nevertheless, memory mixing is crucial for tasks requiring state tracking and interactions among stored components.

# Why each component matters: lessons from ablations
The paper notes that ablation studies on classical LSTM designs have shown that all components of the memory cell are crucial. That is, removing or significantly altering gates, the additive memory update, or the squashing functions degrades performance and learning stability. Each component fulfills a distinct functional role: the forget gate controls retention and prevents unbounded accumulation, the input gate mediates selective storage of new information, and the output gate controls exposure of internal state to downstream computations. The additive update (constant error carousel) is the structural mechanism that preserves gradients over long time horizons. The activation functions constrain numeric ranges and provide smooth nonlinearity necessary for learning.

These insights motivate the design choices in the xLSTM extensions introduced later in the paper. For example, xLSTM retains the core idea of a memory cell with gating and a normalizing/squashing step, but systematically modifies the gating nonlinearities (introducing exponential gating) and the memory structure (introducing scalar-head mixing variants and a matrix-valued covariance memory) to alleviate specific limitations identified for classical LSTMs. The paper uses a sequence of controlled changes—embedding LSTMs in residual backbones, changing projection orders, adding exponential gates, and expanding memory representations—to ablate and attribute performance gains to specific components. The broader lesson is that each canonical LSTM element is functionally important, and improvements must preserve their roles while addressing identified shortcomings like limited storage capacity, inability to revise storage decisions, and parallelization constraints.

In summary, the LSTM foundations—constant error carousel, gated additive updates, squashing and gating nonlinearities, and recurrent mixing in vectorized cells—together explain both the original success of LSTMs and why careful, principled modifications (as advocated in the paper) can yield powerful extensions such as xLSTM.
