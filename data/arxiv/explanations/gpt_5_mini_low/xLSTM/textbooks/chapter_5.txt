Chapter 5: sLSTM: Scalar-Memory xLSTM with Memory Mixing

# sLSTM forward pass: c_t, n_t, h_t with normalized output
The sLSTM is an Extended Long Short-Term Memory variant that keeps the familiar scalar memory cell per channel like the classical LSTM, but augments the cell with new gating and normalization mechanisms tailored to improve revision of stored content and stable retrieval. At each time step $t$ the sLSTM maintains three central state quantities per memory channel: the cell state $c_t$, a normalizer state $n_t$, and the hidden output $h_t$. The forward pass is written compactly as

$c_t = f_t \, c_{t-1} + i_t \, z_t,$

$n_t = f_t \, n_{t-1} + i_t,$

$h_t = o_t \, \tilde{h}_t,\qquad \tilde{h}_t = \dfrac{c_t}{n_t}.$

Here $z_t$ denotes the cell input (the new content proposed for storage), $i_t$ the input gate, $f_t$ the forget gate, and $o_t$ the output gate. Intuitively, $c_t$ accumulates gated contributions of past inputs just like in classical LSTM, but the normalizer $n_t$ accumulates the scalar weights used to form $c_t$ so that the quotient $c_t / n_t$ yields a normalized estimate of the stored content. This normalization ensures that the magnitude of the retrieved signal is controlled relative to the aggregate gating strength, which is critical when gates are allowed to take values beyond the unit interval (see below).

The retrieval $\tilde{h}_t = c_t / n_t$ should be understood as a running weighted average: if $i_t$ and $f_t$ behave like conventional probabilities (values in $(0,1]$), then $c_t$ approximates a weighted sum of past $z$ values and $n_t$ the corresponding sum of weights; dividing yields a weighted mean. This design permits the memory to represent an amortized stored content over time and makes the effect of any single write proportional to its relative weight among the contributions that remain after forget gating.

# Exponential input/forget gates; output gate sigmoid
A major departure from classical LSTM is the choice of activation for the input and optionally the forget gates. In sLSTM the input gate is realized via an exponential activation:

$i_t = \exp(\tilde{i}_t),\qquad \tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i \, h_{t-1} + b_i.$

The forget gate may be either sigmoid or exponential:

$f_t = \sigma(\tilde{f}_t) \quad\text{or}\quad f_t = \exp(\tilde{f}_t),\qquad \tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f \, h_{t-1} + b_f.$

The output gate remains sigmoid as in traditional LSTM:

$o_t = \sigma(\tilde{o}_t),\qquad \tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o \, h_{t-1} + b_o.$

Using exponentials for $i_t$ (and optionally for $f_t$) has a conceptual purpose: exponentials map linear preactivations $\tilde{i}_t$ to positive real multipliers that can span many orders of magnitude. This allows a single write to be given much larger or much smaller effective weight compared to previous stored content. In practice, exponentially large or small gates enable the model to "revise" stored information sharply: a large $i_t$ can overwrite prior content rapidly, while a small $f_t$ (much less than 1 when implemented via an exponential of a negative preactivation) can rapidly decay prior content. The combination thus provides the model with a continuous mechanism to modulate retention and replacement strength across a wide dynamic range, beyond the slow adjustments available with sigmoid gates alone.

# Stabilization with m_t and rescaled gates i'_t, f'_t
Exponentials are powerful but numerically hazardous: unbounded exponentials can overflow or underflow during forward computation and can create extremely large gradients. The sLSTM design therefore introduces a stabilizer scalar state $m_t$ that maintains a running log-scale reference and allows numerically safe rescaling of the gates without changing the functional behavior of the recurrence. The stabilizer is defined by

$m_t = \max\big(\log(f_t) + m_{t-1},\; \log(i_t)\big).$

Using $m_t$ we define rescaled gates that are safe to compute and use in the recurrence:

$i'_t = \exp\big(\log(i_t) - m_t\big) = \exp(\tilde{i}_t - m_t),$

$f'_t = \exp\big(\log(f_t) + m_{t-1} - m_t\big).$

Replacing $i_t$ and $f_t$ by $i'_t$ and $f'_t$ in the forward equations yields exactly the same outputs and derivatives with respect to parameters as the original unrescaled form. The stabilizer works by factoring out a common multiplicative scale $e^{m_t}$ from terms that would otherwise grow or shrink exponentially: one computes exponentials of bounded differences (e.g., $\tilde{i}_t - m_t$) rather than possibly huge raw preactivations. This trick is analogous to standard log-sum-exp stabilization and keeps internal values numerically well-behaved while preserving the expressive large-dynamic-range behavior of exponential gating.

In implementation, one computes $i'_t$ and $f'_t$ and then uses them in the recurrences

$c_t = f'_t \, c_{t-1} + i'_t \, z_t,\qquad n_t = f'_t \, n_{t-1} + i'_t.$

Although the notation uses primes, by construction these stabilized gates are mathematically equivalent to using the raw exponentials in exact arithmetic.

# Multiple cells and memory mixing via recurrent matrices
Just as modern LSTMs use vector-valued memory with multiple scalar channels, the sLSTM naturally extends to multiple scalar memory cells. Let the memory vector be $\mathbf{c}_t \in \mathbb{R}^d$ and the normalizer vector $\mathbf{n}_t \in \mathbb{R}^d$, with elementwise division performed channel-wise to obtain the pre-output $\tilde{\mathbf{h}}_t = \mathbf{c}_t \oslash \mathbf{n}_t$. The crucial extension beyond the original LSTM lies in how inputs and past hidden states interact to produce the cell inputs and gates: memory mixing is achieved by recurrent matrices that map the hidden state back into the gate and candidate preactivations. Concretely, for vectorized quantities one writes

\tilde{\mathbf{z}}_t = \mathbf{W}_z^\top \mathbf{x}_t + \mathbf{R}_z \mathbf{h}_{t-1} + \mathbf{b}_z,\qquad
\tilde{\mathbf{i}}_t = \mathbf{W}_i^\top \mathbf{x}_t + \mathbf{R}_i \mathbf{h}_{t-1} + \mathbf{b}_i,

and analogously for $\tilde{\mathbf{f}}_t$ and $\tilde{\mathbf{o}}_t$. Here each $\mathbf{R}_\bullet \in \mathbb{R}^{d\times d}$ is a recurrent matrix that mixes information across memory channels via the previous hidden state $\mathbf{h}_{t-1}$. After applying the respective activations (exponential or sigmoid), the multi-channel recurrences become

\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \mathbf{z}_t,\qquad
\mathbf{n}_t = \mathbf{f}_t \odot \mathbf{n}_{t-1} + \mathbf{i}_t,

with elementwise multiplication and division defining retrieval. These recurrent matrices provide a flexible mixing mechanism: information stored in one channel can influence gating and writes to other channels via $\mathbf{R}_i,\mathbf{R}_f,\mathbf{R}_z,\mathbf{R}_o$. This mixing is the reason sLSTM retains a key expressive advantage of classical LSTM: it can implement state-tracking computations that depend on interactions among stored components across time.

Memory mixing is essential for tasks that require structured state updates or the composition of different stored items. Unlike architectures which only maintain independent channels (no cross-channel recurrence), sLSTM's recurrent matrices allow it to implement complex sequential algorithms and maintain internal bookkeeping across channels.

# Heads in sLSTM: within-head mixing, no cross-head mixing
To further structure memory mixing and to provide architectural inductive biases, sLSTM supports a "multi-head" decomposition reminiscent of attention heads, but with an important difference in interaction patterns. When the memory vector is partitioned into H disjoint heads, each head maintains its own subset of scalar memory channels. Within a head, the usual recurrent mixing matrices operate: the head's hidden components influence gate and input preactivations for channels of the same head via dedicated recurrent matrices. However, by design there is no recurrent mixing across heads: the $\mathbf{R}_\bullet$ matrices are block-diagonal with blocks corresponding to heads. In other words, heads are independent with respect to memory mixing.

Formally, partition the memory dimension $d$ into $d = \sum_{h=1}^H d_h$ and arrange recurrent matrices to be block-diagonal: for head $h$ the matrices $\mathbf{R}_\bullet^{(h)} \in \mathbb{R}^{d_h\times d_h}$ operate only on the head’s slice of $\mathbf{h}_{t-1}$. Inputs $\mathbf{x}_t$ are projected separately into each head, and updates to $\mathbf{c}_t$ and $\mathbf{n}_t$ are computed head-wise. Output concatenation across heads then yields the full $\mathbf{h}_t$.

This head-wise partitioning provides two practical benefits. First, it reduces the parameter and computational coupling between different memory subspaces, which can stabilize optimization and encourage specialization of heads to different types of patterns. Second, it allows controlled parallelism and modularity: while each head still has internal recurrent mixing, the absence of cross-head recurrence reduces sequential dependencies between unrelated memory subspaces.

# How exponential gating + heads enable new memory mixing behaviors
Combining exponential gating with a head-structured sLSTM yields qualitatively new memory-mixing capabilities. Exponential gates permit multiplicative weights that vary over many orders of magnitude. When such gates are computed from mixed information within a head (via $\mathbf{R}_i^{(h)}$ and $\mathbf{R}_f^{(h)}$), a head can perform sharp and selective revisions to portions of its internal memory based on global or local context.

Concretely, consider a head that has learned to store a running aggregate of some feature in its channels. If at some step the head's input projection produces a large positive $\tilde{i}_t$ for a particular channel, the exponential input gate will give a dominant weight to the new $z_t$ relative to the accumulated $c_{t-1}$; by simultaneously setting $f_t$ small via its preactivation, the head can effectively erase or replace previous content in certain channels. Because the recurrent matrices within the head mix the previous hidden state into the gate computation, the decision to rewrite can depend on complex combinations of previously stored subcomponents. Therefore, exponential gates plus within-head recurrence implement a form of context-dependent fast rewrite: heads can choose, based on the current and past hidden state, to concentrate write mass on a small subset of channels or to distribute it broadly.

The head partitioning constrains this behavior so that such fast rewrites are localized to a head's subspace, preventing uncontrolled interference across all memory channels. This localized, high-dynamic-range rewriting is a new memory-mixing modality: it is neither purely additive averaging (classical LSTM with sigmoid gates) nor the full-rank outer-product memory of matrix-memory variants, but rather an adaptive, head-local multiplicative rewriting mechanism that can be extremely selective.

# Trade-offs: expressivity vs. parallelization
sLSTM preserves the expressive power afforded by recurrent cross-channel mixing, and the addition of exponential gating significantly enhances the model’s ability to rapidly revise stored content. These features make sLSTM particularly well-suited for tasks that require state tracking, selective overwriting, and algorithmic manipulation of internal scalar memory channels.

However, this expressivity comes with trade-offs. The recurrent mixing via $\mathbf{R}_\bullet$ matrices enforces true sequential dependencies: each time step depends on the previous hidden state. Consequently, sLSTM cannot be straightforwardly transformed into a fully parallel time-parallel implementation in the same way as architectures that remove hidden–hidden recurrence (for example, the matrix-memory mLSTM or certain State Space Models). The presence of sequential recurrence limits the extent to which sLSTM can exploit parallel hardware across time steps, making its wall-clock inference and training time dependent on efficient sequential kernels.

To mitigate numerical issues stemming from exponential gates, the stabilizer $m_t$ is necessary and adds a small computational overhead. The head decomposition reduces cross-talk and can improve both sample efficiency and numerical stability, but choosing the number and sizes of heads introduces design choices that affect parameter counts and performance.

In summary, sLSTM trades some parallelizability for richer, head-local memory mixing and high-dynamic-range gating that enable rapid and selective memory revision. This makes it a compelling component when the task demands strong sequential state tracking and controlled internal rewriting, at the cost of requiring careful engineering of efficient sequential implementations and stabilization mechanisms.
