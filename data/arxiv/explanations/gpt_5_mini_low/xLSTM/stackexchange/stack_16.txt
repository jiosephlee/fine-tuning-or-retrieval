\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### Ablation clarity: how much gain comes from exponential gates vs matrix memory vs backbone changes?
Question:
The ablations progressively morph a vanilla LSTM into xLSTM by adding pre-LayerNorm residual backbones, up-projection blocks, exponential gating, and matrix memory. Could someone quantify the incremental perplexity improvements attributable to each change in isolation? For example: vanilla LSTM in residual block (no exp gates), then add exp gates only, then add matrix memory only, then both. This would help separate gains due to training stabilization/backbone from genuine modeling advances (exp gates, mLSTM).
Answer:
Short answer: the paper’s ablation (Table~\ref{tab:ablstudies} referenced in Section 4.2) reports that the largest single gains come from the new memory structures (mLSTM matrix memory) and from exponential gating, with additional modest but non‑negligible benefit from switching the LSTM into the modern pre‑LayerNorm residual backbone and up‑projection block. However, the paper does not print a single linear decomposition (e.g. $\text{backbone: } -X\ \text{ppl},\ \text{exp-gates: } -Y\ \text{ppl},\ \text{matrix: } -Z\ \text{ppl}$ for an otherwise identical model) in the text excerpt you gave; it only states qualitatively that both exponential gating and matrix memory account for the strong improvement and that detailed ablation numbers are in Table~\ref{tab:ablstudies} (top) and Appendix~\ref{sec:appAblDetails}. So I can’t give exact numeric deltas here without quoting that table.

What the paper does make clear (and what’s important when you interpret any ablation numbers) is:

1) Nonlinearity and interaction effects. The components interact: exponential gating changes the dynamics of memory updates and so can amplify (or reduce) the effect of changing the memory structure. That means the improvement of adding component B after A is not necessarily the same as adding B to the vanilla model. The authors therefore report stepwise morphing (vanilla LSTM $\rightarrow$ LSTM inside pre‑LayerNorm residual block $\rightarrow$ add post up‑projection $\rightarrow$ add exponential gating $\rightarrow$ add matrix memory) rather than isolated single‑change experiments only. This is the correct experimental design to show practical gains but it also means simple additive attribution is only approximately valid.

2) Qualitative ordering of contributions. From the paper’s discussion and the ablation summary the authors emphasize two main modeling advances as primary drivers of the performance jump: (a) exponential gating (which enables revising storage decisions and stabilizes long‑term state tracking), and (b) matrix memory (mLSTM) which increases effective storage capacity and improves rare token prediction / associative recall. The backbone changes (pre‑LayerNorm residual blocks, up‑projection) are necessary for stable training at scale and give a nontrivial benefit (training/stabilization and representation power), but they are presented as enabling infrastructure rather than the main modeling novelty.

3) Gate design matters. The paper’s lower part of the ablation shows that making gates input‑dependent and learnable produces incremental improvements — i.e., expressive gating gives further, measurable gains beyond simply using an exponential nonlinearity.

If you need the exact perplexity deltas to attribute percent contribution, there are two concrete actions:

- Look up Table~\ref{tab:ablstudies} (top) and Appendix~\ref{sec:appAblDetails} in the paper/pdf. That table contains the stepwise experiments and the validation perplexities for the sequence of morphing steps. Subtract successive rows to get the incremental deltas (for example: $\text{perplexity}(\text{LSTM-in-residual}) - \text{perplexity}(\text{LSTM-vanilla})$ gives the backbone effect; $\text{perplexity}(\text{+exp-gates}) - \text{perplexity}(\text{prior})$ gives the exp‑gate effect; etc.). Because the authors performed the morph in steps, those differences are the closest thing to the isolated contributions available in the paper.

- If you want a stricter isolation (each change from the same reference baseline), re‑run or request runs for the four canonical controlled comparisons you suggested: (A) baseline = vanilla LSTM inside the residual block (no exponential gates, no matrix memory), (B) baseline + exponential gates only, (C) baseline + matrix memory only, (D) baseline + both. Record validation perplexity for each and compute deltas: $\text{delta\_exp} = \text{ppl}(B) - \text{ppl}(A)$, $\text{delta\_mat} = \text{ppl}(C) - \text{ppl}(A)$, $\text{delta\_both} = \text{ppl}(D) - \text{ppl}(A)$. Expect non‑additivity: $\text{delta\_both}$ often $\neq$ $\text{delta\_exp} + \text{delta\_mat}$ because of interactions.

Practical notes / intuition that the paper supports: exponential gates address a modeling limitation (inability to revise storage decisions) and improve tasks requiring state tracking; matrix memory addresses limited storage capacity and helps rare token prediction and associative recall. The residual backbone and up‑projection mainly stabilize and scale the training (so their contribution is more about making the other changes effective at scale than about improved memory per se). Thus when you see large perplexity improvements in the ablation, interpret them as a mix of modeling capacity increases (exp‑gates and mLSTM) plus improved optimization/training stability (backbone).
