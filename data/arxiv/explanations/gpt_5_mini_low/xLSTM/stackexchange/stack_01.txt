\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How exactly do exponential input/forget gates enable “revising” stored values in sLSTM?
Question:
The paper claims that standard LSTMs struggle to revise storage decisions (e.g., in the Nearest Neighbor Search toy task), and that sLSTM fixes this via exponential gating. In equations (Eq. 11–17 for sLSTM), the update is still additive: $c_t = f_t c_{t-1} + i_t z_t$, but now $i_t = \exp(\tilde{i}_t)$ and $f_t \in \{\sigma(\tilde{f}_t), \exp(\tilde{f}_t)\}$. Intuitively, how does switching from sigmoid to exponential produce the ability to overwrite or revise earlier content? Is the key that $i_t$ can become arbitrarily large (compared to the bounded $\sigma$), thus dominating $f_t c_{t-1}$? If so, how is numerical stability preserved beyond the normalizer $n_t$ and stabilizer $m_t$? A small worked example showing where a later, more-similar vector replaces an earlier stored vector would help.
Answer:
Short answer: exponential gates let a later update multiply the new input by an arbitrarily large positive factor so that, after normalization by the accumulated gate strength, the cell state becomes effectively the new input (i.e. the old stored content is "overwritten"). The sLSTM explicitly keeps a normalizer $n_t$ that sums the effective gate strengths; dividing $c_t$ by $n_t$ yields a weighted average of past inputs where exponential gates control the weights. Numerical stability is handled by the stabilizer $m_t$ (subtracting a running log-scale) so exponentials never overflow while preserving the relative ratios that determine which input dominates.

Why this enables revising (intuitive + math)
In the ordinary LSTM both gates use sigmoid outputs in $(0,1)$. The cell update is additive,
$c_t = f_t c_{t-1} + i_t z_t$,
so each new input contributes at most a bounded fraction $i_t \in (0,1)$ of its transformed value $z_t$. If the network earlier stored a value with some persistent $f$-chain, later inputs cannot suddenly dominate because $i_t$ is bounded and $f_t$ only decays previous content multiplicatively by another value in $(0,1)$. That makes it hard to "revise" (fully replace) a previously committed value unless you explicitly learn a forget gate near zero.

sLSTM changes two things that matter for revision: (1) gates can be exponential, i.e. $i_t = \exp(\tilde{i}_t)$, so $i_t$ is unbounded above and can be made arbitrarily large; (2) the cell keeps a normalizer $n_t$ that accumulates the same gate strengths:
$n_t = f_t n_{t-1} + i_t$,
and the hidden pre-output is the normalized state $\tilde{h}_t = c_t / n_t$. Combine these and rewrite $c_t / n_t$ as a weighted average of past $z$'s (intuitively). If we unroll for two steps for clarity:

At $t=1$:
$c_1 = i_1 z_1,\quad n_1 = i_1,\quad$ so $\tilde{h}_1 = z_1$.

At $t=2$:
$c_2 = f_2 c_1 + i_2 z_2 = f_2 i_1 z_1 + i_2 z_2$,
$n_2 = f_2 n_1 + i_2 = f_2 i_1 + i_2$,
so
$\tilde{h}_2 = \dfrac{f_2 i_1 z_1 + i_2 z_2}{f_2 i_1 + i_2}$.

This is exactly the weighted average of $z_1$ and $z_2$ with weights $f_2 i_1$ and $i_2$. If the network wants $z_2$ to replace $z_1$ it simply makes $i_2 \gg f_2 i_1$ (possible because $i_2$ can be exponentially large). Then $\tilde{h}_2 \approx z_2$. In contrast, with sigmoid gates $i_2$ is capped and might not be able to overwhelm the accumulated $f_2 i_1$ weight, so full replacement is hard.

Worked numerical example
Take simple scalar $z$ values and concrete gate numbers to illustrate replacement. Let $z_1 = 1.0$, $z_2 = 0.9$ (so $z_2$ is more similar to some later query—only the magnitudes matter here). Choose $i_1 = \exp(0) = 1.0$ (first store), $f_2 = \sigma(0) = 0.5$ (moderate carry), and pick two scenarios for $i_2$:

1) Sigmoid-limited scenario (ordinary LSTM-like): suppose $i_2 = \sigma(2) \approx 0.88$. Then
$c_2 = 0.5 * 1.0 * 1.0 + 0.88 * 0.9 = 0.5 + 0.792 = 1.292$,
$n_2 = 0.5 * 1.0 + 0.88 = 0.5 + 0.88 = 1.38$,
so $\tilde{h}_2 = c_2 / n_2 \approx 0.936$. This is a compromise between $1.0$ and $0.9$ and still biased toward the earlier larger $z_1$.

2) Exponential $i_2$ (sLSTM): let $\tilde{i}_2 = 3$ so $i_2 = \exp(3) \approx 20.09$. Now
$c_2 = 0.5 * 1.0 * 1.0 + 20.09 * 0.9 = 0.5 + 18.081 = 18.581$,
$n_2 = 0.5 * 1.0 + 20.09 = 0.5 + 20.09 = 20.59$,
so $\tilde{h}_2 = 18.581 / 20.59 \approx 0.902$. This is essentially $z_2$: the huge $i_2$ overwhelms the carried term $f_2 i_1$, so the later vector replaces the earlier stored content.

Note how the ratio $i_2 / (f_2 i_1)$ controls who wins. Making $i_2$ large is how sLSTM implements revision.

Numerical stability: why we don't overflow and why ratios are preserved
Exponentials can overflow. The paper addresses this with the stabilizer state $m_t$ defined by
$m_t = \max(\log(f_t) + m_{t-1}, \log(i_t))$,
and uses stabilized gates
$i'_t = \exp(\log(i_t) - m_t) = \exp(\tilde{i}_t - m_t)$,
$f'_t = \exp(\log(f_t) + m_{t-1} - m_t)$.
This is a standard log-sum-exp style trick: $m_t$ holds the running maximum log-scale of accumulated contributions; subtracting $m_t$ rescales both the numerator and denominator terms to be in a safe dynamic range. Crucially, this normalization is scale-invariant: it multiplies numerator and denominator of $\tilde{h}_t$ by the same factor so the ratio (hence the network output and gradients) is unchanged. The paper states explicitly that replacing $f_t$ and $i_t$ with $f'_t$ and $i'_t$ "neither change(s) the output of the whole network nor the derivatives of the loss with respect to the parameters." So we get the unbounded relative expressivity of exponential gating without numerical overflow.

Broader perspective and intuition
You can think of sLSTM's $c_t$ and $n_t$ as maintaining a running (unnormalized) weighted sum of stored inputs and of the corresponding weights; dividing yields a kind of exponential-weighted memory readout. Exponential activation turns additive logits into multiplicative (and therefore arbitrarily large) positive weights; the stabilizer ensures operations remain numerically safe. This is similar in spirit to attention where a query can place arbitrarily large (relative) weight on one memory slot via the softmax exponentials; here, the model uses exponentials in the gates to control relative contributions across time. The key difference from standard LSTM is that gates are no longer bounded to $(0,1)$, so a later input can dominate previous memory even when those previous contributions were held by a persistent forget chain.

Concluding remark
So yes: the essential mechanism is that $i_t$ can grow unbounded and by working together with the normalizer $n_t$ the model implements a weighted average where later inputs can dominate (overwrite) earlier ones. The stabilizer $m_t$ and the normalizer $n_t$ are the engineering pieces that keep the arithmetic stable while preserving the relative ratios that effect revision.
