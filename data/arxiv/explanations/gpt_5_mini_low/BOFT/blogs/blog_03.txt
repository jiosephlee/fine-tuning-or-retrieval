\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Fine-Tuning as Information Flow: A New Way to Think About Orthogonal Updates

Fine-tuning large pretrained models is now a routine but expensive task. Orthogonal Finetuning (OFT) proposed a neat idea: instead of adding low‑rank updates or changing the model weights arbitrarily, multiply the pretrained weight matrix on the left by an orthogonal matrix so that pairwise angles between neurons are preserved. That helps retain pretrained structure and often improves stability and generalization—but dense orthogonal matrices are costly: a full $d\times d$ orthogonal matrix naively needs $\mathcal{O}(d^2)$ parameters.

This paper reframes the problem in a simple, useful way: generating a dense orthogonal transform by composing several sparse matrices is equivalent to routing information across a grid. From that viewpoint, the choice of sparsity pattern for the factor matrices is not just an implementation detail—it is the communication topology. Picking the right topology yields dense overall connectivity while keeping the number of trainable entries low. The paper uses this idea to build Orthogonal Butterfly Finetuning (BOFT), which achieves dense, orthogonal transforms with only about $\mathcal{O}(d\log d)$ parameters by exploiting butterfly factorization (the topology behind the FFT).

Below I unpack that viewpoint and highlight why the butterfly topology is a natural and efficient choice.

## Orthogonal updates as an information transmission problem

Think of an orthogonal finetuning update as replacing a pretrained linear layer $(W^0)^\top x$ by $(R W^0)^\top x$ where $R\in\mathbb{R}^{d\times d}$ is orthogonal and learned (initialized as identity). Instead of learning a single dense $R$, represent it as a product of $m$ square matrices:
R = B_m B_{m-1} \cdots B_1.

Now draw a grid with $d$ nodes in each of the $m+1$ vertical layers. Each factor matrix B_i describes the edges between layer i and i+1: a nonzero entry at position (row i, col j) means information from node j in layer i can reach node i in layer i+1. Multiplying all factors is equivalent to composing these local transmissions: for R to be dense, every source node (first layer) must have a path to every sink node (final layer).

This graph view gives two natural desiderata for a factorization:

- Dense connectivity: every source node should be able to reach every sink node via some path across the layers, so the composed matrix can be dense.
- Minimum free/trainable edges: subject to orthogonality constraints, use as few trainable degrees of freedom as possible to reduce parameter count and regularize learning.

Framing the problem this way makes clear why naive choices (e.g., a single dense orthogonal factor) are parameter-heavy, and why some sparse choices (e.g., block‑diagonal OFT) are cheap but fail to provide dense global connectivity.

## Why the sparsity pattern matters

Two sparse factorizations with the same count of nonzeros can behave very differently because they induce different reachability patterns across the grid. A block‑diagonal orthogonal factor (the OFT variant used earlier for efficiency) partitions the $d$ dimensions into independent groups. That saves parameters, but nodes in one block cannot influence nodes in another block—so the composed R is block‑structured and cannot reproduce many standard transforms or capture cross‑group interactions.

From the information flow perspective, block‑diagonal factors literally cut the network into separate subnetworks; some source→sink paths are impossible. This reduces expressivity in a structured-but-arbitrary way and forces a strong inductive bias that may or may not match the downstream task.

What you want instead is a sparse factorization whose local edges, when composed, allow every source to reach every sink while keeping the number of trainable parameters low. That is where butterfly topologies enter.

## Butterfly topologies: efficient global reachability

Butterfly graphs were discovered in the context of the Cooley–Tukey FFT algorithm. They implement a multi-stage communication pattern where each stage only connects small local pairs, but the composition of stages gives global mixing between all inputs and outputs.

Concretely, for $d=2^N$, a radix‑2 butterfly factor at a given stage consists of independent $2\times 2$ blocks arranged so that across $N$ stages every output depends on every input. If you parametrize each stage with orthogonal $2\times 2$ blocks (rotations), the product of the stages is an orthogonal matrix. With block sizes $b$ and $m$ stages, the BOFT parameter count grows like
O((b - 1) d m) (the paper gives $\frac{1}{2}(b-1)dm$ effective trainable parameters),
and with the canonical butterfly choice $b=2$, $m\approx\log d$, this is $\mathcal{O}(d\log d)$ parameters—far cheaper than $\mathcal{O}(d^2)$.

Why is this attractive?

- Every input can reach every output (dense connectivity) after enough butterfly stages, so the composed transform is dense.
- The number of trainable blocks per stage is linear in $d$, and the number of stages grows logarithmically, giving a favorable tradeoff between expressivity and parameter efficiency.
- The butterfly structure can recover many classical fast transforms (FFT, Hadamard, DCT variants), suggesting the topology is well-matched to signal mixing and useful inductive biases.

## BOFT in practice: how the method is set up

BOFT (Orthogonal Butterfly Finetuning) adopts the above factorization in an OFT-style multiplicative update: the pretrained weight $W^0$ stays frozen, and the finetuned layer computes $(R W^0)^\top x$ where R is the product of orthogonal butterfly components. Important practical points from the paper:

- Orthogonality: each butterfly component is constrained to be orthogonal. In practice this is enforced via Cayley parameterization (a standard skew-symmetric parameterization) or 2×2 rotations at the smallest block granularity.
- Identity initialization: to start from the pretrained model exactly, BOFT initializes all butterfly components as identity (zero skew-symmetric parameters), analogous to zero initialization in additive methods like LoRA.
- Multiplicative Dropout: ordinary dropout does not naturally apply to multiplicative updates. BOFT proposes a multiplicative dropout that randomly replaces some butterfly components or blocks with identity matrices during finetuning to regularize and prevent overfitting.
- Flexibility: BOFT generalizes OFT. With one stage and block size $b$ it reduces to block‑diagonal OFT; with $m=\log d$ and $b=2$ it realizes the canonical butterfly giving dense R with $\mathcal{O}(d\log d)$ parameters. Larger block sizes give intermediate tradeoffs.

## Expressivity, inductive bias, and tradeoffs

A few conceptual takeaways the paper emphasizes:

- Expressivity vs. regularity: full dense orthogonal R is maximally expressive but large and can overfit. Block‑diagonal R is small but overly restrictive. Butterfly-structured R sits between them, giving structured expressivity and a smoother interpolation between identity and full orthogonal transforms.
- The butterfly family can represent many useful transforms exactly; with more complex compositions (kaleidoscope-type products of butterflies) it can approximate the whole orthogonal group. But more expressivity is not always better for finetuning; restricting the hypothesis class can improve generalization.
- BOFT preserves spectral norms of the pretrained weight matrices (left multiplication by an orthogonal matrix does not change singular values), which helps training stability.

## Limitations and open points

The approach is not free: multiplying multiple factor matrices in the forward pass adds some training-time overhead compared to few-parameter additive updates. The paper notes this runtime cost, but also that the learned R can be merged into the network weights after finetuning so there is no extra inference cost.

Another open question is whether the butterfly topology is the most parameter‑efficient communication pattern for this goal. The information‑transmission framework introduced in the paper invites exploration of other network topologies from communication and networking literature that might provide even better parameter vs. expressivity tradeoffs.

## Takeaway

Recasting orthogonal finetuning as routing information through a grid is a compact but powerful idea: it exposes why different sparse factorization choices behave so differently and gives a principled way to choose them. The butterfly topology is a practical, well‑motivated choice that delivers dense effective transforms with far fewer parameters than a dense orthogonal matrix, while preserving useful inductive bias and spectral properties. If you are looking for a multiplicative, orthogonality‑preserving finetuning method that balances expressivity and parameter efficiency, BOFT is a conceptually clean and practically attractive option grounded in this information‑flow view.
