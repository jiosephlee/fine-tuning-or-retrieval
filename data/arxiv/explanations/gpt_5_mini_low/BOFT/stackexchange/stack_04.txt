\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the butterfly factorization ensure dense connectivity with only \(\mathcal{O}(d\log d)\) parameters?
Question:
The paper claims that stacking \(m=\log d\) butterfly components gives a dense orthogonal matrix \(\mathbf{R}\) using \(\mathcal{O}(d\log d)\) parameters. Could someone explain in graph-theoretic terms why every source node can reach every sink node after \(\log d\) butterfly layers? A small worked example for \(d=8\) would be very helpful.
Answer:
Short answer: the butterfly factorization is exactly the FFT / butterfly communication network viewed as a layered directed graph. Each butterfly layer mixes pairs of coordinates at a fixed stride so that after $m=\log_2 d$ layers the network can combine (and therefore route information from) every source coordinate to every sink coordinate. Graph-theoretically, each layer provides edges that flip one binary digit of the index; composing all $\log_2 d$ digits lets you reach any destination. Because each layer only uses $\mathcal{O}(d)$ $2\times2$ blocks, the full product uses $\mathcal{O}(d\log d)$ parameters.

Explanation and $d=8$ worked example (intuition + technical detail). The paper models the factorization
$\mathbf{R}=\mathbf{B}_m\mathbf{B}_{m-1}\cdots\mathbf{B}_1$
as information flowing through a $d\times(m+1)$ grid of nodes: the first column are source nodes (input coordinates), the last are sink nodes (output coordinates), and each $\mathbf{B}_\ell$ gives the edges from level $\ell$ to $\ell+1$. A dense $\mathbf{R}$ means every source has at least one path to every sink.

The radix-2 butterfly component at a given layer is a block-diagonal matrix of $2\times2$ mixing blocks whose pattern is a permutation of the adjacent-pair mixings used in the FFT. Concretely, for $d=2^N$ the usual (radix-2) three layers for $d=8$ are:

- Layer 1 (mix stride 1): pairwise mixes $(0,1)$, $(2,3)$, $(4,5)$, $(6,7)$.
- Layer 2 (mix stride 2): pairwise mixes $(0,2)$, $(1,3)$, $(4,6)$, $(5,7)$.
- Layer 3 (mix stride 4): pairwise mixes $(0,4)$, $(1,5)$, $(2,6)$, $(3,7)$.

Here indices are $0\ldots7$. Each mix is a $2\times2$ orthogonal block that allows information to flow between the two indices in that pair. Think of each layer as allowing you to toggle one particular bit in the binary index of a coordinate: layer 1 lets you mix indices that differ in bit $0$, layer 2 mixes those that differ in bit $1$, and layer 3 mixes those that differ in bit $2$.

Why this yields dense connectivity: represent source index and sink index in binary with $3$ bits. Any path from source to sink can be realized by, at each layer, choosing whether to use the local $2\times2$ mixing to flip the target bit or to keep it. More formally, after layer $\ell$ you can reach any index that matches the first $\ell$ (least significant) bits you have chosen; continuing through $\ell=1\ldots m$ lets you set all $m$ bits arbitrarily. Thus for any source index $s$ and any target index $t$ there exists a sequence of local choices (use the mixing in each relevant pair) yielding a path from $s$ to $t$. In the $d=8$ example, take source $s=2$ (binary $010$) and target $t=5$ (binary $101$). Layer-by-layer you can move:

- Layer 1 (bit0): $2$ ($010$) can mix with $3$ ($011$) if you want bit0=$1$, or stay if you want bit0=$0$. To reach $5$ whose bit0=$1$, use block $(2,3)$ to go to $3$.
- Layer 2 (bit1): now at $3$ ($011$), layer 2 mixes $(1,3)$ and $(0,2)$ etc; to get bit1=$0$ (target has bit1=$0$), choose the appropriate branch (use or skip the $(1,3)$ mixing) to end up with index whose bit1 is $0$.
- Layer 3 (bit2): finally control the most significant bit via the $(0,4),(1,5),(2,6),(3,7)$ blocks to set bit2=$1$ and arrive at $5$.

This constructive argument shows a path exists for any $s\to t$, so the composed matrix $\mathbf{R}=\mathbf{B}_3\mathbf{B}_2\mathbf{B}_1$ has no structural zeros — it is dense.

Parameter count: every layer is made of $d/2$ independent $2\times2$ orthogonal blocks (or $d/2$ blocks of size $2b\times2b$ in the block-generalization). Each $2\times2$ orthogonal block has one degree of freedom (an angle), so each layer contributes $\mathcal{O}(d)$ free parameters. With $m=\log_2 d$ layers the total free parameters scale as $\mathcal{O}(d\log d)$, matching the claim in the paper.

Broader connection: this is the same combinatorial property that makes the FFT $O(d\log d)$: the butterfly network achieves full pairwise mixing (global connectivity) by composing local pairwise mixes that each handle one binary digit. The paper uses this network to trade parameter count for depth: many sparse orthogonal factors (each cheap) compose to give a dense orthogonal transform (expressive), yielding parameter-efficient orthogonal finetuning.
