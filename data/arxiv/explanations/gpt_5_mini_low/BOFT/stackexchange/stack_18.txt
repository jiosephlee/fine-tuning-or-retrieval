\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does BOFT handle layers with different input/output dimensions (rectangular \(\mathbf{W}^0\))?
Question:
The formulation uses \(\mathbf{W}^0\in\mathbb{R}^{d\times n}\) and left-multiplies by \(\mathbf{R}\in\mathbb{R}^{d\times d}\). For layers where \(d\neq n\) (e.g., projection up or down), is there any constraint on choosing \(d\) for \(\mathbf{R}\)? Do we ever need a right-multiplicative \(\mathbf{W}^0\mathbf{R}\) to affect the output channel interactions, and if so, how would BOFT be adapted while keeping orthogonality?
Answer:
Short answer: BOFT as written always multiplies the pretrained weight matrix on the left by a $d$-by-$d$ orthogonal matrix $R$ because it is intended to rotate the input/neuron (row) space; nothing in the paper requires $n = d$. If you want to also mix the output (column) channels, you must introduce a separate $n$-by-$n$ orthogonal factor on the right. BOFT extends straightforwardly: parameterize any square orthogonal factor (left or right) with a butterfly factorization (or a block-butterfly when sizes are not powers of two) and enforce orthogonality per the paper (e.g., Cayley / $2\times2$ rotations). This preserves the orthogonality guarantees and the spectral properties the paper emphasizes.

Explanation and details

What the paper assumes and why left-multiplication is used
The paper defines the pretrained linear layer as $W^0 \in \mathbb{R}^{d\times n}$ and replaces the forward pass $z = (W^0)^T x$ by $z = (R W^0)^T x$ with $R \in \mathbb{R}^{d\times d}$ orthogonal. Here $R$ acts on the input / neuron (row) space: it rotates the $d$-dimensional input features / neuron coordinates and therefore preserves pairwise angles between the neurons (columns of $W^0$) as intended by Orthogonal Finetuning (OFT). All of that is valid whether or not $n = d$; $R$ must match the input dimension $d$ because it multiplies on the left.

If $d \neq n$, does $R$ have to change?
No. $R$ must be a square orthogonal matrix with size equal to the input dimension ($d\times d$). There is no constraint forcing $d$ to equal $n$. BOFT parameterizes $R$ efficiently (butterfly / block-butterfly) for whatever $d$ is. The paper already treats the general case $W^0 \in \mathbb{R}^{d\times n}$ and repeatedly writes $R \in \mathbb{R}^{d\times d}$ left-multiplying $W^0$.

When do you need right-multiplication?
Left-multiplication only changes how inputs / neuron coordinates are mixed. If you want to change how output channels (the columns of $W^0$, i.e., the $n$-dimensional output space) interact with each other — for example to rotate/scramble the output basis or to preserve/encourage angle relationships among output channels — then you must also introduce a right-multiplicative orthogonal factor $S \in \mathbb{R}^{n\times n}$ and use $R W^0 S^T$ (or equivalently $(S (W^{0})^T R^T)^T$). Right-multiplication affects column interactions; left-multiplication affects row/input interactions. The two are independent and both can be orthogonal (square) transforms.

How to adapt BOFT while keeping orthogonality
Apply the same BOFT construction independently to each square factor you need:

- For an input-side transform use BOFT to parameterize $R \in \mathbb{R}^{d\times d}$ as in the paper: $R = \prod_{i} \tilde{B}_{(d,i)}^{b}$ with each butterfly component constrained to be orthogonal (Cayley or $2\times2$ rotations). This keeps the identity initialization and spectral-preserving properties the paper emphasizes.

- For an output-side transform use a separate BOFT (or simpler block-diagonal OFT if you prefer) to parameterize an orthogonal $S \in \mathbb{R}^{n\times n}$. The forward pass becomes $z = (R W^0 S^T)^T x = S (W^{0})^T R^T x$ (same effect). Each square factor is orthogonal by construction, so the final product is valid and preserves singular-value-related properties (orthogonal left and right multipliers only change the left/right singular vectors, not the singular values).

Practical notes consistent with the paper
The paper’s BOFT assumes power-of-two-friendly structure in the standard radix-2 butterfly, but it already describes block-butterfly components and BOFT$(m,b)$ so you can handle arbitrary $d$ and $n$ by choosing block size $b$ (tile into $b\times b$ blocks) or by padding and then masking. Each butterfly component is enforced orthogonal using Cayley/$2\times2$ rotations, so you preserve the orthogonality constraints even when you have two different square sizes. Identity initialization and multiplicative dropout ideas transfer straightforwardly to a right-side BOFT as well.

Spectral / stability consequences
Multiplying $W^0$ on the left by an orthogonal $R$ preserves the singular values; multiplying on the right by orthogonal $S$ also preserves singular values (since $W^0 S^T$ has the same singular values). Thus using $R W^0 S^T$ keeps the spectral norm of $W^0$ intact, keeping the stability benefits the paper highlights.

Summary
BOFT in the paper is defined for $R \in \mathbb{R}^{d\times d}$ even when $W^0$ is rectangular; no constraint forces $d = n$. If you need to manipulate output-channel interactions, introduce a separate $n\times n$ orthogonal factor on the right; BOFT’s butterfly parameterization and orthogonality enforcement apply to either square factor independently (using block-butterfly or padding when sizes aren’t powers of two), preserving the paper’s orthogonality and spectral properties.
