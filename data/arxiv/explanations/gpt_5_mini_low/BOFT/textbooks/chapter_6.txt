\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 6: BOFT: Orthogonal Butterfly Parameter-Efficient Finetuning

# BOFT parameterization: R(m, b) as a product of orthogonal butterfly components

Orthogonal Butterfly Finetuning (BOFT) parameterizes the orthogonal update applied to a pretrained weight matrix as a product of structured, sparse orthogonal factors called butterfly components. Concretely, for a linear layer whose frozen pretrained weight matrix is \(\mathbf{W}^0\in\mathbb{R}^{d\times n}\), BOFT replaces the usual forward computation \(\mathbf{z}=(\mathbf{W}^0)^\top\mathbf{x}\) with
\[
\mathbf{z} = \big(\mathbf{R}(m,b)\,\mathbf{W}^0\big)^\top \mathbf{x},
\]
where the learned matrix \(\mathbf{R}(m,b)\in\mathbb{R}^{d\times d}\) is constrained to be orthogonal and is factorized as a product of \(m\) block-butterfly components:
\[
\mathbf{R}(m,b) = \prod_{i=1}^m \tilde{\mathbf{B}}^b_{(d,i)}.
\]

Each component \(\tilde{\mathbf{B}}^b_{(d,i)}\) is a block-diagonal matrix formed by repeating a small structured block (a butterfly factor) along the diagonal. The block size is \(b\) (or equivalently, blocks of size \(2b\times 2b\) when describing the smallest orthogonal parameterized unit), and the number of components \(m\) controls how many sequential sparse information-exchange steps are composed. Intuitively, each component implements a sparse orthogonal mixing across subspaces of the \(d\)-dimensional space; composing \(m\) such sparse mixes enables global information flow between every input and every output coordinate while keeping the number of trainable parameters far below \(O(d^2)\).

The butterfly product is designed so that the sparsity patterns in the successive components interleave and permute connections across coordinates; this is the same kind of connectivity exploited by the classical Cooley–Tukey fast Fourier transform. When chosen appropriately, the sequence of components can produce a dense orthogonal matrix even though each individual component is sparse. The BOFT parameterization therefore trades parameter count for additional repeated structured multiplications during training.

# Ensuring orthogonality: 2x2 (or 2b x 2b) Cayley-parameterized blocks and permutations

Maintaining orthogonality of \(\mathbf{R}(m,b)\) is central to BOFT, since orthogonality preserves geometric relations (pairwise angles) among neurons and yields favorable spectral properties. The BOFT construction ensures orthogonality by enforcing that every factor \(\tilde{\mathbf{B}}^b_{(d,i)}\) is itself orthogonal. Because each component is block-diagonal (with many identical small blocks), orthogonality can be enforced blockwise.

At the smallest granular level, each repeating block is based on a \(2\times 2\) orthogonal building block (or a \(2b\times 2b\) block when operating with block-butterfly components). A convenient and numerically stable way to parameterize such small orthogonal blocks is via the Cayley transform. For a skew-symmetric matrix \(\mathbf{Q}\) (so \(\mathbf{Q}^\top = -\mathbf{Q}\)), the Cayley map
\[
\mathbf{R} = (\mathbf{I}+\mathbf{Q})(\mathbf{I}-\mathbf{Q})^{-1}
\]
produces an orthogonal matrix \(\mathbf{R}\) (where defined), and initializing \(\mathbf{Q}=\mathbf{0}\) yields \(\mathbf{R}=\mathbf{I}\). In BOFT, each small \(2\times 2\) (or \(2b\times 2b\)) block is parameterized by a small skew-symmetric \(\mathbf{Q}\) and converted to an orthogonal block by Cayley. Because the full component is a block-diagonal composition of these blocks (possibly after a fixed permutation of coordinates), the whole component is orthogonal if every block is.

Permutations appear naturally in the butterfly construction: the non-zero pattern of a higher-level butterfly component is a permuted arrangement of the \(2\times 2\) block pattern. Thus, to produce \(\tilde{\mathbf{B}}^b_{(d,i)}\) one can parameterize a canonical block-diagonal orthogonal matrix (via Cayley on the small blocks) and then apply a fixed permutation of rows and columns to realize the butterfly connectivity at that level. Since permutation matrices are orthogonal, permuting an orthogonal block-diagonal matrix preserves orthogonality. This design makes it straightforward to guarantee orthogonality at every component while retaining the desired sparse, interleaving connectivity.

# Special cases: BOFT(1, b) = block-diagonal OFT; BOFT(1, d) = full OFT; BOFT(log(2d/b), b) = dense orthogonal

BOFT is a generalization of previously studied orthogonal finetuning variants and subsumes those as special cases through particular choices of \(m\) and \(b\).

If we set \(m=1\), there is a single component \(\tilde{\mathbf{B}}^b_{(d,1)}\). Because this component is block-diagonal with block size \(b\), BOFT(1, b) is exactly the block-diagonal Orthogonal Finetuning used in prior OFT work. In that regime the orthogonal matrix is restricted to independent orthogonal transforms applied to contiguous groups of coordinates; this reduces parameter count but cannot generate a dense orthogonal transform across coordinates.

If we further set \(m=1\) and choose \(b=d\) (so there is only one block that spans all dimensions), BOFT(1, d) becomes an unconstrained full orthogonal matrix. This recovers the original unconstrained OFT where a full \(d\times d\) orthogonal \(\mathbf{R}\) is learned (typically via Cayley parameterization on a full skew-symmetric matrix), requiring \(O(d^2)\) parameters.

At the other extreme, choosing \(m=\log (2d/b)\) and keeping \(b\) small (in the limit the classic radix-2 butterfly has \(b=2\)) yields a block-butterfly construction that achieves dense connectivity: successive sparse components interleave so that every source coordinate can influence every output coordinate in the composed matrix. In particular, the canonical butterfly case of \(m=\log d\) and \(b=2\) yields a construction whose product is capable of representing many dense linear transforms (and, in more general compositions, can approximate the whole orthogonal group). Thus BOFT(log(2d/b), b) is the regime in which the factorized sparse components collectively produce a dense orthogonal \(\mathbf{R}\) while using far fewer parameters than a single dense factor.

# Parameter counts: O((b-1) d m / 2); O(d log d) when m = log d, b = 2

A primary motivation for BOFT is parameter efficiency. Counting effective trainable parameters (i.e., degrees of freedom in the orthogonal factors), BOFT analysis in the paper shows that BOFT(m,b) requires
\[
\frac{1}{2}(b-1)\,d\,m
\]
effective trainable parameters for finetuning a linear layer of size \(d\times n\). The factor \(\tfrac{1}{2}(b-1)\) arises because each \(2b\times 2b\) orthogonal block has \(\frac{1}{2}(2b)(2b-1)\) skew-symmetric degrees, but when counted per dimension and normalized per component this simplifies to the stated expression for the effective free parameters contributed per component across all \(d\) rows.

Two particularly informative regimes follow directly from this formula. If \(m=\log d\) and \(b=2\) (the classical butterfly), then BOFT uses \(\mathcal{O}(d\log d)\) parameters, since
\[
\frac{1}{2}(2-1)\,d\,\log d = \frac{1}{2}d\log d = \mathcal{O}(d\log d).
\]
This is a dramatic reduction from the \(\mathcal{O}(d^2)\) parameters required by a full orthogonal matrix. In the block-diagonal OFT case (which is BOFT(1,b)), the parameter count reduces to \(\mathcal{O}(bd)\), which is recovered from the general formula by setting \(m=1\). Thus BOFT smoothly interpolates between the block-diagonal regime and the full orthogonal regime, while allowing constructions (small \(b\), larger \(m\)) that achieve dense transforms at parameter costs that grow near-linearly (up to logarithmic factors) in \(d\).

This parameter-count tradeoff is the core practical advantage: by composing a sequence of sparse, structured orthogonal factors, BOFT attains dense global transformations while dramatically limiting the number of trainable parameters, enabling orthogonal finetuning on very large models with modest finetuning budgets.

# Identity initialization for stability and compatibility with pretrained weights

When finetuning a pretrained foundation model, it is important that the finetuning update does not immediately alter the pretrained functionality in uncontrolled ways. BOFT addresses this by initializing every orthogonal butterfly component to the identity. Practically, this is achieved by initializing each small skew-symmetric Cayley parameter \(\mathbf{Q}\) to the zero matrix, which maps to the identity via the Cayley transform. With this initialization, \(\mathbf{R}(m,b)\) starts as the identity matrix, so the initial forward pass is exactly the pretrained model's computation.

Identity initialization yields two useful properties. First, it realizes a zero-effect start: early optimization steps make small, controlled deviations from the pretrained weights rather than abrupt changes, which helps preserve pretraining knowledge and stabilizes learning. Second, identity initialization enables direct comparison with other zero-initialized PEFT methods (for example LoRA initializes additive low-rank updates to zero), and it guarantees that any regularization or dropout designed for zero-initialized reparameterizations can be applied analogously. Because Cayley parameterization naturally supports zero initialization, it is well suited for BOFT's multiplicative, orthogonality-preserving setup.

# Multiplicative Dropout: blockwise identity replacement to regularize multiplicative updates

Standard Dropout, which stochastically zeros additive components, is not directly compatible with BOFT's multiplicative orthogonal update: simply zeroing entries inside an orthogonal factor breaks orthogonality and the structure of the update. To regularize BOFT's multiplicative composition, the paper introduces a multiplicative Dropout that respects the orthogonal factorization.

The multiplicative Dropout operates at the granularity of whole butterfly components and at block granularity within each component. At each training iteration it randomly selects a fraction \(p_1\) of the butterfly components to disable; for each selected component it also randomly selects a fraction \(p_2\) of its diagonal blocks to disable. Disabling a component or a block means replacing that component (or block) with an identity matrix for this forward/backward pass. Because identity matrices are orthogonal, this replacement preserves the orthogonality of the overall product. Conceptually, this procedure randomly removes some of the sparse mixing steps during training, which discourages over-reliance on any single component or sub-block and encourages the optimizer to build more robust, distributed updates across components.

Multiplicative Dropout thus provides a principled way to regularize the multiplicative orthogonal update without violating orthogonality constraints, and it aligns with the intuitive goal of preventing overfitting that ordinary Dropout provides in additive-update PEFT methods.

# Algorithmic steps for forward/backward passes and integration with existing layers

Integrating BOFT into an existing model is straightforward because BOFT applies a left-multiplicative orthogonal update to pre-existing linear layers. At high level, the forward pass for a finetuned linear layer proceeds as follows:

1. Assemble the current orthogonal components \(\{\tilde{\mathbf{B}}^b_{(d,i)}\}_{i=1}^m\). Each component is constructed by applying the Cayley transform to its small skew-symmetric blocks and placing them on the block-diagonal, then applying the fixed permutation that realizes the butterfly connectivity for that level.

2. (Optional multiplicative Dropout) Randomly select a subset of components and blocks as described; for selected components/blocks, replace the corresponding block(s) with identity blocks for this pass.

3. Compute the composed orthogonal matrix (or apply the composition implicitly): \(\mathbf{R}(m,b) = \tilde{\mathbf{B}}^b_{(d,m)}\cdots \tilde{\mathbf{B}}^b_{(d,1)}\). In practice, one should avoid materializing the full \(d\times d\) matrix when \(d\) is large, and instead apply successive sparse block operations to \(\mathbf{W}^0\) or to the activations.

4. Form the finetuned weight matrix \(\widehat{\mathbf{W}} = \mathbf{R}(m,b)\,\mathbf{W}^0\) and compute the layer output \(\mathbf{z} = \widehat{\mathbf{W}}^\top \mathbf{x}\).

For backward propagation, gradients flow through the product of orthogonal factors into the underlying small skew-symmetric Cayley parameters. Because every factor is orthogonal, gradient norms and conditioning on the weight side are better behaved than unconstrained multiplicative factorizations, and the Cayley parameterization provides straightforward differentiable formulas to map gradients on the orthogonal blocks to gradients on the skew-symmetric parameters. In implementation, one typically backpropagates through the sequence of sparse block multiplications; automatic differentiation frameworks handle the chain of operations and produce gradients for the small block parameters. If memory is a concern, the multiplication sequence can be re-computed in reverse during the backward pass (trading compute for memory), or efficient blockwise routines can be used to keep the per-step cost low.

Because BOFT composes with the existing frozen \(\mathbf{W}^0\) via a single left multiplication, it integrates cleanly into models without changing downstream interfaces. At inference time, a learned BOFT orthogonal \(\mathbf{R}\) can be multiplied into \(\mathbf{W}^0\) to produce a single static finetuned weight matrix, so there is no inference-time overhead: the multiplicative sequence is only used during training (unless one chooses to keep the factorized representation). This property preserves the inference efficiency of the base model while enabling parameter-efficient finetuning.

Together, these algorithmic steps and integration details make BOFT a practical, orthogonality-preserving, and parameter-efficient finetuning strategy that generalizes and subsumes OFT variants, while enabling dense orthogonal updates with dramatically fewer parameters when using butterfly factorization.
