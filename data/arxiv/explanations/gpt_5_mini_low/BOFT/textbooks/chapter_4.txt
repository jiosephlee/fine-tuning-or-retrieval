\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: An Information Transmission View of Matrix Factorization

# Dense matrix entries as end-to-end connectivity

A dense square matrix can be interpreted as specifying, for each output coordinate, which input coordinates can influence it and by how much. Concretely, consider a matrix $\mathbf{R}\in\mathbb{R}^{d\times d}$. The element $R_{ij}$ is nonzero precisely when information from the $j$‑th input node can reach the $i$‑th output node through the linear map induced by $\mathbf{R}$. Viewing a matrix this way turns a purely algebraic object into a connectivity pattern: nonzero entries are edges in a directed bipartite graph from $d$ source nodes (inputs) to $d$ sink nodes (outputs). The numerical values of the nonzero entries determine weights on those edges, while the sparsity pattern indicates which direct input→output transmissions are possible.

This interpretation emphasizes an end-to-end perspective: what matters for many downstream uses (including finetuning pretrained layers) is whether each input coordinate can ultimately influence each output coordinate, not necessarily the particular intermediate structure that realizes that connectivity. A single dense matrix provides direct connectivity for all $d^2$ possible input→output pairs. When we speak of generating a dense $\mathbf{R}$ via some factorization, we therefore mean producing a composition of intermediate maps whose overall connectivity graph from inputs to outputs has no missing edges. Framing dense matrix entries in this way makes it natural to reason about sparsity, expressivity, and parameter cost in terms of communications (paths) on a graph instead of raw matrix entries.

# Unrolling products of sparse matrices into layered graphs

When a dense matrix $\mathbf{R}$ is represented as a product of $m$ square matrices,
\[
\mathbf{R} = \mathbf{B}_m \mathbf{B}_{m-1} \cdots \mathbf{B}_1,
\]
each factor $\mathbf{B}_i\in\mathbb{R}^{d\times d}$ can be viewed as connectivity between two adjacent layers of $d$ nodes. Unrolling the product into a layered graph produces $m+1$ layers of $d$ nodes each: layer~0 (the original inputs), layer~1 after $\mathbf{B}_1$, layer~2 after $\mathbf{B}_2$, and so on, up to layer $m$ (the final outputs). An entry $(\mathbf{B}_i)_{uv}$ indicates whether node $v$ in layer $i-1$ connects to node $u$ in layer $i$ (and with what weight).

Under this unrolled graphical view, an end-to-end entry $R_{ij}$ is nonzero precisely when there exists at least one directed path from input node $j$ in layer~0 to output node $i$ in layer~m that traverses edges present in the successive factors $\mathbf{B}_1,\ldots,\mathbf{B}_m$. Thus the composition of sparse adjacency patterns across layers can create dense overall connectivity even though each factor is sparse. This is the key mechanism by which factorization trades off between the number of trainable parameters (edges) and computation: repeated, structured exchanges across the layers can route every input to every output using far fewer total edges than a single dense bipartite graph would require.

A simple illustrative example: take $d=4$ and $m=5$ factors. Each factor corresponds to a bipartite connection between adjacent levels of 4 nodes. If, after composing the five sparse connectivity patterns, every node in layer~0 reaches every node in layer~5, then the product $\mathbf{B}_5\cdots\mathbf{B}_1$ is dense. Crucially, the edges that are present in individual $\mathbf{B}_i$ need not form dense matrices themselves; they only need to enable routing of information across the whole depth. The unrolled layered graph makes it straightforward to check which end‑to‑end entries are reachable and where the sparsity in intermediate factors produces zeros in the composed matrix.

# Desiderata: dense end-to-end connectivity with minimal trainable edges

From the information transmission perspective there are two competing desiderata when we seek parameter‑efficient factorizations of dense matrices. First, we require dense end-to-end connectivity: for the composed matrix to be dense, every source node in layer~0 must have at least one path to every sink node in layer~m. Without this property the composed matrix will have zero entries and will not be fully expressive as a dense transform. Second, we want to minimize the number of free (trainable) edges across the entire layered graph. The fewer the trainable edges, the fewer parameters must be optimized during finetuning; this is the "space" we trade for extra computation.

These desiderata must be balanced. A naive approach that connects every pair of nodes densely in each factor would satisfy the first desideratum trivially but violates the second by using $\mathcal{O}(d^2 m)$ edges. A better approach uses sparse $\mathbf{B}_i$, arranged so that the concatenation of sparse patterns still gives dense paths from every input to every output. Butterfly‑style factorizations (inspired by FFT networks) are canonical examples: they achieve full end‑to‑end connectivity with only $\mathcal{O}(d\log d)$ edges (for $m=\mathcal{O}(\log d)$), substantially reducing the number of trainable parameters compared to a single dense matrix with $\mathcal{O}(d^2)$ entries.

When assessing candidate factorizations in this framework, counting edges in the layered graph gives an intuitive proxy for parameter cost. However, because some entries of orthogonal factors are constrained (see below), the effective count of free parameters is slightly different from the raw edge count; we must account for structural constraints that remove degrees of freedom.

# Orthogonality constraints as structured edge dependencies and bijections

Orthogonality imposes additional, nonlocal structure on the entries of each factor. Two principal consequences matter for the layered graph model.

First, each orthogonal factor must be full rank and invertible, which implies that between any two adjacent layers the factor must implement a bijection between the $d$ nodes (as a linear map). At minimum, therefore, there must exist $d$ independent connections that map the $d$ inputs at layer $i-1$ to the $d$ outputs at layer $i$. In graph terms this means there are at least $d$ disjoint edges (counting multiplicity with weights) needed so the factor achieves full column rank. In practice, for structured sparse orthogonal blocks (for example, made from $2\times 2$ rotations), each factor will have exactly $d$ rows and $d$ columns active in specific patterned ways that enforce invertibility. The paper highlights that these necessary $d$ edges are not free trainable degrees in the same way as arbitrary real entries: in many sparse orthogonal patterns the allowed nonzero entries take constrained forms (for example, $\pm 1$ in permutation-like blocks, or belong to low-dimensional parameterizations like Cayley transforms for $2\times 2$ rotations). Thus the count of trainable edges excludes these structural, non‑parametric connections.

Second, orthogonality induces dependencies among entries: a zero in a particular location often forces zeros or specific values elsewhere to maintain orthogonality. A simple example is a $2\times 2$ orthogonal matrix. If one entry is zero in a $2\times 2$ orthogonal matrix, orthogonality dictates another entry must be zero or fixed, eliminating certain independent parameters. In the layered graph, this means that removing one edge from a factor can create constraints on other edges; modeling factors purely as independent binary edges misses this coupling. Overall, orthogonality reduces the effective degrees of freedom relative to naive counts of nonzero locations, and the specific sparse patterns used (e.g., block rotations, butterfly structures built from $2\times 2$ orthogonal blocks) encode which degrees of freedom remain trainable.

Because of these points, in designing parametric factorizations for orthogonal finetuning we should separate (a) the minimal connectivity needed for invertibility (the bijection-style edges that are structural) from (b) the remaining degrees of freedom that are actually learned. Good factorizations aim to minimize the number of learned degrees while respecting the structural orthogonality constraints that maintain invertibility and desirable spectral properties.

# Why naive dense matrices cost O(d^2) and how factorization trades time for space

A direct parameterization of a dense $d\times d$ orthogonal matrix (or any dense matrix) uses $\mathcal{O}(d^2)$ independent scalar parameters (for orthogonal matrices, the dimension of the orthogonal group is $\frac{d(d-1)}{2}$). This quadratic parameter cost becomes prohibitive for large $d$ when one wishes to finetune many layers in a foundation model. The core idea of matrix factorization is to represent the same end‑to‑end mapping as a composition of several simpler, structured maps so that the total number of free parameters across factors is much smaller than $\mathcal{O}(d^2)$. The tradeoff is computation: evaluating and backpropagating through $\mathbf{R}=\mathbf{B}_m\cdots\mathbf{B}_1$ requires $m$ sparse matrix multiplications (and in training these are performed repeatedly), so we exchange extra per‑step computation for a much smaller parameter footprint.

From the unrolled graph view, rather than building a dense bipartite graph with $d^2$ edges, we build a layered sparse network where each edge participates in many end‑to‑end paths. Carefully designed topologies can realize all $d^2$ input→output connectivities using only $\mathcal{O}(d\log d)$ or $\mathcal{O}(d m)$ edges. The butterfly architecture from the Cooley‑Tukey FFT is a canonical example: with $m=\mathcal{O}(\log d)$ stages and $\mathcal{O}(d)$ connections per stage, the entire layered network uses only $\mathcal{O}(d\log d)$ connections yet achieves dense end‑to‑end routing. Because each stage's nonzero pattern can be parameterized with a small number of learnable parameters per active block (for instance, using $2\times 2$ orthogonal rotations with just one scalar angle per block), the total number of trainable parameters is likewise $\mathcal{O}(d\log d)$.

This is the practical meaning of trading time for space: we pay a multiplicative increase in per‑update computation (multiply through $m$ factors each forward and backward pass) to dramatically reduce the number of trainable scalars stored and optimized. For finetuning large pretrained models, where storing and communicating parameter updates is expensive while additional computation during training is often tolerable, this tradeoff is very attractive. The paper demonstrates that, by designing sparse orthogonal factors (e.g., blockwise $2\times 2$ rotations arranged in butterfly stages), one can retain desirable spectral properties (orthogonality preserves singular values) and expressivity sufficient for downstream tasks, but with parameter complexity reduced from $\mathcal{O}(d^2)$ to $\mathcal{O}(d\log d)$ or, more generally, $\mathcal{O}(dm)$ for $m$ stages.

In summary, the information transmission view reframes dense matrix factorization as a routing problem on layered graphs. This perspective clarifies the goals (dense end‑to‑end connectivity) and constraints (orthogonality forces bijections and structured dependencies) when designing sparse factor patterns, and it explains how factorization enables a controlled time‑for‑space tradeoff: more stages and repeated sparse exchanges produce dense effective transforms using far fewer trainable parameters than a naive dense representation.
