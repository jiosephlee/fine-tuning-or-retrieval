\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 5: Butterfly Structures: From FFT to Efficient Information Mixing

# Cooley–Tukey FFT recursion and the butterfly pattern

The Cooley–Tukey fast Fourier transform (FFT) provides a classic example of how a global dense linear transform can be computed efficiently by composing a sequence of sparse, structured operations. At its heart is a divide-and-conquer recursion: an $N$-point discrete Fourier transform is reduced to smaller transforms on halves of the data, with a small interleaving/scrambling step between them. When this recursion is unrolled, the pattern of nonzero interactions between input indices and intermediate indices forms the characteristic “butterfly” pattern.

Viewed abstractly, the FFT recursion shows how to exchange information between all input positions and all output positions without ever forming an $N\times N$ dense matrix explicitly. Instead one performs $O(N\log N)$ scalar operations arranged into $O(\log N)$ stages; each stage only mixes nearby pairs of values. Each local mixing is a small structured operation (in radix‑2, a 2×2 operator), and the sequence of these local mixings routes information so that, after the last stage, every output has received contributions from every input. This is the key property: dense connectivity between source and target coordinates emerges from a small number of sparse stages.

In the language used in the paper, the FFT demonstrates an information transmission solution on a $d\times (m+1)$ grid (take $d=N$ and $m=\log_2 N$): a chain of sparse factor matrices whose product yields a dense transform. The Cooley–Tukey recursion therefore motivates searching for sparse factorization topologies that achieve dense end-to-end connectivity while using far fewer free parameters than a single dense matrix.

# Butterfly graphs as efficient broadcast/multicast networks

The unrolled stages of an FFT define a layered graph: nodes are positions at each stage, and edges connect positions that interact in a single sparse factor. That layered graph is precisely what the paper calls an information transmission graph. The butterfly graph is a particular layered topology that achieves the desiderata of dense end-to-end connectivity with very few inter-stage edges. Concretely, for radix‑2 and $d=2^N$ inputs, the butterfly network has $N=\log_2 d$ stages and each stage connects each node to only a constant number of nodes in the next stage (for radix‑2, typically two). Over all stages the total number of inter-stage edges is $O(d\log d)$, yet from any source node there exists a path to every sink node. Thus the butterfly graph achieves full broadcast/multicast capability across the $d$ inputs with only $O(d\log d)$ links.

From the perspective of parameter-efficiency in parameterizing linear maps, this graph implies that a dense $d\times d$ mapping can be implemented as a product of $m=O(\log d)$ sparse matrices, each with $O(d)$ nonzero blocks. If those stage matrices are restricted to be orthogonal, then the network realizes a dense orthogonal transform using only $O(d\log d)$ degrees of freedom rather than $O(d^2)$. The paper emphasizes this as a way to meet two transmission desiderata: (i) dense connectivity (every source can reach every sink), and (ii) minimum free edges (use as few trainable locations as possible subject to orthogonality constraints). The butterfly topology is a natural network that satisfies both.

# Butterfly matrices: factors, components, and recursive construction

A butterfly factor in the paper is the elemental block that mixes two neighboring groups of coordinates. For a block size $k$ that is a power of two, a single butterfly factor $\mathbf{B}^F(k)\in\mathbb{R}^{k\times k}$ is written as a 2×2 block matrix whose blocks are diagonal matrices:
\[
\mathbf{B}^F(k)=\begin{bmatrix}
\operatorname{diag}(\mathbf{d}_1) & \operatorname{diag}(\mathbf{d}_2)\\[4pt]
\operatorname{diag}(\mathbf{d}_3) & \operatorname{diag}(\mathbf{d}_4)
\end{bmatrix},
\]
where each $\mathbf{d}_i\in\mathbb{R}^{k/2}$ parameterizes how corresponding coordinates mix. This representation captures the local pairwise interactions (or blockwise pairwise interactions) used at each stage.

Building up to dimension $d=2^N$, the paper defines butterfly components $\tilde{\mathbf{B}}(d,k)$ as block-diagonal matrices composed of many copies of $\mathbf{B}^F(k)$ arranged to cover all coordinates. The full $d\times d$ butterfly matrix is then the product of these components across multiple scales:
\[
\mathbf{B}(d)=\tilde{\mathbf{B}}(d,d)\,\tilde{\mathbf{B}}(d,d/2)\,\cdots\,\tilde{\mathbf{B}}(d,2).
\]
Each component operates at a different granularity: the component with block size $2$ performs the finest-grained pairwise mixes, while the components with larger $k$ permute and mix larger groups. Importantly, the nonzero pattern of every component is a permutation of that of the smallest component $\tilde{\mathbf{B}}(d,2)$, so one can parameterize orthogonality for each component by ensuring each small $2\times 2$ (or $2b\times 2b$ in the block case) block is orthogonal.

Because each component is block-sparse and the number of components is $m=O(\log d)$ for the full butterfly, the product gives an expressive dense matrix while exposing only $O(d\log d)$ trainable elements when the internal blocks are parameterized compactly (for example by Cayley transforms of skew-symmetric parameters). This yields the efficient orthogonal parameterization exploited in BOFT.

# Block butterfly generalization and relation to fast transforms (DFT, DCT, Hadamard)

The paper generalizes the pure scalar radix‑2 butterfly to block butterflies: each scalar entry of the elemental $\mathbf{B}^F(k)$ is replaced by a $b\times b$ matrix. Formally, a block butterfly component is denoted $\tilde{\mathbf{B}}^b(d,k)$ where each diagonal vector $\mathbf{d}_i$ becomes an array of $b\times b$ matrices. Taking $b>1$ allows the method to trade off granularity and parameter count: larger blocks reduce the depth $m$ required to reach dense connectivity while increasing the per-block parameter budget.

This block generalization also connects the butterfly factorization to many classical fast linear transforms. The paper points out that with appropriate choices and permutations, butterfly compositions can exactly recover transforms such as the discrete Fourier transform (DFT), discrete cosine/sine transforms (DCT/DST), and the Hadamard transform. Those classic transforms are canonical examples where global mixing is implemented by a sequence of sparse, structured stages—the same structure the butterfly encodes. Because the block-butterfly family includes these fast transforms as special cases, it supplies an inductive bias aligned with many useful global transforms: the learned parameterization can express these transforms efficiently and can smoothly approximate a broader class of orthogonal maps by tuning the block entries.

This relation underpins the paper’s argument that butterfly parameterizations are well suited as a structured hypothesis class for orthogonal finetuning: they can represent known global mixing patterns while using far fewer degrees of freedom than an unconstrained dense orthogonal matrix.

# Why butterfly topology fits the transmission desiderata better than blocks

Two practical desiderata for sparse factorization were highlighted in the information transmission view: (i) dense connectivity from all sources to all sinks; and (ii) minimum number of free edges (trainable parameters) consistent with orthogonality. The naive block-diagonal approach in earlier OFT satisfies (ii) in a trivial way—each small block is orthogonal and independent—but it fails on (i): block-diagonal structure prevents cross-block information flow entirely, so the composed mapping cannot be dense across all coordinates. That lack of dense mixing can artificially constrain the finetuned model and impede expressivity.

The butterfly topology remedies this by arranging sparsity across multiple stages so that local pairwise (or blockwise) mixes are repeatedly permuted and recombined. Over $m=O(\log d)$ stages, this routing ensures every input index influences every output index, satisfying dense connectivity. At the same time the total number of trainable elements remains $O(d\log d)$ rather than $O(d^2)$. Moreover, orthogonality can be enforced at the small-block level (for example by using Cayley parameterizations or 2×2 rotations), which both reduces the free parameter count and preserves desirable spectral properties (e.g., spectral norm preservation) of the pretrained weight.

The paper demonstrates this trade-off empirically and theoretically: for the same block size, BOFT (butterfly OFT) is more expressive than block-diagonal OFT, and by choosing $(m,b)$ appropriately one can interpolate between the extremes of identity (maximum regularity) and full orthogonal group (maximum expressivity). Practically this yields a hypothesis class that is large enough to capture useful finetuning transformations but constrained enough to improve generalization and training stability. The butterfly therefore provides an information-efficient topology—high connectivity per parameter—that is well matched to the goals of parameter-efficient orthogonal finetuning.
