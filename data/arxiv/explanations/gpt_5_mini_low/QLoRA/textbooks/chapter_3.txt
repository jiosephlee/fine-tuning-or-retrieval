\title{A Textbook about the Paper: "QLoRA: Efficient Finetuning of Quantized LLMs"}

Chapter 3: NormalFloat (NF4): An Information-Optimal 4-bit Data Type

# Quantile quantization and information-theoretic optimality
Quantile quantization is a principled approach to designing low-bit data types whose bins are matched to the distribution of the data being quantized. The core idea is to choose quantization bin boundaries so that each discretized bin receives an equal expected number of values from the target distribution. When this is achieved, the quantizer makes the best possible use of the limited number of representable symbols: it minimizes the expected distortion for that distribution under the constraint of a fixed alphabet size. In other words, for a known distribution of values, the quantile-quantized data type is information-theoretically optimal because it allocates representational capacity proportionally to how frequently values occur.

Practically, quantile quantization is implemented by taking the quantiles of the target distribution and mapping each interval between adjacent quantiles to a distinct discrete value. For a k-bit datatype, one would obtain $2^k$ bins; the quantile boundaries are positioned so that each bin covers an equal probability mass under the assumed distribution. This approach contrasts with uniform or fixed-step quantizers (like straight integer rounding) that do not account for the shape of the distribution and therefore waste representational resolution on rarely occurring ranges.

# Limitations of approximate quantiles and outlier errors
While quantile quantization is attractive in principle, it depends on accurate knowledge of the distributional quantiles of the data being quantized. Estimating quantiles exactly for large tensors can be computationally costly, so prior methods use approximate quantile estimators (for example, SRAM quantiles or other streaming approximations). These approximations can introduce errors, and those errors typically have two problematic effects.

First, approximate quantiles may misplace bin boundaries, which increases expected quantization error compared to the ideal quantile design. Second, approximations are particularly brittle in the presence of outliers: a single large-magnitude outlier can skew the estimated absolute range or distort an approximate quantile estimate, causing many typical values to be mapped to inappropriate bins. In practice this leads to underutilization of some quantization bins and poor preservation of important mid-range or small-magnitude values. For k-bit quantization where k is small (for example, k=4), these errors matter a lot because there are very few bins to distribute across the whole value range.

These practical limitations motivate designs that either avoid expensive quantile estimation or exploit circumstances where quantiles can be determined more reliably.

# Assumption: zero-mean approximately normal weight distributions
A crucial empirical observation used by NormalFloat is that pretrained neural network weights, when considered per-weight-tensor, tend to be approximately zero-centered and follow a distribution close to a normal distribution with some standard deviation $\sigma$. The QLoRA paper reports this observation and points to an appendix for additional details. Because the family of weights across many pretrained models is consistently near-normal (up to a scaling constant), we can exploit this structure to get exact quantiles efficiently.

The important consequence is that if the input to the quantizer is a zero-mean normal distribution with some standard deviation, then the quantile function is known analytically (or can be computed once numerically) for the standard normal $N(0,1)$. By rescaling the actual weight tensor so that its standard deviation matches the reference distribution used to design the quantizer, we can apply a quantile-based data type with exact (precomputed) bin values. This avoids the need for expensive per-tensor quantile estimation and reduces errors introduced by approximate quantile algorithms. In short, the near-normality and zero-centeredness of pretrained weights allow us to design a canonical quantization alphabet tuned to $N(0,1)$ and then apply it to any weight tensor after a simple scale normalization.

# Constructing NFk: exact quantiles of $N(0,1)$ and range normalization
The NFk data type is built by computing the exact quantiles of the standard normal distribution and turning those quantiles into the discrete codebook values of a k-bit data type. The process proceeds as follows.

First, considering a standard normal distribution $N(0,1)$, estimate the $2^k+1$ quantiles (or equivalently the quantile function values needed to partition the distribution into $2^k$ equal-probability bins). The representative value for each bin can be chosen as the midpoint between adjacent quantiles. The paper formalizes the representative points $q_i$ as
\[
q_i = \frac{1}{2}\left( Q_X\!\left(\frac{i}{2^k+1}\right) + Q_X\!\left(\frac{i+1}{2^k+1}\right)\right),
\]
where $Q_X(\cdot)$ is the quantile function of the standard normal distribution $N(0,1)$. These $q_i$ values form the codebook of the k-bit NormalFloat data type for the standard normal.

Second, to quantize an arbitrary pretrained weight tensor that is approximately normal but has some standard deviation $\sigma$ and possibly different absolute scale, one rescales the tensor into the fixed range of the data type. In practice the NF design uses a canonical numerical range (for example $[-1,1]$). Rescaling amounts to dividing the weight tensor by an absolute maximum (or equivalently by a per-block scale) so that the normalized tensor values match the assumed range for which the quantiles were computed. In other words, we transform the tensor so that its distribution aligns with the $N(0,1)$ reference; once aligned, the precomputed $q_i$ are the appropriate representational values.

This two-step construction—compute theoretical quantiles once for $N(0,1)$ and then normalize each tensor into that canonical range—yields a quantizer that is both information-theoretically matched to the (assumed) normal shape and computationally efficient because the quantile computation does not need to be repeated or approximated per tensor.

# Ensuring a discrete zero via asymmetric binning
A practical but important property for model weights is the ability to represent exact zeros without quantization error. Exact zeros frequently occur in practice (for example, in padding or masks) and in some tensors zero preservation is critical. Symmetric quantile placements around zero (as would result from naive midpoint binning of $N(0,1)$) may not align one of the discrete representable values exactly at zero. If no discrete code corresponds exactly to zero, then zero-valued inputs will be rounded to a nearby nonzero code, introducing avoidable error.

To address this, NFk introduces an asymmetric construction that guarantees a discrete zero point while maintaining the equal-probability property as closely as possible. The tactic is to build separate quantile allocations for the negative and positive halves, but with slightly different bin counts so that after merging the negative and positive codebooks there is a single code exactly equal to zero and the total number of codes equals $2^k$.

Concretely, one estimates quantiles dividing the negative side into $2^{k-1}$ bins and the positive side into $2^{k-1}+1$ bins (or vice versa), computes the midpoint representatives for each side, unifies the two sets, and then removes the duplicated zero that would appear in both halves. This produces a k-bit codebook that (1) preserves exact zero as one discrete symbol and (2) keeps the expected occupancy of each bin nearly equal under the symmetric normal assumption. The result is a data type that both leverages normality for efficiency and maintains practical properties needed for neural network storage.

# Empirical advantages: zero-shot, perplexity, and accuracy gains over FP4/Int4
The NF4 data type is not only theoretically well-matched to normal-like pretrained weights; the QLoRA paper reports consistent empirical improvements when using NF4 compared to other 4-bit choices such as 4-bit floating point (FP4) and 4-bit integers (Int4). Across a variety of pretrained language models (OPT, LLaMA, BLOOM, Pythia) and model sizes from 125M up to 13B (and evaluated elsewhere in the paper up to 65B in the broader QLoRA experiments), NF4 produces better post-quantization results in terms of perplexity and zero-shot accuracies on downstream tasks.

Specifically, the reported results show that NF4 yields lower perplexity and higher zero-shot task accuracy than FP4 and Int4 quantization. These gains are attributed to the NF4 codebook being information-theoretically optimal for approximately normal weights and to the removal of approximate quantile estimation error (because NF4 uses exact quantiles of $N(0,1)$ and per-block normalization). The paper also shows that combining NF4 with Double Quantization—where quantization scales themselves are stored in a second, lower-precision representation—reduces memory footprint without observable degradation in performance. Thus NF4 achieves a favorable point in the trade-off between storage cost and model fidelity: it keeps quantization to 4 bits per weight while preserving much more of the pre-trained model quality than less informed 4-bit schemes.

Finally, when NF4 is used in the QLoRA finetuning pipeline (quantized storage with dequantize-to-16-bit computation and LoRA adapters trained in full precision), the experiments indicate that NF4 helps 4-bit QLoRA match or recover the performance of 16-bit LoRA and full 16-bit finetuning on a range of benchmarks (for example, MMLU), which underscores NF4's practical utility beyond mere inference-time compression.

In sum, NF4 leverages the empirical normality of pretrained weights, uses the theoretically optimal quantile codebook for the standard normal, preserves exact zero through asymmetric binning, and delivers measurable empirical improvements over other 4-bit data types—enabling high-fidelity 4-bit storage that is suitable for downstream finetuning with QLoRA.
