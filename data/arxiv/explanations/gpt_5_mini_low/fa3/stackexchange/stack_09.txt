\title{Stack Exchange of the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

### Why does incoherent processing with random orthogonal M reduce FP8 quantization error without changing attention?
Question:
Section 3.3 introduces multiplying both Q and K by the same random orthogonal matrix M (constructed via Hadamard and random sign flips), arguing that (QM)(KM)^T = QK^T keeps attention scores unchanged while reducing outliers before FP8 quantization. Can someone provide an intuition or a short argument for why this reduces the peak magnitudes at FP8 quantization time? Also, are there corner cases where M could worsen quantization (e.g., when outliers are structured across features)?
Answer:
Short answer: multiplying $Q$ and $K$ by the same random orthogonal matrix $M$ does not change the attention because $$(QM)(KM)^\top = QK^\top,$$ and it reduces $\mathrm{FP8}$ quantization error because it "mixes" each feature coordinate into many others so that extreme values (outliers) that were concentrated in a few coordinates get spread across coordinates. Spreading reduces the per-coordinate peak magnitudes and the dynamic range seen by the $\mathrm{FP8}$ quantizer, so fewer values saturate or suffer large rounding relative to a single global scale. This is why the paper calls the step “incoherent processing.” Below I give a concise, intuitive argument plus the main caveats.

Why attention is unchanged
Because $M$ is orthogonal, $M M^\top = I$, so the attention pre-softmax scores satisfy
$$(QM)(KM)^\top = Q M M^\top K^\top = Q K^\top.$$
Thus all subsequent softmax and $P = \mathrm{softmax}(S)$ computations are identical in exact arithmetic; the operation is strictly algebraically invariant.

Intuition for reduced $\mathrm{FP8}$ quantization error
$\mathrm{FP8}$ has very limited dynamic range and precision: only a few exponent and mantissa bits. In the common per-tensor or per-block scaling quantization scheme, the quantizer picks a single scale for a block and then maps each coordinate to a small set of representable $\mathrm{FP8}$ values. The dominant cause of large quantization error is a tiny fraction of very large coordinates ("outliers") that force the scale to be large so the rest of the coordinates are represented with much coarser granularity, or cause saturation/overflow.

Applying a random orthogonal transform $M$ mixes coordinates so each output coordinate is a (signed) linear combination of many input coordinates. Consider a single row $q$ (or column, depending on layout) of $Q$. After multiplication by $M$, one output coordinate is roughly
$$(qM)_i = \sum_{k=1}^d q_k M_{k,i}.$$
If $M$ is a Hadamard-times-signs matrix (the practical choice in the paper), each output coordinate is a sum of about $d$ terms with roughly equal magnitude but different signs. By the central limit / concentration intuition these sums tend to be more "typical" (smaller extremes) than the original coordinates that may have heavy tails. In particular, for a vector $q$ with squared norm $\|q\|^2$, an orthogonal mixing redistributes that squared norm across the $d$ coordinates so the expected variance per mixed coordinate is about $\|q\|^2 / d$. So instead of one coordinate carrying most of the energy (an outlier), many coordinates each carry roughly $1/d$ of the energy. That reduces the maximum coordinate magnitude and therefore reduces the required scale and the quantization error when you apply $\mathrm{FP8}$ quantization per block.

A compact quantitative sketch: if a vector has one coordinate of magnitude $A$ and the rest near zero, its infinity norm is $A$. After multiplying by a random orthogonal $M$, the typical coordinate magnitude becomes about $A/\sqrt{d}$ (up to constants), so the block's dynamic range (max / typical) contracts by roughly $\sqrt{d}$, which yields much lower rounding/saturation problems for $\mathrm{FP8}$.

Why Hadamard + random sign works in practice
A full random orthogonal matrix is expensive. The structured choice used in the paper (random diagonal of $\pm 1$ times a Hadamard) approximates a random orthogonal transform while costing $O(d\log d)$ operations and can be fused with other linear operations (e.g., rotary embedding). It still mixes coordinates well and empirically reduces extreme peaks.

Corner cases and failure modes
This technique is not a universal cure; there are plausible corner cases:

1) Structured outliers aligned across features in many dimensions. If outliers are not just a single coordinate but are present across many coordinates of the same sign so that the energy is already spread, orthogonal mixing will not meaningfully reduce the dynamic range and thus gives little benefit.

2) Adversarial / worst-case transforms. Orthogonal mixing is a rotation; for any fixed orthogonal $M$ there exist input patterns that get concentrated after multiplying by $M$ (rotations can move energy between coordinates). If the data distribution were adversarial and correlated with the particular choice of $M$, you could in principle worsen per-coordinate peaks. However, that is unlikely with a random or Hadamard-based $M$; concentration bounds show such bad alignments have very low probability.

3) Block structure mismatch. The paper uses block quantization: mixing is done per block (or applied before blocking). If outliers are structured across the entire head dimension but the mixing is applied within small blocks that omit some correlated coordinates, then mixing might be less effective. You need the mixing to cover the features that hold the outliers (i.e., use a block size large enough to capture the correlation).

Practical takeaways
Because attention depends only on $QK^\top$, you can freely apply the same orthogonal $M$ to $Q$ and $K$ to change how values are distributed across feature coordinates without affecting the result. Random orthogonal mixing typically reduces per-coordinate peaks and dynamic range seen during $\mathrm{FP8}$ quantization, which lowers rounding and saturation errors. The method is cheap in practice using Hadamard+signs, and combining it with block quantization (separate scales per block) further reduces $\mathrm{FP8}$ error. The main caveat is that if outliers are already broadly distributed or adversarially aligned to the chosen $M$ (or block mixing is too small), the benefit shrinks and in pathological cases quantization could get worse — but with random/Hadamard $M$ and reasonable block sizes this is unlikely and matches the empirical improvements shown in the paper.
