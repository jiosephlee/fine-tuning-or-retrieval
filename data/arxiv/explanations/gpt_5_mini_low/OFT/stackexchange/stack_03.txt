\title{Stack Exchange of the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

### How is hyperspherical energy computed for convolutional layers?
Question:
Sections 3 and 6 mainly discuss fully connected layers. For a convolution with weight tensor of shape $(C_{\text{out}}, C_{\text{in}}, k_h, k_w)$, what exactly are the "neurons" whose directions and pairwise angles are preserved? Do you flatten each output filter into a length-$d$ vector with $d=C_{\text{in}}k_hk_w$ and treat those as columns? If OFT uses a block-diagonal $\mathbf R\in\mathbb R^{d\times d}$, how are blocks aligned with channels or spatial positions, and does this preserve HE across filters in a way comparable to the fully-connected case?
Answer:
Short answer: treat each output filter (convolution kernel) as a $d$-dimensional neuron by flattening its $C_{\text{in}}\times k_h\times k_w$ weights into a vector of length $d = C_{\text{in}}\cdot k_h\cdot k_w$, and apply the same orthogonal transform (or a block‑diagonal orthogonal transform) to those vectors. Any full orthogonal matrix $R$ acting on those $d$-vectors preserves all pairwise angles (and therefore hyperspherical energy) exactly; a block‑diagonal orthogonal $R$ is still an orthogonal matrix in the full $d$ space, so it likewise preserves hyperspherical energy (while trading off parameter cost and flexibility).

Explanation and intuition grounded in the paper
The paper’s hyperspherical energy (HE) is defined on a set of neurons in a layer after normalization, e.g. for a fully connected layer $W = [w_1, \dots, w_n]$ with $w_i \in \mathbb{R}^d$ the HE is $\sum_{i\neq j} \|\hat w_i - \hat w_j\|^{-1}$ where $\hat w_i = w_i/\|w_i\|$. The OFT idea is: rather than changing those neuron directions arbitrarily, learn a layer‑shared orthogonal matrix $R$ and replace $W^0$ by $W = R W^0$. For fully connected layers this is stated explicitly in the paper; for conv layers the same principle applies if you view each output channel/filter as a neuron.

Concretely for a conv weight tensor of shape $(C_{\text{out}}, C_{\text{in}}, k_h, k_w)$ you form $n = C_{\text{out}}$ neurons by flattening each output filter into a column vector $w_i \in \mathbb{R}^d$ with $d = C_{\text{in}}\cdot k_h\cdot k_w$. The forward pass still computes $z = W^\top x$ (with $x$ being a flattened input patch), and OFT replaces $W^0$ by $R W^0$ so that every filter is rotated by the same orthogonal $R$. Because orthogonal transformations preserve inner products and norms, they preserve all pairwise cosines/angles and hence HE exactly.

What about block‑diagonal $R$?
The paper uses a block‑diagonal parameterization $R = \operatorname{diag}(R_1, \dots, R_r)$ for efficiency. Two points to note: (1) any block‑diagonal matrix whose diagonal blocks $R_i$ are orthogonal is itself an orthogonal matrix in $\mathbb{R}^{d\times d}$. As an orthogonal operator on the full flattened filter space it still preserves pairwise angles and therefore HE exactly. (2) the choice of how blocks align with channels / spatial positions is a design choice that controls inductive bias and parameter cost. The paper points out two natural interpretations:

- If you set $r = C_{\text{in}}$ (number of input channels), each block covers one input channel’s spatial kernel (block size = $k_h\cdot k_w$). Then $R_i$ rotates the spatial weights inside each input channel independently — analogous to learning depthwise transformations, and parameter‑efficient.
- If you instead set $r$ so that each block groups spatial positions across channels (or use shared blocks across channels), you get different coupling patterns: sharing the same block across channels applies the same orthogonal transform to every channel’s subvector (more coupling across channels), while more/smaller blocks give stronger regularization and less flexibility.

Trade‑offs and practical effect
Using a full $R$ ($r = 1$) gives maximum flexibility (but $O(d^2)$ parameters). Block‑diagonal $R$ reduces parameters (paper gives complexity reductions) and biases the transformation to act independently on subspaces you choose (channels, spatial locations, or other groupings). Importantly, any of these $R$ choices that are orthogonal preserve HE across filters in the same provable way as the fully connected case, because HE depends only on pairwise angles and orthogonal mappings preserve angles globally.

A small caveat: if you were to apply different orthogonal transforms to different filters (i.e., not layer‑shared), or apply non‑orthogonal blocks, then HE would not be globally preserved; the paper’s guarantee comes from using the same orthogonal $R$ (or a single orthogonal block‑diagonal $R$) shared across the neurons in the layer.

Extra note
Rescaling per‑neuron (the re‑scaled OFT variant) does not change HE because HE uses normalized directions; scaling factors alter magnitudes but not the normalized directions used in HE.
