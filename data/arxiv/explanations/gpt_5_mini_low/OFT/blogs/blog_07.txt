# Measuring Control: New Consistency Metrics for Text-to-Image Guidance

Controllability is a core goal for modern text-to-image diffusion models: given an extra signal (edges, segmentation maps, facial landmarks, etc.), we want the model to follow that signal while still producing high-quality images. But how do we measure whether a model actually respects the control input in a rigorous, comparable way?

The paper "Controlling Text-to-Image Diffusion by Orthogonal Finetuning" introduces a practical framework for this: extract the control signal back from the generated images using an off-the-shelf estimator, then compare that recovered control to the original input. This "control consistency" approach turns qualitative judgments into simple, quantitative metrics that enable fair comparisons between finetuning methods. Below I summarize the idea, the specific metrics used in the paper, practical implementation notes, and caveats to keep in mind.

## What is a control consistency metric?

High-level idea:
- Start from an input control signal c (example: a Canny edge map, a segmentation mask, or a set of face landmarks) and a text prompt p.
- Generate an image Î = G(p, c) from the finetuned diffusion model G.
- Run a deterministic estimator E that extracts a control-like output from Î: ĉ = E(Î).
- Compare ĉ to the original c with a task-appropriate similarity score.

This pipeline answers the question: if I give the model a control c, does the generated image contain the control information back when we extract it with the same estimator we would normally use?

Because the same estimator E is applied to all methods under comparison, this becomes a fair, task-relevant measurement of controllability.

## Metrics used in the paper

The paper applies the consistency framework to three control tasks and uses standard metrics tailored to each:

1. Canny edges → Image (C2I, evaluated on COCO)
   - Recover edges from generated image using a Canny detector (estimator E).
   - Metrics:
     - Intersection-over-Union (IoU) between binary edge maps.
     - F1 score computed from precision and recall of detected edge pixels.

   IoU formula: IoU = |ĉ ∩ c| / |ĉ ∪ c|.

   F1 = 2 · (precision · recall) / (precision + recall), with precision = |ĉ ∩ c| / |ĉ| and recall = |ĉ ∩ c| / |c|.

2. Segmentation map → Image (S2I, evaluated on ADE20K)
   - Recover semantic segmentation from the generated image using an off-the-shelf segmenter E.
   - Metrics:
     - Mean IoU (mIoU) across semantic classes.
     - Mean class accuracy (average per-class recall).
     - Overall pixel accuracy.

   Mean IoU (per class k): IoU_k = TP_k / (TP_k + FP_k + FN_k). Then mIoU = (1/K) Σ_k IoU_k.

3. Landmarks → Face image (L2F, evaluated on CelebA-HQ)
   - Recover facial landmarks from Î using a landmark predictor E producing coordinates.
   - Metric:
     - Mean $\ell_2$ distance between predicted landmarks and control landmarks:
       mean L2 = (1/N) Σ_i ||ĉ_i − c_i||_2, averaged across landmark points and images.

These are the exact metrics reported in the paper to support quantitative comparisons between OFT/COFT and baselines (ControlNet, T2I-Adapter, LoRA).

## Why this is a useful formulation

- Task-aligned: Each metric directly evaluates the property the control signal is supposed to impose (edges, semantic regions, geometry).
- Comparable across methods: All methods are assessed by the same estimator E, so differences reflect generation fidelity, not differing human judgments.
- Automatic and scalable: Enables large-scale, repeatable evaluations rather than only small human studies.
- Interpretable: Standard metrics (IoU, F1, mIoU, L2) are well understood, allowing straightforward comparisons.

## Important practical details

To get reliable, fair results you must standardize several aspects of the pipeline:

- Use the same estimator E and its fixed hyperparameters for all methods. Differences in E would bias comparisons.
- Preprocess inputs and generated images consistently: same resolution, same color normalization, and the same thresholding parameters for binary maps (e.g., edge binarization).
- If the estimator is stochastic (e.g., uses random initializations), fix its seed or average over multiple runs.
- Alignment: Ensure that any geometric normalization used when producing c is applied consistently (same cropping, scaling, and coordinate frames).
- Report estimator performance on ground-truth images: this provides an upper bound and context for the recovered-control scores.
- Sample size and randomness: evaluate on a sufficiently large and varied held-out set and report means with variance (or confidence intervals) across random seeds to avoid cherry-picking.

## Limitations and caveats

- Estimator accuracy matters. The control consistency score reflects both how well the generator encoded the control and how well the estimator E recovers it. A weak estimator will underestimate controllability; a biased estimator may favor certain methods. The paper mitigates this by using established estimators and standard datasets, but one should be explicit about the estimator's limitations.
- Ambiguity in coarse controls. For sparse or highly ambiguous controls (e.g., very rough edge maps), multiple plausible images might match the control qualitatively but differ enough to lower pixel-based metrics. In these cases, interpret scores together with visual examples.
- Metric choice should match task intent. Pixel IoU makes sense for segmentation maps; landmark L2 is natural for geometry; edges may require tolerant metrics because thin structures are sensitive to small misalignments.
- Estimator-guided evaluation can be attacked: a model could overfit to patterns that the estimator finds easy to pick up but that do not reflect true, perceptual control. Complement consistency metrics with perceptual quality or human evaluation when possible.

## Recommended evaluation recipe (practical checklist)

1. Pick estimator E appropriate to the control type (Canny detector for edges, pretrained segmenter for semantic maps, robust landmark predictor for faces).
2. Fix E and its hyperparameters for the entire study.
3. Produce a controlled validation set: pairs of (c, p) and corresponding ground-truth images for estimator calibration.
4. Generate Î = G(p, c) for all models and seeds.
5. Run ĉ = E(Î) and compute the chosen metrics: IoU/F1 for edges, mIoU/accuracy for segmentation, mean $\ell_2$ for landmarks.
6. Report:
   - Mean and standard deviation across the validation set and random seeds.
   - Estimator performance on ground truth (upper bound).
   - Representative qualitative examples that illustrate cases where metric and perception align or diverge.
7. Optionally, ablate estimator choices to confirm stability of relative ranking.

## Bottom line

Control consistency metrics—recover the control from generated images and compare it to the input—give a clean, scalable way to quantify controllability in text-to-image models. The "Controlling Text-to-Image Diffusion by Orthogonal Finetuning" paper demonstrates this approach across edge, segmentation, and landmark controls, using IoU/F1, mIoU/accuracy, and mean $\ell_2$ as task-appropriate metrics. When implemented carefully (same estimator, consistent preprocessing, and reporting estimator upper bounds), this methodology yields fair, interpretable comparisons between finetuning approaches and helps move controllable image synthesis from anecdote to measurement.
