# Foundations: From Classical LSTMs to Modern Challenges

The history of deep learning for sequence modeling is defined by a persistent struggle to balance the ability to remember long-term dependencies with the computational efficiency required to train massive models. In the 1990s, the Long Short-Term Memory (LSTM) network emerged as a groundbreaking solution to the vanishing gradient problem that plagued earlier Recurrent Neural Networks (RNNs). By introducing the concepts of the constant error carousel and sophisticated gating mechanisms, LSTMs became the dominant architecture for sequence tasks for nearly two decades, powering early successes in text generation, machine translation, and even controlling complex systems like nuclear fusion reactors. However, despite their longevity and proven utility, classical LSTMs possess inherent structural limitations that prevent them from scaling effectively to the billions of parameters characteristic of modern Large Language Models (LLMs). As the field shifted toward Transformer architectures utilizing parallelizable self-attention, and more recently toward State Space Models, the question arose whether the foundational ideas of the LSTM could be resurrected and enhanced to compete at this new scale. This chapter explores the mechanics of the original LSTM, dissects its three critical failures regarding storage revision, memory capacity, and parallelization, and sets the stage for understanding why these limitations necessitated the development of extended architectures.

# The Vanishing Gradient Problem and the Birth of LSTM

To appreciate the innovation of the LSTM, one must first understand the fundamental failure mode of standard Recurrent Neural Networks known as the vanishing gradient problem. In a traditional RNN, information flows through time steps via a hidden state that is updated at every interval based on the current input and the previous hidden state. During training, errors are propagated backward through time to adjust the network weights. However, in deep sequences, these gradients are multiplied repeatedly by the recurrent weight matrix. If the eigenvalues of this matrix are less than one, the gradients shrink exponentially as they move backward through time steps, eventually becoming too small to induce meaningful updates to the weights associated with earlier inputs. Conversely, if the eigenvalues are greater than one, gradients can explode, causing numerical instability. This phenomenon made it virtually impossible for standard RNNs to learn dependencies spanning long distances in a sequence, as the influence of early tokens would vanish before reaching later parts of the sequence where they were needed for prediction.

The Long Short-Term Memory architecture was explicitly designed to overcome this hurdle by creating a dedicated pathway for error flow that remains constant over time. Introduced in the 1990s, the core insight was to decouple the long-term memory storage from the short-term nonlinear processing. Instead of forcing every piece of information to pass through a nonlinear activation function at every time step—which causes gradients to vanish or explode—the LSTM introduced a linear self-connected loop known as the cell state. This design ensures that gradients can flow backward through time without being subjected to repeated multiplications by weights or nonlinear derivatives that degrade their magnitude. The birth of the LSTM marked a paradigm shift where networks could theoretically maintain information indefinitely, provided that appropriate gating mechanisms controlled what entered and exited this protected memory stream. This architectural change allowed LSTMs to prevail in text generation and sequence-to-sequence tasks until the advent of Transformers in 2017, establishing them as a cornerstone of deep learning history.

# Anatomy of the Original LSTM Cell: Input, Forget, and Output Gates

The operational heart of an LSTM is its memory cell, which regulates information flow through three distinct gates: the input gate, the forget gate, and the output gate. These gates act as filters that determine how much new information is stored, how much old information is retained, and how much of the internal state is exposed to the rest of the network. Mathematically, at any given time step $t$, these gates are computed based on the current input vector $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. Each gate utilizes a sigmoid activation function $\sigma(x) = 1/(1+\exp(-x))$, which outputs values between 0 and 1. A value close to 0 implies that the gate is "closed," blocking information flow, while a value close to 1 implies it is "open," allowing information to pass through freely.

The specific roles of these gates are precise and complementary. The input gate $i_t$ controls how much of new candidate information $z_t$—derived from a tanh activation function $\varphi$—is added tothe cell state. # Core Innovation I: Exponential Gating and Stabilization

The Long Short-Term Memory (LSTM) network has long been a cornerstone of sequence modeling, relying on the concept of the constant error carousel and gating mechanisms to mitigate the vanishing gradient problem. In the traditional formulation, the cell state $c_t$ is updated additively based on inputs $z_t$ and modulated by sigmoid gates. Specifically, the input gate $i_t$ and forget gate $f_t$, both bounded between 0 and 1 via the sigmoid function $\sigma(x) = 1/(1+\exp(-x))$, control how much new information is added and how much old information is retained. While effective for many tasks, this standard gating mechanism suffers from a fundamental limitation: the inability to decisively revise storage decisions. Once information is stored in the cell state with a certain confidence, the multiplicative nature of sigmoid gates makes it mathematically difficult to completely overwrite or significantly alter that stored value if a more relevant piece of information appears later in the sequence. This rigidity becomes particularly apparent in tasks requiring dynamic memory updates, such as nearest neighbor search, where an LSTM struggles to replace a previously stored vector when a more similar one is encountered. To address this, the Extended LSTM (xLSTM) introduces a paradigm shift by replacing standard sigmoid activations with exponential gating, coupled with rigorous normalization and stabilization techniques.

## Motivation for Exponential Activation Functions in Gates

The primary motivation for transitioning from sigmoid to exponential activation functions lies in the need for flexible memory revision. In a standard LSTM, the forget gate $f_t$ acts as a decay factor strictly less than or equal to 1. If the network decides to retain information at time step $t-1$ with a high probability (e.g., $f_t \approx 1$), subsequent inputs can only slowly erode this memory unless a long sequence of low forget gates occurs. This creates a "sticky" memory effect where early decisions dominate later ones, preventing the model from adapting its internal representation when context shifts or when superior data arrives. This limitation is empirically demonstrated in nearest neighbor search tasks, where standard LSTMs exhibit high mean squared error because they fail to discard suboptimal stored vectors in favor of better matches found later in the stream.

Exponential gating resolves this by allowing the gates to take values greater than 1, thereby enabling the network to actively amplify or aggressively overwrite previous states rather than merely decaying them passively. By utilizing an exponential activation function, specifically $\exp(\tilde{i}_t)$ for the input gate and optionally $\exp(\tilde{f}_t)$ for the forget gate, the range of possible gate values expands from $(0, 1)$ to $(0, \infty)$. This unbounded upper limit grants the model the capacity to perform strong corrective updates. If the network encounters a critical piece of information at time $t$, it can generate a large exponential input gate value that overwhelms the accumulated history, effectively revising the storage decision made at previous time steps. This capability transforms the memory cell from a passive integrator into a dynamic repository capable of rapid content adaptation, which is essential for solving complex state-tracking problems and improving performance on tasks involving rare tokens or shifting contexts.

## Mathematical Formulation of Exponential Input and Forget Gates

The integration of exponential gating fundamentally alters the forward pass equations of the LSTM variant known as sLSTM (scalar LSTM). In this architecture, the cell state update equation retains its additive structure but operates with exponentially activated gates. The cell state $c_t$ at time step $t$ is computed as $c_t = f_t c_{t-1} + i_t z_t$, where $z_t$ represents the cell input derived from the current input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. The crucial distinction arises in how $i_t$ and $f_t$ are calculated. Instead of passing the pre-activation values $\tilde{i}_t$ and $\tilde{f}_t$ through a sigmoid function, sLSTM employs the exponential function for the input gate: $i_t = \exp(\tilde{i}_t)$. Here, $\tilde{i}_t = \mathbf{w}^\top_{i} \mathbf{x}_t + r_{i} h_{t-1} + b_{i}$, maintaining the standard linear combination of inputs, recurrent hidden states, and biases before activation.

For the forget gate, xLSTM offers flexibility, allowing either a sigmoid activation $f_t = \sigma(\tilde{f}_t)$ or an exponential activation $f_t = \exp(\tilde{f}_t)$, depending on the specific design choice within the architecture. When exponential forgetting is used, $\tilde{f}_t = \mathbf{w}^\top_{f} \mathbf{x}_t + r_{f} h_{t-1} + b_{f}$ serves as the log-rate of forgetting. The adoption of these exponential forms means that small changes in the pre-activation logits $\tilde{i}_t$ or $\tilde{f}_t$ can result in orders-of-magnitude changes in the actual gate values. This sensitivity is precisely what empowers the network to execute sharp revisions; a slightly higher logit for the input gate can produce an input contribution $i_t z_t$ that dwarfsthe retained memory $f_t c_{t-1}$, instantly updating the cell state with new priorities. However, this power comes with significant numerical challenges, as exponentials grow rapidly and can easily exceed floating-point limits, necessitating sophisticated stabilization strategies.

# Core Innovation II: The sLSTM Architecture

The evolution of recurrent neural networks reached a pivotal moment with the introduction of the Long Short-Term Memory (LSTM) network, which solved the vanishing gradient problem through the concept of the constant error carousel and gating mechanisms. However, despite decades of success, standard LSTMs face fundamental limitations when scaled to the demands of modern large language models. Specifically, they struggle to revise stored information once it has been written, possess limited storage capacity due to their scalar nature, and lack the parallelizability required for efficient training at scale. The Extended Long Short-Term Memory (xLSTM) framework addresses these issues by introducing two distinct architectural variants. This chapter focuses on the first of these variants: the scalar LSTM, or sLSTM. While the sLSTM retains the traditional scalar memory cell structure of its predecessors, it incorporates radical modifications to the gating mechanism and memory mixing strategies. These enhancements empower the sLSTM to solve complex state-tracking problems that have proven intractable for Transformers and diagonal State Space Models, effectively bridging the gap between classical recurrence and modern deep learning requirements.

# sLSTM Forward Pass Derivation

To understand the mechanics of the sLSTM, one must first examine its forward pass equations, which represent a significant departure from the standard LSTM formulation primarily through the introduction of exponential gating and a dedicated normalizer state. In a traditional LSTM, the cell state $c_t$ is updated additively based on the previous cell state modulated by a forget gate and a new input modulated by an input gate. The sLSTM preserves this additive structure but fundamentally alters how these gates are computed and applied. The core update rule for the cell state at time step $t$ remains $c_t = f_t c_{t-1} + i_t z_t$, where $z_t$ represents the candidate cell input derived from the current input $\mathbf{x}_t$ and the previous hidden state $h_{t-1}$. However, unlike standard LSTMs where gates are constrained to the range $(0, 1)$ via sigmoid activation functions, the sLSTM allows the input gate $i_t$ and potentially the forget gate $f_t$ to take on values determined by exponential activation functions.

The introduction of exponential gates necessitates a mechanism to prevent numerical instability, as exponentials can grow arbitrarily large, leading to overflow errors during computation. To address this, the sLSTM introduces a novel component called the normalizer state, denoted as $n_t$. This state acts as a running sum that tracks the cumulative magnitude of the gating factors. Specifically, the normalizer state is updated via the recurrence $n_t = f_t n_{t-1} + i_t$. This equation mirrors the cell state update but operates solely on the gate values themselves, ignoring the content $z_t$. The purpose of $n_t$ is to provide a denominator for normalization when computing the final hidden state. The hidden state $\tilde{h}_t$ is calculated not merely by squashing the cell state with a non-linearity like $\tanh$, but by dividing the cell state by this normalizer: $\tilde{h}_t = c_t / n_t$. This division ensures that the effective contribution of past memories is normalized relative to the total gating activity, allowing the network to maintain stable dynamics even when gate values become large due to exponential activation.

The complete forward pass integrates these components with standard linear projections and activation functions. The candidate input $z_t$ is computed as $z_t = \varphi(\mathbf{w}_z^\top \mathbf{x}_t + r_z h_{t-1} + b_z)$, where $\varphi$ is typically a $\tanh$ function. Crucially, the input gate is defined as $i_t = \exp(\tilde{i}_t)$, where $\tilde{i}_t$ is the pre-activation logit derived from inputs and recurrent connections. The forget gate offers flexibility, defined either as a sigmoid $\sigma(\tilde{f}_t)$ or an exponential $\exp(\tilde{f}_t)$. The output gate $o_t$ remains a sigmoid function, controlling how much of the normalized internal state is exposed as the final hidden output $h_t = o_t \tilde{h}_t$. This formulation creates a system where information flow is controlled by multiplicative factors that can exceed unity, enabling more dynamic revision of memory contents than previously possible.

To ensure numerical stability in practice, specifically preventing overflow from large exponential values, the sLSTM employs a stabilization technique inspired by log-sum-exp tricks used in other domains. A stabilizer state $m_t$ is maintained alongside the other states. At each time step, $m_t$ is updated as $m_t = \max(\log(f_t) + m_{t-1}, \log(i_t))$. This value representsthe maximum accumulated log-gate value encountered so far inthe sequence history relevant tothe current step. The actual gates used inthe cell update are then rescaled versions: $i'_t = \exp(\log(i_t) - m_t)$ and $f'_t = \exp(\log(f_t) + m_{t-1} - m_t)$. Mathematically, substituting these stabilized gates $i'_t$ and $f'_t$ intothe recurrence relations yields exactlythe same output forthe entire network andthe same derivatives with respectto parameters asthe unstabilized version. This trick allows-the implementation-to compute-with extremely large effective gate values without ever encountering floating-point overflow-thereby unlocking-the full expressive power-of exponential gating while maintaining computational robustness.

# Core Innovation III: The mLSTM Architecture

The evolution of Long Short-Term Memory (LSTM) networks has historically been constrained by the limitations of their internal storage mechanisms. While the original LSTM introduced the concept of a constant error carousel to mitigate vanishing gradients, it relied on a scalar memory cell $c_t \in \mathbb{R}$ to store information. This scalar constraint imposes a fundamental bottleneck on the amount of information that can be retained and retrieved, particularly in complex language modeling tasks where rare tokens or intricate dependencies must be tracked over long sequences. To address these limitations, the Extended LSTM (xLSTM) framework introduces a radical departure from traditional recurrent designs: the matrix LSTM, or mLSTM. This architecture replaces the scalar memory cell with a high-dimensional matrix memory $\mathbf{C}_t \in \mathbb{R}^{d \times d}$, fundamentally altering how information is stored, updated, and retrieved. By transitioning to a matrix-based state and integrating mechanisms inspired by associative memory and attention, mLSTM not only vastly increases storage capacity but also enables full parallelization during training, a feat previously unattainable for standard LSTMs due to their sequential dependency on hidden states.

The core innovation of mLSTM lies in its synthesis of recurrent gating principles with the structural efficiency of modern attention mechanisms. Unlike its predecessor, which mixes hidden states through recurrent connections ($h_{t-1}$ influencing the current gate calculations), mLSTM eliminates these hidden-hidden recurrences. Instead, it relies entirely on input-driven projections to generate queries, keys, and values, updating a global matrix memory via a covariance rule. This architectural shift allows mLSTM to function as a powerful associative memory system capable of storing multiple key-value pairs simultaneously. Furthermore, by decoupling the temporal dependence of the hidden state updates from the memory update logic, mLSTM achieves a level of concurrency that rivals Transformers while maintaining the linear complexity characteristics desirable for long-context processing. This chapter explores the theoretical underpinnings and mechanical operations of mLSTM, detailing how it transforms the humble LSTM cell into a scalable, high-capacity engine for sequence modeling.

# From Scalar to Matrix Memory: Increasing Storage Capacity

The primary motivation for shifting from a scalar to a matrix memory structure is the inherent limitation in storage capacity found in traditional LSTMs. In the standard formulation, the cell state $c_t$ is a single real number (or a vector of independent scalars in multi-unit implementations) that must compress all relevant historical information into a low-dimensional representation. As noted in empirical evaluations involving rare token prediction, this compression often leads to information loss, where the model struggles to distinguish between infrequent patterns because they are forced into the same limited scalar space. The scalar update rule $c_t = f_t c_{t-1} + i_t z_t$ essentially performs a weighted average of past inputs, which is insufficient for retaining distinct, high-fidelity representations of diverse sequence elements when the context grows large.

mLSTM addresses this deficiency by expanding the memory cell from a scalar $c$ to a square matrix $\mathbf{C} \in \mathbb{R}^{d \times d}$. This expansion increases the degrees of freedom for storage quadratically with respect to the dimension $d$. Rather than storing a single aggregated value, the matrix $\mathbf{C}_t$ acts as a rich repository capable of encoding relationships between different feature dimensions. When an input arrives at time step $t$, instead of merely adding a scaled value to a running sum, mLSTM stores an outer product of vectors derived from that input. This allows the memory to capture correlations and interactions between features that a scalar sum would inevitably blur. Consequently, the retrieval process becomes more nuanced; instead of reading out a single compressed state, the model projects a query vector against this high-dimensional matrix to reconstruct specific historical information with greater fidelity. This structural enhancement directly targets the "limited storage capacities" limitation identified in earlier LSTM variants, enabling the model to handle complex distributions of data, such as those found in natural language with its long tail of rare tokens, without suffering from catastrophic forgetting or interference.

# The Covariance Update Rule: Storing Key-Value Pairs

Central to the operation of mLSTM is the covariance update rule, which dictates how new information is integrated into the matrix memory $\mathbf{C}_t$. Drawing inspiration from theories of biological learning and fast weight programmers, mLSTM treats every time step as an opportunity to store a specific association between a "key" vector $\mathbf{k}_t \in \mathbb{R}^d$ and a "value" vector $\mathbf{v}_t \in \mathbb{R}^d$. These vectors are generated from the input $\mathbf{x}_t$ via learned linear projections $\mathbf{W}_k$ and $\mathbf{W}_v$, respectively. The update equation for the cell state is defined as:

$$
\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top
$$

Here, $f_t$ serves as the forget gate (acting as a decay rate) and $i_t$ serves as the input gate (acting as a learning rate). The term $\mathbf{v}_t \mathbf{k}_t^\top$ represents the outer product of the value and key vectors, resulting in a rank-1 matrix that encodes the association between them.
