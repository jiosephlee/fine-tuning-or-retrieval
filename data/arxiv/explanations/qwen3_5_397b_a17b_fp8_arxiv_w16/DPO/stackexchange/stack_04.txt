\title{Stack Exchange of the Paper: "Direct Preference Optimization: Your Language Model is Secretly a Reward Model"}

### Does DPO restrict the space of learnable reward functions compared to explicit Reward Modeling?
Question:
In Section 4 ('Theoretical Analysis'), Theorem 1 claims that 'all reward classes consistent with... Bradley-Terry models can be represented with the reparameterization $r(x, y) = \beta \log \frac{\\pi(y\\mid x)}{\\pi_\\text{ref}(y\\mid x)}$'. 

The proof involves a projection operator $f$ that normalizes the reward by subtracting $\\beta\\log Z(x)$. The authors argue this selects a specific representative from an equivalence class of reward functions (where two rewards are equivalent if they differ only by a function of $x$). 

My question is: In standard RLHF with an explicit reward model $r_\\phi$, do we ever care about recovering the 'true' absolute values of the reward function, or only the relative ordering? If standard RLHF also only cares about relative ordering (since PPO optimizes based on advantage estimates), does DPO actually lose any expressivity? Or are there cases where an explicit reward model could learn a function outside this specific parameterization that would lead to a better policy?
Answer:
Based on the theoretical analysis in Section 4 of the paper, DPO does **not** restrict the space of learnable reward functions compared to explicit Reward Modeling (RM) when operating under the Bradley-Terry (or Plackett-Luce) preference framework. The apparent limitation you identified regarding the parameterization $r(x, y) = \beta \log \frac{\pi(y\mid x)}{\pi_\text{ref}(y\mid x)}$ is resolved by recognizing that preference data only identifies reward functions up to an additive function of the prompt $x$.

The core argument rests on Definition 1 and Lemma 1 in the paper, which establish that two reward functions $r$ and $r'$ are equivalent if they differ only by a function $f(x)$ dependent solely on the prompt. Under the Bradley-Terry model, the probability of preferring $y_w$ over $y_l$ depends entirely on the difference $r(x, y_w) - r(x, y_l)$. Consequently, adding any term $f(x)$ to both rewards cancels out in the subtraction, leaving the predicted preference distribution unchanged. Since standard RLHF optimizes a policy based on these relative preferences (via the advantage or reward differences), it inherently cannot distinguish between members of the same equivalence class; it effectively learns only the relative ordering, not the "true" absolute values of the reward function.

Theorem 1 formalizes this by proving that for *any* arbitrary reward function $r$, there exists a specific representative within its equivalence class that can be perfectly expressed using the DPO reparameterization. The proof constructs a projection operator $f$ that normalizes any given reward function by subtracting $\beta \log Z(x)$, where $Z(x)$ is the partition function required to make the resulting policy a valid probability distribution. This operation shifts the reward function by a term depending only on $x$, thereby moving it into the specific form required by DPO without altering its behavior under the Bradley-Terry model.

Therefore, DPO does not lose expressivity because the "missing" degrees of freedom (the absolute scale or prompt-dependent baselines) are unidentifiable from preference data anyway. An explicit reward model trained via maximum likelihood on pairwise comparisons suffers from the same under-specification and typically requires arbitrary normalization constraints (such as forcing the mean reward to zero) to converge. DPO simply chooses a different, analytically convenient constraint: it selects the unique reward function within each equivalence class such that the optimal policy derived from it sums to one without needing an external partition function calculation. In short, while an explicit RM might learn a function outside this specific parameterization numerically during training, that function would belong to an equivalence class already fully representable by DPO, and it would induce the exact same optimal policy.
