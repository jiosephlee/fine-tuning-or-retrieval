\title{Blogs about the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

# Code First, Math Later: Why Training on Programming Makes AI Better at Calculus

Does learning to write Python code actually help an artificial intelligence solve complex calculus problems? It sounds counter-intuitive. One might assume that to get better at math, a model simply needs more math data. However, the latest research from DeepSeek suggests a different path: mastering code first creates a stronger foundation for mathematical reasoning.

In their paper "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models," the researchers introduce DeepSeekMath 7B, a model that rivals giants like GPT-4 on competition-level math benchmarks despite having a fraction of the parameters. A key driver of this success is a specific training curriculum: code training precedes math pre-training. Furthermore, the team uncovered a surprising finding that challenges common assumptions in the field—training on massive amounts of scientific papers from arXiv provided negligible benefits compared to carefully filtered web data.

## The Power of Code Initialization

For years, a popular hypothesis in the AI community has been that code training improves general reasoning abilities, but concrete evidence has remained elusive. DeepSeekMath provides a compelling partial answer to this question, specifically within the domain of mathematics. The researchers found that initializing a model with code training significantly boosts its ability to solve mathematical problems, both when using external tools and when relying purely on internal logic.

The DeepSeekMath 7B model was not built from scratch as a general language model. Instead, it was initialized using DeepSeek-Coder-Base-v1.5 7B. This base model had already undergone extensive training on programming data. The researchers then continued pre-training this coder-focused model with 120 billion math-related tokens sourced from the web.

The results of this "code-first" approach were stark. When comparing training strategies, the team observed that models subjected to code training followed by math training outperformed those trained on general text followed by math. In experiments involving program-aided reasoning—where the model writes Python scripts to solve equations—the two-stage approach (Code then Math) yielded significant gains. Even more interestingly, this benefit extended to problems solved without tools. The initial code training stage alone provided moderate enhancements to pure mathematical reasoning, and it appeared to make the subsequent math training more efficient, leading to superior final performance.

This suggests that the structured logic, syntax precision, and algorithmic thinking required for coding create a cognitive scaffold that helps the model grasp abstract mathematical concepts more effectively later on. While mixing code and math tokens simultaneously in a single training stage helped prevent "catastrophic forgetting" of coding skills, the sequential approach of code followed by math proved optimal for maximizing mathematical prowess.

## The Surprising Ineffectiveness of arXiv Papers

If code is the secret sauce, what about the traditional staple of scientific AI training: arXiv papers? For years, it has been standard practice to include vast repositories of LaTeX-formatted scientific papers in math pre-training corpora. The assumption is that these peer-reviewed documents represent the highest quality of mathematical knowledge available.

DeepSeekMath turns this assumption on its head. The researchers conducted controlled experiments training models exclusively on arXiv corpora, including cleaned versions totaling billions of tokens. The results were disappointing. Models trained solely on arXiv data showed no notable improvements—and in some cases, even exhibited performance degradation—across various benchmarks ranging from grade-school arithmetic (GSM8K) to competition-level olympiad problems (MATH).

In contrast, the DeepSeekMath team constructed their own corpus by mining Common Crawl, the massive archive of public web pages. They did not just scrape everything; they employed a meticulous, iterative data selection pipeline. Starting with a seed set of high-quality math pages, they trained a classifier to identify and retrieve similar content from the wider web, refining their search over four iterations. This process yielded 120 billion tokens of diverse mathematical content, nearly seven times larger than the math web data used by previous state-of-the-art models like Minerva.

The takeaway is clear: quantity and source matter less than curation and diversity. The messy, varied landscape of the public web—including forums, educational sites, and documentation in multiple languages—appears to offer richer signals for learning reasoning patterns than the dense, highly specialized prose found in academic papers. Additionally, because their web-sourced corpus included significant non-English content (particularly Chinese), DeepSeekMath demonstrated superior performance on multilingual benchmarks compared to English-centric models trained on arXiv data.

## Scaling Intelligence Without Massive Parameters

The combination of code initialization and high-quality web data allowed DeepSeekMath 7B to punch well above its weight class. With only 7 billion parameters, it achieved a score of 51.7% on the MATH benchmark without using external tools or voting techniques. This performance approaches that of closed-source behemoths like Gemini-Ultra and GPT-4 and surpasses Minerva 540B, a model with 77 times more parameters.

This achievement underscores a shifting paradigm in Large Language Model development. It is no longer solely about scaling up parameter counts; it is about scaling up data quality and optimizing the training trajectory. By leveraging publicly available web data through engineered pipelines and respecting the logical foundations laid by code training, researchers can build highly capable reasoning models that are efficient and accessible.

The success of DeepSeekMath invites the research community to rethink data sourcing strategies. Rather than defaulting to established academic datasets, there is immense untapped potential in the broader internet—if one knows how to filter it correctly. As AI continues to evolve, the lesson from DeepSeekMath is evident: sometimes, to teach an AI advanced calculus, you first need to teach it how to code, and you definitely shouldn't rely only on textbooks found in university archives.
