# Principles of Block-wise k-bit Quantization

Quantization serves as the cornerstone for reducing the memory footprint of large language models (LLMs), acting as the bridge between high-precision training environments and efficient, low-resource deployment. At its core, quantization is the process of discretizing an input from a representation that holds a high density of information to a representation with significantly less information. In the context of deep learning, this typically involves converting data types with a large number of bits, such as 32-bit floating-point numbers (FP32), into data types with fewer bits, such as 8-bit integers (Int8) or even 4-bit representations. The fundamental challenge in this conversion is ensuring that the reduced bit-width can still adequately capture the dynamic range and nuance of the original tensor without introducing catastrophic errors that degrade model performance.

To map a high-precision tensor to a lower-precision space effectively, one must employ a rescaling mechanism. This process normalizes the input data so that it fits precisely within the representable range of the target low-bit data type. Consider a standard scenario where we wish to quantize a 32-bit Floating Point tensor, denoted as $\mathbf{X}^{{\text{FP32}}}$, into an 8-bit integer tensor with a valid range of $[-127, 127]$. The transformation relies on identifying the absolute maximum value within the input tensor, referred to as $\text{absmax}(\mathbf{X}^{{\text{FP32}}})$. This maximum value acts as the anchor for calculating a scaling factor, or quantization constant $c^{\text{FP32}}$, which is defined as $127 / \text{absmax}(\mathbf{X}^{{\text{FP32}}})$. The quantized tensor $\mathbf{X}^{ \text{Int8}}$ is then computed by multiplying the original tensor by this constant and rounding the result to the nearest integer: $\mathbf{X}^{ \text{Int8}} = \text{round}(c^{\text{FP32}}\cdot \mathbf{X}^{{\text{FP32}}})$. This operation ensures that the largest magnitude element in the original tensor maps exactly to the boundary of the integer range, thereby utilizing the full capacity of the available bits.

The reverse operation, known as dequantization, allows the model to reconstruct an approximation of the original high-precision values during computation. By dividing the quantized integer values by the stored quantization constant, we retrieve an estimate of the original floating-point values: $\text{dequant}(c^{\text{FP32}}, \mathbf{X}^{\text{Int8}}) = \mathbf{X}^{\text{Int8}} / c^{\text{FP32}} \approx \mathbf{X}^{{\text{FP32}}}$. While this global scaling approach works reasonably well for uniformly distributed data, it faces significant challenges when applied to the weight tensors of neural networks, which often exhibit heavy-tailed distributions containing extreme outliers. If a single outlier exists in the tensor with a magnitude vastly larger than the rest of the data, the quantization constant $c$ becomes extremely small to accommodate this outlier within the target range. Consequently, the vast majority of non-outlier values are scaled down to near-zero and mapped to a very narrow subset of the available integer bins. This phenomenon results in poor utilization of the quantization bins, where many bit combinations remain unused while others are overcrowded, leading to substantial quantization noise and loss of information for the bulk of the parameters.

# Quantization Constants and Outlier Management

To address the inefficiency caused by outliers in global quantization schemes, researchers have developed block-wise quantization strategies. Instead of treating an entire weight matrix or tensor as a single unit for scaling, block-wise quantization partitions the input tensor into smaller, contiguous segments called blocks. Each block is then quantized independently, possessing its own dedicated quantization constant. This localized approach ensures that outliers confined to a specific block only affect the scaling of that particular block, leaving the resolution of other blocks unaffected. Mathematically, if we have an input tensor $\mathbf{X}\in \mathbb{R}^{b\times h}$ representing batch size $b$ and hidden dimension $h$, we flatten this tensor and slice it into $n$ contiguous blocks of size $B$. The number of blocks is determined by $n = ({b\times h} )/{B}$. For each block $i$, where $i$ ranges from $1$ to $n$, we calculate a distinct quantization constant $c_i$ based solely onthe maximum absolute value within that block.

This structural change fundamentally alters how precision is preserved across heterogeneous data distributions typical in LLMs. By assigning a unique scale factor $c_i$ to every block, we effectively normalize each segment individually before mapping it to discrete levels using equations similar to those used in global quantization but applied locally.
