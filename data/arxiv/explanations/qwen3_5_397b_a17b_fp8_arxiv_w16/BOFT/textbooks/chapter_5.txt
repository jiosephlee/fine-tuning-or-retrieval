\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 5: # Orthogonal Butterfly (BOFT): Methodology and Implementation

The transition from theoretical frameworks to practical algorithms requires a precise synthesis of structural constraints, parameterization strategies, and regularization techniques. In the context of adapting large foundation models, the Orthogonal Butterfly (BOFT) method represents a culmination of the information transmission perspective on orthogonal finetuning. Unlike traditional approaches that rely on additive low-rank updates or static block-diagonal orthogonal transformations, BOFT constructs a dynamic, dense orthogonal matrix through the multiplication of sparse, structured components. This chapter details the architectural mechanics of BOFT, elucidating how butterfly factorization enables the construction of dense connectivity with logarithmic parameter complexity. We will explore the critical hyperparameters governing the depth and granularity of these transformations, demonstrate how BOFT generalizes previous orthogonal finetuning methods, and examine the specialized initialization and regularization protocols required to maintain stability in a multiplicative update regime.

# The BOFT Architecture: Product of Sparse Orthogonal Matrices

At the core of the BOFT methodology lies a fundamental shift in how orthogonal matrices are represented for finetuning. Traditional Orthogonal Finetuning (OFT) often struggles with the trade-off between expressivity and parameter efficiency; a full dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ requires $\mathcal{O}(d^2)$ parameters, which is prohibitive for large layers, while block-diagonal approximations restrict information flow between disjoint sets of neurons. BOFT resolves this dichotomy by decomposing the target orthogonal matrix into a product of multiple sparse orthogonal matrices, inspired by the butterfly structures found in the Cooley-Tukey fast Fourier transform algorithm. This factorization allows the model to generate a dense connectivity pattern—where every input dimension can influence every output dimension—while maintaining a parameter count that scales only as $\mathcal{O}(d \log d)$.

The architecture is built upon the concept of the "butterfly factor." For a dimension $k$ that is a power of 2, a butterfly factor $\bm{B}^F(k)$ is defined as a block matrix composed of four diagonal sub-matrices:
$$
\bm{B}^F(k)=\begin{bmatrix}
\text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\
\text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4)
\end{bmatrix}\in\mathbb{R}^{k\times k},
$$
where $\bm{d}_i$ are learnable vectors. By arranging these factors recursively, we construct a "butterfly component" $\tilde{\bm{B}}(d,k)$, which acts as a block-diagonal matrix where each block is itself a butterfly factor. The full orthogonal transformation $\bm{R}(m,b)$ used in BOFT is formed by multiplying $m$ such components together. Specifically, if we denote the $i$-th butterfly component as $\tilde{\bm{B}}^b_{(d,i)}$, the forward pass for a linear layer with pretrained weights $\bm{W}^0$ and input $\bm{x}$ becomes:
$$
\bm{z}=\big(\bm{R}(m,b)\cdot\bm{W}^0\big)^\top\bm{x}, \quad \text{where} \quad \bm{R}(m,b)=\prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}.
$$
Crucially, to ensure that the resulting product remains orthogonal, every individual component $\tilde{\bm{B}}^b_{(d,i)}$ must be constrained to be an orthogonal matrix. This is achieved by parameterizing the internal blocks using skew-symmetric matrices via the Cayley transform or direct rotation parameterizations for $2 \times 2$ blocks. The sparsity pattern of these components follows a specific permutation logic derived from the butterfly graph topology, ensuring that information propagates efficiently across all dimensions as it passes through successive layers of the factorization.

From an information transmission perspective, this architecture can be visualized as a grid-structured graph where nodes represent dimensions and edges represent non-zero entries in the sparse matrices. A single dense matrix would require every node in the input layer to connect directly to every node in the output layer, necessitating $\mathcal{O}(d^2)$ edges. In contrast, the BOFT architecture unrolls the matrix multiplication into a sequence of stages. In each stage, represented by a sparse butterfly component, information is exchanged locally between pairs or small groups of nodes. Through $m$ such stages, information originating from any single node diffuses across the entire graph, eventually reaching all other nodes. This sequential exchange mimics the efficiency of fast linear transforms like the Discrete Fourier Transform, allowing BOFT to achieve global connectivity (a dense matrix) using only local interactions (sparse matrices), thereby drastically reducing the number of trainable parameters without sacrificing the capacity to model complex relationships between neurons.
