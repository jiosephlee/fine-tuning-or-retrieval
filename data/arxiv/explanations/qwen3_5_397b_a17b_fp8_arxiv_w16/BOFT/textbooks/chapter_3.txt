\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: # A New Perspective: The Information Transmission Framework

The challenge of adapting large foundation models to specific downstream tasks often hinges on a delicate balance between preserving the rich knowledge encoded during pretraining and introducing sufficient flexibility to learn new patterns. Orthogonal Finetuning (OFT) addresses the preservation aspect by transforming weight matrices using orthogonal operations, thereby maintaining the pairwise angles between neurons. However, the traditional implementation of OFT faces a significant hurdle: constructing a dense orthogonal matrix that allows for global interaction among all neuron dimensions typically requires a prohibitive number of trainable parameters, scaling quadratically with the dimension size. Conversely, simplifying the structure to save parameters, such as using block-diagonal matrices, restricts the flow of information between different parts of the network, potentially limiting the model's expressiveness. To resolve this tension, we must fundamentally rethink how we construct these orthogonal transformations. This chapter introduces a novel theoretical lens—the information transmission framework—which reframes the algebraic problem of matrix factorization into a graphical problem of transmitting information across a network. By viewing the generation of a dense orthogonal matrix as a sequence of information exchanges on a grid-structured graph, we can systematically design sparse matrix products that achieve full connectivity with remarkable parameter efficiency.

## Conceptual Shift: Matrix Multiplication as Sequential Information Flow

To understand the innovation behind the information transmission framework, one must first abandon the static view of a matrix as merely a grid of numbers and instead perceive it as a dynamic operator governing the flow of data. In the context of Orthogonal Finetuning, the goal is to generate a target dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$. Traditionally, this matrix is treated as a single monolithic entity where every entry $R_{ij}$ represents a direct weighting factor between an input dimension $j$ and an output dimension $i$. If $R_{ij}$ is non-zero, it implies that information from the $j$-th component of the input vector contributes directly to the $i$-th component of the output vector. If $R_{ij}$ is zero, no such direct contribution exists. When $\bm{R}$ is dense, every input node influences every output node, representing a state of maximal connectivity. However, storing and optimizing such a matrix directly incurs a cost of $\mathcal{O}(d^2)$ parameters, which is unsustainable for modern high-dimensional models.

The conceptual shift proposed in this work involves decomposing this single dense matrix $\bm{R}$ into a product of $m$ simpler, sparse matrices: $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$. Algebraically, this is simply matrix factorization. Yet, intuitively, this decomposition transforms the operation from a single-step mapping into a multi-stage process of sequential information exchange. Instead of jumping directly from inputs to outputs in one giant leap, information traverses through intermediate stages defined by each factor $\bm{B}_i$. In this view, generating a dense matrix is equivalent to designing a communication protocol where information originating at any source node must eventually reach every destination node after passing through a series of relay stations. Each sparse matrix $\bm{B}_i$ acts as one such station, performing a limited set of local exchanges before passing the aggregated information to the next stage. This perspective is crucial because it decouples the requirement for global connectivity from the requirement for dense parameterization at any single step. We can achieve global reach not by connecting everyone to everyone immediately, but by orchestrating a chain of efficient local interactions that collectively propagate information everywhere.

This reframing allows us to leverage insights from fields outside of deep learning, particularly network theory and signal processing. Just as complex signals can be synthesized from simple wavelets or messages can be routed across vast distances via local hops in a computer network, a complex orthogonal transformation can be constructed from a sequence of sparse orthogonal steps. The key realization is that the "density" of the final matrix $\bm{R}$ is an emergent property of the cumulative effect of these sparse factors. Even if each individual $\bm{B}_i$ contains mostly zeros (implying very few trainable parameters), their product can fill in those zeros through indirect paths. For instance, if node $A$ connects to node $B$ in step 1, and node $B$ connects to node $C$ in step 2, then effectively node $A$ has transmitted information to node $C$, even though there was never a direct link between them in any single factor. This mechanism enables us to trade computation time (performing multiple matrix-vector multiplications) for space (drastically reducing the number of stored parameters), providing a viable pathway to parameter-efficient finetuning without sacrificing the expressive power of dense transformations.

## Graph Representation: Grid-Structured Nodes and Directed Edges

To formalize this intuition and make it actionable for designing new finetuning architectures, we map the matrix factorization problem onto a specific graph topology known as a grid-structured graph. Consider the factorization $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$, where each $\bm{B}_i$ is a $d \times d$ square matrix. We visualize this process as information flowing through a grid consisting of $d$ rows and $m+1$ columns of nodes. The columns represent discrete time steps or layers in the transmission process, indexed from $0$ to $m$. The nodes in column $0$ represent the initial input dimensions (sources), while the nodes in column $m$ represent the final output dimensions (receivers). The intermediate columns $1$ through $m-1$ serve as hidden states or relay points where information is mixed and forwarded.

In this graphical representation, each matrix $\bm{B}_i$ defines the connectivity pattern between column $i-1$ and column $i$. Specifically, we treat $\bm{B}_i$ as an adjacency matrix for a bipartite graph connecting the nodes at level $i-1$ to the nodes at level $i$. The element $(\bm{B}_i)_{jk}$ corresponds to a directed edge from the $k$-th node at level $i-1$ to the $j$-th node at level $i$. If $(\BM_i)_{jk}$ is non-zero, an edge exists, permitting information flow; if it is zero, no edge exists, blocking direct transmission between those specific nodes at that specific step. Consequently, sparsity in the matrix $\BM_i$ translates directly to sparsity in the graph edges between adjacent levels. A highly sparse matrix implies that each node at level $i-1\) connects to only a few neighbors at level \(i\), drastically reducing the number of edges—and thus trainable parameters—required for that step.

The power of this representation lies in its ability to visualize how indirect connectivity emerges. A path exists from a source node \(u\) in column \(0\) to a destination node \(v\) in column \(m\) if and only if there is a sequence of directed edges linking them through intermediate levels.
