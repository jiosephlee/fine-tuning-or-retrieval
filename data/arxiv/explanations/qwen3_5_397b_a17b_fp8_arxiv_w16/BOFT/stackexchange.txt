\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the 'Information Transmission' view map specifically to matrix multiplication sparsity?
Question:
In Section 3, the authors propose viewing the generation of a dense orthogonal matrix $\bm{R} = \bm{B}_m \cdots \bm{B}_1$ as an information transmission problem on a grid graph. I understand the analogy that non-zero entries represent edges allowing information flow. However, I am struggling to visualize how the 'levels' in the graph correspond to the intermediate dimensions during the sequential matrix multiplications. Specifically, if $\bm{B}_i$ connects level $i$ to $i+1$, does a zero at position $(u, v)$ in the final product $\bm{R}$ strictly imply that there is *no* path from node $v$ in level 1 to node $u$ in level $m+1$? Or is it possible for paths to exist but cancel out numerically due to the orthogonality constraints?
Answer:
The 'Information Transmission' view maps matrix multiplication sparsity to graph connectivity by treating the sequence of sparse matrices $\bm{B}_m \cdots \bm{B}_1$ as layers in a grid graph where nodes represent dimensions and edges represent non-zero entries. In this framework, the "levels" of the graph correspond precisely to the intermediate vector spaces formed during the sequential application of these matrices. Specifically, if we view the input vector at level 1, multiplying by $\bm{B}_1$ transmits information to level 2, multiplying by $\bm{B}_2$ transmits it to level 3, and so on, until the final output at level $m+1$. A non-zero entry at position $(u, v)$ in a specific factor $\bm{B}_i$ creates a directed edge from node $v$ at level $i$ to node $u$ at level $i+1$, allowing information to flow between those specific dimensions at that step of the computation.

Regarding your specific question about whether a zero in the final product $\bm{R}$ strictly implies no path exists: within the logical structure of the information transmission framework proposed in the paper, a zero entry $R_{uv} = 0$ indeed implies that there is no valid path from node $v$ in level 1 to node $u$ in level $m+1$. The authors explicitly define the generation of a dense matrix as a problem of ensuring that "every node in the first level has at least one path to every node in the last level." Conversely, if an element in the product is zero, it signifies that information cannot flow from the source index to the destination index through the cascade of sparse transformations. While in general linear algebra it is theoretically possible for multiple paths to exist but sum to zero due to numerical cancellation (destructive interference), the paper's framework treats sparsity patterns primarily through the lens of topological connectivity rather than arithmetic coincidence. The text emphasizes that "if $R_{ij}$ is zero, then it indicates that information from the $j$-th node cannot flow to the $i$-th node," suggesting that for the purpose of designing parameter-efficient structures like Butterfly networks, the absence of a path is the governing condition for a zero entry.

This distinction is crucial because the goal of Orthogonal Butterfly (BOFT) is to construct a *dense* orthogonal matrix using sparse factors. The "butterfly" topology is selected specifically because it guarantees dense connectivity (a path between every pair of input and output nodes) using only $\mathcal{O}(d \log d)$ edges, whereas a naive dense matrix would require $\mathcal{O}(d^2)$. The orthogonality constraint adds a layer of complexity by enforcing dependencies between edges—for instance, in a $2 \times 2$ orthogonal block, setting one entry to zero forces another specific entry to be zero—but this serves to reduce the number of *trainable* parameters rather than breaking the path existence logic. Therefore, when visualizing these products as graphs, you should interpret a zero in $\bm{R}$ as a structural disconnection in the grid graph, confirming that no sequence of allowed transitions through the intermediate sparse matrices connects the input dimension $v$ to the output dimension $u$.

### Why are exactly $d$ edges considered 'not trainable' in the orthogonality constraint?
Question:
The paper states in Section 3 that for a $d \times d$ orthogonal matrix factor, we need at least $d$ edges to form a bijection, and claims these '$d$ edges... should not be counted into the number of edges, because these elements are not trainable (e.g., ... can only be $\pm 1$).' This confuses me. If I use the Cayley parameterization $\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$ mentioned earlier, aren't the values continuous and dependent on the skew-symmetric matrix $\bm{Q}$? Why does the paper suggest that satisfying the bijection requirement forces entries to be fixed constants like $\pm 1$, rendering them non-trainable? Does this only apply to permutation matrices, or am I misunderstanding the degree of freedom in sparse orthogonal factors?
Answer:
The confusion stems from distinguishing between the *structural necessity* of having $d$ connections to maintain orthogonality and the *parametric freedom* to choose the values of those connections. In the information transmission framework presented in Section 3, the authors analyze the sparsity pattern of the factorized matrices required to form a valid orthogonal matrix. For any $d \times d$ orthogonal matrix to be full-rank (a strict requirement for orthogonality), there must be a bijection between the input nodes at level $i$ and the output nodes at level $i+1$. Graph theoretically, this necessitates at least $d$ edges; if there were fewer than $d$ edges, at least one output node would receive no information, resulting in a zero row and a singular (non-orthogonal) matrix.

The paper argues that these specific $d$ edges are "not trainable" in the context of counting *effective* parameters because, in the minimal sparse case where exactly $d$ edges exist, the orthogonality constraint $\bm{B}^\top \bm{B} = \bm{I}$ severely restricts their values. If a sparse orthogonal matrix has exactly one non-zero entry per row and column (which is the definition of a generalized permutation matrix), those non-zero entries cannot take arbitrary continuous values derived from a skew-symmetric matrix $\bm{Q}$ via Cayley parameterization. Instead, to satisfy the unit norm constraint of the rows and columns, each of these $d$ non-zero entries must strictly be either $+1$ or $-1$. Since these values are discrete constants determined entirely by the choice of permutation and sign rather than continuous optimization variables, they contribute zero degrees of freedom to the learning process.

Your intuition regarding the Cayley parameterization $\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$ applies correctly to cases where there are *more* than $d$ edges (i.e., when the matrix has sufficient density to allow for continuous rotations, such as Givens rotations). In those scenarios, the extra edges beyond the mandatory $d$ provide the necessary degrees of freedom for $\bm{Q}$ to vary continuously, making them trainable. However, the paper's argument isolates the baseline cost of connectivity: the first $d$ edges are merely the "skeleton" required to keep the matrix invertible and orthogonal, acting as fixed wiring (permutations with signs) rather than learnable weights. Therefore, when calculating parameter efficiency, the authors subtract these $d$ structurally forced edges from the total count, considering only the surplus edges that allow for actual continuous variation as "trainable parameters." This distinction allows them to fairly compare different sparse topologies based on how many *extra* connections they need to achieve expressivity beyond simple signed permutations.

### Clarification on BOFT hyperparameters: How do $m$ and $b$ interact to determine density?
Question:
The paper defines BOFT($m, b$) where $m$ is the number of butterfly components and $b$ is related to the block size. It mentions that BOFT($1, b$) reduces to block-diagonal OFT and BOFT($\log \frac{2d}{b}, b$) yields a dense orthogonal matrix. Could someone clarify the relationship between $m$, $b$, and the resulting 'density' of the final matrix $\bm{R}$? If I choose an arbitrary $m$ that is less than $\log d$, is the resulting matrix guaranteed to be sparse (block-diagonal-like), or does it just have a specific structured sparsity pattern that isn't fully dense? How exactly does increasing $m$ transition the hypothesis space from local block transformations to global dense transformations?
Answer:
The interaction between $m$ and $b$ in BOFT determines the "depth" of information mixing across the dimensions of your feature space, effectively interpolating between isolated local transformations and global dense rotations. To understand this, it is helpful to visualize the orthogonal matrix $\bm{R}$ not as a static grid of numbers, but as a multi-stage circuit for transmitting information, where $d$ represents the number of channels (dimensions). In this framework, the parameter $b$ defines the size of the basic processing units (blocks) at each stage, while $m$ dictates how many stages of these units are cascaded together.

When you set $m=1$, the system consists of a single layer of disjoint blocks of size $b$. Mathematically, this results in a block-diagonal matrix where information can only flow between dimensions within the same block; a dimension in block 1 cannot influence a dimension in block 2. This is precisely the behavior of the original Block-Diagonal OFT, representing the most sparse and localized hypothesis space. As you increase $m$, you are stacking additional layers of butterfly components on top of one another. Crucially, the structure of these butterfly components involves permutations that shuffle dimensions between blocks at every stage. Therefore, increasing $m$ allows information to propagate further across the dimension index. A signal starting at dimension $i$ can reach dimension $j$ only if there are enough stages ($m$) to bridge the distance between them through the recursive shuffling inherent in the butterfly topology.

The specific threshold mentioned in the paper, $m = \log \frac{2d}{b}$, corresponds to the depth required for the butterfly network to achieve "full connectivity." Just as the Fast Fourier Transform requires $\log d$ stages to allow every input frequency to influence every output time step, this specific value of $m$ ensures that every input dimension has a computational path to every output dimension. At this point, the product of the sparse matrices yields a theoretically dense orthogonal matrix, meaning the resulting $\bm{R}$ has no structural zeros imposed by the architecture (though individual learned values might be small). If you choose an arbitrary $m$ that is less than this logarithmic bound but greater than 1, the resulting matrix is neither strictly block-diagonal nor fully dense in terms of connectivity. Instead, it possesses a specific structured sparsity pattern where dimensions can mix globally but only up to a certain receptive field determined by the depth. You can think of low $m$ as allowing interactions only between "nearby" features (after accounting for permutations), while high $m$ enables long-range dependencies across all features. Consequently, increasing $m$ smoothly transitions the hypothesis space from rigid, independent local rotations to flexible, global orthogonal transformations, allowing you to trade off parameter efficiency (low $m$) against expressivity (high $m$) without abandoning the orthogonality constraint.

### Intuition behind Multiplicative Dropout: Why replace blocks with Identity instead of Zero?
Question:
In Section 4, the authors introduce 'Multiplicative Dropout' for BOFT. They state that conventional dropout doesn't work for multiplicative updates and propose randomly replacing selected butterfly blocks with Identity matrices. Why is replacing with Identity ($\bm{I}$) the correct analog to dropping units (setting to 0) in an additive framework like LoRA? Since the operation is multiplication ($\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$), setting a part of $\bm{R}$ to zero would destroy information entirely, whereas setting it to $\bm{I}$ preserves the input signal unchanged. Is the goal here to simulate 'skipping' a transformation layer rather than 'dropping' a feature activation?
Answer:
The intuition behind replacing blocks with Identity matrices instead of zeros lies in the fundamental difference between additive and multiplicative update rules, specifically regarding how "no change" is represented in each algebraic structure. In an additive framework like LoRA, the updated weight is $\bm{W} = \bm{W}^0 + \Delta\bm{W}$. Here, the neutral element that preserves the original pretrained weight $\bm{W}^0$ is the zero matrix; setting $\Delta\bm{W} = \bm{0}$ ensures the output remains exactly $\bm{W}^0\bm{x}$. Consequently, standard dropout sets activations to zero to simulate removing a feature's contribution, relying on the remaining network paths to compensate.

However, BOFT operates via a multiplicative update rule defined as $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$, where $\bm{R}$ is an orthogonal matrix constructed from a product of butterfly components. In this multiplicative group, the neutral element that leaves the input signal unchanged is not the zero matrix, but the Identity matrix $\bm{I}$. If you were to apply conventional dropout by setting a block of the orthogonal matrix $\bm{R}$ to zero, you would effectively destroy the information flowing through those dimensions because multiplying by zero collapses the signal to null, violating the orthogonality constraint essential for preserving the pairwise angles of neurons (the core benefit of OFT). Furthermore, a matrix with zero blocks is no longer orthogonal, breaking the theoretical guarantees of the method.

Therefore, "dropping" a unit in this context must be redefined as "skipping" the learned transformation for that specific block. By randomly replacing selected butterfly blocks with $\bm{I}$, the forward pass for those blocks becomes equivalent to applying no transformation at all ($\bm{I}\bm{x} = \bm{x}$), allowing the signal to pass through untouched while maintaining the overall orthogonality of the composite matrix $\bm{R}$. This acts as a regularization technique similar to DropConnect or stochastic depth, where entire transformation layers are bypassed during training to prevent co-adaptation of features, but it does so in a way that respects the geometric constraints of the orthogonal manifold. Essentially, while additive dropout simulates removing a feature activation, multiplicative dropout simulates removing a *transformation step*, forcing the model to rely on diverse pathways through the butterfly factorization graph rather than overfitting to specific rotational adjustments in every block.

### Does BOFT really preserve spectral norms if approximations are used?
Question:
Section 5 claims that Orthogonal Finetuning (and thus BOFT) perfectly preserves the spectral norm of the pretrained weight matrix $\bm{W}^0$ because multiplying by an orthogonal matrix $\bm{R}$ does not change singular values. However, earlier sections discuss approximating dense orthogonal matrices using butterfly factors. If the learned product of butterfly matrices $\hat{\bm{R}} = \prod \tilde{\bm{B}}_i$ is only an *approximation* of a true orthogonal matrix (due to limited capacity or optimization issues), is strict orthogonality ($ \hat{\bm{R}}^\top \hat{\bm{R}} = \bm{I} $) enforced during training? If yes, how? If no, doesn't this break the theoretical guarantee regarding spectral norm preservation and training stability?
Answer:
The concern you raise touches on a subtle but critical distinction between the theoretical properties of the mathematical operation and the practical constraints of the parameterization used to implement it. The short answer is that **yes, strict orthogonality is enforced** for the learned product $\hat{\bm{R}}$, meaning the theoretical guarantee regarding spectral norm preservation holds exactly, not approximately. The "approximation" discussed in the paper refers to the *expressivity* of the hypothesis class (i.e., which orthogonal matrices can be represented), not a relaxation of the orthogonality constraint itself.

To understand why this is the case, we must look at how BOFT constructs the transformation matrix. As detailed in Section 4 ("Orthogonal Parameterization by Butterfly Factorization"), BOFT defines the learnable orthogonal matrix $\bm{R}(m,b)$ as a product of $m$ sparse "butterfly components": $\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$. The crucial mechanism here is that the authors do not simply optimize arbitrary sparse matrices and hope they converge to being orthogonal. Instead, they explicitly constrain every individual butterfly component $\tilde{\bm{B}}^b_{(d,j)}$ to be an orthogonal matrix during the optimization process. The paper states clearly in Equation (4) that the construction satisfies $(\tilde{\bm{B}}^b_{(d,j)})^\top\tilde{\bm{B}}^b_{(d,j)} = \bm{I}_d$ for all $j \in [1, m]$.

This is achieved by parameterizing the non-zero blocks within these sparse matrices using techniques that inherently produce orthogonal outputs, such as the Cayley transform or explicit $2\times 2$ rotations (as mentioned in Section 4 regarding $\tilde{\bm{B}}(d,2)$). Because the set of orthogonal matrices forms a group, it is closed under multiplication. This means that if every factor $\tilde{\bm{B}}_i$ in the product is strictly orthogonal, their product $\hat{\bm{R}} = \tilde{\bm{B}}_m \cdots \tilde{\bm{B}}_1$ is mathematically guaranteed to be strictly orthogonal ($\hat{\bm{R}}^\top \hat{\bm{R}} = \bm{I}$), regardless of how many factors are used or what their specific values are during training. Consequently, when this $\hat{\bm{R}}$ multiplies the pretrained weight $\bm{W}^0$, the singular values of the resulting matrix remain identical to those of $\bm{W}^0$, preserving the spectral norm perfectly as claimed in Section 5 ("Spectral properties").

The "approximation" aspect you noted arises from a different source: **representational capacity**. While any matrix generated by this process is *an* orthogonal matrix, the specific subset of orthogonal matrices that can be formed by a product of only $m$ butterfly factors with block size $b$ is limited. As discussed in Section 5 under "Expressivity of BOFT," a small $m$ restricts the hypothesis class to a structured subset of the full orthogonal group $O(d)$. The paper acknowledges that while this structured subset can recover many classic linear transforms (like FFT or Hadamard), it may not be able to represent *every* possible dense orthogonal matrix unless $m$ is sufficiently large (specifically, scaling with $d$). Therefore, the model approximates the *optimal* orthogonal transformation for a downstream task because it searches within a constrained, parameter-efficient subspace, not because it fails to maintain orthogonality during the search. The trade-off described in the paper is between **expressivity** (how close we can get to the ideal task-specific rotation) and **regularity/efficiency** (using fewer parameters via sparse factors), but orthogonality itself remains an exact invariant throughout training.

### How does BOFT compare theoretically to Kaleidoscope hierarchies for expressing arbitrary orthogonal matrices?
Question:
Theorem 1 states that BOFT is more expressive than OFT with the same block size and mentions that a 'Kaleidoscope hierarchy' ($\bm{B}_{d-1,1}\bm{B}^\top_{d-1,2}\cdots$) can represent the *entire* orthogonal group. The proposed BOFT method seems to use a simpler product structure ($\prod_{i=1}^m \tilde{\bm{B}}_{(d,i)}$). Does standard BOFT with finite $m < d-1$ cover a significantly smaller subset of the orthogonal group compared to Kaleidoscope? What is the practical implication of this difference: does restricting ourselves to simple products (without alternating transposes/inverses) impose an inductive bias that helps generalization, or is it purely a computational simplification?
Answer:
The distinction you raise touches on the core trade-off in BOFT between theoretical universality and practical inductive bias. While it is true that a "Kaleidoscope hierarchy"—constructed by alternating butterfly matrices and their transposes (e.g., $\bm{B}_{d-1,1}\bm{B}^\top_{d-1,2}\cdots$)—can theoretically represent the *entire* orthogonal group when the depth reaches $d-1$, standard BOFT with a finite depth $m < d-1$ (typically $m = \log d$) covers a strictly smaller, structured subset of the orthogonal group. However, the paper argues that this limitation is not a deficit but rather the source of BOFT's superior generalization capabilities compared to both full orthogonal finetuning and block-diagonal OFT.

Theoretically, standard BOFT constructs the orthogonal matrix $\bm{R}(m,b)$ as a simple product of $m$ sparse orthogonal butterfly components, denoted as $\prod_{i=1}^m \tilde{\bm{B}}_{(d,i)}$. As noted in Theorem 1 and the subsequent discussion, achieving universal expressivity (covering the entire orthogonal group) would require extending this structure into a Kaleidoscope hierarchy with alternating transposes and significantly greater depth ($l=d-1$). In contrast, standard BOFT restricts itself to a shallow product without these alternating inverses. Consequently, for any finite $m$ used in practice, BOFT cannot approximate an arbitrary orthogonal matrix with zero error; it is confined to a manifold of matrices that share the specific connectivity patterns of the butterfly graph.

Practically, however, this restriction imposes a powerful **inductive bias** that aids generalization. The paper explicitly contrasts the goal of "universal expressivity" with the needs of parameter-efficient finetuning. Full finetuning possesses universal expressivity yet often suffers from overfitting and instability because the hypothesis space is too vast relative to the limited downstream data. BOFT leverages the butterfly structure—which underpins classic fast linear transforms like the Fast Fourier Transform (FFT), Discrete Cosine Transform (DCT), and Hadamard transform—to create a "smoother interpolation" between the identity matrix (representing no change to the pretrained model) and complex dense transformations. By restricting the search space to this structured subset, BOFT prevents the model from learning arbitrary, potentially noisy rotations that do not align with natural signal processing priors. The authors argue that because many fundamental linear operations in nature and engineering adhere to butterfly-like sparsity patterns, constraining the orthogonal update to this subspace acts as a regularizer. This allows BOFT to achieve high expressivity with only $\mathcal{O}(d \log d)$ parameters—far fewer than the $\mathcal{O}(d^2)$ required for a full dense matrix or even deeper Kaleidoscope structures—while maintaining better stability than low-rank methods like LoRA or block-diagonal OFT, which lack this global connectivity.

Therefore, the difference is not merely a computational simplification to save parameters; it is a deliberate design choice to balance expressivity and regularity. While Kaleidoscope hierarchies offer a complete basis for the orthogonal group, they would likely reintroduce the overfitting risks associated with high-dimensional optimization. Standard BOFT sacrifices the ability to represent *every* possible orthogonal matrix in favor of representing *useful* ones efficiently, thereby finding a "smaller hypothesis class within the orthogonal group" that empirically yields better performance on downstream tasks across vision and language models.
