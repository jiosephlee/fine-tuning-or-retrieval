\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### "Memory mixing” across heads – is it equivalent to multi‑head attention?
Question:
The paper introduces 'memory mixing within each head but not across heads' as new way of memory mixing enabled by exponential gates. Is this analogous to multi-head self‑attention where each head attends independently? If so, can we view sLSTM’s memory mixing as performing self‑attention over past cell states, or is it fundamentally different because of recurrent dependencies?
Answer:
**Short answer**  
No – the “memory mixing inside each head” that sLSTM introduces is *conceptually* similar to having multiple independent self‑attention heads, but the mechanism by which it mixes information is fundamentally different. In sLSTM the mixing happens **sequentially** through the recurrent update (additively, with exponential gates), whereas in multi‑head self‑attention the mixing is a **parallel dot‑product attention** over all tokens of a single sequence step. Because of this recurrence the two systems have different computational properties and expressive power: sLSTM can revise what it has stored at any time, while a standard multi‑head attention block cannot.

---

### 1.  What “memory mixing” means in sLSTM

For an sLSTM with \(d\) memory cells we allow the hidden state \(\mathbf{h}_{t-1}\) to influence the gate and input computations of *all* cells at the next step:

\[
\tilde{\mathbf{z}}_t = \mathbf{W}_{z}\mathbf{x}_t + \mathbf{R}_{z}\mathbf{h}_{t-1} + \mathbf{b}_z ,\quad
\tilde{\mathbf{i}}_t = \mathbf{W}_{i}\mathbf{x}_t + \mathbf{R}_{i}\mathbf{h}_{t-1} + \mathbf{b}_i, \dots
\]

The recurrent matrices \(\mathbf{R}_{\!z},\mathbf{R}_{\!i},\dots\) thus mix the content of all cells within one head *from step \(t-1\) to step \(t\)*.  
When several heads are used, each head has its own set of these matrices; cross‑head interaction is deliberately disabled.

### 2.  Comparison with multi‑head self‑attention

In a Transformer layer a single time‑step token attends to *all* tokens in the same sequence in one parallel operation:

\[
\mathbf{A}_h = \operatorname{softmax}\!\Bigl( Q_h K_h^\top / \sqrt{d_k}\Bigr) V_h ,
\]

with separate learned projections \(Q_h, K_h, V_h\) for every head \(h\). The key differences are:

| Feature | sLSTM memory mixing | Transformer multi‑head self‑attention |
|---------|---------------------|--------------------------------------|
| **Parallelism** | Sequential – requires hidden state from \(t-1\) | Fully parallel across positions |
| **Operations** | Additive recurrent update with exponential gates | Dot‑product attention + softmax |
| **Scope of interaction** | Only *time‑next* interaction (curr step ↔ previous step) | Interaction between any two tokens in the same layer |
| **Key–value structure** | Not explicitly present; gates mediate influence | Explicit key/value query mechanism |

Because the sLSTM mixes information only from \(t-1\), the update cannot directly look at earlier tokens beyond what is already encoded in \(c_{t-1}\). In contrast, a self‑attention head can directly attend to any position \(j < t\). That makes sLSTM’s recurrence more akin to a long‑short‑term memory that evolves over time rather than a static attention graph.

### 3.  Intuition: “Mixing inside a head” ≠ “Self‑attention”

Think of each head as its own tiny LSTM. Within that LSTM, gates decide *how much* of each cell’s previous state should be retained or overwritten by new input data. When you have several such LSTMs running in parallel (the heads), you simply replicate this decision process independently for each copy.

If you wrote out two heads side by side and stack their cell states into a block matrix,

```
[ c_t^h1  c_t^h2  …  c_t^hn ]
```

the next step updates each column separately; there is no term that mixes row 1 into row 2 directly at this moment. After many steps however, information can flow from one column to another *indirectly* because each column carries whatever it has accumulated from previous steps.

This is structurally different from attention where every head produces an output that is a weighted sum over **all** positions simultaneously. Hence, “memory mixing inside a head” shares only the superficial idea of parallelism; it does **not** perform self‑attention over past cell states.

### 4.  Consequences for expressiveness

* The recurrent nature gives sLSTM the ability to revise past decisions (e.g., apply exponential forgetting), something that vanilla Transformers cannot do without auxiliary mechanisms (e.g., adaptive computation).  
* Missing cross‑head interaction means that each head learns somewhat independent representations; if you want richer cross‑information you add another mechanism (e.g., residual connections or inter‑head communication).  
* Because memory mixing only spans successive time steps, long‐range dependencies must be aggregated gradually through many recurrence steps – still efficient owing to linear complexity.

### 5.  Closing remarks

So while both systems benefit from parallel heads or copies, sLSTM’s “mixing” is an additive recurrent process governed by learned gates and exponential decay, whereas transformer multi‑head attention is a simultaneous pairwise weighted sum performed once per layer. The structural difference leads to distinct computational patterns—sequential vs parallel—and distinct expressive capabilities—state tracking and revisable memory vs immediate token-to-token interaction.

In short: **“Memory mixing within heads” is not equivalent to multi‑head self‑attention; it is an RNN‑style recurrent mixing that behaves differently from the parallel dot‑product attention used in Transformers.**
