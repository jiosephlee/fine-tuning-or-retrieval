\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Why BOFT Generalizes Better: Theory of Expressivity, Spectral Norm Preservation & Inductive Bias

*In recent months there has been a surge of “parameter‑efficient finetuning” (PEFT) techniques that let us adapt gigantic foundation models without the cost of full retraining. Among them, **Orthogonal Finetuning (OFT)** stood out because multiplying a pretrained weight matrix by an orthogonal matrix preserves the geometry of the learned features. Yet OFT still needs a lot of trainable weights when the orthogonal matrix is dense.*

*Enter **BOFT** – Orthogonal Butterfly Finetuning – which replaces the blunt dense orthogonal map with a clever product of sparse *butterfly* matrices. The result is a finetuning method that keeps the nice geometric properties of OFT while dramatically cutting down on parameters and adding a useful structural bias.*  

Below we unpack three theoretical pillars that explain why BOFT tends to **generalize** better than its predecessors:

1. **Higher expressivity than block‑diagonal OFT** (and a formal theorem).  
2. **Exact preservation of spectral norms**, which stabilises training.  
3. **An inductive bias baked into the butterfly factorisation** that aligns the model with classic linear transforms.

---

## 1 From Block‑Diagonal Orthogonality to Butterfly Expressivity

### 1.1 What OFT does – and why it can be limiting  

In classic OFT a learnable orthogonal matrix \(\mathbf{R}\in\mathbb{R}^{d\times d}\) multiplies a frozen layer \(\mathbf{W}^{0}\):
\[
\mathbf{z}= (\mathbf{R}\mathbf{W}^{0})^{\!\top}\mathbf{x}.
\]
If we naïvely treat \(\mathbf{R}\) as an unconstrained dense matrix we would need \(\Theta(d^{2})\) trainable entries – untenable for modern models where \(d\) often runs into thousands.

The original solution was **block‑diagonalisation**:
\[
\mathbf{R}= \operatorname{diag}(\mathbf{R}_{1},\dots,\mathbf{R}_{r}),
\quad 
\mathbf{R}_{i}\in \mathbb{R}^{b\times b},\, br=d,
\]
which chops \(\mathbf{R}\) into \(r\) independent blocks each requiring only \(\Theta(b^{2})\) parameters. This reduces storage dramatically (\(\Theta(bd)\)), but at a price:

* The transformation only mixes dimensions inside each block – dimensions belonging to different blocks never communicate during finetuning.
* Consequently the reachable set of orthogonal matrices is severely restricted and cannot represent many useful linear maps (e.g., Fourier or Hadamard transforms).

### 1.2 Butterfly factorisation – sparse matrices that talk to everyone  

BOFT reframes the problem as an **information‑transmission** task on a grid of nodes (the paper’s Figure 2). Imagine we have \(d\) source nodes (input dimensions) that must reach all \(d\) destination nodes after passing through several “layers” of sparse connections \(\mathbf{B}_{1},\dots,\mathbf{B}_{m}\):
\[
\mathbf{R}= \mathbf{B}_{m}\,\mathbf{B}_{m-1}\cdots \mathbf{B}_{1}.
\]
If each \(\mathbf{B}_{i}\) is chosen cleverly, the product becomes a *dense* orthogonal matrix while each factor contains only \(\mathcal{O}(d)\) non‑zero entries — far fewer than \(d^{2}\).

The insight comes from the **Cooley–Tukey fast Fourier transform**. Its “butterfly graph” connects every source to every sink using only \(\mathcal{O}(d\log d)\) edges across \(\log d\) stages. Translating this pattern into linear algebra gives us *butterfly factors*:
\[
\tilde{\mathbf B}(d,k)=
\operatorname{diag}(\mathbf B^{F}_{1}(k),\dots,\mathbf B^{F}_{d/k}(k)),
\qquad
k=2^{t},
\]
where each small factor \(\mathbf B^{F}(k)\) has a very sparse layout (two diagonal blocks). By chaining together factors for decreasing powers of two,
\[
\mathbf R(m,b)=\prod_{i=1}^{m} \tilde{\mathbf B}^{\,b}_{(d,i)},
\]
we obtain an orthogonal matrix built from *\(m=\log_{2}(d/b)\)* components each of block‑size \(b\).

Even when we pick the extreme case \(b=2,\ m=\log_{2} d\), BOFT needs only
\[
\tfrac12(b-1)d\,m = \mathcal O(d\,\log d)
\]
trainable scalars – orders of magnitude fewer than OFT’s \(\Theta(d^{2})\). Yet because information propagates through many stages, **every input dimension can affect every output dimension**, guaranteeing dense connectivity.

### 1.3 Theorem (Expressivity of BOFT)

> **Theorem 1 (from the paper).** *BOFT is strictly more expressive than block‑diagonal OFT with the same block size.* Moreover, any orthogonal matrix of size \(d\times d\) can be approximated arbitrarily well by a product
> \[
>   \mathbf B_{d-1,1}(d)\,\mathbf B_{d-1,2}^{\!\top}(d)
>   \cdots
>   \mathbf B_{1,1}(d)\,\mathbf B_{1,2}^{\!\top}(d),
> \]
> where each \(\mathbf B_{i,j}(d)\) is a butterfly matrix.

In plain language: if you give both methods the same “budget per block”, BOFT’s composition of multiple butterfly components can span a strictly larger part of the orthogonal group than a single block‑diagonal matrix can. Empirically (Figure 3 in the paper), increasing depth \(m\) while shrinking block‑size \(b\) yields lower approximation error for the same number of parameters.

## 2 Spectral Norm Preservation – A Built‑In Training Stabiliser

### 2.1 Why spectral norms matter  

Training deep networks often runs into exploding or vanishing gradients if layer weights dramatically change their singular values during optimisation. A large spectral norm amplifies gradients; too small one shrinks them away—both hurt learning and generalisation.

### 2.2 Orthogonal updates keep singular values intact  

Consider an SVD of a frozen linear layer:
\[
\mathbf W^{0}= \mathbf U\, \boldsymbol{\Sigma}\,\mathbf V^{\!\top},
   \quad
   \boldsymbol{\Sigma}= \operatorname{diag}(\sigma_{1},…,\sigma_{n}).
\]
Multiplying on the left by any orthogonal matrix \(\mathbf R^{\,}\)(i.e., satisfying
\( {\bf R}^{\!\top}{\bf R}= {\bf I}_d)\)
yields
\[
{\bf R}{\bf W}^{0}=({\bf R}{\bf U})\, \boldsymbol{\Sigma}\,\mathbf V^{!\top}.
\]
Since both ${\\bf R}{\\bf U}$ and $\bf V$ stay orthogonal, **the singular values $\sigma_i$ are unchanged**:
the spectral norm $\|\mathbf W^{0}\|_{2} = \sigma_{\max}$ remains exactly what it was before finetuning.

Both OFT and BOFT inherit this property because their learned $\mathbf R$ is always orthogonal (enforced via Cayley parametrisation). In contrast, additive low‑rank updates such as LoRA change $\boldsymbol{\Sigma}$ and thus alter spectral norms—often requiring extra regularisation tricks to remain stable.

### 2.3 Consequences for optimisation  

* **Stable gradient flow:** Because forward activations preserve energy (\(‖{\bf Rx}‖ = ‖x‖$), back‑propagated gradients also retain their magnitude across layers.
* **Consistent Lipschitz constant:** An unchanged spectral norm implies that each layer’s Lipschitz constant stays identical before and after finetuning—a fact linked theoretically to better generalisation [Miyato 2018].
* **No extra inference cost:** After training, butterfly components can be multiplied into ${\\bf W}^{0}$ once, yielding a single dense weight matrix ready for fast inference without runtime overhead.

Thus BOFT inherits all stability benefits of OFT while being far more parameter‑efficient.

## 3 Inductive Bias from Butterfly Structure

### 3.1 What “inductive bias” really means here  

An inductive bias is any design choice that restricts the hypothesis space in a way that matches expected structure in data or tasks. By constraining $\mathbf R$ to be a product of butterfly factors we:

* impose sparsity patterns known to efficiently transmit information,
* force each factor to be orthogonal,
* limit how dimensions can interact at each stage (pairwise mixing then permutation).

These constraints shape learning toward transformations that look like known fast linear maps—Fourier, cosine/sine, Hadamard—without explicitly encoding any particular task data.

### 3.2 Classic transforms emerge automatically  

The Cooley–Tukey algorithm shows that *any* discrete Fourier transform (DFT) can be expressed as a cascade of $2\times2$ rotation blocks arranged in exactly the butterfly pattern used by BOFT. By allowing each $2\times2$ block to learn its own rotation angle (via Cayley parametrisation), BOFT can reconstruct:

* The DFT,
* The discrete cosine transform,
* The Walsh–Hadamard transform,
* And many other “fast” linear operators used broadly in signal processing and computer vision.

Because these transforms are known to capture **global frequency relationships**, they serve as useful priors when adapting vision transformers or language models whose hidden representations encode such patterns implicitly.

### 3.3 Why this bias helps generalisation  

Empirically—see Table 4 in the paper—BOFT outperforms state-of-the-art PEFT methods on tasks ranging from image classification with Vision Transformers to instruction tuning large language models. The authors argue:

* The butterfly subspace is *larger* than block‑diagonal space but still *smaller* than unrestricted $\mathrm O(d)$; this middle ground yields enough capacity while preventing overfitting.
* Structured sparsity introduces an implicit regulariser akin to what happens in dropout or weight decay—but without sacrificing expressiveness.
* Since classic transforms have excellent numerical properties (e.g., unitary energy preservation), they naturally enforce well‑behaved parameter updates across layers.

All these points make BOFT’s hypothesis class well‑suited for downstream tasks that require subtle adjustments rather than wholesale rewiring—a sweet spot for high‑capacity foundation models where preserving core knowledge matters most.

## 4 Putting It All Together – Why Does BOFT Generalise?

| Aspect | What BOFT Does | Why It Helps Generalisation |
|--------|----------------|-----------------------------|
| **Expressivity** | Uses products of sparse butterfly matrices → dense orthogonal transformation with $\mathcal O(d\,\log d)$ trainable params | Can approximate any orthogonal map while still being far smaller than full dense parametrisation → richer adaptation space than block‑diagonal OFT |
| **Spectral Norm Preservation** | Orthogonal left-multiplication leaves singular values untouched | Guarantees stable gradient magnitudes and consistent Lipschitz constants → smoother optimisation and reduced risk of overfitting |
| **Inductive Bias** | Butterfly pattern mirrors fast linear transforms (FFT, Hadamard…) | Implicitly steers learning toward globally coherent operations that align with natural data structures → better out‑of‑distribution performance |

Because these three effects reinforce one another—more expressive yet structured transformations that stay numerically well‑behaved—BOFA successfully bridges the gap between *full finetuning*, which often overfits despite maximal capacity, and *tiny low‑rank adapters*, which sometimes lack sufficient flexibility for challenging domains.

---

## 5 Final Thoughts & Outlook

BOFT demonstrates how classic algorithmic ideas—here, Cooley–Tukey’s butterfly network—can enrich modern deep learning pipelines far beyond their original domain. By interpreting anorthogonal finetuning operation as an information‑transmission problem on a grid graph, we discover an elegant parameterisation that simultaneously reduces storage costs (\(\mathcal O(d\,log d)\)), respects geometric invariants (spectral norms), and injects useful inductive biases derived from decades‑old signal processing theory.

Open questions remain:

* Can other network topologies from computer networking improve upon butterflies?
* How does training runtime scale when many butterfly components are chained?
* Might adaptive depth or variable block sizes further sharpen the tradeoff between expressivity and regularity?

Nevertheless, current experiments across vision transformers, large language models, and text‐to‐image diffusion systems already showcase BOFT’s practical impact: ***better performance under tighter parameter budgets***—a compelling recipe for anyone looking to adapt today’s gigantic foundation models responsibly and effectively.
