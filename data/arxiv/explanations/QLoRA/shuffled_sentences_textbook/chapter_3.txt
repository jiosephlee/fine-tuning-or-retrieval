However, block-wise quantization introduces its own trade-offs. First, the scale $c$ determines the dynamic range used by the low-bit representation: a larger $c$ means the original tensor is multiplied by a larger factor before rounding, so the same low-bit bin covers a smaller region of the original value space. If a single element in a tensor has unusually large magnitude, then selecting a scale based on the absolute maximum maps that outlier to the boundary of the low-bit range and compresses the remaining values into a tiny subset of available bins. When a weight tensor stored in NF4 is needed for computation, it is dequantized (via the stored quantized tensor and its quantization constants) into BF16 and the subsequent forward and backward passes use BF16 arithmetic. This shows that design of the low-bit data type matters: an information-theoretically motivated NF4 can reduce quantization error sufficiently to make 4-bit storage practical for finetuning workflows. Nonetheless, computing $\frac{\partial E}{\partial \mathbf{L}_i}$ requires computing derivatives through the linear operations that involve the base weights, and therefore requires the dequantized values and BF16 arithmetic. To compute those derivatives accurately, QLoRA dequantizes the stored 4-bit weights into BF16 at the time of forward / backward computation, performs the arithmetic in BF16, and backpropagates gradients into the adapter parameters only. This system-level mitigation prevents out-of-memory errors when processing rare long sequences or large batches, enabling single-GPU finetuning of much larger base models than would otherwise be possible. Thus, storage efficiency is decoupled from compute precision: memory footprint is reduced by storing the model in 4-bit, but numerical stability and the precision of linear algebra is maintained by computing in 16-bit. Beyond these empirical conclusions, the underlying principle is straightforward: more aggressive bit reduction increases quantization error and therefore the potential for degraded performance, but careful algorithmic choices (block-wise quantization, NF4 that matches the empirical distribution of weights, and finetuning only lightweight adapters in higher precision) enable recovery of the original model's utility while taking advantage of the memory savings.
