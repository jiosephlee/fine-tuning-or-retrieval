Two key empirical findings are reported:

Because the weights share a predictable shape (normal, centered at zero) but differ in scale across tensors or blocks, we can exploit this property: rather than estimate quantiles separately for every block, we can design a quantization data type whose bin centers or representable values are optimal for a standard normal distribution, and then adapt each block by scaling (normalizing) its values into the range expected by the NFk datatype. This avoids expensive per-block quantile estimation and makes a theoretically principled choice for low-bit representation when the underlying distribution is approximately Gaussian.

Pretrained neural network weight tensors—especially large language model weights—tend to show a characteristic empirical shape: they are approximately zero-centered and well modeled by a Normal distribution. This arises from common initialization schemes, symmetry-breaking during training, and the centralizing effect of many gradient updates. The paper points out that weight distributions are "usually zero-centered normal distributions with standard deviation $\sigma$" (and refers to an appendix for further empirical evidence). The important operational implication is that most weight values cluster around zero and their distribution across a tensor is predictable up to a scale (standard deviation).

1. Estimate the $2^k+1$ quantiles for the theoretical distribution $N(0,1)$, which gives the boundaries (and midpoints) needed for a $k$-bit quantile-type data type.
2. Normalize the resulting data type values into the fixed range $[-1,1]$ so the data type has a canonical numeric range.
3. Quantize each input weight tensor by rescaling the tensor into $[-1,1]$ (through an absolute-maximum rescaling per block) and then mapping tensor values to the nearest representable NFk value.

The NFk construction handles this by using an asymmetric binning trick to guarantee a discrete zeropoint at zero while still using the full $2^k$ available states. Concretely, the paper describes estimating quantiles separately for the negative side and the positive side: use $2^{k-1}$ bins for the negative part and $2^{k-1}+1$ bins for the positive part (or vice versa), compute the midpoints for both sides, then unify the two sets and remove the duplicate zero that would appear in both sets. The result is a $k$-bit data type that (a) keeps the equal-expected-occupancy property for a standard-normal-shaped distribution up to minor asymmetry, and (b) has an exact representable zero value. The paper calls the resulting data type k-bit NormalFloat (NFk). The exact numeric table for NF4 is provided in the paper’s appendix (the paper notes these exact values can be found in Appendix).

In addition, the NF4 approach carries practical advantages. Because NF4’s representable values are precomputed from the analytic quantiles of $N(0,1)$, one does not need expensive per-block quantile estimation. Combined with block-wise rescaling (e.g., blocksize of 64 as used in the paper for precision), NF4 is straightforward to implement and computationally efficient while yielding better accuracy than alternative 4-bit datatypes.

NF4 is a principled 4-bit quantization data type tailored to the empirical reality that pretrained neural network weights are approximately zero-centered and normally distributed up to scale. By constructing the discrete representable values from the midpoints of equal-probability quantile intervals of a standard normal distribution and then normalizing to a canonical range, NF4 realizes the information-theoretically optimal quantile discretization for normally distributed inputs. Practical considerations—such as guaranteeing an exact zero by asymmetric binning and avoiding repeated expensive quantile estimation by using theoretical quantiles—make NF4 both usable and effective.

Quantile quantization is a class of discretization methods that, instead of assigning quantization bin boundaries by uniform spacing in value or by minimizing squared error globally, places bin boundaries so that each bin is expected to receive the same number of values. Concretely, given an input distribution (or an empirical distribution estimated from data), quantile quantization uses the distribution's quantile function to choose thresholds so that each of the $2^k$ discrete states of a $k$-bit datatype covers an equal probability mass. Because each bin carries the same expected probability mass, quantile quantization is information-theoretically optimal for minimizing the expected codification loss under the chosen distribution: no other partition of the value range into $2^k$ bins can give more equal occupancy and therefore, in expectation, less representational waste for that fixed distribution.

The paper gives an explicit formula for the data type’s representative values (the midpoints of quantile segments). For the $i$-th representative value of a $k$-bit NF data type, one can compute
\[ q_i = \frac{1}{2}\Big( Q_X\!\big(\tfrac{i}{2^k+1}\big) + Q_X\!\big(\tfrac{i+1}{2^k+1}\big) \Big), \]
where $Q_X(\cdot)$ is the quantile function (inverse CDF) of the standard normal distribution $N(0,1)$. Intuitively, $q_i$ is the midpoint of the $i$-th quantile interval of the standard normal; using these midpoints as the discrete representable values yields equal-probability bins for standard-normal inputs.

In practice, quantile quantization is implemented by estimating quantiles from the data's empirical cumulative distribution function (CDF). For a general tensor this requires computing or approximating $2^k$ quantiles, which can be computationally expensive. Approximate algorithms (e.g., SRAM quantiles referenced in the paper) can be used, but their approximations can introduce errors, particularly in the presence of outliers, which may harm quantization fidelity.

Given that the optimal quantile bin centers for a standard normal are known analytically (via the inverse CDF or quantile function), NFk constructs its representable values by precomputing these quantiles. The paper outlines the three-step approach to construct and use NFk:

A subtle but important practical issue is that some quantile-based symmetric discretizations do not have an exact representable zero. For many tensors (padding tensors, masked regions, or naturally sparse parts of a tensor), representing exact zeros without quantization error is desirable. If the symmetric quantile partition allocates bins symmetrically around zero, the midpoints of the central negative and central positive bins may surround zero but not exactly equal it, so exact zeros are not representable.

2. Double Quantization (the paper’s complementary technique that quantizes quantization constants) reduces memory footprint without degrading performance when used together with NF4. The experiments reported in the paper show that applying double quantization to NF4 does not harm the language-model metrics, meaning the memory savings can be obtained without a measurable penalty in the tasks they tested.

This asymmetric construction preserves the main benefit of quantile-based binning for normal data while solving the practical problem of exact-zero representation.

NF4 (NormalFloat with 4 bits) leverages the information-theoretic idea of quantile quantization but ties it to a specific assumed distribution: the standard normal $N(0,1)$. By building the $k$-bit data type from the theoretical quantiles of $N(0,1)$, NFk becomes the quantile-optimal discrete data type for any tensor whose (normalized) distribution is standard normal. This gives two advantages: (1) exact quantile values are available analytically (no expensive empirical quantile estimation), and (2) the data type is optimal (in the quantile sense) for normally distributed inputs.

Chapter 6: NormalFloat (NF4): Information-Theoretically Optimal 4-bit Weights

The paper reports empirical comparisons of NF4 against other 4-bit data types, specifically 4-bit floating point (FP4) and 4-bit integer (Int4), across a range of large language model families and sizes (OPT, LLaMA, BLOOM, Pythia) spanning model sizes from 125M up to multi-billion parameter models. These comparisons evaluate both language-modeling performance (e.g., perplexity) and zero-shot task accuracy, following the evaluation setup used in prior quantization studies.

1. NF4 yields consistently better empirical performance than FP4 and Int4. The paper states that NF4 "improves performance significantly over FP4 and Int4" in the evaluated scenarios. This improvement is aligned with the expected advantage of using a quantization data type tailored to the observed weight distribution: since pretrained weights are approximately normal, a quantile-optimal data type derived from $N(0,1)$ minimizes quantization error for the common region around zero where most weight mass lies.

Beyond reporting that NF4 outperforms FP4/Int4, the paper connects the empirical results to the underlying theory: FP4 is designed for floating dynamic range and Int4 for uniform integer bins; neither of these choices matches a normal-shaped, zero-centered distribution as well as a quantile-type discretization derived from the Gaussian. NF4’s design therefore produces lower expected quantization distortion for these tensors, which translates to better empirical downstream performance.

Empirically, NF4 closes the gap that other 4-bit formats leave with respect to 16-bit behavior: across language-model families and sizes, NF4 yields better perplexity and zero-shot task accuracy than FP4 and Int4, and when combined with the paper’s other techniques (double quantization and appropriate blocking) it enables highly memory-efficient storage of large pretrained models with minimal or no loss in downstream finetuning performance.

Matching the tensor’s scale to the data type’s canonical range $[-1,1]$ is equivalent to rescaling the tensor so its effective standard deviation aligns with the standard normal quantiles used to produce $q_i$. In implementation, this is typically done by block-wise absolute-maximum rescaling: divide the block by its absolute maximum to map its values into $[-1,1]$, then quantize to the nearest NFk representable value.
