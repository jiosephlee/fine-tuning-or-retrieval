According to the paper 'QLoRA: Efficient Finetuning of Quantized LLMs', if $3$-bit base quantization plus LoRA worked as hypothesized, the most likely resource outcome would be a smaller memory footprint. The paper shows that the dominant contributor to finetuning memory, aside from transient activation gradients, is the storage of the frozen base model weights, which QLoRA compresses from 16-bit to 4-bit while preserving performance. Because storage cost scales linearly with bit width, moving from $4$-bit to $3$-bit reduces the per-parameter weight storage by $25\\%$. With Double Quantization, the overhead for quantization constants is already small (for 4-bit: $8/64 + 32/(64\\cdot 256) = 0.127$ bits per parameter), so the total bits per parameter would drop from approximately $4.127$ to roughly $3.127$ when switching to 3-bit, yielding a net reduction of about $\\frac{4.127 - 3.127}{4.127} \\approx 24\\%$ in base-model storage. Since QLoRA dequantizes to a 16-bit compute type only at use time, the lower storage precision directly translates to less resident GPU memory pressure, especially for large models.

Moreover, the paper emphasizes that LoRA adapters contribute only a tiny fraction of memory relative to base weights and activation gradients (e.g., for a 7B model, LoRA parameters are $\\approx 26\\,\\text{MB}$ versus $\\approx 5{,}048\\,\\text{MB}$ for the 4-bit base model). Thus, if 3-bit quantization maintains fidelity after LoRA finetuning—as hypothesized in the discussion—overall GPU memory would primarily be governed by the reduced weight storage. Using the paper’s numbers, a back-of-the-envelope extrapolation suggests that a 7B base model would drop from about $\\approx 5.05\\,\\text{GB}$ at 4-bit to $\\approx 5.05\\times \\frac{3}{4} \\approx 3.79\\,\\text{GB}$ at 3-bit, with similar proportional savings at 33B and 65B scales. Since paged optimizers address occasional activation-related spikes and adapter gradients are already small (and further mitigated by gradient checkpointing), the most likely resource outcome of successful 3-bit-plus-LoRA finetuning would indeed be a smaller overall memory footprint.
