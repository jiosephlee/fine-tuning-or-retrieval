According to the paper 'QLoRA: Efficient Finetuning of Quantized LLMs', when relying on paged optimizers, if long sequence mini-batches occur frequently rather than rarely, you should expect noticeable slowdowns. This follows from how paged optimizers leverage NVIDIA unified memory: when gradient checkpointing creates transient spikes in memory demand, optimizer state is automatically evicted to CPU RAM and later paged back to the GPU during updates, which entails repeated page migrations over relatively slow interconnects and page-fault handling; the authors report matching the speed of regular optimizers only in a regime where such paging “occurs when processing mini-batches with long sequence lengths, which is rare,” and explicitly note that future work should characterize when slow-downs arise, implying that if these long-sequence events—and thus paging—happen often, the cumulative overhead of frequent CPU–GPU transfers will dominate and reduce throughput.
