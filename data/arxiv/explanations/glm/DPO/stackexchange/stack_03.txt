\title{Stack Exchange of the Paper: "Direct Preference Optimization: Your Language Model is Secretly a Reward Model"}

### What exactly is the 'implicit reward model' in DPO and how can a policy represent a reward?
Question:
The paper defines an implicit reward as $\hat{r}_\theta(x, y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)}$ and says "the policy network represents both the language model and the (implicit) reward." In standard RLHF, the reward model is a separate neural network that takes $(x, y)$ and outputs a scalar reward. In DPO, is the reward just defined as the log-ratio between the current policy and a reference policy? If so, how can this simple log-ratio be equivalent to a learned reward model that could have arbitrary complexity? What is the intuition for why this parameterization is sufficient?
Answer:
The key to understanding DPO's implicit reward model is recognizing that in the preference learning framework, reward functions are only identified up to an equivalence class, and the log-ratio parameterization captures every such class without loss of generality.

**Where the log-ratio comes from**

The derivation starts from the standard RLHF objective, which maximizes expected reward subject to a KL-divergence constraint from a reference policy $\pi_{\text{ref}}$. As shown in Eq. 5 of the paper, the optimal policy for a given reward function $r(x,y)$ takes the form:

$$\pi_r(y \mid x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x,y)\right)$$

where $Z(x) = \sum_y \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x,y)\right)$ is a partition function. Rearranging this relationship (Eq. 6) yields:

$$r(x,y) = \beta \log \frac{\pi_r(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)$$

So the implicit reward $\hat{r}_\theta(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$ is exactly the first term, with the $\beta \log Z(x)$ term dropped.

**Why dropping $\beta \log Z(x)$ is harmless**

The paper defines an equivalence relation on reward functions: $r$ and $r'$ are equivalent if $r(x,y) - r'(x,y) = f(x)$ for some function $f$ that depends only on the prompt $x$, not the response $y$. Two key lemmas establish that:

1. Under the Bradley-Terry (or Plackett-Luce) preference model, rewards in the same equivalence class induce the same preference distribution. This is because the BT model depends only on the *difference* of rewards, $p^*(y_1 \succ y_2 \mid x) = \sigma(r(x,y_1) - r(x,y_2))$, so any function $f(x)$ added to both rewards cancels out.

2. Rewards in the same equivalence class also induce the same optimal policy under the KL-constrained RL objective.

Since $\beta \log Z(x)$ depends only on $x$, the reward $\hat{r}_\theta(x,y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$ is in the same equivalence class as the "full" reward $r(x,y) = \beta \log \frac{\pi_r(y \mid x)}{\pi_{\text{ref}}(y \mid x)} + \beta \log Z(x)$. Therefore, it produces identical preference predictions and identical optimal policies.

**Why this parameterization is fully general**

Theorem 1 in the paper proves that *every* reward class consistent with the Plackett-Luce/BT framework can be represented in the form $r(x,y) = \beta \log \frac{\pi(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$ for some policy $\pi$. The proof constructs an explicit projection: given any reward $r$, one can normalize it by subtracting $\beta \log Z(x)$ (where $Z$ is the partition function of $r$'s optimal policy), and the result has exactly the log-ratio form while remaining in $r$'s equivalence class.

The intuition is that the log-ratio parameterization simply selects a particular representative from each equivalence class — specifically, the one whose partition function equals $1$ (Eq. 11), ensuring $\pi(y \mid x)$ is a properly normalized distribution. Since the equivalence class structure means we never need to distinguish between rewards within a class, selecting one representative per class is sufficient.

**Why a "simple" log-ratio can match a complex learned reward model**

The log-ratio $\beta \log \frac{\pi_\theta(y \mid x)}{\pi_{\text{ref}}(y \mid x)}$ is not simple in the sense that matters. The policy $\pi_\theta$ is a large neural network (e.g., a 6B-parameter transformer), so $\log \pi_\theta(y \mid x)$ is a highly expressive function of $(x, y)$. The log-ratio inherits all of this complexity. The reference policy $\pi_{\text{ref}}$ is fixed, so the expressive power of $\hat{r}_\theta$ is essentially that of $\pi_\theta$ itself.

The crucial difference from standard RLHF is not in the *capacity* of the reward representation but in the *training procedure*. Standard RLHF trains a separate reward model $r_\phi$ with a dedicated loss (Eq. 3), then uses RL to find the policy that maximizes it. DPO observes that once you commit to the log-ratio parameterization, you can substitute the reward directly into the Bradley-Terry likelihood and optimize the policy parameters $\theta$ with a simple cross-entropy loss (Eq. 8), skipping both the explicit reward modeling and the RL loop entirely. The policy and the implicit reward are two views of the same object, linked by the closed-form solution to the KL-constrained optimization problem.
