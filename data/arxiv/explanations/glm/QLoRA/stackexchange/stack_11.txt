\title{Stack Exchange of the Paper: "QLoRA: Efficient Finetuning of Quantized LLMs"}

### How does the empirical CDF-based quantile estimation avoid approximation errors for NF4?
Question:
The paper mentions that quantile quantization normally requires expensive quantile estimation, and that fast approximation algorithms like SRAM quantiles have "large quantization errors for outliers." But then it says these errors can be avoided "when input tensors come from a distribution fixed up to a quantization constant" because "input tensors have the same quantiles making exact quantile estimation computationally feasible." I'm confused: if we're assuming weights follow $N(0, \sigma)$, aren't we using the theoretical quantile function of $N(0,1)$ rather than estimating quantiles from the data? If so, why does the paper mention the empirical CDF at all? And how does normalizing by the absolute maximum ensure the weight distribution fits exactly into $[-1, 1]$?
Answer:
The mention of the empirical CDF in the paper serves to contrast the **general** quantile quantization approach with the **specific** improvement that NF4 makes. In the general case (from prior work by Dettmers et al., 2022), you do not know the distribution of the input tensor, so you must estimate its quantiles empirically from the data itself. This is computationally expensive, which is why approximation algorithms like SRAM quantiles were introduced—but these introduce errors, especially for outliers. The paper mentions the empirical CDF to explain the limitation that NF4 is designed to overcome.

NF4's key insight is that when you *know* the input distribution is $N(0, \sigma)$ for some unknown $\sigma$, you no longer need to estimate quantiles from data at all. Instead, you can use the **theoretical quantile function** $Q_X(\cdot)$ of the standard normal $N(0,1)$, as shown in Equation 4:

$$q_i = \frac{1}{2}\left( Q_X\left(\frac{i}{2^k+1}\right) + Q_X\left(\frac{i+1}{2^k+1}\right)\right)$$

This is "exact" in the sense that the quantile boundaries are computed from the known inverse CDF of $N(0,1)$ rather than estimated from finite samples. There is no approximation error from quantile *estimation*—the only remaining error is the quantization error inherent in mapping continuous values to discrete bins, which is unavoidable and in fact information-theoretically optimal for this distribution.

The reason this works is that dividing a $N(0, \sigma)$ tensor by its absolute maximum effectively cancels out $\sigma$. For each block of size 64, the absmax value scales proportionally with $\sigma$, so the normalized values $w / \text{absmax}(\mathbf{W})$ all follow the same distribution regardless of the original $\sigma$. Since every block, after normalization, follows the same distribution, they all share the same quantiles—which are exactly the quantiles of $N(0,1)$ truncated to $[-1, 1]$. This is what the paper means by "input tensors have the same quantiles making exact quantile estimation computationally feasible."

As for how absmax normalization ensures the distribution "fits exactly" into $[-1, 1]$: by dividing every element by the absolute maximum of the block, the largest-magnitude value maps to exactly $1$ (or $-1$), so the full range of normalized values is precisely $[-1, 1]$ by construction. The NF4 data type is precomputed to span this same range, with its quantile boundaries derived from $N(0,1)$ and then rescaled to $[-1, 1]$. When the weight tensor is similarly rescaled to $[-1, 1]$, the quantization bins of NF4 align with the quantiles of the normalized weight distribution, ensuring each bin receives an equal expected number of values—making the quantization information-theoretically optimal.

In short, the empirical CDF is mentioned to describe the problem NF4 solves. NF4 replaces empirical quantile estimation with the known theoretical quantile function of $N(0,1)$, and absmax normalization is the mechanism that aligns each weight block's distribution with that fixed data type.
