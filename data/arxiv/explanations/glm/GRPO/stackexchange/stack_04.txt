\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### How do SFT, RFT, DPO, PPO, and GRPO map to the unified paradigm gradient formula?
Question:
The DeepSeekMath paper introduces a 'unified paradigm' where all training methods can be written as:
$$\nabla_{\theta}\mathcal{J}_{\mathcal{A}}(\theta) = \mathbb{E}[(q,o) \sim \mathcal{D}]\left(\frac{1}{|o|}\sum_{t=1}^{|o|} GC_{\mathcal{A}}(q, o, t, \pi_{rf}) \nabla_{\theta}\log \pi_{\theta}(o_t | q, o_{<t})\right)$$

The paper mentions three key components: Data Source $\mathcal{D}$, Reward Function $\pi_{rf}$, and Algorithm $\mathcal{A}$ which determines the gradient coefficient $GC$. The paper says these methods are 'conceptualized as either direct or simplified RL techniques' but the detailed derivation is in an appendix I don't have access to.

Could someone explain how SFT, RFT, DPO, PPO, and GRPO each map to this formula? Specifically, what is $GC_{\mathcal{A}}$ for each method, and what are the data sources? For instance, for SFT, I would guess $GC = 1$ since every token is reinforced equally, but I'm not sure about the others.
Answer:
The unified paradigm in the DeepSeekMath paper provides an elegant way to see that SFT, RFT, DPO, Online RFT, PPO, and GRPO all share the same fundamental structure: they compute a gradient that is a weighted sum of per-token log-probability gradients, where the weight (gradient coefficient $GC$) is what distinguishes each method. The three components—Data Source $\mathcal{D}$, Reward Function $\pi_{rf}$, and Algorithm $\mathcal{A}$—together determine this coefficient.

**Supervised Fine-Tuning (SFT)**

Your intuition is correct. For SFT, the data source $\mathcal{D}$ consists of pre-existing human-annotated question-solution pairs (offline data). There is no explicit reward function—all tokens are treated equally. The gradient coefficient is simply $GC_{\text{SFT}} = 1$ for every token, meaning every token in every training example receives uniform reinforcement. This is the simplest case: the model is just doing maximum likelihood estimation on the provided data.

**Rejection Sampling Fine-Tuning (RFT)**

RFT samples outputs from the initial SFT model (offline data source), then filters them using a rule-based reward function (correctness of the final answer). Only outputs with correct answers are retained for fine-tuning. The gradient coefficient is $GC_{\text{RFT}} = 1$ for tokens in correct outputs and $GC_{\text{RFT}} = 0$ for incorrect outputs—which, practically speaking, means incorrect outputs are simply filtered out of the dataset before training. So RFT is essentially SFT on a filtered subset of model-generated data. The reward signal only affects which data is included, not the magnitude of the gradient.

**Online RFT**

Online RFT follows the same algorithm as RFT (uniform reinforcement, no penalization) but switches to an online data source: outputs are sampled from the real-time policy model rather than the frozen SFT model. The gradient coefficient is the same as RFT—$GC_{\text{Online RFT}} = 1$ for correct responses and $GC_{\text{Online RFT}} = 0$ for incorrect responses. The paper emphasizes that Online RFT "does not penalize incorrect responses and uniformly reinforces all responses with correct answers at the same level of intensity," which is a key contrast with GRPO.

**Direct Preference Optimization (DPO)**

DPO uses offline data (pairs of outputs sampled from the SFT model) with a rule-based reward function that determines pairwise preferences (typically based on correctness). The data source consists of preference pairs $(o_w, o_l)$ where $o_w$ is the preferred (correct) output and $o_l$ is the dispreferred (incorrect) output. The gradient coefficient involves the DPO loss sigmoid: for the preferred output, $GC_{\text{DPO},w} = \beta \cdot \sigma(-s)$ and for the dispreferred output, $GC_{\text{DPO},l} = -\beta \cdot \sigma(-s)$, where $s = \beta\left[\log\frac{\pi_\theta(o_w|q)}{\pi_{ref}(o_w|q)} - \log\frac{\pi_\theta(o_l|q)}{\pi_{ref}(o_l|q)}\right]$ and $\sigma$ is the sigmoid function. Unlike RFT, DPO does penalize the dispreferred output (negative gradient coefficient), but the magnitude of reinforcement/penalization is the same for all tokens within a given output—it does not vary per token based on reward magnitude.

**PPO**

PPO uses an online data source (outputs from the real-time policy) and typically a model-based reward function (a trained reward model). The gradient coefficient is the advantage $A_t$ computed via Generalized Advantage Estimation (GAE), which requires a separately trained value function $V_\psi$. The coefficient varies per token: $GC_{\text{PPO}}(q, o, t) \propto A_t$, where $A_t$ incorporates both the immediate reward and estimated future returns. PPO also includes a clipping mechanism on the probability ratio $\frac{\pi_\theta}{\pi_{\theta_{old}}}$ for stabilization, but the core signal driving the gradient is the advantage.

**GRPO**

GRPO also uses an online data source and a model-based (or rule-based) reward function, but it eliminates the value function. Instead, it samples a group of $G$ outputs for each question, computes their rewards, and normalizes them within the group. For outcome supervision, the advantage is $\hat{A}_{i,t} = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$, which is the same for all tokens in output $o_i$. For process supervision, the advantage at token $t$ is $\hat{A}_{i,t} = \sum_{\text{index}(j) \ge t} \tilde{r}_i^{\text{index}(j)}$, accumulating normalized step-level rewards from the current token onward. The gradient coefficient is $GC_{\text{GRPO}} \propto \hat{A}_{i,t}$, plus a KL regularization term. The crucial difference from Online RFT is that GRPO's gradient coefficient varies in magnitude based on the reward value: outputs that score well above the group average receive strong positive reinforcement, outputs that score poorly receive negative penalization, and the degree scales with how much better or worse the output is relative to its peers.

The key insight from the unified paradigm is that these methods form a progression: SFT uses no reward signal at all; RFT and Online RFT use a binary reward (correct/incorrect) but only reinforce, never penalize; DPO introduces pairwise penalization but with uniform magnitude per output; and PPO/GRPO use continuous, per-token-varying gradient coefficients that both reinforce and penalize based on relative reward magnitude. The paper's experiments show that moving along this progression—from offline to online data, and from binary to continuous gradient coefficients—yields progressively better performance, with GRPO achieving the strongest results.
