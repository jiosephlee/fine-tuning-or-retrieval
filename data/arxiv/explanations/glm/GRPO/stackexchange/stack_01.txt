\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### How does GRPO replace the value function with group statistics without losing variance reduction?
Question:
In the DeepSeekMath paper, GRPO is introduced as a variant of PPO that eliminates the critic/value function. Instead, it uses the average reward of multiple sampled outputs for the same question as a baseline. In PPO, the value function $V_{\psi}$ is used for variance reduction via Generalized Advantage Estimation (GAE). The paper claims that GRPO 'estimates the baseline from group scores.' However, I'm confused about why this is sufficient. In PPO, the value function predicts a state-dependent expected return, which adapts to the difficulty of each question. If GRPO just normalizes rewards within a group by subtracting the mean and dividing by std, does it not lose the per-question adaptivity that the value function provides? Is the variance reduction from group normalization comparable to that of a learned value function?
Answer:
The key insight is that GRPO's group statistics do provide per-question adaptivity, because the baseline is computed separately for each question's group of sampled outputs. When GRPO samples $G$ outputs $\{o_1, \ldots, o_G\}$ for a question $q$ and computes the advantage as $\hat{A}_{i,t} = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$, the group mean $\text{mean}(\mathbf{r})$ serves as an empirical estimate of the expected reward for that specific question. This is directly analogous to what the value function $V_\psi(q)$ estimates in PPO—the expected return conditioned on the question. A hard question will naturally produce a group with lower average rewards, so subtracting the group mean centers the advantages around zero for that question, just as subtracting $V_\psi$ would. An easy question will have a higher group mean, and the same subtraction applies. The per-question adaptivity is therefore preserved because each group is question-specific.

What GRPO does sacrifice is per-token adaptivity of the baseline. In PPO with GAE, the value function $V_\psi(q, o_{<t})$ provides a different baseline at each token position, reflecting the evolving expected return as the partial output develops. In GRPO with outcome supervision, the same advantage $\tilde{r}_i$ is assigned to all tokens in output $o_i$. However, the paper notes an important practical consideration: in the LLM setting, rewards are typically only assigned at the end of the sequence by the reward model, which "may complicate the training of a value function that is accurate at each token." Since the per-token reward signal is sparse (only the last token gets a reward), training a reliable per-token value function is itself problematic. GRPO sidesteps this difficulty entirely.

For process supervision, GRPO does provide step-level rewards, computing advantages as $\hat{A}_{i,t} = \sum_{\text{index}(j) \geq t} \tilde{r}_i^{\text{index}(j)}$, which introduces some per-position differentiation based on the quality of reasoning steps—a middle ground between the full per-token value function of PPO and the single-reward outcome supervision.

The variance reduction from group normalization is comparable to a learned value function in an important sense: both reduce variance by removing the question-dependent component of the reward. The group mean is an unbiased, Monte Carlo estimate of $V(q)$, whereas the learned $V_\psi$ is a biased (but potentially lower-variance) estimate. With a sufficiently large group size (the paper uses $G = 64$), the empirical mean provides a stable and accurate baseline. The additional division by the group standard deviation provides a form of adaptive scaling that PPO does not explicitly perform—normalizing advantages across questions of varying difficulty so that hard questions (with high reward variance) and easy questions (with low reward variance) contribute comparably to the gradient.

The paper also notes that the group-relative approach "aligns well with the comparative nature of reward models, as reward models are typically trained on datasets of comparisons between outputs on the same question." This is a conceptual advantage: since reward models are trained to make relative comparisons rather than absolute assessments, using group-relative advantages leverages exactly the kind of signal the reward model was trained to produce.

In summary, GRPO retains per-question adaptivity through group-specific baselines, loses per-token value estimates in the outcome-supervision setting (but this is arguably a feature given the sparsity of per-token rewards in LLM RL), and achieves variance reduction comparable to PPO through empirical group statistics rather than a learned value function—at the cost of requiring $G$ forward passes per question but saving the memory and compute of training a separate value model of comparable size to the policy.
