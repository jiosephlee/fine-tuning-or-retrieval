\title{A Textbook about the Paper: "LongRoPE: Extending LLM Context Window Beyond 2 Million Tokens"}

Chapter 6: Experimental Evaluation and Results

# Evaluation Setup: Models, Fine-Tuning, and Baselines

The experimental validation of LongRoPE is designed to rigorously assess whether the method can truly extend the context window of pre-trained large language models (LLMs) to an unprecedented 2048k tokens while preserving performance on shorter sequences. To this end, the authors apply LongRoPE to two well-known open-source LLMs: LLaMA2-7B and Mistral-7B. These models are chosen because they both rely on Rotary Position Embedding (RoPE), which is the positional encoding scheme that LongRoPE modifies. By testing on two different architectures, the authors can demonstrate that LongRoPE is not specific to a single model family but is broadly applicable to any RoPE-based LLM. Both models originally have relatively short context windows — LLaMA2 has a 4096-token limit, and Mistral also operates within a comparable range — making them ideal candidates for testing dramatic context window extensions.

The fine-tuning procedure differs slightly between the two models, reflecting their distinct training characteristics and the authors' desire to build upon established practices in the literature. For LLaMA2, the fine-tuning uses a learning rate of $2 \times 10^{-5}$ with linear decay and a global batch size of 32. The training data comes from the RedPajama dataset, which is chunked into 128k-token segments, each bookended with beginning-of-sequence (BOS) and end-of-sequence (EOS) tokens. The fine-tuning is performed in two stages: first, 400 steps are completed to reach a 128k context window, and then, starting from the checkpoint produced after those 400 steps, an additional 600 steps are conducted with the RoPE rescale factors updated to target 256k. This two-stage approach proves more effective than directly fine-tuning to 256k in one shot. The 128k training requires 8 A100 GPUs using a distributed training system, while the 256k stage requires 16 A100 GPUs, reflecting the increased memory and computational demands of longer sequences.

For Mistral, the authors follow the fine-tuning setup established by YaRN, a prior context extension method. Specifically, a constant learning rate of $1 \times 10^{-6}$ and a global batch size of 64 are used. Both the 128k and 256k models are trained for 400 steps on the Together Computer's Long-Data Collections using a 16k sequence length. This setup uses 4 A100 GPUs. The choice to use a 16k training length — significantly shorter than the target context windows — is inherited from YaRN's protocol and has important implications for the results, as we will discuss later in the chapter.

The search for optimal RoPE rescale factors is a critical component of LongRoPE, and its configuration is tailored to the target context window size. For target window sizes up to 256k, the evolutionary search uses a population size $P = 64$, a mutation size $N_1 = 16$, a crossover size $N_2 = 16$, a mutation probability $p = 0.3$, and a maximum of $\mathcal{T} = 40$ iterations. In each iteration, the top-32 individuals (those with the lowest perplexity) are selected as parents for mutation and crossover. The perplexity that guides the search is calculated using 5 random samples from the PG19 validation set, with each sample required to be at least as long as the target context length. For context windows exceeding 512k, the population, mutation, and crossover sizes are halved to manage computational costs, and perplexity is measured on 3 random samples from the Pile-Books3 validation set instead.

The baselines against which LongRoPE is compared represent the state of the art in context window extension. Because reaching 2048k requires fine-tuned models with intermediate context windows, the authors produce two variants: LongRoPE-2048k (ft=128k), which is fine-tuned to 128k before the second search extends it to 2048k, and LongRoPE-2048k (ft=256k), which is fine-tuned to 256k before the second search. These are compared against several open-sourced LLMs that have been fine-tuned after applying other positional interpolation methods, including PI (Position Interpolation), NTK, and YaRN. The specific baselines include Together-32k, Code LLaMA, LongLoRA-full-FT-100k, YaRN-LLaMA, and YaRN-Mistral. This diverse set of baselines ensures that LongRoPE is evaluated against the best available alternatives across different extension ratios and model families.

# Performance on Long Sequence Language Modeling Within 256k Evaluation Lengths

The first major set of results evaluates how well LongRoPE-extended models perform on long sequence language modeling tasks within a 256k evaluation length. This evaluation serves as a foundational test: if a model's context window has been genuinely extended, it should be able to leverage longer context to produce better predictions, which manifests as decreasing perplexity as the evaluation length increases. Perplexity, for those unfamiliar, is a standard measure of language model quality that quantifies how well a model predicts the next token in a sequence; lower perplexity indicates better predictive performance. The authors use a sliding window of 256 tokens for evaluation, which means perplexity is computed over windows of 256 tokens that slide across the document, allowing assessment at various context lengths.

Two datasets are used to demonstrate the generalizability of the results: Proof-pile and PG19. Proof-pile is a dataset of mathematical and scientific texts, while PG19 is a collection of long literary texts from Project Gutenberg books. For PG19, the entire test split of 100 documents is used. For Proof-pile, the authors follow YaRN's protocol and randomly select 10 samples, each with at least 128k tokens in length. The use of two distinct datasets — one mathematical and one literary — helps ensure that any observed improvements are not artifacts of a particular domain.

The results on both datasets reveal two key observations. First, the LongRoPE-extended models show an overall decreasing perplexity trend from 4k to 256k evaluation lengths. This is a crucial finding because it directly demonstrates that the models can effectively utilize longer context to improve their language modeling performance. A model whose context window has not been genuinely extended would show perplexity that plateaus or increases beyond its original training length, as it would encounter out-of-distribution position indices. The decreasing perplexity trend confirms that LongRoPE successfully extends the model's effective context window well beyond its original 4k limit.

Second, even with a context window that is 16 times longer than the baselines — a condition that is typically challenging for maintaining performance at shorter lengths — the LongRoPE-2048k models outperform state-of-the-art baselines within the 256k context length. This is a particularly notable result because one might expect that a model optimized for extremely long contexts (2048k) would sacrifice performance at shorter lengths. The fact that LongRoPE-2048k models maintain superiority even at shorter lengths speaks to the effectiveness of the non-uniform positional interpolation, which preserves key information in the original RoPE embeddings rather than uniformly compressing all position information. The comparison with YaRN is especially instructive: YaRN, which also uses non-uniform interpolation but relies on human-designed grouping rules, underperforms relative to PI and NTK on PG19 in non-fine-tuned settings because it does not reach the target context window length. For example, YaRN's perplexity spikes after 7k in an 8k context size, indicating that its fixed grouping strategy is sub-optimal. LongRoPE's evolutionary search, by contrast, discovers rescale factors that are specifically optimized for each model and target length, avoiding such failure modes.

# Perplexity Evaluation on Extremely Long Sequences Beyond 2000k Tokens

While the 256k evaluation demonstrates LongRoPE's effectiveness at moderately long lengths, the true test of the method is whether it can maintain language modeling quality at extremely long context lengths — specifically, beyond 2048k tokens. This is the regime that no prior method has successfully achieved, and it presents unique challenges including attention dispersion (where attention is spread thinly across millions of token positions) and the scarcity of training data at such lengths.

To evaluate performance on extremely long documents, the authors use the Books3 dataset, which is derived from a collection of full-length books. For evaluation efficiency, 20 books are randomly selected, each exceeding 2048k tokens in length. The sliding window for evaluation is set to 256k, meaning perplexity is computed over 256k-token windows that slide across each book. This setup allows the authors to measure perplexity at various points within extremely long documents and observe how the models perform as the context length approaches and exceeds 2 million tokens.

The results on Books3 reveal that LongRoPE successfully extends both LLaMA2-7B and Mistral-7B's context windows to 2048k while achieving perplexity that is comparable to or superior to baselines within shorter lengths of 8k to 128k. This is a remarkable achievement: the LongRoPE models not only handle extremely long contexts but also remain competitive at shorter lengths, demonstrating the versatility of the approach. However, notable performance differences emerge between the 2048k LLaMA2 and Mistral models.

For LLaMA2, the performance aligns with expectations: perplexity decreases gracefully with longer contexts, with only marginal increases at 1024k and 2048k. This graceful degradation is important because it indicates that the model's language modeling quality does not catastrophically fail even at extreme lengths. Furthermore, LongRoPE-2048k performs better when fine-tuned at 256k rather than 128k. This is because the secondary extension ratio — the factor by which the context window is extended from the fine-tuned length to 2048k — is smaller when starting from 256k (i.e., $2048/256 = 8\times$) compared to starting from 128k (i.e., $2048/128 = 16\times$). A smaller secondary extension ratio means less aggressive interpolation is needed, which better preserves the positional information and results in lower perplexity.

For Mistral, the situation is more complex. Mistral outperforms baselines at shorter lengths, but its perplexity exceeds 7 beyond 256k, indicating some degradation at the longest lengths. Additionally, Mistral performs better at a fine-tuning window size of 128k rather than 256k, which is the opposite of LLaMA2's pattern. The authors attribute this to the fine-tuning protocol: for Mistral's 128k and 256k fine-tuning, the YaRN setting is followed, which uses a 16k training length. This shorter training length affects Mistral's ability to further extend its context window after fine-tuning, because the model has not been exposed to sufficiently long sequences during fine-tuning to develop robust representations for long-range dependencies. This finding underscores the importance of fine-tuning configuration: the training length, learning rate, and number of steps all interact with the positional interpolation strategy to determine the final model's performance at extreme context lengths.

# Passkey Retrieval Accuracy Across Millions of Tokens

While perplexity is a valuable metric for assessing language modeling quality, it does not directly measure a model's ability to perform specific tasks that require retrieving information from long contexts. To address this, the authors evaluate LongRoPE on a synthetic passkey retrieval task, which provides a more direct measure of the effective context window in generative tasks.

In the passkey retrieval task, a model is given a long document containing a sea of irrelevant text, within which a random five-digit passkey is hidden at some position. The model is then asked to retrieve the passkey. This task is specifically designed to test whether the model can attend to and recall information from arbitrary positions within a very long context. If a model's effective context window is genuinely 2048k tokens, it should be able to retrieve a passkey regardless of where it is placed within that window.

The evaluation procedure involves 10 iterations of the passkey retrieval task, with the passkey placed at a random location uniformly distributed across the evaluation context length. This random placement is important because it ensures that the model must be able to attend to any position within the context, not just positions near the beginning or end. The use of 10 iterations provides a reasonable estimate of the retrieval accuracy while keeping the evaluation computationally feasible.

The results of the passkey retrieval experiment are striking. Existing models — those extended using PI, NTK, or YaRN — show retrieval accuracy that rapidly drops to 0 beyond 128k. This means that these models, despite being fine-tuned for longer contexts, cannot reliably retrieve information from positions beyond approximately 128k tokens. This limitation reflects the fundamental constraints of existing positional interpolation methods: they either introduce too much information loss through uniform interpolation (as in PI) or rely on sub-optimal human-designed rules for non-uniform interpolation (as in YaRN).

In contrast, LongRoPE-LLaMA2-2048k (ft=256k) maintains a retrieval accuracy of $\geq 90\%$ from 4k all the way to 2048k. This means that even when the passkey is hidden among over 2 million tokens of irrelevant text, the model can still find it with high reliability. This is a direct demonstration that the effective context window of the model has been genuinely extended to 2048k tokens, not just that the model produces low perplexity at that length. The retrieval task requires the model to form precise attention to specific positions within the context, which is only possible if the positional embeddings at those positions are meaningful and distinguishable.

LongRoPE-Mistral-2048k (ft=128k) achieves 100% accuracy up to 1800k, dropping to 60% at 2048k. This slight degradation at the extreme end aligns with the perplexity results on Books3, where Mistral's perplexity was observed to increase beyond 256k. The 60% accuracy at 2048k, while not perfect, still represents a substantial achievement: the model can retrieve a passkey from 2 million tokens of text more than half the time, far exceeding any existing method. The difference between LLaMA2 and Mistral at 2048k again reflects the different fine-tuning configurations, with LLaMA2 benefiting from the larger fine-tuning length of 256k, which results in a smaller secondary extension ratio.

The passkey retrieval results are perhaps the most compelling evidence of LongRoPE's effectiveness because they directly measure the model's functional ability to use information from extremely long contexts. A model might achieve low perplexity on long documents simply by learning broad statistical patterns, without truly attending to specific positions. The passkey task eliminates this possibility by requiring precise retrieval from specific positions, providing a clean test of the effective context window.

# Performance on Standard LLM Benchmarks Within the Original 4096 Context Window

A critical concern when extending an LLM's context window is whether the extension degrades performance on the original, shorter context window for which the model was initially trained. This concern is well-founded: positional interpolation methods compress position embeddings into a narrower range, which can make positions within the original context window crowded and degrade the model's ability to distinguish between closely positioned tokens. With a 512$\times$ extension ratio (from 4k to 2048k), this crowding effect becomes particularly severe, as positions that were originally spread across the full range of RoPE angles are compressed into a tiny fraction of that range.

To assess whether LongRoPE suffers from this degradation, the authors evaluate the LongRoPE-2048k models on the Hugging Face Open LLM Leaderboard, which comprises standard LLM benchmarks designed for evaluation within short context windows. These benchmarks include 25-shot ARC-Challenge (a science question-answering task), 10-shot HellaSwag (a commonsense reasoning task), 5-shot MMLU (a multitask language understanding benchmark), and 0-shot TruthfulQA (a benchmark measuring whether a model avoids generating false statements). These benchmarks are evaluated in zero-shot and few-shot settings, meaning the models receive either no examples or a small number of examples in their prompts, all of which fit well within the original 4096-token context window.

The results demonstrate that the LongRoPE-2048k models achieve comparable results on these standard benchmarks, matching the performance of models that have not been extended. Remarkably, LongRoPE-Mistral-2048k even outperforms the original Mistral on TruthfulQA by $+0.5\%$, suggesting that the non-uniform positional interpolation, rather than degrading the model, may in some cases slightly improve its ability to generate truthful responses. This is an encouraging finding that speaks to the preservation of key information in the RoPE embeddings: by using evolutionary search to find rescale factors that preserve important dimensions and token positions, LongRoPE avoids the information loss that plagues uniform interpolation methods.

For LongRoPE-LLaMA2-2048k, the model fine-tuned at 256k shows slightly more performance degradation than the one fine-tuned at 128k, but the degradation remains within reasonable ranges for most tasks. This slight degradation is consistent with the intuition that a larger fine-tuning length introduces more interpolation, which can affect the model's behavior at short lengths. However, the authors' short context window recovery strategy — which involves performing an additional evolutionary search to adjust RoPE rescale factors specifically for 4k and 8k lengths — helps mitigate this degradation. During inference, if the sequence length is less than 8k, the model dynamically switches to these specially searched rescale factors, which encourage less positional interpolation and thus reduce the crowding effect.

The effectiveness of this recovery strategy is confirmed through ablation experiments. The authors compare the perplexity of LongRoPE-LLaMA2-2048k on Proof-pile at 4k and 8k lengths, along with the average LLM benchmark accuracy, both with and without the short context recovery. The results show a significant performance improvement at short context lengths when the recovery strategy is applied. This demonstrates that the performance degradation at short lengths is not an inherent limitation of context window extension but rather a consequence of using a single set of rescale factors across all lengths. By dynamically adjusting the rescale factors based on the actual sequence length, LongRoPE achieves the best of both worlds: excellent performance at extremely long lengths and maintained performance at short lengths.

In summary, the experimental evaluation comprehensively demonstrates LongRoPE's effectiveness across multiple dimensions. The perplexity results on PG19, Proof-pile, and Books3 show that the method extends the effective context window from 4k to 2048k while maintaining language modeling quality. The passkey retrieval results provide direct evidence that the extended context window is functionally useful, enabling precise information retrieval from millions of tokens. And the standard benchmark results confirm that this massive context extension does not come at the cost of performance on shorter, more common tasks. Together, these results establish LongRoPE as a significant advance in the field of context window extension for large language models.
