\title{A Textbook about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

Chapter 11: Ablation Studies and Numerical Error Analysis

# Ablation Setup: Fixed Parameters and Experimental Configuration

To rigorously assess the individual and combined contributions of the algorithmic innovations introduced in FlashAttention-3, the authors conduct an ablation study that systematically isolates each technique. The experimental configuration is carefully chosen to reflect a realistic workload while holding all parameters fixed, so that any observed performance differences can be attributed solely to the algorithmic improvements rather than variations in problem size or shape.

The ablation is performed on non-causal FP16 FlashAttention-3, meaning that no causal mask is applied and the computation is carried out in FP16 precision. The fixed parameters are set as follows: a batch size of 4, a sequence length of 8448, 16 attention heads, and a head dimension of 128. These values are representative of a medium-to-long-sequence training scenario, where attention is a significant computational bottleneck and the benefits of overlapping computation should manifest most clearly. With a hidden dimension of 2048 (implied by 16 heads of dimension 128), the total number of tokens processed is $4 \times 8448 = 33792$, which is large enough to saturate the GPU and produce stable throughput measurements.

The choice of non-causal attention for the ablation is deliberate. Causal masking introduces additional control flow and conditional logic into the kernel, which can obscure the clean measurement of how well the warp-specialization and pipelining schemes hide latency. By using the non-causal variant, the authors ensure that every block of the key and value matrices is fully processed for every query block, making the computation pattern uniform and the performance measurements more directly attributable to the overlapping techniques under investigation.

All experiments are conducted on an H100 80GB SXM5 GPU, the same hardware targeted throughout the FlashAttention-3 paper. This GPU features asynchronous Tensor Cores (exposed via WGMMA instructions), the Tensor Memory Accelerator (TMA) for asynchronous memory copies, and support for dynamic register reallocation via `setmaxnreg`, all of which are prerequisites for the warp-specialization and pipelining schemes being ablated. The fixed parameter setting allows for a controlled comparison where the only variables are whether warp-specialization is enabled and whether the 2-stage GEMM-softmax pipelining is active.

# Ablation Results: Contributions of Warp-Specialization and 2-Stage Pipelining

The ablation study quantifies the performance impact of two key innovations: warp-specialization (with its associated pingpong scheduling) and the 2-stage overlapping of GEMM and softmax operations within the consumer warpgroup. The results confirm that these algorithmic improvements, which exploit the asynchronous execution model of the Hopper GPU, lead to a significant and measurable speedup.

The baseline for the ablation is a version of FlashAttention-3 that does not use warp-specialization or intra-consumer overlapping—essentially corresponding to the algorithm described in Algorithm 1 of the paper, where the producer warpgroup loads data into shared memory via TMA and the consumer warpgroup executes the GEMMs and softmax in a strictly sequential fashion, with explicit wait statements serializing the execution of softmax and GEMMs. This baseline achieves approximately 570 TFLOPs/s for the given parameter configuration. While this already represents a substantial improvement over FlashAttention-2 (which achieves only about 35% utilization on the H100), it leaves significant performance on the table by not exploiting the asynchronous capabilities of the hardware.

When warp-specialization is added, the producer and consumer warpgroups operate concurrently: the producer issues TMA loads for the next blocks of $\mathbf{K}$ and $\mathbf{V}$ while the consumer is still processing the current blocks. This hides the memory latency of global memory accesses behind computation, a classic technique for throughput-oriented processors. However, within the consumer warpgroup, the GEMMs and softmax still execute sequentially—the consumer must wait for each WGMMA to complete before beginning the softmax operations that depend on its output, and must wait for the softmax to complete before issuing the next dependent WGMMA.

The 2-stage pipelining technique breaks this sequential dependency by introducing additional register buffers and reorganizing the inner loop so that the softmax for iteration $j$ is overlapped with the second WGMMA ($\mathbf{P}\mathbf{V}$) of the previous iteration and the first WGMMA ($\mathbf{Q}\mathbf{K}^\top$) of the current iteration. Specifically, as described in Algorithm 2 of the paper, within the mainloop the WGMMA computing $\mathbf{O}_i = \mathbf{O}_i + \tilde{\mathbf{P}}_{\mathrm{cur}} \mathbf{V}_{j-1}$ (line 12) is issued without an immediate wait, and the softmax operations based on $\mathbf{S}_{\mathrm{next}}$ (line 14) proceed concurrently while the WGMMA executes asynchronously on the Tensor Cores. The key insight is that the softmax operations—rowmax, exponential, rowsum, and rescaling—are performed by the multi-function units and CUDA cores, which are distinct hardware units from the Tensor Cores that execute WGMMA. Therefore, these operations can genuinely run in parallel.

The combined effect of warp-specialization and 2-stage pipelining is an increase from 570 TFLOPs/s to 661 TFLOPs/s, representing a roughly 16% improvement attributable solely to better exploitation of asynchrony within the kernel. This improvement is on top of the gains already achieved by FlashAttention-3 over FlashAttention-2 through the use of Hopper-specific instructions and the basic warp-specialization scheme. The authors also note that the pingpong scheduling between two consumer warpgroups (where the softmax of one warpgroup is overlapped with the GEMMs of the other) contributes an additional improvement, for example from 570 to 620–640 TFLOPs/s for a similar configuration with sequence length 8192, and the 2-stage pipelining within each warpgroup pushes performance even further.

The ablation also highlights the trade-offs involved in deeper pipelining. The authors propose a 3-stage variant that would further overlap the second WGMMA with softmax, but note that this requires even more registers to maintain additional stages of intermediate results. Each additional stage in the pipeline necessitates keeping another copy of $\mathbf{S}_{\mathrm{next}}$ in registers, costing $B_r \times B_c \times \text{sizeof}(\text{float})$ bytes per threadblock. This increased register pressure can conflict with the desire to use larger tile sizes (which are themselves register-hungry), and the optimal balance between pipeline depth and tile size must be determined empirically through profiling.

# Numerical Error Methodology: FP64 Reference and Outlier Simulation

A critical aspect of validating FlashAttention-3 is ensuring that the speedups achieved through asynchronous execution and low-precision computation do not come at an unacceptable cost in numerical accuracy. To this end, the authors design a rigorous numerical error evaluation methodology that compares the output of FlashAttention-3 against a high-precision reference implementation and simulates the challenging distributional properties of real-world LLM activations.

The reference implementation is computed in FP64 (double precision floating point), which provides 53 bits of mantissa precision and serves as a near-exact ground truth. By computing attention in FP64, the authors obtain an output tensor that is effectively free from the quantization and rounding errors introduced by lower-precision formats. The root mean squared error (RMSE) between the output of each tested implementation and the FP64 reference is then used as the primary metric for numerical accuracy. RMSE is a natural choice here because it penalizes large deviations more heavily than small ones, capturing the impact of outlier-induced errors that can be particularly damaging in downstream tasks.

The design of the input data is equally important. The authors recognize that randomly generated inputs from a standard normal distribution would not adequately stress the numerical precision of the attention computation, as such inputs lack the extreme outlier values that are known to arise in large language models. Prior work has established that LLM activations and weights frequently contain outlier features—specific dimensions or channels whose magnitudes are significantly larger than the typical values. These outliers pose a fundamental challenge for low-precision quantization, as a single large value can force the quantization scale to be large, thereby reducing the precision available for the vast majority of smaller values.

To simulate this realistic and challenging scenario, the authors generate the entries of $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$ according to the following mixture distribution:

$$\mathcal{N}(0, 1) + \mathcal{N}(0, 100) \cdot \mathrm{Bernoulli}(0.001).$$

This distribution means that each entry is drawn from a standard normal distribution with zero mean and unit variance, but for approximately 0.1% of entries, an additional independent term is added that is normally distributed with zero mean and a standard deviation of 10 (since the variance is 100, the standard deviation is $\sqrt{100} = 10$). The Bernoulli indicator variable activates this outlier term with probability 0.001, so roughly one in a thousand entries receives a large perturbation. This construction faithfully reproduces the essential statistical property of LLM activations: a heavy-tailed distribution where most values are well-behaved but a small fraction are extreme outliers. The presence of these outliers makes quantization to FP8 particularly challenging, as the quantization scale must accommodate the full dynamic range of the data, including the outliers, at the cost of precision for the bulk of the values.

The RMSE is computed by taking the element-wise difference between the output of each implementation and the FP64 reference, squaring these differences, averaging over all elements, and taking the square root. This provides a single scalar summary of the numerical error that can be compared across implementations and precision levels.

# FP16 Numerical Error: FlashAttention-2 and FlashAttention-3 Both 1.7x Better Than Standard

In FP16 precision, the numerical error results reveal that both FlashAttention-2 and FlashAttention-3 achieve 1.7$\times$ lower RMSE compared to a standard implementation of attention, when measured against the FP64 reference. This finding is significant because it demonstrates that the algorithmic innovations introduced in FlashAttention-3—warp-specialization, pingpong scheduling, and 2-stage GEMM-softmax pipelining—do not degrade numerical accuracy relative to its predecessor.

The reason for this improved accuracy over the standard implementation is rooted in how the FlashAttention family of algorithms manages intermediate computations. In a standard attention implementation, the intermediate score matrix $\mathbf{S} = \alpha \mathbf{Q}\mathbf{K}^\top$ and the probability matrix $\mathbf{P} = \mathrm{softmax}(\mathbf{S})$ are materialized to HBM (global memory). When these matrices are written to and read from HBM, they are typically stored in FP16 precision to conserve memory bandwidth. This means that the softmax computation, which involves the exponential function and row-wise normalization, is effectively carried out in FP16 precision after the initial FP16 matrix multiplication, introducing rounding errors at each step.

In contrast, both FlashAttention-2 and FlashAttention-3 keep the intermediate results—specifically, the softmax rescaling factors, the running maximum $m_i$, the running sum $\ell_i$, and the blocks of the score matrix $\mathbf{S}$—in FP32 (single precision) registers throughout the computation. The matrix multiplications themselves are accumulated in FP32, as this is the native accumulator precision for both FP16 and FP8 WGMMA instructions on the Hopper GPU. By maintaining these intermediate results in FP32 rather than truncating them to FP16, the FlashAttention algorithms avoid the compounding rounding errors that plague the standard implementation. The rescaling of the output $\mathbf{O}_i$ by the factor $\mathrm{exp}(m_i^{\mathrm{old}} - m_i)$, which is a critical part of the online softmax algorithm, is also performed in FP32, further preserving numerical fidelity.

The fact that FlashAttention-3 matches the FP16 accuracy of FlashAttention-2 is particularly noteworthy given the more aggressive overlapping of operations in FlashAttention-3. The 2-stage pipelining scheme interleaves WGMMA and softmax operations across iterations, which could in principle introduce additional sources of numerical error if, for example, the rescaling of $\mathbf{O}_i$ from a previous iteration is not properly synchronized with the accumulation of new results. However, the algorithm is carefully designed so that each block of $\mathbf{O}_i$ is rescaled by the correct factor before being accumulated with the new partial result, and all rescaling is performed in FP32. The numerical validation confirms that this careful design succeeds in maintaining the same level of accuracy as the simpler, sequential FlashAttention-2 algorithm.

# FP8 Numerical Error: FlashAttention-3 with Block Quantization and Incoherent Processing 2.6x Better Than Baseline

The FP8 numerical error results represent one of the most significant contributions of FlashAttention-3, demonstrating that the combination of block quantization and incoherent processing can substantially mitigate the accuracy challenges inherent to low-precision attention computation. The results show that FlashAttention-3 in FP8 achieves 2.6$\times$ lower RMSE than a baseline FP8 attention implementation that uses standard per-tensor quantization.

The FP8 format used in FlashAttention-3 is the e4m3 format, which allocates 4 bits for the exponent and 3 bits for the mantissa (plus a sign bit). This provides a dynamic range similar to FP16 but with dramatically reduced precision in the mantissa—only 3 bits means that only 8 distinct mantissa values are representable within each exponent binade. When outliers are present in the input tensors, per-tensor quantization must choose a single scale factor that accommodates the largest magnitude values in the entire tensor. This large scale factor means that the majority of values, which are much smaller, are quantized to only a few distinct FP8 representable values, leading to severe information loss.

FlashAttention-3 addresses this problem through two complementary techniques. The first is block quantization: instead of using a single scale factor per tensor, the algorithm maintains one scale factor per block. Specifically, for each of $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$, the tensor is split into blocks of size $B_r \times d$ or $B_c \times d$ (matching the block structure already used by the FlashAttention algorithm), and each block is quantized independently. This means that an outlier confined to one block only affects the scale factor for that block, leaving the quantization of other blocks unaffected. Since the FlashAttention-3 algorithm naturally operates on blocks, the rescaling of each block of $\mathbf{S}$ to account for the per-block quantization scales can be performed at essentially no computational cost—it is simply a multiplication by a known scalar that can be folded into the existing rescaling logic. Moreover, the block quantization itself can be fused with a preceding operation such as rotary embedding, which is memory-bandwidth bound and thus has spare computational capacity to absorb the quantization overhead without slowing down.

The second technique is incoherent processing, which directly targets the outlier problem at a more fundamental level. The key idea is to multiply both $\mathbf{Q}$ and $\mathbf{K}$ by a random orthogonal matrix $\mathbf{M}$ before quantizing to FP8. Since $\mathbf{M}$ is orthogonal, $\mathbf{M}\mathbf{M}^\top = \mathbf{I}$, and therefore:

$$(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{M}\mathbf{M}^\top\mathbf{K}^\top = \mathbf{Q}\mathbf{K}^\top,$$

meaning that the attention output is unchanged by this transformation. The effect of multiplying by $\mathbf{M}$ is to spread out the outliers: each entry of $\mathbf{Q}\mathbf{M}$ or $\mathbf{K}\mathbf{M}$ is a weighted sum of multiple entries of $\mathbf{Q}$ or $\mathbf{K}$, which by the central limit theorem tends to produce values with more uniform magnitudes. Extreme outliers are diluted because they are combined with many non-outlier values, resulting in a distribution that is more amenable to uniform quantization. In practice, rather than using a fully random orthogonal matrix (which would require $O(d^2)$ computation to apply), the authors follow prior work and choose $\mathbf{M}$ to be the product of random diagonal matrices of $\pm 1$ and a Hadamard matrix. This structured orthogonal matrix can be applied in $O(d \log d)$ time and, like block quantization, can be fused with the rotary embedding operation at no additional computational cost.

The combined effect of these two techniques is a 2.6$\times$ reduction in RMSE compared to the baseline FP8 implementation. This is a substantial improvement that makes FP8 attention a viable option for practical use, where the 2$\times$ throughput gain of FP8 over FP16 (reaching close to 1.2 PFLOPs/s on the H100) would otherwise be undermined by unacceptable accuracy degradation, particularly in models with prominent outlier features.

# Baseline FP8 Attention Configuration: Per-Tensor Scaling, FP32 Accumulator, FP16 Softmax

To provide a fair and meaningful comparison for the FP8 numerical error evaluation, the authors define a baseline FP8 attention implementation that represents a straightforward application of FP8 precision without the advanced techniques employed by FlashAttention-3. Understanding this baseline configuration is essential for appreciating the magnitude of the improvement achieved by block quantization and incoherent processing.

The baseline FP8 attention uses per-tensor scaling for quantization, meaning that a single scale factor is computed for each of the entire $\mathbf{Q}$, $\mathbf{K}$, and $\mathbf{V}$ tensors. This is the standard approach advocated in early FP8 training frameworks, where the scale factor is typically chosen as the maximum absolute value of the tensor (or a percentile thereof) to ensure that all values fall within the representable range of the FP8 format. While simple and efficient, per-tensor scaling is particularly vulnerable to outliers: a single large value in the tensor forces the scale factor to be large, which in turn means that all other values are quantized to a coarse grid of FP8 representable numbers, losing significant precision.

In terms of the computation itself, the baseline performs the matrix multiplications in FP8 using the FP8 Tensor Cores, with the accumulators in FP32. This is a natural and necessary choice, as accumulating FP8 products directly in FP8 would lead to catastrophic precision loss due to the limited dynamic range of the format. The FP32 accumulator provides 23 bits of mantissa precision, which is sufficient to faithfully accumulate the partial sums of the matrix product. This aspect of the baseline is actually the same as in FlashAttention-3, since both use WGMMA instructions that natively accumulate in FP32.

Where the baseline differs more substantially is in the handling of the softmax intermediate results. In the baseline FP8 attention, the intermediate softmax computation—the exponential, row-wise maximum, and normalization—is performed in FP16 precision. This is a reasonable middle ground: FP16 provides more precision than FP8 for these sensitive non-linear operations, while being more memory-efficient than FP32. However, it is less precise than the approach used in FlashAttention-3, where (as in the FP16 case) the softmax intermediates are maintained in FP32 registers throughout the computation.

The comparison between this baseline and FlashAttention-3 in FP8 is thus designed to isolate the impact of the quantization strategy (per-tensor vs. block quantization with incoherent processing) while keeping other aspects of the computation as similar as possible. The 2.6$\times$ improvement in RMSE achieved by FlashAttention-3 can therefore be attributed primarily to the more sophisticated quantization approach, which adaptively handles the non-uniform distribution of values in real-world LLM activations. This result has important practical implications: it suggests that the throughput benefits of FP8 attention (nearly doubling the TFLOPs/s compared to FP16) can be realized without the severe accuracy penalties that would otherwise make FP8 attention unsuitable for high-quality model training and inference.
