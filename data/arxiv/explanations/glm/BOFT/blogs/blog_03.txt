\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Networking Meets Neural Networks: Viewing Fine-Tuning as an Information Highway

Adapting massive foundation models like GPT-3 or Stable Diffusion to new tasks is a major challenge. Training them from scratch is prohibitively expensive, so we rely on fine-tuning. One powerful method is Orthogonal Finetuning (OFT), which transforms a model's neurons using orthogonal matrices to preserve the pairwise angles between them. This maintains the pretraining knowledge beautifully, but there's a catch: high-dimensional orthogonal matrices require a massive number of trainable parameters. 

To solve this, a recent paper introduces Orthogonal Butterfly (BOFT). The authors tackle the parameter-efficiency problem by taking a fascinating step back, viewing the construction of orthogonal matrices through the lens of an information transmission network.

## The Information Transmission Perspective

To reduce the number of trainable parameters in OFT, the authors propose composing a dense orthogonal matrix as a product of multiple sparse matrices. Mathematically, we want to generate a dense matrix $\bm{R} \in \mathbb{R}^{d \times d}$ via a factorization like $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$. 

Instead of looking at this purely through linear algebra, the authors reframe it as an information transmission problem on a grid-structured graph. Imagine a grid with $d$ rows and $m+1$ columns of nodes. 

- Each matrix $\bm{B}_i$ represents the connectivity (the directed edges) between the nodes in the $i$-th level and the $(i+1)$-th level. 
- If the element at the $(j_1, j_2)$ position of $\bm{B}_i$ is non-zero, it means there is a directed edge allowing information to flow from the $j_2$-th node in level $i$ to the $j_1$-th node in level $i+1$. 
- For the final composed matrix $\bm{R}$ to be dense, every node in the very first level must have a path to transmit information to every node in the very last level. 

This graphical perspective makes it much easier to reason about how to build our matrices. To achieve parameter efficiency, we want two things: dense connectivity (so information can flow everywhere) and the minimum number of free edges (to keep trainable parameters low).

## The Block-Diagonal Bottleneck

The original OFT attempted to save parameters by using a block-diagonal structure for the orthogonal matrix. In this setup, the matrix is divided into smaller independent blocks along the diagonal. 

Through the information transmission lens, we can instantly see the flaw in this approach. A block-diagonal structure creates isolated sub-networks. Information can flow freely within a block, but it can never cross over to a different block. Because information from the first level cannot reach all nodes in the final level, the resulting matrix is sparse. This severely limits the expressiveness of the finetuned model, preventing it from approximating classic linear transforms.

## Butterflies to the Rescue

We need a network topology that can connect every source node to every receiver node using as few edges as possible. The authors find the perfect solution in an unexpected place: the Cooley-Tukey fast Fourier transform (FFT) algorithm.

The FFT algorithm uses a "butterfly" structure to efficiently exchange information, where a local change in the frequency domain causes a global change in the spatial domain. By applying butterfly factorization, the authors create a dense orthogonal matrix using a product of $\mathcal{O}(\log d)$ sparse matrices, each with $\mathcal{O}(d)$ non-zero entries. 

This brings the total parameter count down from $\mathcal{O}(d^2)$ for a dense matrix to just $\mathcal{O}(d \log d)$ for BOFT, all while ensuring the matrix remains completely dense and orthogonal! The resulting method, BOFT, generalizes OFT (which is just a special case of BOFT) and allows for a much smoother interpolation between expressivity and regularity.

## Why This Matters

By visualizing matrix factorization as information passing through a grid-like network, the authors make the underlying math of orthogonal finetuning intuitive and accessible. This networking perspective doesn't just simplify the concept; it actively guides the design of a better algorithm. 

BOFT’s structured approach introduces a beneficial inductive bias that prevents overfitting and perfectly preserves the spectral norm of the pretrained weights. Because the learned matrices can simply be multiplied back into the pretrained weights after training, BOFT introduces zero inference latency. It's a fantastic example of how borrowing concepts from entirely different disciplines—like computer networking and signal processing—can push the boundaries of modern machine learning.
