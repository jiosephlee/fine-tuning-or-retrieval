\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# Adapting AI Giants: How BOFT Makes Fine-Tuning Massive Models Affordable

## The Challenge of Adapting Foundation Models

Large foundation models like ChatGPT and Stable Diffusion are incredibly powerful, but training them from scratch is prohibitively expensive. To leverage these models for specific downstream tasks, we need efficient adaptation methods. While there are various ways to adapt these models—such as adding adapter layers or using prompt tuning—model finetuning stands out because it introduces no additional inference latency. The fundamental principle behind model finetuning is to ensure that the finetuned model remains similar to the pretrained model, thereby preserving the hard-earned pretraining knowledge.

## The Bottleneck in Orthogonal Finetuning

One promising finetuning approach is Orthogonal Finetuning (OFT). The core idea behind OFT is to preserve the relational information—specifically the pairwise angles between neurons—of the pretrained weight matrices. It achieves this by transforming the neurons of the same layer with a learnable orthogonal matrix $\mathbf{R}$. This preserves the semantic knowledge from pretraining and ensures stable training.

However, OFT has a catch: a dense $d$-dimensional orthogonal matrix requires $\mathcal{O}(d^2)$ parameters. To reduce this, OFT introduces a block-diagonal structure, breaking the matrix into smaller independent blocks. While this saves parameters, it introduces a rigid sparsity pattern. Dimensions in different blocks are transformed independently, reducing the model's expressiveness and preventing it from approximating classic linear transforms. A natural question arises: can we construct a dense orthogonal matrix without losing parameter efficiency?

## Enter BOFT: The Orthogonal Butterfly

The solution proposed in the paper is Orthogonal Butterfly (BOFT). BOFT composes a dense orthogonal matrix by multiplying several sparse orthogonal matrices together: $\mathbf{R} = \mathbf{B}_m \mathbf{B}_{m-1} \cdots \mathbf{B}_1$. 

To understand why this works, the authors frame the problem as an information transmission task on a grid. Generating a dense matrix is like ensuring information can flow from every node in the first level of a grid to every node in the last level. A naive dense connection requires too many edges, corresponding to a massive number of parameters. 

Here is where the Cooley-Tukey fast Fourier transform algorithm comes to the rescue. The butterfly structure in this algorithm efficiently exchanges information with $\mathcal{O}(d \log d)$ edges. By applying butterfly factorization, BOFT generates a $d$-dimensional dense orthogonal matrix using a product of $\mathcal{O}(\log d)$ sparse matrices, each having $\mathcal{O}(d)$ non-zero entries. This drops the required parameters from $\mathcal{O}(d^2)$ down to $\mathcal{O}(d \log d)$, a massive reduction for high-dimensional models.

## Why BOFT Excels

BOFT introduces a generalized orthogonal finetuning framework that subsumes OFT as a special case. By using the butterfly structure, BOFT creates a smoother interpolation between the expressivity of a full orthogonal matrix and the regularity of an identity matrix. This structured approach brings several advantages:

*   **Drastic Parameter Reduction**: BOFT significantly cuts down the trainable parameters. The paper shows that BOFT with a smaller block size and more factorization steps can yield similar approximation errors to standard block-diagonal OFT but with far fewer parameters. In general, BOFT takes $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d \times n$.
*   **Knowledge Preservation**: Like OFT, BOFT multiplies the pretrained weight matrix $\mathbf{W}^0$ by an orthogonal matrix $\mathbf{R}$. This preserves the spectral norm of the weights, ensuring that the pretrained knowledge is largely retained and training remains stable.
*   **No Inference Latency**: Although BOFT introduces a slight training runtime overhead due to the repeated matrix multiplications, the learned orthogonal matrices can be multiplied directly into the pretrained weights after finetuning. This means there is zero additional inference latency when the model is deployed.
*   **Better Inductive Bias**: Because the butterfly structure is the backbone of many fast linear transforms like the discrete Fourier transform, it introduces a structural prior that benefits generalization and prevents overfitting.

In short, BOFT offers a principled way to adapt massive AI models. By framing dense orthogonal matrix generation as an information transmission problem and leveraging the butterfly structure, BOFT drastically cuts down the trainable parameters while maintaining the dense connections needed to preserve the model's original knowledge.
