\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: Butterfly Structures for Orthogonal Parameterization

## Inspiration from the Cooley-Tukey Fast Fourier Transform and Its Efficient Information Exchange Topology

The quest for a parameter-efficient dense orthogonal matrix begins with a simple but powerful observation: a dense $d \times d$ orthogonal matrix naively requires $\mathcal{O}(d^2)$ parameters, which is prohibitively expensive for the high-dimensional weight matrices of modern foundation models. However, as discussed in the information transmission framework, we can compose a dense matrix as a product of sparse matrices, and the key challenge is to find a sparsity pattern that achieves dense connectivity—meaning every source node can transmit information to every receiver node—while minimizing the total number of edges (i.e., trainable parameters). This is precisely the kind of problem that has been studied for decades in a seemingly unrelated domain: signal processing.

The Cooley-Tukey fast Fourier transform (FFT) algorithm, introduced in 1965, is one of the most celebrated algorithms in all of computing. Its fundamental insight is that a discrete Fourier transform of size $N$ can be recursively decomposed into two discrete Fourier transforms of size $N/2$. By applying this decomposition repeatedly, the algorithm reduces the computational complexity of the Fourier transform from $\mathcal{O}(N^2)$ to $\mathcal{O}(N \log N)$. The recursive decomposition induces a characteristic graph topology known as the butterfly graph, which describes how data flows through the stages of the computation. The name "butterfly" arises from the visual appearance of the graph, where pairs of nodes at one level connect to pairs at the next level in a pattern resembling butterfly wings.

The butterfly topology is remarkable because it provides a solution to a general information exchange problem: given $d$ source nodes and $d$ receiver nodes arranged across multiple levels, how can we connect them such that information from every source can reach every receiver, using as few edges as possible? The butterfly network achieves this with only $\mathcal{O}(d \log d)$ edges, which is dramatically fewer than the $\mathcal{O}(d^2)$ edges required by a fully dense connection. To build intuition, consider a scenario with $d = 4$ source nodes and $d = 4$ receiver nodes. A naive dense connection would require $16$ edges (or $12$ trainable edges after accounting for the orthogonality constraint, as $4$ edges are determined by the bijection requirement). The example factorization shown in the paper's information transmission framework uses $10$ edges, already an improvement. The butterfly network, however, achieves dense connectivity with only $8$ edges—a significant reduction that scales favorably as $d$ grows.

This connection between the FFT and our orthogonal finetuning problem is not merely superficial. In the Fourier transform, a local change in the frequency domain causes a global change in the spatial domain. This is conceptually analogous to our information transmission problem: we want every node in the first level to be able to influence every node in the last level, even though each individual factor matrix only connects nodes between adjacent levels. The butterfly structure provides an elegant, proven topology for achieving exactly this kind of global connectivity through local, structured exchanges.

The butterfly structure has also found widespread use as a computer network topology for efficient information exchange in distributed systems. This reinforces the idea that the butterfly graph is a general-purpose structure for routing information efficiently, not merely a computational trick specific to Fourier analysis. By drawing on this well-understood topology, we can design a parameterization scheme that constructs a dense orthogonal matrix from a product of $\mathcal{O}(\log d)$ sparse matrices, each with $\mathcal{O}(d)$ non-zero entries. The total number of parameters thus becomes $\mathcal{O}(d \log d)$, a dramatic improvement over the $\mathcal{O}(d^2)$ parameters required by a full dense orthogonal matrix.

## Mathematical Definition of the Butterfly Factor $\bm{B}^F(k)$ and the Recursive Butterfly Matrix $\bm{B}(d)$

To formalize the butterfly structure for use in orthogonal parameterization, we begin by defining the fundamental building block: the butterfly factor. Assuming that $k \geq 2$ is a power of $2$, the butterfly factor $\bm{B}^F(k)$ is defined as a $k \times k$ matrix with a specific block structure:

$$\bm{B}^F(k) = \begin{bmatrix} \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\ \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4) \end{bmatrix} \in \mathbb{R}^{k \times k}$$

where $\bm{d}_i \in \mathbb{R}^{\frac{k}{2}}, \forall i$ are vectors of length $k/2$. The key structural property of this matrix is that it is composed of four diagonal blocks, each of size $\frac{k}{2} \times \frac{k}{2}$. This means that the butterfly factor is a sparse matrix—most of its entries are zero—and the non-zero entries follow a very specific pattern determined by the diagonal sub-vectors $\bm{d}_1, \bm{d}_2, \bm{d}_3, \bm{d}_4$.

To understand why this structure is useful, consider what happens when we multiply a vector by $\bm{B}^F(k)$. The top half of the output depends on the top half of the input through $\text{diag}(\bm{d}_1)$ and on the bottom half of the input through $\text{diag}(\bm{d}_2)$. Similarly, the bottom half of the output depends on both halves of the input through $\text{diag}(\bm{d}_3)$ and $\text{diag}(\bm{d}_4)$. This "mixing" of information between the top and bottom halves is the essence of the butterfly operation, and it is what enables information to propagate across the entire dimension through repeated application.

With the butterfly factor defined, we can now construct the full $d$-dimensional butterfly matrix $\bm{B}(d)$ recursively. Assuming $d = 2^N$ for some integer $N$, the butterfly matrix is defined as:

$$\bm{B}(d) = \tilde{\bm{B}}(d, d) \cdot \begin{bmatrix} \bm{B}_1\left(\frac{d}{2}\right) & \bm{0} \\ \bm{0} & \bm{B}_2\left(\frac{d}{2}\right) \end{bmatrix} = \tilde{\bm{B}}(d, d)\tilde{\bm{B}}\left(d, \frac{d}{2}\right) \cdots \tilde{\bm{B}}(d, 2)$$

where $\bm{B}_1\left(\frac{d}{2}\right)$ and $\bm{B}_2\left(\frac{d}{2}\right)$ are two independent $\frac{d}{2}$-dimensional butterfly matrices. This recursive definition reveals the self-similar nature of the butterfly structure: a $d$-dimensional butterfly matrix is composed of a butterfly component $\tilde{\bm{B}}(d, d)$ multiplied by a block-diagonal matrix containing two smaller butterfly matrices of half the dimension. By unrolling this recursion completely, we obtain a product of $\log_2 d$ butterfly components: $\tilde{\bm{B}}(d, d), \tilde{\bm{B}}(d, \frac{d}{2}), \ldots, \tilde{\bm{B}}(d, 2)$.

This recursive factorization is the key to the parameter efficiency of the butterfly structure. Each butterfly component $\tilde{\bm{B}}(d, k)$ is a sparse matrix with $\mathcal{O}(d)$ non-zero entries, and there are $\mathcal{O}(\log d)$ such components in the product. The total number of non-zero entries across all components is therefore $\mathcal{O}(d \log d)$, and yet the product of all these sparse matrices yields a dense matrix. This is the mathematical realization of the information transmission intuition: through $\log d$ stages of structured local exchanges, information from any source node can reach any receiver node, producing a dense connectivity pattern.

The recursive structure also reveals an important hierarchical property. At the coarsest level, $\tilde{\bm{B}}(d, d)$ connects the two halves of the dimension. At the next level, $\tilde{\bm{B}}(d, \frac{d}{2})$ connects quarters within each half, and so on, until $\tilde{\bm{B}}(d, 2)$ connects individual pairs of dimensions. This hierarchical mixing pattern—first mixing large blocks, then progressively smaller blocks—is what enables efficient information propagation and is directly inherited from the Cooley-Tukey decomposition strategy.

## Defining the Butterfly Component $\tilde{\bm{B}}(d,k)$ and Its Block-Diagonal Nature

The butterfly component $\tilde{\bm{B}}(d, k)$ is the workhorse of the butterfly matrix factorization. It is defined as a block-diagonal matrix composed of multiple butterfly factors:

$$\tilde{\bm{B}}(d, k) = \text{diag}\left(\bm{B}^F_1(k), \cdots, \bm{B}^F_{d/k}(k)\right)$$

This is a $d \times d$ block-diagonal matrix with $\frac{d}{k}$ blocks along the diagonal, each of which is a $k \times k$ butterfly factor $\bm{B}^F_i(k)$ as defined above. Each butterfly factor may have different parameter values (i.e., different $\bm{d}_i$ vectors), but they all share the same sparsity structure.

The block-diagonal nature of $\tilde{\bm{B}}(d, k)$ is crucial for understanding both its computational and parameteric properties. First, because it is block-diagonal, multiplying a vector by $\tilde{\bm{B}}(d, k)$ can be performed independently on each block, leading to efficient computation. Second, the number of non-zero entries in $\tilde{\bm{B}}(d, k)$ is exactly $\frac{d}{k} \times k = d$ times the number of non-zero entries per row in each butterfly factor. Since each butterfly factor $\bm{B}^F(k)$ has exactly $k$ non-zero entries per row (two per diagonal block, with $\frac{k}{2}$ entries each, giving $4 \times \frac{k}{2} = 2k$... but actually, each butterfly factor has exactly $2k$ non-zero entries total, since it is a $k \times k$ matrix with four $\frac{k}{2} \times \frac{k}{2}$ diagonal blocks, each contributing $\frac{k}{2}$ non-zero entries, for a total of $4 \times \frac{k}{2} = 2k$ non-zero entries). With $\frac{d}{k}$ such blocks, the total number of non-zero entries is $\frac{d}{k} \times 2k = 2d$, which is $\mathcal{O}(d)$.

As $k$ varies from $2$ to $d$ across the different components in the butterfly matrix, the block structure changes. When $k = 2$, the component $\tilde{\bm{B}}(d, 2)$ consists of $\frac{d}{2}$ blocks of size $2 \times 2$, which is the finest level of mixing. When $k = d$, the component $\tilde{\bm{B}}(d, d)$ is a single $d \times d$ butterfly factor, which is the coarsest level of mixing. The progression from $k = 2$ to $k = d$ corresponds to mixing at progressively larger scales, which is the hallmark of the butterfly structure inherited from the Cooley-Tukey algorithm.

It is worth noting that while each individual butterfly component is block-diagonal and therefore sparse with a limited connectivity pattern, the product of all butterfly components across different scales produces a dense matrix. This is because the different components operate at different scales of mixing: $\tilde{\bm{B}}(d, 2)$ mixes pairs of adjacent dimensions, $\tilde{\bm{B}}(d, 4)$ mixes groups of four dimensions, and so on up to $\tilde{\bm{B}}(d, d)$, which mixes the two halves of the entire dimension. The composition of mixing at all scales is what achieves the dense connectivity that a single block-diagonal matrix cannot.

## Ensuring Orthogonality of Butterfly Components Using Cayley Transform and Block-Wise Permutations

The butterfly matrix structure provides an efficient way to compose a dense matrix from sparse factors, but for our finetuning purpose, we need the resulting matrix to be orthogonal. A matrix $\bm{R}$ is orthogonal if $\bm{R}^\top \bm{R} = \bm{R} \bm{R}^\top = \bm{I}$, which preserves angles and norms. The orthogonality of the overall butterfly matrix $\bm{B}(d)$ is guaranteed if and only if each individual butterfly component $\tilde{\bm{B}}(d, k)$ is orthogonal, because the product of orthogonal matrices is itself orthogonal.

To ensure orthogonality of each butterfly component, we start with the simplest case: the block-diagonal matrix $\tilde{\bm{B}}(d, 2)$ with block size $2$. Each block in this matrix is a $2 \times 2$ butterfly factor $\bm{B}^F(2)$, which needs to be orthogonal. For $2 \times 2$ matrices, orthogonality can be guaranteed using the Cayley transform, which parameterizes an orthogonal matrix $\bm{R}$ as:

$$\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$$

where $\bm{Q}$ is a skew-symmetric matrix satisfying $\bm{Q} = -\bm{Q}^\top$. For a $2 \times 2$ matrix, $\bm{Q}$ has only one free parameter (since the diagonal must be zero and the off-diagonal entries are negatives of each other), so each $2 \times 2$ orthogonal block requires only one trainable parameter. Alternatively, the $2 \times 2$ orthogonal block can be parameterized as a 2-dimensional rotation matrix, which also has a single free parameter (the rotation angle). Both approaches guarantee orthogonality by construction.

Having established orthogonality for $\tilde{\bm{B}}(d, 2)$, the orthogonality of the other butterfly components $\tilde{\bm{B}}(d, k)$ for $k > 2$ follows from a key observation about their structure. The non-zero pattern of every butterfly component $\tilde{\bm{B}}(d, k)$ can be viewed as a permutation of the non-zero pattern of $\tilde{\bm{B}}(d, 2)$. In other words, if we rearrange the rows and columns of $\tilde{\bm{B}}(d, k)$ appropriately, we obtain a matrix that has the same sparsity structure as $\tilde{\bm{B}}(d, 2)$—a block-diagonal matrix with $2 \times 2$ blocks. Since permutation matrices are themselves orthogonal, and the product of orthogonal matrices is orthogonal, ensuring that the permuted version of $\tilde{\bm{B}}(d, k)$ is orthogonal (using the same Cayley transform approach) guarantees that $\tilde{\bm{B}}(d, k)$ itself is orthogonal.

This block-wise permutation insight is powerful because it means we do not need to develop a separate orthogonality guarantee for each value of $k$. Instead, we can always reduce the problem to the $2 \times 2$ case, which is well-understood and easily parameterized. This gives us an efficient parameterization of orthogonal matrices built upon many $2 \times 2$ orthogonal matrices, each requiring only a single parameter. With $\frac{d}{2}$ such blocks per component and $\log d$ components, the total parameter count is $\frac{d}{2} \log d = \mathcal{O}(d \log d)$, achieving the desired parameter efficiency.

The identity initialization for BOFT follows naturally from this parameterization. Since the Cayley transform with $\bm{Q} = \bm{0}$ yields $\bm{R} = \bm{I}$, we can initialize all skew-symmetric matrices to zero, which means all butterfly components start as identity matrices. This ensures that the finetuning process begins with the exact pretrained model, analogous to how LoRA initializes its low-rank weight updates to zero.

## Generalization to Block Butterfly Components $\tilde{\bm{B}}^b(d,k)$ for Broader Applicability

While the butterfly parameterization with $2 \times 2$ blocks achieves excellent parameter efficiency, there are situations where a finer-grained control over the trade-off between expressivity and parameter count is desirable. The original OFT with block-diagonal structure used blocks of arbitrary size $b$, and we would like BOFT to similarly support flexible block sizes. To this end, the butterfly structure is generalized following the approach in prior work on pixelated butterfly matrices.

The generalization introduces the block butterfly component $\tilde{\bm{B}}^b(d, k)$, where each scalar entry in the vectors $\bm{d}_i$ of the butterfly factor is replaced by a $b \times b$ matrix. Concretely, the butterfly factor $\bm{B}^F(k)$ now has diagonal blocks $\text{diag}(\bm{d}_i)$ where each $\bm{d}_i$ is no longer a vector of scalars but a block-diagonal matrix of $b \times b$ blocks. This means that each "entry" in the butterfly structure becomes a $b \times b$ matrix, and the effective block size for orthogonal parameterization becomes $2b \times 2b$ instead of $2 \times 2$.

To guarantee that the block butterfly component $\tilde{\bm{B}}^b(d, 2)$ is orthogonal, each $2b \times 2b$ block matrix must be parameterized as an orthogonal matrix. This can again be done using the Cayley transform, now with a skew-symmetric matrix $\bm{Q}$ of size $2b \times 2b$, which has $\frac{2b(2b-1)}{2} = b(2b-1)$ free parameters. The non-zero patterns of the other block butterfly components $\tilde{\bm{B}}^b(d, k)$ for $k > 2$ are block-wise permutations of the non-zero pattern of $\tilde{\bm{B}}^b(d, 2)$, so they can similarly be turned into orthogonal matrices using the same approach.

With this generalization, the forward pass in BOFT is given by:

$$\bm{z} = \left(\bm{R}(m, b) \cdot \bm{W}^0\right)^\top \bm{x}$$

subject to the constraints:

$$\bm{R}(m, b) = \prod_{i=1}^{m} \tilde{\bm{B}}^b_{(d, i)} \quad \text{and} \quad \left(\tilde{\bm{B}}^b_{(d, j)}\right)^\top \tilde{\bm{B}}^b_{(d, j)} = \tilde{\bm{B}}^b_{(d, j)} \left(\tilde{\bm{B}}^b_{(d, j)}\right)^\top = \bm{I}_d, \quad \forall j \in [1, m]$$

where $\tilde{\bm{B}}^b_{(d, i)}$ denotes $\tilde{\bm{B}}^b(d, 2^{m-i+1})$ for notational simplicity, and $\bm{I}_d$ is the $d \times d$ identity matrix. The orthogonal matrix $\bm{R}(m, b) \in \mathbb{R}^{d \times d}$ is composed of a product of $m$ orthogonal butterfly components, each with block size $b$.

The notation BOFT($m$, $b$) is used to denote BOFT with $\bm{R}(m, \frac{b}{2})$, where $b \geq 2$. This notation reveals a rich family of finetuning configurations that interpolates between existing methods. When $m = 1$, BOFT($1$, $b$) reduces to the block-diagonal OFT with block size $b$, which is the original parameter-efficient variant of OFT. When $m = 1$ and $b = d$, BOFT($1$, $d$) reduces to the original OFT with an unconstrained full orthogonal matrix. When $m = \log \frac{2d}{b}$ and $b$ is the block size, BOFT uses the full block butterfly matrix $\bm{B}^{\frac{b}{2}}(d)$ as $\bm{R}$, yielding a dense orthogonal matrix. In general, BOFT($m$, $b$) requires $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d \times n$.

This generalization provides a flexible framework for navigating the trade-off between expressivity and parameter efficiency. Using the full butterfly matrix with $m = \log d$ and $b = 2$ gives BOFT $\mathcal{O}(d \log d)$ parameters, while the original OFT with a full dense orthogonal matrix uses $\mathcal{O}(d^2)$ parameters, and block-diagonal OFT with block number $r$ uses $\mathcal{O}(bd)$ parameters. The critical advantage of BOFT is that it can generate a dense orthogonal matrix with any block size $b$, whereas the original OFT must use $b = d$ to achieve density, requiring the full $\mathcal{O}(d^2)$ parameter budget. This flexibility makes BOFT a strictly more general framework that subsumes OFT as a special case while opening up a much richer space of parameter-efficient orthogonal parameterizations.
