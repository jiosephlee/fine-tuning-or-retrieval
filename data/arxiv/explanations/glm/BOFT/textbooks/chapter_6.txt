\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 6: Theoretical Insights and Properties of BOFT

## Simulating the Expressivity of BOFT vs. OFT in Approximating Random Dense Orthogonal Matrices

A central question in parameter-efficient finetuning is how well a given parameterization can approximate the transformations that a full, unconstrained model could express. In the context of orthogonal finetuning, this question translates to: how well can a structured orthogonal matrix --- whether constructed via block-diagonal decomposition (as in standard OFT) or via butterfly factorization (as in BOFT) --- approximate an arbitrary dense orthogonal matrix drawn uniformly at random from the orthogonal group? This question is practically important because the answer tells us how much expressivity we sacrifice in exchange for parameter efficiency, and it provides a principled basis for choosing between different structured parameterizations.

To investigate this, the authors of BOFT conduct a controlled simulation study. They generate random dense orthogonal matrices of size $512 \times 512$ using a standard method for uniformly sampling from the orthogonal group. For each such random target matrix, they then attempt to approximate it using both BOFT and OFT with various configurations, measuring the approximation error as a function of the number of effective trainable parameters used. The results are averaged over 10 random seeds to ensure statistical reliability.

The key finding from this simulation is that BOFT generally yields better parameter efficiency than OFT. Concretely, the approximation error of BOFT decreases more rapidly as a function of the number of parameters than does the approximation error of OFT. The authors provide specific examples to illustrate this point. For instance, the expressiveness of BOFT$(9, 2)$ --- which uses $m = 9$ butterfly components each with block size $b = 2$ --- is better than that of BOFT$(1, 16)$, which corresponds to the original block-diagonal OFT with block size $b = 16$, despite BOFT$(9, 2)$ using significantly fewer parameters. This is a striking result: by decomposing the orthogonal matrix into a product of many sparse factors rather than a single block-diagonal matrix, BOFT achieves greater expressivity per parameter.

The simulation also reveals an important structural insight about the role of the block size $b$ and the number of factors $m$. BOFT with smaller block size $b$ and correspondingly larger number of factors $m$ is generally more parameter-efficient. For example, BOFT$(6, 4)$ uses much fewer parameters but yields a similar approximation error to BOFT$(2, 16)$. This suggests that the depth of the factorization --- that is, the number of sparse matrices multiplied together --- plays a more important role in expressivity than the width of each individual factor, which is controlled by the block size. Intuitively, this makes sense: each additional factor in the product introduces new degrees of freedom that allow the composed matrix to capture more complex transformations, while increasing the block size merely enlarges the local transformation within each block without enabling information exchange between blocks.

It is worth emphasizing what the leftmost point on each curve in the simulation represents. For each fixed block size $b$, the leftmost point corresponds to BOFT$(1, b)$, which is precisely the original block-diagonal OFT with block size $b$. As one moves rightward along the curve (increasing $m$ while keeping $b$ fixed), one is adding more butterfly factors and thus increasing the number of parameters, but also increasing expressivity. The fact that curves for smaller block sizes start with higher approximation error (since BOFT$(1, b)$ with small $b$ is very restrictive) but then drop steeply as $m$ increases shows that the butterfly structure provides a smooth and efficient pathway from low expressivity to high expressivity, something that the block-diagonal structure cannot achieve without jumping to the extreme of a full dense orthogonal matrix (i.e., $b = d$, which requires $\mathcal{O}(d^2)$ parameters).

This simulation thus provides the first concrete evidence that the butterfly factorization in BOFT represents a more structured subset of the orthogonal group compared to the block-diagonal structure, and that this structured subset is more expressive per parameter. The intuition is that the butterfly structure allows information to flow between all dimensions through the successive sparse matrix multiplications, whereas the block-diagonal structure eternally confines information to within-block interactions, no matter how the block size is chosen.

## Theorem 1: Proof that BOFT is More Expressive than OFT with the Same Block Size

The simulation results described above provide empirical evidence that BOFT is more parameter-efficient than OFT. However, the authors also provide a formal theoretical result that establishes a strict expressivity advantage of BOFT over OFT under certain conditions. This result is stated as Theorem 1 in the paper.

The theorem asserts that BOFT is more expressive than OFT with the same block size. To understand what this means precisely, we need to clarify the notion of expressivity being used here. A parameterization is said to be more expressive than another if the set of matrices that the first parameterization can represent is a strict superset of the set of matrices that the second can represent (or, in a weaker sense, if the first can approximate a broader class of target matrices). In this context, the relevant comparison is between the set of orthogonal matrices that BOFT$(m, b)$ can represent and the set that OFT with block size $b$ (i.e., BOFT$(1, b)$) can represent, for the same block size $b$.

The key observation underlying the theorem is that the block-diagonal structure used in OFT is a special case of the butterfly structure. Specifically, when $m = 1$, BOFT$(1, b)$ reduces exactly to the block-diagonal OFT with block size $b$. As $m$ increases, BOFT$(m, b)$ introduces additional butterfly factors that allow interactions between blocks, thereby expanding the set of representable orthogonal matrices beyond what the block-diagonal structure alone can achieve. Therefore, for any fixed block size $b$, increasing $m$ from 1 to any larger value strictly enlarges the hypothesis space, making BOFT strictly more expressive than OFT.

The theorem goes further to address the question of whether the butterfly matrix can approximate all orthogonal matrices of size $d$. The authors show that the butterfly matrix alone cannot represent the entire orthogonal group, but it can approximate all orthogonal matrices of size $d$ if one multiplies together sufficiently many butterfly matrices and their transposes. Specifically, the theorem states that one can approximate all orthogonal matrices of size $d$ by computing the product $\bm{B}_{d-1,1}(d)\bm{B}^\top_{d-1,2}(d)\cdots\bm{B}_{1,1}(d)\bm{B}^\top_{1,2}(d)$, where each $\bm{B}_{i,j}(d)$ is a butterfly matrix. This product involves $d - 1$ pairs of butterfly matrices and their transposes, and it can represent the entire orthogonal group.

The significance of this result is twofold. First, it provides a formal guarantee that the butterfly parameterization is not a dead-end in terms of expressivity: by composing enough butterfly matrices, one can in principle approximate any orthogonal transformation. Second, it shows that the butterfly structure is a fundamentally richer parameterization than the block-diagonal structure, since the latter can never approximate certain dense orthogonal matrices regardless of how many copies are composed, due to its fixed sparsity pattern.

It is important to note, as the authors do, that better expressiveness does not always lead to better performance in finetuning. Full finetuning, despite its universal expressiveness (it can represent any weight matrix), often yields unsatisfactory performance due to overfitting, especially when the downstream task has limited data. The key to successful finetuning is finding the right trade-off between expressivity and regularity --- that is, between the ability to adapt to the downstream task and the ability to preserve the knowledge from pretraining. BOFT's advantage is not simply that it is more expressive than OFT, but that it provides a smoother and more controllable interpolation between the two extremes of full expressivity (the full orthogonal group) and full regularity (the identity matrix, which corresponds to no finetuning at all).

## Kaleidoscope Hierarchy: Generalizing BOFT to Represent the Entire Orthogonal Group

Theorem 1 suggests a natural generalization of BOFT that can represent the entire orthogonal group. This generalization is based on composing multiple BOFT matrices and their transposes in an alternating fashion, a construction that the authors connect to the concept of a kaleidoscope hierarchy.

The generalized orthogonal matrix is defined as $\bm{R}^G(m_1, b_1, m_2, b_2, l) = \bm{R}_{l,1}(m_1, b_1)\bm{R}_{l,2}^T(m_2, b_2)\cdots\bm{R}_{1,1}(m_1, b_1)\bm{R}_{1,2}^T(m_2, b_2)$, where $\bm{R}_{i,j}^T(m, b)$ denotes the transpose of the orthogonal matrix used in BOFT with parameters $m$ and $b$, and $l$ is the number of pairs in the composition. Each $\bm{R}_{i,j}(m, b)$ is an independent BOFT matrix with its own set of trainable parameters.

The critical insight is that when $m_1 = m_2 = \log d$, $b_1 = b_2 = 2$, and $l = d - 1$, the generalized matrix $\bm{R}^G(m_1, b_1, m_2, b_2, l)$ can represent the entire orthogonal group of size $d$. This means that, in principle, the kaleidoscope hierarchy provides a parameterization that is as expressive as a full, unconstrained orthogonal matrix, while still being built from structured, sparse components.

The name "kaleidoscope hierarchy" comes from prior work by Dao et al., who studied the use of such alternating compositions of butterfly matrices and their transposes to parameterize broad classes of linear transforms. The kaleidoscope pattern --- in which the structure of each factor mirrors and complements the structure of the next --- resembles the reflective symmetry of a kaleidoscope, hence the name. In the context of BOFT, the kaleidoscope hierarchy provides a principled way to scale up expressivity: each additional pair of BOFT matrices in the composition expands the set of representable transformations, and with enough pairs, the entire orthogonal group is covered.

However, the authors are careful to note that achieving full expressivity is not the goal of parameter-efficient finetuning. The kaleidoscope hierarchy is primarily of theoretical interest, as it demonstrates that the butterfly parameterization is not fundamentally limited in expressivity. In practice, one would typically use a single BOFT matrix with a moderate number of factors (far fewer than the $d - 1$ pairs needed for full expressivity), since the goal is to find a sweet spot between expressivity and regularity that generalizes well to the downstream task. The kaleidoscope hierarchy simply assures us that, if needed, we can always increase expressivity by adding more factors, without changing the fundamental structure of the parameterization.

This is in stark contrast to the block-diagonal OFT, where the only way to increase expressivity is to increase the block size $b$, which rapidly increases the parameter count (from $\mathcal{O}(bd)$ to $\mathcal{O}(d^2)$ as $b$ goes from a small constant to $d$) and which cannot achieve dense connectivity unless $b = d$. The kaleidoscope hierarchy, by enabling expressivity to be scaled up through the addition of structured factors rather than through the enlargement of unstructured blocks, provides a more graceful and parameter-efficient pathway to full expressivity.

## Spectral Properties: Preservation of the Spectral Norm of Pretrained Weights for Training Stability

One of the most important theoretical advantages of orthogonal finetuning, shared by both OFT and BOFT, is its favorable spectral properties. The spectral norm (also known as the largest singular value or the operator norm) of a weight matrix is a fundamental quantity that controls the Lipschitz constant of the corresponding linear layer. A smaller spectral norm implies that the layer is more contractive, which in turn leads to more stable training and better generalization, as has been established in prior work on spectral normalization and related techniques.

To understand why orthogonal finetuning preserves the spectral norm, consider the singular value decomposition (SVD) of the pretrained weight matrix $\bm{W}^0 \in \mathbb{R}^{d \times n}$: $\bm{W}^0 = \bm{U}\bm{\Sigma}\bm{V}^\top$, where $\bm{U} \in \mathbb{R}^{d \times d}$ and $\bm{V} \in \mathbb{R}^{n \times n}$ are orthogonal matrices, and $\bm{\Sigma} \in \mathbb{R}^{d \times n}$ is a diagonal matrix of singular values. The spectral norm of $\bm{W}^0$ is simply the largest entry of $\bm{\Sigma}$, which we denote as $\sigma_{\max}(\bm{W}^0)$.

In both OFT and BOFT, the finetuned weight matrix is obtained by left-multiplying $\bm{W}^0$ by an orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$, yielding $\bm{R}\bm{W}^0 = \bm{R}\bm{U}\bm{\Sigma}\bm{V}^\top$. Since $\bm{R}$ is orthogonal, the product $\bm{R}\bm{U}$ is also orthogonal (the product of two orthogonal matrices is orthogonal). Therefore, the SVD of $\bm{R}\bm{W}^0$ is $(\bm{R}\bm{U})\bm{\Sigma}\bm{V}^\top$, which has exactly the same singular value matrix $\bm{\Sigma}$ as $\bm{W}^0$. In particular, the largest singular value --- the spectral norm --- is unchanged: $\sigma_{\max}(\bm{R}\bm{W}^0) = \sigma_{\max}(\bm{W}^0)$.

This is a remarkable property: no matter what orthogonal transformation $\bm{R}$ is applied during finetuning, the spectral norm of the weight matrix remains exactly the same as in the pretrained model. This stands in sharp contrast to other finetuning methods such as LoRA, where the weight update is additive ($\bm{W}^0 + \Delta\bm{W}$) and can potentially increase the spectral norm, leading to instability. In LoRA, the spectral norm of the finetuned weights can grow unboundedly (depending on the magnitude of the low-rank update), which may require additional regularization such as spectral normalization to control.

The preservation of the spectral norm has been shown in prior work to greatly benefit both training stability and generalization. Intuitively, by keeping the spectral norm fixed, orthogonal finetuning ensures that the finetuned model does not become more sensitive to small perturbations in the input than the pretrained model. This prevents the explosion of gradients and activations that can occur when the spectral norm grows, and it also limits the capacity of the model to overfit to the downstream task, since the model's Lipschitz constant --- which bounds how much the output can change for a given change in the input --- remains the same as in the pretrained model.

It is worth noting that BOFT inherits this spectral preservation property from OFT, since the orthogonal matrix $\bm{R}(m, b)$ in BOFT is composed of a product of orthogonal butterfly components, and the product of orthogonal matrices is itself orthogonal. Therefore, regardless of the choice of $m$ and $b$, the spectral norm of the finetuned weights is always exactly preserved. This means that even as we vary the number of butterfly factors and the block size to trade off expressivity and parameter efficiency, we never sacrifice the spectral stability of the finetuning process.

## Orthogonal Finetuning as Learning a Bilinear Similarity Matrix with Strong Regularity

An insightful way to understand orthogonal finetuning --- and BOFT in particular --- is to view it through the lens of bilinear similarity learning. This perspective not only provides a deeper conceptual understanding of what orthogonal finetuning is doing, but also connects it to a rich body of literature in machine learning and mathematics.

Consider the forward pass of a linear layer with orthogonal finetuning. The output for the $i$-th neuron is $z_i = \bm{w}^0_i{}^\top \bm{R}^\top \bm{x} = \bm{w}^0_i{}^\top \bm{R}^\top \bm{x}$, where $\bm{w}^0_i$ is the $i$-th column of the pretrained weight matrix $\bm{W}^0$ (i.e., the $i$-th neuron), $\bm{R}$ is the learnable orthogonal matrix, and $\bm{x}$ is the input. Equivalently, we can write this as $z_i = \bm{w}^0_i{}^\top \bm{R}^\top \bm{x}$, which can be interpreted as computing a bilinear form between the neuron $\bm{w}^0_i$ and the input $\bm{x}$, mediated by the matrix $\bm{R}^\top$. More precisely, the expression $\bm{w}^0_i{}^\top \bm{R}^\top \bm{x}$ is a bilinear similarity: it measures the "similarity" between $\bm{w}^0_i$ and $\bm{x}$ under the transformation $\bm{R}^\top$.

This formulation reveals that orthogonal finetuning is fundamentally about learning a bilinear similarity matrix $\bm{R}$ that modulates the interaction between pretrained neurons and inputs. The key constraint that distinguishes orthogonal finetuning from general bilinear similarity learning is that $\bm{R}$ must be orthogonal, which imposes a strong form of regularity on the learned similarity. Orthogonality of $\bm{R}$ means that $\bm{R}^\top \bm{R} = \bm{I}$, which implies that the transformation $\bm{R}$ preserves distances and angles in the input space. In other words, $\bm{R}$ is an isometry: it does not stretch or compress any direction, and it does not change the angle between any pair of vectors. This is a much stronger constraint than, say, the low-rank constraint in LoRA, which merely limits the rank of the weight update but does not impose any geometric preservation guarantee.

The connection to distance metric learning is particularly illuminating. In distance metric learning, one learns a matrix $\bm{M}$ such that the distance $d(\bm{x}, \bm{y}) = (\bm{x} - \bm{y})^\top \bm{M} (\bm{x} - \bm{y})$ reflects the semantic similarity between inputs $\bm{x}$ and $\bm{y}$. Orthogonal finetuning can be seen as a special case of distance metric learning where the learned matrix $\bm{M} = \bm{R}^\top \bm{R}$ is constrained to be the identity (since $\bm{R}$ is orthogonal), meaning that the metric itself is preserved, but the representation of the neurons is rotated. This is a subtle but important distinction: instead of learning a new metric (which could distort the geometry of the input space), orthogonal finetuning learns a new "viewpoint" (a rotation) from which the pretrained neurons are evaluated. The regularity imposed by orthogonality ensures that this new viewpoint does not introduce any distortion.

The bilinear form perspective also connects to classical results in linear algebra. A bilinear form $\bm{u}^\top \bm{M} \bm{v}$ is a generalization of the inner product $\bm{u}^\top \bm{v}$ to allow for a "weighting" matrix $\bm{M}$. When $\bm{M}$ is orthogonal, the bilinear form reduces to evaluating the inner product after applying an isometric transformation to one of the arguments. This means that orthogonal finetuning is learning the optimal isometric transformation that aligns the pretrained neurons with the downstream task, without introducing any anisotropic scaling or shearing.

In the context of BOFT, the bilinear similarity matrix $\bm{R}$ is further structured through butterfly factorization. This adds another layer of regularity on top of orthogonality: not only is $\bm{R}$ constrained to be orthogonal, but it is also constrained to be decomposable into a product of sparse, structured factors. This hierarchical regularity --- orthogonality at the global level and sparsity at the factor level --- is what gives BOFT its favorable generalization properties. The structured prior on $\bm{R}$ biases the learned similarity toward transformations that have a known, interpretable structure (such as Fourier-like or Hadamard-like transforms), rather than arbitrary rotations.

## Inductive Bias and Generalization: The Implicit Benefits of Structured Classic Linear Transforms

The concept of inductive bias --- the set of assumptions that a learning algorithm makes about the structure of the problem --- is central to understanding why some finetuning methods generalize better than others. In this section, we explore the inductive bias introduced by the butterfly structure in BOFT and argue that this bias is beneficial for generalization.

The orthogonal matrix $\bm{R}(m, b)$ in BOFT does not represent the entire orthogonal group; rather, it represents a structured subset determined by the butterfly factorization. This structured subset is much smaller than the full orthogonal group (which has $\mathcal{O}(d^2)$ degrees of freedom), and it is also structured differently from the block-diagonal subset used in OFT. The choice of this subset constitutes an inductive bias: by restricting the hypothesis class to matrices that can be decomposed into butterfly factors, BOFT implicitly assumes that the optimal orthogonal transformation for the downstream task has a butterfly-like structure.

The question is whether this inductive bias is helpful or harmful. The authors argue that it is helpful, for several reasons. First, the butterfly structure has a shared structured pattern with many classic linear transforms that are known to be useful in signal processing and mathematics. Specifically, the discrete Fourier transform (DFT), the discrete cosine transform (DCT), the discrete sine transform (DST), and the Hadamard transform can all be perfectly represented (up to permutation) by butterfly matrices. These transforms have been extensively studied and are known to capture fundamental patterns in data --- periodicity (DFT), energy compaction (DCT), symmetry (DST), and orthogonal spreading (Hadamard). By parameterizing the orthogonal transformation with butterfly factors, BOFT implicitly biases the finetuning process toward transformations that are related to these classic, well-understood transforms.

This is in contrast to the block-diagonal structure in OFT, which cannot represent any of these classic transforms (unless the block size is equal to the full dimension $d$, in which case it reduces to an unconstrained orthogonal matrix). The block-diagonal structure assumes that the dimensions of the neuron can be partitioned into independent groups, which is an arbitrary and often unjustified assumption. The butterfly structure, on the other hand, assumes that the transformation can be decomposed into a hierarchy of local, structured interactions, which is a much more natural and well-motivated assumption.

Second, the sparse matrix factorization in BOFT may also bring some implicit inductive bias, beyond the explicit structure of the butterfly factors. Prior work has shown that sparse matrix factorization can lead to implicit regularization during optimization, biasing the learned solutions toward simpler, more generalizable patterns. This is related to the broader phenomenon of implicit regularization in deep learning, where the optimization algorithm (typically stochastic gradient descent) implicitly favors solutions with certain properties (such as low norm or low rank) even when these properties are not explicitly enforced. In the case of BOFT, the sparse factorization may implicitly favor orthogonal transformations that have a simpler, more structured decomposition, which could contribute to better generalization.

Third, the butterfly structure provides a smoother interpolation between expressivity and regularity than the block-diagonal structure. In OFT, the only knob for controlling the expressivity-regularity trade-off is the block size $b$: when $b$ is small, the transformation is highly regular but not very expressive; when $b$ is large, the transformation is more expressive but less regular. There is no smooth interpolation between these extremes --- one must choose a single block size, and the resulting transformation is either block-diagonal (for $b < d$) or fully dense (for $b = d$). In BOFT, there are two knobs: the block size $b$ and the number of factors $m$. By varying both, one can smoothly interpolate between a highly regular transformation (small $b$, small $m$) and a highly expressive transformation (small $b$, large $m$), without ever needing to resort to an unstructured dense matrix. This smooth interpolation allows for a more fine-grained control of the bias-variance trade-off, which is crucial for achieving good generalization on downstream tasks with varying amounts of data.

Finally, the authors note that the structured inductive bias of BOFT is particularly well-suited for finetuning large foundation models, which are typically pretrained on diverse, large-scale datasets and therefore have already learned rich, structured representations. The butterfly structure, by biasing the finetuning transformation toward classic linear transforms, respects and builds upon the structure already present in the pretrained weights, rather than overwriting it with an arbitrary rotation. This is consistent with the general philosophy of parameter-efficient finetuning: the goal is not to learn a completely new model from scratch, but to make a small, structured adjustment to the pretrained model that adapts it to the downstream task while preserving as much of the pretraining knowledge as possible.
