Chapter 5: The Orthogonal Butterfly (BOFT) Method

## Formulating the BOFT Forward Pass with the Product of Multiple Orthogonal Butterfly Components

The core of the Orthogonal Butterfly (BOFT) method lies in its reformulation of the forward pass during finetuning. Recall that in standard Orthogonal Finetuning (OFT), the pretrained weight matrix $\bm{W}^0 \in \mathbb{R}^{d \times n}$ is transformed by a single learnable orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$, modifying the forward pass from $\bm{z} = (\bm{W}^0)^\top \bm{x}$ to $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$. BOFT retains this multiplicative structure but replaces the monolithic orthogonal matrix $\bm{R}$ with a product of multiple sparse orthogonal matrices, each derived from the butterfly factorization.

Concretely, the orthogonal matrix in BOFT is constructed as $\bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$, where each $\tilde{\bm{B}}^b_{(d,i)}$ is an orthogonal butterfly component. The forward pass in BOFT is therefore given by $\bm{z} = \big(\bm{R}(m,b) \cdot \bm{W}^0\big)^\top \bm{x}$, subject to the constraint that each butterfly component satisfies $\big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top \tilde{\bm{B}}^b_{(d,j)} = \tilde{\bm{B}}^b_{(d,j)} \big(\tilde{\bm{B}}^b_{(d,j)}\big)^\top = \bm{I}_d$ for all $j \in [1, m]$. This constraint ensures that the product of these components remains orthogonal, preserving the key property of OFT that pairwise angles between neurons are maintained throughout finetuning.

To understand how each butterfly component is constructed, we begin with the butterfly factor $\bm{B}^F(k)$, defined for $k \geq 2$ (a power of 2) as a $k \times k$ matrix of the form $\begin{bmatrix} \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\ \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4) \end{bmatrix}$, where each $\bm{d}_i \in \mathbb{R}^{k/2}$. The butterfly matrix $\bm{B}(d) \in \mathbb{R}^{d \times d}$ is then defined recursively: $\bm{B}(d) = \tilde{\bm{B}}(d,d) \cdot \begin{bmatrix} \bm{B}_1(d/2) & \bm{0} \\ \bm{0} & \bm{B}_2(d/2) \end{bmatrix} = \tilde{\bm{B}}(d,d)\tilde{\bm{B}}(d,d/2) \cdots \tilde{\bm{B}}(d,2)$, where $\bm{B}_1(d/2)$ and $\bm{B}_2(d/2)$ are themselves butterfly matrices of half the dimension. The butterfly component $\tilde{\bm{B}}(d,k)$ is a block-diagonal matrix of size $d \times d$ with block size $k$, composed of butterfly factors: $\tilde{\bm{B}}(d,k) = \text{diag}(\bm{B}^F_1(k), \cdots, \bm{B}^F_{d/k}(k))$.

To ensure orthogonality of each butterfly component, BOFT generalizes the butterfly structure by introducing the block butterfly component $\tilde{\bm{B}}^b(d,k)$, where each scalar entry in the vectors $\bm{d}_i$ becomes a $b \times b$ matrix. For the base component $\tilde{\bm{B}}^b(d,2)$, orthogonality is guaranteed by parameterizing each $2b \times 2b$ block matrix as orthogonal using the Cayley transform: $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$, where $\bm{Q}$ is a skew-symmetric matrix ($\bm{Q} = -\bm{Q}^\top$). The non-zero pattern of every other butterfly component $\tilde{\bm{B}}^b(d,k)$ for $k > 2$ can be viewed as a permutation of the non-zero pattern of $\tilde{\bm{B}}^b(d,2)$, and therefore all butterfly components can similarly be parameterized as orthogonal matrices. This construction yields an efficient parameterization of a potentially dense orthogonal matrix built from many small $2b \times 2b$ orthogonal building blocks.

The notation $\tilde{\bm{B}}^b_{(d,i)}$ is used as shorthand for $\tilde{\bm{B}}^b(d, 2^{m-i+1})$, indexing the butterfly components in the product from $i = 1$ to $m$. This recursive, factorized construction is what allows BOFT to generate a dense orthogonal matrix — one that can mix information across all $d$ dimensions — while using far fewer trainable parameters than a fully dense orthogonal matrix would require.

## BOFT($m$,$b$) Notation and Its Relationship to the Block Size $b$ and Number of Components $m$

The notation BOFT($m$,$b$) provides a compact way to specify the configuration of the butterfly factorization used in finetuning. Here, $m$ denotes the number of orthogonal butterfly components in the product that constitutes the orthogonal matrix $\bm{R}(m,b)$, and $b$ controls the block size within each butterfly component. More precisely, the paper defines BOFT with $\bm{R}(m, \frac{b}{2})$ as BOFT($m$,$b$), where $b \geq 2$. This means that the parameter $b$ in the BOFT notation corresponds to twice the block size used in the underlying block butterfly component $\tilde{\bm{B}}^b(d,k)$.

The relationship between $m$ and $b$ is central to understanding the expressivity and parameter efficiency trade-offs in BOFT. The block size $b$ determines the granularity of each orthogonal building block: larger values of $b$ mean that each $2b \times 2b$ block in the butterfly component can represent a richer set of orthogonal transformations, but at the cost of more parameters per block. The number of components $m$ determines how many layers of sparse orthogonal transformations are composed: more components allow information to propagate more broadly across dimensions, increasing the density and expressivity of the final orthogonal matrix.

When $m$ is set to its maximum value of $\log \frac{2d}{b}$ (assuming $d$ is a power of 2), BOFT uses the full block butterfly matrix $\bm{B}^{b/2}(d)$ as $\bm{R}$, which yields a dense orthogonal matrix. This is the setting in which the product of butterfly components achieves full dense connectivity — every dimension in the input can influence every dimension in the output through the chain of sparse matrix multiplications. With fewer components (smaller $m$), the resulting matrix has a more restricted sparsity pattern, and the transformation is less expressive but more parameter-efficient.

The interplay between $m$ and $b$ also governs where BOFT falls on the spectrum between expressivity and regularity. The butterfly structure provides a smoother interpolation between the full orthogonal group (maximum expressivity, achieved when $m$ and $b$ are large) and the identity matrix (maximum regularity, achieved at initialization). This is in contrast to the block-diagonal structure of the original OFT, which provides a coarser trade-off: one either uses a single large block (full expressivity but many parameters) or many small blocks (fewer parameters but restricted expressivity). The butterfly structure's ability to achieve dense connectivity with multiple sparse factors is what makes this smoother interpolation possible.

## How BOFT Subsumes OFT as a Special Case

One of the elegant properties of BOFT is that it naturally subsumes the original OFT as a special case, providing a unified orthogonal finetuning framework. This subsumption occurs through specific choices of the parameters $m$ and $b$.

When $m = 1$, the orthogonal matrix $\bm{R}(m,b)$ reduces to a single butterfly component $\tilde{\bm{B}}^b(d,2)$, which is a block-diagonal matrix composed of $2b \times 2b$ orthogonal blocks. This is exactly the block-diagonal OFT with block size $b$, where the orthogonal transformation is applied independently within each block and dimensions in different blocks do not interact. Thus, BOFT($1$,$b$) is equivalent to block-diagonal OFT with block size $b$.

Furthermore, when $m = 1$ and $b = d$, the single butterfly component becomes a full $d \times d$ orthogonal matrix without any block-diagonal restriction. This corresponds to the original OFT with an unconstrained full orthogonal matrix, where every dimension can interact with every other dimension. Thus, BOFT($1$,$d$) recovers the original OFT in its most expressive form.

At the other extreme, when $m = \log \frac{2d}{b}$ and $b$ is kept small (e.g., $b = 2$), the product of many sparse butterfly components yields a dense orthogonal matrix — something that block-diagonal OFT can only achieve by setting $b = d$, which requires $\mathcal{O}(d^2)$ parameters. BOFT achieves this same dense connectivity with far fewer parameters by distributing the expressivity across multiple sparse factors rather than concentrating it in a single dense matrix.

This subsumption relationship highlights that BOFT is not merely an alternative to OFT but a generalization. The block-diagonal structure of OFT represents one point in the BOFT parameter space (specifically, the point where $m = 1$), while the butterfly structure opens up a richer family of orthogonal parameterizations that interpolate between the block-diagonal extreme and the fully dense extreme. The ability to control this interpolation through $m$ and $b$ is what gives BOFT its flexibility in balancing parameter efficiency against expressivity.

## Parameter Efficiency Analysis: Achieving $\mathcal{O}(d\log d)$ Parameters Compared to OFT's $\mathcal{O}(d^2)$

The parameter efficiency of BOFT is one of its most compelling advantages over the original OFT. To understand this, we must carefully account for the number of effective trainable parameters in each method.

The original OFT, when using a full dense orthogonal matrix of size $d \times d$, requires $\mathcal{O}(d^2)$ parameters. This is because a $d$-dimensional orthogonal matrix has $\frac{d(d-1)}{2}$ degrees of freedom (the dimension of the orthogonal group $O(d)$), which grows quadratically with $d$. For large foundation models where $d$ can be in the hundreds or thousands, this quadratic scaling makes full OFT impractical.

The block-diagonal OFT addresses this by partitioning the $d$-dimensional orthogonal matrix into $r$ blocks of size $b \times b$ (where $br = d$), reducing the parameter count to $\mathcal{O}(bd)$ — linear in $d$ for fixed $b$. However, as discussed earlier, this comes at the cost of expressivity: the block-diagonal structure cannot produce a dense orthogonal matrix unless $b = d$, which brings us back to $\mathcal{O}(d^2)$ parameters.

BOFT breaks this impudence by composing a dense orthogonal matrix from a product of $m$ sparse orthogonal butterfly components. The parameter count for BOFT($m$,$b$) is $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d \times n$. This formula arises because each butterfly component contains $d/b$ blocks of size $2b \times 2b$, and each such block, being orthogonal, has $b(2b-1)$ trainable parameters (from the skew-symmetric matrix in the Cayley parameterization, which has $\frac{2b(2b-1)}{2} = b(2b-1)$ free parameters). However, the effective number of trainable parameters per block is $\frac{1}{2}(b-1) \cdot 2b \cdot \frac{d}{2b} = \frac{(b-1)d}{2}$ per component, and with $m$ components, this gives $\frac{1}{2}(b-1)dm$.

When we use the full butterfly matrix — that is, $m = \log d$ and $b = 2$ — the parameter count becomes $\mathcal{O}(d \log d)$, which is a dramatic reduction from the $\mathcal{O}(d^2)$ parameters required by the original OFT with a dense orthogonal matrix. This logarithmic factor is the key insight: by trading computation time (performing $\mathcal{O}(\log d)$ matrix multiplications instead of one) for space (fewer trainable parameters), BOFT achieves parameter efficiency while maintaining the ability to produce a dense orthogonal transformation.

To put this in concrete terms, consider a layer with $d = 512$. The original OFT with a full orthogonal matrix would require on the order of $512^2 / 2 \approx 131{,}000$ parameters. BOFT with $m = \log_2 512 = 9$ and $b = 2$ would require approximately $\frac{1}{2}(2-1)(512)(9) = 2{,}304$ parameters — roughly a 57x reduction. This substantial parameter savings is what makes BOFT practical for finetuning large foundation models, where multiple layers each require their own orthogonal transformation.

The paper also provides empirical evidence of this parameter efficiency through a simulation approximating a random $512 \times 512$ dense orthogonal matrix. The results show that BOFT with smaller $b$ and larger $m$ is generally more parameter-efficient. For example, BOFT($9$,$2$) achieves better expressiveness than BOFT($1$,$16$) (block-diagonal OFT with block size 16) while using far fewer parameters. Similarly, BOFT($6$,$4$) uses much fewer parameters than BOFT($2$,$16$) while achieving a similar approximation error. These findings confirm that the butterfly structure represents a more structured and parameter-efficient subset of the orthogonal group compared to the block-diagonal structure.

## Identity Initialization for Butterfly Components to Start with the Exact Pretrained Model

A critical design principle in parameter-efficient finetuning is that the finetuning process should begin from the exact pretrained model, ensuring that the initial state of the finetuned model is identical to the pretrained model. This principle prevents catastrophic forgetting of pretraining knowledge and provides a stable starting point for optimization. In LoRA, this is achieved through zero initialization of the low-rank weight matrices, so that the initial weight update is zero and the model behaves exactly as the pretrained model at the start of finetuning.

BOFT achieves the same principle through identity initialization of all butterfly components. Since the orthogonal matrix $\bm{R}(m,b)$ is a product of butterfly components, initializing each component as an identity matrix ensures that the product $\bm{R}(m,b) = \bm{I}_d$ at initialization. Consequently, the forward pass at initialization becomes $\bm{z} = (\bm{I}_d \cdot \bm{W}^0)^\top \bm{x} = (\bm{W}^0)^\top \bm{x}$, which is exactly the forward pass of the pretrained model.

The identity initialization is implemented through the Cayley parameterization. Recall that each orthogonal block in the butterfly components is parameterized as $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$, where $\bm{Q}$ is a skew-symmetric matrix. When $\bm{Q} = \bm{0}$ (the zero matrix), the Cayley transform yields $\bm{R} = (\bm{I} + \bm{0})(\bm{I} - \bm{0})^{-1} = \bm{I} \cdot \bm{I}^{-1} = \bm{I}$. Therefore, by initializing all skew-symmetric matrices $\bm{Q}$ in every butterfly component to zeros, every block becomes an identity matrix, every butterfly component becomes an identity matrix, and the overall orthogonal matrix $\bm{R}(m,b)$ becomes the identity.

This initialization strategy is important for several reasons. First, it ensures that the finetuning process starts from a point where the model's behavior is unchanged from the pretrained model, which is essential for stable optimization. Second, because the orthogonal matrix starts as the identity and is constrained to remain orthogonal throughout training, the finetuned model can never deviate too far from the pretrained model in terms of the geometric structure of its weight matrices — the pairwise angles between neurons are preserved by the orthogonal transformation, and the transformation itself starts from the identity. Third, the identity initialization provides a natural regularization effect: the model must "learn" to move away from the identity, and the structure of the butterfly factorization constrains how it can do so, which helps prevent overfitting.

## Multiplicative Dropout: Adapting Dropout for Multiplicative Weight Updates by Replacing Blocks with Identity Matrices

Dropout is a widely used regularization technique in deep learning that prevents overfitting by randomly setting a fraction of activations or weights to zero during training. LoRA, for instance, employs a conventional dropout layer on the low-rank weight update to prevent overfitting. However, conventional dropout is designed for additive weight updates and does not naturally extend to the multiplicative weight updates used in BOFT.

The challenge arises because BOFT updates the pretrained weight matrix multiplicatively: $\bm{W} = \bm{R}(m,b) \cdot \bm{W}^0$. Simply zeroing out elements of $\bm{R}(m,b)$ would violate the orthogonality constraint, potentially destabilizing training and destroying the geometric properties that BOFT is designed to preserve. A different dropout mechanism is needed that is compatible with the multiplicative structure and the orthogonality of the butterfly components.

BOFT addresses this by introducing a multiplicative dropout mechanism that leverages the structure of the butterfly factorization. The orthogonal matrix $\bm{R}(m,b)$ is composed of $m$ orthogonal butterfly components, and each butterfly component is a block-diagonal matrix that can be permuted into $2b \times 2b$ block-diagonal orthogonal matrices. The multiplicative dropout operates by randomly selecting $p_1$ percent of the butterfly components and, within each selected component, randomly selecting $p_2$ percent of the diagonal blocks. These selected blocks are then replaced with identity matrices.

Replacing a block with an identity matrix is equivalent to "dropping out" the orthogonal transformation in that block — the transformation becomes the identity, which means no transformation is applied. This is the multiplicative analog of zeroing out a weight in additive methods: in additive methods, zeroing a weight means no contribution is added; in multiplicative dropout, replacing with identity means no transformation is applied. Because the identity matrix is itself orthogonal, this replacement preserves the orthogonality of the overall butterfly component and, consequently, of the full orthogonal matrix $\bm{R}(m,b)$.

The two-level dropout — at both the component level ($p_1$) and the block level ($p_2$) — provides fine-grained control over the regularization strength. Dropping out entire butterfly components ($p_1$) reduces the depth of the information transmission path, effectively simplifying the transformation during training. Dropping out individual blocks within components ($p_2$) further reduces the complexity of each layer's transformation. Together, these mechanisms encourage the model to learn robust transformations that do not rely on any single butterfly component or block, improving generalization.

This multiplicative dropout is a natural fit for the BOFT framework because it respects the structural properties of the butterfly factorization. It does not break orthogonality, it operates on the same building blocks that define the parameterization, and it provides the same regularization benefits as conventional dropout does for additive methods. By randomly "bypassing" parts of the orthogonal transformation during training, the model is encouraged to distribute its learned transformations across multiple components and blocks, rather than overfitting to a specific configuration of the butterfly structure.
