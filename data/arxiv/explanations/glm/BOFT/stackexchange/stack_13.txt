\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Why is it impossible for block-diagonal OFT to recover classic linear transforms?
Question:
The BOFT paper argues that "the butterfly structure can easily recover many classic linear transforms while it is impossible for the block-diagonal structure in OFT to recover any." They use this to argue that BOFT has better inductive bias.

I understand that butterfly matrices are structurally related to FFT, but:
1. Why is it mathematically impossible for block-diagonal matrices to represent transforms like FFT, DCT, or Hadamard transforms? Is it because these transforms require mixing across all dimensions, while block-diagonal only mixes within blocks?
2. Does this impossibility result stem purely from the sparsity pattern, or also from the orthogonality constraint?
3. How significant is this limitation for practical finetuning tasks - is recovering classic transforms actually relevant, or is this more of a theoretical motivation?
Answer:
The impossibility stems fundamentally from the **sparsity pattern** of the block-diagonal structure, not from the orthogonality constraint, and your intuition about mixing across dimensions is exactly right.

A block-diagonal orthogonal matrix in OFT has the form $\text{diag}(\bm{R}_1, \bm{R}_2, \cdots, \bm{R}_r)$ where each $\bm{R}_i \in \mathbb{R}^{b \times b}$ is an orthogonal matrix and $b \cdot r = d$. By definition, this matrix has zeros in every off-diagonal block, meaning that output dimension $j$ in block $i$ can only depend on input dimensions within the same block $i$. There is no information flow between blocks.

Classic transforms like the FFT, DCT, and Hadamard transform are **dense** — every output dimension depends on every input dimension. For example, the Discrete Fourier Transform matrix has entries $F_{jk} = e^{-2\pi i jk/d}$, which are non-zero for all $(j,k)$ pairs. The Hadamard matrix has entries $\pm 1/\sqrt{d}$ everywhere. Since these transforms have non-zero entries in positions that are structurally forced to be zero in any block-diagonal matrix with block size $b < d$, no such block-diagonal matrix can represent them — regardless of what values the non-zero blocks take.

Importantly, this impossibility has nothing to do with the orthogonality constraint. In fact, the FFT, DCT, and Hadamard transforms are themselves orthogonal (or unitary), so orthogonality is perfectly compatible with them. The barrier is purely structural: the block-diagonal sparsity pattern prohibits cross-block mixing, while these transforms require universal mixing. If OFT sets $b = d$ (a single block), it becomes a full $d \times d$ orthogonal matrix that **can** represent these transforms — but this requires $\mathcal{O}(d^2)$ parameters, defeating the purpose of parameter efficiency. The paper notes this explicitly: "the original OFT has to use the block size $b=d$ to generate a dense orthogonal matrix, while BOFT can use any $b$ to achieve this."

The butterfly structure, by contrast, factorizes a dense matrix into $\mathcal{O}(\log d)$ sparse matrices, each with $\mathcal{O}(d)$ non-zero entries. Through the recursive composition of these sparse factors, information from every source node can reach every receiver node across $\mathcal{O}(\log d)$ stages. This is precisely the property that enables the Cooley-Tukey FFT algorithm: the butterfly network achieves dense connectivity with only $\mathcal{O}(d \log d)$ edges, and the resulting matrix product is dense. As the paper states, "the butterfly structure along with permutations can perfectly recover many classic fast linear transforms."

Regarding practical significance, recovering classic transforms is **not** literally required by downstream finetuning tasks. The paper is transparent about this — it uses the FFT/DCT/Hadamard recovery property as a **theoretical motivation** for why butterfly factorization provides a better inductive bias. The deeper argument is about the expressivity-regularity trade-off: block-diagonal OFT constrains dimensions to interact only within arbitrary index-based groups, which "makes no sense to divide the dimensions of a neuron into $r$ groups based on their indices," whereas BOFT enables mixing across all dimensions while still maintaining a structured, parameter-efficient hypothesis class. The practical benefit is that BOFT can produce dense orthogonal matrices with $\mathcal{O}(d \log d)$ parameters instead of $\mathcal{O}(d^2)$, and the simulation results in the paper (Figure 2) confirm that BOFT achieves better approximation of random orthogonal matrices than block-diagonal OFT at the same parameter budget. The classic-transform recovery argument serves to justify that this structural choice is not arbitrary — it aligns with a family of transforms that have proven fundamental across signal processing and linear algebra, lending it a principled inductive bias that the block-diagonal structure lacks.
