\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does BOFT(1,b) mathematically reduce to block-diagonal OFT?
Question:
In the BOFT paper, they claim that when $m=1$, BOFT($1$,$b$) reduces to the block-diagonal OFT with block size $b$. The forward pass is defined as $z = (R(m,b) \cdot W^0)^T x$ where $R(m,b) = \prod_{i=1}^m \tilde{B}^b_{(d,i)}$. When $m=1$, this becomes $R(1,b) = \tilde{B}^b_{(d,1)}$. The paper also defines $\tilde{B}^b_{(d,i)}$ as shorthand for $\tilde{B}^b(d, 2^{m-i+1})$. 

I'm struggling to trace through the notation to see how this single butterfly component equals a block-diagonal matrix with block size $b$. Can someone walk through this reduction step by step, clarifying the notation?
Answer:
# How BOFT$(1,b)$ Reduces to Block-Diagonal OFT

The key to tracing this reduction lies in a subtle notational convention and understanding how the butterfly factor's block generalization works. Let me walk through it step by step.

## The Notational Convention

The paper states: *"For convenience, we denote BOFT with $R(m,\frac{b}{2})$ as BOFT$(m,b)$, where $b\geq 2$."* This means BOFT$(1,b)$ actually uses the function $R(1, \frac{b}{2})$, not $R(1, b)$. This offset by $\frac{b}{2}$ is crucial and easy to miss.

## Tracing the Reduction

Starting from $R(m, b') = \prod_{i=1}^m \tilde{B}^{b'}_{(d,i)}$ with the shorthand $\tilde{B}^{b'}_{(d,i)} = \tilde{B}^{b'}(d, 2^{m-i+1})$, we substitute $m=1$ and $b' = \frac{b}{2}$:

$$R\left(1, \frac{b}{2}\right) = \tilde{B}^{\frac{b}{2}}_{(d,1)} = \tilde{B}^{\frac{b}{2}}\left(d, 2^{1-1+1}\right) = \tilde{B}^{\frac{b}{2}}(d, 2)$$

Now we need to understand what $\tilde{B}^{\frac{b}{2}}(d, 2)$ looks like. The block butterfly component $\tilde{B}^{b'}(d, k)$ is a block-diagonal matrix whose blocks are generalized butterfly factors $B^F(k)$, where each scalar entry in the original factor is replaced by a $b' \times b'$ matrix.

The original butterfly factor for $k=2$ is:

$$B^F(2) = \begin{bmatrix} d_1 & d_2 \\ d_3 & d_4 \end{bmatrix} \in \mathbb{R}^{2 \times 2}$$

where each $d_i$ is a scalar (since $d_i \in \mathbb{R}^{k/2} = \mathbb{R}^1$). When generalized with block parameter $b' = \frac{b}{2}$, each scalar entry becomes a $\frac{b}{2} \times \frac{b}{2}$ matrix, so the generalized factor becomes a $b \times b$ matrix:

$$B^F(2) = \begin{bmatrix} D_1 & D_2 \\ D_3 & D_4 \end{bmatrix} \in \mathbb{R}^{b \times b}$$

where each $D_i \in \mathbb{R}^{\frac{b}{2} \times \frac{b}{2}}$.

## The Final Structure

Since $\tilde{B}^{\frac{b}{2}}(d, 2)$ is block-diagonal with blocks of size $b \times b$, we get:

$$R\left(1, \frac{b}{2}\right) = \tilde{B}^{\frac{b}{2}}(d, 2) = \text{diag}\left(R_1, R_2, \ldots, R_{d/b}\right)$$

where each $R_i \in \mathbb{R}^{b \times b}$ is a $b \times b$ orthogonal matrix. The paper states that *"to guarantee the block butterfly component $\tilde{B}^b(d,2)$ to be orthogonal, we parameterize each $2b \times 2b$ block matrix to be orthogonal"* — in our case with parameter $\frac{b}{2}$, each $b \times b$ block is parameterized as orthogonal via Cayley transform.

This is precisely the block-diagonal OFT with block size $b$: $\text{diag}(R_1, R_2, \cdots, R_r)$ where $R_i \in \mathbb{R}^{b \times b}$ and $br = d$, exactly as defined in the original OFT.

## Intuitive Summary

The reduction works because with $m=1$, there is only a single butterfly component (no factorization into multiple sparse matrices). That single component has the smallest possible butterfly factor size $k=2$, and when generalized with block parameter $\frac{b}{2}$, the $2 \times 2$ factor with $\frac{b}{2} \times \frac{b}{2}$ matrix entries produces $b \times b$ blocks on the diagonal. The $\frac{b}{2}$ offset in the notation convention is precisely calibrated so that BOFT$(1,b)$ yields blocks of size $b$, matching block-diagonal OFT.
