\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Where does the formula $\frac{1}{2}(b-1)dm$ for BOFT parameter count come from?
Question:
The BOFT paper states that "BOFT($m$,$b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters for finetuning a linear layer of size $d \times n$." I'm trying to understand where this formula comes from.

I understand the general setup:
- There are $m$ butterfly components $\tilde{B}^b_{(d,i)}$
- Each component uses Cayley parameterization with skew-symmetric matrices
- The orthogonality constraint reduces parameters

But I can't figure out:
1. Why the factor of $\frac{1}{2}(b-1)$? Is this related to the dimension of skew-symmetric matrices of size $b \times b$?
2. How does the $d$ factor appear when we have block-diagonal structures?
3. Why isn't $n$ (the output dimension) involved in the parameter count, given we're finetuning a $d \times n$ layer?

Could someone break down this calculation step by step?
Answer:
The formula $\frac{1}{2}(b-1)dm$ comes from counting the free parameters in the skew-symmetric matrices used to parameterize the orthogonal blocks across all butterfly components. Let me break this down step by step.

**The block structure.** In BOFT($m$,$b$), the notation means we use $\bm{R}(m, \frac{b}{2})$, i.e., $m$ butterfly components with block parameter $\frac{b}{2}$. Each butterfly component $\tilde{\bm{B}}^{b/2}_{(d,i)}$ is a block-diagonal matrix of size $d \times d$. The butterfly factor $\bm{B}^F(2)$, when generalized with block parameter $\frac{b}{2}$, becomes a $b \times b$ matrix (since each scalar entry becomes a $\frac{b}{2} \times \frac{b}{2}$ block, and the $2 \times 2$ structure of $\bm{B}^F(2)$ yields $2 \times \frac{b}{2} = b$ per dimension). The block-diagonal $\tilde{\bm{B}}^{b/2}(d,2)$ therefore contains $\frac{d}{b}$ such blocks, each of size $b \times b$. The paper confirms this when it states that each "$2b \times 2b$ block matrix" is parameterized as orthogonal — in BOFT($m$,$b$) the analogous blocks are $b \times b$.

**The $\frac{1}{2}(b-1)$ factor.** Each $b \times b$ block must be orthogonal, which is enforced via the Cayley parameterization $\bm{R} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$ where $\bm{Q}$ is a $b \times b$ skew-symmetric matrix ($\bm{Q} = -\bm{Q}^\top$). A $b \times b$ skew-symmetric matrix has zeros on the diagonal and is determined by its upper-triangular entries, giving $\frac{b(b-1)}{2}$ free parameters. Dividing by the block size $b$ gives $\frac{b-1}{2}$, which is the per-dimension parameter cost of each orthogonal block.

**The $d$ factor.** Since there are $\frac{d}{b}$ blocks per butterfly component, each requiring $\frac{b(b-1)}{2}$ parameters, the total per component is $\frac{d}{b} \times \frac{b(b-1)}{2} = \frac{(b-1)d}{2}$. This is where $d$ enters: it is the total input dimension being partitioned into $\frac{d}{b}$ blocks, and the parameter count scales linearly with $d$ regardless of block size.

**The $m$ factor.** BOFT uses $m$ butterfly components $\tilde{\bm{B}}^{b/2}_{(d,1)}, \ldots, \tilde{\bm{B}}^{b/2}_{(d,m)}$, each contributing $\frac{(b-1)d}{2}$ parameters. Multiplying by $m$ gives the total: $\frac{1}{2}(b-1)dm$.

**Why $n$ does not appear.** The orthogonal matrix $\bm{R}(m,b) \in \mathbb{R}^{d \times d}$ acts only on the $d$-dimensional input space. The forward pass is $\bm{z} = (\bm{R}(m,b) \cdot \bm{W}^0)^\top \bm{x}$, where $\bm{W}^0 \in \mathbb{R}^{d \times n}$ is frozen. Since all trainable parameters reside in $\bm{R}$, which is $d \times d$, the output dimension $n$ has no bearing on the parameter count.

**Sanity checks.** For BOFT($1$,$b$), which reduces to block-diagonal OFT with block size $b$, the formula gives $\frac{(b-1)d}{2}$ — exactly $\frac{d}{b}$ blocks each needing $\frac{b(b-1)}{2}$ parameters. For BOFT($\log d$, $2$), it gives $\frac{d \log d}{2}$, matching the $\mathcal{O}(d \log d)$ claim. For BOFT($1$,$d$), which reduces to original OFT with a full orthogonal matrix, it gives $\frac{d(d-1)}{2} \approx \mathcal{O}(d^2)$, the correct parameter count for a $d \times d$ orthogonal matrix parameterized via a skew-symmetric matrix.
