\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### Why Attention-Based Models Fail

Transformers use content-based attention: they compute attention weights from query-key interactions and retrieve weighted averages of values. While this allows flexible retrieval over a context window, the update mechanism itself does not depend on the model's current internal state in a recurrent manner. The attention computation is a function of the input representations, not of a running state that evolves based on its own previous values. This is analogous to a lookup table rather than a state machine — you can retrieve information, but you cannot perform state-conditional updates where the update rule itself depends on what is currently stored.

The xLSTM paper's contribution through the sLSTM is to preserve this memory mixing capability (with the addition of exponential gating for improved expressiveness), while the mLSTM sacrifices it in exchange for parallelizability. The paper's experiments on formal language tasks (Section 3.1) demonstrate that architectures with memory mixing (LSTM, sLSTM) can solve state tracking tasks, while those without (Transformers, SSMs, mLSTM alone) cannot, confirming the theoretical predictions.
