\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 10: Controllable Generation: Experiments and Analysis

## Task Setup: C2I on COCO, S2I on ADE20K, L2F on CelebA-HQ

The controllable generation experiments are designed to evaluate how effectively the Orthogonal Finetuning (OFT) framework can adapt a pretrained text-to-image diffusion model to accept additional control signals beyond text prompts. The general task setting follows the paradigm established by ControlNet and T2I-Adapter, where the goal is to finetune a pretrained diffusion model so that it can generate images guided by both a text prompt and an additional spatial control signal, such as edge maps, segmentation maps, or facial landmarks. Three distinct controllable generation tasks are considered in the main experiments, each chosen to challenge different aspects of controllability and generation fidelity.

The first task is Canny edge-to-image (C2I) generation, evaluated on the COCO dataset. In this task, the control signal is a Canny edge map extracted from a source image. The finetuned model must generate a photorealistic image that is semantically consistent with the text prompt while simultaneously respecting the structural boundaries specified by the edge map. This task is particularly challenging because Canny edges provide only sparse structural information, leaving the model to hallucinate textures, colors, and fine details that are not explicitly specified by the control signal. The COCO dataset, with its diverse collection of natural scene images, provides a broad testbed for evaluating how well different finetuning methods can balance structural adherence with generation fidelity.

The second task is segmentation map-to-image (S2I) generation, evaluated on the ADE20K dataset. Here, the control signal is a semantic segmentation map, where each pixel is assigned a category label indicating the object or region it belongs to. The finetuned model must generate an image where the spatial layout of objects and regions matches the segmentation map. This task demands a higher degree of spatial precision than C2I, as the segmentation map provides explicit categorical and spatial information that the generated image must respect. The ADE20K dataset is particularly well-suited for this evaluation because it contains a rich variety of indoor and outdoor scenes with complex spatial arrangements and a large number of semantic categories.

The third task is landmark-to-face (L2F) generation, evaluated on the CelebA-HQ dataset. In this task, the control signal consists of facial landmarks specifying the locations of key facial features such as eyes, nose, mouth, and face contour. The finetuned model must generate a face image where the facial features align precisely with the given landmarks, which may specify challenging or unusual face poses. This task tests the model's ability to perform fine-grained geometric control, as even small misalignments in facial landmarks can produce visually implausible results. The CelebA-HQ dataset provides high-quality face images that serve as training data for learning this precise spatial correspondence.

Across all three tasks, the base pretrained model used is Stable Diffusion v1.5. All finetuning methods are trained for 20 epochs on each dataset, ensuring a consistent training budget for fair comparison. The control signals are processed and provided as additional conditioning inputs to the diffusion model, and the finetuning objective is to learn how to incorporate these spatial control signals into the image generation process while maintaining the high-fidelity generation capabilities of the pretrained model.

## Baselines: ControlNet, T2I-Adapter, LoRA

To provide a comprehensive evaluation, the OFT framework is compared against three state-of-the-art baselines that represent different philosophies for adapting pretrained diffusion models to controllable generation tasks.

ControlNet is a prominent method that finetunes a pretrained diffusion model by creating a trainable copy of the model's encoding layers, which processes the additional control signal. The trainable copy is connected to the frozen pretrained model through zero-convolution layers that are initialized to produce zero outputs, ensuring that finetuning starts from the pretrained model's behavior. ControlNet has demonstrated impressive controllable generation performance, but it introduces a significant number of additional trainable parameters and adds computational overhead during inference due to the extra network components. The ControlNet architecture processes control signals through a parallel network branch that interacts with the main diffusion model at multiple layers, enabling rich integration of spatial information but at the cost of increased model complexity.

T2I-Adapter is a concurrent approach that similarly finetunes a pretrained diffusion model to accept additional control signals. Like ControlNet, T2I-Adapter introduces additional network components to process control signals and integrate them with the pretrained model. However, T2I-Adapter is designed to be somewhat lighter than ControlNet, using adapter modules that insert control signal information into the diffusion model's intermediate representations. Despite this architectural difference, T2I-Adapter still introduces additional parameters and computational overhead, and the paper's results show that it converges slowly and yields worse final results compared to OFT.

LoRA (Low-Rank Adaptation) represents a fundamentally different approach. Rather than adding new network components, LoRA finetunes the pretrained model by learning low-rank additive updates to the existing weight matrices. Specifically, LoRA assumes that the weight update during finetuning has a low-rank structure and parameterizes the update as the product of two small matrices. This approach is parameter-efficient and introduces no additional inference overhead, as the low-rank updates can be merged into the original weights. However, the low-rank constraint may limit the expressiveness of the finetuning update. In the context of controllable generation, LoRA is applied to the attention weights of the diffusion model, following the same layers where OFT is applied to ensure a fair comparison.

For fairness across all comparisons, OFT and COFT are applied to the same layers where LoRA is used, specifically the attention weights of the diffusion model. This ensures that any performance differences between OFT and LoRA can be attributed to the finetuning strategy rather than differences in which layers are being adapted. All methods use the best possible hyperparameter settings identified through careful tuning, and the same pretrained Stable Diffusion v1.5 model serves as the starting point for all finetuning experiments.

## Convergence Analysis: Faster and Smoother Convergence Compared to Baselines

One of the most striking empirical findings of the OFT framework is its convergence behavior, which is both faster and smoother than existing methods. This is demonstrated through both quantitative and qualitative evaluations, with a particular focus on the landmark-to-face (L2F) task as a representative benchmark.

For the quantitative convergence analysis, the evaluation metric used is the mean $\ell_2$ distance between the control face landmarks (the input control signal) and the predicted face landmarks extracted from the generated images. This metric directly measures how accurately the generated faces align with the specified landmark positions. The face landmark error is plotted for models finetuned with different numbers of training epochs, providing a clear picture of how quickly each method achieves accurate control.

The results reveal that both COFT and OFT achieve significantly faster convergence compared to all baselines. Most notably, it takes 20 epochs for LoRA to converge to the performance level that the OFT framework achieves at only the 8th epoch. This represents a substantial reduction in training time and computational cost. Furthermore, OFT and COFT achieve this faster convergence while using a similar number of trainable parameters as LoRA and far fewer parameters than ControlNet, demonstrating that the efficiency gains come from the principled structure of orthogonal transformation rather than from increased model capacity.

The convergence behavior of ControlNet exhibits a qualitatively different pattern that the paper describes as a "sudden convergence phenomenon." Specifically, ControlNet shows minimal controllability improvement during the early epochs, and then its controllability suddenly emerges after approximately the 8th epoch. This abrupt transition in training dynamics makes it difficult to predict when the model will start performing well and can lead to wasted training resources if the training is stopped prematurely. In contrast, the convergence of OFT and COFT is smooth and gradual, with consistent improvement in control accuracy throughout training.

The qualitative convergence results further illustrate this difference. For OFT and COFT, the generated face poses gradually and consistently align with the control landmarks as training progresses, producing a smooth transition from poor control to accurate control. The training dynamics are predictable and monotonic, making it straightforward to determine when training has reached a satisfactory level. For ControlNet, the controllability appears abruptly between epochs, which matches the sudden convergence phenomenon described in the original ControlNet work. This qualitative observation reinforces the practical advantage of OFT: the smooth and predictable training dynamics make it much easier to find good hyperparameters and determine when to stop training.

The practical implications of this convergence behavior are significant. In real-world applications, the number of training epochs is a critical hyperparameter that must be tuned for each task and dataset. Methods with smooth and predictable convergence, such as OFT and COFT, reduce the burden of hyperparameter tuning because the training trajectory is monotonic and stable. Methods with sudden or unpredictable convergence, such as ControlNet, require more careful monitoring and tuning to achieve optimal results. The insensitivity of OFT and COFT to the exact number of finetuning iterations is a particularly valuable property, as it effectively alleviates the need to tune the iteration count for different control tasks.

## Data Efficiency: OFT Converges with 5% of Training Data

Beyond convergence speed in terms of training epochs, the OFT framework demonstrates remarkable data efficiency, meaning it can achieve good performance with significantly fewer training images than existing methods. This property is especially important in practical scenarios where collecting large-scale training data for specific control tasks may be costly or impractical.

The data efficiency of OFT is demonstrated through experiments showing that OFT can converge well with only 5% of the ADE20K dataset for the segmentation-to-image (S2I) task. This is a dramatic reduction in training data requirements compared to baselines such as ControlNet and LoRA, which require substantially more data to achieve comparable performance. The ability to converge with such a small fraction of the training data suggests that the orthogonal transformation approach effectively leverages the knowledge encoded in the pretrained model, requiring only minimal additional information from the control task training data to learn the new control behavior.

This data efficiency can be understood through the lens of the OFT design philosophy. Because OFT preserves the hyperspherical energy of the pretrained model, it maintains the pretrained model's generative capabilities while learning a relatively constrained transformation to adapt to the new control task. The orthogonal transformation has fewer degrees of freedom compared to unconstrained finetuning, which means the model has less flexibility to deviate from the pretrained behavior. While this might seem like a limitation, it actually serves as a strong inductive bias that prevents overfitting to small training datasets. The pretrained model already contains rich knowledge about image generation, and OFT only needs to learn how to incorporate the control signal into this existing knowledge framework.

In contrast, methods like ControlNet introduce large additional network components with many trainable parameters. These additional parameters provide greater flexibility but also require more training data to be properly tuned, as there is more capacity that needs to be filled with meaningful information. LoRA, while more parameter-efficient than ControlNet, still faces challenges with data efficiency because its low-rank update structure may not align as effectively with the types of changes needed for controllable generation.

The data efficiency of OFT has important practical implications. For practitioners working on new controllable generation tasks, the ability to achieve good performance with limited training data means faster development cycles, lower data collection costs, and broader applicability to specialized domains where large-scale datasets may not be available. This property also suggests that OFT may be particularly well-suited for fine-grained or domain-specific control tasks where the available training data is inherently limited.

## Control Consistency Metric: Estimating Control Signals from Generated Images

A key methodological contribution of the paper is the introduction of a novel control consistency metric for evaluating controllable generation performance. Traditional evaluation of controllable generation has relied primarily on qualitative visual assessment or indirect metrics that do not directly measure how well the generated images follow the input control signals. The control consistency metric addresses this limitation by providing a quantitative measure of control accuracy.

The fundamental idea behind the control consistency metric is to estimate the control signal from the generated image and then compare this estimated control signal with the original input control signal. If the finetuned model has successfully learned to follow the control signal, then extracting the same type of control signal from the generated image should yield a result that closely matches the original input. This approach provides a direct and intuitive measure of control fidelity, as it evaluates whether the structural information specified by the control signal is actually present in the generated image.

For the Canny edge-to-image (C2I) task, the control consistency metric is computed using Intersection over Union (IoU) and F1 score. After generating an image from a given Canny edge map, a Canny edge detector is applied to the generated image to extract its edge map. This extracted edge map is then compared with the original input edge map using IoU, which measures the overlap between the two edge maps, and F1 score, which balances precision and recall of edge detection. A high IoU and F1 score indicate that the generated image contains edges that closely match the input control signal, demonstrating strong control fidelity.

For the segmentation-to-image (S2I) task, the control consistency metric is computed using mean IoU, mean accuracy, and overall accuracy. After generating an image from a given segmentation map, a segmentation model is applied to the generated image to produce a predicted segmentation map. This predicted segmentation map is then compared with the original input segmentation map. Mean IoU computes the average IoU across all semantic categories, providing a per-category measure of segmentation fidelity. Mean accuracy computes the average pixel-wise classification accuracy per category, while overall accuracy computes the global pixel-wise classification accuracy across the entire image. These metrics collectively capture how well the spatial and categorical structure of the segmentation map is preserved in the generated image.

For the landmark-to-face (L2F) task, the control consistency metric is computed using the mean $\ell_2$ distance between the control landmarks and predicted landmarks. After generating a face image from a given set of facial landmarks, a landmark detection model is applied to the generated face to extract predicted landmarks. The mean $\ell_2$ distance between the original control landmarks and these predicted landmarks is then computed, with a smaller distance indicating more accurate control. This metric directly measures the geometric fidelity of the generated face with respect to the specified landmark positions.

The control consistency metric represents a significant contribution to the evaluation methodology for controllable generation. By using off-the-shelf detection and segmentation models to estimate control signals from generated images, this metric provides an objective, reproducible measure of control performance that does not rely on subjective human evaluation. The accuracy of this metric is, of course, bounded by the accuracy of the off-the-shelf models used for control signal estimation, but these models are sufficiently accurate to provide meaningful comparisons between different finetuning methods. This metric enables rigorous quantitative evaluation of controllable generation and can be applied to any method that generates images from spatial control signals.

## Quantitative Comparison: IoU, F1, Mean IoU, Accuracy, $\ell_2$ Distance

The quantitative comparison using the control consistency metric provides a comprehensive evaluation of how OFT and COFT compare to existing methods across all three controllable generation tasks. The results demonstrate that both OFT and COFT yield significantly stronger and more accurate control than the baseline methods.

For all compared methods, the best possible hyperparameter settings are used to ensure a fair comparison. This means that each baseline is given every opportunity to achieve its best performance, and any superiority of OFT or COFT can be attributed to the finetuning strategy itself rather than suboptimal hyperparameter choices. The quantitative results consistently show that OFT and COFT outperform the baselines across multiple metrics and tasks.

The adapter-based approaches, specifically T2I-Adapter and ControlNet, are observed to converge slowly and also yield worse final results compared to OFT and COFT. This is a notable finding, as ControlNet in particular has been widely regarded as a strong method for controllable generation. The slower convergence of these methods means they require more training time and computational resources to reach their final performance, and even after full training, their control accuracy falls short of what OFT achieves. The additional network components introduced by these methods apparently do not translate to better control performance, suggesting that the key bottleneck is not model capacity but rather the finetuning strategy's ability to effectively adapt the pretrained model.

The comparison with LoRA reveals an interesting pattern of task-dependent performance. LoRA performs better than ControlNet in the S2I task but worse in both the C2I and L2F tasks. This variable performance across tasks suggests that LoRA's low-rank adaptation strategy has an inconsistent ability to capture the types of transformations needed for different control tasks. In the S2I task, the relatively structured nature of segmentation maps may align well with low-rank updates, while the sparse structural information in Canny edges and the precise geometric requirements of facial landmarks may demand more expressive transformations that LoRA's low-rank constraint cannot adequately provide. In general, the paper finds that the performance ceiling of LoRA is relatively low, meaning that even with careful hyperparameter tuning, LoRA is unable to match the performance of OFT and COFT.

In contrast, the performance of the OFT framework shows that it has not yet saturated at the level of performance reported. The authors empirically find that OFT continues to improve as the number of trainable parameters increases, suggesting that the orthogonal transformation approach has a higher performance ceiling than the compared baselines. This is an important finding, as it indicates that OFT has greater potential for further improvement through scaling, whereas the baseline methods may have already reached their performance limits within the experimental settings.

The quantitative evaluation using the control consistency metric is highlighted as one of the novel contributions of the paper, as it provides a rigorous and objective way to evaluate control performance. Previous evaluations of controllable generation have often relied on qualitative visual comparisons or indirect metrics that do not directly measure control fidelity. The control consistency metric, by directly estimating and comparing control signals, provides a more meaningful assessment of how well each method achieves the fundamental goal of controllable generation: producing images that faithfully follow the specified control signals.

## Qualitative Comparison Across All Three Control Tasks

Beyond the quantitative metrics, the paper provides extensive qualitative comparisons that offer intuitive insights into the strengths and weaknesses of each method. Randomly generated images are used for all qualitative comparisons, ensuring that the examples are representative of typical performance rather than being cherry-picked.

In the segmentation-to-image (S2I) task, the qualitative comparison reveals stark differences between methods. LoRA completely fails to generate images that follow the input segmentation map, producing images that bear little structural resemblance to the specified spatial layout. This aligns with the quantitative findings where LoRA, despite performing better than ControlNet on S2I metrics, still falls significantly short of OFT and COFT. ControlNet, OFT, and COFT are all able to control the generated images according to the segmentation map, but the quality of the generated images differs substantially. Both OFT and COFT are able to generate high-fidelity images with more vivid details and more reasonable geometric structures compared to ControlNet. This is particularly noteworthy because OFT and COFT achieve this superior quality with far fewer model parameters than ControlNet, demonstrating that the orthogonal transformation approach is more parameter-efficient while also producing better visual results.

In the Canny edge-to-image (C2I) task, both OFT and COFT are able to hallucinate semantically similar images based on the rough Canny edge inputs. The term "hallucinate" here refers to the model's ability to generate plausible textures, colors, and fine details that are not explicitly specified by the sparse edge map but are consistent with the structural information it provides. T2I-Adapter and LoRA perform much worse in this task, struggling to produce images that are both visually coherent and structurally consistent with the input edges. The superior performance of OFT and COFT in this task can be attributed to their ability to effectively modify the semantic generation behavior of the pretrained model while preserving its high-fidelity generation capabilities. The orthogonal transformation adjusts the directions of neurons to incorporate the control signal information, while the preservation of hyperspherical energy ensures that the pretrained model's ability to generate realistic images is not destroyed.

In the landmark-to-face (L2F) task, OFT and COFT produce the most accurate pose control for generated faces, even under challenging face poses. The ability to handle challenging poses is particularly important, as it tests the model's ability to generalize beyond the range of poses commonly seen in training data. The precise geometric control achieved by OFT and COFT is consistent with the quantitative findings showing low $\ell_2$ landmark distances. The qualitative results show that the generated faces not only align with the specified landmark positions but also maintain realistic facial features and expressions, demonstrating that the control is achieved without sacrificing generation quality.

Across all three control tasks, the qualitative comparisons consistently show that both OFT and COFT produce qualitatively better images than the state-of-the-art baselines. This consistent superiority across diverse tasks—ranging from sparse edge control to dense semantic segmentation to precise geometric landmark control—demonstrates the robustness and versatility of the OFT framework. The orthogonal transformation approach appears to be well-suited to a wide range of controllable generation scenarios, as it provides a principled way to adapt the pretrained model's behavior without compromising its generative capabilities.

The qualitative results also illustrate the practical benefits of OFT's stable convergence. Because OFT and COFT converge smoothly and predictably, the final models consistently produce high-quality results without the variance and instability that can affect methods with less predictable training dynamics. This reliability is important for practical deployment, where consistent performance across different inputs and conditions is essential.

## Additional Control Tasks: Dense Pose, Sketch, Depth to Image

Beyond the three main controllable generation tasks evaluated in the main paper, the OFT framework is also demonstrated on additional control tasks to showcase its versatility. These additional experiments, presented in the appendix, include dense pose-to-human-body generation, sketch-to-image generation, and depth-to-image generation. Each of these tasks represents a different type of spatial control signal, further testing the generality of the OFT approach.

Dense pose-to-human-body generation uses dense pose maps as control signals, which specify detailed body surface keypoints and their correspondences to a 3D human body model. This task requires the model to generate human body images that match the specified pose, which is a more complex form of geometric control compared to facial landmarks. The dense pose representation provides rich information about body configuration, and the model must translate this abstract representation into a photorealistic human body image. The ability of OFT to handle this task demonstrates that the orthogonal transformation approach can scale to control signals with higher-dimensional and more complex spatial structures.

Sketch-to-image generation uses free-form sketches as control signals. Unlike Canny edges, which are automatically extracted from images using edge detection algorithms, sketches are typically hand-drawn and may not correspond to any specific source image. This task requires the model to interpret artistic or approximate sketches and generate images that match the intended content while maintaining realistic appearance. The challenge here is that sketches can be highly variable in style and precision, and the model must be robust to this variability while maintaining control fidelity. The application of OFT to this task shows that the framework can handle control signals that are qualitatively different from the structured signals used in the main experiments.

Depth-to-image generation uses depth maps as control signals, specifying the 3D structure of the scene from a particular viewpoint. The model must generate an image that is consistent with the depth information, which requires understanding of 3D geometry and its projection onto 2D image space. Depth maps provide complementary information to segmentation maps and edge maps, focusing on the geometric structure rather than semantic content or boundary information. The successful application of OFT to depth-to-image generation further confirms that the framework is not limited to a specific type of control signal but can be broadly applied to various forms of spatial conditioning.

The demonstration of OFT on these additional control tasks serves multiple purposes. First, it validates the generality of the OFT framework, showing that it is not specialized for a particular type of control signal but can be applied across a wide range of controllable generation scenarios. Second, it provides practical evidence that the orthogonal transformation approach effectively preserves the pretrained model's generative capabilities while learning to incorporate new types of spatial information. Third, it suggests that OFT can be a drop-in replacement for existing finetuning methods in controllable generation pipelines, offering better performance and stability without requiring task-specific modifications to the finetuning strategy.

The breadth of tasks to which OFT can be successfully applied also speaks to the fundamental soundness of the approach. By preserving the pairwise angles between neurons through orthogonal transformation, OFT maintains the structural knowledge of the pretrained model across diverse control scenarios. This structural preservation appears to be a universal requirement for effective finetuning, regardless of the specific type of control signal being used. The consistent success of OFT across all tested tasks supports the paper's central hypothesis that hyperspherical energy preservation is a crucial property for maintaining the semantic generation ability of text-to-image diffusion models during finetuning.
