\title{Stack Exchange of the Paper: ByteLatent}

### How is causal correctness enforced when decoding bytes from patch representations?
Question:
In the local decoder, the decoder first performs cross-attention from byte queries to patch keys/values, then applies a decoder Transformer layer. Since patches summarize multiple future bytes within the same patch, how do you ensure that decoding remains strictly autoregressive at the byte level? Is the cross-attention restricted so that byte position $i$ can only attend to patch information consistent with bytes $\le i$? Or do you rely on the fact that $o_j$ is produced by a global autoregressive model at the patch level, and the local decoder only conditions on the current patch representation and the previously generated bytes, thereby preserving causality?
Answer:
Short answer: causality is preserved by the combination of (1) the latent/global transformer being autoregressive at the patch level (block‑causal attention), and (2) the local decoder doing strictly autoregressive byte‑level self‑attention. The decoder’s cross‑attention is allowed to read the full patch representation $o_j$ because that representation itself was produced causally (it does not contain information from future patches), and the decoder’s byte autoregression prevents a byte from depending on bytes that have not yet been emitted.

Why this is enough (intuitive + technical):

The global model $G$ produces a sequence of patch outputs $o_1, o_2, \ldots$ using a block‑causal attention mask (Section “Latent Global Transformer”). That mask guarantees $o_j$ can only depend on patches up to $j$ (no information from future patches leaks into $o_j$). So every patch representation that the decoder can see is already causal at the patch granularity.

At the finer (byte) granularity the local decoder $D$ operates autoregressively. The decoder’s layers alternate cross‑attention and standard decoder Transformer layers; the decoder Transformer layers implement causal self‑attention over bytes (they “predict a sequence of raw bytes, as a function of previously decoded bytes” — Section “Local Decoder”). This ensures any byte prediction can only condition on previously generated bytes via the decoder’s self‑attention path.

Putting those two facts together: when decoding a byte at position $i$ inside some patch $j$, the decoder may cross‑attend to $o_j$ (and earlier $o_{\le j}$) but $o_j$ only encodes information available up to patch $j$; any dependency on earlier bytes inside the current patch $i'<i$ is enforced through the decoder’s causal self‑attention (the byte queries are initialized from encoder hidden states and then updated autoregressively). Thus there is no path by which a byte can access future byte values: future patches are blocked at the latent level, and future bytes inside the same patch cannot be injected via cross‑attention because decoder self‑attention is causal and the $o_j$ are patch‑level summaries rather than ground‑truth future bytes.

The paper therefore relies on the global model’s patch‑level autoregressiveness plus the local decoder’s autoregressive byte modeling to preserve strict byte‑level causality, rather than applying an extra per‑byte masking in the cross‑attention to forbid attending to parts of a patch. This design simplifies the cross‑attention (keys/values = patch representations) while keeping generation provably autoregressive because the only source of “future” information would be $o_{>j}$ (blocked) or future bytes inside the same patch (blocked by causal decoder self‑attention).
