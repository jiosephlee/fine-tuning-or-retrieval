# Fine-tune on the "winner" texts only, so π_ref matches the observed distribution
def tokenize_winner(batch):
    return ref_tokenizer(batch["prompt"], batch["winner"], truncation=True, padding="max_length")
ref_ds = pref_ds.map(tokenize_winner, batched=True)
ref_trainer = Trainer(
    model=ref_model,
    args=TrainingArguments(output_dir="ref_imputed", num_train_epochs=1, per_device_train_batch_size=8),
    train_dataset=ref_ds,
)
ref_trainer.train()
ref_trainer.save_model("ref_imputed")
```

## Step 4: Training with the DPO Loss

Having $\pi_\text{ref}$ and your preference dataset, we now define and optimize the DPO objective. Intuitively, we want our policy $\pi_\theta$ to make the winner more likely than the loser by the right margin, while remaining close to $\pi_\text{ref}$. Concretely, DPO minimizes:

  
  $$\mathcal{L}_\text{DPO} = -\mathbb{E}_{(x,y_w,y_l)}\Bigl[\log \sigma\bigl(\beta\,\log \tfrac{\pi_\theta(y_w\mid x)}{\pi_\text{ref}(y_w\mid x)} \;-\; \beta\,\log \tfrac{\pi_\theta(y_l\mid x)}{\pi_\text{ref}(y_l\mid x)}\bigr)\Bigr],$$

where $\beta$ controls how tightly we stay near $\pi_\text{ref}$.

### Implementing the Loss in PyTorch

Below is a minimal training loop showing how to compute this loss. We assume you have a fresh model `policy_model` initialized from your SFT checkpoint.

```python
import torch
from torch.nn.functional import sigmoid, log_softmax

beta = 0.1
optimizer = torch.optim.AdamW(policy_model.parameters(), lr=5e-5)

for epoch in range(num_epochs):
    for batch in pref_dataloader:
        # Tokenize winner and loser as inputs for policy_model and ref_model
        inputs_w = policy_tokenizer(batch["prompt"], batch["winner"], return_tensors="pt", truncation=True, padding=True)
        inputs_l = policy_tokenizer(batch["prompt"], batch["loser"],  return_tensors="pt", truncation=True, padding=True)

        # Compute log‐probs under policy
        logits_w = policy_model(**inputs_w).logits
        logits_l = policy_model(**inputs_l).logits
        # Similarly for ref model
        with torch.no_grad():
            ref_logits_w = ref_model(**inputs_w).logits
            ref_logits_l = ref_model(**inputs_l).logits

        # Sum log‐probs over sequence length (we assume causal LM)
        logp_w = log_softmax(logits_w, -1).gather(-1, inputs_w["input_ids"].unsqueeze(-1)).squeeze(-1).sum(-1)
        logp_l = log_softmax(logits_l, -1).gather(-1, inputs_l["input_ids"].unsqueeze(-1)).squeeze(-1).sum(-1)

        ref_logp_w = log_softmax(ref_logits_w, -1).gather(-1, inputs_w["input_ids"].unsqueeze(-1)).squeeze(-1).sum(-1)
        ref_logp_l = log_softmax(ref_logits_l, -1).gather(-1, inputs_l["input_ids"].unsqueeze(-1)).squeeze(-1).sum(-1)

        # Compute the implicit reward differences
        r_w = beta * (logp_w - ref_logp_w)
        r_l = beta * (logp_l - ref_logp_l)
        diff = r_w - r_l

        # DPO loss
        loss = -torch.log(sigmoid(diff)).mean()

        optimizer.zero_grad()
        loss.backward()
        optimizer.step()
```

A few notes on the code:

  • We sum the log-probabilities across tokens to get $\log \pi(y\mid x)$.  
  • We keep the reference model in `.eval()` and under `torch.no_grad()` so it does not get updated.  
  • The scalar $\beta$ scales how strongly policy deviations are penalized.  

## Logging and Monitoring KL
