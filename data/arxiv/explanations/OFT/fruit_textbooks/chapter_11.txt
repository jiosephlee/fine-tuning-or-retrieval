\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 11: Evaluation Protocols and Metrics

# Subject-driven metrics

When evaluating subject-driven generation (the task of generating images of a specific subject given a few example images plus a text prompt), the paper reports four <|endoftext|> automatic metrics. These metrics measure different aspects of the finetuned <|endoftext|> behavior: how well the generated images preserve the subject identity, how well they follow the text prompt, and how diverse the generated samples are. All metrics in the paper are computed over sets of generated images sampled randomly from each finetuned model (the paper emphasizes random sampling to avoid cherry-picking).

1. DINO (subject fidelity)
   - DINO here refers to <|endoftext|> produced by a ViT S/16 network trained with the DINO self-supervised method. The paper uses DINO <|endoftext|> as a measure of visual similarity that emphasizes <|endoftext|> structure.
   - Concretely, if we denote by $e_{\text{DINO}}(x)$ the DINO <|endoftext|> of image $x$, the DINO subject-fidelity score used in the paper is an average cosine similarity between <|endoftext|> of generated images and corresponding real subject images. A typical computation is
     \[
       \text{DINO-score} = \frac{1}{N}\sum_{i=1}^N \cos\big(e_{\text{DINO}}(\text{gen}_i),\, e_{\text{DINO}}(\text{real}_i)\big),
     \]
     where $\cos(a,b)=\dfrac{a\cdot b}{\|a\|\|b\|}$ and the index $i$ runs over generated/real image pairs used for evaluation. Higher values indicate stronger preservation of the subject identity according to DINO features.

2. CLIP-I (image–image subject fidelity)
   - CLIP-I uses CLIP image <|endoftext|> to measure how closely generated images match real images of the subject. The paper describes CLIP-I as "the average pairwise cosine similarity of CLIP <|endoftext|> between generated and real images."
   - Using the CLIP image <|endoftext|> function $e_{\text{CLIP}}(\cdot)$, the CLIP-I score is computed analogously to DINO:
     \[
       \text{CLIP-I} = \frac{1}{N}\sum_{i=1}^N \cos\big(e_{\text{CLIP}}(\text{gen}_i),\, e_{\text{CLIP}}(\text{real}_i)\big).
     \]
   - This metric focuses on whether the generated image looks like the same subject as in the reference images when judged in CLIP's multimodal <|endoftext|> space.

3. CLIP-T (text–image prompt fidelity)
   - CLIP-T measures how well generated images match the target text prompt. The paper computes the average cosine similarity between the CLIP image <|endoftext|> of the generated image and the CLIP text <|endoftext|> of the prompt.
   - If $t$ is the text prompt and $e_{\text{CLIP}}^{\text{text}}(t)$ is its CLIP text <|endoftext|> then
     \[
       \text{CLIP-T} = \frac{1}{N}\sum_{i=1}^N \cos\big(e_{\text{CLIP}}(\text{gen}_i),\, e_{\text{CLIP}}^{\text{text}}(t_i)\big),
     \]
     where $t_i$ is the prompt used for the $i$-th generated image. Higher CLIP-T indicates better adherence to the textual instruction.

4. LPIPS (sample diversity)
   - The paper uses LPIPS to assess diversity among generated samples for the same subject and the same prompt. LPIPS is a perceptual distance; the paper reports an average LPIPS-based measure between generated image pairs.
   - For a set of generated images $\{\text{gen}_1,\dots,\text{gen}_m\}$ produced for the same subject and prompt, the diversity score is computed as the average pairwise LPIPS distance (or average over pairwise LPIPS-based cosine similarities as described in the paper). A standard form is
     \[
       \text{LPIPS-diversity} =
         \frac{2}{m(m-1)}\sum_{1\le i<j\le m} \text{LPIPS}(\text{gen}_i,\text{gen}_j).
     \]
   - Larger LPIPS distances indicate more diverse outputs. In the paper this metric complements the identity/prompt-fidelity metrics to ensure the model does not trivially collapse to identical outputs.

Practical notes from the <|endoftext|> evaluation practice: to reduce randomness effects when reporting final scores, the authors repeated finetuning on the same <|endoftext|> model with 30 different random seeds and averaged results. For qualitative displays, the paper selects the finetuned <|endoftext|> that achieves the best validation CLIP metrics, but images shown are randomly sampled from that chosen <|endoftext|>

# Control consistency metrics

For controllable generation (where the model must respect an additional control signal such as an edge map, segmentation map, or landmark set), the paper introduces a unified "control consistency" evaluation approach: estimate the control signal from the generated image using an off-the-shelf predictor, then compare that estimated signal with the original input control. This measures whether the generation actually follows the control input, and the comparison uses task-appropriate metrics.

General <|endoftext|> denote the original control input as $C_{\text{in}}$ and a deterministic estimator (off-the-shelf model) that extracts the control from an image as $E(\cdot)$. Given a generated image $\hat{x}$, the recovered control is $\hat{C}=E(\hat{x})$. The control consistency score is obtained by applying a comparison function $\Delta(C_{\text{in}},\hat{C})$ appropriate to the control type. The paper uses:

1. Edges (Canny edge to image — C2I; dataset: COCO)
   - Comparison metrics: Intersection-over-Union (IoU) and F1 score between the predicted edges and input edges.
   - If $C_{\text{in}}$ and $\hat{C}$ are binary edge maps, IoU is
     \[
       \text{IoU} = \frac{|C_{\text{in}} \cap \hat{C}|}{|C_{\text{in}} \cup \hat{C}|},
     \]
     and the F1 score (harmonic mean of precision and recall) is calculated from true positives, false positives, and false negatives derived from the two maps.
   - These metrics quantify how accurately the generated image reproduces the edge structure supplied to the model.

2. Segmentation maps (S2I; dataset: ADE20K)
   - Comparison metrics: mean Intersection-over-Union (mIoU), mean per-class accuracy, and overall pixel accuracy.
   - Given $K$ <|endoftext|> classes, for each class $k$ compute IoU$_k$; then
     \[
       \text{mIoU} = \frac{1}{K}\sum_{k=1}^K \text{IoU}_k.
     \]
     Mean per-class accuracy averages class-wise correct-prediction rates, and overall accuracy is the fraction of correctly predicted pixels across the whole dataset. These standard segmentation measures quantify whether objects and regions in the generated image match the required <|endoftext|> layout.

3. Landmarks (L2F: landmarks to face; dataset: CelebA-HQ)
   - Comparison metric: mean $\ell_2$ distance between control landmarks and landmarks predicted from the generated image.
   - If the control provides landmark coordinates $\{p_1,\ldots,p_M\}$ and the recovered landmarks are $\{\hat{p}_1,\ldots,\hat{p}_M\}$, the metric reported is
     \[
       \text{mean-} \ell_2 = \frac{1}{M}\sum_{j=1}^M \|p_j - \hat{p}_j\|_2,
     \]
     averaged over test images. Lower mean-$\ell_2$ indicates more accurate pose/landmark control.

Implementation notes and caveats stated in the paper:
- The recovered control $\hat{C}$ is obtained by running an off-the-shelf predictor <|endoftext|> edge detector, <|endoftext|> segmentation model, or landmark detector) on the generated image. Thus the control consistency scores depend both on the generator's faithfulness to the control and on the accuracy of the estimator $E(\cdot)$. The paper explicitly notes that the evaluation is accurate "up to the accuracy of the off-the-shelf segmentation/detection model."
- The paper evaluates three control tasks (C2I on COCO, S2I on ADE20K, L2F on CelebA-HQ) and reports the control-consistency metrics above. These provide a direct, task-specific assessment of how well finetuning methods produce outputs that follow the input control.

# Convergence speed and stability tracking

Beyond final scores, the paper places strong emphasis on training dynamics: how fast a finetuning method reaches good performance and how stable training is across iterations/epochs. Two related but distinct aspects are tracked:

1. Convergence speed
   - The paper compares methods by plotting task-specific metrics (for example, mean landmark $\ell_2$ error for L2F) as a function of training epochs or iterations. Convergence speed can be quantified as the number of epochs or iterations required to reach a target level of performance (or to match the final performance of a baseline).
   - Empirical findings from the paper: OFT and COFT converge significantly faster than competing methods. For example, in the landmarks-to-face task, OFT/COFT reach LoRA's final performance in substantially fewer epochs (the paper reports that LoRA requires about 20 epochs to reach the performance that OFT achieves by the 8th epoch). Similar faster convergence is reported for other control tasks and for subject-driven finetuning.

2. Stability (training dynamics)
   - Stability refers to whether training progresses smoothly and whether the finetuned model avoids sudden collapse or large degradations as training proceeds. The paper inspects curves of validation metrics over time to judge stability.
   - Key observations reported: OFT and COFT show smooth, stable improvement in control-consistency and fidelity metrics; in contrast, some <|endoftext|> exhibit abrupt transitions or eventual collapse. Specific examples cited in the paper include DreamBooth and LoRA sometimes failing to preserve identity or producing collapsed images after extended training (the paper reports that after 2000 iterations DreamBooth begins to generate collapsed images in one experiment, while OFT/COFT remain stable). For a control task (L2F), ControlNet's controllability "suddenly emerges" after a certain epoch (the 8th in the reported experiment), whereas OFT/COFT improve more smoothly.

Practical measurement details from the paper:
- The paper evaluates stability and convergence both quantitatively (metric curves vs epoch/iteration) and qualitatively (visual inspection at intermediate checkpoints). For subject-driven generation, iteration-level behavior is reported <|endoftext|> performance at 400 and 2000 iterations); for controllable generation, epoch-level behavior is plotted <|endoftext|> landmark error versus epochs).
- To reduce variance in these dynamics assessments, the authors repeated finetuning runs with multiple random seeds (30 seeds for subject-driven quantitative comparisons) and report aggregated performance.

# Human evaluation considerations

The paper supplements automatic metrics with human evaluation (reported in the Appendix) to further validate the perceptual quality and controllability advantages of OFT. Although the main text does not detail the full human-evaluation protocol, the paper highlights that human judgments corroborate the superior perceptual and control qualities seen in automatic measures.

Two empirical practices related to human and qualitative evaluation are explicitly described in the paper and guide interpretation of automatic metrics:
- Random sampling of generations for display and human assessment. The paper emphasizes using randomly picked generated images to avoid selection bias when comparing methods qualitatively or in human studies.
- Model selection for qualitative presentation uses validation CLIP metrics: for each method, the <|endoftext|> chosen for showing qualitative examples is the one achieving the best validation CLIP scores. This aligns shown qualitative outputs with the <|endoftext|> objectively measured best validation performance.

A caution noted in the paper about automatic control-consistency metrics applies equally to human evaluation: any evaluation that infers a control signal from the generated image inherits limitations from the tools used (detectors, segmenters, landmark predictors) and from the diversity of prompts/inputs sampled. Thus human evaluation is used as additional evidence because it can capture perceptual aspects that automatic metrics may miss.

# Summary

The paper combines several <|endoftext|> evaluation procedures to rigorously validate finetuning methods for text-to-image diffusion models. For subject-driven generation the authors use DINO and CLIP image <|endoftext|> to measure subject fidelity, CLIP text–image similarity for prompt fidelity, and LPIPS for sample diversity. For controllable generation they introduce a principled control-consistency approach: recover the control signal from the generated image with an off-the-shelf estimator and compare it to the original control using task-specific metrics (IoU/F1 for edges, mIoU and accuracies for segmentation, mean $\ell_2$ for landmarks). Crucially, the paper evaluates not only final scores but also convergence speed and training stability (plotting metrics vs iterations/epochs and aggregating over multiple random seeds), and corroborates automatic results with human evaluation. The authors explicitly note dependencies and limitations of the control-consistency approach (it is bounded by the accuracy of the estimator used to recover controls), and they take steps (random sampling, multiple seeds, validation-based model selection) to ensure fair and robust comparisons.
