Concretely, with $\bm{R}=\bm{I}$ we have $\bm{W}=\bm{W}^0$ and the forward behavior is identical to the pretrained network.

For convolutional layers, the block structure of $\bm{R}$ admits useful interpretations. If the number of blocks equals the number of input channels, each block transforms a specific channel-subspace independently; this is analogous to learning depthwise channel transforms, similar in spirit to depthwise convolutions that operate per-channel. If blocks are shared across channels, OFT applies a common orthogonal rotation across channels. Thus the block-diagonal parameterization provides a natural way to apply OFT to convolutional kernels while controlling parameterization and computational cost. In short, OFT is flexible enough to be used wherever the linear mapping can be expressed as a matrix multiply by pretrained weights.

This parameterization guarantees orthogonality (and, strictly speaking, produces orthogonal matrices with determinant $+1$, i.e., elements of the special orthogonal group) and is differentiable with respect to $\bm{Q}$. A practical detail is that computing $(\bm{I}-\bm{Q})^{-1}$ requires a matrix inversion, which can become costly for large $d$. OFT tackles this by combining Cayley parameterization with block-diagonal structure for $\bm{R}$ so that each block has smaller size and the inverses are cheaper.

Orthogonal Finetuning reframes finetuning as learning global orthogonal coordinate changes per layer that preserve pairwise angular relations among neurons. The rationale is that neuron directions (phase-like information) encode primary semantic content, and pairwise angular structure captures that content in a robust way; orthogonal transforms change neuron directions globally without altering those pairwise angular relationships. OFT implements this by replacing pretrained weights $\bm{W}^0$ with $\bm{R}\bm{W}^0$, initializes $\bm{R}$ to identity to start exactly at the pretrained model, and uses efficient differentiable parameterizations (Cayley plus block-diagonal structure) to keep optimization and parameter counts practical. The approach applies naturally to fully connected, attention, and convolutional layers and admits a fold-into-weights step so there is no inference overhead. These properties together explain OFT's stability and practical utility for controlling large pretrained text-to-image diffusion models.

A practical advantage of OFT is that it introduces no additional runtime cost at inference. The learned orthogonal matrices are multiplicative transforms of pretrained weights. Once finetuning is complete, one can fold the learned transform into the weight tensors and replace the original pretrained parameters with the finetuned ones:

\[
\bm{z} = \bm{W}^\top \bm{x} = (\bm{R}\,\bm{W}^0)^\top \bm{x}.
\]

Block-diagonalization reduces the number of free parameters and enforces a structured sparsity in the transform: each block rotates a subspace of the input independently, interpolating between full-layer orthogonality ($r=1$) and channel-wise independent transforms ($r=d$, if each block is of size $1$). This parameter reduction also serves as a strong regularizer that keeps finetuning stable while retaining the hyperspherical invariance property for each block. The block-diagonal parameterization still yields an orthogonal matrix (a direct sum of orthogonal blocks), and therefore the layerwise HE invariance still holds.

A central goal of OFT is to finetune a pretrained model while preserving the semantic structures that the pretrained model encodes. Rather than using Euclidean distance between weight matrices as the primary measure of preservation, OFT uses a structural measure that captures pairwise relationships among neurons: hyperspherical energy. For a weight matrix $\bm{W} = [\bm{w}_1,\dots,\bm{w}_n]\in\mathbb{R}^{d\times n}$, where each column $\bm{w}_i\in\mathbb{R}^d$ is a neuron, define the normalized neuron vectors $\hat{\bm{w}}_i := \bm{w}_i / \|\bm{w}_i\|$. The invariance property that makes orthogonal transformations attractive is simple and powerful: orthogonal transforms preserve norms and inner products. If $\bm{R}\in\mathbb{R}^{d\times d}$ is orthogonal (i.e., $\bm{R}^\top \bm{R} = \bm{I}$), then for any neuron $\bm{w}_i$ we have $\|\bm{R}\bm{w}_i\| = \|\bm{w}_i\|$ and for any pair $i,j$ the cosine of the angle between $\bm{R}\bm{w}_i$ and $\bm{R}\bm{w}_j$ equals the cosine between $\bm{w}_i$ and $\bm{w}_j$. The block-diagonal strategy trades parameter count and compute against flexibility. A full orthogonal $\bm{R}\in\mathbb{R}^{d\times d}$ has $\tfrac{d(d-1)}{2}$ degrees of freedom. With $r$ equal-sized blocks, the number of parameters becomes $\frac{d(d/r - 1)}{2}$, i.e. the complexity is roughly $\mathcal{O}(d^2/r)$. Blocks can also be shared across layers or channels in order to further reduce parameter count, down to roughly $\mathcal{O}(d^2/r^2)$ in extreme sharing scenarios. This allows OFT to be tuned for different compute/parameter budgets.

Because $\bm{R}$ is shared for all neurons in the layer, it performs a global rotation/reflection of the input coordinate system for that layer: all neurons are rotated by the same orthogonal transform. This keeps pairwise angles unchanged and enforces a structured, global change in neuron directions rather than independent arbitrary perturbations. From another perspective, we are changing the canonical basis in which the pretrained neurons are expressed; the transformation is multiplicative (left-multiplication by $\bm{R}$) rather than additive.

To give a concrete numerical illustration (as in the OFT study): for a weight matrix of size $128\times128$, LoRA with low-rank $r'=8$ uses about $2{,}048$ trainable parameters, whereas OFT with block count $r=8$ uses about $960$ trainable parameters. Thus OFT can be competitive or superior in parameter efficiency while still enforcing the hyperspherical invariance property.

Thus, by constraining the finetuned weights to be orthogonal transforms of the pretrained weights, OFT achieves exact invariance of hyperspherical energy. Preserving hyperspherical energy is the proxy OFT uses for preserving the semantic generation ability of the pretrained diffusion model: the pairwise angular relations among neurons encode crucial directional (phase-like) semantic information, and orthogonal transforms alter neuron directions in a globally consistent way without breaking those angular relationships.

When an even tighter constraint on deviation from identity is desired (the COFT variant), the Cayley parameterization is convenient: small $\bm{Q}$ implies $\bm{R}\approx\bm{I}+2\bm{Q} + \mathcal{O}(\bm{Q}^2)$ via a Neumann-series approximation of $(\bm{I}-\bm{Q})^{-1}$, and so constraining $\|\bm{Q}\|$ bounds $\|\bm{R}-\bm{I}\|$. This lets practitioners limit the radius of change around the pretrained weights in a computationally tractable manner by projecting $\bm{Q}$ back into a small norm ball during optimization.
