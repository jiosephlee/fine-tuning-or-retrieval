Chapter Title: Parameter Efficiency in Orthogonal Finetuning versus Low-Rank Adaptation

# Overview of Finetuning Strategies and Their Parameterization

Text-to-image diffusion models are powerful but require finetuning to adapt to downstream tasks such as subject-driven generation and controllable generation. Two contrasting approaches to parameter-efficient finetuning emerge in the literature: low-rank additive updates and orthogonal multiplicative transforms. Low-Rank Adaptation (LoRA) modifies pretrained weights by adding a low-rank matrix, thereby constraining the update to lie in a low-dimensional subspace. Orthogonal Finetuning (OFT) transforms pretrained weights by left-multiplying a learned orthogonal matrix that is shared at the layer level, thereby preserving pairwise neuron angles and hyperspherical energy.

The distinction between additive and multiplicative updates leads to fundamentally different parameterization strategies. LoRA introduces a trainable low-rank factorization with rank hyperparameter $r'$, which directly scales the number of parameters with input and output dimensions. In contrast, OFT introduces a trainable orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ for each finetuned layer, and then uses structured parameterizations of $\bm{R}$ to control efficiency while exactly preserving the angular relationships among neurons.

The central question in this chapter is how the number of trainable parameters scales with the neuron dimension $d$, and under what conditions OFT achieves only linear-in-$d$ growth while LoRA scales much more rapidly. We will build this result step by step by first formalizing the OFT parameterization, then counting trainable parameters, and finally comparing scaling laws when both methods’ efficiency hyperparameters grow proportionally with the neuron dimension.

# Orthogonal Finetuning and Block-Diagonal Parameterization

OFT learns a layer-shared orthogonal matrix $\bm{R}$ that transforms a pretrained weight matrix $\bm{W}^0$ via
\[
\bm{W}=\bm{R}\bm{W}^0, \quad \text{with} \quad \bm{R}^\top\bm{R}=\bm{I}.
\]
This preserves the pairwise angles among neurons and therefore preserves hyperspherical energy. To make $\bm{R}$ trainable and efficient, OFT parameterizes $\bm{R}$ using an orthogonal group construction together with block-diagonal structure. Specifically, for a $d\times d$ orthogonal matrix, OFT considers
\[
\bm{R}=\text{diag}(\bm{R}_1,\bm{R}_2,\cdots,\bm{R}_r),
\]
where each block $\bm{R}_i\in\text{O}(d/r)$ is itself orthogonal. This block-diagonal form reduces the number of trainable parameters while retaining exact orthogonality of the overall transform.

Counting parameters in an orthogonal matrix highlights the efficiency benefit of block structure. A full $d\times d$ orthogonal matrix has $d(d-1)/2$ degrees of freedom, which is $\mathcal{O}(d^2)$. By partitioning into $r$ blocks of size $(d/r)\times(d/r)$, each block has $(d/r)\big((d/r)-1\big)/2$ parameters, and there are $r$ such blocks. Summing across blocks yields
\[
\text{parameters in } \bm{R} = r \cdot \frac{(d/r)\big((d/r)-1\big)}{2}
= \frac{d\big((d/r)-1\big)}{2}
= \mathcal{O}\!\left(\frac{d^2}{r}\right).
\]
Thus, as the number of blocks $r$ increases, the trainable parameter count decreases proportionally. Importantly, this reduction pertains to the trainable parameters of the orthogonal transform only; the orthogonality constraint ensures that no compromise is made in preserving hyperspherical energy.

# Low-Rank Adaptation and Its Parameter Count

LoRA modifies the forward pass by adding a learned low-rank correction to a pretrained weight matrix $\bm{W}^0\in\mathbb{R}^{d\times n}$. The low-rank update is parameterized by two trainable matrices of shapes $d\times r'$ and $r'\times n$, resulting in a total number of trainable parameters
\[
\text{parameters in LoRA} = r'(d+n).
\]
This linear dependence on both $d$ and $n$ becomes a critical determinant of scaling behavior when $r'$ itself grows with the neuron dimension $d$. In practical text-to-image diffusion architectures, $n$ can be comparable to or larger than $d$, further amplifying the parameter count.

# Scaling Analysis Under $r=r'=\alpha d$

We now analyze the asymptotic behavior when both methods’ efficiency hyperparameters grow linearly with the neuron dimension, i.e., when
\[
r = r' = \alpha d, \quad \text{for some constant } 0<\alpha\leq 1.
\]
This regime models a setting where the structured flexibility of both OFT’s block decomposition and LoRA’s low-rank update scales proportionally to the dimensionality of the neuron space, a realistic assumption for large diffusion models.

For OFT, substituting $r=\alpha d$ into the block-diagonal parameter count yields
\[
\text{parameters in OFT} = \mathcal{O}\!\left(\frac{d^2}{r}\right)
= \mathcal{O}\!\left(\frac{d^2}{\alpha d}\right)
= \mathcal{O}(d).
\]
Thus, when the number of blocks grows linearly with the neuron dimension, OFT’s trainable parameter growth is only linear in $d$.

In contrast, for LoRA, substituting $r'=\alpha d$ yields
\[
\text{parameters in LoRA} = r'(d+n) = \alpha d (d+n) = \mathcal{O}(d^2 + dn).
\]
Hence, LoRA’s trainable parameter growth becomes quadratic in $d$ plus a term linear in $n$, which is typically non-negligible in diffusion architectures. Even when $n$ is held constant with respect to $d$, the quadratic term $\mathcal{O}(d^2)$ dominates.

This direct comparison shows that under the shared scaling $r=r'=\alpha d$, OFT achieves $\mathcal{O}(d)$ parameter complexity while LoRA requires $\mathcal{O}(d^2+dn)$ parameters. Therefore, in this regime, the method that yields only linear-in-$d$ trainable parameter growth is OFT.

# Intuition Behind OFT’s Linear Complexity

The key intuition for why OFT’s parameter count is linear in $d$ under $r=\alpha d$ lies in the block-diagonal orthogonal structure. Each block acts on a subspace of size $d/r$; when $r$ scales with $d$, each block’s dimension remains constant up to a multiplicative factor $\alpha^{-1}$. The number of degrees of freedom per block is then constant with respect to $d$, and the total number of blocks scales linearly with $d$, yielding an overall linear scaling.

Moreover, OFT’s multiplicative update constrains the transform to preserve neuron directions up to a shared orthogonal change of basis within each block. This structural regularity directly controls the number of parameters, while the orthogonality condition ensures that the pairwise angular relations—and thus hyperspherical energy—remain invariant. The block structure therefore strikes a balance between expressivity and regularity, allowing sufficient flexibility for downstream adaptation without incurring quadratic parameter growth.

By contrast, LoRA’s additive low-rank update must span both the input dimension $d$ and the output dimension $n$, and when its rank $r'$ grows with $d$, the product structure $r'(d+n)$ inevitably leads to quadratic or higher complexity. This is the cost of allowing the update to act across the full input-output coupling without the angular invariance constraints that OFT leverages.

# Practical Implications for Finetuning Large Diffusion Models

The linear-in-$d$ parameter growth of OFT under $r=\alpha d$ has direct practical benefits for finetuning large text-to-image diffusion models. First, it offers a scalable way to increase finetuning flexibility by increasing the number of blocks without exploding the parameter count. Second, it preserves inference efficiency, since the learned orthogonal matrices can be folded into the pretrained weights to produce an equivalent finetuned weight matrix $\bm{W}=\bm{R}\bm{W}^0$ without additional runtime overhead. Third, it supports stable optimization dynamics by operating on the hypersphere manifold and preserving hyperspherical energy, which the paper finds crucial for maintaining generative semantics.

In scenarios where parameter budget, convergence speed, and stability are important, OFT’s structure-controlled linear complexity makes it an attractive design choice. The scaling analysis under $r=r'=\alpha d$ crystallizes this advantage: OFT achieves only $\mathcal{O}(d)$ trainable parameter growth, whereas alternative low-rank adaptation methods entail $\mathcal{O}(d^2+dn)$ growth. Consequently, when increasing capacity to adapt is required in proportion to model width, OFT provides a principled and efficient path forward.
