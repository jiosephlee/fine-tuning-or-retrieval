### Is OFT merely a change of basis for the inputs, and does that limit its expressivity?
Question:
For a linear layer with pretrained weights $W^0$, OFT uses $z = (R W^0)^\top x$. Algebraically this equals $z = (W^0)^\top (R^\top x)$, i.e., applying $R^\top$ to the input feature before the pretrained weights. Does this mean OFT is just a learned reparameterization of the input basis for that layer? If so, how does OFT achieve task-specific adaptation across the entire network when non-linearities, residual connections, and cross-attention are present? Is there a subtlety because $R$ is different per layer (and not absorbed globally), so the composition cannot be reduced to a single global basis change?
Answer:
Short answer: No — algebraically a single OFT layer is equivalent to a learned orthogonal change of basis on that layer’s input, but taken across a real network (nonlinearities, residuals, attention) learning one orthogonal matrix per layer is not reducible to a single global basis change and therefore is expressive enough to adapt the model. Why a single OFT layer looks like a basis change
For a linear layer with <|endoftext|> weights $W^0$ and an orthogonal matrix $R$ OFT uses
$$
z = (R W^0)^\top x = (W^0)^\top (R^\top x).
$$
So at that layer, the forward effect is exactly: first rotate the input by $R^\top$, then apply the original <|endoftext|> linear map $W^0$. That is literally a change of input basis for that layer.

Why that observation does not imply OFT is only a trivial reparameterization of the whole network
The key is that real networks are not one linear layer: they are deep compositions of linear maps and nonlinearities <|endoftext|> plus residual connections and attention modules. If you put different layer-wise orthogonal matrices $R_l$ at each layer $l$ you get
$$
\text{output} = \dots W_L'^\top \phi_L(\dots W_2'^\top \phi_1(W_1'^\top x)\dots)
$$
with
$$
W_l' = R_l W_l^0.
$$
Expanding one or two layers makes the point clear. For a two-layer network with nonlinearity $\phi$:
$$
y = W_2'^\top \phi(W_1'^\top x)
= (W_2^0)^\top R_2^\top \phi\big(R_1 (W_1^0)^\top x\big).
$$

There is no single global orthogonal matrix $R_{\text{global}}$ such that
$$
R_2^\top \phi(R_1 (\cdot)) = \phi\big(R_{\text{global}} (\cdot)\big)
$$
for a generic nonlinearity $\phi$. Nonlinearities break the conjugation that would be needed to absorb all $R_l$ into a single rotation on the network input or output. Concretely, rotations do not commute with nonlinear <|endoftext|> (except in degenerate cases), so layerwise rotations change the intermediate activation geometry and thereby change the subsequent nonlinear processing.

Residual connections and attention further prevent absorption. Consider a residual block $x + F(x)$. If you rotate the input to $F$ but not the skip, the sum interacts differently; to absorb the rotation you would need to rotate both branches in a globally consistent way, which OFT does not enforce. In multi-head attention, queries, keys and values are projected and combined; rotating the input spaces of those <|endoftext|> layer-by-layer alters inner products and attention weights in nontrivial ways. Thus different $R_l$ per layer produce changes in <|endoftext|> and attention patterns that are not equivalent to a single basis change.

At the layer level OFT is a learned change of basis, but across a real model that change is applied layer-by-layer and interacts with nonlinearities, residuals and attention. Because those interactions are nonlinear, you cannot absorb all layerwise $R$'s into a single global basis rotation; therefore OFT genuinely changes the network’s function in a structured, regularized way.
