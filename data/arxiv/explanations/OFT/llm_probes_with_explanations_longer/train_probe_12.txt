In the paper 'Controlling Text-to-Image Diffusion by Orthogonal Finetuning', the authors note that when the number of diagonal blocks equals the number of input channels (r = C), each block transforms a unique neuron channel, making OFT's transform most akin to a depth-wise convolution. This follows from how the block-diagonal orthogonal matrix is applied in convolutional layers. Let the input feature be split by channels as x = [x_1; …; x_C] and let the OFT transform be R = diag(R_1, …, R_C) with each R_i ∈ O(d/C). Then the OFT forward pass can be written as z = (R W^0)^T x = (W^0)^T (R^T x) = (W^0)^T [R_1^T x_1; …; R_C^T x_C], which shows that each channel x_i is rotated/reflected independently in its own subspace. Because there is no cross-channel mixing introduced by a block-diagonal R, the transform respects the per-channel structure exactly like depth-wise convolution, where filters operate separately on each input channel without combining information across channels.

This per-channel independence is precisely why the authors remark that r = C makes OFT most akin to depth-wise convolution: the orthogonal update acts as a channel-wise reparameterization of the feature basis, preserving pairwise angular relationships within each channel’s neuron set while leaving inter-channel relationships untouched. In convolutional terms, flattening the per-channel kernels into vectors and applying R = diag(R_1, …, R_C) amounts to rotating each channel’s kernel space independently, analogous to learning separate depth-wise filters. At the same time, orthogonality ensures that hyperspherical energy within each channel, defined as HE(W) = ∑_{i≠j} ||ŵ_i − ŵ_j||^{-1} with ŵ_i = w_i / ||w_i||, is preserved under R_i, so semantic structure captured by the pretrained per-channel kernels is maintained while allowing controlled, stable adaptation.
