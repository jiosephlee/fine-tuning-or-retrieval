\title{Blogs about the Paper: "Large Language Models Can Automatically Engineer Features for Few-Shot Tabular Learning"}

# Few-Shot Learning Revolution: Beating Complex Models with Just a Few Examples

In the realm of data science, one of the most persistent challenges is the scarcity of labeled data. Traditional machine learning models often require thousands of examples to learn robust patterns, yet in critical domains like healthcare or finance, obtaining such large, annotated datasets is expensive and sometimes impossible. This is where few-shot learning becomes essential. A recent breakthrough in this area comes from a framework called \textsf{FeatLLM}, which demonstrates that we can achieve high-accuracy predictions on complex tabular tasks using only a handful of training examples. By shifting the role of Large Language Models (LLMs) from direct predictors to expert feature engineers, \textsf{FeatLLM} outperforms both traditional deep learning baselines and other LLM-based approaches while maintaining low inference costs.

The core innovation of \textsf{FeatLLM} lies in how it utilizes the vast prior knowledge embedded within LLMs. Instead of feeding raw tabular data into an LLM to get a direct prediction for every single new sample—a process that is computationally expensive and limited by prompt size constraints—\textsf{FeatLLM} asks the LLM to act as a feature engineer. The model is prompted to analyze the task description and a few example demonstrations to infer the underlying "criteria" or rules that distinguish different classes. For instance, in a disease diagnosis task, rather than asking the LLM "Does this patient have heart failure?", the system asks it to generate rules like "If age is greater than 60 and cholesterol levels are high, then heart failure is likely." These natural language rules are then parsed into executable code to create new binary features for the dataset.

Once these rule-based features are generated, they replace or augment the original data columns. The framework then employs a remarkably simple downstream machine learning model, such as linear regression with non-negative weights, to estimate class probabilities. The probability $p$ for a given class $k$ is calculated by taking the dot product of the learned weights $\mathbf{w}_k$ and the binary feature vector $\mathbf{z}_k^i$ representing whether the sample satisfies each rule, followed by a softmax operation:
$$ \text{logit}_k^i = \max(\mathbf{w}_k, 0) \cdot \mathbf{z}_k^i $$
$$ \mathbf{p}^i = \text{Softmax}([\text{logit}_{1}^i, ..., \text{logit}_{c}^i]) $$
This separation of concerns allows the complex reasoning capabilities of the LLM to be leveraged during a one-time feature generation phase, while the actual inference on new data points relies on a lightweight model that does not require querying an API for every sample. This design significantly reduces latency and operational costs compared to end-to-end LLM prediction methods.

To ensure robustness and handle datasets with many features that might exceed standard prompt limits, \textsf{FeatLLM} incorporates an ensemble approach with bagging. The system repeatedly generates sets of rules by varying the few-shot examples and introducing randomness in the generation process (via temperature settings). It then trains multiple simple models on these diverse feature sets and averages their predictions. This strategy not only mitigates the risk of spurious correlations but also effectively manages prompt size limitations by processing subsets of features or instances at a time. Experimental results across 13 diverse datasets show that this approach consistently outperforms strong baselines like TabLLM and STUNT, achieving an average improvement of 10% in performance metrics such as AUC in low-shot regimes.

The implications for real-world applications are profound. In scenarios where labeled data is scarce but domain knowledge exists—such as predicting credit risk or diagnosing rare diseases—\textsf{FeatLLM} offers a viable path forward without needing massive fine-tuning datasets or access to proprietary model weights. By converting an LLM's semantic understanding into structured decision rules, it bridges the gap between human-like reasoning and efficient algorithmic execution. As demonstrated by its ability to filter out irrelevant features even when spurious correlations are introduced, this framework provides not just higher accuracy but also greater reliability in data-scarce environments.
