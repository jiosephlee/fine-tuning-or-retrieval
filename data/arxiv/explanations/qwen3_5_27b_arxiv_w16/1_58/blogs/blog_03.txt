# From Data Centers to Your Pocket: Bringing 70B Models to Mobile Devices

The rapid evolution of Large Language Models (LLMs) has traditionally been a story of scaling up, with models growing from millions to hundreds of billions of parameters. However, this growth has come with a steep price: massive energy consumption, high latency, and memory requirements that confine these powerful AI systems to expensive data centers. The recent introduction of BitNet b1.58 challenges this paradigm by proposing a new era where every single parameter in an LLM is ternary, taking values only from the set $\{-1, 0, 1\}$. This shift to 1.58-bit precision is not just a minor optimization; it represents a fundamental change in how we compute and deploy AI, potentially bringing 70-billion parameter models within reach of edge devices and smartphones.

## The Power of Ternary Weights

To understand the impact of BitNet b1.58, one must first look at the computational bottleneck of modern LLMs. Standard models like LLaMA operate using 16-bit floating-point values (FP16 or BF16), where the bulk of the computation involves matrix multiplications requiring both floating-point addition and multiplication operations. These operations are energy-intensive and slow on standard hardware. In contrast, BitNet b1.58 replaces standard linear layers with "BitLinear" layers that constrain weights to $\{-1, 0, 1\}$.

This constraint transforms the core matrix multiplication into a series of integer additions and subtractions, effectively eliminating the need for expensive multiplication operations during inference. The inclusion of zero as a valid weight value is particularly significant; it allows the model to perform explicit feature filtering, which enhances modeling capability compared to binary-only approaches. Despite this extreme quantization, experiments show that BitNet b1.58 can match the perplexity and end-task performance of full-precision baselines starting from a model size of 3 billion parameters when trained on equivalent datasets.

## Drastic Reductions in Memory and Latency

The most immediate benefit of moving to 1.58-bit precision is the dramatic reduction in memory footprint and inference latency. When comparing BitNet b1.58 to full-precision LLaMA models trained on the same number of tokens (100 billion), the efficiency gains are stark. For instance, a 3.9B BitNet b1.58 model runs 2.4 times faster than a 3B full-precision LLaMA model while consuming 3.32 times less GPU memory. As models scale up, these advantages compound significantly due to the nature of how linear layer costs grow with model size.

At the massive scale of 70 billion parameters, BitNet b1.58 demonstrates a 4.1 times speed-up over its full-precision counterpart in terms of time per output token. Furthermore, because the memory bandwidth required to load weights from DRAM is drastically reduced, the system can process data much more efficiently. In throughput tests on two A100 GPUs using pipeline parallelism, the 70B BitNet b1.58 model supported an batch size up to 11 times larger than the full-precision version, resulting in an overall throughput increase of nearly nine times. These metrics suggest that what was once a resource-hungry operation confined to clusters can now be executed with far fewer resources and significantly lower latency.

## Enabling AI on Edge and Mobile Devices

The implications for edge computing and mobile deployment are transformative. Current mobile devices are severely limited by their memory capacity and thermal constraints regarding energy consumption, making it nearly impossible to run large-scale LLMs locally without offloading tasks to the cloud or sacrificing performance entirely for tiny models like those under 2 billion parameters. BitNet b1.58 changes this equation by reducing both memory usage and energy consumption by orders of magnitude compared to FP16 models.

The paper estimates that for matrix multiplication on 7nm chips, BitNet b1.58 saves approximately 71 times more arithmetic operation energy than full-precision models since it relies primarily on INT8 addition rather than FP16 multiplication and addition. This efficiency makes it feasible to run massive models directly on CPUs found in smartphones and laptops without requiring specialized accelerators like GPUs or TPUs immediately available on those devices. Additionally, because activations are scaled down from 16 bits to 8 bits (and potentially further compressed), the memory overhead for KV caches during long-sequence inference is significantly reduced, allowing for longer context windows on devices with limited RAM. This opens the door for high-performance AI applications—such as real-time translation or complex reasoning assistants—to run natively on personal devices with low latency and zero data privacy concerns associated with cloud processing.

## A New Scaling Law for Hardware Design

Beyond software efficiency, BitNet b1.58 introduces a new scaling law that redefines the relationship between model size and cost-effectiveness. The research suggests that a smaller full-precision model is often less efficient than a much larger quantized one; for example, a 70B BitNet b1.58 model is more efficient in terms of latency, memory usage, and energy consumption than a standard 13B FP16 model effectively making larger models cheaper to run than smaller ones under traditional paradigms). This shift invites hardware manufacturers to design specific chips optimized for this new computation paradigm where integer addition dominates over floating-point multiplication much like recent specialized hardware efforts have shown promise for LLMs but now tailored specifically for ternary weights). By aligning hardware design with these ternary constraints we can unlock even greater efficiencies enabling native support for Mixture-of-Experts architectures which currently suffer from high communication overheads due to large memory footprints).
