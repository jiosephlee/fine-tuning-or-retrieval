\title{Stack Exchange of the Paper: "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits"}

### How does adding '0' to the weight set improve feature filtering compared to the original BitNet?
Question:
The introduction mentions that \textbf{BitNet b1.58} adds an additional value of 0 to the original 1-bit BitNet (which presumably only had \{-1, +1\}). The authors claim this provides 'explicit support for feature filtering.'

Conceptually, I struggle to see how simply allowing a weight to be exactly zero changes the learning dynamics significantly compared to a weight that is just very small (close to zero) in a continuous space. In standard pruning or sparse models, zeros are usually enforced via masks or regularization after training. Here, it seems the quantization function forces values to exactly 0 during forward/backward passes.

Does this mean the gradient flow behaves differently when a weight snaps to exactly 0 versus snapping to -1 or +1? How does this mechanism differ from standard dropout or sparsity-inducing regularizers?
Answer:
The key distinction lies in the difference between **approximate** suppression and **exact** elimination within the constrained discrete domain of 1-bit quantization. In standard continuous-weight models, a weight close to zero (e.g., $10^{-6}$) still participates in the matrix multiplication operation, contributing a tiny numerical value that must be computed, stored, and accumulated. While effectively negligible, it is not structurally absent. By explicitly introducing $0$ into the weight set $\{-1, 0, 1\}$, BitNet b1.58 transforms the model's ability to filter features from a matter of magnitude to a matter of existence. When a weight snaps exactly to $0$, the corresponding connection is mathematically severed; the input feature associated with that weight is completely ignored during the dot product calculation without requiring any arithmetic operation for that specific term.

This structural sparsity fundamentally alters the learning dynamics compared to relying on near-zero values in a continuous space or applying post-hoc masking. During training, the quantization function described in the paper scales weights by their average absolute value ($\gamma$) and rounds them to the nearest integer in $\{-1, 0, 1\}$. This creates a hard decision boundary where gradients push weights toward either active states ($+1$ or $-1$) or complete silence ($0$). Unlike dropout, which randomly drops units during training but restores them for inference (maintaining density), or Lasso-style regularization which encourages small weights but rarely enforces exact zeros without an explicit thresholding step, BitNet b1.58 enforces exact zeros natively throughout both forward and backward passes via the rounding operator. This allows the model to learn an intrinsic sparse topology where irrelevant features are permanently disconnected rather than just dampened. Consequently, this "explicit support for feature filtering" enhances modeling capability by preventing noise accumulation from weak connections and aligns perfectly with hardware optimizations where multiplying by zero can be skipped entirely, thereby reducing computational load beyond what mere precision reduction offers.
