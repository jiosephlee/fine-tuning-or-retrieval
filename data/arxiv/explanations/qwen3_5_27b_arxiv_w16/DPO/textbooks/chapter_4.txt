## Your Language Model is Secretly a Reward Model

The central theoretical breakthrough of Direct Preference Optimization (DPO) lies in recognizing that a language model policy and a reward function are not merely distinct components of a pipeline, but are fundamentally interchangeable representations under specific conditions. In traditional Reinforcement Learning from Human Feedback (RLHF), the process is bifurcated: first, a separate neural network is trained to approximate a latent reward function $r(x, y)$ based on human preferences, and second, an agent (the language model) is trained via reinforcement learning to maximize this reward while staying close to a reference policy. DPO collapses these two stages into one by leveraging an analytical mapping that reveals the language model itself contains all the necessary information to act as the reward model. This insight stems from the observation that for any reward function $r(x, y)$ subject to a KL-divergence constraint against a reference policy $\pi_\text{ref}$, there exists a unique optimal policy $\pi_r(y \mid x)$ derived in closed form. By reversing this relationship, we can express the reward function entirely in terms of the ratio between the current policy and the reference policy. Consequently, optimizing the policy directly using preference data is mathematically equivalent to optimizing a re-parameterized reward function. This duality implies that we do not need to explicitly construct or store a separate reward model; the parameters of the language model $\pi_\theta$ implicitly encode the reward landscape required to satisfy human preferences.

To formalize this relationship, we must first establish what it means for two different mathematical objects to represent the "same" underlying preference structure. In the context of preference learning using models like Bradley-Terry or Plackett-Luce, absolute reward values are less important than relative differences. If we add an arbitrary constant or a function dependent solely on the prompt $x$ to every reward associated with that prompt, the relative ordering of responses—and thus the predicted probability of preferring one response over another—remains unchanged. Formally, we define an equivalence relation between two reward functions $r(x, y)$ and $r'(x, y)$ such that they are considered equivalent if their difference depends only on the input prompt $x$, expressed as $r(x, y) - r'(x, y) = f(x)$ for some arbitrary function $f$. This definition partitions the infinite space of possible reward functions into disjoint equivalence classes. Within any single class, every member induces identical preference distributions over pairs of outputs. Furthermore, when solving the constrained RL problem where we maximize expected reward minus a KL penalty against $\pi_\text{ref}$, all members of an equivalence class lead to exactly the same optimal policy. This redundancy suggests that attempting to recover a specific "true" ground-truth reward function is unnecessary; instead, our goal is simply to identify *any* representative from the correct equivalence class that generates human-consistent preferences and yields an optimal policy.

The power of DPO emerges when we realize that our proposed reparameterization naturally selects a canonical representative from each equivalence class without requiring external constraints or auxiliary networks. By defining the implicit reward as $\hat{r}_\theta(x, y) = \beta \log \frac{\pi_\theta(y \mid x)}{\pi_\text{ref}(y \mid x)}$, we effectively normalize out the dependency on $x$ that causes non-uniqueness in standard formulations. When substituted back into the Bradley-Terry equation for preference probabilities, any additive term depending only on $x$ cancels out perfectly in the numerator and denominator of the softmax-like expression used to calculate win probabilities. Therefore, whether we optimize an explicit neural network for rewards or optimize $\pi_\theta$ directly via DPO's binary cross-entropy loss, we are traversing the same landscape of preference consistency. The language model $\pi_\theta$ is not just approximating a policy; through its logits relative to $\pi_\text{ref}$, it is simultaneously acting as a fully functional reward model capable of distinguishing preferred from dispreferred outputs with perfect fidelity provided sufficient capacity and data.

## Lemma: Identifiability Issues in Plackett-Luce/Brunell-Terry Models and Normalization

A critical challenge in learning from pairwise preferences arises from the inherent under-specification of models like Bradley-Terry and Plackett-Luce. Because these models rely exclusively on ratios or differences between scores (rewards), they cannot uniquely determine absolute values without imposing artificial constraints. For instance, if $r(x, y)$ fits a dataset perfectly, then adding any constant vector dependent only on $x$, say $c(x)$, creates a new function $r'(x, y) = r(x, y) + c(x)$ that predicts exactly identical probabilities for every comparison in history yet assigns completely different absolute scores to individual tokens or sequences. This phenomenon creates an identifiability problem: without fixing these degrees of freedom via regularization or manual normalization (such as forcing mean rewards to zero across contexts), maximum likelihood estimation may converge slowly or fail to settle on meaningful parameters because infinitely many solutions exist with equal likelihood scores. Traditional RLHF pipelines address this by manually normalizing rewards during training or relying on heuristics within reinforcement learning algorithms like PPO to stabilize value estimates indirectly.

However, DPO resolves this identifiability issue elegantly through its structural design rather than ad-hoc constraints. The reparameterization formula derived earlier links any valid optimal policy directly to its corresponding implicit reward via $\beta \log \frac{\pi(y\mid x)}{\pi_\text{ref}(y\mid x)}$. This formulation inherently enforces a specific normalization condition tied to probabilistic validity. Recall that for $\pi(y \mid x)$ to be a valid probability distribution over all possible completions $y$, it must sum to one: $\sum_y \pi(y \mid x) = 1$. Substituting our reparameterized form into this summation constraint reveals that it forces the partition function—the normalizing term usually required in Boltzmann-style distributions—to equal unity when viewed through the lens of this specific parameterization. Mathematically, this imposes that $\sum_y \pi_\text{ref}(y\mid x)\exp\left(\frac{1}{\beta}r(x,y)\right) = 1$. This condition acts as an intrinsic anchor for every equivalence class of rewards; among all possible functions differing by an arbitrary offset $f(x)$ within an equivalence class, only one satisfies this strict normalization requirement imposed by probability axioms. Thus, DPO automatically selects this unique representative without needing external normalization procedures or manual intervention during training iterations.
