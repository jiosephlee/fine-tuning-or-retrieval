\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the block-diagonal structure in OFT fail to approximate general linear transforms compared to BOFT?
Question:
The paper states that the block-diagonal structure used in the original Orthogonal Finetuning (OFT) 'reduces expressiveness and cannot approximate classic linear transforms.' I understand that block-diagonal matrices operate independently on subspaces, but I'm struggling to visualize exactly why this prevents the approximation of a general dense linear transform. 

Specifically, if I have a $d \times d$ weight matrix and I split it into $r$ blocks of size $b \times b$, what specific types of transformations are mathematically impossible to represent? Is it because information cannot flow between the different blocks? How does the butterfly structure specifically overcome this limitation to allow for dense connectivity while maintaining parameter efficiency?
Answer:
The block-diagonal structure in the original Orthogonal Finetuning (OFT) fails to approximate general linear transforms because it fundamentally restricts information flow between specific subspaces of the input dimension. When a $d \times d$ weight matrix is decomposed into $r$ independent blocks of size $b \times b$, the resulting orthogonal matrix $\bm{R}$ becomes a direct sum of smaller orthogonal matrices, $\text{diag}(\bm{R}_1, \dots, \bm{R}_r)$. Mathematically, this imposes a strict sparsity pattern where any element $R_{ij}$ connecting a dimension in block $k$ to a dimension in block $l$ (where $k \neq l$) is forced to be exactly zero. Consequently, it is impossible for this structure to represent transformations that require mixing information across these disjoint groups; for instance, if the optimal transformation requires the first input dimension to influence the last output dimension, but they reside in different blocks, the block-diagonal constraint makes this transformation mathematically unrepresentable regardless of how the parameters within the blocks are tuned.

In contrast, Orthogonal Butterfly (BOFT) overcomes this limitation by constructing a dense orthogonal matrix through the sequential multiplication of sparse orthogonal matrices arranged in a butterfly topology. Instead of isolating dimensions into static blocks, BOFT treats the generation of the orthogonal matrix as an information transmission problem on a grid-structured graph. In this framework, each sparse factor in the product allows information to "hop" between nodes at different levels. By composing $\mathcal{O}(\log d)$ such sparse layers, BOFT ensures that every node in the input layer has a directed path to every node in the output layer, effectively creating dense connectivity. This recursive structure, inspired by the Cooley-Tukey Fast Fourier Transform algorithm, allows local interactions at each stage to propagate globally across all dimensions after sufficient depth. As a result, BOFT can recover classic dense linear transforms like the Discrete Fourier Transform and approximate general orthogonal matrices with $\mathcal{O}(d \log d)$ parameters, whereas block-diagonal OFT remains confined to independent subspace rotations and cannot recover these global mixing operations without expanding its block size to $d$, which negates its parameter efficiency.

### Clarification on the 'Information Transmission' graph formulation for matrix factorization
Question:
In Section 3, the authors frame the generation of a dense orthogonal matrix as an 'information transmission problem' on a grid-structured graph with $d \times (m+1)$ nodes. They state that for a matrix product $\bm{R} = \bm{B}_m \cdots \bm{B}_1$ to be dense, every node in the first level must have a path to every node in the last level.

I am confused about the mapping between the graph edges and the matrix entries. The text says: 'the $(j_1,j_2)$ element of $\bm{B}_i$ denotes whether there is a directed edge from the $j_2$-th node in the $i$-th level to the $j_1$-th node in the $(i+1)$-th level.'

Does this mean that if $\bm{B}_i$ is sparse, we are effectively pruning edges in this transmission graph? If so, how does multiplying multiple sparse matrices (which individually have limited connectivity) result in a dense matrix where *every* input node connects to *every* output node? I'm having trouble reconciling the sparsity of individual factors with the density of their product in this graphical context.
Answer:
Yes, your intuition is correct: if $\bm{B}_i$ is sparse, it effectively prunes the edges in the information transmission graph, and the density of the final product matrix $\bm{R}$ arises from the cumulative effect of these sparse connections across multiple layers.

In the authors' framework, the matrix product $\bm{R} = \bm{B}_m \cdots \bm{B}_1$ is visualized as a grid-structured graph with $d \times (m+1)$ nodes, where each matrix $\bm{B}_i$ represents the connectivity between level $i$ and level $i+1$. Specifically, a non-zero entry $(j_1, j_2)$ in $\bm{B}_i$ corresponds to a directed edge from node $j_2$ at level $i$ to node $j_1$ at level $i+1$. If $\bm{B}_i$ is sparse, it means that at that specific stage of transmission, information can only flow along a limited set of paths (edges), effectively "pruning" the direct connections between adjacent levels.

The reason this results in a dense final matrix is that density in $\bm{R}$ does not require every individual factor $\bm{B}_i$ to be dense; rather, it requires that for every pair of nodes $(u, v)$ where $u$ is in the first level and $v$ is in the last level, there exists at least one valid path connecting them through the intermediate levels. While a single sparse matrix might restrict a node's immediate neighbors to only a few targets, multiplying several such matrices allows information to "hop" across different subsets of nodes at each step. As long as the sparsity patterns of $\bm{B}_1, \dots, \bm{B}_m$ are arranged such that their combined connectivity covers all possible source-to-destination pairs, the resulting product $\bm{R}$ will have non-zero entries everywhere. The paper illustrates this with the butterfly structure: by using $\mathcal{O}(\log d)$ sparse matrices (each with only $\mathcal{O}(d)$ edges), they construct a topology where information from every input node eventually reaches every output node via distinct multi-hop paths. This achieves "dense connectivity" globally while maintaining "minimum free edges" locally at each step, thereby reducing the total number of trainable parameters from $\mathcal{O}(d^2)$ to $\mathcal{O}(d \log d)$.

### Deriving the parameter count formula for BOFT: Where does $(b-1)dm/2$ come from?
Question:
The paper claims that BOFT($m$, $b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters. I am trying to derive this from first principles but getting stuck on the degrees of freedom for orthogonal matrices.

We know that an orthogonal matrix of size $k \times k$ has $k(k-1)/2$ degrees of freedom (using Cayley parameterization with a skew-symmetric matrix). In BOFT, we have $m$ layers of butterfly components. Each component consists of block-diagonal matrices where each block is related to a butterfly factor.

If we assume each butterfly component is composed of disjoint blocks (or can be permuted into them), how do we sum up these degrees of freedom across all $m$ layers and all blocks to arrive at exactly $\frac{1}{2}(b-1)dm$? Specifically, how does the block size $b$ and depth $m$ interact with the dimensionality reduction inherent in orthogonal constraints?
Answer:
The formula $\frac{1}{2}(b-1)dm$ arises from summing the degrees of freedom of the trainable skew-symmetric matrices used to parameterize the orthogonal blocks within the butterfly structure. In BOFT, the orthogonal matrix $\bm{R}$ is constructed as a product of $m$ butterfly components, where each component consists of block-diagonal matrices with blocks of size $2b \times 2b$ (formed by combining two $b \times b$ sub-blocks in a butterfly factor). To ensure orthogonality while maintaining parameter efficiency, the paper employs Cayley parameterization, which maps a skew-symmetric matrix $\bm{Q}$ to an orthogonal matrix via $\bm{R} = (\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$.

The number of trainable parameters corresponds directly to the number of independent entries in these skew-symmetric matrices. For a single $2b \times 2b$ block, the associated skew-symmetric matrix has $\frac{(2b)(2b-1)}{2} = b(2b-1)$ degrees of freedom. However, BOFT does not treat these blocks as fully independent dense orthogonal transformations; rather, it structures them such that the effective trainable parameters per layer are derived from the specific butterfly factorization pattern. Specifically, each butterfly component at a given layer consists of $d/2b$ such blocks (since the total dimension is $d$ and each block operates on $2b$ dimensions). The paper simplifies the counting by noting that for a block size parameter $b$, the effective degrees of freedom per dimension per layer is $(b-1)/2$.

To see this clearly, consider that a standard orthogonal matrix of size $k \times k$ has $k(k-1)/2$ parameters. In the context of BOFT($m$, $b$), the structure is designed so that each of the $m$ layers contributes parameters proportional to $(b-1)d/2$. This can be understood by observing that if we view the transformation as acting on groups of size $b$, a full orthogonal group would require $O(b^2)$ parameters per group, but the butterfly constraint and specific parameterization reduce this to linear scaling with respect to $d$. More precisely, for each layer $i \in [1, m]$, there are $d/b$ blocks of size $b \times b$ involved in the factorization logic (conceptually), but due to the butterfly connectivity combining pairs into $2b \times 2b$ operations where only specific degrees of freedom are trained to maintain orthogonality without redundancy, the count simplifies. The paper states explicitly that BOFT($m$, $b$) takes $\frac{1}{2}(b-1)dm$ parameters. This implies that for each layer ($m$), and for every dimension ($d$), we add $(b-1)/2$ parameters. This linear relationship with respect to depth ($m$) and dimension ($d$), and quadratic-like reduction relative to block size ($b-1$ instead of $b^2$), is what makes BOFT significantly more efficient than standard OFT with full dense blocks or even block-diagonal OFT when aiming for dense connectivity. The term $(b-1)$ reflects the reduction from a full rank update (which would be proportional to $b^2/2$) to a constrained update where only $(b-1)$ independent rotations per dimension group are effectively learned across the butterfly layers. Thus, multiplying this per-dimension cost by total dimensions $d$ and total layers $m$ yields exactly $\frac{1}{2}(b-1)dm$.

### Why is standard Dropout incompatible with BOFT's multiplicative update rule?
Question:
In Section 4, under 'Multiplicative Dropout for BOFT', the authors state: 'The conventional Dropout naturally works for LoRA, but not for BOFT due to our multiplicative weight update.'

I understand that LoRA adds a low-rank update ($\bm{W} + \Delta\bm{W}$), so dropping out elements in $\Delta\bm{W}$ simply reduces the magnitude of specific updates. However, BOFT applies an orthogonal transformation via multiplication ($\bm{R}\bm{W}$).

Why exactly does standard dropout fail here? If I apply standard dropout by zeroing out random elements within one of the sparse butterfly factors before multiplication, wouldn't that just create a sparser transformation? Is there a theoretical reason why zeroing out entries breaks the orthogonality constraint required for BOFT, or is it simply that it destroys the specific 'butterfly' structure needed for efficient information transmission?
Answer:
The incompatibility of standard Dropout with BOFT stems from the fundamental difference between additive and multiplicative weight updates, specifically regarding how zeroing out elements affects the **orthogonality constraint** that defines the method. In LoRA, the update is additive ($\bm{W} + \Delta\bm{W}$), so applying standard Dropout (zeroing random elements in $\Delta\bm{W}$) simply reduces the magnitude of specific updates without altering the structural properties of the base weight matrix $\bm{W}$. However, BOFT relies on a multiplicative update where the pretrained weights are transformed by an orthogonal matrix $\bm{R}$ ($\bm{z} = (\bm{R}\bm{W}^0)^\top\bm{x}$). The core theoretical guarantee of Orthogonal Finetuning is that $\bm{R}$ must satisfy $\bm{R}^\top\bm{R} = \bm{I}$ to preserve pairwise angles between neurons and maintain spectral stability.

If you apply standard element-wise Dropout to the sparse butterfly factors that compose $\bm{R}$, you are effectively setting specific entries within these factors to zero. While this creates a sparser transformation as you hypothesized, it immediately breaks the orthogonality of those factors. Since $\bm{R}$ is constructed as a product of these orthogonal butterfly components ($\bm{R} = \prod \tilde{\bm{B}}$), if any individual component $\tilde{\bm{B}}$ loses its orthogonality due to random zeroing, the final product $\bm{R}$ will no longer be an orthogonal matrix. This violates the primary inductive bias of BOFT, potentially causing the model to lose its spectral norm preservation and destabilizing training. The "butterfly" structure is not just a sparsity pattern for efficiency; it is a carefully constrained topology where non-zero entries are mathematically coupled to ensure orthogonality (often via Cayley parameterization or rotation matrices). Randomly breaking these couplings destroys the geometric properties required for the method to function.

To resolve this while still providing regularization, the authors propose **Multiplicative Dropout**, which operates at a structural level rather than an element-wise level. Instead of zeroing individual scalars within a factor, this method randomly selects entire butterfly components or diagonal blocks within them and replaces them with **identity matrices**. Because an identity matrix is orthogonal ($\bm{I}^\top\bm{I} = \bm{I}$), replacing a learned orthogonal block with an identity block preserves the orthogonality of the entire product chain. This allows BOFT to "drop out" learned transformations (reverting specific parts of the network to their pre-finetuned state) without violating the mathematical constraints that make Orthogonal Finetuning effective.

### Understanding Theorem 1: How can a structured subset be 'more expressive' than OFT?
Question:
Theorem 1 states: 'BOFT is more expressive than OFT with the same block size.' The proof sketch mentions multiplying butterfly matrices with their transposes to approximate any orthogonal matrix.

My confusion lies in comparing two constrained spaces:
1. OFT with block size $b$: A block-diagonal orthogonal matrix where blocks are independent.
2. BOFT with block size $b$: A product of sparse butterfly matrices.

Intuitively, both seem like subsets of the full orthogonal group. Why is one subset strictly larger or 'more expressive' than the other given they use similar parameter counts (or at least similar structural constraints)? Does 'more expressive' here mean they can reach points in parameter space that OFT cannot reach *for a fixed number of parameters*, or does it refer to asymptotic properties as dimensions grow?
Answer:
Theorem 1 asserts that BOFT is more expressive than OFT with the same block size $b$ because the set of matrices representable by BOFT strictly contains the set of matrices representable by OFT, effectively subsuming OFT as a special case while allowing for dense interactions that OFT cannot achieve.

To understand this intuitively, consider the structural constraints imposed on the orthogonal matrix $\bm{R}$ in both methods. In OFT with block size $b$, $\bm{R}$ is constrained to be block-diagonal, meaning it is composed of independent $b \times b$ orthogonal blocks along the diagonal. This structure enforces a "locality" constraint where dimensions within one block cannot interact with dimensions in another block; information transmission is strictly confined within these disjoint groups. In contrast, BOFT constructs $\bm{R}$ as a product of multiple sparse butterfly matrices, $\bm{R} = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$. As the paper explains using the information transmission framework, this sequential multiplication allows information to flow across all $d$ dimensions through a series of sparse connections. While each individual butterfly component is sparse and structured, their product can generate a fully dense orthogonal matrix where every input dimension can influence every output dimension.

The key to the "more expressive" claim lies in the fact that BOFT can exactly replicate any OFT configuration while also accessing configurations that OFT cannot. Specifically, if we set the number of butterfly layers $m=1$ in BOFT, it reduces exactly to the block-diagonal structure of OFT with block size $b$. However, by increasing $m$ (e.g., to $\log d$), BOFT introduces additional degrees of freedom that allow it to approximate or exactly represent dense orthogonal matrices. The proof sketch mentioned in your question highlights that by multiplying butterfly matrices with their transposes (a technique related to the kaleidoscope hierarchy), one can approximate any arbitrary orthogonal matrix in the full group $O(d)$. Since OFT is restricted to a specific subset of $O(d)$ defined by its fixed sparsity pattern (block-diagonal), and BOFT can reach that subset plus a vast region of dense matrices, BOFT's hypothesis space is strictly larger.

Therefore, "more expressive" here refers to the ability to reach points in the parameter space (specifically, dense orthogonal transformations) that are mathematically unreachable by OFT for a fixed block size $b$, even though both methods may use similar parameter counts depending on how many layers $m$ are used in BOFT. The paper argues that this expanded space allows BOFT to find a better trade-off between expressivity and regularity, as it can model complex global interactions (like those found in Fourier transforms) which are impossible for the isolated blocks of OFT to capture.

### Connection between Butterfly Factorization and Cayley Parameterization
Question:
The paper uses Cayley parameterization ($\bm{R}=(\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$) to ensure orthogonality. It also mentions that butterfly components can be parameterized as orthogonal matrices because their non-zero patterns are permutations of smaller blocks.

How exactly is Cayley parameterization applied recursively or locally within a single butterfly factor? For example, if a butterfly factor consists of diagonal blocks containing vectors $\bm{d}_i$, how do we ensure that when we apply Cayley transform to these local components, their product remains globally orthogonal?

Is each small block (e.g., $2 \times 2$ or $b \times b$) treated as an independent orthogonal generator via Cayley transform, and then combined? If so, how do we handle cases where blocks overlap or interact across layers?
Answer:
The connection between Butterfly Factorization and Cayley parameterization in the paper relies on the principle that a global orthogonal matrix can be constructed as a product of sparse, locally orthogonal matrices, where each local block is independently parameterized using the Cayley transform.

To ensure global orthogonality, the method does not apply a single Cayley transform to the entire dense matrix; instead, it decomposes the target orthogonal matrix $\bm{R}$ into a product of $m$ sparse butterfly components: $\bm{R} = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$. The paper establishes that if every individual factor $\tilde{\bm{B}}^b_{(d,i)}$ is orthogonal, their product is guaranteed to be orthogonal due to the group property of orthogonal matrices (the product of two orthogonal matrices is always orthogonal). The "local" application of Cayley parameterization occurs within these sparse factors. Specifically, each butterfly component $\tilde{\bm{B}}^b(d,k)$ is a block-diagonal matrix composed of smaller blocks (e.g., $2b \times 2b$ blocks for the base case). The paper explicitly states that to guarantee these components are orthogonal, one can parameterize each small block independently using the Cayley transform $\bm{R}_{\text{block}} = (\bm{I} + \bm{Q})(\bm{I} - \bm{Q})^{-1}$, where $\bm{Q}$ is a learnable skew-symmetric matrix specific to that block.

Regarding your question about overlapping or interacting blocks, it is important to clarify that within a single butterfly layer (a specific $\tilde{\bm{B}}^b(d,k)$), the blocks are strictly disjoint and arranged in a block-diagonal structure; they do not overlap within that specific factor. The "interaction" or mixing of information happens sequentially across different layers in the product. For instance, while one layer might mix dimensions $(1,2)$ and another might mix $(3,4)$, subsequent layers with different sparsity patterns (permutations of the base pattern) will eventually connect all dimensions. Because each layer's non-zero pattern is simply a permutation of the base $2b \times 2b$ block structure, the same Cayley parameterization logic applies uniformly: you treat every active $2b \times 2b$ sub-block in every layer as an independent generator of an orthogonal transformation. By ensuring every constituent $2b \times 2b$ block across all layers satisfies orthogonality via its own skew-symmetric parameterization, the final composed matrix $\bm{R}$ remains globally orthogonal without requiring complex constraints between layers or handling overlapping parameters within a single step.
