\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Deriving the parameter count formula for BOFT: Where does $(b-1)dm/2$ come from?
Question:
The paper claims that BOFT($m$, $b$) takes $\frac{1}{2}(b-1)dm$ effective trainable parameters. I am trying to derive this from first principles but getting stuck on the degrees of freedom for orthogonal matrices.

We know that an orthogonal matrix of size $k \times k$ has $k(k-1)/2$ degrees of freedom (using Cayley parameterization with a skew-symmetric matrix). In BOFT, we have $m$ layers of butterfly components. Each component consists of block-diagonal matrices where each block is related to a butterfly factor.

If we assume each butterfly component is composed of disjoint blocks (or can be permuted into them), how do we sum up these degrees of freedom across all $m$ layers and all blocks to arrive at exactly $\frac{1}{2}(b-1)dm$? Specifically, how does the block size $b$ and depth $m$ interact with the dimensionality reduction inherent in orthogonal constraints?
Answer:
The formula $\frac{1}{2}(b-1)dm$ arises from summing the degrees of freedom of the trainable skew-symmetric matrices used to parameterize the orthogonal blocks within the butterfly structure. In BOFT, the orthogonal matrix $\bm{R}$ is constructed as a product of $m$ butterfly components, where each component consists of block-diagonal matrices with blocks of size $2b \times 2b$ (formed by combining two $b \times b$ sub-blocks in a butterfly factor). To ensure orthogonality while maintaining parameter efficiency, the paper employs Cayley parameterization, which maps a skew-symmetric matrix $\bm{Q}$ to an orthogonal matrix via $\bm{R} = (\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}$.

The number of trainable parameters corresponds directly to the number of independent entries in these skew-symmetric matrices. For a single $2b \times 2b$ block, the associated skew-symmetric matrix has $\frac{(2b)(2b-1)}{2} = b(2b-1)$ degrees of freedom. However, BOFT does not treat these blocks as fully independent dense orthogonal transformations; rather, it structures them such that the effective trainable parameters per layer are derived from the specific butterfly factorization pattern. Specifically, each butterfly component at a given layer consists of $d/2b$ such blocks (since the total dimension is $d$ and each block operates on $2b$ dimensions). The paper simplifies the counting by noting that for a block size parameter $b$, the effective degrees of freedom per dimension per layer is $(b-1)/2$.

To see this clearly, consider that a standard orthogonal matrix of size $k \times k$ has $k(k-1)/2$ parameters. In the context of BOFT($m$, $b$), the structure is designed so that each of the $m$ layers contributes parameters proportional to $(b-1)d/2$. This can be understood by observing that if we view the transformation as acting on groups of size $b$, a full orthogonal group would require $O(b^2)$ parameters per group, but the butterfly constraint and specific parameterization reduce this to linear scaling with respect to $d$. More precisely, for each layer $i \in [1, m]$, there are $d/b$ blocks of size $b \times b$ involved in the factorization logic (conceptually), but due to the butterfly connectivity combining pairs into $2b \times 2b$ operations where only specific degrees of freedom are trained to maintain orthogonality without redundancy, the count simplifies. The paper states explicitly that BOFT($m$, $b$) takes $\frac{1}{2}(b-1)dm$ parameters. This implies that for each layer ($m$), and for every dimension ($d$), we add $(b-1)/2$ parameters. This linear relationship with respect to depth ($m$) and dimension ($d$), and quadratic-like reduction relative to block size ($b-1$ instead of $b^2$), is what makes BOFT significantly more efficient than standard OFT with full dense blocks or even block-diagonal OFT when aiming for dense connectivity. The term $(b-1)$ reflects the reduction from a full rank update (which would be proportional to $b^2/2$) to a constrained update where only $(b-1)$ independent rotations per dimension group are effectively learned across the butterfly layers. Thus, multiplying this per-dimension cost by total dimensions $d$ and total layers $m$ yields exactly $\frac{1}{2}(b-1)dm$.
