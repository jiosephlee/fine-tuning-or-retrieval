\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### Clarification on the 'Information Transmission' graph formulation for matrix factorization
Question:
In Section 3, the authors frame the generation of a dense orthogonal matrix as an 'information transmission problem' on a grid-structured graph with $d \times (m+1)$ nodes. They state that for a matrix product $\bm{R} = \bm{B}_m \cdots \bm{B}_1$ to be dense, every node in the first level must have a path to every node in the last level.

I am confused about the mapping between the graph edges and the matrix entries. The text says: 'the $(j_1,j_2)$ element of $\bm{B}_i$ denotes whether there is a directed edge from the $j_2$-th node in the $i$-th level to the $j_1$-th node in the $(i+1)$-th level.'

Does this mean that if $\bm{B}_i$ is sparse, we are effectively pruning edges in this transmission graph? If so, how does multiplying multiple sparse matrices (which individually have limited connectivity) result in a dense matrix where *every* input node connects to *every* output node? I'm having trouble reconciling the sparsity of individual factors with the density of their product in this graphical context.
Answer:
Yes, your intuition is correct: if $\bm{B}_i$ is sparse, it effectively prunes the edges in the information transmission graph, and the density of the final product matrix $\bm{R}$ arises from the cumulative effect of these sparse connections across multiple layers.

In the authors' framework, the matrix product $\bm{R} = \bm{B}_m \cdots \bm{B}_1$ is visualized as a grid-structured graph with $d \times (m+1)$ nodes, where each matrix $\bm{B}_i$ represents the connectivity between level $i$ and level $i+1$. Specifically, a non-zero entry $(j_1, j_2)$ in $\bm{B}_i$ corresponds to a directed edge from node $j_2$ at level $i$ to node $j_1$ at level $i+1$. If $\bm{B}_i$ is sparse, it means that at that specific stage of transmission, information can only flow along a limited set of paths (edges), effectively "pruning" the direct connections between adjacent levels.

The reason this results in a dense final matrix is that density in $\bm{R}$ does not require every individual factor $\bm{B}_i$ to be dense; rather, it requires that for every pair of nodes $(u, v)$ where $u$ is in the first level and $v$ is in the last level, there exists at least one valid path connecting them through the intermediate levels. While a single sparse matrix might restrict a node's immediate neighbors to only a few targets, multiplying several such matrices allows information to "hop" across different subsets of nodes at each step. As long as the sparsity patterns of $\bm{B}_1, \dots, \bm{B}_m$ are arranged such that their combined connectivity covers all possible source-to-destination pairs, the resulting product $\bm{R}$ will have non-zero entries everywhere. The paper illustrates this with the butterfly structure: by using $\mathcal{O}(\log d)$ sparse matrices (each with only $\mathcal{O}(d)$ edges), they construct a topology where information from every input node eventually reaches every output node via distinct multi-hop paths. This achieves "dense connectivity" globally while maintaining "minimum free edges" locally at each step, thereby reducing the total number of trainable parameters from $\mathcal{O}(d^2)$ to $\mathcal{O}(d \log d)$.
