\title{Stack Exchange of the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

### How does the block-diagonal structure in OFT fail to approximate general linear transforms compared to BOFT?
Question:
The paper states that the block-diagonal structure used in the original Orthogonal Finetuning (OFT) 'reduces expressiveness and cannot approximate classic linear transforms.' I understand that block-diagonal matrices operate independently on subspaces, but I'm struggling to visualize exactly why this prevents the approximation of a general dense linear transform. 

Specifically, if I have a $d \times d$ weight matrix and I split it into $r$ blocks of size $b \times b$, what specific types of transformations are mathematically impossible to represent? Is it because information cannot flow between the different blocks? How does the butterfly structure specifically overcome this limitation to allow for dense connectivity while maintaining parameter efficiency?
Answer:
The block-diagonal structure in the original Orthogonal Finetuning (OFT) fails to approximate general linear transforms because it fundamentally restricts information flow between specific subspaces of the input dimension. When a $d \times d$ weight matrix is decomposed into $r$ independent blocks of size $b \times b$, the resulting orthogonal matrix $\bm{R}$ becomes a direct sum of smaller orthogonal matrices, $\text{diag}(\bm{R}_1, \dots, \bm{R}_r)$. Mathematically, this imposes a strict sparsity pattern where any element $R_{ij}$ connecting a dimension in block $k$ to a dimension in block $l$ (where $k \neq l$) is forced to be exactly zero. Consequently, it is impossible for this structure to represent transformations that require mixing information across these disjoint groups; for instance, if the optimal transformation requires the first input dimension to influence the last output dimension, but they reside in different blocks, the block-diagonal constraint makes this transformation mathematically unrepresentable regardless of how the parameters within the blocks are tuned.

In contrast, Orthogonal Butterfly (BOFT) overcomes this limitation by constructing a dense orthogonal matrix through the sequential multiplication of sparse orthogonal matrices arranged in a butterfly topology. Instead of isolating dimensions into static blocks, BOFT treats the generation of the orthogonal matrix as an information transmission problem on a grid-structured graph. In this framework, each sparse factor in the product allows information to "hop" between nodes at different levels. By composing $\mathcal{O}(\log d)$ such sparse layers, BOFT ensures that every node in the input layer has a directed path to every node in the output layer, effectively creating dense connectivity. This recursive structure, inspired by the Cooley-Tukey Fast Fourier Transform algorithm, allows local interactions at each stage to propagate globally across all dimensions after sufficient depth. As a result, BOFT can recover classic dense linear transforms like the Discrete Fourier Transform and approximate general orthogonal matrices with $\mathcal{O}(d \log d)$ parameters, whereas block-diagonal OFT remains confined to independent subspace rotations and cannot recover these global mixing operations without expanding its block size to $d$, which negates its parameter efficiency.
