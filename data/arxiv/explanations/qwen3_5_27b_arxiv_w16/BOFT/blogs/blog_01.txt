\title{Blogs about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

# From Blocky to Butterfly: A Smarter Way to Fine-Tune AI Giants

Large foundation models like GPT-3 and Stable Diffusion have revolutionized artificial intelligence, offering unprecedented capabilities in language and vision. However, their sheer scale, often comprising hundreds of billions of parameters, makes training them from scratch prohibitively expensive. Consequently, the field has shifted toward parameter-efficient fine-tuning (PEFT), which aims to adapt these massive models to specific downstream tasks without retraining everything. One promising approach is Orthogonal Finetuning (OFT), which preserves the geometric relationships between neurons by applying orthogonal transformations. Yet, standard OFT faces a significant bottleneck: maintaining orthogonality across high-dimensional matrices requires a vast number of trainable parameters. To solve this, researchers have introduced a novel method called Orthogonal Butterfly (BOFT), which borrows a clever structural trick from signal processing to achieve density and flexibility with minimal cost.

## The Problem with Block-Diagonal Constraints

To understand the innovation behind BOFT, we must first look at the limitations of its predecessor, OFT. The core philosophy of OFT is to transform the neurons in a layer using an orthogonal matrix $\bm{R}$ rather than simply adding a low-rank update like LoRA does. Mathematically, if $\bm{W}^0$ is the pretrained weight matrix, the fine-tuned weights become $\bm{R}\bm{W}^0$. Because $\bm{R}$ is orthogonal ($\bm{R}^\top\bm{R} = \bm{I}$), this operation preserves the pairwise angles between neurons, theoretically safeguarding the semantic knowledge acquired during pretraining.

However, learning a full dense orthogonal matrix of dimension $d \times d$ requires approximately $\mathcal{O}(d^2)$ parameters, which defeats the purpose of parameter efficiency. To mitigate this, earlier versions of OFT adopted a block-diagonal structure. This approach splits the dimension $d$ into smaller chunks and applies independent orthogonal transformations to each chunk. While this drastically reduces the parameter count to $\mathcal{O}(bd)$ (where $b$ is the block size), it introduces rigid constraints. By treating dimensions in isolation based on their index order, block-diagonal OFT assumes that features within one block are irrelevant to those in another. This creates an undesirable inductive bias that limits expressiveness; essentially, it forces the model to ignore cross-block interactions that might be crucial for solving complex downstream tasks. Furthermore, finding an optimal sparsity pattern for these blocks remains an open mystery.

## Viewing Matrix Factorization as Information Transmission

The authors of BOFT propose a fresh perspective to overcome these limitations: viewing the construction of a dense orthogonal matrix as an information transmission problem. Imagine a grid where nodes represent dimensions and edges represent connections allowing information flow. A dense matrix implies that every node at the input level can eventually communicate with every node at the output level through a series of intermediate steps.

If we try to build this connectivity using a single step (a dense matrix), we need too many edges (parameters). Instead, BOFT decomposes the transformation into a sequence of sparse matrices multiplied together: $\bm{R} = \bm{B}_m \dots \bm{B}_1$. In this framework, each sparse matrix $\bm{B}_i$ acts as a stage where limited information exchange occurs between adjacent layers of nodes. The goal is to design these stages such that they collectively allow full connectivity from start to finish while minimizing the total number of edges (trainable parameters). This shifts the challenge from finding arbitrary sparse patterns to designing an efficient communication topology that satisfies two conditions: dense connectivity and minimum free edges under orthogonality constraints.

## Borrowing from Signal Processing: The Butterfly Structure

Where does one find such an efficient topology? The answer lies in signal processing and computer science history: the Cooley-Tukey Fast Fourier Transform (FFT) algorithm. The FFT relies on a recursive structure known as the "butterfly" graph to efficiently compute transforms by breaking down large problems into smaller ones with logarithmic complexity. In this structure, information propagates through layers where pairs of nodes interact locally before mixing globally across subsequent layers.

BOFT adapts this butterfly structure for orthogonal fine-tuning. Instead of isolating dimensions into static blocks, BOFT constructs the orthogonal matrix $\bm{R}$ as a product of multiple sparse "butterfly components." Each component consists of small $2 \times 2$ (or $b \times b$) orthogonal blocks arranged in a specific pattern that allows information to mix progressively deeper into the network stack. By chaining $\mathcal{O}(\log d)$ such layers together, BOFT can synthesize a fully dense orthogonal matrix using only $\mathcal{O}(d \log d)$ parameters. This is a significant improvement over both full dense matrices ($\mathcal{O}(d^2)$) and block-diagonal approaches ($\mathcal{O}(bd)$).

Mathematically, if we define a butterfly factor involving diagonal vectors and arrange them recursively into larger matrices $\tilde{\bm{B}}(d,k)$, we can ensure each component remains orthogonal using techniques like Cayley parameterization or 2D rotations. The resulting composite matrix $\bm{R}(m,b)$ maintains strict orthogonality while providing a smooth interpolation between identity matrices (no change) and complex rotations (full expressiveness). Unlike block-diagonal OFT, which cannot approximate classic linear transforms like Fourier or Hadamard transforms due to its rigid separation of dimensions, BOFT's butterfly structure naturally recovers these operations as special cases or approximations within its hypothesis space.

## Practical Advantages and Empirical Results

Beyond theoretical elegance, BOFT offers practical advantages for modern machine learning workflows. First initialization plays a critical role; BOFT initializes all butterfly components as identity matrices (via zero-initialized skew-symmetric matrices), ensuring fine-tuning starts exactly from the pretrained model state without deviation until gradients dictate otherwise. Additionally, standard dropout techniques designed for additive updates like LoRA do not translate well to multiplicative updates in BOFT due to orthogonality constraints. To address this, BOFT introduces "multiplicative dropout," which randomly replaces selected butterfly components or internal blocks with identity matrices during training to prevent overfitting while preserving structural integrity after merging weights back into the base model at inference time—a process that incurs zero latency overhead since no extra modules remain active during deployment.

Extensive experiments demonstrate that BOFT outperforms existing state-of-the-art methods across diverse domains including Large Language Models (LLMs), Vision Transformers (ViTs), and text-to-image diffusion models. In terms of expressivity simulations approximating random dense orthogonal matrices, BOFT consistently achieves lower approximation errors with fewer parameters compared to block-diagonal OFT configurations with equivalent budgets. For instance, a configuration denoted as BOFT(9, 2)—using 9 layers with block size 2—surpasses BOFT(1, 16) in accuracy despite having significantly fewer trainable parameters. This confirms that increasing depth ($m$) while keeping width ($b$) small yields superior parameter efficiency compared to shallow wide structures typical of traditional block-diagonal methods.
