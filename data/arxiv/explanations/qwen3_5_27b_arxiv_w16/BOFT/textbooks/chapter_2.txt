\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 2: # Chapter 2: The Information Transmission Framework

The pursuit of parameter efficiency in fine-tuning large foundation models often forces a trade-off between the expressivity of the learned transformations and the computational resources required to store them. In the context of Orthogonal Fine-tuning (OFT), the challenge lies in constructing a dense orthogonal matrix that can effectively rotate the feature space of a pretrained model without exploding the number of trainable parameters. Traditional approaches, such as using a full dense orthogonal matrix, require $\mathcal{O}(d^2)$ parameters for a dimension $d$, which is prohibitive for modern architectures. Conversely, restricting the matrix to a block-diagonal structure reduces parameter count but imposes rigid inductive biases that limit expressiveness. To resolve this tension, we introduce a novel conceptual shift: viewing the construction of a dense orthogonal matrix not merely as an algebraic exercise in matrix multiplication, but as an information transmission problem on a graph. This framework provides an intuitive geometric lens through which we can systematically design sparse factorizations that yield dense outcomes, ultimately leading to the development of the Orthogonal Butterfly (BOFT) method.

By reframing matrix factorization through the lens of graph theory, we move away from abstract linear algebra operations toward a visualization of connectivity and flow. In this view, a matrix is no longer just a grid of numbers but a map of relationships where non-zero entries represent active channels for information transfer. This perspective allows us to decompose complex transformations into simpler, sequential steps, much like routing signals through stages of a communication network. The goal becomes clear: we seek to arrange these sparse intermediate steps such that they collectively allow information to travel from any starting point to any destination, thereby creating an effective dense transformation, while minimizing the total number of "active wires" or trainable parameters required to build this network. This chapter details how this information transmission framework operates, defines the criteria for optimal designs within it, and contrasts traditional sparsity patterns with more flexible alternatives enabled by this new viewpoint.

# Reframing Matrix Factorization: From Algebra to Graph Theory

At its core, standard Orthogonal Fine-tuning involves updating a pretrained weight matrix $\bm{W}^0$ by multiplying it with a learnable orthogonal matrix $\bm{R}$. Mathematically, if $\bm{W}^0 \in \mathbb{R}^{d \times n}$ represents the frozen weights of a linear layer and $\bm{x} \in \mathbb{R}^d$ is an input vector, the forward pass computes $\bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}$. The objective is to learn $\bm{R}$ such that it adapts the model to downstream tasks while preserving pairwise angles between neurons. The difficulty arises when attempting to make $\bm{R}$ parameter-efficient. A naive solution might suggest simply setting many entries in $\bm{R}$ to zero (sparsification), but arbitrary sparsity destroys orthogonality and breaks the angle-preserving property essential for stable fine-tuning. Alternatively, one might attempt to factorize $\bm{R}$ into a product of smaller matrices, say $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$, hoping that each factor $\bm{B}_i$ can be made sparse while their product remains dense and orthogonal.

From an algebraic standpoint, analyzing which combinations of sparse matrices yield a dense product is cumbersome and lacks immediate intuition regarding *why* certain patterns work better than others. The information transmission framework resolves this by mapping the algebraic operation onto topological structures. We treat each dimension index $j$ in the vector space as a "node" in a graph. Consequently, a $d \times d$ matrix represents connectivity between $d$ source nodes and $d$ target nodes. If an entry $M_{ij}$ in matrix $M$ is non-zero, it signifies a directed edge allowing information (or signal) to flow from node $j$ at one level to node $i$ at the next level. If $M_{ij}$ is zero, no direct connection exists between these specific nodes at that step. When we multiply matrices sequentially ($\bm{B}_m \cdots \bm{B}_1$), we are effectively stacking these graphs vertically in time or depth. The resulting composite transformation describes whether there exists *any* path from an initial node at level 0 to a final node at level $m+1$.

This reframing transforms the problem from finding coefficients for polynomial-like expressions into designing efficient communication networks. Instead of asking "what values should I assign here?", we ask "how should I wire these nodes together?". In this graph-theoretic interpretation, generating a dense orthogonal matrix equivalent to ensuring that every node in the first layer can reach every node in the final layer through some sequence of edges provided by the intermediate sparse matrices $\bm{B}_i$. This shift is profound because it decouples the complexity of individual connections from their collective outcome. It allows us to reason about global density (connectivity) as an emergent property of local sparsity patterns arranged across multiple layers. Just as telecommunications engineers design routers and switches to maximize bandwidth while minimizing cabling costs, we can now design sparse orthogonal factors that maximize expressivity (global connectivity) while minimizing trainable parameters (total edges).

# Visualizing Matrix Multiplication as Information Flow on Grid Graphs

To fully grasp how sparse factors combine into dense products under this framework, one must visualize matrix multiplication as signal propagation through a grid-structured graph. Consider the factorization $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$. We can imagine this process occurring on a grid consisting of $d$ rows (representing dimensions) and $m+1$ columns (representing layers or time steps). At each column $k$, there are $d$ nodes corresponding to the dimensions at that stage of computation. The matrix $\bm{B}_k$ dictates how information moves from column $k$ to column $k+1$. Specifically, if $(\bm{B}_k)_{uv} \neq 0$, there is a directed edge connecting node $v$ at column $k$ to node $u$ at column $k+1$. The value zero implies no edge exists; thus, no direct transmission occurs between those specific nodes at that step.

When we compute the product $\bm{R}$, we are essentially tracing paths through this multi-layered grid. An entry $(\bm{R})_{xy}$ is non-zero if and only if there exists at least one valid path from node $x$ in column 0 (input) to node $y$ in column $m+1$ (output). If even one path exists involving non-zero edges across all intermediate matrices $\bm{B}_1$ through $\bm{B}_m$, then information originating at input dimension $x$ contributes to output dimension $y$, rendering $(\BM R)_{xy}$ potentially non-zero after optimization. Conversely, if no path connects them—meaning every possible chain of connections contains at least one broken link (a zero entry)—then $(\BM R)_{xy}$ will remain structurally zero regardless of parameter updates during training. This structural zero pattern determines whether our final transformation is truly capable of mixing all features globally or if it remains partitioned into isolated subsystems.

Consider a concrete example where we aim for full density with four dimensions ($d=4$). Suppose we use five sparse matrices ($\BM B_5 \dots \BM B_1$). If we examine partial products like $\BM B_4 \BM B_3 \BM B_2 \BM B_1$, we might find that information from input node 1 cannot reach output node 3 because all potential routes are blocked by zeros in earlier stages; consequently, position $(3,1)$ would be structurally zero in this partial product but could become non-zero once multiplied by subsequent matrices like $\BM B_5$. By unrolling these multiplications into layers on our grid graph, we can visually inspect exactly which pairs are connected and which are not before any numerical training begins. This visualization reveals that achieving global density does not require every single intermediate matrix $\BM B_k$ to be dense; rather, it requires their combined topology to form complete bipartite connectivity between start and finish nodes over time steps 0 and $m+1$. This insight liberates us from needing massive parameter counts per layer; instead, we only need sufficient diversity in connection patterns across layers so that every source eventually reaches every
