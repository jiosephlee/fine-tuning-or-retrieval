Chapter 3: # Chapter 3: Core Innovations II - The sLSTM Variant

The evolution of the Long Short-Term Memory (LSTM) network into the Extended Long Short-Term Memory (xLSTM) architecture addresses fundamental limitations inherent in classical recurrent designs. While the previous chapter explored the matrix-based mLSTM designed for massive storage capacity and parallelization, this chapter focuses on the scalar variant, known as sLSTM. The primary motivation for developing sLSTM stems from a critical deficiency in traditional LSTMs: the inability to effectively revise storage decisions once information has been committed to the cell state. In tasks requiring dynamic updates, such as identifying the nearest neighbor in a stream of data or tracking complex logical states like parity, standard LSTMs often struggle to overwrite old information with newly discovered, more relevant data. The sLSTM resolves this by introducing exponential gating mechanisms coupled with rigorous normalization and stabilization techniques. Unlike its matrix counterpart, which sacrifices sequential dependencies for speed, the sLSTM retains and enhances the concept of memory mixing through hidden-to-gate recurrent connections. This design choice empowers the model to perform sophisticated state tracking, making it uniquely capable of solving formal language problems that stump both Transformers and simpler State Space Models. By integrating these innovations into a scalar memory framework, sLSTM bridges the gap between the historical robustness of LSTMs and the demands of modern large-scale language modeling.

# Architecture of the Scalar LSTM (sLSTM)

The architectural foundation of the scalar LSTM (sLSTM) builds directly upon the classic LSTM formulation but introduces profound modifications to its gating dynamics and normalization strategies. At its core, the sLSTM maintains a single scalar cell state $c_t$ at each time step $t$, serving as a compact repository for temporal information. However, unlike traditional LSTMs where gates are bounded by sigmoid activations that squash values into a fixed interval between zero and one, the sLSTM employs exponential activation functions for its input and forget gates. This shift is not merely cosmetic; it fundamentally alters how information flows into and persists within the memory cell. In standard LSTMs, if an input gate is slightly activated but a subsequent forget gate decides to retain old information strongly, updating that specific piece of information can be difficult because the multiplicative interaction limits flexibility. With exponential gating, the model gains a continuous, unbounded range to modulate these flows, theoretically allowing for more precise control over when to write new data versus when to preserve existing traces.

Crucially, replacing sigmoid functions with exponentials introduces significant numerical instability risks, as exponential growth can rapidly lead to overflow errors during computation. To mitigate this without sacrificing performance or altering the underlying mathematical properties of the network gradients, the sLSTM incorporates a dedicated stabilizer state $m_t$. This auxiliary variable tracks the maximum log-values encountered across time steps involving both input and forget gates. By subtracting this running maximum from the raw logarithmic values before applying the exponential function—a technique akin to log-sum-exp tricks—the network ensures that all intermediate calculations remain within safe floating-point ranges while preserving relative magnitudes. Furthermore, because exponential gating removes implicit bounds on how much information accumulates in $c_t$, a normalizer state $n_t$ is introduced alongside it. This normalizer acts as a dynamic denominator that sums up products of input gates and future forget gates over time. When computing the final hidden state output $\tilde{h}_t$, the cell state $c_t$ is divided by this normalizer $n_t$. This division effectively renormalizes the accumulated memory content at every step, ensuring that signals do not explode or vanish regardless of how many timesteps have passed or how aggressively gates have opened or closed since inception.

# Forward Pass Equations with Exponential Input and Forget Gates

To fully grasp the mechanics of sLSTM, one must examine its forward pass equations in detail, observing how each component interacts sequentially at time step $t$. The process begins with calculating candidate values derived from current inputs $\mathbf{x}_t$ and previous hidden states $\mathbf{h}_{t-1}$. Specifically, pre-activation values $\tilde{z}_t$, $\tilde{i}_t$, $\tilde{f}_t$, and $\tilde{o}_t$ are computed via linear projections involving weight vectors $\mathbf{w}$ and recurrent weights $r$, along with bias terms $b$. The cell input candidate is generated as $z_t = \varphi(\tilde{z}_t)$ where $\varphi$ is typically a hyperbolic tangent function ($\tanh$). The pivotal innovation appears in how these pre-activations are transformed into actual gate values. Instead of passing them through a sigmoid function $\sigma(x)$, which saturates near zero or one exponentially slowly as inputs move away from zero toward infinity or negative infinity respectively (though usually capped), we apply direct exponentiation: $i_t = \exp(\tilde{i}_t)$ for the input gate and potentially $f_t = \exp(\tilde{f}_t)$ for the forget gate (though sigmoid remains an option depending on configuration).

Once these raw exponential values are determined—or stabilized versions thereof—they drive two parallel recursive updates: one for memory accumulation ($c_t$) and one for normalization ($n_t$). The updated cell state follows an additive rule similar to classical LSTMs but driven by unbounded factors:
$$ c_t = f'_t c_{t-1} + i'_t z_t $$
Here $f'_t$ and $i'_t$ represent stabilized forms defined later in this section using $m_{t-1}$ and $m_t$. Simultaneously, a companion equation governs evolution of our normalizing factor:
$$ n_t = f'_t n_{t-1} + i'_t $$
Noticeably absent here is any multiplication by external candidates like $z_t$; instead simply adding scaled contributions allows us track cumulative weighting effects purely dictated by history dependent decision-making processes encoded within those specific gating pathways themselves rather than magnitude fluctuations arising solely from incoming signal strengths alone!
