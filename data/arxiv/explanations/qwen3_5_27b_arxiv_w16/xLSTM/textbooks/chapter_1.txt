Chapter 1: # Chapter 1: The Evolution of Sequence Modeling and the Revival of LSTMs

## Historical Overview: From Constant Error Carousel to Transformer Dominance

The story of sequence modeling in deep learning began in earnest during the 1990s with the introduction of the Long Short-Term Memory (LSTM) network. Before this innovation, standard Recurrent Neural Networks (RNNs) struggled significantly with the vanishing gradient problem, a phenomenon where gradients diminish exponentially as they are backpropagated through time, rendering it nearly impossible for networks to learn dependencies spanning long temporal distances. To overcome this fundamental barrier, researchers introduced two central ideas: the constant error carousel and gating mechanisms. The constant error carousel refers to an additive update mechanism within a dedicated memory cell that allows error signals to flow backward through time without decaying, effectively creating a path for gradients to persist over long sequences. This concept was paired with gating units—specifically input, forget, and output gates—that regulate the flow of information into, out of, and within this memory cell. These innovations allowed LSTMs to stand the test of time for decades, becoming the backbone of numerous deep learning success stories. They were instrumental in pioneering early Large Language Models (LLMs) and excelled in diverse domains ranging from text generation and handwriting synthesis to machine translation and even complex reinforcement learning tasks like controlling nuclear fusion reactors or playing professional-level games such as StarCraft II and Dota 2.

However, despite their robustness and proven efficacy in learning abstractions like syntax and semantics, the landscape of artificial intelligence shifted dramatically with the advent of the Transformer architecture in 2017. The Transformer introduced self-attention mechanisms that were inherently parallelizable, allowing for massive scalability that sequential recurrent models could not match at the time. While LSTMs continued to serve niche applications requiring extreme efficiency or specific types of abstraction extraction, they were largely superseded by Transformers in large-scale language modeling. The inability of LSTMs to leverage modern hardware efficiently due to their sequential nature meant they fell behind as model sizes grew into the billions of parameters. Yet, this displacement raises a compelling question regarding the theoretical limits of recurrent architectures: If we take the foundational principles of LSTMs but systematically mitigate their known structural limitations using modern techniques derived from current Large Language Models, how far can we push their performance? This inquiry forms the basis for revisiting and extending LSTM capabilities to compete once again with state-of-the-art attention-based models.

## Mathematical Foundations of the Original LSTM (Cell State, Input/Forget/Output Gates)

To understand how xLSTM extends these concepts, one must first rigorously define the mechanics of the original LSTM. At its core lies a scalar memory cell state, denoted as $c_t$, which acts as a conveyor belt for information across time steps. The evolution of this cell state is governed by an additive update rule designed to preserve information flow while selectively modifying content based on incoming data. Mathematically, this update is expressed as $c_t = f_t c_{t-1} + i_t z_t$. Here, $c_{t-1}$ represents the previous cell state carried forward from time step $t-1$. The term $f_t$ is the forget gate activation value, which modulates how much of the previous state is retained; if $f_t$ is close to zero, old information is discarded, whereas a value near one preserves it entirely. Simultaneously, new candidate information $z_t$ is generated from the current input $\mathbf{x}_t$ and potentially filtered by an input gate $i_t$. This new information is added to the scaled previous state to form the updated cell state $c_t$.

Once the cell state is updated, it does not directly become the output; instead, it passes through an output gate mechanism to produce the hidden state $h_t$, which serves as both the output for that time step and part of the input for subsequent calculations. This relationship is defined by $h_t = o_t \psi(c_t)$, where $\psi$ is a non-linear activation function (typically $\tanh$) used to normalize or squash the unbounded cell state values into a manageable range. The output gate $o_t$ controls how much of this normalized internal representation is exposed externally. Crucially, all three gates—the input gate $i_t$, forget gate $f_t$, and output gate $o_t$—are computed using sigmoid activation functions $\sigma(x) = 1/(1+\exp(-x))$, ensuring their values lie strictly between 0 and 1. Each gate receives contributions from both external inputs $\mathbf{x}_t$ via weight vectors $\mathbf{w}$ and recurrent connections from the previous hidden state $h_{t-1}$ via recurrent weights $r$. For instance, pre-gate activations like $\tilde{f}_t = \mathbf{w}^\top_f \mathbf{x}_t + r_f h_{t-1} + b_f$ are calculated before passing through the sigmoid function. This intricate system of multiplicative gating allows LSTMs to dynamically manage memory retention and access but relies heavily on scalar representations that impose specific constraints on capacity and flexibility.

## Limitation I: Inability to Revise Storage Decisions (The Nearest Neighbor Search Problem)

A primary structural weakness inherent in traditional LSTMs is their inability to easily revise storage decisions once made during sequential processing. Because standard LSTMs rely on sigmoid gates bounded between 0 and 1 for forgetting ($f_t$), once a piece of information has been partially forgotten or overwritten by subsequent updates involving smaller gate values, recovering or correcting that decision becomes mathematically difficult without significant interference from new data streams that may not align perfectly with prior errors. This limitation manifests starkly in tasks requiring dynamic updating based on global context comparisons within a sequence. A canonical example illustrating this failure mode is the Nearest Neighbor Search problem. In this scenario, given a reference vector at some point in time or implicitly held in working memory, an agent must scan a sequence sequentially to find another vector most similar to it and retrieve its associated value at the end of the sequence. As new vectors arrive that are increasingly similar to the reference vector than previously stored candidates should be selected over older ones—a process requiring continuous revision of what constitutes "best."
