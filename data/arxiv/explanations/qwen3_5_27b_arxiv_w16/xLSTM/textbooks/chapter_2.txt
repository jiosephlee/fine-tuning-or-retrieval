Chapter 2: # Chapter 2: Core Innovations I - Exponential Gating and Stabilization

## From Sigmoid to Exponential Gates: Theory and Benefits

The foundational architecture of the Long Short-Term Memory (LSTM) network relies heavily on gating mechanisms to regulate the flow of information through time. In the classic formulation introduced in the 1990s, these gates—specifically the input gate $i_t$, forget gate $f_t$, and output gate $o_t$—utilize the sigmoid activation function $\sigma(x) = 1/(1+\exp(-x))$. The sigmoid function maps any real-valued input to a bounded interval between 0 and 1. While this boundedness ensures that the magnitude of updates remains controlled, it imposes a strict ceiling on how aggressively the network can modify its internal state. The primary innovation proposed in the xLSTM framework addresses this constraint by replacing the sigmoid activation with an exponential function for specific gates, particularly the input gate and optionally the forget gate. This shift from a saturating, bounded non-linearity to an unbounded exponential growth function fundamentally alters the dynamics of memory updating. By employing an exponential activation, defined as $\exp(\tilde{g}_t)$ where $\tilde{g}_t$ is a linear projection of inputs and previous hidden states, the model gains the theoretical capacity to generate arbitrarily large weighting factors. This capability is critical for scenarios requiring rapid adaptation or drastic revisions of stored information, allowing the network to effectively "overwrite" old memories with high-confidence new signals without being throttled by the asymptotic limit of unity inherent in sigmoidal gating.

## The Role of Exponential Gating in Revising Stored Information

One of the most significant limitations identified in traditional LSTMs is their inability to efficiently revise storage decisions once information has been committed to the cell state. This deficiency is starkly illustrated by tasks such as Nearest Neighbor Search, where a model must scan a sequence to find a vector most similar to a reference vector and retain only that associated value at the end of the sequence. In a standard LSTM utilizing sigmoid gates, if an initial candidate vector is deemed sufficiently similar and stored with a moderate weight, finding a subsequently superior candidate requires increasing its own weight while simultaneously decreasing the influence of the prior storage via the forget gate. Because both gates are constrained to values less than or equal to 1, this process often results in a slow, gradual attenuation rather than an immediate replacement. The network struggles to completely discard inferior information in favor of superior information discovered later in the sequence.

Exponential gating directly remediate this limitation by enabling dynamic range expansion in decision-making weights. When an exponentially activated input gate encounters a highly relevant new piece of information, it can produce a value significantly greater than 1. Simultaneously, if paired with an exponential forget gate or simply relying on relative magnitudes, this large input weight can dominate previous contributions instantly. Mathematically, if $i_t$ represents an exponentially scaled importance score for new data $z_t$, and $f_t$ represents retention probability for old data $c_{t-1}$, an extremely large $i_t$ allows the term $i_t z_t$ to overwhelm $f_t c_{t-1}$ regardless of how close $f_t$ is to 1. This mechanism empowers xLSTM units to perform true "revision," effectively swapping out outdated or incorrect associations with newly discovered correct ones immediately upon observation. This capability transforms the memory cell from a passive accumulator into an active repository capable of correcting its own historical records based on evolving evidence within a sequence.

## Designing the Normalizer State ($n_t$): Tracking Cumulative Gate Products

While exponential gating offers superior flexibility for revising memory, it introduces a fundamental instability regarding scale consistency if left unchecked. In standard LSTMs with sigmoid gates, since all weights are between 0 and 1, repeated multiplications naturally tend toward zero unless actively maintained near unity by biases; however, this bounded nature implicitly prevents runaway growth without explicit normalization logic beyond standard activations like tanh on hidden states. With exponential gates producing values potentially spanning several orders of magnitude above or below 1 depending on their raw logits $\tilde{i}_t$, simply adding these terms into a recursive equation like $c_t = f_t c_{t-1} + i_t z_t$ leads to unpredictable scaling behaviors where valid signal magnitudes become indistinguishable from noise due to arbitrary inflation or deflation over time steps. To resolve this, xLSTM introduces a dedicated auxiliary variable known as the normalizer state, denoted as $n_t$.

The normalizer state serves as a running tracker for the cumulative effect of all gating operations applied along temporal paths leading up to time step $t$.
