\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### How does GRPO eliminate the need for a separate Critic model compared to PPO?
Question:
In the 'Group Relative Policy Optimization' section, the authors state that GRPO 'foregoes the critic model' and instead estimates the baseline from group scores. In standard PPO, the advantage $A_t$ is calculated using a learned value function $V_{\psi}$ via Generalized Advantage Estimation (GAE). 

I am confused about the mechanics here. If we remove $V_{\psi}$, how exactly is the advantage $\hat{A}_{i,t}$ computed? The paper mentions normalizing rewards by subtracting the group mean and dividing by the standard deviation ($\widetilde{r}_i = \frac{r_i- {\rm mean}(\mathbf{r})}{{\rm std}(\mathbf{r})}$). Does this normalization *replace* the temporal difference error calculation entirely? How does this handle variance reduction across different sequence lengths within a group?
Answer:
In the DeepSeekMath paper, GRPO eliminates the need for a separate Critic model by replacing the learned value function $V_{\psi}$ with a statistical baseline derived directly from the rewards of a group of sampled outputs generated for the same prompt. In standard PPO, the advantage $A_t$ relies on Generalized Advantage Estimation (GAE), which requires a trained value network to predict returns and calculate temporal difference errors; this doubles the memory footprint since the Critic is typically as large as the Actor (policy) model. GRPO bypasses this by sampling $G$ distinct completions $\{o_1, \dots, o_G\}$ for a single question $q$, scoring them with a reward model to get $\mathbf{r} = \{r_1, \dots, r_G\}$, and then computing a normalized reward $\widetilde{r}_i = \frac{r_i - \text{mean}(\mathbf{r})}{\text{std}(\mathbf{r})}$.

This normalization serves as the direct substitute for the temporal difference error calculation. Instead of estimating what the return *should* be at every token using a learned function, GRPO treats the group mean as the dynamic baseline for that specific query. Consequently, for **outcome supervision**, where a single reward is given at the end of generation, the advantage $\hat{A}_{i,t}$ for every token $t$ in output $o_i$ is simply set equal to this normalized scalar $\widetilde{r}_i$. For **process supervision**, where rewards are assigned to intermediate reasoning steps, the advantage is calculated as the cumulative sum of normalized rewards from all subsequent steps: $\hat{A}_{i,t} = \sum_{j : index(j) \ge t} \widetilde{r}_{i}^{(index(j))}$. Regarding variance reduction across different sequence lengths within a group, GRPO handles this implicitly through this group-relative formulation; because all outputs in a group respond to the same question $q$, comparing them against their own group statistics inherently controls for difficulty variations inherent to that specific prompt. By anchoring the advantage calculation to the immediate distribution of outcomes rather than a global learned value function, GRPO achieves variance reduction necessary for stable training while removing the computational overhead of maintaining and updating a parallel Critic network.
