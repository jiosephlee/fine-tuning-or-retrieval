\title{Blogs about the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

# FP8 Without the Loss: Achieving Near-Petaflop Speeds with High Accuracy

Switching to low-precision arithmetic like FP8 is often seen as a necessary evil in deep learning: you gain massive computational throughput, but you risk degrading model quality due to numerical errors. This trade-off becomes particularly acute in Large Language Models (LLMs), where activation outliers—values significantly larger than the rest of the distribution—can wreak havoc on quantization schemes. However, the latest release of **FlashAttention-3** challenges this assumption. By leveraging new hardware capabilities on NVIDIA Hopper GPUs and introducing novel algorithmic techniques, FlashAttention-3 achieves speeds approaching 1.2 PFLOPs/s while simultaneously reducing numerical error by 2.6 times compared to standard baselines.

## The Hardware Bottleneck and the Promise of Asynchrony

To understand why FlashAttention-3 is a leap forward, we must look at how attention mechanisms interact with modern GPU hardware. Previous iterations, specifically FlashAttention-2, were designed with a synchronous execution model that did not fully exploit the asynchronous nature of newer architectures like the H100. Consequently, FlashAttention-2 achieved only about 35% utilization on H100 GPUs, leaving significant compute capacity idle.

FlashAttention-3 addresses this by redesigning the algorithm to embrace **asynchrony**. Modern GPUs feature specialized hardware units for distinct tasks: Tensor Cores handle matrix multiplication (GEMM), while Tensor Memory Accelerators (TMA) handle data movement. FlashAttention-3 utilizes a **producer-consumer warp-specialization** scheme. In this setup, some warps act solely as producers, handling data loads via TMA, while others act as consumers, executing computations on Tensor Cores. This separation allows the system to overlap memory transfers with heavy computation effectively hiding latency.

Furthermore, the algorithm introduces a **2-stage pipelining** technique that overlaps low-throughput operations (like the exponential function required for softmax) with high-throughput GEMM operations. By interleaving these tasks across different warpgroups in a "pingpong" fashion, FlashAttention-3 keeps the Tensor Cores saturated, pushing FP16 performance up to 740 TFLOPs/s and achieving roughly 75% hardware utilization.

## Cracking the Code on FP8 Precision

While maximizing throughput in FP16 is impressive, the true breakthrough lies in how FlashAttention-3 handles FP8 precision. On Hopper GPUs, FP8 Tensor Cores offer double the throughput of FP16 cores theoretically allowing for speeds nearing 1.2 PFLOPs/s. However, utilizing FP8 presents two major hurdles: strict memory layout requirements and severe accuracy degradation caused by outliers.

The paper outlines two critical innovations that solve these problems without sacrificing speed or accuracy: **block quantization** and **incoherent processing**.

### Block Quantization
Traditional approaches often use per-tensor scaling for quantization, applying a single scalar multiplier to an entire tensor ($\mathbf{Q}$, $\mathbf{K}$, or $\mathbf{V}$). If a tensor contains even one extreme outlier value, this single scalar forces all other values to be scaled down aggressively to accommodate it, resulting in significant precision loss for the majority of normal values.

FlashAttention-3 replaces this with **block quantization**. Instead of one scalar per tensor, it maintains one scalar per block (e.g., per tile of size $B_r \times d$). Since FlashAttention already processes data in blocks during its tiled computation loop, adding this granular scaling incurs virtually no additional computational overhead. This ensures that outliers in one block do not negatively impact the precision of values in neighboring blocks.

### Incoherent Processing
Even with block quantization, extreme outliers can still skew results within a specific block. To mitigate this, FlashAttention-3 employs **incoherent processing**. Before quantizing $\mathbf{Q}$ and $\mathbf{K}$ to FP8, they are multiplied by a random orthogonal matrix $\mathbf{M}$. Because $\mathbf{M}$ is orthogonal ($\mathbf{M}\mathbf{M}^\top = I$), this transformation preserves the mathematical integrity of the attention output ($(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{K}^\top$).

Practically speaking, multiplying by $\mathbf{M}$ spreads out the energy of outlier features across many entries rather than concentrating them in a few spikes. Each entry in the transformed matrix becomes a random sum of original entries, effectively smoothing out peaks that would otherwise cause quantization errors during conversion to FP8. The authors implement this efficiently using products of random diagonal matrices and Hadamard matrices, allowing for $O(d \log d)$ complexity that can be fused into existing operations like rotary embeddings at no extra cost.

## Empirical Results: Speed Meets Accuracy

The combination of these architectural optimizations yields remarkable empirical results on NVIDIA H100 SXM5 GPUs. In terms of raw speed, FlashAttention-3 delivers a 1.5x to 2.0x speedup over FlashAttention-2 in FP16 mode and reaches close to 1.2 PFLOPs/s when running in FP8 mode for long sequences where it outperforms or matches state-of-the-art vendor libraries like cuDNN 9 depending on head dimensions and masking configurations.

Perhaps more importantly for model reliability is the validation of numerical stability. When tested against synthetic data distributions simulating LLM outliers (normal noise mixed with rare high-variance spikes), standard attention implementations using per-tensor FP8 quantization suffer from significant Root Mean Squared Error (RMSE). In contrast:
*   **FP16 FlashAttention-3** maintains parity with FlashAttention-2 while being significantly more accurate than standard implementations because intermediate softmax calculations remain in FP32 precision locally on-chip before writing results back to global memory later if needed (though FA3 writes final outputs).
*   **FP8 FlashAttention-3**, thanks to block quantization and incoherent processing, achieves **2.6x lower numerical error** compared to baseline FP8 attention using per-tensor scaling.

## Conclusion

FlashAttention-3 demonstrates that high-performance computing does not require compromising on numerical fidelity when moving toward lower precisions like FP8. By aligning software algorithms with hardware realities—specifically through warp-specialized asynchrony—and employing smart statistical tricks like block quantization and orthogonal mixing for outlier mitigation, it unlocks near-petaflop performance without losing accuracy as intermediate steps degrade model quality during training or inference will likely see widespread adoption across frameworks like PyTorch and Hugging Face as these primitives become standardized tools for building next-generation AI systems capable of handling increasingly long contexts and massive datasets efficiently
