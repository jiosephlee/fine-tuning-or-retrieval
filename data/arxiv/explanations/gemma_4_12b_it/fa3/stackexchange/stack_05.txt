\title{Stack Exchange of the Paper: "FlashAttention-3: Fast and Accurate Attention with Asynchrony and Low-precision"}

### What is the intuition behind 'Incoherent Processing' for mitigating quantization error?
Question:
The paper suggests multiplying $\mathbf{Q}$ and $\mathbf{K}$ by a random orthogonal matrix $\mathbf{M}$ before quantizing to FP8. Mathematically, I see that $(\mathbf{Q}\mathbf{M})(\mathbf{K}\mathbf{M})^\top = \mathbf{Q}\mathbf{K}^\top$ because $\mathbf{M}\mathbf{M}^\top = \mathbf{I}$. However, I don't understand the intuition of how this 'spreads out' outliers. If a row in $\mathbf{K}$ has one extremely large value, how does multiplying by a random matrix $\mathbf{M}$ make that value 'easier' to represent in a low-precision format like FP8 (e4m3)?
Answer:
The intuition behind "Incoherent Processing" lies in how outliers affect the dynamic range of a floating-point representation. To understand why multiplying by a random orthogonal matrix $\mathbf{M}$ helps, we have to look at the tension between the peak magnitude of values and the available precision in a low-bit format like FP8.

In formats like FP8 (e4m3), you have a very limited number of bits for the exponent and the mantissa. When you quantize a block of numbers, you typically choose a scaling factor based on the maximum absolute value in that block. If a block contains a significant outlier—a single value much larger than the rest—the scaling factor must be large enough to accommodate that outlier. However, because the scale is so large, the "normal" values in that same block are forced into a very small range relative to the scale. When these small values are converted to FP8, they often lose significant precision or are rounded to zero because the limited mantissa bits cannot represent them accurately at that scale. This is the primary source of quantization error in models with "spiky" activations or weights.

The orthogonal matrix $\mathbf{M}$ acts as a linear transformation that preserves the $L_2$ norm of the vectors while "rotating" them in high-dimensional space. As you noted, since $\mathbf{M}\mathbf{M}^\top = \mathbf{I}$, the final result of the attention score $\mathbf{Q}\mathbf{K}^\top$ remains mathematically identical to the original computation. However, the intermediate values in the matrices $\mathbf{Q}\mathbf{M}$ and $\mathbf{K}\mathbf{M}$ are different. 

Specifically, if a row in $\mathbf{K}$ has a massive outlier (e.g., a vector where one dimension is $1000$ and all others are near $0$), the energy of that outlier is concentrated in a single dimension. When you multiply by a random orthogonal matrix (like the Hadamard-based matrix mentioned in the paper), that "energy" is redistributed across all $d$ dimensions. Each entry in the resulting vector $\mathbf{K}\mathbf{M}$ becomes a linear combination of the original entries. Instead of one dimension having a value of $1000$, you might end up with $d$ dimensions having values significantly smaller than $1000$ (but still summing to the same total magnitude). 

By "spreading out" the magnitude of the outlier across many dimensions, the maximum value in any given block is reduced. This allows the block quantization scheme to use a smaller scaling factor. A smaller scaling factor effectively "zooms in" on the smaller, more common values, allowing them to be represented with much higher precision in the FP8 format. 

In essence, incoherent processing transforms "coherent" outliers (where the magnitude is concentrated in specific features) into "incoherent" distributions (where the magnitude is spread across many features). This doesn't change the final dot product, but it makes the values much more "friendly" for the fixed-range constraints of low-precision hardware. The paper specifically notes the use of a product of random diagonal matrices and a Hadamard matrix because this construction allows the transformation to be computed in $O(d \log d)$ time, making it computationally efficient to fuse into the existing attention pipeline.
