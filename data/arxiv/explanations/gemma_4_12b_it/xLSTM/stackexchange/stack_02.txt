\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How does the stabilizer state $m_t$ mathematically ensure that the gradients remain unchanged?
Question:
In Section 3.1, the authors introduce a stabilizer state $m_t$ to handle the potential overflows of exponential gates. They provide the following equations:

$m_t = \max(\log(f_t) + m_{t-1}, \log(i_t))$ 

$i'_t = \exp(\log(i_t) - m_t) = \exp(\tilde{i}_t - m_t)$

$f'_t = \exp(\log(f_t) + m_{t-1} - m_t)$


The paper claims that replacing $f_t$ and $i_t$ with $f'_t$ and $i'_t$ does not change the output of the network nor the derivatives of the loss. I can see that the $m_t$ term cancels out in the product $i'_t \times f'_t$ (or similar combinations), but I'm struggling to see why the gradient $\frac{\partial \mathcal{L}}{\partial \mathbf{w}}$ remains identical. Could someone provide a brief derivation or intuition for why this stabilization is 'lossless'?
Answer:
The reason this stabilization is "lossless" is that the stabilizer state $m_t$ acts as a dynamic shift in the log-domain that factorizes out of the linear recurrence. Mathematically, while the individual values of the stabilized gates $f'_t$ and $i'_t$ are different from the original gates $f_t$ and $i_t$, the ratio of the components in the cell state update remains invariant.

To see this, let's define the original (un-stabilized) gates as $i_t = \exp(\tilde{i}_t)$ and $f_t = \exp(\tilde{f}_t)$. The stabilizer state is defined as $m_t = \max(\tilde{f}_t + m_{t-1}, \tilde{i}_t)$. When we substitute the definitions of the stabilized gates into the cell state recurrence, we get:

$c_t = f'_t c_{t-1} + i'_t z_t$
$c_t = \exp(\tilde{f}_t + m_{t-1} - m_t) c_{t-1} + \exp(\tilde{i}_t - m_t) z_t$

Because the term $\exp(-m_t)$ is common to both additions, we can factor it out:

$c_t = \exp(-m_t) \left[ \exp(\tilde{f}_t + m_{t-1}) c_{t-1} + \exp(\tilde{i}_t) z_t \right]$
$c_t = \exp(-m_t) \left[ f_t \exp(m_{t-1}) c_{t-1} + i_t z_t \right]$

Now, let's define an auxiliary variable $C_t = c_t \exp(m_t)$. If we substitute $c_{t-1} = C_{t-1} \exp(-m_{t-1})$ into the equation above, the terms simplify significantly:

$C_t \exp(-m_t) = \exp(-m_t) \left[ f_t \exp(m_{t-1}) (C_{t-1} \exp(-m_{t-1})) + i_t z_t \right]$
$C_t = f_t C_{t-1} + i_t z_t$

This shows that $C_t$ follows the exact same recurrence as the original cell state $c_t$ would have followed in a non-stabilized system. The same logic applies to the normalizer state $n_t$: by defining $N_t = n_t \exp(m_t)$, you can show that $N_t = f_t N_{t-1} + i_t$, which is the original normalizer update.

The final hidden state $\tilde{h}_t$ is calculated as the ratio of these two states. In the stabilized version, we have:

$\tilde{h}_t = \frac{c_t}{n_t} = \frac{C_t \exp(-m_t)}{N_t \exp(-m_t)} = \frac{C_t}{N_t}$

Because the $\exp(-m_t)$ terms cancel out perfectly, the value of the hidden state $\tilde{h}_t$ is algebraically identical in both the stabilized and non-stabilized versions of the network. Since the hidden state is the only output of the memory cell that feeds into the rest of the network (and subsequently into the loss function $\mathcal{L}$), any operation performed after this point—including the calculation of the loss and the backpropagation of gradients—is operating on the exact same values. 

In terms of intuition, this is very similar to the "Log-Sum-Exp" trick used in Softmax. In Softmax, $\frac{\exp(x_i)}{\sum \exp(x_j)} = \frac{\exp(x_i - \max(x))}{\sum \exp(x_j - \max(x))}$. The stabilizer $m_t$ performs a similar operation but does so dynamically at every time step. It shifts the magnitude of the gates to prevent numerical overflow while ensuring that the relative proportions of the input and forget operations remain unchanged. Because the forward pass is mathematically invariant to this shift, the Chain Rule ensures that the gradients $\frac{\partial \mathcal{L}}{\partial \mathbf{w}}$ remain identical.
