\title{Stack Exchange of the Paper: "DeepSeekMath: Pushing the Limits of Mathematical Reasoning in Open Language Models"}

### Does GRPO eliminate the need for a Reward Model entirely?
Question:
I am reading the section on Group Relative Policy Optimization (GRPO). The paper states that GRPO 'foregoes the critic model' and instead estimates the baseline from group scores. Since the critic model in PPO is used to estimate the advantage, I'm confused: does this mean we don't need a Reward Model ($r_\varphi$) anymore to train the policy, or is the Reward Model still used to generate the scores for the group?
Answer:
The short answer is no, GRPO does not eliminate the need for a Reward Model ($r_\varphi$). The confusion arises from the distinction between the **Critic model** and the **Reward Model**, which serve different roles in the reinforcement learning pipeline.

In the standard Proximal Policy Optimization (PPO) framework described in the paper, the training process requires two auxiliary models alongside the policy model ($\pi_\theta$). First, it needs a Reward Model ($r_\varphi$) to provide a scalar score for the outputs. Second, it needs a Critic model (a value function $V_\psi$) to estimate the "baseline." The Critic's job is to predict the expected reward for a given state so that the algorithm can calculate the advantage ($A_t$), which represents how much better a specific action was compared to the average expectation. Because the Critic model typically needs to be of a similar size to the policy model, it introduces a significant memory and computational burden.

GRPO is designed specifically to alleviate this burden by "foregoing the critic model." However, it still relies on the Reward Model to provide the raw scores. Instead of using a Critic model to predict a baseline, GRPO samples a group of $G$ different outputs $\{o_1, o_2, \dots, o_G\}$ for the same question $q$. It then uses the Reward Model ($r_\varphi$) to score every output in that group. The "baseline" is then derived relatively from these scores—specifically by calculating the mean and standard deviation of the rewards within that specific group. As shown in Section 4.1.1 and Algorithm 1, the advantage $\hat{A}_{i,t}$ is computed based on these relative rewards.

Intuitively, you can think of the Critic model as an "internal judge" that tries to guess how good a partial sentence is before it is finished. GRPO replaces this internal judge with a "peer review" system: by generating multiple versions of the same answer and scoring them all with the Reward Model, the algorithm can see which versions performed better than the group average. This allows the model to learn from the relative differences between outputs without needing to maintain a separate, large Critic network. 

The paper explicitly confirms this in Algorithm 1, where step 9 states: "Compute rewards $\{r_i\}_{i=1}^{G}$ for each sampled output $o_i$ by running $r_\varphi$." Furthermore, the section on Outcome Supervision reinforces this by stating that a reward model is used to score the outputs to yield the rewards $\mathbf{r}$ used for normalization. Therefore, while the Critic is removed to save memory, the Reward Model remains the essential source of the reinforcement signal.
