\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 4: # Orthogonal Butterfly (BOFT) Construction

To understand the construction of Orthogonal Butterfly (BOFT), one must first understand the problem it aims to solve within the context of Orthogonal Finetuning (OFT). In standard model finetuning, we seek to adapt a pretrained weight matrix $\bm{W}^0$ to a downstream task while preserving the semantic knowledge learned during pretraining. OFT achieves this by applying a multiplicative orthogonal matrix $\bm{R}$ to the weights, such that the new weights become $\bm{R}\bm{W}^0$. Because orthogonal matrices preserve the pairwise angles between neurons, the relational information of the model remains intact.

However, a dense orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ requires $\mathcal{O}(d^2)$ parameters, which is inefficient for large models. Previous attempts to improve efficiency used a block-diagonal structure, where the matrix is divided into independent smaller blocks. While this reduces the number of parameters, it introduces a heavy inductive bias: it assumes that dimensions are grouped into isolated blocks that do not interact. BOFT provides a solution by constructing a dense orthogonal matrix through the factorization of multiple sparse matrices, inspired by the efficiency of the Cooley-Tukey algorithm.

# The Cooley-Tukey algorithm and the butterfly graph topology

The foundation of BOFT lies in the butterfly structure, a topology famously used in the Cooley-Tukey algorithm for the Fast Fourier Transform (FFT). The core intuition behind using this structure is its ability to perform efficient information transmission. In the context of matrix multiplication, a dense matrix $\bm{R}$ represents a dense connectivity where every input dimension can influence every output dimension. If we represent $\bm{R}$ as a product of $m$ matrices $\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1$, we can visualize this as a grid-structured graph with $d \times (m+1)$ nodes.

In this information transmission framework, each matrix $\bm{B}_i$ defines the connectivity between level $i$ and level $i+1$. For the resulting product $\bm{R}$ to be dense, the graph must satisfy the "dense connectivity" desideratum: there must be a path from every node in the first level to every node in the last level. A naive way to achieve this is to use a single dense matrix, but this is parameter-heavy. The butterfly graph topology is an elegant solution because it can densely connect $d$ source nodes to $d$ receiver nodes using only $\mathcal{O}(d \log d)$ edges. By leveraging this topology, BOFT can generate a dense orthogonal matrix while keeping the number of trainable parameters significantly lower than the $\mathcal{O}(d^2)$ required by a full dense matrix.

# Mathematical definition of butterfly factors and butterfly matrices

To formalize this, we first define the butterfly factor. Assuming $k \geq 2$ is a power of 2, the butterfly factor $\bm{B}^F(k)$ is defined as a $k \times k$ matrix:

$$\bm{B}^F(k) = \begin{bmatrix} \text{diag}(\bm{d}_1) & \text{diag}(\bm{d}_2) \\ \text{diag}(\bm{d}_3) & \text{diag}(\bm{d}_4) \end{bmatrix} \in \mathbb{R}^{k \times k}$$

where each $\bm{d}_i \in \mathbb{R}^{\frac{k}{2}}$ is a vector. This structure shows that each node in one level connects to exactly two nodes in the next level (or vice versa), creating the "butterfly" shape. 

Next, we define the $d$-dimensional butterfly matrix $\bm{B}(d)$ recursively. For a dimension $d = 2^N$, the matrix is constructed as:

$$\bm{B}(d) = \tilde{\bm{B}}(d,d) \cdot \begin{bmatrix} \bm{B}_1(\frac{d}{2}) & \bm{0} \\ \bm{0} & \bm{B}_2(\frac{d}{2}) \end{bmatrix} = \tilde{\bm{B}}(d,d) \tilde{\bm{B}}(d,\frac{d}{2}) \cdots \tilde{\bm{B}}(d,2)$$

Here, $\bm{B}_1$ and $\bm{B}_2$ are themselves butterfly matrices of dimension $\frac{d}{2}$. The components $\tilde{\bm{B}}(d, k)$ are known as butterfly components. Each $\tilde{\bm{B}}(d, k)$ is a block-diagonal matrix of size $d \times d$ with block size $k$, where each block is a butterfly factor $\bm{B}^F_i(k)$. This recursive structure ensures that the final product of these sparse components results in a dense matrix, satisfying the information transmission requirements of the model.

# Recursive construction of the butterfly component

The power of the butterfly matrix lies in its recursive decomposition. By breaking down a large $d$-dimensional matrix into a product of components $\tilde{\bm{B}}(d, k)$ where $k$ decreases geometrically (from $d$ down to 2), we effectively distribute the connectivity across multiple stages. Each stage $\tilde{\bm{B}}(d, k)$ handles a specific level of information exchange. 

This recursive construction is what allows BOFT to bridge the gap between the high expressivity of a dense orthogonal matrix and the high parameter efficiency of a sparse matrix. In the original OFT, the block-diagonal structure is essentially a "one-step" transformation where the blocks never interact. In BOFT, the butterfly components allow for a multi-step transformation. Because the matrix $\bm{B}(d)$ is a product of these components, a value at any position in the final dense matrix $\bm{R}$ is a result of information flowing through the butterfly graph. This allows the model to approximate a much wider range of linear transforms than the block-diagonal structure could ever achieve.

# Designing orthogonal butterfly components via block-wise permutations

A critical requirement for BOFT is that the final matrix $\bm{R}$ must be orthogonal. To ensure this, every individual butterfly component $\tilde{\bm{B}}(d, k)$ in the product must also be orthogonal. The researchers achieve this by starting with the simplest possible butterfly component: the one with a block size of 2, denoted as $\tilde{\bm{B}}(d, 2)$. 

To ensure $\tilde{\bm{B}}(d, 2)$ is orthogonal, each $2 \times 2$ block is parameterized using the Cayley transform (which is equivalent to a 2-dimensional rotation). Because the non-zero pattern of any other butterfly component $\tilde{\bm{B}}(d, k)$ for $k > 2$ is simply a block-wise permutation of the non-zero pattern of $\tilde{\bm{B}}(d, 2)$, we can ensure the orthogonality of all components by applying the same rotation logic to the corresponding blocks. 

The framework is further generalized into "block butterfly components" $\tilde{\bm{B}}^b(d, k)$. In this version, each entry in the butterfly factor $\bm{d}_i$ is replaced by a $b \times b$ matrix. To maintain orthogonality, each $2b \times 2b$ block matrix is parameterized to be orthogonal. This allows BOFT to maintain a flexible block size $b$ while still benefiting from the butterfly structure's sparse factorization.

# The BOFT($m, b$) parameterization and its complexity analysis

BOFT is formally defined by two hyperparameters: $m$, the number of butterfly components in the product, and $b$, the block size. The forward pass for a linear layer is modified as follows:

$$\bm{z} = (\bm{R}(m,b) \cdot \bm{W}^0)^\top \bm{x}, \quad \text{s.t. } \bm{R}(m,b) = \prod_{i=1}^m \tilde{\bm{B}}^b_{(d,i)}$$

where each $\tilde{\bm{B}}^b_{(d,i)}$ is an orthogonal butterfly component, and $\bm{I}_d$ is the identity matrix. The term $\bm{R}(m,b)$ represents the total orthogonal transformation applied to the weights. 

The parameter efficiency of this construction is significant. For a linear layer of size $d \times n$, BOFT($m, b$) requires $\frac{1}{2}(b-1)dm$ effective trainable parameters. We can compare this to other methods:
1. **Original OFT:** Uses a full dense orthogonal matrix, requiring $\mathcal{O}(d^2)$ parameters.
2. **Block-diagonal OFT:** Uses a block-diagonal structure with block size $b$, requiring $\mathcal{O}(bd)$ parameters.
3. **BOFT:** If we set $b=2$ and $m = \log d$, the number of parameters becomes $\mathcal{O}(d \log d)$.

This demonstrates that BOFT can achieve a dense orthogonal matrix (which provides high expressivity) with a parameter count that is only logarithmic in growth relative to the dimension, making it much more efficient than the original OFT while being more expressive than the block-diagonal version.

# Initialization strategies: Identity initialization and Multiplicative Dropout

To ensure that the finetuning process starts from a stable point, BOFT employs specific initialization and regularization strategies. Since the goal of finetuning is to start with the pretrained model and deviate only as much as necessary, BOFT initializes all butterfly components as identity matrices. In the context of the Cayley transform, this is achieved by initializing the skew-symmetric matrix $\bm{Q}$ as a zero matrix. When $\bm{Q} = \bm{0}$, the resulting orthogonal matrix $\bm{R}$ is the identity matrix $\bm{I}$, ensuring that at the start of training, the model is identical to the pretrained foundation model.

Because BOFT uses a multiplicative update ($\bm{R} \cdot \bm{W}^0$), standard Dropout—which typically zeros out elements of an additive update—is not directly applicable. Instead, the authors propose "Multiplicative Dropout." This method exploits the fact that the butterfly components can be permuted into $2b \times 2b$ block-diagonal matrices. Multiplicative Dropout works by randomly selecting a percentage $p_1$ of the butterfly components and a percentage $p_2$ of the diagonal blocks within those components. The selected blocks are then replaced with identity matrices. This effectively "turns off" certain parts of the orthogonal transformation, providing a regularization mechanism to prevent overfitting while maintaining the structural integrity of the orthogonal parameterization.
