\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: The Information Transmission Framework

# Interpreting Dense Matrices as Connectivity Between Nodes

To understand the core innovations of Orthogonal Butterfly (BOFT), we must first establish a conceptual foundation for how we view weight matrices during the finetuning process. In the context of Orthogonal Finetuning (OFT), we are interested in an orthogonal matrix $\bm{R} \in \mathbb{R}^{d \times d}$ that transforms a pretrained weight matrix $\bm{W}^0$. Instead of viewing this matrix simply as a collection of $d^2$ numbers, the authors propose a shift in perspective: viewing the matrix as a map of information flow.

In this framework, a $d$-dimensional dense square matrix $\bm{R}$ is interpreted as a system of connectivity between $d$ source nodes and $d$ receiver nodes. Each element $R_{ij}$ in the matrix represents the "pathway" between these nodes. If an entry $R_{ij}$ is non-zero, it signifies that information from the $j$-th node is capable of flowing to the $i$-th node. Conversely, if an entry $R_{ij}$ is zero, it indicates a break in the circuit, meaning that no information from node $j$ can reach node $i$.

By adopting this perspective, the goal of constructing a "dense" orthogonal matrix becomes a problem of network design. A dense matrix is one where every source node has a functional pathway to every receiver node. This connectivity is vital because it ensures that the transformation applied to the neurons preserves the necessary relational information and expressiveness required for the model to adapt to new downstream tasks. If the matrix were too sparse or disconnected, certain parts of the model's knowledge would become isolated from others, limiting the model's ability to learn.

# Matrix Factorization as Sequential Information Exchange

The authors extend this connectivity intuition to the problem of matrix factorization. When we represent a dense orthogonal matrix $\bm{R}$ as a product of multiple smaller matrices, such as $\bm{R} = \bm{B}_m \bm{B}_{m-1} \dots \bm{B}_1$, we are essentially describing a multi-step relay system for information. In this view, the transformation is not happening in a single leap; rather, information is passed sequentially through a series of intermediate stages.

Each matrix $\bm{B}_i$ in the product serves as a specific "exchange" step. Information enters the first matrix $\bm{B}_1$, is transformed and passed to the next level, enters $\bm{B}_2$, and continues this process until it finally exits the last matrix $\bm{B}_m$. This is conceptually similar to how a signal might pass through several different routers in a computer network to reach its final destination. Each router (matrix) performs a partial transformation, and the cumulative effect of all these transformations results in the final dense transformation $\bm{R}$.

This interpretation is powerful because it allows us to analyze the complexity of the model based on the "bottlenecks" or "paths" created at each step. By breaking down a large, dense matrix into a product of sparse matrices, we are trading "space" (the number of parameters required to represent the matrix) for "time" (the computational cost of performing multiple sequential multiplications). The goal of the BOFT method is to find the most efficient way to structure these sequential exchanges so that the final output remains dense and expressive while using the fewest possible trainable parameters.

# Grid-Structured Graph Construction from Matrix Products

To formalize the sequential information exchange described above, the authors construct a grid-structured graph. This graph provides a visual and mathematical map of how information travels through the factorization $\bm{R} = \bm{B}_m \bm{B}_{m-1} \dots \bm{B}_1$. The graph is designed with $d \times (m+1)$ nodes, organized into $m+1$ columns (or levels). Each column contains $d$ nodes, representing the state of the information at each stage of the factorization.

In this grid, the matrix $\bm{B}_i$ is interpreted as the connectivity matrix between the $i$-th level and the $(i+1)$-th level. Specifically, the $(j_1, j_2)$ element of the matrix $\bm{B}_i$ determines whether there is a directed edge from the $j_2$-th node in level $i$ to the $j_1$-th node in level $i+1$. If the element is zero, no edge exists. For the final product $\bm{R}$ to be a dense matrix, the graph must satisfy a specific condition: there must be a valid path of directed edges from every single node in the first level (the source) to every single node in the final level (the receiver).

This graphical representation makes it much easier to identify which sparsity patterns will result in a dense matrix. For example, if we consider a product of four matrices, $\bm{R} = \bm{B}_4 \bm{B}_3 \bm{B}_2 \bm{B}_1$, and we find that there is no sequence of edges that allows node 1 in the first level to reach node 3 in the fifth level, then the resulting matrix $\bm{R}$ will have a zero at the $(3,1)$ position. By analyzing the grid, we can systematically design the non-zero patterns of the sparse matrices $\bm{B}_i$ to ensure that every node in the source level is connected to every node in the receiver level.

# Defining Desiderata for Efficient Orthogonal Matrices: Dense Connectivity vs. Minimum Free Edges

Using the information transmission framework, the authors define two primary desiderata (requirements) for designing an efficient orthogonal matrix. The first is **dense connectivity**. As established, for the matrix $\bm{R}$ to be expressive enough to approximate general linear transforms, every node in the first level of the grid must have at least one path to every node in the last level. This ensures that no information is lost or isolated during the transformation.

The second desiderata is **minimum free edges**. Since the goal of BOFT is parameter efficiency, we want to achieve dense connectivity using as few edges as possible. In this context, an "edge" corresponds to a non-zero entry in one of the factorized matrices $\bm{B}_i$. However, the authors make an important distinction regarding "free" edges. Because the matrices $\bm{B}_i$ must be orthogonal, they must be full-rank. This implies that for each matrix $\bm{B}_i$, there must be at least $d$ edges to form a bijection between the nodes of level $i$ and level $i+1$. These $d$ edges are necessary for the mathematical property of orthogonality and are often non-trainable (for instance, they might be fixed as $\pm 1$). 

The "free" edges are the additional trainable parameters beyond these necessary $d$ connections. A naive way to achieve dense connectivity is to use a single dense orthogonal matrix, which requires $\mathcal{O}(d^2)$ edges. The authors show that by using a more clever graph topology, such as the butterfly structure, one can achieve dense connectivity with only $\mathcal{O}(d \log d)$ edges. The objective of BOFT is to find the optimal sparsity pattern that satisfies the dense connectivity requirement while minimizing the number of free edges.

# Analyzing the Limitations of Block-Diagonal Structures within this Framework

Finally, the information transmission framework provides a clear explanation for why the original Orthogonal Finetuning (OFT) method faces limitations in terms of expressiveness. In the original OFT, the orthogonal matrix $\bm{R}$ is parameterized as a block-diagonal matrix: $\bm{R} = \text{diag}(\bm{R}_1, \bm{R}_2, \dots, \bm{R}_r)$. While this is highly parameter-efficient, the framework reveals a significant structural flaw.

When we visualize a block-diagonal matrix as a grid graph, we see that the nodes are partitioned into $r$ separate groups. The transformations $\bm{R}_i$ only allow information to flow between nodes within the same group. There are no edges connecting a node in group $i$ to a node in group $j$ if $i \neq j$. In the language of the information transmission framework, the block-diagonal structure fails the **dense connectivity** requirement. Because there is no path from a node in one group to a node in another, the resulting matrix $\bm{R}$ cannot be dense; it will always have large blocks of zeros.

This explains why block-diagonal OFT has an inherent "inductive bias" that limits its expressiveness—it cannot approximate classic linear transforms that require cross-group interaction. By contrast, the butterfly structure proposed in BOFT is designed specifically to ensure that every node can communicate with every other node across the grid, providing a much smoother interpolation between the identity matrix (perfect regularity) and the full orthogonal group (full expressiveness).
