\title{Stack Exchange of the Paper: "The Era of 1-bit LLMs: All Large Language Models are in 1.58 Bits"}

### Why is the model referred to as '1.58-bit' specifically?
Question:
The paper introduces BitNet b1.58 and states that every parameter takes on ternary values $\{-1, 0, 1\}$. However, I am confused by the nomenclature. In standard computing, we usually talk about 1-bit, 2-bit, or 8-bit representations. Where does the specific number '1.58' come from mathematically? Is it a rounded value for some other bit depth?
Answer:
The nomenclature "1.58-bit" refers to the information-theoretic amount of information (entropy) contained in each weight, rather than a standard integer bit-depth used in traditional binary storage.

In computer science, we are accustomed to integer bit depths because hardware is designed to address memory in powers of two. A 1-bit value can represent $2^1 = 2$ distinct states, and a 2-bit value can represent $2^2 = 4$ distinct states. However, the amount of information required to represent a choice from a set of $k$ possibilities is defined mathematically as $\log_2(k)$. 

In the BitNet b1.58 architecture, the authors constrain every weight to a ternary set of values: $\{-1, 0, 1\}$. Because there are exactly $3$ possible states for each parameter, the number of bits required to represent these states is $\log_2(3)$. When you calculate this value, $\log_2(3) \approx 1.58496$. The authors use "1.58-bit" to provide a precise description of the model's information density; it is not a rounded value for a 2-bit representation, but rather a specific mathematical derivation of the ternary constraint.

This distinction is important for the model's computation paradigm. If the model were a true 2-bit model, it would require 4 states, which would increase the complexity of the $\text{BitLinear}$ operations. By using exactly $3$ states, the model stays in a "ternary" regime where weights can be represented as integers, allowing the matrix multiplications to be replaced by integer additions (as the paper notes, "the matrix multiplication of BitNet only involves integer addition"). The 1.58-bit label effectively signals that the model has slightly more expressive power than a binary 1-bit model (which only has $2$ states) but remains significantly more efficient than standard 2-bit or 4-bit quantized models.
