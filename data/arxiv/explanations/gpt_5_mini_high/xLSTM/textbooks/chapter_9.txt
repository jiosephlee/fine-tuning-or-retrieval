\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 9: Positioning Among Prior Work

# Transformers and quadratic attention vs. linearized variants

Transformers, introduced with parallelizable self-attention as their core mechanism \citep{Vaswani:17}, reshaped sequence modeling and became the dominant architecture for large language models. Their strength comes from the ability to compute interactions between tokens in a way that can be parallelized across positions, which is a major reason they scale so well on modern accelerators and enabled the emergence of the first very large LLMs. At the same time, the pairwise token interactions that self-attention computes imply a cost that grows quadratically with context length; this quadratic dependence on sequence length is the central scalability bottleneck that many later methods attempt to mitigate.

Because of that quadratic scaling, a large body of follow-on work has focused on preserving the modeling power of attention while reducing its computational and memory footprint for long contexts. Some solutions try to approximate or restructure attention to obtain linear (or near-linear) complexity in the context length, while others propose entirely different sequence-processing primitives that are intrinsically linear in the context length. The tension is therefore between (a) the powerful, parallel and expressive token–token interactions of Transformers and (b) the need for linear resource usage for very long contexts or resource-constrained deployments. xLSTM positions itself in this landscape by recovering some of the key LSTM advantages (gating and memory mechanisms) while adopting memory structures and architectural choices that address the practical scaling concerns that motivated the linear/efficient-attention lines of work.

# Linear attention methods: Synthesizer, Linformer, Performer, GLA, Hyena

A first family of responses to the quadratic cost of standard attention consists of approaches that alter the attention computation so that it no longer requires all-pairs interactions. The paper groups several prominent proposals under the “linear attention” heading and briefly summarizes their strategies.

Synthesizer \citep{Tay:20arxiv} abandons explicit token–token similarity in favor of learned synthetic attention weights, thereby removing the requirement for token–token inner products. Linformer \citep{Wang:20arxiv} replaces the full attention matrix by a low-rank factorization that reduces memory and computation. Linear Transformer \citep{Katharopoulos:20} and related methods re-express attention in a way that lets the softmax kernel be linearized; Performer \citep{Choromanski:21} implements such a linearization through positive orthogonal random feature approximations to the softmax kernel. GLA (Gated Linear Attention) \citep{Yang:23arxiv} brings gating mechanisms into linear attention to improve flexibility. Other work replaces attention with long, efficient convolutions; for example, Structured Global Convolution (SGConv) \citep{Li:22} and the Hyena Hierarchy \citep{Poli:23} realize attention-like long-range computations with specially structured convolutions.

All these approaches aim to make the cost scale closer to linearly with the context length, thereby enabling very long-context processing. The trade-offs vary: some are approximations of softmax attention, others adopt structural inductive biases (convolutions, low-rank assumptions), and some add gating to recover flexibility. xLSTM should be read alongside these methods as another approach to linear-time sequence modeling that retains explicit recurrent-style memory but augments it with modern gates and memory structures designed for scalability.

# State Space Models: S4, DSS, GSS, S5, BiGS, H3, Mamba

State Space Models (SSMs) have emerged as a powerful class of sequence models that are intrinsically linear in the context length and which showed inspiring performance on long-context tasks. Representative instances include S4 \citep{Gu:21}, Diagonal State Space (DSS) \citep{Gupta:22}, Gated State Space (GSS) \citep{Mehta:22}, S5 \citep{Smith:22}, Bidirectional Gated SSM (BiGS) \citep{Wang:22}, H3 \citep{Fu:23}, and the recent Mamba \citep{Gu:24arxiv}. These models typically instantiate a linear dynamical system (or variants thereof) whose convolutional kernel or state matrices are engineered or learned so that convolutions over long contexts can be computed efficiently.

SSMs are attractive because they offer linear-time (and often constant-memory per position) algorithms for processing long sequences and can be integrated into residual/block-structured backbones used by contemporary LLMs. Several SSM variants also incorporate gating mechanisms (e.g., GSS, BiGS) to increase modeling flexibility. In the landscape painted by the paper, SSMs are one of the principal alternatives to Transformers and stand as natural competitors to xLSTM when one seeks linear scaling with sequence length.

# RNN families: HGRN/HGRN2, LRUs, RWKV

Recurrent Neural Networks (RNNs) enjoyed dominance before Transformers and have seen a resurgence motivated by the need for efficient, long-context processing and the desire to preserve the recurrent inductive biases (sequential state update, compact internal memory). The paper highlights several recent RNN-derived architectures: Deep Linear Recurrent Units (LRUs) \citep{Orvieto:23, De:24arxiv}, Hierarchically Gated Linear RNNs (HGRN and HGRN2) \citep{Qin:23,Qin:24arxiv}, and the RWKV family \citep{Peng:23arxivshort,Peng:24arxivshort}. RWKV in particular has become a well-known RNN approach for large language modeling, showing that recurrent formulations can be competitive with Transformers when carefully engineered.

These RNN revivals typically emphasize linear complexity in the context length and often bring back or re-imagine gating mechanisms to control information flow. Importantly, they aim to reconcile the classical strengths of RNN-type stateful processing (compact memory, natural sequential updates) with the demands of modern LLM-scale training and inference. xLSTM sits within this cohort: it is an evolution of the LSTM family that borrows modern training and architectural practices while addressing well-known LSTM limitations (revisability of storage, capacity, and parallelizability).

# Covariance/retention-style updates: Fast Weights, Retention, RWKV-5/6

A closely related strand of work augments models with associative, matrix-based memories that implement fast updates of stored key–value pairs. The key mathematical idea is the covariance (outer-product) update:

\[
\mathbf{C}_t = \mathbf{C}_{t-1} + \mathbf{v}_t \mathbf{k}_t^\top,
\]

where a key vector $\mathbf{k}_t$ and value vector $\mathbf{v}_t$ are written into a matrix memory $\mathbf{C}_t$ and later retrieved via a query $\mathbf{q}$. This update rule is a classical idea from associative memory literature and is equivalent to early “Fast Weight Programmers” \citep{Schmidhuber:92ncfastweights,Schlag:21}. The paper points out that, with zero-mean keys (for example after a layer norm), this covariance-rule is optimal in the sense of maximizing separability under certain retrieval objectives \citep{Dayan:91}.

Modern works have adapted this idea for scalable sequence modeling: fast weight updates can be combined with decay (a multiplicative forget/decay applied to $\mathbf{C}_{t-1}$) and scaled by a learning rate (analogous to input gates) \citep{Ba:16}. Retention-like models and recent RWKV variants (RWKV-5 and RWKV-6) adopt similar outer-product update mechanisms. The mLSTM in xLSTM is explicitly built on this covariance-update tradition: it keeps a matrix memory updated by outer products and uses gating (forget gate as decay; input gate as learning rate) and a normalizer state to stabilize retrieval.

A practical detail that appears in the literature and in xLSTM is normalization of retrieved values: because retrieval involves dot products between queries and accumulated key-weight sums, numerical stability and signal-to-noise considerations motivate dividing by a scalar proportional to the accumulated key weight (in xLSTM this is implemented as dividing by $\max\{|\mathbf{n}_t^\top\mathbf{q}_t|, 1\}$). This is one of several engineering choices that make covariance-style memories usable in large-scale models.

# What’s distinct in xLSTM: exponential gating + memory mixing

The contribution that most clearly distinguishes xLSTM from the prior families is the combination of two ideas applied to the LSTM paradigm: (1) exponential gating with explicit normalization and stabilization, and (2) a reworked memory structure that includes either a scalar, mixed memory (sLSTM) or a matrix, covariance-style memory (mLSTM).

Exponential gating. Traditional LSTM gates use a sigmoid nonlinearity to produce values in $(0,1)$, effectively attenuating contributions. xLSTM introduces exponential activation for gates (e.g., $i_t=\exp(\tilde{i}_t)$ and optionally $f_t=\exp(\tilde{f}_t)$), which permits gate outputs in $(0,\infty)$ rather than being bound to $(0,1)$. Because exponentials can grow large, xLSTM adds a stabilizer state $m_t$ and a normalization mechanism that keeps the forward values and gradients numerically well behaved. For the scalar sLSTM the forward updates include a normalizer $n_t$ that accumulates gate-strength-weighted contributions (so the network keeps a running measure of how much effective input has been stored), and the hidden readout is normalized by this normalizer:

\[
\begin{aligned}
c_t &= f_t c_{t-1} + i_t z_t,\\
n_t &= f_t n_{t-1} + i_t,\\
\tilde h_t &= c_t / n_t,\\
h_t &= o_t \tilde h_t .
\end{aligned}
\]

A stabilizer $m_t$ enforces numerically stable exponentials via a log-space max trick and rescales $i_t$ and $f_t$ accordingly (see the paper for the exact formulas). Intuitively, exponential gates plus the normalizer allow the model to revise past storage decisions more flexibly: because gates are not constrained to be attenuators, later inputs can amplify or de-amplify past contributions in a graded multiplicative fashion.

Memory mixing. The sLSTM retains the classical LSTM capability for memory mixing: when multiple scalar memory cells are arranged into a vector, recurrent weight matrices can mix the outputs of those cells, enabling richer state representations and the essential mechanism for state tracking. The paper highlights a new notion of memory mixing introduced for sLSTM: the model may be partitioned into heads, with memory mixing allowed across cells inside a head but not across heads — this provides an additional modularity in how the model distributes and mixes memory.

Matrix memory (mLSTM). To overcome the limited storage capacity of scalar cell-state vectors, xLSTM also introduces the mLSTM variant in which the memory cell is a matrix $\mathbf{C}_t\in\mathbb{R}^{d\times d}$ updated by the covariance rule

\[
\mathbf{C}_t = f_t \mathbf{C}_{t-1} + i_t \mathbf{v}_t \mathbf{k}_t^\top,
\]

and readout uses matrix–vector multiplication $\mathbf{C}_t \mathbf{q}_t$ normalized by the dot product between a normalizer vector $\mathbf{n}_t$ and the query $\mathbf{q}_t$. In mLSTM the forget gate plays the role of a decay (multiplicative forgetting of $\mathbf{C}_{t-1}$), while the input gate controls learning rate of the new outer-product update. Because mLSTM deliberately abandons recurrent hidden–to–hidden mixing (no hidden-hidden recurrent matrices), it becomes parallelizable across time steps: the matrix memory is updated and read using matrix operations that can be organized to avoid serial scan-like dependencies. The cost is that $\mathbf{C}_t$ is a $d\times d$ object and so updates are computationally heavier than scalar LSTM updates; but this trade-off is central to the design choices in xLSTM.

By combining exponential gating and these novel memory forms, xLSTM aims to get the best of several worlds: revisable gating that supports dynamic storage decisions, scalar-cell memory mixing when needed for expressivity (sLSTM), large associative storage via matrix memories when capacity is the bottleneck (mLSTM), and, in the mLSTM case, parallelizability that makes it more amenable to modern large-scale training and inference.

# Expressivity and state tracking theory: RNNs vs. SSMs/Transformers

A recurring theme in the paper is that the architectural differences above are not merely implementation choices but have implications for expressivity — what classes of sequence-processing problems a model can represent and solve. In particular, the paper (and recent literature it cites) highlights that RNNs with recurrent hidden–to–hidden mixing (as in classical LSTMs and in sLSTM) can implement state-tracking behaviors that some alternatives cannot.

State tracking refers to the need to maintain and update internal variables that summarize relevant aspects of the past in order to make correct future predictions. Tasks such as evaluating computer programs, tracking entities across a long narrative, or certain formal languages (e.g., parity) require the model not only to remember content but to maintain structured, revisable state that depends on complex interactions over time. The experiments reported in the paper show that models lacking memory mixing — such as many Transformers or SSMs in their standard formulations — fail to solve some of these state-tracking tasks (for example, certain regular-language or parity-style tasks). This empirical finding aligns with theoretical results indicating that, for some families of sequence problems, RNNs with appropriate recurrent structure are strictly more expressive than architectures that only rely on feedforward token–token interactions or linear state-space dynamics \citep{Merrill:24,Deletang:23}.

xLSTM addresses this divide by offering two complementary solutions in the same family: sLSTM reclaims memory mixing and thus the state-tracking expressivity of LSTMs, while mLSTM provides large associative memories and parallelizability. In practice, xLSTM architectures can mix sLSTM and mLSTM blocks so that both state tracking and high-capacity associative memory are available in a single stacked network. This design choice is motivated by the observation that language modeling and related sequence tasks often require both kinds of behavior: robust, revisable state for algorithmic or tracking problems, and large capacity for encoding rare tokens and long-range associations.

# Residual stacking as the shared architectural backbone

Despite the heterogeneity of sequence-modeling primitives (attention, SSMs, RNNs, covariance memories), a common architectural trend in recent large models is to organize processing into residually stacked blocks, typically with pre-layer-norm normalization \citep{Ba:16b}. The paper situates xLSTM within this modern practice: xLSTM variants (sLSTM and mLSTM) are integrated into residual block backbones that resemble the pre-LayerNorm residual modules used in Transformers and SSM-based models.

Two residual block styles are described in the paper: a post up-projection block (Transformer-like) that first nonlinearly summarizes the past in the original representational space and then projects up into a higher-dimensional space for further processing, and a pre up-projection block (SSM-like) that projects first into a high-dimensional space and then performs non-linear summarization there. The choice matters: for xLSTM, sLSTM blocks are paired with post up-projection (reflecting that the scalar cell and its mixing operate naturally in the original space), while mLSTM blocks are paired with pre up-projection (so that the matrix memory lives in the higher-dimensional embedding space, maximizing capacity).

The motivation for embedding summaries into higher-dimensional spaces is classic: Cover’s theorem suggests that nonlinearly mapping data into a higher-dimensional space makes linear separation of different histories or contexts more likely \citep{Cover:65}. For next-token prediction, better separation of distinct pasts translates into easier linear readout. Residual stacking provides the deep, compositional scaffold in which these per-block memory and processing primitives operate. By integrating the xLSTM memory mechanisms into residually stacked, pre-LayerNorm backbones, xLSTM leverages the same architectural backbone that underlies contemporary LLMs while trading in the core processing primitive of a Transformer block for an LSTM-derived block with exponential gating and augmented memory.

# Concluding perspective

When we place xLSTM in the broader landscape painted by the paper, it is best seen as an attempt to reconcile and combine strengths from several prior lines of work. From the LSTM lineage, it inherits gating and the idea of a compact recurrent state that supports state tracking. From covariance/fast-weight traditions, it borrows associative, matrix-based memories that vastly increase per-layer storage capacity. From the efficiency-driven literature (linear attention, SSMs, and RNN revivals), it adopts design choices that allow linear-time processing and, for the mLSTM variant, parallelizable memory operations. Finally, by embedding these primitives into modern residual, pre-LayerNorm block stacks, xLSTM aligns with the architectural practices that enabled the scaling of Transformers to very large model sizes.

The paper argues — and empirically supports — that this synthesis yields models that recover the algorithmic expressivity advantages of recurrent mixing while delivering the capacity and scalability that characterize contemporary long-context architectures. The design comes with trade-offs (e.g., compute cost for $d\times d$ matrix updates, or limited parallelism for the mixed-memory sLSTM), but the overall position of xLSTM in the literature is to inhabit the point of the design space that sits between Transformers, linear-attention approximations, SSMs, and RNN revivals: combining gating, associative memory updates, and residual stacking to target both expressivity and efficiency.
