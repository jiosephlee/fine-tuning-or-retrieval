\title{A Textbook about the Paper: "xLSTM: Extended Long Short-Term Memory"}

Chapter 5: sLSTM: Scalar Memory with Exponential Gating and New Mixing

# sLSTM forward pass: cell update, normalizer, and normalized output

The sLSTM retains the core LSTM idea of an additive "constant error carousel" update for a scalar memory cell, but augments it with a normalizer state and exponential gating. At each time step $t$ the scalar forward pass of the sLSTM is given by the following set of equations:

$c_t = f_t \, c_{t-1} \;+\; i_t \, z_t$  (cell state)

$n_t = f_t \, n_{t-1} \;+\; i_t$  (normalizer state)

$h_t = o_t \, \tilde{h}_t,\qquad \tilde{h}_t = \dfrac{c_t}{n_t}$  (hidden state and normalized output)

$z_t = \varphi(\tilde{z}_t),\qquad \tilde{z}_t = \mathbf{w}_z^\top \mathbf{x}_t + r_z \, h_{t-1} + b_z$  (cell input)

$i_t = \exp(\tilde{i}_t),\qquad \tilde{i}_t = \mathbf{w}_i^\top \mathbf{x}_t + r_i \, h_{t-1} + b_i$  (input gate)

$f_t = \sigma(\tilde{f}_t)\ \text{OR}\ \exp(\tilde{f}_t),\qquad \tilde{f}_t = \mathbf{w}_f^\top \mathbf{x}_t + r_f \, h_{t-1} + b_f$  (forget gate)

$o_t = \sigma(\tilde{o}_t),\qquad \tilde{o}_t = \mathbf{w}_o^\top \mathbf{x}_t + r_o \, h_{t-1} + b_o$  (output gate)

These equations should be read together: the cell $c_t$ accumulates past content $c_{t-1}$ attenuated (or amplified) by the forget gate $f_t$, plus the new write $i_t z_t$ modulated by the input gate $i_t$. The novel normalizer $n_t$ accumulates the exact same write weights (forget-modulated input gate strengths) but without the content vectors; dividing $c_t$ by $n_t$ produces $\tilde{h}_t$ — a normalized, content-weighted summary of the past. Finally, the output gate $o_t$ modulates this summary to produce the visible hidden state $h_t$.

To see what the sLSTM is computing over the entire history, unroll the recurrences. With $c_0 = n_0 = 0$ (for simplicity),

$c_t \;=\; \sum_{s=1}^{t} \Bigg( \Big(\prod_{u=s+1}^t f_u\Big) \, i_s \, z_s \Bigg), 
\qquad
n_t \;=\; \sum_{s=1}^{t} \Bigg( \Big(\prod_{u=s+1}^t f_u\Big) \, i_s \Bigg).$

Thus $\tilde{h}_t = c_t / n_t$ is a weighted average of past cell inputs $z_s$ with weights $w_s = i_s \prod_{u=s+1}^t f_u$. The normalizer $n_t$ is exactly the denominator of that average: it tracks the total effective write mass. This representation is central to the sLSTM intuition: the network maintains a compressive summary of the past as a normalized mixture of stored inputs, where the mixture weights are built from input gates and the sequence of subsequent forget gates.

Because sLSTM uses exponential activations for the input gate (and optionally for the forget gate), it necessarily includes numerical stabilization to avoid overflow; that mechanism is described below in the stabilization subsection.

# Gate parameterization: input-, hidden-dependence, and biases

Each pre-activation in the sLSTM — the affine quantities $\tilde{z}_t$, $\tilde{i}_t$, $\tilde{f}_t$, and $\tilde{o}_t$ — follows the classic LSTM pattern: a linear projection of the current input plus a recurrent contribution from the previous hidden state and a bias term. In the scalar presentation above you saw terms like $\mathbf{w}_i^\top \mathbf{x}_t + r_i h_{t-1} + b_i$. When sLSTM is generalized to multiple cells, the vectorized versions use matrices in place of the scalar recurrent terms. Concretely, a multi-cell pre-activation takes the form

$\tilde{\mathbf{z}}_t = \mathbf{W}_z \mathbf{x}_t + \mathbf{R}_z \mathbf{h}_{t-1} + \mathbf{b}_z,$

and analogous equations hold for $\tilde{\mathbf{i}}_t$, $\tilde{\mathbf{f}}_t$, and $\tilde{\mathbf{o}}_t$. The matrices $\mathbf{R}_{\cdot}$ are the recurrent mixing matrices that map the previous hidden state back into gate and candidate pre-activations.

There are three levers in this parameterization: (i) input dependence (the $\mathbf{W}_\cdot \mathbf{x}_t$ terms), (ii) hidden dependence (the $\mathbf{R}_\cdot \mathbf{h}_{t-1}$ terms), and (iii) learnable bias terms ($\mathbf{b}_\cdot$). The sLSTM explicitly inherits the original LSTM design choice: any gate can be chosen to depend on input, hidden, both, or neither, and each gate has its own bias. Making a gate hidden-dependent (nonzero $\mathbf{R}_\cdot$) is what enables memory mixing across cells: the previous hidden state carries cross-cell information back into new write and forget decisions. Including a bias is important in practice because it sets the baseline operating point of the exponential or sigmoid nonlinearity (e.g., initializing forget gates to prefer retention or decay).

Because the input gate in sLSTM is exponential, the bias term $\mathbf{b}_i$ influences the baseline magnitude of writes strongly: a modest positive bias in $\tilde{i}_t$ becomes a multiplicative factor via $\exp(\tilde{i}_t)$. Similarly, if the forget gate uses exponential activation then its bias controls multiplicative decay or growth over time; if it uses sigmoid, the bias controls a bounded decay factor. These interactions make gate parameterization choices and initial biases important hyperparameters in training.

# When to use sigmoid vs. exponential for the forget gate

sLSTM deliberately permits two choices for the forget gate nonlinearity: the conventional sigmoid $\sigma(\cdot)$, which maps pre-activations to the interval $(0,1)$, or an exponential $\exp(\cdot)$, which maps to $(0,\infty)$. Each has different qualitative behavior and practical trade-offs.

Using sigmoid for $f_t$ implements the familiar LSTM-style multiplicative decay: forget factors lie between 0 (fully forget) and 1 (fully keep), so the product $\prod f_u$ always shrinks or stays bounded as more steps accumulate. Sigmoid forget gates are numerically stable and require no special handling beyond ordinary training care; they are a conservative choice if you want stable attenuation over time.

Using exponential for $f_t$ gives the forget factor a multiplicative, unbounded positive range. If $f_t=\exp(\tilde f_t)$, then products of forget factors exponentiate sums of pre-activations:

$\prod_{u=s+1}^t f_u \;=\; \exp\!\Big(\sum_{u=s+1}^t \tilde f_u\Big).$

This lets the model both attenuate (if the sum is negative) and amplify (if positive) contributions from past writes, giving much larger dynamic range. That dynamic range is precisely what enables the sLSTM to "revise" storage decisions: with exponential forgets and exponential inputs, a late write can be made to dominate earlier writes by producing much larger multiplicative weights, or earlier contributions can be amplified or suppressed by subsequent forgets. The paper demonstrates that this capability materially improves performance on problems that require revising previous storage choices (e.g., the Nearest Neighbor Search toy task).

The downside of exponential forget gates is numerical: exponentials can overflow or produce extremely large/small values during unrolled accumulation. To address this, sLSTM uses a stabilization trick (below) based on working in log-space with a running maximum. If you prefer a simpler, safer default or your task does not require the revising behavior, choosing sigmoid for $f_t$ avoids the stabilization complexity.

One practical note made in the paper is that the initialization of forget-gate parameters matters: because forget dynamics can grow multiplicatively over many time steps (especially with exponential forgets), biases and initial weights must be chosen carefully to avoid pathological growth or rapid collapse of memory.

# Multiple memory cells and recurrent mixing matrices

sLSTM can be scaled from a single scalar memory to multiple scalar memory cells collected into a vector $\mathbf{c}_t \in \mathbb{R}^d$. The multi-cell sLSTM retains the same structural equations, but all scalar quantities become vectors and elementwise operations are used where appropriate. A compact vectorized form is

$\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} \;+\; \mathbf{i}_t \odot \mathbf{z}_t,$

$\mathbf{n}_t = \mathbf{f}_t \odot \mathbf{n}_{t-1} \;+\; \mathbf{i}_t,$

$\mathbf{h}_t = \mathbf{o}_t \odot (\mathbf{c}_t \oslash \mathbf{n}_t),$

with pre-activations

$\tilde{\mathbf{z}}_t = \mathbf{W}_z \mathbf{x}_t + \mathbf{R}_z \mathbf{h}_{t-1} + \mathbf{b}_z,$

$\tilde{\mathbf{i}}_t = \mathbf{W}_i \mathbf{x}_t + \mathbf{R}_i \mathbf{h}_{t-1} + \mathbf{b}_i,$

$\tilde{\mathbf{f}}_t = \mathbf{W}_f \mathbf{x}_t + \mathbf{R}_f \mathbf{h}_{t-1} + \mathbf{b}_f,$

$\tilde{\mathbf{o}}_t = \mathbf{W}_o \mathbf{x}_t + \mathbf{R}_o \mathbf{h}_{t-1} + \mathbf{b}_o.$

Here $\odot$ denotes elementwise multiplication and $\oslash$ elementwise division. The recurrent matrices $\mathbf{R}_\cdot \in \mathbb{R}^{d\times d}$ are the explicit mixing mechanisms: they let the previous global hidden state influence every cell's gate and candidate pre-activation, thereby enabling cross-cell interaction at write and forget time.

This recurrent mixing is the principal differentiator between sLSTM and models that lack such hidden–hidden connections. Because the gates themselves (via $\tilde{\mathbf{i}}_t$ and $\tilde{\mathbf{f}}_t$) can depend on the entire hidden state, the amount and fate of each cell's stored content can be decided conditionally on a global view of the recent history. In other words, the network can use the hidden state as a routing and coordination signal to direct which cells to write into, which to decay, and how to combine them into output. The presence of exponential gating multiplies the expressivity of these recurrent mixing matrices: a small change in a pre-activation that flows through an exponential can change a cell's contribution multiplicatively by orders of magnitude.

# Multi-head sLSTM: mixing within heads but not across heads

The sLSTM supports a multi-head layout that partitions the set of memory cells into independent groups (heads). Each head contains a subset of the scalar cells and its own set of recurrent mixing matrices. Concretely, if you split the $d$ memory cells into $H$ heads of size $d_h$ each ($d = H d_h$), then the recurrent matrices can be structured so that mixing is only within each head: each head $j$ has its own $\mathbf{R}^{(j)}_z,\mathbf{R}^{(j)}_i,\mathbf{R}^{(j)}_f,\mathbf{R}^{(j)}_o$ that act only on that head's portion of $\mathbf{h}_{t-1}$. Equivalent is to let the global recurrent matrices be block-diagonal, with one diagonal block per head.

The crucial design point is that sLSTM allows memory mixing inside each head but explicitly prevents mixing across heads. This architectural bias has two main consequences. First, it compartmentalizes memory so that different heads can specialize on different kinds of temporal patterns or tasks without interfering. Second, because there is no cross-head mixing, the head-level computations can be more readily parallelized across compute units and less prone to degenerate global interference. The authors emphasize that combining heads with exponential gating "establishes a new way of memory mixing": each head can manage a separate multiplicative scale and temporal behavior, and the exponential gates amplify these per-head dynamics.

Note that multi-head sLSTM is not the same as multi-head self-attention; the heads here are groups of recurrent memory cells with independent recurrent dynamics rather than independent attention projections. Still, the head-wise partitioning plays a similar role in letting different subspaces specialize and in structuring how mixing is permitted.

# Exponential gating as a new lever for memory mixing

One of sLSTM's defining ideas is to replace or augment sigmoid gates with exponential activations (at least for the input gate, and optionally for forget). This single change has profound implications for how memory mixing and revision operate.

From the unrolled formula for $c_t$ and $n_t$ we identified weights $w_s = i_s \prod_{u=s+1}^t f_u$ for the contribution of $z_s$ to the normalized output $\tilde{h}_t$. If $i_s=\exp(\tilde{i}_s)$ and $f_u=\exp(\tilde{f}_u)$, then

$w_s = \exp\!\Big( \tilde{i}_s + \sum_{u=s+1}^t \tilde{f}_u \Big).$

This shows two things at once. First, the write weight is multiplicative in the exponentiated pre-activations, so small additive changes in pre-activation space become multiplicative changes in contribution weight. Second, the sequence of forget pre-activations between write time $s$ and read time $t$ accumulates additively in the exponent; later forget decisions can dramatically amplify or attenuate earlier writes. That algebraic structure gives sLSTM fine-grained control over which past writes matter at any later time.

If instead the forgets use sigmoid, then the product $\prod f_u$ is bounded in $(0,1)$ and $w_s$ is a product of positive numbers in a bounded range. This is still multiplicative — early writes can be downweighted — but the dynamic range is far narrower than with exponentials. In practice, exponential gates allow the model to sharply concentrate attention on a small subset of past writes (by making their exponentiated pre-activations large) or to spread attention more evenly; sigmoid forgets tend to enforce smoother decay.

These properties make exponential gating a lever for richer memory mixing: the same recurrent matrices that decide pre-activations now operate in the exponent, so they can produce multiplicative routing effects. Combined with multi-head partitioning, the model can effect very different multiplicative regimes in different subspaces, enabling flexible, adaptive, and sometimes large-scale revisions to the stored summary.

Because these operations can grow or shrink very rapidly, sLSTM introduces a stabilization trick based on a running max (denoted $m_t$ in the paper) that maintains numerical stability when computing exponentials across a time series. Formally the stabilizer updates are

$m_t = \max\!\big( \log(f_t) + m_{t-1} , \, \log(i_t) \big)$

and the stabilized gates become

$i'_t = \exp(\log(i_t) - m_t) = \exp(\tilde{i}_t - m_t),\qquad
f'_t = \exp(\log(f_t) + m_{t-1} - m_t).$

These transformations perform the same effective weighting but computed in a numerically safe log-space relative to the current maximum scale. The paper proves that replacing $(i_t,f_t)$ by $(i'_t,f'_t)$ leaves the network outputs and gradients unchanged.

# Expressivity and state tracking advantages

Two structural elements give sLSTM superior expressivity for state-tracking problems compared to models without hidden–hidden mixing: (i) recurrent mixing across cells and (ii) multiplicative, exponential gating combined with normalization. Recurrent mixing ($\mathbf{R}_\cdot$ matrices) enables conditional routing: the decision about which cells to write to or forget can depend on the whole hidden state, allowing the network to implement arbitrarily coupled state-update rules. Exponential gating inflates these conditional decisions into multiplicative, often very selective, weightings of stored content. The normalizer ensures those multiplicative write weights are turned into a stable, comparable summary.

This combination is especially important for tasks that require maintaining and updating discrete or symbolic-like state over time (state tracking), such as formal language recognition or parity/counter-like computations. The paper reports that models lacking memory mixing — including many Transformers and State Space Models — fail on certain formal language tasks because they cannot implement the required sequential state-update logic. In contrast, sLSTM (as part of xLSTM) succeeds on those tasks: the recurrent, gated scalar cells implement internal state variables whose updates and interactions can mimic finite-state machines or counters.

Another way to think about expressivity: sLSTM's normalized mixture form means it can represent a context-dependent center-of-mass of past representations. The network can cause this center-of-mass to shift rapidly (via exponential writes) or to be reweighted by future forget gates; with multiple cells and recurrent mixing, those shifts can be coordinated across many sub-dimensions. That expressive repertoire is what enables stateful, sequential reasoning that is difficult for models without recurrent mixing.

# Computational profile and practical GPU kernel notes

sLSTM trades parallelizability for expressivity. Memory mixing via hidden–hidden recurrent connections implies a true sequential dependency across time: computing $\mathbf{h}_t$ requires $\mathbf{h}_{t-1}$, so a straightforward parallel scan over time (as used by many Transformer-like architectures) is not possible. Nevertheless, sLSTM has favorable asymptotics relative to full-attention Transformers: its computation per time step is linear in the model width and independent of sequence length, and its memory usage is constant with respect to sequence length because the model maintains only its compressed cell and normalizer states rather than buffering full per-token keys.

Because sLSTM is sequential, high-performance implementations matter. The authors report having implemented a fast CUDA kernel with register-level memory optimizations that substantially reduces the practical runtime penalty; in their implementation sLSTM is typically less than two times slower than the fully parallelizable mLSTM variant. This difference is relatively modest given the expressivity gains. The implementation also needs to include the stabilizer update ($m_t$) and the log-space arithmetic for exponential gates in order to ensure numerical correctness.

Practical guidance emerging from the paper includes choosing the appropriate forget-gate nonlinearity for the task (sigmoid when you prefer stable decay; exponential when you need revisability and a wide dynamic range), carefully initializing forget-biases, and using the post up-projection residual block when integrating sLSTM into an xLSTM block (the paper uses post up-projection backbones for sLSTM blocks). When using exponential gates, include the stabilization scheme described above; this is essential to avoid overflow/underflow while preserving exact equivalence of outputs and gradients.

In summary, sLSTM is a principled extension of LSTM that keeps the scalar memory cell and recurrent mixing but introduces exponential gating and a normalizer to enable normalized, multiplicatively reweightable summaries of the past. These design choices substantially increase the model's ability to revise and route memory content while still preserving the constant-error carousel that makes LSTMs trainable over long horizons.
