\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### Is the mLSTM normalizer n_t an analogue of an attention partition function?
Question:
In mLSTM the normalizer evolves as $n_t = f_t n_{t-1} + i_t k_t$ and the output uses $(C_t q_t) / \max(|n_t^T q_t|, 1)$. This resembles linear attention, where a denominator approximates the softmax partition.
- Under what assumptions (e.g., keys normalized by layer norm, certain statistics of $k_t$ and $q_t$) does $n_t^T q_t$ approximate the sum of unnormalized attention weights?
- Is there a derivation that makes the connection precise, or is this mainly a heuristic stabilization?
- How critical is the directional alignment between $n_t$ and $q_t$ for good normalization?
Answer:
Short answer: Yes — but only in the sense of linear (dot‑product) attention, not softmax attention. The mLSTM normalizer $n_t$ plays exactly the role of the partition / denominator for a linearized attention where the feature map is the identity ($\phi(k)=k$, $\phi(q)=q$). It is not a mathematically exact softmax partition unless you make additional approximation assumptions (or replace the feature map).

Why this is exact for a linear attention interpretation. Write the scalar gating product that each stored key/value receives as
$$
\alpha_s \;=\; i_s \prod_{u=s+1}^{t} f_u,
$$
which follows from iterating the recurrence $n_t = f_t n_{t-1} + i_t k_t$ (and similarly for $C_t$). Then the matrix memory and normalizer expand to
$$
\mathbf{C}_t=\sum_{s\le t}\alpha_s\,\mathbf{v}_s\mathbf{k}_s^\top,\qquad
\mathbf{n}_t=\sum_{s\le t}\alpha_s\,\mathbf{k}_s.
$$
Acting on the current query $q_t$ gives
$$
\mathbf{C}_t\mathbf{q}_t=\sum_{s\le t}\alpha_s(\mathbf{k}_s^\top\mathbf{q}_t)\,\mathbf{v}_s,\qquad
\mathbf{n}_t^\top\mathbf{q}_t=\sum_{s\le t}\alpha_s(\mathbf{k}_s^\top\mathbf{q}_t).
$$
Therefore the mLSTM readout before gating,
$$
\tilde{\mathbf{h}}_t \;=\; \frac{\mathbf{C}_t\mathbf{q}_t}{\mathbf{n}_t^\top\mathbf{q}_t},
$$
is exactly the weighted average of stored values with weights proportional to $\alpha_s(\mathbf{k}_s^\top\mathbf{q}_t)$. That is precisely the linear (dot‑product) attention readout: scores = $k_s^\top q_t$, per‑item importance = $\alpha_s$, and the denominator $\mathbf{n}_t^\top\mathbf{q}_t$ is the partition that normalizes those (unnormalized) dot‑product scores. So in the linear attention view the correspondence is exact, not merely heuristic.

Why this is not the softmax partition in general. Standard Transformer attention uses softmax weights $\propto\exp(\mathbf{k}_s^\top\mathbf{q}_t)$. To make $\mathbf{n}_t^\top\mathbf{q}_t$ equal (or close) to $\sum_s \exp(\mathbf{k}_s^\top\mathbf{q}_t)$ you would need either (a) a feature map $\phi$ with $\phi(\mathbf{k})^\top\phi(\mathbf{q})\approx\exp(\mathbf{k}^\top\mathbf{q})$ (Performer / random feature approximations try to do exactly this), or (b) a small‑score regime where $\exp(x)\approx 1+x$ and some bookkeeping gives the same form (but that approximation is crude except for very small $x$). mLSTM uses $\phi=\text{id}$ (and gates $\alpha_s>0$), so it matches linearized attention exactly but does not in general equal the softmax partition. The paper therefore rightly describes the resemblance to linear attention.

The paper’s practical design choices that help make the normalizer behave sensibly are worth noting. They apply a LayerNorm before key/value projection (so keys have controlled mean/variance) and they scale keys by $1/\sqrt{d}$ (so dot‑product magnitudes stay $O(1)$). The input/forget gates $i_t, f_t$ are positive (exponential or sigmoid), so the $\alpha_s$ are positive weights. Still, $\mathbf{k}_s^\top\mathbf{q}_t$ can be negative or can cancel across stored items, so the scalar $\mathbf{n}_t^\top\mathbf{q}_t$ can be small or change sign. For that reason the paper uses $\max(|\mathbf{n}_t^\top\mathbf{q}_t|,1)$ (and absolute value) as a stabilization: this is a practical heuristic to avoid division by tiny or sign‑flipping denominators and is not derived from a softmax identity.

How important is alignment between $n_t$ and $q_t$? It is critical for the normalization to be meaningful. If the stored keys that matter for a query are coherently aligned with $q_t$ (so each $\mathbf{k}_s^\top\mathbf{q}_t$ is positive and they point in similar directions), then $\mathbf{n}_t^\top\mathbf{q}_t$ will reflect the total unnormalized mass and the normalization yields a sensible convex (or signed) average of values. If stored keys have mixed signs/projections relative to $q_t$, the denominator can shrink by cancellation and the raw numerator can be misleading; that is exactly why the model needs the LayerNorm/scaling and learns gates $\alpha_s$ that emphasize relevant memory entries. In other words, good directional alignment (or learned gating that suppresses negatively projecting keys) makes the normalizer a faithful partition; lack of alignment makes the clamp/absolute stabilization necessary and introduces bias compared to a softmax normalization.

In summary: mLSTM’s $n_t$ is the partition function for dot‑product linear attention (exactly), and the paper’s denominator implements that exact linear normalization plus a pragmatic stabilization (absolute value and lower bound). It becomes an approximation to softmax attention only under additional assumptions (small scores or an explicit exponential/feature approximation). The directional alignment of stored keys with the query is therefore an important factor for the denominator to reflect useful attention mass.
