\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How does mLSTM relate algebraically to fast weight programmers and linear attention?
Question:
mLSTM updates $C_t = f_t C_{t-1} + i_t v_t k_t^T$ and retrieves via $C_t q_t$ (then normalizes). Could someone expand the recurrence to show the explicit sum
$C_t = \sum_{s=1}^t \big( i_s \prod_{u=s+1}^t f_u \big) v_s k_s^T$,
so that $C_t q_t = \sum_{s \le t} w_{s,t} v_s (k_s^T q_t)$ with weights $w_{s,t} = i_s \prod_{u=s+1}^t f_u$? 
This would make the similarity to linear attention (kernel $\phi(x)=x$) and fast weight programmers more transparent. Also, is the normalizer $n_t$ implementing an approximate partition function analogous to linear-attention denominators?
Answer:
Short answer: yes — unrolling the mLSTM recurrence gives exactly a Fast-Weight / outer-product memory and retrieval that is algebraically the same form as causal linear attention with kernel $\phi(x)=x$, up to two important differences: (i) mLSTM multiplies each written outer product by a positive, input-dependent write weight $w_{s,t}$ (the learned “learning rate” and decay), and (ii) the paper’s normalizer is the same weighted projection of keys (with an absolute-value + lower bound clamp for stability), so it plays the role of the linear-attention denominator but modified for stability and the write-weights.

Derivation (unroll the recurrence). Start from the paper’s mLSTM write/update
$$\mathbf{C}_t = f_t \,\mathbf{C}_{t-1} + i_t\,\mathbf{v}_t\mathbf{k}_t^\top,$$
and assume $\mathbf{C}_0=0$. Expanding inductively gives
$$\mathbf{C}_t=\sum_{s=1}^t \Big(i_s\prod_{u=s+1}^t f_u\Big)\,\mathbf{v}_s\mathbf{k}_s^\top.
$$
Define the shorthand write-weight
$$w_{s,t} \coloneqq i_s\prod_{u=s+1}^t f_u,
$$
(which is positive because the paper enforces $i_s=\exp(\cdot)>0$ and $f_u$ is either $\sigma(\cdot)\in(0,1)$ or $\exp(\cdot)>0$). Then the stored matrix is
$$\mathbf{C}_t=\sum_{s\le t} w_{s,t}\,\mathbf{v}_s\mathbf{k}_s^\top.
$$

Retrieval and normalizer. Multiplying the memory by the query $\mathbf{q}_t$ gives
$$\mathbf{C}_t\mathbf{q}_t=\sum_{s\le t} w_{s,t}\,\mathbf{v}_s\big(\mathbf{k}_s^\top\mathbf{q}_t\big),
$$
exactly the form “sum of values scaled by key–query inner products”, with an extra multiplicative prior $w_{s,t}$. The paper’s normalizer state
$$\mathbf{n}_t=f_t\mathbf{n}_{t-1}+i_t\mathbf{k}_t
$$
unrolls in the same way to
$$\mathbf{n}_t=\sum_{s\le t} w_{s,t}\,\mathbf{k}_s,
$$
so its projection on the query is
$$\mathbf{n}_t^\top\mathbf{q}_t=\sum_{s\le t} w_{s,t}\,(\mathbf{k}_s^\top\mathbf{q}_t).
$$
The mLSTM then forms the (stabilized) normalized readout
$$\tilde{\mathbf{h}}_t=\frac{\mathbf{C}_t\mathbf{q}_t}{\max\{\,|\mathbf{n}_t^\top\mathbf{q}_t|,1\,\}}
=\frac{\sum_{s\le t} w_{s,t}\,(\mathbf{k}_s^\top\mathbf{q}_t)\,\mathbf{v}_s}{\max\{\,|\sum_{s\le t} w_{s,t}\,(\mathbf{k}_s^\top\mathbf{q}_t)|,1\,\}}.
$$

Connection to linear attention and fast weights. Causal linear attention with kernel $\phi$ typically produces
$$\text{out}_t=\frac{\phi(\mathbf{q}_t)^\top\big(\sum_{s\le t}\phi(\mathbf{k}_s)\mathbf{v}_s^\top\big)}{\phi(\mathbf{q}_t)^\top\big(\sum_{s\le t}\phi(\mathbf{k}_s)\big)}.
$$
If $\phi$ is the identity, this becomes
$$\text{out}_t=\frac{\sum_{s\le t}(\mathbf{k}_s^\top\mathbf{q}_t)\,\mathbf{v}_s}{\sum_{s\le t}(\mathbf{k}_s^\top\mathbf{q}_t)},
$$
which matches the mLSTM algebraic retrieval when all write-weights $w_{s,t}=1$ and you ignore the absolute/clamp used in the paper. Thus mLSTM is the same algebraic family as linear attention with $\phi(x)=x$, except that mLSTM (a) multiplies each term by a positive, time-dependent write-weight $w_{s,t}$ (the input gate acts like a per-write learning rate and the forget gates implement decay), and (b) stabilizes the denominator by taking absolute value + $\max(\cdot,1)$. The paper explicitly points out the equivalence to Fast Weight Programmers (outer-product updates) by identifying the covariance outer-product update $\mathbf{C}_t\leftarrow f_t\mathbf{C}_{t-1}+i_t\mathbf{v}_t\mathbf{k}_t^\top$ with that literature.

Interpretation / intuition. Fast-weight programmers keep a fast weight matrix of outer-products that the network writes into and later queries by multiplication; mLSTM is exactly that, but with learned, input-dependent write strength and decay (so it can emphasize or forget particular past writes). Linear attention stores compressed sufficient statistics (sums of outer-products or keyed sums) to produce the same causal, streaming readout; mLSTM stores the same compression but with gated per-write scaling. The normalizer $\mathbf{n}_t^\top\mathbf{q}_t$ is therefore the natural “partition” or total compatibility scalar appearing in linearized attention, but mLSTM uses the weighted sum and an absolute/clamp to avoid small or sign-changing denominators (the paper motivates and implements that stabilization).

Takeaway. Algebraically mLSTM = Fast Weights = causal linear attention with $\phi(x)=x$ up to (useful) generalizations: learnable, input-dependent write/decay weights $w_{s,t}$, and a stabilized/weighted normalizer. If you set $i_s\!=\!1$, $f_u\!=\!1$, and remove the clamp, mLSTM becomes exactly the $\phi(x)=x$ linear-attention readout (modulo transpose conventions).
