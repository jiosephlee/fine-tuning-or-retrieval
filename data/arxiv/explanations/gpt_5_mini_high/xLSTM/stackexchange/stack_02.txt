\title{Stack Exchange of the Paper: "xLSTM: Extended Long Short-Term Memory"}

### How does the stabilizer m_t make the exponential gates numerically safe without changing outputs or gradients?
Question:
The paper defines a stabilizer state $m_t$ and stabilized gates via
- $m_t = \max(\log f_t + m_{t-1}, \log i_t)$
- $i'_t = \exp(\log i_t - m_t)$, $f'_t = \exp(\log f_t + m_{t-1} - m_t)$,
and then claims that replacing $i_t,f_t$ by $i'_t,f'_t$ does not change the network's outputs nor the gradients of the loss w.r.t. parameters.
Could someone provide a step-by-step derivation that shows:
1) why $c_t$ and $n_t$ computed with $(i'_t,f'_t)$ are exactly proportional to those computed with $(i_t,f_t)$ in such a way that $h_t = o_t (c_t/n_t)$ remains identical, and
2) why the backward pass is also invariant, even though $m_t$ depends on parameters through $\max(\cdot,\cdot)$ (which is nondifferentiable at ties)?
Intuitively this looks like a log-sum-exp style rescaling, but I don't see immediately why the gradients are unaffected.
Answer:
Short answer: the stabilizer is exactly the same algebraic trick as “subtracting the max” in a softmax/log-sum-exp implementation. If you write the cell as a weighted sum of past inputs, the stabilizer divides every weight feeding the current output by the same positive scalar $p_t = \exp(m_t)$ (so the normalized combination is unchanged). For gradients the key identity is that the Jacobian of a softmax (the map from log-weights to normalized weights) annihilates the all-ones vector, so any contribution coming from the dependence of $m_t$ on parameters cancels. Ties (nondifferentiability of max) are handled by subgradients; any valid subgradient of the max sums to $1$, so the same cancellation holds (ties are measure zero in practice).

Below is a short step-by-step derivation.

1) Forward invariance (outputs unchanged)

Define
$p_t := \exp(m_t)$. From the paper’s definition
$m_t = \max(\log f_t + m_{t-1}, \log i_t)$
we get (by exponentiating)
$p_t = \max(f_t p_{t-1}, i_t)$.

The stabilized gates are
$i'_t = \exp(\log i_t - m_t) = \frac{i_t}{p_t}$,
$f'_t = \exp(\log f_t + m_{t-1} - m_t) = \frac{f_t p_{t-1}}{p_t}$.

Write the usual expansion of the cell/normalizer as a weighted sum of past contributions (this identity follows by unrolling the recurrence):
$w_{s,t} := i_s \prod_{u=s+1}^{t} f_u$,  for $s \le t$,
so
$c_t = \sum_{s\le t} w_{s,t} z_s$,   $n_t = \sum_{s\le t} w_{s,t}$.

Observe that $p_t = \max_s w_{s,t}$ (this is exactly what the recursive definition gives: $p_t = \max(i_t, f_t p_{t-1})$ and inductively equals the maximal $w_{s,t}$). If we form the same weights using stabilized gates we get
$w'_{s,t} = i'_s \prod_{u=s+1}^{t} f'_u = \frac{w_{s,t}}{p_t}$,
because each $i_s$ and each $f_u$ is divided by $p_{(\cdot)}$ in a telescoping way that results in an overall division by $p_t$ for every term contributing to time $t$. Therefore
$c'_t = \sum_{s\le t} w'_{s,t} z_s = \frac{1}{p_t}\sum_{s\le t} w_{s,t} z_s = \frac{c_t}{p_t}$,
$n'_t = \frac{n_t}{p_t}$.

Thus the ratio used for the hidden output is unchanged:
$\tilde h_t = \frac{c_t}{n_t} = \frac{c'_t}{n'_t}$,
so $h_t = o_t \tilde h_t$ is identical whether you use $(i,f)$ or $(i',f')$.

(Induction proof of $c'_t = \frac{c_t}{p_t}$ is immediate from the one-step recurrence once you note $i'_t = \frac{i_t}{p_t}$ and $f'_t = \frac{f_t p_{t-1}}{p_t}$.)

2) Backward invariance (gradients unchanged)

It is convenient to work with the log-weights
$u_{s,t} := \log w_{s,t} = \log i_s + \sum_{u=s+1}^{t} \log f_u$.
The normalized weights appearing in the output are
$\alpha_{s,t} := \frac{\exp(u_{s,t})}{\sum_{r\le t}\exp(u_{r,t})}$,
so the output at time $t$ is a linear function of the vector $\alpha_{\cdot,t}$. Stabilization replaces $u$ by
$u'_{s,t} := u_{s,t} - m_t$,
but $\alpha$ depends only on differences of the u’s, so $\alpha(u) = \alpha(u')$ algebraically.

To see why gradients are unchanged even though $m_t$ depends on parameters, compute derivatives via the chain rule. Let $J$ denote the Jacobian of the softmax map with respect to its input vector $u'$ (the usual softmax Jacobian). Its $(i,j)$ entry is
$J_{ij} = \alpha_i (\delta_{ij} - \alpha_j)$,
and a crucial property is $J \mathbf{1} = 0$ (each column of $J$ sums to zero), equivalently the softmax is invariant to adding the same scalar to every component.

Now $u' = u - m_t \mathbf{1}$, so $\frac{\partial u'}{\partial u} = I - \mathbf{1} v^T$ where $v := \frac{\partial m_t}{\partial u}$ is the gradient (or a subgradient) of the scalar max w.r.t. the components of $u$. Note that for the max operator $v$ is a vector with nonnegative entries that sum to $1$ (if there is a unique maximizer $v$ is the one-hot vector at that maximizer; at ties $v$ is any probability vector supported on argmax indices). By chain rule,
$\frac{\partial \alpha}{\partial u} = J\frac{\partial u'}{\partial u} = J(I - \mathbf{1} v^T) = J - J(\mathbf{1} v^T)$.
But $J \mathbf{1} = 0$, so $J(\mathbf{1} v^T) = (J \mathbf{1}) v^T = 0$ and therefore
$\frac{\partial \alpha}{\partial u} = J$.
In words: although $u'$ depends on $u$ through $m_t$, the extra term involving $\frac{\partial m_t}{\partial u}$ is annihilated by the softmax Jacobian. Hence the derivative of the normalized weights $\alpha$ with respect to the underlying log-weights $u$ is the same whether you write $\alpha$ in terms of $u$ or in terms of $u' = u - m_t \mathbf{1}$.

Finally $u$ depends linearly on the gate log-values (log $i$ and log $f$), and those log-values depend on the pre-activations $\tilde i,\tilde f$ (for exponential gates $\log i_t = \tilde i_t$, for sigmoid forget gates you can still use $\log f_t$ but the same linear relations from $\log f$ to $\tilde f$ hold via the chain rule). By composing the equal Jacobians we get identical gradients $\frac{dL}{d\tilde i_t}$ and $\frac{dL}{d\tilde f_t}$ in the stabilized and unstabilized computations.

About nondifferentiability of max: the argument above used an arbitrary subgradient $v = \frac{\partial m_t}{\partial u}$. For the max function any subgradient $v$ satisfies $\sum_j v_j = 1$, so $J \mathbf{1} = 0$ still makes $J(\mathbf{1} v^T)=0$. Thus the cancellation works for any valid subgradient. Ties are a measure-zero event in continuous parameter spaces, and using subgradients at ties is standard; the gradient invariance statement therefore holds almost everywhere (and with any selection of a valid subgradient at ties).

Intuition / final remark

This is exactly the same phenomenon that lets us subtract max(logits) before exponentiating in a numerically stable softmax implementation: subtracting a (data-dependent) scalar from every log-weight does not change the normalized probabilities, and because the softmax Jacobian annihilates the all-ones direction, the dependence of that scalar on parameters does not alter gradients. The xLSTM stabilizer keeps the per-time-step maximal path weight $p_t$ under control (so exponentials never overflow), while algebraically only dividing all path-weights by the same factor for each $t$ — hence both forward values and backward gradients are unaffected.
