\title{A Textbook about the Paper: "Parameter-Efficient Orthogonal Finetuning via Factorization"}

Chapter 3: From Dense to Factorized Orthogonals: An Information Transmission View

# Matrix factorization as sequential information exchange

A central operation in Orthogonal Finetuning (OFT) is to replace a pretrained linear layer weight by its left-multiplication with an orthogonal matrix. Instead of learning one large dense orthogonal matrix $\bm{R}\in\mathbb{R}^{d\times d}$ directly, we can parameterize $\bm{R}$ as a product of smaller matrices,
\[
\bm{R} = \bm{B}_m \bm{B}_{m-1} \cdots \bm{B}_1,
\]
and make each factor $\bm{B}_i$ sparse and (optionally) orthogonal. Written this way, the multiplication is naturally interpreted as a sequence of information exchanges: $\bm{B}_1$ mixes the $d$ input coordinates into the next stage, $\bm{B}_2$ further mixes those intermediate coordinates, and so on until $\bm{B}_m$ produces the final coordinates that act on the pretrained weights.

Thinking about factorization in this sequential way highlights a trade-off that underlies the BOFT approach: we trade computation (multiplying several sparse matrices every forward/backward pass) for space (fewer trainable parameters than specifying a dense $\bm{R}$). It also makes clear the key design goal: by composing multiple sparse mixing steps we may obtain a final matrix that is dense (non-zero entries everywhere) while requiring far fewer total non-zero entries across the factors than the naive dense representation would. This is the perspective that leads to an information-transmission view of orthogonal factorization.

# Grid graph construction: nodes, levels, and edges from sparsity patterns

To make the sequential view graphically concrete, represent the factorization $\bm{R}=\bm{B}_m\cdots\bm{B}_1$ as a layered grid. Create $m+1$ vertical levels (also called stages or layers) and place $d$ nodes at each level, producing a $d\times(m+1)$ grid of nodes. Interpret the $j$-th entry at level $\ell$ as the node $(j,\ell)$.

Each factor $\bm{B}_i\in\mathbb{R}^{d\times d}$ induces directed edges from level $i$ to level $i+1$: specifically, the entry $(\bm{B}_i)_{p,q}\neq 0$ corresponds to a directed edge from node $(q,i)$ (source) to node $(p,i+1)$ (receiver). If $(\bm{B}_i)_{p,q}=0$ there is no direct edge between those two nodes in that stage. Unrolling the matrix product corresponds to concatenating these stage-to-stage connections into paths that go from level $1$ (the original coordinates) to level $m+1$ (the final coordinates).

This construction gives a clean dictionary between algebra and combinatorics. Algebraically, each entry of the final matrix $\bm{R}$ is a sum over products of entries from the factors; combinatorially, a nonzero term in that sum corresponds to a path of nonzero edges connecting a source node at level $1$ to a sink node at level $m+1$. Thus the pattern of nonzero entries of $\bm{R}$—the sparsity pattern we care about for expressivity—is exactly the reachability pattern in this layered grid graph.

# Dense connectivity requirement: every source must reach every sink

What does it mean for the composed matrix $\bm{R}$ to be dense from the graph viewpoint? The answer is simple and exact: for every source node $s\in\{1,\dots,d\}$ at the first level and every sink node $t\in\{1,\dots,d\}$ at the last level there must exist at least one directed path from $(s,1)$ to $(t,m+1)$ that traverses the intermediate levels using only edges corresponding to nonzero entries. If any pair $(s,t)$ lacks such a path, the corresponding entry $R_{t,s}$ will be zero and $\bm{R}$ will not be dense.

This reachability criterion gives a concrete target when we design sparsity patterns for the factors: we must ensure dense connectivity in the layered graph. Designing sparse factors that nevertheless allow every source to reach every sink is the combinatorial heart of factorized orthogonal finetuning. The advantage of this lens is that it separates two questions that are conflated if one only looks at matrices: (1) connectivity — whether the chosen sparsity pattern can possibly produce a dense final matrix, and (2) parameter count — how many independent, trainable degrees of freedom are required by that pattern once orthogonality constraints are imposed.

# Minimum free edges under orthogonality and full-rank constraints

Given the graph viewpoint, we can ask: among all layered graphs that achieve dense connectivity, which have the fewest trainable edges? The paper formalizes this as two desiderata: (i) dense connectivity and (ii) minimum free edges. Here “free edges” means the nonzero entries that are truly trainable parameters (as opposed to structural nonzeros that are forced by orthogonality constraints to take special values).

Orthogonality imposes nontrivial constraints on the per-stage matrices. First, each factor $\bm{B}_i$ that is required to be orthogonal must be full-rank; combinatorially this means there must be at least $d$ edges between level $i$ and level $i+1$ so that rows and columns can be matched as a bijection. These $d$ baseline edges are structural: for certain extreme patterns (for example a permutation matrix) the nonzeros can be $\pm 1$ and thus are not free real-valued parameters in the same way as arbitrary nonzeros would be. The paper highlights this by observing that one can find orthogonal matrices with only $d$ nonzero entries (permutation matrices), in which case those entries are restricted to $\pm 1$ and are not freely parameterizable.

Beyond requiring at least $d$ edges per stage, orthogonality also makes many nonzero entries interdependent. In other words, the number of independent (free) parameters associated to a given nonzero pattern is generally strictly less than the count of nonzero entries, because orthogonality couples entries across rows and columns. Therefore, when counting the resources required by a factorization we should focus on the number of free trainable parameters implied by the orthogonality constraint, not simply the raw number of nonzero locations.

A naive single dense factor (one dense orthogonal $\bm{R}$) is expensive: it naively requires on the order of $d^2$ entries. The paper reports that, counting in the paper’s bookkeeping convention, a single dense factor yields $d^2 - d$ trainable edges (for example, with $d=4$ this number is $12$). The central quest is to find layered factorizations that achieve dense final connectivity while dramatically reducing that effective count of trainable parameters.

# Impact of orthogonality on feasible edge sets and dependencies

Orthogonality does more than enforce full rank; it introduces algebraic dependencies among entries that change which sparsity patterns are feasible and how many free parameters they imply. A simple illustration is the $2\times 2$ case: let an orthogonal matrix be
\[
\begin{bmatrix} a & b \\ c & d \end{bmatrix},
\]
with orthonormal columns. If $a=0$, then column normalization forces $c=\pm 1$, and orthogonality between the two columns forces $b\cdot 0 + d\cdot c = d c = 0$, so $d=0$. In other words, a single zero at position $(1,1)$ forces another zero at $(2,2)$. This is the concrete phenomenon the paper alludes to: a missing edge in one position may imply a missing edge elsewhere once orthogonality constraints are enforced. The algebraic structure of the orthogonal group therefore couples entries, and a sparsity pattern that looks permissive at the level of nonzero locations may in fact allow very few independent parameters after orthogonality is enforced.

Conversely, orthogonality can also be used to our advantage. If a sparsity pattern is chosen carefully, the orthogonality constraints can reduce the number of independent parameters per block in a predictable way (for example, a $2\times 2$ orthogonal block has only one degree of freedom — a rotation angle — though it contains four nonzero entries). The key is to pick a factorization pattern where many nonzeros are grouped into small orthogonal blocks whose degrees of freedom are far fewer than their raw number of entries. This is exactly the structural leverage that butterfly factorization exploits: many small orthogonal $2\times 2$ blocks are composed in stages so that the final product can be dense while the number of independent parameters remains small.

# Why block-diagonal OFT cannot yield dense connectivity

The original OFT proposal achieved parameter efficiency by restricting the learned orthogonal transform to be block-diagonal:
\[
\bm{R} = \operatorname{diag}(\bm{R}_1,\bm{R}_2,\dots,\bm{R}_r),\qquad \bm{R}_i\in\mathbb{R}^{b\times b},\quad br=d.
\]
A block-diagonal $\bm{R}$ applies an independent orthogonal transformation to each contiguous group of coordinates and leaves off-block interactions strictly zero. From the layered graph perspective this means that nodes belonging to different blocks are never connected: the block structure partitions the $d$ coordinates into $r$ disjoint groups and there are no edges between groups. Consequently, no product of block-diagonal factors with the same partitioning can create off-block nonzeros, and the final matrix remains block-diagonal.

Therefore, the block-diagonal design cannot yield dense connectivity. It saves parameters by forbidding cross-block mixing, but this very sparsity kills the possibility of a dense final $\bm{R}$. The paper points out this limitation: while block-diagonal OFT reduces parameter count, it fixes a sparsity pattern that may introduce undesirable inductive bias and reduces expressiveness because it cannot approximate many dense linear transforms.

# Design desiderata: dense connectivity with few trainable edges

Putting the preceding observations together produces a compact list of design desiderata for any factorized orthogonal finetuning scheme:

1. Dense connectivity. The layered graph induced by the factors must let every source reach every sink, so that the composed matrix $\bm{R}$ can be dense and thus able to mix information across all coordinates.

2. Few free trainable edges. The factorization should require as few independent trainable parameters as possible, counting degrees of freedom after orthogonality constraints are imposed. This is the parameter-efficiency objective.

3. Orthogonality and full rank per factor. Each factor should be orthogonal (or otherwise constrained to preserve desirable properties such as spectral norm), which entails per-stage full-rank connectivity and couples entries algebraically. The chosen sparsity pattern must be compatible with these constraints.

4. A useful trade-off between expressivity and regularity. The factorization should provide enough flexibility to adapt to downstream tasks (expressivity) but should also impose structure to avoid overfitting and to preserve pretraining knowledge (regularity). The paper argues that certain structured factorizations, notably butterfly patterns, provide a smoother interpolation between the identity (high regularity) and the full orthogonal group (high expressivity) than a crude block-diagonal design.

The butterfly factorization satisfies these desiderata in a particularly attractive way: it constructs dense final matrices via a product of $O(\log d)$ sparse factors, each with $O(d)$ nonzeros, yielding $O(d\log d)$ nonzero locations and, after taking orthogonality reductions into account, $O(d\log d)$ effective trainable parameters. This meets the twin goals of dense connectivity and parameter parsimony.

# A worked miniature example contrasting factorizations and edge counts

To make these ideas concrete, consider the small case $d=4$. We compare three approaches and their rough edge counts as discussed in the paper.

1. Single dense orthogonal matrix (no factorization). A dense $4\times 4$ orthogonal matrix has on the order of $4^2=16$ entries. Counting in the paper’s bookkeeping (which subtracts a baseline of structural entries tied to orthogonality), the number of trainable edges reported is $d^2-d=4^2-4=12$. This is the expensive baseline.

2. An ad hoc sparse factorization (an example from the paper’s illustration). The paper gives an example factorization of $\bm{R}=\bm{B}_5\bm{B}_4\bm{B}_3\bm{B}_2\bm{B}_1$ whose combined nonzero pattern across factors requires $10$ edges in total and yet yields a dense final matrix. This shows that a factorized design can already beat the single dense factor in terms of raw nonzeros: $10<12$ for this toy case.

3. Butterfly factorization (radix-2 style). The radix-2 butterfly topology, inspired by Cooley–Tukey FFT, can achieve dense connectivity for $d=4$ with only $8$ nonzero entries across its stages. Intuitively, a $d$-dimensional butterfly uses $m=\log_2 d$ stages and each stage contains $d$ nonzero locations structured as $2\times 2$ blocks, so the total raw nonzero count is on the order of $d\log d$; for $d=4$, $d\log_2 d = 4\cdot 2 = 8$. Crucially, once we account for the orthogonality of each $2\times 2$ block, the number of independent trainable parameters is even smaller: each orthogonal $2\times 2$ block has only one degree of freedom (a rotation angle), so the effective number of real parameters ends up being proportional to the number of blocks rather than the number of raw nonzero entries. For BOFT with $b=2$ and $m=\log_2 d$, the paper gives the general effective parameter count scaling as $\mathcal{O}(d\log d)$; numerically for $d=4$ this produces very small parameter counts compared to the dense case.

This miniature comparison illustrates the core message: by arranging a small number of structured sparse interactions across multiple stages, one can obtain a final dense transformation while drastically lowering the number of independent trainable parameters. The butterfly topology is a particularly attractive instantiation of this idea because it is a compact, stagewise pattern that is known to realize many classical dense transforms (Fourier, Hadamard, etc.) and, as the paper argues, does so with strong parameter efficiency and a favorable bias toward generalization.

--- 

In summary, the information-transmission view turns the problem of constructing a dense orthogonal finetuning transform into a graph design problem. The layered grid representation exposes the two core requirements—dense reachability between every source and sink, and as few free trainable edges as possible under orthogonality constraints—and makes the efficiency of butterfly-style factorizations transparent: they obtain dense connectivity with only $O(d\log d)$ structure, a dramatic improvement over the naive $O(d^2)$ dense parameterization.
