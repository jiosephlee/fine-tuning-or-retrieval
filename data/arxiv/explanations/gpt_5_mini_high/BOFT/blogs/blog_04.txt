# BOFT, Step by Step: How to Plug It Into LLMs, Vision Transformers, and Diffusion Models

BOFT (Orthogonal Butterfly Finetuning) is a plug-in parameter-efficient finetuning recipe: instead of adding low-rank updates (LoRA) or finetuning full weight matrices, BOFT left-multiplies a frozen pretrained weight matrix $W^0$ by a learnable orthogonal matrix $R$ that is factorized into sparse "butterfly" components. The result preserves geometric structure (pairwise angles, spectral norm) while reducing the number of trainable parameters from $\mathcal{O}(d^2)$ toward $\mathcal{O}(d\log d)$.

Below is a practical, implementation-oriented walkthrough: how to instantiate BOFT in common model layers, how to initialize and enforce orthogonality, how multiplicative Dropout works, how to choose the two key knobs (depth $m$ and block size $b$), and what to expect at training and inference time.

## Quick mechanics (what changes in the forward pass)
For a pretrained linear layer with weight $W^0\in\mathbb{R}^{d\times n}$ (neurons are the $n$ columns), BOFT replaces the forward computation
z = (W^0)^\top x
with
z = (R W^0)^\top x,
where the orthogonal matrix $R\in\mathbb{R}^{d\times d}$ is factorized as a product of $m$ block-butterfly components:
\[
R(m,b) \;=\; \prod_{i=1}^{m} \tilde{B}^b_{(d,i)}.
\]
Each $\tilde{B}^b_{(d,i)}$ is a $d\times d$ sparse orthogonal block-butterfly matrix with block size $b$; the whole composition yields expressive dense transforms while keeping the number of free parameters small.

Important special cases:
- BOFT$(1,b)$ = block-diagonal OFT (the original block-diagonal orthogonal finetuning).
- BOFT$(1,d)$ = full OFT (unconstrained dense orthogonal matrix).
- BOFT$(\log d, 2)$ (roughly) gives the classical butterfly factorization and uses $\mathcal{O}(d\log d)$ parameters.

The effective number of trainable parameters for a linear layer of width $d$ is
\[
\text{params} \;=\; \tfrac{1}{2}(b-1)\,d\,m,
\]
so you can directly tune $(m,b)$ to hit your parameter budget.

## Step 1 — Where to insert BOFT in your model
BOFT is a left-multiplicative transform of pretrained weight matrices, so it can be applied anywhere you have dense linear layers. Typical places:
- Transformer attention projections (query/key/value/output) and MLP (feed-forward) linear layers in LLMs.
- Patch embeddings, attention/MLP layers in Vision Transformers.
- Dense linear layers inside U-Net / conditioning blocks in diffusion models.

Implementation pattern: keep $W^0$ frozen, implement a BOFT module that produces $R$ (product of sparse components), compute $W_{\text{eff}}=R W^0$, and use $W_{\text{eff}}$ in the usual forward. During finetuning only the parameters inside the BOFT components are updated.

## Step 2 — Identity initialization (start with no change)
A key practical requirement is that finetuning should not change the pretrained model at step zero. BOFT enforces that by initializing every butterfly component to identity. Concretely parameterize each orthogonal block with a skew-symmetric matrix $Q$ and use the Cayley transform (below); set the parameter that produces $Q$ to zero at init so that $Q=0$ and therefore $R=\mathbf{I}$ initially. This guarantees the model behaves exactly like the pretrained model at the start of finetuning.

## Step 3 — Enforce orthogonality with the Cayley transform
BOFT keeps each butterfly component orthogonal during training. A convenient, exact parameterization is the Cayley transform:
\[
R = (I + Q)\,(I - Q)^{-1},
\]
where $Q^\top = -Q$ (skew-symmetric). When you parameterize $Q$ implicitly (for example store an unconstrained matrix $S$ and set $Q = S - S^\top$), evaluating the Cayley transform yields an orthogonal $R$ for each block.

Practical notes:
- For the smallest blocks ($2\times 2$), you can equivalently parameterize each block as a 2D rotation; this is compact and numerically trivial.
- For larger blocks, compute the Cayley transform per block. It is numerically stable to solve the linear system $(I - Q)Y = (I + Q)$ for $Y$ rather than explicitly computing a matrix inverse.
- Initializing the underlying $Q$ to zero yields $R=I$, matching the identity initialization above.

## Step 4 — Multiplicative Dropout (regularization)
Because BOFT is multiplicative ($R W^0$) rather than additive, conventional dropout on the update does not apply directly. BOFT uses multiplicative Dropout: at each training step randomly select a fraction $p_1$ of the butterfly components and, inside each chosen component, a fraction $p_2$ of its diagonal blocks, and replace those chosen components/blocks with identity matrices for that forward pass. This temporarily removes some factors from the product, which acts as regularization and reduces over-reliance on particular factors of $R$.

The paper leaves $p_1$ and $p_2$ as tunable hyperparameters; treat them like other regularization strengths and tune per task.

## Step 5 — Choosing depth $m$ and block size $b$ (trade-offs)
The two knobs $(m,b)$ control the expressivity / parameter-efficiency trade-off:

- Depth $m$ is the number of butterfly components (factors). Increasing $m$ generally increases expressive power because information can be mixed across more stages.
- Block size $b$ controls the internal block dimension inside butterfly components. Larger $b$ gives more parameters per factor and can increase expressivity per factor but raises the parameter count linearly.

Useful identities and special points:
- Parameter count per linear layer: $\tfrac{1}{2}(b-1)\,d\,m$.
- BOFT$(1,b)$ = block-diagonal OFT with block size $b$ (minimal depth).
- BOFT$(1,d)$ = full dense OFT (recover full orthogonal, maximal parameters).
- Using the classical butterfly choice $b=2$ and $m \approx \log d$ yields a dense transform with $\mathcal{O}(d\log d)$ parameters.

How to choose in practice: pick $(m,b)$ to meet your parameter budget and desired inductive bias. Small $b$ plus larger $m$ tends to be more parameter-efficient (but slightly higher runtime cost during training). If you want the smoothest inductive bias that can recover many classical transforms, choose $b=2$ and increase $m$; if you prefer a coarse-grained block structure, increase $b$ and keep $m$ small. BOFT subsumes OFT choices, so you can traverse the continuum between block-diagonal and full orthogonal.

## Step 6 — Training tips and runtime considerations
- Training overhead: BOFT introduces a modest runtime overhead during finetuning because the factorized orthogonal transform $R$ must be assembled (products of sparse blocks) and multiplied with $W^0$ at every step. This is a training-time cost only.
- Inference latency: zero additional latency. After finetuning you can multiply the learned $R$ into $W^0$ once (compute $W_{\text{final}} = R W^0$) and discard the BOFT module. The inference model then uses the same single dense matrix as usual, so there is no added inference cost.
- Stability and generalization: BOFT preserves the spectral norm of $W^0$ because left-multiplication by orthogonal $R$ does not change singular values; this helps training stability. Identity initialization keeps the model close to pretrained at the start, reducing destabilizing jumps.
- Hyperparameters beyond $(m,b)$ and multiplicative dropout (optimizer, learning rate, etc.) are task dependent. The BOFT paper uses the same general finetuning practice as other PEFT methods; treat BOFT parameters as the primary things to tune for parameter-efficiency vs expressivity.

## Minimal implementation checklist
1. Identify which pretrained linear layers $W^0$ you want to adapt with BOFT (attention projections, MLPs, etc.).
2. Choose $(m,b)$ to fit your parameter budget and desired inductive bias.
3. Implement a block-butterfly component builder that outputs sparse block matrices $\tilde{B}^b_{(d,i)}$ (the nonzero pattern is a permutation of $2\times 2$ blocks generalized to $b$).
4. For each block, parameterize orthogonality via a skew-symmetric $Q$ (store an unconstrained parameter $S$ and set $Q = S - S^\top$) and compute block orthogonal $R_{\text{block}}$ via Cayley transform (or 2D rotation for $2\times 2$ blocks).
5. Initialize all $S$ to zeros so every block's $Q=0$ and every $\tilde{B}^b_{(d,i)}=I$ (identity initialization).
6. During training, optionally apply multiplicative Dropout: randomly replace some components/blocks with identity on each forward pass.
7. After finetuning, fold $R$ into $W^0$ by computing $W_{\text{final}} = R W^0$ and export the single dense matrix for inference.

## Closing notes
BOFT is a practical way to get many of the benefits of Orthogonal Finetuning (OFT) while dramatically reducing trainable parameters by composing a dense orthogonal transform from a product of sparse orthogonal butterfly components. It generalizes block-diagonal OFT and can interpolate between block structure and full expressivity by tuning $(m,b)$. Expect a small training-time overhead from the factorized multiplication, but no inference cost once you fold the learned $R$ into the pretrained weights.

If you are adapting large LLMs, ViTs, or diffusion U-Nets and want a finetuning method that preserves pretrained geometry, offers a clear parameter budget, and carries a structured inductive bias, BOFT is a practical candidate to add to your PEFT toolbox.
