\title{Blogs about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

# From Edges, Segments, and Landmarks to Photorealism

Controllable text-to-image models let you steer generation with more than a caption: a Canny edge map, a segmentation layout, or a set of facial landmarks can be used to produce images that follow a desired structure. The challenge is finetuning a large pretrained diffusion model so it obeys those control signals without destroying the model’s pretrained generative abilities (photorealism, diversity, and semantic understanding). Orthogonal Finetuning (OFT), and its constrained variant COFT, offer a principled answer: change neuron directions via layer-wise orthogonal transforms so the model learns to respect control inputs while preserving the pretrained internal geometry. This post explains how OFT is applied to three common control tasks — Canny edges (C2I), segmentation maps (S2I), and facial landmarks (L2F) — how the paper measures control accuracy with a new control consistency metric, and why OFT gets stronger, more accurate control with fewer updates.

## The three control tasks, in one paragraph each

- Canny edge → image (C2I). The input is a sparse edge sketch. The generator must “hallucinate” plausible surfaces, textures and object fills that are consistent with these sparse cues. This is a weak, ambiguous control signal that tests semantic completion.

- Segmentation map → image (S2I). The input is a dense per-pixel class layout. Here the task is to produce photorealistic imagery that respects object boundaries, layout and class labels. Success requires accurate spatial structure and realistic rendering within each region.

- Landmarks → face (L2F). The input is a set of facial keypoints. The generator must align face pose, expression and geometry to the landmarks while keeping identity and photorealism intact. This tests fine-grained geometric control.

All three are standard benchmarks in the paper and share the same core problem: how to adapt a pretrained diffusion model so it reliably follows the control signal while keeping its pretrained strengths.

## How the paper measures “how well control is followed”: the control consistency metric

A key contribution of the work is a task-agnostic, practical measure of control fidelity: estimate the control signal from the generated image using off-the-shelf detectors / predictors, then compare that estimate to the original control input. The metric is tailored per task:

- For C2I (edge maps) the pipeline computes the Canny edges from the generated image and compares them to the input edge map with IoU and F1 scores. Higher IoU/F1 means the generated image reproduces the structural strokes.

- For S2I (segmentation maps) the approach runs a segmentation model on the generated image to get predicted class maps and compares those to the input segmentation using mean IoU and mean/overall accuracy. This quantifies layout and class adherence.

- For L2F (landmarks) a facial landmark detector is run on the generated image and the mean $\ell_2$ distance between predicted and input landmark coordinates is computed:
  \[
    \text{mean L2} \;=\; \frac{1}{N}\sum_{i=1}^N \left\| \hat{\ell}_i - \ell_i \right\|_2,
  \]
  where $\ell_i$ are the target landmark points and $\hat{\ell}_i$ are detections from the generated image. Smaller values indicate better geometric alignment.

Important caveat: these control-consistency scores are upper-bounded by the accuracy of the off-the-shelf detector/segmenter used to extract the signal from the synthesized image, so results are interpreted “up to the accuracy of” those models. Still, the metric gives a practical, interpretable view of how faithfully a finetuned diffusion model follows its control input.

## Orthogonal Finetuning (OFT) — the core idea, distilled

At a high level OFT changes neuron directions, not magnitudes, and does so in a way that provably preserves a particular global structure of the pretrained model: hyperspherical energy. A few core pieces:

- Hyperspherical energy (intuitively): for a layer with neurons (weight vectors) $\{\bm{w}_i\}$, normalize each vector $\hat{\bm{w}}_i = \bm{w}_i / \|\bm{w}_i\|$. The hyperspherical energy
  \[
    \text{HE}(\bm{W}) := \sum_{i\neq j} \|\hat{\bm{w}}_i - \hat{\bm{w}}_j\|^{-1}
  \]
  captures the pairwise angular relationships among neurons (how they are arranged on the unit hypersphere). These pairwise angles encode semantic structure learned during pretraining.

- Orthogonal invariance: if you apply the same orthogonal transform $\bm{R}$ to every neuron in a layer, the pairwise angles are preserved. That is, replacing $\bm{W}^0$ with $\bm{W} = \bm{R}\bm{W}^0$ leaves $\text{HE}(\bm{W}) = \text{HE}(\bm{W}^0)$. This is the key invariant OFT exploits.

- OFT forward pass: replace layer weights $\bm{W}^0$ with $\bm{R}\bm{W}^0$ and optimize the orthogonal matrix $\bm{R}$ under $\bm{R}^\top\bm{R}=\bm{I}$. Concretely
  \[
    \bm{z} = (\bm{R}\bm{W}^0)^\top \bm{x}, \qquad \bm{R}^\top \bm{R} = \bm{I},
  \]
  and $\bm{R}$ is initialized to the identity so the finetuning starts exactly from the pretrained model.

Why this helps: orthogonal updates let the model move neuron directions (which are highly semantic) while guaranteeing the layer’s global angular structure is unchanged, preventing degradation of pretrained capabilities.

## COFT, Cayley, block-diagonals and practical parameter economy

Two practical refinements the paper uses:

- Constrained OFT (COFT). To avoid drifting too far from the pretrained model, COFT adds an explicit radius constraint $\|\bm{R} - \bm{I}\| \le \epsilon$. In practice the Cayley parameterization is used: represent
  \[
    \bm{R} = (\bm{I}+\bm{Q})(\bm{I}-\bm{Q})^{-1}, \qquad \bm{Q}^\top = -\bm{Q},
  \]
  with skew-symmetric $\bm{Q}$. Using the Neumann expansion one gets $\bm{R} \approx \bm{I} + 2\bm{Q} + \mathcal{O}(\bm{Q}^2)$, so constraining $\|\bm{Q}\|$ via projected gradient descent implements the COFT radius constraint. COFT tends to be even more stable than OFT during finetuning.

- Block-diagonal parameterization for $\bm{R}$. A full $d\times d$ orthogonal matrix has $\mathcal{O}(d^2)$ parameters. To reduce cost OFT uses a block-diagonal $\bm{R}=\mathrm{diag}(\bm{R}_1,\dots,\bm{R}_r)$, each block being orthogonal in a smaller dimension. This cuts parameter count roughly by a factor of $r$ (or more if blocks are shared). The paper gives a concrete example: for a $128\times128$ weight matrix, with LoRA rank $r'=8$ the LoRA trainable parameters are $2{,}048$, while OFT with block count $r=8$ uses about $960$ parameters — a favorable trade-off.

A short note on re-scaled OFT: the authors also propose learning a diagonal magnitude matrix $\bm{D}$ (so weights become $\bm{R}\bm{W}^0\bm{D}$). Rescaling does not change hyperspherical energy by construction (directions remain comparable), but it adds flexibility with minimal extra parameters.

Finally, unlike ControlNet-style adapters, OFT introduces no runtime overhead: at deployment one can multiply $\bm{R}$ into $\bm{W}^0$ once to obtain $\bm{W}=\bm{R}\bm{W}^0$ and run the model at the original speed.

## Why OFT delivers stronger, faster control (intuition + practical effects)

1. Directions matter more than magnitudes for semantics. The paper draws an analogy to phase information in Fourier transforms: phase (angular information) carries most of the perceptual structure. Empirically, changing neuron directions is a powerful lever for semantic change.

2. Orthogonal transforms preserve the pretrained geometric relationships among neurons. That means OFT can adapt behavior (aligning it to control signals) without destroying the pretrained model’s ability to render photorealistic, semantically coherent images. In contrast, unconstrained finetuning can drift and collapse; additive low-rank updates (LoRA) are effective but operate differently and can still struggle to reach the same stability in some control regimes.

3. Optimization on a smooth manifold. Restricting updates to orthogonal matrices constrains the optimization to a well-behaved manifold, improving convergence and stability in practice.

4. Parameter-efficient yet expressive. Block-diagonal Cayley-parameterized orthogonal matrices strike a balance between expressiveness and parameter budget; COFT can further tighten stability when needed.

Empirical consequences reported in the paper: OFT and COFT converge more quickly and stably on the control tasks than LoRA, T2I-Adapter and ControlNet, often achieving better control-consistency metrics and higher-quality images with fewer training epochs and less data. For example, a reported finding was that LoRA needed 20 epochs to reach a level of landmark error that OFT already achieved by epoch 8. OFT also showed strong data-efficiency in some experiments (converging well with only 5% of ADE20K in a segmentation control test).

## Empirical highlights (what to expect if you try OFT for control)

- Faster, smoother convergence. Training dynamics for OFT/COFT are continuous and predictable; ControlNet-style methods sometimes exhibit “sudden” emergence of controllability after several epochs, while OFT tends to improve steadily.

- Stronger control-consistency scores. Across C2I, S2I and L2F, OFT/COFT gave better control-consistency (IoU/F1 for edges, mean IoU/accuracy for segmentation, lower mean L2 for landmarks) than competing finetuning/adaptation methods in the paper’s experiments.

- Better qualitative output. Generated images matched control signals more faithfully while retaining vivid, photorealistic detail and coherent geometry.

- No runtime penalty. Once trained, the finetuned weights yield the same inference cost as the original model.

## Practical tips

- If you want the safest finetuning (very low drift), use COFT with a modest $\epsilon$ so the transform stays near identity; this makes learning-rate and epoch choices less sensitive.

- For parameter constrained settings, tune the block count $r$ to trade between capacity and memory/compute. Shared blocks further reduce parameter counts.

- For fair comparison to LoRA, the paper applied OFT to the same attention-weight matrices that LoRA targets. That’s a sensible default.

- If you need extra flexibility, consider the re-scaled OFT variant (learnable per-neuron diagonal scale), but the baseline OFT already gives strong gains.

## Limitations and open points

- COFT and OFT use Cayley transforms that involve matrix inversion; scalability and numerical efficiency of that step can be further improved.

- The block-diagonal parameterization introduces a bias (less flexibility) in exchange for parameter efficiency; the best block structure is dataset/model dependent.

- The control-consistency metric depends on off-the-shelf detectors/segmenters; interpretations of absolute scores should account for their accuracy limits.

- Compositionality of multiple OFT finetunings (multiplying orthogonal matrices from different tasks) is an intriguing possibility mentioned in the paper but needs further study.

## Takeaway

If your goal is to adapt a large pretrained diffusion model so it faithfully follows structure-level controls — edges, layouts, or landmarks — Orthogonal Finetuning gives a principled, parameter-efficient, and practically effective route. By restricting updates to layer-wise orthogonal transforms that preserve hyperspherical structure, OFT lets the model learn to obey new control signals with fewer updates, more stable training, and no extra inference cost. The control consistency metric introduced in the work gives you a clear, task-specific way to quantify how faithfully your model follows those external controls.
