\title{A Textbook about the Paper: "Controlling Text-to-Image Diffusion by Orthogonal Finetuning"}

Chapter 9: Applying OFT to Controllable Generation

# Control signals: Canny edges (C2I), segmentation maps (S2I), facial landmarks (L2F)

Controllable image generation means augmenting a text prompt with an extra, structured signal that constrains the geometric, structural, or semantic content of the output. In the experiments described in the paper, three such control signals are used because each captures a different kind of constraint that users often want to impose.

Canny edges (C2I) are sparse binary maps that mark strong local gradients and outline object boundaries. As a control input they primarily constrain the geometry and silhouette of objects without prescribing class labels or textures. The paper uses Canny edges extracted from natural images (COCO) to ask the diffusion model to “hallucinate” plausible interior content and textures consistent with a given outline. One notable finding is that OFT and COFT can produce semantically coherent images from rough or sparse edge maps, whereas some adapter-based baselines have more difficulty turning a simple edge map into a semantically plausible render.

Segmentation maps (S2I) partition an image into labeled regions (for example, “sky”, “building”, “person”), and thus provide a stronger, semantic layout constraint than edges. When conditioning on segmentation maps (ADE20K in the experiments), the generator must respect not only shapes but also which semantic class occupies each region. The paper reports that OFT and COFT are effective at following segmentation layouts and producing high-fidelity images that match the intended class regions, while some competing finetuning strategies (notably LoRA in the reported comparisons) can fail to follow the segmentation faithfully.

Facial landmarks (L2F) are sparse coordinate sets that encode keypoints on a face (eyes, nose, mouth corners, etc.) and thus act as a precise control for pose and expression. In the CelebA-HQ experiments, landmarks are used to force a subject or a face to adopt a particular pose. Because landmarks are compact and highly geometric, this task tests a model’s ability to translate a small structural signal into consistent pixel-level facial geometry. The paper demonstrates that OFT and COFT yield very accurate pose control on this task.

Across all three signal types the evaluation pipeline is the same in spirit: the model is given a control input and text prompt, it produces images, and then an off-the-shelf estimator is run on the generated image to recover the control signal (edges, segmentation, or landmarks). The recovered control signal is compared to the original input; the comparison is the “control consistency” metric described below. This strategy lets us quantify how well the finetuned model obeys the intended control without requiring human raters for every evaluation.

# Datasets and setups: COCO, ADE20K, CelebA-HQ

Each control task uses a dataset chosen to match the control modality and to stress different generalization aspects of the finetuned model. Canny edge to image (C2I) is evaluated on the COCO dataset, which contains diverse everyday scenes and therefore tests the model’s ability to synthesize varied object types and contexts from outline cues. Segmentation map to image (S2I) uses ADE20K, a dataset with dense pixel-level semantic labels across many scene categories; this forces the generator to respect semantic layouts and object interrelations. Landmark to face (L2F) is evaluated on CelebA-HQ, a high-quality face image dataset that emphasizes fine facial details and pose consistency.

In the experiments reported in the paper, all finetuning methods—including OFT, COFT, ControlNet, T2I-Adapter, and LoRA—start from the same pretrained Stable Diffusion v1.5 model and are finetuned on the chosen dataset. For fairness, OFT is applied to the same model components that other parameter-efficient methods use (for Transformer-based parts this typically means attention-related weight matrices). Training was run for 20 epochs for the controllable-generation comparisons in the main paper so that convergence curves and final scores could be compared across methods under comparable training budgets.

A practical detail emphasized by the paper is parameter efficiency: OFT and COFT were configured to use a similar number of trainable parameters as LoRA and substantially fewer parameters than ControlNet. Despite this compactness, OFT and COFT reached strong control performance with fewer epochs and less data in several cases, demonstrating both data efficiency and parameter efficiency on these dataset setups.

# Design contrast: OFT versus ControlNet/T2I-Adapter (no extra inference cost)

The key architectural difference between OFT and adapter-based approaches like ControlNet or T2I-Adapter lies in where and how additional capacity is introduced and whether that capacity must be active at inference time.

OFT modifies the pretrained network by learning a layer-shared orthogonal transform applied multiplicatively to the pretrained weights. Concretely, for a weight matrix $\bm{W}^0$ in a given layer OFT learns an orthogonal matrix $\bm{R}$ and uses the transformed weights
\[
\bm{W}=\bm{R}\bm{W}^0,
\qquad\text{subject to}\qquad
\bm{R}^\top \bm{R} = \bm{I}.
\]
Because $\bm{R}$ is initialized as the identity and remains orthogonal during training, OFT preserves the hyperspherical structure of the neuron directions while allowing controlled angular changes that adapt the model to the new control signal.

At inference time there is no need to keep a separate module computing a transform—one can pre-multiply and store the modified weight matrix $\bm{W}=\bm{R}\bm{W}^0$ and use it exactly as a standard layer. This is why OFT introduces no additional inference overhead: the learned orthogonal transform has been folded into the base weights and the runtime computation graph and FLOPs remain identical to the original pretrained model.

ControlNet and T2I-Adapter take a different route: they add external networks or adapter modules that process the control signal and inject control-conditioned features into the diffusion model during inference. Those adapters must run at inference time, which increases both parameter count and computational cost. The paper emphasizes that OFT achieves comparable or better controllability without adding such runtime modules; this property makes OFT more practical for deployment where inference latency or memory overhead matters.

A related practical point is that OFT’s parameterization is flexible: the orthogonal matrix can be represented in a block-diagonal form and parameterized efficiently (for example via a Cayley transform of a skew-symmetric matrix), which keeps the number of trainable parameters compact while preserving the orthogonality constraint. COFT further constrains the learned $\bm{R}$ to stay close to the identity (via an $\epsilon$-deviation constraint) to trade off adaptation flexibility and preservation of pretrained generative ability.

# Control consistency metrics: IoU/F1 for edges, mIoU/accuracy for segmentation, landmark L2

To quantify how faithfully a generated image follows its control input the paper proposes a control consistency evaluation: recover the control signal from each generated image using an off-the-shelf estimator and compare it to the original control input. Formally, given a dataset of $N$ examples, for each example $i$ let the original control be $c_i$ and the model output be $I_i^{\text{gen}}$. An extractor function $\mathcal{T}$ computes the recovered control $\hat{c}_i=\mathcal{T}(I_i^{\text{gen}})$. A task-specific distance or similarity $\mathcal{D}$ measures agreement, and the aggregate metric is
\[
\text{consistency}=\frac{1}{N}\sum_{i=1}^N \mathcal{D}(c_i,\hat{c}_i).
\]
The paper uses standard, interpretable choices of $\mathcal{D}$ for each control modality.

For Canny edges (binary masks) the paper reports Intersection-over-Union (IoU) and F1 score. If $A$ and $B$ are the sets of edge pixels in the original and recovered maps respectively, then
\[
\text{IoU}(A,B)=\frac{|A\cap B|}{|A\cup B|}.
\]
Precision and recall are
\[
\text{precision}=\frac{|A\cap B|}{|B|},\qquad
\text{recall}=\frac{|A\cap B|}{|A|},
\]
and the F1 score is the harmonic mean
\[
\text{F1} = \frac{2\cdot\text{precision}\cdot\text{recall}}{\text{precision}+\text{recall}}.
\]

For segmentation maps (multi-class pixel labels) the paper reports mean Intersection-over-Union (mIoU) and mean and overall pixel accuracy. If there are $K$ semantic classes and $\text{IoU}_k$ denotes the IoU computed for class $k$, then
\[
\text{mIoU}=\frac{1}{K}\sum_{k=1}^K \text{IoU}_k.
\]
Mean pixel accuracy averages per-class accuracies, and overall accuracy is the fraction of correctly labeled pixels over the whole dataset. Concretely, if $TP_k$ is the number of true positives for class $k$ and $N_k$ is the number of ground-truth pixels of class $k$, one common formulation of mean accuracy is
\[
\text{mean-acc}=\frac{1}{K}\sum_{k=1}^K \frac{TP_k}{N_k},
\]
and overall accuracy is
\[
\text{overall-acc}=\frac{\sum_{k=1}^K TP_k}{\sum_{k=1}^K N_k}.
\]

For facial landmarks the paper reports the mean $\ell_2$ distance between the input landmark coordinates and the coordinates recovered from the generated face. If each face has $J$ landmark points and landmark $j$ in example $i$ is $l_{i,j}$ while the recovered landmark is $\hat{l}_{i,j}$, then the mean landmark error is
\[
\text{mean-L2}=\frac{1}{N}\sum_{i=1}^N\frac{1}{J}\sum_{j=1}^J \|l_{i,j}-\hat{l}_{i,j}\|_2.
\]

A crucial practical caveat the paper emphasizes is that these consistency metrics rely on the accuracy of the extractor $\mathcal{T}$ (edge detector, segmentation network, landmark detector). The reported numbers therefore measure how closely the generated images reproduce a control signal that current automated estimators can detect; they are valid and useful comparative metrics but are upper-bounded by the extractor’s own errors.

# Observed benefits: faster, smoother convergence and stronger control

Across the three control tasks the experiments show consistent advantages for OFT (and its constrained variant COFT) over adapter-based and additive finetuning baselines. The benefits appear in three main dimensions: convergence speed, training stability (smoothness), and final control fidelity.

Convergence speed. OFT reaches strong control performance with fewer epochs. A concrete example from the paper is the landmark-to-face (L2F) task: OFT/COFT attain a level of landmark error by epoch 8 that LoRA needs about 20 epochs to reach. This faster convergence was visible both in quantitative curves and in qualitative images as OFT’s generated faces quickly align their pose to the input landmarks. Relatedly, OFT requires fewer training examples in some settings: the paper reports that OFT can converge well even when trained on only 5% of the ADE20K data used in segmentation experiments, showing substantial data efficiency.

Training stability and smoothness. OFT provides smooth, predictable training dynamics. The paper contrasts this with ControlNet, whose controllability often “suddenly emerges” after several epochs in their experiments (a rapid change in behavior that is harder to monitor and tune). By preserving hyperspherical energy, OFT restricts the effective search space of weight updates to orthogonal transforms and hence stabilizes finetuning. COFT adds the explicit $\epsilon$-deviation constraint to further stabilize updates by keeping the learned orthogonal matrix close to identity; smaller $\epsilon$ makes the finetuned model behave more like the pretrained model, while larger $\epsilon$ gives more flexibility.

Stronger control and higher visual fidelity. On the three modalities OFT and COFT produced images that more faithfully followed the input control signals and looked qualitatively better. For segmentation-to-image (S2I) the paper notes that LoRA often fails to reproduce the input segmentation, whereas OFT and COFT follow the segmentation maps and generate realistic textures and geometry. For C2I, OFT and COFT hallucinate plausible interior content from rough Canny outlines; in contrast, T2I-Adapter and LoRA performed worse in the same conditions. For L2F, OFT produced the most accurate pose control even under challenging poses. Overall, OFT delivered higher-fidelity outputs with more vivid details and more coherent geometric structure while using fewer parameters than ControlNet and no extra inference modules.

Why these benefits arise. The paper offers two complementary intuitions. First, angular information among neurons encodes much of the semantic content learned by the pretrained model; changing neuron directions is therefore an efficient way to adapt semantics for a new control signal. Second, orthogonal transforms preserve pairwise neuron angles (hyperspherical energy) and thus maintain the pretrained model’s global relational structure while enabling targeted changes. Together, these effects let OFT make effective, semantically meaningful updates without destroying the pretrained generative ability—this is the heart of why OFT is both effective and stable for controllable generation.

Practical implications. For practitioners, OFT provides an efficient way to add controllability: it is parameter-efficient (comparable to LoRA), data-efficient, converges quickly, and imposes no extra inference overhead because the learned transforms can be folded into the original weights. COFT is a useful variant when conservative adaptation is desired: the $\epsilon$ hyperparameter provides a direct knob to trade off how much the finetuned model may deviate from the pretrained one.

Taken together, the controllable-generation experiments in the paper show that preserving the angular neuron structure while allowing constrained directional adaptation is a powerful recipe for giving pretrained text-to-image diffusion models the ability to follow external control signals accurately and robustly.
