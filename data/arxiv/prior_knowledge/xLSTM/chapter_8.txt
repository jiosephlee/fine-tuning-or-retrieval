Introduction

Attention mechanisms and the Transformer architecture have become foundational to modern natural language processing and many other sequence modeling tasks. Unlike recurrent or convolutional architectures that process inputs with an inductive bias toward locality or temporal recurrence, attention provides a flexible, data-driven way to compute interactions between all positions in an input sequence. This capacity to model long-range dependencies efficiently (in the sense of expressiveness, not always in compute) is the reason Transformers underpin large language models, machine translation systems, and many state-of-the-art models across modalities.

This chapter explains the core ingredients of attention and the Transformer. We begin with the basic building block: scaled dot-product attention, which uses queries, keys, and values to compute contextualized representations. We then describe the softmax-based attention weights and how to interpret them. Next, we introduce multi-head attention: why multiple heads help and how they are implemented. Handle the problem that attention alone is permutation-invariant and therefore requires positional encodings to incorporate sequence order. After that, we examine the full Transformer block: how attention and feed-forward layers are combined, and why residual connections and layer normalization are important for training and stability. Finally, we analyze the computational and memory costs of self-attention, emphasizing the quadratic complexity in sequence length and implications for scaling. Throughout, we provide intuition, equations, and practical considerations you will need to read and implement research papers in the field.

# Scaled dot-product attention: queries, keys, values

Attention computes a new representation for each position in a sequence by mixing information from other positions, using content-dependent weights. A commonly used formulation is scaled dot-product attention, which relies on the concepts of queries, keys, and values. The idea is analogous to information retrieval: each position issues a "query" that asks which other positions are relevant; every position has a "key" that describes its content for matching purposes and a "value" that carries the information to be aggregated when there is a match.

Formally, suppose we have an input sequence of length $n$, and at some layer we represent each position by a vector. We linearly project these input vectors into three sets of vectors: queries $Q \in \mathbb{R}^{n \times d_k}$, keys $K \in \mathbb{R}^{n \times d_k}$, and values $V \in \mathbb{R}^{n \times d_v}$. Each row of $Q$ is the query for a position, each row of $K$ is the key for a position, and each row of $V$ is the value for a position. These projections are learned linear transformations: $Q = XW^Q$, $K = XW^K$, and $V = XW^V$ with $W^Q, W^K \in \mathbb{R}^{d_\text{model} \times d_k}$ and $W^V \in \mathbb{R}^{d_\text{model} \times d_v}$ when $X \in \mathbb{R}^{n \times d_\text{model}}$ are the input representations.

Scaled dot-product attention uses the dot product between queries and keys to measure similarity and then uses that similarity to weight values. For a single query vector $q \in \mathbb{R}^{d_k}$ and keys $K = [k_1; \dots; k_n]$, the raw compatibility scores are $q k_i^\top$. For numerical stability and to keep magnitudes well-behaved as $d_k$ grows, these scores are scaled by $\sqrt{d_k}$. The full attention output for all queries is computed as:

$${\rm Attention}(Q,K,V) = {\rm softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right) V.$$

Here $\frac{QK^\top}{\sqrt{d_k}} \in \mathbb{R}^{n \times n}$ contains pairwise scaled dot products between every query and every key, and the softmax is applied row-wise so each query's similarity scores turn into a distribution over the keys. Multiplying by $V$ aggregates the values according to those distributions, producing an output of shape $\mathbb{R}^{n \times d_v}$.

Intuitively, scaled dot-product attention allows each position to "attend" to the most relevant positions according to learned similarity. The scaling by $\sqrt{d_k}$ is important: if $d_k$ is large, the unscaled dot products tend to have large variance, which drives the softmax into extremely peaky regions and makes gradients small; division by $\sqrt{d_k}$ controls the variance, leading to better-behaved training dynamics.

# Softmax attention, attention weights and interpretation

The softmax in the attention equation converts raw similarity scores into normalized, nonnegative weights that sum to one for each query. If we denote the unnormalized scores matrix as $S = \frac{QK^\top}{\sqrt{d_k}}$, then the attention weights matrix $A$ has entries

$$A_{ij} = \frac{\exp(S_{ij})}{\sum_{l=1}^n \exp(S_{il})}.$$

Each row $A_{i,:}$ is a probability distribution over positions in the sequence, giving the contribution of each key (and associated value) to the output for query $i$. This probabilistic interpretation is useful: it lets us view attention as a soft, differentiable selection mechanism where the model learns to place high mass on a few relevant positions and low mass elsewhere.

Interpreting attention weights can give insight into model behavior. For example, in language tasks, attention weights may reveal that a subject pronoun attends strongly to its antecedent several tokens earlier, or that a verb attends to its object. However, attention weights are not a definitive explanation of model behavior: they show where the model is drawing information, but downstream linear transformations, residual connections, and subsequent layers change representations further. Attention weights are a helpful diagnostic but should not be overinterpreted as causal explanations without further analysis.

From a computational perspective, the softmax operation is differentiable and supports efficient implementation on GPUs. Its row normalization ensures that the weighted sum of values is a convex combination of the value vectors, which helps maintain numerical stability. There are also variants of softmax attention: additive attention (using a small feed-forward network to compute scores), sparse or hard attention (where distributions are constrained or discretized), and temperature-controlled softmax (where a scalar temperature multiplies the logits before softmax). The standard Transformer uses scaled dot-product attention with softmax because it is simple, fast on dense hardware, and empirically effective.

# Multi-head attention: motivation and implementation

A single attention operation with $d_k$-dimensional queries and keys gives a single similarity measure per query-key pair. But different types of dependencies might be easier to capture in different representation subspaces: syntactic relations might be best represented along some dimensions, semantic coreference along others, and positional cues along yet other dimensions. Multi-head attention addresses this by running several attention "heads" in parallel, each operating on a different learned linear projection of the inputs. Each head attends to the sequence using its own queries, keys, and values, allowing the model to capture multiple types of relationships simultaneously.

Concretely, suppose we want $h$ heads. For head number $j$, we project the input $X$ with learned matrices $W_j^Q \in \mathbb{R}^{d_\text{model} \times d_k}$, $W_j^K \in \mathbb{R}^{d_\text{model} \times d_k}$, and $W_j^V \in \mathbb{R}^{d_\text{model} \times d_v}$. We compute

$$Q_j = X W_j^Q,\quad K_j = X W_j^K,\quad V_j = X W_j^V,$$

and then

$$\text{head}_j = \text{Attention}(Q_j,K_j,V_j) = \text{softmax}\!\left(\frac{Q_j K_j^\top}{\sqrt{d_k}}\right) V_j.$$

Each head outputs an $n \times d_v$ matrix. We then concatenate the outputs of all heads along the feature dimension to get an $n \times (h d_v)$ matrix, and finally project back to $d_\text{model}$ dimensions with a learned matrix $W^O \in \mathbb{R}^{h d_v \times d_\text{model}}$:

$$\text{MultiHead}(Q,K,V) = \text{concat}(\text{head}_1,\dots,\text{head}_h) W^O.$$

A typical choice in the original Transformer is $d_v = d_k = d_\text{model}/h$, so that the concatenated heads match the model dimensionality. The reason for splitting into smaller subspaces is both computational and inductive: each head has lower-dimensional projections to focus on certain relationships, and the concatenation plus output projection allows the model to combine these diverse signals.

Intuitively, multi-head attention provides representational richness: different heads can learn to attend to different classes of dependencies (short-range vs long-range, syntactic vs semantic). Practically, multi-head attention improves performance compared to a single head with the same total dimensionality, because learning specialized subspaces is easier than forcing one head to express all relationships within one representation.

Implementation-wise, multi-head attention is efficient because the projections for all heads can be implemented as single large matrix multiplications followed by reshaping, which GPUs handle well. Instead of running $h$ separate small matmuls, frameworks typically compute $Q = X W^Q_\text{all}$ where $W^Q_\text{all} \in \mathbb{R}^{d_\text{model} \times (h d_k)}$ and then reshape to separate heads. This batching yields high throughput without sacrificing the logical separation of heads.

# Positional encodings and handling sequence order

A pure attention mechanism is permutation-equivariant: if you reorder the input sequence and apply the same attention computation, the outputs reorder in the same way but the model cannot distinguish sequences that are permutations of each other. In many sequence tasks, order matters—word order in language determines meaning. Therefore, Transformers must inject information about absolute or relative position into the inputs so that attention can use it.

There are two main strategies for encoding position: absolute positional encodings added to input embeddings, and relative positional encodings incorporated into the attention computation. The original Transformer paper used sinusoidal positional encodings: a deterministic function of position $p$ and dimension index $i$,

$$\text{PE}(p,2i) = \sin\!\left(\frac{p}{10000^{2i/d_\text{model}}}\right), \quad \text{PE}(p,2i+1) = \cos\!\left(\frac{p}{10000^{2i/d_\text{model}}}\right).$$

These vectors are added to token embeddings at the bottom of the model so that each position gets a unique but smoothly varying offset. The sinusoidal form has the property that relative positions can be represented as linear functions, which may help generalization to sequence lengths not seen during training.

Learned absolute positional embeddings are an alternative: a learned vector for each position up to a fixed maximum length is added to token embeddings. Learned embeddings can be more flexible and tend to perform as well or better in practice when sufficient data is available. However, they do not naturally generalize to longer sequences than the learned maximum.

Relative positional encodings encode the distance or relative order between query and key positions directly into the attention scores. One way to do this is to add a learned bias $b_{i-j}$ or a function of the distance when computing the raw score between a query at position $i$ and a key at position $j$:

$$S_{ij} = \frac{Q_i K_j^\top}{\sqrt{d_k}} + B_{i-j},$$

where $B$ is parameterized for different relative distances (possibly truncated). Relative encodings have empirical benefits in tasks where relative position patterns matter (like language with frequent local dependencies) and for models processing longer sequences. More sophisticated schemes combine content-based and relative terms in a way that keeps efficient implementation.

In summary, positional encodings break permutation symmetry by giving attention a way to prefer or discount tokens based on position. The choice between absolute learned, sinusoidal, and relative encodings depends on the task, data regime, and computational constraints. Relative encodings often give better capture of distance-sensitive patterns, while absolute encodings are simpler and widely used.

# Transformer block structure, residual connections and layer norm

A Transformer model is built by stacking multiple identical blocks (or layers). Each block contains two main sub-layers: a multi-head self-attention mechanism and a position-wise feed-forward network. The standard Transformer "encoder" block (from the original paper) is organized as follows:

1. Multi-head self-attention sub-layer.
2. Add & Layer Normalization.
3. Position-wise feed-forward sub-layer (a small two-layer MLP applied independently at each position).
4. Add & Layer Normalization.

More explicitly, if $x$ is the input to a block, the attention sub-layer computes $y = \text{MultiHead}(x,x,x)$ for self-attention. Then the block applies a residual connection and layer normalization:

$$x' = \text{LayerNorm}(x + y).$$

The feed-forward sub-layer is a two-layer MLP applied to each position independently (same parameters for each position), typically with a ReLU or GELU activation:

$$\text{FFN}(x') = W_2 \, \sigma(W_1 x' + b_1) + b_2.$$

Then another residual and normalization:

$$\text{output} = \text{LayerNorm}(x' + \text{FFN}(x')).$$

Residual connections (the additions) are crucial. They let gradients flow directly through the identity path, mitigating vanishing gradients and making it easier to train very deep stacks of layers. Intuitively, residuals let a layer make small, incremental changes to representations instead of having to produce the entire transformed representation from scratch.

Layer normalization stabilizes training by normalizing activations across the feature dimension for each position, controlling covariate shift and making the optimization landscape smoother. LayerNorm differs from batch normalization in that it normalizes per example and per position, which is important for variable-length sequences and when batch statistics are unsuitable. In practice, the order of LayerNorm and residual connections has variants; the original Transformer uses "post-norm" (LayerNorm after the addition) while a later variation called "pre-norm" applies LayerNorm before the sub-layer. Pre-norm often yields more stable training for very deep Transformers because it keeps the sub-layer input normalized.

The position-wise feed-forward network expands the representational capability of the model beyond the linear mixing that attention provides. Specifically, FFN uses a hidden dimension $d_\text{ff}$ larger than $d_\text{model}$ (e.g., 4$x$ the model size) to implement a local nonlinearity at each position. Because FFN acts independently for each position, it cannot mix information across positions; instead, its role is to transform each position's aggregated context into richer features.

Putting these components together—self-attention for cross-position mixing, FFN for local nonlinear transformation, residuals for training stability, and LayerNorm for normalization—produces a highly trainable block that can be stacked many times. The encoder stacks such blocks; the decoder stack adds masked attention and encoder–decoder attention in a similar residual+LayerNorm pattern.

# Computational and memory cost of self-attention (quadratic complexity)

Self-attention appears powerful because it allows each position to attend to every other position, but this universality has computational and memory costs. The principal bottleneck is the computation and storage of the $n \times n$ attention score matrix $S = QK^\top$ when the sequence length is $n$. Computing $QK^\top$ requires $O(n^2 d_k)$ operations (matrix multiplication cost) and storing the full score matrix requires $O(n^2)$ memory. After computing scores, applying softmax and multiplying by $V$ adds further $O(n^2 d_v)$ work and memory. Thus, both compute time and memory scale quadratically in sequence length $n$ (ignoring constants and factorization by $d_k$ or $d_v$). For long sequences, this quickly becomes prohibitive.

To be concrete, consider $d_k$ and $d_v$ are constant or scale modestly with $d_\text{model}$. Then doubling the sequence length increases compute and memory fourfold. For tasks requiring sequences of length thousands or more, or for models that must be trained or fine-tuned with very long contexts, naive self-attention becomes a practical limitation.

The quadratic cost motivates several strategies:

- Limited attention windows: Restrict attention to a local window of size $w$, so each query attends only to $w$ nearby keys. This reduces complexity to $O(n w d)$ and is effective when most dependencies are local, as in many language tasks.

- Sparse or structured attention: Design sparsity patterns (strided, block-local, dilated) so that the attention matrix has only $O(n \log n)$ or $O(n \sqrt{n})$ nonzeros. These patterns try to capture both local and some long-range interactions while avoiding full $n^2$ computation.

- Low-rank approximations: Use kernel-based methods or randomized approximations to factorize attention so that $QK^\top$ is approximated by products involving smaller intermediate matrices, reducing complexity to near-linear in $n$ under certain assumptions.

- Memory/compressed attention: Compress keys and values into a smaller set (e.g., via pooling, clustering, or learned summarization) so queries attend to fewer representatives.

- Recurrent or sliding mechanisms: Combine attention with recurrent passes or cache previously computed keys/values so that attention is computed against a limited memory rather than the entire sequence each time.

Each approach trades off exact global attention for practical scalability. The best choice depends on the task: some require precise long-range interactions (e.g., algorithmic reasoning) while others can tolerate approximate or sparse attention.

On hardware considerations, GPUs and TPUs favor dense matrix operations, so dense attention can be highly optimized and fast for moderate $n$ (hundreds to a few thousands). But memory limits on accelerators constrain the maximum sequence length for which training is feasible. Techniques such as gradient checkpointing, mixed precision, and sharding across devices mitigate but do not remove the fundamental quadratic scaling.

Understanding this tradeoff matters when reading research: claims about model capabilities must be judged against the context length used during training, and many research efforts focus on modifying attention to allow longer contexts efficiently. As sequence lengths continue to be an important frontier (e.g., long-document understanding, code, or multi-modal streams), attention complexity will remain a central engineering and research challenge.

Conclusion

Attention (queries, keys, values and the softmax weighting) is a compact, differentiable mechanism for content-based information routing. Multi-head attention multiplies the model's capacity by letting multiple subspaces model different interactions. Because attention is permutation-equivariant, positional encodings are needed to give models access to sequence order. Transformer blocks combine attention with per-position feed-forward networks, stabilized by residual connections and layer normalization, yielding a stackable architecture that is straightforward to scale. The power of self-attention comes with a cost: quadratic compute and memory in sequence length. Recognizing these costs and the design choices that address them is essential for implementing, scaling, and understanding Transformer-based models in contemporary research.
