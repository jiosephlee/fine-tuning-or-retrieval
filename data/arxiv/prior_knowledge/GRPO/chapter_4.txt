# Introduction

Transformers and autoregressive language models form the backbone of modern large language models (LLMs). This chapter develops the architecture and training paradigm most commonly used in current research and applications. We begin by dissecting the transformer block — the modular unit stacked to form deep models — and explain how multi-head attention, feed-forward layers, and normalization interact. We then focus on causal or autoregressive attention and how it enables decoding and generation token by token. Positional encodings and context length constraints determine how a transformer represents sequence order and how far dependencies can reach. Tokenization converts raw text into model inputs; different strategies such as Byte-Pair Encoding (BPE) and SentencePiece carry distinct tradeoffs. Next, we examine how models convert final-layer activations into output probability distributions via logits and the softmax, and how these are used during training with per-token next-token prediction objectives. Finally, we provide a conceptual overview of scaling laws and the tradeoffs that arise as models, data, and compute grow.

# Transformer blocks: multi-head attention, feed-forward layers, layer norm

The core building block of modern transformers is a small computation graph that transforms a sequence of token embeddings into a new sequence of contextualized embeddings. When transformers are stacked, each block repeatedly refines contextual information. A standard transformer block (as introduced by Vaswani et al., 2017) contains two main sublayers: a multi-head self-attention sublayer followed by a position-wise feed-forward network (FFN). Each sublayer is typically wrapped by residual connections and normalized with layer normalization.

Self-attention computes for every token in the sequence a weighted sum of value vectors derived from all tokens, where the weights reflect pairwise relevance. Concretely, given an input sequence represented by matrix $X \in \mathbb{R}^{n \times d}$ where $n$ is sequence length and $d$ is model dimension, we compute query, key, and value matrices:
$Q = XW_Q$, $K = XW_K$, $V = XW_V$,
where $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$ map from model space to query/key/value subspaces (often $d_k = d/h$ if $h$ heads are used). The attention weights are computed by scaled dot-product:
$A = \mathrm{softmax}\!\big(\tfrac{QK^\top}{\sqrt{d_k}}\big)$,
and the attention output is $A V$. The scale factor $1/\sqrt{d_k}$ counteracts the growth of dot products with dimension.

Multi-head attention extends this by running $h$ independent attention computations (heads), each with its own $W_Q^{(i)}, W_K^{(i)}, W_V^{(i)}$, producing outputs $O^{(i)}$. These are concatenated and linearly projected with $W_O$ back to dimension $d$:
$\mathrm{MHA}(X) = \mathrm{Concat}(O^{(1)},\dots,O^{(h)})W_O$.
The core intuition is that different heads can specialize to capture different types of relationships — short-range syntactic links, long-range coreference, positional patterns, or features relevant to particular tasks — in parallel while preserving computational efficiency.

After attention, a residual connection adds the input back: $X' = X + \mathrm{MHA}(\mathrm{LayerNorm}(X))$ in a pre-layer-norm formulation (modern implementations commonly place LayerNorm before each sublayer for training stability). The second sublayer is a position-wise feed-forward network, applied independently at each position:
$\mathrm{FFN}(x) = W_2 \, \phi(W_1 x + b_1) + b_2$,
where $\phi$ is a nonlinearity such as GELU, and $W_1 \in \mathbb{R}^{d \times d_{ff}}$, $W_2 \in \mathbb{R}^{d_{ff} \times d}$. The FFN expands dimensionality to $d_{ff}$ (often a multiple of $d$, e.g., $4d$), enabling richer per-token nonlinear transformations. A second residual connection follows: $X'' = X' + \mathrm{FFN}(\mathrm{LayerNorm}(X'))$.

Layer normalization stabilizes training by normalizing activations across the feature dimension for each token:
$\mathrm{LayerNorm}(x) = \gamma \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} + \beta$,
where $\mu$ and $\sigma^2$ are the mean and variance computed across the $d$ features of a single token, and $\gamma$, $\beta$ are learned scale and shift parameters. LayerNorm helps gradients remain well-conditioned across many stacked layers, facilitating optimization of very deep models.

Putting attention, layer norm, residuals, and FFN together yields a block that can model complicated interactions between tokens while maintaining stable gradient flow. The expressivity comes from repeated application: stacking $L$ such blocks yields machines that can model very long-range, hierarchical dependencies.

# Causal (autoregressive) attention and decoding

Autoregressive language models generate text token-by-token by conditioning on previously generated tokens and predicting the next token. To enforce this "causal" behavior in a transformer, the attention mechanism must be masked so that when computing the representation for position $t$, it can only attend to positions $\le t$ (or strictly $< t$ during training for next-token prediction, depending on implementation). The standard way is to add a large negative number (or explicitly mask) to the $QK^\top$ logits for disallowed positions before applying softmax, which sets their attention probability to near zero.

Formally, let $M$ be an $n \times n$ mask matrix where $M_{ij} = 0$ if token $i$ is allowed to attend to token $j$, and $M_{ij} = -\infty$ if disallowed. Then attention becomes
$A = \mathrm{softmax}\!\big(\tfrac{QK^\top}{\sqrt{d_k}} + M\big)$.
For causal attention, $M$ is typically triangular, preventing future tokens from influencing current ones.

Decoding during inference proceeds sequentially: starting from an initial context (possibly a prompt), the model computes a distribution over the next token, samples or selects a token from that distribution, appends it to the context, and repeats. Naively recomputing the entire transformer forward pass after each appended token is wasteful. Efficient autoregressive decoding uses cached key and value tensors from previous steps; since $K$ and $V$ for past tokens do not change, only the query for the new token needs to be computed and combined with the cached $K,V$ to produce the next output. This reduces per-step computation from $O(n)$ layers of $O(n)$ attention to $O(n)$ for the new token's computations and reduces redundant work.

The choice of decoding strategy shapes generated text. Greedy decoding selects the highest-probability token each step; beam search keeps multiple partial hypotheses to explore high-probability sequences but is less common for open-ended generation. Stochastic methods include ancestral sampling (sample directly from the softmax), top-k sampling (restrict the distribution to the top $k$ tokens and renormalize), and nucleus (top-p) sampling (choose the smallest set whose cumulative probability is at least $p$). Temperature scaling modifies logits by $1/T$ before softmax to control randomness; lower $T$ sharpens the distribution, higher $T$ flattens it. These strategies trade off coherence, diversity, and the tendency to produce repetitive loops.

# Positional encodings and context length implications

Self-attention is permutation-invariant: without any positional information, attention cannot distinguish sequences that are permutations of each other. Positional encodings inject order information so the model can reason about relative and absolute positions.

Two common approaches are fixed (sinusoidal) positional encodings and learned positional embeddings. Sinusoidal encodings represent each position $p$ by a vector where dimensions vary sinusoidally with different wavelengths:
$\mathrm{PE}(p,2i) = \sin\!\big(\tfrac{p}{10000^{2i/d}}\big)$, $\mathrm{PE}(p,2i+1) = \cos\!\big(\tfrac{p}{10000^{2i/d}}\big)$.
This design gives each position a unique, smooth representation and supports extrapolation to longer sequences than seen during training. Learned positional embeddings assign a learned vector to each absolute position index up to a maximum context length. While learned embeddings often perform well within the training range, they do not naturally generalize to longer contexts.

Beyond absolute encodings, many modern models use relative positional encodings or rotary position embeddings (RoPE). Relative encodings allow attention scores to depend on the distance between tokens rather than their absolute positions, which can be beneficial for tasks where the relative distance matters more. RoPE rotates query and key vectors by position-dependent angles so that dot products encode relative position information in a way that generalizes to longer contexts.

Context length is a practical limit on how much past text the model can condition on. Attention has quadratic time and memory complexity with sequence length: computing $QK^\top$ requires $O(n^2 d_k)$ operations and $O(n^2)$ memory to store pairwise scores. Consequently, doubling the context length increases compute and memory roughly fourfold in the attention layers. This imposes engineering constraints: longer context enables modeling longer-range dependencies and allows richer prompts, but it increases resource usage and often requires architectural or algorithmic optimizations (sparse attention, longformer-like local/global patterns, chunking, recurrence, or memory tokens) to scale. Another consideration is effective context utilization: even if a model can technically accept a long context, empirical results show the model's ability to use distant context degrades with distance unless specifically trained or architectural modifications encourage long-range representation.

# Tokenization strategies (BPE, SentencePiece) and vocabulary

Before text enters a transformer, it is tokenized into discrete units that the model embeds. Tokenization strikes a balance between character-level representations (which need long sequences) and full-word vocabularies (which suffer from out-of-vocabulary words and large softmax layers). Subword tokenization is the dominant approach because it compactly represents frequent words and splits rare words into subword units.

Byte-Pair Encoding (BPE) is a data-driven subword algorithm. Starting from a corpus broken into characters or bytes, BPE iteratively merges the most frequent adjacent symbol pairs into new tokens, building a vocabulary of subword pieces. Frequent words become single tokens; rarer words become sequences of subwords. BPE produces deterministic tokenizations given the learned merges and handles unseen words by decomposing them into known pieces. One drawback is that BPE is greedy and deterministic, which can lead to long tokens for some morpheme boundaries and can leak frequency biases from the training corpus into tokens.

SentencePiece is a toolkit that implements two popular algorithms: a BPE variant and the unigram language model. The unigram model treats tokenization as probabilistic: it learns a large initial vocabulary and then uses an EM-like algorithm to assign probabilities to candidate tokenizations, pruning low-probability tokens. During tokenization, SentencePiece can produce multiple possible segmentations; by default it uses the highest-probability segmentation. SentencePiece often works on raw bytes (byte-level) to avoid complications with Unicode normalizations and to ensure any string can be tokenized.

Vocabulary selection affects model performance and efficiency. Larger vocabularies reduce average token length for common words, shortening sequences and reducing per-step cost, but they increase the size of the embedding matrix and the output softmax, both proportional to vocabulary size $|V|$. Smaller vocabularies increase sequence lengths and may make learning morphological composition harder. Many LLMs use vocabularies on the order of tens of thousands (e.g., 30k–100k tokens) as a practical compromise. Special tokens (padding, beginning-of-sequence, end-of-sequence, unknown, task markers) are added to support training and generation.

Tokenization choices interact with downstream behavior: different tokenizations change how much context a model needs for the same textual content, influence how the model handles rare or misspelled words, and can affect biases learned from data. Byte-level or character-level models maximize robustness to arbitrary input but generally require larger or deeper models to achieve the same performance on natural language tasks.

# Parameterization of output distributions and softmax

A language model converts the internal representation of the final transformer layer at position $t$, usually a $d$-dimensional vector $h_t$, into a probability distribution over the vocabulary $V$. The standard parameterization uses a linear output layer (a logits vector) followed by a softmax:
$\ell = W_{out} h_t + b$, $P(token=i \mid context) = \mathrm{softmax}(\ell)_i = \frac{\exp(\ell_i)}{\sum_{j\in V} \exp(\ell_j)}$,
where $W_{out} \in \mathbb{R}^{|V| \times d}$ and $b \in \mathbb{R}^{|V|}$.

Two common parameterization choices are untied versus tied embeddings. Untied means $W_{out}$ is independent of the input token embedding matrix $E$. Tied embeddings share parameters so that $W_{out} = E^\top$ (possibly scaled), which reduces parameters and often empirically improves generalization. The tie enforces a symmetric relationship between how tokens are embedded when read versus how logits are produced when predicted.

The softmax is the canonical way to convert logits into a categorical distribution because it yields a valid probability distribution and is differentiable. However, softmax over very large vocabularies can be computationally expensive at both training and inference time, since computing normalization requires summing exponentials over all $|V|$ tokens. Various approximations exist (hierarchical softmax, sampled softmax, class-based softmax) but modern transformers usually compute full softmax using efficient parallel hardware and optimized kernels.

Temperature and logit scaling are simple but powerful manipulations. Applying a temperature parameter $T$ rescales logits as $\ell/T$ before softmax: for $T<1$ the distribution sharpens (more confident predictions), and for $T>1$ it flattens. During training, logits scale relative to the cross-entropy gradient; some training schemes adjust logit scale or apply adaptive normalizations to stabilize learning.

Another dimension is calibration: softmax probabilities do not necessarily reflect true probabilities. Large models can be overconfident or underconfident; calibration techniques (temperature scaling on validation data, label smoothing during training) mitigate miscalibration and improve downstream decision-making when probabilities are used.

# Per-token training objectives (next-token prediction)

Autoregressive language models are trained by predicting the next token given all previous tokens — a per-token supervised learning problem commonly referred to as next-token prediction or causal language modeling. Given a training corpus tokenized into a sequence $x_1, x_2, \dots, x_N$, the model is trained to maximize the likelihood of each token conditioned on its prefix:
$\mathcal{L} = -\sum_{t=1}^N \log P_\theta(x_t \mid x_{<t})$,
where $x_{<t}$ denotes tokens $1$ through $t-1$ and $P_\theta$ is the model parameterized by $\theta$. This is equivalent to minimizing the average cross-entropy between the empirical next-token distribution (one-hot at the observed token) and the model distribution.

Training typically uses teacher forcing: at batch time, the model is given the gold prefix $x_{<t}$ and predicts $x_t$. This makes optimization stable and efficient because the training data provides the correct context at every step; it contrasts with free-running generation at inference where mistakes can compound. Models are often trained on sequences of fixed maximum length using sliding windows or packed examples that combine multiple shorter sequences into one batch sample. Masking ensures that loss is computed only where predictions are intended (e.g., not on padding tokens).

Gradients flow through all layers, and optimizers like Adam or AdamW handle the high-dimensional nonconvex optimization. Regularization techniques include weight decay, dropout (less common in very large models), and gradient clipping. Mixed-precision training and careful learning rate schedules (warmup followed by decay) are important for stable optimization.

Next-token prediction is a self-supervised objective: it does not require human labels and scales naturally with more raw text. Despite its simplicity, it produces models that acquire syntactic, semantic, and factual knowledge and can be fine-tuned or adapted for many downstream tasks.

# Scaling laws and tradeoffs (brief conceptual overview)

Empirical scaling laws describe how model performance (often measured by perplexity or cross-entropy) improves as model parameters, dataset size, and compute increase. Pioneering work observed power-law relationships: for a fixed compute budget, there is an optimal allocation between model size and training steps; for a fixed model size, increasing data yields diminishing returns. A simplified form of these observations is that test loss scales approximately as a negative power of model size and dataset size:
$L(N) \approx a N^{-\alpha} + b$,
where $N$ is parameter count, $a,\alpha,b$ are fitted constants, and similar laws hold with dataset size and compute.

These scaling relationships produce key tradeoffs. Given a compute budget, should you build a larger model and train it less, or a smaller model and train longer? Empirical results suggest that larger models with more parameters tend to generalize better if they are trained on enough data; however, to realize the benefit of extra parameters you must scale data and compute appropriately. Another tradeoff is inference cost: larger models improve quality but increase latency and cost per query. Techniques such as knowledge distillation, quantization, pruning, and sparse models (Mixture-of-Experts) trade off performance for efficiency at inference.

Context length scaling has its own set of tradeoffs. Extending context length improves the ability to handle long documents but increases per-inference compute quadratically in naive attention; it may also require retraining or fine-tuning with longer sequences to make effective use of extended context. Architectures that support linear or subquadratic attention attempt to reduce this cost but often require compromises in the kinds of interactions they can represent.

Finally, scaling laws are empirical guides rather than strict laws. They help set expectations about how improvements behave at scale and inform resource allocation: whether to invest compute in more parameters, in more data, in longer context, or in higher-quality data curation. Practical system design also considers energy, latency, and fairness implications alongside raw performance metrics.

# Conclusion

This chapter covered foundational elements of autoregressive transformer language models: how transformer blocks build contextual representations via multi-head attention and feed-forward networks under the stabilizing influence of layer normalization and residuals; how causal attention enables sequential generation and efficient decoding; how positional encodings and context length determine representational capacity and computational cost; how tokenization transforms raw text into subword units and shapes model behavior; how logits and softmax parameterize output distributions; how next-token prediction provides a scalable self-supervised training objective; and how empirical scaling laws guide tradeoffs among model size, data, and compute. Together these pieces explain the architecture, training, and practical constraints underlying contemporary LLM research and provide the tools necessary to read and understand many papers in the field.
