Introduction

Transformers are the foundational architecture behind most modern large language models (LLMs). In this chapter, we will unpack the essential components of transformer architectures and the practical training and deployment practices that researchers and engineers use when building and aligning LMs. The goal is not only to list parts of a transformer, but to develop intuition about why each piece exists, how they interact, and what trade-offs arise when scaling or adapting models. After reading this chapter you should be able to read research papers about transformer-based LMs with confidence: you will understand self-attention and feed-forward blocks, positional encodings and causal masking, the difference between decoder-only and encoder–decoder setups, the nitty-gritty of initialization and normalization for stable training, considerations around parameter scaling and efficiency, common fine-tuning approaches including adapters and LoRA, how mixed-precision and distributed training are used, and how inference efficiency is improved using caching and other techniques.


# Self-attention, multi-head attention, and feed-forward blocks

Self-attention is the mechanism that allows a model to compute interactions between every pair of tokens in an input sequence. Given an input sequence of token embeddings arranged as a matrix $X \in \mathbb{R}^{n \times d}$ where $n$ is sequence length and $d$ is embedding dimensionality, self-attention computes three linear projections: queries $Q = XW_Q$, keys $K = XW_K$, and values $V = XW_V$, with projection matrices $W_Q, W_K, W_V \in \mathbb{R}^{d \times d_k}$ (or related sizes). The attention scores are computed as scaled dot-products between queries and keys: $A = \mathrm{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)$. The output of the attention block is then $A V$. Intuitively, for each token represented by a row in $Q$, the softmax over dot products with all keys yields a distribution of how much that token should "attend" to every other token; these attention weights then mix the value vectors to produce a context-aware representation.

The scaling factor $\sqrt{d_k}$ prevents the dot products from growing too large in magnitude as $d_k$ increases, which would push softmax into extremely small gradients and make learning harder. The softmax yields weights that sum to one, which creates a convex combination of the value vectors. This process is differentiable end-to-end, enabling the model to learn which tokens provide useful context for others.

Multi-head attention extends the basic self-attention by splitting the projection into $h$ independent "heads." Concretely, we use different projection matrices for each head, producing $Q_i, K_i, V_i$ for $i = 1,\dots,h$, compute attention outputs for each head $O_i = \mathrm{softmax}\!\left(\frac{Q_i K_i^\top}{\sqrt{d_k}}\right) V_i$, and then concatenate the outputs and apply a final linear projection. Multi-head attention lets the model attend to different types of relationships in parallel: one head might focus on local syntactic dependencies, another on long-range coreference, and yet another on entity linking. Having multiple low-dimensional heads often works better than a single head at the full dimension because it encourages diverse representations and improves the model's ability to represent multiple relationships simultaneously.

Feed-forward blocks follow each attention block in the standard transformer encoder/decoder layer. The typical feed-forward network (FFN) is position-wise and applied independently to each sequence position. It usually has two linear layers with a nonlinearity between them: $\mathrm{FFN}(x) = W_2 \phi(W_1 x + b_1) + b_2$, where $\phi$ might be ReLU, GELU, or another activation. The inner dimensionality $d_{ff}$ is often larger than $d$, for example $d_{ff} \approx 4d$. The feed-forward network increases the model's capacity to perform complex, token-wise transformations and to mix feature dimensions that attention alone may not combine.

A transformer layer typically interleaves attention and FFN sublayers with residual connections and normalization. The residuals help gradients flow through deep stacks of layers, while normalization stabilizes distributions during training. Common choices are pre-norm (apply layer normalization before attention and FFN) or post-norm (apply after). Modern practice tends to prefer pre-norm for better training stability in very deep networks.


# Positional encodings and causal masking

Self-attention, as described, is permutation invariant: it treats the input tokens as an unordered set unless we inject information about the tokens' positions. Positional encodings provide that sequence order information. There are two main classes of positional encodings: absolute positional encodings and relative positional encodings.

Absolute positional encodings add a position-dependent vector to each token embedding before any attention layers. Vaswani et al. introduced sinusoidal positional encodings where the positional vector at position $p$ has components computed by sines and cosines of different frequencies, enabling the model to extrapolate to sequences longer than those seen during training. Learned absolute positional embeddings are also common: they allocate a learnable vector for each position up to a maximum length and add it to the token embedding. Absolute encodings are simple and work well when inputs remain within the trained maximum context length, but they can be less flexible when handling variable-length or longer contexts.

Relative positional encodings incorporate the relative distances between tokens into the attention computation itself. Instead of adding position vectors to embeddings, relative encodings modify the attention scores so that they are functions of $i-j$ (the offset between query and key positions) as well as the content. This permits the model to better generalize to different sequence lengths and to pay attention based on relative rather than absolute position, which is often more relevant for language tasks. Variants include learned relative biases, as used in many decoder-only models, and more structured relative encodings that modify key and value projections.

Causal masking is crucial for autoregressive (decoder-only) generation. When generating a token at position $t$, the model must not have access to tokens after $t$. Causal masking enforces this by setting attention weights for positions $j > t$ to negative infinity before the softmax, effectively zeroing them out. This triangle-shaped mask ensures that each output only depends on prior inputs, enabling the model to generate in sequence. In encoder-decoder setups used for sequence-to-sequence tasks, the encoder's self-attention is typically not masked (it can attend to the whole input), while the decoder uses causal masking for its self-attention and additionally attends to encoder outputs through encoder–decoder attention.

The design of positional encoding and masking has practical consequences for generalization, computational cost, and how models are used at inference time. For example, relative encodings that are implemented efficiently can make it easier to use longer contexts via sliding windows or cached keys/values, whereas absolute learned embeddings may require special handling for extrapolation.


# Decoder-only vs. encoder–decoder setups

There are two broad architectural families for transformer-based LMs: decoder-only (autoregressive) models and encoder–decoder (sequence-to-sequence) models.

Decoder-only models stack transformer decoder blocks and are trained to predict the next token given previous tokens. They implement the causal mask described earlier. These models naturally fit language modeling objectives and are the architecture behind many large-scale LLMs used in generative tasks. Because training is just next-token prediction, decoder-only models can be scaled straightforwardly to massive sizes and large corpora. At inference time, they generate tokens autoregressively, which aligns with many tasks such as free-form text completion, dialogue, and code generation.

Encoder–decoder models (also called seq2seq or "transformer" in the original Vaswani sense) have a transformer encoder that processes the full input sequence in parallel, producing context representations, and a transformer decoder that generates outputs while attending to the encoder representations. They are trained on conditional generation objectives, where the decoder predicts target tokens conditioned on the encoder outputs and previous targets. This architecture is especially well-suited to tasks that transform one sequence into another, like machine translation, summarization from a long document, or tasks with varied input and output lengths. Because the encoder processes the input non-autoregressively, encoder–decoder models can model bidirectional context in the encoder, which helps tasks that require full-context understanding of the input.

The choice between encoder–decoder and decoder-only affects how you train, fine-tune, and evaluate models. Encoder–decoder models often yield better performance on conditional generation tasks with clear input/output pairs, especially when the task benefits from bidirectional encoding. Decoder-only models are flexible and simpler to scale for general purpose language modeling and, with prompting techniques, can be adapted to many downstream tasks without task-specific modifications. Additionally, decoder-only models often have simpler inference machinery (one stack only), but they may require creative prompting to exploit bidirectional understanding.

Hybrid approaches also exist, such as prefix-tuning where an encoder-like prefix is prepended to a decoder-only model, or encoder–decoder designs that incorporate specialized blocks. Ultimately, the selection is guided by task requirements, data available, and the intended inference patterns.


# Initialization, normalization, and training stability

Training very deep transformer stacks at large scale requires careful attention to initialization and normalization to ensure stable gradients and good optimization behavior. Two interrelated concepts are crucial: how we normalize activations and where we place normalization relative to residual connections (pre-norm vs. post-norm), and how we initialize weight matrices and scale activations within the network.

Layer normalization is the de facto choice for transformers. It normalizes across feature dimensions for each token independently, stabilizing the scale and distribution of activations seen by subsequent layers. In post-norm transformers (the original formulation), layer normalization is applied after the addition of the residual connection. While this works for moderately deep models, very deep or very large models often exhibit training instabilities and slow convergence under post-norm. Pre-norm transformers apply layer normalization before the attention or feed-forward block, and then add the residual. Pre-norm tends to improve gradient flow, allowing much deeper stacks to be trained more reliably and with larger learning rates.

Initialization affects the initial scale of activations. Standard techniques use scaled random initializations like Xavier/Glorot or Kaiming/He initialization adapted for the activation function. A recurring practical trick in large transformer training is to scale the initial weights of certain components—particularly the output projections of attention or the second linear layer in the FFN—by a small factor (e.g., dividing by \sqrt{N} or another function of depth). This so-called "residual scaling" prevents the residual updates from overwhelming the initial signal and can improve early training dynamics.

Another component introduced for stability is gated residual or skip scaling, where the residual is multiplied by a learned scalar initialized to a small value. This lets the model start close to the identity function and gradually learn to modify representations. Similarly, initialization schemes that make attention and FFN blocks initially close to zero output (so the model behaves nearly like an identity mapping at the start) promote stability. Optimizer choices also matter: adaptive optimizers like Adam or AdamW with carefully tuned betas and epsilon have become standard, but their hyperparameters interact with weight decay and learning rate schedules, so practitioners often tune these together.

Gradient clipping, learning rate warmup, and carefully designed learning rate schedules (e.g., linear or cosine decays after warmup) are additional levers to stabilize training. Mixed use of L2 weight decay on certain parameters and exempting biases and layer-norm parameters is common. All these elements combine into best practices that keep activations well-behaved and gradients informative across thousands of layers and billions of parameters.


# Parameter scaling and efficiency considerations

Scaling model parameters—whether increasing depth (number of layers), width (hidden dimension), or attention heads—tends to improve performance, but it also increases computational and memory costs. Understanding trade-offs and efficiency techniques is crucial when designing models or selecting pre-trained checkpoints.

There are several scaling regimes: scaling depth generally improves model capacity to represent hierarchical features, while scaling width increases the representational power per layer. Empirically, many large language model families follow power-law improvements with parameter count, but returns diminish and cost grows quickly. When scaling, the attention component is a hotspot: naive attention has quadratic computational and memory complexity in sequence length $n$ because computing $QK^\top$ requires $O(n^2 d_k)$ operations and storing the $n \times n$ attention matrix. This makes long-context modeling expensive.

To mitigate costs, practitioners use parameter-efficient model modifications. Sparse attention variants, such as local attention, block-sparse, or more structured sparsity patterns, reduce computation by attending only to a subset of positions. Low-rank approximations and kernel-based linear attention methods attempt to rewrite attention so that complexity becomes $O(n d)$ rather than $O(n^2)$, though these often involve accuracy trade-offs. Mixed precision (discussed later) and optimized kernels also reduce time and memory footprint. Another important strategy is model parallelism, where parameters are sharded across devices: tensor parallelism splits matrix multiplications across GPUs, while pipeline parallelism splits layers across devices to enable training very deep models.

Parameter sharing is another consideration. Some architectures reuse parameters across layers to reduce the total number of unique parameters (e.g., Universal Transformer ideas). This reduces memory for storing parameters but may impact expressivity and convergence. Pruning and quantization after training can further reduce inference-time costs; pruning removes less-important weights, while quantization reduces precision of weights and activations to save memory and accelerate compute on specialized hardware.

Finally, choices like head dimension, number of heads, and width of the FFN are design knobs. A common practical heuristic is to keep the inner FFN dimensionality about 4 times the model dimension and to choose the number of attention heads so that each head has a reasonable dimension (e.g., $d_k \approx 64$). These heuristics balance expressivity against computational cost and can be tuned based on hardware constraints and task requirements.
