Introduction

Transformers and their attention mechanism have become central to modern sequence modeling because attention directly models pairwise interactions between positions in a sequence. Standard (dense) self-attention computes attention weights for every pair of tokens, which gives it flexibility and strong empirical performance. However, the quadratic time and memory cost, $O(n^2)$ for a sequence of length $n$, limits applicability to long sequences. This chapter surveys the principal algorithmic and architectural strategies developed to reduce that cost and enable very long contexts. We focus on patterns that keep attention tractable while preserving the model’s ability to capture relevant long‑range dependencies: windowed/local attention and sliding implementations, global and routing tokens and hierarchical attention, low‑rank and sketching approximations, locality‑sensitive hashing (LSH) and related approximate nearest neighbor methods, memory and compression mechanisms (summarization, key/value caching), and the practical tradeoffs among accuracy, speed, and memory.

# Windowed/local attention and sliding window implementations

Windowed or local attention restricts attention computation to a fixed-size neighborhood around each token rather than the entire sequence. If each token attends only to at most $w$ neighboring tokens, the computation and memory drop from $O(n^2)$ to $O(n w)$. The simplest form is a symmetrical window: token $i$ attends to positions $j$ with $|i-j| \le k$ so $w = 2k+1$. Intuitively, this leverages the observation that many dependencies in language and other modalities are local: words and features often require context from nearby elements.

Sliding window implementations process the sequence in blocks (or chunks) and compute attention locally while maintaining overlap (a “halo”) between adjacent blocks to cover boundary interactions. Concretely, split the sequence into nonoverlapping blocks of length $b$ and allow attention within each block and additionally to a fixed number of tokens from neighboring blocks. Overlap can be implemented by extending each block’s input with $h$ tokens on the left and right (the halo). This structure supports streaming and blockwise parallelism: each block attention can be computed independently (in parallel across blocks) and so fits well to GPUs/TPUs. Block processing reduces memory footprint because inside each block we allocate attention matrices of size $b \times (b+2h)$ rather than $n \times n$.

There are several important implementation details and variations. One is causal (autoregressive) vs bidirectional attention: causal windowed attention only attends to earlier positions, which is necessary for autoregressive generation. Another is how to handle long-range dependencies that span many blocks. Pure local windows cannot capture dependencies greater than the window radius, so many models combine local windows with occasional global mechanisms (discussed later) or incorporate dilated windows that sample positions at increasing offsets (similar to dilated convolutions) to expand effective receptive field without quadratic cost.

Operational optimizations matter. Compute kernels can be organized to exploit parallel matrix multiply hardware: reshape the sequence into (num_blocks, block_size, dim) and perform batched attention, which maximizes memory locality. For streaming, chunking with rolling buffers avoids recomputing halo interactions. Attention scores and softmax normalizations are computed within each block, which avoids global scalability issues but requires careful numerical stability when using mixed precision.

Windowed attention often provides strong empirical results for tasks dominated by local structure (speech, vision patches, many language tasks). But its inductive bias limits performance when the task requires arbitrary long-range information; hence it is typically combined with mechanisms that allow selective nonlocal interactions.

# Global tokens, routing tokens, and hierarchical attention

Global tokens and routing tokens are mechanisms that allow a subset of positions to exchange information globally, enabling long-range communication without full dense attention. A global token is a learned or designated token that attends to the entire sequence and is attended to by the entire sequence. This creates a “bottleneck” channel through which distant tokens can communicate by writing to and reading from the global token. The computation cost becomes $O(n g)$ where $g$ is the number of global tokens (often small), plus the local or blockwise cost. The Intuition: instead of all-to-all communication, have a few shared nodes that aggregate and redistribute information.

Routing tokens generalize this idea: multiple routing tokens are responsible for different parts of the sequence or different types of information. For instance, in models like BigBird, a small set of “global” tokens may represent special items (e.g., [CLS], [SEP], or learned summary tokens) that attend broadly. Routing can also be dynamic: tokens can be assigned to clusters each layer, and only attend to their cluster centers and local neighbors. This reduces attention to a mix of local and cluster-based interactions.

Hierarchical attention explicitly constructs layers or stages operating at different resolutions. A common pattern is to build local attention within fine-grained blocks, then compute summaries for each block (via pooling, learned transforms, or a small attention network) and run a global attention on those summaries. The global stage operates on a much smaller sequence length ($\approx n/b$), so $O((n/b)^2)$ cost replaces $O(n^2)$ global interactions. This multi-scale organization resembles classical encoder hierarchies: local context is aggregated into mid-level representations, which then interact globally. During decoding or output reconstruction, information can be propagated back from coarse summaries to fine tokens.

Hierarchical methods introduce design choices: how to pool or summarize (mean pooling, learned attention, convolutional downsampling), how many hierarchical stages, and how to route information downward again. The tradeoff is between preserving fine-grained detail vs compressing aggressively to save compute. Hierarchical attention is particularly effective when information has natural locality and compositional structure.

# Low-rank and sketching methods for attention approximation

Attention matrices often have structure amenable to low-rank approximations: when the attention map or the combined key/value interaction lies near a low-dimensional subspace, we can approximate it with a factorization, reducing complexity. Suppose $Q \in \mathbb{R}^{n \times d}$, $K \in \mathbb{R}^{n \times d}$, and $V \in \mathbb{R}^{n \times d_v}$. Standard attention computes softmax$(QK^\top)V$. If $QK^\top$ can be approximated by a low-rank matrix $U S V^\top$ (rank $r \ll n$), then one can compute attention via two-stage projections in $O(n r)$ rather than $O(n^2)$ operations.

Linformer is an example that projects keys and values to a lower sequence-dimension space using fixed linear maps $E_K, E_V \in \mathbb{R}^{n \times r}$ and computes attention with projected matrices, yielding $O(n r)$ complexity. More principled low-rank approximations come from Nyström methods: randomly sample a subset of columns (or use landmark points) from $QK^\top$ and use them to build a low-rank approximation. Nyströmformer demonstrates this by approximating the attention kernel via a small set of landmark tokens and using pseudoinverse operations to reconstruct a low-rank attention approximation.

Sketching methods use randomized linear transforms (random projections, CountSketch, etc.) to compress $K$ and $V$ into sketches that preserve essential geometry with probabilistic guarantees. The core idea is to compute $S K$ and $S V$ for a random sketching matrix $S \in \mathbb{R}^{r \times n}$ where $r \ll n$, and then compute attention with $(Q (K^\top S^\top)) (S V)$ or similar constructs. Sketching preserves inner products within bounded error by Johnson-Lindenstrauss–style results, enabling approximate attention at reduced cost.

These low-rank and sketching methods often come with theoretical approximation bounds (error scales with singular spectrum decay or sketch size), and they are most effective when the attention matrix has rapid spectral decay. When attention truly requires many degrees of freedom (high effective rank), aggressive low-rank approximations will degrade accuracy.

# LSH attention and other approximate nearest neighbor approaches

Locality‑sensitive hashing (LSH) provides a route to reduce attention by restricting each query’s attention to a small set of likely relevant keys found via hashing. The key idea is to hash keys and queries into buckets so that similar items (under a chosen similarity, e.g., cosine) collide with high probability. For attention, one can bucket keys and queries separately and compute attention only within the same bucket (or a few nearest buckets), thus reducing comparisons from $n$ to about $n/b$ per query where $b$ is bucket size.

Reformer pioneered LSH attention for Transformers. It uses random projections to map vectors to hash codes, groups tokens by hash, and sorts tokens to process buckets efficiently. By using multiple hash rounds (multiple random projections), Reformer reduces the probability that a similar query and key are missed. Complexity drops roughly to $O(n \log n)$ or $O(n \sqrt{n})$ depending on implementation and bucket sizes, with greatly reduced memory. However, LSH introduces non-differentiability and requires careful engineering to make it stable and performant. Reformer also used reversible layers and chunked feedforward nets to reduce memory further.

Other approximate nearest neighbor (ANN) approaches apply locality-aware data structures (k-d trees, product quantization) or learned routing to find top candidate keys for each query. The common pattern is two-stage: quickly propose a small set of candidate keys for each query via ANN, then compute exact attention (softmax and weighted sum) over these candidates. ANN methods are particularly suitable when attention is sparse and dominated by a few top keys; they can be combined with reranking and multi-probe strategies to increase recall.

Limitations include hashing variance (possible misses), difficulties with dynamic queries across training, and hardware inefficiencies due to irregular memory access patterns. In practice, LSH and ANN approaches excel when interactions are highly local in representation space (i.e., few relevant keys per query) and where slight approximation errors are acceptable.

# Memory/compression mechanisms: summarization, key/value caching

Memory mechanisms augment Transformers with external or internal storage that persists information across positions or time. Key/value caching is the simplest and most commonly used memory: during autoregressive generation, keys and values from past tokens are cached so that at step $t$ the model only needs to compute attention between the current query and cached keys/values, avoiding recomputation. This reduces compute per step from $O(t)$ to $O(t)$ anyway—well, caching makes repeated attention feasible, and efficient kv-cache implementations avoid recomputing earlier QK products. For very long contexts, naive kv-cache still requires $O(n)$ memory and $O(n)$ per-query attention, so we often combine caching with compression or selective retention.

Summarization compresses blocks of tokens into fixed-size vectors (memory slots). After processing a window, summarize it by pooling or a small encoder into $m$ memory slots, and discard the detailed tokens. Subsequent layers or blocks attend to these summary slots, which capture salient information. Learned compression strategies (e.g., using attention to choose what to write to memory) are more flexible: the model learns what to retain for future use. Differentiable read/write interfaces allow end-to-end training.

Long-range memory architectures also borrow from retrieval systems: maintain an index of past key/value summaries and fetch relevant entries based on a query. Retrieval-augmented attention finds a small set of memory items relevant to the current query and attends to them. This blends ideas from ANN methods and memory compression: large histories are indexed and accessed sparsely.

Another approach uses lossy compression via transforms. For example, perform a learned linear map (or PCA-like projection) on a block of keys/values, store only the top $r$ components, and reconstruct approximate keys when required. This reduces memory from $O(n d)$ to $O((n/b) r d)$ if summarizing every block of size $b$ into $r$ components. There is a tradeoff: aggressive compression can erase fine details needed later.

Persistent memory slots (fixed-size learned vectors that persist across sequence positions) act as global scratchpads. Models like Transformer-XL use segment-level recurrence: each segment caches the previous segment’s hidden states as extended context; the model attends to them but gradients do not flow across segments in the same way, which stabilizes training. Combining segment recurrence with local windows and global summaries yields scalable architectures that retain long-term coherence.

# Practical tradeoffs: accuracy vs speed vs memory

Designing an attention scheme requires balancing three primary axes: accuracy (task performance), speed (latency and throughput), and memory (peak and persistent storage). No single method dominates across all tasks and regimes; rather, suitability depends on data structure, hardware, and application constraints.

Accuracy: Dense attention is a strong baseline because it imposes minimal restrictions on interactions. Sparse methods (local windows, LSH, low-rank) reduce expressivity and can harm performance if the approximations miss important dependencies. For tasks where long-range, global interactions are essential (e.g., document-level reasoning, code understanding across tens of thousands of tokens), aggressive sparsity or low-rank approximations may degrade results unless compensated by global tokens, memory, or hierarchical stages that retain critical information. Methods that offer theoretical approximation guarantees (e.g., sketching with JL bounds, Nyström with spectral error bounds) are often preferable when predictable degradation is required.

Speed: Windowed attention and blockwise implementations yield straightforward speedups and map well to GPU/TPU hardware via batched dense matrix multiplications. LSH and ANN methods can reduce asymptotic complexity but may suffer from irregular memory access and sorting overheads; their speed advantage often emerges for very long sequences where savings in pairwise comparisons dominate overheads. Linearized attention (kernel methods) can yield $O(n)$ time per layer, which is attractive for streaming and constant-latency applications. However, constant factors and numerical stability (softmax guarantees) matter: kernelized linear attention replaces softmax with kernels and normalization tricks that can have different convergence behaviors.

Memory: Peak memory during training is dominated by storing attention weights and intermediate activations. Blockwise methods reduce peak memory since attention is computed in small blocks. Kv-caching reduces recomputation during generation but increases memory for stored keys and values; compression reduces that but at the cost of information loss. Tradeoffs may differ between training and inference: some methods (e.g., reversible layers, gradient checkpointing) trade compute for memory during training but are less relevant at inference time.

Implementation and hardware considerations: Modern accelerators favor dense, regular computation. Methods that express computation as batched GEMMs (windowed attention, hierarchical pooling with dense global attention on summaries) often achieve better throughput than theoretically faster but irregular algorithms. Also, batch sizes, parallelism across sequences, and memory bandwidth constraints influence which technique is optimal.

Empirical tuning: In practice, hybrid architectures are common: windowed attention for most layers, a few global tokens to allow cross-window communication, and a small set of hierarchical summary layers. Tuning window sizes, number of global tokens, compression ratio, and hash parameters involves validation on downstream tasks. Profiling with realistic sequence lengths and deployment hardware is essential: a method that is fast on paper may be slower due to memory fragmentation or communication overhead.

Conclusion

Scaling attention to long sequences requires a toolbox of complementary methods: local windows and sliding blocks for efficient dense computation on neighborhoods; global/routing tokens and hierarchical structures to enable sparse but powerful long-range communication; low-rank and sketching approximations when attention matrices are compressible; LSH and ANN methods to find a small candidate set of relevant keys; and memory/compression mechanisms to summarize and persist information across time. The best practical systems usually mix several techniques to match task demands and hardware realities. Understanding the assumptions and limits (spectral decay, locality in representation space, tolerance to approximation errors) is crucial when selecting or designing an efficient attention mechanism for long-sequence problems.
