### **Chapter 7: Modeling Preferences and Rankings**

**Introduction**

In many real-world scenarios, we are less concerned with an absolute measure of an item's quality (a *cardinal* value, like a 5-star rating) and more interested in its quality relative to other items (an *ordinal* preference). Which search result is most relevant? Which chess player is stronger? Which product will a customer choose from a list of options? These questions are fundamental to search engines, recommendation systems, competitive sports, and behavioral economics.

This chapter introduces a class of models designed to answer such questions by learning latent "scores" or "strengths" for a set of items based on observed outcomes of comparisons. We will begin with the simplest case—pairwise comparisons—and build towards more complex models for full rankings. Along the way, we will explore the deep connection between these preference models and standard machine learning classification, and we will confront a subtle but critical issue: what exactly can be learned from preference data?

**Prerequisites:** Familiarity with multi-variable calculus, the sigmoid function, gradient-based optimization, and the principle of Maximum Likelihood Estimation (MLE).

#### **7.1 The Bradley–Terry Model: From Pairwise Wins to Latent Strengths**

The simplest form of preference data is the pairwise comparison: given two items, `i` and `j`, we observe that `i` was preferred over `j`. This could be a chess match where player `i` defeated player `j`, or an A/B test where a user clicked on ad `i` instead of ad `j`. The **Bradley–Terry (BT) model**, developed in the 1950s, provides an elegant framework for this scenario.

The core assumption of the BT model is that each item `i` in a universe of items possesses a latent, real-valued score, which we will denote as $s_i$. This score represents its intrinsic strength, quality, or utility. A higher score implies a stronger item.

When items `i` and `j` are compared, the outcome is probabilistic. The model posits that the probability of `i` being preferred over `j` (denoted $P(i \succ j)$) is a function of the *difference* in their scores. A natural choice for modeling probabilities, which must lie in the range $[0, 1]$, is the logistic sigmoid function, $\sigma(z) = \frac{1}{1 + e^{-z}}$.

The Bradley–Terry model is thus defined as:

$$
P(i \succ j) = \sigma(s_i - s_j) = \frac{1}{1 + e^{-(s_i - s_j)}}
$$

Let's unpack the properties of this formulation:

1.  **Dependence on Differences:** The probability depends only on the difference $s_i - s_j$, not on the absolute values of $s_i$ and $s_j$. If two players have scores of 10 and 8, the probability of the first winning is $\sigma(2)$. If their scores were 1 and -1, the probability would be exactly the same, $\sigma(2)$. This captures the intuitive idea that in a direct comparison, only relative strength matters.
2.  **Complementary Probability:** The probability of `j` being preferred over `i` is given by:
    $$
    P(j \succ i) = \sigma(s_j - s_i) = \frac{1}{1 + e^{-(s_j - s_i)}} = \frac{1}{1 + e^{(s_i - s_j)}}
    $$
    A key property of the sigmoid function is that $\sigma(z) + \sigma(-z) = 1$. Therefore, $P(i \succ j) + P(j \succ i) = 1$, which is a necessary condition for a two-outcome probabilistic model.
3.  **No Preference:** If two items have equal scores, $s_i = s_j$, then $P(i \succ j) = \sigma(0) = 0.5$. This corresponds to a coin toss, representing pure chance when strengths are equal.

An equivalent and historically common formulation uses positive-valued strengths, $\lambda_i = e^{s_i}$. In this form, the probability is written as:

$$
P(i \succ j) = \frac{e^{s_i}}{e^{s_i} + e^{s_j}} = \frac{\lambda_i}{\lambda_i + \lambda_j}
$$

You can verify with simple algebra that these two forms are identical. The score-difference formulation, however, makes the connection to modern machine learning more explicit.

#### **7.2 Learning from Data: A Binary Classification Perspective**

Now that we have a model, how do we estimate the scores $s_1, s_2, \dots, s_N$ for all $N$ items? We do this by observing a dataset of outcomes.

Suppose our dataset $\mathcal{D}$ consists of $M$ independent pairwise comparisons. Each observation is a pair $(y_w, y_l)$, where $y_w$ is the item that won and $y_l$ is the item that lost. For example, $\mathcal{D} = \{(i_1, j_1), (i_2, j_2), \dots, (i_M, j_M)\}$, where in the $k$-th observation, item $i_k$ was preferred over $j_k$.

We can find the optimal scores $\mathbf{s} = (s_1, \dots, s_N)$ using the principle of **Maximum Likelihood Estimation (MLE)**. We want to find the scores that make the observed data most probable. The likelihood of the entire dataset, assuming independence, is the product of the probabilities of each individual observation:

$$
\mathcal{L}(\mathbf{s} | \mathcal{D}) = \prod_{k=1}^{M} P(i_k \succ j_k) = \prod_{k=1}^{M} \sigma(s_{i_k} - s_{j_k})
$$

As is standard in machine learning, we work with the log-likelihood for numerical stability and mathematical convenience:

$$
\log \mathcal{L}(\mathbf{s} | \mathcal{D}) = \sum_{k=1}^{M} \log \sigma(s_{i_k} - s_{j_k})
$$

Our goal is to find the vector of scores $\mathbf{s}$ that maximizes this function. Notice the structure of this objective. It is identical to the log-likelihood for a **binary logistic regression** model. For each observation $(i_k, j_k)$, we can think of the "feature" as a sparse vector with a `+1` at the index for $i_k$ and a `-1` at the index for $j_k$. The model's prediction (the logit) is the score difference $s_{i_k} - s_{j_k}$, and the "label" is always 1 (since we observe $i_k$ winning). Maximizing the log-likelihood is equivalent to minimizing the negative log-likelihood, which is the familiar **binary cross-entropy loss**.

Therefore, we can learn the Bradley-Terry scores by simply setting up a binary classification problem and using an optimization algorithm like **gradient descent** (or more sophisticated variants like Adam or L-BFGS) to find the parameters $\mathbf{s}$ that maximize the log-likelihood.

#### **7.3 The Plackett–Luce Model: Generalizing to Rankings**

The Bradley-Terry model is powerful but limited to pairs. What if our data consists of full or partial rankings? For example, a user might be presented with five products, and we observe the one they click on. Or, in a race, we observe the finishing order of all participants. The **Plackett–Luce (PL) model** extends the core idea of latent scores to handle these listwise scenarios.

The PL model describes a generative process for constructing a ranking over a set of items $C$. Imagine drawing the first-place item from the set $C$. The probability that item $i \in C$ is chosen first is proportional to its positive strength, $e^{s_i}$. This is a direct application of the **softmax function** over the scores of the items in $C$:

$$
P(i \text{ is chosen first from } C) = \frac{e^{s_i}}{\sum_{j \in C} e^{s_j}}
$$

To generate a full ranking $\pi = (y_1, y_2, \dots, y_m)$ of the items in $C$, the model proceeds sequentially:
1.  The first item, $y_1$, is chosen from the full set $C$ with probability $P(y_1 | C) = \frac{e^{s_{y_1}}}{\sum_{j \in C} e^{s_j}}$.
2.  The second item, $y_2$, is chosen from the remaining set $C \setminus \{y_1\}$ with probability $P(y_2 | C \setminus \{y_1\}) = \frac{e^{s_{y_2}}}{\sum_{j \in C \setminus \{y_1\}} e^{s_j}}$.
3.  This process continues until all items are ranked.

The probability of observing the specific ranking $\pi$ is the product of these sequential choices:

$$
P(\pi | \mathbf{s}) = \prod_{k=1}^{m} P(y_k | C \setminus \{y_1, \dots, y_{k-1}\}) = \prod_{k=1}^{m} \frac{e^{s_{y_k}}}{\sum_{j=k}^{m} e^{s_{y_j}}}
$$

**Connection to Bradley-Terry:** The Plackett-Luce model is a strict generalization of Bradley-Terry. Consider a set $C = \{i, j\}$. The PL probability of the ranking $(i, j)$ is:

$$
P((i, j)) = P(i \text{ chosen from } \{i, j\}) \times P(j \text{ chosen from } \{j\}) = \left( \frac{e^{s_i}}{e^{s_i} + e^{s_j}} \right) \times \left( \frac{e^{s_j}}{e^{s_j}} \right) = \frac{e^{s_i}}{e^{s_i} + e^{s_j}}
$$

This is exactly the exponential form of the Bradley-Terry probability $P(i \succ j)$. Thus, a pairwise win/loss dataset can be seen as a collection of rankings of length two. Learning PL scores from ranking data again proceeds via Maximum Likelihood Estimation, where the objective is the sum of the log-probabilities of all observed rankings.

#### **7.4 Identifiability and Equivalence Classes: What is Actually Learnable?**

We now arrive at a subtle but fundamentally important concept in preference modeling. As we noted in Section 7.1, the Bradley-Terry probability $P(i \succ j) = \sigma(s_i - s_j)$ is unchanged if we add a constant $c$ to all scores:

$$
\sigma((s_i + c) - (s_j + c)) = \sigma(s_i - s_j)
$$

This means that if a set of scores $\mathbf{s} = (s_1, \dots, s_N)$ is a valid solution that maximizes the likelihood of our data, then the set of scores $\mathbf{s}' = (s_1+c, \dots, s_N+c)$ is an equally valid solution for any constant $c$. The likelihood function is identical for both. The absolute level of the scores is **unidentifiable**.

This set of equivalent solutions is called an **equivalence class**. To obtain a single, unique solution, we must impose a constraint to "fix the gauge." A common constraint is to require that the scores sum to zero ($\sum s_i = 0$) or to fix one item's score to a constant (e.g., $s_1 = 0$). Optimization algorithms often implicitly find one of these solutions.

This issue becomes more profound when we introduce context. Let's say the score of an item `i` depends on some context `x` (e.g., `x` could represent the user making the choice). We might model the score as $s(i, x)$. The probability of `i` being preferred over `j` in context `x` would be:

$$
P(i \succ j | x) = \sigma(s(i, x) - s(j, x))
$$

Now, consider a model where the score is an additive combination of an item-specific term and a context-specific term, for example, $s(i, x) = f(i) + g(x)$. Here, $f(i)$ could be the intrinsic quality of the item and $g(x)$ could be a bias associated with the context (e.g., a user's general tendency to engage). Let's look at the score difference:

$$
s(i, x) - s(j, x) = (f(i) + g(x)) - (f(j) + g(x)) = f(i) - f(j)
$$

The context-dependent term $g(x)$ cancels out completely! This means that from pairwise comparison data alone, it is **impossible** to learn the function $g(x)$. Any function $g(x)$ will produce the exact same likelihood. The models defined by $s(i, x)$ and $s(i, x) + g(x)$ are observationally equivalent and belong to the same equivalence class.

This is a critical insight. It tells us that the structure of our data limits what we can learn. If our data only contains relative judgments (`i` vs. `j`), we can only learn quantities that affect those relative judgments. We cannot learn anything about factors that are constant across the items being compared within a given context. To learn a context bias like $g(x)$, we would need a different kind of data, such as observations of an absolute outcome (e.g., whether a user clicked on a single displayed item or not).

**Summary**

This chapter introduced the foundational models for learning from preference and ranking data.

*   The **Bradley–Terry model** offers a simple yet powerful way to infer latent scores from pairwise comparisons, framing the learning problem as a binary classification task.
*   The **Plackett–Luce model** generalizes this framework to handle full or partial rankings, using a sequential choice process based on the softmax function.
*   Both models are typically learned by maximizing the log-likelihood of the observed data using gradient-based optimization.
*   Crucially, we saw that these models have inherent **identifiability** issues. Scores are only determined up to a constant shift. More generally, any factor that is constant across the items within a single comparison (an additive function of context) cannot be learned from comparison data alone.
