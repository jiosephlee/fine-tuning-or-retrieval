raw_knowledge_statement: In recent years, the field of AI has seen a rapid growth in the size and capabilities of Large Language Models (LLMs).

----- Row 1 -----
raw_knowledge_statement: These models have demonstrated remarkable performance in a wide range of natural language processing tasks, but their increasing size has posed challenges for deployment and raised concerns about their environmental and economic impact due to high energy consumption.

----- Row 1 -----
raw_knowledge_statement: One approach to address these challenges is to use post-training quantization to create low-bit models for inference~\cite{smoothquant, gptq, quip, quip_sharp}.

----- Row 1 -----
raw_knowledge_statement: This technique reduces the precision of weights and activations, significantly reducing the memory and computational requirements of LLMs.

----- Row 1 -----
raw_knowledge_statement: The trend has been to move from 16 bits to lower bits, such as 4-bit variants~\cite{gptq, awq}.

----- Row 1 -----
raw_knowledge_statement: However, post-training quantization is sub-optimal, even though it is widely used in industry LLMs.

----- Row 1 -----
raw_knowledge_statement: Recent work on 1-bit model architectures, such as BitNet~\cite{bitnet}, presents a promising direction for reducing the cost of LLMs while maintaining their performance.

----- Row 1 -----
raw_knowledge_statement: Vanilla LLMs are in 16-bit floating values (i.e., FP16 or BF16), and the bulk of any LLMs is matrix multiplication.

----- Row 1 -----
raw_knowledge_statement: Therefore, the major computation cost comes from the floating-point addition and multiplication operations.

----- Row 1 -----
raw_knowledge_statement: In contrast, the matrix multiplication of BitNet only involves integer addition, which saves orders of energy cost for LLMs.

----- Row 1 -----
raw_knowledge_statement: As the fundamental limit to compute performance in many chips is power, the energy savings can also be translated into faster computation.

----- Row 1 -----
raw_knowledge_statement: In addition to computation, the process of transferring model parameters from DRAM to the memory of an on-chip accelerator (e.g., SRAM) can be expensive during inference.

----- Row 1 -----
raw_knowledge_statement: There have been attempts to enlarge SRAM to improve throughput, but this introduces significantly higher costs than DRAM.

----- Row 1 -----
raw_knowledge_statement: Compared to full-precision models, 1-bit LLMs have a much lower memory footprint from both a capacity and bandwidth standpoint.

----- Row 1 -----
raw_knowledge_statement: This can significantly reduce the cost and time of loading weights from DRAM, leading to faster and more efficient inference.

----- Row 1 -----
raw_knowledge_statement: In this work, we introduce a significant 1-bit LLM variant called \textbf{\text{BitNet b1.58}}, where every parameter is ternary, taking on values of \{-1, 0, 1\}.

----- Row 1 -----
raw_knowledge_statement: We have added an additional value of 0 to the original 1-bit BitNet, resulting in 1.58 bits in the binary system.

----- Row 1 -----
raw_knowledge_statement: Additionally, it has the same energy consumption as the original 1-bit BitNet and is much more efficient in terms of memory consumption, throughput and latency compared to FP16 LLM baselines.

----- Row 1 -----
raw_knowledge_statement: Firstly, its modeling capability is stronger due to its explicit support for feature filtering, made possible by the inclusion of 0 in the model weights, which can significantly improve the performance of 1-bit LLMs.

----- Row 2 -----
raw_knowledge_statement: \text{BitNet b1.58} is based on the BitNet architecture, which is a Transformer that replaces \emph{nn.Linear} with \emph{BitLinear}.

----- Row 2 -----
raw_knowledge_statement: It is trained from scratch, with 1.58-bit weights and 8-bit activations.

----- Row 2 -----
raw_knowledge_statement: Compared to the original BitNet, it introduces some modifications that we summarize below.

----- Row 2 -----
raw_knowledge_statement: To constrain the weights to -1, 0, or +1, we adopt an \emph{absmean} quantization function.

----- Row 2 -----
raw_knowledge_statement: It first scales the weight matrix by its average absolute value, and then round each value to the nearest integer among \{-1, 0, +1\}:

\begin{equation}
    \widetilde{W} = \mathrm{RoundClip}(\frac{W}{\gamma + \epsilon}, -1, 1),
\end{equation}

\begin{equation}
    \mathrm{RoundClip}(x, a, b) = \max(a, \min(b, \mathrm{round}(x))),
\end{equation}

\begin{equation}
    \gamma = \frac{1}{nm}\sum_{ij} |W_{ij}|.
\end{equation}

----- Row 2 -----
raw_knowledge_statement: The quantization function for activations follows the same implementation in BitNet, except that we do not scale the activations before the non-linear functions to the range $[0, Q_b]$.

----- Row 2 -----
raw_knowledge_statement: Instead, the activations are all scaled to $[-Q_b, Q_b]$ per token to get rid of the zero-point quantization.

----- Row 2 -----
raw_knowledge_statement: This is more convenient and simple for both implementation and system-level optimization, while introduces negligible effects to the performance in our experiments.

----- Row 2 -----
raw_knowledge_statement: The architecture of LLaMA~\cite{llama, llama2} has been the de-facto backbone for open-source LLMs.

----- Row 2 -----
raw_knowledge_statement: To embrace the open-source community, our design of \text{BitNet b1.58} adopts the LLaMA-alike components.

----- Row 2 -----
raw_knowledge_statement: Specifically, it uses RMSNorm~\cite{rmsnorm}, SwiGLU~\cite{swiglu}, rotary embedding~\cite{rope}, and removes all biases.
