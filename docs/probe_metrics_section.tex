\textbf{Metrics.} We evaluate the model's performance on our probes throughout training:
\begin{itemize}
[itemsep=1pt, topsep=0pt]
    \item \textbf{Log-Probability}: For cloze probes, we measure the joint log-probability assigned to the ground-truth target span.
    \item \textbf{Target Rank}: We measure the vocabulary rank of the correct target token under teacher forcing. For multi-token targets, we report the worst rank across the span; lower is better.
    \item \textbf{Multiple-Choice Accuracy}: For MCQ probes, we use 5-shot prompting with general-knowledge examples, constrain decoding to the answer choices, and report whether the correct choice receives the highest logit.
\end{itemize}
