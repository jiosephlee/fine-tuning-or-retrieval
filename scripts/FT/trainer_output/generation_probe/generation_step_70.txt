The reward function is not public, so the only way to learn the reward function is to train a policy that optimizes the reward function. However, the policy is optimized by maximizing the sum of rewards, which is a non-convex objective. The authors propose a new objective, called the direct preference optimization (DPO), which is a convex objective that still optimizes the reward function. The DPO objective is the sum of weighted concave functions. Each concave function is the negative of the log of the reward predicted by a certain class of models called reward models. The authors show that the DPO objective can be optimized using a simple conjugate gradient algorithm. In addition, the DPO objective has a simple interpretation: it is the maximum likelihood objective for a certain class of models. Finally, the authors show that the DPO objective can be efficiently optimized using a certain class of reward models called reward function approximators (RFA). An RFA is a function that can be approximated by a neural network with a certain number of layers and a certain number of neurons in each layer.
